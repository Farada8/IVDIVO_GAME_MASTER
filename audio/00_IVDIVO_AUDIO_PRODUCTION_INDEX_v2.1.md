## Universal pipeline

`LOCKED STORY/TEXT → AUTHORITY RESTORE → DELIVERY MODE → PROJECT OVERLAY → STORY AUDIO ANALYSIS → SCENE AUDIO DRAMATURGY → CHARACTER/RELATIONSHIP CONTEXT → ACTOR DIRECTION → PAUSE/LISTENING/BREATH DESIGN → BLOCKING/PROXIMITY/SPATIAL PLAN → HUMAN MICROTEXTURE + FOLEY CAUSALITY → AMBIENCE/WORLD SOUND → EMOTION SOUND DESIGN → MUSIC DRAMATURGY → PROVIDER COMPILATION → CLEAN DIALOGUE/ASSETS → TAKE LOCK → EDIT DIRECTOR → TIMELINE RESOLUTION → SPATIAL AUTOMIX → MASTERING → TECHNICAL + HUMAN QC → SELECTIVE REPAIR → MASTER LOCK`.

## Core laws

- STORY FIRST.
- CHARACTER SECOND.
- LISTENER COMPREHENSION THIRD.
- SOUND SERVES CAUSALITY, CHARACTER, PLACE OR EMOTION.
- SILENCE IS AUTHORED.
- HUMAN MICROTEXTURE IS CAUSAL, NOT DECORATIVE.
- MUSIC NEVER REPLACES DRAMA.
- CRITICAL INFORMATION MUST SURVIVE MONO/PHONE PLAYBACK.
- PROVIDER OUTPUT IS MATERIAL, NOT AUTHORITY.
- GOOD TAKES/ASSETS LOCK; repair the smallest failing layer only.

## Production modes

- NARRATED AUDIOBOOK
- MULTI-VOICE AUDIOBOOK
- DRAMATIZED AUDIOBOOK
- FULL AUDIO DRAMA

The same universal system applies to all modes. Project overlay and density settings change; core production law does not.
