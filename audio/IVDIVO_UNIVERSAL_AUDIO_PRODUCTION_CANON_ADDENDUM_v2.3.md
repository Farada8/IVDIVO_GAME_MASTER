# IVDIVO — UNIVERSAL AUDIO PRODUCTION CANON ADDENDUM v2.3

**Date:** 2026-08-20  
**Status:** CANON / UNIVERSAL AUDIO PRODUCTION STANDARD — ADDITIVE AUTHORITY  
**Scope:** all IVDIVO audiobooks, dramatized audiobooks, audio dramas, doramas, narrated fiction, serial audio, pilots, trailers and audio-first productions.

This document extends v2.1 + v2.2. It does not replace locked story/project canon. Where more specific and non-conflicting, v2.3 controls the audio-production layer.

## 0. Performance is response
A spoken line is not an isolated clip. It is a response to heard information, partner action, environment, body state and expectation.

Every important performance beat must define:
`HEARD_EVENT / RESPONSE_IMPULSE / LISTENING_STATE / ENTRY_TRIGGER / REPLY_MODE / STATE_OUT`.

If the actor/TTS block cannot explain what triggered the line, the block is under-directed.

## 1. Whole-scene context law
A performer may receive only the local text being rendered, but directing logic must know the whole scene.

Every provider block may receive a concise `SCENE_CONTEXT_PACKET` containing:
- immediate scene objective;
- partner objective/tactic when relevant;
- previous event;
- current relationship/status;
- current physical situation;
- expected response opportunity.

Do not leak future mystery answers or later-book knowledge.

## 2. Subtext-to-behavior law
Raw psychology is not provider direction.

Compile:
`SUBTEXT → PLAYABLE BEHAVIOR → PROVIDER-SAFE DIRECTION`.

Prefer behaviors such as:
- quicker/slower response;
- lower projection;
- restrained phrase ending;
- off-axis orientation;
- controlled breath;
- answer-before-thinking;
- withheld emphasis;
- step closer/away;
- failed interruption;
- refusal to answer.

Reject vague directions such as `be emotional`, `be sexy`, `be mysterious`, `be cinematic` when a playable behavior is available.

## 3. Conversational rhythm law
Natural dialogue may use:
`PAUSE / REPLY_LATENCY / INTERRUPTION / OVERLAP / STEPPED-ON-LINE / MICRO-REACTION / SMALL VOCAL EMBELLISHMENT`.

These are story tools, not quotas. Random fillers are forbidden.

Locked-text productions may use nonverbal reactions and editorial timing without changing spoken wording. Any verbal ad-lib requires delivery-mode authorization.

## 4. Foley is performed
Foley is an acted physical event, not only a selected asset.

Meaningful Foley cues must carry, when applicable:
`PERFORMER_INTENT / CHARACTER_WEIGHT / ACTION_TEMPO / CONTACT_FORCE / MATERIAL_RESPONSE / SYNC_TOLERANCE`.

The same door, chair, coat, glass or cutlery may sound differently because characters handle objects differently. Characterization is allowed only when the action supports it.

## 5. Food / drink embodied-action law
Eating and drinking scenes must remain physically coherent.

Possible state chain:
`PICKUP → UTENSIL/CONTAINER → BITE_OR_SIP → MOUTH_STATE → CHEW_OR_LIQUID → SWALLOW → BREATH_RESET → SPEECH → OBJECT_RETURN`.

Do not render every stage automatically.

When audible eating is retained, performance must account for body state through:
`MOUTH_STATE / SPEECH_ALLOWED / SPEECH_IMPAIRMENT / SWALLOW_BEFORE_LINE / BREATH_RESET / UTENSIL_STATE`.

Unless explicitly required by body-horror/ASMR style, chewing and mouth textures must remain selective, brief and subordinate to character/story focus.

## 6. Microtexture salience guard
Close human textures can become disproportionately loud and repellent on headphones.

Every intimate microtexture may define:
`REPULSION_RISK / FATIGUE_RISK / HEADPHONE_GAIN_LIMIT / REPETITION_LIMIT`.

Ordinary realism should usually be perceived as embodied presence, not as an object of attention.

## 7. Physical-state continuity law
Voice performance must inherit current body state.

Relevant states include:
`EATING / DRINKING / WALKING / RUNNING / LYING_DOWN / CRYING_RECOVERY / COLD / EXHAUSTED / INJURED / WHISPER_DISTANCE / PHONE_DEVICE / MASKED_FACE / OTHER`.

If the provider cannot sustain the state naturally, use the smallest responsible combination of:
`ISOLATED_VOCALIZATION / EDIT / PERSPECTIVE_PROCESSING / SELECTIVE_RERENDER`.

## 8. Microphone proximity is acting
Mic distance and room exposure affect perceived intimacy, openness and realism.

`MIC_DISTANCE` and `ACOUSTIC_DISTANCE` should agree by default.
If they intentionally disagree, document the stylization.

Moving a character away must not be simulated by pan alone. Use relevant changes in direct/reverberant ratio, spectral distance, level, occlusion and early-reflection pattern.

## 9. Listener point-of-audition law
Every scene using spatial staging must define where the listener is acoustically located.

Fields:
`LISTENER_POSITION / LISTENER_ORIENTATION / POV_MODE / HEAD_RELATIVE_POSITIONS / MOVEMENT_RELATIVE_TO_LISTENER`.

POV modes:
`OBJECTIVE_SCENE / CHARACTER_SUBJECTIVE / DEVICE_MEDIATED / TRANSITIONAL`.

Ear-specific dialogue is allowed only when geography, intimacy, technology or subjective POV earns it. Critical meaning remains mono-safe.

## 10. Acoustics communicate space
Room tone, resonance, reverberation, occlusion and perspective are story information.

Every scene requiring spatial credibility uses one coherent acoustic passport across dialogue, relevant Foley and SFX.

Do not make dialogue sound inside a room while Foley sounds pasted on top of the mix.

## 11. Director-as-conductor law
Voice, Foley, SFX, ambience, music, silence and mix automation are one coordinated dramatic system.

No department optimizes itself independently.

At each beat, the Audio Director decides:
`FOCUS_OWNER / SUPPORT / BACKGROUND / SUPPRESS / TRANSITION / AFTERMATH`.

## 12. Mix action score law
After alignment resolves real timing, construct a beat-linked mix action score.

Possible moves:
`LEVEL / MUTE_OR_REVEAL / PAN / WIDTH / DEPTH / REVERB / EQ / FILTER / DUCKING / OCCLUSION / MUSIC_INTENSITY / DENSITY`.

Each move requires a dramatic reason and semantic anchor.

## 13. Five mix domains audit
When layers compete, diagnose the conflict across:
`TIME / FREQUENCY / LEVEL / STEREO / DEPTH`.

Solve the actual conflict. Do not default to raising the louder element.

## 14. Mix-objective gate
Beyond technical compliance, premium mix review must test:
- `MOOD` — does the mix preserve intended emotional climate?
- `BALANCE` — are priorities correct?
- `DEFINITION` — can required elements be distinguished?
- `INTEREST` — does the mix evolve with story without becoming restless?

These are subordinate to story truth and listener comprehension.

## 15. Punctuation is not acting
Punctuation may guide language, but provider timing must follow thought, intention, listening, action and scene rhythm.

Exact-text preservation does not require robotic punctuation timing.

If punctuation itself is story-significant or legally/textually protected, preserve its semantic effect.

## 16. Performance variation law
Additional takes are hypotheses, not random rerolls.

Examples:
`TAKE_A = baseline`
`TAKE_B = quicker defensive response`
`TAKE_C = less projected, more withheld`

Only one or two variables should change per diagnostic take when possible.

## 17. Edit-before-rerender extension
Before regenerating a performance, test whether the defect is editorial:
`TRIM / PAUSE / ROOM_TONE_BRIDGE / OVERLAP_SHIFT / BREATH_EDIT / CLIP_GAIN / CROSSFADE / PERSPECTIVE_AUTOMATION`.

Rerender when acting, pronunciation, voice identity, source text or irreparable synthesis artifact is the real failure.

## 18. Current universal pipeline v2.3
`LOCKED STORY → LISTENER CONTRACT → DRAMATIC FORCE MAP → WHOLE-SCENE CONTEXT → AUDIO DRAMATURGY → RESPONSE/PERFORMANCE STATE → BLOCKING + LISTENER POINT OF AUDITION → PAUSE/BREATH/LISTENING → AUDIO COMPOSITION → FOLEY PERFORMANCE + MICROTEXTURE + SFX + AMBIENCE → MUSIC DRAMATURGY → PROVIDER-SAFE PERFORMANCE COMPILATION → DIAGNOSTIC TAKES → EDIT → RESOLVED TIMELINE → MIX ACTION SCORE → NARRATIVE AUTOMIX → MASTER → SOUND/PERFORMANCE/PLAYBACK QC → HUMAN LISTEN → MASTER LOCK`.

## Acceptance
v2.3 is additive universal authority. Project overlays may specialize style, intimacy, sound density, music palette and spatial grammar, but may not weaken:
- story authority;
- performance continuity;
- physical causality;
- listener comprehension;
- mono/phone survival;
- selective sound design;
- fail-closed QC.
