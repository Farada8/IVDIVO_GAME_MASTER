## Three-system production architecture
`SYSTEM A — PERFORMANCE ENGINE`
→ `SYSTEM B — MICROPHONE CHOREOGRAPHY / VIRTUAL RADIO STAGE ENGINE`
→ `SYSTEM C — WORLD SOUND ENGINE`
→ `EDIT + ALIGNMENT`
→ `MIX + MASTER + QC`.

System B is not ordinary pan automation. It owns actor position, listener point-of-audition, microphone position/pattern, body and head orientation, actor trajectories, live/dead pickup zones, near-ear staging, movement/Foley coupling and physical perspective.

## Capture modes
- `REAL_STAGE` — actors physically move around one or more microphones.
- `VIRTUAL_STAGE` — clean performances are spatially choreographed in post.
- `HYBRID_STAGE` — performance contains the physical vocal behavior; exact geometry is imposed in post. Default recommendation for premium AI drama unless real-stage rehearsal proves superior.

## Capture topologies
`MONO_CENTER_MIC / STEREO_PAIR / BINAURAL_HEAD / MULTI_MIC_ISO / VIRTUAL_BINAURAL / VIRTUAL_STEREO`.

A mono microphone may convey proximity/off-axis perspective but cannot claim true left-ear/right-ear localization.
