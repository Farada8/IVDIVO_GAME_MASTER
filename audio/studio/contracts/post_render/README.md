# IVDIVO Audio Studio — Universal Post-Render Contracts v1

**Status:** CANDIDATE / WAVE6 HARDENING. Project overlays remain authoritative for story facts, cue IDs, protected moments, acoustic values and assets.

These contracts generalize only recurring mechanisms from current Audio Studio, ROOM917 post-render engineering and Self-Improvement evidence. They do not create a second runtime.

## Contract chain

`LOCKED MASTER IDENTITY`
→ `SEMANTIC CUE LINEAGE`
→ `ACCEPTED_ALIGNMENT | LIVE_TIMELINE`
→ `CANONICAL INTERVALS`
→ `CLASSIFIER CANDIDATE`
→ `PATCH AUTHORIZATION`
→ `ASSET+RIGHTS+GAIN+HEADROOM`
→ `BOUNDED RENDER`
→ `PROJECT-NEUTRAL BYTE REGRESSION`
→ `REAL HUMAN LISTEN`
→ `SELF-IMPROVEMENT EVENT`
→ `SECOND REAL PROJECT`
→ `DOMAIN PROMOTION REVIEW`.

## Hard separations

1. Classification is not authorization.
2. Provider/request acceptance is not take acceptance.
3. File existence is not evidence PASS.
4. Semantic cue truth is not absolute timing.
5. Synthetic regression is not human listening evidence.
6. One project pilot is not domain authority.
7. Project-specific story/cue/timestamp/assets never become universal defaults.
8. Silent clipping is forbidden; insufficient headroom is HOLD.
