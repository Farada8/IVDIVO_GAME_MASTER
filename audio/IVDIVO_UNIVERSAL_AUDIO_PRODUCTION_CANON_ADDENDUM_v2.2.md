# IVDIVO — UNIVERSAL AUDIO PRODUCTION CANON ADDENDUM v2.2

**Date:** 2026-08-20  
**Status:** CANON / UNIVERSAL AUDIO PRODUCTION STANDARD — ADDITIVE AUTHORITY  
**Scope:** all IVDIVO audiobooks, dramatized audiobooks, audio dramas, doramas, narrated fiction, serial audio, pilots, trailers and audio-first productions.

This document extends v2.1. It does not replace locked project canon. Founder instruction and current project authority remain higher.

## 0. Listener-centered law
The listener is the organizing center of the production system, not the last consumer in a chain.

Every meaningful audio beat must define:
- `LISTENER_MUST_UNDERSTAND`;
- `LISTENER_MAY_FEEL`;
- `LISTENER_MUST_WAIT_FOR`;
- `FOCUS_OWNER`;
- `SUPPRESS`.

If the production element does not serve one of these functions or preserve world continuity, it is optional and should be challenged.

## 1. Four-code law
The primary dramatic codes are:
`WORDS / SOUNDS / MUSIC / SILENCE`.

Their power comes from relationship, contrast, hierarchy and timing.
No code is automatically secondary; no code may become continuous decoration by default.

## 2. Persuasive-illusion law
Audio fiction does not reproduce every sound that would exist physically. It selects enough specific audible detail to create a persuasive mental reality.

Before every Foley/SFX/microtexture cue ask:
1. Does it identify action, body, object, place, status, relationship, clue, rhythm or transition?
2. Is it the most evocative useful detail?
3. Will it blur a more important sound?
4. Will the listener misread it as plot information?

If it fails, omit it.

## 3. Human microtexture law — revised
Breaths, mouth sounds, swallowing, eating, drinking, clothing, chair/bed movement, skin/fabric contact, hair, small body shifts and similar textures may be used when physically caused and dramatically useful.

They are not an ASMR filler layer.

Required cue fields:
`CAUSE / BODY_OR_OBJECT / ACTION / STORY_FUNCTION / AUDIBILITY / PROXIMITY / DURATION / FOCUS_PRIORITY / FORBIDDEN_INTERPRETATION`.

Eating example categories may include bite, chew texture, utensil, plate, package, liquid movement, swallow, breath reset and speech impediment caused by eating. Use only the minimal combination that makes the action intelligible and character-specific.

## 4. Extended-signification guard
A sound can imply more than its physical cause.

Every important sound must carry:
- `LITERAL_MEANING`;
- `POSSIBLE_EXTENDED_MEANING`;
- `FORBIDDEN_IMPLICATIONS`.

Protect against accidental coding of:
`GUILT / ROMANCE / HORROR / SUPERNATURALITY / COMEDY / DANGER / IMPORTANCE / STATUS`.

## 5. Three-mode listening gate
Critical sounds are tested through applicable listening modes:

### CAUSAL
What does the listener believe physically caused the sound?

### CODAL
What message, word, code or signal does the listener decode?

### SONIC IDENTITY
Can the listener recognize the cue by audible qualities independent of knowing its label?

A clue sound is not locked until the required modes pass.

## 6. Dramatic-force-to-sound-map law
Do not choose sound palettes before dramatic forces are mapped.

Required order:
`STORY CHANGE → DRAMATIC FORCE CURVES → ATTENTION MAP → AUDIO COMPOSITION → ASSET CHOICE`.

Possible force curves include:
`POWER / WEAKNESS / TRUST / DESIRE / FEAR / CONTROL / KNOWLEDGE / ISOLATION / CONNECTION`.

Only project-earned curves are used.

## 7. Orchestration law
Dialogue, Foley, SFX, ambience and music are an orchestra. They must not all demand foreground simultaneously.

Per beat define:
`FOCUS_OWNER / SECONDARY_SUPPORT / BACKGROUND / MASKING_BUDGET / DENSITY / WIDTH / FREQUENCY_CONFLICT / DYNAMIC_CONFLICT`.

The mix may move focus by:
- level;
- spectral carve;
- transient control;
- reverb depth;
- width;
- panning;
- silence;
- reduction of competing layers.

## 8. Action–reaction default
A useful default is:
- physical action first carried by the action sound;
- emotional response then carried by actor reaction, silence and optionally music.

This is not an absolute formula. It exists to prevent double-scoring every event.

## 9. Actor unseen-world context
An actor/TTS performance must know what is happening around the character even if the corresponding sound is generated later.

Every render block may require:
`OFFSCREEN_AUDIO_CONTEXT / PARTNER_ACTION_CONTEXT / OBJECT_ACTION_CONTEXT / PREVIOUS_EVENT / NEXT_EXPECTED_EVENT`.

The performer should react to the story world, not to isolated text.

## 10. Intimate-performance default
Audio performance is normally smaller than stage performance.
Close listening magnifies small changes in breath, tempo, articulation, hesitation and energy.

Reject by default:
- broad projection;
- genre caricature;
- repeated ominous pauses;
- generic “sexy” or “cinematic” delivery;
- explicit emotional signalling already carried by context.

## 11. Blocking-to-microphone law
Blocking is part of acting and story.

Where geography matters, define:
`POSITION / DISTANCE_TO_PARTNER / DISTANCE_TO_MIC / HEAD_ORIENTATION / MOVEMENT_PATH / OCCLUSION / PROXIMITY_CHANGE / ENTRY_EXIT`.

Spatial processing follows body geography; it does not replace it.

## 12. Stereo / binaural / ear-specific law
Ear-specific or lateral staging may be used for intimacy, geography, point of audition, technology or clue logic.

However:
- critical information must survive mono;
- binaural effect may enhance but not own causality;
- hard-left/right dialogue is used sparingly outside story-earned moments;
- movement changes distance, direct/reverb ratio and spectral perspective, not pan alone.

## 13. SFX taxonomy law
Each non-dialogue asset has both a physical production class and a story function.

Physical class:
`HARD_EFFECT / FOLEY / BACKGROUND_AMBIENCE / ELECTRONIC_PRODUCTION_ELEMENT / DESIGNED_EFFECT`.

Story function:
`ACTION / BODY / PLACE / MATERIAL / ORIENTATION / TRANSITION / MEMORY / RELATIONSHIP / STATUS / CLUE / THREAT / COMIC / EMOTIONAL_SUPPORT`.

`CLUE_SFX` remains a protected semantic class and may use any physical production class.

## 14. Premix and stem law
Minimum release-control families:
`DIALOGUE / CLUE_SFX / SFX / FOLEY / AMBIENCE / MUSIC`.

Dense projects may add internal subgroups such as:
`FOLEY_BODY / FOLEY_OBJECT / SFX_HARD / SFX_DESIGNED / AMBIENCE_ROOM / AMBIENCE_WORLD`.

Separate treatment is required because dialogue intelligibility, music shape and effects impact need different processing logic.

Where relevant, preserve an M&E-capable path for localization/adaptation.

## 15. Narrative automation law
Static mixing is insufficient for premium dramatized production.

Automation may follow story change in:
`LEVEL / PAN / WIDTH / REVERB_SEND / DELAY / EQ / FILTER / DENSITY / DUCKING / OCCLUSION / PROXIMITY / MUSIC_INTENSITY`.

Automation must be tied to semantic anchors or resolved render timing, never invented timestamps before alignment.

## 16. Mixing-as-art law
Mixing is not only defect repair. Mix choices create attention, depth, intimacy, energy, contrast and emotional perception.

AutoMix therefore has two contracts:
1. `TECHNICAL SAFETY`;
2. `DRAMATIC INTENT PRESERVATION`.

A technically clean mix that flattens story dynamics fails.

## 17. Read-aloud / performability gate
Before source wording is changed for audio, test it aloud or through a controlled actor/TTS read.

Potential defects:
`HOMOPHONE_AMBIGUITY / OVERLONG_SYNTAX / UNPLAYABLE_PUNCTUATION / UNCLEAR_REFERENT / BREATH_IMPOSSIBILITY / TONGUE_TWIST / INFO_DENSITY`.

Repair only after proving a spoken failure and only at the smallest responsible layer.

## 18. Playback-reality law
Target listeners may be walking, driving, cooking or using phone speakers.

Every release uses relevant subsets of:
`HEADPHONES / EARBUDS / PHONE SPEAKER / MONO / LOW VOLUME / CASUAL ATTENTION / 1.25x`.

No premium stereo trick is allowed to make the basic version incomprehensible.

## 19. Reference-source governance
Professional sources are references, not authority above Founder/project canon.

Mechanisms enter universal canon only when:
- evidence is clear;
- mechanism is abstracted;
- it does not copy source expression;
- it improves a real production layer;
- it survives Red Team against current architecture.

## 20. Current universal pipeline
`LOCKED STORY → LISTENER CONTRACT → DRAMATIC FORCE MAP → AUDIO DRAMATURGY → ACTOR CONTEXT/PERFORMANCE → BLOCKING/MIC PERSPECTIVE → PAUSE/BREATH/LISTENING → AUDIO COMPOSITION → MICROTEXTURE/FOLEY/SFX/AMBIENCE → MUSIC DRAMATURGY → PROVIDER COMPILATION → TAKES → EDIT → RESOLVED TIMELINE → NARRATIVE AUTOMIX → MASTER → THREE-MODE SOUND QC → PLAYBACK QC → HUMAN LISTEN → MASTER LOCK`.

## Acceptance
This v2.2 addendum is universal. Project overlays may specialize density, intimacy, clue logic, music palette and spatial grammar, but may not weaken listener comprehension or locked story authority.
