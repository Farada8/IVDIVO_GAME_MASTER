# Path to a genuinely self-improving IVDIVO system

The goal is not maximum rule count. The goal is a production system that becomes measurably safer, faster and more effective while preserving authority and evidence boundaries.

`REAL PRODUCTION OUTCOME -> OBSERVATION -> ROOT CAUSE -> EXISTING-MECHANISM RETRIEVAL -> MINIMUM NEW CANDIDATE -> FALSIFIABLE PILOT -> GUARDRAILS -> DECISION/ERROR/REWORK DELTA -> PROMOTE/NARROW/MERGE/HOLD/ROLLBACK -> APPLICATION -> READBACK -> MONITOR -> PRUNE`

Priority path after Cycle9:
1. Gather genuine SI-0014 interruption/recovery evidence naturally, never manufactured.
2. Run SI-0015 on real router slices and measure false positives/manual overrides.
3. Pilot individual v3 reference mechanisms on current production bottlenecks with preregistered baseline and guardrails.
4. Measure decision delta, rework avoided, errors avoided and recovery correctness.
5. Prune mechanisms that duplicate, overfire or never change decisions.
6. Promote only scoped mechanisms that survive real production evidence; keep v2 as authority until a full replacement demonstrably outperforms it without regression.
