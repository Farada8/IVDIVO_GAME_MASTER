## Anti-inflation rules
1. Translation is not an independent source family.
2. EPUB/PDF/AZW3 copies of one work count once.
3. Multiple works by one author/theoretical lineage broaden a theory but do not create independent replication.
4. Deterministic engine tests prove software behavior, not the source theory in the world.
5. Durable promotion requires project evidence showing a decision/rework/quality effect and a healthy control where appropriate.
