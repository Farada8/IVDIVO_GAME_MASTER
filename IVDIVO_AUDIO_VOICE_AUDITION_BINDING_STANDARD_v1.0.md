# IVDIVO AUDIO — VOICE AUDITION & BINDING STANDARD

**Status:** CURRENT UNIVERSAL AUDIO STANDARD
**Version:** 1.0
**Date:** 2026-08-21

## PURPOSE

Abstract the strongest reusable audition/voice-lock mechanisms proven across current audio-drama projects into one provider-neutral standard.

This standard does not select voices and does not invent provider IDs. It defines the evidence required before voice lock.

## 1. AUTHORITY FIRST

Every audition manifest binds to:
- recording master/version;
- exact spoken sequence hash where available;
- project voice/audio bible;
- project casting scorecard;
- `exact_text_locked` state;
- provider/model/version if known.

If text authority changes, affected audition evidence is stale.

## 2. AUDITION SOURCE LAW

Use exact locked project text wherever possible.

Do not write artificially flattering audition dialogue merely to make a candidate sound good.

For each audition side record:
- block/line ID;
- speaker;
- exact text;
- exact-text SHA256 where machine workflow supports it;
- performance objective;
- tactic;
- subtext;
- status;
- priority;
- energy;
- tempo;
- breath;
- proximity;
- P51 voice guard;
- P52 temperature/state;
- P53/relationship/consent focus where applicable.

## 3. DRY COMPARISON LAW

Initial candidate comparison:
- loudness matched;
- music OFF;
- reverb OFF;
- heavy processing OFF;
- labels anonymous where practical;
- same exact source text/settings class for comparable candidates.

Do not let mix polish choose the actor.

## 4. MINIMUM TAKE TYPES

Each surviving candidate must produce at least:
1. `NATURAL_RESTRAINED` — minimal direction; hear the candidate before prompt engineering;
2. `DIRECTED_CHANGE` — the same excerpt with exactly one meaningful correction.

Direction-change PASS proves controllability without identity drift.

## 5. MULTI-STATE TEST

Do not cast a major role from one best line.

Major characters must be tested across materially different states such as:
- ordinary/routine;
- professional competence;
- pressure/danger;
- shame/failure;
- private vulnerability;
- humor;
- late-arc changed behavior.

The same person must remain recognizable across states.

## 6. LEAD PAIR GATE

For central relationship pairs:
- run a pair/callback test on exact scene text;
- chemistry must survive removal of flirtation tricks;
- score listening, timing, changed response impulse, boundary respect and status negotiation;
- reject chemistry dependent on whispering, matched timbre, sexual breath, mutual smirking or music.

## 7. LONG-FORM FATIGUE GATE

Before season voice lock for leads, require an 8–10 minute continuous/representative fatigue test or equivalent multi-block evidence.

Check:
- identity stability;
- listener fatigue;
- repeated cadence;
- over-acting drift;
- pronunciation drift;
- provider stability across blocks;
- ability to sustain ordinary speech, not only peaks.

A great 15-second sample is not a season voice.

## 8. BLIND DIFFERENTIATION

Where practical, test whether listeners can distinguish regular characters without labels from representative clean dialogue.

Failure may indicate:
- wrong casting;
- P51 text-voice convergence;
- over-processing;
- insufficient performance differentiation.

Do not solve text convergence solely with exaggerated accents.

## 9. ROLE-SPECIFIC HARD FAILS

Each role defines hard fails before audition review.
Examples:
- false villain coding;
- generic alpha/possessive tone;
- helplessness replacing vulnerability;
- maternalization;
- exposition-bot cadence;
- tabloid caricature;
- horror coding where mystery requires human ambiguity;
- flirtation where relationship state is professional.

`ANY_HARD_FAIL` overrides numeric average.

## 10. WEIGHTED SCORECARD

Use role-specific weights rather than one universal beauty/pleasantness score.
Potential dimensions:
- character contradiction;
- natural spoken language;
- voice distinctiveness;
- professional credibility;
- objective/resistance;
- private cost without agency loss;
- consent/power accuracy;
- direction response;
- clue intelligibility;
- public/private register;
- long-form listenability.

Weights must reflect the character’s actual story function.

## 11. DECISION STATES

Recommended generic states:
- `REJECT` — any hard fail or unusable instability;
- `HOLD` — promising but evidence insufficient;
- `CALLBACK` — passes identity and direction change;
- `PROVISIONAL_PILOT_LOCK` — callback + pair/contrast + clue/mono checks as applicable;
- `SEASON_LOCK` — long-form fatigue + representative multi-episode evidence + provider stability.

Numeric thresholds may be project-defined. No score alone can override hard fail.

## 12. REPLAY / EVIDENCE ASSET IDENTITY

If the same recorded voice/source is replayed later as evidence, preserve canonical source identity. Do not regenerate each replay independently unless story explicitly requires a different take/source.

## 13. PROVIDER-NEUTRAL BINDING

Voice lock records:
- role;
- candidate/provider voice ID;
- provider/model/version;
- settings/prompt version;
- date;
- audition sides used;
- accepted take hypothesis;
- known weaknesses;
- pronunciation dependencies;
- long-form evidence;
- project/season lock level.

Nicknames alone are not sufficient identity.

## 14. SOURCE / PORTABILITY NOTE

Reusable mechanisms were abstracted from advanced BODYGUARD E01 audition/binding work and reconciled with current Audio Studio pilot-first, exact-text, selective-regeneration and fail-closed laws.

Project character names/content are not part of this universal standard.
