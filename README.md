# IVDIVO GAME MASTER

Единый репозиторий проекта международной настольной игры и IP-вселенной.

## Назначение

Этот репозиторий является главным текстовым хранилищем проекта: контекст, решения, исследования, механики, миры, карты, кампании, Kickstarter, бизнес-модель, франшиза, AI-результаты и идеи.

Google Drive остаётся хранилищем для Word/PDF, изображений, презентаций, макетов, прототипов и материалов обмена.

## Главные файлы

- [PROJECT_CORE_CONTEXT.md](PROJECT_CORE_CONTEXT.md) — обязательный контекст проекта.
- [IVDIVO_WRITING_PRODUCTION_CANON.md](IVDIVO_WRITING_PRODUCTION_CANON.md) — обязательный канон написания книг, рассказов, сериалов, сцен, диалогов, сверхфизики и Story Gate; обновляется по новым уточнениям основателя.
- [DECISIONS.md](DECISIONS.md) — журнал утверждённых решений основателя.
- [CHANGELOG.md](CHANGELOG.md) — журнал изменений базы знаний.
- [ROADMAP.md](ROADMAP.md) — дорожная карта разработки.

## Рабочие разделы

- [docs/](docs/) — утверждаемые и рабочие документы проекта.
- [ideas/](ideas/) — новые идеи, гипотезы и наброски до утверждения.
- [inbox/](inbox/) — входящие заметки, ссылки, сырой материал.
- [templates/](templates/) — шаблоны документов.
- [references/](references/) — внешние источники, аналоги, книги, ссылки.
- [playtests/](playtests/) — тесты, метрики, отчёты балансировки.
- [assets/](assets/) — лёгкие вспомогательные материалы; тяжёлые файлы хранить в Google Drive.

## Правило проекта

Новая гипотеза не заменяет утверждённое решение. Все значимые изменения должны фиксироваться в `DECISIONS.md` или `CHANGELOG.md`.

Для художественных производств действует дополнительное правило: перед написанием книги, рассказа, серии или крупного сценарного блока необходимо учитывать актуальную версию `IVDIVO_WRITING_PRODUCTION_CANON.md`. Новое прямое уточнение основателя имеет приоритет над старой редакцией и должно быть внесено в следующую версию канона, если оно меняет устойчивый производственный принцип.
