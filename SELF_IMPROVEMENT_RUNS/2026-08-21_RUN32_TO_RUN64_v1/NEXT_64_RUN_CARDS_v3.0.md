## ROUTER-00 — Shared Execution Envelope — NOT COUNTED

Before any numbered card:
1. Restore Founder newest instruction, active project/source-of-truth, current domain authority and project execution state.
2. Read fresh GitHub main / Drive frontier needed for the task; detect sibling-dialog ownership and same-dependency concurrency.
3. Run STALE-WORK GATE: completed/accepted/superseded/blocked work is not repeated.
4. Separate evidence class: PROJECT/PRODUCTION, AUTOMATED/RUNTIME, EXTERNAL_PROVIDER, HUMAN_SIGNAL, MARKET, INTERNAL_DESIGN, REFERENCE_ONLY.
5. Protect CANON/LOCKED text and secrets. No provider/human/market result may be fabricated.
6. Execute only the smallest current card that changes the real frontier or returns evidence-backed HOLD/BLOCKED/NOT_APPLICABLE.
7. Record: TARGET / SOURCE / ACTION / DISPOSITION / FINDING / CHANGED_ARTIFACTS / NEXT_GATE.
8. Persist grouped results after each block of eight; before every material write re-read revision/hash/frontier and rebase rather than overwrite.
9. Continue through authorized unblocked cards; stop only at a real authority/evidence/provider/human/tool/safety/approval gate.
10. Story First. Meta-system work must serve stronger completed books and audio production.

## GROUP A — AUTHORITY / PORTFOLIO / STATE — P01–P08

### P02 — Portfolio Frontier Rebase
**Mission:** Find true current portfolio frontier without trusting aggregate snapshots blindly.  
**Run:** Compare project-specific authorities/gates with aggregate state/routers. Classify LOCKED / COMPLETE / ACTIVE / BLOCKED / FOUNDER_DECISION / EXTERNAL_EVIDENCE / RESERVE.

**Output:** `PORTFOLIO_REBASE` + one highest relevant obligation.

**Gate:** same-file/same-episode/same-gate concurrent advance -> REBASE_OR_REROUTE.  
**Output:** `CONCURRENCY_CARD`.

### P04 — Authority Chain + Source Identity Lock
**Mission:** Bind work to exact controlling source.  
**Run:** Record authority path, filename/ID/version/revision/hash, status, protected text/fields, accepted gates and superseded alternates.  
**Gate:** source identity ambiguity that could change content -> HOLD.  
**Output:** `SOURCE_LOCK`.

### P05 — Accepted-Gate ↔ Current-Status Parity Check
**Mission:** Detect status files that lag accepted gates or newer verified artifacts.  
**Run:** Compare Final/Block/Release gates against DRAFT_STATUS/CURRENT_STATE/router pointers; identify contradictions in next_action/status/completion/lock wording.  
**Gate:** never downgrade a passed gate from stale pointer.  
**Output:** `POINTER_PARITY_REPORT`.

### P06 — Minimal Stale-Pointer Repair
**Mission:** Repair verified pointer drift without rewriting project history/canon.  
**Run:** Fresh-read revision/hash; patch only stale routing/status/next-action fields; preserve historical sections and sibling additions; add supersession note if needed.  
**Gate:** revision changed -> abort/re-read/rebase.  
**Output:** patched pointer + readback.

### P07 — Locked / Superseded / Archive Firewall
**Mission:** Stop attractive old branches from re-entering production.  
**Run:** Enumerate current/working/superseded/rejected/archive variants and verify routers point to current branch.  
**Gate:** unresolved competing branch -> FRONTIER_CONFLICT.
