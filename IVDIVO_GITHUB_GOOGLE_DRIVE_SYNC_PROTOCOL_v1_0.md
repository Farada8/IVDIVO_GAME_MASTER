# IVDIVO — GITHUB / GOOGLE DRIVE SYNC PROTOCOL v1.0

**Status:** CANON PRODUCTION PROCESS

## PURPOSE

Prevent continuity loss between conversations and ensure all meaningful IVDIVO development survives beyond a single chat.

## WRITE ORDER

1. Produce/revise the artifact.
2. Determine status: CANON / ACTIVE / WORKING / OPTION / etc.
3. Write/update GitHub canonical file.
4. Mirror the same artifact to Google Drive.
5. Verify GitHub path/content.
6. Verify Drive file/folder.
7. Update:
   - active `DRAFT_STATUS.md` or `SOURCE_OF_TRUTH` index when the production state changes;
   - changelog/registry when appropriate.
8. Only then state that synchronization is complete.

## WHAT MUST BE SAVED

Save all substantive developed material, including:
- accepted drafts and patched versions;
- gates;
- Red Team reports;
- Reconciler decisions;
- bibles;
- maps/scene architecture;
- reference mechanism passes;
- writer briefs;
- voice/style guardrails;
- canon/control documents.

Intermediate scratch output may remain local only **only if** it has already been superseded within the same work pass and contains no unique decision or mechanism.

If a scratch version contains unique reasoning worth preserving, archive it rather than discard it.
