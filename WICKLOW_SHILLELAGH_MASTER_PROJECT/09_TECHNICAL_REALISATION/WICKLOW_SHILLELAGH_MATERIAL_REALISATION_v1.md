# MURAL TECHNICAL REALISATION v1

## Pre-design data required
- exact wall/site dimensions and photographs
- substrate (render, masonry, concrete, cladding, other)
- coating history / adhesion / moisture / cracks
- orientation, shade, weather exposure
- windows/doors/pipes/gutters/signs/cables
- ground/access constraints and public interface
- primary viewing distances/angles

## Candidate execution sequence
survey → permissions → cleaning/repair → adhesion/moisture checks → primer → drawing/grid/projection → blocking → detail → protective finish only if justified → punch list → documentation → maintenance handover.

## Fail-closed rules
No final material specification from a render alone. No working-at-height plan without site/access data. No illusionistic perspective lock without primary viewpoint. No install GO without commissioner-approved H&S/insurance/permissions package.
