# SYNTHESIS / DEDUPE / ROADMAP — AFTER 32 EXECUTED PROMPTS

## Executive conclusion
The current IVDIVO production OS is no longer missing a basic writing framework. Its strongest areas are authority/freshness routing, evidence-class separation, Story First law, climax/resolution closure, reference abstraction, P51–P53 conditional craft, audio audition discipline, and Self-Improvement v2.

The next gains come from **closing state-integrity gaps and turning several strong prose-level laws into small reusable ledgers/schemas**, not from adding another giant router or another 100-prompt super-system.

## Highest-priority findings

### P0 / Integrity
1. **Registry-state drift:** `CURRENT_IVDIVO_SELF_IMPROVEMENT_STATE` schema 2.7 points to `SI-0008_WRITE_THROUGH_PENDING_SELF_REFERENCE_HYGIENE`, while the central registry search did not return SI-0008. This is a real self-reference integrity gap.
2. **Uniform project state coverage is incomplete:** D04/D09 demonstrate the correct durable pattern, but not every project is equally recoverable from machine-readable state.
3. **Boot information still exists in several human-readable compatibility layers:** the correct long-term solution is one machine-readable boot manifest plus generated/compatibility mirrors.

### P1 / Stronger completed books
4. **Opposition adaptation** should become a conditional architecture ledger. Escalation must respond to protagonist action rather than merely intensify on schedule.
5. **Ensemble Relationship Authority Graph** remains a high-value missing universal mechanism, especially for non-romantic relations, power/knowledge asymmetry and memory/consent cases.
6. **Universal mystery/evidence ledger schema** should encode lineage/access/reliability/current-line proof instead of relying on project-specific formats.
7. **Scene delete/swap tests** should become standard block-audit diagnostics for modular filler and weak causality.
8. **Sociology / institutional pressure** deserves a concrete conditional card; the system is operationally stronger in dialogue/romance than in class/money/work/bureaucracy pressure.

### P2 / Audio
9. **Audio adaptation delta ledger** should audit every non-trivial locked-text-to-audio change.
10. **Performance binding card** should connect P51/scene tactics to provider-neutral audition blocks.
11. **One-listen evidence test** should become a standardized blind-listen validation tool.
12. **Transcript recovery is verified in source/runtime but not packaged in the current promoted v11.2 ZIP.** The next package requires fresh-unzip full regression and checksum before promotion.

### P3/P4 / Production factory
13. **Blocked-frontier parallel scheduler:** a Founder/canon gate must stop that project, not the entire studio. Safe independent Founder-authorized R&D may proceed under WIP guard without implying progress on the blocked project.
14. **Prompt/router sprawl:** classify every file as AUTHORITY / GENERATED MIRROR / COMPATIBILITY / DOMAIN OVERLAY / HISTORY. Do not solve duplication by creating another router.
15. **Cross-model benchmark fixtures** are needed to measure diagnosis quality without mistaking repeated model agreement for independent evidence.

## Strong mechanisms to preserve
- `NO NEW EVIDENCE -> NO NEW GLOBAL REWRITE`.
- `AGENCY != AGGRESSION`.
- `INNER PROCESS SPEED != OUTER MOTION SPEED != SENTENCE LENGTH`.
- `PRIVATE CHARACTER LAB != MANUSCRIPT EXPOSITION`.
- Story Core and Scene Law remain story-first, not field-count rituals.
- Human Signal, live provider evidence and market behavior remain separate from AI/internal tests.
- Series hooks only after current conflict closes.
- Problem-targeted Reference Intelligence; do not process the entire remaining library merely to increase a completion count.

## What was rejected
- Creating a new universal “32-prompt engine” that supersedes current Narrative OS.
- Rerunning the full reference library without a live decision requiring it.
- Treating 32 completed prompts or 64 generated prompts as proof of system quality.
- Automatically executing all 64 next prompts regardless of priority.
- Reopening locked story text because new craft mechanisms were discovered.
- Using D09 Founder gate as permission to lock D09 or generate E25.

## Stop rule
Do not automatically run all 64. Stop/defer when:
- the decision is already supported;
- no new evidence appears;
- the prompt duplicates a current mechanism;
- a real pilot is more informative than more analysis;
- a higher-priority book/audio obligation becomes unblocked;
- a Founder/human/provider/tool gate is reached.
