## Core decision
Do **not** build an asset, software product, property, inventory position or paid acquisition funnel before a buyer funds the next irreversible step.

`FREE DISCOVERY → MANUAL OFFER → BUYER INTEREST → PAID PILOT/DEPOSIT/PO → MANUAL DELIVERY → UNIT ECONOMICS → REPEAT → FINANCE/AUTOMATE/SCALE`

## Anti-Bedlam selection
- **PRIMARY:** Tender / Opportunity Intelligence + Bid/No-Bid service for Irish construction, retrofit and MMC SMEs.
- **PILOT A:** AI estimator / quote + job-document automation for small contractors.
- **PILOT B:** Retrofit lead qualification / coordination.

These are **not market-proven businesses**. Public evidence establishes sector activity (E1), not a willingness to pay. The next real gate is E3 buyer interest followed by E4 paid pilot/deposit/PO.

## Strict €0 contract
PASS only when:
1. founder new cash-out before E4 = €0;
2. no irreversible commitment is required before external payment/funding trigger;
3. first deliverable can be produced manually with already-available resources/free public data;
4. supplier/production spend starts only after paid pilot, deposit, PO, commission trigger or approved external finance;
5. reimbursable grants without a bridge **do not count** as zero-cash funding.
