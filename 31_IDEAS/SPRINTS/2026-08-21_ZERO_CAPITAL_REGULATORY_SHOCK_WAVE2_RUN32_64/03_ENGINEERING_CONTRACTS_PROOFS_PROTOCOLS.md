# ENGINEERING CONTRACTS + PROOFS + PROTOCOLS

## Contracts
- **C01 ZERO_CASH_PREPROOF** — founder cash-out must equal €0 before E4; existing time/subscriptions are sunk resources, not new cash.
- **C02 FRESH_AUTHORITY** — every material run begins from current GitHub main + Drive readback; stale writer cannot overwrite newer state.
- **C03 OFFICIAL_REGULATORY_SOURCE** — dates/scope/enforcement claims require current first-party EU/Irish authority.
- **C04 EVIDENCE_NON_FABRICATION** — model analysis/competitor pages cannot create E3/E4.
- **C05 BUYER_BEFORE_BUILD** — no software product build before E3.
- **C06 PAYMENT_PROOF** — E4 only when money/deposit/PO/paid contractual commitment is observed.
- **C07 LIABILITY_BOUNDARY** — no legal opinion, conformity certification, security assurance or regulatory representation without qualified specialist.
- **C08 MANUAL_V0** — first deliverable must be producible manually with zero new cash.
- **C09 CHANNEL_LEVERAGE** — prefer a partner capable of repeating the pack for multiple end clients when fit is credible.
- **C10 OUTREACH_LIMIT** — batches <=5; inspect replies before next batch; no bulk cold spam.
- **C11 DEADLINE_RECHECK** — every time-sensitive offer rechecks effective/deadline dates on send day.
- **C12 PRICE_AFTER_VALUE** — free sample may prove usefulness; paid pilot has fixed scope and price.
- **C13 KILL_RULE** — 20 qualified contacts with <2 E3 and zero E4 => kill/material pivot.
- **C14 PRICING_RULE** — 5 E3 and zero E4 => test price/scope before changing market.
- **C15 FINANCE_AFTER_PROOF** — debt/grant/investor capital accelerates only after E4/E5; never substitutes for demand.
- **C16 SELF_IMPROVEMENT** — only observed defects change engine; every change gets regression + provenance + rollback path.

## Proof ladder
E0 hypothesis -> E1 current official authority signal -> E2 observed market/competitor evidence -> E3 explicit buyer engagement -> E4 payment/deposit/PO -> E5 repeat paid -> E6 retention/bankable economics -> E7 scale.

## Protocols
- R1 `SIGNAL -> official source -> effective date -> affected actor -> mandatory action -> zero-cash wedge`.
- R2 `WEDGE -> competition scan -> liability boundary -> manual v0 -> fixed deliverable -> target segment`.
- R3 `TARGET -> public fit evidence -> message version/hash -> send -> response ledger`.
- R4 `E3 -> discovery -> objection taxonomy -> minimal offer delta -> next controlled batch`.
- R5 `E4 -> delivery timer -> actual cost/time -> margin -> repeatability -> only then automate`.
- R6 `FAILURE -> demand/price/trust/channel/delivery classification -> minimal repair -> regression -> retry/kill`.
- R7 `PERSIST -> GitHub feature branch/PR + Drive readback; stale state never overwrites current pointers`.
