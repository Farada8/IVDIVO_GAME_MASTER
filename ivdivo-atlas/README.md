## Правило корпуса

Разметка происхождения обязательна для каждого утверждения:

**[И]** источник ИВДИВО · **[С]** внешний источник со ссылкой · **[Р]** реконструкция или гипотеза

В корпусе разработки Аватаресс дополнительно применяются:

**[Д]** решение, реально разработанное в диалоге · **[В]** зафиксированная визуальная версия · **[О]** открытое место, которое нельзя честно заполнить без полного исходного текста.

**[Р] не превращается в [И].** Где данных нет — записано, что их нет.

Пустая клетка есть результат. Правдоподобным текстом не заполняется.

## Состояние

**Готово:** метод; фактическая база из т. 1, Атласа и т. 3; мета-промт и три промта по Движению; система различения портретной серии; ярусы миров; полный документальный реестр первых сорока Аватаресс; разработка пяти восьмёрок; подробные досье 0033–0040; аудит повторяемости; система национального дизайна и сред; визуально-производственный стандарт v2; протокол продолжения.

**Открыто:** восемь вопросов в `00-metod/otkrytye-voprosy.md`. Главные — уровень зерцал, число частностей (16 или 64), число разрядов Частей (5 или 6), что считает число 768.

Для 0001–0032 точные ядра, ритм, доступные ранние решения и понятийные конспекты сохранены. Полные дословные старые производственные промты следует добавлять отдельно в `legacy-verbatim`, когда будет доступен полный экспорт раннего диалога; реконструкция не выдаётся за дословную копию.

## Ограничение по объёму

Полная карта Аватара — около шести тысяч слов. На 384 карты это корпус в два миллиона слов, то есть работа не на один год в одиночку.

Решение то же, что принято для книги: **40–60 карт разрабатываются полностью как образцы, остальные — короткая спецификация на страницу** (позиция, регистр, среда, ярус, кадр, момент). Иначе серия не доедет.
