# Атлас ИВДИВО — рабочий корпус

Материалы двух связанных работ: книги о частностях и метода портретной серии Аватаров Синтеза.

Основа — ИВДИВО, Философия Синтеза В. Сердюка. Дальнейшая разработка ведётся автором самостоятельно.

---

## Устройство

```
00-metod/          метод, исправления, открытые вопросы
01-dvizhenie/      промты для статей о частности Движение
02-avatary/        система портретной серии
03-spravochniki/   проверенные данные из источников
```

## Правило корпуса

Разметка происхождения обязательна для каждого утверждения:

**[И]** источник ИВДИВО · **[С]** внешний источник со ссылкой · **[Р]** реконструкция или гипотеза

**[Р] не превращается в [И].** Где данных нет — записано, что их нет.

Пустая клетка есть результат. Правдоподобным текстом не заполняется.

## Состояние

**Готово:** метод; фактическая база из т. 1, Атласа и т. 3; мета-промт и три промта по Движению; система различения портретной серии; ярусы миров; анализ первых сорока карт; система национального дизайна и сред.

**Открыто:** восемь вопросов в `00-metod/otkrytye-voprosy.md`. Главные — уровень зерцал, число частностей (16 или 64), число разрядов Частей (5 или 6), что считает число 768.

---

## Ограничение по объёму

Полная карта Аватара — около шести тысяч слов. На 384 карты это корпус в два миллиона слов, то есть работа не на один год в одиночку.

Решение то же, что принято для книги: **40–60 карт разрабатываются полностью как образцы, остальные — короткая спецификация на страницу** (позиция, регистр, среда, ярус, кадр, момент). Иначе серия не доедет.
