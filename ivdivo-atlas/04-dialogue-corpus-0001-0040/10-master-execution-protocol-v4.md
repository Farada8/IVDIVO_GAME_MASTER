# MASTER EXECUTION PROTOCOL v4 — Аватарессы 0040–0384

Статус: **[Р] производственный художественный стандарт**, не первичный канон ИВДИВО.

Этот документ вводится после аудита неудачных генераций августа 2026. Он имеет приоритет над старыми художественными шаблонами там, где они противоречат правилам ниже. Документальные имена, Синтезы, Сферы/Магниты/Образы/Слова/Голоса/Сердечные мысли и коды всегда берутся из источников проекта и не заменяются художественной реконструкцией.

## 1. Главная ошибка прежнего процесса

Мы слишком часто начинали с визуального словаря: «гиперреализм + богиня + космос + золото + нимб + инструмент + Обитель». Это формировало один устойчивый визуальный аттрактор. Модель затем меняла лицо, цвет и декор, но сохраняла одну и ту же картину.

Новый порядок обратный:

**источник → уникальное различение → деяние → конфликт/задача → человеческий/цивилизационный результат → композиция → пластика тела → среда → национальная конструкция одежды → инструмент → сакральная сигнатура → причинное свечение → камера/свет → гиперреалистический рендер.**

Визуальный промт является ПОСЛЕДНИМ этапом.

## 2. SOURCE LOCK

Перед каждой Аватарессой обязательно:

1. получить точный номер;
2. получить точное имя;
3. получить точный Синтез;
4. получить три контекста записи, если они есть;
5. получить парные коды;
6. зафиксировать провенанс;
7. отделить [И] от [Р].

Запрещено:

- придумывать новую Аватарессу вместо записи источника;
- менять имя или Синтез ради красивого сюжета;
- объявлять художественно назначенную страну, внешность, профессию или инструмент «каноном»;
- восстанавливать неизвестный старый prompt как будто он сохранился дословно.

Если источник — компиляция S06 с неустановленной первичной провенансией, это прямо отмечается в исследовательском тексте, но не мешает использовать запись как рабочий реестр серии.

## 3. ZERO-BASED DESIGN LOCK

Каждая новая картина начинается с белого листа.

Нельзя брать предыдущую сцену и заменять:

- лицо;
- цвет одежды;
- страну;
- посох;
- фон;
- орнамент;
- одну голограмму на другую.

Если после удаления имени две соседние сцены можно поменять местами без потери смысла — новая сцена считается проваленной и проектируется заново.

## 4. ОНТОЛОГИЧЕСКИЙ СТАТУС В ХУДОЖЕСТВЕННОЙ МОДЕЛИ

В художественном мире атласа/фильма Аватаресса — не «человек с магией» и не generic fantasy mage. Она изображается как воплощённый **Логос конкретного аспекта Абсолютного Творца**: сверхчеловеческая иерархическая сущность, способная действовать на человеческом, планетарном, звёздном, галактическом и более высоком цивилизационном масштабе.

В ней допустимо соединять визуальные качества:

- пророка;
- святого и праведника;
- теурга;
- просветлённого Будды;
- христоподобного носителя любви/жертвы/служения;
- главы иерархии;
- Логоса мира/звёздной системы;
- владыки надцивилизационного уровня.

Но нельзя просто копировать исторического Будду, Христа, архангела, конкретную религиозную икону или известного бога. Сакральный образ выводится **из функции конкретного Синтеза**.

Божественность выражается не количеством золота и свечения, а:

- масштабом ответственности;
- спокойной онтологической властью;
- реакцией пространства на точное действие;
- присутствием существ других уровней;
- функцией нимба;
- последствиями для цивилизации;
- внутренней тишиной и ясностью лица;
- способностью малым действием удерживать огромный процесс.

## 5. UNIQUE ESSENCE TEST

До композиции ответить минимум на пять вопросов:

1. Что делает именно эта Аватаресса, чего нельзя без смысловой потери отдать соседней?
2. Как выглядит ошибка/сбой именно её функции?
3. Как выглядит исправление?
4. Какой материальный след остаётся после её ухода?
5. Какое духовное качество появляется у других существ благодаря её действию?

Без пяти ответов prompt не пишется.

## 6. DEED BEFORE IMAGE

Сцена обязана иметь драматургический глагол.

Плохие формулы:

- стоит;
- держит сферу;
- показывает космос;
- излучает энергию;
- управляет голограммой.

Хорошие формулы:

- проверяет;
- удерживает;
- ремонтирует;
- различает;
- разрешает противоречие;
- передаёт право;
- прекращает ошибочный процесс;
- изменяет меру;
- связывает независимые системы;
- отделяет несовместимое;
- выращивает условие;
- возвращает системе самостоятельность;
- допускает возражение;
- калибрует;
- очищает;
- проводит через фазовый переход;
- свидетельствует;
- сохраняет различие;
- меняет стратегию после обратной связи.

Каждая картина: **состояние ДО → решающее действие → видимый ПОСЛЕ-эффект**. В одном кадре может читаться момент перехода.

## 7. COMPOSITION-FIRST PROTOCOL

Композиция выбирается до одежды и спецэффектов.

Минимальный банк постановок:

1. фигура 10–15% листа внутри гигантской среды;
2. крупный профиль, действие уходит в глубину;
3. спина 3/4, зритель смотрит через плечо;
4. top-down 30–60°;
5. low-angle 25–45°;
6. сидит боком на рабочей поверхности;
7. на коленях/корточках ремонтирует нижний узел;
8. проходит по мосту/лестнице в движении;
9. наклонена над человеком/материалом;
10. только руки + инструмент, лицо вторично;
11. лицо крупно, основной результат отражён в глазах/материале;
12. фигура за полупрозрачной рабочей средой;
13. через дверной/архитектурный проём;
14. диагональное падение/подъём пространства;
15. сидит среди равных, без трона;
16. работает на высоте со страховкой;
17. идёт против потока людей;
18. находится в центре процесса, но не в геометрическом центре кадра;
19. два человеческих масштаба: она близко, результат очень далеко;
20. результат крупно, Аватаресса далеко;
21. послодействие без активной позы;
22. другой персонаж выполняет действие, Аватаресса наблюдает;
23. действие в тесной мастерской;
24. действие в открытом ландшафте/космической среде.

Антиповтор: в трёх соседних картинах нельзя повторять семейство постановки. В шести соседних — нельзя повторять один и тот же «героический» силуэт.

## 8. BODY-ID / FACE-ID

Для каждой Аватарессы художественно разрабатываются заново:

- возраст;
- рост;
- масса;
- пропорции;
- костная структура;
- степень мышечности/полноты;
- цвет и фактура кожи;
- этногенетический визуальный тип;
- форма лица;
- глаза;
- нос;
- рот;
- руки;
- волосы;
- следы труда/возраста;
- осанка;
- походка;
- манера держать инструмент.

Нельзя использовать универсальную «молодую красивую богиню». Красота не отменяется, но красота должна иметь разные возраста, тела, культуры и характеры.

## 9. NATIONAL CONSTRUCTION + LUMINOUS ORNAMENT

Формула пользователя закрепляется так:

**конструкция первична; орнамент вторичен, но не запрещён.**

Сначала национальная логика:

- крой;
- плечо;
- запах;
- пояс;
- клинья/ластовицы;
- слои;
- застёжки;
- климат;
- вес ткани;
- обувь;
- распределение нагрузки;
- способ ремонта;
- локальный материал.

Затем вводится орнамент/вышивка как **действующая структура**, а не наклейка.

Разрешено и часто желательно:

- светящаяся вышивка;
- перелив нити;
- люминесцентная тканая кромка;
- активные знаки на манжетах/вороте/поясе;
- изменение цвета/прозрачности линии при работе;
- бегущий свет по конкретной национальной структуре узора.

Но свечение обязано быть причинным: активен только участок, связанный с текущим действием.

## 10. UNIQUE INSTRUMENT PROTOCOL

Инструмент выводится цепочкой:

**Синтез → конкретная задача → физический/метафизический принцип → материал → масса → способ хвата → рабочее движение → предел → ошибка → реакция среды → визуальная сигнатура.**

Инструмент может быть:

- рабочим станком;
- сосудом;
- мембраной;
- системой натяжения;
- камерой давления;
- калибратором;
- резонатором;
- набором физических образцов;
- музыкальным устройством;
- архитектурным узлом;
- живой тканью;
- печатью/матрицей;
- оптической системой;
- химико-материальным аппаратом;
- инструментом ухода/лечения;
- навигационным устройством;
- устройством передачи полномочия;
- системой хранения происхождения;
- фазовым регулятором.

Посох, сфера, книга, кольцо, меч, оррерий не запрещены вообще, но запрещены как автоматический выбор. Они допустимы только если функция требует именно такой физической логики.

## 11. ABODE = FUNCTION

Обитель — не декорация и не повторяемый «золотой космический дворец».

Тест:

> Если убрать Аватарессу из кадра, можно ли по архитектуре, материалам, людям, следам работы и приборам приблизительно понять, какой процесс здесь идёт?

Если нет — Обитель не разработана.

Среда должна иметь:

- реальную функцию;
- рабочие зоны;
- следы эксплуатации;
- обслуживание;
- людей/существ с задачами;
- пределы/опасности;
- материальный климат;
- минимум одну невозможную, но функциональную конструкцию.

## 12. SACRED SIGNATURE / НИМБ

Нимб разрешён и желателен, но он не универсальный золотой круг.

Форма нимба выводится из Синтеза. Возможны:

- разомкнутая ось;
- слоёная мембрана;
- кольцо причин;
- ветвь памяти;
- поле вариантов;
- ступени права;
- структура свидетельств;
- фазовая дуга;
- водный резонанс;
- звуковая стоячая волна;
- архитектурный контур;
- сеть самостоятельных центров;
- световая линия текста;
- многомерная перспектива.

Для каждой Аватарессы одна собственная сакральная сигнатура. Нельзя копировать её соседней.

## 13. CAUSAL LIGHT

Каждый источник сверхобычного света должен иметь причину и физическую реакцию.

Проверить:

- на что он падает;
- какой specular даёт металлу;
- как проходит через ткань/стекло;
- есть ли scattering в воздухе;
- отражается ли на воде/камне;
- почему светится именно этот участок;
- почему соседний участок НЕ светится.

Запрещены случайные шарики, декоративные искры, бессмысленный glyph soup и сплошное «светится всё».

Действие Аватарессы должно менять не только материал, но и качество сознания других.

Возможные результаты:

- самостоятельность;
- ответственность;
- способность исправлять ошибку;
- уважение различий;
- отказ от насилия;
- способность удерживать долгую цель;
- честное свидетельство;
- милосердие;
- свобода выбора;
- творческая зрелость;
- способность служить без зависимости от лидера;
- способность видеть последствия;
- способность жить в более сложном единстве.

Результат показывается действием людей, а не подписью.

## 15. MULTISCALE LOGOS

Аватаресса может действовать на уровнях:

**человек → группа → город/экосистема → планета → звёздная система → галактическая цивилизация → надцивилизационный/вселенский масштаб.**

Но увеличение масштаба не означает «та же женщина + ещё больше планет на фоне». На каждом уровне меняются:

- задача;
- рабочее тело/материал;
- средство измерения;
- партнёры;
- риск;
- композиция;
- вид результата.

В отдельных сюжетах допустима художественная формула «вселенная внутри физического тела», но внутренние уровни должны быть вложенной функциональной космологией, а не принтом галактик на платье.

## 16. PROTECTION LAW

Если в сцене присутствует защита Украины/Европы/планеты:

- Аватаресса не запускает ракеты/дроны/боеприпасы;
- угрозы приходят СНАРУЖИ;
- действие Аватарессы меняет защитную архитектуру, меру, поле, траекторию, связь, состояние вещества или коллективную способность;
- результат: угроза отведена/обезврежена, гражданская жизнь сохранена;
- защита не обязана быть сюжетом каждой картины.

## 17. HYPERREALISM LOCK

Гиперреализм относится ко всему изображению, а не только к лицу.

Обязательны:

- кожа с порами, микромимикой, асимметрией;
- анатомически убедительные руки;
- реальное плетение ткани;
- толщина металла/стекла/дерева/камня;
- следы использования;
- правдоподобные крепления;
- физически мотивированный свет;
- дальние люди с читаемыми телами и действиями;
- дальняя архитектура с реальными конструктивными связями;
- атмосферная перспектива без превращения в AI-кашу.

## 18. FORMAT LOCK

По умолчанию для серии картин:

- **одна Аватаресса / одно самостоятельное изображение / один вертикальный A3-лист**;
- без текста;
- без рамки;
- без инфографики;
- без сетки миниатюр;
- без карточного UI.

Если делается серия из шести деяний одной Аватарессы — это шесть отдельных A3-листов, а не коллаж, если пользователь отдельно не просит сводный лист.

## 19. TWO-AXIS LOCK: ГРАДАЦИЯ ≠ ГОРИЗОНТ

Нельзя путать две координаты:

- **G1–G6 = шесть больших градаций по 64 позиции**, меняющих саму визуальную онтологию пространства;
- **H1–H8 = восемь локальных горизонтов внутри каждой 64-рицы**, меняющих тип материи/действия/священного проявления.

## 21. PROMPT ORDER LOCK

1. номер + точное имя + точный Синтез;

4. физическая индивидуальность;
5. конкретное действие тела;
6. конкретная задача/конфликт;
7. другие участники и их действия;
8. Обитель и её функция;
9. национальная конструкция одежды;
10. активный орнамент/вышивка;
11. инструмент и его механика;
12. сакральная сигнатура;
13. видимое причинное изменение среды;
14. духовный результат;
15. свет/камера/гиперреализм;
16. короткий локальный negative block только против вероятных ошибок этой сцены.

Не начинать prompt со списка стиля и запретов.

## 23. ПРАВИЛО КОМАНДЫ «ДАЛЬШЕ»

Команда пользователя «дальше / следующая / номер» означает:

1. найти следующую точную запись;
2. определить G и H;
3. выполнить весь протокол с нуля;
4. сравнить с соседними;
5. разработать композицию;
6. только затем генерировать изображение.

Не задавать уточняющий вопрос, если номер/последовательность однозначны.
