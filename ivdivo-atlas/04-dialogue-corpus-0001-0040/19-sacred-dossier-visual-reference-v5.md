# SACRED DOSSIER VISUAL REFERENCE v5

Статус: [Р] обязательный проектный протокол для Аватаресс 001–384. Дополняет протоколы 15–18.

## 1. Новые классы референсов
Новые пользовательские изображения используются как три библиотеки:
- DIVINE PRESENCE — визуальные способы показать высшее существо;
- DOSSIER — структура карты знаний: роль, домен, символы, инструменты, места, отношения, детали;
- BODY STAGING — сидячие, опорные, скрученные и динамические конструкции фигуры.

Референсы не копируются буквально. Из них извлекаются структурные решения.

## 2. Божественный статус
Логосность нельзя строить только на размере тела, бело-золотой одежде, короне или сиянии. Для каждой Аватарессы должны работать несколько независимых каналов: полномочие, домен, уникальный инструмент, сакральная сигнатура, причинный результат, временная глубина, ученики и реакция среды.

## 3. Левая и правая страницы
Левая художественная страница — одна непрерывная физическая сцена без текста и карточного UI.
Правая страница Атласа-досье может использовать многоуровневую информационную архитектуру: имя, номер, точный Синтез, документальное ядро, узкая специализация, задачи, чему учит, Учитель Луча, инструменты, символы, нимб, Обитель, культурная конструкция одежды, деяния, предел полномочий и малые изображения деталей.

## 4. Инструмент как самостоятельная система
Для главного инструмента разрабатывается мини-досье: назначение, материал, масса, способ хвата, рабочая фаза, ограничение, аварийный режим, знак активного состояния, ошибка применения и уровень подготовки ученика.

## 5. Что брать из мифологических досье
Полезна логика: роль → домен → знак → инструмент → место → деяние → служение → характер → ограничение → отношения.
Для Аватаресс она переводится в: Синтез → специализация → служба → проблема → метод → инструмент → символ → Обитель → Учитель Луча → Логосность → предел полномочия.

## 6. Что не копировать
Не использовать как массовый пресет: фронтальную центральную фигуру, симметричную стойку, одинаковое идеализированное лицо, бело-золотую гамму для всех высших уровней, один тип длинных волос, универсальный посох/сферу, одинаковый храм, одинаковый круглый нимб или животное-компаньона без функциональной причины.

## 7. Новые позные классы
В Reference Genome Library добавляются: сидение с асимметрией таза, одна нога вынесена вперёд, локоть на опоре, корпус отклонён назад при активной руке, широкий низкий полуприсед, резкий диагональный перенос веса, касание пола, движение в фазе торможения, сильная скрутка плечевого пояса относительно таза, открытый и закрытый силуэт, фазы до/во время/после действия.

## 8. Контрольный вопрос
Если убрать текст, имя и нимб, какие 3–5 визуальных доказательств показывают одновременно: чем она занимается; почему это существо высокого порядка; почему её нельзя спутать с соседней Аватарессой?
Если ответ держится только на красоте, костюме или сиянии — Scene Spec не готов.
