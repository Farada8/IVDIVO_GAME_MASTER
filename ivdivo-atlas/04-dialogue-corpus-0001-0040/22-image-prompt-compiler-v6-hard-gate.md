# IMAGE PROMPT COMPILER v6 — HARD GATE

Статус: [Р] обязательный производственный протокол для всего Атласа Аватаресс.

Причина версии v6: v5 правильно перечислял Святая / Будда / Владыка / Теург / Логос / Учитель Луча, но допускал ошибку исполнения: Scene Spec мог содержать эти регистры, а финальный image prompt терял часть из них. В v6 это запрещено.

## 1. Непереносимые поля
Финальный image prompt считается НЕГОТОВЫМ, если из Scene Spec в него явно и наблюдаемо не перенесены ВСЕ следующие поля:
1) узкая специализация и конкретная проблема;
2) конкретное действие сейчас;
3) уникальный инструмент и его физическая механика;
4) видимый результат;
5) Святая — конкретное служение существу/жизни;
6) Будда — наблюдаемое качество присутствия при высокой ставке;
7) Владыка — наблюдаемое полномочие и ответственность среди сильных субъектов;
8) Теург — hand/body → instrument/process → material/environment → transformation → verification;
9) Логос — тот же принцип проявлен минимум в трех слоях реальности, без увеличения тела;
10) Учитель Луча — другой субъект самостоятельно применяет принцип в новой форме;
11) минимум три признака надсущества без giant-body shortcut;
12) Face Genome;
13) Body Genome + полная кинематика;
14) три независимых вектора: корпус/действие, голова, глаза;
15) культурная конструкция одежды;
16) функциональный орнамент;
17) уникальная система символов;
18) функциональный нимб/сакральная сигнатура;
19) причинный свет;
20) Обитель как рабочая система;
21) анти-повтор относительно соседних сцен.

Если хотя бы одно из полей 1–11 отсутствует в финальном prompt — prompt НЕ записывать как final и НЕ сообщать пользователю, что он выполнен.

## 2. Шесть регистров обязаны быть визуальными фактами внутри prompt
Запрещено заменять их метками или общими словами.

### Святая
В prompt должен быть виден конкретный объект служения: человек, ребёнок, ученик, раненый, сообщество, живая среда, уязвимая форма жизни. Должно быть видно, какое её решение сохраняет достоинство, субъектность, жизнь или возможность развития.

### Будда
Должно быть видно: дыхание, неподвижность центра внимания, ясное лицо, отсутствие паники/эгоцентрической реакции при высокой ставке. Не использовать лотос/закрытые глаза как автоматический символ.

### Владыка
Должен быть визуально различим субъект/группа высокого уровня, которая признаёт её компетенцию или ждёт её решения; либо система открывает ей полномочие, недоступное другим. Никакой трон/корона как замена полномочия.

### Теург
Должна быть полностью читаема причинная цепь: физическое действие → уникальный инструмент → изменение вещества/среды → измеримый/видимый эффект → проверка результата.

### Логос
Один и тот же принцип должен одновременно проявляться минимум в трёх каналах: её действие; архитектура/живая среда; поведение других существ; дальний системный результат; временная глубина; распознавание полномочия. Human-scale body mandatory.

### Учитель Луча
В prompt обязательно присутствует самостоятельное действие ученика/другого субъекта, которое не является копированием жеста Аватарессы. Он применяет тот же принцип к новой задаче без её руки.

## 3. Надсущество: HARD MINIMUM
Нужно минимум 3 наблюдаемых признака одновременно:
- малый точный жест → огромный причинный результат;
- многослойное внимание;
- распознавание полномочия миром/системой;
- признание среди других высоких субъектов;
- временная глубина больше одной человеческой жизни;
- среда онтологически отвечает её функции;
- после её работы другие становятся самостоятельнее;
- абсолютная ясность при высокой ставке;
- человеческая телесная правдивость контрастирует с масштабом ответственности.

## 4. BODY / FACE HARD GATE
Перед финалом промта сравнить минимум с 8 соседними Аватарессами.
Зеркальный разворот не считается новым решением.

Face test: если убрать волосы, цвет кожи, одежду и нимб, лицо всё равно должно отличаться по черепу, пропорциям, челюсти, скулам, глазам, носу, рту, возрастной фактуре и асимметрии.

Silhouette test: если превратить фигуру в чёрный силуэт, она не должна повторять соседнюю.

BODY STAGING описывается в порядке: стопы → колени → таз → позвоночник → грудная клетка → плечи → локти → кисти → шея → голова → подбородок → глаза → инструмент → фаза движения.

## 5. Инструмент = второй персонаж
Финальный prompt обязан показывать: материал, массу/инерцию, центр тяжести, хват, рабочий узел, физическое воздействие, ошибочный режим/предел, след на среде, проверку результата и путь передачи ученику.

## 6. Символы и нимб
Не декоративная иконография. Минимум:
- знак функции;
- знак полномочия;
- знак ошибки;
- знак Луча;
- знак результата.
Они должны быть материализованы в среде/одежде/инструменте/системе. Нимб — функциональная архитектура присутствия, а не обязательный светящийся круг.

## 7. Финальный compile gate
Перед сохранением финального image prompt мысленно заполнить таблицу:
SPECIALTY=YES; DEED=YES; TOOL=YES; RESULT=YES; SAINT=YES; BUDDHA=YES; RULER=YES; THEURGE=YES; LOGOS=YES; TEACHER_OF_RAY=YES; NAD-SUSCHESTVO>=3; FACE_UNIQUE=YES; BODY_UNIQUE=YES; THREE_ATTENTION_VECTORS=YES; CULTURE=YES; SYMBOLS=YES; HALO=YES; CAUSAL_LIGHT=YES; ABODE=YES; ANTI_REPEAT=YES.

Если хоть одно NO — НЕ сохранять как готовый prompt.

## 8. Правило отчётности
Нельзя писать пользователю «готово», «выполнено», «все правила применены», если финальный prompt не прошёл hard gate. В таком случае статус только: DRAFT / NEEDS RECOMPILE / NOT AUDITED.
