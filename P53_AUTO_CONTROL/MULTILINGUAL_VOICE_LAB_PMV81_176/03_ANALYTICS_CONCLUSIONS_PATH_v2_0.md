# BODYGUARD — MULTILINGUAL VOICE ANALYTICS / CONCLUSIONS / PATH v2.0

## New findings after PMV81–112

1. **Russian is now a full working episode, not an anchor experiment.** E01 has 190/190 spoken lines localized at WORKING level.
2. **Native-language QA and professional-domain QA are separate gates.** Fluent Russian does not prove correct live-stage/security/audio terminology.
3. **External evidence strengthened Russian production language** around `личная охрана`, `бодипак`, IEM/ушной monitoring and TalkBack, while `standby / ack / GO / cue` remains a genuine clue-critical professional blocker.
4. **Timing heuristics are weak evidence.** Character/syllable ratios can identify risk but cannot authorize rewriting. Natural performed duration controls.
5. **Voice Design candidates should explore meaningful boundaries**, not three cosmetically similar attractive voices. Naomi and Eli sets therefore contain baseline, warmer/public-private, and stress-boundary variants.
6. **Provider discovery changed the render strategy.** Current ElevenLabs contracts include TTS with timestamps and Text-to-Dialogue with timestamps. TTD should be tested where conversational continuity matters; it must not replace isolated TTS where exact clue/post-chain/selective regeneration requires isolation.
7. **Render architecture is now measurable:** 72 blocks, 35 TTD candidates, 37 isolated TTS, 190/190 source-line coverage.
8. **Machine QC is not acting QA.** Duration/peak/RMS/hash/alignment can fail a file technically; they cannot determine chemistry, vulnerability, agency or casting.
9. **The earliest-failure order is now explicit:** localization → professional terminology → voice design → performance → pronunciation → edit → mix → listener evidence. Downstream patches must not hide upstream defects.
10. **English is an identity bridge, not a Russian translation.** Canonical English remains the source text. RU Voice Identity can be tested on it; if the same voice fails, build an EN sibling preserving the Character Voice Passport.
11. **The same voice ID across languages remains a hypothesis.** Character continuity outranks acoustic/provider identity.
12. **The next quality gain must come from evidence acquisition**, not a larger abstract rulebook.

## Path to the goal

### Gate 1 — RU text authority
Native Russian + close-protection + live-stage/audio review → glossary/anchor fixes → RU audition anchor v1.0.

### Gate 2 — RU voice identity
Authenticated provider discovery → Voice Design previews → 2-job S0B → S1 fair A/B/C → S2/S3 survivor/direction tests → S4 Naomi/Eli pair → provisional RU pilot voice lock.

### Gate 3 — RU E01 performed proof
Clean render → dialogue edit/alignment → clue processing → mono/mobile → blind native listeners → evidence-based pickups → RU pilot lock.

### Gate 4 — EN identity bridge
Test RU/master identity on untouched canonical English → same-master PASS or English sibling → pair/fatigue/device/listener → EN pilot lock.

### Gate 5 — market languages
Only then decide first Spanish region from market/distribution/native-QA evidence. German/Italian remain low-cost prep until business evidence supports production.

### Gate 6 — self-improvement at scale
Track cost per accepted minute, regeneration causes, clue failures, listener outcomes and identity drift. Promote a project finding to universal runtime only after repeated/reproducible evidence.

## Anti-goals

- no 5-language full-season batch;
- no voice lock from metadata/design descriptions;
- no text rewrite because a voice/mix is weak;
- no TTD everywhere because it is newer;
- no native/audio/provider PASS without evidence;
- no treating multiple AI opinions as independent audience proof.

## Current frontier

**RU native + professional text lock** is the highest real external-evidence gate.
