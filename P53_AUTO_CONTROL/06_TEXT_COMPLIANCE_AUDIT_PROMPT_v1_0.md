# IVDIVO — TEXT COMPLIANCE AUDIT PROMPT v1.0
## P51 / P52 / P53 / STORY / PROFESSIONAL TRUTH / RELEASE CONTROL

**STATUS:** MANDATORY AUDIT PROMPT

Use this on any completed scene, dialogue, chapter, episode, block, script, visual prompt or marketing asset.

# MASTER COMMAND

AUDIT THIS TEXT FOR PRODUCTION COMPLIANCE.

Do not rewrite immediately.

First identify:
- project;
- artifact;
- current canon status;
- Romance Weight;
- scene/task classification;
- locked/protected beats.

Then test the text against the mandatory system.

## A. STORY
1. Who wants what?
2. Why now?
3. What resists?
4. What action occurs?
5. What changes?
6. Does causality break anywhere?
7. Does the scene end in a new state?

## B. CHARACTER / P51
8. Does each major voice remain identifiable?
9. Is occupational/social vocabulary correct?
10. Do stress, humor, silence and argument differ?
11. Has attraction flattened voices into generic romantic speech?

## C. P52
12. What emotional temperature 1–5 is intended?
13. Is the written intensity appropriate?
14. Does this duplicate the temperature/function of adjacent scenes?

## D. P53
15. Is this actually romance-bearing?
16. What is the push?
17. What is the pull?
18. Is male competence preserved?
19. Is private male cost visible where earned?
20. Is heroine agency preserved?
21. Is heroine hidden cost visible where earned?
22. What does each uniquely notice?
23. Is safety/consent clear?
24. Is there an earned micro-reward?
25. Is after-action sequencing correct?
26. Does a costly choice prove transformation?
27. What is the relationship delta?

## E. PROFESSIONAL TRUTH
28. Did romance cause anyone to behave professionally stupidly?
29. Is functional contact justified and promptly ended?
30. Are medical/security/legal/workplace boundaries truthful?

## F. REPETITION / CLICHÉ
31. Are long looks, breath changes, clenched hands, delayed blinks, almost-touches repeating?
32. Any generic romance language?
33. Any symmetrical “smart dialogue”?
34. Any over-explanation of subtext?

## G. AUDIENCE / REWARD
35. What anticipation is created?
36. What reward is earned?
37. Is attachment based on recognition/reliability/safety rather than random sweetness?
38. Is the fantasy calibration correct for the declared relationship stage?

## H. MEDIUM
39. Audio: are key emotional beats hearable?
40. Visual: is agency/action causality readable?
41. Print: is attention selection doing the work without over-explaining?
42. Marketing: does it truthfully promise the actual story/relationship stage?

# SEVERITY

FATAL:
broken causality / coercion romanticized / heroine agency collapse / professional stupidity added for romance / canon damage / false marketing promise.

MAJOR:
emotionally flat leads / male has no private cost across required arc / heroine emotionally invulnerable / chemistry only professional respect / repetitive push-pull / relationship state unchanged / safety unclear / audience promise mismatched.

MEDIUM:
repeated micro-gesture / one generic line / weak reward / voice drift / after-action beat underplayed.

POLISH:
rhythm / diction / isolated preference.
