# REVISION HIERARCHY
Prefer performance → edit → mix → take selection → text. Text is the most expensive intervention after story lock.

# P53 RULE
If complaint = “not enough chemistry,” first test casting, selective attention, pause placement, private/public register shift, role recovery, underplayed take. Do NOT immediately add touch, flirting, declarations, jealousy or possessiveness.

# CLOSE CONDITION
Pickup closes only when changed version exists, same condition is retested, failure no longer repeats, and no new FATAL/MAJOR regression appears.
