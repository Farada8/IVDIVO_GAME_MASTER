**STATUS:** CURRENT WORKING PROMPT SUITE  
**INHERITS:** current Story Authority + Audio Canon + P51/P52/P53 + Provider Adapter + Controlled Self-Improvement Engine

---

## PMV01 — RESTORE MULTILINGUAL AUTHORITY
Restore source-text authority, active localized versions, Character Voice Passports, Language Implementation Ledger, current Audio Canon, provider adapter, P51/P52/P53 and current production frontier.
Classify each artifact CURRENT / WORKING / LOCKED / SUPERSEDED / HOLD.
Output: authority map + contradictions + highest unblocked obligation.

## PMV02 — CHARACTER VOICE PASSPORT
For one character, derive a provider-neutral Voice Passport from canon and existing dialogue/performance evidence.
Include age impression, weight, pitch impression, texture, tempo, articulation, breath, public/private, humor, stress, vulnerability, authority, intimacy, forbidden modes, microphone behavior, pair identity.
Do not choose a provider voice ID.
Output: Voice Passport + hard fails.

## PMV03 — RU LOCALIZATION DIAGNOSTIC
Using locked English source lines, create WORKING contemporary Russian audition/localization lines.
Preserve story/clue/consent/professional/P51/P52/P53 function.
Flag literal-calque risks and lines requiring native/professional review.
Do not call Russian text LOCKED.
Output: source→RU function map + working lines + QA queue.

## PMV04 — EN SOURCE PERFORMANCE AUDIT
Audit English source audition lines as spoken contemporary English.
Do not translate from Russian.
Check P51, public/private register, microphone behavior, clue clarity and P53.
Output: KEEP / PERFORMANCE NOTE / TEXT DEFECT. Locked text changes require evidence.

## PMV05 — SAME-MASTER CROSS-LANGUAGE TEST PLAN
Given one voice implementation, design RU/EN/ES/DE/IT same-voice test anchors.
Define pronunciation, accent, prosody, P51/P52/P53, pair, fatigue and device criteria.
No automatic PASS without audio/native evidence.
Output: comparable test matrix.

## PMV06 — LANGUAGE-SIBLING VOICE DESIGN
When same-master fails, produce a provider-neutral sibling specification preserving Character Voice Passport invariants while optimizing for target locale.
Separate identity invariants from locale-specific pronunciation/prosody.
Output: sibling spec + forbidden modes + provider-safe design brief.

## PMV07 — NATIVE PRONUNCIATION / PROSODY GATE
Audit real rendered samples for native/plausible pronunciation, lexical stress, sentence stress, reductions, rhythm, foreign-accent leakage and unnatural punctuation reading.
Requires native-capable human or validated native review.
Output PASS / REVISE / REJECT / HOLD.

## PMV08 — P51 CROSS-LANGUAGE IDENTITY
Compare one character across language editions.
Remove names mentally. Test vocabulary, length, humor, argument, evasion, stress, silence, occupational syntax, public/private contrast.
Output identity invariants preserved / drift list / smallest repair.

## PMV09 — P52 CROSS-LANGUAGE TEMPERATURE
Map source emotional temperature 1–5 and target localization felt temperature.
Flag emotional inflation/flattening caused by locale wording/performance.
Output temperature equivalence map + repairs.

## PMV10 — P53 CROSS-LANGUAGE CHEMISTRY
Run full P53 on localized romance-bearing dialogue.
Check push/pull, male competence/private cost, heroine agency/hidden cost, female gaze, safety, micro-reward, after-action, choice, relationship delta.
Do not add romance to non-romance scenes.
Output PASS/REVISE + one minimal strongest patch if needed.

## PMV11 — POWER / CONSENT LOCALIZATION
Compare source and target for commands, permission, refusal, authority, professional obligation and ability to say no.
Flag any locale wording that makes the relationship more coercive, intimate or possessive.
Output invariant map + FATAL/MAJOR risks.

## PMV12 — PROFESSIONAL / JARGON LOCALIZATION
For protection/stage/audio/evidence terminology, identify target-language professional wording.
Avoid calque and explanatory dialogue.
Preserve clue distinctions and actor playability.
Output terminology lock candidates + pronunciation queue.

## PMV13 — CLUE / FAIR-PLAY LOCALIZATION
Map every clue-bearing line source→target.
Verify order, semantic payload, ambiguity level and no accidental reveal.
For audio clue language, test discriminability.
Output clue-equivalence ledger + fail-closed defects.

## PMV14 — HUMOR / WORDPLAY LOCALIZATION
Classify humor function before translating.
Preserve status/tension/recognition rather than exact words.
Generate one best locale-natural candidate only when literal version fails.
Run P51/P52/P53 on replacement.
Output KEEP / ADAPT + rationale.

## PMV15 — PAIR CHEMISTRY LANGUAGE TEST
Using real pair audio where available, test Naomi/Eli relationship in one locale.
Target early season: privately important / professionally constrained.
Check extra attention without forced flirt, respected boundaries, complementary rhythms and no maternal/possessive coding.
Output UNDER / TARGET / OVER + cause layer.

## PMV16 — PUBLIC / PRIVATE REGISTER TEST
For each lead compare public-facing vs private-facing lines in target language/voice.
Eli must lose polish privately without helplessness.
Naomi must reveal hidden cost without losing authority.
Output register-separation score + direction note.

## PMV17 — MICROPHONE / PROXIMITY PERFORMANCE TEST
Test voice at actual dramatic distances/states: close professional, private low-volume, command, stage/public, post-action, fatigue.
Separate performance projection from reverb/mix.
Output mic-state matrix + failure modes.

## PMV18 — SILENT REACTION / BREATH / PAUSE TEST
Identify emotional beats better expressed as silence, breath, listening, release or body/Foley rather than extra dialogue.
Create SILENT_REACTION_ANCHOR records.
Ensure spoken-text coverage remains unchanged.
Output anchor plan + do-not-verbalize list.

## PMV19 — S0 PROVIDER PREFLIGHT
Before billable synthesis, verify current adapter contract, key presence without printing, authenticated read-only connectivity, models, explicit model IDs, voice access, language_code strategy, output-format availability and request limits.
Output PROVIDER_PREFLIGHT_PASS or exact fail class.
Do not spend synthesis credits if read-only checks suffice.

## PMV20 — S1 FAIR ANCHOR COMPILER
Compile same-text A/B/C audition jobs per role/locale.
Same function, same text, loudness-matched, music/reverb off.
Record exact text/hash, model, language_code, output profile and provenance.
Output machine-readable S1 manifest.
No casting from metadata.

## PMV21 — SAME-MASTER VS SIBLING DECISION
Given real test results, score pronunciation, accent, prosody, age/status, P51/P52/P53, mic states, pair, fatigue, device.
Decision SAME_MASTER / SIBLING / HOLD.
Any critical native/performance failure blocks SAME_MASTER.

## PMV22 — FATIGUE / LONG-FORM LISTENER TEST
Evaluate 8–10 minutes of accepted candidate performance.
Track vocal sameness, artificial cadence, listener fatigue, character drift, pronunciation accumulation, chemistry flattening and device translation.
Requires real audio/listener evidence.
Output PILOT_CONTINUE / REJECT / HOLD.

## PMV23 — LANGUAGE BUSINESS / RELEASE GATE
For one locale, combine quality evidence with distribution, revenue/cost, human QA availability, provider/voice rights, territory/reuse rights, metadata and marketing readiness.
Output SCALE / PILOT_ONLY / HOLD / DO_NOT_SCALE.
Do not infer market viability from language population alone.

## PMV24 — MULTILANGUAGE REGRESSION / VOICE FAMILY CONSISTENCY
Across all existing locale editions, verify one perceptual character family without forcing identical timbre.
Check story/clue/consent/P51/P52/P53, pronunciation, pair chemistry, provider portability and current locks.
Output family-consistency report + superseded implementations + next test.
