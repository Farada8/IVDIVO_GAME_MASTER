# IVDIVO — P53 DIALOGUE RUNTIME AUTORUN v1.0

**STATUS:** CURRENT MANDATORY RUNTIME

## PURPOSE

Turn P53 from a reference prompt into an automatically inherited dialogue-production routine.

## AUTO-TRIGGER

Whenever the active task creates, rewrites, evaluates, auditions, directs or publishes an important dialogue/relationship scene in dorama, melodrama, romance, women’s fiction, romantic mystery/thriller or a romance-bearing subplot, the studio must silently run:

`RESTORE AUTHORITY → CLASSIFY SCENE → P51 → P52 → P53 → TEXT COMPLIANCE → RED TEAM → PERSIST RESULT`

The Founder does not need to type “P53” each time.

## SCENE CLASSIFICATION

A — romance-bearing
B — relationship-bearing, non-romantic
C — professional/investigative
D — family/friendship
E — antagonistic/status conflict
F — exposition/information transfer
G — action/rescue/emergency
H — audio/performance
I — visual/marketing

A uses full P53. B–E use human truth, asymmetry, vulnerability and status without invented romance. F must first become action/resistance/choice. G requires the After-Action Principle. H must make emotional beats hearable. I requires female-gaze + truthful-promise control.

## REQUIRED DIALOGUE LOOP

1. Restore current canon, relationship state, power/consent state, P51 voice fingerprints, P52 temperature and Romance Weight.
2. Define for each speaker: objective, private desire, fear, status, withheld information, intended belief, information asymmetry, pressure tactic and first attention target.
3. Check real push–pull and end-state delta.
4. Preserve male competence while exposing one earned private cost where appropriate.
5. Preserve heroine agency while allowing one earned hidden emotional price where appropriate.
6. Run Female-Gaze test: attraction through competence, attention, choice, boundary respect and private recognition — not status/possession.
7. Add no more than 1–2 pair-specific micro-rewards when earned.
8. If action/danger occurred: complete safe action first, then place emotional peak in the short aftermath.
9. Protect professional truth and consent/power.
10. Prove transformation through behavior/choice, not thematic speech.
11. Preserve P51 idiolect and P52 temperature; attraction changes what is noticed, not everyone’s voice.
12. Run Text Compliance Audit on the actual output.
13. Record PASS / REVISE / HOLD and patch only demonstrated failures.

## HARD FAILS

FATAL:
- broken causality;
- coercion romanticized;
- heroine agency collapse;
- professional stupidity inserted for chemistry;
- abuse excused by vulnerability;
- canon/clue damage;
- false marketing relationship state.

MAJOR:
- chemistry only professional respect where romance-bearing scene requires more;
- male lead permanently controlled/no private cost across the earned arc;
- heroine emotionally invulnerable;
- repetitive push–pull/micro-gesture;
- relationship state unchanged;
- generic romantic dialogue replacing P51 voice;
- unclear safety/power.

## OUTPUT POLICY

Do not print this checklist unless Founder asks for the audit. Return one integrated strongest result. Do not generate multiple dialogue variants by default.

## LOCKED MATERIAL

Locked material receives regression audit first. Modify only FATAL, MAJOR, high-leverage MEDIUM, direct Founder instruction, repeated human/external evidence, factual error or continuity error.

## RUNTIME TARGET

**Story first. Character truth second. Emotional electricity must be earned.**
