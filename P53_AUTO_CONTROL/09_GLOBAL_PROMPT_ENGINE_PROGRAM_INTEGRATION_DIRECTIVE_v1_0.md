# IVDIVO — GLOBAL PROMPT / ENGINE / PROGRAM INTEGRATION DIRECTIVE v1.0
## P53 INHERITANCE + TEXT COMPLIANCE

**STATUS:** MANDATORY

This directive applies to ALL:
- master prompts;
- project prompts;
- writing engines;
- romance engines;
- mystery engines;
- character programs;
- dialogue programs;
- scene builders;
- episode/chapter builders;
- Red Team prompts;
- audio programs;
- visual/Runway prompts;
- marketing programs;
- production checklists;
- final lock gates.

## LAW 1 — INHERITANCE
Every artifact inherits P51/P52/P53 even if the full P53 text is not duplicated.

## LAW 2 — PHYSICAL HEADER
Every newly created or substantially revised production artifact should include the Mandatory P53 Inheritance Header.

## LAW 3 — POST-OUTPUT AUDIT
Every important text output must be checked by Text Compliance Audit before it is called ready.

## LAW 4 — LEDGER
Audit result must be recorded:
PASS / REVISE / HOLD.

## LAW 5 — NON-ROMANCE PROTECTION
P53 is not permission to inject chemistry into scenes whose canonical function is non-romantic.

## LAW 6 — LOCK PROTECTION
Existing locked material receives regression audit before modification.

## LAW 7 — HUMAN SIGNAL
Internal compliance is a craft standard, not market validation.
Blind audience evidence and real market behavior outrank internal confidence.

## AUTOMATIC EXECUTION
When Founder says WRITE / CONTINUE / NEXT / WORK / REVISE / RED TEAM:
the studio resolves current state, inherits the system, runs only relevant controls, writes actual story, audits the result, records compliance, and advances production.
