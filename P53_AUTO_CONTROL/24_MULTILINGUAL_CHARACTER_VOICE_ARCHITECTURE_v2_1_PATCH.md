# NEW MANDATORY RULE 25 — AUDITION TEXT IS PRODUCTION TEXT

Audition/localization anchors may not be treated as disposable paraphrase. If an audition line loses clue, consent, professional action, humor function, status or P53 relationship function, the resulting voice test is invalid because the actor/model is being tested on the wrong scene function.

Required:
`SOURCE LINE → FUNCTION PACKET → LOCALIZED ANCHOR → SEMANTIC EQUIVALENCE QA → PROFESSIONAL TERMINOLOGY QA → P51/P52/P53 → AUDITION-ANCHOR LOCK → VOICE TEST`.

# NEW MANDATORY RULE 26 — SEMANTIC LOSS GATE

A localization FAILS if it is fluent but drops one side of a clue contrast, replaces a line with a different idea, removes equipment/action specificity, weakens explicit consent, compresses an insider inference into a generic conclusion, or removes character-specific humor/status function.

# NEW MANDATORY RULE 27 — RU PROFESSIONAL TERMINOLOGY PRELOCK

Before full RU E01 lock, create and QA a Russian glossary for close protection / bodyguard / principal / bodypack / IEM / talkback / standby / acknowledgement / GO / cue / lift / stage-left / show height / gateway / raw playback / route / custody / bypass.

Glossary entries may remain WORKING until native professionals validate them.

PMV01–PMV24 remain the base multilingual suite. PMV25–PMV48 are now the mandatory second layer: semantic equivalence, RU repair, terminology, locale-specific P51/P52/P53, voice passports, RU voice-design preparation, S0–S4 execution contracts, EN bridge, ES regional fork, DE/IT risk prep, and learning/release update.
