# 3. CORE LOOP

**TENSION → PRIVATE FRACTURE → MUTUAL NOTICING → SAFE RESPONSE → RESTRAINT → COSTLY CHOICE → EARNED MICRO-REWARD → NEW RELATIONSHIP STATE / NEW TENSION**

This may span multiple scenes.

---

# 4. MALE VULNERABILITY

Target:
**PUBLIC COMPETENCE + PRIVATE COST.**

Allowed:
one mistimed breath / broken prepared rhythm / uncertainty admitted / asking instead of commanding / fatigue, fear or shame briefly visible / private mask drop / help accepted without surrendering agency / costly choice.

Reject:
helplessness as attraction / heroine-as-mother / trauma as instant intimacy / cruelty excused by vulnerability.

---

# 5. HEROINE HIDDEN COST

Target:
**AGENCY + HIDDEN EMOTIONAL PRICE.**

Allowed:
delayed answer / deliberately still hand / work before reaction / softer line withheld / controlled breath / correct professional choice at personal cost / reaction deferred until safe.

Do not reduce competence.

---

# 6. FEMALE GAZE

Mandatory questions:
1. Why is he attractive beyond beauty/status/money/power?
2. What private cost does she see that others miss?
3. What does he see in her competence/cost that others miss?
4. Does he respect boundaries without punishment?
5. Does vulnerability invite intimacy without demanding caretaking?
6. Does she retain an independent goal?
7. Is desire expressed through attention/choice rather than possession?
8. Is she still the subject of her own story?

Failure of #6 or #8 = MAJOR.

---

# 7. ACTION PEAK ≠ EMOTIONAL PEAK

For danger/rescue:
1. complete safe causal action;
2. establish safety;
3. end necessary contact when function ends;
4. only then allow emotional aftermath.

Use release / breath reset / public mask crack / almost-eye-contact / checking the other / professional question replacing the unsayable.

Never slow unsafe action for chemistry.

---

# 8. PROFESSIONAL CONTACT LAW

Before voluntary intimacy is earned, contact is allowed only when functionally justified:
rescue / medical assessment / protection / positioning / safety / unavoidable logistics.

Contact ends when function ends.

Do not deliberately prolong functional contact for romance.

Correct charge:
**the release is noticed.**

---

# 9. PUBLIC SILENCE / PRIVATE RECOGNITION

Support need not become a public romantic gesture.

High-value pattern:
public discipline → private recognition → no demand for gratitude → role recovery.

---

# 10. PUBLIC CHOICE / PRIVATE SEARCH

A costly public factual choice may carry intimacy if the speaker briefly looks for the other person afterward.

It must remain:
recognition, not possession;
choice, not claim;
truth, not romantic theater.

---

# 11. BREATH / RHYTHM DOSAGE

Breath can carry vulnerability:
- one mistimed inhale;
- one controlled reset;
- one brief shared rhythm after safety;
- deliberate role recovery.

Breath synchronization is a rare device.
Do not repeat as a signature in every scene.

---

# 12. MICRO-BEAT FUNCTION DIVERSITY

Across a block, track distinct functions:
respect / trust / fear / rescue / hidden cost / dignity / recognition / boundary / public choice / role recovery.

Repeated long looks, fist clenches, delayed blinks, breath catches or almost-touches become mannerism.

---

# 13. REWARD / ANTICIPATION MODEL

“Dopamine” and “oxytocin” are production shorthand only, not biological guarantees.

Use:

**ANTICIPATION**
uncertainty + almost-reward + delayed fulfillment.

**ATTACHMENT**
recognition + reliable care + dignity + safety + remembered specificity.

Earned micro-rewards:
- remembered detail;
- honored no;
- operational trust;
- dignity protected;
- changed behavior;
- reliable competence;
- private phrase;
- chosen disclosure;
- voluntary staying.

No random sweetness.

---

# 14. AUDIENCE-FIT ROUTING

Use as hypothesis, not deterministic psychology.

Possible audience preference clusters:
- Competent Heroine / Girl-crush
- Slow-burn / Anticipation
- Vulnerability / Healing
- Protective / Chosen
- Light Power-exchange / Status contrast
- Rewatch / Detail hunters

Do not rewrite the core story separately for every cluster.
Select marketing emphasis and micro-beat visibility based on the target.

Broadest overlap usually comes from:
heroine agency + male private fracture + almost-reward + costly public choice.

# 15. FANTASY CALIBRATION

UNDER:
“They are just colleagues.”

OVER:
“They are already basically a couple.”

TARGET:
**“They are trying very hard to remain only colleagues.”**

Use only where slow-burn is the declared relationship architecture.
