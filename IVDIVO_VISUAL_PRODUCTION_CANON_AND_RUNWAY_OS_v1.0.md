# IVDIVO — VISUAL / VIDEO PRODUCTION CANON + RUNWAY OS

**Version:** 1.0  
**Established:** 2026-08-18  
**Status:** CANON / UNIVERSAL PRODUCTION STANDARD  
**Scope:** ALL CURRENT AND FUTURE IVDIVO VISUAL DEVELOPMENT: covers, key art, character plates, AI stills, Runway/Kling video, TikTok/Reels/Shorts, trailers, audiobook motion covers, website hero loops.

## PRIMARY LAW

STORY FIRST.  
CHARACTER IDENTITY SECOND.  
PHYSICAL LOGIC THIRD.  
VISUAL BEAUTY FOURTH.  
MOTION SERVES THE SHOT.  
AI MUST NOT INVENT STORY FACTS.

A beautiful frame with broken identity, impossible object logic, unexplained light, bad anatomy, wrong age, wrong wardrobe, or false story implication is a FAILED frame.

1. Founder’s newest direct instruction.

Statuses:
`CANON / LOCKED / WORKING / SALVAGE / REMAKE / REJECTED / UNKNOWN / REFERENCE ONLY`.

## 2. THE FOUR-LAYER VISUAL SYSTEM

### Layer A — Visual Bible
Locks:
- character face identity;
- apparent age range;
- hair;
- body proportions;
- wardrobe families;
- skin presentation;
- recurring props;
- location architecture;
- lighting logic;
- colour palette;
- camera language;
- forbidden visual implications.

### Layer B — Asset Audit
Every generated still is audited before it can become a production asset.

### Layer C — Shot Plan
Approved stills are assigned a story function, shot duration, camera action, motion risk and transition logic.

### Layer D — Render / Edit
Runway or another provider animates only approved shots. Final editing, typography, sound, music and SFX remain separate controllable layers.

---

## 3. CHARACTER IDENTITY LOCK

A character is not “the same” because the prompt contains the same name.

Before mass generation, create a CHARACTER PLATE SET:
1. neutral front portrait;
2. 3/4 left;
3. 3/4 right;
4. profile;
5. medium shot;
6. full-body;
7. principal locked wardrobe;
8. optional second wardrobe only if story-motivated.

Founder explicitly approves the master face reference(s).

For every new generation:
- reference the locked face plate;
- reference the locked wardrobe when needed;
- do not use a random dramatic frame as the master portrait;
- do not infer identity from an old generation if the locked plate exists.

### Identity fail conditions
Reject or remake if:
- apparent age drifts materially;
- jaw, nose, eyes, face width or hairline changes enough to read as another actor;
- skin suddenly becomes heavily aged, oily, sweaty, wet or beauty-retouched without story reason;
- eye colour, hair colour/style, body scale or costume family changes unintentionally;
- a character’s face is inconsistent between adjacent shots.

### Skin standard
Default:
`natural dry skin, subtle realistic skin texture, no sweat, no oily shine, no wet face, no excessive pores, no over-sharpened aging texture, no beauty-plastic skin`.

Exceptions only when story causes rain, exertion, heat, tears, illness, etc.

## 4. FRAME AUDIT — TWO GATES

NO FRAME enters production because it is merely “beautiful”.

### GATE 1 — TECHNICAL / CAUSAL VALIDITY
Check:
1. identity;
2. age;
3. anatomy;
4. hands/fingers;
5. eyes/teeth;
6. clothing continuity;
7. prop continuity;
8. cable / handset / tool attachment logic;
9. architecture;
10. doors/windows/floors;
11. reflections/mirrors;
12. shadows;
13. light-source causality;
14. object scale/perspective;
15. text/numbers/signage;
16. story motivation of the action;
17. accidental spoiler or false clue;
18. AI artifacts.

If the auditor cannot explain where a physical object, cable, light, reflection or action comes from, mark it `UNKNOWN/ANOMALY`, not “probably fine”.

### GATE 2 — DIRECTING VALUE
Only after Gate 1 passes:
1. story function;
2. composition;
3. depth;
4. emotional readability;
5. unusual/valuable angle;
6. movement potential;
7. transition compatibility;
8. thumbnail/cover value;
9. originality;
10. production reuse.

### Required audit record
`FRAME ID | CONTENT | GATE 1 | ANOMALIES | IDENTITY | GATE 2 | RUNWAY RISK | DECISION | USE`

Decisions:
- `HERO` — top production asset.
- `KEEP` — production-safe.
- `B-ROLL` — useful without identity dependence.
- `SALVAGE` — good composition, local repair possible.
- `REMAKE` — preserve angle/composition but regenerate identity/object/light.
- `REJECT` — do not animate or publish.

---

## 5. THE ANOMALY LAW

AI visual anomalies are presumed errors until positively justified by locked story or physical causality.

Examples:
- telephone handset appears in a corridor without visible/known base or cable;
- unexplained shaft of light seems supernatural;
- a character measures a random structural column with no scene motivation;
- a room number or clue appears earlier than canon allows;
- reflections contain wrong people or duplicate bodies;
- equipment changes type between adjacent shots.

Do not invent retrospective story explanations to save a beautiful frame.

If a strange visual element would cause a viewer to ask “what does this clue mean?”, it is especially dangerous in mystery and must be removed unless it is an intentional clue.

---

## 6. LIGHTING CAUSALITY CANON

Every dominant light must have a plausible source or be deliberately stylised in a way that cannot be mistaken for a plot event.

For every shot identify:
`KEY SOURCE / FILL SOURCE / PRACTICALS / EXTERIOR SOURCE / MOTIVATED EFFECT`.

Reject or remake:
- isolated beams with no window/door/practical source;
- glow emitted by ordinary walls/objects;
- light that creates a false supernatural clue;
- inconsistent key direction across a continuous scene;
- firelight without fire or plausible reflected source;
- impossible shadow direction.

Prestige darkness is not “make everything black”. The viewer must understand space.

---

## 7. PROP + HANDSET + CABLE LAW

Before approval ask:
- Where is the object’s base?
- How is it powered?
- Where does the cable go?
- Who picked it up and from where?
- Can the person physically hold/use it that way?
- Is it the correct historical/current technology?
- Is the object present in the previous/next shot?

For fixed telephones:
a receiver must remain connected to a plausible telephone/switchboard system unless the story explicitly shows a detachable/wireless device.

For investigation tools:
the placement must correspond to a real story question. “She is measuring something” is not enough.

---

## 8. MYSTERY VISUAL FAIRNESS

Visuals may not accidentally create:
- a clue not in the script;
- a supernatural event not in canon;
- a false room/door;
- impossible number/signage;
- evidence held by the wrong character;
- wrong sequence of discovery.

In mystery, every visually salient anomaly is interpreted by the audience as intentional. Therefore visual QC is part of clue continuity.

---

## 9. WARDROBE FAMILIES

A character may have multiple wardrobe states, but each is a named story-motivated family.

Example:
`ELENA_W01_BLACK_FIELDWORK`
`ELENA_W02_FORMAL_ARCHIVE`
`ELENA_W03_EMERGENCY`

Do not mix wardrobes inside one continuous scene or montage that implies continuous time unless the cut clearly establishes a new time/location.

Alternative generations with different wardrobe are not automatically rejected; they become a separate WORKING wardrobe family until approved.

---

## 10. RUNWAY MOTION-SAFETY CLASSIFICATION

### LOW RISK
- empty environment;
- architecture;
- switchboard/equipment macro;
- documents;
- hands with minimal motion;
- slow push-in/pull-out;
- subtle lamp/rain/curtain movement.

### MEDIUM RISK
- one character, medium shot;
- small head turn;
- restrained glance;
- reaching for an existing object;
- walking a few steps;
- simple camera orbit.

### HIGH RISK
- two close faces interacting;
- hands crossing/physical contact;
- kissing;
- handset changing hands;
- complicated tools/cables;
- mirrors;
- fast action;
- character moving from full body to extreme close-up;
- generation that must preserve exact text/numbers.

High-risk shots must be short, separately generated, and never trusted without frame-by-frame QC.

---

## 11. SHOT CONSTRUCTION LAW

Do not ask one AI generation to create a complete 15–30 second edited sequence.

Build:
`INTRO/STINGER → SHOT A → SHOT B → SHOT C → END IDENT`

Each shot:
- has one primary action;
- has one camera instruction;
- preserves existing objects;
- avoids introducing unneeded elements;
- is rendered separately;
- can be replaced without rerendering the whole video.

Default short-form shot length:
2–4 seconds, adjusted to story beat.

---

## 12. IMAGE-TO-VIDEO PROMPT GRAMMAR

For an existing image, describe motion, not the entire picture again.

Template:

`[CAMERA MOTION]. [SUBJECT performs ONE small motivated action]. [SECONDARY ENVIRONMENTAL MOTION]. Preserve the exact character identity, apparent age, hairstyle, wardrobe, room geometry, props and existing lighting logic. No new objects. No new people. No text changes. No unexplained light. Natural restrained cinematic motion. No facial morphing, no anatomy changes, no object teleportation.`

Optional:
`The shot ends with [specific composition] for edit continuity.`

Never overload one shot with five actions.

---

## 13. FIRST/LAST FRAME LAW

Use first/last-frame interpolation only if the frames are actually compatible:
- same actors;
- same wardrobe;
- same location;
- same approximate lens/perspective;
- same object topology;
- plausible action path.

Do NOT interpolate between unrelated portraits merely because they feature the same named character. This causes morphing.

If compatibility is poor:
animate each still separately and cut in the editor.

---

## 14. COVER / KEY ART CANON

Cover art is not a random beautiful scene.

It must pass:
1. identity;
2. premise;
3. genre;
4. hierarchy;
5. title-space;
6. thumbnail readability;
7. originality;
8. no false clue;
9. no visual contradiction;
10. platform crop safety.

Create one MASTER KEY ART, then adapt crops:
- 2:3 / audiobook;
- 1:1;
- 9:16;
- 16:9;
- thumbnail.

Typography remains a controlled design layer whenever correct title spelling matters. Do not rely on generative models to preserve exact brand text unless separately verified.

---

## 15. SHORT-FORM CONTENT SYSTEM

Every short must have one dominant promise:
- mystery hook;
- romantic tension;
- character;
- world/atmosphere;
- evidence/mechanism;
- danger;
- title/brand.

Do not cram all functions into every Reel.

Recommended structure:
`0.0–1.5 HOOK`
`1.5–5.0 QUESTION`
`5.0–10.0 ESCALATION`
`10.0–14.0 TURN`
`14.0–15.0 CLIFF / IDENT`
Adjust for 8–30 second formats.

The stinger may be 1–3 seconds but must not destroy retention. The first story image must still work immediately.

## 16. VISUAL RED TEAM PROMPT

Use this prompt BEFORE any shortlist:

### PROMPT — IVDIVO VISUAL ASSET RED TEAM
You are the IVDIVO Visual Continuity Director, cinematographer, production designer, prop master, VFX supervisor, AI-artifact forensic reviewer, mystery-continuity editor and short-form director.

Audit EVERY supplied frame. Do not shortlist first. Do not praise beauty before physical logic.

For each frame:
1. identify subjects/location/action;
2. verify identity and apparent age against LOCKED character references;
3. inspect face, hands, anatomy;
4. trace all important props, cables, phones and tools to plausible sources;
5. identify the source of every dominant light/reflection;
6. test architecture and perspective;
7. test story motivation: why is the character doing this here?
8. test mystery fairness: does the frame invent a clue, anomaly, room, number, supernatural event or spoiler?
9. assess wardrobe/time continuity;
10. assess Runway animation risk;
11. assess directing/composition value only after the above.

Output one row per frame:
FRAME | CONTENT | TECH PASS/FAIL/QUESTION | ANOMALY | IDENTITY | DIRECTING VALUE A/B/C | RUNWAY RISK L/M/H | DECISION HERO/KEEP/B-ROLL/SALVAGE/REMAKE/REJECT | EXACT USE.

If any physical element cannot be explained, mark QUESTION/ANOMALY. Never invent a story explanation merely to save a visually attractive image.

After all frames are audited, build the shortlist only from passing frames.

## 17. CHARACTER / SHOT REMAKE PROMPT COMPILER

### PROMPT — REMAKE A FAILED BUT VALUABLE FRAME
Inputs:
- SOURCE COMPOSITION FRAME = [ID]
- LOCKED FACE REFERENCE(S) = [IDs]
- LOCKED WARDROBE = [ID/family]
- LOCATION REFERENCE = [ID]
- STORY FUNCTION = [...]
- OBJECTS THAT MUST EXIST = [...]
- OBJECTS THAT MUST NOT EXIST = [...]
- LIGHT SOURCES = [...]
- CAMERA/LENS = [...]
- FAILURE TO FIX = [...]

Generate the same useful composition and camera angle, but replace the failed identity/object/light/anatomy details with the locked production references.

Hard constraints:
- preserve exact locked face identity and apparent age;
- natural dry skin; no sweat/oily/wet face unless story-motivated;
- preserve locked hair and wardrobe;
- no invented props/signage/room numbers;
- every cable and telephone receiver must terminate plausibly;
- every strong light must have a visible or physically plausible motivated source;
- no AI artifacts, extra fingers, duplicate bodies or impossible reflections;
- no new clue or supernatural event.

Return 3 controlled variants, not three unrelated reinterpretations.

## 18. RUNWAY SHOT PROMPT COMPILER

### PROMPT — BUILD RUNWAY SHOTS
Given an approved still sequence and script beat:
1. reject any incompatible first/last-frame pairing;
2. define one 2–4 second shot per beat;
3. specify the exact source still;
4. write one camera move;
5. write one character action;
6. write secondary environmental motion;
7. state objects/identity that must remain fixed;
8. state end composition;
9. state risk LOW/MEDIUM/HIGH;
10. propose a cut, dissolve, match cut, sound bridge or hard cut.

Never solve weak continuity by asking the video model to morph between inconsistent stills.

---

## 19. COVER PROMPT COMPILER

### PROMPT — AUDIOBOOK / SERIES COVER
Build a cover from locked character and location references.

Required:
- one dominant story proposition;
- exact character identity;

- plausible props;
- project-specific visual motif;
- negative space for typography;
- strong readability at phone-thumbnail size;
- no false clue/spoiler;
- no generic “two attractive people in a dark hotel” composition unless transformed by a project-specific mechanism.

Deliver:
A) 2:3 audiobook master
B) 9:16 motion-cover master
C) 1:1 social
D) typography-safe clean plate without generated text.

## 20. DAILY PRODUCTION GATE

Before rendering:
- Is the current story branch loaded?
- Are face references locked?
- Is wardrobe state named?
- Did every source image pass Gate 1?
- Are anomalies documented?
- Are shot pairs topology-compatible?
- Does each shot have one action?
- Does the prompt prohibit new objects/identity changes?
- Is title text handled separately?
- Can one failed shot be replaced without rerendering the sequence?

After rendering:
- inspect first frame, midpoint and last frame;
- inspect face age and identity;
- inspect hands;
- inspect cables/phones;
- inspect reflections;
- inspect light source;
- inspect room geometry;
- inspect text/numbers;
- inspect story implication;
- reject any “interesting accident” that violates canon.

---

## 21. FINAL PRINCIPLE

Do not trust the model’s visual fluency.

A production asset is approved because its
`IDENTITY + PHYSICS + STORY LOGIC + CONTINUITY + DIRECTING VALUE`
all survive inspection.

BEAUTY IS NOT A WAIVER.
