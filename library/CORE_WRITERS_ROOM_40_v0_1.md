# IVDIVO CORE WRITERS' ROOM 40 — v0.1

Status: WORKING / ACTIVE SHELF
Date: 2026-08-16

Purpose: establish a permanent, callable core library for IVDIVO production. Selection is by story function, not popularity.

Primary law:
`REFERENCE → DEEP READ → BOOK CARD → MECHANISM EXTRACTION → ROUTING → IVDIVO TRANSFORMATION → ORIGINAL STORY`

No source is IVDIVO canon. Source authority is task-specific. No source may override direct Founder instruction, approved canon, locked prior-book continuity, or current-book story causality.

## STATUS DEFINITIONS

- `DEEP_READ_COMPLETE_v0.1` — full text available and structurally processed; core chapters, thesis, mechanisms, failure modes and IVDIVO routing extracted. May receive later refinement.
- `DEEP_READ_IN_PROGRESS` — source being processed.
- `QUEUED` — selected for core, not yet granted deep-read status.
- `EXCLUDED_INTEGRITY` — removed because attribution/completeness/integrity failed.

## GOVERNANCE

Priority when sources disagree:
1. Current story causality and character truth.
2. Direct IVDIVO production canon.
3. Task-specific source whose specialty matches the problem.
4. Cross-source synthesis.
5. No formula wins by default.

A diagnostic source must not become a mandatory template. A fiction source is a mechanism laboratory, not a plot donor.

# CORE CALL RULES

When the Studio encounters a problem, it should call 2–4 complementary sources, not all 40.

Examples:
- Broken causality: Truby + Bickham + Swain.
- Weak opposition: McKee Story + Bell.
- Dead scene: Rosenfeld + Bickham + McKee Dialogue if conversation-heavy.
- Weak youth truth: Brody + Script Companion (FNL / MSCL / Veronica Mars) + future scientific Youth Psychology corpus.
- Flat relationship: Hayes + McKee Dialogue + relevant social script.
- SMITH institutional case: le Carré + McKee antagonism + Constantine/Sigma targeted mechanisms.
- AI/synthetic personhood: Murderbot + Ishiguro + Crouch; scientific AI/robotics corpus must be called separately once strengthened.
- Worldbuilding dump: Truby story-world integration + Wolf + Weir discovery loop.
