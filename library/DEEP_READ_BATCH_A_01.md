## A01 — JOHN TRUBY — THE ANATOMY OF STORY

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Story Architect / Dramaturg / Saga Architect
**BEST FOR:** causal architecture, organic story design, character webs, revelations, moral pressure, story-world integration.

### Deep-read finding
The book explicitly rejects externally imposed act breaks as the governing logic of story. Its central model is organic: character, plot, revelations, story world, moral argument, symbols, scenes and dialogue exist as interdependent systems.

The most useful compressed causal engine is:
`weakness/need → desire → opponent → plan → battle → self-revelation → new equilibrium`.

Underneath it is an even more useful motion rule:
`desire → action → learning → decision → changed action`.

### Transferable mechanisms
1. **Desire is the story spine.** Events become story only when they alter the protagonist's pursuit.
2. **Acting and learning must alternate.** New information that does not change behavior is lore, not story movement.
3. **Opponent defines hero relationally.** Opposition should expose the hero's weakness, not merely block a route.
4. **Character web > isolated biographies.** Major characters are best designed through structural contrasts and collisions.
5. **Revelation must change strategy.** A reveal earns its place through consequence.
6. **Story world is pressure architecture.** Setting matters when it shapes choice, cost and conflict.
7. **Subplots require complete miniature causality.** Decorative parallel material weakens narrative drive.

### IVDIVO transformation
Use Truby before prose to test whether HERO/WANT/OPPOSITION/PRICE/CLIMAX form one causal organism. In ORBITAL YOUTH, the orbital society must alter choices. In SMITH, Old Earth Security and Confederation Security must define each other's strengths/blind spots.

### Failure modes
- Turning a living draft into an abstract web diagram.
- Forcing self-revelation into explicit moral speech.
- Over-designing character functions until people feel engineered.

### Cross-source correction
Pair with Rosenfeld/Bickham for scene-level behavior and with McKee for antagonistic pressure. Truby governs architecture, not sentence-by-sentence prose.

## A02 — ROBERT McKEE — STORY

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Story Dramaturg / Red Team / Climax Architect
**BEST FOR:** value turns, progressive complications, antagonism, inciting incident, crisis/climax/resolution, audience expectation.

### Deep-read finding
McKee repeatedly distinguishes principles from formulas. Story design works when events create meaningful change and increasing antagonistic pressure. His strongest contribution to IVDIVO is not act-counting but the **Principle of Antagonism**: the protagonist can only become as interesting as the total forces opposing the protagonist's desire.

### Transferable mechanisms
1. **Story event = meaningful value change.** Something must become better/worse, safer/more dangerous, trusted/suspect, connected/severed, etc.
2. **Expectation/result gap creates action.** Character acts expecting X; reality returns Y; character must adapt.
3. **Progressive complication closes easy routes.** Repetition without narrowing options is not escalation.
4. **Antagonism is a field, not only a villain.** Inner conflict + relationships + institutions + environment can combine.
5. **Crisis is a choice under maximum pressure.** Climax should emerge from that choice, not merely spectacle.
6. **Resolution gives emotional aftershock.** Closing the main conflict before franchise hook is structurally sound.
7. **Audience is intelligent.** Exposition must not explain what the reader can infer.

### IVDIVO transformation
For every major conflict map the four antagonistic levels: SELF / PERSON / INSTITUTION / ENVIRONMENT. For climax ask: what choice becomes unavoidable only because earlier actions removed alternatives?

### Failure modes
- Treating every scene as a mechanically measurable value flip.
- Inflating antagonism until ordinary life disappears.
- Confusing cinematic economy with prose thinness.

### Cross-source correction
Truby supplies organic architecture; McKee supplies pressure and turns. Bickham/Swain test causal links at smaller scale.

## A03 — ROBERT McKEE — DIALOGUE

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Dialogue Editor / Relationship Room / Negotiation Engine
**BEST FOR:** dialogue as action, subtext, character-specific voice, indirect conflict, asymmetry.

### Deep-read finding
The foundational claim is operational: speech is action. A line is spoken because someone wants an effect. Dialogue works through the visible words while deeper desires/subtext drive tactics.

### Transferable mechanisms
1. **Every meaningful line performs a task.** Persuade, evade, seduce, test, dominate, soften, provoke, conceal, recruit, dismiss.
2. **Action/reaction moves beats.** Exchanges should alter leverage, knowledge, emotion or decision.
3. **Said / unsaid / unsayable.** Character depth grows when these layers disagree.
4. **Voice begins with vocabulary.** Syntax, rhythm, tonal habits and word choice differentiate speakers.
5. **Conflict need not be direct.** Asymmetric, indirect, implied and reflexive conflict avoid debate-club dialogue.
6. **On-the-nose language flattens scenes.** Characters rarely state the full true objective cleanly.
7. **Inner speech is also tactical.** A character can lie to, excuse, attack or persuade themselves.

### IVDIVO transformation
Youth dialogue gets a hard test: can the reader infer age, status, fear and relationship from the line without speaker labels? Institutional dialogue gets a second test: does each side possess different information and different authority?

### Failure modes
- Making every line too efficient or quotable.
- Eliminating realistic hesitation, interruption and failed wording.
- Turning subtext into a hidden second script that is too neat.

### Cross-source correction
Pair with *My So-Called Life* / *Veronica Mars* for youth messiness and Rosenfeld for scene intention.

## A04 — ROBERT McKEE — CHARACTER

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Character Director / Ensemble Cast Command
**BEST FOR:** true character under pressure, contradictions, inner/outer selves, cast design.

### Deep-read finding
A crucial distinction: **characterization** is observable/social presentation; **true character** is revealed through choices under pressure. Dimensionality grows through coherent contradiction rather than random traits.

### Transferable mechanisms
1. **Pressure reveals rather than explains.** Biography matters only insofar as it drives choice.
2. **Outer identity can conflict with private identity.** Status/performance vs need/fear is fertile drama.
3. **Contradiction needs a unifying cause.** Otherwise complexity becomes arbitrary quirks.
4. **Subconscious desire may oppose conscious want.** This generates self-sabotage without author explanation.
5. **Cast design is relational.** Characters should bring out different dimensions of one another.
6. **Institutions can function as character pressure.** Rules reveal the person by forcing compromised choices.
7. **Completed character ≠ fully explained character.** Mystery can remain after a decisive arc.

### IVDIVO transformation
Every major character passport must include: public role / ordinary want / hidden desire / fear / contradiction / pressure behavior / relationship asymmetry / mistake / price / change.

### Failure modes
- Psychology labels replacing scenes.
- Artificial contradiction inserted only to look complex.
- Equating extreme trauma with depth.

### Cross-source correction
Use Corbett/Card in later batch for alternative character methods; use McKee only as one lens.

## A05 — JAMES SCOTT BELL — CONFLICT & SUSPENSE

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Story Dramaturg / Mystery Architect / Reader Advocate
**BEST FOR:** stakes, trouble, competing wills, chapter propulsion, suspense questions.

### Deep-read finding
Bell's LOCK model is useful diagnostically: Lead / Objective / Confrontation / Knockout. More useful than the acronym is his insistence that meaningful opposition must hang real loss over the objective and that suspense is fundamentally the reader asking what happens next.

### Transferable mechanisms
1. **Objective must expose loss.** Physical, professional, psychological, relational or social death can work.
2. **Scene trouble is broader than violence.** Embarrassment, exclusion, money, status, trust and obligation are valid pressure.
3. **Dialogue conflict comes from incompatible agendas.** Not from everyone being witty.
4. **Inner conflict requires two strong sides.** Obvious correct answer is not dilemma.
5. **Suspense is a local unanswered question.** It need not be life-or-death.
6. **Stretch tension by delaying resolution while changing conditions.** Empty delay is padding.
7. **Middle needs renewed pressure, not repeated obstacles.**

### IVDIVO transformation
Reader Advocate asks every chapter: what concrete uncertainty carries me through the next page? ORBITAL YOUTH may use social questions as strongly as physical danger.

### Failure modes
- Overstating 'death' stakes.
- Forcing trouble into quiet scenes that need intimacy or reflection.
- Cliffhanger addiction.

### Cross-source correction
Rosenfeld protects scene variety; Truby protects causality; McKee guards against shallow antagonism.

## A06 — JORDAN ROSENFELD — MAKE A SCENE (REVISED & EXPANDED)

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Scene Engine / Development Editor
**BEST FOR:** scene launches/middles/endings, momentum, scene intention, scene types, transitions, revision.

### Deep-read finding
Rosenfeld's most useful definition treats scenes as real-time units of purposeful behavior. Momentum is the feature that most distinguishes scene from summary, while tension, new information, setting, POV and emotional movement make the scene worth experiencing.

### Transferable mechanisms
1. **Scene intention anchors behavior.** Someone wants an outcome now.
2. **Momentum means unfolding behavior.** Characters do not merely discuss context.
3. **New information should usually be consequential.** Often it grows from prior scenes.
4. **Scene type controls intensity.** Suspense, contemplative, dialogue, climactic and epiphany scenes require different balances.
5. **Setting can participate in action.** It should constrain, reveal or complicate.
6. **Scene endings should alter state.** Decision, discovery, setback, emotional shift or new obligation.
7. **Transitions protect narrative continuity.** A good next scene feels caused, not simply scheduled.

### IVDIVO transformation
Scene Gate remains: WHO WANTS WHAT? WHY NOW? WHAT STOPS THEM? WHAT CHANGES? Add a fifth diagnostic: WHAT SPECIFICALLY CAUSES THE NEXT SCENE?

### Failure modes
- Ingredient checklist prose.
- Every scene ending with an obvious 'turn'.
- Excessive real-time dramatization when summary would be better.

### Cross-source correction
Swain/Bickham offer sharper scene chaining; Rosenfeld offers broader scene ecology and variation.

## A07 — JESSICA BRODY — SAVE THE CAT! WRITES A YOUNG ADULT NOVEL

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Orbital Youth Director / Youth Audience / Genre Diagnostic
**BEST FOR:** YA age lens, story-worthy young protagonist, identity/independence pressures, YA genre expectations.

### Deep-read finding
The strongest IVDIVO-compatible idea is that YA is an **age category**, not a single genre. A young protagonist can carry SF, horror, mystery, romance or institutional drama, but the conflict must matter specifically to development, identity and independence.

The book defines a story-worthy hero through Problem + Want + Need, then applies a beat-sheet method across multiple YA story families.

### Transferable mechanisms
1. **Age changes the meaning of the same event.** Losing a job, lover, room, friend or status has developmental consequences.
2. **External genre engine + developmental engine must interact.** Otherwise teen drama becomes a detachable subplot.
3. **Institutionalized stories test belonging vs individuality.** Extremely useful for orbital school/work/security systems.
4. **Problem/Want/Need gives a fast hero diagnostic.**
5. **Series progression should not reset growth.** Later books inherit consequences.
6. **Final image can prove change through behavior/status, not explanation.**

### IVDIVO transformation
Use Brody to ask whether a plot could happen unchanged to a 40-year-old. If yes, ORBITAL YOUTH has probably lost its youth engine.

### Failure modes
- Beat-sheet compliance replacing causality.
- Flattening diverse youth into market-category assumptions.
- Treating identity as obligatory speech/theme rather than lived pressure.

### Cross-source correction
Scientific Youth Psychology corpus is still missing and must eventually override unsupported developmental assumptions. FNL/MSCL/Veronica Mars supply behavioral examples.

## A08 — LES EDGERTON — HOOKED

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Hook Architect / Opening Chapter Lab
**BEST FOR:** openings, inciting disturbance, story-worthy problem, backstory rationing, reader orientation.

### Deep-read finding
The book distinguishes the **surface problem** that launches visible action from the deeper **story-worthy problem** that gives the action lasting emotional meaning. It strongly resists opening with biography/setup detached from immediate dramatic need.

### Transferable mechanisms
1. **Start near active disturbance.** Not necessarily explosion—something meaningful is already off-balance.
2. **Surface problem opens action; deeper problem gives resonance.**
3. **Opening establishes story rules by demonstration.**
4. **Backstory is rationed by present need.**
5. **Character introduction should include behavior under pressure.**
6. **Opening should forecast the kind of story being promised.**
7. **A scene goal meeting incompatible resistance produces changed circumstances.**

### IVDIVO transformation
For every Book One/episode opening: observable present task first, then collision with anomaly/system/relationship. No early franchise cosmology dump.

### Failure modes
- Hyper-optimized 'hook' that misrepresents the novel.
- Artificial disturbance before reader understands why it matters.
- Withholding necessary orientation in fear of exposition.

### Cross-source correction
Use McKee/Truby to ensure the opening disturbance belongs to the main causal organism.

## A09 — DWIGHT V. SWAIN — TECHNIQUES OF THE SELLING WRITER

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Scene Engine / Line Causality / POV Mechanics
**BEST FOR:** stimulus-response clarity, scene/sequel, physical and perceptual causality, viewpoint selection.

### Deep-read finding
Swain works at a smaller mechanical scale than Truby/McKee. His value is precision: what the viewpoint character perceives, how they react, what they decide, and how action and aftermath connect.

### Transferable mechanisms
1. **Stimulus should precede understandable response.** Reader should know what caused behavior.
2. **POV selects experience.** Description is not neutral inventory.
3. **Scene drives toward a goal under conflict.**
4. **Sequel processes result.** Reaction → thought/dilemma → decision → next goal.
5. **Scene and sequel can vary greatly in length.** Function matters more than labels.
6. **Selection and arrangement create emphasis.** Concrete detail earns place through viewpoint/function.
7. **Micro-causality prevents generated-text gestures.** Actions arise from perceived stimuli, not filler choreography.

### IVDIVO transformation
Use as line-edit diagnostic when prose produces disconnected gestures, arbitrary looking around, or emotion labels. For synthetic bodies, stimulus-response differences can reveal new sensorium through action.

### Failure modes
- Robotic stimulus-response prose.
- Treating every interior passage as a formal sequel.
- Older commercial-writing assumptions treated as timeless law.

### Cross-source correction
Rosenfeld provides richer scene variety; McKee Dialogue prevents mechanized conversation.

## A10 — JACK M. BICKHAM — SCENE & STRUCTURE

**STATUS:** DEEP_READ_COMPLETE_v0.1
**PRIMARY ROLE:** Causal Chapter Map / Scene Engine / Escalation Editor
**BEST FOR:** scene chaining, cause/effect, scene/sequel, rising action through reduced options.

### Deep-read finding
Bickham makes linear causality explicit: scenes should not sit beside one another; results generate the next problem. His strongest practical contribution is escalation through **logical but not circular consequences** and tightening options.

### Transferable mechanisms
1. **Cause/effect links scenes.** Reordering scenes without damage is a warning sign.
2. **Scene result creates next necessity.**
3. **Disaster/new problem should evolve conflict, not repeat it.**
4. **Sequel converts consequence into decision and new goal.**
5. **Escalation narrows easy exits.** Later choices become more costly.
6. **Reader propulsion depends on unfinished causal business.**
7. **Scene chains produce plot; summaries of plans do not.**

### IVDIVO transformation
Causal Chapter Map should include for every chapter: `INPUT CONSEQUENCE → ACTIVE WANT → RESISTANCE → RESULT → DECISION/OBLIGATION → NEXT CHAPTER CAUSE`.

### Failure modes
- Forcing every scene to end in disaster.
- Popular-fiction pacing applied to scenes whose function is grief, intimacy, wonder or recovery.
- Excessive linearity suppressing ensemble/polyphonic structure.

### Cross-source correction
Truby allows branching story organism; Rosenfeld supports scene diversity; FNL shows ensemble pressures occurring simultaneously.

# RED TEAM — WHAT BATCH A MUST PREVENT

1. Events arriving while protagonist only receives exposition.
2. Repeated obstacles instead of escalation.
3. Scenes serving only lore delivery.
4. Dialogue where everyone states correct positions.
5. Character biographies substituted for pressure choices.
6. YA that is adult story with teenage ages.
7. Hooks unrelated to the book's actual engine.
8. Mechanical scene/sequel or beat-sheet compliance.
9. Climax spectacle without protagonist choice.
10. Series hook appearing before current main conflict resolves.
