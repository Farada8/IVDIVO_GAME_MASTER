## Core mechanisms extracted

1. **Opening as dramatized inciting incident.** The opening is not primarily setup; it dramatizes the event that generates the protagonist’s first actionable problem.
2. **Surface Problem / Story-Worthy Problem duality.** The immediate external problem must be organically linked to a deeper psychological or identity-level problem that the story gradually reveals.
3. **Causal mutation of surface problems.** Later surface problems may change or escalate, but each should grow out of the previous problem instead of arriving as unrelated episodic trouble.
4. **Minimum viable setup.** Setup and backstory should orient the reader only as much as the current dramatic action requires; larger explanation can follow after the problem is alive.
5. **Opening obligation stack.** A strong opening should introduce the deeper problem, generate reader propulsion, establish story rules, and contain some forecast/foreshadowing of the story’s eventual direction.
6. **Start where trouble becomes story.** Events before the protagonist’s world is meaningfully disturbed are generally setup/backstory, not necessarily the best narrative starting point.
7. **Action reveals inner problem.** The protagonist can begin responding to the deeper problem before consciously understanding or being able to articulate it.
8. **Problem-goal transition.** The opening creates the problem; subsequent scenes become goal-driven attempts to resolve consequences of that problem.
9. **Hook is not merely novelty.** A hook is strengthened when strange/interesting information is attached to a consequential change in the protagonist’s situation.
10. **Opening economy.** Character, setting, language, foreshadowing and backstory support the primary dramatic components rather than replace them.

## IVDIVO application

For `Miss Gallagher / Smith–Enya`, use the hotel/carrier operation as the immediate surface problem generator. Enya’s impossible classification should attack Smith’s deeper identity/world-model problem. Exposition about ownership, tethering, jurisdiction or metaphysical systems should arrive primarily through Smith’s failed tests, revised hypotheses and consequential choices.

For youth books, connect the spectacular trigger to a psychologically age-specific story-worthy problem (belonging, autonomy, shame, identity, recognition, attachment, fear of exclusion) instead of treating the supernatural/technological event as sufficient story by itself.

## Writers’ Room diagnostic

Before approving an opening ask:

`INCITING EVENT -> INITIAL SURFACE PROBLEM -> FIRST ACTION -> DEEPER STORY-WORTHY PROBLEM INDICATED -> CAUSAL NEXT PRESSURE`

If the opening can be removed without changing the protagonist’s causal trajectory, it is probably setup rather than the true beginning.
