# IVDIVO ACTIVE SHELF POLICY

## Principle
ChatGPT Library is a working cache, not the permanent archive.

## Target size
Keep approximately 50–100 highly relevant originals active when practical:
- 20–40 persistent S-tier craft/reference sources;
- 20–60 current-project sources selected for the book, arc, character, research problem or revision pass.

The exact count is functional, not ceremonial.

## Promote to Active Shelf when
- Writers’ Room repeatedly reopens the source;
- the current book requires close scene-level comparison;
- a source contains craft guidance used in repeated production passes;
- a Book Card is insufficient for the present task;
- source verification requires direct access to the original.

## Demote from Active Shelf when
- the relevant mechanisms have been extracted and the current task ended;
- the source is low-frequency reference material;
- a searchable Drive copy plus Book Card is sufficient;
- it duplicates another active edition.

## Persistent S-tier candidates
Final membership is determined by evidence from production, not reputation. Typical roles include story architecture, dialogue/subtext, scene construction, revision, YA/series structure, youth psychology and the strongest representative scripts/novels actually used by IVDIVO.

## Retrieval flow
`PROBLEM → registry → mechanism bank → ranked source set → Book Cards → reopen only the necessary Drive originals → Writers’ Room decision → Writer → Red Team`.

## No-majority rule
Books do not vote. Contradictory craft systems must be resolved by the needs of the story and the IVDIVO production canon, not by counting how many authors repeat a rule.
