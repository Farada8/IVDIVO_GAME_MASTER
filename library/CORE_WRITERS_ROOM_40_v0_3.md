## STOP-RESEARCH RULE

The Core exists to accelerate story production, not postpone it.

For a live problem:
1. Name the exact story failure.
2. Call 2–4 best-fit Core sources.
3. Extract the abstract mechanism.
4. Transform through IVDIVO.
5. Test against character truth, causality and canon.
6. If two independent sources converge and a causal solution is available: **STOP RESEARCH AND WRITE STORY**.

No further expansion of the Core is justified merely because more books exist.
