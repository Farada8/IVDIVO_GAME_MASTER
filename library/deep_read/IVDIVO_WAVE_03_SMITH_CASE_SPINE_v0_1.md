# IVDIVO DEEP READ WAVE 03 — SMITH / OLD EARTH SECURITY CASE SPINE v0.1

Status: WORKING PRODUCTION STANDARD / SOURCE-SYNTHESIS
Date: 2026-08-16
DR3 sources: Tinker Tailor Soldier Spy; Sandstorm; Storm Front; The Da Vinci Code; Constantine TV selected corpus.

No source world or mythology is canon. This file abstracts mechanisms only.

# 1. SMITH PRIMARY LAW

SMITH IS NOT A GENERIC MONSTER HUNTER.

A Smith story is driven by a security problem where:
- observable anomaly contradicts at least one accepted model;
- Old Earth Security possesses historical/procedural memory others lack;
- Confederation/security science can measure or model something Old Earth cannot;
- jurisdiction and interests conflict for legitimate reasons;
- past agreements/successes/crimes remain operationally relevant;
- current case is resolved completely enough to stand as a story;
- consequence permanently alters trust, doctrine, relationship or jurisdiction.

# 2. MASTER CASE LOOP

`OBSERVABLE WRONGNESS`
→ `LOCAL HUMAN/INSTITUTIONAL CONSEQUENCE`
→ `FIRST ORDINARY EXPLANATION`
→ `EVIDENCE CONTRADICTS IT`
→ `OLD EARTH RECOGNITION / ARCHIVE TRACE`
→ `CONFEDERATION MEASUREMENT / DIFFERENT MODEL`
→ `JURISDICTIONAL DISAGREEMENT`
→ `ACTION TESTS BOTH MODELS`
→ `RESULT ≠ EITHER COMPLETE EXPECTATION`
→ `ARCHIVE/TESTIMONY/PHYSICAL CLUE REINTERPRETED`
→ `OLD DEBT / AGREEMENT / ERROR SURFACES`
→ `FORCED COOPERATION OR PRINCIPLED BREAK`
→ `CRISIS CHOICE ABOUT SECURITY VS PERSON/RULE/TRUTH`
→ `IMMEDIATE THREAT RESOLVED`
→ `PRICE / AFTERMATH / DOCTRINE CHANGE`
→ only then `SERIES CONSEQUENCE`.

# 3. FIVE KNOWLEDGE CHANNELS

Every substantial Smith case should use at least three, preferably four/five:

1. **PHYSICAL PHENOMENON** — what bodies/materials/instruments actually do.
2. **OLD ARCHIVE** — prior encounter, agreement, containment, person, place, taboo, failure.
3. **CONFEDERATION MODEL** — modern measurement, comparison, simulation, nonhuman knowledge.
4. **HUMAN TESTIMONY** — memory, lie, social history, local knowledge, witness behavior.
5. **ADVERSARY/ENTITY BEHAVIOR** — actions that reveal objective, constraints, communication or misunderstanding.

No one channel is automatically authoritative.

# 4. INSTITUTIONAL CONFLICT ENGINE

`SAME EVENT → DIFFERENT CLASSIFICATION → DIFFERENT LEGAL/ETHICAL DUTY → DIFFERENT ACTION`.

Old Earth may prioritize agreement/containment/secrecy based on historical consequences.
Confederation may prioritize evidence/personhood/scientific risk/universal procedure.
Local planetary authority may prioritize public safety/property/sovereignty.
Affected subject/entity may have its own rights/objectives.

Conflict should not be 'bureaucrats obstruct hero.' Each position needs a cost of being wrong.

# 5. ARCHIVE MYSTERY ENGINE

Use le Carré-type institutional memory rather than lore dumps:

`OLD FILE/TESTIMONY`
→ `EXPECTED PROCEDURE`
→ `MISSING/INCONSISTENT DETAIL`
→ `WHO HAD ACCESS?`
→ `WHOSE CAREER/RELATIONSHIP CHANGED?`
→ `WHY WAS THIS CLASSIFIED THIS WAY?`
→ `CURRENT EVIDENCE REOPENS THE PAST`
→ `OLD SUCCESS/CRIME REINTERPRETED`.

Archive fact must alter present action.

# 6. CLUE/DISCOVERY ENGINE

From Brown + Rollins + Constantine:

`TRACE/CLUE → PROVISIONAL INTERPRETATION → ACTION/TEST → PARTIAL ANSWER → NARROWER QUESTION → NEW LOCATION/PERSON/PROCEDURE → HIGHER COST`.

A clue fails if it only proves the writer researched something.

# 7. EXPERT TEAM ENGINE

A case team may require:
- Smith / Old Earth procedural-historical knowledge;
- Confederation security scientist/operator;
- local authority/person with jurisdiction;
- domain specialist (biology, language, material, history, AI, environment);
- affected witness/subject with nonreplaceable lived knowledge.

Each must have a goal and risk beyond their skill.

# 8. ENTITY/ANOMALY REVEAL LAW

`PHENOMENON FIRST → PATTERN → FAILED NORMAL EXPLANATION → EXPERT RECOGNITION → TEST → PROVISIONAL ONTOLOGY`.

Do not begin with correct taxonomy.
Entity behavior may be message, defense, contract enforcement, migration, reproduction, rescue, misunderstanding or crime—not automatically predation.

# 9. PROFESSIONAL PRICE

Smith's knowledge should cost something:
- legal exposure;
- obligation to an old agreement;
- personal debt;
- loss of institutional trust;
- risk of reopening a past crime;
- forbidden method required to understand threat;
- choice between containment and personhood/justice;
- responsibility for prior Old Earth action.

If Smith can always say 'I know this one' and perform a ritual, the line fails.

# 10. SMITH STORY GATE

1. What concrete anomaly starts the case?
2. Who is harmed/threatened now?
3. What ordinary explanation is initially reasonable?
4. What does Old Earth know that Confederation does not?
5. What does Confederation understand better?
6. Why do their duties imply different actions?
7. What old agreement/success/crime matters?
8. What clue/test changes the working model?
9. What can the entity/opponent actually want?
10. What is Smith personally risking besides death?
11. What choice resolves the main case?
12. What price is paid?
13. What is now permanently different?
14. Is the immediate conflict genuinely closed before saga hook?

# 11. RED TEAM FLAGS

FATAL:
- generic monster hunt;
- threat solved by unexplained old lore/power;
- no protagonist climax choice;
- main case left open to advertise sequel.

MAJOR:
- Confederation exists only to be naïve;
- Old Earth exists only to be secretly wise;
- local authorities are idiots;
- archive is exposition without present consequence;
- clue chain is decorative puzzle sequence;
- every anomaly tied coincidentally to Smith's personal past;
- scientific explanation settles ethics automatically;
- entity has no objective/constraint beyond 'evil';
- team members exist only as skills.

# 12. ROUTING

le Carré → archive, trust, internal compromise, testimony, biography.
Rollins → interdisciplinary field team, physical anomaly, expedition/location hazard.
Storm Front → professional economics, double jurisdiction, forbidden investigation, suspicion.
Da Vinci Code → answer→new-question clue propulsion and complementary interpretation.
Constantine → phenomenon-first, reluctant expert, old debt, dangerous training/knowledge, morally costly containment.
