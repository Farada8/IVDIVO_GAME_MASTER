# 3. Normalized claim set

R06-C01. A scene is strongest when it is causally connected to prior consequences and leaves a changed state that affects what follows.

R06-C02. Scene intention is an immediate planned action; motivation is why it matters; plot intention is the larger desired outcome. Confusing these levels produces passive or abstract scenes.

R06-C03. A scene may be quiet and still be causal through emotional, relational, epistemic or decision change.

R06-C04. Support/success is as legitimate as opposition when it changes the story. Endless thwarting is not a virtue.

R06-C05. Launch mode is functional, not hierarchical: action, setting, dialogue, character, narrative or sensory entry can work if it immediately establishes the scene’s job.

R06-C06. Scene endings should create a meaningful changed state or resonance; cliffhanger is one option, not a requirement.

R06-C07. Setting and sensory detail earn space when they change action, perception, risk, relationship, mood, knowledge or future payoff.

R06-C08. Subtext is best treated as `surface action + inferable second meaning`; explanatory decoding immediately afterward destroys reader participation.

R06-C09. Suspense is meaningful uncertainty under stakes and can be accelerated or deliberately slowed. Short syntax is not a suspense requirement.

R06-C10. Direct dialogue is most valuable when exact wording itself changes power, consent, trust, evidence, relationship, decision or emotion.

R06-C11. Flashback must alter the reader’s/character’s model of the present; otherwise it is backstory excursion.

R06-C12. Epiphany must be earned by prior experience/evidence and must change behavior, readiness, relationship or choice.

R06-C13. Final scene should demonstrate the consequence/state created by the main story; local conflict closes before optional saga hook.

R06-C14. POV is an access/distance system, not merely pronoun choice. Uncontrolled switching creates disorientation.

R06-C15. A change of POV should buy materially different knowledge, interpretation, emotional cost or dramatic function.

R06-C16. Character hierarchy should control page/POV budget, but Rosenfeld’s prescription of near-equal stage time for all co-protagonists is not universal.

R06-C17. Secondary/minor characters should have clear story functions, but in ensemble/social fiction they must not be reduced to protagonist-serving equipment.

R06-C18. Transitions exist to orient the reader after meaningful changes and to bypass mundane logistics.

R06-C19. Scene-level revision should test relevance, causal connection, character effect, new information/meaning and future consequence before line polishing.

R06-C20. Rosenfeld’s vignette checklist is useful diagnostically but too absolute: a scene need not answer every plot-centric question “yes” if it produces valid relationship/emotional/epistemic/decision causality.

# 4. Mechanism library

## R06-M01 — SCENE CAUSAL RECURSION
`PRIOR CONSEQUENCE → IMMEDIATE INTENTION → ACTION → RESISTANCE / SUPPORT → RESULT → CHANGED STATE → NEXT INTENTION`.

Use as the default scene-engine diagnostic, not a mandatory prose template.

## R06-M02 — SCENE FUNCTION STACK
For a candidate scene identify:
`PRIMARY JOB + SECONDARY JOB(S) + READER EFFECT + CHANGED STATE`.
If no primary job exists, compress/merge/cut before line editing.

## R06-M03 — LAUNCH ROUTING
Choose launch by scene need:
- ACTION when motion/decision already exists;
- SETTING when environment creates pressure/opportunity;
- DIALOGUE when exact words immediately alter the situation;
- CHARACTER/INTERIOR when interpretation is the new action;
- NARRATIVE SUMMARY when mundane time/logistics should be skipped.

## R06-M04 — SUBTEXT LAYER
`VISIBLE WORD/ACTION → UNSTATED AGENDA / HISTORY / FEAR / DESIRE → READER INFERENCE`.
Do not append narrator explanation if inference is already legible.

## R06-M05 — TENSION WITHOUT MELODRAMA
`LEGITIMATE WANT + UNCERTAINTY + POWER/EXPECTATION GAP + CONSEQUENCE`.
Prefer behavior, silence, omission, restrained physical response and competing reasonable goals over emotional overstatement.

## R06-M06 — CONTEMPLATIVE CAUSALITY
`PRESSURE/EVENT → PROCESSING → REINTERPRETATION → DECISION/READINESS/RELATIONSHIP CHANGE → RETURN TO ACTION`.

## R06-M07 — SUSPENSE PACE CONTROL
`READER QUESTION → INFORMATION CONTROL → DELAY/DETAIL → INTERPRETATION OPTIONS → COLLAPSE OF UNCERTAINTY → CONSEQUENCE`.
Pace is selected for reader effect; it may slow near danger.

## R06-M08 — DIALOGUE MODE ROUTING
Use **DIRECT** when wording changes the state.
Use **INDIRECT/SUMMARY** for routine logistics, repeated explanation or process whose wording does not matter.

## R06-M09 — FLASHBACK PRESENT-VALUE TEST
`PAST SCENE → NEW PRESENT MODEL → PRESENT DECISION/RELATIONSHIP/EVIDENCE CHANGE`.
If arrow 2 or 3 is missing, compress as backstory or cut.

## R06-M10 — EARNED EPIPHANY
`ACCUMULATED EXPERIENCE/EVIDENCE → OLD MODEL FAILS → RECOGNITION → COST → NEW CHOICE`.

## R06-M11 — POV SWITCH VALUE
Switch only if the new viewpoint materially changes at least one:
`KNOWLEDGE / INTERPRETATION / EMOTIONAL PRICE / IRONY / DECISION ACCESS`.
Orient person/place/time quickly.

## R06-M12 — CHARACTER STATUS AUDIT
Assign `PRIMARY / SECONDARY MAJOR / SUPPORTING / MINOR / WALK-ON` and check actual page/POV/arc promises against status.
Do **not** mechanically equalize co-protagonist word counts.

## R06-M13 — TRANSITION COMPRESSION
At every scene break ask:
`WHAT CHANGED? PERSON? PLACE? TIME? STATE?`
Orient only what the reader needs; skip travel/process unless travel/process contains story value.

## R06-M14 — OBJECT ATTENTION CONTRACT
`TEXTUAL ATTENTION → READER EXPECTATION OF FUNCTION`.
If a SF object/interface receives disproportionate descriptive attention, it must affect action, character, meaning or payoff.

## R06-M15 — SCENE RELEVANCE TEST
Before line edit:
1. What changed because this scene exists?
2. What prior consequence caused it?
3. What future scene/choice becomes different?
4. What character/relationship/evidence state changes?
5. If cut, what irreplaceable function disappears?

If nothing irreplaceable disappears, merge/compress/cut.

## R06-M16 — REVISION ORDER
`BOOK ENGINE → CHAPTER CAUSALITY → SCENE FUNCTION → POV/STAGING → PARAGRAPH/RHYTHM → SENTENCE/WORD`.
Do not use scene checklists to cosmetically repair a structurally wrong story.

# 5. Failure modes

- **ACTION-LAUNCH MONOCULTURE** — every scene begins with physical motion regardless of function.
- **COMPLICATION INFLATION** — more obstacles added because “something must go wrong.”
- **WITHHOLDING MONOCULTURE** — characters hide natural information merely to sustain tension.
- **ENDING RESTATEMENT** — scene shows change, then narrator explains the change again.
- **OBJECT FALSE PROMISE** — SF object gets attention without later function.
- **SETTING TOURISM** — worldbuilding pauses story instead of changing choice/perception.
- **SENSORY CHECKLIST PROSE** — five senses inserted as inventory.
- **FILTER DISTANCE** — repeated “he saw/he heard/he felt” unnecessarily separates reader from established POV.
- **PLOT-POLICE OVERREACH** — quiet relational/emotional/epistemic scenes cut because no large external event occurs.
- **INTENTION THWARTING LOOP** — every intention blocked, making competence impossible.
- **PROLOGUE INSURANCE POLICY** — prologue exists only because Chapter 1 lacks pressure.
- **CONTEMPLATION LOOP** — multiple processing scenes repeat the same conclusion.
- **SUSPENSE SPEED ERROR** — short sentences assumed to equal suspense.
- **DEBATE DIALOGUE** — characters become essay voices rather than tactical people.
- **REVEAL WITHOUT AFTERMATH** — information changes nothing.
- **BACKSTORY EXCURSION** — flashback has no present consequence.
- **TRIUMPH MONOCULTURE** — climax forced into victory frame.
- **LESSON DOWNLOAD** — protagonist suddenly “understands the theme.”
- **FINAL-SCENE THEME SLOGAN** — last line summarizes author philosophy.
- **POV WHIPLASH** — access changes without structural reason/orientation.
- **EQUAL-TIME ENSEMBLE ACCOUNTING** — co-protagonists mechanically receive equal POV/page shares even when one book has a primary story owner.
- **ALLY-AS-TOOL** — supporting person exists only to help protagonist and has no independent life.
- **MINOR-CHARACTER FALSE PROMISE** — vivid recurring minor is given enough interior/page weight to imply an unpaid arc.
- **TRANSITION LOGISTICS DRAMATIZATION** — every commute, door, transfer and setup is played in real time.
- **VIGNETTE FALSE POSITIVE** — useful quiet/relationship scene deleted because it fails one plot-centric checklist item.
- **CHECKLIST PATCHING** — scene ingredients added cosmetically instead of fixing structural cause.

# 6. Cross-source comparison

## Rosenfeld + Bell (*Conflict & Suspense*)
Agreement: meaningful uncertainty, local tension, modulation, scene pressure. Rosenfeld usefully confirms that suspense may slow down; Bell is stronger on intelligent opposition and suspense questions. IVDIVO synthesis: `CARE → UNCERTAINTY → PRESSURE → CHOICE → CONSEQUENCE`, with pace chosen by reader effect.

## Rosenfeld + Card (*Characters & Viewpoint*)
Agreement: POV controls access/intimacy and character hierarchy matters. Card is stronger on narrator purpose, attention budget and fair withholding. Rosenfeld’s equal-time prescription is rejected when it conflicts with Card/IVDIVO book-level hierarchy.

## Rosenfeld + Kress
Agreement: motivation must produce action; emotional response must be character-specific and causally prepared. Kress is stronger on frustration fingerprints and breaking-point preparation.

## Rosenfeld + Hodgins
Agreement: setting/scene/POV/character are an interacting system. Hodgins is stronger on whole-narrative integrity and re-imagining a scene when staging/POV is wrong.

## Rosenfeld + Chatman
Tension: Rosenfeld’s vignette rhetoric is more plot-centric; Chatman shows that satellites may be structurally optional yet artistically essential. IVDIVO keeps satellite scenes when they earn character, relationship, atmosphere, foreshadowing or emotional preparation and are not redundant.

## Rosenfeld + Zunshine
Agreement: POV/information control matters. Zunshine is stronger on source-monitoring and the difference between observation, inference and fact; Rosenfeld’s suspense withholding is accepted only when epistemically fair.

## Rosenfeld + Oatley/Herman
Rosenfeld explains scene delivery; Oatley/Herman better explain goal-plan simulation, reasons for action and person-level interpretation. IVDIVO therefore rejects scene “energy” that is not grounded in a person’s real reason/concern.

## Rosenfeld + Le Guin/Clark
Agreement: pacing/rhythm must vary by function. Le Guin/Clark provide the stronger anti-choppy correction: sentence/paragraph length is contrast and intent, never a numeric KPI.

# 7. IVDIVO operationalization

## Global production law
A scene survives because it produces a **meaningful changed state**, not because it contains mandatory conflict, action, a cliffhanger or every checklist ingredient.

Valid scene causality classes:
- EVENT;
- DECISION;
- EMOTIONAL;
- RELATIONSHIP;
- EPISTEMIC;
- STATUS/ACCESS;
- SAFETY/COORDINATION.

## ONE MAIN STORY
Every scene must either:
1. advance/complicate the A-story;
2. change a major relationship/character strategy that will alter the A-story;
3. change evidence/knowledge that alters later action;
4. provide necessary recovery/preparation whose consequences become causal.

Otherwise compress/merge/cut.

## Post-money Orbital Youth
Do not use wages/rent/credits as easy intention engines. Scene intention can come from:
- trust;
- one specific responsibility;
- qualification/mastery;
- belonging/team place;
- reputation;
- consent/privacy;
- family obligation;
- relationship;
- unique experience;
- limited time/access/window;
- safety responsibility.

## Conscious robots
Rosenfeld’s “secondary characters serve protagonist” rule is explicitly insufficient. A conscious robot must have independent goals, relationships, rights/refusal and off-scene obligations. If replacing it with a smart appliance leaves the scene unchanged, rewrite.

## Specialist consciousness schools
Use setting/POV causally: reveal the school through what a practitioner can reproducibly do, years of training, competing interpretations, teacher lineage, personal cost and disputed evidence. Do not convert niche knowledge into omniscient exposition.

## Prose / anti-fragmentation
Transitions should skip dead logistics. Do not dramatize `door → corridor → ride → arrival` unless one step carries conflict, relationship, discovery, humor, sensory disorientation or decision value. Short paragraphs remain when they create real emphasis; they are not automatically defects.

# 9. Final production gates

- **R06-G01 PRIOR CONSEQUENCE:** scene intention must arise from an existing situation/consequence unless the scene is an initiating event.
- **R06-G02 INTENTION LEVEL:** distinguish immediate intention, underlying motivation and plot-level want.
- **R06-G03 CHANGED STATE:** scene ends with altered event/decision/emotion/relationship/knowledge/status/safety state.
- **R06-G04 NO MANDATORY FAILURE:** success/support/competence allowed when consequential.
- **R06-G05 LAUNCH FUNCTION:** choose launch by job; no action-opening monoculture.
- **R06-G06 SUBTEXT INFERENCE:** do not explain second meaning after reader can infer it.
- **R06-G07 SUSPENSE PACE:** choose sentence/paragraph pace from reader effect, not “short = tense.”
- **R06-G08 DIALOGUE VALUE:** exact words must matter or compress to indirect/summary.
- **R06-G09 FLASHBACK PRESENT VALUE:** past scene changes present model/action.
- **R06-G10 EARNED EPIPHANY:** insight comes from accumulated evidence/experience and changes behavior.
- **R06-G11 FINAL LOCAL CLOSURE:** resolve book conflict before saga hook.
- **R06-G12 POV INTEGRITY:** no unmotivated access shifts/head hopping.
- **R06-G13 POV SWITCH PAYMENT:** new POV buys knowledge/interpretation/emotional/decision value.
- **R06-G14 NO EQUAL-TIME ACCOUNTING:** ensemble hierarchy outranks mechanical POV equality.
- **R06-G15 INDEPENDENT SUPPORTING PERSON:** recurring ally/robot/local has life beyond serving protagonist.
- **R06-G16 TRANSITION ECONOMY:** skip mundane logistics unless causally valuable.
- **R06-G17 OBJECT ATTENTION:** descriptive emphasis must earn later function.
- **R06-G18 QUIET-SCENE PROTECTION:** relationship/emotional/epistemic/decision causality can justify scene.
- **R06-G19 STRUCTURAL REVISION FIRST:** book/chapter/scene function before line edit.
- **R06-G20 CUT TEST:** if scene is removed, identify the irreplaceable changed state/payoff lost; if none, merge/compress/cut.

# 10. Final verdict

Rosenfeld is strongest as a **scene-system and revision diagnostic**, especially for causal scene intentions, subtext, tension, contemplative scenes, dialogue, transitions and POV continuity.

Her weakest transferable areas are overprescriptive genre assumptions: near-equal time for co-protagonists, allies defined mainly by service to protagonist, universal antagonist pressure, plot-centric vignette tests and Triumph-style climax doctrine.

IVDIVO synthesis keeps the mechanisms and rejects the monocultures.
