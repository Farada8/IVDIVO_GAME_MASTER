## Transferable mechanisms
1. **YA is age lens, not genre.** SF, horror, mystery, romance and institutional drama can all be YA if youth development changes the story.
2. **Story-worthy hero = problem + goal + need.** Reader tracks how events change the hero, not only whether plot succeeds.
3. **External events should trigger internal realization, which triggers proactive decision.** This cross-checks Truby/Swain causality.
4. **Group membership is developmentally charged.** Institutional stories work when belonging/safety/status conflicts with self-definition.
5. **Independence has partial, not absolute, form.** Road/quest stories resonate because teens gain new mobility while still constrained by adults/resources/rules.
6. **Power needs a curse/price.** Ability should complicate identity, relationships and ordinary life rather than only upgrade action capacity.
7. **Friendship/romance can be developmental engine.** Relationship changes how hero sees self/world and must interlock with A-story.
8. **Outsider stories test individuality against establishment.** Being different should create actual social/institutional consequences.
9. **Genre is a diagnostic, not a prison.** A sequel can use a different dominant engine if the new book has a new main conflict.
10. **Series installments still owe local closure.** Even when a larger nemesis survives, the current installment needs a completed confrontation and transformed state.
11. **Youth magic/high concept must connect to experiences of the age group.** Otherwise it is an adult story with teenage casting.
12. **Transformation outranks spectacle.** Space battles and powers matter insofar as they force identity/relationship/independence choices.
