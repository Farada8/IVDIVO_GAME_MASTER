# IVDIVO CORE 40 — DEEP READ REGISTRY v0.1

Status: WORKING / PRODUCTION INFRASTRUCTURE
Date: 2026-08-16

Purpose: convert the strongest reference sources in the normalized IVDIVO library into a persistent, callable Writers' Room core.

Primary law:
`REFERENCE → DEEP READ → ABSTRACT MECHANISM → CROSS-SOURCE CHECK → IVDIVO TRANSFORMATION → ORIGINAL STORY`.

No source below becomes IVDIVO canon merely by entering CORE 40.

## Deep-read states

- `DR0 INVENTORIED` — source identified, integrity/role known, not yet systematically read.
- `DR1 STRUCTURAL READ` — contents/architecture + beginning + representative middle/late material inspected; role and limits verified.
- `DR2 MECHANISM READ` — multiple relevant sections/scenes read and transferable mechanisms extracted.
- `DR3 CORE READY` — dedicated Book Card completed, mechanisms cross-checked against at least one independent source, failure modes and IVDIVO routing recorded.
- `HOLD` — source has a technical/completeness/representativeness problem and cannot be promoted.

A source is not described as 'deep read complete' before DR3.

## Required DR3 Book Card

1. Bibliographic identity / Drive identity.
2. Integrity and completeness status.
3. What the source is uniquely strong at.
4. What NOT to take from it.
5. Structural map / contents map.
6. 8–20 transferable mechanisms, depending on source richness.
7. Trigger / sequence / reader effect / failure mode for each major mechanism.
8. Character mechanisms.
9. Scene/dialogue mechanisms.
10. Escalation/payoff mechanisms.
11. World/institution/social mechanisms where applicable.
12. Exact best-use routing to Writers' Room modules.
13. Cross-source agreement and disagreement.
14. IVDIVO transformation notes.
15. Canon firewall: explicit statement that reference content is not canon.

## Hard rules

1. Story beats are never copied.
2. Distinctive characters, scenes, dialogue, terminology and signature inventions are never transplanted.
3. A mechanism must be abstract enough to survive transformation into IVDIVO.
4. At least two independent sources should support any mechanism promoted to a permanent production rule, unless the mechanism is explicitly marked source-specific.
5. Current-book causality outranks franchise usefulness.
6. `DR2` is not 'book fully read'. Only DR3 permits the source to be called CORE READY.
7. A full-text problem, scan problem or fragment blocks DR3 promotion.
8. Scientific and psychological claims cannot be inferred from fiction. Fiction supplies story mechanisms only.
9. Comparative metaphysics remains REFERENCE ONLY until the Founder separately approves an IVDIVO transformation as canon.
10. The active Writers' Room should route by task, not load all 40 sources indiscriminately.

## Current baseline

Existing source-grounded mechanism passes already cover M001–M132 across story architecture, dialogue/scenes, youth voice, SMITH/institutions, AI/personhood/discovery, comparative metaphysics, relationships/ordinary life and youth behavior. The CORE 40 program does not replace those passes. Its job is to deepen, verify, consolidate and attach them to stable source passports.
