# IVDIVO CORE WRITERS' ROOM — ROUTING MATRIX v0.1

Status: WORKING / ACTIVE
Date: 2026-08-16

Purpose: route story problems to a small set of relevant deep sources. Do not invoke the whole library for every task.

Rule: `PROBLEM → 2–4 SOURCES → ABSTRACT MECHANISMS → IVDIVO STORY DECISION`.

---

## STORY CORE / ARCHITECTURE

### Broken causality / episodic fragments
PRIMARY: Truby — *The Anatomy of Story*
SECONDARY: Bickham — *Scene & Structure*; Swain — *Techniques of the Selling Writer*
CHECK: McKee — *Story*
OUTPUT TEST: Can every major turn be expressed as consequence of prior action/learning/choice?

### Passive protagonist
PRIMARY: Truby
SECONDARY: Bell — *Conflict & Suspense*; McKee Story
OUTPUT TEST: Does new information force protagonist to decide and act differently?

### Weak midpoint / story not changing direction
PRIMARY: Truby + McKee Story
SECONDARY: Bell Plot & Structure [after deep read]
OUTPUT TEST: Does midpoint alter the operational model, strategy or stakes rather than merely increase volume?

### Weak climax
PRIMARY: McKee Story
SECONDARY: Truby
OUTPUT TEST: Is climax caused by a costly protagonist choice under maximum accumulated pressure?

### Main conflict unresolved / sequel bait replacing ending
PRIMARY: McKee Story + Truby
CHECK: Edgerton promise/trajectory
OUTPUT TEST: Current book's principal dramatic question has a completed answer before series hook.

## SCENE ENGINE

### Scene feels dead
PRIMARY: Rosenfeld — *Make a Scene*
SECONDARY: Bickham; Bell
OUTPUT TEST: Who wants what now? What resists? What changes? What causes next state?

### Scene is only exposition
PRIMARY: Rosenfeld + McKee Dialogue
SECONDARY: Truby
OUTPUT TEST: Information arrives because somebody acts, tests, conceals, negotiates, fails or discovers.

### Scenes can be reordered freely
PRIMARY: Bickham
SECONDARY: Swain + Truby
OUTPUT TEST: Result of Scene N is a cause/constraint for Scene N+1.

### Scene repeats same conflict
PRIMARY: Bickham + McKee Story
OUTPUT TEST: Does each recurrence remove an option, alter leverage, expose new information or increase price?

### Quiet scene mistaken for filler
PRIMARY: Rosenfeld
SECONDARY: McKee Character / Dialogue
OUTPUT TEST: Can intimacy, grief, recovery, family, humor or contemplation change relationship/decision/status without artificial danger?

## CHARACTER

### Character is a skill/exposition machine
PRIMARY: McKee Character
SECONDARY: Truby
OUTPUT TEST: public role / private desire / fear / contradiction / mistake / price / choice all exist independently of ability.

### Character arc is spoken instead of dramatized
PRIMARY: McKee Character + Truby
OUTPUT TEST: Can the claimed change be demonstrated through different choices under comparable pressure?

### Ensemble voices/functions blur
PRIMARY: McKee Dialogue + Character
SECONDARY: future Card/Corbett deep reads
SCRIPT LAB: FNL / MSCL / Veronica Mars
OUTPUT TEST: different vocabulary, attention, humor, fear, tactics, status behavior.

### Antagonist is cardboard evil
PRIMARY: McKee Story (antagonism)
SECONDARY: Truby character web; Bell competing agendas
OUTPUT TEST: opposition has coherent want, competence, leverage, blind spot and legitimate self-justification.

## DIALOGUE

### Everyone sounds equally intelligent
PRIMARY: McKee Dialogue
SCRIPT LAB: My So-Called Life / Friday Night Lights / Veronica Mars
OUTPUT TEST: different syntax, rhythm, vocabulary, confidence, concealment and social risk.

### Exposition disguised as conversation
PRIMARY: McKee Dialogue + Rosenfeld
OUTPUT TEST: each speaker is trying to do something to the other; exposition is collateral, not purpose.

### Perfect speeches / no interruption
PRIMARY: McKee Dialogue
SCRIPT LAB: youth/social scripts
OUTPUT TEST: resistance, asymmetry, interruption, withholding, failed wording, status.

### Argument ends with correct thematic formulation
PRIMARY: McKee Dialogue + Character
OUTPUT TEST: conversation changes leverage/relationship/decision; theme remains implication.

## OPENINGS / HOOKS

### Opening is lore dump
PRIMARY: Edgerton — *Hooked*
SECONDARY: Truby; Rosenfeld
OUTPUT TEST: present task/disturbance first; backstory only as required by current action.

### Strong hook but wrong novel promise
PRIMARY: Edgerton + Truby
OUTPUT TEST: disturbance forecasts the actual main engine and story-worthy problem.

### Character introduced through résumé
PRIMARY: Edgerton + McKee Character
OUTPUT TEST: introduction includes behavior under meaningful pressure.

## YOUTH / ORBITAL YOUTH

### Earth school transplanted into space
PRIMARY: Brody (age lens) + Truby story world
SCRIPT LAB: FNL / MSCL / Veronica Mars
WORLD CHECK: orbital jobs, housing, transport, money, maintenance, AI, mixed-species culture materially change adolescence.

### Teen characters sound like adult committees
PRIMARY: McKee Dialogue
SCRIPT LAB: MSCL / FNL / Veronica Mars
CHECK: Brody age stakes
OUTPUT TEST: embarrassment, attraction, peer status, uncertainty, bad wording and incomplete self-knowledge survive.

### Youth subplot detachable from SF plot
PRIMARY: Brody + Truby
OUTPUT TEST: external problem produces youth-specific family/status/independence consequence, which then changes plot action.

### Spectacular powers erase youth life
PRIMARY: Brody + McKee Character
OUTPUT TEST: friendship, family, money, first work, housing, attraction, boredom, exclusion, mistakes still produce decisions.

NOTE: scientific Youth Psychology corpus is currently RED/insufficient. Fiction/script references must not masquerade as developmental science.

PRIMARY: Truby controlled withholding + Bell suspense
FICTION LAB: le Carré / Veronica Mars
OUTPUT TEST: withheld information has an in-world reason and later changes action.

PRIMARY: Bell
SECONDARY: Edgerton

### Reveal only expands lore
PRIMARY: Truby

## SMITH / OLD EARTH SECURITY

### Smith becomes generic monster hunter
PRIMARY FICTION LAB: le Carré + Constantine
CRAFT: McKee antagonism + Truby
OUTPUT TEST: case involves knowledge/jurisdiction/history/old agreements or institutional debt, not merely target elimination.

### Old system automatically right
PRIMARY: McKee antagonistic field
FICTION LAB: le Carré + Weir discovery logic
OUTPUT TEST: Confederation has at least one domain it understands better; Old Earth has at least one blind spot/crime/error.

### Bureaucratic conflict without story
PRIMARY: Truby + McKee Story
OUTPUT TEST: jurisdiction conflict changes what actions are possible and who pays the price.

### Anomaly explained before it is interesting
PRIMARY: Edgerton + prior Constantine mechanism
OUTPUT TEST: observable wrongness → test → escalation → provisional model → terminology.

## AI / SYNTHETIC LIFE / CONSCIOUSNESS EMBODIMENT

### Robot is only a philosophical mouthpiece
PRIMARY FICTION LAB: Murderbot + Ishiguro
CRAFT: McKee Character
OUTPUT TEST: ordinary desire, privacy, work, dependence, error, humor, relationships and costly choice exist.

### Transfer into artificial body is just cosmetic
PRIMARY: Swain (sensorium/response) + McKee Character
FICTION LAB: Weir discovery / Murderbot
OUTPUT TEST: new body changes perception, movement, vulnerability, social treatment, work and relationships.

### Scientific discovery occurs as exposition
PRIMARY FICTION LAB: Project Hail Mary
CRAFT: Truby acting/learning
OUTPUT TEST: observation → hypothesis → test → result/error → revised model → changed action.

### Personhood question resolved by speech
PRIMARY FICTION LAB: Klara / Never Let Me Go / Murderbot
CRAFT: McKee Character
OUTPUT TEST: status changes because of choices, relationships, rights, control and consequences.

NOTE: current scientific AI/robotics/neuro/bio library remains thin. Fiction mechanisms cannot substitute for technical verification.

PRIMARY: Swain stimulus-response
SECONDARY: future Doty / prose craft
OUTPUT TEST: physical action has perceived trigger, tactical or emotional function.

# ROUTING LIMITS

- Maximum default call: 4 sources.
- A fifth source requires a genuine unresolved contradiction.
- Formula disagreement is resolved by current story causality, not majority vote.
- Reference mechanisms are advisory until transformed through IVDIVO.
- Scientific/factual claims require science/reference validation outside fiction craft.
