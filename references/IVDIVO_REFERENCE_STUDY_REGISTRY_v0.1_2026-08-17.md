# STUDY DEPTH LABELS

Use:
- `PRIMARY_STUDIED` — substantial usable source text inspected and mechanisms extracted;
- `MECHANISMS_EXTRACTED` — mechanism pass completed;
- `STUDIED_ADAPTED_REFERENCE` — useful but derivative/adapted source;
- `QUESTION_GENERATOR_ONLY` / `STUDIED_QUESTION_GENERATOR` — useful hypotheses/questions but not authority;
- `ALTERNATE_SCAN / ALTERNATE_TRANSLATION / ALTERNATE_SOURCE` — retain without treating as independent mechanism source;
- `SCANNED_TEXT_UNAVAILABLE` — no textual study claim;
- `BROKEN_REPLACE` — source unusable;
- `ROUTED_PENDING_STUDY` — file is organized but not yet deeply studied.

Do not say `read/studied` merely because a filename was routed.
