# IVDIVO PRODUCTION GATE ADDENDUM — PASSES 12–15

Date: 2026-08-17
Status: WORKING PRODUCTION CONTROL / REFERENCE-DERIVED
Canon effect: NONE unless a Founder-approved repair is later locked.

## PURPOSE
Consolidate screenplay, dialogue, scene/opening and relationship findings from Reference Study Passes 12–15 into one downstream diagnostic gate that can be applied to current drafts without automatically reopening already-GREEN story architecture.

## NON-DESTRUCTIVE APPLICATION LAW

1. An accepted/green Story Core, causal map or chapter is **not reopened merely because a later craft source exists**.
2. New reference mechanisms may trigger repair only when they identify a concrete:
   - FATAL continuity/causality failure;
   - MAJOR motivation/opposition/scene/dialogue/relationship failure;
   - MEDIUM pacing/turn/repetition problem worth fixing.
3. POLISH findings never justify structural rewrite by themselves.
4. Reference-derived terminology never enters manuscript prose unless the world independently earns it.
5. Existing story decisions outrank reference mechanisms.

# GATE A — SCENE CAUSALITY

For each important scene/chapter:

1. **OWNER:** who owns the scene?
2. **IMMEDIATE WANT:** what do they want before it ends?
3. **WHY NOW:** what clock/event/arrival/evidence/deadline makes the scene necessary now?
4. **ATTEMPT:** what do they actually do first?
5. **SPECIFIC RESISTANCE:** person / procedure / cost / time / status / missing information / environment / wrong strategy?
6. **TACTIC CHANGE:** where does resistance force a different action?
7. **FOCAL TURN:** what fact/refusal/mistake/arrival/reversal changes the scene?
8. **CHANGED STATE:** what is different at exit — information / status / relationship / access / money / physical state / decision?
9. **NEXT REQUIRED ACTION:** what becomes necessary because of this result?
10. **SCENE VS SUMMARY:** why must the reader experience this in full scene?
11. **CAUSAL WORLD DETAIL:** what job/housing/transport/money/law/maintenance/social rule actually affects the result?
12. **REMOVAL TEST:** if cut, which later event becomes impossible or emotionally unearned?

### Automatic warnings
- MAJOR if #2, #3, #7, #8 or #9 is missing.
- MEDIUM if the scene repeats an already-dramatized conflict without escalation.
- MEDIUM if the scene begins before pressure or continues after the turn only to explain it.

# GATE B — CHAPTER / ACT PROPULSION

A strong chapter ending changes the operating reality.

Ask:
- What new fact/consequence changes the next required action?
- Is the ending more than louder danger or atmospheric uncertainty?
- Does the next chapter begin because of this ending rather than merely because time passed?

Preferred chain:
`RESULT -> REACTION/DECISION -> NEW GOAL`.

MAJOR if the chapter architecture is only chronological rather than causal.

---

# GATE C — DIALOGUE AS ACTION

For every important conversation:

1. What does A want from B?
2. What does B want instead?
3. Starting status asymmetry?
4. Information asymmetry?
5. What is each unwilling to say directly?
6. Initial verbal tactic?
7. How does the other resist rather than simply answer?
8. Where does tactic change?
9. What silence/interruption/refusal acts as a move?
10. What physical action changes the meaning of words?
11. What information/status/relationship/decision is different after the conversation?
12. Could three lines be reassigned to another character without damage? If yes, voice is weak.
13. Does everyone end by correctly articulating the theme? If yes, RED TEAM.
14. If exposition were removed, would conflict remain? If no, it is probably a briefing.

### Dialogue engine
`WANT -> TACTIC -> RESISTANCE -> COUNTERTACTIC -> SUBTEXT PRESSURE -> STATUS/INFO SHIFT -> TACTIC CHANGE -> TURN -> CONSEQUENCE`.

### Automatic warnings
MAJOR:
- five smart answers in sequence;
- neutral exposition with no owner/resistance;
- same tactic repeated through the scene;
- confession instantly resolves structural conflict;
- group dialogue gives equal airtime regardless of status/objective.

MEDIUM:
- conflict but no turn;
- silence is decorative;
- all voices differ only by slang;
- humor repeatedly releases pressure without changing relationship/status.

---

# GATE D — EXPOSITION OWNERSHIP

For each important fact:
- who knows it?
- who wants it known?
- who benefits if it stays hidden?
- who misinterprets it?
- what does disclosure cost?
- what action changes when it is revealed?

MAJOR if information arrives from a neutral spokesperson and changes no action/trust/status.

---

# GATE E — ENSEMBLE / MULTI-THREAD CONTROL

Do not cut by equal airtime.

Each thread should run:
`OBJECTIVE -> RESISTANCE -> TURN -> CUT`.

For every participant in a group scene track:
`OBJECTIVE / STATUS / PRIVATE KNOWLEDGE / TACTIC / EXIT CONDITION`.

Allow unequal participation: dominate / interrupt / withdraw / get ignored / change alliance / leave.

MAJOR if parallel threads can be deleted without changing the main causal or emotional story.

---

# GATE F — ORDINARY LIFE SURVIVES SPECULATIVE PRESSURE

Every 3–5 high-concept scenes check whether at least some of these materially change:
- job / shift;
- money;
- housing;
- transport;
- family contact;
- friendship;
- romance;
- status;
- sport / entertainment;
- school/training;
- privacy;
- maintenance burden.

If speculative escalation erases ordinary life, Orbital Youth is turning into generic SF adventure.

---

# GATE G — RELATIONSHIP CAUSALITY

For every major relationship arc:

1. What does A want from B now?
2. What does B want from A now?
3. What private need makes the relationship important?
4. What independent life/future does each already have?
5. What vulnerability does closeness expose?
6. What defensive strategy appears under pressure?
7. What does each misread about the other?
8. What external/main-story choice is changed by the relationship?
9. How do friends/family/work/status systems react?
10. What logistical consequence follows from greater closeness/distance?
11. What causes the serious rupture?
12. What repair action costs something?
13. What old behavior must change?
14. What if they do not end together?
15. Can the relationship be removed without changing main-story action? If yes, it is under-integrated.

Relationship engine:
`INDEPENDENT LIVES -> ATTRACTION/AFFILIATION -> VULNERABILITY -> CONNECTION -> EXTERNAL COST -> DEFENSE -> MISREAD/STATUS PRESSURE -> RUPTURE -> COSTLY REPAIR OR SEPARATION -> CHANGED FUTURE`.

MAJOR if romance exists only in dialogue and never changes logistics, decisions, allies, information or status.

---

# GATE H — WRONG MODEL MUST COST SOMETHING

When protagonist/institution holds a wrong hypothesis:
`MODEL -> DECISION -> ACTION -> CONSEQUENCE -> REVISED MODEL`.

MAJOR if the wrong theory is corrected in conversation before it causes meaningful action/price.

For Smith especially, emotional priors and institutional priors must be allowed to distort hypothesis selection without making professionals stupid.

---

# GATE I — AFTERMATH BEFORE SERIES HOOK

After immediate climax:
`RESULT -> RELATIONSHIP CONSEQUENCE -> ORDINARY-LIFE CONSEQUENCE -> PERMANENT CHANGE -> SERIES HOOK`.

MAJOR if the book cuts directly from spectacle to next-book tease without registering cost/change.

---

# GATE J — ORBITAL YOUTH SPECIFIC

For youth chapters additionally ask:
- what can embarrass this character this week?
- what does work/training cost in hours and money?
- what relationship can their strategy damage?
- what clue could only be noticed by someone who actually lives this orbital life?
- what speculative system amplifies an existing desire/insecurity rather than creating personhood from scratch?
- what real future decision exists: job / housing / course / crew / relationship / migration / status?
- if the anomaly vanished, would the character still feel like a person with an active life?

First-job pressure grid:
`JOB -> MONEY -> HOURS -> TRANSPORT -> HOUSING -> STATUS -> FAMILY TIME -> FRIEND TIME -> ROMANCE -> FATIGUE -> MISTAKE -> CONSEQUENCE`.

# SEVERITY / REPAIR POLICY

## FATAL
- broken causality;
- impossible motivation;
- missing current-book climax/resolution;
- major canon contradiction.

Action: STOP downstream progression and repair.

## MAJOR
- scene has no actionable owner/want/turn;
- protagonist passivity at decisive point;
- wrong model has no cost;
- exposition replaces conflict;
- major relationship is detachable;
- speculative plot erases ordinary youth life;
- climax bypasses established constraints;
- aftermath does not register permanent change.

Action: targeted repair before lock.

## MEDIUM
- slow/repeated scene function;
- weak scene turn;
- repeated misunderstanding without escalation;
- over-even group dialogue;
- setting/world detail remains decorative.

Action: repair in development/dialogue pass when cost-effective.

## POLISH
- line rhythm;
- repeated gestures/tags;
- greetings/farewells;
- excessive direct-address names;
- explanatory emotional after-sentences.

Action: line edit only.

# APPLICATION ORDER TO ACCEPTED DRAFTS

1. Read authoritative source-of-truth version first.
2. Do **not** compare against superseded drafts unless a regression is suspected.
3. Run Scene/Propulsion Gate.
4. Run Dialogue/Exposition Gate.
5. Run Relationship/Ordinary-Life Gate.
6. Classify only concrete findings.
7. Repair FATAL/MAJOR first.
8. Re-run local continuity/causality after repair.
9. Preserve accepted story decisions unless repair evidence requires change.
10. Record the audit and repair status in GitHub + Drive mirror.

# RECONCILER VERDICT RULE

`GREEN` means no unresolved FATAL or MAJOR findings under this addendum.
It does **not** mean the chapter is perfect or cannot later receive line polish/external feedback.
