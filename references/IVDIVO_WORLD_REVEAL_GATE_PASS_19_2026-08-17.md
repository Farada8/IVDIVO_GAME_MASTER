# IVDIVO WORLD REVEAL GATE — PASS 19

Date: 2026-08-17
Status: WORKING PRODUCTION GATE / REFERENCE-DERIVED
Canon effect: NONE
Source pass: `references/IVDIVO_REFERENCE_STUDY_PASS_19_WORLD_REVEAL_SPECULATIVE_CIVILIZATION_2026-08-17.md`

## USE
Apply whenever a chapter introduces, relies on, or substantially uses civilization, technology, institution, jurisdiction, habitat, synthetic life, AI, contact, or future social practice.

Do not use as a demand to add more lore.
The gate exists mainly to decide **what not to explain** and **which world details must become causal**.

# A. STORYVIEW
1. What does the current POV actually know?
2. What do they merely believe?
3. What public/institutional explanation differs from deeper canon?
4. Is the POV a native, visitor, outsider, professional, youth, regulator, old-system operator, nonhuman observer?
5. Would this person naturally notice the thing being described, or only notice its failure/deviation/cost/status signal?

# B. ORDINARY WANT FIRST
Before the speculative element enters prose, identify the immediate want:
- get somewhere;
- make a shift/class;
- afford/access something;
- meet someone;
- get privacy;
- avoid embarrassment;
- help family;
- keep a job;
- pass a boundary;
- solve an incident.

If no current want exists, test whether the paragraph is lore rather than story.

# C. RULE -> CONSTRAINT -> PRICE
For each important world rule:
- what does it permit?
- what does it prevent?
- who enforces it?
- what exception exists, if any?
- what does exception cost?
- how does the hero adapt?

Do not waive established rules because the plot wants access.

# D. DEFAULT CHANGE -> CASCADE
For a significant new technology/policy/institution, test consequences across at least the relevant surfaces:
- jobs/work;
- money/ownership/insurance/subsidy;
- housing;
- transport;
- family;
- age/youth independence;
- status/access;
- law/jurisdiction;
- maintenance;
- education/training;
- culture/etiquette/humour;
- failure/emergency.

Not every consequence belongs in the current chapter or even current book.
But the world bible/architecture should not treat major invention as consequence-free.

# E. SPECIFIC DETAIL AS SYSTEM PORTAL
Prefer:
`OBJECT -> USE -> CONSTRAINT -> SOCIAL/CHARACTER IMPLICATION`

over generic future description.

Ask:
What one used object, procedure, queue, fee, route, patch, badge, room layout, scheduling conflict, maintenance problem or form reveals the larger system?

# F. LEARNED DEFAULT
First use: enough context to infer.
Second/third use: reinforce through consequence.
Later: stop explaining.

Flag repeated re-explanation of already learned orbital/Confederation/Old Earth defaults.

# G. MULTIPLE RESPONSES
For any major contact, migration, innovation, disaster or policy:
Do at least several groups plausibly want different things?

Possible positions:
- beneficiary;
- loser;
- operator;
- regulator;
- skeptic;
- opportunist;
- ordinary person occupied by something else.

No civilization-wide policy committee voice.

# H. OLD + NEW COEXIST
Check for credible layering where relevant:
- old modules / new modules;
- legacy standards / current standards;
- premium / cheap access;
- old bureaucracy / new reality;
- retrofits;
- historical crime/success embedded in institutions;
- slang/habits surviving after the system changed.

Uniform future = suspicion.

# I. MYSTERY FIELDS
Does the current story need the ontology/explanation now?

If not:
- preserve UNKNOWN/WORKING where appropriate;
- reveal observable phenomenon first;
- let characters hold incomplete models;
- keep unexplored vistas.

Unknown is allowed.
Arbitrary withholding is not.

# J. ORBITAL YOUTH TEST
Ask:
1. Would this scene work almost unchanged in a current Earth school/city if nouns were replaced?
2. Does orbital civilization alter independence, money, housing, work, transport, family, social status or relationships?
3. Are teens residents/users of the civilization rather than guided tourists?
4. Does the speculative detail create an ordinary consequence they actually care about?
5. Who maintains the system when it breaks?

If the answer to 1 is yes and 2–4 are weak, flag `EARTH LIFE WITH SPACE WALLPAPER`.

# K. SMITH TEST
Ask:
- what old procedure still works?
- what crime/cost did the old system normalize?
- what Confederation science sees that Old Earth terminology misses?
- what old archive/agreement/jurisdiction still binds action?
- what mundane artifact reveals institutional history?
- why must the two systems cooperate?

No institutional history lecture if action/procedure/dispute can reveal it.

# L. CONTACT / CONFEDERATION TEST
A contact fact should eventually produce consequences in more than science alone.
Possible surfaces:
law / security / religion-metaphysics / diplomacy / media / markets / households / youth aspiration / status.

Do not show every consequence at once.
Do not make every institution agree.

# M. SEVERITY
## FATAL / MAJOR
- established world rule broken without earned exception/cost;
- climax technology appears unestablished and unforeseeable;
- POV knows impossible information and plot relies on it;
- chapter depends on legal/social consequences contradicting locked world rules;
- Orbital Youth story remains causally identical after replacing future/orbital details with current-Earth equivalents.

## MEDIUM
- lore dump without current need;
- native characters explain normal life to one another;
- technology with no ownership/maintenance/cost/failure ecology;
- unanimous society reaction;
- all future infrastructure uniform;
- terminology before observable phenomenon;
- proper nouns doing no story work;
- speculative detail decorative rather than causal;
- already learned default repeatedly re-explained.

## POLISH
- local generic future texture;
- one unnecessary invented term;
- one over-explained mechanism;
- one world detail that can be made more POV-specific.

# FINAL ENGINE
`ORDINARY WANT -> SYSTEM USED -> RULE / COST / STATUS INTERVENES -> TACTIC -> CONSEQUENCE -> READER INFERS WORLD -> STORY CONTINUES`.

# FINAL QUESTION
If the world detail is removed, does character action, choice, price, relationship, status or causal outcome change?

If not, decide whether it belongs in the Bible instead of the scene.
