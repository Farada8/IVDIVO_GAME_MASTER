Status: WORKING / DRAFT

Purpose: make the normalized Google Drive library operational for the IVDIVO Writers’ Room.

## Primary rule

REFERENCE → ABSTRACT MECHANISM → TRANSFORM THROUGH IVDIVO → ORIGINAL STORY.

Reference texts are not canon. They are mechanism sources. No plot, character, distinctive dialogue, scene sequence, signature invention, or proprietary terminology is to be copied.

Book One / LESSON ZERO remains publisher/external-feedback stage and is not automatically reopened for rewriting by this capability map.

# 5. PRODUCTION PRIORITY

Before adding more random fiction, acquisition/research effort should prioritize the RED gaps in this order:

1. YOUTH PSYCHOLOGY — directly affects ORBITAL YOUTH credibility.
2. AI / ROBOTICS / NEURO / BIO — directly affects the synthetic-body / embodied-consciousness technological line.
3. SOCIOLOGY / ANTHROPOLOGY — required for orbital civilization to generate story rather than backdrop.
4. INSTITUTIONS / SECURITY / INTELLIGENCE — required for SMITH / Old Earth Security vs Confederation Security.
5. CHARACTER PSYCHOLOGY / RELATIONSHIP SCIENCE — strengthens emotional causality and ordinary life.

The library does NOT currently need more generic writing manuals as urgently as it needs these domain sources.
