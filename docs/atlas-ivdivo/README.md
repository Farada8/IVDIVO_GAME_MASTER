# Большой иллюстрированный атлас ИВАватаров Синтеза

Рабочее текстовое хранилище разработок Атласа внутри репозитория `IVDIVO_GAME_MASTER`.

## Статус

Материалы разделяются на три слоя:

- **[И] Источник** — дословное документальное ядро ИВДИВО. Не редактируется и не дополняется догадками.
- **[Р] Рабочая разработка** — художественно-исследовательская интерпретация Атласа. Не объявляется каноном.
- **[П] Производственный промт** — инструкция художнику или генеративной системе.

Статус «компиляция, первичный документ не установлен» сохраняется в карточках там, где он был установлен в ходе исследования.

## Структура

- `00-system/` — аудит серии, художественная система, квоты, правила неповторения.
- `01-register/` — реестр позиций и состояние миграции.
- `02-cards/` — полные карточки и версии переработок.
- `03-sources/` — сведения о документальных источниках и происхождении материалов.
- `04-audit/` — таблицы проверки первых сорока карт.

## Основное изменение v2

Первая версия Атласа выработала сильный понятийный слой, но визуально начала сходиться к одной картине: одинаковые инженерные учреждения, кассетные приборы, рабочие костюмы и муниципальные сбои. Новая система сохраняет документальное и понятийное ядро, но добавляет независимые квотируемые оси:

1. уровень ставки;
2. домен деятельности;
3. ярус мира;
4. конструктивный регистр костюма;
5. средовую логику;
6. тип инструмента;
7. конфигурацию отношений;
8. тип момента;
9. тип кадра;
10. телесную и возрастную вариативность.

Правило неповторения: ни один ключевой параметр не повторяется в трёх последовательных картах.

## Безопасность

Секреты, GitHub Personal Access Tokens, пароли и ключи API в эту папку не помещаются. Опубликованный ранее токен не использовался.

## Текущий комплект

- перекрёстный анализ карт №38–40;
- система национального дизайна и фантастической среды;
- производственная матрица v2;
- реестр карт №1–40;
- Ниса №38 v2 как первый полный образец новой системы.

Дальнейшая миграция выполняется по карточкам с сохранением старых версий и добавлением новых версий, а не с уничтожением истории разработки.
