## 4. ENGINEERING MODEL v0.2

### SUPERSEDED AS LEAD
`SEQUENCE IMPRINT` described as multiple local histories / versions of reality.

Reason: too much cosmological promise, reader confusion and accidental time-travel implication.

### WORKING LEAD
**BOUNDARY ORDER DIVERGENCE**

Operational shorthand:
**VERIFIED HANDOFF MODEL**.

### Observable rule
Each sealed cell remains internally coherent.

The anomaly affects only the **shared ordering of events across affected boundaries**.

Cell A and Cell B can each possess internally valid physical records while disagreeing about the order of a cross-boundary sequence.

This is NOT:
- clock drift;
- corrupted logs;
- control-loop oscillation;
- memory rewriting;
- backward time;
- alternate timelines;
- duplicated people;
- arbitrary reality warping.

## 5. HARD LIMIT

The anomaly cannot reverse event order along one continuous, physically verified custody chain.

If one physical carrier is observed locally as:

`Cell 2 -> boundary handoff -> Cell 3 -> boundary handoff -> Cell 4`,

that continuous custody sequence provides a temporary shared causal reference for the cells it crosses.

This is the core rule that makes the rescue solvable without explaining the ontology.

## 6. WHY STATIC ISOLATION WORSENS THE EVENT

Under normal operation the Transfer Spine continuously exchanges:
- people;
- baggage;
- maintenance carts;
- cargo;
- service items;
- verified local handoffs.

These physical custody transfers constantly generate fresh shared causal anchors across boundaries.

Hard isolation removes those handoffs.

The local systems continue to function, but under the legacy-class phenomenon their cross-boundary event ordering progressively diverges because no new common physical reference events are created.

Thus isolation is not merely ineffective. It removes the stabilizing interaction that ordinary use was unknowingly supplying.

## 8. COUNTERMEASURE

After handoffs stop, divergence can recur.

A physical carrier can therefore create a **moving coherence window**, not normalize the entire sector permanently.
