## 0. FOUNDER DIRECTIVE

The uploaded writing library is not decorative reference material. Every usable book must be studied, its transferable craft knowledge extracted and preserved in the project, and relevant knowledge must be actively applied when designing, drafting and editing IVDIVO fiction.

The assistant must not rely on vague recollection or say that a book was studied merely because the file, title, contents page or a few excerpts were inspected.

## 1. PERSISTENCE RULE

Knowledge from the library is persisted through project artifacts rather than assumed model memory.

For each source, preserve as applicable:

- identity / edition / integrity status;
- structure map;
- source passport;
- claims;
- mechanisms;
- examples and evidence;
- limits and failure modes;
- conflicts with other schools;
- transferable abstractions;
- DO-NOT-COPY surface elements;
- IVDIVO operational tests;
- manuscript validation findings.

Source status is governed by CRAFT-001. Only material that has actually passed the required stages may be described as studied/integrated.

## 2. THREE KNOWLEDGE LAYERS

### LAYER A — SOURCE NOTES
What a particular author/book actually argues or demonstrates.

### LAYER B — SYNTHESIZED CRAFT KNOWLEDGE
Cross-source mechanisms stripped of author-specific surface form and reconciled with competing schools.

### LAYER C — PRODUCTION RULES
Concrete questions, fields, gates and revision tests used on an IVDIVO book.

A source note is not automatically a production rule. A production rule should normally be supported by synthesis, testing or a clearly identified specialist source.

## 3. MANDATORY APPLICATION TO EVERY MAJOR FICTION TASK

Before substantial drafting, the production process must assemble a task-specific CRAFT PACK from already integrated knowledge.

Minimum routing:

- main story / plot / composition → Aristotle, Truby, McKee, Yorke, Coyne and other operationalized structure sources;
- scene causality → Swain, McKee, Rosenfeld, Burroway, LaPlante and related sources;
- character / motivation / contradiction → Egri, Storr, Corbett, Card, Stanislavski-derived material, Weiland and related sources;
- relationships / subtext → relationship, dialogue and acting-derived sources;
- YA / youth → Brody plus adolescent/reader-psychology sources;
- POV / psychic distance → Card, Gardner-derived craft, Burroway, Pushman and related sources;
- prose / voice / rhythm / diction → Rosenfeld, Le Guin, LaPlante, Burroway, Provost, Clark and related sources;
- mystery / suspense / thriller → clue-fairness, investigation and suspense sources plus fiction reverse engineering;
- SF / worldbuilding → genre theory, SF criticism and successful-fiction mechanism studies;
- developmental edit → Coyne, McKee, structural sources and IVDIVO gates;
- line edit → prose, rhythm, clarity and voice sources.

The production team must never pretend that every source is equally relevant to every problem.

## 4. PRE-DRAFT CRAFT PACK

Before a new novel/episode/large story block, prepare internally:

1. MAIN STORY tests;
2. genre obligations;
3. protagonist and relationship tests;
4. scene causality rules;
5. reader-retention / curiosity rules;
6. POV/voice constraints;
7. prose/rhythm constraints;
8. specialist tests required by the specific story (mystery, romance, suspense, action, SF, etc.);
9. known failure modes from comparable sources;
10. copyright/source-distance firewall.

This is backstage production infrastructure. The founder does not need to receive a giant checklist unless requested.

## 5. DRAFT APPLICATION

While drafting, craft knowledge is used to make decisions, not to decorate prose with theory.

Every scene should be testable through at least:

`POV → IMMEDIATE WANT → ACTION/TACTIC → RESISTANCE → CHANGE/TURN → CONSEQUENCE → INTERPRETATION → DECISION → NEXT PRESSURE`

Every major sequence must remain causally subordinate to the book's ONE MAIN STORY.

Secondary lines (family, school, love, sport, work, friendship, worldbuilding) must collide causally with the main action rather than interrupt it as separate filler.

## 6. REVISION APPLICATION

Revision happens in ordered passes. Do not polish sentences before confirming story viability.

Recommended order:

1. main story / ending;
2. causality and escalation;
3. protagonist agency;
4. antagonist/opposition logic;
5. character/relationship arcs;
6. mystery/reveal/payoff fairness;
7. scene necessity and state change;
8. POV/focalization;
9. reader psychology / pacing / retention;
10. prose voice / rhythm / imagery;
11. line edit / compression / clarity;
12. continuity / canon / source-distance regression.

## 7. NO FORMULA DOGMA

No single author is the IVDIVO doctrine.

Truby, McKee, Yorke, Aristotle, Storr, Egri, Brody, Vogler, Swain, Coyne and others are lenses with different scopes. Conflicts between them must be recorded and resolved according to story function, evidence and IVDIVO production requirements.

The goal is not to make every story resemble a craft textbook. The goal is to increase causal strength, emotional truth, readability, originality and reader impact.

## 8. FICTION REVERSE ENGINEERING

Uploaded novels, stories and scripts are studied as mechanism laboratories.

Extract, when useful:

- opening promise;
- central objective;
- scene/sequence chain;
- relationship engine;
- reveal/clue cadence;
- suspense construction;
- chapter hooks;
- POV/voice function;
- prose rhythm;
- midpoint and crisis;
- climax and payoff;
- sequel/series continuation mechanism.

Never copy names, signature scenes, unique twists, distinctive world systems, prose voice, dialogue rhythm or recognizable event sequences.

## 9. KNOWLEDGE REGRESSION

New books may overturn, narrow or refine earlier rules. Therefore synthesis is versioned.

When a new source materially conflicts with an existing production rule:

`OLD RULE → NEW EVIDENCE → CONFLICT ANALYSIS → REVISED RULE / CONTEXT-SPECIFIC BRANCH → MANUSCRIPT REGRESSION`

No early summary is permanently protected merely because it was written first.

## 10. COMPLETION TRUTH

The assistant must distinguish:

- FILE AVAILABLE;
- READ IN PROGRESS;
- EXTRACTED;
- CROSS-COMPARED;
- OPERATIONALIZED;
- MANUSCRIPT-TESTED;
- STUDIED + INTEGRATED.

Never collapse these states into the word "studied" for convenience.

## 11. PRACTICAL MEMORY RULE

For future IVDIVO fiction work, do not depend on conversational memory alone. Retrieve the current production canon and relevant CRAFT documents/notes from the project whenever accuracy or detailed application matters.

The persistent project documents are the source of truth for accumulated craft knowledge.

## 12. RESULT STANDARD

The library is successful only if it changes the produced fiction.

Expected observable effects include:

- a clearly nameable main story;
- stronger causal chains;
- fewer inert or expository scenes;
- more character-specific decisions under pressure;
- ordinary-life lines that alter the main plot;
- better clue/reveal/payoff architecture;
- stronger suspense and chapter propulsion;
- more controlled POV and psychic distance;
- differentiated voices;
- varied sentence/paragraph rhythm;
- less generic AI prose;
- earned endings;
- stronger emotional and narrative recall.

If study notes grow while manuscripts do not improve, the knowledge process has failed.
