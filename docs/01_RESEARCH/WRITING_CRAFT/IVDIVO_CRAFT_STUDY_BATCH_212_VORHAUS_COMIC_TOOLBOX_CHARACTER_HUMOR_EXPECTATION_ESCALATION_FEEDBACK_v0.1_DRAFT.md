**Source:** John Vorhaus — *The Comic Toolbox*

## Production gates

### B212-01 — Humor Generation/Evaluation Split
`GENERATE / RISK → MATERIAL EXISTS → EVALUATE → REWRITE`.

Do not let line-level comedy judgment choke discovery.

### B212-02 — Character-Owned Comic Lens
`WORLDVIEW + ATTENTION + RELATIONSHIP + WANT → COMIC LENS`.

If the same joke can move unchanged between five characters, it is probably authorial wit rather than character voice.

### B212-03 — Model-Gap Humor
`EXPECTED MODEL A ↔ OBSERVED / CHARACTER MODEL B → GAP → HUMOR / IRONY`.

### B212-04 — Shared Ground
`CUE → SHARED LANGUAGE/CULTURE/CONTEXT → EXPECTATION → PAYOFF`.

No shared ground, no reliable decoding.

### B212-05 — Setup / Payoff Information Sufficiency
Before payoff, the audience needs enough information to build the expectation being defeated.

### B212-06 — Optional Rule of Three
`SETUP → VALIDATION → VIOLATION` is one pattern, not a default rhythm.

### B212-07 — Placeholder Humor
Temporary weak joke / line may mark intended function in discovery draft.
`PLACEHOLDER → REWRITE / REPLACE / CUT`.

### B212-08 — Running Gag Development
`REPEAT → NEW SOURCE / CONTEXT / STAKES / MEANING`.

Pure repetition without state/meaning change decays.

### B212-09 — Callback Payment
`EARLY LOAD-BEARING ITEM → LATER CONTEXT CHANGE → CALLBACK / PAYOFF`.

### B212-10 — Micropressure / Macropressure
A local joke, disagreement or awkwardness may echo the governing thematic/social pressure without becoming overt conflict.

### B212-11 — Language Ornament Last
Alliteration, rhyme, puns, comic names and “funny words” are polish tools. They cannot repair a broken scene or generic character.

### B212-12 — Detail Function
`DETAIL → CHARACTER / POV / HUMOR / CAUSAL FUNCTION → KEEP`; otherwise compress.

### B212-13 — Coupled Escalation / Eyebrow Effect
`LOCAL FIX → UNINTENDED CONSEQUENCE → NEW FIX → GREATER COUPLING / COST`.

Escalation is strongest when the character's attempted solution causes the next state rather than when the author simply adds danger.

### B212-14 — Humor Must Also Pay Story State
A strong line may do multiple jobs:
`STORY STATE + CHARACTER/STANCE + HUMOR`.

But humor alone does not justify a scene or subplot.

### B212-15 — Secondary Strand Payment
`B-STORY CHANGE → A-STORY CONSEQUENCE / REFRAME / PAYOFF`.

### B212-16 — Plot Logic / Character Logic Intersection
`PLOT NEED ∩ CHARACTER WANT / MODEL → CREDIBLE ACTION`.

Dynamic choice never outranks causal/world-rule integrity.

### B212-17 — Beta Reader Contract
`READER EFFECT = EVIDENCE; REPAIR PROPOSAL = HYPOTHESIS`.

### B212-18 — Character Key Is Hypothesis
`SMALL BEHAVIOR → WORKING CHARACTER MODEL → LATER CONFIRMATION / REVISION`.

### B212-19 — Idea Bank
A good joke or premise that does not pay the current causal engine should be banked, not forced into the book.

### B212-20 — Problem Decomposition
Replace vague “make it funnier” with explicit subquestions: character lens, audience shared ground, expectation, payoff location, relationship effect, story-state payment.

## Cross-source conclusions
Vorhaus is strongest when read as a toolbox, not as comedy physics. His own best principle is that categories/tools help answer smaller questions but should not become pigeonholes.

The source strongly converges with the IVDIVO agent architecture:
`OBSERVED DEFECT / CREATIVE QUESTION → RELEVANT TOOL → GENERATE OPTIONS → RETEST`.

It strongly conflicts with IVDIVO when it recommends maximum jeopardy or story dynamic at the expense of logic. Causality, personhood, consent and established world rules remain higher authority.

## Standing laws reinforced
`CHARACTER-OWNED HUMOR > UNIVERSAL AUTHORIAL WIT`.

`JOKE / SARCASM / BANTER ≠ EVIDENCE`.

`JOKE BEAT / CALLBACK / PAYOFF ≠ SENTENCE BREAK`.

`COMPRESSION ≠ CHOPPING`.
