## Directly supported mechanisms

### M125-01 — DESCRIPTION AS ATTENTION

Representation is not merely transcription. The act of describing/drawing can force attention to features that were previously unregistered.

IVDIVO transformation:
`OBJECT / ENVIRONMENT → ATTENTIONAL TASK → NEWLY NOTICED DETAIL → UPDATED PERCEPTION → POSSIBLE ACTION/MEANING`.

Use for:
- orbital architecture;
- technical inspection;
- clue discovery;
- embodied POV;
- line editing of generic description.

Failure mode: **DECORATIVE INVENTORY** — adding detail without changing perception, action, relation, inference, or reader model.

### M125-02 — DESCRIPTION AS CONSCIOUSNESS

A description simultaneously represents the object and the mind selecting, comparing, valuing, and organizing it.

Gate:
`WHY THIS DETAIL FOR THIS POV NOW?`

If the same description could be transferred unchanged between Ethan, Maya, Ollie, Aoife, Samir, a specialist practitioner, and a conscious robot, the POV filter is probably underwritten.

Failure mode: **AUTHOR CAMERA DEFAULT**.

### M125-03 — DESCRIPTION AS THINKING

Description can discover a relation or argument while proceeding. It need not be static world exposition.

IVDIVO sequence:
`SPECIFIC OBSERVATION → COMPARISON / RELATION → MODEL SHIFT → QUESTION / ACTION`.

This is especially useful for technical or mystery scenes where the character is genuinely learning by looking.

Failure mode: **THEME-FIRST DESCRIPTION** — the author already knows the message and selects only details that illustrate it.

### M125-04 — ACCUMULATION NEEDS MOVEMENT

A catalogue/list remains alive when successive items alter tone, scale, relation, implication, rhythm, or conceptual direction. Repetition of the same function numbs the reader.

Gate:
For every item in an descriptive accumulation, ask `WHAT NEW WORK DOES THIS ITEM DO?`

Failure mode: **CATALOG SATURATION**.

### M125-05 — SPECIFICITY BEFORE SYMBOLISM

First establish the perceivable particular; only then permit metaphor, symbolic association, or thematic inference.

Gate:
`WHAT IS OBSERVED? → WHAT DOES THE POV ASSOCIATE WITH IT? → WHAT, IF ANYTHING, MAY THE READER INFER?`

This keeps description compatible with the evidence discipline already established by Zunshine, le Carré, Herman, and the IVDIVO ontology firewall.

Failure mode: **POETIC ASSOCIATION BECOMES FACT**.

## Cross-source comparison — provisional

Doty converges with:
- Le Guin / Francine Prose / Lodge: detail and rhythm are functional, not numerical KPIs;
- Zunshine / le Carré: observation and interpretation must remain separable;
- Wolf: world database is larger than book narrative;
- Swain / Card / Corbett: POV selection depends on the perceiver's goal, history, and attention;
- Baxter: physical staging/details can carry relational meaning without explanatory dialogue.

Doty pushes further than the above sources in treating description itself as an act of perception and thinking rather than as static sensory delivery.

## IVDIVO production gates

1. **POV DETAIL OWNERSHIP** — every salient detail must have a plausible attention-owner.
2. **DETAIL DOUBLE-PAY** — prefer details that do at least two jobs: world + character, clue + relation, embodiment + action option, etc.
3. **NO TECH CATALOG** — SF novelty alone does not earn descriptive space.
4. **NO GENERIC ROBOT SENSOR FEED** — conscious robots perceive through their own embodiment, task, values, and relationships.
5. **PHENOMENOLOGY ≠ ONTOLOGY** — vivid description of an inner/practice experience does not prove a metaphysical explanation.
6. **DESCRIPTION → ACTION TEST** — in high-pressure scenes, description should often alter the next inference, tactic, or emotional/relational state.
7. **LIST MOVEMENT TEST** — accumulations require progression, contrast, or modulation.
8. **SYMBOLISM AFTER PARTICULAR** — do not force theme ahead of observation.

## Relation to anti-'choppy prose' program

Do not fix flat description by inserting more one-line sensory fragments. Use:

`SCENE FUNCTION → POV ATTENTION → SELECTED PARTICULAR → RELATION/INFERENCE → PARAGRAPH INTENT → RHYTHM`.

A coherent descriptive paragraph may be better than five isolated micro-observations.
