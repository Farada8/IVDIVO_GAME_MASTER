## PROVISIONAL MECHANISMS

### M01 — Evidence-Driven Competence
`OBSERVE → QUANTIFY → HYPOTHESIZE → TEST → CONFIRM/FAIL → UPDATE MODEL → ACT`

A competent protagonist remains interesting when knowledge is provisional and action depends on tested models rather than authorial certainty.

### M02 — Technical Exposition Through Present Problem
`QUESTION → MINIMUM NECESSARY TECHNICAL DATA → TEST → RESULT → MODEL UPDATE → NEXT CHOICE`

Technical information earns reader time when it is needed for a current decision and produces a changed state.

### M03 — Intelligent Mistake
`REASONABLE LIMITED MODEL → TEST → CONTRADICTION → REVISED MODEL`

The protagonist can be wrong while remaining competent. The error should be traceable to evidence limits, assumptions, or model scope rather than stupidity-for-plot.

### M04 — Flashback as Present-State Update
`CURRENT ANOMALY → MEMORY TRIGGER → PAST CONTEXT → NEW PRESENT MODEL`

Flashback must alter present knowledge, relationship, evidence status, or action; otherwise compress or remove it.

### M05 — Legible Specificity
Technical precision is useful only when compatible with POV knowledge and enough context exists for the reader to infer the term's function.

### M06 — Causal Worldbuilding
World/science material enters through experiment, constraint, failure, task, decision, or consequence. World database material does not earn prose space merely by being interesting.

### M07 — Competent Countermodel
`REAL CAPABILITY + URGENCY + LEVERAGE + BLIND SPOT/COST`

An institutional actor can be highly competent and still ethically contestable. Capability does not confer moral legitimacy.

### M08 — Ordinary Identity Grounds Extreme Stakes
A protagonist's ordinary role and habits can create emotional specificity inside civilization-scale stakes. Catastrophe alone does not generate reader attachment.

### M09 — Nonlinear Causal Payoff
A return to the past earns its place when it changes the current causal model. Temporal alternation is not valuable merely because it withholds information.

### M10 — Voice/Humor Through Cognitive Habit
Humor can emerge from habitual reasoning, self-correction, profession, social identity, and attitude rather than joke density.

### M11 — Rhythm Firewall
`INTENSITY ≠ SHORT-SENTENCE DENSITY.`
Longer syntax and full paragraphs may be required for model-building, accumulation, technical inference, or sustained suspense.

## PROVISIONAL FAILURE-MODE WATCHES

### F01 — Competence Exposition Loop
Watch for repeated `puzzle → calculation → answer` units that do not also change action, information, relationship, responsibility, or option space.

### F02 — Flashback Convenience
Watch whether memory arrivals become perfectly timed answer dispensers instead of causally/psychologically credible retrieval.

### F03 — Authoritarian Competence Normalization
Watch whether urgency and competence flatten ethical costs, alternatives, consent, or the agency of affected people.
