# BATCH 184 — CHUDNOFF: REASONING · READER MODEL · ARGUMENT TYPE · NARRATIVE ORDER

## Source
Elijah Chudnoff — *A Guide to Philosophical Writing* (Harvard Writing Project, 2007).

## Why this source matters to IVDIVO
This is not a fiction-formula source. Its value is precision at the boundary between **what is observed, what is claimed, what kind of support is actually available, what the reader has been prepared to understand, and how explanatory order differs from discovery order**.

## New production gates

### B184-G01 — Topic/Claim Separation
A broad concern is not yet a usable claim.
`TOPIC → PRECISE CLAIM → SUPPORT CONDITIONS → REFUTATION/QUALIFICATION CONDITIONS`.

### B184-G02 — Support-Type Audit
For every load-bearing conclusion classify actual support:
`DEDUCTIVE / MATERIAL-VALID / INDUCTIVE / IBE / ANALOGY / CHARITY / TESTIMONY / OBSERVATION / UNKNOWN`.
Intended support does not override actual support.

### B184-G03 — Hidden Premise Audit
`ARGUMENT → WHAT MUST ALSO BE TRUE FOR THIS TO WORK?`
If the hidden premise is controversial, expose it and assign evidence status.

### B184-G04 — Cogency Above Formality
A formally valid chain can still be useless if its premises are circular, irrelevant or unsupported.

### B184-G05 — Competing Explanation Requirement
`TRACE SET → MODEL A / MODEL B / MODEL C → DISCRIMINATING EVIDENCE`.
Do not call something the best explanation until alternatives are represented fairly.

### B184-G06 — Analogy Firewall
`ANALOGY → HYPOTHESIS`, not automatic evidence.
The relevant similarity must itself be defended.

### B184-G07 — Reader Intelligibility Stack
When a reader is lost, diagnose separately:
1. expression;
2. motivation — why this appears now;
3. background — what must already be known;
4. elaboration — example/clarification required.

### B184-G08 — Discovery/Explanation/Narrative Separation
`ORDER OF DISCOVERY ≠ LOGICAL-EXPLANATORY ORDER ≠ BEST READER ORDER`.
Draft process does not dictate final discourse.

### B184-G09 — Supporting-Claim Motivation
Every long supporting claim/lemma must answer:
`WHY DOES THE READER NEED THIS BEFORE THE MAIN LINE CAN ADVANCE?`

### B184-G10 — Paragraph Local Job
`PREVIOUS READER STATE → PARAGRAPH FUNCTION → INTERNAL ORDER → EXIT STATE`.
A paragraph without one coherent local job is a structural problem before it is a sentence problem.

### B184-G11 — Feedback Attention Audit
If a reader focuses on a supposedly peripheral detail:
`PRESENTATION DISTORTION? → OR AUTHOR MISJUDGED WHAT IS ACTUALLY CENTRAL?`
Do not assume the reader is simply wrong.

### B184-G12 — Insight/Imagination Firewall
Thought experiment and insight may generate distinctions and hypotheses. They do not independently establish world fact.

## Failure modes
- TOPIC-AS-THESIS
- HIDDEN-PREMISE SMUGGLING
- INTENDED-DEDUCTION / ACTUAL-ANALOGY
- IBE-WITHOUT-COMPETITORS
- ANALOGY-TO-ONTOLOGY LEAP
- EXPERT-TONE-AS-EVIDENCE
- DISCOVERY-ORDER LEAKAGE
- LOGICAL-ORDER DOGMA
- BACKGROUND BEFORE MOTIVATION
- PARAGRAPH-WITHOUT-JOB
- READER-AS-AUTHOR-CLONE
- CLARITY-AS-SHORT-SENTENCE KPI

## Cross-source synthesis
- Genette/Chatman: discourse order; Chudnoff adds a three-order diagnostic.
- Zunshine/Herman/le Carré/Ephron: evidence provenance; Chudnoff adds support-type and hidden-premise classification.
- Williams/Zinsser/Hodgins: paragraph/readability; Chudnoff adds motivation/background/elaboration as separate failure levels.
- Booth: reader inference; Chudnoff adds entitlement and argument-type discipline.
- Aristotle: causal/explanatory coherence; Chudnoff warns that explanatory order and reader order need not coincide.

## Standing synthesis
`CLAIM → PRECISE STATUS → TRACE/PREMISES → SOURCE LINEAGE → SUPPORT TYPE → HIDDEN ASSUMPTIONS → ALTERNATIVE MODEL → PROOF CEILING → ACTION`.

This is a reasoning/evidence layer, not permission to turn fiction into academic exposition.
