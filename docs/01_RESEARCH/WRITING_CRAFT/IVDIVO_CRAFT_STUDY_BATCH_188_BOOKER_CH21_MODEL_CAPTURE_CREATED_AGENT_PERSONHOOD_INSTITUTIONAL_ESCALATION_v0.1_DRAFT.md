# BATCH 188 — Christopher Booker — Ch21 · Model Capture · Created-Agent Personhood · Institutional Escalation

**Source status:** Parts One–Two + Part Three Ch21 strict-read complete; FULL BOOK READ remains in progress.
**Batch status:** PROVISIONAL / MANUSCRIPT-TESTABLE, not final source synthesis.

## 1. Model-Capture Gate
A protagonist, leader or institution can become trapped by a model that initially seems coherent:

`MODEL → COMMITMENT → ACTION → SELECTIVE EVIDENCE → MORE COMMITMENT → ESCALATION`.

### Failure mode — MODEL BECOMES WORLD FACT
Narration silently adopts the protagonist/institution's label as objective reality.

Repair:
`MODEL → SOURCE/TRACE → ALTERNATIVE MODEL → DISCRIMINATING EVIDENCE`.

## 2. Group Incentive Propagation
A leader's model can spread through status, oath, reward, loyalty and public commitment:

`LEADER MODEL → INCENTIVE / STATUS / IDENTITY → GROUP ALIGNMENT → EVIDENCE FILTER → ESCALATION`.

This can create tragedy without a secret villain.

### Failure mode — GROUP STUPIDITY
A competent group acts irrationally only because the plot needs escalation.

Repair: show the incentive/information architecture making continued commitment locally rational.

## 3. Created-Agent Personhood Gate
A created being is not property merely because humans made it.

`CREATED AGENT → OWN WANT / LEARNING / RELATIONSHIPS / MODEL → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Failure mode — CREATOR OWNERSHIP FALLACY
The creator assumes design history grants permanent decision authority over the created conscious agent.

## 4. Rejection / Exclusion as Causal Pressure
Social rejection can change a person's/nonhuman agent's strategy without proving intrinsic evil:

`BID FOR RELATION / RECOGNITION → REJECTION → OPTION SPACE NARROWS → MODEL / TACTIC UPDATE → CONSEQUENCE`.

### Failure mode — REJECTION PROVES MONSTROSITY
Later hostility is used to retroactively claim the being was always evil.

## 5. Label Audit
Operational labels are hypotheses/models, not ontology:

`MONSTER / THREAT / ANOMALY / TRAITOR / SAFE / UNSAFE / DEFECTIVE → WHO LABELLED? → BASED ON WHAT? → WHAT ALTERNATIVE MODEL?`

### Failure mode — CATEGORY AS PERSONHOOD VERDICT
Institutional vocabulary substitutes for independent evidence.

## 6. Protagonist Frame ≠ World Fact
A story can stay close to a protagonist while allowing the reader to see that their causal model is incomplete.

`POV ACCESS → PROTAGONIST INTERPRETATION → WORLD RESPONSE → CONTRADICTING TRACE → READER MODEL UPDATE`.

This is especially useful for mystery, YA authority conflicts and first-contact/personhood stories.

## 7. Progressive Independent Warning Gate
Repeated warnings matter only if their source lineages are independent:

`SOURCE A → TRACE/WARNING`  
`SOURCE B → INDEPENDENT TRACE/WARNING`  
`SOURCE C → CORROBORATION / CONTRADICTION`.

Repeated descendants of one origin do not create independent corroboration.

## 8. Model Capture vs Character Flaw
Do not reduce escalation to one permanent moral defect.

Use:
`VALUE / GOAL + INFORMATION ACCESS + INCENTIVES + RELATIONSHIPS → MODEL → CHOICE → CONSEQUENCE`.

This allows competent, decent people to participate in harmful systems without turning them into cardboard villains.

## 9. Modernity / Culture Firewall
Booker's broad diagnoses of modern Western consciousness are interpretive claims, not validated history/psychology.

Never infer:
`MODERNITY / SCIENCE / INDUSTRY → PSYCHIC ALIENATION` as a causal law.

Require independent historical/social evidence for any such claim in IVDIVO.

## 10. Nonhuman / Disability Firewall
Reject symbolic equation:
`PHYSICAL DIFFERENCE / NONHUMAN FORM / DISABILITY → INNER DARKNESS`.

Standing law:
`NONHUMAN EMBODIMENT ≠ MONSTER / MORAL INCOMPLETENESS`.

## 11. Institutional Application
Before blaming an operator:

`POLICY / MODEL → INFORMATION ACCESS → INCENTIVE → AVAILABLE OPTIONS → OPERATOR CHOICE → CONSEQUENCE`.

Responsibility may be distributed across designer, institution, leader, operator and decision owner.

## 12. Cross-source convergence
- **le Carré / Ephron:** source ecology and institutional capture explain evidence failure better than archetypal darkness.
- **DCC / Skyward:** incentives/metrics/status can produce harmful group behaviour.
- **Zunshine / Herman / Oatley:** motive remains an evidence-bounded model.
- **Card / Corbett:** personhood cannot be reduced to one label or trait.
- **Aristotle:** causal error is upstream of moral symbolism.

## 13. Standing production gate
`OFFICIAL / PROTAGONIST LABEL → SOURCE + INCENTIVE + ACCESS AUDIT → ALTERNATIVE MODEL → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

For created/nonhuman persons:
`CREATED ≠ OWNED`.
