## Chapter 8 — Complex Plots — STRICT FULL READ COMPLETE

The previously missing opening and terminal edges are now recovered in overlapping continuous source runs. The chapter is therefore upgraded from provisional to strict-complete.

### Mechanisms retained

1. **ONE MAIN STORY does not require one POV or one plot strand.** Multiple strands are allowed when each carries real local story weight and changes the same dominant causal engine.

2. **Strand Value Test**
   `OWNER → LOCAL WANT → LOCAL CHANGE → EFFECT ON ANOTHER STRAND / MAIN ENGINE → CONVERGENCE OR PAYOFF`.

3. **Co-presence is not convergence.** A briefing in which separated characters merely exchange summaries is not sufficient. Real convergence changes another strand's available actions, evidence, authority, relationship, cost, or decision.

4. **Each strand must earn switching cost.** A POV/strand switch must provide unique action, evidence, lived experience, countermodel, relationship pressure, or decision.

5. **Nonlinear Reconstruction Contract**
   `WORLD FACT → FRAGMENT/SOURCE → TIME/RELATION CUE → READER MODEL → NEW FRAGMENT → MODEL REVISION → EVENTUAL RECOVERABLE CAUSAL ORDER`.

6. **Theme is carried by values in action, not by author explanation.** Bell's one-meta-message formulation is not treated as a universal rule. IVDIVO permits thematic complexity, but theme must remain embodied in competing choices and consequences.

7. **Motif/recurrence must develop.** Repeated detail, image, setting, or phrase is useful when its meaning changes on return; repetition without semantic development is decorative redundancy.

## Chapter 9 — The Character Arc in Plot — STRICT FULL READ COMPLETE

The chapter is now supported by overlapping continuous source coverage from its exact opening through Bell's layers model, impacting incidents, deepening disturbances, aftermath, epiphany/verification, character-arc table, exercises, and the exact transition into Chapter 10.

### Bell claims retained as tools, not laws
Bell presents character change as a major way plot acquires depth and proposes pressure on beliefs, values, dominant attitudes, and opinions. His A Christmas Carol analysis demonstrates gradual pressure, recurring earlier language, a costly prospective future, declaration, and — critically — behavioral verification in aftermath.

### IVDIVO operationalization

**ARC EVIDENCE CHAIN**
`INITIAL MODEL / VALUE / STRATEGY → PRESSURE → SPECIFIC RESPONSE → ACCUMULATED CONSEQUENCE → MODEL/STRATEGY/RELATIONSHIP/COMMITMENT CHANGE OR TESTED STABILITY → BEHAVIORAL VERIFICATION → AFTERMATH`.

A change is not accepted because narration says a character changed. It must alter later behavior, tactic, relationship, consent decision, evidence handling, authority use, or cost acceptance.

### Character-change firewall
Bell's statement that the lead should be a different person at the end is NOT adopted as a universal law. Valid IVDIVO trajectories include:
- positive change;
- negative change;
- partial change;
- changed tactic without changed core value;
- changed relationship or responsibility;
- tested stability / flat arc;
- wrong conclusion with meaningful consequences;
- deferred change across a series.

**SERIES NO-RESET:** even when a character's central value remains stable, consequences and relationships from prior books cannot vanish merely to recreate the same arc.

### Layer model firewall
Beliefs / values / attitudes / opinions are useful descriptive lenses, but they are not treated as a scientifically proven hierarchy of a universal 'core self.' Trauma is not mandatory. Psychology in IVDIVO remains character-specific and evidence-based.

### Pressure and repetition
Bell's strongest mechanism is not 'break the character harder' but **return earlier material under changed conditions**. An earlier phrase, rule, promise, object, or decision may become pressure when later consequences force the character to confront what it now means.

Operational gate:
`EARLY CHOICE / LANGUAGE → LATER CONSEQUENCE → RECONTEXTUALIZATION → DIFFERENT ACTION`.

### Epiphany firewall
An explicit epiphany is optional. Preferred evidence order:
`PRESSURE → CHOICE / BEHAVIOR → READER INFERENCE → optional articulation`.

A realization may be partial, understated, deferred, or wrong. On-the-nose 'lesson learned' narration is not required.

### Conscious robot/personhood application
A conscious robot is not required to become 'more human' to possess a character arc. Valid change can concern trust, commitments, relations, self-model, governance, strategy, consent boundaries, embodiment-specific practice, or stable values under pressure.

### Orbital Youth / post-money application
Youth growth should not default to earning money, rent independence, consumer status, or credits. Strong arc pressures include autonomy, consent, responsibility, trust, belonging, mastery, privacy, reputation, unique experience, relationship terms, and bounded authority.

## Cross-source synthesis
- **Card / Corbett / McKee Character:** Bell's arc table is useful only when connected to observable choices and relationship-specific behavior.
- **LaPlante / Francine Prose:** meaningful fiction does not require mandatory transformation or explicit epiphany.
- **Vogler / Brody / Weiland:** arc templates are maps/generators, not compulsory beat schedules.
- **Herman / Zunshine:** character interpretation must preserve evidence status; reader/POV models are not automatically world facts.
- **Truby:** pressure is strongest when it changes strategy and causal choice, but no required moral self-revelation is imported.
