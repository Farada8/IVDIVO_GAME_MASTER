## 1. PRODUCTION THESIS
Mystery quality depends not only on what information exists, but on how the book tracks its **provenance, confidence, interpretation and update conditions**.

Core chain:

`OBSERVATION → SOURCE TAG → INTERPRETATION → CONFIDENCE → ALTERNATIVE MODEL → NEW EVIDENCE → STATUS CHANGE → ACTION`

A reveal that changes no model, decision, relationship or next test is usually lore rather than plot.

## 2. SOURCE-MONITORING LEDGER
Every major clue / claim should be able to answer:

1. What exactly was observed?
2. Who produced or reported it?
3. Is it direct observation, memory, inference, document, system output or hearsay?
4. How reliable is the source in this domain?
5. What is the current confidence level?
6. What alternate interpretation remains plausible?
7. What later evidence would upgrade, downgrade or falsify it?
8. What action is justified at the current confidence level?

Recommended statuses:
`OBSERVED / REPORTED / INFERRED / HYPOTHESIS / CORROBORATED / CONTESTED / DISPROVEN / UNKNOWN`.

## 3. MYSTERY FAIRNESS
A fair mystery does not require giving the reader the answer early. It requires keeping **observation and interpretation separable**.

Good ladder:
`FACT A → reasonable MODEL A → contradictory FACT B → revised MODEL B → costly test → bounded reveal`.

Bad ladder:
`vague clue → author withholds obvious fact → surprise answer`.

## 4. UNRELIABLE POV
Do not label a narrator simply RELIABLE / UNRELIABLE.

Test domains separately:
- event sequence;
- memory;
- other-person motive;
- own motive;
- moral evaluation;
- causal explanation;
- institutional/cosmological interpretation.

A narrator can be reliable in one domain and wrong in another. Reliability may also change over time.

## 5. LIES
One lie is not a small local ornament. It creates a revision tree.

`LIE → recipients → decisions caused by lie → second-order effects → later correction cost`.

Production rule: do not add multiple liars to make mystery feel “smart.” Each liar adds combinatorial tracking cost. If everyone may be lying, strongly narrow the central problem-space.

## 6. MATERIAL CLUES
Physical/digital evidence must imply agency:

`TRACE → WHO/WHAT PRODUCED IT → CONDITIONS → IMPLIED ACTION → POSSIBLE PURPOSE → ALTERNATIVE → TEST`.

A technical artifact without reconstructed action is not automatically a meaningful clue.

## 7. MYSTERY + ROMANCE / RELATIONSHIP
Both can demand heavy mind-tracking. Avoid two independent maximum-intensity inference engines running in parallel.

Prefer overlap:
- same person is both emotional and evidentiary problem;
- same recording changes both trust and case interpretation;
- same institutional choice affects both belonging and mystery;
- relationship choice exposes a clue or changes access.

This creates ONE MAIN STORY rather than A-plot plus separate romance tax.

## 8. AI / SYSTEM / CONSCIOUS ROBOT GATES
Prediction is not mind-reading.

`PREDICTED ACTION ≠ MOTIVE ≠ CONSENT ≠ DUTY ≠ RIGHT TO ALLOCATE BURDEN`.

For a conscious robot:
- other characters do not automatically have transparent access to its motives;
- it may strategically disclose or withhold;
- it has source status like any other person;
- its own system logs may record actions without fully explaining motives.

## 9. CONSCIOUSNESS-SCHOOL EPISTEMICS
Maintain five levels:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → RIVAL INTERPRETATION → ONTOLOGICAL CLAIM`.

Do not collapse them because a school is old, prestigious, technologically equipped or spiritually committed.

## 10. FAILURE MODES
- Source Loss.
- Silent Promotion of Hypothesis.
- System-Mind Telepathy.
- Liar Inflation.
- Evidence/Interpretation Collapse.
- Unreliable-Narrator Alibi for author error.
- Material-Clue Fetish.
- Mystery/Romance Double Saturation.
- Final Oral Answer Key.
- Cognitive/Scientific Overreach.
- Reader Inference Starvation.
- Reader Inference Saturation.
