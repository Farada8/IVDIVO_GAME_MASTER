# IVDIVO CRAFT STUDY — BATCH 169

## Jack Hodgins — Narrative Mode · Paragraph Coherence · Organic Structure · Revision

**Status:** manuscript-facing synthesis from completed strict read  
**Source authority:** Jack Hodgins, *A Passion for Narrative: A Guide for Writing Fiction*  
**Pass:** 134

## Executive result

Hodgins is valuable because he refuses two opposite errors at once:

1. intuition without craft;
2. craft that becomes visible scaffolding and paralyzes invention.

For IVDIVO the source reinforces a production architecture in which **generation, diagnosis and revision are different modes of work**.

`LIVE STORY IMPULSE → DRAFT → OBSERVE ACTUAL STORY → DIAGNOSE → APPLY RELEVANT TOOL → RETEST`.

The highest-value new synthesis is at the prose/paragraph layer: Hodgins explicitly identifies monotonous short subject–verb sentences as jerky and recommends joining, subordinating, transitioning and varying sentence structures according to the desired effect. This is direct source support for IVDIVO's anti-`обрубки` system.

---

## 1. The storyteller / artifice polarity

### Retained mechanism

Hodgins treats the writer as both natural storyteller and deliberate maker. The first supplies energy, surprise, material and intuition; the second supplies control over reader effect.

### Production gate

`GENERATE LIVE → OBSERVE → CRAFT CONTROL → RE-IMAGINE IF FOUNDATIONAL → POLISH LAST`.

### Failure modes

- **INTUITION-ONLY BLINDNESS:** writer cannot see why material does not work.
- **CRAFT-CONSCIOUS PARALYSIS:** writer monitors rules while trying to invent.
- **CHECKLIST PERFORMANCE:** text visibly satisfies craft labels but has no discovery or life.

---

## 2. Seed connection as story ignition

Anecdote, person, place, voice, memory, obsession or image may not be a story by itself. Hodgins repeatedly shows story beginning when materials collide and create a new relation.

### Mechanism

`SEED A + SEED B → RELATION → QUESTION / PRESSURE → CHARACTER RESPONSE → STORY ENGINE`.

### IVDIVO use

Before inventing another plot event, test whether two already existing materials create a stronger relation:

- technology + relationship;
- institution + consent;
- setting rule + adolescent status;
- old evidence + present decision;
- robot embodiment + social assumption.

### Failure mode

**NEW EVENT BEFORE NEW RELATION** — adding more incidents instead of discovering what existing material implies.

---

## 3. Narrative-mode routing

Hodgins explicitly legitimizes:

- exposition;
- narrative summary;
- full scene;
- partial / half-scene.

### Gate

Ask before line edit:

`WHAT MUST THE READER WITNESS EXACTLY?`

If exact words/actions change trust, consent, evidence, authority, relation, decision or emotion → scene.

If material mainly moves time, process, repetition or logistics → narrative/summary.

If one local moment matters inside a longer process → partial/embedded scene.

### Application to technical fiction

`SUMMARY OF PROCEDURE → CONSEQUENTIAL REAL-TIME MOMENT → SUMMARY / CHANGED STATE`.

### Failure mode

**MICRODRAMATIZATION:** every movement is acted out because the writer mistakes scene for quality.

---

## 4. Paragraph coherence and the anti-choppiness system

Hodgins gives direct craft evidence that prose composed from many similar short subject–verb sentences becomes jerky. His repair recommendations include:

- logical ordering;
- transition;
- joining related sentences;
- subordination;
- sentence-pattern variation;
- rhythm matched to the emotional/narrative effect.

### Production gate

`PARAGRAPH INTENT → READER-STATE CONTINUITY → GROUP RELATED MICROBEATS → SENTENCE CONTRAST → WORDING`.

### Merge test

If several short paragraphs share:

- same actor;
- same place;
- same time;
- same perceptual focus;
- same decision unit;

then test one coherent paragraph before preserving fragmentation.

### Preserve short lines when they perform a distinct function

- revelation;
- reversal;
- comic timing;
- arrest/pause;
- end-weight;
- sharp contrast;
- deliberate breath.

### Failure modes

- **SHORT-SENTENCE KPI**
- **PARAGRAPH CONFETTI**
- **BEAT=LINE FALLACY**
- **CHOPPY OVERCORRECTION AFTER CUTTING PURPLE PROSE**

## 5. Setting as physical + social mechanism

Hodgins expands setting beyond geography into social milieu:

- peer expectations;
- community norms;
- family values;
- historical time;
- character attitude to place.

### Mechanism

`PLACE / WORLD RULE → SOCIAL + PHYSICAL AFFORDANCE → CHARACTER-SPECIFIC NOTICE → CHOICE → CONSEQUENCE`.

### IVDIVO use

Orbital city should be revealed through what a character can/cannot do, what locals find normal, what peers reward, and what institutions expect — not through a technology catalogue.

### Failure modes

- SETTING TOURISM
- WORLD-BIBLE RECITATION
- LOCATION SWAP WITHOUT CAUSAL CHANGE

---

## 6. Character: precious particle, not dossier

Hodgins' useful “precious particle” principle is selective specificity: one revealing gesture, phrase, image, action or relation can make a character more vivid than an inventory.

### Gate

`DETAIL → WHAT DOES IT REVEAL / ENABLE / COST / CHANGE?`

If the detail only reminds the reader “this is the character with X quirk,” delete or reduce it.

### Cross-source synthesis

- Card / Corbett: relationship-specific behavior;
- McKee Character: modus operandi;
- Collins: value/priority under circumstance;
- Hodgins: selective evidence rather than catalogue.

### Failure modes

- QUIRK TAXIDERMY
- BIOGRAPHY-AS-DEPTH
- MANNERISM SUBSTITUTES FOR MOTIVE

---

## 7. Dialogue as tactical relationship work

Hodgins treats speech as plot, character, relationship and concealment mechanism.

### Dialogue engine

`PRESENT WANT → TACTIC → LISTENER MODEL / RESPONSE → TACTIC CHANGE → CHANGED RELATION / INFORMATION / DECISION`.

### Useful tactics

Demand, coax, plead, charm, lie, flatter, threaten, reason, appeal, withdraw, refuse, invoke precedent, use silence or physical action.

### Gate

If three consecutive turns use effectively the same tactic, dialogue is probably circling.

### Mystery firewall

`UTTERANCE / PAUSE / ATTITUDE → MOTIVE HYPOTHESIS`, not `MOTIVE FACT`.

---

## 8. Plot without war monoculture

Hodgins uses causal plotting while explicitly recognizing non-combat narrative models.

### IVDIVO model

`WANT / RESPONSIBILITY → RESISTANCE OR SUPPORT → TACTIC → OUTCOME → CHANGED POSITION → NEXT CHOICE`.

A scene can progress through:

- success;
- compromise;
- consent/refusal;
- discovery;
- relationship change;
- new obligation;
- evidence-status change;
- responsibility increase.

### Middle gate

`DID THE CHARACTER'S POSITION CHANGE?`

Legal/social/ethical/relational/epistemic position counts. Repeated obstacles without changed position are not meaningful escalation.

---

## 9. Structure as reader-information architecture

Hodgins' strongest structural insight is that order changes meaning and reader experience.

### Gate

`WORLD FACT → DISCOURSE ORDER → POV ACCESS → READER MODEL → LATER REVISION / PAYOFF`.

### Nonlinear / multi-POV test

Every formal complication must buy one or more:

- fair withholding;
- dramatic irony;
- changed sympathy;
- reconstruction work;
- thematic relation;
- different causal understanding.

Otherwise simplify.

### Failure mode

**FORM LOOKING FOR A STORY** — structure invented first, material distorted to justify it.

---

## 10. Flashback present-dependency

### Gate

`WHY DOES THE PRESENT STORY NEED THIS PAST MATERIAL NOW?`

Possible outputs:

- full flashback;
- back-flash;
- summary;
- indirect recollection;
- no insertion.

If the flashback is consistently more alive than the main line, reconsider the book's starting point.

---

## 11. POV / voice authority

### Passport

`WHO SPEAKS → WHO PERCEIVES → WHAT THEY KNOW → WHAT THEY INFER → TIME SINCE EVENT → ATTITUDE TO PAST SELF → WHY TELL → TO WHOM / IN WHAT MODE`.

Changing first to third person can change authority and language, not merely pronouns.

### Mystery firewall

`POV INTERPRETATION ≠ WORLD FACT`.

---

## 12. Symbol: driftwood, not neon

### Mechanism

`EXISTING STORY ELEMENT → RECURS → RELATION / MEANING CHANGES → PAYOFF`.

Before importing a symbolic object, ask whether an already causal setting/prop can carry the same evolving function.

### Failure modes

- NEON SYMBOL
- AUTHOR EXPLAINS SYMBOL AFTER IMAGE
- MOTIF RETURNS WITHOUT NEW MEANING

---

## 13. Revision as re-seeing

Hodgins' Faulkner example makes the key distinction:

A foundational POV/voice change may require **re-imagining the scene**, not swapping pronouns and patching lines.

### Stage router

`DEFECT LEVEL → REPAIR LEVEL`:

- word/sentence → line repair
- paragraph continuity → paragraph rebuild
- dialogue tactic → conversation rebuild
- scene purpose/POV/staging → re-imagine scene
- sequence causality → chapter rebuild
- book engine → development rewrite

### Standing lock

This is not permission for global rewriting of development-locked manuscripts.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

---

## 14. Feedback and internal editor

### Feedback contract

`OBSERVED EFFECT → TEXTUAL CAUSE? → REPEATABILITY → DEFECT LEVEL → REPAIR OPTIONS → PROJECT DECISION`.

All comments merit consideration; proposed solutions do not automatically merit implementation.

A good workshop ultimately trains the writer to become less dependent on the workshop.

## 15. New production gates — Batch 169

- **B169-G01 LIVE-FIRST:** do not run the whole bureau during generation.
- **B169-G02 CONNECTION-TRIGGER:** search existing material for productive relations before adding events.
- **B169-G03 MODE-ROUTER:** exposition/narrative/partial-scene/full-scene are all legitimate.
- **B169-G04 PARAGRAPH-COHERENCE:** join microbeats before optimizing sentence statistics.
- **B169-G05 SOCIAL-SETTING:** treat norms and peer pressure as setting variables.
- **B169-G06 PRECIOUS-PARTICLE:** prefer revealing detail over quirk accumulation.
- **B169-G07 TACTIC-CHANGE:** dialogue progression requires changing tactic/model/state.
- **B169-G08 POSITION-CHANGE:** middle progression is state change, not obstacle count.
- **B169-G09 STRUCTURE-PAYS:** formal complexity must buy reader effect.
- **B169-G10 FLASHBACK-NOW:** past material must change present reading/action.
- **B169-G11 POV-AUTHORITY:** pronoun is not POV architecture.
- **B169-G12 DRIFTWOOD-SYMBOL:** prefer intrinsic evolving motif.
- **B169-G13 RESEE-CORRECT-LEVEL:** structural defect gets structural repair.
- **B169-G14 FEEDBACK-EFFECT-FIRST:** distinguish effect report from repair command.
- **B169-G15 SURPRISE-BEYOND-OUTLINE:** test live consequences that the outline did not anticipate.

## 16. Manuscript-facing verdict

### LESSON ZERO Book One

**KEEP DEVELOPMENT LOCK.** Hodgins adds no new concrete defect evidence requiring a global rewrite.

### Future IVDIVO books

Highest-value application is not another beat sheet. It is:

1. narrative-mode selection;
2. paragraph coherence;
3. causal/social setting;
4. dialogue tactic change;
5. state-change middles;
6. stage-correct revision.

### Final synthesis

Hodgins is an antidote to visible craft machinery. His strongest lesson for IVDIVO is that **all craft systems must disappear into a coherent reader experience**. The project should become more disciplined underneath and less mechanically segmented on the page.
