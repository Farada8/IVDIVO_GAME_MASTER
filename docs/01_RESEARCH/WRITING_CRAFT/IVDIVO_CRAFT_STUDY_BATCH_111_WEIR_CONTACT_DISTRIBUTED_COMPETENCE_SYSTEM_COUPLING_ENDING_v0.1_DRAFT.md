## 1. PURPOSE
Batch 110 captured evidence-driven competence during the first strict segment. Full-source completion adds the more important book-scale mechanisms: first-contact semantics, complementary civilizational competence, reciprocal nonhuman agency, system-coupled successful solutions, identity revision and local-ending architecture.

## 2. GATE B111-01 — SHARED-REFERENT CONTACT
Use:
`SHARED PHENOMENON → MUTUAL SIGNAL → COMMON REFERENT → NUMBER/UNIT MAP → ACTION WORDS → GRAMMAR → ABSTRACT CONCEPTS`.

Do not begin first contact with philosophical exposition if the characters do not yet possess shared semantics.

## 3. GATE B111-02 — COMPLEMENTARY COMPETENCE
For two agents/civilizations:
`A KNOWS/DOES X BUT LACKS Y + B KNOWS/DOES Y BUT LACKS X → SHARED TASK → MUTUAL MODEL UPDATE → NEW JOINT OPTION SPACE`.

Competence should be asymmetric, not a hierarchy where one civilization is simply "more advanced" in everything.

## 4. GATE B111-03 — UNEVEN CIVILIZATIONAL DEVELOPMENT
`DOMAIN A MATURITY ≠ DOMAIN B MATURITY`.

Apply directly to IVDIVO orbital civilization:
- high robotics ≠ mature consciousness science;
- interplanetary infrastructure ≠ large population of long-trained practitioners;
- advanced AI analysis ≠ first-person practice history;
- excellent instruments ≠ settled ontology;
- one field may be scientifically mature while another remains fragmented among small schools.

This is a world-design principle, not an excuse for arbitrary gaps. Each gap needs a causal bottleneck: practitioner scarcity, missing historical data, different sensory embodiment, institutional neglect, reproducibility limits, ethical restrictions or lack of demand.

## 5. GATE B111-04 — RECIPROCAL PERSONHOOD
A nonhuman/conscious robot is not written as a person merely because a human empathizes with it.

Require:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → PREFERENCE/REFUSAL → ACTION THAT CHANGES THE HUMAN'S OPTIONS → CONSEQUENCE`.

Reciprocal rescue/cooperation is stronger than passive "alien needs saving" architecture.

## 6. GATE B111-05 — TRUST THROUGH WORK
`SMALL RELIABLE EXCHANGE → REPEATED ACCURACY → SHARED RISK → RECIPROCAL HELP → VULNERABILITY → COSTLY CHOICE`.

Do not substitute speeches declaring friendship for accumulated behavioral evidence.

## 7. GATE B111-06 — SUCCESS CAN CREATE THE NEXT PROBLEM
`LOCAL SOLUTION WORKS → IT CHANGES ANOTHER SUBSYSTEM → UNMODELED COUPLING → NEW FAILURE/CONSTRAINT → ROOT-CAUSE UPDATE`.

This is not a license for arbitrary reversal. The coupling must be inferable from established systems after the fact.

## 8. GATE B111-07 — SUCCESS-TO-RESPONSIBILITY ESCALATION
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST/ACCESS/RESPONSIBILITY → HARDER NEXT CHOICE`.

Use this aggressively in YA. Competent adolescents do not need to fail repeatedly to have an arc.

## 9. GATE B111-08 — MODEL STATUS
Every technical/mystery explanation carries a status:
`OBSERVATION / MEASUREMENT / INFERENCE / WORKING HYPOTHESIS / CORROBORATED MODEL / UNKNOWN`.

A persuasive explanation is not automatically a world fact.

## 10. GATE B111-09 — RELATIONSHIP CHANGES A-STORY OPTIONS
`EXTERNAL WORK → TRUST/BOUNDARY CHANGE → OPTION SET CHANGES → EXTERNAL DECISION CHANGES`.

Relationship state can alter mission choice while leaving evidence status untouched.

## 11. GATE B111-10 — IDENTITY REVISION MUST BE TESTED BY ACTION
`SELF-MODEL → CONTRADICTORY EVIDENCE → IDENTITY REVISION → LATER CHOICE`.

Do not end with "I finally understood I was brave." Give the revised self-model an expensive behavioral test.

## 12. GATE B111-11 — LOCAL ENDING + COST + EXTERNAL CONFIRMATION
`LOCAL PROBLEM RESOLVED → COST/AFTERMATH → CHANGED LIFE → INDEPENDENT CONFIRMATION → OPTIONAL LARGER QUESTION`.

A saga does not need to solve all ontology to finish a book.

## 13. GATE B111-12 — DISTRIBUTED INTELLIGENCE
Before climax, audit who owns:
1. raw evidence;
2. interpretation;
3. specialized tool/capability;
4. lived consequence;
5. countermodel;
6. final bounded decision.

If one protagonist owns nearly all six, test redistribution.

## 14. GATE B111-13 — TECHNICAL PROSE RHYTHM
`INTENSITY ≠ SHORT-SENTENCE DENSITY`.

When the suspense depends on the reader following a model, coherent multi-sentence paragraphs may be the high-intensity choice.

## 15. FAILURE MODES
- PUZZLE CAROUSEL — repeated calculation/problem scenes without broader state change.
- FLASHBACK ANSWER MACHINE — memory returns exactly what the plot needs every time.
- COMPETENCE = LEGITIMACY — efficient institution treated as ethically right by default.
- SCIENTIFIC VOICE AUTHORITY — fictional technical fluency mistaken for verified science.
- SINGLE-GENIUS MONOPOLY — hero owns evidence, theory, tools, interpretation and decision.
- ALIEN/ROBOT WISH-FULFILLMENT COMPETENCE — nonhuman has perfect capabilities without meaningful limits.
- ANTHROPOMORPHIC CERTAINTY — human interpretation of nonhuman cues treated as motive fact.
- COUPLING CHEAT — a successful fix causes a new failure through a mechanism not previously available even in retrospect.
- SACRIFICE-AS-ONLY-PROOF — love/courage always demonstrated through self-sacrifice.
- LINEAR TECH LADDER — one high capability used to infer universal civilizational superiority.

## 16. CROSS-SOURCE SYNTHESIS
- Herman/Zunshine provide stricter epistemic status discipline than Weir's character voice alone.
- Swain confirms changed-state causality; Weir shows it can live inside long reasoning paragraphs rather than M/R fragments.
- Bell/McKee supply capability/pressure architecture; Weir is a strong counterexample to mandatory setback escalation.
- Card/Corbett/Baxter/Hayes strengthen the personhood/relationship reading: reciprocal agency and changed relationship state, not role labels.
- Wolf/Cambridge SF support the uneven-development and speculative-world firewalls.

## 17. IVDIVO PRODUCTION CONSEQUENCE
For Orbital Youth and the wider saga, use Weir primarily to strengthen:
- uneven domain maturity;
- technical scenes that change social/human state;
- reciprocal conscious-robot/nonhuman agency;
- shared-work trust;
- systems coupling after successful interventions;
- distributed competence;
- bounded local endings.

Do not imitate Astrophage, Taumoeba, Grace, Rocky, Stratt, Weir's cosmology or scientific claims.
