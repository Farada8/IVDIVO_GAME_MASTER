## Main provisional mechanisms extracted

1. `LIVE MATERIAL → OBSERVED DEFECT → RELEVANT TOOL → REPAIR → RETEST`.
2. `PLAN ≠ ACTUAL TEXT ≠ CANON ≠ EVIDENCE STATUS`.
3. Reader-time itself communicates importance; discourse weight should roughly match functional story weight.
4. Theme works through competing models, choices and consequences, not lectures.
5. Character-relative stakes matter more than objective prize size.
6. Opening contract = `ATTENTION + ORIENTATION + PROMISE + FORWARD PRESSURE`, not mandatory action.
7. `CAPABILITY → LIMIT / COST / COUNTERFORCE → OPTION SPACE` for powerful tools/AI/authority.
8. Relationship-specific voice = same person, different history/status/want → different tactic/register.
9. Fictional dialogue is selected/shaped communication, not raw transcript.
10. `UTTERANCE / PAUSE / GESTURE → MOTIVE HYPOTHESIS`, not fact.
11. Conflict is generalized from villain-fighting to meaningful resistance/support that changes state.
