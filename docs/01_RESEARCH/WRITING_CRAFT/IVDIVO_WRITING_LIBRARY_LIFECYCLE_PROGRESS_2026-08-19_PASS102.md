## New production mechanisms

### A. Research provenance

`CLAIM → SOURCE → DOMAIN AUTHORITY → OBSERVATION/MEASUREMENT → INTERPRETATION → ALTERNATIVE MODEL → CONFIDENCE → ACTION`

A plausible analogy is a hypothesis generator, not verification.

### B. Alligator Test

A complication is causally useful only if it changes the current objective/question, evidence, relationship, authority, responsibility, cost, model/tactic, or future option space.

Unrelated spectacle is not escalation.

### C. Scene result correction

Bickham's mandatory disaster is not adopted.

Allowed changed states include genuine success, costly success, partial success, correct restraint, failure, relationship change, evidence change, authority change, and new obligation.

### D. Processing router

Quiet processing is causal when it changes model, relationship, evidence-status, commitment, strategy, or next objective.

It may be immediate, delayed, embedded, compressed, or implied by later behavior.

### E. Anti-choppiness

Do not render cause/reaction as one-line microbeat confetti. Paragraph and narrative-mode diagnosis precede sentence polishing.
