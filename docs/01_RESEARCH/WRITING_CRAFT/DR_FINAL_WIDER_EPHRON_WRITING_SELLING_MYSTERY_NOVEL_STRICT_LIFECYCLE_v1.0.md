## 3. High-value mechanisms retained

### M1 — Fair-play clue architecture
`WORLD FACT → TRACE / CLAIM → SOURCE → SOURCE LINEAGE → ACCESS → WHO KNOWS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION STATUS → NEXT ACTION`

A clue is not merely an object. It can be behavior, statement, discrepancy, document, physical trace or missing expected item. But the observation must remain distinct from the interpretation.

### M2 — Misdirection without authorial lying
`TRUE TRACE → CONTEXT / SALIENCE → PLAUSIBLE MODEL A → DISCRIMINATING EVIDENCE → MODEL B`

The reader may be led toward a wrong interpretation. The underlying trace must remain true.

### M3 — Known-but-hidden POV fairness
If a close-POV character already actively knows X, narration may not simply suppress X solely to manufacture a later surprise.

`POV KNOWLEDGE → FAIR DISCLOSURE BOUNDARY`

This converges with Genette's paralipsis diagnostics.

### M4 — Productive uncertainty vs confusion
`CLEAR QUESTION + MULTIPLE PLAUSIBLE MODELS = MYSTERY`
`UNCLEAR QUESTION / STATUS / SOURCE = CONFUSION`

Misdirect the reader while keeping the causal/evidentiary problem legible.

### M5 — Clue ledger
For every major clue:
`TRACE / CLAIM → SOURCE → LINEAGE → ACCESS → WHO KNOWS → IMPLICATES / EXONERATES → STATUS → NEXT TEST`

IVDIVO extends Ephron by requiring source independence, not just clue counting.

### M6 — Behavior is not motive
A pause, evasive answer, gesture, clothing choice or fidget can create a motive hypothesis.

`OBSERVED BEHAVIOR → MOTIVE HYPOTHESIS → ALTERNATIVE MODEL → CORROBORATION`

Never:
`BEHAVIOR → GUILT / MOTIVE FACT`.

### M7 — Investigation scene routing
Routine investigation should be compressed. Real-time dramatization is reserved for moments where exact words/actions change evidence, consent, relationship, access, authority, interpretation or decision.

`ROUTINE PROCESS → SUMMARY / INDIRECT`
`DISCRIMINATING TEST / EVIDENCE TURN → REAL TIME`

### M8 — Q&A as tactics, not information conveyor
`QUESTIONER WANT → QUESTION TACTIC → LISTENER WANT / RESISTANCE → ANSWER / EVASION → EVIDENCE + RELATIONSHIP STATE CHANGE`

### M9 — Suspense may slow time
`KNOWN / POSSIBLE THREAT → SELECTED SENSORY DETAIL → SUBJECTIVE DURATION EXPANDS → ANTICIPATION`

This directly rejects:
`SUSPENSE = SHORT-SENTENCE DENSITY`.

### M10 — Foreshadowing vs telegraphing
`EARLY TRUE DETAIL + LOW / NATURAL SALIENCE → LATER CONTEXT → RETROSPECTIVE AHA`

Do not underline a clue until only one interpretation remains.

### M11 — Misdirection vs distraction
Good misdirection participates in the same causal question. Mere distraction is unrelated noise.

`RED HERRING → MUST ALTER READER MODEL / CHARACTER MODEL / NEXT TEST`

### M12 — Culprit fair-play
A late culprit cannot be wallpaper promoted to killer in the final act.

Required early support:
`CAPABILITY + ACCESS / OPPORTUNITY + MOTIVE MODEL + TEXTUAL TRACE`

No personality transplant at the reveal.

### M13 — Suspect secret double-use
One hidden fact can plausibly create suspicion while later supporting innocence or a different motive.

`SECRET → MODEL A (suspicion) → CONTEXT / NEW SOURCE → MODEL B`

### M14 — Opening POV as information contract
Opening viewpoint decides what uncertainty is still available. A villain POV can destroy ambiguity simply by proving that a threat exists.

`OPENING = ATTENTION + ORIENTATION + STORY PROMISE + INFORMATION BOUNDARY`

### M15 — Mystery contract / proof ceiling
Not every mystery promises the same kind of answer.

Classify:
- solvable puzzle;
- bounded operational mystery;
- retrospective reinterpretation;
- irrecoverable human mystery.

A book must answer what it actually promised and proved; it must not use a local clue ladder to dump global ontology.

### M16 — Backstory present-consequence gate
`WHY NOW? → WHAT PRESENT MODEL / RELATION / DECISION CHANGES?`

Full flashback is not automatically earned by interesting history.

### M17 — Macro before micro revision
`BOOK ENGINE / PLOT / CHARACTER → SCENE FUNCTION → POV / EVIDENCE → DIALOGUE → PARAGRAPH / RHYTHM → WORDING`

Line-editing cannot repair a wrong culprit, broken clue provenance or causally empty investigation sequence.

### M18 — Feedback: effect vs fix
`READER REPORT → OBSERVED EFFECT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES → TEST`

Readers are authoritative about their experienced confusion/boredom/disbelief, not automatically about the correct repair.

## 4. Limits / rejected universals

Do not adopt as universal laws:
- mandatory personal trauma linking sleuth to case;
- obligatory genius/invincible villain;
- body-language cue as reliable guilt detector;
- intuition/clairvoyance as evidence;
- mandatory cliffhanger or discovery after every suspense passage;
- one specific classic-mystery answer structure for all mystery/SF books;
- act/page arithmetic;
- blanket -ly / -ing purges;
- stronger verbs when they mutate evidence status;
- 2005 agent/query/small-press practices as current market rules.

Adapt coincidence:
`COINCIDENCE MAY COMPLICATE; IT MUST NOT REPEATEDLY SOLVE.`

Adapt intuition:
`INTUITION → HYPOTHESIS → TEST`, not `INTUITION → TRUTH`.

## 5. Cross-source comparison

### Ephron × Genette
Ephron's "don't cheat by hiding what POV knows" operationalizes Genette-style information violations in mystery.

### Ephron × Zunshine
Ephron provides practical clue bookkeeping; Zunshine requires source-monitoring. IVDIVO merges them into provenance + evidence-status.

### Ephron × le Carré
Counting clues is insufficient: corroboration requires independent source lineages.

### Ephron × Herman
A coherent causal narrative about a suspect does not prove motive. Multiple causal models must survive until discriminating evidence.

### Ephron × Scofield / Seger
Investigation scenes need changed state, not just activity. Process can be summary; the discriminating moment gets reader-time.

### Ephron × Le Guin / Lodge / Clark / Hodgins
Suspense can slow time and use longer connected syntax. No short-sentence KPI.

## 6. IVDIVO operationalization

### ROOM 917
Maintain a clue ledger with:
`trace → physical/source lineage → Elena access → Julian access → reader access → interpretation → corroboration → next investigative action`.

Relationship changes may alter disclosure/access/tactic, but:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

### B07 — THE UNLISTED CITY
Personhood evidence cannot be multiple outputs from one classifier/sensor lineage. Once independent personhood threshold is crossed:
`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

### Orbital Youth
Do not turn every investigation/test into a real-time scene. Compress repetitive procedures; dramatize evidence turns, consent, relationship changes, authority decisions and tests that revise the model.

### Consciousness schools
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Strong intuition, vivid experience or specialist fluency does not establish ontology.

### LESSON ZERO
No new global rewrite is authorized by this source alone.
Standing law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Use Ephron only if current text or reader/audio evidence shows a concrete clue-fairness, POV-withholding, provenance, confusion, scene-function or pacing defect.
