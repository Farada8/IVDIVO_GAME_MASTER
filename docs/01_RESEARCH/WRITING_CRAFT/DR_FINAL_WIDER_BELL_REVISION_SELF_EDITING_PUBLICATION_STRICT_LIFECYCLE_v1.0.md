# 1. Structure map

## Front matter / writing-process frame
Bell separates craft knowledge from moment-to-moment creation: learn tools, internalize them, draft with relative freedom, then revise systematically.

## Part One — Self-Editing
1. Philosophy of Self-Editing — craft internalization; creative/critical mode separation.
2. Characters — bond, objectives, flaws, opposition, emotion, inner life.
3. Plot and Structure — stakes, structure, alternatives, adhesive, endings.
4. Point of View — first/third/omniscient, access consistency, attitude.
5. Scenes — objectives/obstacles/outcomes, action/reaction/setup/spice, intensity.
6. Dialogue — tactics, compression, subtext, attribution, distinct voice.
7. Beginnings, Middles, Ends — story movement and large-scale architecture.
8. Show vs. Tell — scene/summary decisions; compression and intensity.
9. Voice and Style — natural voice, reading, syntactic experiments, rhythm.
10. Setting and Description — telling detail, sensory selection, key-moment slowing.
11. Exposition — selection, ownership, indirect delivery, avoiding dumps.
12. Theme — theme through characters, choices, motifs and consequences.

## Part Two — Revision
13. Philosophy of Revision — systematic large-to-small correction.
14. Before You Revise — finish draft, light previous-page edit, 20k step-back, journal, running actual outline, tools and critique groups.
15. First Read-Through — cool-off, read whole manuscript as reader, mark broad effects before wholesale changes.
16. Deepening — laboratory exercises for character/emotion/detail/voice; exploratory rather than compulsory canon.
17. Ultimate Revision Checklist — character, plot, scenes, exposition, POV/voice, setting, dialogue, theme, final polish.

## Epilogue / Appendix
Craft toolbox should be adaptable to circumstance rather than mechanically applied. Exercise answers reinforce POV, scene function, dialogue and show/tell diagnostics.

# 2. High-value claims retained

## A. Create hot; revise cool
`GENERATE / DISCOVER → DISTANCE → DIAGNOSE → REVISE → POLISH`.

Do not keep every craft rule in focal attention while drafting. Craft knowledge should support creation, not freeze it.

## B. Whole manuscript before local surgery
`COOLING PERIOD → WHOLE READ → BROAD EFFECT MARKS → MACRO DIAGNOSIS → LOCAL REPAIR`.

A line defect is not assumed until story/character/scene/POV defects are excluded.

## C. Actual-outline discipline
A running outline should describe the manuscript **as written**, not merely the plan.

`LOCKED/ACTUAL TEXT → STORY-STATE MAP → DIAGNOSIS → UPDATED PLAN`.

## D. Deepening laboratory
Exercises can intentionally overgenerate emotion, backstory, description, voice or alternate behavior. Their output is discovery material, not automatic manuscript canon.

`EXERCISE OUTPUT → CHARACTER TRUTH → CANON → CAUSALITY → PERSONHOOD → ONE MAIN STORY → READER EFFECT → KEEP / BANK / DISCARD`.

## E. Scene/summary routing
Bell explicitly allows summary/transitions and recognizes that showing everything would be slow and bloated.

`LOAD-BEARING SEQUENCE → REAL TIME`  
`ROUTINE PROCESS / TRANSITION / REPEAT → SUMMARY / INDIRECT / ELLIPSIS`.

## F. Slow down important moments
High-pressure moments may require increased descriptive and subjective duration. Suspense is not equivalent to shorter syntax.

## G. Syntactic range
Bell includes exercises that deliberately create long/run-on structures and recommends reading poetry/music-like prose to widen rhythmic range.

`ACTION / SUSPENSE / EMOTION ≠ SHORT-SENTENCE DENSITY`.

## H. Exposition ownership
Information must be selected and assigned to a believable source/POV situation.

`INFO → WHO KNOWS? → WHY NOTICE/SAY/THINK IT NOW? → WHAT CHANGES AFTERWARD?`.

## I. Theme after character
Theme can emerge from draft evidence. Characters should not become mouthpieces for a predetermined thesis.

`THEMATIC QUESTION → COMPETING VALUES/MODELS → CHOICES → CONSEQUENCES → READER INFERENCE`.

# 4. Claims rejected as universal production law

## Conflict/death-stakes monoculture
Reject:
- conflict as the universal blood of every scene;
- death physical/psychological/professional as required stakes;
- worse outcome for the Lead as the default target;
- tension/conflict required in every dialogue exchange.

IVDIVO replacement:
`PRESENT WANT / RESPONSIBILITY → RESISTANCE OR SUPPORT → TACTIC → OUTCOME → CHANGED STATE → DOWNSTREAM CONSEQUENCE`.

Real success may drive escalation:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

## Character formulas
Reject as mandatory:
- grit/aggression as agency;
- Ghost/wound;
- flaws explained by trauma;
- pet-the-dog / honor / unselfishness sympathy shortcuts;
- opposition stronger than Lead as law;
- minor characters reduced to ally/irritant function.

Standing law:
`BOOK FUNCTION ≠ STORYWORLD PERSONHOOD`.

## POV simplifications
Reject:
- fixed hierarchy of intimacy from first → third → omniscient;
- market-based prohibition of omniscient;
- thought/self-report as infallible motive truth.

`THOUGHT / SELF-REPORT = SOURCED SELF-MODEL`, not privileged world fact.

## Fixed structure and market claims
- three-act percentages and doorways are diagnostics, not mandatory arithmetic;
- mythic roles/talismans/final tests are optional lenses;
- 2012 commercial/publishing/self-publishing claims are historical material, not 2026 policy.

# 5. Failure modes derived
1. **REVISION-BEFORE-DISCOVERY** — criticism freezes generation.
2. **LINE-EDITING-A-STRUCTURAL-DEFECT** — prose polish masks book/scene failure.
3. **WHOLE-MANUSCRIPT-BLINDNESS** — local edits begin before a reader-like whole read.
4. **PLAN-AS-CANON** — outline overrides actual manuscript evidence.
5. **DEEPENING-LAB-TO-CANON** — exercise output is inserted because it exists.
6. **CONFLICT-MONOCULTURE** — every interaction converted to combat.
7. **NEGATIVE-OUTCOME-MONOCULTURE** — competence is continually punished.
8. **DEATH-STAKES-INFLATION** — meaningful nonfatal stakes are ignored.
9. **MICROGESTURE-CONFETTI** — emotion is represented by beat fragments between every line.
10. **SHOW-EVERYTHING-BLOAT** — logistics and process are dramatized in real time.
11. **SUMMARY-PHOBIA** — compression is treated as inferior craft.
12. **SHORT-SENTENCE-KPI** — intensity is optimized by punctuation count.
13. **EXPOSITION-PUPPET** — character explains material only for reader benefit.
14. **INNER-THOUGHT-TRUTH-LEAK** — POV belief silently becomes world fact.
15. **MINOR-CHARACTER-INSTRUMENTALIZATION** — supporting people/nonhumans lose independent agency.
16. **THEME-SERMON** — causal proof is replaced by explanation.
17. **CRITIQUE-COMMITTEE-DRIFT** — multiple readers/editors erase intentionality.
18. **POLISH-WITHOUT-STOP-RULE** — revision continues after new evidence has stopped improving the work.

# 6. Cross-source synthesis

## Converges strongly with
- Lamott — discovery before control;
- LaPlante — revision stages and show/tell routing;
- Hodgins — re-imagine structural scene defects rather than line-polish them;
- Seger — diagnose defect level before rewrite;
- Mayer — actual text/state map over neat plan;
- Bickham / Swain — process tools become useful when not used mechanically;
- Le Guin / Francine Prose / Lodge / Zinsser / Williams-Bizup — syntax length is functional; choppiness is often a paragraph/relevance/continuity problem;
- Genette / Chatman — duration and presentation mode precede sentence-level treatment.

## Conflicts / requires filtering against
- Rosenfeld / LaPlante / Hodgins on scene outcomes: success/support/quiet causality are valid;
- Herman / Zunshine on motive inference: behavior/thought is not motive truth;
- Card / Corbett on personhood: recurring supporting characters need independent causal life;
- current IVDIVO evidence architecture: relationship/emotion does not upgrade evidence status.

# 7. IVDIVO production gates

## Revision Stage Router
`DISCOVERY DRAFT → COOLING / DISTANCE → WHOLE-MANUSCRIPT READ → ACTUAL STATE MAP → MACRO DIAGNOSIS → SCENE / POV / EVIDENCE → DIALOGUE / EXPOSITION → PARAGRAPH / READER-STATE → SENTENCE RHYTHM → WORDING / COPY → READER / AUDIO / REGRESSION TEST`.

## Manuscript-lock gate
A craft book is **not evidence of a manuscript defect**.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## Deepening-lab gate
No laboratory exercise automatically enters canon.

## Anti-choppiness gate
`SCENE/MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → GROUP RELATED MICROBEATS → SENTENCE CONTRAST → WORDING`.

`COMPRESSION ≠ CHOPPING`.

## Evidence / POV gate
`WORLD FACT → TRACE/SOURCE → POV ACCESS → INTERPRETATION → STATUS`.

`THOUGHT / FEELING / CONFIDENCE ≠ CORROBORATION`.

# 8. Manuscript validation

## LESSON ZERO Book One
**NO GLOBAL REWRITE.** Bell supplies revision tooling, not new defect evidence. Development lock remains intact. Local change is allowed only if a current reader/audio/continuity/canon/copy defect is independently demonstrated.

## Orbital Youth
Protect real competence and earned success. Do not force negative scene outcomes. Use actual-story-state maps so planned worldbuilding does not override written causality. Compress repeated technical process.

## ROOM 917
Whole-season revision order must be: mystery contract/proof ceiling → clue provenance/reveal order → relationship causal braid → scene necessity → dialogue/subtext → paragraph/rhythm → wording.

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## B07 — THE UNLISTED CITY
Deepening exercises cannot substitute for personhood evidence. After independent threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.
