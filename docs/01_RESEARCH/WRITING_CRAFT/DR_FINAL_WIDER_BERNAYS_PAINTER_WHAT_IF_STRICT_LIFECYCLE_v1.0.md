# 1. Highest-value mechanisms retained

## 1.1 Exercise as component-isolation laboratory
The strongest contribution of the source is methodological: change one craft variable, observe what it does, then decide whether the result belongs in the story.

### IVDIVO law
`EXERCISE = TEST, NOT COMMAND`.

`EXERCISE OUTPUT ≠ CANON`.

An exercise may reveal:
- stronger POV;
- hidden motive conflict;
- missing causal turn;
- better scene mode;
- better dialogue routing;
- voice possibility;
- structural dead end.

It does not automatically create manuscript authority.

## 1.2 Controlled variant generation
The book repeatedly asks writers to produce alternate versions, perspectives, constraints and continuations.

### IVDIVO mechanism
`CURRENT MATERIAL → 3–5 MATERIALLY DIFFERENT VARIANTS → CHARACTER/CANON/CAUSALITY/READER TEST → KEEP / BANK / DISCARD`.

A materially different variant must change more than wording: decision owner, want, evidence, relationship pressure, world constraint, tactic, cost, POV or exit state.

## 1.3 Scene / summary / indirect dialogue are legitimate modes
A major practical strength is its treatment of scene and summary as selectable tools rather than moral categories.

### Dialogue mode router
`EXACT WORDS CHANGE STATE?`
- YES → direct dialogue / real-time scene may be justified.
- NO → summarized dialogue / indirect discourse / narration may be stronger.

Exact wording is load-bearing when it changes:
- consent;
- trust;
- evidence status;
- authority;
- relationship terms;
- decision;
- emotional commitment.

## 1.4 Narrative bridge for secondary time
The source explicitly supports compressing stretches in which the reader does not need beat-by-beat action.

### IVDIVO law
`ROUTINE PROCESS / TRANSPORT / LOGISTICS ≠ AUTOMATIC FULL SCENE`.

Use:
`SUMMARY / BRIDGE → LOAD-BEARING REAL-TIME MOMENT → SUMMARY / CHANGED STATE`.

This is directly useful against choppy over-dramatization.

## 1.5 POV and distance as experimentable variables
Changing first/third person, distance or focal access can reveal what the scene actually needs.

### Gate
`POV EXERCISE → WHAT UNIQUE ACCESS / BLINDNESS / RELATIONSHIP PRESSURE / IRONY APPEARS?`

Do not keep a POV switch solely because the exercise felt fresh.

`POV EXPERIMENT ≠ POV REPAIR UNTIL FUNCTION IS PROVEN`.

## 1.6 Unreliable narration requires cues and reader reconstruction
The useful mechanism is not "make the narrator lie." It is:

`POV REPORT → LANGUAGE / OMISSION / CONTRADICTION / BIAS CUES → READER BUILDS ALTERNATIVE MODEL`.

### Epistemic law
`POV BELIEF ≠ WORLD FACT`.

Unreliability cannot be used as a patch for author continuity errors or impossible knowledge.

## 1.7 Backstory should pay into present action
Exercises around history and exposition repeatedly test whether past material affects the current scene.

### Gate
`PAST EVENT → WHAT PRESENT ASSUMPTION / RELATION / DECISION / FEAR / EVIDENCE DOES IT CHANGE?`

If none:
`SUMMARY / OMIT / PRIVATE WRITER LAB`.

A full flashback must separately earn reader-time.

## 1.8 Interior landscape can remain uncertain
The source is useful in allowing "maybe," mixed motives, partial self-knowledge and contradiction.

### IVDIVO law
`CHARACTER SELF-EXPLANATION ≠ COMPLETE MOTIVE TRUTH`.

Interior uncertainty can be productive when the causal question remains legible.

## 1.9 Constraint exercises expose process assumptions
Alphabet structures, syllable/word limitations, one-sentence variants and other formal tasks are useful because they make habitual choices visible.

### IVDIVO law
`CONSTRAINT = DIAGNOSTIC PRESSURE, NOT HOUSE STYLE`.

A constraint may teach rhythm or selection; it does not become final prose policy.

## 1.10 Short-form density is not short-sentence density
The short-short / flash sections emphasize functional economy of event, image and implication, not a requirement for clipped syntax.

### IVDIVO law
`SHORT FORM ≠ SHORT SENTENCES`.

A long sentence may be the most economical form for one continuous perception or movement.

## 1.11 Revision is re-seeing, not merely polishing
Revision exercises repeatedly test opening, scene function, stakes, dialogue mode, sentence variety, reused details, ending and structural movement.

### Repair order
`ACTUAL STORY STATE → FUNCTION / CAUSALITY → MODE / POV → PARAGRAPH → RHYTHM → WORDING`.

Do not line-edit material whose scene function is wrong.

## 1.12 Learning through imitation is a lab, not plagiarism or canon
Imitation, homage and modeling exercises are useful for isolating technique.

### Gate
`SOURCE TECHNIQUE → IDENTIFY FUNCTION → RECREATE WITH DIFFERENT MATERIAL → OBSERVE EFFECT → DISCARD SURFACE COPYING`.

# 2. Failure modes

## FM-WIF-01 — Exercise-to-Canon Leak
A vivid exercise result becomes world fact without authority review.

## FM-WIF-02 — Constraint-to-House-Style
A one-syllable, fragment, alphabet or short-form exercise becomes permanent prose style.

## FM-WIF-03 — Show-Don't-Tell Absolutism
Everything is dramatized in real time.

## FM-WIF-04 — Dialogue-by-Default
Routine process is forced into quotation marks instead of summary.

## FM-WIF-05 — POV Novelty Bias
A new POV is retained because it feels interesting, not because it buys unique story access.

## FM-WIF-06 — Unreliable-Narrator Patch
Narrative inconsistency is excused as intentional unreliability after the fact.

## FM-WIF-07 — Backstory Museum
Interesting past receives a full flashback without changing current action.

## FM-WIF-08 — Character Questionnaire Bloat
Exercise-generated biography is mistaken for necessary manuscript material.

## FM-WIF-09 — Prompt-Generated Subplot Inflation
Every fruitful prompt becomes a subplot.

## FM-WIF-10 — Trauma / Sympathy Shortcut
High-emotion exercises are used to insert suffering solely to buy reader care.

## FM-WIF-11 — Transport Dramatization
Routine movement is written beat-by-beat.

## FM-WIF-12 — White-Space-as-Transition
A section break is assumed to create causal continuity by itself.

## FM-WIF-13 — Microfiction-to-Fragment Confusion
Density is translated into choppy sentence fragments.

## FM-WIF-14 — Imitation Surface Capture
Borrowed syntax/voice survives instead of the underlying mechanism.

## FM-WIF-15 — Memory-to-Fact Leap
Reconstructed memory is treated as forensic/world fact.

# 3. Cross-source comparison

## LaPlante / Lamott / Bell / Kaufman-Gregoire
Strong convergence:
`GENERATE / EXPERIMENT → DISCOVER → DIAGNOSE → SELECT → REVISE`.

Exercises create possibilities; they do not legislate the story.

## Le Guin / Francine Prose / Hodgins
Strong convergence:
- scene and telling both legitimate;
- rhythm comes from functional variation;
- long sentence is a valid tool;
- paragraph architecture matters more than visual fragment density.

## Scofield / Bickham / Rosenfeld
Convergence on:
`SCENE ONLY WHEN EVENT / EXACT BEHAVIOR MERITS READER TIME`.

## Zunshine / Genette / Chatman
Convergence on:
`POV ACCESS / INTERPRETATION / READER MODEL / WORLD FACT` must remain separate.

# 4. IVDIVO operationalization

## 4.1 New artifact class: LAB_ONLY
Every controlled exercise should produce metadata:
- `exercise_id`
- `target_artifact`
- `target_defect_or_question`
- `variable_changed`
- `variant_id`
- `observed_effect`
- `canon_status = DISCOVERY_ONLY / REJECTED / PROMOTED`
- `promotion_reason`
- `regression_test`

Default is `DISCOVERY_ONLY`.

## 4.2 Exercise routing
Use exercises only when they answer a real question:
- POV unclear → POV/distance lab;
- voices merge → dialogue-only / relation-register lab;
- scene drags → scene-summary mode lab;
- character behavior generic → same-scenario differential-response lab;
- ending weak → alternate consequence / changed-state variants;
- prose choppy → paragraph recombination / long-sentence lab, not more fragments.

## 4.3 ONE MAIN STORY
Prompt success does not justify subplot admission.

`VARIANT → WHAT MAIN-ENGINE STATE CHANGES? → WHAT DOWNSTREAM SCENE DEPENDS ON IT?`

No payment → bank/discard.

## 4.4 ROOM 917
Routine investigation / technical handling can be summarized.

Exact dialogue protected where wording changes:
- clue provenance;
- disclosure;
- Elena↔Julian trust/boundary;
- consent;
- investigative tactic.

Absolute firewall:
`SUSPICIOUS WORDING / UNRELIABLE SPEECH / TRUST / ATTRACTION ≠ CORROBORATION`.

## 4.5 Orbital Youth
Run all major adolescents through the **same** non-canon scenario to discover different salience, threshold and tactics.

Do not import money/job assumptions from exercises into post-money canon.

## 4.6 B07 / nonhuman personhood
A POV exercise written "from the entity" is a writer imagination test, not evidence of personhood.

`EXERCISE POV ≠ WORLD FACT`.

After independent personhood threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.
