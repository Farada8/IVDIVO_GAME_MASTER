# IVDIVO CRAFT STUDY — BATCH 175
## Gillett: Given Circumstances · Objectives · Adaptation · Active Analysis · Embodiment · Ensemble

**Source:** John Gillett — *Acting Stanislavski*  
**Status:** strict FULL READ complete / cross-source synthesis complete  
**Authority:** WIDER / acting-companion craft

## Production thesis

`CAUSE THE MOMENT; DO NOT PRE-MANUFACTURE THE EFFECT.`

For prose:

`GIVEN CIRCUMSTANCES → PRESENT WANT → RELATIONSHIP / WORLD RESPONSE → TACTIC → ADAPTATION → CHANGED STATE`.

## Gates

### G175-01 — Given Circumstances
Before diagnosing low emotion, verify who, where, when, prior action, current want, relationship and immediate cost.

### G175-02 — Objective Is Actionable, Not Necessarily Physical
Valid: understand, decide, persuade, refuse, test, obtain consent, hide, reveal, reconnect.

### G175-03 — Adaptation
If the other party's response changes but the tactic does not, scene pressure may be static.

### G175-04 — Listener Reality
Characters respond to what was actually said/done, not to the author's planned subtext.

### G175-05 — Entrance Continuity
`PRIOR STATE/ACTION → ENTRY`. Cut warm-up logistics that do not alter state.

### G175-06 — Exit Continuity
`EXIT STATE → NEXT OFFSCREEN WANT`. A scene ending should not freeze life.

### G175-07 — Active Analysis Before Micro-Polish
When purpose/staging/relationship is wrong, re-imagine the scene rather than polish lines.

### G175-08 — Beat Map Is Not Typography
`BEAT ≠ SENTENCE` and `BEAT ≠ PARAGRAPH`.

### G175-09 — Inner/Outer Tempo Separation
`INNER SPEED ≠ OUTER SPEED ≠ SENTENCE LENGTH`.

### G175-10 — Pause Has a Job
A pause must continue prior pressure, prepare the next action, contain a decision, or change attention.

### G175-11 — Gesture Budget
Physical beats need character/relationship/tactic/orientation value. Avoid fidget filler.

### G175-12 — Sensory Salience
`EMBODIMENT + WANT + TASK + KNOWLEDGE → SALIENCE`.

### G175-13 — Report Provenance
Self-report and other-report remain sourced claims.

### G175-14 — Private Lab ≠ Page
Backstory/improvisation can help author understanding without becoming exposition.

### G175-15 — Preparation Release
Mechanism labels/scaffolding must disappear from finished prose.

### G175-16 — Ensemble Common Language
Shared canon/evidence/defect vocabulary; distinct objectives/tactics remain.

### G175-17 — Emotion Memory Optional
Personal memory is never a mandatory authenticity requirement.

### G175-18 — Epistemic Firewall
Acting-energy / centre / telepathy / subconscious metaphors do not become IVDIVO science or ontology.

## Anti-choppiness addition

Before shortening or lengthening sentences:

`SCENE FUNCTION → RELATIONSHIP / OBJECTIVE → BEAT LOGIC → PARAGRAPH UNIT → INNER/OUTER TEMPO → SENTENCE CONTRAST`.

If multiple micro-actions belong to one decision/perception, merge them before line polish.

## Key failure modes

- line-actioning every sentence;
- beat-to-fragment conversion;
- microgesture confetti;
- one-superobjective character reduction;
- forced opposition;
- emotion-memory compulsion;
- preplanned line-reading;
- actor-body stereotype;
- preparation addiction;
- genre/style imposed before material;
- rehearsal metaphor promoted to ontology.
