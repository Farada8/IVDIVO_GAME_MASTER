## HIGH-VALUE MECHANISMS

### B93-G01 — FUNCTION BEFORE FORMULA
Ask what structural function is missing before asking whether a Bell beat is missing.

### B93-G02 — DOMINANT CAUSAL ENGINE
ONE MAIN STORY means one dominant causal problem, not one protagonist or one POV.

### B93-G03 — COMMITMENT TRANSITION
A meaningful turn changes obligations/options/authority/evidence, not merely location.

### B93-G04 — MATERIAL VARIANT TOURNAMENT
Generate materially different turns before selecting one. Cosmetic renaming is not variation.

### B93-G05 — OPENING CONTRACT
`ATTENTION + ORIENTATION + PERSON/SUBJECT BOND + STORY PROMISE + FORWARD PRESSURE`.
No forced disaster.

### B93-G06 — SUCCESS MAY ESCALATE
A competent act may genuinely work; escalation can come from the new responsibility created by success.

### B93-G07 — CAUSAL ADHESIVE
Continued involvement must arise from responsibility, evidence, relationship, consent, authority, prior choice or physical world rule—not artificial debt/poverty/kidnapping.

### B93-G08 — MODE ROUTING
Before dramatizing, choose ACTION / REACTION / SETUP / DEEPENING / SUMMARY-INDIRECT / HYBRID.

### B93-G09 — SHOW/TELL IS A ROUTING PROBLEM
Exact behavior earns scene time when wording/action itself changes state. Summary/narration is legitimate when process or repeated information matters more than exact beats.

### B93-G10 — WITHHOLDING DEBT
Delayed answers must change anticipation or inference; a local promise cannot be postponed forever to create a sequel hook.

### B93-G11 — STRAND CONVERGENCE
Co-presence is not convergence. One strand must alter another strand's options, evidence, authority, relationship or decision.

### B93-G12 — BEHAVIORAL ARC PROOF
Do not announce transformation. Demonstrate changed or tested strategy under comparable pressure.

### B93-G13 — PLAN IS HYPOTHESIS
Outline/card/treatment is revisable after live prose reveals stronger character-true causality.

### B93-G14 — MACRO BEFORE MICRO
`ENGINE -> STRUCTURE -> CHARACTER/RELATIONSHIPS -> SCENE -> POV/EVIDENCE -> DIALOGUE -> PARAGRAPH/RHYTHM -> WORD`.

### B93-G15 — FLASHBACK PRESENT-CONSEQUENCE
Past scene earns full dramatization only when exact past event changes the present reader/character state.

### B93-G16 — TANGENT CAUSAL GATE
New live material must pass canon + personhood + ONE MAIN STORY + downstream consequence or be banked.

### B93-G17 — DELIBERATE PRACTICE WITHOUT IMITATION
Read examples for reader effect, map scene functions, extract abstract mechanism, compare across sources, transform through IVDIVO. Never transplant plot content.

### B93-G18 — CHECKLISTS ARE DIAGNOSTIC
A checklist can expose missing functions but does not outrank live story evidence.

### B93-G19 — BACK-COVER COPY AS STRESS TEST
Use internally to test `WHO/PRESENT STATE -> DISTURBANCE -> MAIN PRESSURE -> CENTRAL QUESTION -> EXPERIENCE PROMISE`; do not let marketing copy become canon.

### B93-G20 — LOCAL CLOSURE BEFORE SAGA HOOK
`LOCAL RESOLUTION -> COST/AFTERMATH -> CHANGED STATE -> OPTIONAL NEW VECTOR`.
