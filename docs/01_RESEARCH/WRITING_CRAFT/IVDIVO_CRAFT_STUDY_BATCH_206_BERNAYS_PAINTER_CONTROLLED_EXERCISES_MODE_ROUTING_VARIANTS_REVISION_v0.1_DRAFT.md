# IVDIVO CRAFT STUDY — BATCH 206
## Bernays & Painter — Controlled Exercises · Mode Routing · Variants · Revision

**Date:** 2026-08-22  
**Source:** *What If? Writing Exercises for Fiction Writers*, 3rd ed.  
**Status:** `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`  
**Class:** WIDER

## Governing law
`EXERCISE = COMPONENT-ISOLATION LAB, NOT STORY LAW`.

## Production gates
### 206-01 — Lab Status
Every exercise artifact begins `DISCOVERY_ONLY`.

### 206-02 — One Variable First
A diagnostic exercise should change one major variable whenever possible: POV, distance, narrative mode, scene entry, dialogue directness, ending consequence, constraint, etc.

### 206-03 — Material Variant Test
Variants count as materially different only if they change decision owner, want, evidence, relationship pressure, world constraint, tactic, cost, POV or exit state.

### 206-04 — Scene / Summary Router
`EXACT BEHAVIOR / WORDING CHANGES STATE? → SCENE`.
Otherwise test summary / indirect / embedded scene.

### 206-05 — Dialogue Mode Router
Use direct dialogue for load-bearing wording; summarize routine exchange.

### 206-06 — POV Experiment Payment
A POV switch must buy unique access, blindness, irony, relationship cost, evidence or decision ownership.

### 206-07 — Unreliable Narrator Fairness
`POV BELIEF ≠ WORLD FACT`; unreliability requires cues and cannot retroactively excuse continuity error.

### 206-08 — Backstory Present Payment
Past material gets reader-time only if it changes present interpretation, relation, evidence, fear, option set or decision.

### 206-09 — Constraint Firewall
Alphabet, one-syllable, one-sentence, fragment, formal-imitation and short-short exercises do not become house style.

### 206-10 — Short Form Firewall
`SHORT FORM ≠ SHORT SENTENCES`.

### 206-11 — Revision Before Polish
If the problem is scene purpose / POV / causal state, rebuild there before wording.

### 206-12 — Memory Provenance
`MEMORY / JOURNAL / RECOLLECTION = SOURCED TESTIMONY`, not automatic world fact.

### 206-13 — Prompt Subplot Firewall
A fruitful prompt becomes a subplot only if it changes ONE MAIN STORY and receives downstream payoff.

### 206-14 — Sympathy Shortcut Audit
Do not retain suffering/adversity generated by an exercise solely because it creates instant emotion.

### 206-15 — Imitation Function Extraction
Borrow mechanism/function for study; discard borrowed surface voice/syntax.

## Failure modes
- Exercise-to-Canon Leak
- Constraint-to-House-Style
- Show-Don't-Tell Absolutism
- Dialogue-by-Default
- POV Novelty Bias
- Unreliable-Narrator Patch
- Backstory Museum
- Questionnaire Bloat
- Prompt-Generated Subplot Inflation
- Trauma/Sympathy Shortcut
- Transport Dramatization
- White-Space-as-Transition
- Microfiction-to-Fragment Confusion
- Imitation Surface Capture
- Memory-to-Fact Leap

## Cross-source synthesis
`BERNAYS/PAINTER + LAPLANTE + LAMOTT + BELL + KAUFMAN/GREGOIRE`:
`GENERATE OPTIONS → KEEP NON-CANON → DIAGNOSE → SELECT → PROMOTE EXPLICITLY`.

`BERNAYS/PAINTER + LE GUIN + PROSE + HODGINS`:
`NARRATIVE MODE AND SENTENCE LENGTH ARE FUNCTIONAL VARIABLES, NOT MORAL RULES`.

`BERNAYS/PAINTER + GENETTE + ZUNSHINE`:
`POV REPORT / MEMORY / INTERPRETATION ≠ WORLD FACT`.

## Final engine rule
`EXERCISES EXPAND OPTION SPACE; CANON / CAUSALITY / PERSONHOOD / EVIDENCE / READER-EFFECT GATES CONTRACT IT`.
