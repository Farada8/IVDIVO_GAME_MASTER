# IVDIVO Craft Study Batch 148
## Brandilyn Collins — Personalizing · Values · Objectives · Character Causality

Status: PROVISIONAL / SOURCE FULL READ STILL IN PROGRESS.

## Core synthesis

### A. Character model is causal, not decorative

`CONTEXT / EXPERIENCE → VALUE MODEL → PRESENT WANT → TACTIC → OBSERVABLE BEHAVIOR → CONSEQUENCE → MODEL UPDATE`.

Traits and mannerisms become useful only when they alter action, relationships, reader inference, or plot consequences.

### B. Multiple values, not one master key

Collins's strongest corrective inside `Personalizing` is that inner values interact. They can reinforce, restrain, or redirect one another. IVDIVO therefore rejects single-core-belief determinism.

Production test:
`VALUE A + VALUE B + CURRENT RELATIONSHIP + CURRENT COST → WHICH PRIORITY WINS NOW? → CHARACTER-SPECIFIC TACTIC`.

### C. Reverse-personalizing

Starting with an outward behavior is allowed, but it creates a diagnostic debt:
`QUIRK / MANNERISM → CAUSAL VALUE / HISTORY / CURRENT NEED? → STORY FUNCTION? → KEEP / MODIFY / DELETE`.

If no credible causal/relational basis appears, the behavior is costume.

### D. Live discovery vs outline

Collins explicitly treats unexpected draft behavior as something to investigate after the live flow, not automatically obey or suppress.

IVDIVO gate:
`SURPRISING LIVE MATERIAL → finish generation → CHARACTER TRUTH? → CANON? → CAUSAL CONSEQUENCES? → ONE MAIN STORY? → REPLAN / BANK / DISCARD`.

This converges with Bell's adaptive outline, Lamott/LaPlante generation-vs-revision separation, and Corbett's character hypothesis tested in scenes.

### E. Scene objectives

Collins shifts from who the character is to what the character is trying to accomplish. Useful generalized mechanism:

`SCENE ENTRY STATE → PRESENT WANT / OBJECTIVE → RESISTANCE / SUPPORT → TACTIC CHANGE → OUTCOME → CHANGED STATE`.

An objective can be cognitive or relational. Agency does not require constant external activity.

## Where Collins is too rigid for IVDIVO

Her Four Ds — Desire / Distancing / Denial / Devastation — are retained as one plotting lens only. No mandatory Denial, Devastation, escalating disaster, or final gotcha is imposed. Collins herself notes Devastation may be omitted.

Her frequent conflict framing is broadened to resistance, negotiation, cooperation, consent, evidence constraints, embodiment constraints, and competing legitimate values.

## Cross-source comparison

Card / McKee Character / Corbett: character becomes legible through pressure, relationship-specific behavior, and choice. Collins contributes a useful causal bridge from values to outward mannerism but is more deterministic if read literally.

Stanislavski tradition: objective/action is an impulse to purposeful behavior, not a command that every line carry a tiny separate objective. This protects prose from beat-by-beat mechanical fragmentation.

Scofield / Swain / Rosenfeld: a scene must change state, but the change can be quiet, relational, evidentiary, cognitive, or strategic.

## Production gates

1. VALUE INTERACTION — major characters need at least two meaningful priorities capable of producing different choices in different contexts.
2. MANNERISM CAUSALITY — distinctive behavior must arise from person/context or be cut.
3. RELATIONSHIP-SPECIFIC SELF — same person should not express the same value identically with every interlocutor.
4. OBJECTIVE LEGIBILITY — scene owner needs a present want/actionable question, but it can be to decide, understand, refuse, negotiate, verify, protect a boundary, or cooperate.
5. OBJECTIVE UPDATE — meaningful new information/response should alter tactic, confidence, relationship, or option set.
6. NO QUIRK COUNT — character distinctiveness is not measured by number of gestures/catchphrases.
7. NO MICROGESTURE PATCH — do not repair flat dialogue by adding physical business after every line.
8. DISCOVERY RETEST — unexpected draft behavior is tested after generation before canonization.
9. PERSONHOOD FIREWALL — nonhuman character depth is not measured by human-like mannerisms.
10. EVIDENCE FIREWALL — author motive model and POV interpretation are not corroborated world fact.
