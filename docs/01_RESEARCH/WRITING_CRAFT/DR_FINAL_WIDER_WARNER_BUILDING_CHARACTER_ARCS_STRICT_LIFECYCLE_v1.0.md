## 3. Source passport

### Best use
A **formula-collision laboratory** and catalogue of common beginner-facing arc/structure heuristics.

### Weak use
Not suitable as psychology authority, market authority, universal structure authority, or evidence that all stories require trauma/wound, antagonist, mentor, sidekick, skeptic, seven plot points, happy ending, death-adjacent stakes or a Lie/Truth moral axis.

### Strongest retained ideas
- plot/structure/character should causally interact;
- trackable objectives are useful;
- actions should remain logically consistent with the character model;
- supporting characters should affect the main engine;
- characters should not be reducible to one flaw or quirk;
- out-of-plot scenario exercises can expose character-specific reactions;
- outlines help, but live drafting can reveal stronger behavior;
- character information should be staged rather than dumped;
- not every planned detail belongs in the manuscript.

## 4. Central mechanism extraction

### M1 — Dominant causal nucleus
`MANY EVENTS → ONE DOMINANT CAUSAL QUESTION / ENGINE → CONSEQUENCES`

IVDIVO correction: the nucleus is not necessarily one incident or one hero. It is the main causal engine that all important strands materially affect.

### M2 — Trackable character objective
`PRESENT WANT / RESPONSIBILITY → ACTIONABLE GOAL → TACTIC → CONSEQUENCE`

Retained. Rejected: the goal must be life/death, external, or based on a false desire.

### M3 — Character scenario laboratory
`CHARACTER MODEL → OUT-OF-PLOT SCENARIO → RESPONSE → UPDATE MODEL`

Use as diagnostic lab only. Exercise output is not automatic canon.

### M4 — Plot-character reciprocity
`EVENT CHANGES CHARACTER MODEL/OPTIONS → CHARACTER CHOICE CHANGES PLOT STATE`

Strong and retained.

### M5 — Arc as model-under-pressure
Warner's Lie/Truth language is converted to:
`CURRENT MODEL / VALUE → PRESSURE / EVIDENCE → CHOICE / TACTIC → CONSEQUENCE → MODEL / VALUE / RELATIONSHIP UPDATE`

No mandatory Lie, Truth, Ghost or healing.

### M6 — Supporting-person causal test
`SUPPORTING PERSON → OWN WANT + OWN RELATIONSHIPS → UNIQUE EFFECT ON MAIN ENGINE`

Retained only after de-typing supporting roles.

### M7 — Dynamic consistency
`SURPRISING ACTION → RETROSPECTIVE CHARACTER / CAUSAL SUPPORT`

Retained.

## 5. Major failure modes / rejected universalizations

- **MULTI-FRAMEWORK OVERFIT** — stacked Freytag/Hero's Journey/Three-Act/Story Circle/Fichtean/Save the Cat/Seven-Point obligations.
- **ARC TEMPLATE STACKING** — Positive/Flat/Disillusionment/Fall/Corruption as compulsory molds.
- **TRUTH/LIE OBJECTIFICATION** — `CHARACTER BELIEF ≠ OBJECTIVE TRUTH`.
- **MANDATORY WOUND / GHOST** — depth does not require trauma, secret or brokenness.
- **MANDATORY TRANSFORMATION** — `STATIC ARC ≠ FLAT CHARACTER`.
- **FIVE-ROLE CAST FORMULA** — protagonist/antagonist/mentor/sidekick/skeptic are not five compulsory persons.
- **SUPPORTING CHARACTER AS SERVICE TOOL** — `BOOK FUNCTION ≠ STORYWORLD PERSONHOOD`.
- **ANTAGONIST REQUIREMENT** — resistance may come from physics, evidence insufficiency, consent boundary, institution, competing good values, relationship, timing, embodiment or limited authority.
- **SYMPATHY SHORTCUT** — no automatic empathy through illness, injury, childhood, victimhood, demographic stereotype, pet-loving villain or tragic backstory.
- **HAPPY END / POSITIVE ARC UNIVERSALIZATION** — local closure is required; positivity is not.
- **DEATHLY THIRD-PLOT-POINT / MAXIMUM-STAKES INFLATION** — rejected.
- **OPENING-BANG MONOCULTURE** — opening remains `ATTENTION + ORIENTATION + PROMISE`.
- **SHOW-DON'T-TELL ABSOLUTISM** — narration/summary/indirect remain legitimate.
- **ACTIVE-VOICE / SHORT-SYNTAX PURISM** — rejected.
- **QUIRK = DEPTH** — traits/names/hobbies do not substitute for causal personhood.

## 6. Cross-source comparison

### Card / Corbett / McKee Character
Provide stronger models of relationship-specific self, modus operandi, contradictory values, pressure behavior, cast hierarchy and independent supporting-person life.

### Truby / Brody / Vogler / Bell
Warner demonstrates the danger of stacking templates from multiple schools. IVDIVO retains functions and rejects simultaneous compulsory beat systems.

### LaPlante / Lamott / Swain
Warner's checklist-heavy planning is corrected by:
`GENERATE LIVE → DIAGNOSE → ROUTE TOOL → REPAIR → RETEST`.

### Herman / Zunshine
Warner's motive/“truth” language is epistemically overconfident. IVDIVO retains `BEHAVIOR → MOTIVE HYPOTHESIS`, not motive fact.

### Scofield / Rosenfeld / Ribó
Scenes and arcs do not require constant overt conflict or disaster. Meaningful changed state is the more general test.

## 7. IVDIVO operationalization

### Gate A — Formula Collision Audit
1. Name the actual defect.
2. Pick one diagnostic lens.
3. Note what the lens predicts.
4. Compare with character/canon/causality.
5. Reject any beat that exists only to satisfy the framework.

### Gate B — Arc Model Firewall
`CURRENT MODEL / VALUE → PRESSURE / EVIDENCE → CHOICE → CONSEQUENCE → UPDATE OR TESTED STABILITY`

No mandatory wound/lie/healing.

### Gate C — Stable Personhood
A character may remain fundamentally stable if choices are consequential, tactics adapt, relationships change, costs are paid and reader understanding deepens.

### Gate D — Supporting Character Independence
For every named supporting character ask: what do they want when the protagonist is absent; who else matters; what can they refuse; what choice changes the protagonist's options; what happens outside the protagonist's arc?

### Gate E — Scenario Lab
Out-of-plot tests are useful. `EXERCISE OUTPUT ≠ CANON`.

### Gate F — Post-money Stakes
Do not import default money/job stakes into orbital society. Prefer trust, time, consent, responsibility, specific access, unique mission/place, privacy, relationship, mastery, reputation and lived experience.

### Gate G — Nonhuman Personhood
No conscious robot/nonhuman is a mandatory mentor/sidekick/informer.
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Gate H — Mystery epistemics
`CHARACTER BELIEF/TRUTH CLAIM → SOURCE → ALTERNATIVE MODEL → CORROBORATION → STATUS UPDATE`.
