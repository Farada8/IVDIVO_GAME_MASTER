## 1. METRIC / MISSION SEPARATION

A training game gives points under rules that allow a rational player to optimize the score in a way that would be strategically useless in real combat. The key transferable mechanism is not the specific game but the systems principle:

`REAL OBJECTIVE → PROXY METRIC → AGENT OPTIMIZES PROXY → PROXY WIN / REAL-OBJECTIVE FAILURE → RULE REVISION`.

### IVDIVO gate
For every school score, algorithmic objective, institutional KPI, reputation system or public ranking:

1. What real-world outcome is the metric meant to represent?
2. What behavior does the metric actually reward?
3. Can an intelligent participant maximize it while undermining the real outcome?
4. Who notices the divergence?
5. Can the rule be changed, appealed or audited?
6. Who bears the cost before correction?

This is useful precisely because no villain is required. Bad outcomes can emerge from a reasonable proxy plus adaptive agents.

### Failure mode — METRIC = MISSION
Do not let a ranking, test result, efficiency score or predictive model become evidence of the whole value it was designed to approximate.

Examples of IVDIVO application domains:
- cadet evaluation;
- allocation/scheduling systems;
- safety scores;
- public reputation;
- algorithmic routing;
- specialist-school reproducibility measures;
- robot/human performance evaluation.

## 2. PUBLIC DISCLOSURE AS STATE CHANGE

A fact about family stigma moves from controlled/private context into the peer group's shared knowledge. Its evidentiary truth does not change, but its social causality does.

`CONTROLLED FACT → DISCLOSURE → AUDIENCE MODEL UPDATE → BELONGING / SELF-PRESENTATION / RELATIONSHIP OPTIONS CHANGE`.

### Key distinction
`MORE PEOPLE KNOW X ≠ X IS MORE TRUE`.

This extends the Zunshine/Collins provenance system:
- evidence status;
- audience distribution;
- public interpretation;
- relationship consequence
must be tracked separately.

## 3. STIGMA AND SELF-CONCEPT

The youth pressure is not merely external humiliation. Public stigma can create a second-order identity conflict:

`I DEFEND THIS FAMILY/PERSON → I ALSO WANT TO BE SEEN AS MYSELF → RELIEF WHEN STIGMA IS ABSENT → GUILT ABOUT THAT RELIEF → NEW SELF-PRESENTATION PRESSURE`.

This is stronger than a flat "prove them wrong" arc because loyalty and individuality can both be sincere.

### Orbital Youth application
Useful for:
- family profession/reputation;
- controversial mentor lineage;
- affiliation with a rare school of consciousness practice;
- public error attached to a team;
- robot manufacture/model lineage without treating model origin as destiny.

Firewall:
A lineage or institutional label must not predetermine motive/personhood.

## 4. COMPETITION CAN REVEAL DIFFERENT MODELS OF SUCCESS

In one shared exercise, characters optimize differently:
- speed/aggression;
- observation before acting;
- safe accumulation;
- experimentation;
- precision;
- exploiting written rules.

Mechanism:
`SAME RULES → DIFFERENT CHARACTER MODEL → DIFFERENT TACTIC → DIFFERENT COST / INFORMATION`.

This is a practical ensemble differentiator. A shared test should not merely rank competence; it can reveal how different people define the task.

## 5. PROTAGONIST CLEVERNESS REQUIRES MISSION CHECK

A clever exploit is not automatically admirable just because it wins.

Gate:
`CLEVER MOVE → LOCAL RESULT → TEAM / RELATIONSHIP COST → REAL-MISSION ANALOGUE → WOULD THIS STILL BE GOOD OUTSIDE THE GAME?`

This prevents writers from confusing ingenuity with judgment.

## 7. CROSS-SOURCE COMPARISON

### Skyward + Hunger Games

Combined gate:
`INFORMATION/PERFORMANCE → REAL AUDIENCE → AUDIENCE MODEL → MATERIAL/SOCIAL CONSEQUENCE`.

### Skyward + Weir
Weir emphasizes scientific proxy/test loops; Skyward Ch15 demonstrates proxy failure in social/training design. Together:
`MEASUREMENT ≠ TARGET`.

### Skyward + Swain
Swain's changed-state emphasis applies: the training episode matters because it changes rivalry and the social state, not because a score was generated.

### Skyward + Zunshine
Public knowledge, belief, interpretation and fact must remain separate metadata fields.
