# IVDIVO CRAFT STUDY — BATCH 211
## Orson Scott Card — SF/F World Rules · Exposition · MICE · Reader Protocols

**Source:** *How to Write Science Fiction and Fantasy* (1990)  
**Status:** SOURCE STRICT-COMPLETE / BATCH OPERATIONALIZED

## Core synthesis
Card is most useful when treated as a causal-worldbuilding and information-design source, not as a timeless genre-market authority.

### Gate B211-01 — World Rule Causal Payment
`WORLD RULE → AFFORDANCE / CONSTRAINT → SOCIAL / INSTITUTIONAL RIPPLE → PERSON-SPECIFIC CHOICE → CONSEQUENCE`.

Reject lore-only rules that do not change downstream action.

### Gate B211-02 — Rule-Exception Integrity
A later exception must be foreshadowed, evidenced, or costly. Never invent a climax exception only to save the protagonist.

### Gate B211-03 — Multiple Consequence Ecology
An innovation or disaster should generate multiple reactions and second-order effects. Reject `MONOLITHIC SOCIETY RESPONSE`.

### Gate B211-04 — Seed Is Not Canon
`SEED → DRAFT / WORLD / CHARACTER EVIDENCE → REPLAN`.

### Gate B211-05 — Role Separation
`CAUSAL OWNER ≠ DECISION OWNER ≠ POV ACCESS OWNER`.

### Gate B211-06 — MICE Promise Diagnostic
Milieu / Idea / Character / Event may identify the dominant promise, but no category is mandatory and no single category owns the whole book.

### Gate B211-07 — Opening / Ending Contract
Opening establishes governing need/question/state; ending must pay or meaningfully revise it.

### Gate B211-08 — Controlled Abeyance
`UNKNOWN TERM → SIGNALLED GAP → CONTEXT → PARTIAL MODEL → LATER PAYOFF`.

Reader may not know the answer; reader should know that not knowing is intentional.

### Gate B211-09 — POV Information Fairness
Do not hide load-bearing information already known to the established POV solely to manufacture a twist.

### Gate B211-10 — Reader Model Progressive Disclosure
`ORIENT → ACT → ADD TRACE / TERM → INFERENCE → CLARIFY / REVISE`.

### Gate B211-11 — Diction as Culture / Relationship
Voice follows worldview, social relation, current goal and register; not generic fantasy archaism or future-slang.

### Gate B211-12 — Taboo Lexicon
Cultural taboos can appear through euphemism, avoidance, offense and relationship consequences.

### Gate B211-13 — Technical / Social Coupling
Technical rigor and social rigor must coexist. `DOMAIN A MATURITY ≠ DOMAIN B MATURITY`.

### Gate B211-14 — Nonhuman Causal Model
`EMBODIMENT + ENVIRONMENT + CULTURE + HISTORY + OWN MODEL/WANT → ACTION`.

A human comparator is optional, not required.

### Gate B211-15 — Wise Reader Questions
Do not ask only “did you like it?” Ask where the reader was confused, what they thought was happening, what they expected, where attention dropped, what felt too early/late, and which choice felt unearned.

### Gate B211-16 — Stage Firewall
Pre-lock discovery may overturn outlines. Post-lock revision still requires current defect evidence.

## Cross-source synthesis
Card + Wolf + James + Weir + Herman: worldbuilding is causal, not encyclopedic.

Card + Genette + Ephron + Zunshine: suspense requires honest information architecture.

Card + Bell + Seger + Mayer + Lamott: plan is provisional; actual story evidence may force replan.

Card + Truby Genres: genre/MICE labels diagnose reader promise but do not dictate the causal engine.

Card + Le Guin + Lodge + Zinsser + Clark: exposition and suspense do not imply sentence fragmentation.

## Standing production laws reinforced
`ONE MAIN STORY ≠ ONE POV / ONE CHARACTER`.

`PLAN ≠ ACTUAL TEXT ≠ CANON ≠ EVIDENCE STATUS`.

`PRODUCTIVE UNCERTAINTY ≠ CONFUSION`.

`BOOK ROLE ≠ STORYWORLD PERSONHOOD`.

`ACTION / SUSPENSE / SF / MYSTERY ≠ SHORT-SENTENCE DENSITY`.
