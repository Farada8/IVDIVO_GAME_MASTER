2. **Action Objectives** — scene-level wants and tactical behavior.
3. **Subtexting** — meaning carried beneath or around literal dialogue.
4. **Coloring Passions** — emotional states as mixtures rather than single labels.

## Claims retained after comparison
### 1. Characterization should connect inner priorities to observable behavior
Operational form:
`VALUES / PRIORITIES + RELATIONSHIP + CURRENT COST → PRESENT WANT → TACTIC → CHOICE → CONSEQUENCE`.

### 2. Objective and tactic are different variables
A character may keep the same objective while changing tactics under resistance. Repeated wording with the same tactic is not scene progression.

### 3. Subtext is situational, not mandatory
Direct speech may be stronger when honesty itself is the earned turn. Use subtext where a character cannot, will not, or need not state the full meaning.

### 4. Emotional dimensionality is contextual
`TRAIT STABILITY != BEHAVIORAL UNIFORMITY`.
A stable value can produce different surface behavior under different relationships, costs, evidence, and constraints.

### 5. Inner and outer rhythm are independent
`INNER PROCESS SPEED != OUTER MOTION SPEED`.
A still character can process rapidly; fast action can accompany cold methodical thought.

### 6. Compression is not chopping
`COMPRESSION != SHORT-SENTENCE DENSITY`.
Compression may mean delete repeated meaning, summarize process, use indirect dialogue, merge microbeats, or select a more exact detail.

### 7. Emotional material must be transformed through the character
Useful form:
`AUTHOR / OBSERVED / IMAGINED INPUT → ABSTRACT AFFECTIVE / SENSORY MECHANISM → CHARACTER VALUES + HISTORY + EMBODIMENT + RELATIONSHIP + OBJECTIVE → CHARACTER PERCEPTION / TACTIC / CHOICE`.

## Major correction: Emotion Memory firewall
Collins presents deliberate personal recall more centrally than the broader Stanislavski tradition warrants. Cross-comparison with Stanislavski sources shows emotion can arise from Given Circumstances, action, imagination, objects of attention, relationships, language, sound, setting, and other stimuli.

IVDIVO production law:

**`PERSONAL MEMORY = OPTIONAL INPUT, NOT REQUIRED AUTHENTICITY`.**

Preferred emotional-revision router:
1. Given Circumstances / scene reality.
2. Present want / objective.
3. Relationship, consent, and status.
4. POV knowledge and evidence state.
5. Embodiment and sensory conditions.
6. Tactic / physical or verbal action.
7. Imagination, observation, analogous low-risk experience.
8. Optional personal recall if voluntarily useful.
9. Character-specific transformation.
10. Reader-effect retest.

No writer, collaborator, or agent is required to reopen traumatic personal experience to make fiction authentic.

## New synthesis from the completed Secret #7
### A. Affective analogy is not causal or moral equivalence
The fly-to-murderer exercise demonstrates how a small experience can provide an affective component for writing an extreme character. But this does **not** establish equivalent motive, ethics, psychology, or responsibility.

Gate:
`SHARED AFFECTIVE COMPONENT != SHARED MOTIVE / MORAL STATUS / BEHAVIORAL PREDICTION`.

### B. Observation of others produces hypotheses, not privileged access
Collins recommends watching other people and recording perceived emotions. IVDIVO must preserve the epistemic distinction:
`OBSERVED BEHAVIOR → EMOTION / MOTIVE HYPOTHESIS → ALTERNATIVE MODEL → CHARACTER USE OR CORROBORATION`.

This is especially important for mystery and nonhuman persons.

### C. Reader participation is not endorsement
A reader can imaginatively enter anger, fear, revenge, attraction, or cruelty without endorsing the action.
`READER AFFECTIVE RESPONSE != MORAL LEGITIMACY / CONSENT / WORLD FACT`.

### D. Technique circularity supports routed revision
The seven techniques are best treated as a mechanism bank. Do not run all seven consciously during every sentence.
`LIVE DRAFT → OBSERVED DEFECT → ROUTE TO RELEVANT TOOL → REPAIR → RETEST`.

## Cross-source comparison
- **Card / Corbett / McKee Character:** Collins' values/objectives are strongest when treated as competing priorities under relationship-specific pressure, not one deterministic core truth.
- **Stanislavski / practical Stanislavski scholarship:** expands emotional access beyond direct personal recall and warns against forcing emotion detached from present action.
- **LaPlante / Lamott / Bell / Swain:** supports `GENERATE FIRST → DIAGNOSE LATER`; craft tools should not freeze discovery.
- **Zunshine / Fludernik:** observed cues and emotional inference must retain source and confidence status.
- **Le Guin / Clark / Prose / Lodge / Zinsser:** rejects any automatic mapping from intensity to short sentences.
- **Baxter / Chiarella / McKee Dialogue:** subtext and nonverbal communication are tactical options, not mandatory ornament.

## IVDIVO operationalization
### Character gate
`VALUE A + VALUE B + RELATIONSHIP + CURRENT COST → PRIORITY NOW → TACTIC → CONSEQUENCE`.
Require at least one competing value and relationship-specific variation before treating a major character as understood.

### Dialogue gate
`WANT → VERBAL / NONVERBAL TACTIC → ACTUAL LISTENER RESPONSE → TACTIC CHANGE → CHANGED STATE`.
Subtext may alter relationship or suspicion; it does not automatically change evidence status.

### Emotion gate
`WRITER FEELS X != CHARACTER FEELS X != READER FEELS X`.

### Mystery gate
`EMOTIONAL DISPLAY → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.

### Conscious nonhuman person gate
`OWN PRIORITIES → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.
Human-style autobiographical emotion memory, facial expression, trauma, warmth, or nervous mannerisms are not prerequisites for personhood.

### Consciousness-practice epistemic gate
`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.
Intensity of experience is not ontological proof.

### Prose / anti-choppiness gate
`SCENE FUNCTION → POV / EVIDENCE → EMOTIONAL / RELATIONAL TURN → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.
Do not translate emotion into gesture-by-gesture typography.
