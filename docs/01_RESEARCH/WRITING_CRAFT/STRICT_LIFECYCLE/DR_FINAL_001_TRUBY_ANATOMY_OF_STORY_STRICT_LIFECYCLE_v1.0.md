# 3. STRUCTURE MAP

## Ch1 — Story as organic development
Core proposition: story should grow from internal relations among desire, action, learning, character and world rather than external act markers.

## Ch2 — Premise
Explore possibilities before commitment; identify promise, inherent story problems, designing principle, central conflict, basic action, possible change and audience appeal.

## Ch3 — Seven key structure steps
Weakness/need → desire → opponent → plan → battle → self-revelation → new equilibrium. Useful as causal vocabulary, not universal IVDIVO template.

## Ch4 — Character web
Character is designed relationally: function, value, opposition, desire, variation and pressure across a web rather than isolated biography.

## Ch5 — Moral argument
Theme becomes persuasive through action/consequence and value conflict; dialogue is secondary to structural proof.

## Ch6 — Story world
Arena, subworlds, natural/man-made spaces, tools, passageways, time and world-development should interact with character and structure.

## Ch7 — Symbol web
Repeated and varied images/objects/actions can accumulate meaning. Symbols work best as relational webs, not isolated authorial labels.

## Ch8 — Plot
Plot = designed causal/revelatory weaving of actions and information. Includes journey, unity, reveals, 22-step expansion, revelation sequence and storyteller.

## Ch9 — Scene weave
Scene list as minute plot architecture: order, crosscutting, causal continuity, strand control and gap detection before prose.

## Ch10 — Scene construction / symphonic dialogue
Scene position on character arc; desire, endpoint, opponent, plan, conflict, reveal; dialogue operates through plot-action, values/moral argument and repeated key language.

## Ch11 — Never-ending story
Reject premature/arbitrary/overclosed endings. Rich reread value comes from interacting systems, consequential ambiguity, background texture and endings that recontextualize rather than merely close a puzzle.

# 5. CLAIM EXTRACTION — FINAL

## C1 — STORY IS AN INTERDEPENDENT SYSTEM
Character, plot, world, theme, symbol, scene and dialogue become stronger when causally interlocked.

## C2 — ACTION + LEARNING DRIVE STORY
A character acts toward a desire, learns new information, revises a decision and acts again.

## C3 — PREMISE MUST BE EXPLORED BEFORE EXPENSIVE EXECUTION
The first obvious version of an idea is rarely the only possible story.

## C4 — DESIGNING PRINCIPLE IS AN ORGANIZING PROCESS
A useful designing principle changes how the story unfolds, not merely how the writer describes it.

## C5 — PLOT IS ACTION + INFORMATION MANAGEMENT
Plot is not just event sequence. Revelation order changes interpretation and therefore action.

## C6 — REVELATION MUST CAUSE DECISION
A reveal that does not alter desire, motive, plan, relationship or behavior is usually lore rather than plot.

## C7 — CHARACTER IS RELATIONAL
A character becomes legible through contrasts, alliances, opposition, values, habits and roles across a social network.

## C8 — STRONG OPPOSITION EXPOSES A WEAK MODEL
The best resistance has intelligence, evidence and a partially valid worldview.

## C9 — THEME IS STRUCTURAL
The book's argument is strongest when consequences demonstrate it before anyone explains it.

## C10 — WORLD CHANGES OPTIONS
Space, infrastructure, technology, time and social arrangement matter when they alter action, risk, access, relationship or meaning.

## C11 — PASSAGEWAYS SIGNAL RULE-CHANGE
A transition between materially different subworlds can prepare the reader for a new rule set; the transition itself may deserve narrative attention when it changes cognition/behavior.

## C12 — TOOLS REVEAL RELATIONSHIP TO WORLD
Technology can reveal identity, competence, dependency, power and system structure, but this is a causal function, not an invitation to tech catalogues.

## C13 — SYMBOLS ACCUMULATE THROUGH VARIATION
Repeated detail gains meaning when recurrence changes context or emotional charge.

## C14 — SCENE WEAVE PRECEDES LINE POLISH
Scene ordering, strand interaction and missing causal links should be fixed before sentence-level editing.

## C15 — SCENES HAVE LOCAL OBJECTIVES INSIDE GLOBAL ARCS
Scene design benefits from knowing the scene's place in a relationship/character/plot development, not only its isolated conflict.

## C16 — DIALOGUE IS MULTITRACK ACTION
Dialogue can simultaneously move immediate action, expose values and develop repeated language/subtext. These tracks should not become mandatory checkboxes.

## C17 — ENDINGS SHOULD CLOSE THE LOCAL STORY WITHOUT DEADENING THE WORLD
An ending may complete the book while preserving ongoing desire, ambiguity, changed relationships and future consequences.

# 6. MECHANISM EXTRACTION — IVDIVO TRANSFORMATIONS

## M1 — ONE CAUSAL ENGINE
`ONE MAIN STORY = one dominant evolving problem, not one character doing everything.`

Multiple POVs/private lives are valid if their consequences alter and reconverge on the main problem.

## M2 — ACTION / LEARNING LOOP
`STATE → WANT → ACTION → RESPONSE → NEW INFORMATION → MODEL REVISION → DECISION → NEW ACTION`.

Use for plot, investigation, relationships and training.

## M3 — REVELATION-TO-ACTION GATE
`OBSERVATION → SOURCE STATUS → INTERPRETATION → COUNTERMODEL → DECISION → CONSEQUENCE`.

A revelation earns plot status only when it changes action or meaningful state.

## M4 — TRACKABLE OBJECTIVE VS DEVELOPMENTAL NEED
Autonomy, belonging, maturity and identity are developmental pressures. They do not substitute for a concrete book-level objective with an observable resolution condition.

## M5 — CHARACTER WEB / RELATIONSHIP NETWORK
Define major people through differing wants, methods, values and obligations relative to the same story pressure. Preserve independent personhood.

## M6 — COUNTERMODEL OPPOSITION
`REAL BENEFIT + REAL EVIDENCE + REAL COST OF HERO'S PLAN + BLIND SPOT`.

This supports competent adults, institutions and conscious robots without villain retrofit.

## M7 — VALUE SHADOW
Important values can produce both strength and costly overextension:
`responsibility → reliability / overcontrol`, etc.

Only use when demonstrated in action.

## M8 — SYSTEMIC CONSEQUENCE
`SYSTEM RULE → LOCALLY RATIONAL CHOICE → ACCUMULATION → UNEXPECTED AGGREGATE EFFECT → MODEL REVISION`.

Especially useful in post-money/high-automation society.

## M9 — WORLD-RULE CAUSALITY
`WORLD / INFRASTRUCTURE RULE → PERSON-SPECIFIC OPTION SET → CHOICE → CONSEQUENCE`.

Reject world tourism.

## M10 — PASSAGEWAY AS COGNITIVE TRANSITION
Use a transition in detail only when crossing changes physical rules, social norms, sensory assumptions, access or behavior. Compress routine transitions after the rule is learned.

## M11 — TECHNOLOGY AS CHARACTER RELATION
`TOOL/SYSTEM → WHAT IT AMPLIFIES → WHAT DEPENDENCY/POWER IT CREATES → HOW CHARACTER USES/REFUSES IT → CONSEQUENCE`.

Do not infer that all available technology is socially or morally equivalent.

## M12 — DEVELOPING SYMBOL
`DETAIL/IMAGE → RECURRENCE IN NEW CONTEXT → CHANGED MEANING → PAYOFF`.

No mandatory symbol line. No fixed dictionary meaning.

## M13 — REVEAL LADDER
Revelations should be logically learnable and should change the operational model. They need not monotonically become louder or arrive faster.

## M14 — SCENE WEAVE AUDIT
Before prose polish, map each scene by:
`PRIOR CONSEQUENCE / OWNER / INTENTION / PRESSURE / CHANGED STATE / NEXT CAUSAL LINK / PAYOFF`.

## M15 — DIALOGUE THREE-FUNCTION CHECK
Direct dialogue is strongest when exact wording changes at least one of:
- immediate action/tactic;
- relationship/power;
- values/interpretation;
- evidence status;
- recurring language/subtext.

Routine procedure should often be summarized.

## M16 — LOCAL CLOSURE + OPEN WORLD
`MAIN LOCAL PROBLEM RESOLVED → COST/AFTERMATH → NEW STABLE-ENOUGH STATE → OPTIONAL SAGA HOOK`.

Do not use an ending reveal merely to reopen the just-resolved book.

# 7. FAILURE MODES — FINAL

1. **ANTI-TEMPLATE BECOMES TEMPLATE** — replacing three-act rigidity with seven/22-step rigidity.
2. **MANDATORY MORAL FLAW** — forcing a hero to harm others so the model has a moral need.
3. **SELF-REVELATION MONOCULTURE** — requiring every climax to be a lesson about how to live.
4. **ONE-DESIRE DOGMA** — treating staged objectives as multiple stories despite one causal engine.
5. **SAME-GOAL OPPONENT DOGMA** — contriving competition for one prize when real conflict is method/obligation/value.
6. **CONSTANT-PRESSURE MONOCULTURE** — forgetting success, intimacy, curiosity, competence and contemplation can move story.
7. **ARCHETYPE FLATTENING** — story function replacing personhood.
8. **FOUR-CORNER NUMEROLOGY** — exact topology mistaken for a law.
9. **THEME AS VERDICT** — causal complexity replaced by author's moral pronouncement.
10. **WORLD-AS-METAPHOR OVERREAD** — every room/object forced to mirror the hero.
11. **MICROCOSM TOTALIZATION** — one district/institution treated as the entire civilization.
12. **TECHNOLOGY TELEOLOGY** — technology assumed to carry a predetermined moral meaning.
13. **PASSAGEWAY INDULGENCE** — every transition dramatized because it can be symbolic.
14. **SYMBOL OVERENGINEERING** — author-designed symbol web becomes visible machinery.
15. **REPETITION WITHOUT DEVELOPMENT** — repeated symbol/tagline does not change meaning.
16. **WITHHOLDING OVERREACH** — reader denied facts the POV legitimately knows.
17. **REVEAL ESCALATION LADDER** — each revelation forced to be bigger/faster regardless of logic.
18. **REVERSAL GIMMICK** — final twist dominates character and causality.
19. **STORYTELLER FRAME DECORATION** — narrator exists only to announce that a story is being told.
20. **SCENE-WEAVE OVERPLANNING** — scene list becomes substitute for discovering actual human behavior.
21. **DIALOGUE TRACK CHECKLIST** — every exchange forced to contain plot + moral debate + motif.
22. **FIRST-LINE TOTALIZATION** — opening sentence treated as needing to encode the entire book.
23. **FALSE NEVER-ENDINGNESS** — refusing satisfying local closure in the name of ambiguity or saga continuation.
24. **PREMISE FATALISM** — early premise statement treated as immutable instead of revisable under evidence.
25. **FORM HIERARCHY** — branching/multiperspective assumed more advanced than linear form.

# 8. CROSS-SOURCE COMPARISON

## Truby × Rosenfeld
Convergence: causal continuity and scene consequences.
Correction: Rosenfeld is more useful at scene scale and permits partial success, contemplation and varied outcomes; this prevents Truby's macro pressure from becoming repetitive scene attack.

## Truby × Bell
Convergence: intelligent opposition, suspense through uncertainty, plot as designed pressure.
Correction: Bell and Truby both need a firewall against stakes/pressure inflation and universal conflict prescriptions.

## Truby × Card
Convergence: relational character design.
Correction: Card better protects independent personhood, POV distance and relationship-specific selves. Character function is not identity.

## Truby × Brody
Convergence: trackable external problem plus developmental pressure.
Correction: neither 22 steps nor 15 beats are mandatory timing laws. IVDIVO uses causal function, not percentage retrofit.

## Truby × Herman / Oatley
Convergence: action follows reasons, models and goals.
Correction: person-level reasons and reader simulation are psychologically stronger than mandatory moral weakness.

## Truby × Zunshine
Convergence: reader actively interprets information.
Correction: source-monitoring makes information fairness explicit and blocks arbitrary withholding.

## Truby × Chatman
Convergence: structural distinction between essential causal events and presentation.
Correction: story/discourse analysis prevents Truby's plot architecture from dictating one narrative order or POV implementation.

## Truby × Le Guin / Clark / Prose
Correction layer: macro causality does **not** imply chopped syntax, uniform paragraphing, nonstop speed or overt motif. Reader effect governs prose rhythm.

# 9. IVDIVO OPERATIONALIZATION

## ONE MAIN STORY
Before chapter drafting, write one evolving causal chain. Subplots must either alter decisions/relationships in that chain or be deliberately limited ordinary-life texture.

## ORBITAL YOUTH
Post-money conflict should rely on time, trust, responsibility, relationship, unique roles, non-fungible access, consent, reputation, mastery and finite human/robot attention—not disguised currency.

Worldbuilding is accepted when orbital infrastructure changes decisions. A transit rule, gravity regime, household norm, robot community or environmental system earns detail only if it changes the human/robot option set.

## CONSCIOUS ROBOTS
Truby's function/archetype language is explicitly subordinated to personhood. A named conscious robot requires:
- independent want;
- right to refuse;
- relationships outside the human protagonist;
- preferences/obligations;
- consequences if replaced by a tool.

## SPECIALIST CONSCIOUSNESS SCHOOLS
Do not import mystical certainty through archetype symbolism. Require:
`LINEAGE / METHOD → PRACTICE TIME → REPRODUCIBLE OBSERVATION → INTERPRETATION LIMIT → SCHOOL DISAGREEMENT → PERSONAL MOTIVE/COST`.

High orbital technology does not imply high mainstream dimensional/consciousness knowledge.

## MYSTERY / REVEALS
Use reveal ladder only with source-monitoring:
`FACT → SOURCE → OBSERVATION/INFERENCE → ALTERNATIVE → TEST → STATUS CHANGE → ACTION`.

## PROSE
Structural causality is upstream of line edit. First repair wrong scenes/order/POV/reveal ownership. Then apply sentence/rhythm/paragraph gates. Never chase “shorter = more suspense.”
