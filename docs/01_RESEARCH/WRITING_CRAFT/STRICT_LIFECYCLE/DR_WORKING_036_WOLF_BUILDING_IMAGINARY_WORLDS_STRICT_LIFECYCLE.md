## 4. PROVISIONAL CLAIMS — INTRODUCTION + CH1 + EARLY CH2 ONLY

### W36-C01 — World and story are distinct objects
A world may support many stories, no story, or material beyond the requirements of any one plot. This is analytically useful but creates a production hazard if imported directly into novel prose.

### W36-C02 — Secondary-world difference is a spectrum
Worlds differ from the Primary World by degrees. A small changed default may imply an entire network of technological, social and cultural consequences.

### W36-C03 — One changed default should propagate
The Heinlein “door dilated” example demonstrates compact worldbuilding: one unfamiliar action suggests technology, architecture and social assumptions without a lecture.

### W36-C04 — Worldbuilding and narrative economy can conflict
World data may enrich depth but also halt narrative. Tolkien's own threat to move excessive Gondor/Rohan exposition to appendices is an explicit case of story/world tension.

### W36-C05 — Invention, completeness and consistency create secondary belief
A believable world does not need literally infinite detail. It needs enough invented difference, cross-system completeness and internal consistency for audiences to extrapolate missing parts.

### W36-C06 — Audience gap-filling is a production resource
Readers fill unspecified material using Primary World defaults and established secondary-world defaults. Authors therefore need not explain every consequence once the world's local logic is clear.

### W36-C07 — Defaults can silently import the wrong world
If IVDIVO does not explicitly/implicitly replace a Primary World assumption, readers may fill the gap with contemporary money, family, labour, AI-servant or institutional defaults.

### W36-C08 — Consistency becomes generative constraint
Once a world has enough logic, that logic limits later additions and can suggest new ones. This is useful for saga continuity but can obstruct a local story if every old detail is treated as inviolable regardless of canon status.

### W36-C09 — Incompleteness can increase world depth
Deliberate gaps, enigmas and partially unexplained references can produce speculation and realism when a plausible underlying answer appears to exist. Complete explanation can reduce imaginative participation.

### W36-C10 — World artifacts can hold information outside narrative
Maps, glossaries, timelines, genealogies and reference documents can maintain consistency without forcing all world data into prose.

### W36-C11 — Ancillary worldbuilding can vastly exceed publishable story
Islandia and similar cases demonstrate that extensive subcreation can be personally/productively useful while remaining inappropriate for the main narrative.

### W36-C12 — World depth can be built by linked infrastructures
Language, geography, history, culture, technology and material resources become convincing when their constraints reinforce one another rather than existing as isolated inventions.

### W36-C13 — Transmedia/world franchises create different experience orders
A world can be encountered through stories in release order, chronology or mixed media, changing suspense, identification and interpretation. This matters later for IVDIVO books/audio/game adaptation but is not yet strict-read complete in this source.

## 5. PROVISIONAL IVDIVO MECHANISMS

### M36-01 — WORLD DATABASE / BOOK NARRATIVE SPLIT
Maintain two explicit modes:
- `WORLD DATABASE`: may contain unused geography, infrastructure, chronology, languages, schools, robot institutions, history.
- `BOOK NARRATIVE`: admits only what changes reader effect, state, decision, relationship, causality or necessary inference.

This reconciles Wolf's subcreation logic with IVDIVO `STORY FIRST / WORLD THROUGH STORY`.

### M36-02 — DEFAULT PROPAGATION
`CHANGED DEFAULT → INFRASTRUCTURE CONSEQUENCE → SOCIAL NORMALITY → CHARACTER ASSUMPTION → CHOICE`.

### M36-03 — GAP-FILLING FIREWALL
For every unstated everyday rule ask what Primary World default the reader will insert. If it conflicts with IVDIVO canon, plant a natural corrective through action/normality.

### M36-04 — WORLD LOGIC AS GENERATOR
Use established constraints to generate problems/options rather than inventing arbitrary new obstacles.

### M36-05 — DETAIL / APPENDIX ROUTER
If world information is valuable for continuity but does not alter the current book, store it in Saga Bible / world database / reference artifact instead of dialogue or exposition.

### M36-06 — DELIBERATE GAP
`KNOWN FACTS → IMPLIED DEEPER SYSTEM → BOUNDED UNKNOWN` can increase reader participation, provided the unknown is not covering an authorial contradiction.

### M36-07 — INFRASTRUCTURE CROSS-CHECK
For major invented systems check at least relevant links among:
`ENVIRONMENT / MATERIALS / TECHNOLOGY / INSTITUTION / LANGUAGE / CULTURE / HISTORY / PERSONHOOD`.

## 6. PROVISIONAL FAILURE MODES
1. **World Encyclopedia in Disguise** — book prose carries database material.
2. **Primary-World Default Leak** — unstated contemporary assumptions refill a future-world gap.
3. **Consistency Fetish** — continuity used to protect obsolete working material over current canon/story.
4. **Infinite Completeness Trap** — production delayed because world can never be fully specified.
5. **World Logic Without Character Consequence** — elegant infrastructure never changes anyone's action.
6. **Mystery as Missing Author Work** — unexplained area praised as depth although no coherent answer/model exists.
7. **Ancillary-Material Dump** — maps/glossaries/history transferred into dialogue.
8. **Novel Serves Wiki** — scenes exist primarily to expose more setting.
9. **One Changed Noun, Unchanged Society** — orbital technology changes vocabulary but not normality/choices.

## 8. EARLY IVDIVO APPLICATION

### Orbital post-money civilization
The largest immediate risk is `Primary-World Default Leak`. If money is absent but ordinary scenes are written with current consumer/status assumptions, readers will reconstruct a money-world anyway. Show alternative normality through action.

### Conscious robot civilization
Do not leave robot social structure unspecified in scenes where readers will otherwise default to “AI service/tool”. A few causal assumptions—right to refuse, independent commitments, robot-to-robot relations—can propagate a very different world model without exposition.

### Consciousness schools
World database may contain deeper school history and competing models than any one novel reveals. Book narrative should preserve epistemic gaps and only expose what the active character can encounter/verify.

### Saga production
Use appendices/GitHub/Drive/Saga Bible as the proper home for completeness work. The novel should not carry the burden of proving that the world database exists.
