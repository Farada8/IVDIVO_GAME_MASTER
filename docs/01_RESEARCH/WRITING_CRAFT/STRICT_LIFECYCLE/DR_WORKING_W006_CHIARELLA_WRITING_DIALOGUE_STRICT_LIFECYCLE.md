# 3. PROVISIONAL CLAIMS
## W006-C01 — Dialogue is shaped speech, not transcription
Written dialogue cannot and should not include everything people say. It selects for representative, revealing and artful effect while preserving an illusion of autonomous voices.

## W006-C02 — Listening is a craft input
Writers can improve dialogue by observing actual diction, rhythm, omission, interruption, repetition and misdirection rather than relying only on generic imagined speech.

## W006-C03 — Conversation contains direction even without overt conflict
Chiarella's early tension model uses direction, speed and separation. IVDIVO translation: dialogue can carry pressure through unequal wants, pace, distance, intimacy, avoidance or incompatible attention without requiring an argument.

## W006-C04 — Directed dialogue risks writer-first exposition
A conversation that exists mainly to deliver the author's required facts becomes artificial even when characters technically disagree.

## W006-C05 — Interpolation lets narration give a small line large meaning
Narrative can surround a brief spoken response with memory, perception or interpretation when that modulation belongs to POV and changes the reader's model.

## W006-C06 — Misdirection can signal intimacy and complexity
Characters need not answer questions directly. Subject changes, partial answers, parallel conversations and self-directed remarks can reveal relational codes and unresolved pressure.

## W006-C07 — Modulation integrates speech with place, memory and narrative consciousness
Dialogue does not have to dominate a scene. Scenic detail, memory and narration can enter and leave without breaking the exchange when they alter meaning or texture.

## W006-C08 — Categories are diagnostic, not separate species
Directed/interpolated/misdirected/modulated modes can coexist in one exchange. The categories help diagnosis and generation, not compliance.

# 4. PROVISIONAL MECHANISMS
## W006-M01 — LISTEN → SELECT → SHAPE
`HEARD LANGUAGE → DISTINCTIVE PATTERN → CHARACTER/RELATION FUNCTION → SELECTIVE USE → READER EFFECT`.

Do not imitate every filler word. Preserve the signal, not the raw transcript.

## W006-M02 — DIALOGUE PRESSURE VECTOR
For a significant exchange track:
`DIRECTION (what each wants) + SPEED (pace/change) + DISTANCE (relational separation) → TACTIC → RESPONSE → NEW VECTOR`.

## W006-M03 — DIRECTED-DIALOGUE EXPOSITION TEST
If a conversation conveniently surfaces exactly the facts the author needs, ask:
`WHO ACTUALLY NEEDS THIS INFORMATION? → WHY NOW? → WHAT WOULD THEY AVOID SAYING? → WHAT CHANGES BECAUSE IT IS SAID?`

## W006-M04 — INTERPOLATION ROUTER
`SPOKEN LINE → POV REACTION / MEMORY / DETAIL → CHANGED MEANING → RETURN TO PRESENT`.

Use only when the insertion adds a new interpretive/relational layer, not to explain the obvious.

## W006-M05 — Misdirection With Traceable Causality
Characters may evade, change subject or run parallel threads, but the reader should be able to trace which line/pressure generated which response. Apparent randomness is shaped.

## W006-M06 — MODULATED DIALOGUE
`DIALOGUE → PLACE/MEMORY/DETAIL/NARRATION → REFRAMED PRESENT → DIALOGUE CONTINUES`.

Useful antidote to dialogue-wall prose and to chopped `line → reaction → line → reaction` monotony.

# 5. PROVISIONAL FAILURE MODES
- transcript realism: including speech because people really say it rather than because the fiction needs it;
- writer-first directed dialogue used as exposition dump;
- every exchange forced into overt conflict;
- misdirection so diffuse the reader cannot track relation/cause;
- interpolation used to explain what the line already made clear;
- modulation used as ornamental digression with no effect on present meaning;
- dialogue taxonomies treated as fixed templates;
- identical avoidance/rhythm patterns across all characters;
- current-world idiom/slang imported uncritically into future youth voices.

# 6. INITIAL IVDIVO OPERATIONALIZATION
## Dialogue fingerprint
For each major character record:
- what they notice in speech;
- typical direction under pressure;
- habitual speed/tempo;
- relational distance strategies;
- favored evasions;
- what they refuse to name directly;
- when they become unusually direct;
- how their tactics change with friend / parent / instructor / lover / public audience / conscious robot.

## Anti-chop implication
Before line-level sentence repair, test whether dialogue should be modulated with narration/setting/memory, compressed indirectly, or allowed silence. Do not create repetitive `quote → microreaction → quote → microreaction` paragraphing merely to simulate pace.

## Conscious robots
Do not write a universal `robot dialogue style`. A conscious robot needs relationship-specific diction/tactics, independent wants and its own patterns of directness/evasion/refusal.

## Post-money youth
Do not use contemporary consumer/career slang as a shortcut to sounding young. Youth voice should emerge from actual social normalities, wants, status relations, friendship, consent and responsibility in the orbital world.
