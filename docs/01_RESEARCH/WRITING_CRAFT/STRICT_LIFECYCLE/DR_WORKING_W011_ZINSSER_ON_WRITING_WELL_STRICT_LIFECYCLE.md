# 2. PROVISIONAL CLAIMS / MECHANISMS
## W011-C01 — There is no single valid personal writing process
Zinsser opens with two contradictory writers whose methods both work for them. Transform: workflow tools should be judged by whether they produce clear, strong, finished prose, not by conformity to one ritual.

## W011-C02 — Rewriting is a primary craft operation
Unlike Lamott’s generation protection, Zinsser emphasizes later deliberate revision. Useful synthesis: `GENERATE WITHOUT PARALYSIS → REWRITE WITHOUT SENTIMENTAL ATTACHMENT`.

## W011-C03 — Writer presence is part of reader value
Even in nonfiction, interest often comes from the writer’s particular attention, enthusiasm, selection and voice rather than topic alone. For fiction transform: worldbuilding becomes compelling through character-filtered attention rather than encyclopedia value.

## W011-M01 — FUNCTIONAL WORD TEST
For each sentence element ask: what reader-facing function does it perform? Remove/rebuild words that merely duplicate meaning, inflate status or obscure agency.

## W011-M02 — CLARITY BEFORE PRESTIGE
When a technical/institutional phrase is more impressive than precise, prefer the form that makes actor/action/relationship legible.

## W011-M03 — REWRITE LOOP
`draft → identify unnecessary/unclear structure → simplify without flattening meaning/voice → read in context → repeat`.

# 3. PROVISIONAL FAILURE MODES / FIREWALLS
1. **Simplicity = Shortness Confusion** — rejected. Clear complex sentences may be long.
2. **Delete Every Adverb / Passive Absolutism** — functional diagnostics, not bans.
3. **Nonfiction Rule Imported Unchanged into Fiction** — medium differences matter.
4. **Plain Language = Flat Voice** — clarity must preserve character/attitude/rhythm.
5. **Historical Usage/Market Advice as Current Authority** — date-sensitive claims require fresh verification if operationalized.
6. **Institutional Jargon Used as Worldbuilding** — fictional institutions should sound real, but reader comprehension and POV truth remain primary.

# 4. CROSS-SOURCE POSITION — PROVISIONAL
## Zinsser + Francine Prose
Strong complement: Prose asks writers to examine every word; Zinsser supplies an aggressive clarity/function filter.

## Zinsser + Lamott
Lamott protects discovery; Zinsser protects the reader from the excess that discovery produces. Combined router:
`DISCOVERY DRAFT → STRUCTURAL REVISION → CLARITY/CLUTTER PASS → RHYTHM/VOICE PASS`.

## Zinsser + Pushman
Agreement that paragraph/sentence form must serve intention; simplicity is not a formal length target.

# 5. IVDIVO OPERATIONALIZATION — PROVISIONAL
## Prose / “обрубки”
Do not translate simplicity into short sentences. First decide the complete thought/attention unit; then make its syntax as clear as that unit requires.

## Worldbuilding
Prefer concrete causal terms over inflated institutional nomenclature. If a cadet/robot/administrator naturally uses jargon, context must let the reader infer what action and consequence the jargon denotes.

## Post-money civilization
Avoid accidentally rebuilding monetary ideology through bureaucratic language. Terms like allocation, access, qualification, contribution, scheduling and priority must describe actual mechanisms rather than euphemisms for purchasing power.

## Conscious robots
Plain language must not erase different robot personhood. Clarity means legible intent/action, not homogenized speech.
