# 2. PROVISIONAL CLAIMS / MECHANISMS
## W010-C01 — Attention precedes craft polish
Lamott repeatedly treats close observation, memory and specific lived detail as raw material. Useful IVDIVO transform: world/character truth begins with what a particular consciousness notices, not with lore summary.

## W010-C02 — Production and publication are different reward systems
The desire to publish can distort the writing process. Historical publishing/agent claims are not current market authority; the transferable mechanism is to separate intrinsic production goals from external validation.

## W010-M01 — BIRD-BY-BIRD / SHORT ASSIGNMENT ROUTER
`large intimidating project → smallest coherent visible unit → finish that unit → reassess next unit`.
This is a generation/process tool, not permission to fragment final prose.

## W010-M02 — DISCOVERY DRAFT
`generate freely → discover live material / actual subject → structural selection → rewrite → line polish`.
A first draft may contain necessary waste that enables discovery.

## W010-M03 — WHAT IT IS BY LEARNING WHAT IT ISN'T
`attempt → mismatch → discard/redirect → sharper model of story/scene → next attempt`.
Failure during generation can supply information rather than merely indicate incompetence.

## W010-M04 — HOT SPOT EXTRACTION
After a loose draft, identify the passage/voice/image/relation with actual life; preserve that mechanism while cutting the scaffolding that was needed to reach it.

## W010-M05 — PERFECTIONISM FIREWALL
Do not demand final-draft compliance during discovery. Early gate overload can suppress surprise, character-specific behavior and prose life.

# 3. PROVISIONAL FAILURE MODES / FIREWALLS
1. **First-Draft Shame Loop** — treating rough generation as evidence the story is bad.
2. **Gate-at-Generation Overload** — applying all Writers' Room checks while each sentence is being born.
3. **Short Assignment = Short Final Unit Confusion** — process chunking mistaken for paragraph/sentence fragmentation.
4. **Publication Validation Trap** — external recognition becomes substitute for craft diagnosis.
5. **Autobiographical Truth = World Fact Confusion** — Lamott's personal/spiritual accounts are experience, not universal psychology/science.
6. **Trauma/Illness as Artistic Prerequisite** — categorically rejected; personal suffering in memoir does not create an IVDIVO depth rule.
7. **Historical Market Advice as Current Authority** — agents/publication economics require current external verification if used operationally.

# 5. IVDIVO OPERATIONALIZATION — PROVISIONAL
## Writers' Room
Separate passes:
`DISCOVERY/GENERATION → identify live mechanism → causal/scene diagnosis → POV/dialogue/paragraph pass → line edit`.
Do not ask a hundred specialist agents to approve each sentence while drafting.

## ONE MAIN STORY
Short assignments are local working windows inside one causal book engine. They do not justify disconnected vignette accumulation.

## Orbital Youth
Generate from small lived moments — a disagreement, commute, repair, meal, shared task, robot-human interaction, awkward responsibility — then test whether the moment changes the main causal/relationship chain. Ordinary life does not require artificial catastrophe.

## Post-money firewall
Lamott's own financial/publication biography belongs to her historical personal context. Do not transfer money anxiety into orbital youth motivation. Use nonfungible stakes already established by current IVDIVO canon.

## Conscious robots
Discovery drafting may reveal unexpected robot behavior; retain it if it is person-specific and causally credible. Do not force the robot back into preassigned Ally/Mentor/tool function.

## Prose / “обрубки”
`short assignment` describes the writer's work scope, NOT desired sentence/paragraph length. Final rhythm remains governed by reader effect and paragraph intent.
