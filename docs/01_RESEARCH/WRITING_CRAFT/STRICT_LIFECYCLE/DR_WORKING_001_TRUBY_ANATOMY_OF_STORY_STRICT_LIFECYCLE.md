# 4. PROVISIONAL CLAIMS / MECHANISMS FROM CONTIGUOUSLY READ MATERIAL

These remain working notes only. Full-source synthesis is forbidden until FULL READ closes.

### T1 — ORGANIC CAUSALITY OVER EXTERNAL ACT MARKERS
Strongest transferable principle remains:
`CAUSE → CHARACTER INTERPRETATION → ACTION → CONSEQUENCE → LEARNING → REVISED ACTION`.

### T2 — STORY = ACTION + LEARNING
Useful across plot, mystery and YA. New information must alter behavior or decision, not merely add lore.

### T3 — STORY SUBSYSTEMS MUST INTERACT
Character, plot, revelations, world, moral pressure, symbols, scenes and dialogue should not behave as independent layers pasted together.

### T4 — AUDIENCE THINKING + FEELING
Reader should both inhabit experience and build/revise models. Existing IVDIVO source-monitoring gates override Truby whenever generic withholding conflicts with POV fairness.

### T5 — PREMISE POSSIBILITY BEFORE COMMITMENT
Before expensive architecture/prose, deliberately generate alternatives from the same premise and identify the inherent promises and problems of each.

IVDIVO translation:
`IDEA → POSSIBILITIES → PROMISES → INHERENT PROBLEMS → CAUSAL TEST → CHOOSE`.

### T6 — DESIGNING PRINCIPLE AS ORGANIZING PROCESS
Useful distinction:
- **premise** = what concretely happens;
- **designing principle** = the deeper process/form by which this specific story unfolds.

IVDIVO gate: a designing principle is useful only if it changes scene selection, world use, information order or relationship structure. A poetic sentence with no operational consequence is decoration.

### T7 — SINGLE CAUSAL SPINE, NOT SINGLE CHARACTER MONOPOLY
Truby's `single cause-and-effect pathway` strongly converges with ONE MAIN STORY.

Correction for ensemble IVDIVO:
- one book needs one dominant causal engine;
- it does **not** require one protagonist to perform every important action;
- multiple POV/character lines may branch if consequences reconverge on the shared main problem.

### T8 — TRACKABLE EXTERNAL DESIRE VS DEVELOPMENTAL NEED
The distinction is operationally valuable. External objective should normally have an observable success/failure condition. Developmental needs such as autonomy, belonging or maturity are not substitutes for the objective.

Correction: a book may contain staged/renewed objectives if the causal engine remains one story; reaching an intermediate goal does not automatically mean two stories have been glued together.

### T9 — TRUE CHOICE AS COMPETING GOODS / COMPETING COSTS
Truby's rejection of fake positive-vs-obvious-negative choices is useful.

IVDIVO translation:
`VALUE A / BENEFIT A / COST A` versus `VALUE B / BENEFIT B / COST B`.

The choice need not be explicitly “moral,” but both options must remain credible enough that choosing reveals priorities.

### T10 — CHARACTER WEB BEFORE EQUAL-AIRTIME ENSEMBLE
Characters become sharper by comparison and relationship, not by isolated biographies.

IVDIVO correction:
- use relationship/value web;
- do not reduce people to archetype/story function;
- saga-level equality does not imply book-level equal POV;
- named conscious robots require independent personhood, not a function slot.

### T11 — OPPONENT AS INTELLIGENT COUNTERMODEL
Very strong convergence with Bell: opponent/pressure is more powerful when competent, partly right and capable of exposing the hero's weak model.

Correction:
- opponent does **not** have to want literally the same goal;
- systems, circumstances, allies and institutions can create meaningful resistance;
- conflict can come from incompatible obligations or methods rather than one prize.

### T12 — VALUE CLUSTERS WITH SHADOW SIDE
Useful mechanism: important values should have positive and potentially harmful expressions.

Example translation:
`responsibility → reliability / overcontrol`
`care → support / paternalism`
`autonomy → self-direction / refusal of needed coordination`.

This is more productive than assigning a generic “flaw.”

### T13 — OPPOSITION NETWORK, NOT HERO-CENTRIC QUEUE
Truby's four-corner opposition is useful as a diagnostic for social density.

IVDIVO translation:
major characters should have incompatible aims/values **with one another**, not merely take turns challenging the protagonist.

Do not force exactly four corners.

### T14 — THEME IS PROVED BY CONSEQUENCES
Strong principle: moral/theme argument works through action and results; dialogue should not carry what the causal structure has failed to demonstrate.

Production gate:
If deleting a thematic speech removes the book's theme, the structural argument is underbuilt.

### T15 — STRONG OPPONENT ARGUMENT MUST CONTAIN TRUTH
A serious opponent should be right about something consequential. Avoid straw-man ethical debates.

### T16 — SYSTEMIC ARGUMENT THROUGH EFFECTS
The satire/black-comedy sections provide a transferable mechanism even outside comedy:
`SYSTEM RULE → LOCALLY RATIONAL ACTION → AGGREGATE EFFECT → CONTRADICTION EXPOSED`.

Useful for institutions/algorithms in IVDIVO without requiring a villain.

### T17 — WORLD AS CAUSAL SOCIAL GEOGRAPHY
Worldbuilding earns page space when space, rules, infrastructure, technology or environment alter:
- options;
- relationships;
- status/access;
- risk;
- timing;
- movement;
- meaning.

This converges strongly with current Orbital Youth production rules.

### T18 — ARENA UNITY WITHOUT LOCATION MONOTONY
A book can range across many locations and still feel unified if they share a legible overarching arena/process. This is especially useful for an orbital city.

### T19 — VISUAL/SPATIAL OPPOSITIONS SHOULD GROW FROM HUMAN OPPOSITIONS
Do not choose spectacular settings first and then insert characters. Ask which real differences in values, bodies, roles and relationships the environment makes visible.

### T20 — MICRO-COSM / INSTITUTION AS COMPRESSION DEVICE
A city is too large to dramatize directly. A district, transit system, training center, household, sport league, workshop or public event can function as a social miniature through which the larger civilization becomes legible.

Correction: the microcosm must not be mistaken for the whole civilization.

# 5. PROVISIONAL FAILURE MODES

Existing:
- **ANTI-TEMPLATE BECOMES TEMPLATE**
- **UNIVERSAL GROWTH CLAIM**
- **WITHHOLDING OVERREACH**
- **SUBSYSTEM TOTALIZATION**
- **PREMISE FATALISM**
- **FORM HIERARCHY**

New from this pass:
- **ONE-DESIRE DOGMA** — treating any intermediate objective change as proof that the novel contains two stories.
- **MANDATORY MORAL FLAW** — forcing every protagonist to hurt others at the opening merely to satisfy the model.
- **MORAL SELF-REVELATION MONOCULTURE** — assuming every climax needs the hero to discover the proper way to live.
- **SAME-GOAL OPPONENT DOGMA** — inventing contrived competition for one prize when the real conflict is obligation/method/values.
- **CONSTANT-PRESSURE MONOCULTURE** — believing every scene must attack the hero's weakness; friendship, success, discovery, intimacy and competence also produce causal story movement.
- **FOUR-CORNER NUMEROLOGY** — treating exactly four oppositional positions as a law rather than a design aid.
- **ARCHETYPE FLATTENING** — story-function/archetype labels replacing independent human subjectivity.
- **THEME AS AUTHORIAL VERDICT** — predetermining which value system is “superior” instead of allowing ambiguity and reader judgment.
- **WORLD-AS-METAPHOR OVERREAD** — forcing every room, landscape and object to symbolically mirror character/theme.
- **ARENA CLAUSTROPHOBIA** — rejecting necessary expansion simply because a story crosses a physical boundary.
- **SETTING DICTIONARY** — importing fixed symbolic meanings of ocean/attic/city etc. instead of using culture/POV-specific meaning.
- **MICROCOSM TOTALIZATION** — treating one institution/district as a complete model of all orbital civilization.

# 6. EARLY CROSS-SOURCE NOTES

- **Brody** and Truby converge on macro clarity; Truby's causal/organic emphasis is the stronger antidote to beat-percentage retrofit.
- **Rosenfeld** operationalizes Truby's action/learning loop at scene scale and is more tolerant of partial success, contemplation and varied scene outcomes.
- **Card** is the necessary correction to Truby's function/archetype language: supporting characters must remain people with independent networks and motives.
- **Bell** converges strongly on intelligent opposition, but both require correction against constant pressure/stakes inflation.
- **Herman/Oatley** improve Truby's character-change model by centering reasons, plans, social cognition and reader simulation rather than mandatory moral flaw.
- **Zunshine** sharpens “audience puzzle” into explicit source-monitoring and prevents unfair withholding.
- **Le Guin/Clark** prevent Truby's structural intensity from leaking into sentence-level monotony; causality does not imply chopped syntax.

# 7. PROVISIONAL IVDIVO PRODUCTION GATES FROM THIS PASS

**T-G01 CAUSAL SPINE** — Can the book's dominant problem be expressed as one evolving cause-and-effect chain even with multiple POVs?

**T-G02 OBJECTIVE TEST** — What external result can the reader recognize as achieved/not achieved?

**T-G03 DEVELOPMENT IS NOT OBJECTIVE** — “Become independent / mature / belong” cannot by itself substitute for the book's operational goal.

**T-G04 DESIGNING-PRINCIPLE CONSEQUENCE** — Does the organizing principle change actual architecture, or is it only a clever sentence?

**T-G05 PREMISE PROMISE / PROBLEM** — Before prose, list what the premise promises and which hard story problems it inherently creates.

**T-G06 TRUE CHOICE** — At a major choice, are at least two options genuinely defensible and costly?

**T-G07 VALUE SHADOW** — For each major value, what is its useful form and its overextended/harmful form?

**T-G08 OPPOSITION NETWORK** — Do major characters meaningfully disagree with one another, not only with the lead?

**T-G09 NO STRAW PERSON** — Does the strongest opposing argument contain truth that survives the scene?

**T-G10 STRUCTURAL THEME PROOF** — Would the theme remain legible if explanatory dialogue were removed?

**T-G11 SYSTEM EFFECT** — When institutional/systemic critique is present, show locally rational decisions accumulating into a problematic aggregate effect.

**T-G12 WORLD CHANGES ACTION** — Does the setting/infrastructure materially alter what a character can do, know, risk, access or choose?

**T-G13 ARENA UNITY** — Do multiple locations still belong to one legible story arena/process?

**T-G14 MICRO-COSM LIMIT** — Is the chosen institution/district understood as a lens on civilization rather than civilization itself?

**T-G15 NO WORLD TOURISM** — Spectacle without causal or relational function is compress/delete material.
