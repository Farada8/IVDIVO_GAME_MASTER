# 2. SOURCE PASSPORT
## Strong at
- transitions between stable states and changed-rule environments;
- temporary story functions rather than only permanent character types;
- preparation/commitment/aftermath/return as distinct dramatic jobs;
- reader-facing promise/contract;
- polarity and reversals as engines of pressure;
- rhythm of tension/release and permission for quiet climaxes;
- a large repertoire of diagnostic questions for mythic/adventure-shaped stories.

## Weak / bounded
- many claims are Campbell/Jung-derived symbolic interpretations rather than established psychology;
- gender-essentialist anima/animus material is not accepted as universal;
- death/rebirth, sacrifice, wound, heroism, moral lesson and transcendence are frequently overgeneralized;
- chakra/vibration/ESP/telepathy/clairvoyance/pineal claims are not scientific evidence;
- film/screenwriting examples must not become novel-format rules;
- retrospective mapping can overfit successful works to the model.

# 3. CORE CLAIMS
1. Hero's Journey works best as a flexible map, not a mandatory beat sheet.
2. Archetypes are more useful as temporary functions/masks than permanent personality boxes.
3. A threshold matters when rules, options, obligations or error costs actually change.
4. Refusal can be internal, externalized, repeated or absent; willing heroes are legitimate.
5. Mentor/guardian/ally/shadow functions may migrate among characters and institutions.
6. Preparation before a hard test can change team roles, strategy, information and commitment.
7. High-pressure ordeal functions as a major test, but literal or psychological death is not required for IVDIVO.
8. Aftermath/reward needs space to convert events into changed relations, knowledge and responsibility.
9. Return should alter ordinary life; local closure is compatible with a continuing saga.
10. Audience attention is a contract: opening/genre/voice/world create promises that later pages must fairly satisfy or revise.
11. Polarity can generate pressure but may resolve through synthesis, bounded coexistence, negotiation or separation rather than destruction.
12. Tension needs contrast/release; maximum intensity everywhere deadens reader response.
13. Bodily reader response is useful diagnostic evidence, not objective proof of artistic truth.
14. Vogler's spiritual metaphors are symbolic craft frameworks, not IVDIVO ontology.

# 4. TRANSFERABLE MECHANISMS
## W009-M01 — BASELINE → DISTURBANCE
`ordinary/baseline state → durable call/disturbance → changed need for action`.

## W009-M02 — SPECIAL WORLD AS RULE CHANGE
`old rules/options/costs → threshold → materially changed rules/options/costs`.
A new district, role, institution, relationship or training environment qualifies only if behavior genuinely changes.

## W009-M03 — CONFLICTING CALLS
Multiple legitimate obligations can create richer commitment pressure than one obvious mission.

## W009-M04 — FUNCTION MIGRATION
`scene need → temporary mentor/guardian/herald/shadow/ally/trickster function → current carrier`.
Do not build a permanent character solely to fill each label.

## W009-M05 — COMPETENT THRESHOLD GUARDIAN
A block may protect real interests. Crossing can require readiness, negotiation, proof or changed strategy, not defeat of a villain.

## W009-M06 — COMMITMENT THRESHOLD
`possibility → risk acknowledgment/refusal → preparation/help → bounded commitment → changed options/obligations`.

## W009-M07 — NESTED RULE WORLDS
A book can contain several nested environments. Each earns space by changing action logic, not by changing scenery alone.

## W009-M08 — PRE-ORDEAL REORGANIZATION
`hard problem approaches → doubts/resources/roles surfaced → strategy redistributed → readiness changes`.
Use instead of generic briefing scenes.

## W009-M09 — COSTLY MODEL TEST
`high-pressure test → old strategy/model insufficient → costly choice → changed state/model`.
This replaces mandatory death/rebirth.

## W009-M10 — AFTERMATH / REWARD SPACE
`pressure/payoff → decompression → emotional/relationship/evidence integration → new agenda`.
Do not sprint mechanically from crisis to crisis.

## W009-M11 — RETURN / ELIXIR AS RESPONSIBILITY
`decisive local action → result → aftermath → new knowledge/relationship/responsibility → changed ordinary life`.

## W009-M12 — AUDIENCE ATTENTION CONTRACT
`opening/genre/voice/world promise → reader expectation → progressive fulfillment/revision → fair payoff`.

## W009-M13 — STATE RENEGOTIATION SCENE TEST
Vogler's “deal” is broadened for prose:
`entry state (relationship/knowledge/access/power/commitment/emotion) → interaction → materially changed exit state`.
Quiet scenes can qualify without power combat.

## W009-M14 — WISH → WILL
`desire/wish → attempted action → unexpected consequence → adaptation → stronger/weaker/changed commitment`.
No mandatory hidden “need.”

## W009-M15 — POLARITY AS COMPETING MODELS
`model A ↔ model B → pressure/evidence/consequence → reversal/exchange → synthesis / coexistence / separation / bounded defeat`.

## W009-M16 — TENSION / RELEASE RHYTHM
`pressure → partial release/ordinary life/humor/intimacy → renewed pressure`.
Contrast preserves sensitivity.

## W009-M17 — BODY RESPONSE AS DIAGNOSTIC
Collect reader signals — boredom, breath-holding, warmth, confusion, discomfort, excitement — then triangulate with causality/POV/prose evidence. Never treat sensation as final verdict.

## W009-M18 — EFFECT-DOMAIN ROUTER
Non-metaphysical abstraction of the chakra chapter:
`security/survival | creativity/problem solving | agency/power | attachment/care | expression/voice | insight/model change | awe/transcendence`.
These are possible dramatic/reader-effect domains, not literal energy centers.

## W009-M19 — QUIET CLIMAX
Climax function = strongest decisive local choice/resolution. Volume, death count and spectacle are optional.

## W009-M20 — ENDING PUNCTUATION
Choose intended closing feel — firm closure, energized continuation, unresolved question, open resonance — while still resolving the book's local main problem.

## W009-M21 — CATALYST / BRIDGE HERO
A principal character need not undergo maximal internal transformation; they may catalyze change in others/world, provided they retain stakes, agency and personhood.

## W009-M22 — NOBA / SECOND-ORDER CONSEQUENCE
`known action/result → not only expected effect, but also unexpected second-order effect → model/strategy revision`.
Useful for complex orbital systems where nobody is a villain.

# 5. FAILURE MODES / FIREWALLS
1. Hero's Journey Retrofit — forcing every IVDIVO novel into twelve stages.
2. Archetype = Person — reducing a full person/robot to Mentor, Ally, Shadow, etc.
3. Mandatory Refusal/Fear — assuming every hero must initially reject the call.
4. Mandatory Mentor — creating a dedicated wise guide when the function is distributed.
5. Threshold = Geography — treating a location change as transformation when rules/actions stay the same.
6. Life/Death Inflation — rejecting trust, consent, role, relationship, responsibility, reputation, time or unique opportunity as sufficient stakes.
7. Ordeal = Death/Rebirth — forcing literal/psychological death metaphors.
8. Mandatory Wound/Sacrifice/Healing — trauma is not a depth tax.
9. Clairvoyance-by-Suffering — mystical perception after ordeal is symbolic material, not world evidence.
10. Epiphany/Divinity Requirement — protagonist need not achieve spiritual revelation.
11. Villain Must Be Destroyed — competent countermodels may require negotiation/reform/separation/accountability.
12. Binary Polarity Overfit — not every problem has two clean sides.
13. Scene = Power Deal Overreach — knowledge, relation, emotion or commitment may change without dominance shift.
14. Three-Beats-per-Subplot Rule — useful reminder, not law.
15. Audience Wish Must Be Granted — reader desire may be productively denied if causally/thematically earned.
16. Poetic Justice Mandatory — endings may be tragic, mixed or unresolved in secondary dimensions.
17. Body Sensation = Objective Truth — reader physiology is one signal only.
18. Chakras/Vibrations/ESP = Science — categorically rejected as evidence.
19. Story Literally Alive/Conscious — productive metaphor only.
20. Writer as Wounded Healer — suffering is not prerequisite for artistic authority.
21. Cross-Cultural Universality Overclaim — recurring myths do not prove one simple universal psychology.
22. Gender-Essentialist Shapeshifter — anima/animus framework is not adopted.
23. Hero Knowledge Monopoly — ensemble evidence/interpretation/decision functions may be distributed.
24. Choppy Suspense Myth — journey pressure does not imply short-sentence quotas.

# 6. CROSS-SOURCE COMPARISON
## Vogler vs Truby / McKee / Brody
All provide strong diagnostic structures but become harmful when treated as mandatory geometry. IVDIVO keeps causal state change, commitment, consequence and payoff while rejecting fixed stage/page/act placement.

## Vogler + LaPlante / Prose / Pushman
LaPlante/Prose/Pushman are essential counterweights: organic discovery, variable scene forms, paragraph/sentence effect and non-formulaic character development prevent mythic architecture from flattening prose.

## Vogler + Card / Corbett / McKee Character
Temporary archetypal function is useful only after personhood. Character-specific wants, tactics, relationships and contradiction outrank role labels.

## Vogler + Zunshine / Herman
Mythic interpretation must remain separate from evidence status. A symbolic pattern is not causal or ontological proof.

## Vogler + Wolf
World thresholds are strongest when world rules genuinely alter behavior. World database remains larger than any one journey shown in a book.

# 7. IVDIVO OPERATIONALIZATION
## ONE MAIN STORY
Use journey vocabulary only as a transition/function diagnostic:
`baseline → disturbance → commitment → changed-rule environment → tests/model revision → costly decisive choice → aftermath → changed return`.
Delete, reorder or ignore stages freely. Never retrofit an accepted book merely to satisfy Vogler.

## Orbital Youth / post-money civilization
Calls/rewards/elixirs should arise from nonfungible stakes: trust, responsibility, relationship, consent, role, qualification, time, unique mission/experience, reputation, access to a specific person/place. Do not restore wages, rent, credits or consumer hierarchy.

A training center/new district/joint project is a true threshold only when actual rules/options/obligations change. A competent adult, procedure or conscious robot may guard that threshold for legitimate reasons.

## Conscious robots
Archetypal function is temporary. Named conscious robots require independent desire, relationships, consent, refusal and interests beyond helping the human lead. A robot can mentor in one scene and oppose, test, negotiate or need help in another without becoming a utility.

## Consciousness schools / dimensional knowledge
Vogler's Jung/chakra/vibration/telepathy material is a textbook example of why symbolic craft material must not establish ontology. Preserve:
`practitioner observation → reproducible effect → school interpretation → competing interpretation → possible ontological conclusion`.
Body/attention descriptions may be phenomenological evidence; they are not proof of ESP, souls or dimensional worlds.

## YA psychology
A refusal, threshold, ordeal or return may concern autonomy, trust, belonging and first responsibility without catastrophe. Do not invent trauma/death merely to make the journey “mythic.”

## Mystery / suspense
The journey can organize commitment and aftermath, but evidence must still obey provenance/fair-play rules. Mythic resonance cannot substitute for clue causality.

## Prose / rhythm / paragraphs
Vogler's catharsis/body-response sections reinforce reader-effect testing, not syntax quotas. Keep the established repair hierarchy:
`ONE MAIN STORY/causality → scene necessity → show/tell → POV → dialogue mode → paragraph intent → sentence rhythm → wording`.
After high pressure, a slower aftermath scene may be structurally necessary.

# 8. MANUSCRIPT VALIDATION
## LESSON ZERO Book One
No evidence from Vogler justifies reopening the development lock. The author himself repeatedly warns that the journey is not a cookbook. Re-outline only if a concrete current defect is independently established.

## Future Orbital Youth
Use the model to test whether transitions into roles/institutions/projects truly change rules and commitments; protect independent lives in the ensemble; permit quiet climaxes and aftermath; keep post-money and robot-personhood firewalls.

## Production-system implication
Do not run twelve-stage compliance during sentence generation. Generate/discover first, then use Vogler selectively in architecture/revision passes. A successful manuscript may legitimately omit or rearrange most named stages.

# 9. SYNTHESIS
Vogler is valuable to IVDIVO as a vocabulary for **transition, temporary story function, commitment, ordeal-as-test, aftermath, return and reader contract**. He is dangerous when mythic metaphor is mistaken for psychology, science, metaphysics or mandatory structure.

Canonical IVDIVO transform:
`FLEXIBLE TRANSITION MAP + PERSONHOOD + CAUSAL STATE CHANGE + FAIR EVIDENCE + READER CONTRACT`,
not
`TWELVE STAGES + ARCHETYPE BOXES + DEATH/REBIRTH + MYSTICAL UNIVERSALS`.
