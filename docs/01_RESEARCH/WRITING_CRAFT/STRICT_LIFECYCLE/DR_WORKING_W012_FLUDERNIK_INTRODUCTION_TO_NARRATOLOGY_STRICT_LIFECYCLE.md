# 3. PROVISIONAL CLAIMS / MECHANISMS
## W012-C01 — Story, narrative discourse and narrative act are different analytical layers
A story can be realized in different discourse orders/media; discourse decisions determine what reader sees when and from where.

IVDIVO transform:
`STORY FACTS / EVENTS → DISCOURSE ORDER → POV / ACCESS → READER MODEL`.
Do not confuse changing presentation with changing canon facts.

## W012-C02 — Fable/core, plot manifestation and discourse are separable
Different tellings can share a recognizable core while changing selection, emphasis, event sequence and perspective.

IVDIVO use: adaptation/reference mechanism extraction must import abstract function, not source expression/canon.

## W012-C03 — Narrative is selective by necessity
No story/history can reproduce an entire world. Selection reveals perspective.

Reinforces:
`WORLD DATABASE ≠ BOOK NARRATIVE` and `SAGA SCALE ≠ BOOK SCALE`.

## W012-C04 — Source-constrained reconstruction differs from invention
Historical explanation may interpret gaps but cannot responsibly contradict source evidence without reason.

IVDIVO transform for mystery/archives:
`TRACE/SOURCE → ALLOWED INFERENCE → GAP → HYPOTHESIS`, not `interesting theory → retrofit evidence`.

## W012-C05 — Medium changes discourse realization
The same underlying story may be realized differently in prose, film, drama or other media.

IVDIVO use: audio adaptation should preserve causal/story function while changing discourse tools rather than mechanically reading screenplay/prose conventions across media.

## W012-C06 — Event chains are common but not the only source of narrativity
Fludernik discusses approaches that treat experiential presence of a character in a world as minimally narrative even without a dense action chain.

IVDIVO firewall: this does NOT license filler. Quiet/ordinary scenes remain only if experience changes relationship, model, commitment, identity, evidence or later choice.

## W012-C07 — Narrative is temporally/spatially anchored experience
Characters exist somewhere/when; discourse can reorder this anchoring.

Operational question:
`WHERE/WHEN IS POV NOW? → WHAT PAST/FUTURE MATERIAL ENTERS? → WHO CONTROLS TRANSITION?`.

## W012-C08 — Narratological categories are descriptive tools, not quality scores
Narratology explains `what/how` narrative operates; interpretation/quality judgment requires additional reasoning.

IVDIVO gate:
`LABEL ≠ DIAGNOSIS ≠ REPAIR`.
Calling something `analepsis`, `internal focalization` or `iterative narration` does not prove it works.

## W012-C09 — Models/typologies are historically situated and often competing
Genette, Stanzel, Chatman, Prince and others carve variables differently.

IVDIVO transform: use the smallest model that resolves a production question; do not force prose to validate one terminology school.

# 4. EARLY FAILURE MODES / FIREWALLS
1. **Narratology = Writing Formula** — rejected. Descriptive taxonomy is not a beat sheet.
2. **Term Sophistication = Better Story** — rejected.
3. **Narrative = Mandatory Plot Density** — rejected; experiential/relational state change can be narrative.
4. **Quiet Narrative = Filler Permission** — rejected; deletion test still applies.
5. **Source Perspective = Source Falsehood** — perspective/selection does not automatically make testimony false.
6. **Historical Theory = Current Cognitive Science** — cognitive claims in a 2009 textbook require current primary-source verification before scientific use.
7. **Anthropomorphic Criterion Imported as Robot Rule** — rejected. IVDIVO conscious robots are persons in their own right, not meaningful only insofar as they imitate humans.
8. **Media Equivalence** — same story function does not imply same prose/audio/film presentation.
