# 1. Source role

Bell's strongest useful claim for IVDIVO is not that fiction needs decorative style. It is that narrative voice emerges from a **specific perceiving person**, filtered through authorial sensibility and then realized through sentence-level craft.

Bell's CAP formula is:

`CHARACTER background + language → filtered through AUTHOR → rendered by craft on PAGE = VOICE`.

For IVDIVO, the crucial correction is:

**VOICE IS NOT A COATING. VOICE IS CHARACTER-SPECIFIC SELECTION, INTERPRETATION AND EXPRESSION.**

A prose passage can be grammatically polished and still fail voice if any interchangeable IVDIVO character could have perceived and phrased it the same way.

---

# 2. CAP method — operational translation

Bell begins character voice from a small cluster of high-yield variables:

- dominant impression;
- physical presence;
- basic background;
- a life-altering event;
- yearning;
- free-form Voice Journal.

IVDIVO should not turn these into compulsory biography worksheets. The production value is the causal chain:

`LIVED HISTORY → ATTENTIONAL BIAS → DEFAULT INTERPRETATION → WORD CHOICE / IMAGE CHOICE / RHYTHM → VOICE`.

A character's history matters only when it changes what that person notices, assumes, avoids, jokes about, compares, names or refuses to name.

### B29-G01 — CHARACTER-FILTER GATE

For any focalized paragraph ask:

1. Why does **this** character notice these details?
2. Which available details do they ignore?
3. What do they infer too quickly?
4. What vocabulary is native to their work, class, age, hobby, family and current mood?
5. What would another POV character describe differently?

If answers are generic, the paragraph has weak voice even if the diction is attractive.

# 3. Voice Journal — useful as laboratory, not manuscript

Bell recommends free-form writing entirely in the character's voice until surprising, non-stereotyped language begins to appear.

IVDIVO adoption:

Create **VOICE LABS**, not exposition dossiers.

For a major character, write private non-canon exercises on subjects that matter to ordinary life:

- the worst teacher/manager they ever had;
- money they resent spending;
- a person they envy;
- an embarrassing attraction;
- a rule they secretly think is stupid;
- a smell that means home;
- a technology everyone loves that they hate;
- a lie they tell friends;
- what they would never post publicly;
- what they think another main character gets completely wrong.

Extract only recurrent language/attention mechanisms. **Do not paste the Voice Journal into the novel as backstory.**

### B29-G02 — VOICE-LAB TRANSFER GATE

A Voice Lab is successful only if it changes at least one production variable:

`DICTION | SYNTAX | HUMOR | METAPHOR SOURCE | ATTENTION | SILENCE | SOCIAL MASK | ARGUMENT STYLE`.

If it only produces biography, it is not yet voice work.

# 4. Attitude is not sarcasm

Bell's attitude chapter emphasizes that POV voice carries heat: a stance toward what is being experienced. He also shows that this can operate in close third person, not only first person.

Cross-source correction from Rasley/Storr/Prose:

Attitude is broader than snark. It can be:

- procedural fascination;
- embarrassment;
- defensive superiority;
- suspicion;
- tenderness;
- boredom;
- awe actively resisted;
- social anxiety;
- irritation at inefficiency;
- hunger for status;
- fear disguised as expertise.

Thus:

`WORLD EVENT × CHARACTER WORLDVIEW × CURRENT OBJECTIVE × MOOD = MOMENTARY ATTITUDE`.

### B29-G03 — ATTITUDE-SPECIFICITY GATE

Do not ask only `What does the narrator think?`

Ask:

`WHAT IS THEIR STANCE TOWARD THIS PARTICULAR THING RIGHT NOW, GIVEN WHAT THEY WANT?`

A stable personality adjective is insufficient. Attitude changes under pressure.

# 5. Description is characterization plus scene emotion

Bell demonstrates the same physical location rendered through different inner states. The observable environment remains available, but selection, comparison and evaluative language change.

This aligns strongly with Storr's claim that voice is partly what a character notices and with focalization work already extracted from Ribó/Fludernik.

Operational model:

`RAW ENVIRONMENT → POV SELECTION → CHARACTER ASSOCIATION → EMOTIONAL VALENCE → ACTION-RELEVANT DESCRIPTION`.

### B29-G04 — DESCRIPTION-FILTER GATE

Every descriptive block must do at least two of the following:

- orient space for coming action;
- expose POV character;
- establish social/class/status information;
- create or alter emotion;
- plant/pay off an object;
- reveal system/world function;
- create a decision constraint.

Generic camera inventory is compress/cut territory.

### B29-G05 — SHARED-LOCATION TEST

For ensemble books, periodically test the same room/route/event through two characters.

If both passages select the same details, use the same metaphors and arrive at the same social judgment, voices are collapsing.

---

# 6. Specific detail does not equal maximal description

Bell's discussion of minimalist prose demonstrates that strong voice can coexist with low rhetorical ornament. Specificity, sequencing and POV relevance can carry tension without flamboyant language.

Cross-check with Le Guin/Williams:

- short/plain is not automatically vivid;
- long/ornate is not automatically voiced;
- sentence length should match mental/emotional movement;
- description must remain legible and causal.

### B29-G06 — ORNAMENT NECESSITY GATE

Before keeping a striking metaphor/simile/image ask:

1. Could this character plausibly generate it?
2. Does it sharpen perception rather than merely advertise the author?
3. Does it fit current scene pressure?
4. Is a simpler image more character-native?

If the line is memorable but belongs to the writer rather than the character/book, cut or relocate it.

---

# 7. Voice varies by genre and situation without losing identity

Bell explicitly exercises voice variation by rewriting the same space through different genre expectations and POV modes.

IVDIVO implication:

A character voice is **not one permanent sentence texture**.

Ethan during:
- a school embarrassment;
- a procedural audit;
- attraction;
- a safety incident;
- an argument with Aaron;

should remain recognizably Ethan while cadence, vocabulary density, humor and attention change.

### B29-G07 — STABLE-CORE / VARIABLE-STATE GATE

Define voice as:

`STABLE CHARACTER CORE + CURRENT SOCIAL MASK + CURRENT OBJECTIVE + CURRENT EMOTION + SCENE GENRE PRESSURE`.

Reject the idea that “consistent voice” means identical rhythm in every scene.

# 8. YA: intimacy is an option, not a formula

Bell's YA examples note that first-person direct address can create strong reader intimacy. This is a **demonstrated option**, not a universal law of YA.

IVDIVO correction:

Do not add faux-confessional direct address, slang or snark merely to “sound young.” Youth voice should arise from:

- status sensitivity;
- friends and private loyalties;
- embarrassment;
- partial independence;
- school/work/money/logistics;
- attraction and comparison;
- adult power they cannot fully control;
- culture and technology they treat as ordinary;
- uncertainty about future identity.

### B29-G08 — AGE-AUTHENTICITY GATE

A teen voice fails if it sounds like:

- an adult policy brief;
- a franchise lore curator;
- a therapist explaining their own arc;
- generic online slang inserted by author;
- constant cleverness without embarrassment, boredom or bad judgment.

A youth character may be highly intelligent and still have age-specific social priorities.

# 9. Voice and dialogue are related but not identical

Bell's framework implies a distinction useful for IVDIVO:

`PRIVATE VOICE ≠ SPOKEN VOICE`.

Characters manage status. Their narration/internal perception may contain language they would never say aloud.

Use:

`PRIVATE INTERPRETATION → SOCIAL MASK → SPOKEN TACTIC → LEAK / CONTRADICTION`.

This joins Baxter's subtext mechanism.

### B29-G09 — MASK DIFFERENTIAL GATE

For major dialogue scenes identify:

- what the character privately calls the situation;
- what they are willing to call it aloud;
- why the difference exists;
- what leaks anyway.

If private and public language are identical in every high-pressure interaction, social life is too flat.

# 10. Anti-homogenization matrix for current LESSON ZERO cast

This is a **production test**, not new canon biography.

| Character | Primary attention bias to protect | Likely danger if homogenized |
|---|---|---|
| Ethan | scope, authority, procedure, status, responsibility | turns every theme into explicit managerial thesis |
| Maya | bodies, movement, immediate social/physical consequence | becomes generic ethical commentator |
| Samir | evidence boundaries, pattern, precision, claim ceiling | becomes exposition computer |
| Ollie | feasibility, failure modes, physical systems, workaround | becomes joke engineer / solution vending machine |
| Aoife | framing, recording, what a statement will become publicly | becomes neutral journalist narrator |

The rule is not to force these domains into every paragraph. It is to use them as **default gravitational fields** and let ordinary-life interests complicate them.

# 11. Book Two application — Chapters 11–15

## Ch11 Maya

Do not narrate burden distribution first as statistics. Maya should notice **repeated bodily/social accommodation** before the team can name the metric. Her voice advantage is not that she knows the correct policy; it is that she notices who moved, waited, yielded, doubled back, apologized or made themselves smaller.

## Ch12 Aoife

Her voice should distinguish:

`WHAT THE CAMERA RECORDED` from `WHAT THE EDIT MAKES IT MEAN`.

She should notice framing, sequence, omitted seconds, captions, audience interpretation and her own temptation to use a cleaner story.

## Ch13 Maya / Nico

Maya's private language can run ahead of what she is entitled to do. Her growth is shown when action stops before certainty does.

## Ch14 Samir

His voiced distinction between resemblance/correlation/support/claim should feel native, not authorial legalese. The human affected case must remain in memory so precision does not become bloodless.

## Ch15 Ethan

His strongest voice move is not a speech about epistemic humility. It is **procedural self-injury**: he corrects a claim that would help him win because the claim exceeds the evidence.

# 12. Failure modes

**REJECT:** everyone has the same polished dry wit.  
**REJECT:** profession/hobby vocabulary used every line until it becomes gimmick.  
**REJECT:** ornate metaphor treated as proof of voice.  
**REJECT:** YA = first person + slang + sarcasm.  
**REJECT:** Voice Journal pasted into manuscript.  
**REJECT:** character “attitude” that never changes with objective/mood/status.  
**REJECT:** scenic description not filtered through attention.  
**REJECT:** all intelligent teens sounding like adult committees.  
**REJECT:** narratorial insight greater than the character's earned knowledge simply because the sentence sounds good.

# 13. New production tests

### B29-G10 — SWAP TEST

Replace the POV character's name with another major character. If the paragraph still works with minimal edits, voice specificity is weak.

### B29-G11 — METAPHOR-SOURCE TEST

For every nontrivial comparison, identify its source domain: family, job, sport, class, media, place, body, hobby, technology, religion/culture, fear. Repeatedly using the author's favorite source domain across the cast is homogenization.

### B29-G12 — READ-ALOUD IDENTITY TEST

Read 200–400 words without character names. A production reader should be able to identify the POV by attention, syntax and attitude, not catchphrases alone.

### B29-G13 — VOICE-BEFORE-POLISH RULE

Do not line-edit an undifferentiated paragraph into prettier undifferentiated prose. First restore POV selection/attitude; then polish sentence music.

---

# 14. Bounded conclusion

Bell is high-value for converting the vague editorial demand “give it more voice” into manipulable variables: character history, yearning, free-form voice exploration, attitude, description, syntax and variation.

IVDIVO adopts the character-filter mechanism but rejects any shortcut that turns voice into mandatory snark, decorative metaphor or one immutable style per character.

Operational synthesis:

`WHO IS PERCEIVING? → WHAT DO THEY WANT NOW? → WHAT DO THEY NOTICE? → HOW DO THEY VALUE IT? → WHAT WOULD THEY NEVER SAY? → WHAT LANGUAGE/RHYTHM FITS THAT MIND NOW? → WHAT CHANGES UNDER PRESSURE?`

Only after those questions are answered should prose-level polish begin.
