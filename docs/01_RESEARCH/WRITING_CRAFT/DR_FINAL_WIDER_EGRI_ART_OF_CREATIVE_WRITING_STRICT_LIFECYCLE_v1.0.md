## 3. Claims retained after Red Team

### C1 — Character behavior must remain causally legible
A character can behave differently under different pressure without becoming arbitrary.

IVDIVO form:
`VALUE / PRIORITY + RELATIONSHIP + CURRENT COST + INFORMATION → TACTIC / CHOICE → CONSEQUENCE`.

### C2 — Contradiction is data, not automatically inconsistency
Opposite-looking behaviors can arise from one stable value under different circumstances, or from competing values.

Do not flatten character to one trait.

### C3 — Originality often comes from specific person-models
A familiar premise can feel fresh when character priorities, relationships, embodiment, social context and tactics are specific.

Reject Egri's stronger claim that characterization alone explains literary originality.

### C4 — Motivation requires repeated `why?`, but answers remain hypotheses
`ACTION → POSSIBLE MOTIVE MODEL → PRIOR HISTORY / RELATIONSHIP / CURRENT PRESSURE → ALTERNATIVE MODEL → TEXTUAL CONSEQUENCE`.

The author's private motive-model guides construction; it is not automatically reader evidence or world fact.

### C5 — Dramatic pressure should expose decision structure
Pressure is useful because it forces prioritization and reveals what a character protects, trades, refuses or redefines.

Reject: pressure reveals one immutable hidden “true self.”

### C6 — Sustained involvement needs a causal adhesive
Egri's “unbreakable bond” is useful when translated to:
`WHY DO THESE AGENTS REMAIN CAUSALLY INVOLVED?`

Valid adhesives include accepted responsibility, relationship, evidence ownership, shared mission, legal/physical constraint, consent agreement, consequences of prior action, or mutually dependent problem-solving.

Reject: forced captivity, hate or maximal conflict as defaults.

### C7 — Transitions require causal preparation
Large behavior/relationship changes need legible intermediate causes.

IVDIVO form:
`PRIOR STATE → PRESSURE / EVIDENCE → MODEL OR RELATION UPDATE → TACTIC CHANGE → NEW STATE`.

Reject Egri's demand that every emotional micro-step be explicitly dramatized. Summary, ellipsis and compressed inference remain valid.

### C8 — Character interrogation is a laboratory
Egri's questioning/interviewing method can expose assumptions, contradictions and missing history.

But:
`EXERCISE OUTPUT ≠ CANON`.

Any surprising answer must pass canon, character truth, causality, personhood and ONE MAIN STORY before promotion.

## 4. High-value mechanisms

### M1 — Competing Values Matrix
For each major character:
`VALUE A + VALUE B + RELATIONSHIP + CURRENT COST → PRIORITY NOW → TACTIC`.

This is stronger than “one dominant trait explains everything.”

### M2 — Contradiction Audit
When behavior seems inconsistent:
1. Did circumstances change?
2. Did relationship/status change?
3. Did evidence/knowledge change?
4. Did competing value become more expensive?
5. Is this a genuine character change?
6. Or is it author convenience?

### M3 — Adhesive / Walk-Away Audit
`IF CHARACTER COULD WALK AWAY, WHY DON'T THEY?`

Do not invent death/debt/kidnapping merely to trap them. Prefer accepted responsibility, relationship, evidence chain, prior choice and world constraint.

### M4 — Opposed-Model Design
Egri's orchestration is retained in non-binary form:
`MODEL / VALUE A ↔ MODEL / VALUE B → BOTH HAVE REAL BENEFITS / COSTS → TACTICS → CONSEQUENCES`.

The counterforce may be a competent ally, institution, robot, physical rule or competing ethical value, not a villain.

### M5 — Transition Ladder
Before a major reversal:
`OLD STATE → DISCONFIRMING EVENT → REASSESSMENT → NEW OPTION SET → CHOICE → NEW STATE`.

Use only the steps needed for reader causal continuity. Do not turn the ladder into a scene quota.

### M6 — Character-First Idea Generator
`TRAIT / VALUE CONTRADICTION → PRESSURE SITUATION → RELATIONSHIP → CHOICE → CONSEQUENCE → PREMISE CANDIDATE`.

This is an idea generator, not a canon generator.

### M7 — Premise as hypothesis
Egri treats premise as a governing proof. IVDIVO weakens this to:
`PREMISE / THEMATIC HYPOTHESIS → DRAFT EVIDENCE → COMPETING MODEL → CONSEQUENCES → READER INFERENCE`.

Story does not exist to prove a slogan.

### M8 — Reader Identification without sympathy shortcuts
Egri's reader-identification insight is retained, but “sure-fire” suffering devices are rejected.

Connection routes include:
`COMPETENCE / RELATIONSHIP / CURIOSITY / HUMOR / VALUES-IN-ACTION / RESPONSIBILITY / VULNERABILITY / MYSTERY / MORAL UNCERTAINTY`.

No mandatory illness, humiliation, orphanhood, abuse or victimhood.

### M9 — Surface Change vs Deep Continuity
Useful diagnostic:
`BEHAVIOR CHANGED — DID THE UNDERLYING VALUE CHANGE, OR ONLY THE TACTIC?`

Both are legitimate story outcomes.

### M10 — Consequence Before More Conflict
Egri overvalues rising conflict. IVDIVO retains rising consequence:
`ACTION → WORLD RESPONSE → CONSEQUENCE → NEW OPTION SPACE`.

Real success can progress the story:
`COMPETENT ACTION → SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

## 5. Rejected universals / failure modes

Do NOT adopt as laws:
- all people are fundamentally the same except in degree;
- one universal motive (“importance”) explains all action;
- physical appearance, heredity or family history deterministically predicts psychology;
- contradiction always reveals one fixed subterranean essence;
- every action has one discoverable motive;
- love = security as a universal definition;
- conflict is the only source of story life;
- two militant opposites are the ideal default cast;
- antagonist tolerance kills story;
- every strong story needs an “unbreakable” bond;
- every story should open in crisis;
- every significant emotional transition must be explicitly shown step-by-step;
- conflict must rise continuously without relief;
- every protagonist must be ruthless/relentless;
- every surrounding character must take a side;
- premise must be “proved” by predetermined character destiny;
- mid-century psychoanalytic claims as modern psychology.

Failure modes added:
- UNIVERSAL-MOTIVE REDUCTION
- IMPORTANCE-AS-EVERYTHING
- TRAIT DETERMINISM
- PHYSIOGNOMY / BODY→MOTIVE LEAP
- PRESSURE-REVEALS-TRUE-SELF DOGMA
- OPPOSITES-ONLY CAST
- MILITANT-CONFLICT MONOCULTURE
- FORCED ADHESIVE
- EVERY-SCENE ESCALATION
- TRANSITION OVEREXPLANATION
- PREMISE-PROOF PROPAGANDA
- SYMPATHY-BY-SUFFERING SHORTCUT
- CHARACTER-INTERVIEW BECOMES CANON
- TACTIC CHANGE MISREAD AS PERSONALITY TRANSPLANT
- REAL CHANGE FORBIDDEN BY “DEEP ESSENCE” THEORY

## 6. Cross-source comparison

### Egri × Card / Corbett / McKee Character
Egri's pressure/contradiction insight survives. His single-cause character essentialism does not. Character is modeled as a causal network with relationship-specific behavior.

### Egri × Herman / Zunshine
A coherent motive-story is not motive proof. Behavior generates hypotheses; source/context/evidence update confidence.

### Egri × Rosenfeld / Scofield / Swain
Changed state is broader than conflict/disaster. Success, consent, evidence, relationship and responsibility changes are full causal progression.

### Egri × Truby / Bell / Seger
Premise, orchestration and structural turns are useful lenses. They are not destiny or fixed page arithmetic.

### Egri × Vogler / Warner
A named framework must not force beats into a living draft. Use mechanism-level diagnosis only.

### Egri × LaPlante / Lamott
Improvisation/exploration belongs in discovery. Critical gates enter after live material exists.

### Egri × Williams/Bizup / Le Guin / Hodgins
Character causality does not justify choppy beat typography. Related perceptual/decision beats should form coherent paragraphs and varied syntax.

## 7. IVDIVO operationalization

### LESSON ZERO
No global rewrite authorized.
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Use Egri only when current evidence identifies:
- unexplained character reversal;
- generic ensemble behavior;
- weak causal adhesive;
- scene where characters can walk away without cost;
- one tactic repeated under changing pressure;
- thematic speech unsupported by action/consequence.

### Orbital Youth
Differentiate teenagers through:
`WHAT THEY VALUE → WHAT THEY NOTICE → WHAT COST THEY ACCEPT → WHAT TACTIC THEY TRY → HOW THEY ADAPT`.

No forced trauma or antagonist needed.
Post-money stakes remain trust, consent, time, responsibility, role/access, privacy, mastery, belonging, relationship and unique opportunity.

### ROOM 917
Elena↔Julian opposition/attraction can create relational pressure and access changes, but:
`RELATIONSHIP STATE ≠ EVIDENCE STATUS`.

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE ≠ CORROBORATION`.

### B07 — THE UNLISTED CITY
Human institutional “importance” or status cannot substitute for personhood evidence. After independent personhood threshold:
`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

### Conscious robots
Do not map Egri's human ego model onto nonhuman minds.
Personhood remains:
`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Consciousness-practice schools
Egri's psychological confidence has no ontological authority.
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 8. Anti-choppiness / prose law
Egri's transition logic is causal, not typographic.

Never convert:
`pressure → reaction → contradiction → choice`
into
`short line → short line → short line → short line` by default.

Standing router:
`BOOK ENGINE → CAUSAL FENCE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH TOPIC/READER-STATE → INNER/OUTER TEMPO → SENTENCE RHYTHM/CONTRAST → WORDING`.

`BEAT MAP ≠ SENTENCE BREAK`.
`CONFLICT / ACTION / EMOTION ≠ SHORT-SENTENCE DENSITY`.

## 9. Final production synthesis
Keep Egri's strongest question:
**Why would this particular person choose this particular tactic now, and what pressure makes the priority visible?**

Reject his strongest overreach:
**there is no single universal human motive, conflict ladder, immutable essence or militant-opposition formula that all IVDIVO stories must prove.**

Final IVDIVO engine:
`VALUES / RELATIONSHIPS / KNOWLEDGE / EMBODIMENT → PRESENT WANT → OPTION SET → TACTIC → WORLD / PARTNER RESPONSE → CONSEQUENCE → MODEL / RELATION UPDATE → NEXT CHOICE`.
