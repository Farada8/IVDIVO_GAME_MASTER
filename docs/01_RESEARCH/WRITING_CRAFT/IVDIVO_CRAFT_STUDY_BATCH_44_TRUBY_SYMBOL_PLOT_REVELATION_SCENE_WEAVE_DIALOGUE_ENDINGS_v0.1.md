# IVDIVO CRAFT STUDY — BATCH 44
## John Truby — Symbol · Plot · Revelation · Scene Weave · Dialogue · Endings

Date: 2026-08-17
Status: **SOURCE STRICT LIFECYCLE CLOSED**
Source: John Truby, *The Anatomy of Story*

This batch records the mechanisms extracted from the final continuous read segment, from the remaining `Story World` material through terminal book text.

## 1. Passageways: transition earns detail only when rules change

Truby's `passageway between worlds` is useful when movement itself prepares the reader for a materially different rule set.

IVDIVO translation:
`CURRENT RULE SET → TRANSITION EXPERIENCE → NEW PHYSICAL/SOCIAL/SENSORY RULE SET → BEHAVIOR CHANGE`.

Do **not** dramatize every commute or threshold. Once the reader knows the rule, routine repetition should compress unless the crossing has new relational, safety or informational consequences.

## 2. Technology is a relationship, not a catalogue

Truby treats tools as extensions of character capability and as signals of how systems exert power. The transferable mechanism is:

`TECHNOLOGY → WHAT HUMAN/ROBOT CAPABILITY IT AMPLIFIES → WHAT DEPENDENCY/ACCESS IT CREATES → HOW A PERSON USES OR REFUSES IT → CONSEQUENCE`.

For IVDIVO, high technology is ordinary world infrastructure. Its narrative value is not novelty but altered choice.

## 3. Symbol: recurrence must develop

Useful kernel:
`DETAIL / IMAGE / OBJECT / ACTION → RECURRENCE → CHANGED CONTEXT → CHANGED MEANING`.

This converges with Le Guin's developing repetition. A repeated symbol/tagline that means exactly the same thing each time is not deepening; it is repetition noise.

### Firewall
- no symbol dictionary;
- no requirement for one `symbol line`;
- no visible allegorical machinery unless the form genuinely wants it;
- conscious robots and nonhuman persons cannot be reduced to symbolic types.

## 4. Plot = action + information architecture

Truby's best late-book plot claim is that a plot is both what happens **and how information about what happened is made available**.

IVDIVO transformation:
`ACTION STATE + INFORMATION STATE` must both be tracked.

A scene can change the story because:
- someone acted;
- someone learned;
- evidence status changed;
- a source became less/more credible;
- a relationship changed what information can be accessed;
- the same fact acquired a new interpretation.

## 5. Organic plot requires event necessity, not event loudness

Transferable tests:
- Does the event grow from character/world conditions already present?
- Does it cause a changed state?
- If removed, what later event/choice stops making sense?
- Is its page weight proportionate to its function?

This is stronger than forcing every event to be a setback or escalation.

## 6. Journey-plot warning: repeated encounter ≠ development

Truby correctly diagnoses a common journey problem: new location + new opponent can produce episodic repetition if the hero's model/relationship/strategy does not change.

Orbital Youth gate:
A new ring, district, workshop, training center or robot community is not a story beat merely because it is new.

Require:
`NEW PLACE → NEW PRESSURE OR INFORMATION → STRATEGY/RELATIONSHIP/MODEL CHANGE`.

## 7. Revelation earns plot status only by changing behavior

Strong final mechanism:
`REVELATION → DECISION → CHANGED DESIRE / PLAN / MOTIVE / RELATIONSHIP / EVIDENCE STATUS`.

If a reveal simply makes lore more impressive, it is exposition.

### Correction to Truby
Do not require each reveal to become monotonically bigger or arrive faster. Logical order, reader fairness, contrast and emotional processing can require quiet or slower revelations.

## 8. Reversal reveal has a high failure rate

A final reversal can recontextualize the story, but Truby himself notes the risk that plot becomes a gimmick.

IVDIVO gate:
A twist is accepted only if:
1. retrospectively supported;
2. does not invalidate legitimate POV knowledge;
3. changes interpretation without making earlier causality fake;
4. does not substitute for the local climax/choice;
5. leaves character and relationship value after the puzzle is solved.

## 9. Storyteller/narrator: WHY THIS TELLING?

Truby's storyteller section converges strongly with Card and later POV work.

For any conspicuous storyteller/narrator ask:
- Who is telling?
- To whom?
- Why this story?
- Why now?
- What can they know?
- What do memory, bias and later knowledge change?

A narrator frame that only says `let me tell you what happened` is decoration.

## 10. Scene weave before prose repair

The scene weave is most useful as a structural diagnostic, not as an exhaustive blueprint religion.

IVDIVO scene-weave row:
`SCENE OWNER | PRIOR CONSEQUENCE | INTENTION | PRESSURE | INFORMATION CHANGE | RELATIONSHIP CHANGE | OUTCOME | NEXT INTENTION | PAYOFF`.

If several adjacent scenes have identical rows except for location, merge/compress/rebuild before line editing.

## 11. Crosscutting must create interaction, not just variety

Crosscutting strands should affect reader inference, timing, causal pressure or eventual collision. Alternating POV merely to distribute pages is not structural weaving.

## 12. Scene construction starts with position in development

A scene is clearer when its role in a longer relation/character/plot arc is known.

Gate:
**What is different after this scene that matters to a later scene?**

Do not force Truby's exact local checklist on every scene; quiet scenes can move emotional, epistemic or relational state without overt confrontation.

## 13. Dialogue: three useful layers, not three mandatory tracks

Truby's three-track dialogue distinction is useful:
1. immediate story/tactical dialogue;
2. value/moral interpretation;
3. recurring words/images/phrases.

IVDIVO correction:
- not every exchange needs all three;
- direct dialogue earns space when exact wording matters;
- values are better expressed through tactics/subtext than debate speeches;
- recurring phrase/tagline must develop or disappear.

## 14. Opening: prototype pressure, not encyclopedia

Truby's best opening examples establish:
- story-world pressure;
- character method;
- core relationship/opposition;
- tone;
- an early version of the larger process.

But the first line/scene does **not** need to encode the whole book.

## 15. Ending: local closure without false finality

Useful distinction among bad endings:
- premature: the central development/problem ends before the book does;
- arbitrary: the story simply stops;
- falsely closed: all desire/world complexity is artificially frozen.

IVDIVO final form:
`LOCAL PROBLEM RESOLVED → CONSEQUENCE / COST → RELATIONSHIP/WORLD STATE CHANGED → LIFE CONTINUES → OPTIONAL SAGA HOOK`.

This preserves complete books inside a long saga.

## 16. Never-ending story ≠ unresolved book

Reread value can come from:
- details that gain meaning later;
- minor/opponent character reinterpretation;
- symbolic recurrence;
- ambiguous but bounded moral implications;
- narrator/relationship recontextualization.

It does **not** require withholding resolution of the book's main local problem.

## 17. New production gates

- **T-G16 RULE-CHANGE PASSAGEWAY** — dramatize transition when rules/behavior materially change.
- **T-G17 TECHNOLOGY-RELATION TEST** — tech changes capability/dependency/choice, not just spectacle.
- **T-G18 DEVELOPING SYMBOL** — recurrence changes meaning.
- **T-G19 ACTION + INFORMATION STATE** — track both physical and epistemic change.
- **T-G20 REVEAL CHANGES ACTION** — lore-only reveal fails plot gate.
- **T-G21 REVEAL LOGIC BEFORE INTENSITY** — no mandatory bigger/faster ladder.
- **T-G22 TWIST RETROSPECTIVE SUPPORT** — reversal must survive reread.
- **T-G23 NARRATOR NECESSITY** — why this teller, this audience, this moment?
- **T-G24 SCENE-WEAVE DIFFERENTIATION** — adjacent scenes need distinct causal function.
- **T-G25 CROSSCUT INTERACTION** — alternating strands must change pressure/inference/collision.
- **T-G26 SCENE POSITION** — scene function located in larger arc.
- **T-G27 DIALOGUE EXACT-WORD VALUE** — dramatize wording only when wording changes state.
- **T-G28 MOTIF DEVELOPMENT** — repeated language/image needs evolution.
- **T-G29 OPENING PROTOTYPE** — opening demonstrates process/pressure without encyclopedia burden.
- **T-G30 LOCAL CLOSURE** — close book problem before saga hook.
- **T-G31 REREAD VALUE ≠ NONRESOLUTION** — texture/recontextualization must not sabotage closure.

## 18. Final cross-school synthesis

**Truby + Rosenfeld:** macro weave + scene recursion.

**Truby + Zunshine:** revelation architecture + source-monitoring/fairness.

**Truby + Chatman:** essential causal event versus discourse presentation.

**Truby + Card:** relational character web corrected by independent personhood and POV truth.

**Truby + Le Guin:** recurring symbol/motif must develop; repetition without changed meaning is dead weight.

**Truby + Bell:** opponent and plot pressure, corrected against compulsory escalation.

**Truby + IVDIVO canon:** use organic causal integration; reject template retrofit, money reintroduction, consciousness-transfer leakage and robot-as-archetype flattening.
