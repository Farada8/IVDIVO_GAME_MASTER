## Scope

This batch operationalizes strict-confirmed Section 20 and Section 23 plus explicitly provisional material from recovered-but-not-yet-continuous Sections 21, 22, 24, and 25 of Jack M. Bickham's *The 38 Most Common Fiction Writing Mistakes*.

No claim is made that the whole book is studied.

## 1. Research is an evidence problem, not a prestige problem

Bickham's useful warning is simple: analogous experience can produce the opposite of the real answer. For IVDIVO, the stronger form is:

`CLAIM → SOURCE → DOMAIN AUTHORITY → DATE/CONTEXT → OBSERVATION OR MEASUREMENT → INTERPRETATION → CONFIDENCE`

A confident expert character can still be wrong. An official document can still be wrong. Research changes confidence; it does not erase provenance.

### Gate B135-G01 — RESEARCH PROVENANCE
For any externally checkable technical, historical, medical, legal, institutional, or scientific claim that materially affects causality, record where it came from and what kind of source it is.

### Gate B135-G02 — ANALOGY IS NOT VERIFICATION
A plausible analogy may generate a hypothesis but cannot close factual verification.

### Gate B135-G03 — RESEARCH MAY GENERATE STORY, NOT CANON
A discovered real-world fact may suggest a stronger scene or plot mechanism. It enters canon only after compatibility, character, causality, and ONE MAIN STORY checks.

## 2. Observation and interpretation must remain separable

Bickham's observation exercises are useful only if we do not turn immediate human inference into fact.

`OBSERVED PARTICULAR → POV ATTENTION → INTERPRETATION → ALTERNATIVE INTERPRETATION → ACTION / TEST`

### Gate B135-G04 — TRACE BEFORE TRAIT
Write what the POV can observe before naming a moral, psychological, or ontological conclusion.

### Gate B135-G05 — PERSON MODEL IS PROVISIONAL
Face, posture, silence, speech pattern, robot behavior, or practitioner experience can update a model of a person; none alone proves motive.

## 3. The Alligator Test: complication must belong to the causal engine

Bickham's strongest mechanism in Section 23 is that a dramatic event is not automatically a useful complication. The famous unrelated alligator fails because it does not answer or transform the scene's actual question.

IVDIVO generalization:

`CURRENT OBJECTIVE / QUESTION → NEW EVENT → DOES IT CHANGE OBJECTIVE, EVIDENCE, RELATIONSHIP, AUTHORITY, COST, OR OPTION SPACE?`

If **no**, the event is spectacle, not progression.

### Gate B135-G06 — CAUSAL COMPLICATION
A complication must couple to the current causal engine.

### Gate B135-G07 — NO SPECTACLE SUBSTITUTION
Do not repair a weak middle by adding another accident, anomaly, villain, technology, secret, or attack unless it changes an existing causal line.

### Gate B135-G08 — OUTCOME NEED NOT BE NEGATIVE
A scene may end in failure, partial success, costly success, correct restraint, relationship change, evidence upgrade/downgrade, or genuine success that increases responsibility.

## 4. Scene question is a diagnostic lens, not a binary law

Bickham's yes/no scene question is useful for clarifying muddy material. It is too narrow as a universal production template.

Better IVDIVO questions:

- What state is different by the end?
- What did the POV want now?
- What resistance/support mattered?
- What changed in action, evidence, relationship, authority, responsibility, model, emotion, or future options?
- What does the next scene now have to deal with?

### Gate B135-G09 — CHANGED STATE OVER FORMULA
A scene earns its place through meaningful changed state and downstream dependency, not by satisfying a fixed conflict/disaster template.

## 5. Processing is part of causality

Recovered Section 24 material reinforces a useful function: after pressure, a character may need time to process what happened and form the next commitment.

IVDIVO router:

`OUTCOME → PROCESSING NEED? → MODEL/RELATION/EVIDENCE UPDATE → OPTION SET → DECISION / DELAY / REFUSAL → NEXT ACTION`

Rendering options:

- immediate processing;
- delayed processing;
- embedded processing within the next action;
- compressed summary;
- implied processing revealed by changed later behavior.

### Gate B135-G10 — PROCESSING MUST CHANGE SOMETHING
Introspection is causal when it changes model, relationship, evidence-status, commitment, strategy, or the next objective.

### Gate B135-G11 — NO PROCESSING CONFETTI
Do not break one continuous mental unit into a sequence of one-line emotion/thought/gesture fragments unless contrast truly requires it.

## 6. Summary and scene weight

Bickham's anti-summary rule is historically useful but too absolute. Cross-source comparison with Swain, LaPlante, Rosenfeld, Scofield, Lodge, Bell, and Prose supports a functional router:

`FULL SCENE / EMBEDDED SCENE / SCENE FRAGMENT / SUMMARY / INDIRECT / COMMENTARY`

### Gate B135-G12 — REAL-TIME WORDING MUST EARN READER TIME
Use full real-time rendering when exact words/actions alter consent, evidence, trust, authority, relationship, decision, or reader inference.

### Gate B135-G13 — COMPRESS PROCESS
Repeated procedure, travel, setup, known explanation, and intermediate time are candidates for summary/indirect mode.

## 7. Application to IVDIVO domains

### Orbital Youth
A technical complication should not be `new gadget breaks`. Better:

`existing rule/system works → teen acts competently → access/responsibility changes → previously hidden coupling becomes relevant → next decision becomes harder`.

### Conscious robots / nonhuman persons
A human observer's description is evidence of behavior, not proof of motive.

`ROBOT ACTION → CONTROL/CONSTRAINT PROVENANCE → OWN MODEL → CONSENT/REFUSAL → MOTIVE HYPOTHESES → RESPONSIBILITY STATUS`

### Consciousness schools
Research and vivid subjective description cannot collapse the epistemic ladder:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

### Mystery
Never beautify or rearrange factual evidence without preserving source, order, timestamp, dimensions, and evidence-status.

## 8. Cross-source synthesis

- **Swain:** causal stimulus/response and scene/sequel are useful diagnostics, not a prose metronome.
- **Rosenfeld:** intention and consequence can end in several kinds of result, not only disaster.
- **LaPlante:** scene and summary are both legitimate narrative modes; theory diagnoses story rather than commanding it.
- **Scofield:** embedded-scene architecture often solves process-heavy prose better than full dramatization.
- **Zunshine / le Carré:** source lineage and interpretation status remain essential even when research looks authoritative.
- **Herman:** coherent causal story is not identical to verified cause.
