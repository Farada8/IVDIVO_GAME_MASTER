## 1. THEME — QUESTION, NOT SERMON

Useful source mechanism:
- theme can be dramatized through protagonist choice, opposition, subplot, supporting characters, dialogue and recurring imagery;
- the opposing position should be represented strongly enough to create genuine drama;
- theme becomes emotionally legible through consequences, not just stated ideas.

IVDIVO transformation:

`THEMATIC QUESTION → COMPETING MODELS → CHOICES → CONSEQUENCES → PROVISIONAL ANSWER`

Production gate B65-G01 — THEME SURVIVES SPEECH REMOVAL  
If all explicit thematic dialogue is removed, the causal pattern of the book should still make the thematic conflict visible.

Production gate B65-G02 — COMPETENT COUNTERARGUMENT  
The opposing model must possess real benefits, evidence, affected stakeholders and intelligent defenders. No straw-man institution, adult, robot or rival.

Failure modes:
- character becomes a mouthpiece;
- every supporting character exists to represent one abstract facet;
- antagonist carries the `negative theme` only because the template expects it;
- leitmotif repeats without changing meaning.

## 2. CHARACTER CONNECTION IS MULTI-CHANNEL

Iglesias distinguishes recognition/empathy, fascination and mystery. IVDIVO expands this to:

`RECOGNITION / EMPATHY + FASCINATION + MYSTERY + COMPETENCE + RELATIONSHIP + MORAL/TACTICAL UNCERTAINTY`

No character needs every channel.

Production gate B65-G03 — CONNECTION ROUTER  
Before strengthening a character, specify which connection channel is currently weak. Do not default to injury, humiliation or tragic backstory.

Production gate B65-G04 — EMPATHY MANIPULATION AUDIT  
Flag any use of:
- child vulnerability;
- animal affection;
- disability;
- illness;
- undeserved humiliation;
- rejection;
- sudden sacrifice;
- extreme poverty/misfortune;
when the main function is simply to buy reader sympathy.

These elements may remain when they are causal, person-specific and independently necessary.

## 3. ACTION / INACTION UNDER PRESSURE

The strongest transferable character principle is not `trait list`, but behavior when a want meets pressure.

`WANT → PRESSURE → CHARACTER-SPECIFIC TACTIC → REACTION → TACTIC CHANGE / REFUSAL → CONSEQUENCE`

Production gate B65-G05 — SAME PRESSURE / DIFFERENT PEOPLE  
When two major characters face the same pressure, their first and second tactics should usually diverge in ways grounded in worldview, relationship and prior experience.

Production gate B65-G06 — INACTION COUNTS  
Refusal, restraint, silence, waiting or not using an available power can reveal character as strongly as visible action if the alternative is real and the cost is legible.

## 4. ANTICIPATION AS FUTURE MODELING

Iglesias is strongest when he treats goals, plans, warnings, promises, appointments, deadlines and dramatic irony as ways to make the reader model a possible future.

IVDIVO mechanism:

`KNOWN FUTURE POSSIBILITY → READER EXPECTATION → CURRENT ACTION ACQUIRES HOPE/WORRY/CURIOSITY → PAYOFF OR REVISION`

Production gate B65-G07 — FUTURE MODEL, NOT HOOK QUOTA  
A future-oriented fact is useful when it changes how the current scene is read. It does not require a cliffhanger or explicit question at every beat.

Production gate B65-G08 — PROMISE ACCOUNTING  
If the text strongly establishes an anticipated event, answer it, deliberately transform it, or explicitly close the branch. Avoid forgotten promises.

## 5. QUESTIONS AT MULTIPLE SCALES — USEFUL, NOT MANDATORY

The source proposes act/sequence/scene/beat questions. IVDIVO retains them only as diagnostics.

Useful:
- what is unresolved at book scale?
- what immediate uncertainty matters in this scene?
- what does the reader now expect or fear?

Rejected:
- every beat must create a new unanswered question;
- every chapter must end as a hook;
- calm competence or relational payoff is inferior because it closes uncertainty.

Production gate B65-G09 — QUESTION MONOCULTURE  
If every scene creates uncertainty but rarely delivers competence, intimacy, understanding, beauty, humor or resolution, reader fatigue is likely.

## 6. FAIR SURPRISE / RED HERRINGS

Useful distinction:
- surprise is strongest when the old evidence remains valid after the new interpretation;
- misdirection should guide the reader toward a plausible model, not falsify reality.

`TRUE PRIOR EVIDENCE → MODEL A → NEW EVIDENCE → MODEL B → RETROSPECTIVE SUPPORT`

Production gate B65-G10 — RED HERRING LEGITIMACY  
A red herring must be a true fact, honest observation or legitimately incomplete interpretation. Authorial fabrication designed solely to fool the reader fails.

Production gate B65-G11 — POV FAIRNESS  
`reader inferior position` cannot justify suppressing a fact the active POV naturally knows unless there is a credible narration/attention reason.

This cross-validates Zunshine/Herman source-provenance rules.

## 7. SETUP / PAYOFF AS CAUSAL MEMORY

Expand setup beyond props:

`OBJECT / SKILL / RULE / HABIT / RELATIONSHIP / INFORMATION / ENVIRONMENT / LANGUAGE`

Production gate B65-G12 — PAYOFF CHANGES SOMETHING  
A structural payoff should affect action, inference, relationship, access or outcome. A pure repeated image may still be stylistic resonance, but should not be counted as causal payoff.

Production gate B65-G13 — NO DEUS EX PAYOFF  
A solution-defining capability must be established early enough for the reader to understand its availability and limitations.

## 8. EMOTIONAL MODULATION

The same book that advocates tension also relies on relief, humor, victory, loss, separation/reunion and quiet anticipation. Therefore permanent maximum intensity is self-defeating.

`PRESSURE → RELEASE/COMPETENCE/INTIMACY/HUMOR → NEW INFORMATION OR RESPONSIBILITY → NEW PRESSURE`

Production gate B65-G14 — RELEASE HAS STORY VALUE  
A recovery scene can remain quiet, but should usually change relationship, interpretation, commitment, knowledge or readiness.

Production gate B65-G15 — NO YES/NO PING-PONG FORMULA  
Alternating victory/defeat is a possible rhythm, not an obligatory pattern. A genuine success can increase responsibility and make later choices harder.

## 9. STRUCTURE — KEEP FUNCTIONS, REJECT STATIONS

Iglesias presents a conventional screenplay chain:
opening → inciting event → point of no return → midpoint → progressive complications → darkest moment → recovery → final showdown → resolution.

IVDIVO decomposition:

- disturbance = durable state change;
- commitment = meaningful narrowing / accepted responsibility;
- midpoint = changed model, goal, method, relationship or evidence status;
- severe low point = optional, not compulsory despair;
- climax = decisive bounded action resolving the local engine;
- resolution = aftermath and changed state.

Production gate B65-G16 — NO PERCENTAGE RETROFIT  
Do not move events to satisfy screenplay timing.

Production gate B65-G17 — NO DARKEST-MOMENT RETROFIT  
Do not manufacture death, betrayal, collapse or despair because the structure supposedly requires it.

Production gate B65-G18 — CLIMAX SCALE FIREWALL  
The climax must be causally decisive, not necessarily physically largest. A consent decision, institutional hold, refusal, rescue protocol or truthful disclosure may be the real climax.

## 10. ENDING — LOCAL SATISFACTION BEFORE SAGA HOOK

Iglesias lists happy, tragic, bittersweet, twist and open endings. Treat these as repertoire only.

IVDIVO rule:

`LOCAL CORE PROBLEM RESOLVED OR DELIBERATELY BOUNDED → COST / AFTERMATH → RELATIONSHIP & KNOWLEDGE STATE UPDATED → OPTIONAL SAGA HOOK`

Production gate B65-G19 — TWIST IS NOT MARKET OBLIGATION  
A twist must deepen/reframe the causal story; never add it merely to create buzz.

Production gate B65-G20 — OPEN END ≠ UNFINISHED BOOK  
Ontology or long-series questions may remain open, but the book's promised local engine must reach a satisfying state.

## 11. DIRECT IVDIVO APPLICATION

### LESSON ZERO
No development-lock reopening. Use reader-effect analysis only if a concrete current-version defect is found. New theory alone is not evidence.

### ORBITAL YOUTH
`stakes rising` must mean increasing consequence in trust, responsibility, consent, relationship, reputation, unique role/opportunity, time or safety. It must not resurrect wages, rent, credits or consumer hierarchy.

### CONSCIOUS ROBOTS
Do not use petting-the-dog, helpless victimhood or secret-humanity tricks to purchase sympathy. Build attachment through autonomous want, relation-specific behavior, competence, vulnerability appropriate to embodiment, consent, refusal and consequence.

### CONSCIOUSNESS / DIMENSIONAL SCHOOLS
Mystery and emotional fascination do not upgrade school interpretation into ontology. Preserve:
`observation → reproducible practice effect → school interpretation → competing interpretation → possible world fact`.

### MYSTERY
Use anticipation and red herrings only inside the evidence contract. Track who knows what, source status and what future model the reader has been invited to build.

### STYLE / SYNTAX
Iglesias's reader-effect rhetoric must not become short-sentence density. Emotional effect chooses pace; pace chooses syntax. Quiet suspense can require longer sentences and expanded subjective time.
