# IVDIVO CRAFT STUDY — BATCH 194
## Jack M. Bickham — Scene & Structure
### Causal State · Scene/Sequel · Pacing · Hidden Story · Anti-Mechanical Firewall

**Status:** source strict-complete / manuscript-facing synthesis

## 1. Primary retained mechanism — changed state
Bickham's most useful contribution is causal bookkeeping, not mandatory disaster.

`PRIOR STATE → PRESENT WANT → PRESSURE / SUPPORT → TACTIC → OUTCOME → CHANGED STATE → PROCESSING / NEW STRATEGY → NEXT CAUSAL LINK`.

Every load-bearing scene should change one or more axes:
- physical/operational state,
- knowledge/evidence,
- relationship/trust,
- consent/boundary,
- authority/access,
- responsibility/obligation,
- strategy/model,
- emotional commitment,
- future option space.

If none changes in a downstream-relevant way, test `SUMMARY / MERGE / DELETE / REBUILD` before line editing.

## 2. Outcome Direction Audit
For each major scene ending record:
- **scope** — how much of the book it affects,
- **immediacy** — when consequence becomes actionable,
- **finality** — how many options it closes,
- **direction** — what new causal vector it creates.

A vivid scene can be wrong if its outcome sends the book onto an unintended branch.

## 3. Scene / Sequel — retain the function, reject the metronome
Useful diagnostic modes:
- **ATTEMPT / ACTION** — exact behavior and wording matter now.
- **PROCESSING** — meaning, emotion, evidence, relationships or options must be reassessed.
- **HYBRID** — processing is embedded inside action.
- **SUMMARY / INDIRECT** — routine or repeated process is compressed.

Processing may be immediate, delayed, embedded, summarized, or inferred from later behavior.

Reject:
`scene → sequel → scene → sequel` as compulsory visible architecture.

## 4. Pacing = reader-time allocation
To accelerate:
- enter later,
- omit routine action,
- compress repeated procedure,
- reduce processing when the next action is obvious,
- narrow time/option windows only when causally earned.

To slow:
- expand consequential processing,
- extend subjective time around a load-bearing moment,
- give the character room to reconsider evidence/relationships/options,
- allow real aftermath.

Therefore:
`PACING ≠ SHORT-SENTENCE DENSITY`.

## 5. Hidden Story Ledger
For every important offstage action:
`ACTOR → WANT → DECISION → ACTION → TIME/PLACE → TRACE CREATED → WHO CAN ACCESS TRACE → DISCLOSURE ORDER → PAYOFF`.

Use especially for:
- mystery,
- institutional decisions,
- conspiracies without cartoon villains,
- distributed systems,
- multi-POV causality.

Hidden-story timing must remain physically possible.

## 6. Scene-entry and scene-exit gates
### Admission
`WHY REAL TIME?`
Exact sequencing earns full scene when it changes clue status, consent, trust, authority, responsibility, relationship terms or decision ownership.

### Exit
Do not demand disaster.
Require:
`OUTCOME → CHANGED STATE → READ-ON / DOWNSTREAM VALUE`.

Valid outcomes:
- failure,
- partial success,
- costly success,
- real success,
- correct non-action,
- evidence turn,
- relationship turn,
- new responsibility,
- narrowed option set.

## 7. Success Escalation
Protect:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

This is particularly important in YA. Competence does not need to be punished to create drama.

## 8. POV stability without POV monoculture
Useful:
- do not accidentally reveal another mind inside close POV;
- maintain clear knowledge/access provenance.

Reject:
- universal one-POV dominance percentages;
- POV switching solely to provide equal ensemble screen time.

Switch only if the new mind buys unique:
- evidence,
- action,
- lived consequence,
- relationship pressure,
- countermodel,
- decision.

## 9. Inadvertent Promise / Red-Herring Audit
If discourse strongly emphasizes a future threat, clue or possibility, reader expectation is created.

Before keeping it ask:
`IS THIS LIVED DETAIL OR A LOAD-BEARING PROMISE?`

If load-bearing, later either pay it, reinterpret it fairly, or reduce its emphasis.

## 10. Anti-choppiness integration
Bickham's causal units are not typographic units.

`BEAT MAP ≠ SENTENCE BREAK`.
`STIMULUS / PROCESSING / RESPONSE ≠ THREE ONE-LINE PARAGRAPHS`.

Repair order:
`SCENE NECESSITY → MODE → POV/EVIDENCE → PARAGRAPH JOB → READER-STATE CONTINUITY → SENTENCE CONTRAST → WORDING`.

## 11. Red Team — rejected universal claims
Reject as laws:
- every scene must end in disaster,
- every scene must contain overt conflict,
- summary is inherently inferior,
- every stimulus must receive immediate external response,
- every novel needs a dominant POV quota,
- rising action means monotonically worsening trouble,
- every chapter should end on a disaster,
- ticking clocks are generic suspense medicine,
- the hero must never relax,
- protagonist-villain framing is universal.

## 12. Cross-source synthesis
- **Swain:** causal diagnostic foundation.
- **Scofield/Rosenfeld/LaPlante:** quiet causal change and scene-mode flexibility.
- **Genette/Chatman:** order/duration/frequency and discourse before syntax.
- **Bell/Seger/Hodgins:** macro diagnosis before line edit; re-imagine scene when purpose/staging is wrong.
- **Ephron/Zunshine/le Carré:** clue provenance/source lineage/proof ceiling.
- **Le Guin/Prose/Williams-Bizup/Clark:** sentence-length variation by function; anti-choppy paragraph continuity.
