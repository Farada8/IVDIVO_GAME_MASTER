## 6. New production gates

### A. Action-to-Event Summation

Before line edit, complete:

`Because these actions occurred, ______ changed.`

Valid changed-state families:

- physical / operational;
- knowledge / evidence;
- relationship / trust;
- consent / boundary;
- authority / access;
- responsibility / obligation;
- strategy / causal model;
- emotional commitment;
- future option space.

If no consequential state can fill the blank, test:

`SUMMARY / MERGE / DELETE / REBUILD`.

### B. Quiet Event Legitimacy

`QUIET ≠ STATIC`.

A quiet scene can be structurally major when it changes trust, consent, interpretation of evidence, relationship terms, private commitment, hypothesis, authority legitimacy or available next action.

### C. Event / Meaning Separation

Do not collapse:

`WHAT HAPPENED`

into

`WHAT POV THINKS IT MEANS`.

Mystery / SF model:

`WORLD FACT → OBSERVED ACTION/TRACE → SCENE EVENT → POV INTERPRETATION → ALTERNATIVE MODEL → EVIDENCE UPDATE → ACTION`.

### D. Consequence Harvest

`SCENE OUTCOME → FIRST-ORDER CONSEQUENCE → SECOND-ORDER CONSEQUENCE → LATER PAYOFF`.

Before adding another anomaly, attack, witness, technology, secret or subplot, ask:

`What already happened that has not yet been allowed to cause its natural downstream effects?`

This reinforces ONE MAIN STORY and blocks `NEW EVENT ADDICTION`.

## 8. Anti-choppy prose integration

Pipeline strengthened to:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT → NARRATIVE MODE → EVENT TARGET → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Do not render event causality as:

`action. reaction. gesture. thought. conclusion.`

If several micro-actions serve one event and one perceptual/decision unit, preserve coherent paragraph/sentence movement unless a deliberate break creates a specific reader effect.
