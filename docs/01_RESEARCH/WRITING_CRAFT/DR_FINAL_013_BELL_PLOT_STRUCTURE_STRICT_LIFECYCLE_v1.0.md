## CORE CLAIMS — ACCEPT / TRANSFORM / REJECT

### ACCEPT / TRANSFORM
1. A story needs a trackable causal center.
   IVDIVO transform: `ONE DOMINANT CAUSAL ENGINE + DISTRIBUTED CHARACTER OBJECTIVES + MEANINGFUL RESISTANCE + EARNED LOCAL CLOSURE`.

2. A durable structural transition changes what the protagonist can now do or avoid.
   IVDIVO transform: `DISTURBANCE -> OPTIONS STILL OPEN -> COMMITMENT TRANSITION -> NEW OBLIGATIONS/OPTIONS -> SUSTAINED MAIN ENGINE`.

3. Broad generation should precede strict selection.
   IVDIVO: `SEED -> MATERIAL VARIANTS -> CANON/PERSONHOOD/CHARACTER/CAUSALITY/READER-EFFECT VALIDATION -> KEEP/BANK/DISCARD`.

4. Openings create a reader contract.
   IVDIVO: `ATTENTION -> ORIENTATION -> PERSON/SUBJECT BOND -> STORY PROMISE -> FORWARD PRESSURE`.

5. Middles need changing pressure, not repeated incidents.
   IVDIVO: `WANT/RESPONSIBILITY -> RESISTANCE -> REACTION -> STRATEGY/MODEL CHANGE -> CONSEQUENCE -> NEW PRESSURE`.

6. Endings should resolve the local engine and create resonance.
   IVDIVO: `DOMINANT BOOK QUESTION -> DECISIVE ACTION/CHOICE -> LOCAL OUTCOME -> COST -> AFTERMATH -> CHANGED STATE -> OPTIONAL SAGA HOOK`.

7. Scene function precedes prose polish.
   IVDIVO scene router: `PRIOR CONSEQUENCE -> OWNER -> PRESENT WANT -> MODE -> PRESSURE/ATTENTION -> ACTION/KNOWLEDGE/RELATIONSHIP CHANGE -> OUTCOME -> NEXT CAUSAL LINK`.

8. Complex structure is justified by convergence, not quantity of strands.
   IVDIVO: `LOCAL ACTION -> EFFECT ON ANOTHER STRAND/MAIN ENGINE -> NEW OPTION/CONSTRAINT -> PAYOFF`.

9. Outlines are tools, not canon.
   IVDIVO: `PLAN = HYPOTHESIS`; live material may force re-planning after canon/causality/personhood validation.

10. Revision must move macro-to-micro.
   IVDIVO: `BOOK ENGINE -> STRUCTURE -> CHARACTER/RELATIONSHIPS -> SCENES -> POV/EVIDENCE -> DIALOGUE -> PARAGRAPH/RHYTHM -> WORDING`.

### REJECT AS UNIVERSAL LAW
- Mandatory three-act percentages.
- Mandatory physical/psychological/professional death stakes.
- Mandatory stronger villain/opponent.
- Mandatory negative scene outcomes.
- Mandatory action-first opening.
- Mandatory transformation arc.
- Mandatory sacrifice, final battle, twist or cliffhanger.
- `Show, don't tell` as an absolute law.
- Commercial-market assumptions as timeless craft truth.

## MECHANISMS

### M01 — LOCK, transformed
Bell: Lead / Objective / Confrontation / Knockout.
IVDIVO: `FOCAL AGENT(S) / TRACKABLE OBJECTIVE / MEANINGFUL RESISTANCE / EARNED LOCAL CLOSURE`.
Use: diagnose a book that has worldbuilding but no main engine.
Limit: ensemble fiction can distribute ownership; resistance can be institutional, relational, epistemic, physical or self-created.

### M02 — Commitment Transition
A real turn changes available actions and obligations. New location or technology alone is not a turn.
Gate: `WHAT CAN THE CHARACTER NOW NO LONGER IGNORE / UNDO / LEAVE WITHOUT COST?`

### M03 — Material Variant Tournament
Generate materially distinct alternatives before selecting a major turn.
Material variation changes at least one: decision owner, want, evidence, relationship pressure, world constraint, tactic, price, end-state.

### M04 — Opening Mode Router
Valid modes include ACTION, VOICE/ATTITUDE, RELATIONSHIP, MYSTERY/EVIDENCE, FRAME, PROLOGUE/TEASER, ORDINARY-LIFE DISTURBANCE.
No catastrophe requirement.

### M05 — Adhesive as Causal Involvement
Replace coercive Bell adhesive with: accepted responsibility, promise, consent, evidence-chain ownership, bounded authority, relationship, consequences of prior action, physical rule of world.

### M06 — ARM, broadened
Bell: Action -> Reaction -> More Action.
IVDIVO: `ACTION -> WORLD/PERSON RESPONSE -> EMOTIONAL/RELATIONAL/EPISTEMIC PROCESSING -> NEW STRATEGY -> NEXT ACTION`.

### M07 — Ending Multi-Axis Audit
Track separately: objective, relationship, personhood/ethics, evidence/knowledge, authority/role, cost, future option-space.
A book may close locally while global ontology remains unknown.

### M08 — Scene Mode Router
ACTION / REACTION / SETUP / DEEPENING / SUMMARY-INDIRECT / HYBRID.
Use function, not labels, to choose reader time.

### M09 — Strand Convergence Test
Co-presence or briefing is not convergence.
A strand converges only when it changes another strand's actions, knowledge, authority, relationship, evidence-status or options.

### M10 — Behavioral Arc Verification
Narrator saying a character changed is insufficient.
Require behavior/choice under comparable pressure that demonstrates a changed or tested strategy.
Transformation remains optional.

### M11 — Adaptive Planning
`GENERATE -> ORGANIZE -> DRAFT -> OBSERVE LIVE MATERIAL -> REPLAN -> VALIDATE`.
Outline is a working model.

### M12 — Macro-Before-Polish Revision
Diagnose story before paragraphs; diagnose paragraphs before words.
Protects against cosmetic repairs to structural problems.

### M13 — Plot Pattern Repertoire
Quest, revenge, love, change, adventure, chase, one-against, one-apart, power, allegory are option-generators, not templates.

### M14 — Diagnose Before Surgery
`OBSERVED READER EFFECT -> DEFECT LEVEL -> MINIMUM CORRECT REPAIR -> RETEST`.
Distinguish story defect from writer fatigue.

### M15 — Flashback Present-Consequence Test
Full flashback only when the exact past scene changes present understanding, relationship, evidence, choice or strategy. Otherwise use back-flash/summary.

### M16 — Tangent Causal Test
`NEW LIVE MATERIAL -> CHARACTER TRUTH -> CANON -> ONE MAIN STORY -> DOWNSTREAM CONSEQUENCE -> KEEP/REPLAN/BANK/DISCARD`.

### M17 — Show/Tell Functional Routing
Bell strongly favors showing, but his examples still reveal the useful core: abstract labels are weak when exact action/gesture carries character meaning.
IVDIVO correction from LaPlante/Prose/Lodge/Rosenfeld: choose scene, narration, indirect dialogue or summary according to reader-time value and function.

### M18 — Delayed Answer / Cutaway
Bell's soap-opera device can sustain curiosity, but each delay incurs debt.
Gate: withholding must change anticipation, evidence or relationship; do not indefinitely postpone the book's promised local answer.

### M19 — Plot Journal as Generator, Not Canon
Free-form questions, reversals and surprises generate candidates. Every candidate must subsequently pass canon, personhood, causality and proof-ceiling gates.

### M20 — Deliberate Practice Loop
Bell's plotting drill is valuable as craft training: read for reader effect -> scene-map -> compare mechanisms -> revisit rapidly -> infer patterns.
IVDIVO addition: extract abstract mechanisms, not plot content; prevent imitation contamination.

### M21 — Appendix Checklist as Diagnostic, Not Constitution
Use checklists to expose missing functions; reject their fixed structural ideology when current story evidence supports another form.

### M22 — Back-Cover Copy Stress Test
Useful internal diagnostic:
`WHO / PRESENT STATE -> DURABLE DISTURBANCE -> MAIN PRESSURE -> CENTRAL QUESTION -> EXPERIENCE PROMISE`.
Marketing template is not story canon.

## CROSS-SOURCE COMPARISON

### Bell vs Truby
Convergence: causal spine, alternatives, opposition, revelation/decision linkage.
Difference: Bell's LOCK/three-act framing and Truby's 22 steps are both too rigid if treated as mandatory.
IVDIVO: retain causal functions, discard beat-count authority.

### Bell vs McKee Story
Convergence: structure before dialogue polish, progressive pressure, decisive ending.
Difference: both overstate death/high-stakes paradigms.
IVDIVO: meaningful nonfungible cost is enough when it changes character choice and reader concern.

### Bell vs Rosenfeld
Convergence: scene intention and consequence.
Correction: Rosenfeld better accommodates support, partial success, contemplation and changing intention; Bell's negative-outcome bias is rejected.

### Bell vs LaPlante / Francine Prose / Lodge
Key correction: Bell's show/tell hierarchy is too absolute. Fiction gains power from controlled scene, summary, narration, indirectness, long/short syntax and variable distance.
IVDIVO uses FUNCTIONAL MODE ROUTING, not `show always`.

### Bell vs Zunshine / Herman
Bell's mystery-retention tools manage curiosity; Zunshine/Herman more rigorously separate evidence, source, interpretation, motive and world fact.
IVDIVO mystery therefore requires provenance and proof ceiling, not just delayed answers.

### Bell vs Card / Corbett
Bell's plot functions can tempt plot-puppet construction.
Card/Corbett restore independent personhood, relationship-specific behavior and multi-cause motive.

### Bell vs Wolf
Plot journal/ideas must not silently become world canon. Wolf's provenance model governs authority and supersession.

## IVDIVO OPERATIONALIZATION

### ONE MAIN STORY
One dominant causal engine does not require one POV or one protagonist. Every major strand must causally alter the central engine and earn a payoff.

### POST-MONEY FIREWALL
Bell's job/career/money examples are historical/cultural examples only. Translate functions into actual IVDIVO stakes: responsibility, access, trust, consent, time, relationships, reputation, unique mission/experience, qualification, evidence integrity, safety. Do not recreate salary/rent/credits.

### CONSCIOUS ROBOTS / NONHUMAN PERSONS
A conscious robot/nonhuman cannot be only opposition, helper, prize or deepening complication. Require independent want, relationships, evidence/model, consent/refusal and at least one causally indispensable choice when relevant.

### CONSCIOUSNESS SCHOOLS / METAPHYSICS
Bell's fictional mediums, mythic references or speculative conventions are not evidence for IVDIVO ontology.
Maintain: `PRACTITIONER OBSERVATION -> REPRODUCIBLE EFFECT -> SCHOOL INTERPRETATION -> COMPETING INTERPRETATION -> POSSIBLE ONTOLOGICAL CLAIM`.

### YA / ORBITAL YOUTH
Competent youth may succeed. Strong escalation can be `competent act -> genuine success -> more trust/access/responsibility -> harder bounded choice`, not repeated humiliation/failure.

### PROSE / ANTI-FRAGMENTATION
`ONE MAIN STORY/CAUSALITY -> SCENE NECESSITY -> ORDER/DURATION/FREQUENCY -> SHOW/TELL -> POV -> DIALOGUE MODE -> PARAGRAPH INTENT -> READER-STATE CONTINUITY -> SENTENCE RHYTHM -> WORDING`.
Do not use sentence shortening as a substitute for scene design.

## FINAL SYNTHESIS
Bell is strongest as a practical structural diagnostic and idea-generation toolbox. He is weakest when his commercial-thriller preferences are universalized into laws: death stakes, fixed three-act proportions, negative outcomes, stronger villain, show-always, and cliffhanger pressure.

IVDIVO should use Bell as a high-utility diagnostic router under higher authorities: current canon, independent personhood, causal truth, evidence provenance, reader effect, and stage-appropriate revision.

Final production law:
**TOOLS DIAGNOSE AND GENERATE; STORY EVIDENCE DECIDES.**
