## Source authority / limits
Useful as a **planning workbook and diagnostic lens**, not as universal psychology, epistemology, ethics or story law.

The source repeatedly treats `Lie` and `Truth` as objective moral/psychological categories, ties character change to fixed three-act percentages, treats Ghost/wound as a common causal explanation, and often assumes low points, death imagery, final confrontation and moral proof. Those claims are retained only where cross-source evidence supports the underlying function.

## Retained mechanisms
### M1 — Character Model / Pressure Loop
`CURRENT MODEL / VALUE → PRESENT WANT → TACTIC → WORLD / RELATION RESPONSE → CONSEQUENCE → MODEL UPDATE OR TESTED STABILITY`.

This replaces the literal `Lie → Truth` ontology while retaining the useful pressure-and-update mechanism.

### M2 — Plot / Character / Theme Braid
`EXTERNAL EVENT → CHARACTER INTERPRETATION / CHOICE → CONSEQUENCE → NEXT EXTERNAL STATE`.

Theme should emerge from competing models, choices and consequences; plot and character must pay into the same causal engine.

### M3 — Want / Need Separation
Useful diagnostic distinction:
- `WANT` = trackable present objective or desired outcome.
- `NEED` = capability, relationship condition, knowledge, value correction or strategy the character may require to act better.

Firewall: Want is not always external; Need is not automatically an objective moral Truth.

### M4 — Arc Proof Through Behaviour
`EARLY PRESSURE CASE → CHARACTER RESPONSE A → LATER ANALOGOUS PRESSURE CASE → RESPONSE B → CONSEQUENCE DIFFERENCE`.

A claimed arc must become visible in changed behaviour, tactic, boundary, evidence threshold, responsibility or relationship terms—not narrator explanation.

### M5 — Tested Stability / Flat-Arc Salvage
`CORE VALUE / MODEL → PRESSURE → DOUBT / COST → ADAPTIVE TACTIC → VALUE RETAINED OR REFINED`.

A character can remain fundamentally stable while relationships, methods, knowledge and responsibility change.

### M6 — Negative-Arc Differentiation
Distinguish:
- **Disillusionment:** epistemic model becomes darker/more constrained; ethical decline is not required.
- **Fall:** repeated choices worsen the operative model and downstream option space.
- **Corruption:** character begins with access to a better model/value but repeatedly rejects it for a competing benefit.

These are trajectory families, not mandatory moral templates.

### M7 — Baseline / Normal-World Function
`STARTING AFFORDANCES + RELATIONSHIPS + NORMS + HABITS → READER BASELINE`.

The opening environment supplies a comparison baseline for later changes. It need not be a literal separate physical “Normal World.”

### M8 — Midpoint as Model Re-weighting
`NEW EVIDENCE / EXPERIENCE → OLD MODEL EXPLAINS LESS → NEW MODEL OR STRATEGY GAINS WEIGHT → ACTION CHANGES`.

No mandatory 50% location, false victory/defeat or single Moment of Truth.

### M9 — Resolution as State Proof
`LOCAL CONFLICT RESOLVED → COST / AFTERMATH → BEHAVIOURAL / RELATIONAL / EPISTEMIC PROOF → CHANGED FUTURE OPTION SPACE`.

Do not end with a theme speech merely because the workbook requests a thematic answer.

### M10 — Exercise Output Firewall
`WORKBOOK ANSWER / ARC VARIANT → DISCOVERY_ONLY → CANON + CHARACTER + CAUSALITY + EVIDENCE + PERSONHOOD TEST → KEEP / REPLAN / BANK / DISCARD`.

Workbook completion never creates canon by itself.

## Failure modes / rejected universal claims
- **LIE/TRUTH ONTOLOGY:** character belief is not automatically objectively false/true.
- **MORAL ANSWER KEY:** theme need not reduce to one author-certified Truth.
- **WANT-EXTERNAL / NEED-INTERNAL ABSOLUTISM:** useful tendency, not law.
- **MANDATORY GHOST / WOUND:** trauma is not required for depth or change.
- **GHOST-SIZE ARITHMETIC:** large behaviour change does not require proportionally large trauma.
- **HEALING RETROFIT:** story need not become therapeutic recovery.
- **THREE-ACT PERCENTAGE LOCK:** 25/50/75/88/98% positions are heuristic, not ontology.
- **MIDPOINT TRUTH OBLIGATION:** a midpoint need not deliver a moral revelation.
- **THIRD-PLOT-POINT DEATH CLOUD:** literal/symbolic death is not required.
- **MANDATORY LOW POINT:** consequence/re-weighting can happen through success, discovery, authority change or relationship change.
- **FINAL BATTLE / ANTAGONIST REQUIREMENT:** decisive action may be institutional, epistemic, relational or technical.
- **PROTAGONIST MUST BE PRIMARY CATALYST:** distributed competence and affected-party decision ownership may be more legitimate.
- **SUPPORTING CHARACTER AS THEME PROOF:** supporting agents retain independent personhood.
- **SELFLESSNESS = UNIVERSAL POSITIVE MARKER:** context and consent matter.
- **OBJECTIVELY HAPPY / SAD ARC CLASSIFICATION:** reader effect and ethical status are not reducible to the workbook’s labels.
- **HUMAN CHANGE AS UNIVERSAL FIVE-ARC PSYCHOLOGY:** craft taxonomy, not established psychology.
- **COGNITIVE-DISSONANCE CASUALISM:** do not turn the term into a diagnostic shortcut.
- **NORMAL WORLD / ADVENTURE WORLD BINARY:** many stories remain in one physical environment while causal conditions change.
- **ARC BEAT = CHAPTER / PARAGRAPH / SENTENCE BREAK:** analytical structure must not dictate typography.

## Cross-source comparison
### Card / McKee Character / Corbett / Swain
Convergence: character becomes legible through choices, priorities, relationships and tactics under pressure.
Correction to Weiland: a person is not reducible to one Lie, one Truth or one Ghost.

### Herman / Zunshine / Oatley
Convergence: characters and readers maintain provisional models of motives and reasons.
Correction: `CHARACTER BELIEF / SELF-REPORT ≠ WORLD FACT` and behaviour does not prove motive.

### Truby / Brody / Vogler / Bell
Convergence: structural beats can diagnose trajectories.
Correction: frameworks are optional lenses; fixed percentages and mandatory beats are rejected.

### Kress / Collins
Convergence: motivation, frustration response and contextual emotional expression differentiate characters.
Correction: change must remain relationship- and context-specific, not a single moral conversion.

### Le Guin / Prose / Hodgins / Clark
Convergence: story beats do not dictate sentence length or paragraph breaks.
`ARC BEAT ≠ SENTENCE BREAK`; `ACTION / EMOTION ≠ SHORT-SENTENCE DENSITY`.

### Hayes
Convergence: relationships can create causal change.
Correction: another person does not “complete” or heal the protagonist by default.

## IVDIVO operationalization
### Arc Diagnostic Card
For every major character:
1. Current model/value.
2. Present want/responsibility.
3. Relationship-specific risk.
4. Evidence / experience pressure.
5. Tactic.
6. Outcome.
7. What changed: model, tactic, boundary, trust, responsibility, evidence threshold, authority or future options?
8. Later analogous pressure case proving change or tested stability.

### Arc Admission Gate
A proposed character arc receives book-level space only if:
`CHARACTER CHANGE / STABILITY → CHANGES A MAJOR CHOICE OR RELATIONSHIP → CHANGES THE ONE MAIN STORY ENGINE / PAYOFF`.

If the arc can be removed without downstream consequences, compress, merge or bank it.

### Theme Gate
`THEMATIC QUESTION → COMPETING MODELS → CHARACTER-TRUE CHOICES → CONSEQUENCES → READER INFERENCE`.

Do not install a character’s “Truth” as authorial exposition.

### Mystery / evidence firewall
`ARC REVELATION / CHARACTER TRUTH ≠ CORROBORATED WORLD FACT`.

Any claimed realization about the world must still pass:
`TRACE/SOURCE → SOURCE LINEAGE → ACCESS → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING TEST → STATUS UPDATE`.

### Personhood firewall
A conscious robot or nonhuman agent does not require a human Ghost, wound, healing arc or “becoming more human.”

`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### YA firewall
Do not retrofit adolescent depth as `TRAUMA → LIE → HEALING`.
Autonomy, belonging, first responsibility, privacy, consent, competence, reputation, relationships and competing good values can generate equally strong arcs.

### Post-money Orbital Youth
Character stakes remain non-fungible: trust, time, access, unique mission, responsibility, mastery, privacy, relationship and consent—not salary/rent/credits disguised as status points.

## Manuscript validation
### LESSON ZERO Book One
No new specific current-text reader/audio/continuity/canon defect established.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Do **not** retrofit the locked manuscript to Weiland’s percentages, Lie/Truth vocabulary, mandatory Ghost, Midpoint Moment of Truth or Third-Plot-Point low point.

If future reader evidence identifies a character-arc defect, first compare early and later analogous pressure cases and inspect actual behavioural/tactical change before revising structure.

### Future IVDIVO books
Use Weiland primarily as an **arc-trajectory and behavioural-proof laboratory** after the causal engine is known.

Prefer neutral production vocabulary (`CURRENT MODEL / VALUE / WANT / PRESSURE / TACTIC / UPDATE`) over treating `Lie / Truth` as objective world ontology.

## Prose / choppiness validation
Arc beats are analytical units, not typographic commands.

`ARC TURN / MOMENT OF TRUTH / RECOGNITION ≠ NEW SHORT PARAGRAPH BY DEFAULT`.

Standing repair order remains:
`BOOK ENGINE → CHAPTER / SCENE FUNCTION → NARRATIVE MODE → POV / EVIDENCE → PARAGRAPH INTENT / READER-STATE → SENTENCE RHYTHM / CONTRAST → WORDING`.

## Final synthesis
Weiland is most valuable to IVDIVO as a **structured character-trajectory workbook**: it forces explicit linkage among model, want, pressure, behaviour and later proof. Its main danger is turning this practical planning vocabulary into universal psychology or mandatory plot arithmetic.

Retain the causal/behavioural diagnostics. Reject the moral ontology and formula lock.
