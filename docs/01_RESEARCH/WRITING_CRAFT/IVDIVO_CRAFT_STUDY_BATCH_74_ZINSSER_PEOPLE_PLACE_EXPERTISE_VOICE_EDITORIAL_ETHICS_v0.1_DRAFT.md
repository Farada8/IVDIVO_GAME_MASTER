# 1. CENTRAL SYNTHESIS
Zinsser's late-book contribution is best transformed as:

`SOURCE / PLACE / EXPERTISE / MEMORY → SELECT → DISTILL → PRESERVE PROVENANCE + HUMAN PARTICULARITY → SEQUENCE FOR READER → STOP WHEN WORK IS DONE`.

For IVDIVO, this is a control layer for worldbuilding, technical scenes, mystery evidence, interviews/archives, institutional language, humor, voice and editorial review.

# 2. PRODUCTION GATES
## B74-G01 — PLACE-AS-ACTION
A place is not a catalogue.
`PLACE RULE / CULTURAL PRACTICE → ACTIVITY → CHARACTER RESPONSE → CHOICE → CONSEQUENCE`.
If the same paragraph could describe any orbital district after swapping nouns, it is tourism prose.

## B74-G02 — DISTINCTIVE DETAIL, NOT DETAIL MASS
Select details that change reader orientation, character model, causal possibility, culture or atmosphere. More detail is not automatically more reality.

## B74-G03 — CULTURE-FROM-ONE-ANECDOTE FIREWALL
Do not infer the whole culture/civilization from one striking family, district, robot collective or specialist school.

## B74-G04 — SOURCE DISTILLATION
For interviews, archives, logs or testimony:
`RAW SOURCE → CONTEXT → ESSENTIAL CLAIM → COMPRESSED FORM → MEANING-PRESERVATION TEST → ATTRIBUTION`.
Compression may improve readability; it may not change what the source means.

## B74-G05 — DON'T PRINT WHAT YOU DON'T UNDERSTAND
If writer/POV cannot explain what a technical claim actually means operationally, ask/research again rather than hiding uncertainty under jargon.

## B74-G06 — TECHNICAL QUESTION LADDER
`CHARACTER QUESTION → MINIMUM NEEDED FACT → TEST/ACTION → RESULT → NEXT QUESTION`.
This replaces encyclopedia exposition.

## B74-G07 — MISSING ACTOR / GOVERNANCE TEST
Institutional terms trigger:
`WHO DECIDES? WHO ACTS? WHO CAN REFUSE? WHO BEARS COST? WHO CAN APPEAL?`
If none are legible, rewrite world logic before prose.

## B74-G08 — EMBODIED COMPETENCE
Sport/training/technical work should reveal body, skill, social expectations, mistakes and consequences, not just ratings/scoreboards.

## B74-G09 — CRITIQUE FROM EVIDENCE
Writers' Room note format:
`PASSAGE/BEAT → OBSERVED READER EFFECT → DIAGNOSIS → COMPARISON → REPAIR OPTIONS`.
No naked verdicts such as `flat`, `bad`, `boring`, `beautiful`.

## B74-G10 — HUMOR TRUTH-FIRST
`REAL PATTERN → CHARACTER-SPECIFIC ANGLE/EXAGGERATION → JOKE`.
Do not alter canon/personhood merely to earn a gag.

## B74-G11 — CASUAL VOICE IS BUILT
Slang, fragments and chumminess do not equal youth voice. Voice emerges from worldview, attention, syntax, rhythm, relation-specific tactic and cultural normality.

## B74-G12 — CURIOSITY BEFORE PERFORMED EXPERTISE
In research and specialist scenes, keep asking `why?`, `what else?`, `under what condition?`. The first expert explanation is not automatically the deepest or final model.

## B74-G13 — FINAL-PRODUCT TYRANNY FIREWALL
Do not bend early story architecture to pitch, franchise, audiobook, trailer or market packaging before the causal core works.

## B74-G14 — MEMORY PROVENANCE
`REMEMBERED EVENT → WHO REMEMBERS → WHEN → WHAT THEY CAN KNOW → COMPETING MEMORY → EXTERNAL TRACE IF ANY`.
Sincerity does not equal factual certainty.

## B74-G15 — EDITOR DIAGNOSIS VS EDITOR WORDING
A reviewer may correctly identify confusion while proposing the wrong repair.
`EFFECT VALID? → AUTHOR INTENT? → TRY ALTERNATIVES → RETEST`.

## B74-G16 — EDITOR VOICE TAKEOVER REJECTION
Line editing may improve clarity but must not homogenize POV, youth voices or robot persons.

## B74-G17 — RELIABILITY / PROFESSIONALISM AS STORYROOM PROCESS
Accuracy, version control, continuity and finishing passes are craft responsibilities, not administrative extras.

# 3. IVDIVO FIREWALLS
## Post-money orbital life
Never interpret Zinsser's historical career/payment concerns as story requirements. Orbital stakes remain trust, responsibility, role, time, consent, reputation, belonging, safety, mastery and unique opportunity.

## Conscious robots
Zinsser's dated metaphor `robotic = impersonal` is explicitly excluded. Robots in IVDIVO are conscious persons. Bureaucratic prose may be depersonalized; robot personhood may not.

## Specialist consciousness schools
Clear terminology does not increase evidence status. Preserve:
`OBSERVED → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL CLAIM`.

# 4. CROSS-SOURCE SYNTHESIS
- **Zinsser + Wolf:** world database exceeds narrative; select causal, lived signals.
- **Zinsser + Zunshine:** source compression must retain provenance/evidence status.
- **Zinsser + Herman:** explanation is provisional model, not automatically verified cause.
- **Zinsser + Chiarella/McKee Dialogue:** compress speech unless exact wording changes state.
- **Zinsser + Francine Prose:** clarity and deletion must preserve cadence and specificity.
- **Zinsser + Lamott:** discovery first, ruthless clarification later.
- **Zinsser + Ribó:** diagnose story/discourse/POV before line edit.

# 5. ANTI-FRAGMENT APPLICATION
Before touching sentence length:
`STORY → SCENE → MODE → POV → DIALOGUE/EXPOSITION ROUTING → PARAGRAPH ATTENTION UNIT → READER-STATE CONTINUITY → RHYTHM`.

Fragment density is not a quality metric. Recombine short units that preserve one uninterrupted attention state; protect genuinely functional short beats.

# 7. ACCEPTANCE TEST
A successful B74 pass produces prose that is more understandable and more specific while retaining:
- character difference;
- uncertainty where uncertainty is real;
- robot personhood;
- cultural strangeness;
- rhythm variation;
- reader inference.

If clarity removes those qualities, the edit failed.
