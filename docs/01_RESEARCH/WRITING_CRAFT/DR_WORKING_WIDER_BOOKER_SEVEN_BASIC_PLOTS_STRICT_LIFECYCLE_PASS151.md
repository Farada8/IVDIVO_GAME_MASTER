## Provisional structure interpretation
Booker proposes seven recurring plot families and then tries to reduce them to a shared archetypal light/dark and constriction/liberation structure. The source itself acknowledges substantial overlap among plot families and stories combining several families.

### Retain provisionally
1. Pattern families can be useful **after** causal analysis, as comparison lenses.
2. Plot signatures can expose missing causal functions, duplicated movement, weak goal architecture, or a mismatch between promised story experience and actual development.
3. `Quest` is useful as a diagnostic for a distant trackable goal plus sustained causal obstacles.
4. `Voyage and Return` is useful when entry into an unfamiliar system changes the protagonist's model, affordances, relationships, or future decisions.
5. `Recognition` in comedy can be reframed as `mis-modelled state → discriminating evidence → model update → changed relationship/action`.
6. Tragic progression can sometimes be usefully reframed as `strong local objective/model → ignored variable → consequence → patch → compounding lock-in`.
7. Constriction/release can be tracked as reader-pressure modulation, but not as mandatory alternation.

### Reject / science-firewall
Do **not** promote to production law:
- `all stories = exactly seven plots`;
- collective-unconscious/archetypal metaphysics as fact;
- universal `dark power / light` moral ontology;
- masculine/feminine essence assignments;
- Princess/Prince or heterosexual union as universal completion;
- marriage/kingdom as universal happy ending;
- physical difference, deformity, nonhuman embodiment, or disability as symbolic proof of monstrosity or moral incompleteness;
- tragedy as selfish desire inevitably punished by destruction;
- fixed five-stage cycles as mandatory beats;
- rule-of-three/four numerology as a production requirement.

## Cross-source comparison — provisional
- **Aristotle:** causal unity is stronger than Booker's family taxonomy. `AFTER ≠ BECAUSE` remains upstream.
- **Truby/Brody/Vogler/Warner:** Booker joins the framework-collision bank; no pattern receives automatic authority.
- **Chatman/Genette:** discourse order/duration/frequency remains separate from story-pattern classification.
- **Herman/Zunshine/Oatley:** person/motive inference must remain evidence-bounded; archetypal labels cannot replace motive models.
- **Corbett/Card/McKee Character:** contradictory behaviour requires context/value/relationship analysis, not archetypal slot assignment.
- **Cambridge Companion / Edward James:** genre and narrative-history evidence argues strongly against claiming timeless exclusive taxonomy from one school.
