## Mechanism 1 — Image as Focusing Element
A scene image is not merely decoration. Selected sensory particulars can focus the event, emotional meaning, and reader attention.

Operational model:
`SCENE EVENT → POV-SPECIFIC SENSORY SELECTION → IMAGE SEQUENCE → EMOTIONAL / INTERPRETIVE FOCUS → READER MODEL`

The Mary Morris example is useful because the horror is carried by a small set of selected perceptions rather than by abstract explanation: current, face, silence, body movement, disappearance, then later visual contrast.

### Gate B157-G01 — Image Function
For each emphasized image ask:
1. Who notices it?
2. Why this detail now?
3. What event / relation / inference does it focus?
4. What would be lost if it were removed?

If the answer is only `it makes the prose atmospheric`, compress or replace.

## Mechanism 2 — Sensory Selection, Not Sensory Checklist
Strong sensory writing is selective. It does not need to touch sight + sound + smell + taste + touch in every scene.

Operational model:
`SENSORIUM → SALIENCE FILTER → FEW LOAD-BEARING PARTICULARS → EFFECT`

### Gate B157-G02 — No Five-Sense Checklist
Do not add a sensory channel merely because it is missing. Add it only when it changes orientation, affordance, mood, evidence, relation, or inference.

## Mechanism 3 — Contrast Transfers Meaning
A later image can change the meaning of an earlier image without an explanatory theme sentence.

Operational model:
`IMAGE A → IMAGE B / CONTRAST → EMERGENT RELATION → READER INFERS MEANING`

### Gate B157-G03 — Contrast Before Explanation
Before adding a sentence that explains the emotional/theme meaning, test whether a carefully chosen contrasting image can carry it.

## Mechanism 4 — Description Is Part of Causality When Attention Changes
Description earns reader time when noticing itself changes what the POV understands, feels able to do, fears, values, or chooses.

Operational model:
`NOTICE → RELATE → REFRAME → OPTION / ACTION CHANGE`

### Gate B157-G04 — Description State-Change Test
If a descriptive passage can be removed without altering reader orientation, character model, relation, evidence, or next action, shorten it unless lived-world texture is itself the intended reader reward.

## Mystery / evidence firewall
Literary vividness must not silently upgrade evidence.

`VIVID IMAGE ≠ CORROBORATION`

Use:
`RAW TRACE → OBSERVATION → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION / STATUS UPDATE`

A metaphor or emotionally charged visual may alter a character's hypothesis. It may not alter timestamp, measurement, provenance, source independence, or what the trace actually proves.

### Gate B157-G05 — Evidence Veracity
When an image describes a clue, preserve the literal forensic/evidentiary layer separately from the POV's metaphorical or emotional rendering.

## Orbital Youth
Worldbuilding description should follow:
`WORLD RULE / EMBODIMENT → CHARACTER-SPECIFIC NOTICE → AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`

Do not describe an orbital technology because it exists in the world bible. Describe what this person notices because it matters to their present goal, body, relationship, or task.

### Gate B157-G06 — No Tech Catalogue
Three or more novel technological details in a row require a vector: changing action, relation, inference, access, or emotional meaning.

## Conscious nonhuman persons
Richer sensing does not imply omniscience.

`EMBODIMENT + OWN WANT + TASK + RELATIONSHIP + KNOWLEDGE LIMIT → SALIENCE → NOTICED DETAIL`

### Gate B157-G07 — No Universal Sensor-Feed Voice
A conscious robot/nonhuman should not narrate as a generic instrument panel. Its attention must reveal personhood, task, history, relationships, and limits.

## Consciousness-school firewall
Phenomenological vividness is not ontological proof.

`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`

### Gate B157-G08 — Experience Intensity ≠ Ontology
The intensity or beauty of an experience can justify narrative emphasis, not a stronger truth-status.

## Prose / choppiness application
Bad pattern:
`object. sensory fragment. second object. micro-reaction. metaphor. theme sentence.`

Preferred diagnostic order:
`SCENE FUNCTION → EVENT TARGET → POV ATTENTION → SELECTED IMAGES → RELATION / CONTRAST → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`

### Gate B157-G09 — Image Sequence Is Not Fragment Sequence
If several images belong to one continuous perceptual unit, default to a coherent paragraph/sentence architecture. Short isolated lines require a distinct emphasis function.
