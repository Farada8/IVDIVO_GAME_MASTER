## Mechanisms extracted so far

### 1. Rewrite Diagnosis Before Rewrite

Seger’s strongest practical idea is that rewrites multiply when the defect is vaguely named. A change to the second act can expose or create a character/subplot problem because the script is a connected system.

IVDIVO adaptation:

`OBSERVED DEFECT → DEFECT LEVEL → DEPENDENCIES → MINIMAL CORRECT FIX → REGRESSION TEST`

Standing law:

`NO BROKEN THING → NO REWRITE`.

### 2. Tool Is Collaborator, Not Blueprint

Seger explicitly warns that writing software encodes its designer’s logic and can make the writer believe there is one required process.

IVDIVO adaptation:

`TOOL → QUESTIONS / ORGANIZATION / DIAGNOSIS`

not

`TOOL → STORY MUST TAKE THIS SHAPE`.

This directly constrains the multi-specialist Writers’ Room: specialists are routed to actual problems; they do not all govern generation simultaneously.

### 3. Multiple Valid Creative Entry Points

Idea, image, character, theme, dialogue, index cards, treatment, journal, research, audio recording and direct drafting can all be legitimate starts.

IVDIVO adaptation:

`LIVE MATERIAL → EXTERNALIZE BY USEFUL MODE → FIND RELATIONSHIPS → CAUSAL ORGANIZATION → DRAFT → DIAGNOSE`.

No single planning method is mandatory.

### 4. Plan / Treatment Is a Fluid Hypothesis

A polished treatment can become psychologically mistaken for truth. Seger advises keeping planning material changeable while story logic is still being discovered.

IVDIVO law:

`PLAN = HYPOTHESIS, NOT CANON`.

Any plan change still passes current canon, personhood and causal gates.

### 5. Research Changes Story, Not Just Decoration

Research affects vocabulary, pressure, relationships, actions and sometimes story direction.

IVDIVO adaptation:

`DOMAIN QUESTION → SOURCE / OBSERVATION → CHARACTER-SPECIFIC KNOWLEDGE & LANGUAGE → ACTIONABLE DETAIL → STORY CONSEQUENCE`.

Research is not permission for lore dumping.

### 6. Generate Hot / Critique Cool

Seger allows a writer to keep drafting rather than interrupt a live first-draft flow for grammar, typos or local alternatives.

Cross-source convergence: Lamott, LaPlante, Swain, Bell.

IVDIVO production order:

`DISCOVERY → CANON / ONE MAIN STORY → CAUSALITY → CHARACTER / PERSONHOOD → SCENE → POV / EVIDENCE → DIALOGUE → PARAGRAPH / RHYTHM → WORDING → READER TEST`.

## Chapter 2 provisional cross-source comparison

Seger strongly privileges three-act structure and approximate screenplay page ratios. This is useful as one diagnostic school, **not a universal production law**.

Truby explicitly argues that mechanical act breaks are external to story and can encourage episodic construction. Bell accepts three-act structure but likewise becomes most useful when translated into functional transitions rather than page arithmetic.

IVDIVO synthesis:

`STRUCTURAL TRANSITION = GOAL / OPTION / RELATION / EVIDENCE / AUTHORITY / RESPONSIBILITY STATE CHANGES`

not

`STRUCTURAL TRANSITION = PAGE N`.

The functional value of setup/development/closure is retained; fixed ratios are rejected for novels and audio drama.
