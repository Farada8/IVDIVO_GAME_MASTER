## 3. New system mechanisms

1. **Controlled Exercise Routing** — name the defect and variable before running an exercise.
2. **Five-Fork Minimum** — stalled story/sequence gets multiple continuation candidates before commitment.
3. **Inherent-Promise Selection** — prefer consequences latent in the existing story over imported twists.
4. **Dead-Story Permission** — if no organic forward motion exists, deletion/replacement is allowed.
5. **First-Melting Protection** — identify what already works before major rewrite.
6. **Component-Isolation Revision** — test POV, tense, scene/summary, cast, imagery, scene length etc. separately when possible.
7. **Dialogue-Mode Routing** — summary / indirect / direct dialogue selected by function.
8. **Opening Set-in-Motion** — opening must create altered state/desire/pressure, not only milieu.
9. **Constraint-as-Diagnostic** — exercise word limits reveal focus but are not manuscript quotas.
10. **Variant Organicity** — a variant must strengthen Story Contract and causal network.
