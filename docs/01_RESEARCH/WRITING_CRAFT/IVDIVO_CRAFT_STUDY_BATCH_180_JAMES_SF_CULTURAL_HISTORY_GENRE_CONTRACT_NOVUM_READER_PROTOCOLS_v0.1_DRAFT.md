# IVDIVO CRAFT STUDY BATCH 180 — EDWARD JAMES — SF CULTURAL HISTORY · GENRE CONTRACT · NOVUM · READER PROTOCOLS v0.1

**Source:** Edward James, *Science Fiction in the Twentieth Century* (OUP, 1994)  
**Source status:** `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`  
**Role:** genre-history / reader-protocol / worldbuilding-causality diagnostic

## Production synthesis

### Gate J180-01 — GENRE CONTRACT
Before applying an SF trope, state what reader pleasure/promise it serves: cognition/model-building, wonder, mystery, relationship, adventure, satire, social extrapolation or estrangement.

A label alone is not a story function.

### Gate J180-02 — NOVUM CAUSAL PAYMENT
`NOVUM → AFFORDANCE/CONSTRAINT → SOCIAL/HISTORICAL RIPPLE → PERSON-SPECIFIC CHOICE → CONSEQUENCE`.

Fail if the technology/social rule can be removed with no material change.

### Gate J180-03 — FAMILIARITY COMPRESSION
Explain less when POV action and context let the target reader reconstruct enough. Explain more when omission would force Earth-present defaults that are false in IVDIVO.

### Gate J180-04 — FUTURE DEFAULT OVERRIDE
If the future differs from the present on money, work, robots, privacy, training, family or authority, establish the difference through ordinary causal life before the reader silently restores 2020s defaults.

### Gate J180-05 — WONDER MUST MOVE SOMETHING
`WONDER → MODEL / SCALE / VALUE / OPTION-SPACE CHANGE`.
Spectacle without downstream change is tourism.

### Gate J180-06 — TECHNICAL DETAIL ROUTER
Technical explanation is allowed when process itself is part of the promised reader pleasure and changes the working model/action.
`QUESTION → MINIMUM NECESSARY TECH DATA → TEST/USE → RESULT → NEXT CHOICE`.

### Gate J180-07 — PRODUCTIVE UNCERTAINTY
Unknown vocabulary may remain unexplained temporarily if the reader knows that it is unknown, context accumulates, and misunderstanding does not destroy scene causality.

### Gate J180-08 — SHARED-MEGATEXT AUDIT
Never assume all readers share the same SF shorthand. Ask what a new IVDIVO reader can infer without a glossary.

### Gate J180-09 — HISTORICAL-CONVENTION AUDIT
Before enforcing a “genre rule,” ask:
`what editor / magazine length / market / fandom / movement created this convention?`
Retain it only if current reader effect requires it.

### Gate J180-10 — COMPETENCE / LEGITIMACY FIREWALL
`EXPERTISE ≠ LEGITIMACY ≠ CONSENT ≠ DECISION OWNERSHIP`.

### Gate J180-11 — PSEUDOSCIENCE FIREWALL
Historical SF treatment of psi, telepathy, UFOs, mystical consciousness, etc. is not evidence for IVDIVO ontology.

### Gate J180-12 — NONHUMAN PERSONHOOD
Do not stop at alien/robot-as-metaphor. Named conscious nonhuman:
`OWN WANT → OWN MODEL → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Gate J180-13 — FAN FEEDBACK SEGMENTATION
Expert/fan feedback is high-information but segment-specific.
`FAN RESPONSE ≠ MASS-READER RESPONSE`.

### Gate J180-14 — NOVELTY / ORIGINALITY DISTINCTION
New gadget/planet/twist ≠ original story. Originality may reside in causal relation, person, social consequence, form, viewpoint, moral decision, relationship or language.

### Gate J180-15 — STYLE MOVEMENT FIREWALL
Pulp velocity, New Wave experiment and cyberpunk density are selectable registers, not “the SF style.”

### Gate J180-16 — WORLD DATABASE ≠ BOOK NARRATIVE
Write enough hidden history to make the world causal; publish only what the current book needs.

## Failure modes

- `GENRE DEFINITION ESSENTIALISM`
- `NOVUM WITHOUT RIPPLE`
- `SENSE-OF-WONDER TOURISM`
- `CONSENSUS-MEGATEXT OVERASSUMPTION`
- `TECHNOCRATIC LEGITIMACY`
- `GERNSBACK LECTURE DUMP`
- `PSEUDOSCIENCE ONTOLOGY LEAK`
- `MARKET-ECOLOGY BLINDNESS`
- `FANDOM-AS-ALL-READERS`
- `INSIDER RECURSION TAX`
- `FUTURE-WITH-PRESENT-DAY-DEFAULTS`
- `ALIEN-AS-ALLEGORY-ONLY`
- `NOVELTY-AS-ORIGINALITY`
- `STYLE-MOVEMENT MONOCULTURE`

## Anti-choppiness consequence

Historical SF demonstrates many successful pacing regimes. Therefore:

`ACTION / WONDER / TECHNICAL COGNITION / SUSPENSE ≠ SHORT-SENTENCE DENSITY`.

Route first through:
`CAUSAL ENGINE → DISCOURSE MODE → READER INFERENCE BUDGET → PARAGRAPH CONTINUITY → RHYTHM`.
