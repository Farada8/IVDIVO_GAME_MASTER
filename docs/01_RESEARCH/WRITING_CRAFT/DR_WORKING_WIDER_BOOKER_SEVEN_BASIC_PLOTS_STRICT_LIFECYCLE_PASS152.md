## Highest-value retained mechanisms from Part Two

### 1. Blind-Spot / Unrealised-Capability Gate
Booker's `unrealised value` is retained only after removing gender/archetypal determinism:

`CURRENT COMPETENCE / MODEL → BLIND SPOT OR MISSING CAPABILITY → COUNTERFORCE EXPOSES IT → DISCRIMINATING EXPERIENCE/EVIDENCE → STRATEGY OR CAPABILITY UPDATE`.

The counterforce can reveal what the protagonist lacks without being a villain or metaphysical shadow.

### 2. Competence-With-Blind-Spot
A powerful agent can lose because of a limited model rather than because the plot makes them stupid:

`POWER / COMPETENCE → PREDICTABLE BLIND SPOT → OTHER AGENT USES DIFFERENT MODEL → OUTCOME`.

Useful for intelligent opponents, institutions, robots and technical systems.

### 3. Distributed Capability / Convergence
Booker's allies often supply different capacities needed for success. IVDIVO retains the distributed-competence mechanism but rejects his claim that allies are merely extensions of the hero:

`ONE CAUSAL PROBLEM → INDEPENDENT AGENTS WITH UNIQUE CAPABILITIES → INTERDEPENDENT ACTIONS → CONVERGENCE`.

Every supporting/conscious agent keeps its own personhood and decision ownership.

### 4. Support-Withdrawal / Internalisation Gate
A mentor/tool/helper may disappear when the protagonist can perform a capability independently, but only if the helper's own storyworld personhood is preserved:

`EXTERNAL SUPPORT → LEARNING / ACCESS → CAPABILITY INTERNALISED → SUPPORT NO LONGER REQUIRED FOR THIS FUNCTION`.

Never:
`supporting person becomes disposable once hero learned lesson`.

### 5. Reframing / Trickster Function
Salvage the functional mechanism without Jungian metaphysics:

`FIXED MODEL → DISRUPTING EVENT / EXPERIMENT / REFRAME → OLD MODEL BECOMES UNTENABLE → NEW MODEL → CHANGED ACTION`.

The disrupting agent can be friend, adversary, evidence, environment or experiment.

### 6. Community Consequence Gate
A local protagonist change may legitimately matter to the wider world only when a causal chain exists:

`LOCAL CHOICE / CAPABILITY CHANGE → INSTITUTION / RELATION NETWORK CHANGE → WIDER CONSEQUENCE`.

Reject `hero becomes whole → world is automatically healed`.

### 7. Fatal-Flaw Reframe
Booker's `fatal flaw` is retained only as a defeasible model/blind-spot mechanism:

`CURRENT VALUE / MODEL → SYSTEMATIC BLIND SPOT → REPEATED CHOICE → CONSEQUENCE → PATCH / ESCALATION → MODEL UPDATE / EXIT / FAILURE`.

No immutable tragic essence; no mandatory destruction; no moral punishment requirement.

### 8. Pattern Overlap Confirmed
Ch19 itself uses *The Lord of the Rings* to show multiple pattern signatures inside one work. IVDIVO retains:

`ONE CAUSAL SPINE → MULTIPLE FUNCTIONAL PATTERN SIGNATURES`.

Reject:
`MULTIPLE PATTERNS → MULTIPLE INDEPENDENT MINI-NOVELS`.
