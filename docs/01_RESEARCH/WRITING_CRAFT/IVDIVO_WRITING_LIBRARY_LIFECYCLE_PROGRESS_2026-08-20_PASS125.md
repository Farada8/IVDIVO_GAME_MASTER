## 5. MAJOR NEW SYNTHESIS — BATCH 160

### Functional structural transition
`PRIOR STATE → EVENT / REVELATION / DECISION → MATERIAL CHANGE → NEW GOVERNING PROBLEM / STRATEGY`

No screenplay page arithmetic imported into novels/audio.

### Subplot causal payment
`LOCAL OBJECTIVE → LOCAL CHANGE → EFFECT ON A-STORY / ANOTHER STRAND → PAYOFF`

Recurring texture/thread does not automatically require a full subplot.

### Momentum
`MOMENTUM = CAUSAL STATE CHANGE + PRESSURE ON THE NEXT OPTION`

Momentum is not action density, pace, number of incidents, or short-sentence density.

### Offscreen / implicit event
`OFFSCREEN EVENT / SUMMARY → VISIBLE CONSEQUENCE → NEXT ACTION`

Not every important process/event requires a full real-time scene.

### Fair surprise
`TRUE TRACE → READER MODEL A → NEW CONTEXT/EVIDENCE → MODEL B → RETROSPECTIVE SUPPORT`

### Scene sequence
`SEQUENCE QUESTION → LINKED STATE CHANGES → SEQUENCE PAYOFF`

Not every individual scene requires a miniature three-act structure.

### POV access budget
Every switch must buy unique evidence, action, relationship pressure, irony, lived consequence, context, or decision ownership.

### Flashback present-consequence
Past material earns a full scene only when it changes present interpretation, evidence, relationship, strategy, or decision.

### Scene entry / exit
Start at the latest point consistent with orientation/causal pressure and leave after the relevant changed state.

### Developing repetition
`ELEMENT RETURNS → CONTEXT / FUNCTION / MEANING CHANGES`

### Change impact map
Structural edits must be regression-tested against setup, evidence provenance, motives, relationships, authority/access, later payoffs, and series continuity.
