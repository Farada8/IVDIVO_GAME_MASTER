## CORE TRANSFORMATION

### B122-G01 — SCAPEGOAT CAUSAL LOOP
`PUBLIC LABEL → ATTRIBUTION BIAS → REPEATED EXPLANATION → MATERIAL CONSEQUENCE → BEHAVIOR / SELF-MODEL → LABEL APPEARS CONFIRMED`.

Fail whenever repeated social belief is treated as causal evidence merely because many people share it.

### B122-G02 — CORRELATION / CAUSE / PERSON FIREWALL
`CO-OCCURRENCE ≠ CAUSATION ≠ MOTIVE ≠ PERSONHOOD`.

### B122-G03 — SURFACE WANT / RELATIONAL WANT
For YA leads distinguish:
- publicly legible want: membership/status/qualification;
- actual relational want: belonging, trust, family, autonomy, recognition, love, friendship.

The deeper want must be demonstrated by choices, not supplied as a therapy slogan.

### B122-G04 — DESIRED INSTITUTION MUST BE WORTH WANTING
Do not make every prestigious institution secretly evil.

Build:
`REAL BENEFIT + REAL COMMUNITY + REAL RULES + REAL IMPERFECTION + APPEAL / REFORM / EXIT OPTIONS`.

### B122-G05 — FORMAL VALUES / ACTUAL SELECTION PRESSURE
`OFFICIAL VALUE → TEST DESIGN → INFORMAL ADVANTAGE → BEHAVIOR REWARDED → WHO PAYS`.

A trial can claim to assess virtue while operationally rewarding secrecy, patron access, risk or metric gaming.

### B122-G06 — FRIENDSHIP ≠ NETWORKING
`INSTITUTIONAL ALLIANCE FRAME ≠ FREELY CHOSEN MUTUAL ATTACHMENT`.

In post-money society do not replace monetary exchange with universal social-credit exchange.

### B122-G07 — RECIPROCITY WITHOUT TRANSACTION
One character may help another and receive later help without a negotiated exchange price.

Causal reciprocity is allowed; transactional accounting is not required.

### B122-G08 — PERSON FIRST / CATEGORY SECOND
Before revealing or acting on a high-impact category, build independent evidence of the person's behavior, relationships and choices.

`PERSON MODEL → CATEGORY` rather than `CATEGORY → PERSON ESSENCE`.

### B122-G09 — CAPABILITY / CATEGORY ≠ MORAL DESTINY
A powerful talent, lineage, synthetic architecture, diagnosis, school membership or nonhuman category cannot predetermine morality.

### B122-G10 — PROTECTIVE WITHHOLDING AUDIT
`PROTECTIVE INTENT → INFORMATION WITHHELD → WHAT DECISION SUBJECT COULD NOT MAKE → REVOCABILITY / APPEAL → CONSEQUENCE`.

### B122-G11 — BENEFICIAL OPTION ≠ RIGHT DECISION OWNER
Adults, institutions and engineers can have good motives and still lack the right to decide for a conscious subject.

### B122-G12 — MEMORY / RECOGNITION PROVENANCE
If cognition can be influenced:
`MEMORY / RECOGNITION → CONTROL PROVENANCE → CORROBORATION → EVIDENCE STATUS`.

### B122-G13 — PLACE AS RELATIONSHIP
`PLACE DETAIL / RULE → REPEATED INTERACTION → ASSOCIATION → HOME / BELONGING MODEL`.

Worldbuilding should accumulate lived attachment, not merely visual novelty.

### B122-G14 — BELONGING BEFORE BADGE
Formal membership may ratify belonging that already exists rather than create it.

Audit whether ordinary shared life has done the emotional work before the ceremony/title.

### B122-G15 — PUBLIC ERASURE
`WHO MAY BE NAMED / REMEMBERED → SOCIAL EXISTENCE → ACCESS / RELATIONSHIP CONSEQUENCE`.

Useful for institutional/family memory without literal disappearance.

### B122-G16 — MIXED FAMILY MODEL
Avoid binary `old family bad / found family perfect` architecture. Allow contradictory actions, partial loyalty and specific repair limits.

### B122-G17 — SOURCE PRESENTATION ≠ SOURCE RELIABILITY
A calm, reasonable or helpful intermediary may still carry false identity or agenda.

`TONE / CHARM ≠ PROVENANCE`.

### B122-G18 — TRIALS AS BEHAVIORAL EVIDENCE
A good test creates choices from which character can be inferred. A score that merely declares character worth is weak evidence.

### B122-G19 — SPECULATIVE ONTOLOGY FIREWALL
Wunder/Gossamer/Wundersmith mechanics remain fiction-only.

### B122-G20 — YOUTH VOICE THROUGH ATTENTION
Differentiate young characters by what they fear, joke about, misunderstand, exaggerate, desire and notice under social pressure—not only slang.

### B122-G21 — RHYTHM FIREWALL
`YA / SUSPENSE ≠ SHORT-SENTENCE DENSITY`.

### B122-G22 — NONHUMAN WORKER PERSONHOOD
A conscious nonhuman in a service role is not a servant species/function. Require independent desire, relationships, refusal and embodiment-specific agency.
