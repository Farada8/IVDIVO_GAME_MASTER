# IVDIVO CRAFT STUDY — BATCH 92
## Bell: Troubleshooting · Flashback · Tangent · Tool Routing

Version: v0.1 DRAFT
Date: 2026-08-18
Source status: James Scott Bell, *Plot & Structure* — Ch13 strict-complete; Ch14 partial strict read.

## Principle
A visible prose symptom does not identify the level of the defect.

Production order:

`OBSERVED READER EFFECT -> DEFECT LEVEL -> MINIMUM CORRECT REPAIR -> RETEST`

Never substitute line polish for a scene, causal, POV, evidence or canon defect.

## G92-01 — Diagnose Before Surgery
Before rewriting, identify whether the defect is primarily:
- book engine / causality;
- chapter order;
- scene necessity;
- scene changed-state;
- POV / focalization / knowledge;
- evidence provenance;
- dialogue mode;
- paragraph organization;
- rhythm;
- wording.

Do not begin at sentence level by default.

## G92-02 — Hot-Spot / Irreducible Change
For a weak scene, identify the smallest indispensable event, decision, relationship turn, evidence turn or model change that justifies scenic treatment.

If no indispensable changed-state exists, consider summary, merge, relocation or deletion before line edit.

## G92-03 — Flashback Necessity
Before a full flashback, ask:
1. What does the reader/current POV need from the past now?
2. Can narration, memory fragment, back-flash or indirect summary perform the job?
3. If dramatized fully, what current state changes because the reader experienced it?

A flashback is not earned merely because the backstory is interesting.

## G92-04 — Flashback Present-Consequence
Past material must alter at least one present variable:
- interpretation;
- decision;
- relationship;
- evidence-status;
- trust;
- obligation;
- tactic;
- reader model.

Otherwise compress.

## G92-05 — Past-Explains-Person Firewall
Do not explain a complex person with one childhood wound, humiliation, diagnosis, family event or revelation.

Prefer:
`present behavior pattern -> multiple contexts -> consequences -> provisional causal model`.

## G92-06 — Tangent Causal Test
When live drafting produces an unexpected branch:

`UNPLANNED MATERIAL -> CHARACTER TRUTH -> CANON -> MAIN ENGINE EFFECT -> DOWNSTREAM CONSEQUENCE -> KEEP / REPLAN / BANK / DISCARD`.

Novelty alone does not grant canon status.

## G92-07 — Character Over Outline
Outline, beat sheet, treatment and scene cards are planning hypotheses.

If a planned action requires a character to become less intelligent, less informed, less ethical or less independent than established without causal reason, repair the plan first.

## G92-08 — Writer Fatigue != Story Defect
Before adding escalation because the middle feels dead, test:
- repetition;
- low consequence;
- scene-function duplication;
- poor reader reward;
- weak POV/relationship pressure;
- actual writer fatigue.

Do not manufacture a villain, death, accident, secret, romance, betrayal or new technology as treatment for fatigue.

## G92-09 — Step-Back: Generate Hot / Diagnose Cool
When blocked, temporarily widen generation. Afterward return with analytic distance and validate alternatives against canon, personhood, causality and reader effect.

This reinforces the IVDIVO two-phase system:
`DISCOVERY -> SELECTION/RED TEAM`.

## G92-10 — Unanticipate Variant Test
Unexpectedness is useful only when the result remains retrospectively convincing.

`SURPRISE -> CHARACTER TRUTH -> WORLD TRUTH -> CAUSAL SUPPORT -> RETROSPECTIVE LEGIBILITY`.

## G92-11 — Planting / Capability Provenance
If climax depends on a capability, object, permission, relationship, rule or knowledge state that would otherwise feel convenient, establish fair provenance earlier.

But DO NOT convert every ordinary detail into a future payoff. Lived-world detail can honestly serve verisimilitude, POV, memory, rhythm or culture.

## G92-12 — Notebook Status Separation
External story memory must distinguish:
- CANON
- LOCKED MANUSCRIPT FACT
- WORKING DRAFT
- HYPOTHESIS
- QUESTION
- REFERENCE / INSPIRATION
- SUPERSEDED

Recency or detail does not automatically equal authority.

## G92-13 — Genre Convention != Canon
Genre patterns are option generators and reader-contract diagnostics. They do not authorize:
- money/rent/credits in post-money orbital cities;
- human consciousness-transfer technology;
- mainstream dimensional-science knowledge;
- conscious robots as servants/tools;
- mandatory death stakes or villains.

## G92-14 — SF Rule Consistency
Speculative element earns page weight through causal use:

`WORLD RULE -> AVAILABLE / UNAVAILABLE ACTION -> CHOICE -> CONSEQUENCE`.

Technology catalogue without human/nonhuman consequence is not story progression.

## G92-15 — Speculative Personhood
If a conscious nonhuman appears in a plot function, personhood takes priority over function.

Required checks:
- independent want;
- own evidence/model;
- consent/refusal;
- relation network outside protagonist utility;
- indispensable choice/action.

## Failure modes
1. Tension Monoculture — every scene forced to fight.
2. Hot-Spot Overtrim — orientation, texture and causally needed processing cut away until prose becomes fragments.
3. Flashback Museum — past dramatized because it is interesting, not because the present needs it.
4. Past-Explains-Person — one backstory fact falsely explains the whole character.
5. Tangent-as-Canon — discovery draft automatically alters world canon.
6. Outline Tyranny / Plot Puppet — personhood bent to beat sheet.
7. Slog Inflation — fatigue treated with more plot machinery.
8. Vision Speech — theme explained instead of embodied in choices and consequences.
9. Show-Don't-Tell Absolutism.
10. Surprise-for-Surprise's-Sake.
11. Plant-Everything / Chekhov Overreach.
12. Notebook Status Collapse.
13. Genre Convention Becomes World Canon.

## Cross-source synthesis
Bell Ch13–14 is strongest when combined with:
- LaPlante: discovery and revision are different cognitive jobs;
- Rosenfeld: scene intent grows from prior consequences;
- Fludernik/Ribó: diagnose discourse/time/POV before altering story fact;
- Zunshine/Herman: interpretation and causal story are not verified world fact;
- Zinsser/Clark/Prose: cut/merge at the correct level before polishing wording.

## IVDIVO application rule
The studio should not ask `How can we make this passage more dramatic?` first.

Ask:
`What job must this material perform, what state changes, and what is the cheapest honest narrative mode that performs that job without damaging personhood, canon or reader trust?`
