## Mark Doty — Veracity · Uncertainty · Evidence · Description

Version: v0.1 PROVISIONAL

Source: Mark Doty, *The Art of Description: World into Word*

## 1. Core synthesis
Doty’s strongest contribution is not “use more sensory detail.” It is that description is a **selective act of attention performed by a consciousness**.

Operationally:

`SIMULTANEOUS SENSORIUM → EMBODIED/RELATIONAL ATTENTION → SELECTED PARTICULAR → LANGUAGE → READER MODEL`.

The world delivers more information than prose can contain. Description therefore reveals both the thing and the perceiver’s priorities, limits, history, body, knowledge and present desire.

## 2. Description as thinking
The best descriptive sequences can discover a thought rather than merely decorate a thought the author already knows.

`PARTICULAR → ASSOCIATION / APPOSITION → NEW RELATION → REFRAMED PARTICULAR → EMERGENT THOUGHT`.

Production implication: if the paragraph states its thematic conclusion first and then supplies sensory examples, test reversing the process. Let precise observation generate the inference.

## 3. Dynamic accumulation
Accumulation is not equivalent to quantity.

A descriptive list earns length when each addition performs at least one transformation:
- changes scale;
- changes sensory channel;
- changes tone;
- introduces contradiction;
- adds movement;
- changes relation between observer and object;
- changes the conceptual model;
- prepares an action or decision.

If details are freely reorderable and removable with no change in effect, classify as **CATALOGUE WITHOUT VECTOR**.

## 4. Veracity
Doty’s later alphabet material treats descriptive truth as fidelity to the process of knowing rather than simple photographic transcription.

For fiction craft this is useful, but it needs an evidence firewall.

### Artistic description
May legitimately use:
- metaphor;
- selective emphasis;
- defamiliarization;
- unusual syntax;
- subjective salience;
- unresolved perception.

### Mystery / forensic evidence
Must preserve:
- exact source;
- sequence;
- dimensions;
- timestamps;
- confidence status;
- provenance;
- what was observed versus inferred.

Rule:

**BEAUTIFUL DESCRIPTION ≠ LICENSE TO MUTATE EVIDENCE.**

## 5. Productive uncertainty
Strong description can approach the boundary of perception while acknowledging that the observer does not possess the whole object or final truth.

Production gate:

`WHAT IS DIRECTLY PERCEIVED? → WHAT IS INFERRED? → WHAT REMAINS INDETERMINATE?`

Do not force descriptive closure merely to sound authoritative.

## 6. POV attention gate
For every significant descriptive block:

1. Who is perceiving?
2. What do they want right now?
3. What can their body/sensors actually detect?
4. What do they know how to recognize?
5. What does their relationship/history make salient?
6. What do they ignore?
7. What does the selected detail change?

If the same paragraph could be moved unchanged from Maya to Samir to Ollie to a conscious robot, the description is probably author-camera prose rather than character-owned perception.

## 7. Conscious robot adaptation
Do not equate richer sensors with omniscient narration.

Use:

`EMBODIMENT + OWN WANT + CURRENT TASK + RELATIONSHIP + KNOWLEDGE LIMIT → SALIENCE → NOTICED DETAIL`.

A robot may have more channels than a human while still allocating attention selectively, misclassifying relevance, or lacking context.

Personhood remains:

`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

## 8. Orbital worldbuilding
Description should reveal civilization through lived causality rather than inventory.

`WORLD RULE → CHARACTER-SPECIFIC NOTICE → AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

Examples of useful descriptive pressure:
- gravity differences alter posture, movement or intimacy;
- post-money abundance changes what a teenager does **not** notice;
- limited human time/trust becomes more salient than manufactured objects;
- robot embodiment changes shared-space etiquette;
- training access is experienced as relationship/responsibility rather than consumer purchase.

## 9. Mystery application
Description and evidence must remain separate layers.

`TRACE → NOTICING → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION / CONTRADICTION → ACTION`.

A metaphor can sharpen perception but cannot raise an inference to fact.

## 10. Consciousness-practice schools
Do not use intense subjective imagery as evidence for ontology.

Keep the ladder:

`PRACTICE OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGY CEILING`.

## 11. Anti-choppy prose application
Description often becomes GPT-choppy when each microperception gets its own sentence/paragraph.

Bad structural pattern:

`object → sensory fragment → object → microreaction → metaphor → theme sentence`.

Repair order:

`SCENE FUNCTION → POV ATTENTION → SELECTED PARTICULARS → RELATION / INFERENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Short fragments remain allowed when they have a precise contrast, revelation, pause or end-weight function.

## 12. Failure modes
1. **CATALOGUE WITHOUT VECTOR** — accumulation without transformation.
2. **SENSORIUM CHECKLIST** — sight/sound/touch/smell inserted mechanically.
3. **GENERIC CAMERA POV** — no evidence of who is noticing.
4. **OMNISCIENT SENSOR FEED** — robot/world sensor abundance becomes unlimited narrative access.
5. **DESCRIPTION-AS-LORE-DUMP** — setting detail is actually exposition inventory.
6. **METAPHOR-TO-ONTOLOGY LEAP** — image or felt resemblance becomes fact claim.
7. **EVIDENCE BEAUTIFICATION** — factual trace altered for prose elegance.
8. **DETAIL EXHAUSTION** — exhaustive coverage destroys salience.
9. **STATIC ADJECTIVE STACK** — modifiers accumulate without relation/action.
10. **UNCERTAINTY ERASURE** — narration claims more certainty than observer possesses.
11. **SYMBOL-FIRST DESCRIPTION** — object chosen to prove theme before being concretely perceived.
12. **THEME AFTER EVERY IMAGE** — narrator explains the meaning immediately after the reader can infer it.

## 13. Cross-source comparison
- **Francine Prose:** close reading and word choice; Doty adds the perceptual-selection layer before wording.
- **Lodge:** stylistic mode can vary locally; Doty clarifies why different consciousnesses should produce different descriptive emphasis.
- **Wolf:** world database exceeds book narrative; Doty supplies the attention filter that chooses what enters prose.
- **Zunshine / le Carré:** source and interpretation are separate; Doty requires the same separation when vivid perception is involved.
- **Herman:** person-level cognition is embodied/social; Doty gives a craft implementation through descriptive attention.
- **Swain:** selection precedes arrangement and description; Doty deepens what selection means phenomenologically.
