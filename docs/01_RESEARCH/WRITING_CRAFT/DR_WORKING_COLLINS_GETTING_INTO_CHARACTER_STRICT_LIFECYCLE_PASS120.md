## Historical / methodological correction
Collins speaks broadly of "Method Acting" and Stanislavsky as though deliberate personal emotion recall were a unified lineage. Cross-source material on Stanislavski's later practice shows a more complicated picture:
- emotion can arise from Given Circumstances, action, imagination, objects of attention, relationships, sound/setting, and other stimuli;
- direct personal recall is not the only route;
- later Stanislavski practice is not interchangeable with Strasberg's Method;
- forcing personal emotion can disconnect the performer from present action and can be counterproductive.

Therefore IVDIVO adopts an **Emotion Memory Firewall**:

`PERSONAL MEMORY = OPTIONAL INPUT, NOT REQUIRED AUTHENTICITY`

Preferred routing when a scene feels emotionally false:
1. clarify Given Circumstances / scene reality;
2. clarify present want / objective / relationship;
3. test embodied action and sensory environment;
4. use imagination / observation / analogous experience;
5. use direct personal emotion recall only if genuinely useful and voluntarily chosen;
6. translate any recalled feeling through the character rather than copying the author's reaction.

## Reader-effect firewall
`WRITER FEELS X != CHARACTER FEELS X != READER FEELS X`

The author experiencing grief, fear, anger, attraction, or relief while drafting is not proof that the character expression is specific or that the reader will feel the intended effect. The draft still requires character truth, scene causality, POV, paragraph/rhythm, and reader testing.

## Trauma / ethical firewall
No writer, collaborator, or agent is required to mine traumatic personal memory to make fiction authentic.

Failure mode: `TRAUMA-MINING-AS-CRAFT-DUTY`.

Safer and often stronger alternatives include imagined circumstances, observation, analogous low-risk memories, action/objective work, sensory research, relationship modelling, and revision from reader effect.

## Character-transfer gate
Even when personal emotion is useful, it must be transformed:

`AUTHOR EXPERIENCE → ABSTRACT EMOTIONAL / SENSORY MECHANISM → CHARACTER-SPECIFIC VALUE + HISTORY + EMBODIMENT + RELATIONSHIP + OBJECTIVE → CHARACTER ACTION / PERCEPTION`

If the character simply reacts as the writer would, this is author-proxy leakage rather than deep characterization.

## Mystery / epistemic firewall
`EMOTIONAL CERTAINTY != EVIDENCE`

A POV character's strong emotional response can change attention, suspicion, relationship, or decision threshold. It cannot by itself establish motive, guilt, personhood, consent, causality, or ontology.

For consciousness-practice material:
`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`

## Conscious nonhuman persons
Human emotion-memory methods are not a requirement for nonhuman personhood or characterization.

Use:
`OWN PRIORITIES + EMBODIMENT + MODEL/EVIDENCE + RELATIONSHIPS + CONSTRAINTS + CONSENT/REFUSAL → TIMING / COMMUNICATION / CHOICE → CONSEQUENCE`

A conscious robot or distributed intelligence does not need human facial cues, autobiographical trauma, or human-style emotional recall to qualify as a full person in storyworld terms.

## Prose / anti-choppiness consequence
Emotion work must not be converted into microgesture-by-microgesture typography.

Wrong automation:
`emotion → gesture → one-line thought → breath → gesture → one-line sentence`

Correct router:
`SCENE FUNCTION → POV / EVIDENCE → EMOTIONAL / RELATIONAL TURN → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`
