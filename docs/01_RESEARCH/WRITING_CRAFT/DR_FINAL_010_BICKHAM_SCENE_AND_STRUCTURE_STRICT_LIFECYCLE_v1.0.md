## Structure map — retained mechanisms
### 1. Cause / consequence as structural spine
Bickham's strongest contribution is the insistence that story units must not merely follow one another; an outcome should materially constrain or motivate what comes next.

IVDIVO form:
`PRIOR STATE → PRESENT WANT / RESPONSIBILITY → PRESSURE / COUNTERFORCE / SUPPORT → TACTIC → OUTCOME → CHANGED STATE → PROCESSING / NEW STRATEGY → NEXT CAUSAL LINK`.

### 2. Scene outcome consequence matrix
Chapter 5's most transferable diagnostic is to inspect an outcome by:
- scope,
- immediacy,
- finality,
- direction.

A spectacular ending can be structurally wrong if it pushes the book onto an unintended causal vector. Repair the load-bearing outcome before cosmetically rewriting later scenes.

### 3. Scene / sequel as modes, not mandatory alternation
Classic model:
- Scene: Goal → Conflict → Disaster.
- Sequel: Emotion → Thought → Decision → Action.

IVDIVO generalization:
- Attempt/action mode when exact behavior/words deserve real-time reader attention.
- Processing mode when the character must reassess emotion, evidence, relationships, options, responsibility or strategy.
- Processing may be immediate, delayed, embedded, summarized, or inferred from later changed behavior.

### 4. Pacing as mode allocation and reader-time distribution
Bickham repeatedly changes pace by:
- starting later,
- omitting routine material,
- compressing action,
- expanding processing,
- changing time pressure,
- delaying or interrupting sequel,
- switching viewpoint.

Therefore:
`PACING ≠ SHORT-SENTENCE DENSITY`.

### 5. Hidden-story timeline
Bickham's backstory / present story / hidden story distinction is highly useful for mystery and multi-agent causality.

Production gate:
`WORLD CHRONOLOGY → OFFSTAGE ACTION → TRACE / SOURCE → POV ACCESS → DISCLOSURE ORDER → READER MODEL`.

Offstage events must be spatially and temporally possible even if never dramatized.

### 6. Structural POV continuity
Useful retained rule: avoid accidental head-hopping inside a close-POV scene; keep access and interpretation legible.

Rejected as universal: one viewpoint must own ~70% of every novel. Multi-POV architecture is valid when each switch buys unique action, evidence, lived consequence, relationship pressure, countermodel or decision.

### 7. Inadvertent red-herring / promise audit
A detail introduced as a meaningful threat or possibility creates reader expectation. Do not casually plant load-bearing-looking material with no later function.

But not every lived-world detail is a Chekhov gun. The gate applies when discourse emphasis plausibly promises future causal relevance.

### 8. Scene variation and specialized forms
Useful repertoire:
- non-POV character initiates encounter,
- interrupted scene,
- scene within scene,
- delayed sequel,
- flashback / scene fragment,
- dialogue-heavy scene,
- action-heavy scene,
- maneuver against unseen opponent,
- multi-agenda scene.

These are options chosen for a diagnosed function, not obligatory tricks.

### 9. Chapter endings as read-on contracts
Retained: chapter break should usually preserve or increase meaningful reader orientation/curiosity.
Rejected: every chapter must end on disaster/cliffhanger.

Valid read-on values include:
- changed evidence status,
- earned success with new responsibility,
- relationship turn,
- decision/commitment,
- narrowed option set,
- bounded unanswered question,
- model revision.

### 10. Master plot is explicitly not fill-in-the-blanks
Bickham repeatedly states his twenty-chapter suspense blueprint is a flexible illustration, not a mandatory formula. This is retained and used against later formula leakage.

## Cross-source comparison
### Swain
Bickham inherits scene/sequel and motivation-reaction logic from Dwight V. Swain. Both are valuable as causal diagnostics. Neither is used as a prose metronome.

### Rosenfeld / Scofield / LaPlante
These sources broaden scene causality beyond overt conflict and negative outcome. IVDIVO therefore rejects `no conflict = no scene` and `every scene must end badly`.

### Genette / Chatman
They show that order, duration, frequency, discourse placement and focalization must be diagnosed before rewriting story fact. This limits Bickham's moment-by-moment orthodoxy.

### Bell / Hodgins / Seger
They support macro-before-micro revision, adaptive planning, and scene re-imagination when purpose/staging is wrong.

### Le Guin / Prose / Williams-Bizup / Clark
They reject short-sentence monoculture. Causal beats are not typographic units.

### Ephron / Zunshine / le Carré
They strengthen Bickham's red-herring and hidden-story ideas with source lineage, proof ceilings and fair-play evidence status.

## Failure modes / rejected universal claims
1. **Mandatory Disaster** — not every meaningful scene must end negatively.
2. **Conflict Monoculture** — resistance can be insufficient evidence, consent, physical constraint, institutional procedure, competing good values, or internal tradeoff.
3. **Moment-by-Moment Absolutism** — summary/ellipsis/indirect modes are legitimate.
4. **Stimulus-Response Typography** — causal units must not become one short sentence each.
5. **Mandatory Rising Misery** — success may increase responsibility and create harder choices.
6. **Single-POV Quota** — no universal 70/20/10 rule.
7. **Mandatory Ticking Clock** — time pressure only when causal, not as artificial suspense injection.
8. **Never Relax** — reader rewards, recovery and contemplative processing can be structurally necessary.
9. **Universal External Conflict** — quiet causal scenes are valid.
10. **Historical Market Leakage** — 1990s word-count, chapter-length, romance-publisher and reader-market statements are historical, not 2026 policy.
11. **Psychology-as-Fact** — self-concept rigidity and reader-identification claims are craft hypotheses, not current science.
12. **Villain Requirement** — no mandatory personal antagonist.
13. **Red-Herring Overreach** — emphasis creates promise, but ordinary lived detail need not all pay off as plot.
14. **Chapter Cliffhanger Monoculture** — read-on value need not equal disaster.

## IVDIVO operationalization
### Core scene-state record
For each load-bearing scene:
`OWNER → PRESENT WANT → PRESSURE/SUPPORT → TACTIC → OUTCOME → ACTION STATE → KNOWLEDGE/EVIDENCE → RELATIONSHIP/CONSENT → AUTHORITY/ACCESS/RESPONSIBILITY → FUTURE OPTION SPACE → NEXT DEPENDENCY`.

### Success escalation
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

### Processing router
After a major outcome ask whether processing should be:
- immediate,
- delayed,
- embedded,
- summarized,
- implied through later changed behavior.

### Hidden-story ledger
For mystery/institutional causality maintain:
`OFFSTAGE ACTOR → WANT → ACTION → TIME/LOCATION → TRACE CREATED → WHO CAN ACCESS TRACE → DISCLOSURE ORDER → LATER PAYOFF`.

### POV fairness
`WHO PERCEIVES ≠ WHO KNOWS ≠ WHO INTERPRETS ≠ WHO DECIDES`.
No knowledge without access provenance.

### Anti-choppiness law
`BEAT MAP ≠ SENTENCE BREAK`.
`CAUSE/RESPONSE ≠ ONE MICROBEAT PER SENTENCE`.
`COMPRESSION ≠ CHOPPING`.
`ACTION / SUSPENSE / EMOTION ≠ SHORT-SENTENCE DENSITY`.

Repair order:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH LOCAL JOB / READER-STATE CONTINUITY → SENTENCE RHYTHM / CONTRAST → WORDING`.

## Final synthesis
The durable value of *Scene & Structure* is not a rigid `Goal–Conflict–Disaster / Emotion–Thought–Decision–Action` formula. Its durable value is disciplined tracking of causal state, scene outcome direction, processing, offstage causality, reader-time allocation and structural continuity.

Use the framework as a diagnostic map. Do not let the map dictate sentence length, force negative outcomes, require villains, or override evidence/personhood/canon.
