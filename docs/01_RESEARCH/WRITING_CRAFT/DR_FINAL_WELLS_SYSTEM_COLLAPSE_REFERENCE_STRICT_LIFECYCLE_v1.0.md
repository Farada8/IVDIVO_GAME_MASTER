## 2. Functional structure map

This map records narrative function rather than retelling plot.

### Phase A — impaired but functional operator
The protagonist begins under post-trauma constraints while remaining operationally competent. The book establishes that psychological injury can alter attention, memory confidence and processing without converting the person into an incompetent plot device.

### Phase B — political / epistemic problem expands
The colony problem cannot be reduced to a rescue logistics task. Records, colonist reports, sensor limits, institutional agendas and an unlisted second population alter the model of what rescue even means.

### Phase C — distributed search and model revision
Different agents contribute nonfungible evidence: historical records, local memory, sensor access, geospatial inference, system intelligence, embodied security perception and political context. No one character owns the whole answer.

### Phase D — control, personhood and consent collide
Questions of governor modules, emancipating other SecUnits, institutional coercion and colonist choice become operational rather than philosophical. The story repeatedly separates the ability to alter another agent from the legitimacy of choosing for them.

### Phase E — persuasion becomes an evidence problem
Raw facts alone are insufficient for an isolated audience with a different trust model. A persuasive narrative artifact is built, but its emotional/narrative layer remains linked to source materials and provenance rather than replacing them.

### Phase F — action under incomplete evidence
Technical and political interventions create new couplings. Cooperation, betrayal, internal institutional factions, alien/precorporate hazards and nonhuman choices reshape the option space.

### Phase G — local closure, open ontology
The immediate colony/governance problem reaches a bounded resolution with plural choices by affected groups. Trauma remains real but not totalizing. Alien-remnant ontology is not converted into a final explanatory lecture.

## 3. High-value mechanisms

### M1 — Trauma without automatic incompetence
`IMPAIRMENT / TRAUMA → SPECIFIC FUNCTIONAL CONSTRAINT → ADAPTATION / SUPPORT → COMPETENCE UNDER PRESSURE → SELF-KNOWLEDGE → NEXT RESPONSIBILITY`

Use: characters may remain capable while carrying real recovery limits.

Reject:
- trauma = incompetence;
- recovery = personality replacement;
- one therapeutic insight = cure;
- suffering as the only proof of depth.

### M2 — Personhood is not humanity
`OWN WANT → OWN MODEL / EVIDENCE → OWN RELATIONSHIPS → CONSENT / REFUSAL → CHOICE → CONSEQUENCE`

Murderbot, ART/PERI, AdaCol2 and other nonhuman agents do not share one generic AI psychology or voice. Different embodiment, information bandwidth, obligations and relationships produce different tactics.

Gate:
`PERSONHOOD ≠ HUMAN-LIKENESS`.

### M3 — Controlled action is not motive
`ACTION → CONTROL PROVENANCE → AVAILABLE CHOICE → MOTIVE HYPOTHESES → RESPONSIBILITY STATUS`

This is essential whenever a person or artificial person acts under embedded control, compulsion, institutional coercion or corrupted command architecture.

### M4 — Capability to free does not equal right to force freedom
The protagonist can provide another controlled agent with a route to disable control, but cannot know in advance what that person will choose afterward.

Operational form:
`FREEDOM-ENABLING CAPABILITY → OPTION CREATED → INFORMED AGENT CHOOSES → HERO ACCEPTS REFUSAL / DIFFERENT PATH`.

Reject:
- emancipation as remote control by the liberator;
- liberated person must join the hero;
- one prior case predicts all future agents.

### M5 — Trust requires multiple observations under different pressure
`OBSERVATION → DECISION UNDER PRESSURE A → DECISION UNDER PRESSURE B → CONTRADICTION / CONSISTENCY → TRUST UPDATE`

One helpful gesture does not prove loyalty or motive.

### M6 — Distributed complementary intelligence
`AGENT A HOLDS TRACE → AGENT B HOLDS CONTEXT → AGENT C HOLDS TOOL / ACCESS → AGENT D HOLDS LIVED KNOWLEDGE → COUNTERMODEL → BOUNDED DECISION OWNER`

This prevents protagonist-omniscience while preserving ONE MAIN STORY.

### M7 — Unknown cause requires alternative models
`TRACE / EFFECT → MODEL A / B / C → DISCRIMINATING TEST → STATUS UPDATE → ACTION`

Important distinction:
`DANGEROUS EFFECT ≠ HOSTILE INTENT`.

An alien/precorporate remnant may be harmful without being an intentional villain.

### M8 — Speech has a real audience, not merely an interlocutor
`VISIBLE CONVERSATION → REAL TARGET AUDIENCE → RHETORICAL TACTIC → AUDIENCE MODEL → CONSEQUENCE`

Gate for negotiations, hearings, streamed meetings and public institutional scenes:
`WHO IS THIS SPEECH REALLY FOR?`

### M9 — Persuasion layer and evidence layer must remain separate
The novel provides a strong mechanism for communicating complex truth to an audience that does not trust raw official data.

`FACTS / SOURCES → SELECTION → NARRATIVE MODEL → EMOTIONAL LEGIBILITY → SOURCE PACKAGE / TRACEABILITY → AUDIENCE MODEL UPDATE`

Production firewall:
`STORY MAY EXPLAIN FACTS; STORY MUST NOT REPLACE FACTS`.

This is directly useful for mystery, institutional SF, public evidence and ROOM 917 marketing/storytelling distinctions.

### M10 — Decision-owner legitimacy
`BENEVOLENT INTENT ≠ LEGITIMATE DECISION OWNERSHIP`.

Helping, protecting or being technically right does not grant the right to choose another conscious agent's future.

Resolution pattern:
`EVIDENCE / SUPPORT → OPTION SPACE EXPANDS → AFFECTED AGENT CHOOSES → CONSEQUENCE`.

### M11 — Institutions are not single minds
`INSTITUTION → INTERNAL INCENTIVES / FACTIONS → DIFFERENT BEHAVIOR → ALLIANCES MAY SHIFT WITHOUT MORAL CONVERSION`.

This protects IVDIVO from cardboard evil institutions and equally cardboard benevolent institutions.

### M12 — Success can create the next problem
`COMPETENT SUCCESS → MORE ACCESS / TRUST / RESPONSIBILITY → NEW COUPLING → HARDER NEXT CHOICE`.

This is superior to failure-monoculture for competent YA/SF characters.

### M13 — Embodiment changes affordances, not personhood
`EMBODIMENT / INSTANCE LIMIT → INFORMATION BANDWIDTH + PHYSICAL AFFORDANCES + RISK → TACTIC`.

An instance with reduced processing/access remains the same person if continuity is otherwise maintained; different body/system limits alter available actions rather than conferring greater or lesser personhood.

### M14 — Subjective memory requires provenance
`SUBJECTIVE MEMORY → EXTERNAL LOG / TRACE → COMPARISON → CONFIDENCE STATUS`.

Important dual truth:
- false memory content is not world fact;
- distress caused by the memory can still be real.

### M15 — Emotional interpretation is not emotional identity
`MODEL OF HUMAN EMOTION ≠ HAVING HUMAN EMOTION`.

Understanding human culture through stories/data does not mean a nonhuman mind has become human.

### M16 — Local closure with proof ceiling
`LOCAL PROBLEM RESOLVED → AFFECTED AGENTS RETAIN CHOICE → AFTERMATH → CHANGED CAPACITY / SELF-KNOWLEDGE → NEXT VECTOR`.

The book closes a colony/political/rescue problem without resolving every question about alien remnants or trauma.

## 5. Cross-source comparison

### Artificial Condition
Strong continuity: autonomy is not fulfilled by merely removing a control mechanism. *System Collapse* extends this into plural post-control choices and the refusal to assume all emancipated agents choose the same life.

### Andy Weir — Project Hail Mary
Both support complementary distributed competence and evidence-driven model revision. Wells adds stronger consent, institutional and control-provenance layers.

### Crouch — Dark Matter / Recursion
Crouch contributes decision-owner legitimacy, identity/memory provenance and intervention blast radius. Wells adds controlled-agent responsibility, emancipation without ownership and nonhuman peer relationships.

### Herman / Zunshine
Wells provides a fiction laboratory for their distinction between behavior, reason, source, interpretation and world fact. The novel is especially useful for showing how records, reports, sensors and memories can disagree without collapsing into arbitrary unreliability.

### Baxter / McKee Dialogue
Wells adds hidden-audience negotiation: a dialogue scene may be strategically aimed at observers rather than the named interlocutor.

### Swain / Bell / Rosenfeld
The book repeatedly supports `success → increased responsibility` rather than setback monoculture, and it uses processing/reaction without making every unit a formal scene-sequel metronome.

## 6. IVDIVO operationalization

### A. B07 — THE UNLISTED CITY
Once the distributed nonhuman life crosses a personhood threshold:

1. Humans may establish safety and preserve option space.
2. Humans may present evidence, risks and viable alternatives.
3. Humans may not replace the entity's decision merely because they can technically preserve it.
4. The entity must own at least one outcome-critical choice.
5. A human procedure is not legitimate merely because it is neutral among human claimants.
6. A strange pattern is not enough to prove motive or personhood; evidence must cross a defined threshold.
7. Once personhood is sufficiently established, continuing to treat the entity as an object becomes its own ethical/causal error.

Required climax architecture:
`HUMAN EVIDENCE → PERSONHOOD THRESHOLD → ENTITY'S OWN MODEL / PREFERENCE → CONSENT / REFUSAL → HUMAN OPTION SPACE CHANGES → BOUNDED ACCOUNTABLE DECISION`.

### B. Orbital Youth
Every named conscious robot/nonhuman should pass:
`OWN WANT → OWN MODEL → OWN RELATIONSHIPS → REFUSAL RIGHT → CHOICE → CONSEQUENCE`.

Different bodies / instances / bandwidths alter tactics but never become a hidden hierarchy of moral worth.

Youth competence gate:
`REAL SUCCESS → GREATER TRUST / RESPONSIBILITY → HARDER NEXT CHOICE` is protected from forced-error rewrites.

### C. Consciousness-practice schools
The novel is fiction and offers no evidence for IVDIVO metaphysics.

Preserve:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → ONTOLOGY CEILING`.

Additionally:
`SUBJECTIVE MEMORY / INNER EXPERIENCE ≠ EXTERNAL WORLD FACT`.

A lived experience can be psychologically real and narratively important while its causal/metaphysical explanation remains uncertain.

### D. Mystery / evidence architecture
Use a provenance ledger with at least:
- observed trace;
- reporter/source;
- sensor/log status;
- memory status;
- current interpretation;
- competing interpretation;
- confidence level;
- next discriminating test.

Narrative persuasion may simplify and humanize the evidence, but should preserve an underlying source package.

### E. Institutional conflict
Do not write `institution = one mind`.
Track:
- formal policy;
- operational actor;
- private incentive;
- faction;
- who controls information;
- who can refuse;
- who bears consequences;
- who can appeal.

### F. Style and line editing
Do not import Murderbot's sardonic / fragment-heavy voice into IVDIVO house prose.

Protected repair order:
`BOOK ENGINE → SCENE NECESSITY → ORDER / DURATION / FREQUENCY → POV / EVIDENCE → SHOW / TELL → DIALOGUE / SUBTEXT → PARAGRAPH / READER-STATE → SENTENCE RHYTHM → WORDING`.

Action and suspense are not measured by fragment density.
