# PRIMARY SYNTHESIS
The first ten tools are strongest when treated as **effect controls**, not grammar laws:

`MEANING / AGENCY → SENTENCE SPINE → EMPHASIS → VERB/VOICE → MODIFIERS → ASPECT → LENGTH → PATTERN → PUNCTUATION → SELECTION`.

# B77 PRODUCTION GATES
## B77-G01 — Tools After Discovery
Do not make 100 specialists police each generative sentence. Use tools in targeted revision passes after live material exists.

## B77-G02 — Sentence Spine
When clarity is failing, identify the grammatical spine:
`WHO/WHAT → DOES/IS WHAT`.
Move key actor/action earlier unless deliberate delay earns suspense or discovery.

## B77-G03 — Emphasis Position
Test sentence/paragraph beginning and ending for the intended emphasis. Do not engineer every end as a slogan.

## B77-G04 — Agency Verb Gate
Prefer verbs that expose actor/action when agency matters.

## B77-G05 — Passive Agency Audit
Passive is valid when receiver/focus matters. In institutions, inspect whether passive accidentally hides responsibility.

## B77-G06 — Modifier Information Test
Keep adverb/modifier if it adds contradiction, precision, attitude or information not already encoded by the verb/adjective.

## B77-G07 — Aspect Choice
Simple vs progressive forms are effect choices. Do not mechanically delete `-ing` words.

## B77-G08 — Long Sentence Permission
A long sentence is allowed and often desirable when it carries a coherent journey: chronology, accumulation, technical thought, perception, embarrassment, pressure or emotional layering.

## B77-G09 — Length Contrast
Shortness gains force from surrounding variation. Permanent shortness destroys contrast.

## B77-G10 — Pattern / Twist
Create recognizable syntax/rhythm/repetition, then vary it intentionally to create emphasis or altered meaning.

## B77-G11 — Punctuation Function
Treat punctuation as grouping/rhythm/voice, not a fixed speed formula.

## B77-G12 — Cut Big Before Small
Revision priority:
`REMOVE WRONG SCENE/BLOCK → REMOVE REDUNDANT PARAGRAPH → REMOVE REDUNDANT SENTENCE → REMOVE WORD`.
Never substitute word tightening for structural deletion.

# IVDIVO APPLICATION
## Anti-fragmentation
Before line editing:
`SCENE/MODE → PARAGRAPH UNIT → SENTENCE SPINE → LENGTH CONTRAST → PUNCTUATION → DICTION`.

Diagnostic for a fragment-heavy passage:
- Is the fragment a real beat/change?
- Does it need isolation for emphasis?
- Is it only one shard of the same thought?
- Would one longer sentence better represent continuous perception/thought?
- Is the real problem an unnecessary micro-scene?

## Post-money institutions
Audit passive constructions such as:
`was assigned / was allocated / was denied / was approved / was rerouted`.
Determine whether the missing actor is intentionally unknown, structurally distributed, or merely hidden by bureaucratic prose.

## YA / Orbital Youth
Competent adolescent cognition should not be reduced to clipped dialogue and fragments. Technical focus, fascination, social anxiety and complex observation may legitimately lengthen sentences.

## Robot personhood
No generic syntax template for conscious robots. Grammar follows individual cognition/relationship/tactic, not species stereotype.

# FIREWALLS
- active voice is not universally superior;
- adverbs are not banned;
- `-ing` forms are not banned;
- long sentences are not defects;
- short sentences are not inherently tense;
- punctuation is not a mechanical BPM control;
- tools are not applied simultaneously during generation.
