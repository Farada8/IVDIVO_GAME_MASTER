# IVDIVO CRAFT STUDY — BATCH 204
## James Scott Bell — Process · Tactics · Adaptive Planning · Feedback

**Source:** *The Art of War for Writers* (2009)  
**Source lifecycle:** STRICT COMPLETE / SYNTHESIZED  
**Class:** WIDER

## Core synthesis

Bell's most useful contribution is a practical separation between **generating story material** and **evaluating it**. The war metaphor is disposable; the operating distinction is not.

### B204-G01 — Generate Hot / Diagnose Cool
`DISCOVERY → DISTANCE → DIAGNOSIS → REVISION → POLISH`.

Do not require raw prose to satisfy every specialist gate while it is being generated.

### B204-G02 — Exercise Output Is Discovery
Voice journals, randomized words, alternate openings, second-right-answer lists and free dialogue may reveal useful material.

`EXERCISE OUTPUT ≠ CANON`.

### B204-G03 — Variant Materiality
A meaningful alternative must change at least one causal variable: decision owner, want, evidence, relationship pressure, world constraint, tactic, cost or exit state.

### B204-G04 — Plan Is Hypothesis
Bell explicitly validates outline/no-outline/hybrid processes.

`PLAN → LIVE TEXT → CHARACTER/CANON/CAUSALITY TEST → REPLAN / KEEP / BANK / DISCARD`.

### B204-G05 — Scene Bull's-Eye
A real-time scene must have a load-bearing reason to exist.

`SCENE → WHAT CHANGED THAT COULD NOT BE CHEAPLY SUMMARIZED?`

Accepted answers include decision, evidence-status, consent, relationship terms, authority/access, model revision, earned success and other downstream-relevant changed states.

### B204-G06 — Progressive Revelation Fairness
`TRUE FACT / TRACE → PARTIAL MODEL → NEW EVIDENCE → MODEL UPDATE`.

Do not hide information already known to the active close POV solely to manufacture surprise.

### B204-G07 — Dialogue as Tactic
`WANT → VERBAL/NONVERBAL TACTIC → LISTENER RESPONSE → TACTIC/MODEL UPDATE → CHANGED STATE`.

### B204-G08 — Dialogue Mode Router
Exact wording gets reader-time when wording itself matters. Routine conversation, process and low-value exchange may be summarized or rendered indirectly.

### B204-G09 — RUE as Redundancy Audit
`ACTION / CONTEXT ALREADY MADE MEANING LEGIBLE → DO NOT EXPLAIN IT AGAIN`.

RUE does not ban telling, summary, indirect dialogue or direct thought.

### B204-G10 — Feedback-to-Diagnosis
`READER EFFECT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES → RETEST`.

### B204-G11 — Writer-State Separation
Anxiety, envy, fatigue, slow production and rejection are process-state information.

`WRITER STATE ≠ MANUSCRIPT DEFECT`.

### B204-G12 — Fast Draft / Final Prose Firewall
`FAST DRAFT ≠ CHOPPY FINAL PROSE`.

Production speed is not sentence style.

### B204-G13 — Compression Without Chopping
`DELETE REPEATED MEANING → SUMMARY ROUTINE PROCESS → INDIRECT LOW-VALUE DIALOGUE → MERGE MICROBEATS → RETEST RHYTHM`.

### B204-G14 — Process Metric Firewall
Word quota, daily schedule, scene count, outline length and promotion output are process metrics.

`PROCESS METRIC ≠ STORY QUALITY`.

## Rejected / constrained prescriptions
- mandatory physical/professional/psychological death stakes;
- mandatory hero-villain geometry;
- mandatory climactic battle;
- mandatory wound/brokenness/redemption arc;
- mandatory opening disturbance;
- mandatory conflict in every conversation;
- mandatory conflict+emotion+surprise trio for every high-value scene;
- categorical dream/weather opening bans;
- 2009-era agent/query/platform/submission rules as current market facts.

## Cross-source convergence

Bell strongly converges with:
- **Lamott / LaPlante / Swain / Le Guin:** generation before criticism;
- **Seger / Mayer:** actual text outranks old plan during diagnosis;
- **Scofield / Rosenfeld / Bickham:** scene reader-time requires function/change;
- **McKee Dialogue / Chiarella / Baxter:** dialogue is strategic interaction, not transcript;
- **Le Guin / Prose / Hodgins / Williams-Bizup:** short syntax is a contrast tool, not a pace KPI;
- **Zunshine / Genette / le Carré / Ephron:** revelation must preserve evidence/source/knowledge fairness.

## IVDIVO standing laws reinforced
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

`ONE MAIN STORY ≠ ONE HERO DOES EVERYTHING`.

`ACTION / SUSPENSE / MYSTERY / EMOTION ≠ SHORT-SENTENCE DENSITY`.

`BEAT ≠ SENTENCE BREAK`.

`COMPRESSION ≠ CHOPPING`.

`PLAN ≠ ACTUAL TEXT ≠ CANON ≠ EVIDENCE STATUS`.

`READER EFFECT = EVIDENCE; REPAIR PROPOSAL = HYPOTHESIS`.
