## Highest-value new mechanisms
1. `SPEAKER INTENTION ≠ LISTENER DECODING ≠ READER DECODING`.
2. `WORDPLAY = RELATIONAL INFERENCE MECHANISM` when it changes affiliation/status/character/theme/tension/reader model.
3. Shared linguistic/cultural ground is required for fair decoding.
4. Character-owned humour/wordplay is preferred over universal authorial wit.
5. Wordplay/association/homophony/sarcasm can generate a hypothesis or stance, **not corroboration**.
6. Hidden/ambiguous wordplay needs an interpretive stopping rule.
7. Translation/audio adaptation should preserve function and relationship effect while protecting load-bearing clue wording/evidence status.
8. `WORDPLAY BEAT ≠ SENTENCE BREAK`; excessive fragmentation can destroy the context needed to decode the line.
