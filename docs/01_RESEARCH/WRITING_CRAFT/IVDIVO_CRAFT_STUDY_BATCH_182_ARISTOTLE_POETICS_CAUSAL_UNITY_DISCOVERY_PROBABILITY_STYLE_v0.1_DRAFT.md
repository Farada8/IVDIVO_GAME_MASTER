# IVDIVO CRAFT STUDY — BATCH 182
## Aristotle — *Poetics* — causal unity · discovery · probability · style · detective crosswalk

Status: `SYNTHESIZED SOURCE APPLICATION / PRODUCTION GATES`

## Executive finding
The durable value of *Poetics* for IVDIVO is **not** a universal three-act/tragedy template. It is a set of early, still-useful causal distinctions:

`AFTER ≠ BECAUSE`

`ONE HERO ≠ ONE STORY`

`DISCOVERY SHOULD GROW FROM PRIOR EVENTS`

`RESOLUTION SHOULD ISSUE FROM THE STORY ITSELF`

`CLEAR BASE + CONTROLLED DEVIATION > FLATNESS OR ORNAMENT MONOCULTURE`

Dorothy L. Sayers' appended detective-fiction lecture makes the mystery transfer explicit, but modern IVDIVO strengthens it with evidence provenance, source independence and consent/personhood gates.

## 1. Unified action
Aristotle's strongest transferable claim is that unity does not come from following one person. A person experiences many unrelated events. Unity comes from a connected action whose parts affect the whole.

### IVDIVO gate
For every major strand:
`LOCAL EVENT → CHANGED STATE → EFFECT ON DOMINANT ENGINE → LATER PAYOFF / CONVERGENCE`.

If a strand can be removed without changing the main problem, a later choice, a relationship/evidence state or the ending, it needs a documented satellite function or compression/removal.

## 2. Causal dependency
Aristotle's distinction between something happening **after** previous events and **because of** them is central.

### Audit
For each adjacent major beat:
1. What state did A change?
2. What new option/constraint/evidence/relationship did that create?
3. Why does B happen differently because A occurred?
4. If A vanished, would B materially change?

If not, the sequence may be episodic.

## 3. Scale
A story should be graspable as a whole.

### IVDIVO translation
`SAGA SCALE ≠ BOOK SCALE`.

The saga may contain civilizations, centuries and multiple ontologies. A book chooses one dominant causal problem and exposes only the world material necessary to experience and resolve it.

## 4. Surprise with consequence
High-value surprise:
`TRUE SETUP → PLAUSIBLE EXPECTATION → CONSEQUENT EVENT / REVEAL → MODEL REVISION`.

Low-value surprise:
`UNSEEDED INTERRUPTION → SHOCK → NEW STORY`.

The former changes the meaning of earlier material without falsifying it.

## 5. Discovery architecture
Aristotle ranks recognitions emerging from the course of events above arbitrary tokens or author declaration.

### Modern IVDIVO version
`TRACE → SOURCE / LINEAGE → ACCESS → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING TEST → DISCOVERY → ACTION`.

A badge, scar, file, phrase or symbol is not load-bearing evidence merely because the author announces that it is.

## 6. No deus ex machina
The central problem should be resolved by already established causal resources.

### Failure test
Before climax resolution ask:
- Was this technology/rule/person/authority introduced or inferable earlier?
- Did protagonists earn access to it?
- Does its use create a cost/constraint already established?
- Would the book collapse if the mechanism were removed?

If the answer reveals a late convenience, rebuild upstream.

## 7. Character choice
Aristotle usefully associates character with meaningful selection/rejection, but his moral hierarchy is historical and rejected.

### IVDIVO character model
`VALUE A + VALUE B + RELATIONSHIP + KNOWLEDGE + CURRENT COST → PRIORITY NOW → TACTIC / CHOICE`.

This supports `CONSISTENTLY INCONSISTENT`: apparent contradiction can be character-true when competing values/context explain it.

## 8. Plot vs character — cross-source correction
Aristotle puts plot before character. IVDIVO does not retain this as a universal hierarchy.

- Aristotle: causal action is the skeleton.
- Card/Corbett/McKee Character: person-specific behavior and relationships generate choices.
- Herman/Zunshine: reasons and models are inferred, not mechanically known.

### IVDIVO synthesis
`PERSON MODEL ↔ CHOICE ↔ WORLD RESPONSE ↔ UPDATED PERSON/RELATION MODEL`.

No plot puppet; no character dossier without causal action.

## 9. Style
Aristotle's useful stylistic polarity is clarity vs unusual/elevated expression. He recommends mixture and appropriateness.

### IVDIVO style gate
`CLEAR BASE → SELECTIVE DEVIATION → CONTRAST / EMPHASIS`.

Reject:
- every sentence made figurative;
- technical jargon as prestige;
- short syntax as default energy;
- metaphor used as factual evidence.

## 10. Metaphor
Aristotle values seeing similarity. For IVDIVO:

`PARTICULAR A → RELATION TO B → METAPHOR → READER MODEL / EMOTIONAL EFFECT`.

But:
`METAPHOR / ANALOGY → HYPOTHESIS GENERATOR`, not `CORROBORATION`.

This is critical for consciousness-school and mystery material.

## 11. Epic / ensemble
Narrative mode permits simultaneous incidents and variety, provided they are germane to the issue.

### Ensemble gate
`STRAND OWNER → LOCAL WANT → UNIQUE INFORMATION/ACTION/RELATION FUNCTION → MAIN ENGINE EFFECT`.

Meeting in the same room is not convergence. One strand must change another strand's option space or the main engine.

## 12. Sayers / mystery paralogism
Sayers highlights Aristotle's false-inference pattern.

Modern fair version:
`TRUE CONSEQUENT B → READER INFERS CAUSE A → LATER EVIDENCE SHOWS CAUSE C`.

### Fair-play constraints
- B must remain literally true after reveal.
- A must have been genuinely plausible.
- C must have retrospective support.
- no narrator lie;
- no POV fact secretly withheld if POV already knows it solely for surprise;
- evidence provenance remains stable.

## 13. Detective-character reveal
Surprising culprit/identity must remain retrospectively believable.

`SURPRISE + EARLIER BEHAVIOR SUPPORT + ACCESS/OPPORTUNITY + MOTIVE EVIDENCE + NO CHARACTER RETCON`.

Behavior alone is still not motive proof.

## 14. Historical / philosophical firewalls
Do not operationalize as IVDIVO law:
- women/slaves/social-rank hierarchy;
- tragic hero formula;
- mandatory fall/unhappy ending;
- pity/fear as universal reader effect;
- tragedy superiority;
- catharsis as clinical psychology;
- Sidney/Shelley moral universals;
- Sayers' requirement that detective fiction close every possible loose end;
- ancient metre/grammar as prose style rules.

## 17. Anti-choppiness application
Aristotle's style logic is mixture, clarity and appropriateness—not fragment density.

Standing law:
`ACTION / SUSPENSE / DISCOVERY / EMOTION ≠ SHORT-SENTENCE DENSITY`.

Repair order:
`BOOK ENGINE → UNIFIED ACTION → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → PARAGRAPH/READER-STATE → SENTENCE RHYTHM/CONTRAST → WORDING`.
