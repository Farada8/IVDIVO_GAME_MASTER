## Early mechanisms — provisional
### A. Reader respect / no condescension
Bickham argues against writing down to readers or using erudition as display.

IVDIVO adaptation:
`COMPLEX IDEA -> CHARACTER-RELEVANT FORM -> LEGIBLE LANGUAGE -> READER MODEL`

### B. Technical knowledge must serve story
Specialist knowledge is useful when it changes current understanding/action, not when inserted to prove author expertise.

### C. Opening as meaningful change
Bickham frames story openings around threat/change. IVDIVO rejects mandatory threat but retains the useful core:
`ESTABLISHED STATE -> MEANINGFUL CHANGE / RESPONSIBILITY / OPPORTUNITY -> CHARACTER RESPONSE -> FORWARD QUESTION`.

### D. Description pacing is mode selection
Bickham's delivery-system discussion distinguishes exposition, description, narrative, dialogue and dramatic summary by pace/function.

IVDIVO adaptation:
`READER EFFECT -> NARRATIVE MODE -> DURATION -> PARAGRAPH/SENTENCE RHYTHM`.

This strongly supports the anti-choppiness rule that pacing should not be optimized through short-sentence percentage.

### E. Description is legitimate when causally loaded
Bickham's sunset example works because the changing light is itself part of the threat/timing system. Thus:
`DETAIL / DESCRIPTION -> WHAT STORY VARIABLE DOES IT CHANGE?`
