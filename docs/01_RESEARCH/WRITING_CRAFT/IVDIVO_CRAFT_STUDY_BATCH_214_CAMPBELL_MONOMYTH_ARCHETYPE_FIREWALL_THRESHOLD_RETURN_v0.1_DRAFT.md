# IVDIVO CRAFT STUDY — BATCH 214
## Campbell — Monomyth · Threshold · Return · Archetype Firewall

**Source:** Joseph Campbell — *The Hero with a Thousand Faces*  
**Status:** manuscript-facing synthesis from strict full read

## Production mechanisms

### B214-G01 — Causal spine before mythic pattern
`ACTUAL CAUSAL SPINE → PATTERN SIGNATURE → OPTIONAL COMPARISON`.
Do not choose a monomyth stage first and manufacture a scene to satisfy it.

### B214-G02 — Pattern falsification
For every archetypal reading ask:
`WHAT OBSERVATION WOULD MAKE THIS READING WRONG?`
If no answer exists, the pattern is interpretive decoration, not a diagnostic.

### B214-G03 — Threshold means new option space
A threshold requires a material change in access, responsibility, evidence, rules, relationships, consent, or future options. A new location alone is insufficient.

### B214-G04 — Trial differentiation
Successive tests must alter different variables or demand different tactics. Louder repetition is not progression.

### B214-G05 — Return must pay
After a central discovery/gain, test what changes in relationships, institutions, responsibility, or action. No mandatory literal homecoming or elixir.

### B214-G06 — In-world cosmology is sourced belief
`OFFICIAL MYTH / SCHOOL DOCTRINE / RITUAL MODEL ≠ WORLD FACT`.
A culture may canonically believe a cosmology that is partly or wholly wrong.

### B214-G07 — Mythic analogy is not evidence
`SYMBOL / ARCHETYPE / PARALLEL → HYPOTHESIS`, never automatic corroboration.

### B214-G08 — Initiation ethics
`TRIAL / INITIATION ≠ ETHICAL LEGITIMACY`.
Training systems still require consent, proportionality, welfare, information, appeal, reversibility where appropriate, and clear decision ownership.

### B214-G09 — Personhood outranks archetype
`BOOK ROLE / ARCHETYPE ≠ STORYWORLD PERSONHOOD`.
Nonhuman persons are not monsters, shadows, mentors, prizes, or helpers by essence.

### B214-G10 — Nonhuman embodiment firewall
`NONHUMAN EMBODIMENT ≠ MONSTER ≠ MORAL INCOMPLETENESS`.

### B214-G11 — Gender-archetype firewall
Do not use Goddess / Temptress / masculine-feminine complementarity as universal psychology. Relationship causality must arise from independent agents and current choices.

### B214-G12 — Archetypal resonance is not ontology
`EMOTIONAL / SYMBOLIC RESONANCE ≠ PSYCHOLOGY ≠ SCIENCE ≠ IVDIVO ONTOLOGY`.

### B214-G13 — ONE MAIN STORY payment
Multiple journeys/functions are allowed only if they causally change the same dominant book engine and produce downstream dependency/payoff.

### B214-G14 — Stage is not typography
`THRESHOLD / ORDEAL / RECOGNITION / RETURN ≠ CHAPTER BREAK ≠ PARAGRAPH BREAK ≠ SENTENCE BREAK`.

## Strong salvage
- transition / threshold thinking;
- differentiated trials;
- private gain becoming social/relational consequence;
- myths as storyworld institutions and cultural models;
- comparison across distant narrative traditions;
- recurring image / ritual as functional storyworld infrastructure.

## Rejected as universal production laws
- one monomyth as the natural structure of all stories;
- omitted stages are always implied;
- Jung/Freud claims as current psychology;
- collective unconscious as scientific fact;
- universal mother/father or sexual symbolism;
- Meeting with Goddess / Woman as Temptress as required stages;
- male/female union as universal completeness;
- ritual ordeal as morally legitimizing;
- spiritual identity with the cosmos as world fact;
- monster imagery as valid ontology for nonhuman beings.

## Cross-source convergence
Campbell is strongest when used beneath causal/evidence systems established by Truby, Bickham, Chatman, Genette, Zunshine, Herman, Card, Wolf, Vogler and Booker. Pattern vocabulary is secondary. Causal state, source provenance, consent and personhood remain authoritative.
