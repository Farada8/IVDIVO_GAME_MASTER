## Highest-value retained mechanisms
### M1 — Given Circumstances / Action / Adaptation
`GIVEN CIRCUMSTANCES + IF → PRESENT TASK / ACTION → PARTNER / WORLD RESPONSE → ADAPTATION → CHANGED STATE`.

For fiction this is a stronger scene engine than emotion-first writing: circumstances, present want and actual response generate the next tactic.

### M2 — Action Before Manufactured Emotion
`CIRCUMSTANCE / TASK / PARTNER / PHYSICAL ACTION → STATE / FEELING MAY EMERGE`.

Feelings cannot reliably be forced directly. Emotion Memory is ancillary/optional rather than required authenticity.

### M3 — Task / Objective as Active Question
A task should be concrete, immediate, active and genuinely compelling.

IVDIVO translation:
`PRESENT WANT / ACTIONABLE QUESTION → TACTIC → RESPONSE → ADAPTATION`.

Agency includes deciding, testing, refusing, waiting for evidence, cooperating or deliberately not intervening.

### M4 — Bits Are Analytic, Not Final Form
`BREAKDOWN FOR ANALYSIS → RECOMBINE FOR LIFE`.

Bits/tasks are rehearsal-analysis units. They must reconnect into an unbroken living line.

IVDIVO:
`BEAT MAP ≠ FINAL PROSE`; `BEAT ≠ SENTENCE BREAK`.

### M5 — Throughaction / ONE MAIN STORY Salvage
`LOCAL TASKS → COMMON CAUSAL DIRECTION → WHOLE EXPERIENCE`.

Beautiful local fragments can still fail if they do not connect into an intelligible whole.

IVDIVO translation:
`ONE MAIN STORY = COMMON CAUSAL DIRECTION / DEPENDENCY`, not merely a collection of individually good scenes.

### M6 — Adaptation
The same goal under different partner/context responses must change tactic.

`WANT → PARTNER RESPONSE → TACTIC UPDATE`.

Repeated external form without changed circumstances becomes mechanical.

### M7 — Partner Before Audience
Communication is directed to the partner/object within the circumstances, not performed generically for the audience.

Dialogue gate:
`LINE / TACTIC → ACTUAL LISTENER RESPONSE → MODEL UPDATE → NEXT TACTIC`.

Characters should not lecture the reader through each other.

### M8 — Emotion Memory Firewall
`PERSONAL MEMORY = OPTIONAL INPUT, NOT REQUIRED AUTHENTICITY`.

Safer/stronger routes include given circumstances, imagination, observation, analogous experience, partner response, physical action and environment.

### M9 — Inner / Outer Rhythm Separation
`INNER PROCESS SPEED ≠ OUTER MOTION SPEED ≠ SENTENCE LENGTH`.

A nearly motionless character may process rapidly; fast action may be internally methodical.

### M10 — Speech Grouping / Anti-Choppiness
Within a coherent verbal unit, Stanislavski warns against spitting words into disconnected bits. Long language should be grouped logically, not mechanically chopped.

IVDIVO:
`RELATED MICROBEATS → COHERENT UNIT`.
`PAUSE / BREAK MUST HAVE FUNCTION`.

### M11 — Psychological Pause
A pause can carry meaning but overuse creates messy, extended performance; underuse can make speech arid.

Prose translation:
`ONE-LINE PARAGRAPH / DASH / ELLIPSIS / FRAGMENT → FUNCTION REQUIRED`.

### M12 — Perspective / Emphasis Hierarchy
Not every word, clause, episode or event receives equal stress.

`READER-TIME / EMPHASIS HIERARCHY` should match story importance.

### M13 — Logic / Sequence Then Automaticity
Detailed analysis may initially make action feel less natural. Once causality is understood, technique should recede from conscious performance.

`ANALYZE → INTEGRATE → LET FRAMEWORK DISAPPEAR`.

### M14 — General Creative State / Anti-Tool Worship
Attention-for-attention, adaptation-for-adaptation and action-for-action become dead technique.

IVDIVO:
`GATE-FOR-GATE / AGENT-FOR-AGENT = PROCESS FAILURE`.

### M15 — The System as Guide, Not Philosophy
Chapter 29 explicitly frames the system as reference/guide, not cookbook or philosophy, and says it should be put aside in live performance.

Production law:
`FRAMEWORK SHOULD DISAPPEAR INTO LIVE STORY`.

### M16 — Exercise Output Firewall
Training exercises generate material/skill; they do not create story canon.

`EXERCISE OUTPUT ≠ CANON`.

### M17 — Embodiment / Affordances
Body/voice/physical conditions alter available actions and social reading.

For nonhuman characters:
`EMBODIMENT → AFFORDANCES / LIMITS → SALIENCE → ACTION OPTIONS → SOCIAL RESPONSE → CHOICE`.

Embodiment is not humanization.

### M18 — Characterization Against Category
Stanislavski repeatedly rejects generic playing of social/type labels.

`CATEGORY / ROLE LABEL ≠ PERSON`.

### M19 — Polish After Coherence
Finishing touches should clarify a coherent living line; excessive external finish can obscure it.

`POLISH FOLLOWS COHERENCE`.

### M20 — Dependency / Ensemble Ethics
Theatre is a dependency system: one person's preparation affects the whole production.

IVDIVO production translation:
`ART AUTHORITY UPSTREAM + EXPLICIT DEPENDENCIES + ROLE ACCOUNTABILITY`.

## Historical / science / ontology firewalls
Reject as current science or universal human truth:
- outdated physiology/body prescriptions;
- gender/class/national stereotypes;
- quasi-mystical claims about subconscious transmission/reception;
- historical scientific vocabulary presented as modern evidence;
- actor-training claims as general psychology;
- one fixed interpretation of the System;
- Emotion Memory as mandatory authenticity;
- literal mind/feeling/will typologies as scientific ontology.

Smeliansky's afterword itself demonstrates that major Stanislavski successors modified or rejected pieces of the system: action/counteraction, arrhythmia, improvisatory rehearsal, alternative understandings of throughaction and task.

Therefore:
`HISTORICAL CRAFT SYSTEM ≠ CURRENT PSYCHOLOGY ≠ IVDIVO ONTOLOGY`.

## Failure modes
- **EMOTION-FIRST FORCING** — actor/character instructed to display result instead of pursuing a causal task.
- **RESULT-POSING** — playing theme, emotion or outcome rather than action/process.
- **MECHANICAL TASKING** — every line tagged with an action regardless of actual need.
- **BIT FRAGMENTATION** — analytic units remain visibly disconnected in final prose/performance.
- **THROUGHACTION DOGMA** — one conceptual line oversimplifies a complex story/character.
- **GATE-FOR-GATE** — technique exists for itself rather than solving observed defect.
- **AUDIENCE PERFORMANCE LEAK** — characters speak to impress/explain to reader rather than act on partner.
- **EMOTION-MEMORY MANDATE** — personal trauma mined as prerequisite authenticity.
- **MICROGESTURE CONFETTI** — action/feeling beats rendered as repetitive gestures between every line.
- **TEMPO = SENTENCE LENGTH** — inner/outer rhythm collapsed into short-sentence KPI.
- **PAUSE/FRAAGMENT MONOCULTURE** — punctuation/one-line paragraphs used as default intensity marker.
- **CATEGORY CHARACTERIZATION** — role, class, age, nationality, gender or body substitutes for person.
- **POLISH BEFORE LIFE** — line/performance finish applied before causal/action coherence.
- **SYSTEM AS SCRIPTURE** — training framework treated as universal law.
- **HISTORICAL SCIENCE LEAK** — outdated psychophysiology imported into world canon.

## Cross-source synthesis
### Gillett / Collins
Strong convergence on given circumstances, objectives, tactics, adaptation and the need to transform exercises into character-specific action.
Correction: Collins' broad Method/Emotion-Memory framing is narrowed by Benedetti/late-Stanislavski context.

### Swain / Bickham / Rosenfeld / Scofield
Convergence on causal action and processing.
Correction: analytic beats/tasks do not require visible micro-segmentation in final prose.

### Le Guin / Prose / Clark / Hodgins
Strong convergence on rhythm:
`ACTION / EMOTION ≠ SHORT-SENTENCE DENSITY`.
Long connected syntax may be more alive than a series of stop-start fragments.

### Bell / Lamott / LaPlante
Convergence on phase separation and anti-mechanical drafting:
`LIVE MATERIAL → DIAGNOSE → REPAIR`, not simultaneous checklist enforcement.

### Card / Corbett / McKee Character / Herman
Convergence on person-specific goals, relationships and choice under pressure.
Correction: role/type labels never substitute for personhood or motive evidence.

### Genette / Chatman / Zunshine
Knowledge/evidence remain separate from performer/character interpretation.
`BELIEF / EXPERIENCE / SELF-REPORT ≠ WORLD FACT`.

## IVDIVO operationalization
### Scene Action Card
`GIVEN CIRCUMSTANCES | PRESENT WANT/TASK | PARTNER/COUNTERFORCE/SUPPORT | TACTIC | RESPONSE | ADAPTATION | CHANGED STATE`.

### Dialogue Gate
Exact line remains real-time when wording changes trust, consent, evidence, authority, relationship terms, commitment or next tactic.

`CHARACTER TALKS TO PARTNER FOR A GOAL`, not to deliver author explanation.

### Beat-to-Prose Gate
Use beat/task analysis only to verify causality.
Then recombine:
`BEAT MAP → LOGIC / PACING AUDIT → NATURAL PARAGRAPH / PROSE`.

### Framework Automaticity Gate
Specialist/tool output that is not FATAL/MAJOR should not hijack live drafting.
`OBSERVED DEFECT → RELEVANT TOOL → REPAIR → RETEST`.

### Personhood Gate
For conscious robots/nonhuman agents:
`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Do not measure development by human gesture, human physiology or becoming more human.

### Evidence Firewall
`CHARACTER / ACTOR BELIEF → HYPOTHESIS`, not factual proof.

## Prose / anti-choppiness synthesis
Stanislavski provides unusually strong indirect support for prose continuity:
- coherent verbal units should not be spat into arbitrary pieces;
- pauses need function;
- tempo-rhythm is not mechanical meter;
- micro-actions are analyzed then recombined;
- excessive finish can become false.

Standing IVDIVO rule:
`BEAT / TASK / ACTION / PAUSE ≠ SENTENCE BREAK`.

Repair order:
`STORY / SCENE FUNCTION → NARRATIVE MODE → POV / EVIDENCE → PURPOSE / TACTIC → PARAGRAPH ARCHITECTURE → READER-STATE CONTINUITY → SENTENCE RHYTHM / CONTRAST → WORDING`.

## Final synthesis
Stanislavski is most valuable to IVDIVO as a **live causal-action and adaptation system** plus an explicit warning against turning technique into visible mechanism.

The deepest portable law is not “use the System.” It is:

`UNDERSTAND THE ACTION → TRAIN / ANALYZE THE PARTS → RECOMBINE THEM → LET THE FRAMEWORK DISAPPEAR INTO LIVING STORY`.
