## A. HIGH-VALUE MECHANISMS

### A1 — Public-value / actual-access divergence
An institution may publicly celebrate equality, contribution and safety while access, inherited status, stigma or informal exceptions produce a different lived system.

Gate:
`PUBLIC IDEAL → FORMAL RULE → EXCEPTIONS / INFORMAL INCENTIVES → BURDEN DISTRIBUTION → APPEAL / EXIT`.

This is stronger than writing the institution as a single hypocritical villain. Different layers can sincerely believe different versions of the institution.

### A2 — Stigma creates a preloaded audience model
`PAST PUBLIC NARRATIVE → PERSON/FAMILY MODEL → ACCESS / REPUTATION CONSEQUENCE → SELF-PRESENTATION / RESISTANCE`.

The protagonist may be forced to respond to an interpretation before anyone evaluates current individual evidence.

### A3 — Unfair access and real competence can coexist
Do not collapse class/status unfairness into incompetence.

`PRIVILEGED ACCESS + REAL SKILL` is often a stronger countermodel than `privileged fool`.

Corresponding firewall:
`COMPETENCE ≠ LEGITIMACY`.

### A4 — Embodied competence requires live testing
`DECLARED / THEORETICAL COMPETENCE → LIVE SENSORIMOTOR TEST → LIMIT → CHARACTER-SPECIFIC RESPONSE → TRAINING → UPDATED CAPABILITY MODEL`.

Useful for flying, EVA, unfamiliar gravity, tool use, interfaces, performance, medicine and other embodied orbital skills.

### A5 — Domain transfer must be causal and bounded
`PRIOR SKILL → NEW AFFORDANCE → TRANSFER CONDITION → SPECIFIC ADVANTAGE`.

A previous skill may become unexpectedly decisive, but it does not make the character universally capable.

### A6 — Dream ownership
`SHARED PREPARATION ≠ SHARED DESIRE`.

Friends, siblings, teams or cohorts may train together for years while wanting different lives. A person can discover after success that they do not want the successful path.

### A7 — Qualification does not consume future consent
`QUALIFIED → INFORMED EXPERIENCE → RENEW / WITHDRAW / MODIFY COMMITMENT`.

A successful exam, selection or trial does not create permanent obligation to continue.

### A8 — Partial institutional inclusion
`FORMAL MEMBERSHIP → CHECK ACTUAL ACCESS TO SPACE / TIME / INFORMATION / COMMUNITY / SUPPORT / DECISION RIGHTS`.

The title may be granted while daily belonging remains withheld.

### A9 — Formal safety / informal prestige split
`SAFE POLICY → PEER STATUS CODE → REPUTATIONAL PENALTY FOR SAFE BEHAVIOR → RISKIER ACTUAL PRACTICE`.

This mechanism is useful for cadets, labs, sport, exploration and specialist schools without requiring evil administrators.

### A10 — Desired world can feel wrong in the body
`LONGED-FOR PLACE → ACTUAL SENSORIUM → AWE + DISCOMFORT / FEAR → BEHAVIOR`.

World wonder becomes character-specific rather than tourism.

### A11 — World rule earns prose by changing tactics
`PHYSICS / INFRASTRUCTURE / TECHNOLOGY → AFFORDANCE / LIMIT → TACTIC → CONSEQUENCE`.

If an SF detail changes no action, relationship, evidence or choice, it is a candidate for compression.

### A12 — Social behavior requires motive alternatives
Silence, limited speech, eye contact, distance or unusual timing can reflect language ability, embodiment, training, anxiety, attention, culture or hostility.

Gate:
`OBSERVED BEHAVIOR → MULTIPLE MODELS → NEW CONTEXT / EVIDENCE → UPDATE`.

### A13 — Success can escalate through responsibility
`REAL SUCCESS → MORE TRUST / ACCESS / VISIBILITY → MORE RESPONSIBILITY → HARDER CHOICE`.

This avoids setback monoculture and is highly suitable to competent YA protagonists.

### A14 — Ensemble competence should be complementary
A team should not consist of five variants of “smart, brave, witty.” Give each member:
- a competence domain;
- a boundary/failure domain;
- a current want;
- a response to pressure;
- a relationship-specific behavior pattern;
- something they do not want despite group expectation.

## B. CROSS-SOURCE COMPARISON

### Skyward + Hunger Games
Both use youth identity under institution, but their mechanisms differ. Collins emphasizes public performance, surveillance and coercive audience incentives. Early *Skyward* emphasizes stigma, inherited access, qualification, embodied competence and institutional subculture. Do not collapse them into a generic “oppressive institution” model.

### Skyward + Swain
Strong convergence on `success → changed state → next problem`. The fiction lab provides a YA example where competence can generate more responsibility rather than mandatory defeat.

### Skyward + Card / Corbett
Supports relationship-specific behavior and independent wants. Rig's choice is particularly useful against plot-puppet teams: a supporting friend can discover a life goal different from the protagonist's.

### Skyward + Weir
Both support competence as testable model revision. Weir is stronger on explicit scientific hypothesis loops; *Skyward* is stronger on embodied performance and team-domain transfer in the strict-read portion.

### Skyward + Collins + Brody
Brody is a developmental diagnostic; Collins and Sanderson are fiction laboratories. For Orbital Youth, borrow stakes in autonomy, qualification, belonging, reputation and responsibility without importing dystopian scarcity or compulsory beat templates.

## C. FAILURE MODES TO BLOCK

1. Privileged rival automatically incompetent.
2. Competent rival automatically morally legitimate.
3. Passing selection means the youth must continue.
4. Shared preparation means shared dream.
5. Institution's written policy equals its lived culture.
6. Stigma treated as verified truth about motive.
7. Theoretical knowledge treated as embodied competence.
8. Every young character responds to risk with the same sarcasm/bravery.
9. Military-school competition imported wholesale into peaceful orbital education.
10. Scarcity/merit currency imported into post-money IVDIVO.
11. Worldbuilding treated as catalogue rather than affordance.
12. Silence/accent/limited language treated as character defect.
13. Hero success immediately reversed only to preserve tension.
14. Technical/action cadence treated as a house-style short-sentence KPI.

## D. PROVISIONAL PRODUCTION GATES

### Gate 119.1 — Institutional reality
For every important institution:
`PUBLIC CLAIM → WRITTEN RULE → ACTUAL ACCESS → INFORMAL STATUS SIGNAL → BURDEN → APPEAL / EXIT`.

### Gate 119.2 — Youth goal ownership
For each major young character:
`WHAT DO THEY WANT NOW, INDEPENDENT OF THE PROTAGONIST?`
If the answer is only “help protagonist,” fail.

### Gate 119.3 — Renewed consent after qualification
When a character passes selection/training:
`DO THEY STILL WANT THE LIFE THE QUALIFICATION OPENS?`

### Gate 119.4 — Embodied test
Any body-dependent competence claim must encounter a live constraint before climax-level reliance.

### Gate 119.5 — Success escalation
Before adding a setback, test whether a real success can create the next difficulty through added trust, access, visibility or responsibility.

### Gate 119.6 — Status/skill separation
Never use social privilege as sufficient evidence of technical incompetence, nor technical competence as sufficient evidence of fairness.
