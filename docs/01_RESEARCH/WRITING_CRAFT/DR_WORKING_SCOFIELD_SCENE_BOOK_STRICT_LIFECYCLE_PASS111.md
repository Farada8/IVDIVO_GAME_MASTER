### Chapter 2

`ACTION IS NOT EVENT`.

`MICRO-ACTIONS → RELATION / PATTERN → SCENE EVENT → CONSEQUENCE`.

Diagnostic:

`Because these actions occurred, __________ changed.`

Dialogue can constitute real event if exact words change relationship, decision, evidence, consent, commitment or future option space.

### Chapter 3

They are not prose units.

`BEAT MAP → LOGIC CHECK → PROPORTION / PACING → NATURAL PROSE`.

`ACTION BEAT ≠ SENTENCE`.

`BEAT ≠ PARAGRAPH`.

Action and emotion can be separately mapped without being written as a metronome.
