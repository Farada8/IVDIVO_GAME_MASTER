## Provisional mechanisms from actually read material

### 1. Process pluralism

The book repeatedly allows planning, exploratory drafting, cards, summaries and direct drafting as alternative methods. The useful IVDIVO mechanism is:

`LIVE MATERIAL → OBSERVED DEFECT → RELEVANT TOOL → REPAIR → RETEST`

not one compulsory drafting workflow.

### 2. Plan is hypothesis

The running plot summary should be updated when the book changes. Therefore:

`PLAN ≠ ACTUAL TEXT ≠ CANON ≠ EVIDENCE STATUS`

Production documents cannot overrule what the locked text actually establishes.

### 3. Story significance / reader-time hierarchy

The authors distinguish bare events from the motivations, consequences and relevance that make them matter. For IVDIVO:

`EVENT → WHO CARES / WHY → CAUSAL OR RELATIONAL CONSEQUENCE → READER-TIME WEIGHT`

Equal page-space for unequal story functions creates a false hierarchy.

### 4. Framework firewall

Hero's Journey, seven basic stories and three-act percentages are useful idea/diagnostic lenses only. The source itself repeatedly calls such templates starting points rather than absolute limits.

IVDIVO rule:

`FRAMEWORK → QUESTION / DIAGNOSIS`, never `FRAMEWORK → MANDATORY BEAT`.

### 5. Theme as causal question

Useful core:

`THEMATIC QUESTION → COMPETING MODELS → CHARACTER ACTION → CONSEQUENCE → READER INFERENCE`

Theme is not an author speech. Premise is treated as a causal proposition, which in IVDIVO remains a hypothesis to be tested by the draft rather than canon imposed in advance.

### 6. Opening contract

The source often recommends a strong first-paragraph hook and at times overstates `begin with a bang`. The transferable mechanism is narrower:

`ATTENTION + ORIENTATION + PROMISE + FORWARD PRESSURE`.

No mandatory accident, violence or action opening.

### 7. Character under pressure

Useful model:

`CURRENT WANT / VALUE → PRESSURE → SPECIFIC TACTIC / CHOICE → CONSEQUENCE → RETROSPECTIVE CHARACTER MODEL`.

Rejected as universals: one defining trait, larger-than-life bias, simplistic physiognomy/name shortcuts, obligatory underdog/fair-fight dynamics.

### 8. Capability limit

The source's `sonic screwdriver` warning generalizes well:

`CAPABILITY → LIMIT / COST / COUNTERFORCE → OPTION SPACE`.

If a tool, AI, robot or institutional power can solve everything without limits, the causal engine collapses.

### 9. Relationship-specific self

Family, lovers, friends and enemies create different registers, shorthand, permissions and vulnerabilities. Strong adaptation:

`SAME PERSON + DIFFERENT RELATIONSHIP → DIFFERENT WANT / RISK / TACTIC / REGISTER`.

This supports character differentiation without slang or quirks.

### 10. Dialogue as selective communication

Real conversation is repetitive, fragmented and often boring; fictional dialogue is shaped selection rather than transcription.

`PRESENT WANT + RELATIONSHIP + KNOWLEDGE → COMMUNICATION TACTIC → LISTENER RESPONSE → CHANGED STATE`.

Exact dialogue earns reader-time when wording itself changes trust, consent, evidence access/status, authority, relationship terms or decision.

### 11. Speech / behaviour firewall

The authors correctly note that one utterance can support several explanations. Therefore:

`UTTERANCE / PAUSE / GESTURE → MOTIVE HYPOTHESIS`, not `MOTIVE FACT`.

This is mandatory for mystery and nonhuman personhood.

### 12. Conflict reinterpreted

The source strongly identifies story with conflict and frequently prefers person-against-person opposition. IVDIVO retains only:

`PRESENT WANT → MEANINGFUL RESISTANCE / SUPPORT → TACTIC → OUTCOME → CHANGED STATE`.

Resistance can be another person, evidence uncertainty, consent, physical rule, institution, time, relationship, embodiment or competing good values. No obligatory villain.
