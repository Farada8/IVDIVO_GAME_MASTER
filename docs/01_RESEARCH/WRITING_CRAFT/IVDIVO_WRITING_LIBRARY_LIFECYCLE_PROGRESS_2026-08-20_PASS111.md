## 5. New production gates

### A. Changed-State Sentence

Before line edit, complete:

`Because these actions occurred, __________ changed.`

If no downstream-relevant state changes, test summary/merge/delete/rebuild.

### B. Beat Logic, Not Beat Typography

`BEAT MAP → LOGIC/PACING AUDIT → NATURAL PROSE`.

Never turn beat analysis into:

`action. reaction. gesture. thought. conclusion.`

A beat may occupy part of a sentence, a sentence, several sentences or a larger narrative unit.

### C. Background-Motion Test

Physical activity does not automatically create scene progression.

Routine technical manipulation, walking, setup or object handling remains grounding unless it alters consequential state.

### D. Dialogue-Event Test

Use exact dialogue when wording changes trust, consent, evidence, authority, relationship terms, commitment, decision or future expectations.

Otherwise test indirect dialogue/summary.

### E. Pulse Without Forced Conflict

A scene's emotional need/pressure may remain quiet until action activates consequences.

No mandatory argument.
