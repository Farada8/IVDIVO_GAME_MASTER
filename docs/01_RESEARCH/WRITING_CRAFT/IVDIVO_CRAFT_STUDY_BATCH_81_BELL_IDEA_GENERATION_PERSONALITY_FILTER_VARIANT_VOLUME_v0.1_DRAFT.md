## Why this batch exists

This batch operationalizes only mechanisms supported by the continuously read portion of Bell Chapter 3. Later chapter material may be referenced as provisional context but is not allowed to advance lifecycle status.

## Core synthesis

### A. Divergence before convergence

Use two different studio modes:

**DISCOVERY MODE**  
Generate rapidly. Preserve odd combinations. Do not ask every specialist to veto every seed.

**SELECTION MODE**  
Activate canon, personhood, causality, reader contract, originality, downstream-payoff and manuscript-fit checks.

Failure occurs when the studio tries to perform both modes simultaneously.

### B. Variant volume must be structural, not cosmetic

A variant only counts as new if it materially changes one or more of:

- decision owner;
- objective;
- resistance/countermodel;
- evidence;
- relation at risk;
- world constraint;
- tactic;
- cost bearer;
- resulting state.

Changing a planet name, school name, gadget, gender, corridor color or surface hazard does not create a genuinely new story engine.

### C. Personal energy is raw material, not character identity

Bell's personality-filter idea becomes:

**AUTHOR/FOUNDER PRESSURE OF INTEREST → TRANSFORMATION → INDEPENDENT CHARACTER MOTIVES → RELATION-SPECIFIC TACTICS → CONSEQUENCES.**

The project may repeatedly care about autonomy, responsibility, consciousness, personhood and technological power. The cast must not all arrive at identical positions or speak with a single authorial intelligence.

### D. Idea bank protects ONE MAIN STORY

A strong unused idea is not wasted. Bank it.

This makes it easier to reject attractive secondary engines that would otherwise fracture the current novel.

**GOOD IDEA ≠ GOOD IDEA FOR THIS BOOK.**

## Production gates

### B81-G01 — GENERATION / EVALUATION SEPARATION
No Red Team veto during the first divergent burst unless a generated item would be unsafe to retain at all. Canon checking begins in selection mode.

### B81-G02 — MINIMUM MATERIAL DIFFERENCE
Before comparing engines, verify that alternatives differ causally, not cosmetically.

### B81-G03 — FIRST-IDEA IMMUNITY BAN
Time already spent developing a variant gives it no protection.

### B81-G04 — AUTHOR-PROXY TEST
For every major character, ask: `Would this character still want this if the author did not personally care about the theme?` If no, motivation is underwritten.

### B81-G05 — CANON-BY-BRAINSTORMING BAN
A what-if cannot enter Saga Bible as fact without explicit canon reconciliation.

### B81-G06 — WORLD-SEED TEST
A technology/location/image only survives if it changes action, relationship, evidence, available options or cost.

### B81-G07 — IDEA-BANK ROUTING
If an idea is strong but does not alter the current dominant causal engine, store it for another book/story rather than adding a subplot.

### B81-G08 — POST-MONEY DEFAULT
For Orbital Youth, generation should first seek trust/time/role/consent/reputation/mastery/relationship/unique-experience stakes before any economic analogy.

### B81-G09 — ROBOT PERSONHOOD AT IDEATION
A robot-centered variant must specify the robot's objective, refusal rights and at least one relationship not reducible to human utility.

### B81-G10 — EPISTEMIC SCHOOL FIREWALL
A consciousness-school variant may dramatize an interpretation but cannot treat that interpretation as settled ontology without independent proof.

### B81-G11 — DOWNSTREAM DIFFERENCE
Before choosing a variant, ask what chapters/scenes/payoffs change because of it. If downstream architecture is identical, the variant may be superficial.

### B81-G12 — LIVE-MATERIAL PRIORITY
If a generated version unexpectedly produces stronger character truth than the outline, test it before suppressing it. Discovery may update the plan; canon does not bend silently.

## Failure modes

- **Gate Swarm at Birth** — too many specialist checks produce sterile prose/ideas.
- **First Plausible Answer** — a merely workable solution becomes canon because it arrived first.
- **Twenty Names, One Engine** — variant count inflated by cosmetic changes.
- **Theme Clone Cast** — every character voices the founder's preferred conclusion.
- **Worldbuilding Seduction** — a cool system becomes the plot even though no choice changes.
- **Subplot Accretion** — bankable ideas are forced into the current novel.
- **Earth Default Re-entry** — money/rent/status consumption returns because it is an easy brainstorming shorthand.
- **Robot Instrumentalization** — conscious robot used as clever premise object rather than agent.
- **Metaphysical Promotion** — a school's interpretation is upgraded from belief to fact for dramatic convenience.

## Studio procedure

For high-stakes story decisions:

1. State the problem in one sentence.
2. Generate at least 10 materially different variants.
3. Remove cosmetic duplicates.
4. Identify the strongest human/personhood pressure in each.
5. Run canon and ontology firewall.
6. Run ONE MAIN STORY relevance.
7. Run causal downstream map.
8. Run reader-effect / freshness comparison.
9. Keep one primary; optionally retain one backup.
10. Bank the rest with a one-line note explaining what was valuable.

## Application principle

The studio should be **large during search and narrow during execution**.

A hundred specialist perspectives are useful for producing and attacking alternatives. The finished scene still needs one coherent causal purpose, one controlled POV logic and readable prose rather than visible committee output.
