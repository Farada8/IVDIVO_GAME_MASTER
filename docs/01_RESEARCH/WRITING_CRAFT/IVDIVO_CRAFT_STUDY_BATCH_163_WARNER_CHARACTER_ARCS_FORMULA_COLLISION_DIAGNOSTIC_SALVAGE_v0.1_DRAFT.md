# IVDIVO CRAFT STUDY — BATCH 163
## WARNER — CHARACTER ARCS · FORMULA COLLISION · DIAGNOSTIC SALVAGE

**Date:** 2026-08-21  
**Source:** John S Warner — *Building Character Arcs 2 Books in 1*  
**Source status:** WIDER `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`

## Executive result

This source is most valuable as a **stress test of stacked craft systems**.

It places within one beginner-facing volume Freytag, Hero's Journey, Three-Act, Story Circle, Fichtean Curve, Save the Cat, Seven-Point structure and five character-arc patterns.

Central IVDIVO lesson:

**`FRAMEWORKS ARE DIAGNOSTIC LENSES, NOT SIMULTANEOUS OBLIGATIONS.`**

## Gate 163-01 — Formula Collision Audit

`OBSERVED DEFECT → CHOOSE RELEVANT LENS → DIAGNOSIS → CHARACTER/CANON/CAUSALITY CHECK → KEEP OR DISCARD LENS`

Failure: `MULTI-FRAMEWORK OVERFIT`.

Symptoms:
- midpoint exists only because several templates demand one;
- mentor appears because Hero's Journey demands one;
- Dark Night exists because Save the Cat expects it;
- deathly third plot point exists because arc workbook expects it;
- protagonist receives wound/lie because template expects it;
- final battle appears although the real climax is a decision.

## Gate 163-02 — Model, Not Lie

Replace `LIE → TRUTH` with:

`CURRENT MODEL / VALUE → PRESSURE / EVIDENCE → CHOICE → CONSEQUENCE → UPDATE / TESTED STABILITY`.

This permits positive, negative, partial, tactical, stable and series-long change without compulsory moral certainty.

## Gate 163-03 — Static Arc ≠ Flat Character

A stable protagonist can remain deep if relationships are specific, tactics change, costs accumulate, choices reveal priorities and reader understanding deepens.

## Gate 163-04 — Supporting Person ≠ Service Function

Warner's supporter / antagonizer / informer taxonomy is treated as temporary story function only.

Every named conscious person still needs:
`OWN WANT → OTHER RELATIONSHIPS → REFUSAL CAPACITY → CHOICE → CONSEQUENCE`.

Mandatory for robots/nonhumans.

## Gate 163-05 — Sympathy Shortcut Firewall

Do not buy reader attachment by inserting illness, disability, childhood vulnerability, victimization, trauma, demographic stereotype or pet-loving villain.

Prefer:
`GOAL / PLAN → CHOICE UNDER PRESSURE → RELATIONSHIP → CONSEQUENCE`.

## Gate 163-06 — Scenario Lab, Not Canon

`MODEL → TEST SCENARIO → RESPONSE → MODEL UPDATE`.

`EXERCISE OUTPUT ≠ CANON`.

## Gate 163-07 — ONE MAIN STORY / Nucleus

Salvage Warner's nucleus as:
`ONE DOMINANT CAUSAL ENGINE`.

Do not reduce this to one hero, one event, one villain or one POV.

## Gate 163-08 — Closure Without Mandatory Positivity

`LOCAL QUESTION → DECISIVE ACTION → OUTCOME → COST → AFTERMATH → CHANGED STATE`.

No mandatory happy ending, redemption or moral lesson.
