## Highest-value retained mechanisms

### External outcome versus actual resolution
`OBJECTIVE RESULT → RELATION / EVIDENCE / RESPONSIBILITY / AGENCY / FUTURE-OPTION STATE`.

Winning the prize, role, battle, marriage, rescue or technical fix does not automatically resolve the book's governing human problem.

### Goal legitimacy
`WHO SET THE GOAL? → WHO BENEFITS? → WHO BEARS COST? → WHO MAY REFUSE? → WHAT SUCCESS CHANGES?`

`GOAL ACHIEVEMENT ≠ GOAL LEGITIMACY`.

### Relationship closure
`FORMAL LABEL / KISS / REUNION / MARRIAGE ≠ TRUST / CONSENT / NEW TERMS`.

### New-system payment
`NEW WORLD / TECHNOLOGY / INSTITUTION → AFFORDANCE / CONSTRAINT → MODEL UPDATE → CHANGED ACTION / RELATION → CONSEQUENCE`.

### Recognition
`OLD MODEL → DISCRIMINATING EVIDENCE / EXPERIENCE → RECOGNITION → CHANGED TACTIC / RELATION / DECISION`.

Recognition is useful as model revision, not mystical completion.

### Narrative glamour audit
`CHARISMA / FOCALIZATION / BEAUTY / HUMOUR / INTERIORITY ≠ MORAL LEGITIMACY`.

Check whether discourse allocation hides the costs borne by other characters.

### Surface reset versus durable change
`AMNESIA / NEW NAME / NEW BODY / RELOCATION / STATUS CHANGE ≠ CHARACTER CHANGE`.

Durable change must be visible in later pressured choices.

### Corpus pattern restraint
`RECURRING FICTION PATTERN → CRAFT TENDENCY HYPOTHESIS → TEST IN CURRENT MANUSCRIPT`.

Never infer author psychology as fact from recurring fictional patterns alone.

### Coincidence stack
`COINCIDENCE MAY COMPLICATE; IT MUST NOT REPEATEDLY SOLVE OR FORCE THE REQUIRED END STATE`.
