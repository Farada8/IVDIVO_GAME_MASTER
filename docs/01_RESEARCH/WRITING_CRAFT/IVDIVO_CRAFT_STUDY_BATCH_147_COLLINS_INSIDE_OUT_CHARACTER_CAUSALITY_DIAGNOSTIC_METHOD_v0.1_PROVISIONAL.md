## Core synthesis

### A. Character causality should precede decorative traits
Useful direction:
`EXPERIENCE / SOCIAL CONTEXT → VALUE MODEL → PRESENT WANT → TACTIC → CHOICE → CONSEQUENCE`.

A trait or mannerism earns importance when it affects action, relationship, interpretation, or cost. A quirky gesture with no causal function is not character depth.

### B. Values are hypotheses, not deterministic labels
For each major character keep at least:
- value / commitment currently protected;
- relationship or context where it changes priority;
- competing value;
- observable behavior that supports the model;
- counterexample that prevents flattening.

Gate: `ONE CORE VALUE MUST NOT EXPLAIN EVERYTHING`.

### C. Character and plot are co-discovered
`CHARACTER MODEL → CHOICE → PLOT CONSEQUENCE → NEW EVIDENCE ABOUT CHARACTER → REPLAN IF BETTER`.

This is compatible with `PLAN = HYPOTHESIS, NOT CANON`, but all live-material changes still pass canon, personhood, causal-engine, and downstream-consequence checks.

### D. Scene objective is causal, not performative
The useful acting-to-fiction transfer is not “act harder”; it is:
`WHAT DOES THIS PERSON WANT FROM THIS MOMENT / PERSON?`.

Then:
`WANT → TACTIC → RESPONSE → TACTIC CHANGE → CHANGED STATE`.

This mechanism remains provisional until Collins Secret #2 is strict-read.

### E. Learn mechanisms consciously; deploy selectively
Collins explicitly frames detailed steps as training/troubleshooting tools that should not freeze natural writing. This strongly supports the IVDIVO multi-pass studio architecture.

Production rule:
`DO NOT RUN ALL SPECIALISTS DURING GENERATION`.

Use:
`DISCOVERY → HOT SPOT / DEFECT → ROUTE TO RELEVANT SPECIALISTS → REPAIR → RETEST`.

## Gates B147-01–B147-12

**B147-01 — INNER CAUSALITY BEFORE QUIRK**  
No mannerism is accepted as character depth without a causal/relational function.

**B147-02 — VALUE MODEL EVIDENCE**  
A claimed core value must be supported by multiple pressured choices, not just biography or author notes.

**B147-03 — COMPETING VALUE**  
Major characters require at least one context in which another legitimate value competes with the dominant one.

**B147-04 — RELATIONSHIP-SPECIFIC PRIORITY**  
The same person may protect different values/tactics with friend, parent, instructor, lover, institution, or conscious robot.

**B147-05 — FRUSTRATION DIFFERENTIATION**  
If ensemble members react to blocked goals with the same wit, defiance, competence display, or withdrawal, differentiation is insufficient.

**B147-06 — CHARACTER/PLOT RECIPROCITY**  
A strong new character truth may force re-planning; a plot event may reveal a previously unknown character truth. Neither layer automatically outranks the other.

**B147-07 — NO PLOT-PUPPET VALUE**  
Do not invent a belief solely to justify an outline beat.

**B147-08 — NO AUTHOR-PROXY MONOCULTURE**  
Shared saga themes must not produce identical moral reasoning in all major characters.

**B147-09 — PERSONHOOD WITHOUT HUMAN PERFORMANCE**  
A conscious robot/nonhuman person does not need human emotional display or human bodily mannerisms to satisfy character depth.

**B147-10 — MOTIVE STATUS FIREWALL**  
Character-sheet motive is an authorial design model; in-world characters must infer motive from evidence.

**B147-11 — METHOD-ACTING EPISTEMIC FIREWALL**  
Stanislavsky-derived concepts are craft tools, not contemporary scientific proof about psychology, consciousness, or metaphysics.

**B147-12 — TROUBLESHOOTING MODE**  
Use the detailed method when a character/scene is flat or inconsistent; do not force every first-draft sentence through the full checklist.

## Cross-source placement
- **Card / Corbett:** Collins supplies a practical interrogation route toward the causes behind behavior.
- **McKee Character:** compatible with modus operandi, but IVDIVO rejects one extreme choice as proof of permanent “true self.”
- **Herman / Zunshine:** correct Collins by preserving uncertainty between behavior and motive.
- **Scofield:** values/objectives only matter on the page when they contribute to scene event, negotiation, changed state, or downstream consequence.
- **Lamott / LaPlante / Swain / Bell / Bickham:** strong agreement that detailed craft procedures should serve revision/troubleshooting rather than paralyze generation.
