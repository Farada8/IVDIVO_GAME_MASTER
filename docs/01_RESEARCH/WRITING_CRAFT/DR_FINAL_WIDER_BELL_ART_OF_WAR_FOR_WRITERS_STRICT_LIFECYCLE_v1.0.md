## 3. Highest-value claims after Red Team

### 3.1 Generate hot, edit cool
Bell repeatedly separates discovery from criticism. The durable version is:

`GENERATE LIVE MATERIAL → DISTANCE → DIAGNOSE → REVISE → POLISH`.

Fast drafting is a **writer-process** tactic, not a command to produce choppy final syntax.

### 3.2 Deliberate practice is defect-specific
Exemplars, reader/editor comments and targeted self-study are useful when routed to a concrete craft problem.

`OBSERVED DEFECT → TARGETED STUDY / EXERCISE → NEW ATTEMPT → RETEST`.

### 3.3 Exercise output is not canon
Voice journals, random words, alternate dialogue, second-right-answer lists and speculative scene variants are discovery mechanisms.

`EXERCISE OUTPUT ≠ CANON`.

They must pass canon, character, causality, ONE MAIN STORY, personhood, reader-effect and payoff gates before entering a manuscript.

### 3.4 Premise tournament beats first-idea lock
Bell's useful core is to keep multiple ideas alive long enough to compare them. IVDIVO version:

`SEED → MATERIAL VARIANTS → CHARACTER / CANON / CAUSALITY / ONE MAIN STORY / READER EFFECT / PAYOFF → KEEP / BANK / DISCARD`.

### 3.5 Outer and inner are separate state tracks
Bell's outer/action vs inner/reaction distinction survives if generalized beyond mandatory transformation:

`ACTION STATE + KNOWLEDGE / RELATION / MODEL / RESPONSIBILITY STATE`.

A scene may move one or several tracks. A stable-value protagonist can still undergo major tactical, relational, epistemic or responsibility change.

### 3.6 Freshness comes from alternatives, not arbitrary noise
`FLIP THE OBVIOUS`, `SECOND RIGHT ANSWER`, random-word and voice-journal techniques are useful generators, but the output must be causally earned.

### 3.7 Scene bull's-eye is a functional change
Bell's bull's-eye survives as:

`WHY WAS THIS MATERIAL WORTH REAL-TIME DRAMATIZATION?`

Possible answers: decision, evidence-status change, consent change, relationship turn, authority/access shift, model revision, revelation, earned success or other load-bearing changed state.

### 3.8 Progressive revelation requires POV fairness
Useful:
`TRACE / FACT → PARTIAL MODEL → FURTHER EVIDENCE → MODEL UPDATE`.

Rejected: hiding something a close-POV character already knows solely to manufacture surprise.

### 3.9 Dialogue is tactic
Durable formulation:

`PRESENT WANT → VERBAL / NONVERBAL TACTIC → ACTUAL LISTENER RESPONSE → TACTIC / MODEL UPDATE → CHANGED STATE`.

Exact dialogue is justified when exact wording changes trust, consent, evidence, authority, relationship terms, emotion, decision or future options.

### 3.10 Narrative dialogue / summary is a first-class compression tool
Bell explicitly validates summary of routine conversation and elapsed process. IVDIVO broadens his conflict-only criterion:

`ROUTINE / REPEATED / LOGISTICAL / LOW-STATE-CHANGE MATERIAL → SUMMARY / INDIRECT / ELLIPSIS`.

`LOAD-BEARING WORDING / DECISION / EVIDENCE / CONSENT / RELATION TURN → REAL TIME`.

### 3.11 RUE is anti-redundancy, not anti-telling
Useful core:

`IF ACTION / CONTEXT ALREADY MADE THE EFFECT LEGIBLE → DO NOT EXPLAIN IT AGAIN`.

Rejected: turning RUE into a ban on narration, summary, exposition or direct thought.

### 3.12 Adaptive planning
Bell explicitly validates outline/no-outline/hybrid processes and allows a live draft to force outline revision.

`PLAN = HYPOTHESIS, NOT CANON`.

`LIVE MATERIAL → CHARACTER / CANON / CAUSALITY TEST → REPLAN / BANK / DISCARD`.

### 3.13 Feedback becomes diagnosis
Durable form:

`READER REPORT → OBSERVED EFFECT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES → TEST`.

A reader owns their effect; their preferred repair remains a hypothesis.

## 4. Failure modes rejected or constrained

1. **DEATH-STAKE MONOCULTURE** — physical/professional/psychological death is not mandatory.
2. **MANDATORY HERO / OPPOSITION / FINAL BATTLE** — one causal engine does not require one heroic protagonist or villain.
3. **WOUND / BROKENNESS REQUIREMENT** — depth does not require trauma.
4. **REDEMPTION MONOCULTURE** — stable values, partial change, negative change and relational/epistemic arcs remain valid.
5. **DISTURBANCE-FIRST OPENING LAW** — opening requires attention, orientation, person/subject bond, promise and forward pressure; not necessarily trouble.
6. **DREAM / WEATHER ABSOLUTISM** — these are mode/contract questions, not categorical bans.
7. **DIALOGUE = CONFLICT ONLY** — cooperation, refusal, clarification, intimacy, negotiation and evidence handling can be causally active.
8. **SCENE GREATNESS = CONFLICT + EMOTION + SURPRISE** — useful generator, not universal gate.
9. **COMEDY = TRIVIAL TRAGEDY ONLY** — one lens, not a universal theory; character-owned humor rules remain higher authority.
10. **FIRST-PERSON MEMORY OMNISCIENCE** — reported/reconstructed scenes require source provenance; narrator imagination must not silently become world fact.
11. **ACTION-FIRST BACKSTORY ABSOLUTISM** — backstory/summary may lead when the narrative contract requires it.
12. **MARKET-ERA LEAKAGE** — agent/query/platform/conference/bookstore advice is 2009-era historical material.
13. **WRITER-WORTH MORALISM** — productivity, resilience and publication status do not establish artistic worth or psychological health.
14. **PROCESS METRIC = STORY QUALITY** — word quotas and schedules are process tools only.

## 6. IVDIVO operationalization

### 6.1 Discovery / specialist scheduling
`LIVE DRAFT → FATAL/MAJOR? → YES: INTERRUPT → NO: BACKLOG → POST-DISCOVERY SPECIALIST PASS`.

Do not run the entire specialist stack against every raw sentence.

### 6.2 Scene acceptance
`PRIOR STATE → OWNER / WANT → TACTIC / PRESSURE / SUPPORT → BULL'S-EYE CHANGE → EXIT STATE → DOWNSTREAM LINK`.

### 6.3 Dialogue mode router
`EXACT WORDING CHANGES STATE? → DIRECT DIALOGUE`.
`ROUTINE / PROCESS / REPEAT? → INDIRECT / SUMMARY`.

### 6.4 Revelation
`WORLD FACT → TRACE/SOURCE → POV ACCESS → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

### 6.5 Prose / anti-choppiness
`SCENE/MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE CONTRAST → WORDING`.

`FAST DRAFT ≠ CHOPPY FINAL PROSE`.
`COMPRESSION ≠ CHOPPING`.
`BEAT ≠ SENTENCE BREAK`.
