**Date:** 2026-08-21

## Production purpose
Extract the durable narrative mechanisms while preventing popular-neuroscience, evolutionary-psychology and “sacred flaw” claims from becoming IVDIVO psychology or ontology.

## A. Retained gates

### B179-G01 — Meaningful Change Attention Gate
`CURRENT MODEL / EXPECTATION → MEANINGFUL DEVIATION → ATTENTION / CURIOSITY → CHARACTER-SPECIFIC RESPONSE`.

Change can be quiet. Crisis is not mandatory.

### B179-G02 — Curiosity Model
`CLEAR QUESTION → PARTIAL MODEL → PLAUSIBLE ALTERNATIVES → MISSING DISCRIMINATING INFO → SEEK/TEST`.

Total confusion is not mystery.

### B179-G03 — Reader Model Update
`SELECTED CUE → READER MODEL → PREDICTION → NEW CUE → MODEL UPDATE`.

### B179-G04 — Character-Specific Perception
`VALUES + HISTORY + KNOWLEDGE + EMBODIMENT + PRESENT WANT → SALIENCE → NOTICED DETAIL → INTERPRETATION`.

### B179-G05 — Other-Mind Model
`A'S MODEL OF B → TACTIC → B'S ACTUAL RESPONSE → MODEL ERROR / CONFIRMATION → UPDATE`.

**Firewall:** `MODEL OF OTHER MIND ≠ OTHER MIND FACT`.

### B179-G06 — Subjective-Time Detail
Under tension, selected detail can increase while reader time slows.

`SUSPENSE ≠ SHORT-SENTENCE DENSITY`.

### B179-G07 — Personal Association
`PARTICULAR → PERSONAL HISTORY / VALUE ASSOCIATION → CHARACTER-SPECIFIC MEANING → RESPONSE`.

### B179-G08 — Cause Legibility
`CAUSE / PRIOR STATE LEGIBLE ENOUGH FOR READER MODEL → CONSEQUENCE → INFERENTIAL SPACE`.

Do not explain everything.

### B179-G09 — Model Under Pressure
`CURRENT MODEL / VALUE → PRESSURE / CONTRADICTORY EVIDENCE → TACTIC → CONSEQUENCE → MODEL UPDATE OR TESTED STABILITY`.

No mandatory flaw/healing.

### B179-G10 — Person × Event Specificity
`EVENT → CONTACT WITH THIS PERSON'S MODEL / VALUE / RESPONSIBILITY → SPECIFIC RESPONSE → STORY ENGINE ACTIVATES`.

### B179-G11 — Setting-as-Hypothesis
`SETTING FEATURE / RESIDUE → POV ATTENTION → CHARACTER / RELATIONSHIP HYPOTHESIS`.

Environment does not prove personality.

### B179-G12 — Memory as Testimony
`MEMORY / SELF-REPORT → CURRENT SELF-MODEL`, not historical world fact.

### B179-G13 — Context-Dependent Self
`CORE VALUES / TRAITS + RELATIONSHIP + SITUATION + COST → CURRENT PRIORITY → TACTIC`.

Contradiction may be causal variation, not inconsistency.

### B179-G14 — Outer / Inner Track
`OUTER EVENT / ACTION ↔ INNER MODEL / RELATION / COMMITMENT UPDATE`.

### B179-G15 — Want/Need Optionality
Use conscious want + less conscious mismatch only where the manuscript actually supports it. No mandatory hidden need.

### B179-G16 — Competing Moral Models
`MODEL / VALUE A ↔ MODEL / VALUE B → REAL BENEFITS + REAL COSTS → TACTICS → CONSEQUENCES`.

### B179-G17 — Symphony of Change
Track independent change axes:
- physical/action;
- knowledge/evidence;
- relationship/consent;
- authority/access;
- responsibility;
- goal/strategy;
- self-model;
- reader model;
- secondary-character state;
- future option space.

### B179-G18 — Framework Waymarkers
Plot recipes are optional navigation aids after story/character evidence exists.

`STORY NEED → OPTIONAL LENS → TEST → KEEP/DISCARD`.

### B179-G19 — Ending Without God-Moment Requirement
`DOMINANT BOOK QUESTION → DECISIVE ACTION/CHOICE → CONSEQUENCE → CHANGED STATE → AFTERMATH`.

### B179-G20 — Prior-Scene Laboratory
Author may privately write formative scenes to understand current behavior.

`PRIVATE PRIOR EVENT → CURRENT CONSEQUENCES → FLASHBACK ONLY IF IT EARNS READER TIME`.

## B. Science / psychology firewall

Storr is a 2019 popular-science synthesis, not current primary evidence.

**Standing rule:**

`STORR SCIENCE CLAIM → SOURCE CLAIM / CRAFT HYPOTHESIS`.

Before any real-world scientific assertion enters canon/nonfiction:
- verify current primary/systematic evidence;
- preserve uncertainty;
- do not use story usefulness as proof of scientific truth.

## E. Standing IVDIVO synthesis

### Character
`VALUES / RELATIONSHIPS / KNOWLEDGE / EMBODIMENT → CURRENT MODEL / PRIORITY → PRESENT WANT → OPTION SET → TACTIC → RESPONSE → CONSEQUENCE → MODEL UPDATE OR TESTED STABILITY`.

### Mystery
`CLEAR QUESTION → PARTIAL MODEL → ALTERNATIVES → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

### Prose
`CHANGE / CURIOSITY / SUSPENSE → READER EFFECT → ORDER/DURATION/FREQUENCY → PARAGRAPH INTENT → SUBJECTIVE TIME → SENTENCE RHYTHM`.

### Anti-overfit
`TOOLS HELP ASK / ORGANIZE / DIAGNOSE; STORY DOES NOT EXIST TO VALIDATE TOOLS`.

### Science
`CRAFT MODEL ≠ PSYCHOLOGICAL FACT ≠ ONTOLOGICAL FACT`.
