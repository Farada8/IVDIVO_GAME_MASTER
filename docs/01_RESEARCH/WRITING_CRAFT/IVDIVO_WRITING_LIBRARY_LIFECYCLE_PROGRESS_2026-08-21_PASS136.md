### Temporal architecture

`STORY ORDER → DISCOURSE ORDER → READER MODEL`.

Key distinctions:
- analepsis / prolepsis;
- reach / extent;
- completing vs repeating analepsis;
- advance notice vs advance mention;
- ellipsis / summary / scene / pause;
- singulative / repeating / iterative frequency.

### Fair reinterpretation

`EARLY TRACE REMAINS TRUE → LATER EVIDENCE CHANGES ITS MEANING`.
