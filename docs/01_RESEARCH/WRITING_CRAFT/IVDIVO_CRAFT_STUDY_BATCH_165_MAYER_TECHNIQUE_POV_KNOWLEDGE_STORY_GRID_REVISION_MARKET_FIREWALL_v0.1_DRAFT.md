## 1. Mechanisms retained

### A. Plan / Actual-State Split
`PLAN → DRAFT → ACTUAL MANUSCRIPT STATE → CANON/CAUSALITY TEST → REPLAN / KEEP / BANK / DISCARD`.

A plan is a hypothesis. Repetition in production documents does not promote a planned fact into canon.

### B. Knowledge-State Mapping
Track separately:
- what objectively happened;
- what each POV can perceive;
- what each character knows;
- source/provenance;
- interpretation/confidence;
- what the reader currently knows;
- what a disclosure changes.

Production chain:
`WORLD FACT → SOURCE/TRACE → POV ACCESS → INTERPRETATION → READER MODEL → ACTION`.

### C. Story-State Grid
`TIME → LOCATION → OWNER → GOAL → ACTION STATE → KNOWLEDGE/EVIDENCE → RELATIONSHIP/CONSENT → AUTHORITY/ACCESS → EXIT STATE → NEXT LINK`.

The grid describes the actual manuscript, not the intended outline.

### D. Clue Salience Budget
Fairness needs visibility; mystery needs non-coercive emphasis.

`PLANT → READER CAN NOTICE → DO NOT REPEAT UNTIL ONLY ONE INFERENCE IS POSSIBLE → LATER RECONTEXTUALIZE / PAY OFF`.

### E. Macro-before-Micro Revision
`OBSERVED EFFECT → DEFECT LEVEL → DEPENDENCIES → MINIMAL CORRECT FIX → REGRESSION TEST`.

Do not line-edit a scene whose causal purpose, POV access or chronology is wrong.

### F. Synopsis Stress Test
If a compressed account cannot expose one dominant causal spine, inspect subplot/function duplication and process scenes before adding more plot.

## 2. Limits / rejected universals

- MBTI/profiling is not scientific character truth.
- Pressure reveals a choice under conditions, not an immutable hidden essence.
- 2003 agent/query/postage/e-book/POD/marketing advice is historical, not current market authority.
- Commercial publishing outcome is not evidence of manuscript quality.
- Series should evolve; sequel reset is not a production virtue.
- Earth money/career examples do not override post-money IVDIVO canon.
