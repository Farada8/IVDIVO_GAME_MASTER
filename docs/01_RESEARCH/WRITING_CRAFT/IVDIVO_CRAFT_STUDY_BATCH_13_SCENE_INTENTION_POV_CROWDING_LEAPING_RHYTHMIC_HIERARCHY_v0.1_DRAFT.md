## Sources advanced in this pass

### Ursula K. Le Guin — Steering the Craft (2015 edition)
Current conservative status: READABLE / STRUCTURE MAPPED / MULTI-CHAPTER THEMATIC PASS / MECHANISMS EXTRACTED / MANUSCRIPT TEST STARTED.

Substantive chapters processed in this pass:
- The Sound of Your Writing;
- Sentence Length and Complex Syntax;
- Point of View and Voice;
- Indirect Narration / telling context;
- Crowding and Leaping.

Key mechanisms:

1. **Sentence length is relational.** Short sentences are powerful when contrasted with surrounding syntax; an all-short default becomes monotonous and falsely simplistic. Long sentences work when their syntactic connections are clear. There is no universal optimum length; the production target is purposeful variation.

2. **Mind's-ear test.** Narrative has audible qualities even when read silently. Rhythm, pace and forward movement should be tested aloud after structural revision.

3. **POV and voice are coupled.** Who tells, what can be perceived, and what linguistic texture carries perception should be treated as one production problem rather than separate checkboxes.

4. **Crowding and Leaping.** Strong prose is dense with relevant sensation, meaning, implication and internal echoes, but also leaves out vastly more than it includes. Listing is not description; omission is a structural tool.

Operational formula:

`SELECT RELEVANT DETAIL → CONNECT IT TO POV / ACTION / THEME → LEAP OVER LOW-VALUE PROCESS → LAND ON NEXT CONSEQUENTIAL MOMENT`

### Ursula K. Le Guin — The Wave in the Mind
Current conservative status: READABLE / RHYTHM CLUSTER THEMATIC PASS / MECHANISMS EXTRACTED.

Key mechanism:

Long-form narrative rhythm is created by **developing repetitions** of words, images, actions, moods and themes. Pure repetition without changed meaning kills forward drive; varied recurrence creates coherence while advancing the story.

Operational distinction:

`PURE REPEAT = SAME BEAT / SAME FUNCTION / SAME EMOTION`

vs.

`DEVELOPING REPEAT = RECOGNIZABLE MOTIF + NEW CONTEXT + NEW COST / MEANING / DECISION`

### Jordan Rosenfeld — Make a Scene, Revised and Expanded Edition
Current conservative status: READABLE / STRUCTURE MAPPED / CORE SCENE CHAPTERS THEMATIC PASS / MECHANISMS EXTRACTED / MANUSCRIPT TEST STARTED.

Key mechanisms:

1. A scene requires momentum: behavior unfolding in narrative time.
2. Each scene should give the protagonist something new to react/respond to, normally arising from prior scenes.
3. Scene intention is a concrete action-direction, distinct from motivation (why the character wants it).
4. Intention should meet complication; complication should alter the result and the next intention.
5. Personal history is not exposition pasted into a scene; it should shape how the character behaves in the scene.
6. First two-thirds generally benefit from rising complication, but this is a genre/tempo tendency rather than an absolute law.

Operational scene chain:

`PRIOR CONSEQUENCE → SCENE INTENTION → ATTEMPT → OPPOSITION / CATALYST → COMPLICATION → RESULT → EMOTIONAL/KNOWLEDGE CHANGE → NEXT INTENTION`

### Jordan Rosenfeld — Writing the Intimate Character
Current conservative status: READABLE / STRUCTURE MAPPED / POV-INTIMACY THEMATIC PASS / MECHANISMS EXTRACTED.

Key mechanisms:

- POV is not only pronoun choice; it determines access to thoughts, sensory perception, worldview and emotional intimacy.
- A story problem should be specifically linked to the protagonist and force pressure on both outer life and inner model.
- Multiple-POV work requires differentiation in what each character notices, interprets, feels, values and linguistically foregrounds.

Operational POV fingerprint:

`KNOWLEDGE BOUNDARY | FIRST-NOTICED DETAIL | SENSORY PRIORITY | SOCIAL BIAS | FEAR/DESIRE FILTER | LEXICON | SYNTAX | HUMOR | WHAT THEY MISREAD`

### Alice LaPlante — The Making of a Story
Current conservative status: FULL FILE VERIFIED / READ PASS IN PROGRESS / PLOT-POV-REVISION CLUSTERS EXTRACTED / MANUSCRIPT TEST STARTED.

Key corrective mechanism:

Causality in fiction must not be reduced to simplistic linear mechanics. A scene may matter by amplifying irritation, unease, desire, relationship pressure or decision-readiness even when it does not directly cause the next external fact.

Therefore IVDIVO must distinguish:

`EVENT CAUSALITY`
`DECISION CAUSALITY`
`EMOTIONAL CAUSALITY`
`RELATIONSHIP CAUSALITY`
`EPISTEMIC CAUSALITY`

A scene can pass if it meaningfully changes one or more of these and that change later matters.

## Cross-source synthesis

### 1. Strong scene ≠ every scene is a mini-action thriller

Rosenfeld's intention/complication model is valuable for preventing vignette drift. LaPlante prevents it from becoming mechanical. A quiet scene can be structurally necessary when its consequence is emotional, relational or interpretive rather than immediately external.

### 2. Anti-staccato rule must preserve emphasis hierarchy

Le Guin confirms the problem in current LESSON ZERO fragments: isolated short sentences can be forceful, but they lose force when used as default cadence.

New revision sequence:

`IDENTIFY FUNCTION OF BREAK → KEEP TRUE IMPACT BREAKS → MERGE ACCIDENTAL CHOP → VARY SYNTAX → READ ALOUD → CHECK PARAGRAPH-LEVEL FLOW`

### 3. Repetition is allowed only if it develops

Recurring Ethan material about age/status/authority is not automatically redundant. It earns recurrence when each return changes at least one of:

`ACCESS | RELATIONSHIP | SELF-UNDERSTANDING | TACTIC | COST | RISK | FUTURE OPTION`

If none changes, it is thematic restatement and should be compressed, merged or cut.

## New production gates

### Gate DJ — Consequence Type
Every retained scene must materially alter at least one of: event state, decision state, emotional state, relationship state or knowledge state, and that alteration must matter later.

### Gate DK — Scene Intention Chain
Major scenes require a concrete intention that meets meaningful opposition/complication and produces a changed next intention.

### Gate DL — Quiet-Scene Legitimacy
A scene is not cut merely because no major external event occurs; emotional/relational/epistemic causality can justify it if later behavior depends on it.

### Gate DM — Developing Repetition
Recurring motif/theme/problem must return with changed context, meaning, cost or action. Pure restatement fails.

### Gate DN — Short-Sentence Scarcity
Short isolated narration is an emphasis resource, not default house style.

### Gate DO — Sentence-Contrast Test
Revision checks sentence length by local contrast and function, not fixed target length.

### Gate DP — Crowding/Leaping
Keep vivid, exact, consequential details; leap over low-value process and redundant transitions.

### Gate DQ — POV Fingerprint
Every POV scene must have a character-specific attention, knowledge, value and language filter.

### Gate DR — Read-Aloud Rhythm
After structural lock, every major chapter receives a read-aloud pass for accidental chop, syntactic bog, repetition and weak transitions.

### Gate DS — Mystery Counterevidence
Important clue sequences must include legitimate disconfirming or alternative evidence where appropriate; clues cannot all conveniently point in one direction.
