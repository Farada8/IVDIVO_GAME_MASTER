## 2. Mechanism A — See a Problem, Solve a Problem
Vorhaus's practical revision attitude is useful beyond standup: failed humor should be treated as a diagnosable craft event rather than defended as an expression of authorial intent.

### IVDIVO humor repair chain
`JOKE / WIT BEAT → READER/AUDIENCE RESPONSE → FAILURE TYPE → ISOLATE VARIABLE → PATCH → RETEST IN CONTEXT`

Potential failure types:
- setup unclear;
- assumed context missing;
- trigger/keyword placed too early;
- trigger/keyword buried after the release point;
- line belongs to the author rather than the character;
- joke duplicates the previous beat's function;
- joke follows a serious consequence too quickly;
- joke explains itself after landing;
- joke is understandable but does not fit the scene's pressure.

### Limit
A non-laugh is not proof a line is objectively bad. Audience, genre, character attachment, cultural context, and seriousness all matter. Use repeated or high-confidence response evidence, not one person's taste, before aggressive deletion.

## 3. Mechanism B — Setup Information Budget
A comic turn often works like a small inference problem. The audience needs enough setup to construct the expected direction, but the key information should arrive late enough to create the turn.

### Operational form
`REQUIRED CONTEXT → EXPECTATION → DELAYED KEY/TRIGGER → REINTERPRETATION → RELEASE`

### Failure modes
- too little context → confusion, no inference;
- too much context → punchline pre-solved;
- explanation after the punchline → second, weaker ending;
- repeated setup across speakers → scene loses speed.

## 4. Mechanism C — Tool-Driven Creativity Without Formula Forcing
Vorhaus explicitly advocates switching diagnostic tools when one way of looking at a story stops helping: scene want, theme, pivots, action/emotion, etc. The larger transferable principle is valuable for IVDIVO.

### IVDIVO Tool-Switching Protocol
When blocked:
1. name the actual craft problem;
2. identify the current lens being used;
3. ask whether the lens is generating useful distinctions;
4. if not, switch lens rather than forcing the material to satisfy the tool;
5. return to story evidence and reader effect;
6. keep only tools that improve the manuscript.

Example routing:
- weak scene → intention/consequence lens;
- flat chapter ending → handoff/reveal-ownership lens;
- samey characters → voice/relationship lens;
- joke not landing → setup/trigger/context lens;
- lore-heavy scene → action/decision lens;
- mystery too easy → evidence-ladder/counterevidence lens.

### Limit
Tools are not a license to run every checklist on every paragraph. Over-routing creates mechanical prose and revision noise.

## 6. New production gates

### Gate GG — Humor Diagnosis Before Deletion
Before deleting a failed joke, classify whether the problem is context, trigger placement, voice, density, timing, seriousness, or irrelevance.

### Gate GH — Humor Comprehension Prerequisite
The reader must possess the minimum context needed to solve the comic turn without an explanatory after-line.

### Gate GI — Trigger Placement
Place the recontextualizing word/phrase as late as natural syntax and character voice allow.

### Gate GJ — One-Variable Humor Revision
When testing a joke repair, change one main variable at a time where practical; otherwise the reason for improvement/failure becomes unknowable.

### Gate GK — Tool-Switching
If a diagnostic framework stops producing useful distinctions, switch frameworks rather than forcing the manuscript to fit it.

### Gate GL — Character Ownership of Wit
Every comic line must plausibly come from that character's worldview, vocabulary, status strategy, fear, habit, or relationship—not from a universal authorial joke engine.

### Gate GM — Humor Density Contrast
Dense banter requires quieter stretches. Do not make every speaker land a polished line in every exchange.

### Gate GN — No Joke Explanation Tail
After a comic turn lands, do not append a prose explanation of why it is funny unless misunderstanding itself is the dramatic point.

### Gate GO — Seriousness Override
Existing CRAFT-020 rule reinforced: injury, consent failure, moral cost, grief, fear, or accountability may require humor suppression or delay.

### Gate GP — Humor Retest in Scene Context
A line that works alone may fail inside the scene because it interrupts pressure, repeats a function, or gives the wrong character the emotional last word.
