## 1. EVIDENCE-DRIVEN COMPETENCE GATE
A technically capable character should usually advance by:

`OBSERVE → QUANTIFY → HYPOTHESIZE → TEST → CONFIRM/FAIL → UPDATE MODEL → ACT`

### PASS
- observation is specific;
- hypothesis is distinguishable from fact;
- test can in principle fail;
- result changes the model or action;
- competence reduces uncertainty without eliminating story pressure.

### FAIL
- protagonist simply knows the answer;
- equation/explanation does not change a decision;
- evidence is reverse-engineered to prove the preferred theory;
- every test succeeds immediately.

## 2. MINIMUM NECESSARY TECHNICAL DATA
Route technical exposition through a current problem:

`CHARACTER QUESTION → MINIMUM TECH DATA → TEST/ACTION → RESULT → NEW QUESTION/CHOICE`

Do not explain the whole system because the writer knows it. Explain the subset required to understand the present inference or decision.

## 3. INTELLIGENT MISTAKE GATE
Competent characters may be wrong through a reasonable limited model:

`AVAILABLE EVIDENCE → PLAUSIBLE MODEL A → NEW TEST → CONTRADICTION → MODEL B`.

The reader should be able to reconstruct why Model A looked reasonable. Avoid stupidity-for-plot.

## 4. FLASHBACK CURRENT-STATE PAYOFF
Flashback earns scene time when:

`CURRENT ANOMALY → MEMORY/PAST CONTEXT → CURRENT MODEL CHANGES → PRESENT ACTION CHANGES`.

If the past is interesting but current action/knowledge/relationship remains identical, compress or bank it.

## 5. LEGIBLE SPECIFICITY
Technical specificity must satisfy all three:
1. POV has a credible reason/capacity to use the term;
2. the reader can infer enough function from context;
3. the specificity changes understanding, action, risk, or character.

Precision without legibility becomes documentation rather than fiction.

## 6. TECHNICAL SCENE STATE-CHANGE GATE
After a technical scene, log at least one changed state:
- action/physical possibility;
- knowledge/evidence;
- relationship/trust;
- authority/access;
- responsibility;
- strategy/model;
- emotional commitment;
- future option space.

If none changes, the scene is a likely exposition loop.

## 7. COMPETENT COUNTERMODEL + MORAL COST
An opposing institution/person may be highly capable:

`REAL CAPABILITY + REAL URGENCY + REAL LEVERAGE + REAL BENEFIT + BLIND SPOT/COST`.

Do not flatten a competent countermodel into villainy. Equally, competence and urgency do not prove ethical legitimacy.

## 8. READER-MODEL UPDATE
For science/mystery inference track:

`WORLD FACT → OBSERVATION/TRACE → CHARACTER MODEL → READER MODEL → TEST → STATUS UPDATE`.

A reveal is useful when it changes what the reader can predict, fear, hope, or understand—not simply because it adds lore.

## 9. COMPETENCE-LOOP WATCH
Repeated units of:

`puzzle → calculation → correct answer`

risk monotony. Rotate what the reasoning changes: relationships, authority, cost, option space, ethics, or causal understanding.

## 10. FLASHBACK-CONVENIENCE WATCH
If every present uncertainty unlocks exactly the memory needed to answer it, memory becomes an answer dispenser. Require believable retrieval triggers, partial information, unresolved gaps, or delayed relevance.

## 11. RHYTHM / ANTI-FRAGMENTATION GATE
`INTENSITY ≠ SHORT-SENTENCE DENSITY.`

Technical reasoning often needs sustained syntax because the reader is constructing a model. Do not split every observation, calculation, reaction, and conclusion into separate one-line paragraphs.

Repair order:
`CAUSAL FUNCTION → INFORMATION ORDER → POV → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

## 12. CROSS-SOURCE SYNTHESIS
- **Herman / Zunshine:** evidence, reason, motive and world fact remain distinct statuses.
- **Swain:** causal continuity matters, but M/R should diagnose rather than dictate every sentence.
- **Bell / McKee:** competence can generate stronger responsibility and stronger countermodels without mandatory failure.
- **LaPlante / Zinsser / Clark:** select and structure information before polishing it.
- **Lodge / Prose:** suspense may slow time; short syntax is one contrast tool, not a universal pace control.

## 13. IVDIVO SCIENCE / ONTOLOGY FIREWALL
Weir's fictional science is not evidence for IVDIVO science or metaphysics.

For consciousness-practice material:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL CONCLUSION`.

Scientific-sounding exposition cannot elevate interpretation into fact.
