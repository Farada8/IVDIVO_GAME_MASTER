# IVDIVO Craft Study Batch 155
## Brandilyn Collins — Emotion Memory · Character Transfer · Ethical Firewall

Status: DRAFT / source FULL READ still in progress.

## 1. Mechanism worth keeping
Collins's useful core is not "feel exactly what the character feels." It is a transfer problem:

`AVAILABLE HUMAN EXPERIENCE / OBSERVATION → FELT MATERIAL → TRANSLATION THROUGH CHARACTER → SPECIFIC ACTION / PERCEPTION / LANGUAGE`

The important production question is therefore not whether the writer can summon a sufficiently intense private emotion, but whether the resulting prose belongs to the character and changes the scene.

## 2. Emotion Memory is optional, not mandatory
Cross-source correction from Stanislavski scholarship:
- Given Circumstances, objective, imagination, physical action, listening, relationship and setting can evoke useful feeling;
- deliberate autobiographical recall is one technique among several;
- Stanislavski's later system should not be collapsed into Strasberg-style personal recall;
- forcing personal emotion can detach the creator from the present action and circumstances.

### Gate B155-G01 — OPTIONAL MEMORY
No scene fails merely because the writer did not mine a personal memory.

### Gate B155-G02 — CIRCUMSTANCES FIRST
Before emotion-recall troubleshooting, verify:
`WHO / WHERE / WHAT JUST CHANGED / WHAT DO I WANT / FROM WHOM / WHAT CAN I DO NOW?`

### Gate B155-G03 — CHARACTER TRANSFORMATION
Personal material must be transformed through:
`VALUE + HISTORY + EMBODIMENT + RELATIONSHIP + OBJECTIVE + KNOWLEDGE LIMIT`.

### Gate B155-G04 — NO AUTHOR PROXY
If a character responds exactly as the writer would despite different history, body, role and relationships, diagnose author-proxy leakage.

## 3. Writer emotion, character emotion, reader emotion are different states

`WRITER FEELS X != CHARACTER FEELS X != READER FEELS X`

A writer may feel devastated while drafting a scene that reads melodramatically or vaguely. Conversely, controlled prose can produce strong reader effect without the writer being emotionally overwhelmed during composition.

### Gate B155-G05 — EFFECT TRANSFER TEST
After drafting an emotional scene, test:
1. What observable/POV material causes the reader inference?
2. Is it specific to this character?
3. Does it change action, relationship, decision or model?
4. Does a reader actually report the intended effect?

## 4. Ethical firewall
### Failure mode — TRAUMA-MINING-AS-CRAFT-DUTY
Do not require writers or collaborators to revisit personal trauma as proof of artistic seriousness.

Preferred escalation:
`GIVEN CIRCUMSTANCES → OBJECTIVE/RELATIONSHIP → IMAGINATION → OBSERVATION → ANALOGOUS LOW-RISK MEMORY → DIRECT PERSONAL RECALL ONLY IF VOLUNTARY AND USEFUL`.

## 5. Mystery / evidence firewall
Emotion is evidence of emotional state, not automatically of external truth.

`DISPLAY / FELT CERTAINTY → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`

Do not infer automatically:
- fear → guilt;
- hesitation → deception;
- confidence → truth;
- attraction → trustworthiness;
- distress → consent withdrawal unless communicated/established;
- vivid spiritual experience → ontology.

### Gate B155-G06 — EMOTION DOES NOT UPGRADE CLAIM STATUS
Evidence states remain:
`OBSERVED / REPORTED / INFERRED / HYPOTHESIS / CORROBORATED / CONTESTED / UNKNOWN`.

## 6. Conscious nonhuman persons
Human emotion-memory craft is anthropocentric and cannot be a personhood criterion.

Use:
`OWN PRIORITIES → OWN MODEL/EVIDENCE → RELATIONSHIPS → EMBODIMENT → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Gate B155-G07 — NO HUMANITY TEST
A conscious robot/distributed intelligence need not display human grief, facial leakage, autobiographical trauma or human nervous rhythm to be written as a full person.

## 7. YA application
Avoid the automatic equation:
`TEEN DEPTH = WOUND + BREAKDOWN + HEALING`.

Young-character depth can emerge from:
- first real responsibility;
- competing good values;
- autonomy vs coordination;
- belonging vs independence;
- attraction vs privacy;
- competence vs uncertainty;
- consent and boundaries;
- success that creates larger responsibility.

### Gate B155-G08 — NO MANDATORY WOUND
A major youth character does not need trauma as the source of every strong feeling.

## 8. Prose / rhythm application
Do not convert emotional richness into typographic fragmentation.

Bad automation:
`line → gesture → one-line thought → breath → line → body cue`.

Preferred:
`EMOTIONAL/RELATIONAL TURN → PARAGRAPH INTENT → SELECT LOAD-BEARING CUES → READER-STATE CONTINUITY → SENTENCE RHYTHM`.

### Gate B155-G09 — ONE PERCEPTUAL UNIT, ONE COHERENT SHAPE
If multiple microbeats form one perception/decision, allow a normal sentence or paragraph rather than forced fragments.

## 9. Cross-source synthesis
- Collins: personal emotion can provide raw felt material.
- Stanislavski scholarship: imagination, circumstances, action and relationship can be primary; direct recall is optional and historically contested.
- Lamott/LaPlante: protect discovery; diagnose after live material exists.
- Oatley/Iglesias: reader emotion is produced by simulated goals/concerns and narrative context, not by naming or privately feeling emotion.
- Zunshine/Herman: felt certainty does not equal verified motive or external cause.

## 10. IVDIVO production rule

`LIVE SCENE → IF EMOTION FEELS FALSE, DIAGNOSE CIRCUMSTANCES / WANT / RELATIONSHIP / POV / EMBODIMENT → GENERATE FELT MATERIAL BY ANY SAFE ROUTE → TRANSFORM THROUGH CHARACTER → RETEST READER EFFECT`.

Emotion Memory is therefore a **tool in the repair kit**, not a law of composition or authenticity.
