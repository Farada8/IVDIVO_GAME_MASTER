## 5. Highest-value mechanisms

### Purpose is not motive
`TRACKABLE PURPOSE / OBJECTIVE ≠ SELF-EXPLANATION ≠ MOTIVE HYPOTHESIS ≠ WORLD FACT`.

Character action can make purpose legible while motive remains uncertain even to the character.

### Importance-to-action
`PRIORITY / CONCERN → PRESENT OBJECTIVE → TACTIC → CHOICE → CONSEQUENCE`.

A value that never changes action is decorative.

### Continuing causal involvement
Ask:
`WHY DOES THIS AGENT REMAIN CAUSALLY INVOLVED?`

Accepted responsibility, relationship, evidence/consequence ownership, consent-based cooperation, role/access or physical constraint are valid adhesives. Death/threat is not mandatory.

### Competing values
`VALUE A + VALUE B + RELATIONSHIP + CURRENT COST + KNOWLEDGE → PRIORITY NOW → TACTIC`.

Therefore:
`TRAIT STABILITY ≠ BEHAVIORAL UNIFORMITY`.

### Background payment
Backstory enters only if it changes present salience, relation, tactic, model, evidence or option space.

### Experience is not destiny
`EXPERIENCE → CHARACTER-SPECIFIC INTERPRETATION → CURRENT MODEL / TACTIC`.

### Role is not personhood
`BOOK ROLE ≠ STORYWORLD PERSONHOOD`.

For nonhuman persons:
`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.
