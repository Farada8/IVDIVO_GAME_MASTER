## 1. CORE SYNTHESIS
Swain's early Chapter 2 can be operationalized as four linked decisions:

`STORYWORLD MATERIAL -> SELECTION -> ARRANGEMENT -> DESCRIPTION -> READER MODEL`.

The writer never transfers a world neutrally. The writer chooses what enters attention, orders it, and renders it through language. Each layer changes reader inference.

## 2. MECHANISMS
### B95-M01 — SELECTION IS ATTENTION DESIGN
Selection includes:
- whose experience is foregrounded;
- which action is shown;
- which detail is noticed;
- when it is noticed;
- what is omitted;
- what the reader is invited to infer.

IVDIVO gate:
`POV CAPACITY + PRESENT WANT + RELATIONSHIP + KNOWLEDGE -> NOTICED DETAIL -> READER INFERENCE`.

### B95-M02 — ARRANGEMENT CHANGES MEANING
The same facts in a different sequence create different emphasis and causal hypotheses.

IVDIVO gate:
`WORLD FACTS stay fixed; DISCOURSE ORDER may change; EVIDENCE STATUS may not be falsified.`

### B95-M03 — VIVIDNESS IS NOT BREVITY
Swain explicitly treats simplicity and brevity as conditional virtues and warns that brevity in the wrong place can harm the prose.

IVDIVO consequence:
`ACTION / SUSPENSE != SHORT-SENTENCE DENSITY`.

Sentence and paragraph length are selected by reader effect: accumulation, speed, continuous perception, technical reasoning, intimacy, shock, pause or contrast.

### B95-M04 — LEGIBLE SPECIFICITY
A more exact term only improves vividness if the reader can understand or infer it.

Gate:
`SPECIFIC TERM -> POV AUTHENTIC? -> READER LEGIBLE? -> FUNCTIONAL PAYOFF?`

If not, contextualize, simplify or defer.

### B95-M05 — CONCRETE DETAIL IS NOT A CHECKLIST
Concrete sensory detail should be selected for function, not accumulated across all senses.

Useful functions:
- POV characterization;
- physical possibility/constraint;
- relationship signal;
- evidence;
- world rule;
- mood/rhythm;
- memory;
- causality.

### B95-M06 — WORLD DATABASE FILTER
For a large saga:
`WORLD DATABASE >> BOOK MATERIAL >> SCENE MATERIAL >> SENTENCE MATERIAL`.

A detail is not owed page space merely because it exists in canon.

## 3. CROSS-SOURCE SYNTHESIS
### Swain + Francine Prose + Le Guin + Lodge + Zinsser + Clark
Convergence: short prose is not inherently stronger prose. Rhythm and clarity depend on function and contrast.

### Swain + Zinsser
Productive tension:
- Zinsser: remove clutter and inflated language.
- Swain: do not confuse simplicity/brevity with the primary goal.

Synthesis:
`CUT NONFUNCTIONAL COMPLEXITY; PRESERVE NECESSARY COMPLEXITY AND VIVID EXPERIENCE.`

### Swain + Fludernik/Chatman
Swain's arrangement layer corresponds to discourse organization. Repair order before rewriting world facts.

### Swain + Zunshine/Herman
Order and interpretation may alter the reader's model but must not silently upgrade inference into fact.

### Swain + Wolf
Large-world production requires aggressive selection. Saga Bible proves the world to the studio; prose only needs to prove what the current story uses.

## 4. FAILURE MODES
- **SELECTION-BY-LORE:** detail chosen because it exists in the bible rather than because this POV/story needs it.
- **VIEWPOINT LEAK:** narrator supplies information the focal character cannot know or naturally attend to.
- **DISCOURSE-ORDER CHEAT:** clue order makes an interpretation look factual without fair evidence.
- **BREVITY WORSHIP:** cuts made because shorter is assumed stronger.
- **SHORT-SENTENCE FETISH:** suspense/action rendered with monotonous fragments.
- **TECHNICAL-PRECISION OPACITY:** exact terminology reduces reader understanding.
- **JARGON PRESTIGE:** specialist vocabulary used to signal sophistication rather than meaning.
- **SENSORY CHECKLIST:** forced sight/sound/smell/touch/taste inventory.
- **GENERIC-NOUN FOG:** vague nouns where specificity would change the imagined event.
- **VIVIDNESS-AS-OVERWRITING:** maximum sensory/metaphorical density mistaken for vividness.
- **READER-LEXICON ASSUMPTION:** prose assumes specialist knowledge not earned by context.

## 5. IVDIVO PRODUCTION GATES
### GATE B95-01 — DETAIL OWNERSHIP
For each unusual detail ask:
1. Who notices it?
2. Why this person now?
3. What does it do?
4. Would another POV notice something else?

### GATE B95-02 — EVIDENCE ORDER FAIRNESS
For every mystery reveal:
`fact -> source -> placement -> reader inference -> later correction/payoff`.
No authorial lie.

### GATE B95-03 — TECHNICAL TERM LEGIBILITY
A specialist term must be either:
- already established;
- inferable from context/action;
- necessary to a character's authentic cognition;
- or immediately anchored without lecture.

### GATE B95-04 — ANTI-FRAGMENTATION
Before editing sentence length:
`scene necessity -> duration -> show/tell -> POV -> dialogue mode -> paragraph intent -> reader-state continuity -> sentence rhythm -> word choice`.

### GATE B95-05 — POST-MONEY NORMALITY
Do not explain 'this society has no money' abstractly if ordinary action can prove it. Select a concrete situation where ordinary goods are easy but time, consent, trust, role, relationship or unique opportunity are not manufacturable.

### GATE B95-06 — ROBOT POV PERSONHOOD
A conscious robot's selected details should follow its embodiment, relationships, knowledge and goals. Do not default to sterile sensor readouts as personality.

### GATE B95-07 — CONSCIOUSNESS-SCHOOL TERMINOLOGY
Precision inside a school does not upgrade its interpretation to ontology. Keep:
`observation -> reproducible effect -> school interpretation -> competing interpretation -> possible ontological claim`.

### ORBITAL YOUTH / FUTURE BOOKS
Worldbuilding scenes should demonstrate a rule through a person making a choice under that rule. Avoid catalogues of habitats, technologies and institutional vocabulary.

### MYSTERY / SCIENCE FICTION
When the same evidence can support multiple models, prose order may manage suspense but must preserve provenance. Technical nomenclature cannot substitute for proof.
