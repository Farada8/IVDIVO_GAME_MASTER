## Linda Seger — Subplots · Momentum · POV · Scene Design · Unity
Status: DRAFT / SOURCE FULL READ STILL IN PROGRESS

## PURPOSE
Operationalize mechanisms confirmed by strict sequential reading of Linda Seger, *Making a Good Script Great*, Chapters 2–7, while separating durable craft functions from screenplay-specific formulas.

## CORE SYNTHESIS
Seger's strongest contribution is not page arithmetic. It is the ability to ask whether structural elements materially change the story state.

Primary IVDIVO model:

`PRIOR STATE → EVENT / REVELATION / DECISION → MATERIAL CHANGE → NEW GOVERNING PROBLEM / STRATEGY → DOWNSTREAM CONSEQUENCE`

## PRODUCTION GATES

### B160-G01 — FUNCTIONAL TRANSITION, NOT PERCENTAGE
A turn must alter objective, option space, evidence status, relationship/consent, authority/access, responsibility, strategy/model, price, or future options.
Do not retrofit novels/audio to screenplay page percentages.

### B160-G02 — MIDPOINT RE-WEIGHTING
Midpoint = material re-weighting of the story model.
It may be a success, stronger evidence, new responsibility, relationship shift, countermodel, or failure.
No mandatory false victory/false defeat.

### B160-G03 — SUBPLOT CAUSAL PAYMENT
A subplot must change the main causal engine or decisions that later affect it.

`LOCAL OBJECTIVE → LOCAL CHANGE → EFFECT ON A-STORY → PAYOFF`

### B160-G04 — THREAD / SUBPLOT SEPARATION
A recurring relationship, person, motif, or activity need not become a full subplot.
Do not over-architect texture.

### B160-G05 — MOMENTUM IS NOT SPEED
`MOMENTUM = CAUSAL STATE CHANGE + PRESSURE ON THE NEXT OPTION`

Fast physical activity may have low momentum.
A quiet evidence or relationship turn may have high momentum.

### B160-G06 — NO MOMENTUM-BY-EXPLOSION
If the middle feels weak, diagnose the stalled state variable before adding attack, chase, anomaly, villain, countdown, or catastrophe.

### B160-G07 — IMPLICIT EVENT / CONSEQUENCE
Not every important event needs full real-time dramatization.

`OFFSCREEN EVENT / SUMMARY → VISIBLE CONSEQUENCE → NEXT ACTION`

### B160-G08 — FAIR SURPRISE
A reveal may overturn inference, not established fact.

`TRUE TRACE → MODEL A → NEW CONTEXT/EVIDENCE → MODEL B → RETROSPECTIVE SUPPORT`

### B160-G09 — SCENE-SEQUENCE FUNCTION
A multi-scene sequence may possess the local beginning/middle/end that individual scenes do not need.

`SEQUENCE QUESTION → LINKED STATE CHANGES → PAYOFF`

Use for investigation, rescue, training, technical tests, travel with causal stages, or relationship negotiation.

### B160-G10 — POV ACCESS BUDGET
Every POV switch must buy unique information, action, relationship pressure, irony, lived consequence, or decision ownership.

`NEW POV → UNIQUE VALUE → EFFECT ON READER/CHARACTER MODEL`

### B160-G11 — CROSSCUT CAUSALITY
Crosscutting is not justified merely because two strands are simultaneous.
Each cut must change anticipation, interpretation, pressure, or eventual convergence.

### B160-G12 — NARRATIVE RESTATEMENT TEST
Voiceover/narration/commentary must add contrast, layer, interiority, provenance, or compression.
Delete commentary that only explains what action already made clear.

### B160-G13 — FLASHBACK PRESENT-CONSEQUENCE
Full flashback earns reader time only if it changes present interpretation, evidence, relationship, strategy, or decision.
Otherwise prefer summary/back-flash or omit.

### B160-G14 — SCENE MULTIFUNCTION WITHOUT CHECKLIST
Plot, character, theme, image/world, relationship and evidence are available scene functions.
A scene need not perform every function.

### B160-G15 — EXPOSITION OWNERSHIP
`WHO NEEDS/WANTS X? → WHY NOW? → SOURCE/ACCESS → MINIMUM NECESSARY INFORMATION → CHANGED ACTION/MODEL`

Author desire to brief the reader is not sufficient motivation for dialogue.

### B160-G16 — SCENE ENTRY / EXIT
First identify the exit state.
Then enter at the latest viable point that preserves orientation, pressure and causality.
Leave after the relevant change, not after every logistical aftermath beat.

### B160-G17 — DEVELOPING REPETITION
Motif, image, phrase, sound, object, action or thematic recurrence must return with altered context/function/meaning.

`REPEAT → TRANSFORM`

### B160-G18 — SETUP / PAYOFF FAIRNESS
Important payoff requires prior support.
Support need not be conspicuous, but must be recoverable retrospectively.

### B160-G19 — CHANGE IMPACT MAP
A structural revision must trace effects backward and forward:
- setup;
- clue provenance;
- relationship state;
- character motive;
- authority/access;
- later payoff;
- series continuity.

### B160-G20 — MACRO BEFORE MICRO
Do not polish sentences inside a scene whose structural function, POV, evidence logic, or causal placement is still wrong.

## CROSS-SOURCE COMPARISON

### Seger × Bell / Swain / Scofield
Convergence:
- meaningful state change matters more than spectacle;
- scenes and sequences require causal relation;
- repeated process can be compressed;
- planning tools are diagnostic, not sacred.

Seger correction:
- screenplay act/page arithmetic is form-specific.

### Seger × Brody
Brody's false victory/false defeat midpoint is one usable pattern.
Seger confirms a midpoint may simply strengthen/re-focus the central story.
IVDIVO keeps the broader function.

### Seger × Fludernik / Card / Kress
Seger's concern with POV/information access is useful.
Her stronger pressure toward one controlling POV is not universal.
IVDIVO permits controlled multiple POV when switching cost is paid.

### Seger × LaPlante / Rosenfeld / Prose / Lodge
Her concern that flashback may stall present action is a useful warning, not a ban.
Full flashback remains valid if it changes the present causal/evidentiary state.

## ANTI-CHOPPY PROSE CONSEQUENCE
`MOMENTUM ≠ SPEED ≠ SHORT-SENTENCE DENSITY`.

Revision order:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → EVENT TARGET → POV/EVIDENCE → EXPOSITION OWNERSHIP → PARAGRAPH INTENT/READER-STATE → SENTENCE RHYTHM → WORDING`.

If momentum is weak because no meaningful state changes, fragmenting syntax cannot repair it.
