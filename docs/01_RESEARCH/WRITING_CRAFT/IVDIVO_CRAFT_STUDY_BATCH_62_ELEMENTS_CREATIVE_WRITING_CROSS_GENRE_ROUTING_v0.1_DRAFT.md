## 1. WHY THIS SOURCE MATTERS

The source is unusual in the IVDIVO library because it crosses fiction, poetry and nonfiction. Its highest value is not a new story formula. It demonstrates repeatedly that craft choices are **routing decisions**: different modes solve different reader-effect problems.

Core synthesis:

`STORY FUNCTION → MODE → POV / DIALOGUE → PARAGRAPH / RHYTHM → WORDING`

not:

`preferred style rule → force all material into it`.

## 2. NEW PRODUCTION GATES

### B62-G01 — STATE CHANGE BEFORE SCENE COUNT
A sequence progresses only when action, relationship, information, status, commitment or meaning changes.

### B62-G02 — SHOW/TELL ROUTER
No blanket "show don't tell." Route by time-scale and consequence.

### B62-G03 — HALF-SCENE OPTION
Compress low-value process while preserving one concrete action/line that carries character or causality.

### B62-G04 — TACTIC-SHIFT CHARACTERIZATION
Differentiate characters by what they do after the first tactic fails.

### B62-G05 — DIALOGUE MODE ROUTER
Use `summary → indirect → direct` according to the importance of exact wording.

### B62-G06 — TRIGGER-WORD CONTINUITY
Dialogue should react to specific language, omission, gesture or status movement rather than alternate monologues.

### B62-G07 — VOICE ≠ SLANG
Voice = attitude + attention + rhythm + relationship-specific tactic.

### B62-G08 — SETTING AS CAUSAL SYSTEM
If place changes no option, behavior, relation or inference, description is a compression candidate.

### B62-G09 — STILLNESS CAN CHANGE STATE
Quiet scenes pass when they alter later behavior/interpretation/relationship.

### B62-G10 — POV ACCESS MATRIX
Track observable / known / inferred / unknown / impossible-to-know.

### B62-G11 — PARAGRAPH INTENT
Short paragraphs require a job. Random fragmentation is a defect even when each sentence is individually clear.

### B62-G12 — RHYTHM EXPECTATION/BREAK
Rhythm comes from pattern and modulation. No target percentage of short sentences.

### B62-G13 — READ-ALOUD PASS
After structure, check breath, stress, sound repetition, rhyme, landing and monotony.

### B62-G14 — METAPHOR AFTER LITERAL CLARITY
Establish what happens before beautifying it.

### B62-G15 — DETAIL DOUBLE-PAY
Prefer details that perform multiple story/reader functions.

### B62-G16 — SYNTAX AGENCY
Sentence order changes perceived agency, emphasis and suspense.

### B62-G17 — MODE MIX
Use dramatic / narrative / lyrical modes deliberately. Avoid all-scene or all-summary prose.

### B62-G18 — SPECULATION LABEL
`FACT / MEMORY / REPORT / INFERENCE / SPECULATION` must remain distinct.

### B62-G19 — RESEARCH MAY CHANGE THE MODEL
Research is allowed to contradict the initial theory and redirect story design.

### B62-G20 — REVISION SCALE ROUTER
Line edit cannot repair scene, sequence or engine defects.

## 4. CROSS-SCHOOL POSITION

**Against formula monoculture:** aligns with LaPlante/Lodge and limits Truby/McKee/Brody where their models risk becoming mandatory architecture.

**For causality:** does not endorse shapelessness. State change and downstream consequence remain non-negotiable.

**For character:** aligns with Corbett/Card/McKee Character on relation-specific behavior; adds tactic-shift exercises.

**For mystery:** aligns with Zunshine on information provenance and credible model revision.

**For worldbuilding:** aligns with Wolf/Cambridge on world-as-lived-system rather than encyclopedia.

## 5. IVDIVO PROSE PIPELINE

For cadence / "обрубки":

`CAUSAL ENGINE`
→ `SCENE NECESSITY`
→ `SHOW/TELL / HALF-SCENE`
→ `POV ACCESS`
→ `DIRECT/INDIRECT DIALOGUE`
→ `PARAGRAPH INTENT`
→ `RHYTHM`
→ `SOUND`
→ `WORDING`.

Never start with sentence-length statistics.
