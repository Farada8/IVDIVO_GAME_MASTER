# IVDIVO CRAFT STUDY — BATCH 195
## John Truby — The Anatomy of Genres
### Genre Contract · System Models · Cross-Genre Causality · Relationship Personhood · Epistemic Firewalls

**Source status:** Core #11 strict-complete.

## Core synthesis
`GENRE CONTRACT ≠ STORY LAW`.

Use genre chapters as libraries of reader expectations and mechanisms, not as universal psychology, metaphysics, gender theory, sociology, history, or mandatory beat lists.

## Production engine
`DOMINANT CAUSAL ENGINE → PRIMARY GENRE PROMISE → SECONDARY GENRE FUNCTIONS → CAUSAL PAYMENT / PAYOFF → READER EFFECT`.

A secondary genre strand is admitted only when it changes the same main engine or a major later choice.

## 1. Genre-mixing firewall
Truby strongly advocates mixing genres and ultimately “all genres all the time.” IVDIVO rejects the quantity rule.

Gate:
`GENRE B → WHAT UNIQUE FUNCTION? → WHAT CHANGED STATE? → WHAT DOWNSTREAM DEPENDENCY?`

No causal payment = remove/bank.

## 2. World/system causal gate
`WORLD RULE / TECHNOLOGY / INSTITUTION → AFFORDANCE / CONSTRAINT → PERSON-SPECIFIC CHOICE → CONSEQUENCE`.

This is the most reusable mechanism across SF/Fantasy/Western/Gangster/Myth.

## 3. Institutional model-capture gate
`MODEL / METRIC / INCENTIVE → ACCESS / STATUS / REWARD → EVIDENCE FILTER → LOCALLY RATIONAL BEHAVIOR → AGGREGATE EFFECT → MODEL UPDATE OR ESCALATION`.

This supports competent institutions with genuine benefits and genuine blind spots.

## 4. Competence and strategy
`TACTIC ≠ STRATEGY`.
`TACTICAL WIN ≠ STRATEGIC SUCCESS`.

Protect:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

## 5. Mystery / Detective
Use Truby's split between what happened and how the investigator learns it, but upgrade with modern IVDIVO evidence discipline:

`WORLD FACT → TRUE TRACE → SOURCE LINEAGE → ACCESS → MODEL A/B/C → DISCRIMINATING TEST → CORROBORATION STATUS → ACTION`.

No known-POV information may be hidden solely to manufacture surprise.

## 6. Relationship braid
Retain only the causal part of Truby's Love architecture:

`INDEPENDENT LIFE GOAL A ↔ INDEPENDENT LIFE GOAL B → SUSTAINED CONTACT → TRUST / DESIRE / BOUNDARY / DISCLOSURE CHANGE → RELATIONSHIP STATE → NEXT EXTERNAL CHOICE`.

Reject missing-half psychology, marriage as universal endpoint, gender-complementarity essence and mandatory breakup/reunion structures.

## 7. Long-term relationship / contract gate
Useful beyond romance:
`EXPECTATION / ROLE / BOUNDARY → DAILY PRESSURE → NEGOTIATION / CARE / REFUSAL → NEW TERMS → CONSEQUENCE`.

This is useful for friendship, family, crews, human–robot partnership and institutions.

## 8. Alternative-future relationship gate
Multiple suitors/partners/allies are useful when each represents a materially different future life/value/cost configuration.

`PERSON / RELATIONSHIP OPTION → FUTURE MODEL → COST / BENEFIT → CHARACTER CHOICE`.

Do not turn people into prizes or archetypal fragments.

## 9. Recognition / revelation
`MIS-MODELLED STATE → DISCRIMINATING EVIDENCE / EXPERIENCE → MODEL UPDATE → CHANGED ACTION / RELATIONSHIP`.

Recognition is earned by evidence/experience; it does not create fact by declaration.

## 10. World-transition mismatch
`OLD MODEL / CAPABILITY → NEW SYSTEM RULE → AFFORDANCE MISMATCH → STRATEGY UPDATE / FAILURE / REPOSITIONING`.

Useful for changing orbital institutions and cultures without importing Western-frontier fatalism.

## 11. Personhood firewall
Truby repeatedly uses robot/nonhuman becoming-human structures. IVDIVO explicitly rejects this as a personhood metric.

`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

`NONHUMAN EMBODIMENT ≠ MONSTER ≠ MORAL INCOMPLETENESS`.

## 12. Epistemic firewall
Genre cosmologies, spiritual interpretations and fictional science are not evidence.

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Red Team — major rejected claims
- universal seven-step Story Code;
- all beats mandatory;
- 3–4 genres or “all genres all the time” required;
- genre ladder as hierarchy of consciousness;
- story as universal religion;
- technology level = consciousness level;
- Jungian archetypes as psychological fact;
- Great Chain / artist/visionary/higher-person hierarchy;
- masculine/feminine essence and gendered psychology;
- marriage/romantic union as completion of self;
- lover as unique missing half;
- Ghost/wound/Need mandatory;
- final battle/self-revelation mandatory;
- violence/life-death as Action essence;
- social-stage theories as history/science;
- robot becoming human as development;
- universal consumer/shame/guilt cultural ladders.
