## PRIMARY MECHANISMS EXTRACTED

### 1. Middle Engagement Engine — IVDIVO Adaptation

Bell's `confrontation` is retained in a broader form:

`CURRENT OBJECTIVE / RESPONSIBILITY → MEANINGFUL RESISTANCE → RESPONSE / MODEL UPDATE → NEW STRATEGY → CONSEQUENCE → NEXT PRESSURE`

Resistance can be another person, institution, environment, missing information, incompatible legitimate goals, consent limits, relationship history, or a world rule.

### 2. Stakes ≠ Mandatory Death

Bell's physical / psychological / professional death taxonomy is treated as a commercial heuristic, not a universal production law.

IVDIVO asks instead:

`WHAT SPECIFICALLY MATTERS? → WHAT CAN BE LOST / DAMAGED / FORECLOSED? → WHY DOES THIS PERSON CARE? → HOW DOES THE LOSS CHANGE LATER ACTION?`

Legitimate non-death stakes include trust, consent, relationship, responsibility, evidence integrity, reputation, unique access/opportunity, role, time, belonging, mastery, privacy, and safety.

### 3. Adhesive → Commitment / Constraint Coherence

Bell's adhesive is useful when reframed as:

`WHY DOES THIS PERSON REMAIN CAUSALLY ENGAGED?`

Possible IVDIVO adhesives:
- accepted responsibility;
- evidence that ethically requires response;
- relationship obligation freely undertaken;
- consent already given or specifically withheld;
- bounded authority;
- physical/world constraint;
- unresolved harm caused partly by the character's own action;
- a promise or commitment;
- a goal that cannot be achieved without resolving the present engine.

Do NOT manufacture kidnapping, debt, poverty, death, secret villainy or arbitrary confinement merely to trap a character inside the plot.

### 4. ARM — Corrected Beyond Action Monoculture

Bell: Action → Reaction → More Action.

IVDIVO version:

`ATTEMPT / ACTION → WORLD / PERSON RESPONSE → EMOTIONAL / RELATIONAL / EPISTEMIC PROCESSING → STRATEGY CHANGE → NEXT ACTION`

A reaction may be quiet and still causally active if it changes a later decision, relationship, evidence status, obligation or model.

### 5. Qualitative Escalation

Escalation need not mean bigger danger.

Rotate pressure type:

`TECHNICAL → RELATIONAL → EVIDENTIARY → INSTITUTIONAL → CONSENT → SOCIAL → OPERATIONAL → PERSONAL RESPONSIBILITY`

A technically smaller event can be a stronger middle beat if it changes what a person is allowed, willing, or able to do.

### 6. Societal Stakes Without Scale Inflation

Bell's societal stakes are useful only when the surrounding system causally changes the local story.

`SOCIAL RULE / CULTURAL EXPECTATION / PUBLIC RESPONSE → LOCAL OPTION CHANGES → CHARACTER CHOICE → CONSEQUENCE`

Do not add war, collapse, conspiracy or civilization-level danger merely because the middle feels quiet.

### 7. Middle Problem Router

Before adding plot material, diagnose:

`STORY DEFECT? / SCENE DEFECT? / REPETITION? / LOW CONSEQUENCE? / WEAK ENGAGEMENT? / WRITER FATIGUE?`

Bell's `Wall` insight is retained strongly:

**WRITER FATIGUE ≠ STRUCTURAL DEFECT.**

Do not add a subplot, new villain, accident or revelation merely because the drafting process feels difficult.

### 8. Lethargic Middle — Safer IVDIVO Repair Order

Before Bell's generators `add complication / character / subplot`, test:

1. Is the current objective still specific?
2. Has the last consequence actually changed the next strategy?
3. Are scenes repeating the same pressure geometry?
4. Is a relationship/evidence/authority state available for change?
5. Is the problem simply writer fatigue?
6. Only then generate new complication / character / subplot.

### 9. Overweight Middle — Structural Compression Before Line Edit

`REDUNDANT CHARACTER → COMBINE/CUT`

`FLOATING SUBPLOT → ABSORB INTO MAIN ENGINE / BANK / CUT`

`REPEATED MEETING / PROCESS → SUMMARY / INDIRECT / MERGE`

`SCENE WITH NO NEW STATE → REBUILD / COMPRESS / CUT`

This directly precedes any sentence-level polishing.

### 10. Subplot Organicity

A subplot earns space when it changes the dominant engine:

`SUBPLOT EVENT → CHANGES A-STORY DECISION / RESOURCE / RELATIONSHIP / EVIDENCE / COST → LATER PAYOFF`

Romance, family, mystery, school life or robot relationships are not automatically useful merely because they increase emotional material.

## CROSS-SOURCE SYNTHESIS

- **Bell + Hodgins:** a middle must develop, not merely repeat conflict at higher volume.
- **Bell + Rosenfeld:** next intention should grow from prior consequence; repeated obstruction is not progression.
- **Bell + Truby/McKee:** resistance should force strategy/model change; IVDIVO rejects formulaic act percentages and mandatory death stakes.
- **Bell + LaPlante/Ribó:** quiet emotional/epistemic/relationship causality can be real causality.
- **Bell + Cambridge SF:** societal scale does not make SF stronger unless it changes local human/nonhuman action.
- **Bell + Lamott:** distinguish story trouble from writer-process trouble before inflating the book.

## FAILURE MODES ADDED

1. Death-Stakes Compliance — artificial death/ruin added because craft theory says stakes must be ultimate.
2. Escalation-by-Volume — every later beat is only louder, larger or more dangerous.
3. Adhesive-by-Hostage — characters are trapped by contrivance instead of earned responsibility/constraint.
4. ARM Monoculture — action beats leave no causal room for thought, relationship or evidence processing.
5. Writer-Fatigue Story Inflation — drafting exhaustion misdiagnosed as need for new plot.
6. Midbook Character Injection — a new person is added solely to create trouble and has no independent storyworld life.
7. Subplot Defibrillator — romance/family/mystery added only because the middle feels slow.
8. Societal-Stakes Inflation — civilization-level trouble added without local causal necessity.
9. Redundant Ally Fog — multiple supporting characters perform the same function.
10. Middle Meeting Loop — discuss → review → explain → discuss, without changed state.
11. Stakes Ledger Without Choice — losses get bigger but strategy/decision does not change.
12. Post-Money Regression — Bell's professional/economic examples accidentally reintroduce wage/rent/credit logic into orbital society.

## IVDIVO CANON FIREWALLS

- Post-money orbital society remains locked; professional-role examples must be translated into role/responsibility/trust/qualification, not wage dependence.
- Conscious robots retain independent personhood, motives, consent and refusal rights.
- Human consciousness-transfer/body-swapping is not imported from genre examples.
- Specialist consciousness schools retain evidence-status separation; school interpretation is not world ontology.
