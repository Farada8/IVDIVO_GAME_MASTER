# CLAIM EXTRACTION
## Strong craft claims retained
1. Fiction craft is a system of interacting tools, not a single secret.
2. Creation and criticism are different cognitive/production phases.
3. Meaning depends on selection and arrangement, not just factual content.
4. Reader experience is mediated through a focal person's values, knowledge and perception.
5. Cause/reaction legibility matters, but should not be applied mechanically.
6. Scenes and processing units have different temporal and dramatic functions.
7. Story progression requires changed states, not merely more incidents.
8. Delay and complication are structurally different.
9. Tension requires modulation; peaks gain force through valleys.
10. Character is revealed strongly through behavior under varied pressure.
11. Research and planning must serve production rather than replace it.
12. Revision and polishing are distinct operations.
13. Structural cutting should occur at the level of the structural defect.
14. Sentence length is functional; excessive short sentences can become choppy.
15. Writer-specific recurring-error checklists are useful after general craft principles are understood.

## Claims treated as historical / non-authoritative
- 1960s publishing-market assumptions;
- postal submission mechanics;
- dated gender and sexual-role assumptions;
- poetic-justice / reward-punishment expectations as universal reader psychology;
- lack/compensation and `secret self` as scientific personality laws;
- universal reader desire for fear/tension/scapegoat;
- mandatory disaster/death logic.

# MECHANISM EXTRACTION
## M1 — Creation / Critique Router
`DISCOVER → DRAFT → DISTANCE → DIAGNOSE → REVISE → POLISH`.

Use specialist desks sequentially rather than making every specialist veto every generating sentence.

## M2 — Selection / Arrangement / Description
`STORYWORLD MATERIAL → SELECT WHAT THIS POV NEEDS/NATURALLY NOTICES → ARRANGE FOR CAUSAL/READER EFFECT → RENDER CLEARLY`.

## M3 — Motivation / Reaction Audit
Use after live drafting:
`STIMULUS / EVENT → PERCEPTION → CHARACTER-SPECIFIC RESPONSE → CONSEQUENCE`.

Do not write prose as a mechanical M/R metronome.

## M4 — Scene / Processing Router
External attempt:
`PRESENT WANT → PRESSURE / SUPPORT → TACTIC → OUTCOME → CHANGED STATE`.

Processing when needed:
`CONSEQUENCE → INTERPRETATION / EMOTION → OPTION SET → DECISION / COMMITMENT → NEXT STRATEGY`.

Processing may be immediate, delayed, embedded or implied through later changed behavior.

## M5 — Commitment Transition
`DISTURBANCE / OPPORTUNITY → OPTIONS OPEN → ACCEPTED RESPONSIBILITY / CHOICE → NEW OBLIGATIONS + NEW OPTIONS → SUSTAINED MAIN ENGINE`.

## M6 — Middle State Change
Every substantive middle unit changes a downstream-relevant state:
- action/social situation;
- knowledge/evidence;
- relationship;
- authority/access;
- responsibility;
- strategy/model;
- emotional commitment;
- future option space.

## M7 — Delay / Complication Distinction
`DELAY = time/logistics cost`.
`COMPLICATION = changes downstream possibility/state`.

## M8 — Peaks / Valleys
`PRESSURE PEAK → CONSEQUENCE → LOWER-PRESSURE PROCESSING / ORDINARY LIFE → MODEL/RELATION CHANGE → NEXT STRATEGY → NEXT PEAK`.

## M9 — POV Orientation Cost
`FOCAL ORIENTATION OWNER != HERO LABEL != POV ACCESS OWNER`.

A POV switch must purchase unique evidence, action, lived consequence, relationship pressure, countermodel or decision.

## M10 — Character Under Varied Pressure
`WANT → RELATIONSHIP CONTEXT → PRESSURE → CHARACTER-SPECIFIC TACTIC → CHOICE → CONSEQUENCE`.

Relation-specific behavior is more useful than biography-only characterization.

## M11 — Cast Economy + Personhood
Merge redundant narrative functions where useful, but preserve:
`BOOK FUNCTION != STORYWORLD PERSONHOOD`.

## M12 — Research Balance
`STORY QUESTION → TARGETED RESEARCH → ENOUGH EVIDENCE TO MAKE THE STORY DECISION → STOP / WRITE`.

## M13 — Flexible Planning
`PLAN = HYPOTHESIS`.

`PLAN → DRAFT → LIVE MATERIAL → REPLAN IF CHARACTER/CAUSAL/CANON GAIN IS REAL`.

## M14 — Revision / Polishing Separation
Revision changes structure, order, scene function, character behavior, evidence architecture or inclusion.
Polishing changes clarity, rhythm, diction, local flow and line-level impact.

## M15 — Cutting at Defect Level
`MACRO REDUNDANCY → MACRO CUT/MERGE`.
`MICRO REDUNDANCY → MICRO CUT`.

## M16 — Sentence Rhythm
`READER EFFECT → DURATION/RHYTHM → SENTENCE ARCHITECTURE`.

No short-sentence KPI.

## M17 — Local Ending / Proof Ceiling
`BOOK QUESTION → BOUNDED DECISIVE ACTION → CONSEQUENCE → COST → LOCAL RESOLUTION → AFTERMATH → CHANGED STATE → OPTIONAL SAGA VECTOR`.

Evidence may prove local mechanism without proving global ontology.

# CROSS-SOURCE COMPARISON
## Strong convergence
### Lamott + LaPlante
Discovery first; criticism/revision later; do not paralyze generation with simultaneous rules.

### Rosenfeld + Bell Plot & Structure
Scene consequence, processing, transition economy, flexible planning, macro repair before prose polish.

### McKee / Truby
Swain shares causal pressure logic, but IVDIVO rejects converting these systems into mandatory act/beat templates.

### Lodge + Prose + Le Guin + Zinsser
Sentence length and paragraphing are functional tools, not quality metrics. Swain's own warning about choppiness supports the same conclusion.

### Card + Corbett + Kress + McKee Character
Character becomes legible through choices, relationships and behavior under pressure, not merely trait lists.

### Zunshine + Herman
Narrative causal explanation is not verified causality; observed behavior does not uniquely prove motive.

### Wolf
Research/world database may be large while book narrative remains selective.

# IVDIVO OPERATIONALIZATION
## ONE MAIN STORY
Use Swain's causality/state-change tools only if strands pay into the dominant engine.

`LOCAL STRAND ACTION → CHANGES MAIN ENGINE / ANOTHER STRAND → DOWNSTREAM CONSEQUENCE → PAYOFF`.

## ORBITAL YOUTH
Prefer qualitative pressure rotation over louder technical failure:
`operational → relationship → evidence → ordinary life → responsibility → consent/personhood → technical → public/social → personal → decisive local problem`.

Competence may produce real success:
`SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Post-money stakes remain trust, consent, time, role, reputation, mastery, relationship, unique opportunity, responsibility and safety — not disguised credits/rent/salary.

## CONSCIOUS ROBOTS
Named conscious robots require:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Human evaluation of a robot is not robot motive.

## CONSCIOUSNESS SCHOOLS
Maintain:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL CLAIM`.

Feeling, terminology and institutional prestige never substitute for evidence.

## MYSTERY / EVIDENCE
Keep:
`WORLD FACT → TRACE/SOURCE → POV INTERPRETATION → DISCOURSE ORDER → READER MODEL`.

Narrative ordering may control suspense but may not change what evidence actually proves.

## ANTI-FRAGMENTATION / LINE EDIT
Final router:
`BOOK ENGINE / CAUSALITY → CHAPTER FUNCTION → SCENE NECESSITY → ORDER/DURATION/FREQUENCY → SHOW/TELL → POV/EVIDENCE → DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Short sentences/fragments remain available for specific effects. A row of state-neutral microbeats is first tested for summary, merge, paragraph integration or deletion.

# FINAL SYNTHESIS
The durable Swain is not a rigid scene/sequel formula. It is a layered causal-production toolkit:

`LIVE MATERIAL → CAUSAL LEGIBILITY → CHANGED STATE → CHARACTER-SPECIFIC RESPONSE → MODULATED PRESSURE → FLEXIBLE PLAN → STRUCTURAL REVISION → FUNCTIONAL POLISH`.

For IVDIVO, Swain is strongest when treated as a diagnostic engineer of causality, scene/processing rhythm and production workflow — and weakest when his period-specific commercial, gender, moral or psychological assumptions are mistaken for universal laws.
