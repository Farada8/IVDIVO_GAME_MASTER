## Provisional mechanisms

1. Character causality
`EXPERIENCE / CONTEXT → VALUE MODEL → PRESENT WANT → TACTIC / TRAIT → BEHAVIOR → CONSEQUENCE`.

2. Multiple-value interaction
A major character should not be explained by one core belief. Values can reinforce, inhibit, reorder, or contradict one another depending on relationship and context.

3. Reverse-personalizing audit
`OUTWARD MANNERISM / QUIRK → WHAT VALUE / HISTORY / CURRENT WANT MAKES THIS PLAUSIBLE? → KEEP / MODIFY / DELETE`.

4. Discovery discipline
If a live draft produces surprising character behavior:
`DO NOT FREEZE GENERATION → finish the live material → diagnose character truth / canon / causality → REPLAN / BANK / DISCARD`.

5. Objective as action, not compulsory activity
`CURRENT WANT → ACTION / VERBAL / COGNITIVE / REFUSAL / DECISION OBJECTIVE → RESPONSE → CHANGED STATE`.
A legitimate objective can be psychological (for example, deciding between options); agency is not synonymous with physical activity or aggression.

## Firewalls

- SINGLE-CORE DETERMINISM — one inner value may not explain every choice.
- TRAUMA-IS-DESTINY — a past event does not mechanically determine all future behavior.
- QUIRK COSTUME — mannerisms without causal/relational grounding are decorative.
- MANNERISM OVERLOAD / MICROGESTURE CONFETTI — more gestures do not create more depth.
- DISCOVERY-WORSHIP — surprising live-draft behavior is a hypothesis, not automatic character truth.
- DISCOVERY-OVERRULE — an outline is not allowed to erase stronger character-consistent live material without testing it.
- FOUR-DS RETROFIT — Collins's Desire/Distancing/Denial/Devastation is a diagnostic/generative school, not a mandatory IVDIVO architecture. Devastation is explicitly optional even in Collins.
- MANDATORY CONFLICT — objectives may produce negotiation, cooperation, refusal, decision, evidence work, or support; not every scene needs overt interpersonal conflict.

## IVDIVO application

For major youth characters, differentiate values and priorities before adding slang or quirks. Useful non-monetary axes include autonomy/coordinated responsibility, belonging/privacy, mastery/caution, fairness/procedure, evidence/loyalty, intimacy/independence, consent/duty.

For conscious robots, human mannerisms are not personhood evidence. Use `EMBODIMENT + OWN PRIORITIES + OWN MODEL/EVIDENCE + RELATIONSHIPS + CONSENT/REFUSAL → BEHAVIOR`.

For mystery, an author's private motive model remains separate from reader evidence: `OBSERVED → INFERRED → HYPOTHESIS → CORROBORATED / CONTESTED`.

For choppy prose, do not insert gestures between every line to demonstrate character. Characterization must not generate `dialogue → microgesture → thought → dialogue` confetti.
