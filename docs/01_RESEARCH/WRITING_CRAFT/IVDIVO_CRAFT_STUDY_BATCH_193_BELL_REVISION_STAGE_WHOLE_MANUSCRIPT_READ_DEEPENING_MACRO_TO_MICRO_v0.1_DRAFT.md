# IVDIVO CRAFT STUDY BATCH 193
## James Scott Bell — Revision Stage · Whole-Manuscript Read · Deepening Lab · Macro-to-Micro Repair

**Status:** SYNTHESIS / PRODUCTION GATES  
**Source:** James Scott Bell — *Revision and Self-Editing for Publication*, 2nd ed. (2012)  
**Pass:** 158

# Core synthesis
Bell's most useful contribution is not a new plot formula. It is a revision architecture that separates **creative generation, diagnostic distance, whole-book reading, deepening, macro repair and final polish**.

## Gate B193-01 — CREATE HOT / REVISE COOL
During discovery, do not force the writer to consciously run every craft rule.

`LIVE MATERIAL → OBSERVED DEFECT → RELEVANT TOOL → REPAIR → RETEST`.

This aligns with Lamott, LaPlante, Swain, Bickham and Gillett.

## Gate B193-02 — WHOLE BEFORE LOCAL
Before wholesale edits:
`FINISH DRAFT → COOL OFF → READ AS READER → MARK BROAD EFFECTS → DIAGNOSE LEVEL`.

No sentence is presumed guilty until book/sequence/scene/POV problems are excluded.

## Gate B193-03 — ACTUAL STORY MAP
The revision map records what the manuscript **actually does**, not what the outline intended.

`ACTUAL TEXT → START/END STATE PER CHAPTER → CAUSAL DEPENDENCIES → UPDATED PLAN`.

## Gate B193-04 — DEEPENING LAB FIREWALL
Bell's exercises can deliberately overgenerate character history, fear, voice, description, alternate objectives, sensory detail and emotional material.

`EXERCISE OUTPUT ≠ CANON`.

Admission requires:
`CHARACTER TRUTH → CANON → CAUSALITY → PERSONHOOD → ONE MAIN STORY → READER EFFECT`.

## Gate B193-05 — MODE BEFORE SENTENCE
Bell explicitly allows summary and transition compression and recommends slowing down important moments.

`ROUTINE PROCESS / LOGISTICS / REPEAT → SUMMARY / INDIRECT / ELLIPSIS`

`LOAD-BEARING CHOICE / CLUE / CONSENT / RELATION TURN → REAL TIME`.

## Gate B193-06 — ANTI-CHOPPINESS
Bell's own exercises include long/run-on syntax and slow-motion descriptive expansion.

Therefore:
`ACTION / SUSPENSE / EMOTION ≠ SHORT-SENTENCE DENSITY`.

Repair order:
`NARRATIVE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → MERGE RELATED MICROBEATS → SENTENCE CONTRAST → WORDING`.

## Gate B193-07 — SUCCESS IS ALLOWED
Reject Bell's default preference for worse outcomes in most scenes.

IVDIVO escalation may be:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

## Gate B193-08 — QUIET CAUSALITY
A scene can change:
- knowledge/evidence;
- relationship/trust;
- consent/boundary;
- responsibility;
- authority/access;
- strategy/model;
- future option space;
without overt conflict.

`QUIET ≠ STATIC`.

## Gate B193-09 — EXPOSITION OWNER
`INFO X → WHO KNOWS? → WHY NOTICE/SAY/THINK IT NOW? → WHY THIS PERSON? → WHAT CHANGES AFTERWARD?`

If the answer is only "the reader needs to know", route to another mode or rebuild the setup.

## Gate B193-10 — POV EPISTEMIC FIREWALL
Bell's inner-thought material is useful for intimacy but not as epistemology.

`THOUGHT / SELF-REPORT = SOURCED SELF-MODEL`.

It does not automatically prove motive, consent, guilt or world fact.

## Gate B193-11 — THEME THROUGH CONSEQUENCE
Retain:
`THEMATIC QUESTION → COMPETING MODELS/VALUES → CHOICES → CONSEQUENCES → READER INFERENCE`.

Reject author lecture and mandatory binary moral answer.

## Gate B193-12 — CRITIQUE INPUT CONTRACT
Reader feedback reports **effect** first.

`READER REPORT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES → TEST`.

The reader's proposed repair is not automatically authority.

## Gate B193-13 — STOP RULE
Revision must have a stopping condition.

`NEW DEFECT EVIDENCE? → YES: ROUTE / FIX / RETEST`
`NO NEW DEFECT EVIDENCE → STOP GLOBAL REVISION`.

# Red Team — Bell-specific overreach
Do not import as universal law:
- conflict in every scene/dialogue;
- mandatory physical/psychological/professional death stakes;
- default negative scene outcomes;
- mandatory Ghost/wound;
- pet-the-dog sympathy engineering;
- stronger villain/opposition as requirement;
- one-scene-one-POV as universal artistic law;
- fixed act percentages/doorways;
- omniscient POV market judgments;
- 2012 publishing/self-publishing assumptions;
- thought as honest access to motive;
- minor characters as merely allies/irritants.

# Cross-source convergence
Strong agreement with:
- Lamott — discovery before perfection;
- LaPlante — revision stage discipline;
- Hodgins — re-imagine rather than line-polish a structural scene defect;
- Seger — diagnose defect before rewrite;
- Mayer — actual manuscript state over planned state;
- Genette/Chatman — mode/duration/order before sentence polish;
- Le Guin/Prose/Lodge/Zinsser/Williams-Bizup — rhythm through function and contrast, not short-sentence quotas.

# Final Batch 193 production equation
`DISCOVERY → DISTANCE → WHOLE READ → ACTUAL STATE MAP → MACRO DIAGNOSIS → DEEPENING LAB (OPTIONAL) → STRUCTURE / CHARACTER / SCENE / POV-EVIDENCE → DIALOGUE / EXPOSITION → PARAGRAPH / READER-STATE → SENTENCE RHYTHM → WORDING / COPY → READER-AUDIO-REGRESSION TEST → STOP RULE`.
