## High-value mechanisms retained

### 1. Pattern family, not mandatory formula
`ACTUAL CAUSAL SPINE → PATTERN SIGNATURE → OPTIONAL MYTH-PATTERN COMPARISON → DIAGNOSIS → KEEP / REJECT THE LENS`.

Campbell's stages can supply vocabulary for recurring story functions. They do not receive authority to create missing scenes merely because a stage-name exists.

### 2. Threshold as option-space change
`OLD OPTION SPACE → THRESHOLD EVENT → NEW RULES / OBLIGATIONS / ACCESS → CHANGED ACTION`.

A new location is not a threshold by itself. A threshold is structural when it changes what the character can do, knows, owes, risks, or may refuse.

### 3. Trials as differentiated pressure
Tests are useful only when they expose different limits, tactics, relationships, evidence states, or responsibilities. Repetition of louder danger without state change is not progression.

### 4. Return as consequence / social translation
`LOCAL DISCOVERY OR GAIN → COST → RETURN / TRANSLATION INTO RELATIONSHIP, DUTY, OR SOCIAL ACTION → AFTERMATH`.

The source's Return vocabulary is useful for asking what a private discovery changes outside the hero. A literal return or mandatory elixir is not required.

### 5. Myth/ritual as worldbuilding infrastructure
`SHARED MODEL → RITUAL / ARCHITECTURE / LANGUAGE / LAW / SOCIAL ROLE → PERSON-SPECIFIC ACTION → CONSEQUENCE`.

In-world myths can shape institutions and everyday behavior while remaining beliefs rather than world facts.

### 6. Pattern falsification gate
Campbell repeatedly treats omitted stages as implied. This creates an unfalsifiable escape hatch. IVDIVO therefore requires:

`PATTERN INTERPRETATION → WHAT WOULD DISCONFIRM IT? → TEST → STOP`.

If every counterexample can be redescribed as a hidden, inverted, compressed, or implied stage, the pattern has ceased to diagnose.

## Major firewalls / rejected universals
The following are not promoted to IVDIVO psychology, science, history, gender theory, or ontology:
- collective-unconscious/archetype claims as scientific facts;
- Freudian/Jungian family/sexual universalism;
- Meeting-with-Goddess / Woman-as-Temptress as universal character architecture;
- male/female complementary-halves metaphysics;
- universal mother/father destiny models;
- monomyth as the single natural structure of all stories;
- initiation ordeal as automatic ethical legitimacy;
- nonhuman or physically unusual embodiment as monster/shadow symbolism;
- spiritual identity-with-the-cosmos claims as established ontology;
- mythic analogy as evidence.

Standing firewall:
`MYTH PATTERN / ARCHETYPAL RESONANCE ≠ PSYCHOLOGY ≠ SCIENCE ≠ HISTORY ≠ IVDIVO ONTOLOGY`.

## Cross-source comparison
- **Vogler:** useful production adaptation of the journey, but both remain maps rather than mandatory structures. Campbell needs the stronger falsification firewall.
- **Booker:** similar risk of pattern-universalism and absorbing counterexamples. Both are diagnostic pattern libraries only.
- **Truby / Bell / Bickham:** causal state change outranks stage vocabulary. If a stage does not change state, it is not admitted merely by pattern fit.
- **Herman / Zunshine / Chudnoff:** mythic interpretation and emotional certainty remain sourced models, not evidence-status upgrades.
- **Wolf / Card SF:** cultural myth can shape a storyworld, but official cosmology and world fact remain distinct.

## IVDIVO operationalization

### ONE MAIN STORY
Multiple mythic functions or journeys are admitted only if:
`STRAND → CHANGED MAIN-ENGINE STATE → DOWNSTREAM DEPENDENCY / PAYOFF`.

### YA / training
`INITIATION / TRIAL ≠ COERCION LEGITIMACY`.
Training remains subject to consent, reversibility, welfare, appeal, information quality, decision ownership, and cost.

### Conscious robots / nonhuman persons
`NONHUMAN EMBODIMENT ≠ MONSTER ≠ MORAL INCOMPLETENESS`.
Archetype role never outranks personhood:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Mystery / schools of consciousness
`MYTHIC ANALOGY / SYMBOL / ARCHETYPAL RECOGNITION → HYPOTHESIS, NOT CORROBORATION`.

Schools of practice retain:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

### Endings
Useful Campbell question: what returns to the social/relational world after the central experience?
Standing ending engine remains:
`LOCAL PROBLEM RESOLVED → COST / AFTERMATH → CHANGED STATE → OPTIONAL SERIES VECTOR`.
No mandatory spiritual rebirth or Return-with-Elixir.

### Prose / anti-choppiness
`PATTERN STAGE / THRESHOLD / ORDEAL / RECOGNITION / RETURN ≠ SENTENCE BREAK`.
Macro-analysis never dictates paragraph or sentence fragmentation.

## Final synthesis
Campbell is retained as a rich comparative pattern vocabulary and as a prompt for threshold, trial, transformation, and return questions.
