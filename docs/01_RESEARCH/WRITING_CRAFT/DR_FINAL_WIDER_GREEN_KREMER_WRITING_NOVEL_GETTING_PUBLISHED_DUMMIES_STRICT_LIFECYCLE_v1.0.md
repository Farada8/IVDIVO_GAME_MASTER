# 2. Source passport

## What this source is good at

1. Broad end-to-end orientation for a first novelist.
2. Strong emphasis on flexible process rather than one drafting ritual.
3. Useful relationship-centred view of novel complexity.
4. Practical action/consequence thinking.
5. Concrete final-draft diagnostics: character continuity, relationship maps, scene function, place, outline chain, pacing and feedback.
6. Strong warning that ideas/research/process tools should support actual writing rather than replace it.
7. Useful distinction between writer-facing generation and later analytical editing.
8. A historically informative snapshot of UK publishing circa 2007.

## Authority limits

- This is an introductory commercial craft manual, not a primary psychology, narratology or cognitive-science source.
- Hero’s Journey / seven-stories / three-act discussions are secondary craft frameworks.
- Some grammar/style advice is simplified to the point of being unreliable as a universal production rule.
- Ch15–19 market, submission, agent, bookstore, discount, royalty and self-publishing specifics are from 2007 and are **historical-market material** unless re-verified against current primary sources.
- Publishing advice is UK-centric.

# 3. Principal claims retained after Red Team

## A. Novel depth comes from layering

Useful source idea: a novel commonly gains richness through several simultaneous relationship/story/emotional layers.

IVDIVO adaptation:

`ONE MAIN STORY + RELATIONSHIP / EVIDENCE / SOCIAL / WORLD LAYERS → EACH LAYER EARNS READER-TIME THROUGH UNIQUE CONSEQUENCE OR PAYOFF`

Layering does **not** mean writing several independent mini-novels side by side.

## B. Action produces consequences

The source repeatedly frames story as action/reaction chains and correctly notes that no visible response can itself be meaningful.

Useful adaptation:

`ACTION / INFORMATION / REFUSAL → RESPONSE OR NON-RESPONSE → MODEL / RELATION / OPTION CHANGE → NEXT ACTION`

Do not turn this into a sentence-by-sentence stimulus/reaction metronome.

## C. Generation and criticism require different mental modes

Ch13 and Ch14 strongly support a production distinction already convergent across Lamott, LaPlante, Swain, Bell, Mayer and Seger:

`GENERATE / DISCOVER → DISTANCE → DIAGNOSE → STRUCTURAL REVISION → LINE / COPY POLISH`

## D. The actual manuscript must be reverse-mapped during revision

Ch14 asks the writer to build an outline chain from the draft that actually exists, not from the original plan.

IVDIVO:

`LOCKED TEXT → ACTUAL STORY-STATE MAP → DIAGNOSIS → PRODUCTION PLAN`

not

`OLD OUTLINE → FORCE MANUSCRIPT TO PRETEND OUTLINE WAS RIGHT`.

## E. Reader-time implies importance

Scenes, descriptions and explanations consume reader-time. Equal space for unequal functions creates false emphasis.

`FUNCTION / CONSEQUENCE → SCENE WEIGHT / DURATION`

This is especially useful against technical over-dramatization.

## F. Character motivation must be legible without becoming simplistic

Useful source core:

`PRESENT WANT / VALUE → SITUATION → TACTIC / CHOICE → CONSEQUENCE → RETROSPECTIVE MODEL`

The book correctly allows seemingly inconsistent behaviour if the circumstances make it convincing and the text plants enough causal support.

## G. Relationship maps are causally useful

The source recommends externalising relationships during revision.

IVDIVO version stores more than labels:

`RELATIONSHIP → HISTORY → WANT FROM OTHER → POWER / ACCESS → TRUST → CONSENT / BOUNDARY → CURRENT TACTIC → CHANGE`

## H. Setting must alter available action

The source’s strongest setting idea is functional rather than decorative: the same people cannot behave identically in materially different environments.

`WORLD / PLACE RULE → AFFORDANCE / CONSTRAINT → CHOICE → CONSEQUENCE`

## I. Information withholding is a reader contract

The source usefully notes that too much withholding makes readers feel manipulated while too little destroys mystery.

IVDIVO combines this with Zunshine / le Carré:

`WORLD FACT → SOURCE / TRACE → POV ACCESS → INTERPRETATION → READER MODEL → FAIR WITHHOLDING → LATER CORROBORATION / REVISION`

Withholding may control access; it may not falsify evidence or hide a fact that the current POV transparently knows merely to manufacture suspense.

## J. Feedback must be selected, not obeyed

The source recommends limited trusted readers, clear questions and delay before acting on suggestions.

IVDIVO:

`READER REPORT → OBSERVED EFFECT → REPEATABILITY → DEFECT LEVEL → MULTIPLE REPAIR HYPOTHESES → RETEST`

Reader effect is evidence. Reader-prescribed repair is a hypothesis.

# 4. Mechanism bank

## M1 — Layer Payment Test

For every subplot / subsidiary relationship / recurring activity:

`LOCAL WANT → LOCAL CHANGE → EFFECT ON A-STORY OR MAJOR LATER CHOICE → PAYOFF`

If the layer has no consequence and no independent lived-reality value worth its cost, compress / merge / bank.

## M2 — Consequence Chain

`EVENT → FIRST-ORDER CONSEQUENCE → SECOND-ORDER CONSEQUENCE → RELATION / EVIDENCE / ACCESS / RESPONSIBILITY CHANGE → LATER PAYOFF`

Before adding a new event, ask what the existing event still has to cause.

## M3 — Non-Response Is Data, Not Explanation

`EXPECTED RESPONSE → OBSERVED NON-RESPONSE → MULTIPLE MOTIVE MODELS → LATER EVIDENCE`

Silence is behaviour; it is not automatically consent, guilt or motive.

## M4 — Discovery Variant Router

`STUCK POINT → GENERATE MATERIAL VARIANTS → TEMPORARILY DEFER CENSORSHIP → CHARACTER / CANON / CAUSALITY / ONE MAIN STORY TEST → KEEP / BANK / DISCARD`

## M5 — Visualization as Scenario Lab

`CHARACTER MODEL → DIFFERENT SITUATIONS → OBSERVED / IMAGINED RESPONSE → UPDATE MODEL`

Visualization does not make the result canon until it survives manuscript/canon causality tests.

## M6 — Reverse Outline / Actual-State Map

`SCENE → FUNCTION → OWNER → ENTRY STATE → EVENT → EXIT STATE → NEXT DEPENDENCY`

Use the current manuscript, not the old outline.

## M7 — Relationship-State Map

`PAIR / NETWORK → WANT → TRUST → ACCESS → POWER → CONSENT → CURRENT TERMS → CHANGE → NEXT EFFECT`

## M8 — Setting Causality

`LOCATION / ENVIRONMENT RULE → WHAT BECOMES POSSIBLE / IMPOSSIBLE → CHARACTER TACTIC → CONSEQUENCE`

## M9 — Scene Purpose + Changed-State Test

`Because this scene happened, ______ changed.`

Possible axes:
- physical / operational state;
- knowledge / evidence;
- relationship / trust;
- consent / boundary;
- authority / access;
- responsibility / obligation;
- strategy / model;
- emotional commitment;
- future option space.

If nothing downstream-relevant changes, test SUMMARY / MERGE / DELETE / REBUILD before prose polish.

## M10 — Revision Pass Separation

`CHARACTER CONTINUITY → RELATIONSHIPS → SCENE FUNCTION → PLACE / TIMELINE → ACTUAL OUTLINE CHAIN → PACING → LANGUAGE / GRAMMAR → PRESENTATION`

Exact pass sequence can vary; the important principle is not attempting all defect levels simultaneously.

## M11 — Reader-Time Hierarchy

`STORY IMPORTANCE / EXACT-WORD IMPORTANCE / CONSEQUENCE → DURATION / SCENE WEIGHT`

Do not give routine setup the same discourse weight as consent reversal, evidence-turn or decisive choice.

## M12 — Fair Mystery Information Budget

`ENOUGH INFORMATION TO MODEL POSSIBILITIES + REAL UNCERTAINTY + NO AUTHORIAL FALSIFICATION`

## M13 — Final-Draft Distance

`INTENSE IMMERSION → DELIBERATE DISTANCE → SLOW FINAL READ → ONLY EVIDENCE-BASED CHANGES`

No mandatory two-week number is imported; the function is perceptual distance.

## M14 — Market/Craft Separation

`CRAFT CLAIM → evaluate against manuscript evidence`  
`MARKET CLAIM → date / territory / channel → re-verify before use`

# 6. Cross-source comparison

## With Lamott / LaPlante / Swain
Strong convergence on separating discovery from later criticism. Green/Kremer’s speed-writing / openness belongs in generation, not canon validation.

## With Mayer / Seger
Strong convergence on the value of reverse mapping the manuscript that actually exists. Green/Kremer’s `outline chain` is an early form of the IVDIVO Actual Story-State Grid.

## With Scofield
Green/Kremer’s `something new should have happened` is useful, but Scofield is more precise: action is not event; the scene earns existence through meaningful change. Scofield also better protects quiet and embedded scenes.

## With Chatman
Green/Kremer’s layering is useful, but Chatman prevents over-pruning: satellites may enrich character, rhythm, atmosphere and thematic resonance without being kernels. Function and reader-time cost matter more than crude plot necessity.

## With Zunshine / le Carré
Green/Kremer correctly identifies information as power but lacks sufficient provenance discipline. IVDIVO therefore couples withholding with source lineage, evidence status and independent corroboration.

## With Le Guin / Francine Prose / Clark / Lodge
Green/Kremer’s occasional preference for shorter sentences and simplified punctuation is too crude. The stronger corpus consensus is:

`ACTION / SUSPENSE ≠ SHORT-SENTENCE DENSITY`.

Sentence length is a functional rhythm variable; too many short sentences become choppy and may slow the reader through repeated stops.

## With LaPlante / Rosenfeld / Bell on show/tell
Green/Kremer’s late `show, don’t tell` formulation is too absolute. IVDIVO uses mode routing:

`EXACT WORDS / ACTIONS MATTER → SCENE`  
`PROCESS / REPETITION / LOGISTICS / LESS-IMPORTANT SPEECH → SUMMARY / INDIRECT`.

## With Herman / Corbett / McKee Character
Green/Kremer’s motivation material is useful but narrower. IVDIVO retains multiple motives, relationship-specific priorities, uncertainty and competing values rather than a single explanatory cause.

## With Hayes / relationship work
Green/Kremer’s central relationship idea is useful but romance is not privileged. Relationship progression must change choices and consequences; intimacy does not equal evidence.

# 7. IVDIVO operationalization

## Global Writer’s Room

1. Do not run every specialist during generation.
2. Protect live discovery.
3. After a scene/chapter exists, reverse-map its actual state.
4. Diagnose defect level before repair.
5. Use Layer Payment and Consequence Harvest before adding another subplot/event.
6. Separate story facts, character knowledge, reader knowledge and production plan.
7. Allocate reader-time by story function, not by technology novelty.
8. Run line editing only after structural/mode/POV/evidence decisions are stable.

## ONE MAIN STORY

Allowed:
- multiple relationships;
- ordinary-life layers;
- multiple POVs;
- specialist threads;
- romance;
- institutional and technical consequences.

Required:

`LAYER → UNIQUE CHANGE → EFFECT ON MAIN ENGINE / MAJOR LATER CHOICE`.

Co-presence or shared briefing is not convergence.

## Mystery / evidence

`WORLD FACT → TRACE/SOURCE → ACCESS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION → STATUS UPDATE → ACTION`.

Withholding is legitimate only if reader orientation remains fair.

## YA / Orbital Youth

Do not import the book’s 2007 money/job/retail assumptions into post-money orbital life.

Use non-fungible stakes:
- trust;
- consent;
- time;
- privacy;
- responsibility;
- concrete role / mission;
- mastery;
- belonging;
- relationships;
- unique opportunity;
- safety.

Strong progression remains:

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

## Conscious nonhuman persons

No classification, speech pattern or compliance proves motive/personhood.

`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

## Consciousness schools

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Vivid experience and institutional fluency do not raise epistemic status automatically.

## Anti-choppy prose

Full repair router:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → EXPOSITION/DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Do not convert action/reaction into typography:

`action. reaction. gesture. thought.`

If those microbeats constitute one perceptual/decision unit, merge them into natural prose.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Possible future targeted use only when evidence appears:

- test scene-function duplication;
- check reader-time hierarchy;
- compress process that is over-dramatized;
- audit evidence withholding if mystery comprehension fails.

## ROOM 917

Use layering as a braid, not independent mini-series:

`MYSTERY EVENT → RELATIONSHIP / TRUST CHANGE → ACCESS / DISCLOSURE CHANGE → NEXT INVESTIGATIVE CHOICE`.

Hard firewall:

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

Repeated recorder setup, mic placement, geometry checks and known procedures earn full scene only if exact real-time wording/action changes evidence status, consent, trust, access or investigative strategy.

## Orbital Youth

Worldbuilding detail earns reader-time through character-specific affordance/friction. Relationship layers must alter later choices. No salary/rent/credits leakage from the source’s contemporary market assumptions.

## B07 — THE UNLISTED CITY

After independent personhood threshold:

`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Human layering around the entity cannot replace its decision ownership.

# 10. Final synthesis

The source is most valuable to IVDIVO when stripped of its beginner formulae and 2007 market specifics. Its strongest contribution is a practical bridge between **discovery, layering, consequence, reverse mapping and staged revision**.

The retained production law is:

`DISCOVER LIVE MATERIAL → MAP WHAT THE TEXT ACTUALLY DOES → TRACE LAYERS AND CONSEQUENCES → DIAGNOSE DEFECT LEVEL → REPAIR THE HIGHEST BROKEN LEVEL → RETEST → ONLY THEN POLISH`.

And the standing anti-overfit law remains:

`TOOLS HELP ASK / ORGANIZE / DIAGNOSE; STORY DOES NOT EXIST TO VALIDATE TOOLS.`
