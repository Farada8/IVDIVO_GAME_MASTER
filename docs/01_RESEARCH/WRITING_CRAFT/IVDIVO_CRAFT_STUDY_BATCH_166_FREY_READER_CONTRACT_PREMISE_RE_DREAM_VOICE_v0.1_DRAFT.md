# IVDIVO CRAFT STUDY — BATCH 166
## James N. Frey — Reader Contract · Premise · Suspense · Voice · Re-Dreaming

**Source:** *How to Write a Damn Good Novel II: Advanced Techniques for Dramatic Storytelling* (1994)

**Lifecycle basis:** complete sequential FULL READ; this batch is derived from the finalized strict source record, not snippets.

## Production synthesis

### B166-G01 — Pseudo-Rule Audit
Before promoting any advice to production law:
`RULE → claimed reader/story function → counterexamples → scope → KEEP / NARROW / DISCARD`.

### B166-G02 — Reader Bond Has Multiple Routes
Do not equate reader attachment with pity.

Possible routes:
`goal attachment / competence / fascination / intimacy / humor / moral uncertainty / relationship / vulnerability / responsibility / curiosity`.

**Failure:** `SYMPATHY-BY-SUFFERING`.

### B166-G03 — Story-Question Debt
A deliberately foregrounded question creates a payoff obligation.

`QUESTION → modeled possibilities → pressure → answer / partial answer / model revision`.

A saga hook does not excuse refusing the local answer promised by the book.

### B166-G04 — Menace Without Violence
Suspense pressure may concern trust, consent, privacy, role, relationship, evidence, belonging, access or unique opportunity.

**Forbidden shortcut:** danger/death/countdown added only to make a scene feel important.

### B166-G05 — Premise Is Hypothesis, Not Canon
Use premise to test relevance and causal coherence, but permit draft evidence to falsify or revise it.

`PREMISE HYPOTHESIS → DRAFT → ACTUAL STATE MAP → CANON / CHARACTER / CAUSALITY TEST → REPLAN`.

### B166-G06 — Reorderability Test
For major scenes A and B ask:
`Does B depend on the state left by A?`

If major scenes can swap freely, test for episodicity, missing consequences or redundant functions.

### B166-G07 — Situational Ensemble Is Not Automatically ONE MAIN STORY
A shared institution/location/problem can produce different character responses, but convergence requires causal interaction.

`STRAND ACTION → changes another strand's option space / evidence / relationship / authority → later payoff`.

### B166-G08 — Subplot Causal Payment
`LOCAL WANT → LOCAL CHANGE → A-STORY EFFECT → PAYOFF`.

A repeating character or romance is not automatically a subplot.

### B166-G09 — Voice = Attention + Attitude
`WHO PERCEIVES → WHAT BECOMES SALIENT → ATTITUDE → SPECIFIC DETAIL → WORD CHOICE / SYNTAX / RHYTHM / REGISTER`.

Do not differentiate teenagers with slang alone. Do not create a universal robot voice.

### B166-G10 — Grammatical Person ≠ Narrative Distance
First person can be emotionally distant; third person can be intimate.

`PERSON / FOCALIZATION / KNOWLEDGE / DISTANCE` are separate variables.

### B166-G11 — Epistemic Reconstruction Must Be Marked
If a narrator imagines another mind/offstage event, the discourse must not launder that reconstruction into world fact.

`OBSERVED / KNOWN / REPORTED / INFERRED / HYPOTHESIS / UNKNOWN`.

### B166-G12 — Reader Contract
Track:
- opening promise;
- genre/mode promise;
- information rules;
- narrator reliability rules;
- local book question;
- payoff/re-contract point.

Formal surprise is legitimate; arbitrary rule-changing is not.

### B166-G13 — Fair-Play Mystery
`TRACE/SOURCE → access → interpretation → alternative model → corroboration`.

Coincidence may complicate; it must not repeatedly solve.

`RELATIONSHIP STATE ≠ EVIDENCE STATUS`.

### B166-G14 — Intelligent Mistake
Characters do not need to perform at theoretical maximum capacity.

A strong mistake is:
`reasonable limited model → character-specific choice → contrary evidence → cost → model update`.

### B166-G15 — Re-Dream Before Paraphrase
When the scene's purpose/objective/staging is wrong, do not polish the existing sentences.

`SCENE DEFECT → re-imagine entry / objective / pressure / staging / exit state`.

`LINE DEFECT → line edit`.

### B166-G16 — Courage ≠ Harm Inflation
Do not add brutality, death, humiliation or trauma simply to prove artistic seriousness.

Strong cost may be relational, ethical, evidential, institutional or responsibility-based.

### B166-G17 — Critique Contract
`READER REPORT → observed effect → repeatability → defect level → repair hypotheses → test`.

Reader effect is evidence. Reader-prescribed repair is a hypothesis.

### B166-G18 — Generate First, Diagnose Later
`DRAFT / DISCOVERY → DISTANCE → STRUCTURAL DIAGNOSIS → REVISION → LINE/POLISH`.

No hundred-agent committee at sentence birth.

### B166-G19 — Market Timestamp Firewall
Frey's 1994 publishing and genre-market claims are historical context only.

Do not derive current acquisition strategy, submission practice or audience forecasts from them.

### B166-G20 — Passion Is Not Proof
`AUTHOR CONCERN → THEMATIC QUESTION → COMPETING MODELS → CHARACTER CHOICES → CONSEQUENCES → READER INFERENCE`.

Author belief does not establish psychology, morality, science or IVDIVO ontology.

### B166-G21 — Post-Money Stakes Firewall
Translate functional stakes only:
`time / trust / consent / privacy / responsibility / access / mastery / belonging / relationship / unique opportunity / safety`.

Never restore salary/rent/credits as default youth drama.

### B166-G22 — Syntax Firewall
Suspense mechanisms do not dictate sentence length.

`READER EFFECT → SUBJECTIVE DURATION / CONTINUITY → PARAGRAPH INTENT → SENTENCE SHAPE → CONTRAST`.

**Forbidden:** `SUSPENSE → FRAGMENT DENSITY`.

## Cross-school reconciliation

### Frey × Lamott / LaPlante / Swain
Strong convergence on draft-before-critique and discovery before polish.

### Frey × Bell / Seger / Mayer
Premise/outlines are useful structural hypotheses, not canonical authority over actual text.

### Frey × Zunshine / Herman / le Carré
Frey's narrator/reliability advice requires stricter source lineage and evidence-status tracking.

### Frey × Card / Corbett / McKee Character / Collins
Ruling passion is one driver, not a total causal explanation of a person.

### Frey × Prose / Le Guin / Lodge / Clark / Zinsser
No support for sentence-length KPI. Choppy prose is not suspense.

## Standing IVDIVO law reinforced

`LIVE MATERIAL → OBSERVED DEFECT → DEFECT LEVEL → RELEVANT SPECIALISTS → MINIMAL CORRECT FIX → REGRESSION TEST`.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.
