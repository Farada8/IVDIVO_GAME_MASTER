## Retained mechanisms after Red Team

### 1. Quiet causality / non-movement test
Booker often treats passive or externally static protagonists as failed because they do not move toward his archetypal completion. The metaphysics and value judgment are rejected. The useful diagnostic is:

`LOW OUTWARD ACTIVITY → DOES MODEL / RELATION / COMMITMENT / EVIDENCE / OPTION SPACE CHANGE?`

If yes, quiet causality exists. If no downstream-relevant state changes, the material may truly be static.

`QUIET ≠ STATIC`.
`PASSIVE EXTERIOR ≠ NO AGENCY`.

Agency may be refusal, waiting for an evidence threshold, processing, consent, decision, delegation or deliberate non-intervention.

### 2. Pseudo-ending / state-resolution audit
A last image, circular callback, violent shock, departure, new partner, new body, new status or sentimental epilogue does not by itself resolve the book.

`ENDING DEVICE ≠ LOCAL CLOSURE`.

Audit final state across:
- objective;
- evidence/knowledge;
- relationship/consent;
- responsibility/authority;
- agency/decision ownership;
- cost;
- future option space.

A callback earns its place when its meaning has changed, not merely because it rhymes with the opening.

### 3. Sensation escalation / diminishing returns
Ch27 repeatedly describes stories that substitute increasingly intense sex/violence/shock for causal progression. Booker's moral/cultural theory is rejected, but the structural diagnostic is useful:

`REPEATED HIGH-INTENSITY CONTENT + NO NEW STATE → DIMINISHING RETURNS`.

`CONTENT INTENSITY ≠ STRUCTURAL PROGRESSION`.

Before escalating spectacle, ask what new evidence, relation, responsibility, option, tactic or cost changes.

### 4. Shock does not create closure
A final death, mutilation, explosion, suicide or unresolved threat can be a valid aesthetic ending, but it is not automatically a resolution.

`SHOCK / SPECTACLE ≠ ENDING FUNCTION`.

Likewise, the absence of punishment or moral recompense is not a structural defect by itself. Booker's mandatory moral-balancing claim is rejected.

### 5. Investigator involvement is a variable, not a defect
Booker treats the classic detective as detached from the drama and uses this to argue that whodunnits are shallow. Reject the universalization.

Useful distinction:
`INVESTIGATOR CAUSAL INVOLVEMENT → NONE / INDIRECT / DIRECT / SELF-IMPLICATED`.

A personally involved investigator may be dramatically stronger, provided evidence status is not distorted by intimacy.

### 6. Mystery contract / fair inference
The strongest salvage from Ch29:

`TRUE TRACE → MODEL A → ALTERNATIVE MODEL(S) → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

The reader may be wrong. The narrator may not lie about the literal trace.

`WITHHOLDING ≠ FAIR PLAY` unless the withheld material respects established POV/knowledge access.

### 7. Investigator-inside-causal-system
Oedipus supplies the high-value diagnostic case where the investigator is also part of the hidden causal system.

`INVESTIGATOR QUESTION → TRACE CHAIN → SELF-IMPLICATING EVIDENCE → MODEL COLLAPSE → RESPONSIBILITY / ACTION UPDATE`.

This is useful well beyond guilt stories: the investigator's own earlier decision, institution, tool or relationship can be causally implicated without making the investigator secretly villainous.

### 8. Responsibility must distinguish knowledge, control and consequence
Booker often collapses guilt, fate, motive and responsibility into archetypal moral language. IVDIVO requires a more granular audit:

`ACTION → WHAT WAS KNOWN? → WHAT OPTIONS EXISTED? → WHAT CONTROL / COERCION APPLIED? → WHAT CONSEQUENCES FOLLOWED? → RESPONSIBILITY STATUS`.

This applies especially to institutions, constrained adolescents and conscious robots.

### 9. Counterforce legitimacy / institutional model
Ch28's Job / Brave New World / Nineteen Eighty-Four cluster yields a useful question independent of Booker's theology:

`IMMENSE POWER / INSTITUTION CLAIM → BENEFIT → COERCION → EVIDENCE CONTROL → APPEAL / REFUSAL → WHO BEARS COST?`

`POWER ≠ LEGITIMACY`.
`COMPETENCE ≠ LEGITIMACY`.
`ORDER / STABILITY ≠ CONSENT`.

### 10. Plotting can generate its own counter-effects
Ch30's Hamlet discussion usefully highlights plans that alter the system and rebound on their makers.

`PLAN / DECEPTION → SYSTEM RESPONSE → UNINTENDED EFFECT → NEW EVIDENCE / RELATION → PLAN OBSOLETE OR SELF-DEFEATING`.

This is retained as causal-system design, not as proof of cosmic moral law.

### 11. Microcosm is not the whole world
Hamlet's Elsinore can function as a concentrated system while the larger world remains visible.

`MICROCOSM → SELECTED PRESSURES / RELATIONS → STORY FUNCTION`, not `MICROCOSM = COMPLETE CIVILIZATION MODEL`.

Useful for Orbital Youth districts, schools, habitats and institutions.

### 12. Narrative glamour / focalization audit strengthened
A charismatic, funny, intelligent or deeply focalized protagonist may attract reader alignment even when causing harm.

`ALIGNMENT / INTERIORITY / WIT → READER MODEL`, not `MORAL LEGITIMACY`.

Audit who receives interiority and who bears consequences.

## Cross-source comparison
- **Ephron / Zunshine / le Carré / Chudnoff:** source lineage, alternative models and discriminating tests are stronger mystery tools than Booker's moral/archetypal reading.
- **Genette / Chatman:** withholding and focalization must be distinguished from story facts; reader model can change without retconning the trace.
- **Card / Corbett / Oatley / Herman:** quiet agency, relationship-specific action and model update are stronger than fixed archetypal essences.
- **Seger / Bell / Swain / Scofield:** changed state and downstream dependency are better progression tests than intensity or archetypal stages.
- **DCC / Murderbot / Weir / Skyward:** personhood does not depend on humanization, heterosexual pairing or symbolic role.
- **Booth:** ambiguity needs stopping rules; productive uncertainty is not the same as confusion.
