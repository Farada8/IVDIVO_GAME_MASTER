`PRIOR CONSEQUENCE → OWNER/WANT → PRESSURE/COUNTERFORCE/SUPPORT → TACTIC → ACTION/INFORMATION/RELATION CHANGE → OUTCOME → DOWNSTREAM LINK`

### Processing router

`OUTCOME → PROCESSING → MODEL/RELATION/EVIDENCE UPDATE → OPTION SET → DECISION/COMMITMENT → NEXT ACTION`
