## 1. Scene is an immediacy mode, not the whole narrative
Scofield explicitly rejects the idea that a story must be a rosary of fully developed scenes. She allows narrative to move in and out of:
- full scenes;
- embedded scenes;
- scene fragments;
- summary;
- commentary;
- memory/interiority.

### IVDIVO production router
`WHAT READER EXPERIENCE IS NEEDED NOW? -> FULL SCENE / EMBEDDED SCENE / FRAGMENT / SUMMARY / COMMENTARY`

### Gate B130-G01 — Mode Before Line Edit
Before repairing prose rhythm, determine whether the material is in the correct narrative mode.

A procedural passage does not become a better scene merely because its sentences are polished.

---

## 2. Scene power comes from event + emotional presence, not spectacle
Scofield's examples include both high-action moments and intimate, quiet moments. The common factor is not scale but the reader's sense that something meaningful is happening now.

### Working model
`PRESENT EVENT -> CHARACTER RESPONSE / RELATION -> CHANGED STATE`

### Gate B130-G02 — Quiet Event Legitimacy
A quiet scene may remain a full scene when exact behavior, words or timing change:
- trust;
- consent;
- evidence status;
- relationship terms;
- commitment;
- identity/belonging;
- next action.

### Failure mode
`SPECTACLE-AS-SCENE-PROOF` — assuming that a scene is justified because something large happens.

---

## 3. Event and interiority can share the same prose space
Scofield distinguishes prose from film: fiction can present action while simultaneously giving memory, thought, association and subjective response.

### IVDIVO model
`EXTERNAL EVENT <-> EMBODIED POV <-> MEMORY/THOUGHT <-> ACTION UPDATE`

The interior layer earns space when it changes interpretation, emotional pressure or the next choice.

### Gate B130-G03 — Interiority Must Pay Forward
Do not add a micro-thought after every action. Interiority remains only when it changes the reader's model or the character's next state.

### Failure mode
`MICROREACTION CONFETTI` — action -> one-line thought -> gesture -> one-line explanation -> next action.

---

## 4. Embedded-scene principle
Scofield argues that the underlying sense of scene can organize narrative even when the final text does not contain a fully developed scene.

### IVDIVO model
`SUMMARY -> BULL'S-EYE MOMENT IN REAL TIME -> SUMMARY / CHANGED STATE`

Use this when most of a process is routine but one exact exchange/gesture/choice must be experienced in real time.

Examples for IVDIVO:
- long technical calibration compressed; exact consent question shown;
- routine travel compressed; one route-choice that changes relationship/evidence shown;
- institutional briefing compressed; the moment authority is granted/refused shown;
- archive search compressed; the exact provenance contradiction shown.

### Gate B130-G04 — Bull's-Eye Expansion
Expand only the part where exact wording/action materially changes state.

---

## 5. Scene weight must vary
Scofield explicitly says major, minor, embedded and fragmentary scenes need not receive equal weight.

### Scene-weight scale
- **HEAVY** — irreversible choice, evidence turn, consent/refusal, relationship redefinition, climax-level responsibility.
- **MEDIUM** — meaningful strategy/model update, social consequence, bounded success/failure.
- **LIGHT** — short orientation, lived-world signal, minor relational adjustment.
- **COMPRESSED** — logistics, routine process, repeated explanation, travel with no new state.

### Gate B130-G05 — Weight Proportionality
`READER TIME` should roughly track `STATE CHANGE + IRREVERSIBILITY + RELATIONAL/EVIDENCE IMPORTANCE`, not technological novelty.

### Failure mode
`EQUAL-WEIGHT MANUSCRIPT` — every scene receives the same beat density and paragraph-level attention.

---

## 6. Practice scene != publication scene
Scofield recommends writing prior or exploratory scenes to understand story history even when those scenes never enter the final manuscript.

### IVDIVO two-ledger model
**DISCOVERY LEDGER** — scenes allowed to exist only to discover character/history/world.

**PUBLICATION LEDGER** — scenes must earn reader time inside ONE MAIN STORY.

### Gate B130-G06 — Discovery/Public Separation
Do not force a useful discovery scene into the book merely because writing it taught the studio something important.

### Failure mode
`RESEARCH-SCENE ENTITLEMENT` — "we wrote it, therefore readers must see it."

---

## 7. Reading models without copying them
Scofield advocates deliberate apprenticeship through model scenes but also warns against copying an admired writer's surface.

### IVDIVO adaptation
Extract:
- function;
- causal mechanism;
- information routing;
- scene weight;
- relation change;
- reader effect.

Do NOT copy:
- sentence fingerprint;
- signature imagery;
- characteristic dialogue cadence;
- scene dressing.

### Gate B130-G07 — Mechanism, Not Surface
Reference intelligence must produce transferable mechanisms, never imitation-by-style.

## 8. Cross-source synthesis
### Converges with LaPlante
Generation and analytic revision are different modes; scene vs narration is a routing choice, not a moral hierarchy.

### Converges with Bell / Swain
A scene needs a functional change, but the IVDIVO version does not require disaster, setback or open conflict.

### Converges with Rosenfeld
Consequences should create the next state, but the exact scene form can vary.

### Converges with Prose / Lodge / Zinsser
Rhythm and sentence length are downstream of scene/mode decisions.

### Key correction to formula schools
`SCENE FUNCTION != FULL-SCENE OBLIGATION`.
A function can be delivered by summary + embedded real-time moment.

## 9. Anti-'обрубки' update
Final routing order now includes scene weight and embedded-scene choice:

`ONE MAIN STORY / CAUSALITY -> CHAPTER FUNCTION -> SCENE NECESSITY -> SCENE WEIGHT -> NARRATIVE MODE -> ORDER/DURATION/FREQUENCY -> POV/EVIDENCE -> DIALOGUE/SUBTEXT -> PARAGRAPH INTENT -> READER-STATE CONTINUITY -> SENTENCE RHYTHM -> WORDING`.

If a paragraph is choppy because the writer is dramatizing every tiny procedural beat, sentence-level repair is the wrong level.
