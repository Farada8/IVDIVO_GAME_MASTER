## 1. Why this source changes production

Genette gives a precise vocabulary for defects that are often misdiagnosed as plot, pacing or prose problems. The production question is no longer merely `what happens?` but:

`WHAT HAPPENS → WHEN THE READER RECEIVES IT → HOW LONG READER-TIME IS SPENT → HOW OFTEN IT IS NARRATED → WHAT MODEL THIS CREATES`.

This prevents line editing from being used to repair a disclosure-order, scene-weight or repetition defect.

## 2. Order

### 2.1 Anachrony passport

For every major flashback, forecast or displaced revelation record:

- type: `ANALEPSIS / PROLEPSIS / ACHRONIC-SYLLEPTIC`;
- reach: how far from current story point;
- extent: duration covered;
- source / access owner;
- function;
- evidence-status effect;
- return / junction point;
- later payoff.

### 2.2 Completing vs repeating return

`COMPLETING ANALEPSIS` fills a prior gap.

`REPEATING ANALEPSIS` revisits an already narrated event because later knowledge changes its meaning.

Production rule:

`REPEAT ONLY IF STATUS / MEANING / RELATION / DECISION CHANGES`.

### 2.3 Advance notice vs advance mention

`ADVANCE NOTICE` explicitly points to a later event or consequence.

`ADVANCE MENTION` plants material whose significance is not yet visible.

For fair mystery, advance mention is powerful when:

`EARLY DETAIL IS TRUE → LATER EVIDENCE RECLASSIFIES IT → READER CAN RETROSPECTIVELY VERIFY THE NEW MODEL`.

### 2.4 Paralipsis distinction at order level

An omitted constituent inside an otherwise covered period is not the same thing as skipping the entire period.

Production implication:

`MISSING TIME ≠ MISSING INFORMATION WITHIN PRESENT TIME`.

The second is more dangerous in close-POV mystery because it may become a fair-play cheat.

## 3. Duration

### 3.1 No literal scene=real-time equivalence

Written narrative has no fixed reading speed. `Scene` is a convention, not a stopwatch equation.

Therefore:

`PACING DEFECT → CHECK DISCOURSE DURATION BEFORE SENTENCE LENGTH`.

### 3.2 Duration router

Use:

- `ELLIPSIS` — recoverable/irrelevant interval omitted;
- `SUMMARY` — process or period compressed;
- `SCENE` — exact sequence earns reader-time;
- `PAUSE / DESCRIPTIVE OR REFLECTIVE EXPANSION` — story action slows/stops while perception/thought gains weight.

### 3.3 Description can be narrative action

If focal attention develops, discovers, mistakes, compares or revises its model, description is not necessarily static pause.

`PERCEPTION → RELATION/PATTERN → MODEL CHANGE → ACTION`.

### 3.4 Ellipsis audit

Distinguish:

- explicit ellipsis;
- implicit ellipsis;
- hypothetical/uncertain ellipsis.

For mystery:

`SILENCE / ABSENCE BECOMES EVIDENCE ONLY IF EXPECTED PRESENCE WAS ESTABLISHED`.

## 4. Frequency

### 4.1 Three core forms

`SINGULATIVE`: once-told / once-happened.

`REPEATING`: same event told again.

`ITERATIVE`: one telling covers repeated events.

### 4.2 Repetition gate

Before repeating a prior scene, clue or conversation:

`NEW SOURCE? → NEW POV? → NEW EVIDENCE STATUS? → NEW RELATIONSHIP MEANING? → NEW ACTION?`

If all are NO, compress or delete.

### 4.3 Iterative baseline

Iterative narration is useful for ordinary life and world rules:

`REPEATED NORMALITY → READER LEARNS THE SYSTEM → SINGULAR EXCEPTION → BEFORE/AFTER ROUTINE CHANGE`.

This is especially valuable for post-money Orbital Youth because it shows normality without lecture.

### 4.4 Determination / specification / extension

For habitual narration record:

- temporal boundaries (`determination`);
- recurrence rule (`specification`);
- duration of each unit (`extension`).

This prevents vague statements such as “they always did X” from smuggling false universality into canon.

### 4.5 Pseudo-iterative watch

A supposedly repeated routine rendered with hyper-specific identical microdetail may be narratively conventional but can become continuity implausible.

Failure mode: `PSEUDO-ITERATIVE OVERPRECISION`.

## 6. IVDIVO production gates

### G171-01 — ORDER DEFECT ≠ STORY DEFECT
Do not rewrite canon when only disclosure order is wrong.

### G171-02 — REACH / EXTENT PASSPORT
Every major flashback/prolepsis has declared temporal scope.

### G171-03 — REINTERPRETATION FAIRNESS
Later reveal may change meaning, never silently mutate an earlier trace.

### G171-04 — ADVANCE-MENTION PAYOFF
Seed earns retention only if later significance is causally/evidentially recoverable.

### G171-05 — DURATION BEFORE SYNTAX
Decide ellipsis/summary/scene/pause before sentence-level pacing repair.

### G171-06 — RECOVERABLE LOGISTICS
Routine transitions omitted when reader can infer them and no state changes.

### G171-07 — REPEATING INFORMATION PAYMENT
Repetition requires a new state/meaning/source/action.

### G171-08 — ITERATIVE BASELINE
Use habitual narration to establish normal systems before singular disruption.

### G171-09 — ROUTINE CHANGE
A singular event is a structural turn only if future recurrence/expectation changes.

### G171-10 — EVIDENCE CHRONOLOGY
Nonlinear presentation must preserve recoverable evidence chronology where proof depends on sequence.

## 7. Failure modes

- `CHRONOLOGY TOURISM`
- `RETCON AS REINTERPRETATION`
- `RECAP AS PROGRESSION`
- `ELLIPSIS HIDES REQUIRED CAUSE`
- `OVERDRAMATIZED LOGISTICS`
- `SCENE-TIME KPI`
- `PSEUDO-ITERATIVE OVERPRECISION`
- `ROUTINE WITHOUT BOUNDARIES`
- `SUSPENSE BY SENTENCE CHOPPING`
- `ADVANCE MENTION WITHOUT PAYOFF`
