## Core claims retained
1. `TOPIC ≠ CLAIM`. A usable claim must be focused enough that support/refutation conditions are legible.
2. `INTENDED ARGUMENT TYPE ≠ ACTUAL ARGUMENT TYPE`. A speaker may intend deductive support while actually relying on hidden or weaker assumptions.
3. Argument strength is not the sum of isolated premise strengths; relations among premises matter.
4. `VALID ≠ COGENT`. Formal validity does not rescue circular, irrelevant or unsupported premises.
5. Analogy is best treated as a hypothesis generator unless relevant similarity is independently defended.
6. Inference to the best explanation requires explicit competition among explanations; explanatory elegance alone is not entitlement.
7. Audience design includes four variables: expression, motivation, background, elaboration.
8. `ORDER OF DISCOVERY ≠ LOGICAL-EXPLANATORY ORDER ≠ BEST NARRATIVE ORDER`.
9. Narrative order should manage reader expectation while preserving explanatory intelligibility.
10. Paragraphs perform local narrative work; paragraph function and transition should be legible.
11. Feedback reveals reader effect, but reader focus can indicate either presentation failure or the author's mistaken hierarchy of importance.
12. Imagination/insight can generate useful cases and distinctions but do not create evidence automatically.

## Mechanism bank

### M1 — Claim Precision Gate
`TOPIC → SPECIFIC CLAIM → WHAT WOULD SUPPORT IT? → WHAT WOULD REFUTE/QUALIFY IT?`

IVDIVO use: any major story-world claim, mystery hypothesis or consciousness-school claim must have a definable proof ceiling.

### M2 — Argument-Type Audit
`CLAIM → PREMISES → INTENDED SUPPORT TYPE → ACTUAL SUPPORT TYPE → HIDDEN ASSUMPTIONS → STATUS`

Useful for characters, institutions, schools, AIs and investigators who speak confidently but may be using analogy/IBE while presenting their conclusion as certainty.

### M3 — Competing Explanation Gate
`TRACE SET → MODEL A / B / C → EXPLANATORY WORK → DISCRIMINATING EVIDENCE → STATUS UPDATE`

A "best explanation" is provisional until alternatives are represented fairly and tested.

### M4 — Analogy Firewall
`CASE A → RELEVANT FEATURE → CASE B → RELEVANT SIMILARITY PROVEN? → HYPOTHESIS / REJECT`

`ANALOGY ≠ EVIDENCE` unless the relevance relation itself is defended.

### M5 — Reader Intelligibility Stack
`EXPRESSION + MOTIVATION + BACKGROUND + ELABORATION → READER MODEL`

When a reader is confused, diagnose which layer failed before adding more exposition.

### M6 — Three Orders Router
`DISCOVERY ORDER → LOGICAL/EXPLANATORY ORDER → READER/NARRATIVE ORDER`

Discovery can be messy; final discourse should not preserve that mess merely because it reflects author process.

### M7 — Thesis/Lemma Narrative
`MAJOR QUESTION / CLAIM → SUPPORTING SUBCLAIM → WHY THIS SUBCLAIM MATTERS NOW → RETURN TO MAJOR LINE`

Supporting detail should be motivated by the work it performs for the main causal/intellectual line.

### M8 — Premise Entitlement
`PREMISE → SOURCE / PRIOR ARGUMENT / OBSERVATION / ASSUMPTION / THOUGHT EXPERIMENT → ENTITLEMENT STATUS`

No premise receives authority merely from polished prose or expert tone.

### M9 — Paragraph Narrative Function
`PREVIOUS READER STATE → PARAGRAPH JOB → INTERNAL ORDER → EXIT STATE`

This strengthens the existing anti-choppiness system: multiple related microbeats normally belong to one coherent paragraph when they perform one local job.

### M10 — Feedback Attention Test
`READER ATTENDS TO X → WAS X INTENDED CENTRAL? → IF NO: PRESENTATION DISTORTION OR AUTHOR PRIORITY ERROR? → REPAIR HYPOTHESIS`

Reader report is evidence of effect, not automatic authority over the repair.

## Cross-source comparison
- **Genette / Chatman:** distinguish story/discourse order; Chudnoff adds discovery vs explanatory vs reader order.
- **Zunshine / Herman / le Carré / Ephron:** source and inference discipline; Chudnoff adds argument-type and premise-entitlement audits.
- **Blundell:** causal fence and source ecology; Chudnoff adds explicit claim/refutation boundaries.
- **Williams / Zinsser:** clarity and reader-state; Chudnoff adds local paragraph narrative and motivation/background/elaboration separation.
- **Booth:** inference reconstruction; Chudnoff strengthens stopping/entitlement by asking what reasons actually support a claim.
- **Aristotle:** causal/explanatory unity; Chudnoff adds the warning that logical order is not automatically the best narrative order.
- **LaPlante / Lamott / Bell / Swain:** discovery may be messy and provisional; final text should be rebuilt for reader effect rather than preserve drafting sequence.

## IVDIVO operationalization

### General reasoning/evidence gate
`CLAIM → PRECISE STATUS → PREMISES/TRACES → SOURCE LINEAGE → SUPPORT TYPE → ALTERNATIVE MODEL → HIDDEN ASSUMPTIONS → PROOF CEILING → ACTION`

### Mystery / suspense
A character may believe a deductive conclusion while actually using analogy or IBE. Store both:
`CHARACTER MODEL` and `EVIDENCE STATUS`.

### Conscious robots / nonhuman persons
`BEHAVIOR → HUMAN INTERPRETATION` is not a premise entitled to prove motive/personhood. Personhood remains:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Consciousness schools
`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

A thought experiment or analogy may reveal a distinction; it does not establish ontology.

### YA / Orbital Youth
Exposition should be routed by reader need and character access. Do not explain ordinary future norms before the story gives the reader a reason to need the distinction.

### Style / anti-choppiness
Chudnoff favors short sentences for academic clarity, but this is a genre-specific recommendation and conflicts with the broader prose corpus when treated as a universal KPI.

Standing law remains:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → PARAGRAPH TOPIC/LOCAL JOB → READER-STATE CONTINUITY → SENTENCE RHYTHM/CONTRAST → WORDING`.

`CLARITY ≠ SHORT-SENTENCE DENSITY`.

### Orbital Youth

### B07 — THE UNLISTED CITY

`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## Final synthesis
Chudnoff's strongest contribution is a compact **reasoning-and-reader architecture**. It sharpens IVDIVO's distinction between claim, premise, support type, hidden assumption, alternative explanation and reader presentation. Its most useful production effect is not to make fiction sound like philosophy papers; it is to prevent polished language, analogy, expert fluency or narrative order from silently upgrading a hypothesis into a fact.
