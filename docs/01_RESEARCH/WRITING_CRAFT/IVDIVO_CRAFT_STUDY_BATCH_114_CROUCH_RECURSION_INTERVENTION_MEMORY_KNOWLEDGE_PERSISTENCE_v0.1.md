## PRIMARY TRANSFERABLE SYSTEM
`PERSONAL PAIN → INTERVENTION → LOCAL SUCCESS → DOWNSTREAM SYSTEM CHANGE → KNOWLEDGE PERSISTS → PROLIFERATION / REPAIR LOOP → GOVERNANCE + RELATIONSHIP COST → BOUNDED FORWARD ACTION`.

## NEW PRODUCTION GATES

### B114-G01 — Intervention Blast Radius
Every powerful intervention must be audited beyond its direct target:
`TARGET → RELATIONSHIPS → INSTITUTIONS → INFORMATION → INCENTIVES → FUTURE OPTIONS`.

### B114-G02 — Tool Destruction Is Not Knowledge Destruction
`HARDWARE REMOVED ≠ KNOW-HOW REMOVED`.

Track people, logs, memories, independent rediscovery paths and incentives.

### B114-G03 — Memory Provenance
A vivid memory is a source claim, not a world fact:
`MEMORY → SOURCE/CONDITIONS → CORROBORATION → ALTERNATIVE → STATUS`.

### B114-G04 — Shared Memory Still Needs Verification
Multiple people remembering the same thing increases the evidence class but does not automatically establish metaphysical ontology.

### B114-G05 — Formal Consent Audit
`AGREEMENT → INFORMATION → REVOCABILITY → POWER → ALTERNATIVES → ACTUAL CONSENT`.

### B114-G06 — Purpose Does Not Legitimate Method
Medical, humanitarian, scientific or civilizational benefit does not cancel consent, appeal, review or affected-person agency.

### B114-G07 — Recurrence Must Change State
If a plot revisits the same place/event/problem, each recurrence must alter:
`KNOWLEDGE / RELATIONSHIP / AGENCY / AUTHORITY / RESPONSIBILITY / OPTIONS / EVIDENCE`.

### B114-G08 — Catch-Up Point
Design delayed consequences explicitly:
`EARLY CHANGE → LATENT DEPENDENCY → SYNCHRONIZATION/CUTOVER → CONSEQUENCE SURFACES`.

### B114-G09 — Relationship Memory ≠ Present Relationship
`I REMEMBER US ≠ YOU OWE ME US`.

Current consent and current personhood govern.

### B114-G10 — Information Is an Intervention
Moving knowledge across institutions/generations/agents can alter behavior even when no physical technology moves.

### B114-G11 — Scale Expansion Must Follow Model Expansion
Do not escalate from personal to global merely by increasing explosions. Scale expands when evidence proves the causal model has a larger domain.

### B114-G12 — Forward-Life Gate
A character may choose acceptance of irreversible loss rather than perfect restoration; this is one earned model, not universal IVDIVO philosophy.

## FAILURE MODES
- ontology leak from speculative time/memory mechanism
- hardware-only containment
- knowledge-erasure fantasy
- formal-consent fallacy
- good-purpose immunity
- recursive repair without changed state
- apocalypse escalation monoculture
- shared-memory truth shortcut
- past-relationship ownership
- scientific reference halo
- temporal complexity replacing character causality

## CROSS-SOURCE CONVERGENCE
- **Weir:** local success can cause coupled system failure; competence remains real.
- **Dark Matter:** current agency/decision ownership outranks prior relationship claims.
- **Zunshine/Herman:** source and interpretation remain separate from verified fact.
- **Wolf:** changed world facts require downstream propagation and provenance.
- **Hayes/Corbett/Card/Baxter:** relationship history never erases independent personhood.
- **Cambridge SF/Lodge:** speculative mechanism is narrative equipment, not technical canon.

## MASTER IVDIVO RULE
Before introducing or deploying any high-impact technology, policy or practice, ask:

`IF IT WORKS, WHAT ELSE CHANGES?`

Then ask:

`IF WE DESTROY IT, WHAT KNOWLEDGE, INCENTIVE OR RELATIONSHIP CAN RECREATE IT?`
