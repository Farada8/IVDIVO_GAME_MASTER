## A. Rewrite Diagnosis Gate

Before any rewrite:

`SYMPTOM → OBSERVABLE READER/STORY EFFECT → DEFECT LEVEL → DEPENDENCIES → FIX OPTIONS → MINIMAL CORRECT FIX → REGRESSION TEST`

Possible defect levels:

- book engine / ONE MAIN STORY
- chapter function
- scene necessity / changed state
- character motive / personhood / relationship
- POV / knowledge / evidence provenance
- exposition / dialogue / subtext
- paragraph / reader-state continuity
- sentence rhythm / wording

**Failure mode: REWRITE WITHOUT DIAGNOSIS** — changing a whole act/chapter because it “feels weak,” then creating new defects elsewhere.

## B. Tool-Theory Firewall

Every tool, framework, AI program or specialist encodes a theory of story.

Production law:

`TOOL HELPS ASK / ORGANIZE / DIAGNOSE; STORY DOES NOT EXIST TO VALIDATE TOOL.`

This applies to Truby, McKee, Bell, Brody, Swain, Seger, the IVDIVO Narrative OS and any future AI agent.

## C. Multi-Specialist Routing

Do not run all specialists as simultaneous generation constraints.

Preferred order:

`LIVE GENERATION → CANON → MAIN ENGINE → CAUSALITY → CHARACTER/PERSONHOOD → SCENE → POV/EVIDENCE → DIALOGUE/SUBTEXT → PARAGRAPH/RHYTHM → WORDING → READER TEST`.

Only desks relevant to an observed defect are activated for repair.

## D. Planning Hypothesis Gate

Treatment, outline, beat sheet, cards, journal and AI-generated architecture are **working hypotheses**.

`PLAN → DRAFT EVIDENCE → CHARACTER / WORLD / CAUSAL TEST → KEEP / REPLAN / BANK / DISCARD`.

A neat document is not automatically canon.

## E. Research-to-Story Gate

`QUESTION → SOURCE / OBSERVATION → DOMAIN-SPECIFIC REALITY → POV-SPECIFIC VOCABULARY / DETAIL → ACTION / RELATION / CONSTRAINT → CONSEQUENCE`.

Research earns prose space when it changes the story or the reader’s necessary model. Avoid both research avoidance and research display.

For high-stakes mystery claims:

`EXPERT CLAIM ≠ WORLD FACT` until provenance/corroboration standards are met.

## F. Structural Geometry Firewall

Seger’s three-act/page distribution is retained as a screenwriting diagnostic example, not a novel law.

Cross-source conflict:

- Seger: strong three-act/page-ratio preference.
- Truby: warns that externally imposed act geometry can become mechanical and episodic.
- IVDIVO synthesis: measure transitions by changed causal state.

Use:

`SETUP / ORIENTATION → SUSTAINED CAUSAL DEVELOPMENT → DECISIVE LOCAL RESOLUTION`

and identify transitions by:

`GOAL / OPTION / RELATION / EVIDENCE / AUTHORITY / RESPONSIBILITY CHANGE`.

Do not retrofit page percentages.

## G. Anti-Choppy Prose Implication

Screenplay concision does not become a prose sentence-length rule.

Continue using:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → MODE → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Do not turn screenplay-style visual/action compression into a novel of fragments.
