## 5. “ОБРУБКИ” diagnostic advance

The old problem is now defined more precisely.

Chopped prose can come from:
- attention pinballing;
- excessive paragraph isolation;
- repeated sentence stress;
- routine micro-action dramatization;
- insufficient old→new bridges;
- action hidden in abstraction;
- uniform short syntax;
- structural scene/process problems upstream.

Therefore the fix is **not bulk paragraph merging**.

New Anti-Chop protocol:

`CLASSIFY BREAK`
→ `RECOVER PARAGRAPH INTENTION`
→ `ACTION CLARITY`
→ `TOPIC/ATTENTION STRING`
→ `OLD→NEW BRIDGE`
→ `STRESS HIERARCHY`
→ `READ-ALOUD RHYTHM`.

Old Book One sample was used only for diagnosis. Book One was **not rewritten**, because current project instruction places it in external/publisher feedback stage.
