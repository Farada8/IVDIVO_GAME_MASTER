# IVDIVO CRAFT STUDY — BATCH 200
## Turkin — Visual Dramaturgy · Meaningful Dynamics · Dialogue · Objects · Montage

**Source:** В. К. Туркин — *Драматургия кино*  
**Strict source status:** `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`  
**Pass:** 165

## A. Highest-value mechanisms

### B200-01 — STORY AUTHORITY / PRODUCTION AUTHORITY SEPARATION
`LITERARY / STORY STATE ≠ SHOOTING / TECHNICAL DOCUMENT`.

A shot list, audio render map, mix plan, TTS request, camera instruction or machine-state record may realize the story but cannot silently alter canon, evidence or character motivation.

### B200-02 — INTERMEDIATE ARTIFACT QUALITY TEST
`NEW ARTIFACT → WHAT NEW DECISION / CAUSAL UNDERSTANDING / PRODUCTION SAFETY DOES IT CREATE?`

More detail is not automatically progress.

### B200-03 — SPECTACLE PAYMENT
`SPECTACLE / WORLD EVENT / NOVUM → PERSON-SPECIFIC SIGNIFICANCE → CHANGED STATE → DOWNSTREAM CONSEQUENCE`.

If spectacle changes nothing downstream, it is texture/world-tourism.

### B200-04 — MEANINGFUL DYNAMICS, NOT MECHANICAL SPEED
`KINEMATIC SPEED / MANY CUTS / PHYSICAL MOTION ≠ TENSION`.

Tension comes from expectation, stakes, information, forces, relation and consequence.

### B200-05 — MYSTERY IS OPTIONAL; INFORMATION ASYMMETRY IS FUNDAMENTAL
Track:
- reader knows / character does not;
- character knows / reader does not;
- neither knows;
- different characters know different partial facts.

`ASYMMETRY → LEGIBLE QUESTION → ACTION / INTERPRETATION → PAYOFF`.

### B200-06 — MYSTERY-IN-AUTHOR'S-POCKET REJECTION
If withheld information does not affect character behavior, evidence state or reader question, it is not productive suspense.

### B200-07 — MOTIVATION ≠ PREPARATION
`MOTIVATION = WHY EVENT/CHOICE CAN HAPPEN`.
`PREPARATION = HOW READER IS READIED TO RECEIVE / ANTICIPATE IT`.

Audit both independently.

### B200-08 — DIALOGUE ACTION INCLUDING SILENCE
`PRESENT WANT → VERBAL / NONVERBAL TACTIC → PARTNER RESPONSE → TACTIC UPDATE → CHANGED STATE`.

Silence may be an action. It is never automatic consent.

### B200-09 — SUBTEXT CONTEXT
`SURFACE UTTERANCE → ACTION CONTEXT / RELATION / CONSTRAINT → POV INTERPRETATION → RESPONSE`.

`SUBTEXT ≠ MOTIVE FACT`.

### B200-10 — OBJECT / COSTUME / SETTING FUNCTION
`OBJECT / COSTUME / PLACE → RELATION TO CHARACTER → AFFORDANCE / FRICTION / STATUS / MEMORY → ACTION → CONSEQUENCE`.

Reject catalogue detail with no changed relation or inference.

### B200-11 — ENVIRONMENT AS COUNTERFORCE OR SUPPORT
`ENVIRONMENT RULE → OPTION SET → TACTIC → CONSEQUENCE`.

Useful for orbital habitats, non-Earth bodies and technical infrastructure.

### B200-12 — CLIMAX / AFTERMATH SEPARATION
`DECISIVE COLLISION / CHOICE → OUTCOME → AFTERMATH / RELATION / RESPONSIBILITY UPDATE`.

A large climax does not remove the need for aftermath.

### B200-13 — PROLOGUE / EPILOGUE PAYMENT
`FRAME MATERIAL → NEW KNOWLEDGE / CAUSAL SETUP / EMOTIONAL PREPARATION / AFTERMATH / FUTURE STATE`.

Otherwise compress or remove.

### B200-14 — PAST-TIME ROUTING
`WHY PAST NOW? → WHAT PRESENT STATE CHANGES? → FULL FLASHBACK / REPORTED MEMORY / SUMMARY / OMIT`.

A character's telling can be better than reenactment when present attitude, source reliability or relation is the point.

### B200-15 — MONTAGE AS RELATION
`A → CONTRAST / PARALLEL / ASSOCIATION → B → EMERGENT READER RELATION`.

Do not use montage/juxtaposition merely to display formal cleverness.

### B200-16 — TRANSITION FUNCTION
A transition earns emphasis only if it carries orientation, causal parallel, time change, meaning or controlled reader-state shift.

`CLEVER TRANSITION WITHOUT PAYMENT → SIMPLE TRANSITION`.

### B200-17 — REPEATED FORMAL DEVICE NEEDS NEW WORK
Repeated sound bridges, correction lines, montage rhymes, aphoristic reversals and author-signature devices must change function or meaning.

## B. Cross-source reconciliation

### Scofield / Bickham / Swain / Storynomics
Convergence:
`ACTIVITY / PROCESS / SPECTACLE ≠ EVENT / PROGRESSION`.

### Baxter / Seger Subtext / McKee Dialogue / Kempton
Dialogue and silence act relationally; modern IVDIVO adds motive uncertainty, listener attention, evidence and consent firewalls.

### Genette / Chatman
Turkin's flashback/montage/parallel-action mechanisms should be audited with order/duration/frequency/focalization rather than treated as camera-only craft.

### Wolf / James / Cambridge SF
World detail earns space by changing affordance, social reading, action or model—not by technical novelty alone.

### Le Guin / Prose / Hodgins / Clark / Williams-Bizup
Turkin's own distinction between kinetic speed and dramatic dynamics reinforces the anti-choppiness system.

## C. Historical firewall

Do not promote to modern IVDIVO law:
1. Soviet ideological prescriptions;
2. 1930s production constraints;
3. silent/sound-film shot economy;
4. fixed screenplay size/part arithmetic;
5. Freytag catastrophe canon;
6. mandatory conflict;
7. political conformity as positive character development;
8. physiognomic/moral reading of costume/appearance;
9. format-specific dialogue brevity as prose law;
10. historical audience-psychology assumptions.

## E. Production synthesis

`WHAT IS HAPPENING → WHO DOES IT MATTER TO → WHAT CHANGED → WHAT LATER NOW DEPENDS ON THAT CHANGE?`

That question is the main retained contribution of the source.
