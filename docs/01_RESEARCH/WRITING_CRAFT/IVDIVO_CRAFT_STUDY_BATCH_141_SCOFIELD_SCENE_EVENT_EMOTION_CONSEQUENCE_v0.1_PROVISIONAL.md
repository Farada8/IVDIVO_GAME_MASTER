## Mechanism 1 — Scene = focused event in time, not mere vivid presence

Scofield's Chapter 1 makes a useful distinction between material that is simply present on the page and material that has become a scene. Her scene model centers on a focused event unfolding in continuous time, with character agendas, action/response, some meaningful discovery/change, and consequences.

IVDIVO adaptation:

`SCENE OWNER → PRESENT AGENDA → FOCUSED EVENT IN READER TIME → ACTION / NOTICE / RESPONSE → MEANINGFUL CHANGE → CONSEQUENCE`

A scene therefore earns real-time reader attention because something consequential is happening **now**, not because the setting, dialogue, or technology is inherently interesting.

### Gate B141-G01 — EVENT-IN-TIME
Before expanding material into full scene, answer:
1. What is the event?
2. Who is its experiential/focal owner?
3. What changes because it occurs in real time?
4. Why does exact sequencing matter?

If these answers are weak, test SUMMARY / EMBEDDED SCENE / SCENE FRAGMENT instead.

## Mechanism 2 — Event + emotion must be causally coupled

Scofield treats scene as a knot binding event and emotional response rather than two independent tracks. The useful production question is not "did we include emotion?" but:

`WHAT HAPPENED → WHO EXPERIENCED IT → WHAT DID IT MEAN TO THEM → WHAT CHANGED IN THEIR NEXT OPTION / RELATION / MODEL?`

This prevents the common GPT pattern:

`event → free-standing emotional sentence → another event → another emotional sentence`

where the emotional lines decorate rather than alter causality.

### Gate B141-G02 — EVENT/EMOTION COUPLING
An emotional beat earns space when it changes at least one of:
- interpretation/model,
- trust/relationship,
- commitment,
- evidence handling,
- tactic,
- consent/boundary,
- future option space.

Otherwise compress it, embed it, or let later behavior carry it.

## Mechanism 3 — A scene should "add up"

Scofield's later self-evaluation material provides a strong diagnostic phrasing: if the reader is not left in a meaningfully different place, rethink whether the material merits a scene. This converges with Rosenfeld, Bell, Swain, Ribó, Chatman, and Truby, but Scofield usefully combines **event, emotion, function, and structure**.

IVDIVO changed-state matrix:
- action/physical state,
- knowledge/evidence status,
- relationship/trust,
- authority/access,
- responsibility/obligation,
- strategy/model,
- emotion/commitment,
- future option space.

### Gate B141-G03 — SCENE ADDS UP
A full scene should normally change at least one matrix axis in a way that matters downstream.

`NO DOWNSTREAM DIFFERENCE → SUMMARY / MERGE / DELETE / REBUILD CANDIDATE`

This is **not** the claim that every scene needs overt conflict, defeat, revelation, or a cliffhanger.

## Mechanism 4 — Character agenda does not require antagonist monoculture

Scofield emphasizes characters entering scenes with specific agendas. IVDIVO retains the agenda requirement but rejects the narrow equation:

`AGENDA → OPPOSING PERSON → FIGHT`

Use instead:

`PRESENT WANT / RESPONSIBILITY → PRESSURE / SUPPORT / CONSTRAINT → TACTIC → OUTCOME → CHANGED STATE`

Pressure may come from:
- another person's incompatible but reasonable goal,
- missing evidence,
- consent,
- physical environment,
- embodiment,
- institutional rule,
- limited time,
- relationship history,
- a conflict between two good values.

Real success remains allowed:

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`

## Mechanism 5 — Scene weight before sentence repair

Scofield's framework strongly supports the existing IVDIVO mode router:

`FULL SCENE / EMBEDDED SCENE / SCENE FRAGMENT / SUMMARY / COMMENTARY`

A procedure can be mostly summary with one real-time bull's-eye:

`SUMMARY → CONSEQUENTIAL 20–60 SECOND MOMENT → SUMMARY / CHANGED STATE`

Example diagnostic:
- routine equipment setup: compress;
- exact sentence in which consent is withdrawn: dramatize;
- repetitive testing: summarize;
- test result that overturns the working model: dramatize.

### Gate B141-G04 — SCENE WEIGHT
Classify before line editing:
- HEAVY — irreversible choice/evidence/relationship/personhood turn;
- MEDIUM — meaningful local state change;
- LIGHT — short scenic contact with one precise function;
- COMPRESSED — process/logistics/repetition whose exact beats do not matter.

## Anti-"обрубки" consequence

Do **not** implement scene mechanics as:

`stimulus.`
`reaction.`
`gesture.`
`thought.`
`decision.`

The repair order remains:

`ONE MAIN STORY → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT/MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → EVENT/EMOTION COUPLING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`

If several microbeats belong to one perceptual/decision unit, they should usually be allowed to live in one coherent paragraph and sentence sequence.

## Mystery / evidence firewall

Scofield's "unexpected discovery/change" is a scene function, not permission to manufacture evidence.

`TRACE → SOURCE → OBSERVATION → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION → STATUS UPDATE → ACTION`

A scene may change **what a character believes** without changing **what the evidence proves**.

## Nonhuman personhood firewall

For a conscious robot or distributed nonhuman person, scene function never overrides personhood:

`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`

A nonhuman character may be the scene owner; human interpretation of its behavior is not its motive.

## Consciousness-school epistemic firewall

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`

A vivid scene about subjective experience can establish experience and its consequences; it cannot by itself establish metaphysical ontology.

## Cross-source synthesis

### Scofield × Rosenfeld
Both emphasize consequential scene construction. IVDIVO rejects compulsory conflict/climax and keeps changed state + downstream consequence.

### Scofield × Swain/Bickham
All offer causal scene diagnostics. IVDIVO refuses stimulus-response metronome prose and mandatory disaster.

### Scofield × LaPlante/Prose/Lodge
These sources together support flexible routing between scene, summary, commentary, and indirect rendering.

### Scofield × Chatman/Ribó/Fludernik
Scene is one discourse mode inside a larger story/discourse architecture; story importance does not automatically require maximum scenic duration.

## Provisional failure modes

1. **SCENE-AS-PRESENCE** — vivid material without consequential event.
2. **EVENT/EMOTION PARALLEL TRACKS** — feeling decorates action but changes nothing.
3. **MICROBEAT CONFETTI** — scene theory implemented as one-line stimulus/reaction fragments.
4. **SCENE-WEIGHT FLATTENING** — every interaction dramatized at equal length.
5. **CONFLICT MONOCULTURE** — every agenda requires an antagonist and argument.
6. **DISCOVERY INFLATION** — every scene forced to reveal a new secret.
7. **STATE-NEUTRAL REAL TIME** — exact sequence consumes pages but has no downstream effect.
8. **NONHUMAN FUNCTIONALIZATION** — conscious being used as scene device rather than decision owner.
9. **EVIDENCE/INTERPRETATION COLLAPSE** — character's discovery treated as world fact.
10. **THEME AFTER THE EVENT** — action already communicates meaning, then narration explains it again.
