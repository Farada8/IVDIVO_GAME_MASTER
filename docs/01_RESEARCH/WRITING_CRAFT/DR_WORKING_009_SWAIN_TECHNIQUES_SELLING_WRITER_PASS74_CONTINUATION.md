## CHAPTER 3 — KEY SYNTHESIS

### 1. Dual-state causality
`EXTERNAL CHANGE <-> INTERNAL / RELATIONAL / MODEL CHANGE`

Swain is strongest when read as a continuity tool: an event matters because a character registers it, evaluates it, and the resulting response changes the next state.

### 2. M-R as a diagnostic, not a drafting template
Swain explicitly warns against using M-R mechanically and recommends drafting naturally, then checking whether reactions are motivated, motivating stimuli receive appropriate response, and language obscures no causal link.

IVDIVO gate:
`LIVE DRAFT -> CAUSAL/REACTION AUDIT -> REPAIR ONLY WHERE READER CONTINUITY BREAKS`.

### 3. Proportion / duration gate
The amount of text devoted to an event should scale with:
- required readjustment;
- magnitude/subtlety of state change;
- immediacy;
- difficulty of decision;
- difficulty of action;
- reader need for comprehension.

This is not a command to dramatize every microreaction.

### 4. Anti-chop correction
Swain explicitly notes that a choppy passage may need sentence restructuring/surface unity rather than added M-R steps. His own tension discussion also warns against extremes and says short must be balanced with long.

IVDIVO:
`INTENSITY != SHORT-SENTENCE DENSITY`.

### 5. Epistemic firewall
Swain's one-to-one cause/effect model is useful for legibility, but he acknowledges actual causality is complex. Therefore:
`NARRATIVE MODEL != VERIFIED CAUSE`.
Use Zunshine/Herman/LaPlante safeguards for mystery, motive, consent, science and ontology.

### 6. Moral-commercial firewall
Swain's period claim that satisfying commercial fiction tends to reward virtue/reaffirm reader philosophy is historically situated craft ideology, not an IVDIVO law. Theme is proven by consequences, not mandatory moral reward.
