## 1. DESCRIPTION IS SELECTION UNDER ATTENTION

Working model:

WORLD / SENSORIUM → POV ATTENTION → SELECTION → LANGUAGE → READER MODEL

Description is not neutral transcription. Perception is simultaneous and layered; language forces selection. Therefore every descriptive choice also reveals what the perceiving consciousness privileges, fears, desires, knows, ignores, or cannot yet interpret.

### Production gate: ATTENTION PROVENANCE
For any non-trivial descriptive paragraph ask:
- Who is perceiving?
- What do they want right now?
- What can their body / training / history let them notice?
- Why this detail rather than a neighboring one?
- What does the selected detail change for reader inference, action, relation, evidence, or rhythm?

Failure mode: CAMERA-WITHOUT-OWNER — generic description that could belong to any POV.

## 2. DESCRIPTION CAN BE A MODE OF THINKING

Doty’s analysis of descriptive chains shows description can develop an argument or model rather than merely decorate a pre-existing idea.

Operational form:

PARTICULAR → ASSOCIATION / COMPARISON → NEW RELATION → REFRAMED PARTICULAR → EMERGENT THOUGHT

This is useful for IVDIVO technical/mystery prose: a character may think by observing, comparing, revising, and naming. The insight should emerge from the sequence rather than be announced first and illustrated afterward.

Failure mode: THEME-FIRST DECORATION — author states the conclusion, then selects details only to prove it.

## 3. ACCUMULATION MUST MOVE

A list/catalog is not automatically rich description. Accumulation stays alive when successive elements shift tone, scale, register, sensory channel, contradiction, or conceptual pressure.

Production gate: DYNAMIC ACCUMULATION
Each additional descriptive unit should do at least one new job:
- add a new sensory dimension;
- change scale;
- complicate the previous interpretation;
- move from literal to relational meaning;
- introduce tension/contradiction;
- alter rhythm;
- change evidence status;
- expose the perceiver.

If item N could be removed/reordered with no meaningful loss, compress.

Failure mode: CATALOGUE WITHOUT VECTOR.

## 4. SPECIFICITY IS NOT THE SAME AS DATA

The source repeatedly distinguishes lived sensory apprehension from dry informational listing. For IVDIVO this supports:

WORLD DATABASE ≠ DESCRIPTION

A technical term, measurement, material specification, or piece of lore only belongs in prose when it becomes experience, inference, action, relation, or evidence.

Technical-description router:
CHARACTER QUESTION → MINIMUM RELEVANT PARTICULAR → SENSORIUM / MEASUREMENT → INTERPRETATION → TEST / ACTION → CHANGED MODEL

Failure mode: SPECIFICATION DUMP.

## 5. EXACT FACT MAY BE ALTERED IN ART — EVIDENCE MAY NOT

Doty’s discussion of Bishop’s “The Fish” usefully separates documentary fidelity from artistic description: art may change factual particulars for pattern/effect. This must be firewalled in IVDIVO mystery and forensic layers.

### FICTIONAL DETAIL FIREWALL
- In lyrical/worldbuilding prose, a non-evidentiary detail may be shaped for pattern, emphasis, rhythm, or symbolic coherence if canon remains intact.
- In clue/evidence architecture, measurements, source provenance, timestamps, physical traces, testimony status, and corroboration may NOT be cosmetically altered for beauty.

BEAUTIFUL DESCRIPTION ≠ LICENSE TO MUTATE EVIDENCE.

## 6. METAPHOR MUST REVEAL BOTH OBJECT AND OBSERVER

A comparison is strongest when it does more than decorate the object. It should expose a cognitive/experiential domain belonging to the POV.

Metaphor gate:
OBJECT → POV DOMAIN → COMPARISON → WHAT NEW PROPERTY BECOMES LEGIBLE?

If Maya, Samir, Ollie, Aoife, Ethan, Elena, Julian, and a conscious robot all reach for the same metaphor domain, authorial voice has overridden character perception.

Failure mode: UNIVERSAL AUTHOR METAPHOR.

## 7. DESCRIPTION MAY CONTAIN PRODUCTIVE AMBIGUITY

Inventive verbs/syntax can carry multiple simultaneous relations. Ambiguity is useful when both readings enrich the same experiential field; it is harmful when the reader cannot determine basic action, actor, evidence source, or causal status.

Gate:
PRODUCTIVE AMBIGUITY = multiple meaningful readings + stable basic event.
CONFUSION = basic event / actor / source / consequence cannot be recovered.

For mystery:
poetic ambiguity ≠ evidence ambiguity unless deliberately authored and later testable.

## 8. APPLICATION — ORBITAL YOUTH

Do not describe an orbital city as a technology catalogue. Use:

WORLD RULE → CHARACTER-SPECIFIC NOTICE → AFFORDANCE / FRICTION → ACTION → CONSEQUENCE

Post-money culture should be inferred through normal attention: ordinary manufactured objects barely attract economic thought, while scarce human/nonfungible things — trust, consent, time, unique mission slots, reputation, access to a person, lived practice — receive disproportionate attention.

## 9. APPLICATION — CONSCIOUS ROBOTS

No universal “sensor-feed voice.”

ROBOT EMBODIMENT + OWN WANT + RELATIONSHIP + TASK + KNOWLEDGE → SELECTED DETAIL

Observable sensor data does not equal motive. A robot can perceive with extraordinary precision and still interpret according to its own history, values, obligations, blind spots, and relationships.

## 10. APPLICATION — SCHOOLS OF CONSCIOUSNESS PRACTICE

Vivid description of an altered state must not raise epistemic status.

LIVED EXPERIENCE → OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL CLAIM

Intensity, beauty, sacred terminology, or conviction do not substitute for reproducibility/provenance.

## 11. ANTI-CHOPPY PROSE CONSEQUENCE

Description should not be atomized into one sensory fragment per paragraph by default.

Bad default:
object → one-line visual detail → one-line sound → one-line reaction → metaphor → thematic restatement

Preferred diagnostic order:
SCENE FUNCTION → POV ATTENTION → SELECTED PARTICULARS → RELATION / INFERENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM

A long integrated sentence/paragraph may better represent layered perception than a sequence of fragments.
