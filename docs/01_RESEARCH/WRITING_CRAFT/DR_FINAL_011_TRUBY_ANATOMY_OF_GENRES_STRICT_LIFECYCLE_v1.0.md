# Retained mechanisms

## 1. Genre contract, not genre law
Useful abstraction:
`PRIMARY STORY ENGINE → GENRE CONTRACT → EXPECTED FUNCTIONAL PAYOFFS → OPTIONAL CROSS-GENRE TOOLS → READER EFFECT`.

Genres are reader-expectation / mechanism families. They do not define psychology, morality, history, ontology, gender, or mandatory beat order.

`GENRE MIXING ≠ BEAT PILEUP`.

Secondary genre elements must pay into the same dominant causal engine or be removed/banked.

## 2. Genre pattern as diagnostic map
For any genre-specific beat:
`WHAT READER FUNCTION DOES THIS BEAT SERVE? → IS THAT FUNCTION NEEDED HERE? → WHAT CHARACTER/WORLD-SPECIFIC IMPLEMENTATION SERVES IT BEST?`

Never insert a beat merely because the genre chapter names it.

## 3. World rule / affordance / consequence
Especially strong in Science Fiction, Fantasy, Western and Myth:
`WORLD RULE / TECHNOLOGY / SOCIAL SYSTEM → AFFORDANCE / CONSTRAINT → PERSON-SPECIFIC CHOICE → CONSEQUENCE`.

A new world element earns reader-time only when it changes options, relationships, evidence, responsibility, risk, or social structure.

`NOVUM / NEW DISTRICT / NEW TECHNOLOGY ≠ NEW SCENE FUNCTION`.

## 4. Social-system model capture
Across Science Fiction, Crime, Western and Gangster:
`OFFICIAL MODEL / METRIC / INCENTIVE → ACCESS / STATUS / REWARD → EVIDENCE FILTER → LOCALLY RATIONAL ACTION → AGGREGATE EFFECT → MODEL UPDATE OR ESCALATION`.

Useful for writing institutions that are competent yet wrong without cartoon villains.

## 5. Tactic vs strategy
Action chapter's durable mechanism:
- **tactic** = local method used now;
- **strategy** = larger plan connecting actions to objective.

`TACTICAL WIN ≠ STRATEGIC SUCCESS`.

Improvisation can demonstrate competence without requiring violence.

## 6. Competence-success escalation
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

This is protected for YA and professional/institutional narratives.

## 7. World transition / model mismatch
Western/Fantasy/SF salvage:
`OLD MODEL / CAPABILITY → NEW SYSTEM RULE → AFFORDANCE MISMATCH → STRATEGY UPDATE / FAILURE / REPOSITIONING`.

Useful for changing institutions and cultures; does not require tragic death or historical-determinist stage theory.

## 8. Metric / mission distinction
Gangster/SF/social-system salvage:
`REAL OBJECTIVE → PROXY METRIC / INCENTIVE → OPTIMIZATION → METRIC WIN / MISSION LOSS → RULE / MODEL REVISION`.

Particularly useful for qualification systems, rankings, recommendation engines and governance.

## 9. Mystery: event vs inquiry
Detective/Thriller gives a strong two-track model:
`WHAT ACTUALLY HAPPENED` versus `HOW INVESTIGATOR / READER LEARNS IT`.

IVDIVO strict form:
`WORLD FACT → TRUE TRACE → SOURCE LINEAGE → POV ACCESS → MODEL A/B/C → DISCRIMINATING TEST → CORROBORATION STATUS → ACTION`.

Fairness constraints:
- POV belief is not world fact;
- known POV information cannot be hidden solely for surprise;
- relationship state is not evidence status;
- global ontology may remain unknown after a local operational answer is proven.

## 10. Investigator self-implication
Useful version:
`INVESTIGATOR QUESTION → TRACE CHAIN → SELF-IMPLICATING PRIOR DECISION / TOOL / POLICY / CLASSIFICATION → MODEL COLLAPSE → RESPONSIBILITY / ACTION UPDATE`.

This does not require the investigator to be the secret criminal.

## 11. Relationship causality
Love chapter's durable contribution after removing essentialism:
`INDEPENDENT WANT / LIFE GOAL A ↔ INDEPENDENT WANT / LIFE GOAL B → SUSTAINED CAUSAL CONTACT → TRUST / DESIRE / BOUNDARY CHANGE → RELATIONSHIP STATE → NEXT EXTERNAL CHOICE`.

A relationship becomes plot when its changing terms alter decisions, access, risk, disclosure, responsibility, or future plans.

## 12. Long-term relationship as evolving contract
For durable partnerships:
`EXPECTATIONS / RESPONSIBILITIES / BOUNDARIES → DAILY PRESSURE → NEGOTIATION / REFUSAL / CARE → NEW TERMS → CONSEQUENCE`.

This is stronger than courtship-only beats and does not require marriage, gender complementarity, or two-incomplete-halves psychology.

## 13. Alternative-future character comparison
Multiple suitors/partners/allies can function as competing future models when each represents a materially different way of life.

IVDIVO form:
`RELATIONSHIP OPTION → FUTURE LIFE / VALUE / COST MODEL → CHARACTER CHOICE`.

Do not reduce partners to prizes or symbolic personality fragments.

## 14. Recognition / model revision
Comedy/Love/Detective salvage:
`MIS-MODELLED STATE → DISCRIMINATING EVIDENCE / EXPERIENCE → MODEL UPDATE → ACTION / RELATIONSHIP CHANGES`.

Recognition does not create evidence from nowhere.

## 15. Quiet and distributed story progression
Not every genre function requires overt combat or worsening.

Multiple strands are valid when:
`STRAND LOCAL CHANGE → DOWNSTREAM EFFECT ON SAME MAIN ENGINE → CONVERGENCE / PAYOFF`.

`ONE MAIN STORY ≠ ONE HERO / ONE POV`.

# Major failure modes / rejected universal claims

## Genre-formula overreach
Reject:
- every good story hits all genre beats;
- mixing 3–4 genres is mandatory;
- genre ladder from Horror to Love is objective;
- Appendix seven steps are universal Story Code;
- final battle, self-revelation and new equilibrium are mandatory.

## Metaphysics / psychology overreach
Reject as fact:
- Jungian collective unconscious, anima/animus, archetypal essences;
- Great Chain of Being / higher-person hierarchies;
- genre as religion / enlightenment ladder;
- story as the universal religion or route to higher human consciousness;
- technology level as expression of human consciousness level;
- fixed `true self under pressure` psychology;
- universal Ghost/wound/Need.

## Gender / sexuality essentialism
Reject:
- man/woman as primary universal human distinction;
- biologically determined male/female psychological tendencies;
- shame/guilt gender binaries;
- pursuit/conquest as male norm and connection/care as female norm;
- heterosexual partnership or marriage as completion of the self;
- lover as the uniquely necessary missing half;
- `man becomes machine / woman becomes child` as universal marriage psychology;
- sex ordering rules as universal reader-effect laws.

## Personhood failure
Reject:
- robot/nonhuman becoming human as development metric;
- helper/opponent/archetype role superseding independent personhood;
- physical nonhuman difference as monster/shadow evidence.

`ARCHETYPAL FUNCTION ≠ PERSONHOOD`.

## Conflict / stakes overreach
Reject:
- violence as Action essence;
- life/death as default meaningful stakes;
- conflict as the only source of scene value;
- apparent defeat required;
- final violent battle required;
- `happiness is nearly impossible to dramatize` as law.

## Society / history overreach
Reject as science/history:
- fixed four-stage social evolution;
- universal frontier/capitalism/gangster models;
- broad national/cultural psychology claims;
- political binaries treated as complete explanatory systems.

# Cross-source comparison

## Bickham / Swain
Truby genre beats are downstream pattern maps. Bickham/Swain are stronger for local causal-state bookkeeping. Neither dictates typography.

## Brody / Vogler / Booker
All are useful as pattern/expectation lenses. None are allowed to stack mandatory beats into one production checklist.

## Genette / Chatman / Fludernik
Narrative order, duration, frequency, voice and focalization remain independent of genre pattern.

## Zunshine / Herman / Ephron / le Carré
Their source/provenance/evidence discipline supersedes Truby's more impressionistic Detective/Thriller philosophy.

## Hayes / Rosenfeld / Baxter / Chiarella
They supply stronger relationship personhood, consent, subtext and listener models than Truby's gender-essential Love machinery.

## Cambridge Companion / Edward James / Wolf
They supply stronger historical/worldbuilding discipline than Truby's genre metaphysics.

## Le Guin / Prose / Williams-Bizup / Clark / Hodgins
They supersede any inference that high-intensity genre requires short/choppy prose.

# IVDIVO operationalization

## Genre module contract
For each book/series:
1. identify dominant causal engine;
2. name primary genre promise;
3. name secondary genre functions;
4. for each secondary function, name the downstream causal payment;
5. remove/bank genre beats with no causal payment.

## Mystery module
`TRUE TRACE → SOURCE LINEAGE → ACCESS → MODEL A/B/C → DISCRIMINATING TEST → STATUS UPDATE → ACTION`.

`KNOWN POV INFO MAY NOT BE HIDDEN SOLELY FOR SURPRISE`.

## Relationship module
`TWO COMPLETE AGENTS → SUSTAINED CAUSAL CONTACT → CHANGED TRUST / DESIRE / BOUNDARY / DISCLOSURE → EXTERNAL CHOICE CHANGES → COST → NEW TERMS`.

`LOVE / KISS / CONFESSION / SILENCE ≠ CORROBORATION`.

## Institution / governance module
`MODEL / METRIC / INCENTIVE → WHO SETS IT → WHO BENEFITS → WHO PAYS → WHO CAN REFUSE / APPEAL → LOCAL BEHAVIOR → AGGREGATE EFFECT → REVISION`.

## Personhood module
`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

`NONHUMAN EMBODIMENT ≠ MONSTER ≠ MORAL INCOMPLETENESS`.

`ACTION / SUSPENSE / ROMANCE / MYSTERY / EMOTION ≠ SHORT-SENTENCE DENSITY`.

# Final synthesis
The durable value of *The Anatomy of Genres* is a large library of reader-contract patterns, opposition structures, system/world mechanisms, reveal forms and cross-genre comparison tools. Its weakest layer is its repeated conversion of those patterns into universal psychology, gender theory, social history and metaphysics.

IVDIVO retains the mechanisms and discards the essentialisms.

`GENRE CONTRACT ≠ STORY LAW`.
`PATTERN ≠ PERSON`.
`ARCHETYPE ≠ ONTOLOGY`.
