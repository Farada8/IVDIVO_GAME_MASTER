# IVDIVO CRAFT STUDY — BATCH 213
## Lisa Cron — Reader Models · Causal Meaning · Fair Reveal · Setup/Payoff · Revision

**Source:** Lisa Cron, *Wired for Story* (2012)  
**Lifecycle status:** `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`  
**Class:** WIDER  
**Date:** 2026-08-22

## Why this source matters
Cron is most useful not as “brain science,” but as a bridge between character appraisal, reader prediction, scene causality, setup/payoff, knowledge-state tracking and revision.

The source is strongest where it asks what a fact **means to this person now** and how that meaning changes the next choice.

## Production mechanisms

### B213-G01 — Event Significance
`EVENT / TRACE → WHO CARES? → BY WHAT GOAL / VALUE / RELATION? → APPRAISAL → ACTION`.

### B213-G02 — World / Character / Reader Separation
`WORLD FACT | POV ACCESS | POV BELIEF | READER BELIEF`.

Never let confident interpretation silently become canon.

### B213-G03 — Fair Reveal
`TRUE EARLY TRACE → PLAUSIBLE INITIAL MODEL → ADDITIONAL TRUE TRACES → DISCRIMINATING REVEAL → RETROSPECTIVE SUPPORT`.

### B213-G04 — Known-Information Fairness
If close POV already knows a load-bearing fact, narration may not erase it solely to manufacture surprise.

### B213-G05 — Setup Debt
Any salient capability, warning, object, anomaly, relationship promise or institutional rule creates expectation debt.

### B213-G06 — Causal Payment
`SCENE OUTCOME → LATER DEPENDENCY`.

If later chapters do not depend on what changed, test compression / merge / delete.

### B213-G07 — Genuine Success
Do not force `solution → worse problem` every time.

`COMPETENT ACTION → REAL SUCCESS → MORE RESPONSIBILITY → HARDER NEXT CHOICE`.

### B213-G08 — Productive Uncertainty
`CLEAR QUESTION + PARTIAL SPECIFICS + MULTIPLE PLAUSIBLE MODELS`.

Reject vague secrets with no usable particulars.

### B213-G09 — Specificity Filter
`POV SALIENCE + STORY FUNCTION + LIVED REALITY → DETAIL`.

Reject sensory checklists and detail-density KPIs.

### B213-G10 — Motive Inference
`BODY LANGUAGE / PAUSE / SELF-REPORT / UTTERANCE → MOTIVE HYPOTHESIS`.

Require corroboration for motive, guilt, consent or personhood claims.

### B213-G11 — Backstory Present Payment
`PAST → PRESENT MODEL / RELATION / TACTIC / EVIDENCE CHANGE`.

### B213-G12 — Subplot Main-Engine Payment
`SUBPLOT CHANGE → MAIN ENGINE OR MAJOR LATER CHOICE`.

### B213-G13 — Processing Variation
Reaction may be immediate, delayed, embedded, summarized or implied through later changed behavior.

### B213-G14 — Reader-State Feedback
Ask beta/audio listeners what they think is happening, what POV knows, what they expect next, where causal orientation broke.

`READER EFFECT = EVIDENCE; REPAIR PROPOSAL = HYPOTHESIS`.

### B213-G15 — Science Firewall
Cron’s neuroscience claims are explanatory rhetoric unless independently verified.

Craft law must survive removal of the neuroscience explanation.
