## 2. Primary mechanism — ACTION IS NOT EVENT

Scofield separates moment-to-moment actions from the larger event they add up to.

IVDIVO operationalization:

`MICRO-ACTIONS → RELATION / PATTERN → SCENE EVENT → CONSEQUENCE`

A scene can contain abundant movement and still have no meaningful event.

### Diagnostic

Ask after every candidate scene:

1. What happened beat by beat?
2. What changed globally because those beats occurred?
3. Who is differently placed afterward?
4. What later action, interpretation, relationship, evidence status, authority, responsibility, or option space now differs?

If question 2 cannot be answered without a thematic paraphrase, the scene is likely activity rather than event.

---

## 3. Production Gate B143-G01 — ACTION-TO-EVENT SUMMATION

Before line edit, reduce the scene to one sentence:

`Because these actions occurred, ______ changed.`

Valid changed-state families:

- physical / operational;
- knowledge / evidence;
- relationship / trust;
- consent / boundary;
- authority / access;
- responsibility / obligation;
- strategy / causal model;
- emotional commitment;
- future option space.

If no consequential blank can be filled, test:

`SUMMARY / MERGE / DELETE / REBUILD`.

---

## 4. Production Gate B143-G02 — ACTIVITY WITHOUT CONSEQUENCE

Failure mode:

`ACTION POPPING`

Symptoms:

- movement, banter, interface interaction, travel, tests, alarms, argument, or spectacle;
- no decision or evidence-status change;
- no new constraint or opportunity;
- no relationship or responsibility change;
- next scene would function identically if the scene disappeared.

Repair:

`identify intended event → rebuild beats so they converge on it`,

or compress the material.

This is particularly important for technical chapters where `test → screen → explanation → another test` can look active while remaining state-neutral.

---

## 5. Production Gate B143-G03 — QUIET EVENT LEGITIMACY

Scofield's event does not require spectacle.

For IVDIVO:

`QUIET ≠ STATIC`.

A quiet scene earns real-time treatment when it changes:

- a person's willingness to cooperate;
- consent;
- interpretation of evidence;
- trust;
- relationship terms;
- a private commitment;
- a hypothesis;
- the legitimacy of an authority claim;
- the available next action.

Therefore scene importance is measured by **consequence**, not loudness.

---

## 6. Production Gate B143-G04 — CONSEQUENCE OUTLIVES FRAME

A strong event may resonate beyond the physical frame of the scene.

Audit:

`SCENE OUTCOME → FIRST-ORDER CONSEQUENCE → SECOND-ORDER CONSEQUENCE → LATER PAYOFF`

This combines Scofield with the existing IVDIVO `Consequence Harvest` rule:

Before inventing a new anomaly, attack, witness, technology, secret, or subplot, ask:

`What has the event already introduced that has not yet had its natural consequence?`

This protects ONE MAIN STORY from `NEW EVENT ADDICTION`.

---

## 7. Production Gate B143-G05 — EVENT / MEANING SEPARATION

Do not confuse:

`WHAT HAPPENED`

with

`WHAT A CHARACTER THINKS IT MEANS`.

Mystery / SF state model:

`WORLD FACT → OBSERVED ACTION/TRACE → SCENE EVENT → POV INTERPRETATION → ALTERNATIVE MODEL → EVIDENCE UPDATE → ACTION`.

A scene may establish the event while leaving its meaning contested.

This is especially important for:

- ROOM 917 clue scenes;
- B07 nonhuman-personhood evidence;
- consciousness-practice schools;
- robot motive interpretation.

---

## 8. Production Gate B143-G06 — EVENT MUST HAVE AN OWNER OF CONSEQUENCE

A scene does not become meaningful merely because the setting or system changes.

Ask:

`WHO is affected, and how does that affect what they can/will do next?`

For ensemble fiction, the person who experiences the largest consequence need not be the POV owner, but the consequence must become causally legible.

This strengthens:

`WHO SPEAKS ≠ WHO PERCEIVES ≠ WHO INTERPRETS ≠ WHO DECIDES ≠ WHO BEARS COST`.

## 9. Cross-source comparison

### Scofield vs Swain / Bickham

Swain/Bickham make causal beat order highly visible. Scofield adds a higher-order question:

`What do the beats ADD UP TO?`

Integrated law:

`CAUSAL MICRO-READABILITY + GLOBAL EVENT CONSEQUENCE`.

Do not write stimulus/reaction as a metronome if the resulting scene still has no meaningful event.

### Scofield vs McKee

McKee defines story event through meaningful change. Scofield is useful for prose because she explicitly allows intellectual/emotional consequence and scene/narrative variation without requiring screenplay-like visible mechanics.

### Scofield vs LaPlante / Prose / Lodge

All support the distinction between narrative mode and story function. Summary can carry necessary time/process; full scene is reserved for material whose exact unfolding earns reader time.

## 10. Anti-choppy prose application

Do **not** translate `actions add up to event` into:

`action. reaction. gesture. thought. conclusion.`

Correct router:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT → NARRATIVE MODE → EVENT TARGET → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several micro-actions serve one event and one perceptual/decision unit, they should normally be allowed to form a coherent paragraph or longer sentence structure.

## 11. IVDIVO-specific implications

### ROOM 917

A recorder setup, wall measurement, contact-mic pass, corridor walk, or switchboard check is not automatically a scene event.

A true event occurs when the exact sequence changes:

- clue status;
- source provenance;
- Elena↔Julian trust/boundary;
- consent;
- investigative tactic;
- what one of them is now willing to disclose.

Romantic state change may alter action, but:

`TRUST / ATTRACTION / KISS ≠ CORROBORATION`.

### Orbital Youth

A new technology or district is not a scene event because it is novel.

Use:

`WORLD RULE → PERSON-SPECIFIC AFFORDANCE/FRICTION → CHOICE → CONSEQUENCE`.

### B07 — THE UNLISTED CITY

`interesting pattern detected` is not yet the meaningful event.

Possible event ladder:

`pattern → independent personhood evidence threshold → human policy no longer sufficient → entity preference/consent becomes decision-relevant → human option space changes`.

### Conscious robots

Human-observed behavior is not the event's final meaning.

`BEHAVIOR → CONTROL PROVENANCE / OWN MODEL → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Consciousness-practice schools

A vivid episode can be a consequential scene event for the practitioner without proving the school's ontology.

`EXPERIENCE CONSEQUENCE ≠ ONTOLOGY CONFIRMATION`.

## 12. New failure modes

1. **ACTION POPPING** — many actions, no consequential event.
2. **TECHNICAL BUSYWORK SCENE** — process is dramatized despite no state change.
3. **EVENT = THEME PARAPHRASE** — writer cannot state the scene event except as abstract meaning.
4. **LOUDNESS FALLACY** — spectacle is mistaken for consequence.
5. **QUIET-SCENE FALSE NEGATIVE** — relationship/evidence/commitment change is cut because no overt conflict occurs.
6. **MEANING COLLAPSE** — POV interpretation is silently promoted to world fact.
7. **CONSEQUENCE AMNESIA** — later chapters ignore the event's natural downstream effects.
8. **NEW-EVENT ADDICTION** — new complication is invented before existing consequences are harvested.
9. **MICROBEAT CONFETTI** — causality is rendered as choppy one-line units instead of coherent paragraph logic.
10. **TECH TOURISM AS EVENT** — new world element appears without affecting choice or future options.
