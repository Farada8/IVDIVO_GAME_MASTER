# IVDIVO CRAFT STUDY — BATCH 57
## David Lodge — Mode Variety · Duration · Implication · Endings

Date: 2026-08-17
Status: WORKING / SYNTHESIS DERIVED FROM STRICT FULL READ
Primary source: David Lodge, *The Art of Fiction* — Core #40, strict lifecycle completed in `DR_FINAL_040_LODGE_ART_OF_FICTION_STRICT_LIFECYCLE_v1.0.md`.

## PURPOSE
Convert the second half of Lodge's fifty close-reading essays into callable IVDIVO production mechanics without turning literary examples into mandatory formulas.

## 1. HIGH-VALUE MECHANISMS

### B57-M01 — DEFAMILIARIZATION THROUGH CONSEQUENCE
Do not make a future world feel new merely by naming new devices. Take an ordinary function, norm, relationship or object and reveal a consequence that the POV character cannot ignore.

`FAMILIAR FUNCTION → CONSEQUENTIAL DIFFERENCE → CHARACTER RESPONSE → REVISED WORLD MODEL`

Use especially for post-money life, robot personhood, orbital mobility, mixed-species infrastructure and specialist consciousness schools.

### B57-M02 — SETTING IS A BEHAVIOUR SYSTEM
A place is story-relevant when it changes movement, access, status, sensory experience, social expectation, evidence or choice.

`PLACE RULE → OPTION CREATED/REMOVED → CHARACTER TACTIC → CONSEQUENCE`

### B57-M03 — CHARACTER INTRODUCTION BY SYNECDOCHE
Prefer a few consequential details plus action/speech over dossier exposition.

`SELECTED DETAIL + CHOICE + SPEECH/TACTIC + OTHER PERSON'S REACTION → IMPLIED PERSON`

### B57-M04 — FAIR SURPRISE
A surprise should be underweighted before the reveal, not absent.

`PLANT → PLAUSIBLE INITIAL MODEL → REVEAL → RETROSPECTIVE LEGIBILITY → CONSEQUENCE`

### B57-M05 — REPETITION WITH DELTA
Every meaningful recurrence changes at least one dimension:
`MEANING / OWNER / RELATIONSHIP / STAKES / KNOWLEDGE / CONTEXT / EMOTIONAL VALUE`.

### B57-M06 — MODE ROUTING BEFORE PROSE POLISH
Route content among scene, summary, direct dialogue, indirect dialogue, free indirect style, direct thought and authorial narration according to reader need.

`READER EFFECT → MODE → DURATION → PARAGRAPH → SENTENCE`

### B57-M07 — FUTURE THROUGH NORMALITY + ONE CONSEQUENTIAL DIFFERENCE
A convincing future often enters faster through an ordinary activity transformed by one meaningful future condition than through a technology catalogue.

### B57-M08 — SYMBOL LITERAL-FIRST
An object/action must first function in the literal story. Symbolic charge may then accumulate through recurrence and context.

### B57-M09 — LOCAL UNRELIABILITY
Do not label a narrator globally reliable/unreliable. Track reliability separately for:
`OBSERVATION / MEMORY / MOTIVE INFERENCE / CAUSALITY / SELF-JUDGMENT / WORLD KNOWLEDGE`.

### B57-M10 — MOTIVE STACK
Before freezing a character's motivation, generate multiple compatible causes: practical, relational/status, self-image and possibly unadmitted. Do not reduce a person to one wound.

### B57-M11 — DURATION IS A READER-EFFECT VARIABLE
Fiction may spend pages on seconds and summarize years in one sentence.

`SUSPENSE / EMOTION / INFERENCE / TRANSITION NEED → EXPAND OR COMPRESS`

### B57-M12 — IMPLICATION CONTRACT
Omission works only if the text leaves enough trace for a fair inference.

`OMIT EXPLICIT STATEMENT → LEAVE TRACE → READER INFERS → LATER ACTION CONFIRMS/COMPLICATES`

### B57-M13 — IDEA EMBODIMENT
Do not stage a panel discussion merely to state the theme.

`MODEL A → COMPETENT PERSON/INSTITUTION → ACTION → BENEFIT/COST`
versus
`MODEL B → COMPETING PERSON/INSTITUTION → ACTION → BENEFIT/COST`.

### B57-M14 — UNCANNY DOUBLE-MODEL
When deliberate ambiguity is desired, construct two coherent explanatory models and make key evidence genuinely compatible with both until the contract allows narrowing.

### B57-M15 — ENDING TWO-LAYER
Separate resolution of the book engine from the final textual gesture.

`LOCAL QUESTION → DECISIVE CHOICE/RESULT → COST/AFTERMATH → FINAL IMAGE/LINE/EPILOGUE → OPTIONAL SAGA HOOK`.

## 2. FAILURE MODES ADDED/REINFORCED
1. **Description Tourism** — setting is displayed but does not change behaviour.
2. **Catalogue Worldbuilding** — technologies accumulate without causal/social work.
3. **Twist Without Fuse** — surprise has no recoverable prior support.
4. **Repetition Without Delta** — recurring image/phrase returns unchanged.
5. **Mode Monoculture** — every important fact receives full scene/direct dialogue/deep POV.
6. **Symbol Before Object** — object exists only to carry thesis.
7. **Unreliable-Narrator Excuse** — continuity defect is retroactively called unreliability.
8. **Single-Cause Psychology** — one trauma/trait explains everything.
9. **Implication Without Evidence** — withholding becomes vagueness.
10. **Ideas Panel** — theme exists primarily as explicit debate.
11. **Ambiguity as Evasion** — author has not decided proof ceiling/reader contract.
12. **Aporia as Underdevelopment** — unresolved craft problem is romanticized as uncertainty.
13. **Wind-Up Overpayment** — ending answers every secondary question and kills aftermath.
14. **Open-Ending Underpayment** — local book engine remains unresolved under guise of sophistication.
15. **Suspense = Chop** — prose is fragmented merely because stakes rise.

## 3. CROSS-SOURCE SYNTHESIS

### Lodge + Truby/McKee
Use Truby/McKee for causal book architecture; use Lodge to prevent architecture from hardening into local-form monotony. ONE MAIN STORY does not require one scene shape, one POV depth, one chapter ending or one prose tempo.

### Lodge + Rosenfeld/LaPlante
Strong convergence: show/tell is routing, not morality. Structural repair and mode choice precede line editing.

### Lodge + Zunshine
Lodge defines different mystery contracts; Zunshine supplies provenance/evidence-state control. Together they prevent both over-explanation and cheating ambiguity.

### Lodge + Card/McKee Character
Character may be implied through selected details and relation-specific behaviour. Exhaustive backstory and universal inner access are unnecessary.

### Lodge + McKee Dialogue
Remote media, addressee and missing bodily information change verbal tactics. Dialogue should be designed as action inside a communication channel, not just lines of speech.

## 4. PRODUCTION GATES
**B57-G01 — Mode Variety:** no default full-scene/deep-POV/direct-dialogue treatment.

**B57-G02 — Setting Causality:** description earns length by changing options, interpretation or relationship.

**B57-G03 — Surprise Fairness:** important reveal must be retrospectively reconstructable.

**B57-G04 — Repetition Delta:** every protected recurrence changes meaning/context.

**B57-G05 — Duration Freedom:** no sentence/paragraph/chapter length KPI tied to suspense or action.

**B57-G06 — Implication Evidence:** omitted meaning still leaves a recoverable trace.

**B57-G07 — Local Reliability:** track what a POV is reliable about rather than applying one global label.

**B57-G08 — Multi-Cause Motive:** generate competing/combined motives before locking psychology.

**B57-G09 — Idea Embodiment:** thematic claims must survive removal of explanatory dialogue because consequences still demonstrate them.

**B57-G10 — Uncanny Contract:** deliberate double-model ambiguity needs an explicit proof ceiling.

**B57-G11 — Ending Local Closure:** close the current book before franchise continuation.

**B57-G12 — Anti-Fragment:** diagnose mode/duration/paragraph intent before changing sentence length.

## 5. IVDIVO PROSE ROUTER
When a passage feels flat, over-explained or chopped, diagnose in this order:

`ONE MAIN STORY / CAUSALITY → SCENE NECESSITY → INFORMATION FUNCTION → MODE ROUTING → POV/DISTANCE → DURATION → PARAGRAPH INTENT → SENTENCE RHYTHM → WORD`.

Do not perform line surgery on a structural or mode-selection defect.

## 6. FINAL BATCH PRINCIPLE
**Long-form IVDIVO needs one dominant causal book engine, but it should deliberately vary local narrative mode, distance, duration, implication and chapter rhythm according to reader effect and character truth.**
