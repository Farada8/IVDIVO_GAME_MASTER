## 6. Highest-value mechanisms
### Given circumstances / action / adaptation
`GIVEN CIRCUMSTANCES + PRESENT TASK → ACTION / TACTIC → PARTNER / WORLD RESPONSE → ADAPTATION → CHANGED STATE`.

### Action before emotion/result
`CIRCUMSTANCE / TASK / PARTNER / ACTION → STATE MAY EMERGE`.

Do not directly perform authorial result (“show fear,” “show growth,” “show chemistry”).

### Bits/tasks are analytic units
`BREAK DOWN FOR ANALYSIS → RECOMBINE FOR LIFE`.

`BEAT / TASK ≠ SENTENCE BREAK / PARAGRAPH BREAK`.

### Through-line salvage
`LOCAL TASKS → COMMON CAUSAL DIRECTION → WHOLE EXPERIENCE`.

IVDIVO translation: ONE MAIN STORY is a common causal/dependency line, not a stack of individually attractive scenes.

### Partner response
`LINE / TACTIC → ACTUAL LISTENER RESPONSE → MODEL UPDATE → NEXT TACTIC`.

### Emotion Memory firewall
`PERSONAL MEMORY = OPTIONAL INPUT, NOT REQUIRED AUTHENTICITY`.

### Inner/outer rhythm
`INNER PROCESS SPEED ≠ OUTER MOTION SPEED ≠ SENTENCE LENGTH`.

### Speech grouping / pause function
`RELATED MICROBEATS → COHERENT COMMUNICATION UNIT`.

`PAUSE / DASH / ELLIPSIS / ONE-LINE PARAGRAPH → FUNCTION REQUIRED`.

### Framework automaticity
`ANALYZE → INTEGRATE → FRAMEWORK DISAPPEARS`.

### System anti-dogma

`FRAMEWORK = GUIDE / LAB, NOT SCRIPTURE`.
