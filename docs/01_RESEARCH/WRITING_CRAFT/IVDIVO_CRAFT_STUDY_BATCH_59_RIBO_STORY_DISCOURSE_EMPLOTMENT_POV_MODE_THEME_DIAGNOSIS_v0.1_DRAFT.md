# IVDIVO CRAFT STUDY — BATCH 59
## Ribó: Story/Discourse · Emplotment · POV · Mode · Theme Diagnosis

Status: WORKING / OPERATIONALIZED
Date: 2026-08-17
Source basis: strict-complete Core #37 — Ignasi Ribó, *Prose Fiction*.

## PRIMARY USE
Ribó is not another beat system. It is a **routing layer** that identifies what kind of narrative problem exists before a specialist repair source is called.

Primary diagnostic:
`STORY OR DISCOURSE? → WHICH SUBSYSTEM? → WHAT CHANGED / FAILED? → THEN CHOOSE TOOL`.

## SIX-COLUMN DIAGNOSTIC
1. **PLOT** — events, order, duration, frequency, causal connection, relevance.
2. **SETTING** — environment, topography, atmosphere, constraint, verisimilitude.
3. **CHARACTERISATION** — individuation, agency, behaviour, relationship function.
4. **NARRATION** — narrator, focalisation, knowledge, scene/summary, commentary.
5. **LANGUAGE** — syntax, rhythm, diction, paragraphing, foregrounding, figures.
6. **THEME** — interpreted meaning, motifs, ideology, moral/political implications.

A reported weakness must first be placed in one or more columns before repair.

## GATES

### B59-G01 — STORY / DISCOURSE FIRST
If changing sentence wording cannot repair the event/character/world state, stop line editing and return to story architecture.

### B59-G02 — EMPLOTMENT FIVE VARIABLES
For a weak sequence test separately:
`ORDER / DURATION / FREQUENCY / CONNECTION / RELEVANCE`.

### B59-G03 — EVENT STATE
Activity is not necessarily an event. Ask what state changed: action, information, relationship, emotion, social standing, access, safety, obligation.

### B59-G04 — NON-CONFLICT CAUSALITY
A quiet scene can earn its place through growth, discovery, recognition, accumulation, practice or relationship shift if future behaviour changes.

### B59-G05 — SUSPENSE / SURPRISE SPLIT
Do not confuse suspense with twists. Suspense is anticipated uncertainty; surprise violates expectation. Both require fair information architecture.

### B59-G06 — SETTING FUNCTION
Tag setting as `FUNCTIONAL / MENTAL / SOCIAL-ATMOSPHERIC / SYMBOLIC / TEXTURAL`. A setting can matter without physically blocking the hero.

### B59-G07 — DETAIL ROLE
Tag prominent detail: `CAUSAL / CHARACTER / ATMOSPHERE / SYMBOL / VERISIMILITUDE / REDUNDANT`.
Do not delete all non-payoff details under a false Chekhov-gun law.

### B59-G08 — STORYWORLD PERSON / BOOK FUNCTION
Supporting character page-time is not personhood. For conscious robots and nonhumans explicitly separate their book function from their independent storyworld life.

### B59-G09 — POV THREE QUESTIONS
`WHO SPEAKS? / WHO PERCEIVES? / WHAT CAN BE KNOWN?`
A pronoun change is not a POV repair.

### B59-G10 — SHOW/TELL ROUTING
Scene when exact words/actions alter state. Summary/indirect when compressing time, repetition, routine, logistics or lower-value conversation.

### B59-G11 — POLYPHONY
Ensemble diversity means different goals/world-models/tactics, not five variations of one witty author voice.

### B59-G12 — STYLE COMPONENT
Before a global style rewrite identify the failing component: `RHYTHM / SYNTAX / LEXICON / PARAGRAPH / FIGURATION / SOUND`.

### B59-G13 — SYMBOL / THEME SEPARATION
Recurring object ≠ theme. Require changing association and interpretable consequence before calling it a thematic motif.

### B59-G14 — IDEOLOGY REWARD AUDIT
Compare stated moral position with causal rewards: who gets agency, competence, victory, sympathy, cost and right of refusal.

### B59-G15 — ADAPTATION IS TRANSFORMATION
For audio/video adaptation preserve story function and reader/listener effect; do not mechanically transfer prose discourse into another medium.

## CHOPPY-PROSE ROUTER
For “обрубки” repair in this order:
`STORY/DISCOURSE → SCENE NECESSITY → DURATION/FREQUENCY → SHOW/TELL → POV → PARAGRAPH INTENT → SYNTAX/RHYTHM → WORDING`.
