## 2. New mechanism: SCENE GHOST ARCHITECTURE

Scofield explicitly rejects the idea that contemporary prose must be built as a rosary of fully developed scenes. Once the writer understands scene mechanics, prose can move through:

`FULL SCENE → EMBEDDED SCENE → SCENE FRAGMENT → SUMMARY → COMMENTARY → TIME JUMP → RETURN TO SCENE`

while still retaining an underlying scene structure — a **scene ghost** — that gives the narrative causal and emotional coherence.

### IVDIVO operationalization

`VISIBLE MODE MAY VARY; UNDERLYING CAUSAL EVENT MUST REMAIN LEGIBLE.`

The question is not:

> Is every page a full scene?

The question is:

> Can the reader reconstruct what meaningful event is occurring, who experiences it, what changes, and why the next material follows?

This is a major anti-formula counterweight to scene systems that accidentally encourage `scene rosary` prose.

---

## 3. Scene mode router — strengthened

Before line editing, assign the narrative unit one of these modes:

1. **FULL SCENE** — exact sequence deserves reader-time.
2. **EMBEDDED SCENE** — summary/narration contains one consequential real-time moment.
3. **SCENE FRAGMENT** — only a short image/exchange/action needs dramatization.
4. **SUMMARY** — process, recurrence, travel, logistics, repeated procedure, elapsed time.
5. **COMMENTARY / REFLECTION** — interpretation or meaning is the active function.

### Gate

`DO NOT FORCE FULL SCENE WHEN EXACT SEQUENCE DOES NOT MATTER.`

If a technical procedure lasts ten minutes but only one thirty-second consent exchange changes the story:

`SUMMARY → CONSENT MOMENT IN REAL TIME → SUMMARY / CHANGED STATE`

This is not weaker prose. It is better allocation of reader attention.

## 4. New mechanism: PRIOR-SCENE LABORATORY

Scofield recommends writing important prior scenes for the writer's own understanding even when they may never appear in the final narrative.

### IVDIVO operationalization

When backstory is vague, contradictory, or causing exposition dumps:

`WRITE THE PRIOR EVENT AS A PRIVATE SCENE → IDENTIFY WHAT ACTUALLY HAPPENED → EXTRACT ONLY CURRENTLY RELEVANT CONSEQUENCES → KEEP THE LAB SCENE OUT OF MANUSCRIPT UNLESS IT EARNS READER-TIME.`

This is especially useful for:
- old institutional decisions;
- relationship ruptures;
- first-contact precedents;
- consent history;
- prior evidence-handling failures;
- consciousness-school lineage incidents;
- robot/human trust events.

### Failure mode: PRIOR-SCENE DUMP

Writing a useful laboratory scene does **not** create an obligation to publish it as a flashback.

`AUTHOR NEEDS TO KNOW ≠ READER NEEDS FULL SCENE.`

## 5. New mechanism: EVENT + EMOTION COUPLING

Scofield's scene-evaluation material repeatedly couples the event with the emotion attached to it and asks whether the scene "adds up" to a meaningfully different state.

### Production model

`EVENT BEAT ↔ CHARACTER RESPONSE BEAT → NEW MEANING / RELATION / DECISION`

This does **not** mean:

`event. reaction. gesture. thought.`

as isolated fragments.

It means the external and internal lines should interact causally.

### Gate

For a consequential scene, map two tracks:

**ACTION TRACK**
- what objectively happens;
- who acts;
- what changes externally.

**RESPONSE TRACK**
- what the POV notices;
- what interpretation shifts;
- what relationship/commitment changes;
- what next choice becomes possible or impossible.

Then test whether the tracks actually touch.

If action and emotion could be swapped into unrelated scenes without changing meaning, the coupling is weak.

## 6. New mechanism: SCENE WEIGHT VARIATION

Scofield explicitly says not every scene should carry the same weight.

IVDIVO scene-weight assignment:

- **HEAVY** — irreversible decision, personhood/consent threshold, major evidence-status turn, relationship contract change, high-cost authorization.
- **MEDIUM** — meaningful local state change with clear downstream consequence.
- **LIGHT** — brief scenic contact with one precise function.
- **COMPRESSED** — repeated process/logistics/low-value transition.

### Failure mode: EQUAL-WEIGHT MANUSCRIPT

If every interaction is dramatized at the same resolution, the reader cannot tell what matters.

Symptoms:
- every arrival gets a scene;
- every technical test gets full dialogue;
- every emotional reaction gets a separate paragraph;
- every clue gets equal emphasis;
- chapter rhythm becomes metrically uniform.

## 7. New mechanism: SCENE FUNCTION CAPTION

Scofield's evaluation method asks the writer to identify the scene's function with a concise label.

Recommended IVDIVO captions:

`INFORMATION / CONFRONTATION / DECISION / REVELATION / RECOGNITION / CATALYST / REFLECTION / TURNING POINT / CAPITULATION / RESOLUTION`

plus project-specific functions:

`CONSENT CHANGE / EVIDENCE STATUS / AUTHORITY CHANGE / PERSONHOOD THRESHOLD / TRUST CHANGE / MODEL REVISION / OPTION-SPACE CHANGE`.

### Gate

If two adjacent scenes receive the same function caption and create substantially the same changed state, test:

`MERGE / SUMMARY / DELETE / REBUILD`.

This is a direct defense against repetitive middle chapters and technical-meeting loops.

## 8. Anti-choppy prose synthesis

Scofield further strengthens the current anti-fragmentation production order:

`ONE MAIN STORY → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT → NARRATIVE MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → EVENT-RESPONSE COUPLING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`

### Forbidden interpretation

Do **not** translate scene craft into:

`stimulus. reaction. gesture. thought. decision.`

When several microbeats constitute one perceptual/decision unit, they should normally be written as coherent sentence/paragraph flow.

## 9. Cross-source comparison

### Scofield × Rosenfeld

Convergence:
- scenes need intention/function and consequence;
- transitions may compress low-value material;
- real-time dramatization is selective.

Scofield's distinctive corrective:
- prose need not be a chain of full scenes;
- scene understanding can live underneath freer narrative texture.

### Scofield × Swain/Bickham

Swain/Bickham are useful for causal readability and response logic.

Scofield prevents these systems from becoming a visible mechanical grid.

Production synthesis:

`CAUSAL LEGIBILITY WITHOUT METRONOMIC PROSE.`

### Scofield × LaPlante

Strong convergence:
- generation and analysis are different activities;
- summary and scene are both legitimate tools;
- exercises can reveal structure without dictating final form.

### Scofield × Prose/Lodge/Zinsser

Convergence:
- reader continuity and paragraph-level flow matter more than rule compliance;
- stylistic variety must serve effect;
- a manuscript can be structurally rigorous without sounding schematic.

## 10. Failure modes added

1. **SCENE ROSARY** — manuscript is forced into equally explicit full scenes.
2. **SCENE ABSOLUTISM** — summary/commentary treated as inferior by default.
3. **PRIOR-SCENE DUMP** — author-lab backstory automatically inserted into manuscript.
4. **EQUAL-WEIGHT MANUSCRIPT** — every event receives same narrative resolution.
5. **EVENT WITHOUT RESPONSE** — external action changes but POV/relationship/model does not register it.
6. **RESPONSE WITHOUT EVENT** — emotional processing repeats without new causal input.
7. **ACTION-EMOTION PARALLEL TRACKS** — action and interiority coexist but never causally interact.
8. **FUNCTION DUPLICATION** — adjacent scenes do the same structural job.
9. **MOVIE-IMITATION PROSE** — visual beats copied without prose-specific interior/summary freedom.
10. **MICROBEAT CONFETTI** — event-response coupling rendered as one-line fragments.

## 11. Provisional production gates

### B142-G01 — MODE BEFORE LINE EDIT
Choose full scene / embedded scene / fragment / summary / commentary before sentence polishing.

### B142-G02 — SCENE-GHOST LEGIBILITY
Free narrative form must preserve a reconstructible causal event underneath.

### B142-G03 — PRIOR-SCENE LAB
Write missing backstory privately when necessary; publication requires a separate reader-time test.

### B142-G04 — EVENT-RESPONSE COUPLING
Action and interior response must alter one another, not merely alternate.

### B142-G05 — SCENE-WEIGHT VARIATION
Major and minor narrative events must not receive identical resolution by default.

### B142-G06 — FUNCTION CAPTION
Every candidate scene should have a concise current-book function.

### B142-G07 — DUPLICATE-FUNCTION CHECK
Adjacent scenes with the same function/state change trigger merge/compress review.

### B142-G08 — PARAGRAPH BEFORE FRAGMENT
Microbeats belonging to one perceptual/decision unit should usually remain paragraph-coherent.

### B142-G09 — READER-TIME JUSTIFICATION
Exact real-time sequence is earned only when exact sequence changes meaning, evidence, consent, trust, authority, decision, or reader effect.

### B142-G10 — NO FORMULA IMPORT
Scofield's teaching examples are diagnostic aids, not a mandatory scene template for every IVDIVO chapter.
