## A. Production mechanisms

### B178-G01 — Discovery Draft Is Evidence, Not Canon
`DRAFT DISCOVERY → CHARACTER/CANON/CAUSALITY TEST → KEEP / REPLAN / BANK / DISCARD`.

A live draft may reveal a stronger motive, relationship or scene direction. It does not override world authority automatically.

### B178-G02 — Door Shut / Door Open Routing
`GENERATE LIVE → DISTANCE → READ AS READER → DIAGNOSE → REWRITE → EXTERNAL TEST`.

Do not run every specialist during sentence generation.

### B178-G03 — Rewrite Above the Line Before Line Edit
Check in this order:
1. coherence / dominant engine;
2. motive / causality;
3. character and relationship truth;
4. scene necessity and changed state;
5. POV / evidence access;
6. paragraph continuity;
7. sentence rhythm;
8. wording.

### B178-G04 — Description Selection
`POV ATTENTION → FEW LOAD-BEARING DETAILS → READER BUILDS MODEL`.

Description is not exhaustive inventory.

### B178-G05 — Detail Weight / Reader-Time
Textual space should approximately reflect narrative importance. If routine process receives the same detail weight as a major consent/evidence/relationship turn, the discourse hierarchy is misleading.

### B178-G06 — No Physical-Trait Character Shortcut
Physical/grooming details can support a POV hypothesis. They do not prove intelligence, virtue, mental illness, motive or moral essence.

### B178-G07 — Dialogue Is Selected Speech
`LISTEN / OBSERVE → SELECT / SHAPE → RELATION-SPECIFIC TACTIC → LISTENER RESPONSE`.

Do not transcribe raw speech. Do not make characters literary mouthpieces.

### B178-G08 — Utterance Is Not Motive Fact
`UTTERANCE / PAUSE / GESTURE → MOTIVE HYPOTHESIS → ALTERNATIVE MODEL → CORROBORATION`.

### B178-G09 — Symbol Follows Functional Material
`FUNCTIONAL OBJECT/IMAGE → RECURS → MEANING CHANGES → OPTIONAL REVISION EMPHASIS`.

No theme-neon objects.

### B178-G10 — Theme as Revision Lens
`STORY CONSEQUENCES → RECURRING CONCERN → THEMATIC QUESTION → UNITY PASS`.

Theme should survive removal of thematic speeches.

### B178-G11 — Feedback Convergence
`READER REPORT → OBSERVED EFFECT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES → RETEST`.

One reader’s proposed fix is not authority.

### B178-G12 — Ideal Reader Is Simulation, Not Monoculture
A trusted reader can sharpen reader-effect prediction. Target-audience and multiple beta evidence remain separate.

### B178-G13 — Pace Is Not Maximum Speed
`PACE = READER-TIME ALLOCATION FOR INTENDED EFFECT`.

Fast is not inherently commercial; slow is not inherently literary.

### B178-G14 — Compression Is Not Chopping
`DELETE REDUNDANCY / INFERABLE STAGE DIRECTION → MERGE MICROBEATS → SUMMARY/INDIRECT PROCESS → KEEP LOAD-BEARING DETAIL → RETEST RHYTHM`.

### B178-G15 — 10% Cut Is Heuristic Only
King’s numeric reduction is not a KPI. Some drafts require expansion, substitution, reordering or longer syntactic units.

### B178-G16 — Backstory Present-State Debt
`PAST FACT → WHY NOW? → PRESENT MODEL / RELATION / DECISION / EVIDENCE CHANGE`.

### B178-G17 — Research Behind Story
`STORY QUESTION → KNOWLEDGE GAP → SOURCE → CORRECT ACTIONABLE DETAIL → CONSTRAINT / VERISIMILITUDE → CONSEQUENCE`.

Research volume is not reader value.

### B178-G18 — Reader Thinking Is Not Author Work
If the reader can infer a stage direction, obvious causal connection or simple interpretation, do not repeatedly explain it.

### B178-G19 — Prop/Setup Fairness
If a later payoff requires a prop, capability or rule, establish it before the payoff at a level proportionate to fair play.

### B178-G20 — Function Overrides Slogan
King’s actual `1408` revision keeps exceptions to his own stated preferences when those exceptions do useful work.

`FUNCTION > ADVERB BAN / CUT FORMULA / SHORTNESS RULE`.

## B. Failure modes

- **KING-METHOD UNIVERSALIZATION** — treating discovery drafting as the only authentic method.
- **TALENT ESSENTIALISM** — treating skill ceilings as fixed personal essence.
- **STORY-AS-FOSSIL LITERALISM** — turning a useful metaphor into ontology.
- **CRAFT TELEPATHY ONTOLOGY LEAK** — importing writer-reader “telepathy” into IVDIVO metaphysics.
- **BEHAVIOR→DIAGNOSIS LEAP** — diagnosing state/motive/illness from surface cues.
- **DESCRIPTION INVENTORY** — visual checklist without scene function.
- **PHYSICAL-TRAIT CHARACTER SHORTCUT** — “intelligent eyes,” “determined chin,” etc.
- **DIALOGUE TRANSCRIPT** — raw speech rather than selected dramatic communication.
- **THEME-FIRST PROPAGANDA** — characters serving a thesis.
- **SYMBOLISM OVERLAY** — imported symbols with no organic story function.
- **IDEAL-READER MONOCULTURE** — one trusted reader replacing audience evidence.
- **TEN-PERCENT KPI** — cutting to a target instead of fixing actual excess.
- **ADVERB/PASSIVE PURISM** — editing by word-class prohibition instead of function.
- **BACKSTORY MUSEUM** — interesting past that does not change present action/model.
- **RESEARCH PRIDE DUMP** — displaying research rather than using it.
- **WORKSHOP VAGUENESS** — feedback without a concrete text/effect diagnosis.
- **POPULAR-SUCCESS AUTHORITY LEAK** — treating commercial success as proof of universal rule.
- **HISTORICAL-MARKET LEAK** — importing 2000-era agent/submission practices as 2026 policy.
- **COMPRESSION→CHOPPING** — replacing redundancy with fragments instead of coherent prose.
- **READER-THINKING OVERWRITE** — author repeatedly interprets what action already showed.

## C. Cross-source decisions

### King vs Plot-First Schools
King’s discovery preference is retained as one valid generation mode. Bell/Seger/Mayer/Truby provide useful planning alternatives. Production router chooses method by project/defect, not ideology.

### King vs Theme/Premise Schools
King’s story-first approach is a strong firewall against propaganda. Egri/Truby/Brody premise tools remain useful as hypotheses/questions, never obligations the story must prove.

### King vs Sentence Shortness
Le Guin, Prose, Hodgins, Clark, Williams/Bizup and King’s own revised prose converge: shortness is not quality. Paragraph/topic continuity and contrast dominate raw sentence-length metrics.

### King vs Evidence-Cognition Sources
King’s intuitive reading of behavior is subordinated to Zunshine/Herman/le Carré/Ephron:
`OBSERVATION → HYPOTHESIS → ALTERNATIVE MODEL → CORROBORATION`.

## D. Standing IVDIVO synthesis after Batch 178

### Generation
`LIVE MATERIAL FIRST; SPECIALIST AUDIT AFTER A DEFECT OR MILESTONE EXISTS`.

### Revision
`ACTUAL TEXT → ACTUAL STORY STATE → DEFECT LEVEL → MINIMAL CORRECT REPAIR → REGRESSION TEST`.

### Prose / anti-choppiness
`SCENE/MODE → PARAGRAPH INTENT → OLD→NEW READER STATE → GROUP RELATED MICROBEATS → SENTENCE CONTRAST → WORDING`.

### Mystery
`RELATIONSHIP / INTUITION / EMOTIONAL DISPLAY ≠ CORROBORATION`.

### Personhood
`HUMAN-LIKE EXPRESSION IS NOT REQUIRED FOR NONHUMAN PERSONHOOD`.

### Manuscript law
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.
