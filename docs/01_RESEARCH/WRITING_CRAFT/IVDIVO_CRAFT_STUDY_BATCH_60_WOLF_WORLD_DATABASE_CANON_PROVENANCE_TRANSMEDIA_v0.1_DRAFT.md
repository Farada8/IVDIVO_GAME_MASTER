# IVDIVO CRAFT STUDY — BATCH 60
## Mark J. P. Wolf: World Database · Canon Provenance · Transmedia · Structured Unknowns

Date: 2026-08-17
Status: WORKING / PRODUCTION SYNTHESIS
Strict source: Core #36 — Mark J. P. Wolf, *Building Imaginary Worlds*

## 1. CENTRAL SYNTHESIS
Wolf is most useful to IVDIVO when worldbuilding is treated as a **persistent database and governance problem**, not as permission to put more lore into the novel.

Production chain:
`WORLD DATABASE → CURRENT CANON FILTER → BOOK-RELEVANCE FILTER → DISCOURSE/MEDIUM ROUTING → CHARACTER CONSEQUENCE`.

## 2. GATES

### B60-G01 — WORLD DATABASE / STORY SELECTION
A fact may be valuable enough to preserve in the Saga Bible while being wrong for the current scene or book.

### B60-G02 — PRIMARY-WORLD DEFAULT OVERRIDE
For every important unstated normality ask what contemporary reader default fills the gap. If the default violates IVDIVO, show a small ordinary counterexample through causal life.

### B60-G03 — CHANGED DEFAULT PROPAGATION
A major speculative difference must propagate into at least the systems it materially affects. Future vocabulary with unchanged behavior is not enough.

### B60-G04 — WORLD-INFERENCE CONSISTENCY
Use maps/timelines/institutions/language/history only to the depth required to keep causal possibilities coherent.

### B60-G05 — CANON PROVENANCE
No consequential lore claim without source + authority + status.

### B60-G06 — NEWEST FILE IS NOT HIGHEST AUTHORITY
Recency does not outrank Founder correction, approved canon or a locked manuscript.

### B60-G07 — RETCON MUST BE EXPLICIT
A corrected rule needs a supersession record and downstream repair list; silent replacement is forbidden.

### B60-G08 — OFFICIAL IN-WORLD ≠ TRUE
Institutional documentation, school doctrine, testimony and public history can canonically exist while being incomplete or wrong.

### B60-G09 — STRUCTURED UNKNOWN
Unknown ontology may remain UNKNOWN. Do not complete the world merely because the database has a blank cell.

### B60-G10 — BOOK CLOSURE BEFORE FRANCHISE EXPANSION
Saga continuation cannot substitute for resolving the local story engine.

### B60-G11 — SALIENT-INVARIANT ADAPTATION
Across prose/audio/video/game preserve world logic, personhood, ontology boundaries, relationship history and causal consequences. Change presentation according to medium.

### B60-G12 — REFERENCE-FICTION FIREWALL
External fiction contributes abstract mechanisms only. It does not become history, technology or metaphysics of IVDIVO.

### B60-G13 — ROBOT PERSONHOOD INVARIANT
Independent conscious robot civilisation is world canon, not a cosmetic SF feature. Every named robot must retain agency under adaptation and plot pressure.

### B60-G14 — POST-MONEY INVARIANT
No credits/rent/wages reintroduced as convenient YA shorthand. Use genuinely nonfungible stakes instead.

### B60-G15 — CONSCIOUSNESS-SCHOOL EPISTEMIC BOUNDARY
Rare-practitioner knowledge must retain provenance and disagreement; school interpretation is not mainstream orbital science.

## 3. FAILURE-MODE ROUTER
When a scene feels overloaded with worldbuilding, diagnose in this order:
1. Is the fact needed for the current causal choice?
2. Does the reader need it now rather than later?
3. Can normal behavior imply it?
4. Does the current POV legitimately know it?
5. Is the material actually database/appendix content?

When continuity conflicts:
1. Identify claim.
2. Identify every source asserting it.
3. Rank authority.
4. Mark CURRENT / SUPERSEDED / WORKING / IN-WORLD CLAIM.
5. Repair only downstream artifacts that depend on the losing claim.

## 4. CROSS-SCHOOL POSITION
- Truby/McKee constrain **book causality**; Wolf permits a world much larger than the book.
- Ribó/Lodge constrain **narrative/discourse selection**; Wolf supplies the persistent substrate being selected from.
- Zunshine constrains **in-world evidence provenance**; Wolf constrains **project-level canon provenance**.
- Cambridge SF shows that genre conventions mutate historically; Wolf shows how one changed default must propagate systematically.
- LaPlante protects uncertainty from false explanatory closure; Wolf protects world incompleteness from encyclopedic saturation.

## 5. PRODUCTION FORMULA
`CANONICALLY ALLOWED ≠ NARRATIVELY REQUIRED`.

A world fact enters prose only if it pays for at least one current function:
`ACTION / CHOICE / RELATIONSHIP / ORIENTATION / INFERENCE / TENSION / PAYOFF / CHARACTER FILTER`.

Otherwise preserve it in the world database and keep writing the story.
