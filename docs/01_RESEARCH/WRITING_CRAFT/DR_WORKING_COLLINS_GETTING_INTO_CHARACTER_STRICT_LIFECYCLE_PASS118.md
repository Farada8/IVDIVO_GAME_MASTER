## Mechanism synthesis from Secret #5

### 1. Inner rhythm is not outer speed

`INNER PROCESS PRESSURE / SPEED != OUTER MOTION SPEED`

A character may be nearly motionless while thought and emotion accelerate, or may move quickly while internally remaining methodical.

### 2. Rhythm discovery is upstream of prose

Collins' beating / body-response exercises are generation and diagnosis tools. They are not templates for finished narration.

`DISCOVER INNER RHYTHM -> GENERATE POSSIBLE EXPRESSIONS -> FILTER THROUGH CHARACTER / RELATIONSHIP / OBJECTIVE -> SELECT LOAD-BEARING EXPRESSION -> WRITE NATURAL PROSE`

### 3. Multiple external expressions are possible

Do not map one emotion to one gesture.

`INNER STATE -> MULTIPLE POSSIBLE EXTERNAL EXPRESSIONS -> CHARACTER-SPECIFIC FILTER -> TACTIC / OMISSION / ACTION`

This prevents generic body-language coding.

### 4. Inner rhythm can change without the external situation changing

New evidence, guilt, shame, hope, relationship pressure or a revised objective can change the inner tempo while the room, task and physical action remain quiet.

### 5. Sentence rhythm is a downstream choice

No direct rule exists from emotional intensity to fragment density.

`READER EFFECT -> POV STATE -> INNER/OUTER RHYTHM RELATION -> PARAGRAPH INTENT -> SENTENCE RHYTHM`

Not:

`HIGH EMOTION -> SHORT SENTENCES`.

## Cross-source comparison

- **Stanislavski:** strongly supports the distinction between inner and outer tempo-rhythm and explicitly treats physical rhythm drills as temporary aids rather than a universal performance method.
- **Le Guin / Francine Prose / Lodge / Zinsser:** reinforce that short syntax is a contrast tool, not an intensity KPI.
- **Swain / Bickham:** provide causal continuity; Collins adds character-specific tempo and embodiment to the same causal beat.
- **Card / Corbett / McKee Character:** reinforce that the same person behaves differently across relationships and pressure contexts.
- **LaPlante / Lamott:** reinforce discovery first, diagnosis and shaping later.
