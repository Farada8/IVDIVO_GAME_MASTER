## Secret #5 synthesis

### Inner rhythm is not outer speed

`INNER PROCESS PRESSURE / SPEED != OUTER MOTION SPEED`

A character may be nearly motionless while thought and emotion accelerate, or move quickly while internally remaining methodical.

### Rhythm discovery is upstream of prose

`DISCOVER INNER RHYTHM -> GENERATE POSSIBLE EXPRESSIONS -> FILTER THROUGH CHARACTER / RELATIONSHIP / OBJECTIVE -> SELECT LOAD-BEARING EXPRESSION -> WRITE NATURAL PROSE`.

### No emotion-to-gesture lookup table

`INNER STATE -> MULTIPLE POSSIBLE EXTERNAL EXPRESSIONS -> CHARACTER-SPECIFIC FILTER -> TACTIC / OMISSION / ACTION`.

### Sentence rhythm is downstream

`READER EFFECT -> POV STATE -> INNER/OUTER RHYTHM RELATION -> PARAGRAPH INTENT -> SENTENCE RHYTHM`.

Not `HIGH EMOTION -> SHORT SENTENCES`.

## Secret #6 provisional synthesis and firewall

### Restraint is not raw brevity

Useful core:

`SCENE / PARAGRAPH FUNCTION -> REMOVE REDUNDANT OR NONFUNCTIONAL MATERIAL -> PRESERVE LOAD-BEARING DETAIL -> SHAPE RHYTHM`.

Do not translate Restraint into `shorter is always better`.

### Collins' sentence-rhythm rule is not an IVDIVO law

Collins argues that long structures tend to feel languid and short/choppy structures tend to feel jarring, and broadly recommends the latter for suspense/action. This is a useful **option generator**, not a universal production rule.

Cross-source correction:

- Le Guin explicitly rejects an optimum sentence length and warns that continuous short/simple syntax becomes monotonous and choppy.
- Roy Peter Clark notes that repeated periods may actually slow the reader because they behave like stop signs.
- Williams/Bizup distinguish grammatical length/complexity from perceived processing difficulty.
- McKee, Lodge and other completed sources show high suspense can involve slowed subjective time and extended syntax.

Therefore:

`ACTION / SUSPENSE != SHORT-SENTENCE DENSITY`.

Use:

`READER EFFECT -> DURATION / CONTINUITY -> PARAGRAPH INTENT -> SENTENCE SHAPE / LENGTH -> CONTRAST`.

### Compression is not chopping

Later confirmed Collins material defines Compression as removing unnecessary wording and replacing general language with more specific language. IVDIVO provisional translation:

`REMOVE REPEATED MEANING / PROCESS -> MERGE MICROBEATS -> SUMMARY / INDIRECT WHEN APPROPRIATE -> KEEP SPECIFIC LOAD-BEARING LANGUAGE`.

Do **not** create more fragments while claiming to compress.

### Specific/vivid wording must remain evidence-safe

A vivid verb can encode interpretation. In forensic/mystery passages distinguish:

`RAW OBSERVATION -> POV WORDING / INTERPRETATION -> CORROBORATED CLAIM`.

Do not let a loaded verb silently raise evidence status.

## Historical-method firewall

Collins uses a broad `Method Acting` label for ideas attributed to Stanislavski. Modern Stanislavski scholarship distinguishes his evolving System / Method of Physical Action from Strasberg's later Method, especially on Emotion Memory. Treat Collins as a novelist's craft adaptation, not as authoritative theatre history or psychology.

This becomes especially important before Secret #7.
