## Core claims retained
1. Grammar is best treated as a repertoire of **purposeful language tools**, not merely a prohibition system.
2. Small lexical, syntactic and punctuation choices alter reader pace, emphasis, interpretation and social stance.
3. Rules become useful when the writer understands the conventional baseline and can depart from it for a specific effect.
4. Sentence variety and contrast create rhythm; no single sentence length is inherently superior.
5. Intentional fragments can be effective, but lose force when overused.
6. Active, passive and linking constructions all have legitimate functions; the relevant question is agency/emphasis, not ideological preference for one voice.
7. Tense shifts, modifier placement and syntactic dependency affect reader orientation and should be controlled deliberately.
8. Ambiguity can be productive or accidental; the writer must distinguish interpretive openness from reader confusion.
9. Concrete/particular detail and abstraction work best as a ladder rather than mutually exclusive modes.
10. Specialist, foreign, dialectal and nonstandard language require shared ground and reader legibility.

## Production mechanisms
### M1 — Grammar of Intent
`INTENDED READER EFFECT → LANGUAGE OPTION → LOCAL CONSEQUENCE → RETEST`.

Do not ask only whether a construction is permitted. Ask what it does to pace, emphasis, clarity, stance and relation between ideas.

### M2 — Punctuation as discourse engineering
`IDEA RELATION → PUNCTUATION / OMISSION → PACE / EMPHASIS / CONNECTION → READER MODEL`.

Period = strong stop/space; semicolon = separation plus connection; colon/dash/parentheses = hierarchy/interruption; ellipsis = omission/delay; quotation marks can also mark stance.

### M3 — Functional fragment
`COMPLETE CONTEXT → PURPOSEFUL OMISSION / FRAGMENT → SHOCK / PAUSE / INVENTORY / INFORMALITY / FOCUS`.

Fragment is allowed only when its function is stronger than a complete sentence in that exact location.

### M4 — Sentence contrast
`READER EFFECT → SUBJECTIVE DURATION / CONTINUITY → SENTENCE SHAPE / LENGTH → CONTRAST`.

Short and long structures derive force from relation to surrounding syntax.

### M5 — Dependency distance
`ELEMENT A REQUIRES ELEMENT B → DISTANCE / INTERRUPTION → CONFUSION RISK`.

Bring load-bearing grammatical or semantic partners closer unless distance itself creates a deliberate effect.

### M6 — Agency visibility
`WHO ACTS? → WHO RECEIVES? → WHAT SHOULD BE EMPHASIZED? → ACTIVE / PASSIVE / LINKING CHOICE`.

Passive is legitimate when receiver/consequence matters; suspect it when it conveniently hides decision ownership or responsibility.

### M7 — Strategic tense shift
`BASE TIME FRAME → PURPOSEFUL SHIFT → SPECIFIC READER EFFECT → RETURN / STABILITY`.

A tense change must buy immediacy, reflective distance, foregrounding or another legible function.

### M8 — Productive ambiguity
`CLEAR QUESTION / CONTEXT → MULTIPLE LEGIBLE MEANINGS → INTENDED EFFECT`.

Versus accidental ambiguity:
`UNCLEAR REFERENT / MODIFIER / CONNOTATION / WORD RELATION → READER CONFUSION`.

### M9 — Particularity ladder
`ABSTRACTION → CONCRETE EXAMPLE / PARTICULAR → READER INFERENCE → RETURN TO PATTERN`.

Or bottom-up:
`PARTICULAR → PATTERN → PROVISIONAL MEANING`.

### M10 — Shared-ground vocabulary
`SPECIAL TERM → WHO USES IT? → WHO UNDERSTANDS IT? → CONTEXT / TRANSLATION / CONSEQUENCE`.

Terminology should reveal discourse community/world knowledge without becoming a comprehension wall.

### M11 — Metaphor/analogy firewall
`ANALOGY / METAPHOR → ASSOCIATION / HYPOTHESIS`, never automatic proof.

The differences between compared things matter as much as similarities.

### M12 — Scare-quote / stance provenance
Quotation marks, euphemisms and word choice can embed stance. In mystery/evidence contexts:
`WORDING / SCARE QUOTES → STANCE CUE`, not `WORLD FACT`.

## Highest-value IVDIVO law — anti-choppiness
Clark strongly reinforces the existing convergence from Le Guin, Hodgins, Williams/Bizup, Lodge, Zinsser and others:

`ACTION / SUSPENSE / MYSTERY / EMOTION / SHORT FORM ≠ SHORT-SENTENCE DENSITY`.

One long, syntactically clear sentence may move faster than many short stop-start sentences. A short sentence or fragment is strongest as contrast, focus or deliberate stop.

Standing repair route:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE / MODE → POV / EVIDENCE → PARAGRAPH INTENT / READER-STATE → SENTENCE CONTRAST / RHYTHM → PUNCTUATION / WORDING`.

`BEAT ≠ SENTENCE BREAK`.

`PARAGRAPH BREAK ≠ VISUAL-DENSITY KPI`.

`COMPRESSION ≠ CHOPPING`.

## Failure modes
- FRAGMENT MONOCULTURE — fragments lose emphasis because everything is fragmented.
- PERIOD OVERBRAKING — too many full stops repeatedly reset reader momentum.
- PUNCTUATION DECORATION — marks chosen to look literary rather than encode relation/effect.
- PASSIVE RESPONSIBILITY MASK — institutional passive hides who decided/acted.
- ACTIVE-VOICE DOGMA — forced active syntax damages intended emphasis.
- TO-BE PURGE — removing linking verbs despite relational/stative function.
- TENSE SHOWBOATING — shifts display technique but do not buy reader effect.
- DEPENDENCY SEPARATION — linked elements are placed too far apart to process easily.
- ACCIDENTAL AMBIGUITY — reader must solve a wording problem the story did not intend.
- HYPERGRAMMAR — technically prestigious wording calls attention to correctness and damages voice.
- JARGON GATEKEEPING — discourse-community language becomes an access barrier without story function.
- UNIVERSAL AUTHORIAL REGISTER — all characters share the same elevated vocabulary/metaphors.
- METAPHOR-TO-EVIDENCE LEAK — an elegant analogy is treated as proof.
- PARTICULARITY FETISH — detail is specific but does not change model, character or inference.
- ACRONYM WALL — institutional abbreviations hide mechanism and agency.
- ONLINE-SHORTNESS RETROFIT — old digital-form conventions are applied as universal prose law.

## Cross-source comparison
### Converges strongly with Le Guin
Both reject universal sentence-length rules and make rhythm a function of contrast and purpose. Clark's intentional fragment maps cleanly to Le Guin's warning that persistent short syntax becomes monotonous.

### Converges with Williams/Bizup and Zinsser
Clarity depends on reader processing, dependency placement, agency visibility and structure—not a blanket preference for shortness.

### Converges with Hodgins / Prose / Lodge
Style is a repertoire; the writer chooses scene, sentence, detail and pace according to effect rather than fixed formal rules.

### Corrects simplistic active-voice advice
Clark explicitly treats active/passive/linking forms as functional alternatives. This supports the IVDIVO Missing Actor Gate without creating a passive-voice ban.

### Corrects simplistic `show, don't tell`
The book is not a scene-craft manual, but its whole rhetoric of purpose supports mode routing: literal/figurative, explicit/elliptical, abstract/concrete are choices, not virtue hierarchies.
