## Provisional mechanisms extracted from verified Chapter 8 material

### 1. ONE MAIN STORY does not require one POV or one thread

Multiple tracks are legitimate if they remain legible and contribute to a dominant book-level causal engine or an earned counterpoint.

IVDIVO adaptation:

`ONE MAIN STORY = ONE DOMINANT CAUSAL ENGINE, NOT ONE CHARACTER DOING EVERYTHING.`

### 2. Strand Value Test

For every substantial plot/POV strand:

`OWNER → LOCAL WANT → LOCAL CHANGE → EFFECT ON MAIN ENGINE/OTHER STRAND → CONVERGENCE OR PAYOFF`

If removing a strand leaves the climax, evidence chain, decisive relationship, and main causal engine materially unchanged, the strand is detachable rather than integrated.

### 3. Convergence is causal, not spatial

Bell's parallel-plot examples gain force as separate lines increasingly affect the same decisive story.

IVDIVO production gate:

`CO-PRESENCE ≠ CONVERGENCE.`

Characters meeting in one room, receiving the same briefing, or recapping discoveries is not convergence unless one strand changes another strand's available actions, evidence, relationships, authority, or decision.

### 4. Switching Cost Gate

Every POV/track switch imposes orientation cost.

Switch only if the new strand contributes at least one of:

- unique action;
- unique evidence;
- unique relationship pressure;
- unique lived experience;
- a necessary countermodel;
- a decision unavailable to the current strand.

Do not switch merely to equalize screen time across an ensemble.

### 5. Section / phase continuity

A long novel may move through major phases, locations, institutions, or periods while retaining a stable relational or causal spine.

Bell often applies a mini three-act pattern to phases. For IVDIVO this is retained only as a diagnostic heuristic, not a mandatory fractal template.

### 6. Nonlinear Reconstruction Contract

Verified Bell material explicitly treats nonlinear narrative as information arriving out of chronological order that readers must assemble into a coherent story.

IVDIVO adaptation:

`WORLD FACT → FRAGMENT / SOURCE → TIME / RELATION CUE → READER MODEL → NEW FRAGMENT → MODEL REVISION → EVENTUAL CAUSAL RECONSTRUCTION`

Confusion is not sophistication. The reader need not know the answer early, but must eventually be able to understand how the evidence fits.

### 7. Evidence placement is discourse, not ontology

A nonlinear reveal changes when and through whom information appears; it does not retroactively change the world fact merely to surprise the reader.

This reinforces the existing IVDIVO separation:

`WORLD FACT ≠ SOURCE CLAIM ≠ POV INTERPRETATION ≠ READER MODEL.`

### 8. Saga Scale Firewall

Bell's complex-plot discussion can tempt a large-series project to add more lines simply because the universe is large.

IVDIVO rule:

`SAGA SCALE ≠ BOOK SCALE.`

A world can contain hundreds of active systems while one novel remains narrow enough for reader memory and emotional causality.

### 9. Nonhuman / robot strand personhood

A conscious robot or nonhuman intelligence cannot be used as an exotic parallel interlude or information-delivery camera.

A genuine strand requires:

`OWN WANT → OWN CONSTRAINT → OWN RELATIONSHIPS → CONSENT / REFUSAL CAPACITY → ACTION THAT CHANGES THE SHARED CAUSAL ENGINE.`

### 10. Post-money translation firewall

Bell's business/money examples are structural illustrations only. Their function may translate into role, access, trust, responsibility, time, a unique opportunity, consent, or relationship stakes.

They do **not** authorize salary/rent/credits to re-enter orbital society.

## Cross-source comparison

### Chatman / Fludernik

Supports distinction between story and discourse, especially order/duration/frequency and the difference between world event and presentation order.

### Herman

Distributed intelligence helps explain how multiple strands can divide evidence, interpretation, lived experience, technical capability, countermodel, and bounded decision ownership without destroying ONE MAIN STORY.

### Card

Character hierarchy prevents ensemble equality at saga scale from becoming equal POV/screen-time obligation in each book.

### Rosenfeld / LaPlante

A strand can be causally active through relationship, emotional, or epistemic changes, not only physical event causality.

## Failure modes added

- ENSEMBLE EQUALITY RETROFIT — giving every major saga character a strand because they are important somewhere in the series.
- PARALLEL DECORATION — separate tracks that never alter each other's options.
- BRIEFING CONVERGENCE — mistaking shared exposition for causal convergence.
- NONLINEAR FOG — withholding chronology without a recoverable causal pattern.
- SOURCE/WORLD COLLAPSE — treating a fragment or testimony as world fact because it appears later in the book.
- POV NOVELTY SWITCH — changing POV for freshness without unique story work.
- SAGA DUMP — using one book to exhibit the size of the setting.
- ROBOT CAMERA — giving a conscious robot POV only to show alien/technical perception without independent agency.
- MONEY EXAMPLE REGRESSION — importing Bell's money/business stakes into post-money orbital society.
