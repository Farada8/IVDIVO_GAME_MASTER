## 5. Highest-value mechanisms

### Embedded narrative
`NARRATIVE / STORY AUTHORITY MUST ENTER BEFORE DOWNSTREAM ARTIFACTS HARDEN`.

A late writer becomes a script doctor repairing problems already embedded in design/assets/systems.

### Plan vs implementation
`PLAN ≠ ACTUAL TEXT ≠ CANON ≠ EVIDENCE STATUS`.

A GDD/outline is a starting model; implementation/text can create evidence requiring plan revision.

### Dependency handoff
`UPSTREAM CHANGE → EXPLICIT CONSUMERS → SELECTIVE INVALIDATION → RECHECK AFFECTED ARTIFACTS`.

### Trace before lecture
`WORLD FACT → LOAD-BEARING TRACE → POV NOTICE → READER INFERENCE`.

Environmental/audio information can replace exposition when evidence status remains explicit.

### Feature freeze
`DEVELOPMENT LOCK → EVIDENCE-BACKED REPAIR ONLY`.

A new craft idea is not evidence that a locked manuscript needs global reconstruction.

### Dialogue production value
For audio/game contexts:
`EXACT LINE → STORY / RELATION / EVIDENCE / PERFORMANCE FUNCTION → COST → KEEP / COMPRESS / INDIRECT / CUT`.

This does not become a novel short-sentence law.
