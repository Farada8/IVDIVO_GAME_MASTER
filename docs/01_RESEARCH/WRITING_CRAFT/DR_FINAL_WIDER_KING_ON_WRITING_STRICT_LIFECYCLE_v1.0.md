## 2. Structure map

King’s book is not a linear textbook. Its functional structure is:

1. **Memoir / formation** — lived events, work, rejection, family, addiction/recovery, early publishing.
2. **What Writing Is** — writer-reader transfer metaphor and the basic reader-model problem.
3. **Toolbox** — vocabulary, grammar, style, sentence/paragraph/tool hierarchy.
4. **On Writing** — reading/writing practice; situation/plot; description; dialogue; character; theme/symbol; revision; Ideal Reader; pace; backstory; research; classes; historical publishing advice.
5. **On Living** — accident, recovery and return to work.
6. **Door Shut / Door Open** — actual raw vs revised fiction demonstration.
7. **Booklist** — recent reading influences.

This architecture matters because the source repeatedly demonstrates rather than merely asserts its craft principles.

## 4. High-value mechanisms retained

### K1 — Door Shut / Door Open

**Mechanism**

`DISCOVERY DRAFT → PRIVATE STORY PRESSURE → REST / DISTANCE → READ AS READER → STRUCTURAL / CHARACTER / CLARITY DIAGNOSIS → REWRITE → EXTERNAL READER TEST`.

**IVDIVO use**
Do not ask every specialist to police every sentence during generation. Generate live material first; route actual defects afterward.

**Cross-source convergence**
Lamott, LaPlante, Swain, Bell, Seger, Mayer, Collins/Gillett.

---

### K2 — First Draft Is Discovery Evidence, Not Canon

King repeatedly discovers character, symbol and theme after or during drafting.

**Gate**

`FIRST-DRAFT DISCOVERY → CHARACTER / CANON / CAUSALITY TEST → KEEP / REPLAN / BANK / DISCARD`.

A draft can reveal a stronger truth about the story. It cannot override established IVDIVO canon merely by existing.

---

### K3 — Character Model Can Update During Draft

King’s accounts of Carrie, Johnny Smith and other characters show the author’s initial model can be incomplete or wrong.

**Gate**

`AUTHOR MODEL → PRESSURED BEHAVIOR → NEW EVIDENCE → CHARACTER MODEL UPDATE`.

This is not mystical “characters write themselves.” It is an evidence-based revision of the writer’s own model.

---

### K4 — Character-Causal Plausibility

King’s useful core is not “character must obey outline,” but:

`WHAT WE KNOW ABOUT THIS PERSON + PRESENT PRESSURE → BEHAVIOR THAT HELPS STORY AND REMAINS PLAUSIBLE`.

For IVDIVO:

`VALUES / RELATIONSHIPS / KNOWLEDGE / EMBODIMENT → PRESENT WANT → OPTION SET → TACTIC → CONSEQUENCE → MODEL UPDATE`.

---

### K5 — Selected Detail / Reader Co-Creation

King’s description principle is fundamentally selective: enough specificity to create a shared scene-model, but not exhaustive inventory.

**Mechanism**

`SCENE FUNCTION → POV ATTENTION → FEW LOAD-BEARING DETAILS → READER COMPLETES MODEL`.

**Gate**
A detail should pay through orientation, affordance, character, relation, inference, mood, rhythm or later payoff. Description should not become a world-database dump.

**Cross-source convergence**
Doty, Scofield, Hodgins, Blundell, Williams/Bizup.

---

### K6 — Detail Budget Tracks Story Importance

King’s own revision cuts lobby/stage-direction/detail that does not deserve equal attention.

**Mechanism**

`READER TIME / DETAIL WEIGHT ≈ NARRATIVE IMPORTANCE / EFFECT`.

Routine movement and neutral inventory get compressed; load-bearing moments get space.

---

### K7 — Dialogue: Listen → Select → Characterize

King’s useful dialogue core:

`OBSERVE / LISTEN → SELECT / SHAPE → RELATION-SPECIFIC UTTERANCE → LISTENER RESPONSE → NEXT TACTIC`.

Real speech is not transcribed raw. Literary “speechifying” is not more authentic than ordinary language.

**Evidence firewall**
`UTTERANCE / PAUSE / GESTURE → MOTIVE HYPOTHESIS`, not motive fact.

---

### K8 — Theme After Story / Theme as Revision Lens

King discovers recurrent thematic patterns after the story exists, then strengthens them in revision.

**Mechanism**

`LIVE STORY → RECURRING PATTERN → THEMATIC QUESTION / CONCERN → REVISION FOR UNITY → CONSEQUENCES CARRY MEANING`.

This prevents thesis-first propaganda.

**Important limitation**
King’s “story first, theme later” is a strong default for discovery writing, not a universal ban on premise-led or allegorical work.

---

### K9 — Symbol Emerges, Then Is Strengthened

Useful version:

`FUNCTIONAL OBJECT / IMAGE → REPEATED CONTEXT → MEANING CHANGES / ACCUMULATES → OPTIONAL REVISION EMPHASIS`.

Do not import a neon symbol merely to advertise theme.

Cross-source convergence: Hodgins “driftwood symbol,” Le Guin developing repetition.

---

### K10 — Revision Starts Above the Line

King’s first re-read asks large questions: coherence, character motivation, recurring elements, unity, missing logic — while also doing smaller cleanup.

For IVDIVO the order remains:

`BOOK ENGINE → CAUSALITY → CHARACTER / RELATIONSHIPS → SCENES → POV / EVIDENCE → PARAGRAPH / READER-STATE → SENTENCE RHYTHM → WORDING`.

Do not solve structural defects with line polish.

---

### K11 — Distance Before Revision

King’s six-week recommendation is personal, but the stable mechanism is:

`DRAFT → COGNITIVE DISTANCE → FRESH RE-READ → DEFECT DETECTION`.

No fixed six-week production law is adopted.

---

### K12 — Feedback Convergence, Not One Reader as Sovereign

King uses an Ideal Reader and several trusted readers.

IVDIVO synthesis:

`READER REPORT → OBSERVED EFFECT → REPEATABILITY / SOURCE QUALITY → DEFECT LEVEL → MULTIPLE REPAIR HYPOTHESES → TEST`.

A single reader can reveal a real issue. A single reader’s proposed fix does not become canon.

**Ideal Reader firewall**
One trusted reader is a useful simulation target, not a replacement for target-audience evidence or diverse beta evidence.

---

### K13 — Pace Is Not Maximum Speed

King explicitly rejects the assumption that commercially successful prose must always be fast.

**Standing law strengthened**

`PACE = CONTROLLED READER-TIME ALLOCATION`, not `short sentences + constant events`.

A story should unfold at the pace required by its reader effect.

---

### K14 — Compression ≠ Chopping

King’s famous `2nd Draft = 1st Draft – 10%` is a personal heuristic. His actual `1408` demonstration is more valuable:
- remove repeated meaning;
- remove stage direction the reader can infer;
- remove clumsy backstory;
- move load-bearing props earlier;
- retain exceptions that do useful work;
- preserve enough description for orientation and atmosphere.

**IVDIVO gate**

`DELETE REDUNDANCY / PROCESS → MERGE MICROBEATS → SUMMARY / INDIRECT WHEN NEEDED → KEEP LOAD-BEARING DETAIL → RETEST RHYTHM`.

`COMPRESSION ≠ SHORT-SENTENCE DENSITY`.

---

### K15 — Backstory Has Present-State Debt

King’s useful core:

`PAST FACT → WHY NOW? → PRESENT CHARACTER / RELATION / DECISION / EVIDENCE EFFECT`.

If backstory does not change the current reader/character model or action, compress or remove it.

His dislike of flashbacks/in medias res is personal taste, not production law.

---

### K16 — Research Supports Story, Not the Reverse

`STORY QUESTION → KNOWLEDGE GAP → SOURCE / FIELD RESEARCH → CORRECT ACTIONABLE DETAIL → VERISIMILITUDE / CONSTRAINT → STORY CONSEQUENCE`.

Research belongs behind the story unless the story’s actual engine is investigation/expertise.

**Evidence law preserved**
Expert fluency does not raise a claim to world fact without corroboration.

---

### K17 — Specific Feedback Beats Vague Praise

King’s workshop critique of vague “tone/feeling” comments supports:

`SPECIFIC TEXT / BEAT → OBSERVED READER EFFECT → DIAGNOSIS → REPAIR OPTIONS`.

Vague praise or disapproval gives little production value.

---

### K18 — Practice / Reading as Skill Ecology

Useful core:
- read broadly;
- write regularly;
- learn through exposure, attempts and revision.

Rejected:
- exact hours/day as KPI;
- “if you don’t compulsively write/read, you lack talent”;
- fixed ceiling between competent/good/great writers.

---

### K19 — Recovery / Writing as Personal Meaning, Not Prescription

King’s accident/postscript is strong memoir evidence that writing helped him return to ordinary life and purpose.

It is **not** a medical, therapeutic or universal psychological prescription.

---

### K20 — Actual Revision Demonstration Overrides Slogans

The `1408` before/after is one of the source’s highest-value sections because it reveals King’s actual editing behavior.

It proves his own slogans are not absolute:
- he cuts many adverbs, but keeps one when it performs a precise function;
- he cuts detail, but keeps/strengthens load-bearing detail;
- he shortens, but does not convert prose into fragments;
- he moves a prop earlier to make later payoff fair;
- he deletes reader-thinking/redundant explanation.

**Production law**
`FUNCTION > SLOGAN`.

## 5. Claims explicitly rejected or constrained

### F1 — Talent Essentialism
King’s hierarchy of bad/competent/good/great writers is not adopted as psychological law. Training, domain, feedback, time and task-specific performance complicate such claims.

### F2 — Discovery Drafting as Universal Method
Situation-first discovery works for King. It is not superior by definition to outlining, hybrid planning, treatment/grid methods or iterative architecture.

### F3 — “Story as Fossil” as Ontology
Useful metaphor for discovery; not a literal claim that stories pre-exist independently of authors.

### F4 — “Telepathy” as Science
Writer-reader “telepathy” is metaphor. It provides **zero** evidence for telepathy, consciousness transfer, subtle worlds or IVDIVO metaphysics.

### F5 — Behavior → Diagnosis
Visible grooming, eating, speech or other behavior may support hypotheses about state; it does not justify clinical diagnosis or moral essence.

### F6 — Adverb Ban / Passive Ban / Grammar Purism
No universal bans. Use functional tests for agency, clarity, rhythm, POV and emphasis.

### F7 — 10% Cut Formula as KPI
A useful challenge for puffy drafts, not a numeric target. Some revisions need expansion, reordering, replacement or a longer coherent sentence.

### F8 — Ideal Reader Monoculture
One trusted reader can sharpen intent but cannot replace target readership, multiple beta readers, audio evidence or specialist feedback.

### F9 — Market Advice as Current Policy
Agents, magazine markets, paper submission, Writer’s Market tactics and 2000-era business norms are historical. Verify current publishing practice separately.

### F10 — Workshop Skepticism as Universal
Vague workshop feedback is weak; well-designed workshops, controlled exercises and specialist critique can be valuable.

### F11 — Backstory / Flashback Preference as Law
King prefers chronological narration. Genette, Chatman, Lodge, Scofield and others show non-linear ordering can be highly functional when it changes reader inference.

### F12 — Popular Success → Universal Craft Authority
Commercial success makes King’s process worth serious study. It does not transform personal preference into universal mechanism.

## 6. Cross-source synthesis

### King × Lamott × LaPlante × Swain
Strong convergence:
`GENERATE LIVE → PROTECT DISCOVERY → DISTANCE → DIAGNOSE → REVISE`.

### King × Bell × Seger × Mayer
Plan and premise are hypotheses. Revision should follow actual draft evidence and defect level.

### King × Doty × Scofield × Hodgins × Blundell
Description is selected attention. Reader-time and detail weight should track story function; catalogues without vector are weak.

### King × Le Guin × Prose × Hodgins × Clark × Williams/Bizup
No support for a short-sentence KPI. Rhythm depends on contrast, topic chain, paragraph intent and reader-state continuity.

### King × Card × Corbett × McKee Character × Herman
Character becomes legible through choices, relationships, behavior and changing models; quirks/physical shorthand do not substitute for personhood.

### King × Zunshine × Herman × le Carré × Ephron
King’s behavioral/mental-state inferences must be subordinated to the stronger evidence law:
`OBSERVATION → HYPOTHESIS → ALTERNATIVE MODEL → CORROBORATION`.

### King × Genette × Chatman
King’s chronological/pace preferences are personal. Order, duration, frequency and focalization remain independent production variables.

## 7. IVDIVO operationalization

### Standing generation / revision law

`LIVE DRAFT → ACTUAL STORY STATE → DEFECT LEVEL → RELEVANT SPECIALIST TOOLS → MINIMAL CORRECT REPAIR → REGRESSION / READER TEST`.

### Standing anti-choppiness law — King reinforcement

`BOOK ENGINE → CAUSAL FENCE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → EXPOSITION/DIALOGUE MODE → PARAGRAPH TOPIC CHAIN → OLD→NEW / READER-STATE CONTINUITY → DETAIL BUDGET → SENTENCE RHYTHM/CONTRAST → WORDING`.

`BEAT MAP ≠ SENTENCE BREAK`.

`ACTION / SUSPENSE / EMOTION ≠ SHORT-SENTENCE DENSITY`.

### Description gate

`WHO NOTICES? → WHY NOW? → WHAT DETAIL IS LOAD-BEARING? → WHAT DOES IT CHANGE / ENABLE / IMPLY?`.

### Rewrite gate

`REMOVE REPEATED MEANING → REMOVE INFERABLE STAGE DIRECTION → FIX CAUSAL/MOTIVE HOLES → MOVE PAYOFF SETUPS EARLIER → STRENGTHEN READER ORIENTATION → RETEST RHYTHM`.

### Theme gate

`STORY / CHARACTER CONSEQUENCES FIRST → THEMATIC PATTERN SECOND → NO SERMON REQUIRED`.

### Reader gate

`ONE TRUSTED READER = useful signal; MULTIPLE CONVERGENT EFFECT REPORTS = stronger evidence; FIX PROPOSALS remain hypotheses`.

## 8. Manuscript validation

### LESSON ZERO Book One
**Verdict:** `KEEP DEVELOPMENT LOCK`.

King does not supply new current manuscript evidence requiring a rebuild. His strongest relevant advice actually supports the current law: revision should be evidence-driven and should remove non-story material without destroying live voice.

Standing law remains:

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

If future beta/audio evidence flags choppiness, test in this order:
1. unnecessary real-time scene/process;
2. paragraph topic-chain;
3. repeated reader-thinking / explanation;
4. stage-direction microbeats;
5. description weight vs scene importance;
6. only then sentence length/rhythm.

### Orbital Youth
- Use a few lived details, not technology inventory.
- Allow discovery draft to reveal stronger youth motives, but validate against post-money canon.
- Preserve `COMPETENT ACTION → REAL SUCCESS → MORE TRUST/RESPONSIBILITY → HARDER NEXT CHOICE`.
- Do not import King’s career/money stakes into post-money city life.

### ROOM 917
- Cut dialogue/exposition that only repeats known evidence.
- Preserve load-bearing clue setup early enough for fair payoff.
- Relationship state may change disclosure/tactic, never evidence status.
- `TRUST / ATTRACTION / KISS / CONFESSION / SILENCE ≠ CORROBORATION`.

### B07 — THE UNLISTED CITY
- Human emotional identification with a distributed entity is not personhood proof.
- Keep independent evidence threshold.
- After threshold, entity’s own preference/consent/choice must change human option space.

### Consciousness-practice schools
King’s craft “telepathy,” intuition, symbolic resonance and personal spiritual language have no epistemic authority.

Continue:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 9. Final synthesis

The durable contribution of *On Writing* to IVDIVO is not a list of King rules. It is a **production rhythm**:

`LIVE STORY FIRST → DISTANCE → READ WHAT ACTUALLY EXISTS → FIX MOTIVE / CAUSAL / UNITY PROBLEMS → CUT NON-STORY / REPEATED THINKING → STRENGTHEN LOAD-BEARING DETAIL → TEST WITH REAL READERS → POLISH LAST`.

King is most useful when his demonstrations are trusted more than his slogans. His actual revision practice repeatedly chooses function over dogma.
