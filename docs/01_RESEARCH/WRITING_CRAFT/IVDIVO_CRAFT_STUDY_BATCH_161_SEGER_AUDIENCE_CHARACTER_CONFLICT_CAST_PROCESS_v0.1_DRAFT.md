## PRODUCTION GATES

### B161-G01 — MARKET CLAIM FIREWALL
Seger's 2010 Hollywood market examples are historical context, not current publishing/streaming market law.

`MARKET EXAMPLE → GENERATION/POSITIONING HYPOTHESIS`, not `STORY CANON`.

### B161-G02 — AUDIENCE CONNECTION THROUGH SPECIFIC PERSON
Broad social/ethical questions should be embodied in specific people, choices and consequences.

`ABSTRACT ISSUE → PERSON-SPECIFIC COST / WANT / RELATIONSHIP → CHOICE → CONSEQUENCE`.

Do not convert this into demographic stereotyping or lowest-common-denominator stakes.

### B161-G03 — THEME THROUGH CAUSALITY
`THEMATIC QUESTION → COMPETING MODELS → CHOICES → CONSEQUENCES → READER INFERENCE`.

Theme must survive removal of explanatory speeches.

### B161-G04 — STAKES MULTI-AXIS
Track separately:
- safety;
- trust;
- consent;
- relationship;
- role/authority;
- responsibility;
- dignity;
- evidence integrity;
- belonging;
- mastery;
- unique opportunity;
- future option space.

Do not equate stakes with death by default.

### B161-G05 — DESCRIPTION / DIALOGUE DIVISION OF LABOR
Ask:
`WHAT CAN ACTION/SETTING/IMAGE CARRY? → WHAT REQUIRES EXACT WORDS? → WHAT CAN NARRATION/SUMMARY COMPRESS?`

Screenplay brevity rules do not become novel syntax rules.

### B161-G06 — CHARACTER VOICE = CONTEXTUAL SYSTEM
`WORLDVIEW + RELATIONSHIP + STATUS + PRESENT WANT + CULTURE → WORD CHOICE / SYNTAX / RHYTHM / REGISTER / OMISSION`.

No universal teen slang and no universal robot voice.

### B161-G07 — SUBTEXT MODEL GAP
`SURFACE WORDS/ACTION → UNSTATED WANT/PRESSURE → LISTENER MODEL → RESPONSE → CHANGED STATE`.

Subtext is optional; direct truth may be the earned payoff.

### B161-G08 — MOTIVATION / OBJECTIVE / TACTIC SEPARATION
`PRESENT REASON → TRACKABLE OBJECTIVE → TACTIC/ACTION → CONSEQUENCE`.

Do not use biography, wound, or explanation as substitute for present causality.

### B161-G09 — AGENCY NOT PHYSICAL ACTIVITY
Decision, refusal, waiting for evidence, negotiation, delegation, consent, disclosure, or controlled inaction may be highly agentic.

### B161-G10 — CONFLICT ROUTER
`WANT / VALUE / MODEL A ↔ COUNTERFORCE / VALUE / MODEL B → TACTICS → CONSEQUENCE / NEW TERMS`.

Conflict may be internal, relational, institutional, situational, epistemic, procedural, environmental or value-based.

### B161-G11 — NO INTERPERSONAL-CONFLICT MONOCULTURE
Seger's film preference for externalized interpersonal conflict is medium-specific.
Quiet internal/epistemic/relational causality remains valid in prose/audio.

### B161-G12 — NONVIOLENT CONFLICT REFRAME
`PRESSURE → FRAME / OPTION SET CHANGES → NEGOTIATION / REFUSAL / RECOGNITION / NEW TERMS`.

A strong climax need not end in defeat, explosion or domination.

### B161-G13 — MULTIDIMENSIONAL CHARACTER
`ATTITUDE / VALUES + CHOICES/ACTIONS + EMOTIONAL/RELATIONAL RESPONSES → READER MODEL`.

Do not reduce complexity to a list of traits.

### B161-G14 — CHANGE OPTIONAL, EVIDENCE REQUIRED
If a character changes, prove it through later choices/behavior/relationship terms.
No mandatory transformation arc.
No numeric beat quota.

### B161-G15 — CHARACTER FUNCTION ≠ PERSONHOOD
A cast member may have a book-level function, but a conscious major/supporting person needs independent wants, relationships and the ability to choose/refuse.

### B161-G16 — CAST REDUNDANCY AUDIT
`CHARACTER → UNIQUE FUNCTIONS → UNIQUE RELATION/EVIDENCE/DECISION VALUE → KEEP / MERGE / REMOVE`.

Do not merge sources if source independence or decision ownership would be destroyed.

### B161-G17 — THEME CHARACTER FIREWALL
Never create a character whose only job is to lecture the author's position.

### B161-G18 — SKEPTIC CONVERSION ≠ PROOF
A skeptical character accepting a supernatural/ontological interpretation is a narrative event, not scientific corroboration.

### B161-G19 — BACKWARD DESIGN
`DECISIVE END STATE → REQUIRED PRIOR CONDITIONS → EVIDENCE / RELATION / CAPABILITY SETUP → EARLIER PLANTING`.

Useful for mystery and climax design; do not pre-script every living scene.

### B161-G20 — PASSION ≠ MARKET CHASING
Use trends as external context only.
Do not deform story/canon to chase a currently popular genre/theme.

## CROSS-SOURCE CONVERGENCE
- Seger + Zunshine/le Carré: character belief is not evidence status.
- Seger + Hayes/Baxter: relationship lines must alter choices, but love does not erase personhood or proof requirements.

- Seger + Swain/Bell/Scofield: causality and changed state precede line polish.
