# IVDIVO CRAFT STUDY — BATCH 201
## James Scott Bell — Mental Game: Creative Process / Productivity / Recovery

**Date:** 2026-08-22  
**Source status:** strict lifecycle complete  
**Scope:** writer-process control, generation/evaluation separation, distraction routing, recovery, metrics firewall

## Primary synthesis
A sophisticated writing engine can fail by diagnosing the **writer’s temporary state** as a **defect in the manuscript**. Bell is most useful as a control layer against that error.

## Production laws
### B201-G01 — Writer State Is Not Text State
`WRITER STATE ≠ MANUSCRIPT DEFECT`

Before structural rewrite: identify actual textual evidence. Fatigue, envy, frustration, boredom or one weak work session are not sufficient evidence.

### B201-G02 — Process Metrics Are Not Literary Quality
`PROCESS METRIC ≠ STORY QUALITY`

Word count, throughput, scene count, gate count, agent count, output speed, likes or retention proxies may help operations; none is the artistic objective.

### B201-G03 — Divergence Before Convergence
`GENERATE → CAPTURE → DEFER JUDGMENT → DISTANCE → FILTER`

Use canon, personhood, causality, ONE MAIN STORY, reader effect and payoff only after sufficient option generation.

### B201-G04 — Specialist Interruption Queue
`NEW SPECIALIST OBSERVATION → FATAL/MAJOR NOW? → YES: INTERRUPT / NO: CAPTURE BACKLOG`

Prevents 100-agent context thrash during live generation.

### B201-G05 — Exercise Output Is Not Canon
`EXERCISE / WHAT-IF / FREEWRITE → DISCOVERY MATERIAL → CANON TEST → KEEP / BANK / DISCARD`

### B201-G06 — Recovery Before False Rewrite
If several passes degrade at once, test process conditions before changing story canon.

`LOW-QUALITY OUTPUT → FATIGUE / SWITCHING / OVERLOAD CHECK → RECOVER → RETEST → TEXT DIAGNOSIS`

This is production hygiene, not medical diagnosis.

### B201-G07 — Draft Speed and Prose Speed Are Independent
`FAST DRAFT ≠ FAST READER EXPERIENCE ≠ SHORT SENTENCES`

### B201-G08 — Audience Contract Is Not Market Obedience
`INTENDED EXPERIENCE → TEST`, not `TREND → STORY LAW`.

### B201-G09 — Distinctive Strength Is Not Brand Prison
Use observed strengths to improve selection; do not force every book or character into a fixed author persona.

### B201-G10 — Controllable / Uncontrollable Split
Separate controllable production actions from outcomes such as sales, rankings, reviews, luck and external validation.

## Failure modes

- QUOTA FETISH

- FAST-DRAFT RHYTHM LEAK INTO FINAL PROSE

## Cross-source comparison
**Lamott:** discovery draft must survive initial imperfection.  
**LaPlante:** generate, deep revise, constructively revise, line edit are different tasks.  
**Swain:** create first, critique after; rules are diagnostic.  
**Seger:** tool/program must not become blueprint.  
**Bell Mental Game:** adds process-state, distraction, recovery and controllable-metric discipline.

Combined:
`DISCOVERY → CAPTURE → DISTANCE → ACTUAL TEXT READ → DEFECT ROUTING → REPAIR → POLISH → READER TEST`.

## IVDIVO operationalization
### Multi-agent Writers' Room
A specialist should not seize the active draft merely because it has a good idea. Route non-critical observations into a versioned backlog with source, target artifact, suspected defect level and validation condition.

### ONE MAIN STORY
New ideas generated during creative sprints are BANKED unless they materially improve the current dominant causal engine.

### YA / characters
Do not interpret writer fatigue with one character as proof that the character needs trauma, a secret, a romance or a new subplot.

### Mystery / evidence
A clever new theory generated during drafting remains a hypothesis until clue provenance and proof ceiling support it.

### Style / choppiness
Never convert 'write fast' into staccato final prose. Sentence and paragraph rhythm are chosen during revision from reader effect and continuity.

## Science / market firewall
Bell's NLP, visualization, supplements/stimulants, mental-health and burnout assertions are not promoted to current scientific guidance. 2016 publishing-market observations require fresh verification before business use.
