## 1. Most useful transferable mechanisms

### 1.1 Possibility before commitment
Before drafting expensive scene architecture, expand an idea in multiple directions and identify both its audience promise and its inherent execution problems.

IVDIVO:
`IDEA → OPTIONS → PROMISES → INHERENT PROBLEMS → CAUSAL TEST → SELECT`.

### 1.2 Designing principle
Separate `what happens` from `the organizing process by which this story uniquely unfolds`.

Production test: if the supposed designing principle does not alter scene selection, information order, world use, relationship pattern or causal structure, it is only a slogan.

### 1.3 Single causal spine
Truby's strongest macro tool strongly supports ONE MAIN STORY.

IVDIVO correction:
`ONE CAUSAL ENGINE ≠ ONE PERSON DOES EVERYTHING`.

An ensemble may branch across POVs and private lives if the consequences continuously feed the same dominant problem and eventually reconverge.

### 1.4 External objective versus developmental need
A developmental pressure such as autonomy, belonging, maturity or self-respect is not the same thing as the book's operational objective.

Reader-facing question:
**What observable event/result tells us whether the protagonist or ensemble achieved the book's concrete goal?**

### 1.5 Value shadow
A useful value can generate a weakness when overextended.

Examples:
- responsibility → reliability / overcontrol;
- autonomy → self-direction / refusal of coordination;
- care → support / paternalism;
- competence → usefulness / inability to admit uncertainty.

Use only when causally demonstrated. Do not generate flaws from a table.

### 1.6 Character web
Major characters become clearer through comparison, relationship and different responses to the same central problem.

IVDIVO correction: character function/archetype is a design aid, never a replacement for independent personhood.

### 1.7 Opposition network
A social story becomes denser when major characters possess incompatible methods, values and obligations **with one another**, not merely with the protagonist.

No requirement for exactly four corners.

### 1.8 Strong counterargument
The strongest opposing character/institution should be right about something consequential.

`OPPOSING MODEL = REAL BENEFIT + REAL EVIDENCE + BLIND SPOT / COST`.

### 1.9 Theme through effects
Thematic argument should be visible in actions and consequences before explanatory dialogue.

Gate:
> If deleting the thematic speech deletes the theme, rebuild causal evidence before rewriting the speech.

### 1.10 Systemic argument
Truby's satire/black-comedy discussion yields a useful non-comic mechanism:

`SYSTEM RULE → LOCALLY RATIONAL ACTION → ACCUMULATED EFFECT → CONTRADICTION / COST`.

This is particularly useful for high-functioning institutions and algorithms where no villain is required.

### 1.11 World as social geography
The environment earns narrative weight when it alters action, risk, access, status, relationships, timing, or meaning.

`WORLD RULE → HUMAN OPTION SET → CHOICE → CONSEQUENCE`.

### 1.12 Arena and microcosm
A huge civilization becomes narratively legible through a bounded arena or microcosm—district, transit system, household, training center, event, workshop—while remaining explicitly only one lens on the larger society.

## 2. Important Truby claims rejected as universal rules

- Every hero must begin with a major moral flaw that hurts others.
- The hero must remain unaware of the need until near the end.
- One desire line can never develop through staged intermediate objectives.
- The opponent must literally compete for the same goal.
- Hero and opponent must remain in the same physical place.
- Every major story requires battle → self-revelation → new equilibrium in Truby's preferred form.
- Exactly four oppositional corners are inherently superior.
- Every environment carries a fixed symbolic meaning independent of POV/culture.
- A story world should be spatially compressed merely to satisfy arena theory.
- The author's moral vision must conclusively prove one way of life superior in every story.

## 3. Cross-source synthesis

**Truby + Rosenfeld:** Truby supplies macro causal spine; Rosenfeld gives scene-level consequence/intention recursion and prevents every beat becoming attack/failure.

**Truby + Card:** character web is valuable, but Card's independent-character/network approach prevents function/archetype flattening.

**Truby + Bell:** intelligent opposition converges strongly; both require a firewall against permanent pressure and stakes inflation.

**Truby + Herman/Oatley:** reasons/plans/person models offer a more psychologically precise account than mandatory moral flaw.

**Truby + Zunshine:** audience puzzle becomes source-monitoring rather than arbitrary withholding.

**Truby + Le Guin/Clark:** macro causality does not imply short sentences, chopped paragraphs or permanent narrative acceleration.

## 4. New provisional production gates

- **T-G01 CAUSAL SPINE** — one dominant evolving problem across the book.
- **T-G02 OBJECTIVE TEST** — observable achievement/failure condition.
- **T-G03 NEED ≠ OBJECTIVE** — developmental abstraction cannot replace plot objective.
- **T-G04 DESIGNING PRINCIPLE PAYS RENT** — architecture changes because of it.
- **T-G05 PROMISE / PROBLEM** — premise promises and hard execution problems identified before prose.
- **T-G06 TRUE CHOICE** — competing goods/costs, not obvious correct answer.
- **T-G07 VALUE SHADOW** — value's strength and overextension both available.
- **T-G08 OPPOSITION NETWORK** — major characters collide laterally, not only with lead.
- **T-G09 NO STRAW PERSON** — strongest opposing case contains surviving truth.
- **T-G10 STRUCTURAL THEME PROOF** — consequence carries theme before explanation.
- **T-G11 SYSTEM EFFECT** — locally rational choices can aggregate into harm.
- **T-G12 WORLD CHANGES ACTION** — environment modifies options or consequences.
- **T-G13 ARENA UNITY** — locations belong to one legible story process.
- **T-G14 MICRO-COSM LIMIT** — local institution is a lens, not the whole civilization.
- **T-G15 NO WORLD TOURISM** — spectacle without causal/relational function is compressed.

## 5. IVDIVO / Orbital Youth implications

The current Orbital Youth architecture should not be retrofitted to Truby's seven steps.

Useful applications instead:
- keep one dominant causal engine even when the five young characters separate into different lives;
- let Vela's transit, gravity, environmental systems, households and maintenance practices alter concrete choices rather than serve as tour stops;
- use competent locals/adults/robots as countermodels with genuine reasons;
- preserve independent life for supporting characters and conscious robots;
- let an institution be useful and problematic at the same time;
- treat microcosms (ring, transit corridor, workshop, household, civic event) as partial windows into post-money orbital society;
- do not manufacture a moral flaw in Ollie merely because Truby prefers one;
- do not import money/credits, consciousness transfer, or mainstream dimensional science through old examples.
