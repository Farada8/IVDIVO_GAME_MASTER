## 1. LINE-UP AS DIAGNOSTIC COMPRESSION, NOT FORMULA
Swain compresses the commercial story into five variables: focal character, situation, objective, opponent, disaster. Useful function: force ambiguity out of the story premise before pages proliferate.

### IVDIVO adaptation
`FOCAL ORIENTATION OWNER + CURRENT SITUATION + TRACKABLE OBJECTIVE + MEANINGFUL RESISTANCE + HIGH-COST FAILURE CONDITION`

Firewalls:
- resistance need not be a person;
- `disaster` need not be death/catastrophe;
- ensemble book may distribute objectives while retaining one dominant causal engine;
- conscious robot/nonhuman agent may be focal orientation owner in its own right.

## 2. STORY QUESTION AS READER CONTRACT
Swain's statement/question device is useful because it makes the book-level uncertainty explicit.

### IVDIVO gate
`BOOK PROMISE / QUESTION -> WHAT CAN CHANGE ITS ANSWER? -> WHAT EVIDENCE/ACTION ADVANCES IT? -> WHAT CONSTITUTES LOCAL CLOSURE?`

Do not force every question into binary `yes/no` if the book promises a bounded operational answer, relationship renegotiation, evidence ceiling or ethical choice.

## 3. COMMITMENT TRANSITION
Strong insight: a beginning ends functionally when the focal agent stops merely encountering a disturbance and assumes a stance that creates continuing causal involvement.

### IVDIVO adaptation
`DISTURBANCE / OPPORTUNITY -> OPTIONS STILL OPEN -> CHOICE / ACCEPTED RESPONSIBILITY -> NEW OBLIGATIONS + NEW OPTION SPACE -> SUSTAINED MAIN ENGINE`

Commitment can be:
- accepting a bounded role;
- agreeing to investigate;
- making a promise;
- refusing an institution's demand but accepting consequences;
- choosing to remain with a person/team;
- consenting to a test;
- taking responsibility for evidence already generated by one's prior action.

It need not be `I'll fight` and should not require macho confrontation.

## 4. PERIPHERAL OPENING MUST PAY INTO MAINLINE
Swain's warning against an exciting side issue that never matters is highly useful.

### Gate
`OPENING MATERIAL -> WHICH DOMINANT BOOK QUESTION / RELATIONSHIP / CAUSAL ENGINE DOES IT LOAD?`

If the answer is none, then:
- merge into later material,
- repurpose it as a genuine causal strand,
- or cut it.

This is especially important for IVDIVO because spectacular technologies can create false opening promises.

## 5. HOPE + FEAR, NOT WORRY MONOCULTURE
Swain explicitly treats suspense as hope plus fear, even though his commercial vocabulary overweights worry.

### IVDIVO Engagement Palette
`curiosity + hope + worry + intimacy + wonder + competence pleasure + humor + discovery + ethical uncertainty + earned relief`

No three adjacent scenes should use the exact same engagement engine without a deliberate reason.

## 6. MIDDLE AS CHANGE -> ADJUSTMENT -> NEW ACTION
Swain's middle begins from a clean causal loop: change forces adjustment; the character searches for a workable goal/response, acts, then new change forces another adjustment.

### IVDIVO middle engine
`CHANGED STATE -> MODEL/RELATIONSHIP/EVIDENCE UPDATE -> OPTION SET -> NEW STRATEGY -> ACTION -> CONSEQUENCE -> NEXT CHANGED STATE`

This is broader than `setback -> worse setback`.
Allowed changed states include:
- success creates trust/access/responsibility;
- evidence changes confidence;
- relationship changes willingness to cooperate;
- consent narrows or expands acceptable actions;
- a technical fix works locally but exposes system-level coupling;
- a person correctly refuses an option, changing the team's plan.

## 7. DON'T STAND STILL = NO STATE-NEUTRAL REPETITION
Swain's strongest middle diagnostic is not `always escalate`, but that story units should not repeatedly end with everyone in effectively the same state.

### State-change axes
Track separately:
- ACTION / physical/social state;
- KNOWLEDGE / EVIDENCE status;
- RELATIONSHIP / trust / intimacy;
- AUTHORITY / access / role;
- RESPONSIBILITY / obligation;
- STRATEGY / causal model;
- EMOTION / commitment;
- FUTURE OPTION SPACE.

A scene can be quiet and still pass if one or more relevant axes change in a way that affects later choices.

## 8. SUCCESS-BASED PROGRESSION
Swain's period model often prefers danger and defeat, but the deeper mechanics support another progression particularly valuable in YA:

`COMPETENT ACTION -> REAL SUCCESS -> MORE TRUST / ACCESS / RESPONSIBILITY -> MORE COMPLEX NEXT CHOICE`

This prevents competent young characters from being made artificially stupid merely to sustain plot motion.

## 9. ONE MAIN STORY CHECK
Each middle unit should answer:
1. What state was changed by the prior unit?
2. Who now owns the next problem/decision?
3. What new information/relationship/authority condition exists?
4. What strategy follows from that update?
5. What does the action change?
6. How does the result constrain or enable the following unit?

If these cannot be answered, the unit is a candidate for MERGE / COMPRESS / BANK / DELETE.

## 10. FAILURE MODES
- BINARY-STORY-QUESTION PRISON
- MANDATORY PERSONAL OPPONENT
- DISASTER INFLATION
- COMMITMENT-AS-MACHO FIGHT
- SPECTACLE OPENING FALSE PROMISE
- PERIPHERAL-HOOK DRIFT
- WORRY MONOCULTURE
- SETBACK MONOCULTURE
- STATE-NEUTRAL MIDDLE
- INFORMATION REHASH
- SUCCESS ERASED TO PRESERVE TENSION
- FIVE ENSEMBLE THREADS WITHOUT CAUSAL EXCHANGE
- CONSCIOUS ROBOT USED AS OBSTACLE RATHER THAN AGENT

## 11. CROSS-SOURCE COMPARISON
- Bell `Plot & Structure`: strong convergence on trackable objective and commitment/doorway; IVDIVO rejects fixed percentages and death-stakes.
- Rosenfeld: supports prior-consequence -> intention -> result -> next intention; better than mandatory defeat.
- Chatman / Ribó / Fludernik: state change can be informational, relational or discourse-level, not only physical event.
- Herman / Zunshine: evidence/model changes must keep provenance and confidence status explicit.
- LaPlante / Francine Prose / Lodge: correct Swain against forcing every meaningful unit into overt conflict.

## 12. IVDIVO PRODUCTION GATES ADDED
### B101-G01 — BOOK QUESTION LEGIBILITY
The reader must know what local uncertainty/responsibility organizes the book, even if the answer is unknown.

### B101-G02 — COMMITMENT TRANSITION
The active middle begins when a character/team accepts a course, role, responsibility or consequence that generates continuing causal involvement.

### B101-G03 — OPENING PAY-IN
Early high-attention material must pay into the actual dominant book engine.

### B101-G04 — STATE CHANGE MATRIX
Every sustained scene/unit changes at least one relevant state and that change must matter downstream.

### B101-G05 — SUCCESS MAY ESCALATE RESPONSIBILITY
Do not sabotage earned success merely to produce a setback.

### B101-G06 — NO REHASH
Repeated reminder of the same danger/argument/evidence is not progression unless its meaning/status changes.

### B101-G07 — ENGAGEMENT ROTATION
Do not equate suspense with continuous fear/worry.

### B101-G08 — PERSONHOOD UNDER STRUCTURE
Opponent/resistance labels never override independent agency, consent and motive of conscious persons/robots/nonhuman beings.
