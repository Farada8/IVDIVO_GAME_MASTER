## 2. CORE SYNTHESIS

### 2.1 SHOW/TELL IS A ROUTING DECISION
`DIRECT SCENE` is useful when exact words/actions must be experienced because they change trust, consent, evidence, decision, relationship, power or emotion.

`NARRATION / SUMMARY / INDIRECT` is useful when the stronger reader experience is compression, elapsed time, backstory, thought, interpretation, routine or repeated process.

Production consequence:
`SCENE NECESSITY → SHOW/TELL ROUTING → PARAGRAPH INTENT → SENTENCE RHYTHM → WORDING`.

This is especially important for IVDIVO's choppy-prose problem. Some “обрубки” are not sentence defects at all; they are symptoms of material that should never have been dramatized frame by frame.

### 2.2 POV = ACCESS + DISTANCE + ATTITUDE
Grammatical person is only one parameter.

Use a POV matrix:
`WHAT CAN THE POV OBSERVE? → WHAT CAN THEY KNOW? → WHAT DO THEY INFER? → WHAT DOES THE TEXT CONFIRM INDEPENDENTLY? → HOW CLOSE IS THE NARRATIVE DISTANCE?`

A first-person narrator may be distant; a third-person narrator may be intimate; omniscience does not automatically mean detachment.

### 2.3 RELIABILITY IS CALIBRATED
Do not reduce unreliable narration to `liar / truthful`.

Track separately:
- observable event;
- narrator interpretation;
- memory/self-model;
- independent evidence;
- consequences;
- established story-world rules.

Mechanism:
`POV CLAIM → HARD TRACE → INDEPENDENT SOURCE / CONSEQUENCE → READER MODEL UPDATE`.

### 2.4 SPECULATIVE ONTOLOGY FIREWALL
An impossible-seeming event may be:
1. an established world rule;
2. a focal-character distortion;
3. an information gap;
4. an author/canon mistake.

Do not use “unreliable POV” as an all-purpose repair for ontology contradictions.

For IVDIVO:
`CHARACTER BELIEF ≠ SCHOOL INTERPRETATION ≠ REPRODUCIBLE OBSERVATION ≠ CIVILIZATION-WIDE FACT`.

### 2.5 DIALOGUE IS SELECTED ACTION
Dialogue is not raw realistic transcription.

Mechanism:
`WANT → VERBAL/NONVERBAL TACTIC → RESPONSE → TACTIC CHANGE → CHANGED RELATION/DECISION/INFO STATE`.

Silence, gesture, object handling and environmental action belong to the dialogue scene.

### 2.6 RELATIONSHIP-SPECIFIC VOICE
One person should not sound/behave identically with:
- friend;
- parent;
- instructor;
- rival;
- intimate partner;
- public audience;
- conscious robot.

The difference should come from altered want, risk, history and leverage — not cosmetic slang.

### 2.7 PLACEHOLDER DIALOGUE IS ALLOWED DURING GENERATION
A generative pass may first establish who needs what and what information must move.

Then revise:
`PLAIN INFORMATION / AGENDA → CHARACTER FILTER → INDIRECTNESS / RHYTHM / GESTURE / SUBTEXT / ENVIRONMENT → TRIM`.

This protects generative flow while still demanding finished dialogue quality.

### 2.8 SOFT CAUSALITY IS REAL CAUSALITY
Not every meaningful scene mechanically causes the next external event.

A scene may alter:
- emotional pressure;
- relationship state;
- social status;
- evidence status;
- interpretation/model;
- readiness to choose.

Mechanism:
`EVENT → PRESSURE / MODEL CHANGE → COPING OR TACTIC → CONSEQUENCE → NEXT CHOICE`.

This supports ONE MAIN STORY without reducing the book to domino mechanics.

### 2.9 RENDER HOW BEFORE EXPLAINING WHY
Avoid single-cause pop psychology.

Prefer:
`SPECIFIC BEHAVIOR → CONTEXT → REPETITION / VARIATION → CONSEQUENCE → READER INFERS MULTIPLE CAUSES`.

A wound/backstory may matter, but it should not function as a diagnostic answer key.

### 2.10 ROUND CHARACTER = SURPRISING + CONVINCING
Roundness does not equal biography volume.

Test:
`NEW BEHAVIOR SURPRISES? → RETROSPECTIVELY CHARACTER-TRUE? → CAUSED BY RELATION/PRESSURE/WANT? → CHANGES READER MODEL?`

Minor/walk-on characters need only the depth their story function requires.

### 2.11 INTERNAL EVENTS CAN MOVE PLOT
Memory, imagination, fantasy, interpretation and projection count as plot functions when they change later action or strategy.

### 2.12 SCENES-À-FAIRE NEED ALTERNATIVES
When a scene feels “required by genre,” generate alternative embodiments before accepting it.

`CONVENTIONAL FUNCTION → 3+ DIFFERENT SCENE DESIGNS → CHARACTER/WORLD/CAUSAL FIT → CHOOSE`.

## 4. PRODUCTION GATES

**B53-G01 — POV Access Legality**  
Every consequential fact in close POV needs a lawful path into that consciousness.

**B53-G02 — Knowledge/Distance Separation**  
Do not repair POV by changing pronouns before diagnosing access and distance.

**B53-G03 — Reliability Evidence Channel**  
If focal perception is unreliable, provide traces/sources/consequences from which the reader can calibrate reality.

**B53-G04 — Ontology Contract**  
Do not collapse anomaly, belief, school doctrine and world fact.

**B53-G05 — Dialogue State Change**  
Use direct dialogue when exact wording changes a meaningful state; otherwise consider indirect/summary.

**B53-G06 — Relationship-Specific Voice**  
Major characters must change tactics/register according to relationship and leverage.

**B53-G07 — Embodied Dialogue**  
Important conversations include gesture, silence and physical world when those alter meaning.

**B53-G08 — Placeholder Revision**  
Serviceable first-pass dialogue is permitted; it is not final dialogue.

**B53-G09 — No Mandatory Subtext**  
Subtext must emerge from competing wants/relations, not be pasted onto every line.

**B53-G10 — Soft Causality Accepted**  
Emotional/relational/epistemic movement counts when it changes downstream choice.

**B53-G11 — Render How Before Why**  
Do not explain complex behavior with a single wound, diagnosis or childhood fact.

**B53-G12 — No Mandatory Antagonist**  
Quiet pressure, legitimate incompatible goals, environment or uncertainty may carry opposition.

**B53-G13 — Plot Order Justification**  
Nonchronological order must change information effect, not merely look sophisticated.

**B53-G14 — Scene-à-Faire Alternative Test**  
Before accepting a genre-obligatory scene, generate alternatives.

**B53-G15 — Round Character Evidence**  
Surprise must remain retrospectively convincing.

**B53-G16 — Character Attention Budget**  
Do not give every supporting person equal backstory, POV and revelation weight.

## 5. IVDIVO APPLICATION

### LESSON ZERO
No new evidence here justifies reopening Book One. Use these gates only where a current manuscript defect is demonstrated.

### ORBITAL YOUTH
Close POV should reveal a huge orbital civilization through bounded lived knowledge. Teenagers can know their routes, peer cultures, training rules and family situations without authorial access to total civilization-level truth.

### CONSCIOUS ROBOTS
No generic “robot voice.” A conscious robot should have its own objective, refusal rights, relationships, tactics, silences and differing registers with different people.

### SPECIALIST CONSCIOUSNESS SCHOOLS
Use:
`PRACTITIONER OBSERVATION → REPRODUCIBLE PRACTICE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → ONTOLOGICAL CLAIM`.
The last step cannot be smuggled into narration merely because one POV believes it.

### MYSTERY / FAIR PLAY
`POV BELIEF ≠ TRACE ≠ SOURCE INTERPRETATION ≠ INDEPENDENT CONFIRMATION ≠ WORLD FACT`.
A mystery reveal should alter a model and therefore action; mere lore accumulation does not qualify.

### “ОБРУБКИ” / PROSE
Diagnose in this order:
`SCENE NECESSITY → SHOW/TELL ROUTING → POV DISTANCE → DIRECT/INDIRECT DIALOGUE → PARAGRAPH INTENT → SENTENCE RHYTHM`.
Short syntax itself is not the first suspect.
