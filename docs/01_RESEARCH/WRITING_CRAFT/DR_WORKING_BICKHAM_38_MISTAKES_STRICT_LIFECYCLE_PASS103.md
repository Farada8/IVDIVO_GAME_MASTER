## Mechanism corrections

### Observation
Useful:
`RAW NOTICE → RECORD → DISTILL → POV-SPECIFIC PARTICULAR → STORY FUNCTION`

Correction:
Observation is not motive, cause, or world fact. Keep observation and inference separately tagged.

### Scene
Useful Bickham skeleton: immediate goal, opposition, tactics, changed ending.

IVDIVO correction:
`OWNER/WANT → PRESSURE/SUPPORT → TACTIC → CHANGED ACTION/INFO/RELATION STATE → DOWNSTREAM LINK`

Do not adopt mandatory disaster, mandatory binary scene question, mandatory personified opponent, or no-summary dogma.

### Processing
Useful:
`OUTCOME → PROCESSING → OPTION SET → DECISION → NEXT GOAL`

IVDIVO correction: processing can be immediate, delayed, embedded, summary, dialogue, or implied by later behavior. Do not render it as one-line microbeat confetti.

### Story compass
Useful: writer should know the dominant problem/goal line.

Correction: outline is a hypothesis, not canon. Live character-true material is tested by downstream causality and ONE MAIN STORY rather than suppressed automatically.
