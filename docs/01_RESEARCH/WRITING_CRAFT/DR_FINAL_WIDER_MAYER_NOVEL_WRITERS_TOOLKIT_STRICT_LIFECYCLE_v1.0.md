## Core claims retained

### 1. Plan is a working hypothesis
An outline records what the writer intends; the manuscript records what the story actually became.

IVDIVO form:
`PLAN / ACTUAL TEXT / CANON / EVIDENCE STATUS` are separate layers.

Authority direction:
`LOCKED TEXT → ACTUAL STATE MAP → PRODUCTION PLAN`, not the reverse.

### 2. Story state should be externalized
Useful registers include chapter purpose, chronology, location, action, character state, research facts and plot-line tracking.

IVDIVO extension:
`SCENE/CHAPTER → TIME → LOCATION → OWNER → GOAL → ACTION STATE → KNOWLEDGE/EVIDENCE STATE → RELATIONSHIP/CONSENT → AUTHORITY/ACCESS → EXIT STATE → NEXT CAUSAL LINK`.

### 3. Character knowledge is not author knowledge
POV controls what can be noticed, known, inferred and disclosed.

IVDIVO form:
`WORLD FACT → POV ACCESS / SENSORIUM / BACKGROUND → CHARACTER INTERPRETATION → READER MODEL`.

And:
`READER KNOWLEDGE × CHARACTER KNOWLEDGE × SOURCE PROVENANCE × DISCLOSURE COST`.

### 4. Revision should move macro → micro
Before polishing words, diagnose continuity, logic, scene necessity, motive, chronology, POV access and causal transitions.

IVDIVO form:
`OBSERVED DEFECT → DEFECT LEVEL → DEPENDENCIES → MINIMAL CORRECT FIX → REGRESSION TEST`.

### 5. Research must become usable story information
Research is valuable when it changes action, constraint, vocabulary, decision, evidence or reader understanding. Research volume is not a quality metric.

### 6. Synopsis can expose causal diffusion
Compression is diagnostic: if a book cannot be summarized without dissolving into procedures/subplots, ONE MAIN STORY may be weak or obscured.

## Mechanism bank

### MAYER-01 — Plan / Actual-State Split
`PLAN → DRAFT → ACTUAL STATE → CANON/CAUSALITY TEST → REPLAN / KEEP / BANK / DISCARD`.

### MAYER-02 — Knowledge-State Map
For every clue/reveal/decision:
`WHO KNOWS WHAT? → FROM WHAT SOURCE? → WITH WHAT CONFIDENCE? → WHAT DOES THE READER KNOW? → WHAT DISCLOSURE CHANGES?`

### MAYER-03 — State Grid
`TIME + LOCATION + OWNER + GOAL + ACTION + KNOWLEDGE + RELATIONSHIP + AUTHORITY + EXIT STATE`.

### MAYER-04 — Defect Router
`READER EFFECT → DEFECT LEVEL → DEPENDENCIES → MINIMAL FIX → RETEST`.

### MAYER-05 — Clue Salience Budget
A clue must be perceptible enough to be fair but not repeatedly underlined until inference becomes compulsory.

### MAYER-06 — Synopsis Stress Test
Compress the book to its dominant causal chain; distinguish indispensable state changes from attractive but non-load-bearing material.

### MAYER-07 — Series Evolution Gate
A sequel must change the problem, relationships, responsibility or option space rather than reset and replay the prior engine.

## Cross-source comparison

- **Bell / Seger / Lamott / LaPlante / Swain:** converges on plan-as-hypothesis and macro diagnosis before line polish.
- **Fludernik / Zunshine:** Mayer's grids become substantially stronger when knowledge is tracked with discourse placement and source provenance.
- **Card / Kress / Herman / Corbett / McKee Character:** constrain Mayer's occasional essentialist assumptions about personality and stress.
- **Le Guin / Francine Prose / Lodge / Clark:** constrain any action-oriented drift toward choppy syntax; intensity is not short-sentence density.
- **Wolf:** complements project-level canon provenance: production documents do not become world truth through repetition.

More sensors do not equal narrative omniscience. Observed behavior does not establish motive. Maintain:
`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Final synthesis

The highest-value Mayer contribution is infrastructure: separate intent from actual manuscript state, externalize chronology/knowledge/causal state, revise macro before micro, and treat planning tools as revisable instruments rather than authority.

The main limits are dated market advice, occasional personality essentialism and commercial conventions that should not be mistaken for universal narrative law.
