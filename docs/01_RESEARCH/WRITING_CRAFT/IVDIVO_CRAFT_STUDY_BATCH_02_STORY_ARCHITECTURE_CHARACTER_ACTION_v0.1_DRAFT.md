# SOURCE 1 — ARISTOTLE, *POETICS*

**Status after this pass:** READ / MECHANISM EXTRACTION — CORE PLOT SECTIONS PROCESSED.  
**Primary role:** unity of action, causal necessity/probability, whole action, reversal, recognition, non-episodic plot.

## A01 — Unity Is Functional, Not Merely Topical
A plot imitates one whole action. A part belongs organically only if removing or moving it visibly damages the whole.

**Mechanism:** narrative unity is created by dependency among parts, not by having all scenes happen to the same hero or on the same topic.

**IVDIVO test — Removal Test:** for every chapter/scene ask: if it disappears, which later objective, knowledge, relationship state, cost, setup/payoff or climax condition becomes impossible or materially weaker? If the answer is “nothing,” the unit is structurally suspect.

## A02 — Episodic Plot = Succession Without Necessity or Probability
Aristotle explicitly criticizes episodes that merely follow one another without probable/necessary connection.

**IVDIVO test — Therefore Test:** between major story units, replace “and then” with “therefore / but because of that / which forces.” If the link cannot be expressed causally, investigate the gap.

## A03 — Beginning / Middle / End Are Causal Positions
A beginning is not simply page one; a middle follows prior action and generates further action; an end follows prior action and does not require another event to complete the same action.

**IVDIVO consequence:** the local book ending must close the main action. A sequel door may open afterward, but cannot be the missing completion of the current book’s action.

## A04 — Reversal and Recognition Should Arise From Plot Structure
Strong reversal changes the direction/value of action; recognition changes ignorance into knowledge. The strongest versions emerge from what the plot has already caused, not from arbitrary coincidence or rescue.

**IVDIVO test — Earned Turn Gate:** every major reversal/reveal must identify its causal setup and why the new state follows from previous actions.

## A05 — Unexpected + Logical Is Stronger Than Random Surprise
Surprise gains force when retrospectively intelligible. An event should feel unexpected before it happens but causally legible afterward.

**IVDIVO application:** mystery/thriller reveal = surprise on first encounter + causality on review.

## A06 — Plot Effects Should Not Depend on Spectacle Alone
Aristotle privileges the internal construction of action over spectacle for producing emotional effects.

**IVDIVO consequence:** portals, battles, cosmic entities, synthetic bodies and visual grandeur cannot substitute for a built action/choice chain.

# SOURCE 2 — JOHN TRUBY, *THE ANATOMY OF STORY*

**Status after this pass:** READ / MECHANISM EXTRACTION — CORE STRUCTURE, PLOT, REVELATION AND SCENE-WEAVE MATERIAL PROCESSED.  
**Primary role:** organic story architecture; desire/opposition; revelations; decisions; character web; plot/scene weave.

## T01 — Story Is a System of Interlocking Subsystems
Truby’s structural steps combine character web, moral argument, story world and event sequence. The value of the model is integration rather than a numbered checklist.

**IVDIVO consequence:** Book Contract, Character Web, World Rules and Plot Ladder cannot be designed independently and simply glued together later.

## T02 — Seven Major Structural Functions as Minimum Diagnostic
The source repeatedly uses a compact core around weakness/need, desire, opponent, plan/struggle, battle, self-revelation/moral decision and new equilibrium, while the fuller model expands to additional revelations and decisions.

**IVDIVO use:** treat the seven-step logic as a diagnostic map, not mandatory visible beats. Every long-form main line must nevertheless contain equivalents of:
`deficiency/pressure → goal → opposition → adaptive strategy → decisive confrontation → discovery/choice → changed equilibrium`.

## T03 — Revelation Must Cause Decision and Course Change
A revelation is dramatically useful when new information causes the hero to decide and alter desire, motive, plan or route.

**IVDIVO test — Revelation Consequence Gate:** no major reveal exists solely to amaze. Record `REVEAL → WHO LEARNS IT → DECISION CAUSED → PLAN/GOAL CHANGE → NEW RISK`.

## T04 — Initial Plan Should Meet Intelligent Resistance
If the hero merely executes the original plan, plot becomes predictable. Opposition should force learning and redesign.

**IVDIVO plot ladder:**
`OBJECTIVE → PLAN 1 → RESISTANCE → FAILURE/PARTIAL RESULT → REVELATION → PLAN 2 → STRONGER COUNTERACTION ...`

## T05 — Opponent Is Structurally Linked to Hero Weakness/Goal
The best opposition is not random obstruction. It pressures the hero exactly where the hero’s weakness, values, method or desire are vulnerable.

**IVDIVO test:** write one sentence: `This opponent can uniquely hurt/test this protagonist because ____.` If generic, opposition is underdesigned.

## T06 — Scene Weave Gives Multi-Line Stories Density Only If Lines Remain Complete
Truby’s multistrand analysis emphasizes juxtaposition and interaction among lines; multiple lines should not explode into unrelated mini-series.

**IVDIVO consequence:** B/C lines must either pressure, mirror, complicate or reframe the main story. “Ordinary life” is valuable when it collides causally with the main task.

## T07 — Genre Adds Obligatory Beats but Must Be Twisted
Genre conventions provide expected functions, not copyable sequences.

**IVDIVO Genre Gate:** identify required audience promises, then design an original mechanism for satisfying each promise.

# SOURCE 3 — ROBERT McKEE, *STORY*

**Status after this pass:** READ / MECHANISM EXTRACTION — STRUCTURE, SCENE DESIGN, ACT DESIGN AND SUBPLOT MATERIAL PROCESSED.  
**Primary role:** value change, scene turning point, gap between expectation/result, antagonism, climax progression, subplot orchestration.

## M01 — Scene = Desire + Action + Conflict + Value Change
McKee defines a scene as an action through conflict that turns a value-charged condition of life. Length and visual busyness are irrelevant if nothing changes.

**IVDIVO Scene Value Test:** name the principal value before and after scene (`trust→distrust`, `safe→exposed`, `ignorant→knows`, `excluded→conditionally admitted`, etc.). No meaningful delta = scene challenged.

## M02 — Gap Between Expectation and Result Generates Story Movement
Character acts expecting one result; world/opposition reacts more powerfully or differently; this gap forces adaptation.

**IVDIVO sequence engine:** `EXPECTATION → ACTION → UNEXPECTED RESPONSE → GAP → NEW CHOICE`.

## M03 — Scene Objective Must Belong to Story Spine
Immediate scene desire should be an aspect of the story-long quest, even if its surface form is domestic, relational or professional.

**IVDIVO test:** for every plot-bearing scene write `SCENE WANT → HOW IT SERVES/THREATENS MAIN STORY`.

## M04 — Progression Requires Increasingly Powerful Reversals
Scene/sequence/act changes operate at different magnitudes. Structure gains escalation when later reversals have greater consequence rather than merely more noise.

**IVDIVO test:** score major turns by irreversible consequence, not explosions. If Act III “bigger” event changes less than Act I, escalation is false.

## M05 — Subplots Are Independent Dramatic Questions That Strengthen Central Design
Subplots can add reversals, empathy, thematic counterpoint and pressure, especially across a long middle. They remain stories, not decorative detours.

**IVDIVO B-Line Gate:** every substantial B-line has its own inciting pressure, goal/question, reversals and local payoff, while still colliding with A-line.

## M06 — Convention May Be Bent Only to Preserve Something More Important
McKee’s examples explicitly frame structural convention as a means rather than dogma; if a convention is broken, the redesign must preserve a higher-value dramatic effect.

**IVDIVO Change Justification:** `RULE BENT → VALUE PROTECTED → NEW MECHANISM REPLACING LOST FUNCTION`.

# SOURCE 4 — LAJOS EGRI, *THE ART OF CREATIVE WRITING*

**Status after this pass:** READ / MECHANISM EXTRACTION — CHARACTER, CONTRADICTION, BOND, MOTIVATION, CONFLICT SECTIONS PROCESSED.  
**Primary role:** three-dimensional character; contradiction; motivation; emotional bond; growing conflict.

## E01 — Credible Character Is Contradictory
Egri treats contradiction not as inconsistency to eliminate but as evidence of dimensionality. Under pressure, different layers emerge.

**IVDIVO Character Contradiction Test:** every core character needs at least one tension that can produce behavior in opposite directions under different pressures, e.g. `craves autonomy / needs approval`, `protects others / controls them`, `skeptical / desperate to believe`.

## E02 — Conflict Reveals Character
Character is not proven by biography. Conflict peels away façade and forces latent traits into action.

**IVDIVO consequence:** character bible statements are provisional until dramatized by choice under pressure.

## E03 — Conflict Must Grow, Not Repeat
Static conflict repeats the same pressure/argument; jumping conflict escalates without sufficient motivation. Both fail.

**IVDIVO Escalation Gate:** every repeat encounter must change at least one of `stakes / knowledge / leverage / tactic / relationship / cost / available choices`.

## E04 — Strong Bond Explains Why Characters Cannot Simply Leave
Love, hate, guilt, dependency, duty, ambition, shared danger, family, debt or other powerful emotional/social bonds keep opposed characters in the same dramatic field.

**IVDIVO Relationship Bond Gate:** when two characters repeatedly clash, specify why walking away is harder/costlier than staying.

## E05 — Motivation Prevents Straw-Man Behavior
A conflict jump without adequate causal motive makes a character feel manipulated by the writer.

**IVDIVO test:** before any extreme act write `PRESSURE + PRIOR DISPOSITION + IMMEDIATE TRIGGER → ACTION`. Missing term = under-motivated turn.

## E06 — Reader Identification Is Emotionally Mediated
Egri’s framework foregrounds emotion as the route through which readers recognize human stakes.

**IVDIVO application:** philosophical/cosmic problem must be converted into a felt human situation before thematic meaning can land.

# SOURCE 5 — KONSTANTIN STANISLAVSKI, *AN ACTOR'S WORK* + PRACTICAL STANISLAVSKI CORPUS

**Status after this pass:** READ / EXTRACTION — SELECTED OBJECTIVE, GIVEN-CIRCUMSTANCES, ACTION AND SYSTEM PRINCIPLES PROCESSED.  
**Primary role:** truthful behavior, objective, purposeful action, given circumstances, anti-empty-gesture principle.

## S05-01 — Given Circumstances Produce Specific Behavior
Character does not act in a vacuum. Concrete circumstances — history, place, social situation, immediate facts, constraints — shape what action is plausible now.

**IVDIVO Scene Prep:** before key scene record only the circumstances that can alter behavior in the scene; avoid decorative biography.

## S05-02 — Objective Converts Feeling Into Action
The practical Stanislavski tradition centers playable objectives/tasks. “Be sad” is not an action; “make her stay,” “hide that I’m afraid,” “force him to admit it” are actionable.

**IVDIVO prose test:** replace abstract emotional instruction with a target-directed action whenever possible.

## S05-03 — Empty Gesture Is the Enemy
The source tradition distinguishes expressive form from empty theatricality. A gesture/effect needs inner dramatic justification.

**IVDIVO Fantastic Effect Gate:** visual/superphysical effect must be caused by a rule, objective, perception or consequence. Decorative spectacle alone is cut or reassigned a function.

## S05-04 — System Is Adaptive, Not Fail-Proof
Stanislavski’s own evolving practice resists turning one snapshot of method into a universal formula.

**IVDIVO governance consequence:** craft frameworks are diagnostic instruments. Founder specification and the needs of the actual story outrank doctrinal allegiance to any guru.

# SOURCE 6 — ORSON SCOTT CARD, *CHARACTERS & VIEWPOINT*

**Status after this pass:** READ / EXTRACTION — SELECTED CHARACTER-WEIGHT AND VIEWPOINT-TRANSITION MATERIAL PROCESSED.  
**Primary role:** character hierarchy; POV clarity; reader orientation; viewpoint cost.

## C06-01 — Viewpoint Change Has Reader Cost
Card treats POV shift as one of the more demanding transitions for readers. Clear structural signals and immediate reorientation reduce cognitive friction.

**IVDIVO Multi-POV Gate:** after POV change, establish early: `WHO perceives | WHERE | WHEN relative to previous unit | what information is uniquely available now`.

## C06-02 — POV Is a Knowledge Constraint
A viewpoint should not casually provide information the focal character cannot know; violations change narrative contract.

**IVDIVO Mystery Gate:** clue ledger marks not only whether a fact exists, but **who has access to it and when**.

## C06-03 — Irony Can Come From Asymmetric Character Knowledge
Switching viewpoints can expose the gap between what characters believe about each other and what the reader knows.

**IVDIVO Relationship Use:** dual POV is justified when the contrast itself creates tension, irony or emotional depth — not merely to show both characters’ thoughts.

# SOURCE 7 — DAVID CORBETT, *THE ART OF CHARACTER*

**Status after this pass:** READ / EXTRACTION — SELECTED CONTRADICTION, SECRETS, MOTIVE AND ROLE PRINCIPLES PROCESSED.  
**Primary role:** character dimensionality; contradiction; secrets; behavior; limits of motive-based simplification.

## C07-01 — Contradiction Generates Curiosity
A character whose behavior cannot be collapsed into one adjective invites inference. Contradictions can be organic rather than “quirks.”

**IVDIVO test:** each contradiction must trace to competing values, roles, needs or fears; random eccentricity does not count.

## C07-02 — Secret Changes Present Behavior
A secret is useful when concealment influences decisions, speech, attention and relationships now.

**IVDIVO Secret Gate:** `SECRET → WHAT MUST BE PROTECTED → BEHAVIORAL DISTORTION → WHO CAN EXPOSE IT → COST OF EXPOSURE`.

## C07-03 — Do Not Reduce Character to a Single Motive
Corbett explicitly warns against over-simple causal reduction (“tyranny of motive” in the book’s framing). People can act from layered, conflicting pressures.

**IVDIVO consequence:** a motivation field may include dominant motive + secondary motive + self-justification + disowned motive; not every layer must be consciously known by the character.

# SOURCE 8 — K. M. WEILAND, *CREATING CHARACTER ARCS WORKBOOK*

**Status after this pass:** READ / EXTRACTION — ARC TAXONOMY AND PLOT-ARC ALIGNMENT PROCESSED.  
**Primary role:** Lie/Truth; Want/Need; Ghost; positive/flat/negative arcs; alignment with plot beats.

## W08-01 — Want and Need Are Productively Misaligned
The external thing pursued may not solve the internal problem. The friction creates decisions and thematic development.

**IVDIVO Character Contract:** `WANT | WHY CHARACTER THINKS IT WILL FIX LIFE | NEED | WHY NEED IS RESISTED`.

## W08-02 — Lie / Truth Is a Model, Not a Mandatory Moral Lecture
The workbook organizes arcs through what the character believes versus a more adequate understanding. For IVDIVO this is useful only when dramatized by consequences rather than authorial preaching.

**IVDIVO use:** translate “Lie/Truth” into `OPERATING MODEL → EVIDENCE AGAINST IT → COST OF CLINGING → REVISED MODEL` where a moralized binary would be simplistic.

## W08-03 — Ghost Is Causal Backstory
Backstory matters when a prior wound/event shaped the current operating model and can still influence present choices.

**IVDIVO Ghost Gate:** no flashback solely because it is interesting. Show/mention backstory when it changes interpretation or action in the current story.

## W08-04 — Multiple Arc Families
Positive change, flat, disillusionment, fall and corruption arcs prevent the false assumption that every protagonist must “heal” in the same direction.

**IVDIVO Long-Saga Use:** assign arc type per book/phase; do not force permanent improvement every volume.

## W08-05 — Character Evolution and Plot Structure Should Interlock
The workbook explicitly maps arc beats onto plot beats.

**IVDIVO Double-Delta rule strengthened:** every major structural turn asks both `WHAT HAPPENED OUTSIDE?` and `WHAT MODEL/RELATIONSHIP/SELF-CONCEPT CHANGED OR WAS TESTED?`

# SOURCE 9 — BRANDILYN COLLINS, *GETTING INTO CHARACTER*

**Status after this pass:** READ / EXTRACTION — SOURCE ARCHITECTURE + SELECTED ACTING-TO-FICTION MECHANISMS PROCESSED.  
**Primary role:** personalizing, action objectives, subtext, emotional complexity, inner rhythm, restraint.

## B09-01 — Action Objective Over Mood Label
A novelist can borrow the actor’s playable-objective logic: the scene becomes more alive when a character tries to do something to/with another person rather than merely “feels.”

**IVDIVO application:** scene cards contain `ACTION OBJECTIVE`, not only emotional state.

## B09-02 — Subtext Is Produced by Objective + Constraint
What a character wants and what they are willing/able to say are often different.

**IVDIVO application:** integrate with CRAFT-003 Dialogue Action Gate.

## B09-03 — “Coloring Passions” Creates Emotional Dimensionality
A broad emotion can be decomposed into component feelings, opposites and changing intensity rather than repeated as one-note anger/love/fear.

**IVDIVO Emotion Gate:** in high-emotion sequence identify primary emotion + secondary component + resisted/opposite impulse + change over scene.

## B09-04 — Restraint Can Intensify Emotion
Maximum declared emotion is not necessarily maximum reader impact. Controlled expression can create stronger inference/subtext.

**IVDIVO prose consequence:** avoid automatically translating every internal state into explicit explanation.

# CROSS-SOURCE CONFLICT / CONVERGENCE MATRIX

## X01 — PLOT-FIRST VS CHARACTER-FIRST IS A FALSE BINARY
- Aristotle foregrounds unity/causal action.
- Truby integrates character need/desire/opponent with plot.
- McKee ties scene objectives to a story spine and value change.
- Egri insists conflict reveals character and motivation prevents artificial action.
- Weiland explicitly aligns plot structure and character arc.

**IVDIVO synthesis:**
`CHARACTER PRESSURE MODEL → OBJECTIVE → ACTION → WORLD/OPPONENT RESPONSE → CONSEQUENCE → REVISED CHARACTER MODEL → NEW ACTION`.
Plot is character in causal motion; character is not a dossier detached from action.

## X02 — STRUCTURAL BEATS: FUNCTION BEFORE POSITION
Truby and Weiland provide explicit step/beat systems; McKee provides act/sequence/scene hierarchy; Aristotle provides causal/organic criteria. These systems should not be mechanically merged into a mega-template.

**IVDIVO rule:** identify the dramatic function first; only then consider approximate position. A beat exists because the story requires a causal turn, not because page 75 demands one.

## X03 — MIDPOINT: USE AS IRREVERSIBILITY DIAGNOSTIC, NOT DOGMA
The wider corpus (Yorke via secondary evidence, Weiland, McKee/Seger-type structural traditions) often emphasizes a central reorientation. But not every strong story requires an identical halfway event.

**IVDIVO test:** around the central region ask whether the story has deepened/reframed enough that returning to the opening strategy is no longer viable. If yes, midpoint function exists even if location/shape varies.

## X04 — THEME MUST EMERGE FROM ACTION
Aristotle privileges constructed action; Truby integrates moral decision; Egri ties human behavior/conflict to meaning; Weiland uses Lie/Truth; McKee uses controlling idea/value change.

**IVDIVO synthesis:** theme is audited backward from choices and consequences. No philosophical statement is accepted as earned unless the plot has demonstrated its cost.

## X05 — CHARACTER CONTRADICTION + OBJECTIVE = SCENE LIFE
Egri/Corbett supply contradiction; Stanislavski/Collins supply objective/action; McKee supplies conflict/turn.

**Operational equation:**
`COMPETING INNER PRESSURES + SPECIFIC OBJECTIVE + RESISTANT OTHER/SYSTEM → TACTICS → REVELATORY CHOICE`.

# NEW / STRENGTHENED IVDIVO PRODUCTION GATES

## Main Story Organic Unity Gate
Before outline freeze:
1. What is the one whole action of the book?
2. What event starts this action?
3. What concrete objective makes protagonist act?
4. What opponent/system uniquely resists this protagonist?
5. Which plan fails first and why?
6. Which revelations force changed decisions?
7. What is the irreversible central reorientation?
8. What decisive confrontation answers the main question?
9. What new equilibrium proves the action is complete?
10. Which scene can be removed without damaging the chain? Remove/rebuild it.

## Revelation-to-Decision Ledger
For each major reveal:
`EVIDENCE → INTERPRETATION → REVEAL → DECISION → CHANGED PLAN/DESIRE → NEW CONSEQUENCE`.

## Character Pressure Card
For every core character:
`WANT | NEED/DEEPER REQUIREMENT | OPERATING MODEL/LIE | CONTRADICTION | SECRET | GHOST/CAUSAL BACKSTORY | BOND THAT PREVENTS EXIT | OBJECTIVE IN CURRENT SCENE | LINE THEY WILL NOT CROSS | CONDITION THAT MAY MAKE THEM CROSS IT`.

## Escalation Integrity Gate
Every repeat confrontation must increase/change at least one:
`stakes | knowledge | leverage | tactic | cost | time pressure | relationship damage | available choices | institutional consequence`.

## POV Access Gate
For every POV scene:
`FOCAL CHARACTER | KNOWN FACTS | MISBELIEFS | UNSEEN FACTS | UNIQUE PERCEPTUAL BIAS | WHY THIS POV NOW`.
