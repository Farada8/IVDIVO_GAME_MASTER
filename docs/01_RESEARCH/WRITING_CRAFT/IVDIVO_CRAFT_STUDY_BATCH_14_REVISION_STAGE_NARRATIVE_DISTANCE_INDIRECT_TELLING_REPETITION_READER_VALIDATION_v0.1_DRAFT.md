# 1. Alice LaPlante — THE MAKING OF A STORY

Conservative source status after this pass:

`FULL FILE VERIFIED / STRUCTURE SUBSTANTIALLY MAPPED / REVISION + PLOT + POV CLUSTERS READ / CLAIMS & MECHANISMS EXTRACTED / LIMITS PARTLY ANALYSED / CROSS-COMPARED / MANUSCRIPT-TESTED / FULL LIFECYCLE NOT YET COMPLETE`

## 1.1 Revision is stage-dependent

LaPlante's revision chapter distinguishes materially different stages of a work:

1. generating;
2. creative/deep revision;
3. constructive revision;
4. copyediting.

The critical transferable mechanism is not a preferred number of drafts. It is this:

`DIAGNOSE MATURITY OF THE WORK → CHOOSE THE KIND OF REVISION THAT MATCHES THE MATURITY`

A draft still discovering its real subject may need replacement of POV, setting, scenes, characters or plot. A work that has already cohered should not automatically be blown apart because an editor knows how to blow things apart.

### Failure mode A — premature polish

`STRUCTURE UNSTABLE → LINE EDIT → BEAUTIFUL WRONG DRAFT`

### Failure mode B — perpetual deep revision

`STRUCTURE VALIDATED → KEEP REOPENING FUNDAMENTALS WITHOUT NEW EVIDENCE → DESTROY ACCUMULATED CAUSAL/CHARACTER PAYOFFS`

Both are errors.

## 1.2 Deep-revision exercises are diagnostic probes, not mandatory replacement text

LaPlante's exercise-based revision is valuable because it can expose the hidden reason a relationship, scene, POV or plot line is weak. The generated exercise material may never enter the manuscript.

IVDIVO operational form:

`SYMPTOM → MARGIN EXERCISE → NEW KNOWLEDGE ABOUT MATERIAL → STRUCTURAL DECISION → ONLY THEN MANUSCRIPT CHANGE`

Examples for future IVDIVO drafts:
- write five prior conflicts between two characters when their relationship feels thin;
- rewrite a problematic scene from another POV to discover withheld information or bias;
- write the version of an event nobody in the final text gets to narrate;
- isolate abstractions, weak verbs and generic imagery only after story function is stable.

### Limit

The exercise is a probe. Do not import exploratory material simply because it exists.

## 1.3 Mechanical prose diagnostics should point upward

LaPlante's mechanical revision exercises—highlighting weak/general verbs, abstractions, imagery, similes/metaphors, or sentences that stumble aloud—are most useful when treated as **symptom detectors**.

`MICRO DEFECT → ASK WHETHER LOCAL OR STRUCTURAL → FIX AT HIGHEST CAUSAL LEVEL`

This prevents line editing from becoming cosmetic camouflage.

# 2. Ursula K. Le Guin — STEERING THE CRAFT

Conservative source status after this pass:

`FULL EDITION VERIFIED / STRUCTURE MAPPED / MAJOR CRAFT CHAPTERS READ / CLAIMS & MECHANISMS EXTRACTED / LIMITS PARTLY ANALYSED / CROSS-COMPARED / MANUSCRIPT-TESTED / EXERCISE-BY-EXERCISE LIFECYCLE NOT YET COMPLETE`

This pass extends earlier work beyond short-sentence rhythm into person/tense, POV mode and narrative selection.

## 2.1 No universal sentence-length target

Short syntax has impact by contrast. Long syntax has value when the logical/syntactic connections remain clear. Therefore percentage metrics are useful as smoke alarms, not house style.

Operational rule:

`MEASURE → INSPECT CLUSTERS → IDENTIFY FUNCTION → REVISE ONLY NON-FUNCTIONAL PATTERN`

Not:

`MEASURE → FORCE EVERY CHAPTER TOWARD ONE PERCENTAGE`

## 2.2 POV is a voice-and-distance decision, not a pronoun checkbox

Changing who tells can change tone, moral stance, available knowledge, intimacy and even the perceived meaning of the same event.

For a stuck future draft, IVDIVO should test alternate narration in a **margin prototype**, rather than blindly converting hundreds of pages.

`SAME EVENT → 2–3 POV MODE TESTS → COMPARE ACCESS / INTIMACY / IRONY / SPEED → SELECT MODE → THEN COMMIT`

## 2.3 Narrative must move, but movement is broader than spectacle

Le Guin's useful definition is that narrative ends somewhere different from where it began. Internal thought, a walk through a supermarket, a quiet decision or a changed relation may still constitute movement.

This cross-validates the existing IVDIVO Gate DJ/DL distinction between event, decision, emotional, relationship and epistemic causality.

## 2.4 Crowding and leaping operate at revision stage

Once the story is known, prose should be crowded with the relevant and should leap over low-value process. This supports compression **without** demanding that every ordinary-life scene disappear.

`KEEP WHAT CHANGES THE HUMAN OR STORY STATE; LEAP OVER PROCESS THAT ONLY CONNECTS TWO ALREADY-UNDERSTOOD STATES.`

# 3. Ursula K. Le Guin — THE WAVE IN THE MIND

Conservative status:

`FULL FILE VERIFIED / RELEVANT RHYTHM ESSAYS THEMATICALLY READ / MECHANISMS EXTRACTED / CROSS-COMPARED / MANUSCRIPT-TESTED / COLLECTION NOT FULLY SYNTHESIZED`

## 3.1 Developing repetition vs redundant repetition

Le Guin's large-scale rhythm discussion gives a stronger model than simply banning repeated words/themes.

`DEVELOPING REPETITION = RECOGNIZABLE RETURN + ALTERED CONTEXT + NEW MEANING / COST / EMOTION / DECISION`

`DEAD REPETITION = SAME FUNCTION + SAME CONCLUSION + NO NEW PRESSURE`

This matters for long novels because motifs can bind the whole structure. The correct editorial question is not “did we use this image/theme before?” but “what has changed when it returns?”

## 3.2 Long rhythm is not reducible to sentence metrics

Whole-novel rhythm may be built from alternating stress/release, repeated images, actions, moods and thematic correspondences. Therefore a line editor who optimizes only sentence/paragraph statistics can damage long-form music.

# 4. Robert McKee — DIALOGUE (cross-source advance)

Conservative status remains below full lifecycle completion.

This pass advances one mechanism important to prose pacing:

## 4.1 Direct telling and indirect dialogue have legitimate uses

The slogan `show, don't tell` is too crude. Skilled narration can give:

- speed;
- counterpoint;
- compressed exposition;
- summary of banal/low-value conversation;
- controlled access to thought/subtext.

But weak narration degenerates into `and then... and then...` information pumping.

Operational test:

`WOULD THE EXACT WORDING / BEHAVIOR OF THIS EXCHANGE ALTER RELATIONSHIP, POWER, CLUE INTERPRETATION, CHARACTER OR EMOTION?`

- YES → dramatize enough of it.
- NO, only upshot matters → indirect dialogue/summary may be superior.

This is an important anti-bloat tool for future 70-book production.

# 5. Orson Scott Card — CHARACTERS AND VIEWPOINT (cross-source advance)

Conservative status remains `PARTIAL / THEMATIC EXTRACTION`.

Card supplies a useful tradeoff model:

`OMNISCIENT / AUTHORIAL MODE → MORE STORY PER UNIT TEXT, MORE DISTANCE`

`LIMITED MODE → LESS STORY PER UNIT TEXT, MORE INTIMACY / IDENTIFICATION`

This is not an absolute equation; it is a diagnostic tradeoff.

### IVDIVO use

Before expanding a side character into a full POV, calculate the narrative cost:

`NEW INFORMATION GAIN + EMOTIONAL GAIN + IRONY GAIN`
versus
`ADDED WORD COUNT + RESET COST + ATTACHMENT DILUTION + CONTINUITY BURDEN`.

# 6. Jordan Rosenfeld — MAKE A SCENE (advance)

The scene-intention work from CRAFT-015 is retained. This pass adds final-scene/epilogue routing.

A final scene should pay the consequences of the main story and show the changed state. An epilogue, if used, comes after that closure and should not be used to perform work the climax/final scene failed to perform.

Operational distinction:

`CLIMAX → CONSEQUENCE / CHANGED STATE → MAIN STORY CLOSED → OPTIONAL EPILOGUE OPENS LATER QUESTION`

not

`UNFINISHED MAIN STORY → EPILOGUE EXPLAINS WHAT ENDING SHOULD HAVE DRAMATIZED`.

# 7. CROSS-SOURCE SYNTHESIS — REVISION-STAGE ROUTER

[OUR SYNTHESIS / DRAFT]

Before every substantial editorial pass, classify the manuscript.

## Stage A — DISCOVERY / GENERATING
Allowed:
- exploratory scenes;
- alternate POV tests;
- relationship exercises;
- contradictory possibilities;
- loose prose.

Forbidden priority:
- polishing every sentence;
- word-count optimization;
- submission copyediting.

## Stage B — DEEP / CREATIVE REVISION
Allowed:
- replace scenes;
- change POV architecture;
- change plot chain;
- change relationship engine;
- cut/merge/expand chapters;
- rethink protagonist/goal.

Trigger required:
- evidence that story engine or causality is not working.

## Stage C — CONSTRUCTIVE / DEVELOPMENTAL REVISION
Allowed:
- chapter necessity;
- scene causality;
- escalation;
- subplot collision;
- character arc and payoff;
- mystery clue architecture;
- scene/summary allocation.

## Stage D — LINE / PROSE REVISION
Allowed:
- syntax variation;
- paragraph architecture;
- diction;
- POV texture;
- exposition compression;
- indirect dialogue;
- repeated authorial formulas;
- read-aloud rhythm;
- local motif tuning.

Structural reopening requires new evidence.

## Stage E — READER VALIDATION
Use blind readers to locate:
- boredom;
- confusion;
- attachment failure;
- false expectations;
- repetitive explanation;
- weak ending/payoff;
- unwillingness to continue.

Do not contaminate readers with the intended answer before testing.

## Stage F — COPY / SUBMISSION PREP
Grammar, spelling, consistency, typography, continuity and package-level prep. No gratuitous artistic redesign.

# 8. LESSON ZERO — CURRENT MANUSCRIPT VALIDATION

## 8.1 The previous 'latest master' ambiguity is resolved enough for production routing

Current project materials identify Book One as development-locked at v0.16, with 35 chapters + epilogue and approximately 113k words. A v1.0 complete Writers' Room assembly and final regression also exist.

Therefore current source-of-truth hierarchy for editorial decisions should be:

1. **v0.16 development/story gate** for structure;
2. **v1.0 complete Writers' Room assembly** for integrated prose review;
3. current chapter map / production dossier for declared function;
4. earlier diagnostics only as historical evidence unless reverified against current text.

## 8.2 Deep structural revision is no longer the default

The final development gate reports no justified CUT/MERGE across the 35 chapters and records specific final patches rather than structural replacement.

This is a direct manuscript validation of the revision-stage router:

`DEVELOPMENT PASS = GREEN → DO NOT REOPEN WHOLE ARCHITECTURE WITHOUT NEW READER / CONTINUITY / CAUSAL EVIDENCE`.

This does **not** mean the novel is perfect or canon. It means the burden of proof has shifted.

## 8.3 The 'обрубки' problem has moved from systemic to controlled

Earlier scans showed extreme short-paragraph density across many chapters. Subsequent chapter-by-chapter passes reduced it into a much lower band while explicitly retaining intentional impact beats.

Most important validation: an automated over-compression pass that pushed some chapters below ~5% was rejected. That proves the metric is not a target.

Therefore:

`SHORT-PARAGRAPH DENSITY = INSPECTION SIGNAL, NOT QUALITY SCORE`.

A chapter passes when its paragraph breaks are functional and its cadence varies, not when it reaches a magic percentage.

## 8.4 Current manuscript already demonstrates developing-repetition editing

The v0.16 story gate removed a duplicate `door` metaphor from Chapter 34 specifically so Chapter 35 owns the final open-door payoff. This is a clean example of Le Guin's developing-repetition principle:

- recurring motif may remain;
- duplicate near-payoff is removed;
- final recurrence gains structural weight.

The same gate replaces several authorial growth-summary formulas with behavior (calendar action, withholding a solution, physical distance from control). This reduces explanatory moralizing and lets changed action carry the arc.

## 8.5 Old diagnostics must not be blindly inherited

An older independent audit found a duplicated age-calculation discovery between Chapters 2 and 3. Because that diagnostic predates the current development-locked state, it is **not automatically an active defect**. It must be checked against the exact current master before any new rewrite.

This becomes a regression rule:

`OLD MAJOR FINDING → CURRENT-TEXT REVERIFICATION → KEEP / CLOSE / REOPEN`.

## 8.6 Next evidence source should increasingly be readers

A blind beta-reader protocol now exists. Since the book passes the internal development gate, the next large structural change should require converging external reader evidence or a newly proven continuity/causality defect.

This does not make readers sovereign over the book. It prevents the Writers' Room from endlessly creating problems by inspecting its own work.

# 9. NEW PRODUCTION GATES

### Gate DT — Revision Stage Lock
Before editing, classify the manuscript stage. Do not use a later-stage tool on an earlier-stage problem or a deep-revision tool on a locked manuscript without evidence.

### Gate DU — Deep-Revision Trigger
Whole-scene/chapter/POV/plot replacement requires a demonstrated structural defect, not editor restlessness.

### Gate DV — Line-Edit Timing
Line editing becomes primary only after story/scene architecture is sufficiently stable.

### Gate DW — Indirect Dialogue Compression
When only the outcome of a low-value conversation matters, summarize/indirect it; dramatize exact speech when wording/behavior changes character, power, clue meaning, relationship or emotion.

### Gate DX — Narrative Distance Budget
Choose POV mode and distance by tradeoff among intimacy, information bandwidth, irony, speed and attachment. Adding a POV has a cost.

### Gate DY — Developing Repetition
A repeated motif/theme/phrase must deepen or change meaning; duplicate near-identical payoff should be removed or transformed.

### Gate DZ — Cadence Metric Non-Target
Paragraph/sentence metrics are diagnostics, never optimization targets. Correct the pattern, not the number.

### Gate EA — Current-Text Regression
Historical diagnostics must be reverified on the current source of truth before reopening a resolved issue.

### Gate EB — Reader-Evidence Escalation
After development lock, major new structural changes require converging reader evidence or a newly demonstrated continuity/causal defect.

### Gate EC — POV Prototype Before Migration
Before large-scale POV conversion, test representative scenes in alternate modes and compare reader access, intimacy, irony and speed.

### Gate ED — Exposition Speed / Counterpoint
Use narration/summary when it gives needed speed or counterpoint; reject bland chronology that merely pumps information.

### Gate EE — Final Scene Before Epilogue
The main story must close in its climax/consequence/final scene. An epilogue may open a later question but must not substitute for Book-One payoff.
