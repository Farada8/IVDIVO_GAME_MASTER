# Executive synthesis
The highest-value use of *Ender's Game* for IVDIVO is not `gifted child + battle school`. It is the causal conflict between **effective competence production** and **legitimate decision architecture**.

A system may demonstrably improve performance while simultaneously corrupting consent, welfare, information, decision ownership and responsibility attribution.

## Core equation
`SYSTEM SELECTS / TRAINS AGENT → AGENT BECOMES HIGHLY COMPETENT → SYSTEM EXPANDS RESPONSIBILITY → INFORMATION FRAME HIDES MATERIAL STAKES → AGENT MAKES IRREVERSIBLE DECISION → OBJECTIVE SUCCESS → MORAL / EPISTEMIC RECLASSIFICATION`.

# Mechanisms

## B196-M01 — Training Consent Audit
For every high-stakes youth training system:
`TRAINING BENEFIT → REAL STAKES → WHO KNOWS? → WHAT IS REVERSIBLE? → CAN LEARNER REFUSE / STOP / APPEAL? → WHO MONITORS WELFARE? → WHO OWNS FINAL DECISION?`

**Gate:** `TRAINING SUCCESS ≠ INSTITUTIONAL LEGITIMACY`.

## B196-M02 — False-Frame Decision
`SIMULATION BELIEF → DECISION → REAL IRREVERSIBLE CONSEQUENCE → POST-HOC DISCLOSURE → MORAL INJURY`.

This is not a recommended training device; it is a powerful failure mode.

## B196-M03 — Responsibility Provenance
`DESIGNER → INSTITUTION → INFORMATION FRAME-SETTER → OPERATOR → DECISION OWNER → AFFECTED PARTY`.

Do not place all blame on the last visible actor if the option set and knowledge state were engineered upstream.

## B196-M04 — Giftedness / Youth Rights Separation
`HIGH PERFORMANCE ≠ ADULTNESS ≠ INFORMED-CONSENT CAPACITY FOR UNDISCLOSED ADULT STAKES`.

A talented adolescent remains an adolescent with developmental, relational and welfare needs.

## B196-M05 — Success Escalation
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Use this instead of mandatory setback escalation when the protagonist is genuinely capable.

## B196-M06 — Distributed Command
`CENTRAL PURPOSE + LOCAL AUTONOMY + DISTINCT CAPABILITIES + SHARED MODEL + EXCEPTION HANDLERS → CONVERGENCE`.

The lead can own a bounded final decision without monopolizing evidence, tactics, local judgment or execution.

## B196-M07 — Adaptive Test Legitimacy
`LEARNER MODEL → CURRICULUM ADAPTS → TEST VALIDITY → DISCLOSURE / REVERSIBILITY → WELFARE → STOP / APPEAL RIGHTS`.

Adaptive difficulty is useful. Secret limitless escalation is not automatically legitimate.

## B196-M08 — Authentic-but-Coerced Source
`AUTHENTIC CONTENT → PRODUCTION CONTEXT / COERCION → PURPOSE OF ELICITATION → PROVENANCE STATUS`.

A message can genuinely be written by its apparent author and still be produced under pressure.

## B196-M09 — Fragmented Archive Reconstruction
`SCATTERED TRUE FRAGMENTS → SOURCE / ORDER RECONSTRUCTION → EVENT MODEL → CONTRADICTION WITH OFFICIAL COMMENTARY`.

Official propaganda may contain true footage while producing a false or incomplete causal model.

## B196-M10 — Enemy-Model Failure
`OTHER BEHAVIOR → OWN-SPECIES ASSUMPTION → HOSTILITY MODEL → POLICY → CATASTROPHIC CONSEQUENCE → LATER COGNITIVE MODEL UPDATE`.

**Gate:** `ENEMY LABEL ≠ MOTIVE FACT`.

## B196-M11 — Communication Architecture Mismatch
The failure to communicate with a radically different mind is not proof of hostility or absence of personhood.

`NO SHARED CHANNEL → MULTIPLE MOTIVE MODELS → TEST / TRACE / BEHAVIORAL HISTORY → BOUNDED CLAIM`.

## B196-M12 — Operational Victory / Moral Reclassification
`OBJECTIVE WON → NEW INFORMATION → OLD MORAL MODEL FAILS → NEW RESPONSIBILITY → AFTERMATH / REPAIR`.

A climax can close the operational problem while opening the responsibility problem.
