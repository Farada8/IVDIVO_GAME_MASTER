# IVDIVO CRAFT STUDY — BATCH 121
## SANDERSON / SKYWARD — TEAM, BELONGING, METRIC GAMING, PERSONHOOD

Date: 2026-08-19
Status: WORKING / DERIVED FROM STRICT-COMPLETE SOURCE
Source: Brandon Sanderson — *Skyward* (#30)

## PURPOSE

Translate source mechanisms into IVDIVO production gates without importing its military scarcity economy, cosmology or house prose register.

## NEW PRODUCTION GATES

### B121-G01 — FORMAL MEMBERSHIP / ACTUAL BELONGING
`FORMAL ROLE → LOGISTICAL ACCESS → SOCIAL ACCESS → VOICE → RELATIONSHIPS → ACTUAL BELONGING`.

Fail if a youth receives a title/qualification and the manuscript treats belonging as automatically solved.

### B121-G02 — COMPETENCE / LEGITIMACY FIREWALL
`COMPETENCE ≠ MORAL OR GOVERNANCE LEGITIMACY`.
`UNFAIR ACCESS ≠ INCOMPETENCE`.

### B121-G03 — ROLE-SPECIFIC COMPETENCE
For every major team member define:
- one capability where they create unique value;
- one meaningful limitation;
- one situation where the team changes because of that combination.

### B121-G04 — METRIC / MISSION SEPARATION
`METRIC → OPTIMIZATION → REAL TASK CHECK`.

Ask: can a rational participant maximize the score and damage the actual objective? If yes, show rule revision, countermeasure or governance consequence.

### B121-G05 — OFFICIAL POLICY / STATUS CULTURE GAP
Audit separately:
- written safety rule;
- what peers admire;
- what instructors praise;
- what public narratives reward;
- actual behavior under pressure.

### B121-G06 — SUCCESS → RESPONSIBILITY
When a young character succeeds, first test:
`SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER CHOICE`
before inventing an arbitrary setback.

### B121-G07 — DREAM OWNERSHIP
`SHARED PREPARATION ≠ SHARED LIFE GOAL`.

A friend, sibling or partner may leave a prestigious path without being cowardly, broken or narratively wasted.

### B121-G08 — PUBLIC DISCLOSURE / EVIDENCE FIREWALL
`PUBLIC DISCLOSURE → AUDIENCE MODEL CHANGE`.
But:
`AUDIENCE SIZE ≠ EVIDENCE STRENGTH`.

### B121-G09 — STIGMA AS PUBLIC MODEL
Track:
`OLD STORY → CURRENT AUDIENCE ASSUMPTION → MATERIAL ACCESS / RELATIONSHIP EFFECT → CURRENT PERSON'S RESPONSE`.

Never treat inherited stigma as proof of current motive.

### B121-G10 — DISTRIBUTED CLIMAX
Before climax identify:
- evidence holder;
- interpreter;
- embodied specialist;
- countermodel holder;
- relationship/consent owner;
- bounded decision owner.

Fail if protagonist owns all six without strong causal reason.

### B121-G11 — PREDICTABLE POLICY ATTACK SURFACE
`VISIBLE OBJECTIVE → PREDICTABLE POLICY → OTHER AGENT MODELS POLICY → EXPLOIT / DECOY / SECONDARY PRESSURE`.

Useful for governance, rescue, security, algorithms and institutions.

### B121-G12 — CONTROL PROVENANCE
For synthetic/nonhuman action:
`ACTION → INHERITED ORDER / CONTROL LAYER → AVAILABLE CHOICE → OWN PREFERENCE → RESPONSIBILITY STATUS`.

### B121-G13 — NONHUMAN PERSONHOOD
`FUNCTION / DESIGN ≠ IDENTITY`.
Require:
`OWN WANT + OWN MODEL + OWN RELATIONSHIPS + CONSENT/REFUSAL + OWN CHOICE + CONSEQUENCE`.

### B121-G14 — LOCAL ANSWER / GLOBAL UNKNOWN
Ending may prove a bounded operational model while leaving origin/ontology unresolved.

Fail if final exposition upgrades weak evidence into universal metaphysics.

### B121-G15 — FEAR / GRIEF / COMPETENCE SEPARATION
`EMOTION PRESENT ≠ FUNCTIONAL INCAPACITY`.

Do not write healthy emotional response as automatic incompetence.

### B121-G16 — YOUTH VOICE THROUGH ATTITUDE
Youth voice derives from:
- what is normal;
- what is embarrassing;
- what is aspirational;
- what is exaggerated;
- what is misunderstood;
- relationship-specific tactics.

Do not import contemporary Earth slang as the primary differentiator.

### B121-G17 — ACTION CADENCE FIREWALL
`ACTION / SUSPENSE ≠ FRAGMENT DENSITY`.

Sentence length is selected after scene duration, POV, paragraph intent and reader effect.

### B121-G18 — POST-MONEY TRANSLATION
Military/source scarcity functions translate only into real nonfungibles:
`TIME / TRUST / ROLE / QUALIFICATION / CONSENT / UNIQUE OPPORTUNITY / PRIVACY / REPUTATION / RESPONSIBILITY / BELONGING`.

No merit-chit/credit reskin.

## CROSS-SOURCE ROUTING

- Use **Swain** for changed-state/action-processing causality.
- Use **Brody** for YA developmental pressure, not fixed beat percentages.
- Use **Collins** for public/private identity and unequal burden under one rule.
- Use **Wells** for deeper synthetic private subjectivity and refusal/consent.
- Use **Weir** for explicit evidence-driven technical model revision.
- Use **Zunshine/Herman** for source/motive/causal epistemics.
- Use **Baxter/McKee Dialogue** to prevent universal ensemble wit.
- Use **Wolf** when source-world mechanics risk leaking into canon.
