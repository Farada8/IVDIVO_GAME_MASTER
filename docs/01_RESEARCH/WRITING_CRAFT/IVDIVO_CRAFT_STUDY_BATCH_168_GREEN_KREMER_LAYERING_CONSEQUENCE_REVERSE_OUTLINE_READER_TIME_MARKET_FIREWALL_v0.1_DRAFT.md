## 1. Layering is not parallel-novel permission

Retained mechanism:

`ONE MAIN STORY + RELATIONSHIP / EVIDENCE / SOCIAL / WORLD LAYERS → EACH LAYER EARNS READER-TIME THROUGH UNIQUE CONSEQUENCE OR PAYOFF`

### Gate B168-G01 — Layer Payment
For every recurring layer ask:
1. Who owns the local want?
2. What changes inside the layer?
3. What later choice / evidence / relationship / option does that change affect?
4. What payoff justifies the reader-time?

If the layer merely coexists with the A-story, test `MERGE / COMPRESS / BANK / DELETE`.

### Failure mode
`LAYERING-AS-PARALLEL-NOVELS` — five character threads each become an independent mini-book and only meet at briefings.

## 2. Harvest consequences before inventing events

Retained mechanism:

`EVENT → FIRST-ORDER CONSEQUENCE → SECOND-ORDER CONSEQUENCE → RELATION / EVIDENCE / ACCESS / RESPONSIBILITY CHANGE → LATER PAYOFF`

### Gate B168-G02 — Consequence Harvest
Before adding a new anomaly, attack, technology, witness, subplot or secret, ask:

> What must an event already present in the book still cause?

Prefer an earned secondary consequence over `NEW EVENT ADDICTION`.

### Strong YA progression

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`

Success is allowed to create pressure.

---

## 3. Reverse-map the book that exists

Green/Kremer's late revision practice strongly supports a reverse outline of the actual draft.

IVDIVO production law:

`LOCKED TEXT → ACTUAL STORY-STATE MAP → DIAGNOSIS → PRODUCTION PLAN`

not

`OLD PLAN → FORCE TEXT TO MATCH IT`.

### Gate B168-G03 — Actual-State Map
For every chapter / substantial scene record:

`TIME → LOCATION → OWNER → WANT → ACTION STATE → KNOWLEDGE/EVIDENCE → RELATIONSHIP/CONSENT → AUTHORITY/ACCESS → EXIT STATE → NEXT CAUSAL DEPENDENCY`

If scene cards and current text disagree, the disagreement must be resolved explicitly. Planning repetition does not create canon.

---

## 4. Reader-time is structural emphasis

The amount of discourse time given to material tells the reader how important it is.

### Gate B168-G04 — Reader-Time Hierarchy

`FUNCTION / CONSEQUENCE / EXACT-WORD IMPORTANCE → SCENE WEIGHT / DURATION`

Protect full real-time when precise wording/action changes:
- evidence status;
- consent / boundary;
- relationship terms;
- authority / access;
- decision ownership;
- strategy/model;
- future option space.

Compress routine process, travel, known briefing, repeated verification and interface manipulation when their exact sequence does not matter.

### Failure mode
`FALSE DISCOURSE HIERARCHY` — routine setup gets as much space as the decisive evidence or consent turn.

---

## 5. Scene existence is paid by changed state

Useful source core:

`Because this scene happened, ______ changed.`

Possible axes:
- physical / operational;
- knowledge / evidence;
- relationship / trust;
- consent / boundary;
- authority / access;
- responsibility / obligation;
- strategy / model;
- emotional commitment;
- future option space.

### Gate B168-G05 — State-Neutral Scene
If no downstream-relevant axis changes, test:

`SUMMARY / MERGE / DELETE / REBUILD`

before line editing.

Quiet scenes remain valid when they materially change one of these states.

---

## 6. Non-response is evidence, not explanation

The source usefully notes that a lack of response can matter, but the IVDIVO evidence discipline must be stricter.

### Gate B168-G06 — Non-Response Provenance

`EXPECTED RESPONSE → OBSERVED NON-RESPONSE → MULTIPLE MOTIVE MODELS → LATER EVIDENCE`

Never jump:

`SILENCE → CONSENT / GUILT / MOTIVE`.

This gate applies equally to humans, conscious robots and distributed persons.

---

## 7. Generate first; validate later

The source repeatedly values exploratory ideas, visualisation and temporary freedom from self-censorship.

### Gate B168-G07 — Variant Generation

`STUCK POINT → MATERIAL VARIANTS → TEMPORARILY DEFER CENSORSHIP → CHARACTER / CANON / CAUSALITY / ONE MAIN STORY TEST → KEEP / BANK / DISCARD`

Exercise/visualisation output is a hypothesis, not canon.

### Writer's Room law

`LIVE MATERIAL → OBSERVED DEFECT → RELEVANT SPECIALISTS → REPAIR → RETEST`

Do not ask every specialist to police every sentence during generation.

---

## 8. Feedback reports effect; it does not own the fix

### Gate B168-G08 — Feedback Contract

`READER REPORT → OBSERVED EFFECT → REPEATABILITY → DEFECT LEVEL → MULTIPLE REPAIR HYPOTHESES → RETEST`

The reader is authoritative about their own experience (`I was confused`, `I stopped believing`, `I lost interest`). Their proposed repair remains a hypothesis.

---

## 9. Mystery withholding requires provenance

The source discusses controlling reader information but is not sufficiently strict about source lineage. IVDIVO combines it with Zunshine and le Carré.

### Gate B168-G09 — Fair Withholding

`WORLD FACT → TRACE/SOURCE → ACCESS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION → STATUS UPDATE → ACTION`

Required reader condition:

`ENOUGH INFORMATION TO MODEL POSSIBILITIES + REAL UNCERTAINTY + NO AUTHORIAL FALSIFICATION`.

Do not hide a fact the active POV transparently knows merely to manufacture suspense.

---

## 10. Style firewalls

The source contains several simplified style rules that do not survive cross-source comparison.

### Rejected as universal laws
- `SHOW, DON'T TELL` absolutism;
- passive-voice ban;
- shorter-sentence preference;
- comma = breath as a universal rule;
- action = faster/choppier typography.

### IVDIVO rule

`ACTION / SUSPENSE ≠ SHORT-SENTENCE DENSITY`.

Full anti-choppy router:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → EXPOSITION/DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Do not convert causal beats into typography:

`action. reaction. gesture. thought.`

If they form one perceptual/decision unit, merge them into natural prose.

---

## 11. Setting is causal, not decorative

### Gate B168-G10 — Setting Affordance

`WORLD / PLACE RULE → AFFORDANCE / CONSTRAINT → CHARACTER CHOICE → CONSEQUENCE`

A setting detail earns prominence by changing possible action, social interpretation, relationship, risk or evidence—not merely by being imaginative.

---

## 12. Relationship map must encode agency

### Gate B168-G11 — Relationship State

`HISTORY → WANT FROM OTHER → POWER / ACCESS → TRUST → CONSENT / BOUNDARY → CURRENT TACTIC → CHANGE → NEXT EFFECT`

Do not reduce relationship maps to `love / hate / friend / enemy` labels.

For conscious nonhumans this includes independent wants and refusal rights.

---

## 13. Market-age firewall

Ch15–19 were strict-read in full but describe UK publishing circa 2007.

### Gate B168-G12 — Market Claim Routing

`MARKET CLAIM → DATE + TERRITORY + CHANNEL → CURRENT PRIMARY VERIFICATION BEFORE USE`.

Do not operationalize as 2026 policy without fresh verification:
- agent submission etiquette;
- postal/manuscript format requirements;
- retailer shares and discount structures;
- advances / royalty norms;
- rights practices;
- self-publishing economics;
- web/blog assumptions;
- genre-fashion claims.

Craft insight and market history are different source classes.

## 14. Cross-source synthesis

### Converges with Lamott / LaPlante / Swain
Separate discovery from criticism.

### Converges with Mayer / Seger
Reverse-map the manuscript that actually exists.

### Corrected by Scofield
Activity is not automatically an event; scene admission requires meaningful change.

### Corrected by Chatman
Not every non-kernel layer is useless; satellites can carry character, rhythm, atmosphere and resonance.

### Corrected by Zunshine / le Carré
Information control must retain source lineage and evidence status.

### Corrected by Le Guin / Prose / Clark / Lodge
No short-sentence KPI; syntax is functional and contrastive.

### Corrected by LaPlante / Rosenfeld / Bell
Scene and summary are both legitimate narrative modes.

### Corrected by Herman / Corbett / McKee Character
Do not reduce human action to one clean motive.

# Production conclusion

Green/Kremer is most valuable to IVDIVO after removing beginner formulae and dated publishing specifics. The retained engine is:

`DISCOVER LIVE MATERIAL → MAP WHAT THE TEXT ACTUALLY DOES → TRACE LAYERS AND CONSEQUENCES → DIAGNOSE DEFECT LEVEL → REPAIR THE HIGHEST BROKEN LEVEL → RETEST → ONLY THEN POLISH`.

Standing meta-law:

`TOOLS HELP ASK / ORGANIZE / DIAGNOSE; STORY DOES NOT EXIST TO VALIDATE TOOLS.`
