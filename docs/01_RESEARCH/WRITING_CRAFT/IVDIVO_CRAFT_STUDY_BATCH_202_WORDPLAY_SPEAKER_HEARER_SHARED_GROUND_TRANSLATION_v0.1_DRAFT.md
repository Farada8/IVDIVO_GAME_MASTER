# IVDIVO CRAFT STUDY — BATCH 202
## Wordplay · Speaker/Hearer Interaction · Shared Ground · Translation

**Primary source:** Zirker & Winter-Froemel (eds.), *Wordplay and Metalinguistic / Metadiscursive Reflection* (2015)  
**Source status:** `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`

## Production gates

### B202-G01 — WORDPLAY FUNCTION
`SURFACE → SECONDARY PATH → DECODER → FUNCTION → CONSEQUENCE`.
Reject clever lines that do not alter relationship, status, characterization, thematic inference, humour, tension or reader model.

### B202-G02 — SHARED GROUND
Before retaining a pun/allusion/bilingual joke, identify exactly what language/cultural/contextual knowledge enables decoding. If no plausible shared ground exists, support it, adapt it, or cut it.

### B202-G03 — INTERNAL / EXTERNAL AUDIENCE MATRIX
For any load-bearing verbal ambiguity record:
- speaker intends secondary meaning?;
- direct listener decodes?;
- other characters decode?;
- reader decodes?;
- consequence if decoding differs.

### B202-G04 — STOPPING RULE
Do not keep multiplying possible meanings after one reading best explains formal cue + context + relationship + downstream consequence. Hidden wordplay must be falsifiable enough to avoid interpretive free-for-all.

### B202-G05 — CHARACTER OWNERSHIP
Wordplay style is owned by the character/relationship. Validate against worldview, education, technical domain, social goal, emotional state and audience.

### B202-G06 — DISCOURSE TRADITION
Future/alien/robot cultures require locally learned humour and wordplay conventions. Do not import contemporary Earth slang as a universal youth register.

### B202-G07 — WORDPLAY IS NOT EVIDENCE
`PUN / HOMOPHONY / ALLUSION / METAPHOR / SARCASM → HYPOTHESIS / STANCE` only.
Never promote a verbal resemblance into motive, guilt, personhood, provenance or ontology without independent evidence.

### B202-G08 — TRANSLATION / AUDIO FUNCTION
Adaptation target is `FUNCTION + RELATIONSHIP EFFECT + READER/HEARER INFERENCE`. Literal preservation is secondary unless the exact wording is itself a clue, canon fact or acoustic evidence.

### B202-G09 — NONHUMAN COMMUNICATION
A conscious robot/nonhuman agent need not use human puns. Wordplay may emerge from timing, protocol ambiguity, multimodal signals, formal transformations or culturally learned language — but only if embodiment and shared decoding are established.

### B202-G10 — NO AFTER-PUNCHLINE EXPLANATION
If the reader can reconstruct the joke/ambiguity, do not add a separate explanatory sentence that restates the effect.

## Failure-mode tests
1. Could this joke be moved unchanged to another character? → universal-wit risk.
2. Does the joke require knowledge neither listener nor reader has? → shared-ground failure.
3. Does the line create five possible readings with no stopping condition? → overreading risk.
4. Does a pun become a clue solely because two words sound alike? → evidence violation.
5. Is future youth voice just current slang with SF nouns? → discourse-tradition failure.
6. Does audio localization preserve the joke but alter clue wording? → authority/provenance violation.
7. Does every speaker compete to be clever? → humour-status monoculture.
8. Is the explanatory sentence after the joke doing work the joke already did? → compression candidate.
