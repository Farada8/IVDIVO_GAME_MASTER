## NEW MECHANISMS
1. **SELECTION / ARRANGEMENT / DESCRIPTION**
   `storyworld material -> selected attention -> discourse order -> rendering -> reader model`.

2. **ATTENTION IS CHARACTERIZATION**
   `POV capacity + present want + knowledge + relationship -> noticed detail -> reader inference`.

3. **ORDER CHANGES INFERENCE**
   Same facts in a different order can create different reader models. Mystery ordering may manage suspense but may not falsify evidence status.

4. **VIVIDNESS OVER BREVITY WORSHIP**
   Shorter is not automatically stronger. Wrongly imposed brevity can damage continuity, accumulation, perception or pressure.

5. **LEGIBLE SPECIFICITY**
   `more precise term -> POV authentic? -> reader legible? -> functional payoff?`.
   Precision without comprehension becomes opacity.
