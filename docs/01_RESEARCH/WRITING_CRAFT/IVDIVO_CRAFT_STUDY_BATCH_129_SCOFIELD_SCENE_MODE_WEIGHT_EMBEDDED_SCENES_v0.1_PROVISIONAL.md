## Strict boundary
Only directly and sequentially read material from the Introduction and early Chapter 1 is used here. Later chapter titles/TOC are not treated as read content.

## 1. Full scene is one narrative mode, not a universal default
Scofield explicitly frames scene as especially vivid/immediate, while also allowing summary, commentary, embedded scenes, fragments, temporal jumps and freer narrative flow.

Operational router:
`FULL SCENE / EMBEDDED SCENE / SCENE FRAGMENT / SUMMARY / COMMENTARY`.

### Gate B129-G01 — MODE BEFORE LINE EDIT
Before polishing a slow or choppy passage, ask whether it is in the correct narrative mode at all.

If exact moment-by-moment action is not the value, test compression or embedding.

## 2. Scene weight must vary
Not every event deserves equal duration or completeness.

### Gate B129-G02 — SCENE WEIGHT
Assign scene weight by function:
- decisive choice/evidence/relationship turn: high weight;
- setup or transition with some character pressure: medium/low weight;
- routine/logistics/repetition: summary or fragment unless something changes.

Failure mode: `UNIFORM SCENE WEIGHT`.

## 3. Event and interiority are not opposites
Prose can render action while also entering memory, subjective association, interpretation and interior response.

### Gate B129-G03 — ACTION/INTERIORITY BALANCE
Do not imitate screenplay logic by stripping prose to externally visible beats.

But do not let interiority erase event consequence either.

Use:
`EVENT → SUBJECTIVE PROCESSING / ASSOCIATION → ALTERED ACTION OR MEANING`.

## 4. Embedded scene as anti-choppy tool
A narrative paragraph can briefly open into one exact exchange, gesture or remembered image, then return to summary.

### Gate B129-G04 — EMBED ONLY THE BULL'S-EYE
If a five-minute process contains one thirty-second exchange where exact wording matters, dramatize the thirty seconds and summarize the rest.

This prevents:
`walk → door → glance → microthought → line → microgesture → line → exit`.

## 5. Practice draft ≠ final manuscript obligation
Writing a scene can be useful for discovering history, motive, spatial logic or relationship state even if the scene never appears in the book.

### Gate B129-G05 — DISCOVERY SCENE BANK
Allow exploratory/prior scenes during generation.

Before final manuscript inclusion, require:
`CURRENT-BOOK FUNCTION + CAUSAL PAYOFF + READER-TIME JUSTIFICATION`.

Failure mode: `DISCOVERY MATERIAL ENTITLEMENT` — keeping a scene because it was useful to the author rather than necessary to the reader.

## 6. Reader memory favors image + action + meaning
Scofield’s early scene discussion emphasizes memorable event and image while acknowledging prose-specific interiority.

IVDIVO adaptation:
`MEMORABLE PARTICULAR → ACTION/RELATION → MEANING EMERGES`.

Do not convert this into spectacle-first writing.

## 7. Cross-source synthesis
### Converges with
- LaPlante: show/tell are tools, not moral categories.
- Rosenfeld: scene intention and consequences matter more than universal scene formula.
- Bell: action/reaction/setup/deepening as different functions.
- Swain: scene/sequel should not become a mechanical alternation.
- Ribó/Fludernik: duration and discourse mode can be revised independently from story fact.
- Doty: paragraph attention and selected particulars should form a coherent movement.

### Corrects
- screenplay-style beat-by-beat prose;
- all-scenes-equal drafting;
- action-vs-interiority false binary;
- belief that exploratory scenes must survive into final manuscript.

## 8. IVDIVO applications
### Orbital Youth
Do not dramatize every transit, training procedure, interface setup or briefing.

Use full scene when exact experience changes:
- responsibility;
- belonging;
- consent;
- relationship;
- evidence;
- access/authority;
- future option set.

### Conscious robots
A robot’s interiority need not imitate human self-talk. It may appear through selective attention, model revision, refusal, strategy and relation-specific response.

### Mystery
Summarize repeated procedure; dramatize the moment evidence status changes.

### ROOM 917
Audio/physical clue interactions can use high-immediacy scene, while repetitive research or logistics should compress unless exact wording/procedure creates a clue.

## 9. Anti-choppy integration
Expanded router:
`ONE MAIN STORY → CHAPTER FUNCTION → SCENE NECESSITY → MODE (FULL/EMBEDDED/FRAGMENT/SUMMARY) → ORDER/DURATION → POV → DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE → SENTENCE RHYTHM`.

Sentence repair remains downstream.

## 10. Failure modes
- UNIFORM SCENE WEIGHT
- SCREENPLAY PROSE
- MICRODRAMATIZED LOGISTICS
- INTERIORITY WITHOUT EVENT CONSEQUENCE
- ACTION WITHOUT SUBJECTIVE MEANING
- DISCOVERY MATERIAL ENTITLEMENT
- FULL-SCENE DEFAULT
- EMBEDDED-SCENE OVERUSE
- SUMMARY GUILT
