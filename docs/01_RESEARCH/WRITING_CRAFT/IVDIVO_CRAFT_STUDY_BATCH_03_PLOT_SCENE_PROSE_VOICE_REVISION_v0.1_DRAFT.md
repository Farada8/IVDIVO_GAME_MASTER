# 1. COYNE — THE STORY GRID

## 1.1 Scene as measurable change

Coyne’s strongest operational contribution is that a scene is not merely a location/time block or a conversation. It must contain a **value shift**: the state that matters to the characters moves in a meaningful direction.

Transferable mechanism:

`SCENE START VALUE → INCITING DISTURBANCE → PROGRESSIVE COMPLICATIONS → TURNING POINT → CRISIS QUESTION → CLIMAX ACTION → RESOLUTION / NEW VALUE STATE`

This is useful because it gives an editor a diagnostic that is more precise than “the scene feels slow.”

### IVDIVO TEST — VALUE SHIFT
For every planned scene record:
- dominant value at entry;
- polarity/intensity at entry;
- exact turning-point beat;
- dominant value at exit;
- why the shift matters to the next action.

If the scene begins and ends at functionally the same state, it requires a strong secondary justification or must be merged/rebuilt.

## 1.2 Five-commandment scene grammar

Coyne’s micro-form:
1. Inciting Incident;
2. Progressive Complications;
3. Crisis;
4. Climax;
5. Resolution.

The useful point is not the number five as dogma. The useful mechanism is that **a disturbance creates escalating difficulty, which creates a real decision, which is answered by action, after which the consequences must be metabolized**.

### Failure mode
Mechanical use can make every scene feel identical. Some scenes compress several functions into a beat; some distribute them across a sequence. Therefore IVDIVO uses the functions as an audit, not a mandatory page template.

## 1.3 Turning point = action or revelation that changes the situation

Coyne identifies two primary turn mechanisms:
- character action;
- revelation/new information.

Important synthesis for IVDIVO: a revelation is not a turn merely because it is surprising. It becomes a turn when it **changes the available decision space**.

### IVDIVO TEST — ACTIONABLE REVELATION
`NEW FACT → OLD MODEL BROKEN? → NEW OPTIONS / LOST OPTIONS → DECISION → ACTION CONSEQUENCE`

If the fact only expands lore, it is information, not a dramatic turn.

## 1.4 Crisis must be a real choice

Coyne’s useful distinction:
- best bad choice;
- irreconcilable goods.

This directly supports IVDIVO’s anti-fake-dilemma rule. A crisis becomes dramatically strong when choosing one value damages another value that also matters.

### IVDIVO TEST — NONTRIVIAL CRISIS
Reject a crisis when:
- one option is obviously correct and costless;
- the “wrong” option exists only because the character becomes stupid;
- the choice changes nothing important;
- the choice can be reversed immediately without cost.

## 1.5 Climax = action, not stated intention

The character’s crisis answer is only provisional until enacted. The climax is the on-page/on-stage action that reveals what the character actually chooses under pressure.

### Production consequence
A protagonist’s decisive climax cannot be outsourced to:
- a report from another character;
- an off-page event;
- a deus ex machina;
- a stronger adult who finishes the protagonist’s problem.

## 1.6 Resolution is not optional administrative cleanup

Coyne emphasizes fallout after climax. IVDIVO already requires local closure; this source strengthens the need to show enough aftermath that the reader can understand **what the climax changed**.

# 2. WEILAND — STRUCTURING YOUR NOVEL

## 2.1 Plot point = event + irreversible reaction

Weiland’s First Plot Point becomes useful when stripped of percentage fetishism. The key mechanism is not “25% exactly.” It is:

`SETUP STATE → MAJOR EVENT → PROTAGONIST REACTS IRREVERSIBLY → OLD MODE OF LIFE NO LONGER SUFFICIENT`

The event alone is insufficient. The protagonist’s reaction converts event into story movement.

### IVDIVO TEST — THRESHOLD
At the end of the setup, ask:
- what can the hero no longer return to?
- what commitment, exposure, loss, promise, discovery, or relationship change makes retreat costly?
- what does the hero now have to do that was unnecessary before?

## 2.2 First half / second half of the middle

Weiland’s useful middle-book distinction:
- early middle: protagonist largely reacts to the new situation;
- around midpoint: new understanding/decision changes tactics;
- later middle: protagonist becomes more proactive.

Do not use this as a rigid universal law. Use it as a stagnation detector.

### IVDIVO MIDPOINT TEST
The midpoint must change at least one of:
- mission;
- model of the problem;
- identity/self-understanding;
- target;
- tactic;
- relationship allegiance;
- perceived stakes.

If the second half of the book is merely “more of the same attempts but louder,” midpoint function has failed.

## 2.3 Scene / sequel causal bridge

Weiland extends Swain:

**Scene:** `GOAL → CONFLICT → OUTCOME/DISASTER`

**Sequel:** `REACTION → DILEMMA → DECISION`

The most valuable part is the bridge:

`OUTCOME → REACTION → DILEMMA → DECISION → NEXT SCENE GOAL`

This is an anti-episodic machine. The next scene grows from the previous outcome rather than being selected by author convenience.

### IVDIVO TEST — NEXT GOAL CAUSALITY
Every new scene goal should identify its parent:
- previous consequence;
- previous discovery;
- previous promise;
- previous failure;
- previous relationship turn.

“No parent” is a structural warning.

## 2.4 Decision is the motor of forward movement

A dilemma without decision becomes rumination. Weiland’s useful distinction between long-term objective and short-term decision helps prevent diffuse scenes.

Operational model:

`LONG-TERM WANT → CURRENT OBSTACLE → DILEMMA → SHORT-TERM DECISION → IMMEDIATE GOAL`

## 2.5 Sentence-level causality / MRU

Weiland imports Swain’s Motivation–Reaction Unit to prose:

`STIMULUS/MOTIVATION → PERCEPTION/REACTION → ACTION`

This is not a grammar law. It is a clarity test for moments where the reader must understand physical and psychological causality.

### Failure mode
Over-enforcement creates robotic prose. Artistic inversion is allowed when intentionally controlling surprise, temporal perception, or voice.

# 3. ROSENFELD — THE SOUND OF STORY

## 3.1 Voice is not decoration

Rosenfeld treats voice as produced by a network:

`BACKSTORY + CULTURE + AGE + SOCIAL POSITION + HISTORY + EMOTIONAL HABITS + SPECIFICITY OF NOTICE + OPINION/JUDGMENT + SYNTAX + LEXICON + RHYTHM`

This is stronger than a simplistic “give everyone catchphrases” approach.

### IVDIVO CHARACTER VOICE PASSPORT — ADDITIONS
For every core character add:
- default sentence architecture;
- lexical field / words naturally available to them;
- metaphors they are likely/unlikely to use;
- what they notice first under stress;
- judgment style;
- code-switch conditions;
- rhythm under calm / stress / intimacy / authority;
- taboo vocabulary and avoided formulations.

## 3.2 Syntax carries identity

Sentence architecture is part of character/narrator expression. Two characters with the same factual information should not necessarily form the same sentence.

### IVDIVO TEST — VOICE WITHOUT NAMES
Remove dialogue tags and proper names from 20 lines spoken by core characters. If attribution becomes impossible, inspect syntax, lexicon, assumptions, and reasoning rhythm—not merely slang.

## 3.3 Lexicon is a world model

Vocabulary is not just education level. It reflects profession, community, family, technology, social status, trauma, hobbies, era, and identity.

For IVDIVO this is critical because scientists, teenagers, operators, orbital residents, artists, AI, and initiated subjects should not describe the same phenomenon using one universal author vocabulary.

## 3.4 Rhythm and musicality are functional

Rhythm can alter:
- speed;
- intimacy;
- pressure;
- comic timing;
- dread;
- attention to image;
- perceived certainty.

### IVDIVO RHYTHM TEST
Read critical scenes aloud. Mark:
- accidental monotony in sentence length;
- repeated paragraph cadence;
- repeated rhetorical structures;
- places where syntax slows action unintentionally;
- places where short syntax destroys emotional accumulation.

This directly targets the Book 1 line-edit problem of repeated short-paragraph/rhetorical cadence.

## 3.5 Cut clutter without sterilizing voice

Rosenfeld distinguishes intentional repetition from accidental repetition/redundancy. Useful rule:

`REPETITION MUST CREATE NEW FORCE, PATTERN, EMPHASIS, OR MUSIC.`

If the second formulation merely explains the first, it is probably clutter.

### IVDIVO REDUNDANCY TEST
For adjacent sentence/gesture/dialogue units ask:
- does each add new information, emotional pressure, image, or rhythm?
- are action, thought, and dialogue all redundantly stating the same emotion?

# 4. BURROWAY — WRITING FICTION

## 4.1 Fiction must create felt experience, not merely state ideas

Burroway’s central prose principle: ideas matter, but fiction must make the reader experience them through characters, sensory particulars, actions, speech, and consequence.

### IVDIVO PHILOSOPHY FIREWALL
A philosophical proposition does not earn page space merely because it is important to the universe. It must enter through at least one of:
- perception;
- conflict;
- experiment;
- consequence;
- relationship;
- choice;
- concrete object/detail.

## 4.2 Significant detail does double work

Strong detail is concrete and sensory but also meaningful. It proves the reality of the scene while carrying character, atmosphere, tension, or theme.

### IVDIVO DETAIL TEST
For every descriptive paragraph identify:
1. what can be perceived;
2. why this POV notices it;
3. what narrative work it performs.

If only #1 exists, the description may be decorative inventory.

## 4.3 Dialogue should do more than one job

Burroway treats effective dialogue as distilled rather than transcribed speech. It can simultaneously:
- characterize;
- move action;
- expose relationship;
- deliver necessary information;
- foreshadow;
- create setting/atmosphere;
- reveal concealed emotion.

### IVDIVO DIALOGUE TEST
A substantial exchange that performs only exposition should be rebuilt around competing intentions.

## 4.4 Plot: forward movement plus causal meaning

Burroway recognizes the reader’s desire for both:
- what happens next;
- why this happened / what it means.

This supports a two-axis plot model:

`FORWARD QUESTION` + `CAUSAL/EMOTIONAL UNDERSTANDING`

A book can be eventful yet empty if the causal/emotional axis is weak; it can be insightful yet unreadable if forward pressure disappears.

## 4.5 Conflict is not the only possible shape

Burroway/Hodgins discuss alternatives to “plot as war”: connection, growth, gathering, healing, circular/network forms. This is important for IVDIVO because not every book should culminate in combat.

### Operational synthesis
A main story still needs movement, pressure, transformation, and consequence, but opposition can arise from:
- incompatible needs;
- scarcity;
- uncertainty;
- time;
- social structure;
- internal contradiction;
- difficult construction/creation;
- negotiation;
- rescue;
- environment;
- loss;
without requiring a villain.

## 4.6 POV includes distance, not just person

Burroway frames POV through:
- who speaks;
- to whom;
- in what form;
- at what distance.

Psychic/authorial distance can be intentionally widened or narrowed.

### IVDIVO POV TEST
For each scene define:
- focal consciousness;
- knowledge boundary;
- temporal position;
- psychic distance target;
- what must remain uninterpreted/unavailable.

## 4.7 Revision = re-vision, not surface polish

Burroway’s strongest editorial lesson: revision can require reconceiving structure, deleting the passage that originally inspired the piece, or discovering that the initial intention was wrong.

This directly supports the Founder correction that a 114k-word draft cannot be protected merely because it exists.

### IVDIVO REVISION ORDER
`MAIN STORY → STRUCTURE → CHARACTER CAUSALITY → SCENE FUNCTION → POV/INFORMATION → PROSE/RHYTHM → COPYEDIT`

Never reverse this hierarchy.

# 5. HODGINS — A PASSION FOR NARRATIVE

## 5.1 Traditional plot as causal chain

Hodgins identifies practical plot ingredients:
- protagonist worth following;
- goal plus strong reason;
- obstacles;
- causal connection between events;
- intensifying conflict/tension;
- crisis/turn;
- satisfying ending state.

He also warns that a conventional blueprint can become contrived and lifeless.

### IVDIVO SYNTHESIS
**Story architecture is required; formulaic surface pattern is not.**

We need causal structure without forcing every book into identical beats.

## 5.2 Character can generate plot

Hodgins’ useful corrective to pure outlining: once a character is sufficiently specific, their response to pressure should generate plausible next events.

### IVDIVO TEST — CHARACTER-CAUSED PLOT
For major turns ask:
- why *this* character makes *this* choice;
- what another plausible character would do differently;
- whether the plot still works if personalities are swapped.

If the plot is unchanged after swapping character psychology, the characters may be passengers.

## 5.3 Keep a major object ahead without overlocking the route

Hodgins cites the usefulness of having a major destination/event ahead while allowing the route to change as the material develops.

This maps well to IVDIVO’s Specification-First discipline if we distinguish:
- **frozen outcome obligations** (what the story must resolve);
- **discoverable implementation** (how exactly scenes reach it).

No silent redesign of the Book Contract, but scene execution can discover better causal routes via controlled Change Requests.

## 5.4 Alternative plot architectures remain legitimate

Hodgins presents network/carrier-bag/birth/growth models as alternatives to war/quest dominance. IVDIVO should use them when the human problem demands them rather than for novelty alone.

# 6. NOLL — THE WRITER’S FIELD GUIDE TO THE CRAFT OF FICTION

## 6.1 Setting must participate in drama

Noll’s practical principle: setting should not behave like a green screen. Characters can use place, objects, access, confinement, visibility, and architecture as tactics.

### IVDIVO SETTING-ACTION TEST
For important scenes ask:
- how does the location constrain action?
- what resource does it provide?
- who controls access?
- what can be hidden/seen/heard?
- how does the POV character use the setting against another person or problem?

## 6.2 Unequal access to an object of desire creates tension

A shared desire becomes more dramatic when characters have unequal access, rights, knowledge, money, mobility, status, or risk.

This is directly applicable to Earth/Orbit/Contact technology asymmetry.

### IVDIVO ACCESS MATRIX
For every scarce/desirable object/system track:
`WHO WANTS IT | WHO CONTROLS IT | WHO CAN ACCESS IT | WHO PAYS MORE | WHO RISKS MORE | WHO CAN WALK AWAY`

## 6.3 Dialogue can progress from information to resistance

A dialogue built only as question→answer ends when information arrives. Noll shows a stronger structure where the listener resists, doubts, reframes, or refuses the implication of the information.

Operational chain:

`INFORMATION GAP → ANSWER → RESISTANCE/DOUBT → EVIDENCE/PRESSURE → EMOTIONAL ACCEPTANCE OR REFUSAL → STATE CHANGE`

This is particularly valuable for investigation scenes and extraordinary-world revelations.

## 6.4 Action scenes need interior consequence

Action choreography alone is insufficient. Interiority can alter the meaning of movement, anticipation, memory, shame, fear, or interpretation.

### IVDIVO ACTION TEST
After spatial choreography is clear, ask:
- what does the POV think the event means while it happens?
- what expectation is broken?
- what personal fear/desire changes the chosen tactic?

Do not interrupt every action beat with reflection; use interiority where it changes perception or choice.

## 6.5 Incompatible ideas create hooks

A hook can arise when two facts/world expectations appear unable to coexist. The reader continues to resolve the incompatibility.

Formula:

`EXPECTED WORLD + IMPOSSIBLE/CONTRADICTORY FACT → QUESTION`

Useful for IVDIVO because the extraordinary should often enter through a violation of recognizable ordinary life rather than through lore declaration.

# 7. CROSS-SOURCE SYNTHESIS — NEW CORE MECHANISMS

## 7.1 The complete causal scene chain

Combining Coyne + Weiland + Burroway + Hodgins + Noll:

`ENTRY STATE / VALUE`
`→ IMMEDIATE WANT`
`→ DISTURBANCE`
`→ ACTION / TACTIC`
`→ RESISTANCE`
`→ PROGRESSIVE COMPLICATION`
`→ TURN (ACTION OR REVELATION)`
`→ CRISIS / DILEMMA`
`→ DECISION`
`→ CLIMAX ACTION`
`→ OUTCOME / VALUE SHIFT`
`→ HUMAN REACTION`
`→ INTERPRETATION`
`→ NEW SHORT-TERM DECISION`
`→ NEXT SCENE GOAL`

This is not a mandatory prose sequence. It is a diagnostic causal graph.

## 7.2 Three levels of change

Every major scene should be checked across three different dimensions:

1. **Plot state:** what external option/constraint changed?
2. **Relationship/character state:** what changed in trust, status, fear, desire, identity?
3. **Reader model:** what assumption/question changed for the reader?

A scene can be strong with one dominant dimension, but high-value scenes often alter two or three simultaneously.

## 7.3 Information must have a dramatic metabolism

Combined Coyne + Noll + Burroway:

`INFORMATION → INTERPRETATION → ACCEPT/RESIST → DECISION → ACTION → CONSEQUENCE`

Worldbuilding that never enters this metabolism is not yet story material.

## 7.4 Prose is downstream of structure but not irrelevant

Rosenfeld + Burroway + Weiland establish a hierarchy:

`STORY CAUSALITY → SCENE FUNCTION → POV EXPERIENCE → SIGNIFICANT DETAIL → SYNTAX/LEXICON → RHYTHM → LINE CLEANUP`

Beautiful sentences cannot rescue absent story causality; crude sentence rhythm can still damage a structurally good story.

## 7.5 Voice must be generated from worldview and language mechanics

`WHO THE CHARACTER IS → WHAT THEY NOTICE → HOW THEY JUDGE → WHAT WORDS THEY HAVE → HOW THEY ARRANGE THEM → RHYTHM UNDER CURRENT PRESSURE`

This replaces catchphrase-based voice design.

# 8. NEW IVDIVO PRODUCTION GATES FROM BATCH 03

## GATE A — SCENE CAUSALITY
A scene fails if no clear chain exists from previous consequence to current objective to next consequence.

## GATE B — VALUE / STATE DELTA
A scene fails if nothing relevant changes and removal produces no structural loss.

## GATE C — CRISIS QUALITY
A major crisis fails if one option is costless/obvious or the character must become stupid to choose badly.

## GATE D — REVELATION METABOLISM
A reveal fails if it does not alter interpretation, decision, target, tactic, risk, relationship, or permission.

## GATE E — SETTING PARTICIPATION
An important setting fails if it could be replaced by a blank room with no effect on action, power, perception, or meaning.

## GATE F — VOICE DIFFERENTIATION
A core voice fails if syntax, lexicon, noticed details, judgment, and reasoning rhythm are interchangeable with another core character.

## GATE G — DESCRIPTION FUNCTION
Description fails if it is sensory inventory without POV selection or narrative work.

## GATE H — REVISION HIERARCHY
Line editing is prohibited from becoming the primary fix while main-story/structure/scene causality remains unresolved.

Before drafting a scene, the scene card should now contain:

`PARENT CONSEQUENCE | POV | ENTRY VALUE | IMMEDIATE WANT | SETTING CONSTRAINT/RESOURCE | OPPOSITION | TACTIC | COMPLICATION | TURN TYPE | CRISIS | DECISION | CLIMAX ACTION | EXIT VALUE | RELATIONSHIP DELTA | READER-MODEL DELTA | REACTION | NEXT GOAL`

For prose calibration add:

`PSYCHIC DISTANCE | SIGNIFICANT DETAILS | CHARACTER LEXICON | SENTENCE RHYTHM TARGET | INTENTIONAL REPETITION | REDUNDANCY CHECK`

For a reveal add:

`FACT | WHO KNOWS | WHO RESISTS | EVIDENCE | MODEL BROKEN | OPTIONS CHANGED | DECISION CAUSED | CONSEQUENCE`

# 10. CONFLICTS / LIMITS BETWEEN SCHOOLS

1. **Coyne/Weiland structural regularity vs Hodgins/Burroway flexibility.** Resolution: use structural functions as diagnostics, not page-count dogma.
2. **Conflict-centered models vs connection/growth/network plots.** Resolution: require pressure, consequence, movement, and choice, but not always a villain or combat.
3. **MRU causal order vs expressive prose freedom.** Resolution: use MRU where clarity matters; permit deliberate inversion for voice/effect.
4. **Scene value-shift insistence vs atmospheric/reflective passages.** Resolution: a passage may exist without a full Coyne-style scene if it performs a necessary transition, compression, setup, or resonance function; it must still justify its page cost.
5. **Voice richness vs prose efficiency.** Resolution: cut accidental clutter, not distinctive language.
