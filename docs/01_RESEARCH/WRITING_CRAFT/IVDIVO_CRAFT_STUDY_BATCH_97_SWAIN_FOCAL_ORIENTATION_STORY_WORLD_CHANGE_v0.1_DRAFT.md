## 2. CORE SYNTHESIS

### 2.1 Evaluation requires an evaluator
`EVENT / RULE / TECHNOLOGY -> PARTICULAR AGENT -> GOAL / VALUES / YARDSTICK -> BENEFIT / COST -> RESPONSE -> READER MEANING`

An event is not narratively `good`, `bad`, `safe`, `efficient`, `advanced`, `primitive`, or `fair` in the abstract. The story must make legible who is evaluating it and by what standard.

### 2.2 Focal character ≠ hero ≠ POV character
Swain explicitly distinguishes these functions. The focal character is the primary orientation center; the viewpoint character is the perceptual/knowledge access point; the hero label adds moral/genre baggage and is not required.

IVDIVO operationalization:
`WHO ORIENTS THE READER TO THE BOOK/SCENE?` is a different question from `WHOSE SENSES / KNOWLEDGE / INTERIORITY ARE CURRENTLY AVAILABLE?`

This is useful for ensemble and mystery architectures where the person whose problem organizes the reader may not be the person through whose consciousness a given clue is encountered.

### 2.3 Reader-orientation debt
An unfamiliar world creates orientation debt. Paying that debt does not require a lecture.

Preferred route:
`WORLD RULE -> THIS PERSON NOTICES IT BECAUSE IT AFFECTS A PRESENT WANT -> PERSON EVALUATES / REACTS -> ACTION / CONSEQUENCE -> READER LEARNS THE NORM`.

### 2.4 Story world = sensory + subjective + selected
Swain's three-part frame is useful when stripped of sensory-checklist dogma:
1. reader may not know the place;
2. lived experience enters through sensory availability;
3. description is filtered through goals, mood, history and attitude.

Operational rule:
`WORLD DATABASE -> POV-RELEVANT SELECTION -> SENSORIUM / EMBODIMENT -> ATTITUDE -> ACTIONABLE DETAIL`.

### 2.5 Setting words encode evaluation
Description is not neutral. Lexical choices can carry approval, disgust, familiarity, fear, nostalgia, status judgment or institutional ideology.

Gate:
`DETAIL / LABEL -> WHO WOULD USE THIS WORD? -> WHAT VALUE MODEL DOES IT IMPORT? -> IS THAT MODEL ATTRIBUTED OR ACCIDENTALLY CANONIZED?`

### 2.6 Story equals meaningful change
Swain frames story as movement from one state of affairs / mind to another. IVDIVO broadens this beyond mandatory personality transformation.

Trackable state axes:
- external / physical;
- knowledge / evidence;
- relationship;
- authority / access;
- obligation / responsibility;
- strategy / model;
- emotional state;
- future option space.

A story can preserve core personality and still produce strong change on these axes.

### 2.7 Change is not spectacle
A change may be quiet. What matters is that it changes the agent's available choices, interpretation, commitment, relationship, evidence status or consequences.

Do not equate `change` with accident, death, attack, betrayal, or loud reversal.

## 3. CROSS-SOURCE COMPARISON

### Swain vs Fludernik / Chatman
Swain's focal orientation and subjective world align with the separation between story facts, discourse presentation and focal access. IVDIVO keeps the stronger distinction:
`WORLD FACT != FOCAL EXPERIENCE != READER MODEL`.

### Swain vs Card / Kress / Rosenfeld
Strong convergence that focal/POV functions are not reducible to first/third person grammar. Card/Kress/Rosenfeld provide finer control over narrative distance and multi-POV cost.

### Swain vs Wolf / Cambridge SF
Worldbuilding should be much larger in the database than on the page. The page needs lived, causal, POV-relevant manifestations rather than inventory.

### Swain vs Zunshine / Herman
Human or institutional evaluation of a conscious robot does not establish the robot's motive. A school interpretation of a consciousness-practice result does not establish ontology.

### Swain limitation: single-focal orthodoxy
Swain strongly prefers a single focal center and treats diffuseness as a major risk. Keep the diagnosis, reject the universal law. Multi-focal / ensemble novels work when each strand pays for its switching cost and modifies one dominant causal engine.

## 4. IVDIVO PRODUCTION GATES

### B97-01 — ORIENTATION OWNER
For every chapter/scene, identify the current reader-orientation center. Do not assume it equals hero or POV character.

### B97-02 — POV ACCESS SEPARATION
`FOCAL PROBLEM OWNER -> POV ACCESS OWNER -> KNOWLEDGE LIMIT -> READER KNOWLEDGE`.
If these differ, make the relation legible.

### B97-03 — EVALUATION ATTRIBUTION
Every `good/bad/fair/safe/efficient/advanced` claim answers:
`WHO SAYS/THINKS THIS -> BY WHAT YARDSTICK -> WHO BENEFITS -> WHO PAYS`.

### B97-04 — WORLD ORIENTATION THROUGH USE
Before exposition, test whether the world rule can be shown through a present want, ordinary action, friction or consequence.

### B97-05 — SENSORIUM WITH FUNCTION
Sensory detail must arise from embodiment/attention and perform character, world, relation, causality, orientation or rhythm work. No five-senses checklist.

### B97-06 — DESCRIPTION CONNOTATION
World-description vocabulary must belong to a narrator/POV/institutional frame or be independently established. Do not let attitude masquerade as ontology.

### B97-07 — STATE-CHANGE AUDIT
At meaningful chapter/scene boundaries record which state changed:
`ACTION / KNOWLEDGE / RELATION / AUTHORITY / OBLIGATION / MODEL / EMOTION / OPTIONS`.
No requirement that all axes move.

### B97-08 — QUIET CHANGE PERMISSION
Do not inflate a quiet but causal state change into catastrophe solely to satisfy a structural template.

### B97-09 — ENSEMBLE ORIENTATION
Multiple POVs are permitted when each adds unique action/evidence/relationship/model work and all strands affect ONE MAIN STORY.

### B97-10 — DEFAULT-EARTH-YARDSTICK FIREWALL
In future/post-money scenes, do not let the reader's default Earth-2020s valuation silently define stakes. Make the in-world evaluator and cost structure concrete.

## 5. IVDIVO APPLICATION

### Post-money orbital society
Do not explain `there is no ordinary money economy`. Show an ordinary moment where a mundane object/resource is easy to obtain but trust, another person's time, consent, a unique mission slot, reputation, mastery or lived experience remains nonfungible.

The same city rule may be beneficial to one resident and burdensome to another. The narration should not pre-label the system; people reveal competing yardsticks through action.

### Conscious robots
A human focal character may experience a robot as `helpful`, `unsafe`, `cold`, `loyal` or `efficient`. These are focal evaluations, not robot motive.

Robot personhood gate:
`ROBOT OWN WANT -> OWN RELATIONSHIPS -> OWN EVIDENCE/MODEL -> CONSENT/REFUSAL -> CHOICE -> CONSEQUENCE`.

### Consciousness-practice schools
A practitioner's frame of reference legitimately shapes lived description, but does not raise school vocabulary into ontology.
Maintain:
`PRACTITIONER OBSERVATION -> REPRODUCIBLE EFFECT -> SCHOOL INTERPRETATION -> COMPETING INTERPRETATION -> POSSIBLE ONTOLOGICAL CLAIM`.

### Mystery / evidence
Separate orientation from truth:
`WORLD FACT -> TRACE/SOURCE -> POV ACCESS -> FOCAL EVALUATION -> DISCOURSE ORDER -> READER MODEL`.
A compelling focal interpretation may still be wrong.
