# IVDIVO CRAFT STUDY — BATCH 162
## Gloria Kempton — Dialogue Function · Tactic · Voice · Evidence Firewall

**Date:** 2026-08-20  
**Source:** Gloria Kempton, *Dialogue*  
**Source status:** STRICT_LIFECYCLE_SYNTHESIZED_v1.0  
**Batch status:** DRAFT / PRODUCTION-READY MECHANISMS

## Executive synthesis

Kempton is useful when dialogue is treated as **character action routed through relationship and knowledge**, not as page decoration, exposition delivery or an automatic source of speed/tension.

Primary IVDIVO model:

`PRESENT WANT + RELATIONSHIP + KNOWLEDGE → COMMUNICATION TACTIC → ACTUAL LISTENER RESPONSE → TACTIC / MODEL UPDATE → CHANGED STATE`.

The presentation mode is chosen after function:

`DIRECT DIALOGUE / INDIRECT DIALOGUE / NARRATION / ACTION / SILENCE / MIX`.

---

## B162-G01 — Exact-Wording Value

Use real-time direct dialogue when exact wording changes:
- consent/boundary;
- trust;
- relationship terms;
- evidence access/status;
- authority/status;
- decision/commitment;
- emotional state with downstream causal consequence;
- future option space.

Routine process, repeated facts, logistics and non-load-bearing exchanges are candidates for summary or indirect dialogue.

## B162-G02 — Exposition Ownership

Before a character explains information:

`WHO NEEDS/WANTS TO SAY/ASK/HIDE THIS? → WHY NOW? → WHY TO THIS PERSON? → WHAT CHANGES AFTERWARD?`

If the answer is only `the reader needs to know`, reroute the information.

## B162-G03 — Listener Attention

Do not assume that everyone present processes the same line identically.

Track:
`HEARD? → UNDERSTOOD? → ALREADY KNEW? → MISREAD? → AVOIDED? → HAS STANDING TO ANSWER?`

This is especially important in five-person youth ensembles and institutional meetings.

## B162-G04 — Tactic Rotation

If a character repeats the same objective, the dialogue should not simply rephrase the same tactic.

Possible tactic shifts:
`ask → minimize → joke → challenge → disclose → refuse → bargain → wait → redirect → repair`.

Repeated wording with no tactic/state change is a compression candidate.

## B162-G05 — Relationship-Specific Voice

Voice is generated through:

`WORLDVIEW + RELATIONSHIP + STATUS + PRESENT WANT + ATTITUDE + SOCIAL HISTORY → WORD CHOICE + SYNTAX + RHYTHM + REGISTER + OMISSION`.

Do not solve voice differentiation by slang, accents or quirks alone.

## B162-G06 — Motive Firewall

`UTTERANCE / PAUSE / INFLECTION / GESTURE → MOTIVE HYPOTHESIS`, not motive fact.

For mystery:
`OBSERVED COMMUNICATION → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.

## B162-G07 — Silence / Consent Firewall

Silence, compliance, delayed reply and cooperation under constraint are not automatic consent.

`SILENCE / COMPLIANCE ≠ CONSENT`.

## B162-G08 — Dialogue-Pace Firewall

No equation:
`DIALOGUE = FAST`.

Dialogue can accelerate, decelerate, stall, circle, intensify or create subjective suspension.

Choose pace through reader effect and information load.

## B162-G09 — Anti-Chop Dialogue

Do not convert dialogue beats into typography:

`line → gesture → thought → line → gesture`.

If several microbeats form one perceptual/decision unit, allow one coherent paragraph.

`INTENSITY ≠ SHORT-SENTENCE DENSITY`.

## B162-G10 — Action-Beat Necessity

Use an action beat when it changes or clarifies:
- spatial orientation;
- power/status;
- consent/boundary;
- evidence handling;
- tactic;
- physical possibility;
- character-specific behavior.

Do not add coffee cups, glances, fingers, breaths and clothing adjustments merely to avoid `said`.

## B162-G11 — Character-Owned Humor

A joke must belong to the speaker's worldview, tactic and relationship.

If five characters could exchange jokes without changing them, the humor is author-owned rather than character-owned.

## B162-G12 — Quiet Dialogue Legitimacy

No compulsory confrontation.

A quiet conversation can be a full scene if it changes:
`TRUST / CONSENT / KNOWLEDGE / RELATIONSHIP TERMS / COMMITMENT / EVIDENCE ACCESS / NEXT DECISION`.

## B162-G13 — Theme Through Consequence

A character may articulate theme, but thematic validity must survive removal of the speech.

`THEMATIC QUESTION → COMPETING MODELS → CHOICES → CONSEQUENCES → READER INFERENCE`.

## B162-G14 — Nonhuman Voice Personhood

No default robot register.

For a conscious nonhuman agent:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → EMBODIMENT → CONSENT/REFUSAL → COMMUNICATION TACTIC → CHOICE → CONSEQUENCE`.

## B162-G15 — Generation / Critique Separation

Do not apply the full dialogue checklist while generating every first-draft line.

`LIVE DRAFT → OBSERVED DEFECT → ROUTE TO RELEVANT GATE → REPAIR → RETEST`.

## Failure modes

- **EXPOSITION PUPPET** — character recites information only for reader benefit.
- **TENSION MONOCULTURE** — every conversation forced into overt conflict.
- **CLIFFHANGER MONOCULTURE** — every dialogue scene ends on a startling line.
- **MOTIVE CERTAINTY** — speech or gesture treated as direct proof of motive.
- **ENNEAGRAM DETERMINISM** — personality type treated as causal truth.
- **YA VOICE STEREOTYPE** — bluntness/slang used as default youth voice.
- **CLINICAL SPEECH STEREOTYPE** — speech quirks used to infer disorder, trauma, intelligence or morality.
- **UNIVERSAL ROBOT VOICE** — all synthetic persons share one clipped/logical register.
- **ACTION-BEAT FIDGETING** — meaningless gestures inserted to replace tags.
- **DIALOGUE-WHITE-SPACE KPI** — dialogue favored because the page looks airy.
- **DIALOGUE=SPEED** — narrative mode mistaken for pace itself.
- **THEME SERMON** — argument exists only in speeches.
- **GENRE REGISTER ESSENTIALISM** — genre label dictates dialogue surface.
- **MARKET STALENESS** — historical publishing advice treated as current rule.

## Cross-source synthesis

- **McKee Dialogue:** strengthens dialogue-as-action/tactic.
- **Chiarella:** better model of listening, selection and conversational pressure.
- **Baxter:** corrects speaker-centric dialogue through staging and non-listening.
- **Zunshine/Herman:** correct motive-certainty with epistemic provenance.
- **Le Guin/Clark/Lodge:** block short-sentence pacing dogma.
- **Scofield/LaPlante/Rosenfeld:** scene value comes from consequential change, not mandatory overt conflict.
- **Card/Kress/Corbett:** relationship-specific self is stronger than demographic/personality templates.
- **Vorhaus:** humor must be character-owned.
- **Lamott/Bell/Swain:** generate first, diagnose later.

`DIALOGUE IS NOT VALUABLE BECAUSE IT IS DIALOGUE.`

It earns real-time space when exact communication changes the story.
