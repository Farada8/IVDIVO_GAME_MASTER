## Dwight V. Swain — *Creating Characters*: Purpose, Motive, Background, Relationship, Personhood

**Pass:** 173  
**Source status:** `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`  
**Class:** WIDER

## Core synthesis
Swain is most useful when his dated deterministic assumptions are removed. The durable mechanism is:

`WHAT MATTERS → PRESENT PURPOSE → RELATIONSHIP / PRESSURE → TACTIC → OUTCOME → UPDATED MODEL / NEXT CHOICE`.

### Gate 1 — Importance-to-Action
A declared value matters only when it changes behavior.

`PRIORITY / CONCERN → CHOICE UNDER PRESSURE`.

### Gate 2 — Purpose / Motive Separation
`PURPOSE / OBJECTIVE` = what the character is trying to do now and can be tracked in action.

`MOTIVE` = why; often uncertain, rationalized or only partially known.

Therefore:
`OBSERVED ACTION / DECLARED REASON → MOTIVE HYPOTHESIS`, not `MOTIVE FACT`.

### Gate 3 — Continuing Causal Involvement
Ask:
`WHY DOES THIS AGENT KEEP PARTICIPATING?`

Valid answers include accepted responsibility, relationship, evidence ownership, consequence ownership, consent-based cooperation, role/access or physical constraint.

Do not manufacture death, debt, kidnapping or villainy merely to prevent exit.

### Gate 4 — Competing Values
`VALUE A + VALUE B + RELATIONSHIP + CURRENT COST + KNOWLEDGE → PRIORITY NOW → TACTIC`.

This prevents one-trait character algorithms.

### Gate 5 — Background Payment
Backstory enters only when it changes present salience, interpretation, tactic, relationship, evidence or option space.

`BACKGROUND WITHOUT PRESENT PAYMENT → COMPRESS / BANK / CUT`.

### Gate 6 — Experience Is Not Destiny
`SAME EXPERIENCE ≠ SAME RESPONSE`.

Use:
`EXPERIENCE → CHARACTER-SPECIFIC INTERPRETATION → CURRENT MODEL / TACTIC`.

### Gate 7 — Labels Are Provisional
`LABEL → READER MODEL → BEHAVIOR / RELATIONSHIP EVIDENCE → UPDATE`.

Do not let a tag become identity.

### Gate 8 — Quirk Causality
A mannerism/tag earns space when it reveals relation, state, tactic or recurring pattern.

`QUIRK WITH NO STORY/RELATION PAYMENT → REMOVE`.

### Gate 9 — Role Function / Personhood Separation
`BOOK ROLE ≠ STORYWORLD PERSONHOOD`.

Mentor, antagonist, incidental, love interest or nonhuman are functions, not total identities.

### Gate 10 — Nonhuman Personhood
`ROLE LABEL / HUMAN INTERPRETATION ≠ PERSONHOOD / MOTIVE`.

For a conscious nonhuman:
`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### Gate 11 — Dialogue as Selected Action
`WANT → VERBAL/NONVERBAL TACTIC → LISTENER RESPONSE → TACTIC UPDATE → CHANGED STATE`.

Use direct dialogue when exact wording is load-bearing. Use indirect/summary for routine transfer.

### Gate 12 — Purposeful Silence
`SILENCE → possible tactic / boundary / refusal / processing`.

But:
`SILENCE / COMPLIANCE ≠ CONSENT`.

### Gate 13 — Milieu as Causal Pressure
`WORLD RULE / SOCIAL NORM → SALIENCE → AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

This is especially valuable for post-money Orbital Youth.

### Gate 14 — Believability Leak Audit
Check:
- impossible knowledge;
- unsupported skill;
- behavior/motive inconsistency without changed pressure;
- unsupported social/cultural assumption;
- source-lineage break;
- unexplained option that characters ignore.

Repair the specific leak, not the whole book.

### Gate 15 — Emotional Memory Ethical Firewall
Personal recall may be used, but is optional.

`WRITER FEELS X ≠ CHARACTER FEELS X ≠ READER FEELS X`.

## Cross-source synthesis
Swain + Card/Corbett/McKee Character:
- character needs actionable priorities and relationship-specific behavior;
- avoid one-trait reduction.

Swain + Herman/Zunshine/Oatley:
- purpose/action can be observed;
- motive remains a model requiring evidence.

Swain + LaPlante/Hodgins/Prose/Mayer:
- backstory/detail must pay in the present.

Swain + Lamott/LaPlante/Bell/Le Guin:
- generate naturally; use mechanisms to troubleshoot, not to write by numbers.

Swain + Collins/Gillett:
- personal emotion memory is optional and ethically non-mandatory.

Swain + Le Guin/Williams-Bizup/Hodgins/Clark:
- causal beats do not imply short-sentence typography.

## Anti-choppiness rule
`CHARACTER BEAT / TAG / GESTURE ≠ SENTENCE BREAK`.

Repair order:
`SCENE FUNCTION → POV/EVIDENCE → CHARACTER PURPOSE/TACTIC → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several microbeats are one perceptual/decision unit, prefer a coherent paragraph over artificial one-line beats.

## Final production law
`CHARACTER DEPTH = CAUSAL, RELATIONAL, EVIDENTIAL VARIATION UNDER PRESSURE`, not biography volume, trauma count, quirks, or slang differentiation.
