# IVDIVO CRAFT STUDY — BATCH 198
## Pullman — *The Golden Compass*: Child Agency, Information Asymmetry, Personhood, Institutional Control

**Date:** 2026-08-22  
**Status:** DRAFT / SOURCE STRICT-COMPLETE

## Core engine
`PARTIAL MODEL → CHARACTER-TRUE ACTION → CONSEQUENCE → NEW EVIDENCE → MODEL UPDATE`.

The central craft value of the novel is that a young protagonist can remain intelligent, active, funny, deceptive, mistaken, and morally consequential at the same time. Youth agency does not require adult-level knowledge.

## Gate 198-01 — Child Salience
`SAME WORLD → CHILD / ADULT DIFFERENT PRIORITY & ACCESS → DIFFERENT NOTICED DETAILS → DIFFERENT MODELS`.

Do not write children as adults with smaller bodies, nor as ignorant plot carriers.

## Gate 198-02 — Incomplete-but-Reasonable Model
A young character may infer wrongly if the model is supported by what they reasonably know. Correction must arrive through evidence/consequence.

## Gate 198-03 — Question-First Worldbuilding
`PRESENT QUESTION → MINIMUM NECESSARY WORLD RULE → ACTION / TEST → NEXT QUESTION`.

Avoid world-bible lecture.

## Gate 198-04 — Care / Control Split
An adult/institution may provide real education, safety, status, beauty, food, or opportunity while simultaneously coercing, surveilling, or manipulating.

`BENEFIT ≠ LEGITIMACY`.

## Gate 198-05 — Institutional Euphemism
For every clean term, inspect the material action beneath it:
`LABEL → PRACTICE → WHO BEARS COST → WHO CAN REFUSE → WHO CAN APPEAL`.

## Gate 198-06 — Compliance ≠ Consent
Following a charismatic adult, obeying staff, taking medicine, entering a program, or not resisting does not establish informed consent.

## Gate 198-07 — Truth Tool ≠ Understanding
Advanced information systems require:
`QUERY → OUTPUT → PROVENANCE / UNCERTAINTY → INTERPRETATION → ACTION`.

Do not use the alethiometer as a precedent for a perfect IVDIVO oracle.

## Gate 198-08 — Rumor Ecology
`EVENT → RUMOR VARIANTS → SOURCE LINEAGE → SOCIAL MODEL → CORROBORATION / CORRECTION`.

## Gate 198-09 — Distributed Youth Investigation
`OBSERVATION + PEER REPORTS + ADULT SOURCES + TOOL OUTPUT + DIRECT TEST → UPDATED MODEL`.

Do not make one child own all evidence.

## Gate 198-10 — Under-Observed Harm
Audit whose disappearance/injury receives institutional attention. Status affects visibility without changing factual importance.

## Gate 198-11 — Embodiment-Specific Personhood
`EMBODIMENT → AFFORDANCE / TABOO / INTIMACY / VULNERABILITY → SOCIAL RULE → CHOICE`.

Do not reduce nonhuman/robotic personhood to human resemblance.

## Gate 198-12 — Early True Trace / Later Reinterpretation
`TRUE TRACE → MODEL A → NEW SOURCE → MODEL B`.

Later meaning can change; earlier fact cannot be silently rewritten.

## Gate 198-13 — Identity / Status Imitation
Do not equate adoption of a dominant group's symbols/status markers with moral development or legitimate identity.

## Gate 198-14 — Mission Source Check
`WHO ACTUALLY TOLD THE PROTAGONIST THE MISSION?`

If the objective is inferred rather than stated/verified, preserve that uncertainty. Lyra's assumption that she must deliver the alethiometer is load-bearing and wrong.

## Gate 198-15 — Good Local Action / Bad Coupling
`GOOD LOCAL ACTION → DOWNSTREAM SYSTEM → UNMODELED EFFECT → MORAL / CAUSAL RECLASSIFICATION`.

Rescuing someone can still place them into a new danger if the system model is incomplete.

## Gate 198-16 — Counter-Authority Hypothesis
`DISCREDITED AUTHORITY → ALTERNATIVE HYPOTHESIS`, not `OPPOSITE FACT`.

Lyra/Pan's final inference that Dust may be good is a strong next-book question, not demonstrated truth.

## Gate 198-17 — Prophecy Firewall
Prophecy/destiny can create pressure, but must not automatically confer moral authority or erase local choice.

## Gate 198-18 — Local Arc / Saga Vector
`LOCAL ARC RESOLVED → COST / AFTERMATH → MODEL UPDATE → NEW SERIES QUESTION`.

## Cross-source convergence
- **Ender's Game:** child instrumentalization, information asymmetry, hidden real stakes, moral reclassification.
- **Nevermoor:** belonging, labels, desired but imperfect institutions.
- **Skyward:** youth competence, peer coordination, institutional narrative vs lived reality.
- **Children of Time:** nonhuman personhood and category failure.
- **Herman/Zunshine:** behavior/motive/source model separation.
- **Genette/Chatman:** information order and POV access.
- **Ephron/le Carré:** source lineage, fair reinterpretation.
- **Gillett/Collins:** present want → tactic → response → adaptation.

## Major rejected transfers
- daemons/Dust as real consciousness/soul science;
- alethiometer as a precedent for infallible epistemic technology;
- prophecy as legitimate chosen-one authority;
- child abduction/harm as default YA depth;
- religious/factional ideology as a single universal motive;
- human social/gender assumptions as psychology;
- Iorek's `armor = soul` metaphor as literal ontology;
- Iofur's human imitation as proof that cultural hybridization is corrupt;
- final `bad authorities say Dust bad → Dust good` as proof;
- fantasy action cadence as an IVDIVO syntax law.

## Production questions
1. What does the young POV actually know?
2. What are they reasonably inferring?
3. What could disconfirm the inference?
4. What adult/institutional benefit is real?
5. What information or consent is missing?
6. What euphemism hides a material consequence?
7. Which clues have independent source lines?
8. Does the protagonist's local good action create a new downstream risk?
9. Is nonhuman personhood being tested independently of human resemblance?
10. Is the final hypothesis clearly separated from corroborated fact?
