## Ch21 — retained mechanisms after Red Team

### 1. Model-Capture / Obsession Propagation
A leader or institution can turn one interpretation into a self-reinforcing action system:

`LEADER / INSTITUTION MODEL → PUBLIC COMMITMENT / STATUS / INCENTIVE → GROUP ALIGNMENT → EVIDENCE FILTER → ESCALATION`.

Useful for institutional pressure, military/scientific teams, youth cohorts, algorithmic governance and mystery organisations.

### 2. Label ≠ World Fact
`MONSTER / THREAT / TRAITOR / FAILURE / ANOMALY / SAFE / UNSAFE` are labels produced by a model.

Use:
`LABEL → SOURCE / EVIDENCE → ALTERNATIVE MODEL → STATUS UPDATE`.

Never infer personhood or moral status from institutional vocabulary alone.

### 3. Created-Agent Personhood
A created/nonhuman being must be treated as an independent agent once evidence supports personhood:

`CREATOR ACTION / REJECTION → ENTITY RESPONSE → SECOND-ORDER CONSEQUENCES`.

`CREATED AGENT ≠ CREATOR PROPERTY`.

The entity's later behaviour must be causally traced; it cannot be retroactively reduced to `it was always a monster`.

### 4. Rejection Changes Option Space
Social exclusion/rejection can alter tactics without proving inherent evil:

`REQUEST / BID FOR RELATION → REJECTION / EXCLUSION → OPTION SPACE NARROWS → NEW TACTIC / MODEL → CONSEQUENCE`.

Useful for nonhuman contact, YA belonging, institutional stigma and relationship arcs.

### 5. Progressive Independent Warnings
Repeated encounters may form a source ecology when each line is genuinely independent:

`SOURCE A → WARNING / TRACE → SOURCE B → CORROBORATION / CONTRADICTION → SOURCE C → MODEL PRESSURE`.

Do not count repeated descendants of one source as independent evidence.

### 6. Protagonist Frame ≠ World Fact
A protagonist's interpretation may organise the action while still being wrong:

`PROTAGONIST MODEL → ACTION → WORLD RESPONSE → CONTRADICTING TRACE → MODEL UPDATE OR DEEPER CAPTURE`.

### 7. Group Incentive Architecture
Commitment/oath/reward/status mechanisms can make a group rationally continue a bad model:

`MODEL → INCENTIVE / IDENTITY → BEHAVIOUR → SELECTIVE EVIDENCE → LOCK-IN`.

This supports institutional causality without requiring secret evil.
