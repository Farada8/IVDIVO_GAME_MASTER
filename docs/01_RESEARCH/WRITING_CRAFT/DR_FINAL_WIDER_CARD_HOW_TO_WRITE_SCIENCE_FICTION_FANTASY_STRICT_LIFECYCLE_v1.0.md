## Highest-value mechanisms retained

### 1. World Rule Causal Payment
`WORLD RULE / TECHNOLOGY / MAGIC LIMIT → AFFORDANCE / CONSTRAINT → SOCIAL / INSTITUTIONAL RIPPLE → PERSON-SPECIFIC CHOICE → CONSEQUENCE`.

A world rule that changes nothing downstream is lore-only. Restrictions should generate tactics, institutions, relationships, costs, and choices rather than merely decorate the setting.

### 2. Rule-Exception Integrity
Once a rule is established, a later exception cannot appear only to rescue the protagonist. An exception needs prior evidence, cost, or setup.

Failure mode: `CLIMAX_RULE_CHEAT`.

### 3. Multiple Consequences / Social Plurality
`EVENT / INNOVATION → MULTIPLE FIRST-ORDER RESPONSES → SECOND-ORDER SIDE EFFECTS → DIFFERENT AGENTS / INSTITUTIONS ADAPT`.

Do not let an entire society react as one mind.

### 4. Seed Is Not Canon
Card explicitly allows new discoveries to overturn outlines and preliminary plans.

`SEED → WORLD / CHARACTER CAUSAL TEST → LIVE DRAFT → REPLAN`.

### 5. Main Character / Protagonist / POV Separation
The principal causal agent, the person a reader roots for, and the current viewpoint owner need not be the same person.

For IVDIVO use:
`CAUSAL OWNER ≠ DECISION OWNER ≠ POV ACCESS OWNER`.

A POV shift must buy unique perception, evidence access, relationship pressure, irony, or decision ownership.

### 6. MICE as Promise Diagnostic, Not Formula
Milieu / Idea / Character / Event are useful ways to identify dominant reader promises, but not compulsory architecture.

Generalized IVDIVO diagnostic:
- milieu: entry into / navigation of a system or environment;
- idea: bounded question and proof ceiling;
- character: role / relationship / model change;
- event: disorder and a changed stable condition.

Multiple functions may coexist if they pay one dominant causal engine.

### 7. Opening–Ending Contract
`OPENING CREATES NEED / PROMISE → ENDING SATISFIES OR MEANINGFULLY REVISES IT`.

Do not open one governing story and close another.

### 8. Abeyance / Controlled Unknown Term
An unknown word or rule may remain unexplained when the text clearly signals that the reader is not expected to know it yet.

`UNKNOWN TERM → SIGNALLED GAP → CONTEXTUAL CLUES → PARTIAL MODEL → LATER PAYOFF`.

This yields productive uncertainty rather than jargon-wall confusion.

### 9. POV Fair Exposition
If a close-POV character knows information that materially changes the meaning of the current event, hiding it solely for a later surprise is usually unfair.

Cross-source firewall: Genette allows strategic withholding under a clear narrative contract; therefore Card's rule is not absolute. IVDIVO requires a justified information architecture rather than fake suspense.

### 10. Reader Model Progressive Disclosure
`JUST ENOUGH TO ORIENT → ACTION → NEW TERM / TRACE → INFERENCE → LATER CLARIFICATION`.

`PRODUCTIVE UNCERTAINTY ≠ CONFUSION`.

### 11. Diction Alignment
`WORLDVIEW + STATUS + RELATIONSHIP + REGISTER + SCENE PURPOSE → DICTION / RHYTHM`.

Reject fake archaic diction and jargon used only to prove that the world is unusual. Future-YA voice must come from future culture, not current Earth slang pasted onto orbital life.

### 12. Taboo Lexicon as Worldbuilding
`CULTURAL VALUE / TABOO → LANGUAGE AVOIDANCE / EUPHEMISM / OFFENSE → RELATION / CONSEQUENCE`.

Language can reveal what a culture treats as charged, but vocabulary remains evidence about culture, not ontology.

### 13. Technical–Social Integration
`TECHNICAL MODEL ↔ SOCIAL MODEL ↔ EMBODIMENT ↔ INSTITUTION ↔ PERSON`.

Do not make hard science detailed while society and characters are clichés; do not make social theory detailed while material affordances are vague.

Standing law reinforced: `DOMAIN A MATURITY ≠ DOMAIN B MATURITY`.

### 14. Nonhuman Causal Modeling
Useful salvage from Card's alien-design discussion:
`EMBODIMENT + ENVIRONMENT + CULTURE + HISTORY + OWN WANT / MODEL → ACTION`.

Reject the idea that a human reference character is always necessary. A nonhuman POV can stand alone if the reader can construct a causal model.

### 15. Workshop / Wise Reader Mechanics
Workshop failure modes:
- `GROUP_FAMILIARITY_BLINDNESS`
- `ABUSIVE_CLEVERNESS`
- `TIME_CONSUMPTION`
- `ONE_WRITER_DOMINANCE`
- `REWORKSHOP_CONFIRMATION`
- `GENRE_MISMATCH`

Useful feedback law remains:
`READER EFFECT = EVIDENCE; REPAIR PROPOSAL = HYPOTHESIS`.

Ask targeted questions: where confused, where attention dropped, what the reader thought was happening, what they expected next, which information felt too early/late, and which choice felt unearned.

## Important rejected / limited claims
- Genre boundaries and bookstore/market categories of 1990 are not timeless craft laws.
- Specific magazine, agent, fee, address, award, submission and professional-organization advice is historical publishing material only.
- The blanket anti-prologue claim is rejected. Use `PROLOGUE MUST PAY`, not `NO PROLOGUES`.
- Card's speculative evolutionary / alien-development examples are not current biology or psychology.
- A human reference point is not required for nonhuman personhood or POV.
- Deliberate symbolism is not forbidden; the production gate is that symbol/motif must remain load-bearing and not replace causality.
- Advice about health, dependence, discipline and lifestyle is anecdotal process material, not medical authority.

## Cross-source comparison
- Bell / Seger / Mayer / Lamott / LaPlante: Card strongly converges on `PLAN = HYPOTHESIS, NOT CANON`.
- Genette / Ephron / Zunshine: converges on POV-information fairness and reader model construction.
- Wolf / James / Weir / Herman: strengthens causal worldbuilding and rejects lore-tourism.
- Le Guin / Lodge / Zinsser / Clark: Card's clarity and exposition mechanics do not support short-sentence KPIs.
- Truby Genres: MICE/genre labels are reader-contract diagnostics, not story laws.

## Prose / choppiness conclusion
Card supplies no justification for sentence-fragment optimization. Worldbuilding, suspense and revelation operate above sentence length.

Standing router:
`BOOK ENGINE → CHAPTER FUNCTION → NARRATIVE MODE → POV / KNOWLEDGE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE CONTRAST / RHYTHM → WORDING`.

`BEAT / WORLD RULE / REVEAL ≠ SENTENCE BREAK`.
