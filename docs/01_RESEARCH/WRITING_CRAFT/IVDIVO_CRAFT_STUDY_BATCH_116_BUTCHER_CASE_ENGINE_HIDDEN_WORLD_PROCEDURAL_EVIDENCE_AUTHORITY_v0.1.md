## Production mechanisms

### B116-01 — Case Braid
`CASE A TRACE → CHANGES CASE B MODEL → CASE B ACTION / PRESSURE → REFRAMES CASE A → CONVERGENCE → SINGLE ENDGAME`.

Two mysteries do not become ONE MAIN STORY merely because the same protagonist investigates both.

### B116-02 — Hidden-World Procedural
`RULE / LIMIT → TRACE → HYPOTHESIS → TEST / INTERVIEW → MODEL UPDATE → ACTION`.

Worldbuilding earns prose space by changing investigative possibilities.

### B116-03 — Evidence-Status Firewall
`OBSERVED → REPORTED → INFERRED → HYPOTHESIS → CORROBORATED → DISPROVEN / UNKNOWN`.

POV confidence does not raise evidence status.

### B116-04 — Multi-Authority Matrix
For each authority:
`WHAT IT KNOWS → WHAT IT CAN DO → WHAT IT CAN PUNISH → WHAT IT NEEDS → WHAT IT MISREADS`.

Conflict can come from incompatible legitimate jurisdictions rather than one villain.

### B116-05 — Protective Withholding Audit
`INFORMATION WITHHELD TO PROTECT → OTHER AGENT'S MODEL DEGRADES → INDEPENDENT ACTION → TRUST / SAFETY COST`.

Use especially for mentor/youth, romance, human/robot and investigator/police relationships.

### B116-06 — Institutional Countermodel Update
`PRIOR SUSPICION → DISCONFIRMING OBSERVATION → EVIDENCE DUTY → STATUS UPDATE → PERSONAL DISLIKE MAY REMAIN`.

No forced antagonist-to-friend conversion required.

### B116-07 — Source-of-Source Provenance
Track witnesses and intermediaries explicitly rather than treating rumor as a flat clue.

### B116-08 — Mundane Causality Inside Speculative Systems
Ordinary physics, records, witnesses, material objects and procedural decisions must remain causally relevant even in a high-tech/magical world.

### B116-09 — Case Loop Variation
Repeated `clue → interview → threat → next clue` is acceptable only if each cycle changes at least one of:
- causal model;
- evidence status;
- relationship;
- authority/access;
- option set;
- cost;
- location/tactic.

### B116-10 — Local Closure / Serial Continuity
`LOCAL PROMISE → PROOF → DECISIVE ACTION → RESULT → AFTERMATH → OPTIONAL SERIES VECTOR`.

Do not call withheld local proof a sequel hook.

## Failure modes

- POV CERTAINTY AS FACT
- PROTECTIVE WITHHOLDING WITHOUT COST
- CASE LOOP MONOCULTURE
- HERO KNOWLEDGE MONOPOLY
- SPECIAL POWER AS MORAL AUTHORITY
- CARDBOARD INSTITUTION
- GENDER/STEREOTYPE AS MOTIVE EVIDENCE
- SEXUALITY AS CHARACTER SHORTCUT
- LOVE-POTION CONSENT COMEDY
- SOULGAZE / MAGIC AS IVDIVO ONTOLOGY
- MONETARY-STAKES LEAK
- ATTACK ESCALATION AS ONLY PROPULSION

## IVDIVO routing

### ROOM 917
Use Case Braid when relationship and mystery share consequences. A clue may alter Elena's trust in Julian; changed trust may alter disclosure/access. Neither trust nor attraction changes what a clue proves.

### SMITH
Use multi-authority pressure: local law, Confederation, institutional command, archival authority and affected conscious agents may hold incompatible but legitimate powers.

### Orbital Youth
Translate economic source-world pressure into nonfungible stakes; preserve reasonable mistakes from incomplete models rather than stupidity.

### Synthetic/nonhuman persons
Behavior remains evidence, not motive. Preserve independent self-report, refusal, evidence and decision ownership.

### Consciousness-practice research
All magical ontology is source-world fiction only. Keep observation/reproducibility/interpretation/ontology levels separate.

Final verdict: PERMANENT PROCEDURAL / CASE-BRAID ROUTER; NOT ETHICS, PSYCHOLOGY OR ONTOLOGY AUTHORITY.
