# IVDIVO CRAFT STUDY — BATCH 99
## Swain: Scene / Sequel / Compression / Transition / Credibility

Status: DRAFT / MANUSCRIPT-APPLICABLE
Date: 2026-08-18
Source: Dwight V. Swain, `Techniques of the Selling Writer`, Chapter 4 strict-complete in this pass.

## CORE MECHANISM
Swain's most durable contribution is not a rigid alternating template. It is a distinction between two narrative jobs:

1. `EXTERNAL ATTEMPT / PRESSURE -> CHANGED STATE`
2. `PROCESSING / REAPPRAISAL -> NEW GOAL / STRATEGY`

IVDIVO scene router:

`PRIOR CONSEQUENCE -> OWNER -> PRESENT WANT -> MODE -> PRESSURE / SUPPORT -> OUTCOME -> ACTION/KNOWLEDGE/RELATIONSHIP STATE CHANGE -> PROCESSING NEED -> NEXT STRATEGY -> NEXT CAUSAL LINK`.

## PRODUCTION GATES

### B99-G01 — Mode Before Prose
Before line edit, decide whether material deserves:
- full real-time scene;
- compressed processing/sequel;
- indirect dialogue;
- summary;
- embedded reaction beat;
- omission with consequence shown later.

### B99-G02 — Time/Topic Unity
Real-time confrontation is usually unified by continuous time. Processing may compress large time/space jumps if one current problem or question unifies it.

### B99-G03 — Sequel Compression
Do not dramatize every walk, meal, waiting period, message check or repeated technical procedure while a character thinks.

Keep only material that changes:
- interpretation;
- relationship;
- evidence status;
- option set;
- commitment;
- strategy.

### B99-G04 — Decision Earns Next Goal
A processing unit must either produce a changed strategy/commitment or intentionally preserve paralysis at a cost. Mere recap is not enough.

### B99-G05 — No Mandatory Disaster
Do not force a negative ending to every scene. Legitimate outcomes include:
- failure;
- partial success;
- costly success;
- clean success;
- success that increases responsibility;
- correct restraint;
- new evidence that changes the problem.

### B99-G06 — Success Escalation
Preferred YA/competence pattern when appropriate:
`COMPETENT ACTION -> REAL SUCCESS -> INCREASED TRUST/ACCESS/RESPONSIBILITY -> HARDER NEXT CHOICE`.

### B99-G07 — Quiet-State Change
Absence of overt conflict is not automatic failure. A quiet unit may remain a full scene if it materially changes trust, intimacy, consent, identity, knowledge, obligation or future choice.

### B99-G08 — Processing Placement
After an intense outcome choose intentionally among:
- immediate processing;
- delayed processing;
- processing embedded in ongoing action;
- implied processing revealed by changed behavior.

### B99-G09 — Credibility of Strategy Shift
Before a character adopts a new plan, ask what minimum emotional/epistemic bridge the reader needs to believe that decision.

### B99-G10 — Anti-Rumination
If processing repeats the same interpretation without new option, evidence, relation or commitment, compress/merge/delete.

### B99-G11 — Anti-Microdramatization
Pattern at risk:
`open door -> glance -> microthought -> line -> microreaction -> walk on`.

First test whether the whole process deserves a scene. Do not repair structurally unnecessary dramatization by merely lengthening sentences.

### B99-G12 — Conscious Robot Processing
Do not anthropomorphically force every conscious robot through stock human emotional sequencing.

Require its own:
`PERCEPTION / MODEL -> VALUE OR OBLIGATION CONFLICT -> CONSENT/REFUSAL -> STRATEGY -> CONSEQUENCE`.

### B99-G13 — Evidence Firewall
Processing by a POV character or specialist school can change that character's model; it cannot by itself change an interpretation into a world fact.

### B99-G14 — One Main Story
A processing unit earns length when the resulting commitment changes the dominant causal engine. If not, it is a strong compression candidate.

## FAILURE MODES
- SCENE/SEQUEL METRONOME — alternating full action and full reflection mechanically.
- DISASTER MONOCULTURE — every scene ends badly regardless of causal truth.
- RUMINATION LOOP — reaction restates reaction without option/model change.
- MICRODRAMATIZATION — routine process exploded into tiny beats.
- SUMMARY PHOBIA — belief that all important material must be shown moment by moment.
- SUCCESS SABOTAGE — competent success artificially converted into setback.
- QUIET-SCENE PURGE — deleting meaningful relationship/evidence processing because nobody argues.
- ROBOT HUMANIZATION TEMPLATE — proving personhood through stock human emotion display.
- DECISION TELEPORT — new plan appears without enough processing/evidence to be credible.
- AFTERMATH OVEREXPLANATION — action already proves the change, then narration explains it again.

## CROSS-SOURCE COMPARISON
Swain's strict Chapter 4 is best used with later corrections:
- Rosenfeld: intention/result/next intention and scene endings;
- LaPlante: scene vs narration is functional, not hierarchy;
- Lodge / Prose: prose rhythm and narration may intentionally slow or compress;
- Bell: action/reaction can be embedded and need not ping-pong;
- Herman / Zunshine: character interpretation and causal story are not verified fact;
- Corbett / Card: reactions must remain character- and relationship-specific.

## IVDIVO APPLICATION
For Orbital Youth / B07 / future books, technical middle sections should not default to:
`anomaly -> briefing -> explanation -> anomaly -> briefing`.

Instead rotate causal work:
`action -> consequence -> processing -> relationship/evidence shift -> revised strategy -> different kind of action`.

For post-money life, ordinary low-conflict scenes can be valuable when they prove normal social mechanics through action rather than exposition.

For rare consciousness schools, a processing scene may legitimately show a practitioner changing interpretation, but must preserve:
`OBSERVATION -> REPRODUCIBLE EFFECT -> SCHOOL INTERPRETATION -> COMPETING INTERPRETATION -> POSSIBLE ONTOLOGICAL CLAIM`.

## STYLE / ANTI-CHOP APPLICATION
New combined router:

`ONE MAIN STORY / CAUSALITY -> SCENE NECESSITY -> ORDER/DURATION/FREQUENCY -> MODE (SCENE/SUMMARY/INDIRECT) -> POV -> DIALOGUE MODE -> PARAGRAPH INTENT -> READER-STATE CONTINUITY -> SENTENCE RHYTHM -> WORDING`.

Shortness is never the first repair target.
