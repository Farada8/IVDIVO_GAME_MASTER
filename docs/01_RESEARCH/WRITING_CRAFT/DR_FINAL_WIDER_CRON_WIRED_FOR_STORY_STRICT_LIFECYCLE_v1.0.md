## Source authority / limits
### High craft value
- Reader model / character model separation.
- Goal as interpretation yardstick.
- Specificity and causal relevance.
- Setup → pattern → payoff.
- Fair reveal: hints must exist and remain literally true.
- Scene-to-scene causal consequence.
- Who-knows-what-when mapping.
- Revision as layered discovery rather than first-draft perfection.

### Low / conditional authority
Do **not** import as universal IVDIVO laws:
- “brain is wired for story” as a precise scientific model;
- mirror-neuron explanations for reader empathy;
- dopamine / neurotransmitter rhetoric as direct craft causation;
- universal survival/evolution explanation of fiction;
- one protagonist / one head per scene as universal architecture;
- every story requiring an inner issue, fear, flaw, or corrective transformation;
- conflict as the only engine of movement;
- every remedy making the situation worse;
- “everything that can go wrong must go wrong”;
- ticking clock as a default;
- secrets always needing exposure;
- body language as infallible motive evidence;
- protagonist always needing to confront “demons”;
- every sensory detail requiring a direct later payoff;
- narrator neutrality/invisibility as a general law.

These are retained only when cross-source evidence supports the underlying function.

## Retained mechanisms

### M1 — Event → Appraisal → Choice
`WORLD EVENT / TRACE → POV SIGNIFICANCE / APPRAISAL → GOAL / MODEL → RESPONSE / TACTIC → CHANGED STATE`.

An event is not dramatic merely because it is objectively large. It must acquire significance for a particular agent.

### M2 — Goal as a Reader Yardstick
`PRESENT WANT / RESPONSIBILITY → OPTIONS → CHOICE → PROGRESS / COST`.

The goal lets the reader evaluate whether a new fact helps, hurts, complicates or redefines the operative problem.

Firewall: the protagonist need not have one hidden “true” goal or one psychological deficiency.

### M3 — Reader Model vs Character Model
Maintain separately:
- `WORLD FACT`
- `WHAT POV KNOWS`
- `WHAT POV BELIEVES`
- `WHAT OTHER CHARACTERS BELIEVE`
- `WHAT READER CURRENTLY BELIEVES`

Useful production artifact:
`WHO KNOWS WHAT, WHEN?`

### M4 — Fair Reveal Pattern
`TRUE HINT / TRACE → PLAUSIBLE MODEL A → ADDITIONAL TRUE HINTS → REVEAL / MODEL B → RETROSPECTIVE COHERENCE`.

A reveal may transform interpretation; it may not invent an absent subplot or retroactively falsify literal prior evidence.

### M5 — Causal Payment
`DECISION / ACTION → WORLD RESPONSE → PROCESSING → NEW DECISION / STRATEGY`.

A scene must create a downstream dependency. If removing it changes nothing that follows, test `MERGE / SUMMARY / DELETE / REBUILD`.

Firewall: “downstream change” can be epistemic, relational, consent-based, institutional or emotional, not only external conflict.

### M6 — Setup Expectation Debt
Any salient setup creates a reader expectation:
`SETUP → PATTERN / TELL → PAYOFF OR EXPLICIT DISCONFIRMATION`.

An accidental “special ops background,” unexplained unusual skill, striking object, or specific warning can redirect the reader into a different imagined book.

### M7 — Context Before Vague Mystery
`CLEAR QUESTION + PARTIAL SPECIFICS + PLAUSIBLE ALTERNATIVES = PRODUCTIVE UNCERTAINTY`.

`VAGUE SECRET + NO SPECIFICS = CONFUSION / LOW ENGAGEMENT`.

### M8 — Specificity Is Selective
`POV + WANT + KNOWLEDGE + RELATIONSHIP → SALIENCE → SPECIFIC DETAIL → READER INFERENCE`.

Specificity does not mean sensory checklist or maximal detail density.

### M9 — Backstory Must Pay in Present
`PAST FACT / MEMORY → PRESENT INTERPRETATION / TACTIC / RELATION / EVIDENCE CHANGE`.

If past information does not change the present, compress, bank or cut.

Firewall: no single childhood event is allowed to deterministically explain the whole person.

### M10 — Show/Tell Reframed
Useful Cron salvage:
`DO NOT REPORT A CONCLUSION WHEN THE CAUSAL PROCESS ITSELF IS THE LOAD-BEARING MATERIAL`.

But:
- full scene is not universally superior;
- summary, indirect dialogue, narration and ellipsis are legitimate;
- a visual cue is not automatically stronger than a clear causal sentence.

### M11 — Subplot Causal Payment
`SUBPLOT LOCAL CHANGE → NEW INFORMATION / RELATION / OPTION → MAIN ENGINE EFFECT → PAYOFF`.

A subplot may provide pacing contrast, but “breathing room” alone is insufficient if it never alters the governing story.

### M12 — Pacing by Contrast
Continuous high conflict normalizes itself and loses force.

Working law:
`PRESSURE → PROCESSING / ANTICIPATION / OTHER FUNCTION → RENEWED PRESSURE`.

Firewall: no mandatory conflict rhythm; quiet scenes can progress through knowledge, consent, trust, responsibility or decision.

### M13 — Knowledge-State Revision
`ACTUAL WORLD → CHARACTER MODEL → READER MODEL → NEW EVIDENCE → MODEL UPDATE`.

This directly supports mystery, institutional stories, YA learning and nonhuman-personhood plots.

### M14 — First Draft Is Diagnostic Material
`DRAFT → DISTANCE → ACTUAL-TEXT READ → DEFECT LEVEL → REVISION → RETEST`.

Do not demand perfection while generating; do not confuse author certainty with manuscript legibility.

### M15 — Feedback Without Repair Capture
Ask readers what they thought was happening, what they expected, where they were confused, and what they believed characters knew.

`READER EFFECT = EVIDENCE; REPAIR PROPOSAL = HYPOTHESIS`.

## Failure modes
1. **Inner-Issue Monoculture** — every protagonist must be “wrong inside.”
2. **Conflict Monoculture** — every meaningful scene must contain escalating opposition.
3. **Everything-Gets-Worse Machine** — genuine success is forbidden.
4. **Ticking-Clock Reflex** — deadline added when the actual problem is weak causal movement.
5. **Body-Language Certainty** — gesture treated as motive proof.
6. **Reveal-by-Omission** — writer withholds information the POV already knows solely for surprise.
7. **Vague-Secret Hook** — reader knows a secret exists but has no usable particulars.
8. **Sensory Checklist Specificity** — smell/taste/touch added without salience.
9. **Chekhov-Gun Absolutism** — every lived-reality detail forced into later plot payoff.
10. **Single-Root-Psychology** — one childhood wound explains the person.
11. **Theme Sermon** — all story evidence arranged to prove one proposition without a competent countermodel.
12. **Science-to-Story-Law Leap** — 2012 popular neuroscience treated as settled craft science.
13. **Microgesture Confetti** — internal significance translated into gesture after every line.
14. **Choppy Causal Notation** — `action. reaction. thought. decision.` mistaken for causal prose.
15. **Narrator-Invisibility Absolutism** — authorial/narratorial presence treated as inherently defective.
16. **One-Head Absolutism** — multi-POV rejected without testing actual switching value/cost.
17. **Subplot-as-Break Only** — side material does not pay back into main engine.
18. **Setup Pollution** — vivid detail or capability creates reader expectations the actual story never services.

## Cross-source comparison
### Converges strongly with
- **Zunshine / Herman / Oatley:** character-model and reader-model distinction; behavior does not equal motive.
- **Genette / Chatman / Fludernik:** information access, discourse placement and reader model must be separated from world fact.
- **Ephron / le Carré:** fair clues, source logic, independent corroboration, no authorial cheating.
- **Bell / Bickham / Swain / Scofield:** causal changed state and downstream dependency.
- **LaPlante / Rosenfeld / Hodgins / Le Guin:** scene and summary are different tools; causal relevance before line polish.
- **Williams/Bizup / Le Guin / Clark:** reader-state continuity precedes sentence-level rhythm fixes.

### Corrected by
- **Scofield / LaPlante / Hodgins / Ribó:** quiet/non-conflict scenes can create meaningful change.
- **Le Guin / Prose / Lodge / Clark:** “show, don’t tell” and short-syntax maxims are not universal.
- **Card / Corbett / McKee Character / Herman:** character depth does not require one hidden wound/inner flaw.
- **Genette / Kress / multi-POV craft:** one POV per entire work or one dominant head is a design choice, not a universal rule.
- **Zunshine / Herman:** body language and self-report create motive hypotheses, not privileged access to truth.
- **current science discipline:** popular-neuroscience claims require independent contemporary verification.

## IVDIVO operationalization

### G1 — Reader/Character/World State Matrix
For every load-bearing scene track:
`WORLD FACT | POV KNOWLEDGE | POV BELIEF | READER BELIEF | NEW TRACE | EXIT MODEL`.

### G2 — Causal Scene Test
`Because this scene occurred, ______ is now different, and later scene ______ depends on it.`

If blank: merge / summary / delete / rebuild test.

### G3 — Genuine Success Allowed
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Reject Cron’s universal “every fix makes things worse.”

### G4 — Reveal Fairness
No late reveal unless:
- literal prior trace remains true;
- reader had reason to suspect a gap;
- new evidence distinguishes models;
- POV fairness is preserved.

### G5 — Motive Evidence Firewall
`GESTURE / PAUSE / BODY LANGUAGE / SELF-REPORT → HYPOTHESIS`, not fact.

### G6 — Specificity Without Detail Tax
A detail earns space through POV salience, lived reality, causal use, relationship meaning, evidence, rhythm or atmosphere. It need not become a later plot device.

### G7 — Subplot Payment
Every major subplot must change the A-story, a major later choice, relationship/consent terms, evidence state or responsibility.

### G8 — Processing Mode Router
After an outcome, processing may be:
- immediate scene;
- embedded thought;
- delayed;
- summarized;
- visible later through changed behavior.

No mandatory microreaction paragraph.

### G9 — Anti-Choppiness Router
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → NARRATIVE MODE → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE CONTRAST/RHYTHM → WORDING`.

`BEAT / APPRAISAL / DECISION ≠ SENTENCE BREAK`.

### G10 — Science Firewall
Any neuroscience/psychology claim used as world fact or human universal requires current independent evidence. The craft mechanism may be retained without accepting the scientific explanation.

## Manuscript validation

### LESSON ZERO Book One
**Verdict: DEVELOPMENT LOCK REMAINS.**

Cron does not provide new manuscript-specific evidence requiring a global rewrite.

Allowed surgical checks only if current reader/audio evidence points to:
- vague story question / reader confusion;
- POV character knows something the narration unfairly hides;
- scene has no downstream state change;
- setup creates an unpaid expectation;
- character choice lacks legible causal bridge;
- repetitive technical process should be summary;
- paragraph fragmentation breaks reader-state continuity.

Standing law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

### Orbital Youth
Protect:
- competent youth may succeed;
- success may increase responsibility;
- no compulsory wound/inner-flaw architecture;
- post-money stakes remain trust, consent, privacy, role, access, time, mastery, belonging, relationship, unique opportunity;
- new technology must change affordances/constraints and downstream choices.

### ROOM 917
Use:
`WORLD FACT → TRACE / SOURCE → ELENA/JULIAN ACCESS → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING TEST → CORROBORATION STATUS → ACTION`.

Absolute firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION / BODY LANGUAGE ≠ CORROBORATION`.

### B07 / nonhuman personhood
Human reaction is not personhood evidence.

`INDEPENDENT PERSONHOOD EVIDENCE → ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## Final synthesis
Cron is valuable when read as a **reader-model and causal-coherence diagnostic**, not as a neuroscience-backed universal story formula.

Highest-value retained laws:
- `EVENT → APPRAISAL → MODEL/GOAL → CHOICE → CHANGED STATE`.
- `WORLD FACT ≠ POV MODEL ≠ READER MODEL`.
- `TRUE HINTS → PLAUSIBLE MODEL → FAIR REVEAL`.
- `SETUP CREATES EXPECTATION DEBT`.
- `SUBPLOT MUST PAY INTO THE MAIN ENGINE`.
- `SPECIFICITY IS SELECTIVE, NOT DENSITY`.
- `BACKGROUND MUST PAY IN THE PRESENT`.
- `READER EFFECT = EVIDENCE; REPAIR = HYPOTHESIS`.

Highest-value rejected simplifications:
- conflict is the only movement;
- every solution must worsen the situation;
- every hero needs a wound/inner flaw;
- body language does not lie;
- every detail needs plot payoff;
- one-head architecture is universal;
- popular neuroscience is settled science;
- suspense implies choppy syntax.
