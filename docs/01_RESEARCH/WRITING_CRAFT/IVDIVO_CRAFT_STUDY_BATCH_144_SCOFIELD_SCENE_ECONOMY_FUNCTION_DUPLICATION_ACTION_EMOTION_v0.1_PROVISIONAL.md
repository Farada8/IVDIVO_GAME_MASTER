## 1. Source progress in this pass

Fresh same-file retrieval reconfirms the complete 14-chapter spine and exposes Scofield's later self-evaluation material in detail.

The evaluation layer asks, before polishing a scene:

- what the scene's event is;
- what emotion is connected to it;
- whether the event deserves a full scene or could be summarized;
- what function the scene performs;
- whether the scene enters too early;
- whether it could be integrated into another scene;
- whether it repeats already explored actions/behaviors;
- whether it arises from what came before and leads to what follows.

It also proposes captioning scene function and comparing action beats with emotion/response beats around a focal turn.

This gives IVDIVO a distinct higher-order revision mechanism beyond Batch 143's `ACTION IS NOT EVENT`.

## 2. Primary mechanism — SCENE ADMISSION BEFORE PROSE REVISION

Do not spend expensive prose-revision time until the scene has earned admission.

Operational sequence:

`SCENE CANDIDATE → FUNCTION CAPTION → UNIQUE CHANGED STATE → CAUSAL POSITION → READER-TIME VALUE → KEEP / MERGE / SUMMARY / DELETE / REBUILD → ONLY THEN PROSE REVISION`

This creates a hard firewall against polishing structurally redundant material.

### B144-G01 — REVISION ADMISSION GATE

Before line edit, answer:

1. What is the scene's event?
2. What is its primary function?
3. What is different at the exit?
4. What later scene depends on that difference?
5. Could the same function/outcome be carried by summary or an adjacent scene?
6. Can the scene begin later?
7. Is the exact real-time unfolding itself important?

If the scene fails 2–4, line editing is prohibited until structure is repaired.

## 3. Function Caption + Exit-State Audit

Scofield explicitly recommends giving a scene a short functional caption such as Information, Confrontation, Decision, Revelation, Recognition, Catalyst, Reflection, Turning Point, Capitulation, Resolution.

IVDIVO extends this list for current projects:

- INFORMATION
- EVIDENCE STATUS
- SOURCE PROVENANCE
- DECISION
- REVELATION
- RECOGNITION
- RELATIONSHIP TURN
- CONSENT / BOUNDARY CHANGE
- AUTHORITY / ACCESS CHANGE
- PERSONHOOD THRESHOLD
- MODEL REVISION
- CONSEQUENCE
- REFLECTION / PROCESSING
- CATALYST
- LOCAL RESOLUTION

Represent every candidate scene as:

`FUNCTION CAPTION + EXIT STATE`.

### B144-G02 — FUNCTION DUPLICATION AUDIT

For adjacent or nearby scenes, compare:

`FUNCTION A + EXIT STATE A`

against

`FUNCTION B + EXIT STATE B`.

If both scenes perform substantially the same function and leave substantially the same state, test:

`MERGE / COMPRESS / DELETE`.

Two individually good scenes can still be structurally redundant.

## 4. Reader-Time Economy

A full scene is expensive: it asks the reader to inhabit exact time, exact ordering, exact dialogue and exact physical behavior.

Therefore:

`MORE REAL-TIME DETAIL → GREATER FUNCTIONAL DEBT`.

### B144-G03 — READER-TIME BUDGET

Use full real-time scene when exact unfolding changes:

- evidence or source provenance;
- consent or relationship terms;
- authority/access;
- decision ownership;
- personhood status;
- strategy/model;
- a nonfungible emotional/relational commitment;
- future option space.

Prefer summary / indirect / embedded scene when material is primarily:

- repeated process;
- logistics;
- known setup;
- travel;
- routine interface work;
- repeated briefing;
- information whose exact wording does not matter.

This is not an anti-scene rule. It is a reader-time allocation rule.

## 5. Action/Emotion Coupling Without Metronomic Prose

Scofield's evaluation method places action beats and emotional-response beats side by side and asks the writer to link them causally around a focal point.

IVDIVO operationalization:

`ACTION / INFORMATION BEAT ↔ POV RESPONSE / RELATION / MODEL BEAT → FOCAL TURN → DOWNSTREAM CONSEQUENCE`.

But this must **not** become:

`action. emotion. gesture. thought. next action.`

### B144-G04 — COUPLING LEVEL TEST

Coupling may occur at:

- sentence level;
- paragraph level;
- scene level;
- delayed later-scene level.

Use the smallest level needed for clarity, not the smallest possible unit.

If several microbeats form one perceptual/decision unit, preserve coherent paragraph movement.

---

## 6. Focal Turn ≠ Mandatory Twist

Scofield's focal-point logic is useful, but IVDIVO does not convert it into a compulsory twist/cliffhanger.

A scene turn may be:

- evidence changes status;
- consent is granted or withdrawn;
- trust changes;
- a character accepts responsibility;
- an institution's authority becomes contestable;
- a model is revised;
- a relationship acquires new terms;
- a personhood threshold is crossed;
- an apparently minor success changes future obligations.

### B144-G05 — TURN FUNCTION

`TURN = MATERIAL CHANGE IN HOW THE SCENE'S PROBLEM CAN NOW BE UNDERSTOOD OR ACTED UPON.`

Loudness is irrelevant.

## 8. Anti-choppy prose integration

Updated diagnostic order:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE FUNCTION + EXIT STATE → SCENE WEIGHT / MODE → ORDER / DURATION / FREQUENCY → POV / EVIDENCE → ACTION-RESPONSE COUPLING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

This prevents two common false repairs:

1. polishing a scene that should be summarized or merged;
2. adding a separate reaction line after every action to make causality "clear".

## 10. Failure modes

1. **LINE-EDIT BEFORE ADMISSION** — polishing before deciding whether scene belongs.
2. **BEAUTIFUL REDUNDANT SCENE** — strong prose, duplicate structural job.
3. **FUNCTION DUPLICATION** — adjacent scenes carry the same function and exit state.
4. **SCENE ECONOMY BLINDNESS** — failure to ask whether summary/merge would preserve all value.
5. **ENTER-TOO-EARLY** — real-time starts before consequential material.
6. **SUMMARY PHOBIA** — process is dramatized because summary is wrongly treated as inferior.
7. **READER-TIME WASTE** — exact unfolding consumes pages without state change.
8. **ACTION/EMOTION METRONOME** — every action receives a separate reaction sentence.
9. **TURN-AS-TWIST MANDATE** — focal change is forced into a surprise/cliffhanger.
10. **EVALUATION CHECKLIST OVERLOAD** — every Scofield criterion applied simultaneously rather than routing by diagnosed defect.
