## Highest-value mechanisms retained

### 1. Generation / Evaluation Separation
Vorhaus's “ferocious editor” is useful when converted into a stage firewall:
`GENERATE / RISK → MATERIAL EXISTS → EVALUATE → REWRITE`.

The “rule of nine” is explicitly a useful fiction rather than an empirical success rate. Use it only to lower generation pressure.

### 2. Comic Premise as Model Gap
Useful generalization:
`CHARACTER / AUDIENCE MODEL A ↔ OBSERVED REALITY / MODEL B → GAP → COMIC OR IRONIC EFFECT`.

Comedy may arise from incompatible models, expectations, social rules, or registers. Do not confuse the character's comic perspective with world fact.

### 3. Character-Owned Comic Perspective
`WORLDVIEW + ATTENTION + RELATIONSHIP + CURRENT WANT → CHARACTER-SPECIFIC COMIC LENS`.

This is stronger than generic authorial wit. Humor should emerge differently from different characters.

### 4. Classification as Tool, Not Law
Vorhaus himself warns that categories can clarify material but become destructive when treated as pigeonholes.

`DEFECT / CREATIVE QUESTION → RELEVANT CATEGORY / TOOL → GENERATE OPTIONS → KEEP / DISCARD TOOL`.

### 5. Clash of Context / Inappropriate Response
`EXPECTED CONTEXT / RESPONSE → INCOMPATIBLE BUT CHARACTER-TRUE CONTEXT / RESPONSE → READER MODEL SHIFT`.

Use for idea generation and character contrast, not as a mandate to maximize absurdity.

### 6. Comic Opposites as Competing Models
Retain as:
`MODEL / VALUE A ↔ MODEL / VALUE B → RELATIONSHIP-SPECIFIC TACTICS → CONSEQUENCE`.

Reject the idea that every strong relationship must be diametric opposition.

### 7. Tension / Release and Payoff Placement
Setup must provide enough shared information for the audience to build an expectation. Payoff should arrive after required setup and often benefits from end-weight.

`SETUP → EXPECTATION → PAYOFF / REVISION`.

### 8. Rule of Three — Optional Pattern
Vorhaus himself notes it can feel forced.

Use only as one option for `SETUP → VALIDATION → VIOLATION`, never as a required rhythm or sentence pattern.

### 9. Jokoid / Placeholder Drafting
A temporary bad joke can mark intended function in a discovery draft.

`PLACEHOLDER FUNCTION → REWRITE / REPLACE / CUT`.

`PLACEHOLDER ≠ FINAL QUALITY ≠ CANONIC WORDING`.

### 10. Running Gag Must Develop
Repetition remains alive when source, circumstance, stakes, meaning, or relationship changes.

`REPEAT → NEW CONTEXT / SOURCE / COST / MEANING`.

Pure repeat without new function decays.

### 11. Callback
Earlier detail may return with additional meaning or closure.

`EARLY LOAD-BEARING ITEM → LATER CONTEXT CHANGE → CALLBACK / PAYOFF`.

### 12. Micropressure Mirrors Macro Question
Vorhaus calls this microconflict / macroconflict. IVDIVO broadens it beyond overt conflict:
`MACRO QUESTION / VALUE PRESSURE → LOCAL INTERACTION / JOKE / DISAGREEMENT / CHOICE ECHOES OR TESTS IT`.

### 13. Language Ornament Is Late-Stage
Alliteration, rhyme, funny words, puns and ear-tickles cannot rescue a bad joke or scene and should not obscure meaning.

`STRUCTURE / CHARACTER / FUNCTION FIRST → LANGUAGE ORNAMENT LAST`.

### 14. Detail Must Pay
Specific detail can improve vividness and character, but excessive arch detail pulls attention away from story.

`DETAIL → POV / CHARACTER / COMIC / CAUSAL FUNCTION → KEEP`; otherwise compress.

### 15. Eyebrow Effect / Coupled Escalation
A solution generates a larger problem, whose solution generates the next problem.

`LOCAL FIX → UNINTENDED CONSEQUENCE → NEW FIX → GREATER COUPLING / COST`.

This aligns strongly with Weir-style systems causality.

### 16. Three-Dimensional Joke
Useful generalization:
`STORY STATE FUNCTION + CHARACTER / THEME STANCE + HUMOR FUNCTION`.

Do not treat the “truth” component as world fact. It may be viewpoint, attitude, cultural model or irony.

### 17. Audience Shared-Ground Contract
Humor requires enough shared reference to decode the intended gap.

`CUE → SHARED GROUND → EXPECTATION / ALTERNATIVE MEANING → PAYOFF`.

If decoding requires obscure background unavailable to the audience, the joke fails as communication.

### 18. Sitcom Arc of Stability — Optional Diagnostic
`OLD STABILITY → INSTABILITY → NEW STABILITY` can diagnose changed relational/social terms, but episodic reset is format-specific and not a novel law.

### 19. A/B Story Payment
Secondary comic strands are strongest when they comment on, complicate, or causally affect the main story.

`B-STORY CHANGE → A-STORY CONSEQUENCE / REFRAME / PAYOFF`.

### 20. Plot Logic + Character Logic
A move must both advance the story and remain credible to the acting character.

`PLOT NEED ∩ CHARACTER WANT / MODEL = ACTION`.

### 21. Mining / Refining
`MINE / GENERATE → DISTANCE → REFINE / REWRITE`.

Writing extra material can be useful in discovery, but fixed overproduction ratios are not rules.

### 22. Beta Reader Contract
`READER EFFECT = EVIDENCE; REPAIR PROPOSAL = HYPOTHESIS`.

Use specific questions and multiple readers until marginal information value declines.

### 23. Character Key
A small action can efficiently establish a working reader model of a character, but one action does not prove essence.

`SMALL BEHAVIOR → TRAIT / MODEL HYPOTHESIS → LATER CONFIRMATION / REVISION`.

### 24. Comic Vocabulary / Idea Bank
Unused jokes, phrases, reversals and premises may be banked without forcing them into the current book.

`GOOD IDEA ≠ CURRENT STORY OBLIGATION`.

### 25. Problem Sets
Break a vague creative problem into explicit constraints and subquestions. Use this as a generation method, not as proof that creativity is mechanical.

## Major claims rejected / limited
- `COMEDY = TRUTH + PAIN` is a useful lens, not a universal definition.
- `MORE JEOPARDY = MORE COMEDY` is rejected as a universal law; do not escalate automatically to trauma, violence, death or family harm.
- `STORY DYNAMIC > LOGIC` is rejected. IVDIVO requires dynamic choices to remain credible under established causal/world rules.
- `EXAGGERATION CAN NEVER BE TOO MUCH` is rejected.
- Physical difference, disability, body shape, speech difficulty, age, gender, ethnicity or nonhuman embodiment are not inherently comic flaws.
- `INNER CONFLICT IS ALWAYS RICHEST`, `COMEDY REQUIRES CONFLICT`, mandatory “hero hits bottom”, “risks all”, happy ending, double win, displaced loyalty, and love-as-inner-need are not production laws.
- Fixed sitcom act-break / commercial structure, spec-script market advice and 1994 show targets are historical/format-specific.
- Fixed sketch nine-step escalation is diagnostic only.
- `WRITE 50% EXTRA THEN CUT 50%` is not a production law.
- `TALENT + DRIVE + TIME = SUCCESS` is motivational rhetoric, not a guarantee.
- Pop-psychology claims about self-image, fear, confidence and audience universals are not psychological science.

## Cross-source comparison
- Lamott / LaPlante / Bell / Swain: strong convergence on separating generation from evaluation.
- Booth / Zirker-Winter-Froemel: shared-ground and interpretation mechanics sharpen humor/irony decoding.
- Williams-Bizup / Le Guin / Clark: language ornament and short-form beats must not destroy reader-state continuity.
- Truby / Bickham / Scofield: story logic and changed-state causality remain above comic formulas.
- Weir / Herman: eyebrow escalation is strongest when modeled as real system coupling, not arbitrary “make it worse”.
- Vorhaus conflicts with IVDIVO when he recommends choosing outrageous dynamics over logic; causal integrity wins.
