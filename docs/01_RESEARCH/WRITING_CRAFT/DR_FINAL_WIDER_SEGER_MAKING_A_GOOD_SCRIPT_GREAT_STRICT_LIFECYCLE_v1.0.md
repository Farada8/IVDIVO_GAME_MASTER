## 5. CLAIM EXTRACTION — DURABLE CLAIMS

1. Structural problems should be diagnosed before dialogue/line polish.
2. A structural transition is meaningful because it changes the story state, not because it occurs at a prescribed page.
3. A subplot earns its weight by affecting the main story and/or major decisions.
4. Momentum is created by causal connection and consequential progression, not merely physical speed.
5. Important events need not all be dramatized in real time; consequences can carry offscreen/summary material.
6. Fair surprise may change interpretation but should not invalidate explicitly established fact without support.
7. POV controls information access and emotional alignment.
8. Scene sequences can carry local structure that individual scenes do not each need to duplicate.
9. Exposition works better when owned by a story need, character need, image, action, or consequential dialogue.
10. Scene entry and exit should be governed by required orientation and changed state.
11. Repetition/motif/setup-payoff create unity when recurrence develops meaning.
12. Major revisions require backward/forward regression checks.
13. A character's present motivation, objective and choices/actions form a practical causal spine.
14. Character values/philosophy are more convincing when visible through decisions and behavior than lectures.
15. Conflict can be internal, interpersonal, social, situational, transcendent, or group-based.
16. Conflict may resolve through reframing, negotiation, recognition or changed terms, not only defeat/violence.
17. Major characters benefit from multidimensionality and relationship-specific expression.
18. Character change may be internal, external, relational or absent; Seger herself acknowledges that not every film requires a transformation arc.
19. Cast design should control reader/viewer attention and prevent redundant function.
20. Planning systems should remain flexible; the living draft may require reorganization.

## 6. MECHANISM EXTRACTION

### M1 — Functional Transition
`PRIOR STATE → EVENT / REVELATION / DECISION → MATERIAL STATE CHANGE → NEW GOVERNING PROBLEM / STRATEGY`

### M2 — Midpoint Re-weighting
`CURRENT MODEL → MIDPOINT EVENT/KNOWLEDGE/RELATION CHANGE → PRIORITIES/STAKES/FOCUS RE-WEIGHTED → NEW SECOND-HALF STRATEGY`

### M3 — Subplot Causal Payment
`LOCAL WANT → LOCAL CHANGE → EFFECT ON A-STORY / MAJOR LATER CHOICE → PAYOFF`

### M4 — Thread vs Subplot
Recurring presence can be a thread without carrying an independent causal arc.

### M5 — Momentum
`MOMENTUM = CAUSAL STATE CHANGE + PRESSURE ON THE NEXT OPTION`

### M6 — Offscreen / Implicit Event
`OFFSCREEN EVENT / SUMMARY → VISIBLE CONSEQUENCE → NEXT ACTION`

### M7 — Fair Surprise
`TRUE TRACE → MODEL A → NEW CONTEXT/EVIDENCE → MODEL B → RETROSPECTIVE SUPPORT`

### M8 — Scene Sequence
`SEQUENCE QUESTION → LINKED STATE CHANGES → SEQUENCE PAYOFF`

### M9 — POV Access Budget
`POV SWITCH → UNIQUE KNOWLEDGE / ACTION / RELATION / IRONY / CONSEQUENCE → MODEL OR DECISION CHANGE`

### M10 — Flashback Present-Consequence
`PAST MATERIAL → PRESENT INTERPRETATION / EVIDENCE / RELATION / DECISION CHANGES`

### M11 — Scene Entry / Exit
`EXIT TARGET → MINIMUM ORIENTATION REQUIRED → LATEST VIABLE ENTRY → CAUSAL DEVELOPMENT → EXIT AFTER RELEVANT CHANGE`

### M12 — Exposition Ownership
`WHO NEEDS/WANTS X? → WHY NOW? → SOURCE/ACCESS → MINIMUM NECESSARY INFO → ACTION/INTERPRETATION/DECISION → CHANGED STATE`

### M13 — Developing Repetition
`ELEMENT RETURNS → CONTEXT / FUNCTION / MEANING CHANGES`

### M14 — Change Impact Map
`EDIT → EARLIER SETUP → EVIDENCE PROVENANCE → CHARACTER MOTIVE → RELATION STATE → AUTHORITY/ACCESS → LATER PAYOFF → SERIES CONTINUITY`

### M15 — Audience Connection Without Formula
`SPECIFIC PERSON / SITUATION → LEGIBLE HUMAN CONCERN → CONSEQUENCE → READER INFERENCE / ATTACHMENT`

### M16 — Thematic Causality
`THEMATIC QUESTION → COMPETING MODELS → CHARACTER CHOICES → CONSEQUENCES → PROVISIONAL READER ANSWER`

### M17 — Stakes as Multiple Value Axes
Track safety, relationship, role, responsibility, dignity, evidence, belonging, autonomy, opportunity, etc. separately rather than reducing all stakes to survival.

### M18 — Image / Dialogue Division of Labor
`WHAT CAN BE EXPERIENCED THROUGH ACTION/SETTING/IMAGE? → WHAT REQUIRES EXACT WORDS? → CHOOSE MINIMUM EFFECTIVE CHANNEL`

### M19 — Voice Through Character Context
`WORLDVIEW + ROLE + RELATIONSHIP + PRESENT WANT + CULTURE → WORD CHOICE / RHYTHM / REGISTER / OMISSION`

### M20 — Subtext as Model Gap
`SURFACE WORDS/ACTION → UNSTATED WANT/PRESSURE → LISTENER MODEL → RESPONSE → CHANGED STATE`

### M21 — Character Causal Spine
`MOTIVATION / PRESENT REASON → TRACKABLE OBJECTIVE → TACTIC/ACTION → CONSEQUENCE`

### M22 — Conflict Type Router
`WANT / VALUE / MODEL A ↔ COUNTERFORCE / VALUE / MODEL B → TACTICS → CONSEQUENCE / NEW TERMS`

### M23 — Nonviolent Conflict Reframe
`TENSION PEAK → FRAME CHANGES / HUMAN PARTICULAR ENTERS → OPTION SET CHANGES → NEGOTIATION / WITHDRAWAL / NEW TERMS`

### M24 — Multidimensional Character
`ATTITUDE / VALUES + DECISIONS/ACTIONS + EMOTIONAL/RELATIONAL RESPONSES → READER MODEL`

### M25 — Character Change Evidence
`PRESSURE → NEW CHOICES / NEW RESPONSE PATTERN / NEW RELATION TERMS → DOWNSTREAM BEHAVIOR`

### M26 — Cast Function Audit
`CHARACTER → UNIQUE STORY FUNCTION(S) → INDEPENDENT WANT / PERSONHOOD → NECESSITY / MERGE / REMOVE TEST`

### M27 — Backward Construction
`END STATE / DECISIVE PROBLEM → REQUIRED PRIOR CONDITIONS → EARLIER CAUSAL SETUP`

## 8. CROSS-SOURCE COMPARISON

### Seger × Truby / Bell / Brody / Swain
Agreement: structure, objective, transitions and causal development matter.
Correction: IVDIVO rejects fixed page percentages, mandatory three-act arithmetic, mandatory disaster/death stakes and formula midpoints.
Seger herself provides useful counterevidence by allowing optional/flexible midpoint and variable subplot structure.

### Seger × Scofield / Rosenfeld
Convergence: scenes need meaningful event/change; not all process deserves full dramatization; scene sequences and compression are legitimate.

### Seger × LaPlante / Francine Prose / Lodge
Screenplay visuality cannot become a prose ban on interiority, telling, long paragraphs, or reflective scenes.
Novel scene/summary/interiority remain legitimate tools.

### Seger × Card / Kress / Fludernik
POV is access and alignment, not merely grammatical person.
Controlled multi-POV is legitimate when switching cost is paid.

### Seger × Corbett / McKee Character / Collins
Present want, decisions, actions, values and emotional/relational responses are useful character evidence.
No mandatory wound, transformation, or single deterministic motive.

### Seger × Hayes / Baxter
Relationship lines must alter trust/boundary/choice; supporting characters remain complete agents.
Subtext and relationship state do not replace evidence.

### Seger × Zunshine / le Carré
Seger's fair surprise and viewer skepticism are strengthened by source provenance:
`TRACE → SOURCE → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.
Character belief or conversion is not proof.

### Seger × Le Guin / Clark / Zinsser / Lodge
Momentum, action and suspense do not imply short-sentence density.
Screenplay visual white-space rules must not leak into novel syntax.

## 9. IVDIVO OPERATIONALIZATION

### ONE MAIN STORY
`LOCAL STRAND → UNIQUE CHANGE → EFFECT ON MAIN ENGINE → PAYOFF`.
No five parallel mini-novels.

### CAUSALITY / MIDDLE
When momentum weakens, first identify which state variable stopped changing.
Do not add a new anomaly/attack/technology by reflex.

### YA
Protect:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.
No mandatory failure or trauma.

### POV
Every switch must buy unique knowledge, lived consequence, relationship pressure, irony, or decision ownership.

### DIALOGUE / EXPOSITION
Exact dialogue only when wording itself changes trust, consent, evidence, authority, relationship, emotion or decision.
Routine process may use summary/indirect dialogue.

### MYSTERY
`TRUE TRACE → SOURCE/PROVENANCE → MODEL A → NEW EVIDENCE → MODEL B → ACTION`.
Fair surprise cannot mutate evidence.

### CONSCIOUS NONHUMAN PERSONHOOD
Character function never overrides agency:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### CONSCIOUSNESS SCHOOLS
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.
A skeptic's conversion is not scientific proof.

### POST-MONEY WORLD
Seger's market/career/survival examples are not imported as default youth stakes.
Use time, trust, consent, role, responsibility, privacy, belonging, mastery, relationship, unique opportunity, safety and reputation where causally appropriate.

### ANTI-CHOPPY PROSE
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → EVENT TARGET → POV/EVIDENCE → EXPOSITION OWNERSHIP → PARAGRAPH INTENT/READER-STATE → SENTENCE RHYTHM → WORDING`.

`MOMENTUM ≠ SPEED ≠ SHORT-SENTENCE DENSITY`.
