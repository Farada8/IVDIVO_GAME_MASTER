## 6. New production mechanisms

### A. Scene Ghost Architecture

`CAUSAL LEGIBILITY WITHOUT METRONOMIC PROSE.`

A novel may be structurally rigorous without looking like a screenplay or a chain of equal scene blocks.

### B. Prior-Scene Laboratory

When backstory is unclear:

`WRITE IMPORTANT PRIOR EVENT AS PRIVATE SCENE → CLARIFY WHAT HAPPENED → EXTRACT PRESENT CONSEQUENCES → PUBLISH ONLY IF IT EARNS READER-TIME`.

This prevents both vague backstory and automatic flashback dumping.

### C. Event–Response Coupling

Map two tracks:

`ACTION / OBJECTIVE EVENT`

and

`POV RESPONSE / INTERPRETATION / RELATION / COMMITMENT`.

They should causally alter one another rather than merely alternate.

### D. Scene-Weight Variation

Use:

`HEAVY / MEDIUM / LIGHT / COMPRESSED`.

Equal narrative resolution for every interaction produces an equal-weight manuscript where the reader cannot tell what matters.

### E. Scene Function Caption

Caption each candidate scene with a current-book function such as:

`INFORMATION / CONFRONTATION / DECISION / REVELATION / RECOGNITION / CATALYST / REFLECTION / TURNING POINT / RESOLUTION / CONSENT CHANGE / EVIDENCE STATUS / AUTHORITY CHANGE / PERSONHOOD THRESHOLD / MODEL REVISION`.

Adjacent scenes with the same function and same changed state trigger merge/compress review.

## 7. Anti-choppy prose integration

Pipeline strengthened to:

`ONE MAIN STORY → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT → NARRATIVE MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → EVENT-RESPONSE COUPLING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Do not translate scene mechanics into:

`stimulus. reaction. gesture. thought. decision.`

When microbeats form one perceptual/decision unit, preserve paragraph/sentence coherence unless a deliberate break has a specific reader-effect function.

## 8. Cross-source comparison

Scofield adds an important counterweight to Swain/Bickham/Bell-style visible mechanics:

- **Swain/Bickham:** causal readability and response logic;
- **Bell/Rosenfeld:** scene objective/function/consequence;
- **Scofield:** scene structure may remain underneath freer narrative texture;
- **LaPlante:** generation/analysis separation and scene/summary routing;
- **Prose/Lodge/Zinsser:** reader continuity and stylistic effect over rule compliance.

Integrated production law:

`STRUCTURE SHOULD SUPPORT THE DREAM, NOT SHOW ITS SCAFFOLDING.`
