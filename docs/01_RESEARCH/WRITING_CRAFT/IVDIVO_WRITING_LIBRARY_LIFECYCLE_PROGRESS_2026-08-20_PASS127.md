## 5. Primary mechanisms extracted

### Dialogue as communication tactic
`PRESENT WANT + RELATIONSHIP + KNOWLEDGE → COMMUNICATION TACTIC → LISTENER RESPONSE → TACTIC/MODEL UPDATE → CHANGED STATE`.

### Exposition ownership
`INFO X → WHO NEEDS/WANTS TO SAY/ASK/HIDE X? → WHY NOW? → WHY THIS PERSON? → WHAT CHANGES AFTERWARD?`

### Mode routing
`READER EFFECT / FUNCTION → DIRECT / INDIRECT / NARRATION / ACTION / SILENCE / MIX`.

### Relationship-specific voice
`WORLDVIEW + RELATIONSHIP + STATUS + PRESENT WANT + ATTITUDE + SOCIAL HISTORY → WORD CHOICE + SYNTAX + RHYTHM + REGISTER + OMISSION`.

### Epistemic firewall
`UTTERANCE / GESTURE / SILENCE → MOTIVE HYPOTHESIS`, not motive fact.
