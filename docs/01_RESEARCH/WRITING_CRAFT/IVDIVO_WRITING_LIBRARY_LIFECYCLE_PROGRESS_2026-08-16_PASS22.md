# 4. MAJOR MECHANISMS EXTRACTED

## Subtext
`surface action → local agenda → unspoken pressure → reader inference → changed scene meaning`.
Do not explain subtext immediately after demonstrating it.

## Tension / suspense
Tension is meaningful uncertainty, leverage, expectation gap or competing interpretation; not necessarily overt conflict.
Suspense may be deliberately **slow**. Sentence rhythm follows desired reader effect, not a `suspense = short syntax` rule.

## Intention
`prior consequence → immediate intention → action → resistance/support → result → next intention`.
Support/allies are legitimate causal movement; mandatory repeated failure is rejected.

## Contemplative scenes
`event/pressure → processing → reinterpretation → changed readiness/decision → next action`.
Quiet scenes survive if they alter emotional, relational, epistemic or decision causality.

## Dialogue
Exact dialogue is dramatized when wording itself alters power, trust, consent, evidence, relationship, decision or emotion. Routine process/reporting is a summary/indirect candidate.

## Flashback
Use a dramatized past scene only when entering the past changes the present reader/character model. Otherwise summarize.

## Climax
Transferable core:
`inciting pressure → accumulated consequences → narrowed options → decisive convergence → choice/test → permanent consequence`.

Rosenfeld’s mandatory `Triumph`, victory framing and universally maximal climax are rejected as school-specific.
IVDIVO synthesis:
`CAUSAL CONVERGENCE → BOUNDED CHOICE → COST → LOCAL RESULT → AFTERMATH`.

## Epiphany
`accumulated evidence/experience → old model fails → recognition → cost → changed choice/behavior`.
No lesson-download realization.

## Final scene
Main local conflict closes first; consequence/changed state becomes visible; saga hook may follow only after local closure. Final line should resonate rather than state the author thesis.
