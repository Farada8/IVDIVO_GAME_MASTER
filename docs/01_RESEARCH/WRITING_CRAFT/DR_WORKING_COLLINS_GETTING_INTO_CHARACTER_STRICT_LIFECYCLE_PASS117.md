## Provisional IVDIVO synthesis

### A. Emotional dimensionality

Do not write `anger`, `love`, `fear`, `confidence` as uniform surfaces.

Working production model:

`VALUE / CONCERN + DESIRE + RELATIONSHIP + CIRCUMSTANCE + CURRENT COST -> EMOTIONAL COMPONENT MIX -> TACTIC -> CHOICE/ACTION -> CONSEQUENCE`

### B. Credible contradiction

`TRAIT STABILITY != BEHAVIOURAL UNIFORMITY`

An apparently opposite behaviour must arise from a changed circumstance, competing priority/value, relationship or cost. Random opposite behaviour is not depth.

### C. Growth preparation

Large emotional or behavioural change requires prior capacity evidence.

`EARLY CAPACITY SEED -> PRESSURE -> VARIED SURFACE RESPONSES -> STRATEGY/RELATION CHANGE -> LATER CREDIBLE CHANGE`

This does **not** impose a mandatory healing arc, trauma arc or pole-to-pole transformation.

### D. Inner vs outer rhythm

Provisional scene diagnostic:

`INNER PROCESS SPEED/PRESSURE <-> OUTER BEHAVIOUR/ENVIRONMENT RHYTHM -> CHARACTER-SPECIFIC LEAK / CONTROL / TACTIC`

The two rhythms may align or diverge. A quiet body can contain fast thought; fast external movement can conceal slower deliberation.

### E. Prose firewall

Inner Rhythm is **not** permission for microgesture confetti or fragment density.

Do not translate analytical rhythm into:

`look. hand. breath. thought. line.`

Use:

`SCENE FUNCTION -> POV STATE -> INNER/OUTER RHYTHM RELATION -> CHARACTER-SPECIFIC ACTION/OMISSION -> PARAGRAPH INTENT -> SENTENCE RHYTHM`

Beat/rhythm analysis is upstream of typography.

## Cross-source comparison

- **Stanislavski / acting tradition:** supports divergence between internal and external tempo-rhythm, and warns against rhythm for rhythm's sake.
- **Swain / Bickham:** useful causal audit, but Collins adds a missing layer: the same causal beat can have different embodied tempo depending on character and circumstance.
- **Le Guin / Prose / Lodge / Zinsser:** reinforce that sentence length is an expressive consequence, not a suspense KPI.
- **Card / Corbett / McKee Character:** reinforce relation-specific self and behaviour under pressure rather than decorative quirks.
- **Bell Unforgettable Characters:** confirms that sweeping transformation is not universally required; Collins' growth mechanism should be used as a credibility test, not an arc mandate.
