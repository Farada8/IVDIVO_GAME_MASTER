### Main synthesis

`INFORMATION → PRESENT OWNER / NEED → SOURCE / ACCESS → VERBAL OR NARRATIVE ROUTING → ACTION / INTERPRETATION / DECISION → CHANGED STATE`

Dialogue:

`WANT → VERBAL / NONVERBAL TACTIC → LISTENER ATTENTION / RESPONSE → TACTIC CHANGE → CHANGED STATE`

`WORLDVIEW + RELATIONSHIP + STATUS + PRESENT GOAL + ATTITUDE → WORD CHOICE + SYNTAX + RHYTHM + REGISTER + OMISSION`

## Cross-source corrections

Bickham's useful warnings about lectures, data-dump dialogue, rambling speeches, phonetic dialect, abstract-space dialogue and conspicuous attribution were retained. The following were rejected as universal laws:

- reducing ensemble dialogue to one-on-one by default;
- treating 1992-era editor/market preferences as current law;
- using a numeric `said` percentage;
- inserting sensory/action beats after every line;
- assuming all exposition must be dramatized rather than sometimes summarized/indirectly reported.

Baxter, Chiarella, Fludernik, LaPlante, Card, Rosenfeld, Kress, Zinsser and existing IVDIVO production gates provide the counterweights.

## Anti-choppy-prose update

Do not repair dialogue as:

`line → glance → sensory fragment → thought → gesture → line`.

Use:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT / MODE → POV / EVIDENCE → EXPOSITION OWNER → DIALOGUE TACTICS → PARAGRAPH INTENT / READER ORIENTATION → SENTENCE RHYTHM → WORDING`.

If several microbeats form one perceptual/decision unit, combine them before line polish.
