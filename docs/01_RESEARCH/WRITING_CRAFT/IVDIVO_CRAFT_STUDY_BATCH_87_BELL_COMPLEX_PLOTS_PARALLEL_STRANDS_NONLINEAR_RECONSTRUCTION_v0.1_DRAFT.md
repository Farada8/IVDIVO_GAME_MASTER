# IVDIVO CRAFT STUDY — BATCH 87

## Bell — Complex Plots · Parallel Strands · Nonlinear Reconstruction

Status: PROVISIONAL MECHANISM EXTRACTION FROM VERIFIED CH8 MATERIAL
Source lifecycle: James Scott Bell, *Plot & Structure* — FULL READ IN PROGRESS
Important: Batch 87 does **not** mark Chapter 8 or the book complete.

## Central synthesis

Complexity should come from **interacting causal perspectives**, not from multiplying plots for scale.

### Primary formula

`SHARED BOOK ENGINE → STRAND-SPECIFIC WANT / KNOWLEDGE / RELATIONSHIP → LOCAL ACTION → EFFECT ON OTHER STRAND OR SHARED ENGINE → CONVERGENCE / PAYOFF`

## Production Gates

### B87-G01 — Dominant Engine Gate

Before adding a strand, state the book's dominant causal engine in one sentence. If the new strand cannot be mapped into it, bank it for another book.

### B87-G02 — Strand Ownership Gate

Every substantial strand needs a clear owner and a local want/question.

### B87-G03 — Unique Work Gate

A strand must contribute unique action, evidence, lived experience, relationship leverage, countermodel, or decision ownership.

### B87-G04 — Causal Convergence Gate

Two strands converge only when one changes the other's options, evidence, relationships, authority, or decision.

### B87-G05 — No Briefing Convergence

Shared room + shared recap ≠ convergence.

### B87-G06 — Switching Cost Gate

Every POV/track switch must repay orientation cost with unique story value.

### B87-G07 — Saga Equality Firewall

Long-series importance does not entitle every recurring character to equal book-level POV or page count.

### B87-G08 — Section / Phase Gate

Major phases may have local objectives and payoffs, but no mandatory mini-three-act retrofit. Each phase must alter the next phase's option space.

### B87-G09 — Nonlinear Reconstruction Gate

For nonlinear discourse:

`WORLD FACT → SOURCE/FRAGMENT → ORIENTATION CUE → READER MODEL → NEW EVIDENCE → MODEL REVISION → RECONSTRUCTABLE CAUSAL ORDER`

### B87-G10 — Fair Chronology Gate

The reader may be uncertain about chronology; the author may not make chronology impossible to reconstruct merely to manufacture surprise.

### B87-G11 — Source Status Gate

Later placement does not make a source more truthful. Track:

`OBSERVED / REPORTED / INFERRED / HYPOTHESIS / CORROBORATED / CONTESTED / DISPROVEN / UNKNOWN`.

### B87-G12 — Nonhuman Personhood Gate

A conscious robot/nonhuman strand must retain independent want, consent/refusal, relationships, and causal action.

### B87-G13 — No Exotic Camera

Do not add a robot/nonhuman POV merely to display unusual perception or technology.

### B87-G14 — Saga Scale Firewall

`WORLD DATABASE ≠ BOOK NARRATIVE` and `SAGA SCALE ≠ BOOK SCALE`.

### B87-G15 — Post-Money Translation Gate

When an external craft example uses money/business as pressure, translate the **function**, not the commodity:

role / trust / access / responsibility / time / unique opportunity / consent / relationship / evidence integrity.

## Failure Modes

1. ENSEMBLE FOG — too many POVs with insufficient differentiation of work.
2. PARALLEL DECORATION — parallel tracks that never affect one another.
3. BRIEFING CONVERGENCE — all lines meet only to exchange information.
4. NONLINEAR FOG — shuffled chronology without a recoverable causal pattern.
5. SOURCE/WORLD COLLAPSE — testimony becomes ontology without proof.
6. POV NOVELTY SWITCH — perspective changes only for variety.
7. SAGA DUMP — book becomes a tour of the universe.
8. ROBOT CAMERA — conscious being reduced to viewing instrument.
9. FALSE EQUALITY — same screen time assigned to everyone for fairness.
10. BUSINESS-EXAMPLE REGRESSION — money/rent/credits return through imported craft examples.

## Cross-school synthesis

- Bell contributes practical parallel-plot and nonlinear-story illustrations.
- Chatman and Fludernik provide stronger story/discourse terminology and order/duration/frequency diagnostics.
- Herman provides distributed-intelligence architecture for ensembles.
- Card supplies character hierarchy and attention-budget discipline.
- Rosenfeld/LaPlante broaden causal contribution beyond physical action to relationship, emotion, interpretation and knowledge.

## IVDIVO standard

The preferred multi-strand architecture is not `many interesting lives beside one another` but:

`DISTRIBUTED PERSONHOOD + DISTRIBUTED KNOWLEDGE + DISTRIBUTED ACTION + ONE DOMINANT CAUSAL ENGINE`.

The climax may therefore be ensemble-built without one protagonist monopolizing discovery, interpretation, technical competence and final authority.
