`PRIOR EVENT → CHANGED STATE → NEW OPTION/CONSTRAINT/EVIDENCE/RELATION → NEXT EVENT`.

### Unified action

`ONE MAIN STORY ≠ ONE POV / ONE CHARACTER`.

### Book scale
`SAGA SCALE ≠ BOOK SCALE`.

`TRACE → SOURCE → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING EVIDENCE → DISCOVERY → ACTION`.
