## PRIMARY MECHANISMS — IVDIVO ADAPTATION

### 1. Scene Function Router
Bell's four chords are retained as functional lenses, not mandatory scene boxes:

`ACTION` — purposeful attempt/tactic toward a present objective.

`REACTION` — emotional, relational or epistemic processing that changes the next strategy.

`SETUP` — minimum enabling context required for later causality/comprehension.

`DEEPENING` — character/world/relationship material that changes the reader's model or future meaning.

A scene may combine these.

### 2. Action Does Not Require Failure
Bell often routes action through conflict and setback. IVDIVO rejects setback as a universal requirement.

Valid progression includes:

`OBJECTIVE → ACTION → SUCCESS → INCREASED TRUST / RESPONSIBILITY / DEPENDENCY / KNOWLEDGE → HARDER NEXT CHOICE`.

Success can be causal escalation.

### 3. Reaction Is Real Causality
Reaction is not dead air when it changes:
- interpretation;
- trust;
- evidence status;
- emotional commitment;
- consent;
- relationship terms;
- next strategy.

A reaction beat may exist inside action rather than as a separate scene.

### 4. Setup Without Artificial Conflict
Bell recommends putting a problem into setup. IVDIVO broadens the attention engine.

Setup can earn reader time through:
`CURIOSITY / RELATIONSHIP / COMPETENCE / ANTICIPATION / LIVED-WORLD SPECIFICITY / HUMOR / CONTRAST / PRESSURE`.

Do not manufacture an argument or accident merely to justify information.

### 5. Deepening Is Not Decorative Spice
Deepening is retained when it changes reader understanding of:
- a person;
- a relationship;
- a world rule;
- a recurring motif;
- a future choice;
- the meaning of a later payoff.

If it can be removed without changing any later reading or decision, compress/cut it.

### 6. Summary Is a First-Class Mode
Bell explicitly distinguishes scene from summary and uses summary to skip beats between meaningful real-time moments.

IVDIVO routing:

`LOW-CONSEQUENCE / PROCESS / REPETITION / LOGISTICS → SUMMARY / INDIRECT`

`DECISION / CONSENT / EVIDENCE TURN / RELATIONSHIP TURN / CRITICAL ACTION → SCENE`

This directly supports anti-choppy prose work.

### 7. HIP Reinterpreted
Bell: Hook / Intensity / Prompt.

IVDIVO:

`ENTRY CONTRACT → MEANINGFUL ATTENTION/PRESSURE → CHANGED STATE → REASON TO CONTINUE`.

A prompt need not be danger or cliffhanger. It may be:
- an earned success that enlarges responsibility;
- a relationship shift;
- a new option;
- a completed local answer that opens a better question;
- a voluntary commitment;
- a changed evidence status.

### 8. Intensity Is Not Short-Sentence Density
Bell's intensity scale controls selection, vividness and show/tell concentration. It does not imply that high intensity requires short syntax.

IVDIVO remains:

`READER EFFECT → PACE → SYNTAX`.

A tense scene may slow into long perception or thought. A quiet scene may be highly consequential.

### 9. Intensity Variation, Not Constant Escalation
Bell's numeric 0–10 scale is retained only as a sketching diagnostic.

Reject:
- every scene must rise;
- every scene must contain anxiety;
- transition scenes must be hurried;
- only conflict creates intensity.

Allow intimacy, wonder, competence, humor, reflection and beauty when they alter the causal/relational state.

## SCENE ACCEPTANCE GATE

`PRIOR CONSEQUENCE → SCENE OWNER → PRESENT WANT/PURPOSE → MODE → ATTENTION/PRESSURE ENGINE → ACTION/INFO/RELATION CHANGE → OUTCOME → NEXT CAUSAL LINK → ENTRY/EXIT READER EFFECT`.

If the scene cannot identify a meaningful change, first test summary/merge/delete before line editing.

## FAILURE MODES
1. Conflict-for-Setup — fake argument inserted only to carry exposition.
2. Setback Monoculture — every action must fail.
3. Reaction-as-Filler — reflection repeats an emotion without changing strategy/model.
4. Deepening-as-Tourism — lore/character texture that changes nothing.
5. HIP Cliffhanger Monoculture — every exit becomes danger/question bait.
6. Intensity KPI — numerical scale treated as objective quality score.
7. Anxiety Substitution — quiet scene given generic worry to make it 'dramatic'.
8. Show-All Exhaustion — every process dramatized beat by beat.
9. Scene-by-Default — logistics written in real time because 'scenes are the building blocks'.
10. Choppy Intensity Fallacy — short sentences substituted for causal pressure.

## CROSS-SOURCE SYNTHESIS
- Bell + Rosenfeld: scene intention and changed next intention matter more than mandatory setback.
- Bell + LaPlante: show/tell is routing, not hierarchy; summary is legitimate craft.
- Bell + McKee: action/reaction is useful, but IVDIVO allows non-adversarial pressure and success.
- Bell + Francine Prose / Le Guin / Lodge: syntax length is functional and contrastive, not a suspense KPI.
- Bell + Fludernik/Ribó: scene change may be informational, relational or interpretive, not only physical.
- Bell + Herman/Zunshine: reaction can be epistemic model revision that changes action.
