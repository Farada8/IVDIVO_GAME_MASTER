# IVDIVO CRAFT STUDY — BATCH 192
## Christopher Booker — Ch34 / Epilogue — Narrative Role Capture · Media Selection · Innovation Externalities · Stopping Rules

**Source status:** Booker strict lifecycle COMPLETE.  
**Use class:** WIDER comparative / diagnostic source, not Core-counted.

# 1. Narrative-role capture

A shared story may begin to determine which facts receive attention and which actions seem legitimate:

`ROLE LABEL (HERO / MONSTER / VICTIM / SAVIOR) → ATTENTION FILTER → OPTION NARROWING → ACTION → CONSEQUENCE`.

Production gate:
- identify the role-label currently applied;
- list evidence it highlights;
- list evidence it hides;
- state at least one competing model;
- require discriminating evidence before promotion.

**Failure mode:** `ROLE LABEL → WORLD FACT`.

# 2. Newsworthiness is not representativeness

Useful salvage from Ch34's mass-media discussion:

`WORLD EVENTS → SELECTION FOR NOVELTY / CONFLICT / EMOTION → PUBLIC STORY → AUDIENCE MODEL`.

Standing law:

`NEWSWORTHINESS ≠ REPRESENTATIVENESS`.

A vivid, repeated or widely distributed case may be causally important without being statistically typical.

# 3. Public story can narrow policy options

`PUBLIC / INSTITUTIONAL STORY → ROLE ASSIGNMENT → EXPECTED ENDING → POLICY OPTION FILTER`.

Before a policy/character decision:

`ANALOGY → HYPOTHESIS → INDEPENDENT TRACE → ALTERNATIVE MODEL → DISCRIMINATING TEST → ACTION`.

Do not let a familiar story-pattern become evidence.

# 4. Innovation externality gate

Booker's Loki metaphor is rejected as metaphysics, but it prompts a useful engineering question:

`NEW CAPABILITY → DIRECT BENEFIT → NEW DEPENDENCIES / EXTERNALITIES → MISUSE / FAILURE SURFACE → SAFEGUARDS / GOVERNANCE → RESIDUAL RISK`.

This supports nuanced SF:
- useful technology may really work;
- success can create new coupling;
- governance follows demonstrated externalities, not techno-doom rhetoric;
- `TECHNICAL CAPABILITY ≠ AUTOMATIC SOCIAL LEGITIMACY`.

# 5. Sensation versus model-building

`EVOCATIVE IMAGE / EMOTIONAL INTENSITY → READER EXPERIENCE` may occur without any improvement in causal understanding.

Ask:
`DOES THIS IMAGE / EFFECT CHANGE THE READER MODEL, RELATIONSHIP, OR EXPERIENCE — OR ONLY ADD INTENSITY?`

Intensity alone is not structural progression.

# 6. Universal-taxonomy / unfalsifiability failure mode

Booker's model can absorb counterexamples by calling them incomplete, dark, inverted or sentimental variants.

IVDIVO therefore requires:

`PATTERN FIT → WHAT WOULD FALSIFY THIS FIT? → TEST → STOP`.

If every possible outcome confirms the pattern, the lens has stopped being diagnostically useful.

# 7. Personal-note process salvage

Booker's personal note documents decades of rewriting, expansion and re-seeing.

Useful process lesson:
`LONG PROJECT → PERIODIC RE-SEEING → RESTRUCTURE WHEN EVIDENCE REQUIRES`.

Danger:
`THESIS COMMITMENT → EXPAND THEORY TO ABSORB ALL COUNTEREXAMPLES`.

For IVDIVO:
- persistence is useful;
- thesis-lock is not;
- a framework must be discardable;
- manuscript evidence outranks framework loyalty.

# 8. High-risk firewalls

Reject as IVDIVO psychology, science, history or ontology:
- Jungian collective unconscious / Self / anima / animus as established science;
- masculine/feminine essences;
- heterosexual union or marriage as universal completion;
- bodily/nonhuman difference as moral darkness;
- God/One/Self metaphysics as world fact;
- literary pattern as historical/political causal proof;
- speculative prehistory/religious reconstruction as settled scholarship;
- violence/sex/darkness escalation as a measure of seriousness.

# 9. Cross-source comparison

- **Aristotle:** causal unity is stronger than taxonomy. `AFTER ≠ BECAUSE`.
- **Booth:** interpretation requires shared ground and a stopping rule.
- **Zunshine / le Carré / Ephron / Chudnoff:** source lineage + alternatives + discriminating evidence outrank role intuition.
- **Genette / Chatman:** story fact, discourse placement and reader model are different layers.
- **Card / Corbett / Herman / Oatley:** person-level wants/models/relationships are stronger than archetypal essence.
- **Edward James / Cambridge SF / Wolf:** genre/worldview systems are historically situated.
- **Murderbot / DCC / Weir / Crouch:** nonhuman personhood does not require humanization or symbolic service to a protagonist.

# 10. Production gates

## ONE MAIN STORY
`PATTERN SIGNATURE → CHANGED STATE → DOWNSTREAM DEPENDENCY / PAYOFF`.

No scene is admitted merely because a pattern framework expects it.

## Mystery
`TRUE TRACE → SOURCE LINEAGE → MODEL A/B/C → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

`NARRATIVE ROLE / STORY ANALOGY → HYPOTHESIS, NOT PROOF`.

## Institutions
`OFFICIAL MODEL → ACCESS/STATUS/REWARD → EVIDENCE FILTER → BLIND SPOT → OUTLIER → TEST → UPDATE/ESCALATION`.

## Technology
`CAPABILITY → BENEFIT → SECOND-ORDER DEPENDENCY → FAILURE/MISUSE SURFACE → GOVERNANCE → RESIDUAL RISK`.

## Personhood
`CREATED / DISCOVERED / RESCUED ≠ OWNED`.

After independent personhood evidence:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## Anti-choppiness
`PATTERN / RECOGNITION / REVERSAL / MODEL UPDATE ≠ SENTENCE BREAK`.

`ACTION / SUSPENSE / MYSTERY / EMOTION ≠ SHORT-SENTENCE DENSITY`.

Analytic stages are not typography.
