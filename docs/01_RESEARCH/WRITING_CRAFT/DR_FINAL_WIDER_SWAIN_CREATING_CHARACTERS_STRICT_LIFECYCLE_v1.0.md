## Highest-value claims and mechanisms

### 1. Importance-to-action
Swain's strongest durable idea is that a major character must care about something strongly enough that it changes behavior.

IVDIVO translation:
`PRIORITY / CONCERN → PRESENT OBJECTIVE → TACTIC → CHOICE → CONSEQUENCE`.

A declared value that never changes choice is decoration, not character mechanism.

### 2. Purpose is not motive
Swain distinguishes actionable purpose from the internal reason for it. A character may know what they are trying to do while misunderstanding or rationalizing why.

IVDIVO gate:
`TRACKABLE PURPOSE / OBJECTIVE ≠ SELF-EXPLANATION ≠ MOTIVE HYPOTHESIS ≠ WORLD FACT`.

This strongly aligns with Zunshine, Herman and Oatley: behavior and declared reasons are evidence for a motive-model, not transparent access to motive.

### 3. Continuing causal involvement
Swain's drive model usefully asks why the character keeps acting instead of walking away.

IVDIVO translation:
`PRIORITY → OBJECTIVE → PRESSURE → REASON TO REMAIN CAUSALLY INVOLVED`.

Valid involvement can come from accepted responsibility, relationships, evidence ownership, consequences of a prior choice, consent-based cooperation, bounded authority/access, or physical constraints. Threat/death is not mandatory.

### 4. Conflicting attitudes produce variable behavior
Swain acknowledges that dominant attitudes coexist with counter-attitudes and circumstances.

IVDIVO model:
`VALUE A + VALUE B + RELATIONSHIP + CURRENT COST + KNOWLEDGE → PRIORITY NOW → TACTIC`.

Therefore `TRAIT STABILITY ≠ BEHAVIORAL UNIFORMITY`.

### 5. Background must pay in the present
Body, environment, experience and ideas matter when they alter present perception, options or action. Swain explicitly discourages unnecessary biographical dissertation.

Gate:
`BACKGROUND → PRESENT SALIENCE / MODEL / RELATIONSHIP / TACTIC / OPTION SPACE OR CUT/COMPRESS`.

### 6. Experience is not destiny
The same event does not generate one uniform response in every person.

Gate:
`EXPERIENCE → CHARACTER-SPECIFIC INTERPRETATION → CURRENT MODEL / TACTIC`.

### 7. Labels are orientation, not identity
A dominant impression can help a reader recognize a character, but it must remain revisable by behavior and relationship context.

Gate:
`LABEL → READER MODEL HYPOTHESIS → BEHAVIOR / RELATIONSHIP EVIDENCE → UPDATE`.

### 8. Role function is not personhood
Swain's role taxonomy is useful for book-level function but dangerous if treated as total identity.

IVDIVO law:
`BOOK ROLE ≠ STORYWORLD PERSONHOOD`.

A mentor, antagonist, incidental character or nonhuman character still needs independent priorities, relations and choices when written as a person.

### 9. Humor through expectation and reframe
Useful core from `The Light Touch`:
`SHARED EXPECTATION → CHARACTER-SPECIFIC DEVIATION / INCONGRUITY → REFRAME`.

Humor must remain character-owned. `UNIVERSAL AUTHORIAL WIT` is a failure mode.

### 10. Selected detail over catalogue
`LOAD-BEARING PARTICULAR > FEATURE LIST`.

Detail should alter reader model, character salience, relation, action or atmosphere; it should not exist merely because research produced it.

### 11. Dialogue is selected action
Useful translation:
`WANT → VERBAL/NONVERBAL TACTIC → LISTENER RESPONSE → TACTIC UPDATE → CHANGED STATE`.

Direct speech is warranted when exact wording changes consent, evidence, trust, authority, relationship or decision. Routine speech can be indirect/summary.

### 12. Milieu is both physical and social
For unfamiliar worlds:
`WORLD RULE / SOCIAL NORM → CHARACTER SALIENCE → AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

This directly supports Orbital Youth worldbuilding without exposition dumps.

### 13. Believability leaks are diagnosable
Belief breaks when the text gives impossible knowledge, unsupported skill, inconsistent behavior without changed pressure, ungrounded cultural assumptions or broken source lineage.

Gate:
`BELIEVABILITY DEFECT → IDENTIFY SPECIFIC LEAK → MINIMAL REPAIR → RETEST`.

## Failure modes / rejected universals

1. `ONE-CORE-MOTIVE DETERMINISM` — a person cannot be reduced to one universal motive.
2. `AUTHOR-PROXY COLLAPSE` — “all characters are you” is not a production law.
3. `QUIRK TAXIDERMY` — tags/mannerisms are not depth.
4. `HEREDITY/BODY DETERMINISM` — dated and rejected.
5. `GENDER/RACE/AGE ESSENTIALISM` — dated, rejected as psychology.
6. `PATHOLOGY-AS-COLOR` — diagnosis/mental illness cannot be shorthand for danger, eccentricity or depth.
7. `COURAGE / LARGER-THAN-LIFE REQUIREMENT` — not universal.
8. `PROTAGONIST/ANTAGONIST METAPHYSICS` — roles are optional functions.
9. `NONHUMAN = HUMANIZED TO BE LEGIBLE` — rejected.
10. `ALWAYS OPEN WITH DIALOGUE` — historical pulp-editor advice, not law.
11. `AUDIENCE MORES = MORAL TRUTH` — historical assumption, rejected.
12. `MARKET ADVICE 1990 = CURRENT POLICY` — rejected; current publishing requires fresh verification.
13. `EMOTION MEMORY REQUIRED` — rejected; optional tool only.
14. `SPEECH/BEHAVIOR = MOTIVE FACT` — rejected.
15. `BEAT/TAG/GESTURE = SENTENCE BREAK` — rejected.

## Cross-source comparison

- Card / Corbett / McKee Character: Swain's `care/purpose/drive/attitude` is useful, but these later sources provide stronger relational and non-deterministic character models.
- Herman / Zunshine / Oatley: strongly corroborate `purpose/behavior may be observable; motive remains inferred`.
- LaPlante / Hodgins / Prose / Mayer: corroborate background-payment and anti-dossier discipline.
- Lamott / LaPlante / Bell / Le Guin: corroborate Swain's own Preface warning against writing by numbers; generation and diagnosis should be separated.
- Collins / Gillett: correct Swain's emotion-memory assumptions; personal recall is optional, not required authenticity.
- Le Guin / Williams-Bizup / Hodgins / Clark: correct any tendency to translate character beats into sentence fragmentation.

## IVDIVO operationalization

### Production gates
1. **Importance-to-Action Gate** — what matters enough now to alter choice?
2. **Purpose/Motive Separation Gate** — objective is actionable; motive remains provisional.
3. **Continuing-Involvement Gate** — why is this agent still causally involved?
4. **Trait-Conflict Gate** — competing values + relationship + cost determine current tactic.
5. **Background Payment Gate** — background only enters when it changes present story state.
6. **Quirk Causality Gate** — mannerism must reveal relation/state or be removed.
7. **Pathology Firewall** — diagnosis is not characterization shorthand.
8. **Believability Leak Audit** — knowledge, skill, culture, motive/action consistency, source lineage.
9. **Medium Selection Gate** — preserve function/personhood, not identical presentation across novel/audio/film.
10. **Nonhuman Personhood Gate** — role/label/human interpretation does not define personhood or motive.
11. **Voice Ownership Gate** — worldview + relationship + want + status + attention + omission.
12. **Purposeful Silence Gate** — silence may be tactic/boundary; `SILENCE ≠ CONSENT`.
13. **Anti-Choppiness Gate** — character beat/tag/gesture is not a sentence or paragraph break.
14. **Emotion-Memory Ethical Firewall** — personal recall optional; writer feeling ≠ character truth ≠ reader effect.
15. **Historical Audience-Mores Firewall** — 1990 market/social assumptions are not current universals.

## Synthesis
Swain is most valuable when stripped of dated deterministic psychology. His durable contribution is a practical distinction between what matters, what a character is trying to do, why they may think they are doing it, what keeps them causally involved, and how relationships/background shape tactics. Used as a diagnostic layer rather than a personality formula, it strengthens character causality, mystery fairness and nonhuman personhood while preserving the existing IVDIVO anti-formula and anti-choppiness architecture.
