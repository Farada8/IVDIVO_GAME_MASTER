## Erin M. Pushman: Form · Structure · Character · POV · Scene · Language

Status: WORKING / PRODUCTION GATES

# PURPOSE
Convert Pushman's cross-genre close-reading framework into executable IVDIVO gates without importing a new beat-sheet or aesthetic monoculture.

# A. FORM ROUTING
## A1 — Genre is a reader contract
Before applying genre technique define what the reader is promised: truth status, dominant experience, expected kind of payoff, and how much formal experimentation the contract can carry.

## A2 — Hybrid form must earn itself
`FORM B → UNIQUE INFORMATION/EFFECT → INTERACTION WITH FORM A → CHANGED INFERENCE/FEELING`.
A transcript, log, chat, image, diagram or audio artifact that merely repeats prose is cut.

## A3 — Short form is density, not chop
Flash/micro techniques transfer as multifunctional detail and compression, not sentence-fragment quotas.

# B. ONE MAIN STORY + LOCAL VARIETY
The book keeps one dominant causal/emotional engine. Local chapters/scenes may use different modes, POV distances, durations and formal structures when those choices return value to the main engine or a major relationship chain.

Traditional five-part arc is a diagnostic map, not a retrofit requirement.

# C. STRUCTURE / BREAKS / TRANSITIONS
## C1 — Break Intent
Every paragraph/section/chapter break answers: `what changed enough to justify a new visual unit?`
Valid shifts include time, focal attention, tactic, emotional beat, POV, evidence status, location, conceptual frame or deliberate emphasis.

## C2 — Transition Scale
Small discontinuity → textual bridge.
Medium discontinuity → paragraph/scene break.
Large time/POV/plot discontinuity → section/chapter boundary.

## C3 — Anti-confetti
If several adjacent one-sentence paragraphs are one continuous thought/action with no distinct beat, merge before touching sentence wording.

# D. CHARACTER
Character detail should accumulate in action rather than arrive as biography.
Useful detail classes: physical; inner; habits/reactions; speech/interaction. They are diagnostic categories, not mandatory checklist fields.

`ESTABLISH HABIT → PRESSURE → HABIT CHANGES/FAILS/INTENSIFIES → READER INFERS STATE`.

Pity is not depth. Injury, illness, exclusion and vulnerability require independent causal/personhood functions.

# E. POV
POV matrix:
`LENS HOLDER → OBSERVABLE → KNOWABLE → INFERRED → UNKNOWN → DISTANCE → READER EFFECT`.

Pronoun change without access/distance change is not real POV redesign.
Second person, plural first and objective third are permitted only when their reader-effect earns them.

# F. SETTING
`WORLD DETAIL → CHARACTER OCCUPIES IT → PHYSICAL/SOCIAL RESPONSE → CHOICE/RELATION/CONSEQUENCE`.

For Orbital Youth, infrastructure is not scenery. Gravity, transport, mixed-body environments, robot-human conventions, privacy and habitat geometry should alter action or relationship.

# G. SCENE ROUTING
Full scene when exact words/actions/sensory sequence matter.
Partial scenic rendering when concrete immediacy is valuable but full real-time expansion is not.
Summary/indirect when process, routine, travel, repetition or less-significant dialogue would otherwise consume reader time.

`importance + exactness requirement + attention budget → scene mode`.

# H. LANGUAGE / RHYTHM
Sentence length, punctuation, fragment/completeness, sound and diction are reader-effect tools.

Strong rule:
`MEANING → DICTION → SYNTAX → PUNCTUATION → SOUND/RHYTHM`.

A long sentence can embody sustained perception or thought. A fragment can embody rupture or resonance. Neither is automatically superior.

# K. EDITING ROUTER
For choppy/artificial prose use:
`ONE MAIN STORY / CAUSALITY → SCENE NECESSITY → SHOW/TELL → POV → DIALOGUE MODE → PARAGRAPH INTENT → SENTENCE RHYTHM → WORDING`.

Do not solve an upstream problem with downstream cosmetics.
