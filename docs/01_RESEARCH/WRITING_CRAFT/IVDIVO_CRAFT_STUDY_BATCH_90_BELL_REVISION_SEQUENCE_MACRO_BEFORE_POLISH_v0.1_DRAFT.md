# IVDIVO CRAFT STUDY — BATCH 90
## Bell: Revision Sequence · Macro Diagnosis Before Polish

Status: DRAFT / OPERATIONAL
Date: 2026-08-18
Primary source: James Scott Bell, *Plot & Structure*, Chapter 11

## Core revision router
`FINISH DRAFT → DISTANCE → READER READ-THROUGH → MACRO DIAGNOSIS → STRUCTURAL/CHARACTER/SCENE REWRITE → REFINE → POLISH`.

Do not line-edit a manuscript whose causal engine, scene architecture, character motivation, evidence structure, or POV access is still wrong.

## Diagnostic hierarchy
`BOOK ENGINE → STRUCTURE → CHARACTER/RELATIONSHIPS → SCENES → POV/EVIDENCE → DIALOGUE → PARAGRAPH/RHYTHM → WORDING`.

For IVDIVO's anti-fragmentation work:
`ONE MAIN STORY / CAUSALITY → SCENE NECESSITY → ORDER/DURATION/FREQUENCY → SHOW/TELL → POV/FOCALIZATION → DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

## Production gates
1. **Reader Read Before Repair:** first read for effect before prescribing edits.
2. **Macro Before Micro:** causal/structural repair always outranks prose cosmetics.
3. **Weak-Scene Signal, Not Quota:** ranking weak scenes identifies investigation targets; it does not authorize automatic cuts by percentage.
4. **Hot-Spot Protection:** preserve a loved passage only if it serves story/character/reader effect; otherwise bank or rewrite it.
5. **Character/Opposition Audit:** test motivations and countermodels before increasing external conflict.
6. **Scene Function Audit:** merge/compress/delete repeated process before polishing dialogue.
7. **Refine After Rebuild:** transitions, foreshadowing, continuity, evidence and scene balance follow structural repair.
8. **Polish Last:** rhythm, diction, dialogue trimming, sensory precision and line clarity belong late.
9. **No Mandatory Information Delay:** delay only when it improves fair uncertainty; do not manufacture suspense by hiding known POV facts.
10. **No Mandatory Dialogue Compression:** Bell's short-dialogue preference is a tool; natural rhythm, subtext, relation and reader effect decide length.
11. **No More-Conflict Monoculture:** a scene may gain force through intimacy, competence, revelation, consent, success, beauty-with-consequence, or a changed relationship.
12. **RUE as Reader-Trust Gate:** do not redundantly explain an action/beat whose meaning the reader can already infer.

## Failure modes
LINE-EDIT-BEFORE-STRUCTURE; REVISION-BY-PERCENTAGE; DARLING IMMUNITY; CONFLICT INFLATION; DELAY-EVERYTHING SUSPENSE; DIALOGUE SHRINKING KPI; POLISH-AS-REWRITE SUBSTITUTE; EXPLAIN-AFTER-SHOWING; AUTOMATED FRAGMENT MERGE WITHOUT FUNCTION TEST.

## Writers' Room use
Specialists should diagnose in staged passes. A 100-desk studio is strongest when each pass has a specific question, not when 100 rules simultaneously constrain every sentence.
