## Highest-value mechanisms

### 1. Speaker–Hearer / Author–Reader Double Layer
`SURFACE UTTERANCE → SPEAKER INTENTION → LISTENER DECODING → OTHER CHARACTER DECODING → READER DECODING → SOCIAL / RELATIONAL CONSEQUENCE`.

A line may be misunderstood inside the story while being legible to the external reader. This supports dramatic irony, double entendre and status play without authorial explanation.

### 2. Wordplay Function Gate
`FORMAL CUE → ALTERNATIVE MEANING / SOURCE FORM → WHO CAN DECODE? → WHY DOES IT MATTER? → PAYOFF`.

Wordplay earns space when it changes affiliation, exclusion, status, characterization, thematic relation, tension, intimacy or reader inference. Cleverness alone is insufficient.

### 3. Shared-Ground Gate
A pun/allusion/lexical blend requires demonstrated linguistic, cultural or relational common ground. Multilingual wordplay requires plausible competence and contextual support.

### 4. Interpretive Work + Stopping Rule
`CUE ECOLOGY → PLAUSIBLE READINGS → CONTEXTUAL SUPPORT → BEST-FIT READING → STOP`.

Not every imaginable secondary meaning is equally supported. Hidden wordplay must not become an unfalsifiable interpretive game.

### 5. Character-Owned Wordplay
Humour and verbal play should arise from `WORLDVIEW + KNOWLEDGE + RELATIONSHIP + PRESENT WANT + REGISTER`, not one universal witty authorial voice.

### 6. Discourse-Tradition Gate
Whether wordplay is expected, legible or socially valuable depends on genre/community conventions. Future cultures therefore need their own discourse traditions rather than imported Earth-2020s slang.

### 7. Translation / Adaptation Function Gate
For audio/subtitle/translation:
`SOURCE FORM → FUNCTION → RELATIONSHIP EFFECT → EVIDENCE STATUS → TARGET-LANGUAGE / TARGET-MEDIUM SOLUTION`.
Literal wording may change when function is preserved, **except** where wording itself is canon/load-bearing evidence and authority explicitly permits no change.

### 8. Evidence Firewall
`PUN / HOMOPHONY / METAPHOR / ASSOCIATION / SARCASM → HYPOTHESIS OR STANCE`, never corroboration by itself.

## IVDIVO operationalization
### LESSON ZERO
No global rewrite. Audit only if beta/audio evidence shows universal wit, unclear shared ground, joke masking evidence/consent, or explanatory after-punchline prose.

### Orbital Youth
Future-youth humour must arise from future norms, roles, friendships, post-money assumptions and character-specific knowledge. The five teens do not need equal joke density or the same kind of verbal cleverness.

### ROOM 917
`PUN / DOUBLE ENTENDRE / SARCASM / INFLECTION → RELATIONAL INFERENCE`, not proof.
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.
If an audio adaptation alters a pun/homophone, clue provenance and evidence status remain locked.

### B07 / nonhuman personhood
Human nicknames, labels or jokes about a nonhuman entity are human cultural frames, not personhood evidence. Nonhuman wordplay is allowed only if its own communication system and a plausible decoding path are established.

## Prose / anti-choppiness implication
`WORDPLAY BEAT ≠ SENTENCE BREAK` and `PAUSE / PUN / REVEAL ≠ NEW PARAGRAPH BY DEFAULT`.
Wordplay frequently depends on keeping multiple contextual cues active. Fragmenting every cue into isolated one-line beats can destroy the relationship the reader must reconstruct.

## Final synthesis
Wordplay is best treated as a **relational inference mechanism**: language form creates a second path of meaning that must be recoverable by specific participants for a specific purpose. The production question is not “is this clever?” but “who can decode it, why, what changes, and what evidence status remains untouched?”
