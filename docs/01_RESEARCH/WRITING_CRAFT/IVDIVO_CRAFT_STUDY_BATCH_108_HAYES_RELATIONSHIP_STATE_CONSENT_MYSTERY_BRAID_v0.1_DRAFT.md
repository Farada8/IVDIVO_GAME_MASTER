# IVDIVO CRAFT STUDY — BATCH 108
## HAYES — RELATIONSHIP STATE · CONSENT · MYSTERY BRAID

Date: 2026-08-19
Status: ACTIVE PRODUCTION GATES
Source: Gwen Hayes — *Romancing the Beat* — strict lifecycle complete.

## PURPOSE
Use Hayes for relationship causality without importing a mandatory beat sheet, mandatory trauma, forced breakup, partner-as-cure logic or romance-primary closure into products whose primary promise is mystery/YA/SF.

## CORE MODEL
`TWO COMPLETE AGENTS → SUSTAINED CAUSAL CONTACT → RELATIONSHIP STATE CHANGE → EXTERNAL CHOICE CHANGE → COST → NEW TERMS`

## GATE 108-01 — RELATIONSHIP STATE, NOT CHEMISTRY COUNT
Track changed state rather than kisses, banter, proximity or glances.
Potential axes: trust, respect, desire, privacy, disclosure, consent, reliance, future expectation, boundary, status, willingness to share evidence, willingness to take risk.

PASS: interaction changes one or more axes and affects later behavior.
WATCH: attractive scene with no downstream change.
FAIL: repeated chemistry is treated as automatic progression.

## GATE 108-02 — TWO COMPLETE AGENTS
Neither agent exists to complete, cure, civilize or validate the other.
Both retain independent wants, relationships, obligations and future options.

## GATE 108-03 — SUSTAINED CAUSAL CONTACT
Repeated interaction requires a credible causal basis: shared task, investigation, school/team, family/social network, evidence chain, responsibility, voluntary return.

Forced proximity is not consent.

## GATE 108-04 — EXTERNAL / RELATIONSHIP BRAID
Every major relationship turn should be tested in both directions:
1. What external event/choice changed the relationship state?
2. What next external choice becomes different because the relationship state changed?

If the answer to both is “nothing,” the lane is probably detached from ONE MAIN STORY.

## GATE 108-05 — MYSTERY EVIDENCE FIREWALL
`ATTRACTION / TRUST / LOVE / CONFESSION ≠ CORROBORATION`.
Relationship change can alter access, disclosure, cooperation or interpretation. It cannot alter what a trace proves.

## GATE 108-06 — CONSENT REMAINS LIVE
Consent is not a one-time romance checkbox. Changed information, risk, power or circumstances can require changed boundaries.
A costly romantic action must leave the receiving agent genuinely free to accept, refuse or renegotiate.

## GATE 108-07 — RUPTURE MUST BE EARNED
Do not manufacture a breakup because the template expects one.
A rupture/downgrade is accepted when it grows from established values, evidence, boundaries, conflicting obligations or previous choices.
Alternatives: trust downgrade, temporary distance, refusal, changed terms, incompatible commitments, evidence-driven reassessment.

## GATE 108-08 — COSTLY CREDIBLE RELATIONAL ACTION
Replace spectacle-first “grand gesture” logic with:
`RELATIONAL CLAIM → SPECIFIC CHARACTER-TRUE COST → ACTION → OTHER AGENT FREE TO RESPOND`.

## GATE 108-09 — PRODUCT WEIGHT ROUTER
### MYSTERY-PRIMARY
Case/evidence closes first. Romance changes human stakes and investigative choices but never substitutes for proof.

### BALANCED
External and relationship engines repeatedly cause changes in each other.

### ROMANCE-PRIMARY
Relationship resolution is a core product promise; Hayes may be used more densely, still without mandatory wounds or fixed percentages.

## GATE 108-10 — POST-MONEY ROMANCE
Do not default to salary/rent/credits as relationship stakes in orbital civilisation.
Prefer: time, privacy, trust, reputation, belonging, mission/role, concrete responsibility, future coordination, unique experience, family/social expectations, consent.

## GATE 108-11 — CONSCIOUS ROBOT / NONHUMAN PERSONHOOD
If a conscious robot/nonhuman participates in intimacy or romance, verify:
`OWN WANT → OWN RELATIONSHIPS → OWN MODEL/EVIDENCE → CONSENT/REFUSAL → OWN CHOICE → CONSEQUENCE`.
No “AI companion” exists merely to understand/heal a human better than humans do.

## GATE 108-12 — RELATIONSHIP ENDING CONTRACT
`LOCAL RELATIONAL QUESTION → DECISIVE RELATIONAL ACTION/CHOICE → RESPONSE → COST → CHANGED TERMS → PERSONALITY CONTINUITY → OPTIONAL FUTURE VECTOR`.

Do not replace personality with idealized couple behavior in the final pages.

## ACCEPTANCE TEST FOR A ROMANTIC SCENE
Before polishing prose, answer:
1. What does each agent want now?
2. What boundary is live?
3. What new information/action occurs?
4. Which relationship axis changes?
5. What does that change make possible/impossible next?
6. Does it alter the ONE MAIN STORY or earn a necessary relational payoff?
7. Does consent remain genuine?
8. If mystery evidence is involved, has its status remained honest?

If these are weak, do structural repair before line edit.
