## 4. High-value mechanisms retained

### S1 — Unexpected Change as Attention Trigger, Not Mandatory Crisis

Useful core:

`LIVED MODEL / EXPECTATION → MEANINGFUL DEVIATION → ATTENTION / CURIOSITY → CHARACTER-SPECIFIC RESPONSE`.

The deviation may be quiet: a responsibility, anomalous trace, changed relationship, rule mismatch or unexpected success.

**Rejected universal:** every story must begin with crisis or dramatic rupture.

---

### S2 — Curiosity as Partial Model + Information Gap

`KNOWN / PARTLY KNOWN → QUESTION → PLAUSIBLE MODELS → MISSING DISCRIMINATING INFORMATION → SEEK / TEST`.

Useful for mystery because total ignorance gives the reader nothing to model and total certainty gives no curiosity.

**IVDIVO form**
`CLEAR QUESTION + MULTIPLE PLAUSIBLE MODELS = PRODUCTIVE UNCERTAINTY`.

---

### S3 — Reader Model Building

Storr’s predictive/model-building language is useful as craft metaphor:

`SELECTED CUES → READER MODEL → PREDICTION → NEW CUE → MODEL UPDATE`.

Do not turn the neuroscience metaphor into ontology.

---

### S4 — POV as Character-Specific Model

`VALUES / HISTORY / KNOWLEDGE / EMBODIMENT / CURRENT WANT → SALIENCE → NOTICED DETAIL → INTERPRETATION`.

Two POV characters should not simply notice the same world in the same order with different slang.

---

### S5 — Theory-of-Mind Error as Dramatic Engine

`A'S MODEL OF B → TACTIC → B'S ACTUAL RESPONSE → MODEL ERROR / SURPRISE → UPDATE`.

Strong convergence with Zunshine and Herman.

**Evidence firewall**
`MODEL OF OTHER MIND ≠ OTHER MIND FACT`.

---

### S6 — Salient Detail / Subjective Time

High pressure may produce **more** fine-grained attention, not less.

Therefore:
`SUSPENSE ≠ SHORT-SENTENCE DENSITY`.

A scene can slow subjective time with selected detail while tension rises.

---

### S7 — Detail + Personal Association

`PARTICULAR → CHARACTER HISTORY / VALUE ASSOCIATION → SPECIFIC MEANING → RESPONSE`.

This helps differentiate voices without gimmicky phrasing.

---

### S8 — Cause Legibility Without Over-Explanation

Useful synthesis:

`CAUSE / PRIOR STATE LEGIBLE ENOUGH FOR READER MODEL → ACTION / CONSEQUENCE → INFERENTIAL SPACE`.

Do not explain every causal link if the reader can reconstruct it.

---

### S9 — Character Model Under Pressure

A less prescriptive version of Storr’s flaw model:

`CURRENT MODEL / VALUE → PRESSURE / CONTRADICTORY EVIDENCE → TACTIC → CONSEQUENCE → MODEL UPDATE OR TESTED STABILITY`.

No mandatory flaw, wound or healing.

---

### S10 — Ignition as Person × Event Specificity

`EVENT → CONTACT WITH THIS PERSON'S MODEL / VALUE / RESPONSIBILITY → SPECIFIC RESPONSE → STORY ENGINE ACTIVATES`.

The same external event should not produce identical story pressure for every character.

---

### S11 — Setting as Evidence of Attention / Identity

Useful core:

`SETTING FEATURE / RESIDUE → POV ATTENTION → CHARACTER / RELATIONSHIP HYPOTHESIS`.

**Firewall**
Environment/possessions support hypotheses; they do not prove personality or moral essence.

---

### S12 — Memory and Self-Report as Sourced Testimony

`MEMORY / SELF-NARRATIVE → CURRENT SELF-MODEL`, not automatic historical fact.

For mystery:
`MEMORY = SOURCE WITH PROVENANCE / DISTORTION POSSIBILITY`.

---

### S13 — Multiple Context-Dependent Selves

Useful craft synthesis without neural literalism:

`CORE VALUES / TRAITS + RELATIONSHIP + SITUATION + COST → CURRENT PRIORITY → CURRENT TACTIC`.

Contradictory behavior can be character-true when the relational/causal conditions differ.

---

### S14 — Outer Plot + Inner Model Track

`OUTER EVENT / ACTION ↔ INNER MODEL / RELATION / COMMITMENT UPDATE`.

This is useful for quiet YA scenes and relationship-led mystery without requiring every beat to be overt conflict.

---

### S15 — Want / Need as Optional Lens

Useful only when present:
- conscious objective;
- less conscious model/value correction or conflicting good;
- consequences reveal mismatch.

**Rejected universal:** every protagonist has a hidden wound-generated need that the plot must heal.

---

### S16 — Competing Moral Models

Strongest salvage from Storr’s group/tribal material:

`MODEL / VALUE A ↔ MODEL / VALUE B → BOTH EXPERIENCED AS LEGITIMATE → TACTICS → CONSEQUENCES`.

Use competent countermodels, not strawman villains.

---

### S17 — Plot as Symphony of Change

One of Storr’s strongest craft passages.

Possible change layers:
- external action state;
- knowledge/evidence;
- relationship;
- goal;
- plan/tactic;
- self-model;
- reader model;
- secondary-character state;
- open/closed information gaps.

**Production gate**
A middle can progress without escalating physical danger if meaningful state continues changing across layers.

---

### S18 — Plot Recipes Are Waymarkers, Not Dictators

Storr explicitly warns that following recipes produces the same cake.

`STORY NEED → OPTIONAL FRAMEWORK LENS → TEST → KEEP/DISCARD`.

Strong convergence with the IVDIVO anti-overfit law.

---

### S19 — Ending as Local State Resolution, Not “God Moment” Requirement

Useful core:

`DOMINANT BOOK QUESTION / PRESSURE → DECISIVE ACTION / CHOICE → CONSEQUENCE → CHANGED STATE → AFTERMATH`.

Storr’s control/God-moment theory is one archetypal reading, not a universal ending requirement.

---

### S20 — Character-Creation Rewind Is Optional Laboratory

Storr’s Appendix recommends writing origin/confirmation scenes privately.

Useful revised form:

`PRIVATE PRIOR-SCENE LAB → UNDERSTAND CURRENT MODEL → EXTRACT PRESENT CONSEQUENCES → PUBLISH FLASHBACK ONLY IF IT EARNS READER-TIME`.

No mandatory trauma scene.

## 5. Major failure modes / rejected universals

### F1 — NEUROSCIENCE-TO-CRAFT CERTAINTY LEAP
A popular-science claim is not automatically a robust law of narrative or psychology.

### F2 — SCIENCE-SOURCE AGING
2019 synthesis and cited older work must be rechecked before becoming modern scientific fact.

### F3 — EVOLUTIONARY-PSYCHOLOGY UNIVERSALIZATION
Do not turn speculative/adaptive explanations into universal human motives.

### F4 — WEST / EAST CULTURE BINARY
Storr’s individualist-West / collective-East account is too coarse for character or world canon.

### F5 — CONTROL-THEORY MONOCULTURE
Not every human or story is best modeled as a control struggle.

### F6 — STATUS-AS-UNIVERSAL ENGINE
Status can matter; it is not the hidden explanation of every desire, relationship or story.

### F7 — TRIBAL-STORY MONOCULTURE
Stories can perform social/group functions without being reducible to tribal propaganda.

### F8 — HERO-MAKER UNIVERSAL
Self-justification is useful as one character mechanism; do not assume every psychologically healthy person experiences themselves as morally heroic in the same way.

### F9 — HIGH-SELF-ESTEEM / MORAL-IDEALISM → EVIL OVERSIMPLIFICATION
Not a usable causal law for villains, violence or institutions.

### F10 — FLAW MANDATORY
A protagonist need not be “broken.”

### F11 — ORIGIN-DAMAGE MANDATORY
A specific childhood wound is not required for depth or motivation.

### F12 — SUBCONSCIOUS-NEED TEMPLATE
Want/need can be useful; it is not required.

### F13 — HEALING / TRANSFORMATION MONOCULTURE
Stories may use partial change, tactical change, tested stability, negative arcs or unresolved series development.

### F14 — FINAL-BATTLE / GOD-MOMENT REQUIREMENT
No mandatory life-or-death confrontation or total-control ending.

### F15 — BEHAVIOR → PERSONALITY / MOTIVE FACT
Surface behavior supports hypotheses only.

### F16 — CLINICAL-EXAMPLE NORMALIZATION
Split-brain, delusion, alien-hand and other clinical cases cannot be casually treated as literal models of ordinary cognition.

### F17 — DETAIL / SALIENCE NEURO STORY → PROSE LAW
Interesting neuroscience does not dictate sentence length, POV depth or description density.

### F18 — COMMERCIAL / LITERARY FALSE DICHOTOMY
Causal tightness vs ambiguity is a spectrum and a design choice, not a genre-quality hierarchy.

### F19 — DIALOGUE DENSITY OVERCOMPRESSION
Meaningful dialogue need not encode entire biography/personality in every line.

### F20 — “SACRED FLAW” CHARACTER REDUCTION
One belief can organize a story, but major characters usually require competing values, relational variation and counterevidence.

## 7. IVDIVO operationalization

### Character model

`VALUES / RELATIONSHIPS / KNOWLEDGE / EMBODIMENT → CURRENT MODEL / PRIORITY → PRESENT WANT → OPTION SET → TACTIC → WORLD RESPONSE → CONSEQUENCE → MODEL UPDATE OR TESTED STABILITY`.

### Curiosity / mystery

`CLEAR QUESTION → PARTIAL MODEL → PLAUSIBLE ALTERNATIVES → DISCRIMINATING EVIDENCE → MODEL UPDATE → ACTION`.

### Layered story progression

Track separately:
- action state;
- knowledge/evidence;
- relationship/consent;
- authority/access;
- responsibility;
- goal/strategy;
- self-model;
- reader model;
- future option space.

### Science evidence firewall

`STORR SCIENCE CLAIM ≠ IVDIVO SCIENTIFIC FACT`.

Any real-world neuroscience/psychology claim used as fact requires current evidence verification.

### Anti-choppiness

`CHANGE / CURIOSITY / SUSPENSE → READER EFFECT → ORDER/DURATION/FREQUENCY → PARAGRAPH INTENT → SUBJECTIVE TIME → SENTENCE RHYTHM`.

No short-sentence KPI.

Storr’s strongest usable diagnostic for later beta/audio evidence:
- does each important event contact a character-specific model/value?

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

### Orbital Youth
Apply:

- belonging/status as optional, not universal stakes;
- culture through lived norms, not East/West binaries;
- multiple layers of change instead of constant danger escalation;
- post-money stakes remain trust, consent, role, privacy, time, responsibility, mastery, relationship, unique opportunity and safety.

### ROOM 917
Use:
`PARTIAL CLUE MODEL → ALTERNATIVE MODEL → DISCRIMINATING TEST → EVIDENCE UPDATE`.

Do not use emotional/theory-of-mind inference as corroboration.

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

### B07 — THE UNLISTED CITY
Human observers may form changing models of the distributed entity. Their model is not the entity’s motive/personhood.

Required:
`INDEPENDENT TRACE LINEAGES → PERSONHOOD THRESHOLD → ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

### Conscious robots
Storr’s anthropomorphism/theory-of-mind material must not equate human readability with personhood.

`PERSONHOOD ≠ HUMAN-LIKE EXPRESSION`.

### Consciousness-practice schools
Predictive/model language and Storr’s neuroscience cannot be used to validate subtle-world ontology.

Maintain:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 9. Final synthesis

The durable Storr contribution is not “every hero is broken and needs to regain control.” It is this:

`PEOPLE / READERS BUILD MODELS → CHANGE OR CONTRADICTION CREATES ATTENTION → CHARACTERS ACT FROM THEIR CURRENT MODELS → CONSEQUENCES TEST THOSE MODELS → STORY PROGRESSES THROUGH MULTIPLE LAYERS OF MODEL AND STATE CHANGE`.

That mechanism is useful. The universal neuroscience/evolutionary/status/flaw story built around it is not adopted as IVDIVO law.
