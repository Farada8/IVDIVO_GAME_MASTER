## 6. Anti-choppy prose integration

New Scofield layer reinforces the current anti-fragmentation pipeline:

`ONE MAIN STORY → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT/MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → EVENT/EMOTION COUPLING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`

Forbidden default interpretation of scene mechanics:

`stimulus. reaction. gesture. thought. decision.`

If several microbeats form one perceptual/decision unit, they should usually be rendered as coherent paragraph/sentence flow rather than isolated one-line fragments.
