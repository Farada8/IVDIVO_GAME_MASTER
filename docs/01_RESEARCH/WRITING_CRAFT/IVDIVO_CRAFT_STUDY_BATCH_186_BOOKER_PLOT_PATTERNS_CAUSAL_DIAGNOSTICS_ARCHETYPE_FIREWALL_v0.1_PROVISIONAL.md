# BATCH 186 — Christopher Booker — Plot Patterns · Causal Diagnostics · Archetype Firewall

**Source status:** PART ONE strict-read complete; FULL BOOK READ still in progress.
**Batch status:** PROVISIONAL / MANUSCRIPT-TESTABLE, not final synthesis.

## 1. Pattern-After-Causality Gate
Plot-family recognition happens only after the actual causal spine is known.

`ACTUAL CAUSAL SPINE → PATTERN SIGNATURE → OPTIONAL FAMILY COMPARISON → DIAGNOSIS → KEEP / REJECT LENS`

Failure mode: **PATTERN-FIRST RETROFIT** — writing scenes because a named pattern expects them.

## 2. Pattern Overlap Gate
One book may contain several pattern signatures. This is not a defect if each pays into ONE MAIN STORY.

`STRAND / PATTERN → LOCAL CHANGE → MAIN-ENGINE CONSEQUENCE → PAYOFF`

Failure mode: **PATTERN COLLECTION** — multiple interesting mini-arcs with no downstream causal integration.

## 3. Quest Goal Architecture
Useful retained function:

`DISTANT / IMPORTANT GOAL → TRACKABLE OBJECTIVE → CONSTRAINTS / TESTS → STRATEGY UPDATES → ARRIVAL / FINAL ACCESS PROBLEM → LOCAL CLOSURE`

Reject: automatic ordeal-count, mandatory final battle, hero supremacy.

## 4. Voyage-and-Return Gate
An unfamiliar world, institution, technology or social system earns narrative weight when it changes the protagonist's model and options.

`ENTRY INTO NEW SYSTEM → NEW AFFORDANCES / CONSTRAINTS → MODEL ERROR / LEARNING → CHANGED ACTION → RETURN / CONTINUATION WITH CHANGED MODEL`

Failure mode: **WORLD TOURISM** — new place/technology without changed choices or relationships.

## 5. Recognition Gate
Booker's comedy recognition is retained only as an epistemic/relational mechanism:

`MIS-MODELLED STATE → DISCRIMINATING EVIDENCE → MODEL UPDATE → RELATIONSHIP / ACTION CHANGES`

Reject: marriage as universal resolution; gendered Prince/Princess completion.

## 6. Blind-Spot Tragedy Gate
Useful non-moralistic version:

`STRONG WANT / MODEL → IGNORED VARIABLE → CONSEQUENCE → PATCH → MORE ENTANGLEMENT → MODEL UPDATE / EXIT / FAILURE`

This can produce tragedy, redesign, bounded defeat, or recovery. No automatic moral doom.

## 7. Constriction / Release
Retain only as reader-pressure modulation:

`OPTION SPACE NARROWS ↔ OPTION SPACE REOPENS`

May occur through evidence, consent, relationships, authority, physical access or social position — not only danger.

Reject mandatory threefold/five-stage alternation.

## 8. No Gender-Archetype Gate
Never infer character function, completeness, maturity, morality, or desired ending from masculine/feminine archetypal roles.

`PERSON → OWN VALUES / WANT / RELATIONSHIPS / MODEL / EMBODIMENT → CHOICE`

not

`GENDER SLOT → PSYCHOLOGICAL DESTINY`.

## 9. No Monster-Dehumanization Gate
Physical difference, disability, nonhuman embodiment or unusual morphology cannot be shorthand for evil, egotism, incomplete personhood or psychic darkness.

For conscious/nonhuman agents:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

## 10. Ending Pluralism
Reject `happy ending = heterosexual union + kingdom + wholeness`.

IVDIVO ending contract remains:
`BOOK QUESTION / LOCAL PROBLEM → DECISIVE CHOICE/ACTION → OUTCOME → COST → AFTERMATH → CHANGED STATE → OPTIONAL SERIES VECTOR`.

## 11. Rule-of-Three Firewall
Threefold repetition can be a rhythm/generation tool, but no numerical count is a production requirement.

Use only if repetition changes meaning, pressure, evidence, tactic or relationship.

Failure mode: **NUMEROLOGY-AS-STRUCTURE**.

## 12. Cross-source verdict
Booker is useful as a large comparative corpus of recurring narrative shapes, but his universal explanatory theory is much weaker than his descriptive pattern observations. IVDIVO retains pattern recognition and rejects archetypal determinism.
