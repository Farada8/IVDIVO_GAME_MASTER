## Claims retained

### Subtext is relational, not merely hidden content

`SURFACE EXPRESSION + CONTEXT + RELATIONSHIP + RISK + KNOWLEDGE → POSSIBLE SECONDARY MEANING`.

The same words can carry different subtext in different relationships or situations.

### Subtext may be conscious, unconscious or emergent

A character may deliberately conceal meaning; may reveal more than intended; or the writer may discover an underlying pattern only after drafting.

Therefore:

`AUTHOR INTENT ≠ CHARACTER INTENT ≠ READER INFERENCE`.

### Direct dialogue is not a failure

Seger often recommends avoiding on-the-nose dialogue, but her own examples and Alvin Sargent material imply that directness can be the correct payoff when concealment has ended or when the exact words themselves change the state.

IVDIVO rule:

`SUBTEXT WHEN PRESSURE/RELATIONSHIP CREATES A REASON FOR INDIRECTNESS; DIRECTNESS WHEN DIRECT SPEECH IS CHARACTER-TRUE AND LOAD-BEARING`.

### Subtext can be misread

Characters and readers may infer the wrong hidden meaning. Therefore:

`CUE → INTERPRETATION A / B / C → NEW CONTEXT / EVIDENCE → MODEL UPDATE`.

This is especially important for mystery fairness.

### Backstory should affect present salience and tactics

Biography matters when it changes what a character notices, wants, hides, fears, values or does now. Dossier completeness has no independent value.

### Word choice can reveal stance but can also smuggle interpretation

A loaded verb/adjective may encode the POV's inference. In evidence-sensitive prose distinguish:

`RAW TRACE → NEUTRAL OBSERVATION → POV INTERPRETATION → CORROBORATED CLAIM`.

### Repetition needs developmental movement

Repeated words, images or props may accumulate meaning, but pure repetition without changed relation/context becomes thematic overstatement.

### Analogy is explanatory, not evidentiary

`ANALOGY → HYPOTHESIS / COMPREHENSION AID`, not `ANALOGY → PROOF`.

### Gestures and tempo-rhythm are interpretive cues

Body language and rhythm can communicate pressure and stance, but:

`GESTURE / PAUSE / INFLECTION / SILENCE ≠ MOTIVE FACT ≠ CONSENT ≠ CORROBORATION`.

### Images and genre can carry contextual meaning

Weather, props, sound, setting and genre expectations can create associations. They must remain grounded in the scene rather than become decorative symbolic code.

### Superobjective is useful as an underlying direction, not a hidden thesis

A recurring underlying objective can unify different characters and scenes, but it is only useful if it changes actions, tactics, relations and consequences.

### Sargent provides the strongest anti-formula correction

His workflow is effectively:

`ACTION / INTENTION → CONSEQUENCE → NEXT PROBLEM → LIVE MATERIAL → LATER SUBTEXT RECOGNITION / LAYERING`.

This supports IVDIVO's existing discovery-first process.

## Mechanisms extracted

### M1 — Subtext causal loop

`PRESENT WANT / BOUNDARY → REASON NOT TO SPEAK DIRECTLY → SURFACE TACTIC → LISTENER INTERPRETATION → RESPONSE → TACTIC / RELATION UPDATE`.

### M2 — Subtext fairness

`TRUE SURFACE CUE → PLAUSIBLE INTERPRETATIONS → LATER CONTEXT / EVIDENCE → REINTERPRETATION`.

The early cue remains literally true.

### M3 — Directness payoff

`SUSTAINED INDIRECTNESS → PRESSURE / TRUST / COST CHANGE → CHARACTER CAN/WILL SPEAK DIRECTLY → EXACT WORDS CHANGE STATE`.

### M4 — Exposition ownership

`INFO X → WHO WANTS/NEEDS TO SAY/ASK/HIDE IT? → WHY NOW? → WHY THIS PERSON? → WHAT CHANGES AFTERWARD?`.

If the only answer is `the reader needs to know`, use another mode or rebuild the scene.

### M5 — Character-specific subtext

`VALUE + RELATIONSHIP + STATUS + PRESENT WANT + RISK → WORD CHOICE / OMISSION / TACTIC`.

### M6 — Gesture interpretation chain

`OBSERVED ACTION → POV MODEL OF MOTIVE → ALTERNATIVE MODEL → LATER TEST / CONTEXT`.

### M7 — Image/context layer

`CONCRETE IMAGE / PROP / SOUND → CHARACTER RELATION → REPEATED / CHANGED CONTEXT → EMERGENT MEANING`.

### M8 — Underlying-current audit

`RECURRING UNDERLYING WANT / QUESTION → DIFFERENT CHARACTER TACTICS → COLLISIONS / CONSEQUENCES → CHANGED TERMS`.

### M9 — Discovery-first subtext pass

`LIVE DRAFT → ACTUAL BEHAVIOR / CONSEQUENCES → IDENTIFY UNDERLYING PRESSURE → SUBTEXT / DIRECTNESS AUDIT → RETEST`.

## Failure modes

1. `SUBTEXT MONOCULTURE` — every line must mean the opposite of what it says.
2. `DIRECTNESS PHOBIA` — avoiding clear speech even when it is the earned dramatic action.
3. `MIND-READING FALLACY` — treating cue/gesture/inflection as verified motive.
4. `SILENCE=CONSENT FALLACY` — reading non-response/compliance as permission.
5. `MICROGESTURE CONFETTI` — inserting a gesture between every dialogue line.
6. `PHYSIOGNOMY FALLACY` — treating body/facial form as essence or moral truth.
7. `EXPOSITION PUPPET` — character states information solely for reader delivery.
8. `SYMBOLIC OVERDETERMINATION` — weather, props, names and images all loudly repeat one theme.
9. `ANALOGY-AS-PROOF` — using resemblance as corroboration.
10. `GENRE-AS-ONTOLOGY` — treating SF/horror/romance associations as facts of the world.
11. `ROMANCE-AS-EVIDENCE` — attraction/trust is allowed to alter proof status.
12. `THEME/SUPEROBJECTIVE SERMON` — underlying current becomes explicit author thesis.
13. `JUNGIAN ONTOLOGY LEAK` — shadow/collective-unconscious language treated as psychology/science.
14. `CULTURAL DEFAULT LEAK` — dated gender/class/sexual assumptions treated as universal.
15. `FILM→NOVEL FORMAT LEAK` — visual-screenwriting advice turned into short prose blocks / white-space KPI.
16. `NOTHING-IS-ACCIDENTAL OVERFIT` — every object/word forced to carry symbolic meaning.
17. `SUBTEXT WITHOUT READER GROUND` — hidden meaning depends on information the reader cannot reasonably possess.
18. `INFERENCE WITHOUT STOPPING RULE` — endless hidden readings prevent a usable scene model.

## Cross-source comparison

### Baxter / Chiarella / Kempton / McKee Dialogue

Strong convergence: dialogue is action/tactic and meaning depends on relationship/listening. Seger adds a broader map across image, genre and staging; Baxter provides stronger caution about non-listening and physiognomy; Chiarella/Kempton help compression and direction/speed/distance.

### Collins

Converges on subtext channels and character tactics. Collins' TIME method risks checklist behavior; Seger/Sargent give a useful correction: subtext may emerge organically from action and consequence.

### Booth — irony

Booth provides the missing stopping rule: readers reconstruct hidden meaning from converging cues, but interpretation must eventually stabilize enough for the work's contract.

### Zunshine / Herman / Oatley

These sources strengthen the evidence firewall: surface behavior is input to a mind-model, not direct access to motive.

### Ephron / le Carré / Genette

Mystery fairness requires source lineage, POV honesty and no mutation of earlier literal traces. Seger-style subtext can misdirect, but cannot falsify evidence.

### LaPlante / Prose / Hodgins / Le Guin / Williams-Bizup

Convergence on prose rhythm: subtext beats and gestures do not imply sentence/paragraph breaks. Paragraph continuity and syntax are separate decisions.

## IVDIVO operationalization

### Dialogue / subtext router

`FACT / WANT / BOUNDARY → WHY INDIRECT? → SURFACE TACTIC → LISTENER MODEL → RESPONSE → CHANGED STATE`.

If there is no reason for indirectness, allow direct speech.

### Mystery subtext passport

For any potentially incriminating cue:

`SURFACE FACT → SOURCE → POV ACCESS → INTERPRETATION A/B/C → WHAT WOULD DISCRIMINATE? → CURRENT STATUS`.

### Image / metaphor firewall

`IMAGE / METAPHOR / ANALOGY → ASSOCIATION / HYPOTHESIS`, never automatic evidence.

### Subtext pass timing

Do not force subtext into discovery drafting line by line.

`DRAFT LIVE → STRUCTURE/CAUSALITY → CHARACTER/RELATION → SUBTEXT/DIRECTNESS PASS → PARAGRAPH/RHYTHM PASS`.

### Anti-choppy gate

`SUBTEXT BEAT ≠ SENTENCE BREAK`.

`PAUSE / GESTURE ≠ NEW PARAGRAPH BY DEFAULT`.

If several cues belong to one perceptual/decision unit, keep them in a coherent paragraph.

### Orbital Youth

Youth voice should express future-world norms through what characters imply, omit and assume, not Earth-2020s slang. Directness/indirectness should vary by relationship and institution.

Post-money life should be lived rather than explained: manufactured goods may be background-normal while time, consent, trust, privacy, mastery, belonging and unique opportunity carry real relational subtext.

### B07 — THE UNLISTED CITY

Human interpretation of nonhuman gesture/pattern does not establish personhood. After independent personhood threshold:

`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

### Conscious robots

No universal human body-language or `robot voice` model.

`EMBODIMENT + OWN WANT + MODEL/EVIDENCE + RELATIONSHIP + RISK → COMMUNICATION TACTIC`.

Silence/compliance does not equal consent.

### Consciousness-practice schools

`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Final synthesis

Best retained principle:

`SUBTEXT IS A RELATIONAL INFERENCE SYSTEM, NOT A REQUIREMENT THAT EVERY LINE HIDE THE OPPOSITE MEANING.`

Best production sequence:

`LIVE MATERIAL → CAUSAL / CHARACTER TRUTH → RELATIONAL PRESSURE → SUBTEXT OR DIRECTNESS CHOICE → READER MODEL → RETEST`.
