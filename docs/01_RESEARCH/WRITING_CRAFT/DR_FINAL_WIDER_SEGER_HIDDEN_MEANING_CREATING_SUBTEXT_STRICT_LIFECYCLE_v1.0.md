## High-value claims retained

### Subtext is relational

`SURFACE EXPRESSION + CONTEXT + RELATIONSHIP + RISK + KNOWLEDGE → POSSIBLE SECONDARY MEANING`.

The same words can carry different subtext in different relationships.

### Author intent, character intent and reader inference are different

`AUTHOR INTENT ≠ CHARACTER INTENT ≠ READER INFERENCE`.

Subtext may be deliberate, unconscious or emergent in revision.

### Direct dialogue is not a failure

Use subtext when character/relationship pressure creates a credible reason for indirectness. Use directness when exact speech is itself the earned decision, consent, refusal or relationship turn.

### Subtext can be misread

`CUE → INTERPRETATION A/B/C → NEW CONTEXT/EVIDENCE → MODEL UPDATE`.

This is crucial for mystery fairness.

### Backstory pays only through the present

Biography matters when it changes present salience, want, risk, tactic, relation or choice. Dossier completeness has no independent value.

### Loaded language can smuggle interpretation

In evidence-sensitive prose:

`RAW TRACE → NEUTRAL OBSERVATION → POV INTERPRETATION → CORROBORATED CLAIM`.

### Repetition must develop meaning

Repeated words/images/props earn space only when context, relation, tactic or meaning changes.

### Analogy is not evidence

`ANALOGY → HYPOTHESIS / COMPREHENSION AID`, not proof.

### Gesture is an interpretive cue

`GESTURE / PAUSE / INFLECTION / SILENCE ≠ MOTIVE FACT ≠ CONSENT ≠ CORROBORATION`.

### Images/genre create associations, not world facts

Metaphor, prop, weather, sound and genre expectation can prime reader inference; they cannot mutate source facts or evidence status.

### Superobjective is useful only if causally paid

An underlying current earns its place only when it changes tactics, collisions, choices, relations and consequences.

### Alvin Sargent is the strongest internal anti-formula correction

`ACTION / INTENTION → CONSEQUENCE → NEXT PROBLEM → LIVE MATERIAL → LATER SUBTEXT RECOGNITION / LAYERING`.

Do not force hidden meaning into every discovery-draft line.

## Mechanisms

1. `PRESENT WANT / BOUNDARY → REASON NOT TO SPEAK DIRECTLY → SURFACE TACTIC → LISTENER INTERPRETATION → RESPONSE → TACTIC / RELATION UPDATE`.
2. `TRUE SURFACE CUE → PLAUSIBLE INTERPRETATIONS → LATER CONTEXT/EVIDENCE → REINTERPRETATION`.
3. `SUSTAINED INDIRECTNESS → PRESSURE/TRUST/COST CHANGE → EARNED DIRECTNESS → CHANGED STATE`.
4. `INFO X → WHO WANTS/NEEDS TO SAY/ASK/HIDE IT? → WHY NOW? → WHY THIS PERSON? → WHAT CHANGES?`.
5. `VALUE + RELATIONSHIP + STATUS + PRESENT WANT + RISK → WORD CHOICE / OMISSION / TACTIC`.
6. `OBSERVED ACTION → POV MOTIVE MODEL → ALTERNATIVE MODEL → TEST / CONTEXT`.
7. `CONCRETE IMAGE / PROP / SOUND → CHARACTER RELATION → CHANGED CONTEXT → EMERGENT MEANING`.
8. `RECURRING UNDERLYING WANT / QUESTION → DIFFERENT TACTICS → COLLISIONS / CONSEQUENCES → CHANGED TERMS`.
9. `LIVE DRAFT → ACTUAL BEHAVIOR / CONSEQUENCES → UNDERLYING PRESSURE → SUBTEXT/DIRECTNESS AUDIT → RETEST`.

## IVDIVO operationalization

### Dialogue/subtext router

`FACT / WANT / BOUNDARY → WHY INDIRECT? → SURFACE TACTIC → LISTENER MODEL → RESPONSE → CHANGED STATE`.

If there is no credible reason for indirectness, allow direct speech.

### Mystery passport

`SURFACE FACT → SOURCE → POV ACCESS → INTERPRETATION A/B/C → DISCRIMINATING TEST → CURRENT STATUS`.

### Image/metaphor firewall

`IMAGE / METAPHOR / ANALOGY → ASSOCIATION / HYPOTHESIS`, never automatic evidence.

### Subtext pass timing

`DRAFT LIVE → STRUCTURE/CAUSALITY → CHARACTER/RELATION → SUBTEXT/DIRECTNESS PASS → PARAGRAPH/RHYTHM PASS`.

### Anti-choppy gate

`SUBTEXT BEAT ≠ SENTENCE BREAK`.

`PAUSE / GESTURE ≠ NEW PARAGRAPH BY DEFAULT`.

Multiple cues in one perceptual/decision unit should normally remain in a coherent paragraph.

`SUBTEXT IS A RELATIONAL INFERENCE SYSTEM, NOT A REQUIREMENT THAT EVERY LINE HIDE THE OPPOSITE MEANING.`
