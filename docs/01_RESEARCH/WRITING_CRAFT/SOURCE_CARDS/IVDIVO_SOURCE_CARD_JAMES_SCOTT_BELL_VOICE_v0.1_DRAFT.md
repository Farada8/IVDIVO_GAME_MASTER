## Source passport

**Primary problem addressed:** how a writer develops distinctive prose/narrative voice rather than merely competent prose.  
**School/tradition:** pragmatic commercial-fiction craft with strong character/actor-method emphasis.  
**Strongest contribution:** CAP model; character-specific attitude; description filtered through mood/inner life; practical variation exercises.  
**Best IVDIVO use:** character voice differentiation, POV repair, description, anti-homogenization and line-edit preparation.  
**Weakness if over-applied:** “attitude” can be mistaken for mandatory heat/snark; exercises can become gimmicks; authorial emotional identification is not a substitute for social/cultural research; genre examples are illustrative, not exhaustive laws.  
**Not sufficient for:** narratology, sociolinguistics, dialect ethics, multilingual characterization, empirical YA psychology, discourse analysis or complete prose theory.

## Current bounded conclusion

Bell provides a strong practical antidote to generic narrator voice: make the prose arise from the perceiving character's history, language, attitude and current emotional state, then realize it with sentence craft.

For IVDIVO the core adopted mechanism is:

`LIVED HISTORY → ATTENTIONAL BIAS → INTERPRETATION → LANGUAGE / IMAGE / RHYTHM → VOICE`.
