## Source passport
Primary contribution: a cross-level practical toolbox that connects sentence/paragraph decisions with story architecture and writing process.

Strongest current relevance to IVDIVO:
1. tools are diagnostics, not universal rules;
2. sentence length controls speed;
3. paragraph length/breaks should match intent;
4. white space and distinctive words are emphasis resources;
5. difficult concepts benefit from simple presentation, not disconnected fragments;
6. movement up/down abstraction prevents technical exposition from floating free of experience;
7. a dominant reader-facing question acts as macro story engine;
8. readers need distributed rewards, especially in the middle;
9. cliffhangers must be attached to live uncertainty;
10. selection/order should precede line polish.

## Current mechanisms
- `FUNCTION → READER SPEED → SENTENCE SHAPE`.
- `PARAGRAPH BREAK → FOCUS/TURN/BREATH/IMPACT OR ERROR`.
- `CONCRETE EVENT → EFFECT → INTERPRETATION → ABSTRACT MODEL → CONSEQUENCE`.
- `MACRO QUESTION → SEQUENCE PRESSURE → PARTIAL ANSWER → CONSEQUENCE → HARDER QUESTION`.
- `TENSION/WORK → READER REWARD → RENEWED PRESSURE`.
- `EXPLORE/COLLECT → FOCUS → SELECT → ORDER → DRAFT → REVISE`.

## Limits / failure modes
- Clark draws heavily from journalism/nonfiction as well as fiction; transfer requires medium awareness.
- Short sentence emphasis is not a command to fragment prose.
- Paragraph variation is not a numerical optimization target.
- “Gold coins” must be story-earned, not decorative entertainment beats.
- Key-question engine cannot substitute for causal scene construction.
- Do not apply all tools simultaneously while drafting; route by stage/defect.

## Cross-source position
