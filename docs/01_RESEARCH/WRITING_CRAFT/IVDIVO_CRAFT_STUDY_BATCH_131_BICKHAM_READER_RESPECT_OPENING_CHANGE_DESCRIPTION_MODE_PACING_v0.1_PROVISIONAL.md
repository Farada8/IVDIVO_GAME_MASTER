## 1. Reader-respect gate
Bickham repeatedly warns against condescension and self-display.

### IVDIVO mechanism
`COMPLEX WORLD / IDEA -> WHAT THIS POV NEEDS NOW -> LEGIBLE FORM -> READER INFERENCE`

A sophisticated world does not require sophisticated-sounding sentences.

### Gate B131-G01 — No Prestige Fog
Technical, institutional or philosophical diction must perform a precise job. If it only signals intelligence/status, simplify or remove it.

### Failure mode
`PRESTIGE VOCABULARY AS WORLD DEPTH`.

---

## 2. Expertise is background fuel, not foreground entitlement
Specialist knowledge should support a character's problem, not become a lecture proving author research.

### Gate B131-G02 — Expertise Must Change State
Keep specialist detail if it changes:
- action;
- model/evidence;
- authority/access;
- relationship/trust;
- risk;
- next option.

Otherwise compress, relocate or bank it.

### Application to IVDIVO
Orbital engineering, robot embodiment and consciousness-school vocabulary do not receive prose space merely because the database contains them.

---

## 3. Opening: preserve the change function, reject mandatory threat
Bickham argues that fiction starts at threat/change. The transferable mechanism is **change**, not mandatory danger.

### IVDIVO opening model
`LIVED BASELINE -> MEANINGFUL CHANGE / RESPONSIBILITY / OPPORTUNITY / ANOMALY -> CHARACTER-SPECIFIC RESPONSE -> STORY PROMISE`.

Valid opening changes include:
- first real responsibility;
- admission/qualification;
- refusal;
- consent request;
- relationship shift;
- unexpected evidence;
- opportunity with cost;
- system success that creates new duty.

### Gate B131-G03 — No Disaster Retrofit
Do not move a later catastrophe into Chapter 1 merely to satisfy a craft dictum.

---

## 4. Description is a pacing/mode decision
Bickham's early pacing taxonomy distinguishes exposition, description, narrative, dialogue and dramatic summary.

IVDIVO must not accept his speed hierarchy literally, but the routing insight is useful:

`READER EFFECT NEEDED -> MODE -> DURATION -> AMOUNT OF DETAIL -> RHYTHM`.

### Gate B131-G04 — Mode Before Syntax
If a passage drags, first ask whether it should be:
- summary;
- scene;
- embedded scene;
- dialogue;
- indirect dialogue;
- concise exposition.

Do not first shorten every sentence.

---

## 5. Causally loaded description
Bickham's own sunset exception is structurally useful: description earns unusual length when the described phenomenon itself changes the dramatic situation.

### IVDIVO model
`DESCRIPTION VARIABLE -> CHANGES TIME / ACCESS / PHYSICAL POSSIBILITY / EVIDENCE / RELATION -> READER TRACKS IT AS STORY`.

Examples:
- changing light affects sensor confidence;
- gravity transition alters movement/options;
- door state changes consent/privacy;
- weather erases evidence;
- robot embodiment creates/denies an affordance.

### Failure mode
`DECORATIVE DURATION WITHOUT CAUSAL LOAD`.

## 6. Anti-'обрубки' convergence
Bickham's delivery-mode discussion converges with Scofield, LaPlante, Rosenfeld, Lodge, Prose and Zinsser.

Updated principle:
**Choppiness is often a mode-selection error before it is a sentence-length error.**

Pipeline:
`ONE MAIN STORY -> CHAPTER FUNCTION -> SCENE NECESSITY -> SCENE WEIGHT -> NARRATIVE MODE -> POV/EVIDENCE -> PARAGRAPH INTENT -> READER-STATE CONTINUITY -> SENTENCE RHYTHM -> WORDING`.

### Failure mode
`SHORT-SENTENCE PACING SUBSTITUTE`.

## 7. Cross-source comparison
### Bickham vs Doty
Bickham fears description stopping motion; Doty treats description as attention/thinking.

IVDIVO synthesis:
Description is strong when it either:
1. changes a story variable; or
2. changes the POV/reader model in a way that affects later interpretation/action.

Thus description need not contain external motion, but must have **functional motion**.

### Bickham vs Scofield
Bickham emphasizes forward movement; Scofield allows embedded/elliptical scene structures.

Synthesis:
`FORWARD MOVEMENT != CONSTANT FULL-SCENE ACTION`.
Summary, commentary, interiority and description may move knowledge, relation, commitment or option space.

### Bickham vs Swain
Both privilege cause/effect and reader clarity; IVDIVO retains the diagnostic causal core while rejecting rigid commercial-era prescriptions.

## 8. YA / Orbital Youth application
Do not introduce the future by explaining it.

Preferred:
`ordinary youth want -> future-world rule becomes relevant -> choice/friction -> consequence -> reader learns world`.

Do not make post-money society sound sophisticated through abstract institutional nouns. Resolve every abstraction into:
- who decides;
- what is allocated/accessed;
- why;
- who can refuse/appeal;
- what is genuinely scarce/nonfungible.

---

## 9. Conscious robots
No universal simplified or technical robot register is required.

Technical precision must be person-specific and relationally specific.
A robot's extensive knowledge does not license exposition unrelated to its current want/task.
