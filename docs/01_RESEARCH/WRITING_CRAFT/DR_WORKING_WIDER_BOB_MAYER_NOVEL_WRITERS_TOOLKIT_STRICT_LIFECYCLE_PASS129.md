## Tool 1 — provisional mechanisms
- creation needs practice, persistence and real lived attention rather than mystical talent;
- process is individual: outline-heavy/rewrite-light and discovery-heavy/rewrite-heavy can perform equivalent underlying cognitive work;
- open-mindedness includes willingness to revise one's own craft model;
- validation-seeking is not the same as useful feedback;
- writer's block should be troubleshot before adding random story events.

## Tool 2 — provisional mechanisms
- externalized cognitive infrastructure reduces continuity load;
- maintain character/fact registers, maps/diagrams, story grids and source-preserving research notes;
- `STORY GRID ≠ OUTLINE`: outline records intended future; grid records what the manuscript actually did;
- spatial/temporal diagrams are causal-continuity tools, not decoration;
- tools should reduce friction rather than become writing avoidance.

## Tool 3 — provisional mechanisms
- `IDEA ≠ STORY`;
- writer emotion does not guarantee reader emotion;
- strong personal interest may seed a story but is not evidence that the premise works;
- market trend is not story authority;
- Mayer's claim that the original idea must never change is rejected as too rigid.

Replacement:
`ORIGINATING PROMISE / HYPOTHESIS → DRAFT EVIDENCE → CHARACTER / CANON / CAUSALITY TEST → KEEP / REPLAN / BANK / DISCARD`.

## Tool 4 — provisional mechanisms
### Research as story construction
`QUESTION → SOURCE / OBSERVATION → SELECTED ACTIONABLE DETAIL → STORY CONSEQUENCE`.

Expert accuracy is necessary where facts matter, but research volume does not earn page time. The novelist selects the material that serves the story.

### Book dissection
Useful dimensions:
- premise/idea;
- transformation into story;
- opening position;
- POV;
- scope/bookends;
- pacing;
- ending/payoff;
- subplot payment into the main line;
- setting function;
- omissions.

This is mechanism extraction, not imitation.

### Outline vs actual manuscript
Mayer explicitly allows the outline to change when writing reveals physical, spatial, causal or character facts the outline did not anticipate.

Production law:
`PLAN = HYPOTHESIS; WRITTEN/LOCKED STATE = EVIDENCE`.

### Chapter planning
Useful stable questions:
`START STATE → CHARACTERS / TIME / PLACE → REQUIRED EVENTS → CONTINUITY DEBTS → END STATE → CHAPTER FUNCTION`.

Reject the idea that every chapter must maximize the number of functions. Multifunctionality is useful only while clarity and reader effect remain strong.

## Tool 5 — provisional mechanisms
### Defect levels
Mayer separates idea, character, story construction, POV, pacing and execution. This supports diagnosis before line polish.

### Narrative structure
His inciting incident → complications → crisis → climax → resolution is treated as one commercial model, not IVDIVO law.

Rejected as universal:
- protagonist/antagonist mandatory pairing;
- escalating suspense as the primary engine of nearly all fiction;
- darkest-moment crisis;
- all loose ends must close;
- climax always requires protagonist vs antagonist;
- action should always be shown rather than summarized.

### Coincidence
Useful core:
`COINCIDENCE MAY CREATE/COMPLICATE; IT MUST NOT REPEATEDLY SOLVE FROM OUTSIDE THE CAUSAL SYSTEM`.

### Show / tell
Mayer himself admits it is a sliding scale. IVDIVO keeps mode routing rather than show-purism.

### Backstory / memory
Useful distinction:
`MEMORY = PERSON-SOURCED MODEL OF PAST`, not objective world fact.

### Pace / reader weighting
Important mechanism:
`TEXTUAL DURATION / SPACE → READER ASSUMES RELATIVE IMPORTANCE`.

If a trivial office description receives the same reader-time as a major relocation, the discourse may mis-weight the story even when the event hierarchy is correct.

### Ending
Retain local payoff / aftermath distinction, but reject universal closure of every uncertainty. Series/mystery proof ceilings remain authoritative.
