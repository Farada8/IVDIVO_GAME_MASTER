## STRUCTURE MAP

### Phase A — inherited stigma + inaccessible dream
Spensa's desire to fly is specific and active, while her father's public coward narrative changes access before her own behavior is evaluated.

### Phase B — qualification without belonging
She earns training access but remains socially/logistically excluded. Embodied skill begins replacing fantasy competence.

### Phase C — team formation + real loss
The flight differentiates by role, temperament and ability. Deaths expose the difference between heroic story-language and lived consequence.

### Phase D — alternate competence + M-Bot relationship
Rig exits the inherited dream and discovers engineering competence. M-Bot introduces independent nonhuman preference, inherited orders and ambiguous self-model.

### Phase E — official story destabilization
Cobb, Ironsides, battle records and Spensa's own unusual experience create a ladder from public narrative to contradictory traces to a narrower new model.

### Phase F — institutional/peer incentive conflict
Formal safety, honor rhetoric, rank, stigma and actual behavior diverge. Metric success can conflict with mission competence.

### Phase G — distributed team competence
Different pilots become valuable for different functions. A single linear ranking no longer represents actual team value.

### Phase H — final disclosure + local action
The father's event, Spensa's own phenomenon and institutional concealment partially resolve. The immediate defense problem receives a local answer while larger cytonic/Krell ontology remains open.

## CORE CLAIMS / MECHANISMS

### 1. Formal role is not belonging
`QUALIFICATION / TITLE → INFRASTRUCTURE + SOCIAL ACCESS + VOICE + RELATIONSHIPS → ACTUAL BELONGING`.

Being admitted does not mean being included.

### 2. Same public ideal can create unequal burden
`PUBLIC VALUE CLAIM → FORMAL RULE → INFORMAL EXCEPTION / STIGMA → WHO BENEFITS → WHO PAYS`.

### 3. Unfair access and competence are different variables
`UNFAIR ACCESS ≠ INCOMPETENCE`.
`COMPETENCE ≠ LEGITIMACY`.

A privileged cadet can be genuinely excellent; a disadvantaged cadet can be genuinely difficult. This makes institutional pressure more credible than moral sorting.

### 4. Theory is not embodied skill
`KNOWLEDGE → LIVE EXECUTION → BODY / SENSORIUM LIMIT → PRACTICE → UPDATED SELF-MODEL`.

### 5. Dream ownership
`SHARED PREPARATION ≠ SHARED LIFE GOAL`.

Rig's exit from pilot training is not failure. Qualification and sunk effort do not create a duty to continue.

### 6. Success can escalate responsibility
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Do not require setback monoculture.

### 7. Uniform metric can mismeasure mission value
`REAL OBJECTIVE → PROXY METRIC → RATIONAL AGENT OPTIMIZES METRIC → METRIC WIN / MISSION FAILURE → RULE REVISION`.

Production test:
`WHAT IS MEASURED? → WHAT ACTUALLY MATTERS? → CAN SOMEONE WIN THE SCORE WHILE HARMING THE REAL TASK?`

### 8. Role-specific competence beats universal ranking
`PERSON → SPECIFIC CAPABILITY → SPECIFIC LIMIT → TEAM CONFIGURATION → NEW COLLECTIVE OPTION`.

Kimmalyn, FM, Hurl, Jorgen, Spensa and others are not useful on one single axis.

### 9. Official policy and status culture can conflict
`WRITTEN SAFETY RULE → PEER / INSTRUCTOR STATUS SIGNAL → INFORMAL NORM → ACTUAL BEHAVIOR`.

An institution can sincerely publish one rule while socially rewarding another.

### 10. Public disclosure changes relationship state, not truth status
`CONTROLLED FACT → PUBLIC DISCLOSURE → AUDIENCE MODEL UPDATE → BELONGING / SELF-PRESENTATION / ACCESS CHANGE`.

But:
`MORE PEOPLE KNOW X ≠ X BECOMES MORE TRUE`.

### 11. Stigma is a causal public model
`PAST PUBLIC NARRATIVE → AUDIENCE / INSTITUTION MODEL → ACCESS / REPUTATION CONSEQUENCE → CURRENT PERSON RESPONSE`.

Do not confuse inherited public story with evidence about current motive or character.

### 12. Countermodel ladder for institutional mystery
`OFFICIAL VERSION → CONTRADICTORY TRACE → LIVED EXPERIENCE → TECHNICAL / WITNESS CORROBORATION → NARROWER NEW MODEL → ACTION`.

Useful for mystery without requiring an all-knowing conspiracy.

### 13. Local operational answer / global ontology unknown
A book may resolve what the protagonist must do now while leaving the deeper nature/origin of the phenomenon open.

`LOCAL EVIDENCE → BOUNDED MODEL → BOUNDED ACTION`.

Do not turn a late reveal into an ontology lecture.

### 14. Predictable policy becomes attack surface
`VISIBLE HIGH-VALUE OBJECTIVE → PREDICTABLE RESPONSE POLICY → ADVERSARY MODELS POLICY → DECOY / SECONDARY ATTACK`.

Reasonable policy can become exploitable when perfectly predictable.

### 15. Distributed competence convergence
`ONE CAUSAL PROBLEM + DISTINCT CAPABILITIES + INTERDEPENDENT ACTIONS → CONVERGENCE`.

The protagonist does not need to see, understand and solve every layer personally.

### 16. Nonhuman personhood is not human imitation
M-Bot demonstrates a usable fiction mechanism:
`OWN PREFERENCE → OWN RELATIONSHIPS → INHERITED CONSTRAINT / ORDER → CONSENT / REFUSAL → SELF-AUTHORED CHOICE → CONSEQUENCE`.

`NONHUMAN PERSONHOOD ≠ BECOMING HUMAN`.

### 17. Controlled action is not motive
`ACTION → CONTROL / ORDER PROVENANCE → AVAILABLE CHOICE → MOTIVE HYPOTHESES → RESPONSIBILITY STATUS`.

Assigned instructions or embedded constraints must not be collapsed into personal desire.

### 18. Relationship through epistemic work
Spensa/M-Bot and flight relationships grow through shared tasks, boundary tests, evidence exchange and revised models of one another—not only disclosure speeches.

### 19. Fear / grief can coexist with competence
`EMOTION PRESENT ≠ UNFITNESS`.

A skilled actor can remain afraid, grieving or uncertain while still functioning. Performance and emotional state are related but not identical variables.

### 20. Youth voice is attitude, not slang
The protagonist's register comes from what she values, exaggerates, misreads, performs and gradually revises. Do not imitate surface slang or rhetorical fragmentation as a house style.

## CROSS-SOURCE COMPARISON

- **Swain:** Skyward validates success→responsibility and changed-state middles, while showing why mandatory disaster in every scene is unnecessary.
- **Brody:** supports YA autonomy/belonging pressures, but the novel's progression does not require fixed beat percentages or mandatory Dark Night architecture.
- **Collins:** both examine youth/institution/public identity; Skyward is stronger as a lab for competence differentiation, belonging after qualification and official-policy/informal-culture gaps.
- **Wells:** M-Bot is useful for nonhuman preference and inherited control; Wells remains stronger for sustained private synthetic subjectivity and refusal/consent analysis.
- **Weir:** both use competence and model revision; Weir is stronger for explicit observation→test science, Skyward for youth/team/institutional social ecology.
- **Crouch:** identity and ontology ambiguity are relevant, but Crouch's speculative physics remains fiction-only; Skyward similarly cannot establish IVDIVO metaphysics.
- **Baxter / McKee Dialogue:** use these when Skyward-style team banter risks turning all young characters into one witty authorial voice.
- **Card / Corbett:** use for relationship-specific self and independent personhood when adapting ensemble functions.

## IVDIVO OPERATIONALIZATION

### Orbital Youth
Use Skyward for:
- qualification without belonging;
- role-specific competence;
- peer culture vs official safety;
- first real responsibility;
- public stigma changing access;
- success creating harder responsibility;
- team convergence without equal POV time;
- mentor/institution disagreement without cartoon villainy.

Do NOT import:
- food scarcity;
- merit chits / requisition economy;
- inherited financial privilege as default;
- militarization as default adolescence;
- glory/death rhetoric as ordinary IVDIVO value system.

Post-money translation:
`money/status good → TRUST / ROLE / QUALIFICATION / TIME / CONSENT / UNIQUE OPPORTUNITY / REPUTATION / RESPONSIBILITY / BELONGING`.

### Conscious robots
Apply:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Assigned function, inherited order or designed capability must not define the whole person.

### Consciousness schools
Skyward's cytonic material is fiction mechanism only.
Maintain:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → ONTOLOGY CEILING`.

### Mystery / evidence
Use the official-story contradiction ladder, but keep:
`WORLD FACT ≠ OFFICIAL RECORD ≠ CHARACTER BELIEF ≠ PUBLIC NARRATIVE`.

### Prose / rhythm
Do not imitate Sanderson action cadence as an IVDIVO default.
`SUSPENSE ≠ FRAGMENT DENSITY`.
Use the established router through scene necessity, paragraph intent and reader-state continuity before sentence rhythm.
