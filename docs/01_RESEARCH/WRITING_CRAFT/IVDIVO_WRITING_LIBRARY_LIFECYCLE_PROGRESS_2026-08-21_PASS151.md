## Provisional mechanisms retained
1. **Pattern-After-Causality**
   `ACTUAL CAUSAL SPINE → PATTERN SIGNATURE → OPTIONAL COMPARISON → DIAGNOSIS`.

2. **Pattern Overlap**
   Multiple pattern signatures may coexist when each changes the same main causal engine.

3. **Quest Goal Architecture**
   Trackable distant goal + constraints + strategy updates can be useful diagnostics.

4. **Voyage-and-Return Model Update**
   A genuinely unfamiliar environment/system must alter affordances, relationships, model or future choice; otherwise it is world-tourism.

5. **Recognition as Evidence/Relationship Revision**
   `MIS-MODELLED STATE → DISCRIMINATING EVIDENCE → MODEL UPDATE → CHANGED ACTION/RELATION`.

6. **Blind-Spot Progression**
   `STRONG LOCAL MODEL → IGNORED VARIABLE → CONSEQUENCE → PATCH → MORE ENTANGLEMENT`.

7. **Constriction / Release**
   Can be used as an option-space / reader-pressure diagnostic, not mandatory rhythm.
