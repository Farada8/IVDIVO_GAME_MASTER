# 1. POV — useful core

Rosenfeld’s useful claim is not “choose first/third person correctly” but:

`POV = ACCESS + DISTANCE + SELECTION + ORIENTATION`.

A reader should know whose perceptions govern the scene. A switch in access should be deliberate and should buy story value.

### IVDIVO rule
Switch POV only if new access materially changes:
`KNOWLEDGE / INTERPRETATION / EMOTIONAL PRICE / IRONY / DECISION ACCESS`.

### Failure mode
**POV WHIPLASH:** character A’s interiority → unexplained access to B → return to A, with no new structural value.

# 2. Multiple protagonists — correction to Rosenfeld

Rosenfeld recommends roughly equal stage time for co-protagonists. This is **not promoted** to IVDIVO law.

Cross-source correction from Card + current Writers’ Room practice:

`SAGA EQUALITY ≠ BOOK-LEVEL EQUAL POV ACCOUNTING`.

A five-person ensemble may remain equally important across the saga while one book has:
- one primary protagonist;
- one secondary major;
- several supporting majors;
- selective POV distribution.

Mechanical ABC/ABC chapter rotation is allowed only when it improves causality and reader effect.

### Gate
**NO EQUAL-TIME ACCOUNTING:** word count/POV count follows causal ownership and promise, not fairness arithmetic.

---

# 3. Secondary/minor characters — correction to Rosenfeld

Rosenfeld’s hierarchy insight is valuable: page time and interior access create reader expectations. Her narrower idea that allies primarily exist to support the protagonist is too limited for IVDIVO social/ensemble fiction.

### IVDIVO synthesis
A recurring supporting person must satisfy both:
1. **STORY FUNCTION** — affects A-story/major character;
2. **INDEPENDENT LIFE** — has own wants, obligations, relationships and capacity to refuse.

For conscious robots this becomes mandatory. A robot that exists only to assist human protagonists is not yet written as a person.

### Strong diagnostic
`Can the reader imagine this character’s day if the protagonist disappeared?`
If no, deepen or demote.

### Failure modes
- **ALLY-AS-TOOL**
- **MINOR-CHARACTER FALSE PROMISE**
- **SUPPORTING-CHARACTER TAKEOVER** when page/POV/arc weight silently promotes the person without paying the new promise.

# 4. Transitions — direct anti-fragmentation value

Rosenfeld is strongest here.

Transitions should:
- orient changed person/place/time/state;
- compress mundane elapsed time;
- skip travel/process with no story value;
- connect the next scene to prior consequence.

### IVDIVO transition law
`WHAT CHANGED? → ORIENT ONLY WHAT MATTERS → ENTER NEXT CAUSAL MOMENT`.

Do not dramatize every:
`door → corridor → elevator → transport → check-in → setup`.

But transit remains a scene when transit itself changes:
- gravity/orientation;
- social rule;
- timing;
- relationship;
- knowledge;
- risk;
- character model.

This distinction is crucial for Orbital Youth: Chapter 3 earns detailed transit because the characters’ wrong assumptions about movement are the story. Later routine travel should often collapse into one line.

# 5. Revision — useful core and major correction

Rosenfeld’s scene assessment is useful as a diagnostic, especially:
- causal connection to prior scene;
- protagonist effect;
- new information/meaning;
- consequences requiring later response;
- relevance of setting/dialogue/action;
- cut/merge tests.

But two claims are too absolute:
1. a scene is not a vignette merely because one plot-centric checkbox is “no”;
2. every scene does not need fresh external plot information.

### IVDIVO changed-state test
A scene survives if it produces a nonredundant change in one or more:
`EVENT / DECISION / EMOTION / RELATIONSHIP / KNOWLEDGE / STATUS / ACCESS / SAFETY`.

### Structural order
`BOOK ENGINE → CHAPTER CAUSALITY → SCENE FUNCTION → POV/STAGING → PARAGRAPH/RHYTHM → SENTENCE/WORD`.

A structurally wrong scene must not be “fixed” by adding sensory detail, dialogue, action or a complication from a checklist.

# 6. Final cross-source synthesis

## Rosenfeld + Bell
Scene pressure and suspense are meaningful uncertainty, not mandatory speed. Slow suspense is legitimate.

## Rosenfeld + Card
POV/access and hierarchy converge; Card corrects Rosenfeld’s equal-time co-protagonist rule.

## Rosenfeld + Chatman
Chatman protects satellites/quiet scenes from Rosenfeld’s too-plot-centric vignette test.

## Rosenfeld + Kress/Hodgins
Motivation and emotional reaction must be causally prepared; if staging/POV is wrong, re-imagine rather than line-polish.

## Rosenfeld + Zunshine
Withholding is allowed only with source/knowledge fairness; suspense cannot convert inference into fact.

## Rosenfeld + Le Guin/Clark
Pace and syntax are functional/contrastive. Short paragraphs and sentences are not quality targets.
