## Provisional mechanisms earned from sequential material

### 1. INSIDE-OUT CHARACTERIZATION
Collins’s useful causal direction is:
`BACKGROUND / EXPERIENCE → INTERPRETIVE VALUE → TRAIT / HABIT → ACTION UNDER PRESSURE`.

IVDIVO correction: a character must not be reduced to one deterministic “core truth.” Values can conflict, change priority by relationship/context, and be only partly conscious.

### 2. CHARACTER ↔ PLOT CIRCULAR DESIGN
Collins explicitly treats character and plot discovery as circular rather than a one-way pipeline. Operationalized:
`CHARACTER HYPOTHESIS → PRESSURED CHOICE → PLOT CONSEQUENCE → NEW CHARACTER EVIDENCE → UPDATE CHARACTER MODEL / PLOT`.

This supports live-material revision while preserving canon/personhood gates.

### 3. SCENE WANT BEFORE PERFORMANCE DETAIL
The Introduction previews Action Objectives as scene-specific wants that cause speech and movement. This is provisional until Secret #2 is strict-read, but it reinforces:
`PRESENT WANT → TACTIC → RESPONSE → TACTIC / MODEL CHANGE`.

Gesture, voice, sentence rhythm, and subtext should grow from the scene’s causal pressure rather than be decorative characterization.

### 4. CRAFT PASSES, NOT 100 SIMULTANEOUS RULES
Collins explicitly warns that dissected steps are for learning/troubleshooting and should become less consciously mechanical with practice. IVDIVO production law:
`GENERATE LIVE MATERIAL → DIAGNOSE THE RELEVANT LAYER → APPLY THE FEWEST RELEVANT GATES → RETEST`.

This converges strongly with Lamott, LaPlante, Swain, Bell, and Bickham.

## Provisional failure modes
- **CORE-TRUTH REDUCTION** — one value explains every action.
- **OUTSIDE-IN QUIRK DESIGN** — accent, gesture, clothes, or tic substitutes for causal character construction.
- **PLOT-PUPPET VALUE** — “inner value” is selected only because the outline needs a choice.
- **AUTHOR-PROXY VALUE COLLAPSE** — ensemble members inherit the same worldview because the theme matters to the author.
- **METHOD-ACTING SCIENCE LEAK** — historical acting theory is treated as verified psychology.
- **ANTHROPOCENTRIC PERSONHOOD** — conscious robots are judged by human emotional display rather than autonomous wants, models, consent, and choices.
- **CHECKLIST FREEZE** — every characterization step is consciously applied during first-draft sentence generation.
