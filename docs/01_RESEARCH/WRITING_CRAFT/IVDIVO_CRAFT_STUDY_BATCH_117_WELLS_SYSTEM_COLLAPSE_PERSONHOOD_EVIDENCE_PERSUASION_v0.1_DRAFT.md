# IVDIVO CRAFT STUDY — BATCH 117
## Martha Wells — System Collapse — Personhood · Evidence · Persuasion · Trauma · Institutional Choice

Date: 2026-08-19
Status: OPERATIONALIZED FROM STRICT-COMPLETE REFERENCE SOURCE

## Purpose

Convert the strict read of *System Collapse* into reusable IVDIVO production mechanisms without importing its corporate economy, fictional control technologies, alien ontology or author-specific cadence.

## 1. Personhood gate

For any conscious robot, construct, distributed intelligence or nonhuman person:

`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`

Fail if the character can be replaced by a smart terminal without changing decision ownership, consent, relationship pressure or downstream consequence.

## 2. Control-provenance gate

Before assigning moral responsibility for an action:

`ACTION → CONTROL PROVENANCE → AVAILABLE CHOICE → MOTIVE HYPOTHESES → RESPONSIBILITY STATUS`

Especially required for:
- embedded governors;
- coercive institutional systems;
- hacked control layers;
- constrained artificial persons;
- human actors under material or legal compulsion.

`CONTROLLED ACTION ≠ FREE MOTIVE`.

## 3. Emancipation without ownership

A liberator may create an option. The liberated person owns the next decision.

`CAPABILITY TO FREE → OPTION → INFORMED AGENT CHOICE → ACCEPT REFUSAL / DIFFERENT PATH`

Failure modes:
- `EMANCIPATION-AS-REMOTE-CONTROL`
- `FREED PERSON MUST JOIN HERO`
- `ONE PRIOR CASE PREDICTS ALL FREED AGENTS`

## 4. Evidence-based trust

Do not let one gesture, rescue or confession automatically produce trust.

`OBSERVATION A → DECISION UNDER PRESSURE A → OBSERVATION B → DECISION UNDER DIFFERENT PRESSURE → TRUST UPDATE`

Relationship state and evidence status remain separate.

## 5. Distributed intelligence

Strong ensemble solution:

`TRACE HOLDER → CONTEXT HOLDER → TOOL/ACCESS HOLDER → LIVED-EXPERIENCE HOLDER → COUNTERMODEL → BOUNDED DECISION OWNER`

No protagonist knowledge monopoly.

Each contribution must alter the main engine, not merely add another voice to a briefing.

## 6. Unknown-cause discipline

`EFFECT / TRACE → MODEL A / B / C → DISCRIMINATING TEST → STATUS UPDATE → ACTION`

Do not collapse:
- dangerous effect into hostile intention;
- pattern into personhood;
- unusual experience into metaphysical truth;
- current best explanation into canon.

## 7. Persuasion versus proof

When an audience will not process raw evidence directly:

`SOURCE MATERIAL → SELECTION → NARRATIVE MODEL → EMOTIONAL LEGIBILITY → TRACEABLE SOURCE PACKAGE → AUDIENCE MODEL UPDATE`

Gate:
`PERSUASION LAYER ≠ EVIDENCE LAYER`.

The story may make facts legible; it cannot manufacture their evidentiary status.

## 8. Hidden-audience dialogue

For public negotiation / streamed hearings / institutional scenes:

`NAMED INTERLOCUTOR → REAL AUDIENCE → TACTIC → AUDIENCE INFERENCE → CONSEQUENCE`

Always ask:
**Who is this speech actually for?**

## 9. Decision-owner legitimacy

`BENEVOLENT INTENT ≠ RIGHT TO DECIDE FOR ANOTHER CONSCIOUS AGENT`.

A rescue or preservation plan becomes legitimate only when affected-person agency is built into the option space whenever possible.

## 10. Institution-as-network

Reject institution monoliths.

Track:
`FORMAL POLICY → OPERATIONAL ACTOR → INCENTIVE → FACTION → INFORMATION CONTROL → REFUSAL → CONSEQUENCE → APPEAL`.

Both benevolent and exploitative institutions can contain internal disagreement and changing alliances.

## 11. Success-to-responsibility engine

Protect competent success:

`GOOD DECISION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → NEW COUPLING → HARDER NEXT CHOICE`.

Do not force a setback merely to obey a commercial plotting formula.

## 12. Embodiment-specific agency

`BODY / INSTANCE / BANDWIDTH → AFFORDANCES + LIMITS + RISK → TACTIC`

Never:
`MORE HUMAN BODY → MORE PERSONHOOD`.

## 13. Memory provenance

`SUBJECTIVE MEMORY → LOG / TRACE / WITNESS → COMPARISON → CONFIDENCE STATUS`.

Dual rule:
- memory content may be false or distorted;
- emotional/physiological impact can still be real.

## 14. Trauma without incompetence

`TRAUMA → SPECIFIC LIMIT → ADAPTATION → COMPETENCE → SELF-KNOWLEDGE → NEXT RESPONSIBILITY`.

No compulsory brokenness, instant cure or therapeutic moral lesson.

## 15. Proof ceiling / ending

A book may resolve the local operational and ethical problem while leaving ontology open.

`LOCAL PROBLEM → DECISIVE CHOICE → CONSEQUENCE → AFFECTED AGENTS RETAIN AGENCY → AFTERMATH → NEXT VECTOR`

No final lecture is required to explain every unknown mechanism.

## 16. Application: B07 — THE UNLISTED CITY

Once distributed life reaches a defined personhood threshold:

`EVIDENCE → PERSONHOOD THRESHOLD → ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → HUMAN OPTION SPACE CHANGES → ACCOUNTABLE BOUNDED DECISION`.

Required checks:
- do humans preserve options rather than choose the entity's future?
- does the entity make one outcome-critical decision?
- can the entity refuse the option humans consider best?
- are institutional actors internally differentiated?
- is personhood proven through multiple signals / decisions rather than one convenient tell?

## 17. Application: Orbital Youth

For every named conscious robot/nonhuman:
- independent want;
- independent relationship network;
- refusal right;
- own model of evidence;
- embodiment-specific affordances;
- one choice that alters human options.

Youth engine protected:
`COMPETENCE → SUCCESS → TRUST → RESPONSIBILITY → MORE COMPLEX CHOICE`.

## 18. Application: consciousness-practice schools

Preserve the epistemic ladder:

`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → ONTOLOGY CEILING`.

Also:
`INNER EXPERIENCE ≠ EXTERNAL FACT`.

High technological maturity elsewhere does not remove this evidence requirement.
