## Retained mechanisms after Red Team

### 1. Third-model / polarization diagnostic
Booker repeatedly interprets stories through paired opposites and a final synthesis. His metaphysics are rejected, but the structural question is useful:

`MODEL / VALUE A ↔ MODEL / VALUE B → WHAT DOES EACH EXPLAIN? → WHAT DOES EACH MISS? → DISCRIMINATING CONSEQUENCES / TEST → THIRD MODEL / REFRAME IF EARNED`.

The third model is **not** an automatic midpoint compromise and must not create false balance. It earns authority only by explaining evidence or consequences better than the alternatives.

### 2. Collective-model capture
Ch32 contains a useful institutional pattern independent of Booker's political psychoanalysis:

`OFFICIAL MODEL → ACCESS / STATUS / REWARD → EVIDENCE FILTER → GROUP ALIGNMENT → BLIND SPOT → DISSENT / OUTLIER TRACE → DISCRIMINATING TEST → MODEL UPDATE OR ESCALATION`.

A competent institution can remain wrong because its information ecology rewards the existing model.

### 3. Pattern-projection firewall
Narrative patterns can help generate hypotheses about politics, institutions or history, but resemblance is not proof:

`STORY PATTERN / ANALOGY → HYPOTHESIS`, not `EMPIRICAL CAUSE`.

Do not diagnose a real institution, culture or person because it resembles Quest, Tragedy, Shadow, Rebirth or any other plot family.

### 4. Mutual-projection audit
When factions interpret one another through simplified stories:

`SIDE A MODEL OF B → EVIDENCE / OMISSIONS`
`SIDE B MODEL OF A → EVIDENCE / OMISSIONS`

Compare both to independent traces. Reject both false equivalence and automatic heroic framing of either side.

### 5. Persona / public-self gap
Public role, rhetoric and self-presentation can differ from private priorities and behavior:

`PUBLIC CLAIM / PERSONA → RELATION-SPECIFIC BEHAVIOR → CONTRADICTIONS → CHARACTER MODEL UPDATE`.

But observed contradiction remains evidence for a motive hypothesis, not proof of a hidden essence.

### 6. Worldview infrastructure
Ch33 is most useful when stripped of Booker's religious/Jungian truth claims:

`SHARED MODEL / COSMOLOGY → RITUAL / ARCHITECTURE / LANGUAGE / LAW / ROLE → PERSON-SPECIFIC ACTION → CONSEQUENCE`.

A culture's worldview should be visible in lived institutions and ordinary choices rather than expository lectures.

### 7. In-world belief is not world fact
A religion, school, institution or civilization may canonically hold a belief without that belief being true:

`IN-WORLD BELIEF / OFFICIAL CLAIM ≠ WORLD FACT`.

Store separately:
- what the culture believes;
- what practices reproduce;
- what traces exist;
- what alternative interpretations remain;
- what the ontology ceiling permits.

### 8. Inherited-model layering
Institutions and habits can preserve older assumptions after explicit ideology changes:

`OLD MODEL → INSTITUTION / RITUAL / LANGUAGE RESIDUE → NEW EXPLICIT MODEL → FRICTION / HYBRID PRACTICE`.

Useful for deep worldbuilding without requiring a history lecture.

### 9. Shared story can coordinate a group without proving itself
A collective narrative can change legitimacy, action and identity:

`SHARED STORY → EXPECTATION / ROLE → COORDINATION → ACTION → CONSEQUENCE`.

Its causal power as a belief does not establish its factual truth.

### 10. Culture-change should be behavioral
Do not announce that a society has 'changed worldview'. Show:

`MODEL CHANGE → RULE / LANGUAGE / ARTIFACT / RITUAL / INSTITUTION CHANGE → PERSON-SPECIFIC CHOICE CHANGE`.

### 11. Threshold symbols are optional discourse tools
A doorway, journey, ritual, title or costume can externalize a changed state, but symbolism is subordinate to causal change:

`SYMBOLIC THRESHOLD ≠ STRUCTURAL TRANSITION` unless goal, option space, evidence, relationship, authority, responsibility or strategy changes.
