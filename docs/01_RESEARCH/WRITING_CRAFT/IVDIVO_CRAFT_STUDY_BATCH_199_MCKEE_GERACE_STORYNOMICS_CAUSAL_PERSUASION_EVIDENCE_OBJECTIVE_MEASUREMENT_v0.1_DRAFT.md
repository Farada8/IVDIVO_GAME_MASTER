## McKee / Gerace — Causal Persuasion · Evidence · Objective · Measurement

**Source:** Robert McKee & Thomas Gerace, *Storynomics* (2018)  
**Strict source status:** `STRICT_LIFECYCLE_SYNTHESIZED_v1.0`  
**Pass:** 164

## A. What is genuinely new for IVDIVO

The book's fiction structure largely repeats McKee *Story*. Its new value is that it deliberately treats story as a technology for changing belief and behavior. That makes it an ideal stress test for IVDIVO's evidence, consent and legitimacy systems.

### Gate B199-01 — PROCESS IS NOT PROGRESSION
`VISIBLE ACTIVITY → WHAT STORY STATE CHANGED?`

If no load-bearing state changes, route material to summary, ellipsis, montage/iterative narration, atmosphere-with-budget, or deletion.

### Gate B199-02 — STORY COHERENCE IS NOT TRUTH
`COHERENT CAUSAL ACCOUNT → ALTERNATIVE MODEL → DISCRIMINATING TEST → EVIDENCE STATUS`.

A persuasive explanation can be false.

### Gate B199-03 — PERSUASION IS NOT LEGITIMACY
`AUDIENCE ACCEPTS STORY ≠ CLAIM PROVEN ≠ DECISION LEGITIMATE ≠ CONSENT INFORMED`.

Especially important for institutions, youth authority, AI/robotic systems, B07 personhood and consciousness schools.

### Gate B199-04 — SOURCE INTEREST
For a load-bearing claim:
`SOURCE → BENEFIT / INCENTIVE / CONTROL → LINEAGE → INDEPENDENT CORROBORATION`.

Self-interest lowers automatic credibility but does not prove falsehood.

### Gate B199-05 — EXPECTATION GAP ROUTER
`EXPECTATION → ACTION → ACTUAL RESPONSE → GAP → MODEL UPDATE → NEXT TACTIC`.

Use when organically generated. Do not manufacture a surprise in every scene.

### Gate B199-06 — REAL SUCCESS IS LEGAL
`COMPETENT ACTION → EXPECTED POSITIVE RESPONSE → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

No mandatory setback after every attempt.

### Gate B199-07 — TRADEOFF / DECISION OWNERSHIP
`OPTION A / OPTION B → BENEFIT → COST → WHO MAY CHOOSE → WHO MAY REFUSE → CONSEQUENCE`.

A clear protagonist choice does not override affected-person consent.

### Gate B199-08 — REPEAT WITH CHANGED FUNCTION
A repeated clue, motif, process or relationship beat is admitted only when at least one changes:
`SOURCE / STATUS / PRESSURE / TACTIC / RELATION / MEANING / FUTURE OPTION SPACE`.

### Gate B199-09 — PROMISE / REALITY CONGRUENCE
`OFFICIAL / CHARACTER PROMISE → OBSERVED BEHAVIOR → MATCH / CONTRADICTION → TRUST UPDATE`.

This is stronger than authorial exposition saying an institution is good/bad.

### Gate B199-10 — OBJECTIVE BEFORE METRIC
`REAL OBJECTIVE → OBSERVABLE OUTCOME → PROXY → GAMING / GOODHART AUDIT → RETEST`.

Do not optimize retention, chapter-end cliffhangers, word count or short-sentence percentage as if they were the story objective.

### Gate B199-11 — CAUSAL MEMO, NOT BULLET ACCUMULATION
When diagnosing a complex plot/system:
`WHAT HAPPENED → WHY → WHAT DEPENDS ON IT → WHAT FUTURE CONSEQUENCE FOLLOWS`.

But the memo remains a causal model subject to falsification.

### Gate B199-12 — ETHICAL STORYTELLING FIREWALL
A story may increase empathy, identification and compliance without increasing epistemic quality.

`EMOTIONAL EFFECT → BEHAVIORAL EFFECT`, potentially;  
`EMOTIONAL EFFECT ↛ TRUTH / CONSENT / PERSONHOOD`.

## B. Cross-source reconciliation

### McKee Story / Action / Dialogue / Character
Retain tactic-response causality and meaningful change. Reject mandatory conflict/value reversal/positive closure.

### Scofield / Bickham / Swain
Strong convergence:
`ACTIVITY ≠ EVENT`; `SCENE → CHANGED STATE`; processing may be compressed or delayed.

### Chatman / Genette / Fludernik
Storynomics understates discourse manipulation. Use narratology to audit when persuasive order/duration/frequency/focalization changes reader inference.

### Zunshine / Herman / le Carré / Ephron / Blundell
These override Storynomics on epistemics:
`SOURCE LINEAGE + ALTERNATIVES + TEST` are mandatory before claim promotion.

### Oatley / Storr
Cognitive claims require a science firewall. Storynomics's neuroscience/evolution claims are not imported as current fact.

### Le Guin / Prose / Hodgins / Clark / Williams-Bizup
No support for staccato optimization. Process compression happens primarily at scene/paragraph/discourse level.

## D. IVDIVO production synthesis

### Story-state first
`OWNER / WANT → TACTIC → RESPONSE → ACTION STATE + KNOWLEDGE STATE + RELATION STATE + AUTHORITY / CONSENT STATE → NEXT OPTION SET`.

### Reader effect is separate
`STORY STATE CHANGE` and `READER EFFECT` are tracked independently.

### Proof ceiling remains
A story may close a local operational question while leaving global ontology unknown.

### Revision router
`STRUCTURAL DEFECT → STRUCTURAL REPAIR`  
`DISCOURSE DEFECT → ORDER / DURATION / POV REPAIR`  
`PARAGRAPH DEFECT → TOPIC / READER-STATE REPAIR`  
`LINE DEFECT → LINE EDIT`.

## E. Anti-choppiness consequence

Storynomics repeatedly values action/reaction, but this must not become typography.

`ACTION / REACTION PAIR ≠ TWO SENTENCES`.

If multiple microbeats constitute one perceptual or decision unit, preserve them as a coherent paragraph/sentence structure. If the process itself is not load-bearing, compress it above sentence level.

Standing law:
`ACTION / SUSPENSE / PERSUASION / EMOTION ≠ SHORT-SENTENCE DENSITY`.
