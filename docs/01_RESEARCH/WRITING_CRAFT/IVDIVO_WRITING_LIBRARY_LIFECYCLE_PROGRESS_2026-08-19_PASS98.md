Global router now explicitly includes scene weight:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT → NARRATIVE MODE → POV/EVIDENCE → PARAGRAPH/RHYTHM → WORDING`.

### Anti-'обрубки' application
Before adjusting sentence length, test:
1. Is the passage a full scene by mistake?
2. Is its scene weight too high for its function?
3. Should routine beats be summary/indirect?
4. Are several one-line paragraphs actually one continuous perceptual/causal unit?
5. Only then modify sentence rhythm.

No short-sentence KPI is permitted.

### Technical scenes
Reject repetitive coverage such as:
`arrive → connect → inspect → explain → think → ask → answer → leave`.

Find the bull's-eye beat where evidence, consent, authority, relation or decision changes; compress the rest.

### Mystery/evidence
`SEARCH PROCESS (summary) → TRACE FOUND (scene) → INTERPRETATION CONTESTED (scene if exact language matters) → RESULTING ACTION`.

Evidence properties themselves may not be altered for prose beauty.

### Conscious nonhuman persons
Do not expand a scene merely because embodiment is novel; do not compress away a nonhuman subject's own consent/refusal/decision when it changes the option space.
