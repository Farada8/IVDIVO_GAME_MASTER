# Final retained mechanisms

## 1. Pattern as diagnostic lens, not blueprint
`ACTUAL CAUSAL SPINE → PATTERN SIGNATURE → OPTIONAL COMPARISON → DIAGNOSIS → KEEP / REJECT THE LENS`

A pattern earns use only after actual causality exists. It may describe part of a book; it does not dictate the book.

## 2. Pattern overlap must pay causally
Multiple plot families may coexist only if each changes the same main engine:
`LOCAL PATTERN FUNCTION → CHANGED STATE → DOWNSTREAM DEPENDENCY / PAYOFF`.

`PATTERN OVERLAP ≠ MULTIPLE PARALLEL MINI-NOVELS`.

## 3. External-success / governing-problem split
`OBJECTIVE SUCCESS ≠ COMPLETE STORY RESOLUTION`.

Audit separate ending axes:
- objective;
- evidence / knowledge;
- relationships / consent;
- authority / responsibility;
- agency / decision ownership;
- cost;
- future option space.

## 4. Goal-legitimacy gate
`GOAL ACHIEVEMENT ≠ GOAL LEGITIMACY`.

Ask:
`WHO DEFINED THE GOAL? → WHO BENEFITS? → WHO BEARS COST? → WHO MAY REFUSE? → WHAT CHANGES IF SUCCESSFUL?`

## 5. Competence with blind spot
`COMPETENCE / MODEL → BLIND SPOT → COUNTERFORCE / TRACE → DISCRIMINATING EVIDENCE → STRATEGY UPDATE`.

A capable protagonist, adult, institution or robot may be wrong without becoming stupid.

## 6. Distributed competence
`ONE CAUSAL PROBLEM → INDEPENDENT AGENTS WITH UNIQUE CAPABILITIES → INTERDEPENDENT ACTIONS → CONVERGENCE`.

Allies are persons, not fragments of the protagonist's psyche.

## 7. Model capture / institutional escalation
`MODEL → COMMITMENT / STATUS / INCENTIVE → GROUP ALIGNMENT → EVIDENCE FILTER → ESCALATION`.

More explicit operational form:
`OFFICIAL MODEL → ACCESS / STATUS / REWARD → EVIDENCE FILTER → BLIND SPOT → OUTLIER TRACE → DISCRIMINATING TEST → UPDATE OR ESCALATION`.

Competent groups can remain wrong because the information ecology rewards the current model.

## 8. Third-model gate
`MODEL A ↔ MODEL B → WHAT EACH EXPLAINS → WHAT EACH MISSES → DISCRIMINATING CONSEQUENCES / TEST → MODEL C ONLY IF IT EXPLAINS MORE`.

`THIRD MODEL ≠ AUTOMATIC COMPROMISE`.

## 9. Narrative-role capture
People and institutions can begin acting through simplified story roles:
`ROLE LABEL (HERO / MONSTER / VICTIM / SAVIOR) → ATTENTION FILTER → OPTION NARROWING → ACTION → CONSEQUENCE`.

The label may have causal power as a belief without being factually true.

## 10. Story-pattern analogy firewall
`STORY PATTERN / HISTORICAL ANALOGY → HYPOTHESIS`, not proof.

A policy, institution or event resembling Tragedy, Quest, Rebirth or Overcoming the Monster does not establish its cause.

## 11. Mutual-projection audit
`SIDE A MODEL OF B → EVIDENCE / OMISSIONS`
`SIDE B MODEL OF A → EVIDENCE / OMISSIONS`
`INDEPENDENT TRACE → DISCRIMINATING TEST`

Reject both false equivalence and automatic heroic framing.

## 12. In-world belief versus world fact
`IN-WORLD BELIEF / OFFICIAL DOCTRINE ≠ WORLD FACT`.

Store separately:
- belief;
- practice;
- reproducible effect;
- source lineage;
- competing interpretation;
- evidence status;
- ontology ceiling.

## 13. Worldview infrastructure
`SHARED MODEL / COSMOLOGY → RITUAL / ARCHITECTURE / LANGUAGE / LAW / ROLE → PERSON-SPECIFIC ACTION → CONSEQUENCE`.

Worldview should be visible through lived systems, not only lectures.

## 14. Inherited-model residue
`OLD MODEL → INSTITUTION / LANGUAGE / RITUAL RESIDUE → NEW EXPLICIT MODEL → FRICTION / HYBRID PRACTICE`.

A society can stop explicitly believing X while continuing to live inside institutions built by X.

## 15. Collective story as coordination mechanism
`SHARED STORY → EXPECTATION / ROLE → COORDINATION → ACTION → CONSEQUENCE`.

Its behavioral power does not prove its truth.

## 16. Narrative selection bias / public-story ecology
Ch34's discussion of news and mass storytelling is useful after stripping Booker's ideology:
`WORLD EVENTS → SELECTION FOR NOVELTY / CONFLICT / EMOTION → PUBLIC STORY → AUDIENCE MODEL`.

`NEWSWORTHINESS ≠ REPRESENTATIVENESS`.

The most visible stories may systematically overrepresent crisis, conflict and anomaly.

## 17. Narrative analogy can misdirect policy
Ch34 repeatedly shows actors treating real situations through inherited narrative frames. Salvage only:
`PUBLIC / INSTITUTIONAL STORY → ROLE ASSIGNMENT → EXPECTED ENDING → POLICY OPTION FILTER`.

Before acting:
`ANALOGY → HYPOTHESIS → INDEPENDENT EVIDENCE → ALTERNATIVE MODEL → TEST`.

## 18. Innovation externality gate
Booker's Loki metaphor is rejected as metaphysics but yields a useful engineering question:
`NEW CAPABILITY → DIRECT BENEFIT → NEW DEPENDENCIES / EXTERNALITIES → MISUSE / FAILURE SURFACE → SAFEGUARDS / GOVERNANCE → RESIDUAL RISK`.

`TECHNICAL CAPABILITY ≠ AUTOMATIC SOCIAL LEGITIMACY`.

## 19. Sensation versus model-building
Booker's distinction between imagination and fantasy is too metaphysical, but one craft distinction survives:
`EVOCATIVE IMAGE / EMOTIONAL SENSATION` may create experience without improving causal understanding.

Use the question:
`DOES THIS IMAGE / EFFECT CHANGE THE READER'S MODEL, RELATIONSHIP, OR EXPERIENCE — OR ONLY ADD INTENSITY?`

Intensity alone is not progression.

## 20. Surface reset versus durable change
`AMNESIA / NEW NAME / NEW BODY / RELOCATION / NEW TITLE / NEW PARTNER ≠ DURABLE CHANGE`.

Durable change requires later behavioral evidence:
`MODEL / VALUE / RELATION → PRESSURE → NEW TACTIC / DECISION → CONSEQUENCE`.

## 21. Narrative glamour audit
`CHARISMA / FOCALIZATION / HUMOUR / BEAUTY / INTERIORITY ≠ MORAL LEGITIMACY`.

Audit costs borne by people outside the focal character's frame.

## 22. Created / discovered / rescued is not owned
`CREATED ≠ OWNED`
`DISCOVERED ≠ OWNED`
`RESCUED ≠ OWNED`

Once personhood is independently established, decision ownership belongs to the person affected.

## 23. Quiet causality
`QUIET ≠ STATIC`.

A quiet scene may causally move evidence, relationships, consent, responsibility, strategy, commitment or option space without overt conflict.

## 24. Investigator self-implication
`INVESTIGATOR QUESTION → TRACE CHAIN → SELF-IMPLICATING EVIDENCE → MODEL COLLAPSE → RESPONSIBILITY / ACTION UPDATE`.

Useful beyond guilt: an investigator's earlier classifier, policy, relationship assumption or technical decision may be part of the current mechanism.

## 25. Final stopping rule for pattern interpretation
Booker's theory tends to absorb counterexamples by calling them dark, inverted, incomplete or sentimental variants. IVDIVO therefore requires:
`PATTERN FIT → WHAT WOULD FALSIFY THIS FIT? → TEST → STOP`.

If every possible story outcome can be redescribed as confirming the pattern, the pattern is not a useful diagnostic.

# High-risk failure modes / rejected claims

## Universal-taxonomy absorption
A theory that reclassifies every counterexample as an inversion/partial version becomes unfalsifiable.

**Gate:** every interpretive lens must state what evidence would count against it.

## Archetype-to-psychology leap
Reject Booker's Jungian `Self / ego / anima / animus / collective unconscious` system as established psychology.

## Gender-essentialist completion
Reject masculine/feminine essences, left/right gender coding, heterosexual union or marriage as universal maturity/completion.

## Body / species moral symbolism
Reject bodily difference, disability, animal imagery or nonhuman embodiment as signs of moral darkness or incompleteness.

## Story-to-history proof leap
Reject broad psychoanalytic diagnoses of historical periods, nations, political movements, religions or cultures from literary patterns.

## Religious / metaphysical truth leap
Reject `God / One / Self`, reincorporation into cosmic unity, archetypal rebirth and similar claims as IVDIVO ontology.

## Prehistory reconstruction overconfidence
Reject speculative claims about prehistoric religion, Mother Goddess systems or ancient psychology as settled scholarship.

## One-sided political role assignment
Reject automatic mapping of contemporary actors to monster/hero/victim roles.

## Romance-as-completion
Reject partner acquisition, marriage or reunion as proof of complete personal growth.

## Happy-ending absolutism
Reject the claim that archetypally complete stories must end happily or resolve every uncertainty.

## Conflict / darkness escalation
Reject the assumption that greater violence, sex, catastrophe or darkness necessarily creates greater structural seriousness.

## News / media moralization
Retain selection-bias mechanics; reject Booker's broad political/cultural conclusions as evidence.

# Cross-source comparison

## Aristotle
Strong convergence on unity of action and causal necessity; Booker is much weaker when he turns recurring patterns into universal psychology.

## Truby / Brody / Vogler / Warner
All pattern systems are useful as repertoires or diagnostics, dangerous as simultaneous obligations. Booker is the strongest stress-test for formula collision because his framework tries to subsume enormous numbers of stories.

## Card / Corbett / McKee Character / Herman / Oatley
Person-level wants, models, relationships and pressured choices provide stronger character explanations than archetypal essences.

## Zunshine / Chudnoff / le Carré / Ephron
Source lineage, alternatives and discriminating evidence outrank narrative-role intuition.

## Genette / Chatman
Story facts, discourse placement and reader model remain distinct. A pattern interpretation belongs to reader/model level unless corroborated.

## Booth
Interpretive reconstruction needs shared ground and a stopping rule. This directly supports the anti-unfalsifiability gate.

## Edward James / Cambridge SF / Wolf
Genre/worldview systems are historically situated; they do not provide universal psychic laws.

## Murderbot / DCC / Weir / Crouch
Nonhuman personhood does not require humanization, archetypal service to a protagonist, or symbolic moral function.

# IVDIVO operationalization

## ONE MAIN STORY
`STRAND → CHANGED STATE → DOWNSTREAM DEPENDENCY / PAYOFF`.

Multiple plot signatures may coexist, but no strand is admitted merely because a pattern framework expects it.

## Book-ending audit
`OBJECTIVE → EVIDENCE → RELATIONSHIP/CONSENT → RESPONSIBILITY/AUTHORITY → AGENCY/DECISION OWNERSHIP → COST → FUTURE OPTIONS`.

Local closure can coexist with saga uncertainty.

## Institutional conflict
`OFFICIAL MODEL → BENEFIT / STATUS / ACCESS → EVIDENCE FILTER → BLIND SPOT → OUTLIER TRACE → TEST → UPDATE / ESCALATION`.

Do not default to secret villainy.

## Mystery
`TRUE TRACE → SOURCE LINEAGE → MODEL A/B/C → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

Pattern recognition is hypothesis generation only.

# Anti-choppiness / prose law

`PATTERN STAGE / RECOGNITION / REVERSAL / WORLDVIEW TURN / MODEL REVISION ≠ SENTENCE BREAK`.

`ACTION / SUSPENSE / MYSTERY / EMOTION / DISCOVERY ≠ SHORT-SENTENCE DENSITY`.
