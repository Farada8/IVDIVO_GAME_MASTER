## Core claims retained
1. Wanting to write and deciding to build a writing practice are different states.
2. Large goals need controllable process plans.
3. Creative generation benefits from temporary suspension of premature evaluation.
4. Regular practice and deliberate learning can improve production reliability.
5. External validation, luck and market response are partly uncontrollable.
6. Distractions can be captured and deferred instead of forcing immediate context switching.
7. Recovery/rest can be necessary when repeated work quality deteriorates.
8. Drafting speed and editing speed need not be the same.

## IVDIVO mechanisms
### M1 — Writer-State Router
`OBSERVED PROBLEM → TEXT DEFECT OR WRITER/PROCESS STATE? → IF TEXT DEFECT, DEFECT LEVEL → REPAIR → RETEST`

Fatigue, envy, frustration, boredom or a bad work session do not prove that the manuscript engine is broken.

### M2 — Divergence / Convergence Separation
`GENERATE MANY OPTIONS → DEFER CENSORSHIP → REST / DISTANCE → CANON + CHARACTER + CAUSALITY + READER-EFFECT FILTER → KEEP / BANK / DISCARD`

### M3 — Process Metric Firewall
`PROCESS METRIC ≠ STORY QUALITY`

Word count, number of scenes, number of gates passed, number of agents invoked, retention proxies and production speed are operational measurements, not literary quality.

### M4 — Side-Thought Capture
`SIDE IDEA / TASK → CAPTURE → DEFER → PRIORITIZE LATER`

Useful for the IVDIVO multi-agent environment: a new specialist observation during live drafting enters a queue rather than hijacking the active creative context.

### M5 — Draft / Edit Speed Separation
`FAST DISCOVERY DRAFT ≠ CHOPPY PROSE`

Drafting quickly is a process tactic. Sentence length and paragraph rhythm remain reader-effect decisions.

### M6 — Recovery Before False Rewrite
`REPEATED LOW-QUALITY SESSION → CHECK SLEEP / FATIGUE / CONTEXT SWITCHING / OVERLOAD → RECOVER → RETEST TEXT → ONLY THEN CONSIDER STRUCTURAL REWRITE`

Not medical diagnosis; a production safeguard against mistaking temporary state for manuscript evidence.

### M7 — Audience Contract Firewall
`INTENDED READER EFFECT → DESIGN / TEST`, not `MARKET TASTE → STORY CANON`.

### M8 — Distinctive Strength Without Brand Prison
A writer may identify distinctive strengths, but a marketing identity must not freeze voice, character design or genre into a compulsory formula.

## Failure modes / rejected universal claims
- **REAL-WRITER MORALIZATION:** persistence is not a moral test of identity.
- **NLP-AS-SCIENCE:** Neuro-Linguistic Programming claims are not accepted as established science.
- **MENTAL-HEALTH OVERSIMPLIFICATION:** writing practices are not clinical treatment.
- **BURNOUT SIMPLIFICATION:** rest is useful process hygiene, not a complete clinical model.
- **STIMULANT / SUPPLEMENT ADVICE:** not a writing-system law.
- **2016 MARKET FREEZE:** publishing/self-publishing observations require fresh verification before current business use.
- **AUDIENCE-DELIGHT ABSOLUTISM:** reader orientation matters; formulaic market obedience does not follow.
- **UWP BRAND RIGIDITY:** uniqueness is not a mandatory persona.
- **QUOTA / SPEED FETISH:** output volume is not quality.
- **SCENE CONFLICT PREMAP AS LAW:** objective/obstacle/outcome is a useful launch heuristic, not a universal scene ontology.
- **JOY PREREQUISITE:** motivational rhetoric conflicts with the book’s own discipline model; not a gate.

## Cross-source synthesis
Bell converges strongly with Lamott, LaPlante, Swain and Seger on phase separation:
`GENERATE LIVE MATERIAL → DIAGNOSE → REVISE → POLISH`.

It also reinforces Bickham/Mayer/Book Engine process control: operational metrics and planning artifacts must not outrank actual text evidence.
