# IVDIVO CRAFT STUDY — BATCH 191
## Christopher Booker — Polarity · Collective Models · Worldview Infrastructure

**Source status:** WIDER / `FULL READ IN PROGRESS` through Ch33.  
**Use:** provisional mechanisms only; do not treat Booker as SYNTHESIZED until the whole source is completed.

## 1. Salvageable mechanisms

### G191-01 — Third-Model Gate
When a story polarizes two models or values, do not force a compromise. Test:

`A explains ___ / misses ___`
`B explains ___ / misses ___`
`What evidence or consequence distinguishes them?`

A third model earns adoption only when it accounts for the evidence/choices better.

### G191-02 — Collective Model Capture
`OFFICIAL MODEL → ACCESS / STATUS / REWARD → FILTERED EVIDENCE → GROUP ALIGNMENT → BLIND SPOT → OUTLIER → TEST → UPDATE / ESCALATION`.

Useful for competent institutions that are wrong without being evil.

### G191-03 — Pattern Projection Firewall
`STORY PATTERN / HISTORICAL ANALOGY → HYPOTHESIS`, never automatic causal proof.

### G191-04 — Mutual Projection Audit
For opposed groups, write both internal models, then test them against independent traces. No automatic false balance.

### G191-05 — Persona Gap
`PUBLIC SELF → RELATION-SPECIFIC BEHAVIOR → CONTRADICTION → MODEL UPDATE`.
Contradiction can deepen character; it does not reveal one secret immutable essence.

### G191-06 — Worldview Infrastructure
`SHARED MODEL → RITUAL / ARCHITECTURE / LANGUAGE / LAW / ROLE → ACTION → CONSEQUENCE`.
Worldview should be enacted through ordinary systems and choices, not delivered as lore.

### G191-07 — Belief/Fact Firewall
Track separately:
- in-world belief;
- institutional doctrine;
- observed effect;
- source lineage;
- competing explanation;
- current world-fact status.

### G191-08 — Inherited Model Residue
`OLD MODEL → INSTITUTION / LANGUAGE / RITUAL RESIDUE → NEW MODEL → FRICTION / HYBRID PRACTICE`.

### G191-09 — Shared Story as Coordination
A community narrative can coordinate action without being true:
`SHARED STORY → ROLE / EXPECTATION → COORDINATION → CONSEQUENCE`.

### G191-10 — Behavioral Culture Change
Do not state 'the worldview changed'. Show changed rules, language, roles, rituals, artifacts and choices.

### G191-11 — Symbolic Threshold Firewall
A doorway, initiation, costume or journey is not a structural turn unless it changes actual options, evidence, relation, authority, responsibility or strategy.

## 2. Failure modes
- `FALSE-SYNTHESIS`: midpoint compromise mistaken for a superior third model.
- `PATTERN-AS-PROOF`: archetypal resemblance promoted to causal/historical fact.
- `GROUP-ESSENCE`: institution or culture treated as one mind.
- `DOCTRINE-TO-ONTOLOGY`: an in-world belief silently promoted to world fact.
- `WORLDVIEW-LECTURE`: cultural difference explained instead of enacted.
- `SYMBOLIC-THRESHOLD-WITHOUT-STATE-CHANGE`.
- `MAJORITY/MINORITY-MORAL-SHORTCUT`.
- `JUNGIAN-PSYCHOLOGY-LEAK`.
- `GENDER-ESSENTIALISM-LEAK`.
- `RELIGION-AS-EMPIRICAL-PROOF`.
- `NONHUMAN-AS-SYMBOL-FIRST`: personhood subordinated to symbolic human function.
- `PATTERN-STAGE-TO-TYPOGRAPHY`: analytic beat converted into forced short sentence/paragraph.

## 3. Red Team / rejected universals
Do **not** operationalize:
- collective unconscious, Self, anima/animus as established psychology;
- masculine/feminine essence as explanatory science;
- heterosexual union/marriage as universal completion;
- Booker's political left/right gender coding;
- sweeping psychohistory of revolutions, nations or religions;
- speculative prehistory/religious reconstruction as current scholarship;
- God/One/Self as ontology;
- bodily/nonhuman difference as moral darkness;
- literary symbolism as scientific evidence.

## 4. Cross-source hierarchy
When Booker conflicts with evidence-oriented sources, prefer:
- Zunshine / le Carré / Ephron / Chudnoff for source lineage and proof;
- Herman / Oatley / Card / Corbett for person models;
- Genette / Chatman for discourse and reader-model control;
- Wolf / Edward James / Cambridge SF for historical/world-model discipline;
- Murderbot / DCC / Weir / Crouch for nonhuman personhood.

## 5. Production routing
Use Booker here only after a concrete defect exists:

`OBSERVED DEFECT → DOES POLARIZATION / GROUP MODEL / WORLDVIEW INFRASTRUCTURE EXPLAIN IT? → APPLY ONE GATE → RETEST`.
