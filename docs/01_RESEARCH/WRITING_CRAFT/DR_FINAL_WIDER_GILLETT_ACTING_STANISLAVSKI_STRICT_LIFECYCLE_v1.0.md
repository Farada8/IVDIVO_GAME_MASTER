## 3. Highest-value claims translated to narrative craft

### 3.1 Process before result

Gillett repeatedly distinguishes live organic action from premanufactured effect.

IVDIVO translation:

`PREPARE / UNDERSTAND → GENERATE LIVE ACTION → OBSERVE → DIAGNOSE → REFINE`

Not:

`PRESELECT EFFECT → FORCE EVERY LINE TO PERFORM IT`.

This strongly converges with Lamott, LaPlante, Bell, Swain, Seger and the existing 100-specialist routing law.

### 3.2 Given circumstances before generalized emotion

`WHO / WHERE / WHEN / WHY HERE / WHAT DO I WANT → ACTION`

Emotion is usually more convincing when it arises from circumstance, relationship, object of attention, thwarted or fulfilled objective, sensory and imaginative experience.

Production gate:

`CIRCUMSTANCE + PRESENT WANT + RELATIONSHIP + COST → TACTIC → RESPONSE → EMOTION / MODEL UPDATE`.

### 3.3 Objective is not physical activity

A valid objective can be: understand, persuade, refuse, decide, conceal, obtain consent, test, delay, reconnect, make sense of evidence.

Therefore:

`AGENCY ≠ AGGRESSION`  
`OBJECTIVE ≠ PHYSICAL BUSYNESS`.

### 3.4 Adaptation is the engine of live dialogue

`OBJECTIVE → TACTIC → ACTUAL PARTNER RESPONSE → TACTIC UPDATE`

A conversation stalls when a character repeats one tactic despite meaningful changes in the partner.

### 3.5 Attention to partner beats preplanned line-reading

Narrative translation:

`WHAT I WANT FROM THIS PERSON → WHAT THEY ACTUALLY DO/SAY → WHAT CHANGES IN MY MODEL → NEXT TACTIC`.

This reinforces listener-attention matrices from Baxter/Chiarella/Kempton.

### 3.6 Entrance and exit continuity

`PRIOR ACTION / STATE → ENTRY IN MOTION → SCENE WANT → EXIT STATE → OFFSCREEN NEXT WANT`.

This is useful for removing dead warm-up logistics.

### 3.7 Active analysis: rough action before over-analysis

Core rehearsal loop:

`MENTAL RECONNAISSANCE → ACTIVE EXPLORATION / IMPROVISATION → ASSESS → RETURN TO TEXT`.

IVDIVO translation:

`SCENE DESIGN → ROUGH LIVE VERSION → OBSERVE CHARACTER-TRUE TACTICS / RELATIONSHIPS → REVISE`.

Do not intellectually action every sentence before a live version exists.

### 3.8 Beat map is not typography

The source warns against over-small objectives and line-by-line mechanical actioning.

IVDIVO law:

`BEAT MAP ≠ SENTENCE BREAK`  
`BEAT MAP ≠ PARAGRAPH BREAK`.

Several micro-actions may belong in one sentence or paragraph if they form one perceptual/decision unit.

### 3.9 Inner and outer tempo are separate variables

A character may be physically still while internally racing, or physically fast while internally cold and methodical.

Gate:

`INNER PROCESS SPEED ≠ OUTER MOTION SPEED ≠ SENTENCE LENGTH`.

This strongly reinforces:

`ACTION / SUSPENSE / EMOTION ≠ SHORT-SENTENCE DENSITY`.

### 3.10 Pause must have causal function

A pause is useful when it completes what just happened, prepares the next event, changes attention, contains a choice, or creates relation/evidence pressure.

A pause is not automatically depth.

### 3.11 Physical expression should emerge from action, not cliché

Narrative gate:

`PHYSICAL BEAT → CHARACTER / RELATION / TACTIC / ORIENTATION FUNCTION`.

Otherwise delete it.

### 3.12 Sensory detail serves action

`POV WANT + EMBODIMENT + CIRCUMSTANCE → SALIENCE → SELECTED DETAIL → ACTION / INFERENCE`.

No five-sense checklist. No universal robot sensor-feed voice.

### 3.13 Character data are evidence layers

Gillett's four lists become:
- text/world facts;
- what character says about self;
- what character says about others;
- what others say about character.

Narrative translation:

`SELF-REPORT / OTHER-REPORT ≠ WORLD FACT`.

### 3.14 Character contradiction vs inconsistency

Contradictions may deepen a model if caused by relationship, competing value, circumstance, cost, or changed objective. Inconsistency is behavior violating established causal logic with no support.

### 3.15 Rehearsal-only material need not become page material

Life histories, improvised prior scenes, as-if substitutions and background images may help generate truth without being published.

`PRIVATE LAB MATERIAL ≠ CANON ≠ PAGE OBLIGATION`.

### 3.16 Perspective and whole-role economy

Late refinement asks whether each local detail serves current unit, scene, episode and whole story.

`LOCAL BEAT → SCENE FUNCTION → BOOK ENGINE`.

### 3.17 Preparation must eventually disappear

Mechanism banks are scaffolding. Once a scene works, do not leave visible craft labels in prose.

### 3.18 Ensemble: common process without character homogenization

`COMMON STORY / EVIDENCE / CANON LANGUAGE + DISTINCT CHARACTER WANTS / MODELS / TACTICS`.

## 4. Failure modes

1. **OBJECTIVE TYRANNY** — forcing every beat to carry overt conscious change.
2. **COUNTERACTION MONOCULTURE** — assuming every scene requires personal opposition.
3. **SUPEROBJECTIVE REDUCTIONISM** — explaining a whole person with one life-goal.
4. **ACTIONING EVERY LINE** — mechanical verbal labels replace live interaction.
5. **BEAT-TO-TYPOGRAPHY LEAK** — every action becomes a short sentence/paragraph.
6. **MICROGESTURE CONFETTI** — gesture inserted between every line to show emotion.
7. **PHYSIOGNOMY ESSENTIALISM** — body/voice/centre treated as proof of personality.
8. **EMOTION-MEMORY COMPULSION** — personal traumatic recall treated as required authenticity.
9. **ATMOSPHERE REIFICATION** — subjective/collective acting device treated as external force.
10. **TELEPATHY / ENERGY ONTOLOGY LEAK** — rehearsal exercises promoted to science/metaphysics.
11. **RIGHT-BRAIN / LEFT-BRAIN SCIENCE LEAK** — historical heuristic treated as current neuroscience.
12. **PREPARATION ADDICTION** — scaffold never released; prose/performance becomes dead.
13. **LIFE-HISTORY LORE DUMP** — private character preparation leaks onto page without causal need.
14. **STYLE-FIRST ACTING / WRITING** — genre style imposed before material and action.
15. **GENRE MONOTONE** — comedy always fast, tragedy always solemn, etc.
16. **ENSEMBLE CONSENSUS FOG** — collaboration erases decision ownership and distinct viewpoints.
17. **HISTORICAL INDUSTRY POLICY LEAK** — old training/market conditions treated as current facts.

## 5. Cross-source comparison

### Collins — *Getting Into Character*
Convergence: objectives, adaptation, character-specific expression, action before forced emotion. Gillett gives a stronger firewall against compulsory emotion memory and mechanical line actioning.

### McKee *Dialogue*, Chiarella, Kempton
Convergence: words are tactics; listener response matters; silence and physical behavior can be action. Correction: no dialogue-speed / short-line KPI.

### Scofield
Convergence: beats are analytic units, not typography; event and response interact; quiet scenes can carry decisive change.

### Hodgins / Le Guin / Prose / Williams-Bizup
Convergence: rhythm requires contrast; related material needs paragraph/sentence continuity; choppiness cannot be repaired by more fragments.

### Herman / Zunshine
Correction: inference about another person's feeling/motive remains a model, not mind-reading fact.

### Epistemic limits
Prana, solar-plexus radiation, imaginary centres, thought-transmission exercises, subconscious/right-brain language and similar claims are retained only as historical/phenomenological acting devices.

## 6. IVDIVO operationalization

### Universal scene-action gate
`GIVEN CIRCUMSTANCES → PRESENT WANT → PARTNER / WORLD RESPONSE → TACTIC ADAPTATION → CHANGED STATE → NEXT ACTION`.

Allow support and success, not only opposition.

### Dialogue gate
`WANT → TACTIC → ACTUAL LISTENER ATTENTION / RESPONSE → MODEL UPDATE → NEXT TACTIC`.

### Embodiment gate
`BODY / SENSORIUM / CAPABILITY → SALIENCE / AFFORDANCE → ACTION OPTION → SOCIAL RESPONSE → CHOICE`.

For conscious robots: `EMBODIMENT ≠ HUMANIZATION`.

### Character evidence gate
`TEXT FACT / BEHAVIOR / SELF-REPORT / OTHER-REPORT / POV INFERENCE` are stored separately.

### Active-analysis lab
When a scene is conceptually correct but dead:
`RE-IMAGINE / ROUGH IMPROVISE → FIND LIVE OBJECTIVES / TACTICS / RELATIONAL PRESSURE → REWRITE`.

Do not line-edit a dead scene into a polished dead scene.

### Ensemble / Writers' Room gate
`COMMON CANON + COMMON EVIDENCE MODEL + COMMON DEFECT LANGUAGE → SPECIALIST PASS → DECISION OWNER`.

Do not run every specialist on every sentence.

## 8. Final synthesis

The most useful lesson is not "write novels like actors perform." It is:

**Do not manufacture the visible result before the causal life of the moment exists.**

Prepare circumstances, values, objectives, relationships and knowledge. Generate live behavior. Observe what actually happens. Diagnose at the correct layer. Then refine until the scaffolding disappears.
