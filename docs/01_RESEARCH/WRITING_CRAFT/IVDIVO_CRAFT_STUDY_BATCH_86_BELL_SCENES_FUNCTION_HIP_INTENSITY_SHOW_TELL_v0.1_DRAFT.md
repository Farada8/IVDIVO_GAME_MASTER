# IVDIVO CRAFT STUDY — BATCH 86
## Bell: Scene Function · HIP · Intensity · Show/Tell · Summary

Date: 2026-08-18
Status: DRAFT / OPERATIONALIZED
Primary source: James Scott Bell, *Write Great Fiction: Plot & Structure* (2004), Chapter 7 `Scenes`.

## CORE SYNTHESIS

Bell's strongest contribution in this chapter is not the claim that every scene needs conflict. It is the functional decomposition of scene material and the explicit recognition that summary is a legitimate shortcut between real-time units.

IVDIVO scene model:

`PRIOR CONSEQUENCE → OWNER → WANT/PURPOSE → MODE → ATTENTION/PRESSURE ENGINE → TACTIC/PROCESS → ACTION/INFORMATION/RELATION CHANGE → OUTCOME → NEXT LINK`.

### Mode router
- ACTION — purposeful attempt.
- REACTION — processing that changes model/strategy/commitment.
- SETUP — minimum enabling context.
- DEEPENING — material that changes reader understanding or future meaning.
- SUMMARY/INDIRECT — compression of process, repetition, logistics or lower-value talk.
- HYBRID — most strong prose scenes can combine modes.

## PRODUCTION GATES

### B86-G01 — Scene Necessity Before Line Edit
Before polishing a weak scene, ask whether it deserves real-time dramatization at all.

### B86-G02 — Changed-State Requirement
A scene must alter at least one meaningful axis:
`action / information / relationship / authority / commitment / emotional state / evidence status / option space`.

### B86-G03 — Success May Escalate
Do not force setback. A successful action is valid when it increases trust, responsibility, dependency, exposure, access or later cost.

### B86-G04 — Reaction Must Change Something
Reflection that only restates feeling is compression material.

### B86-G05 — Setup Attention Engine
Setup may be held by curiosity, competence, relationship, humor, lived-world specificity, anticipation or contrast. No artificial quarrel required.

### B86-G06 — Deepening Payoff
Deepening must change reader model or future meaning; otherwise compress.

### B86-G07 — Summary Is Legitimate
Routine transport, repeated procedure, low-value meeting process and redundant conversation should not become micro-scenes by default.

### B86-G08 — Entry Contract
Scene openings need attention and orientation appropriate to function, not mandatory action.

### B86-G09 — Exit Continuation
A scene ending needs a reason to continue, not necessarily a cliffhanger.

### B86-G10 — Intensity Is Multidimensional
Track emotional, relational, evidentiary, ethical, institutional and physical intensity separately when useful.

### B86-G11 — No Intensity KPI
Bell's 0–10 scale is a sketch tool, never a target metric.

### B86-G12 — Show/Tell Routing
Use vivid scene where exact moment matters; use narration/summary when the reader mainly needs compressed state change.

### B86-G13 — Rhythm Before Sentence Length
Do not manufacture excitement by fragment density.

### B86-G14 — Quiet Causality
Intimacy, reflection, competence or ordinary life count when they alter the later story.

### B86-G15 — Prompt Variation
Rotate scene exits: decision, result, relation shift, earned answer, evidence change, new option, unresolved pressure, humor, image, ordinary-life aftershock.

## ANTI-CHOPPY ROUTER

`ONE MAIN STORY / CAUSALITY → SCENE NECESSITY → ORDER/DURATION/FREQUENCY → SHOW/TELL → POV/FOCALIZATION → DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

A string of short paragraphs should first be checked for scene/mode/paragraph errors. Sentence expansion is the last repair, not the first.

## CROSS-SOURCE POSITION

**Against formulaic Bell:** IVDIVO rejects mandatory conflict, setback and constant rising intensity.

**With Rosenfeld:** intention and next intention remain central.

**With LaPlante:** scene and narration are equal tools selected by function.

**With McKee:** tactics and changed state matter, but conflict can be non-adversarial.

**With Francine Prose / Le Guin / Lodge / Zinsser:** sentence length and paragraph shape are expressive variables, not quality scores.

**With Herman / Zunshine:** model revision and evidence-status change are valid scene movement.
