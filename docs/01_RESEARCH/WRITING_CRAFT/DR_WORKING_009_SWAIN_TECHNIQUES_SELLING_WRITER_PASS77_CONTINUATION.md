## KEY MECHANISMS CONFIRMED

### S09-M40 — COMMITMENT AS CAUSAL TRANSITION
`DISTURBANCE / OPPORTUNITY -> OPTIONS STILL OPEN -> CHOICE / ACCEPTED RESPONSIBILITY -> NEW OBLIGATIONS + NEW OPTION SPACE -> SUSTAINED MAIN ENGINE`.

IVDIVO correction: commitment need not be a macho `I'll fight`. It may be accepting responsibility, agreeing to investigate, making a promise, consenting to a test, refusing a demand while accepting consequences, or taking ownership of evidence created by one's prior action.

### S09-M41 — STORY QUESTION AS LOCAL READER CONTRACT
`BOOK PROMISE / QUESTION -> WHAT CAN CHANGE ITS ANSWER? -> WHAT EVIDENCE/ACTION ADVANCES IT? -> WHAT CONSTITUTES LOCAL CLOSURE?`

IVDIVO correction: not every story question needs a binary yes/no answer. Mystery/SF may promise a bounded operational answer, relationship renegotiation, proof ceiling or ethical choice.

### S09-M42 — PERIPHERAL OPENING PAY-IN
High-attention opening material must load the actual dominant book engine. A spectacular side issue or technology that never pays into the main story creates a false promise.

### S09-M43 — MIDDLE AS CHANGE / ADJUSTMENT / ACTION
`CHANGED STATE -> MODEL / RELATIONSHIP / EVIDENCE UPDATE -> OPTION SET -> NEW STRATEGY -> ACTION -> CONSEQUENCE -> NEXT CHANGED STATE`.

This is broader than setback escalation.

### S09-M44 — STATE-CHANGE MATRIX
Track relevant changes across:
- action / physical-social state;
- knowledge / evidence;
- relationship / trust / intimacy;
- authority / access / role;
- responsibility / obligation;
- strategy / causal model;
- emotion / commitment;
- future option space.

A quiet scene can be causal if one of these changes and matters later.

### S09-M45 — SUCCESS-BASED PROGRESSION
`COMPETENT ACTION -> REAL SUCCESS -> MORE TRUST / ACCESS / RESPONSIBILITY -> MORE COMPLEX NEXT CHOICE`.

Do not sabotage competent YA characters with artificial failure merely to preserve motion.
