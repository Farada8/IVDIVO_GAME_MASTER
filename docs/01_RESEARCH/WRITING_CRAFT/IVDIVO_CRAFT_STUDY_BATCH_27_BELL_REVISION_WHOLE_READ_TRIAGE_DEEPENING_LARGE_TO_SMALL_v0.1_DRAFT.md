# 1. SOURCE ARCHITECTURE

Bell deliberately separates two functions.

## Part One — self-editing during craft development

Character, plot/structure, POV, scenes, dialogue, beginnings/middles/ends, show/tell, voice/style, setting/description, exposition and theme.

## Part Two — revision after a complete draft

Revision philosophy → distance before revision → first whole read → deepening → ultimate checklist.

This structure itself matters because it rejects a common failure:

`WRITE SOME → POLISH SOME → DISCOVER STRUCTURAL ERROR → POLISH AGAIN → REWRITE EARLY PAGES → NEVER SEE WHOLE STORY`.

---

# 2. DRAFTING MODE ≠ REVISION MODE

Bell’s useful distinction can be abstracted as:

`DISCOVERY / FORWARD GENERATION ≠ CRITICAL COMPARISON / REPAIR`.

The exact tempo is author-specific; the transferable mechanism is mode separation.

### IVDIVO application

During active manuscript discovery:
- record structural alarms;
- fix blockers that make continuation impossible;
- do not repeatedly line-polish early chapters as emotional avoidance of the unfinished middle/end.

After architecture/full-draft stabilization:
- switch to deliberate comparative revision;
- read what is actually on the page, not what production remembers intending.

### Failure mode

Premature polish creates **sunk-cost attachment** to material whose scene, POV or story function may later be deleted.

---

# 3. REVISION DISTANCE — MECHANISM, NOT RITUAL

Bell recommends temporal/cognitive distance before revision.

IVDIVO does **not** encode an exact mandatory number of days.

What matters:

`AUTHOR MEMORY OF INTENTION ↓`
`READER-LIKE PERCEPTION OF ACTUAL TEXT ↑`

Possible distance mechanisms:
- time away;
- different format/device;
- print/read-aloud;
- whole-book read without editing;
- independent editor/beta reader;
- scene-card reconstruction from text rather than outline.

### Gate implication

If the editor can only explain why a passage works by citing planning notes that are not on the page, the manuscript has failed the reader-facing test.

---

# 4. FIRST WHOLE READ BEFORE LOCAL REPAIR

The first revision read should preserve enough speed to detect global experience.

Do **not** stop every sentence to repair diction.

Capture signals such as:

`DRAG | CONFUSION | FALSE EXPECTATION | REPETITION | MISSING CAUSE | MISSING REACTION | STRONG HOT SPOT | PAYOFF | UNPAID SETUP | POV BREAK | WANT TO SKIM | WANT TO CONTINUE`.

### Reason

Micro-editing resets local attention and destroys the evidence of macro pacing.

### IVDIVO Whole-Read Margin Tags

- `H` — hot spot / protect mechanism;
- `D` — drag;
- `C` — confusion;
- `R` — repetition;
- `X` — contradiction/continuity;
- `?` — unearned inference;
- `P+` — setup with payoff;
- `P-` — setup with no payoff;
- `K` — kernel / removal changes causal logic;
- `S` — satellite / compressible or movable;
- `V` — voice/prose issue, repair later unless comprehension is blocked.

# 5. THE FIRST QUESTION: WHAT STORY IS THIS MANUSCRIPT ACTUALLY TELLING?

Before revising chapters, recover the book-level contract from the manuscript itself.

For IVDIVO:

`INCITING DISTURBANCE`
→ `PROTAGONIST-SPECIFIC OBJECTIVE`
→ `OPPOSITION / CONSTRAINT SYSTEM`
→ `ESCALATING CONSEQUENCES`
→ `CRISIS CHOICE`
→ `CLIMACTIC ACTION`
→ `LOCAL RESULT`
→ `AFTERMATH`.

Then compare with frozen specification.

Three cases:

1. **Text matches frozen story** → revise execution.
2. **Text accidentally reveals a stronger alternative story** → open formal change request; do not silently drift.
3. **Text has no coherent one-main-story chain** → stop line edit and return to development.

This is the strongest point of convergence between Bell and the Founder’s specification-first law.

# 6. LARGE → SMALL REVISION ORDER

[OUR SYNTHESIS / DRAFT — NOT CANON UNTIL FOUNDER APPROVAL]

Correct production order:

1. **One Main Story / ending**
2. **Causal spine / escalation / pressure rotation**
3. **Protagonist agency / objective ownership**
4. **Opposition and counterevidence**
5. **Character/relationship arcs**
6. **Mystery/reveal/payoff architecture**
7. **Chapter and scene necessity**
8. **POV / knowledge budget / narrative distance**
9. **Scene beats / action-reaction / endings/transitions**
10. **Exposition / setting / detail selection**
11. **Prose voice / syntax / cadence / paragraphing**
12. **Line/copy continuity**

### Why

A sentence cannot compensate for a missing scene consequence; a scene cannot compensate for a broken climax; a beautiful subplot cannot compensate for the absence of a main objective.

# 7. DEFECT TRIAGE — ROUTE THE PROBLEM TO THE RIGHT LEVEL

For every weak passage, classify before editing.

| Defect | Correct route |
|---|---|
| story objective unclear | STORY DEVELOPMENT |
| chapter repeats same function | MERGE / CUT / REASSIGN OWNER |
| scene has useful evidence but no event | EMBED EVIDENCE IN STRONGER SCENE |
| wrong character owns discovery | POV / REVEAL OWNERSHIP REBUILD |
| no consequence after turn | CAUSAL BRIDGE REBUILD |
| reaction missing | CHARACTER / MRU / RESPONSE PASS |
| scene works but prose chopped | RHYTHM / PARAGRAPH PASS |
| exposition clear but inert | ACTION / LEVERAGE / SCENE INTEGRATION |
| voice generic | DICTION / SYNTAX / ATTENTION FILTER PASS |
| sentence merely verbose | LINE EDIT |

### Anti-band-aid law

Do not solve:
- weak scene with banter;
- missing causality with explanatory paragraph;
- repetitive chapter with prettier prose;
- no stakes with arbitrary danger;
- flat character with biography dump.

# 8. SCENE REVISION — BELL CORRECTED BY CROSS-SOURCE EVIDENCE

Bell’s action-scene triad:

`OBJECTIVE → OBSTACLE → OUTCOME`.

Useful, but too narrow if universalized.

Cross-source IVDIVO model:

`PRIOR CONSEQUENCE`
→ `OWNER / IMMEDIATE OBJECTIVE`
→ `PRESSURE / OBSTACLE / SUPPORT`
→ `ACTION + REACTION BEATS`
→ `FOCAL POINT / BULL'S-EYE`
→ `OUTCOME`
→ `CHANGED NEXT INTENTION`.

Scofield adds the decisive scene test: action and emotion should add up around a focal point and leave the narrative in a different place.

### Outcome families

Rotate rather than mechanically worsen protagonist position:

- success creating harder responsibility;
- refusal preserving a value but losing access;
- partial answer creating more precise question;
- restraint under temptation;
- discovery with ethical cost;
- failed tactic producing new knowledge;
- relationship gain creating obligation;
- public win creating false confidence;
- material loss producing moral clarity;
- costly hold/stop preserving rights while degrading service.

# 9. DEEPENING COMES AFTER STRUCTURE

Once scene/story function is viable, deepen using targeted passes.

### Character deepening

`EVENT → ATTENTION → INTERPRETATION → EMOTION → DECISION → BEHAVIOR`.

Look for:
- generic reaction;
- emotion named but not embodied;
- insight that does not change action;
- repeated internal statement of theme after behavior already proves it.

### Relationship deepening

`WHAT I WANT FROM YOU → WHAT I CANNOT SAY → TACTIC → YOUR RESPONSE → STATUS/TRUST SHIFT`.

### Setting deepening

Use environment as:
- constraint;
- resource;
- status marker;
- sensory pressure;
- memory trigger;
- social rule;
not scenic wallpaper.

### Prose deepening

Only after macro stability:
- attention filter;
- exact verbs/nouns;
- sentence shape;
- paragraph intention;
- rhythm contrast;
- read-aloud cadence;
- controlled emphasis.

# 10. DEDICATED PASSES BEAT ONE OMNIBUS EDIT

A single pass trying to fix everything tends to privilege easy visible errors.

IVDIVO pass stack:

`STORY PASS`
→ `CAUSALITY PASS`
→ `CHARACTER/RELATIONSHIP PASS`
→ `MYSTERY/KNOWLEDGE PASS`
→ `SCENE FUNCTION PASS`
→ `POV PASS`
→ `EXPOSITION/SETTING PASS`
→ `RHYTHM/PARAGRAPH PASS`
→ `LINE PASS`
→ `CONTINUITY/CANON PASS`
→ `READER SIMULATION / REGRESSION`.

Each pass must preserve gains from previous levels.

# 11. BELL'S NEGATIVE-OUTCOME ADVICE — BOUNDED, NOT ADOPTED AS LAW

Bell often encourages scenes to worsen the lead’s position because worry sustains reading.

IVDIVO accepts the mechanism:

`OUTCOME MUST CREATE FORWARD PRESSURE`.

IVDIVO rejects the universal rule:

`EVERY SCENE MUST END WORSE`.

Why:
- repeated defeat becomes mechanical;
- civic/institutional stories need genuine system success and adult competence;
- positive outcomes can raise responsibility/stakes;
- reader needs reward, relief and counterevidence;
- Book Two depends on Lattice actually helping people before Ethan must decide whether/when to hold it.

### Gate LC — Whole-Story Question Before Polish
Before deep prose revision, state the actual manuscript’s one-main-story chain and compare it with frozen specification.

### Gate LD — Revision Distance
Create enough perceptual distance to judge the page rather than remembered intention; exact waiting time is optional.

### Gate LE — Fast Whole Read
First developmental read prioritizes global experience and margin tags over sentence repair.

### Gate LF — Defect Triage
Classify defect level before editing; no line-level repair for structural defect.

### Gate LG — Large-to-Small Revision
Macro architecture precedes scene repair; scene repair precedes line polish.

### Gate LH — Structural Note / No Mid-Draft Loop
During active drafting, record non-blocking structural issues rather than repeatedly rebuilding early pages.

### Gate LI — Deepening After Structure
Emotion, setting, voice and sensory richness may deepen only after the underlying story/scene function passes.

### Gate LJ — Dedicated Pass Separation
Use distinct revision passes so visible micro-errors do not hide macro failures.

### Gate LK — Line Polish Last
Syntax, cadence and paragraph cosmetics are last-stage work unless comprehension itself is broken.

### Gate LL — Revision Regression Test
After each major revision level, recheck causality, character ownership, payoff, canon/spec and previously solved defects.

# 15. CROSS-SOURCE CONVERGENCE

### LaPlante
Deep revision before cosmetic polishing; weak passages may reveal deeper story/POV problems.

### Scofield
A scene needs event + emotional meaning, action/reaction beats, focal point and a changed state.

### Rosenfeld
Scene intention, tension transfer, endings/transitions and contemplative spacing prevent nonstop identical pressure.

### Swain
Stimulus/reaction and scene/sequel logic protect continuity of motivation.

### McKee
Scene action/turn/value change and character choices under pressure.

### Hodgins
Scene utility, setting/POV/revision integrity and causal story progression.

### Le Guin
Prose rhythm and selection require deliberate contrast; microstyle cannot be separated from larger narrative movement.

### Williams/Bizup
Revision is recursive choice in service of the reader, but their global organizational advice is not imported wholesale into fiction.

### Founder production law
Specification first; freeze; execute; change through controlled revision rather than invisible drift.

The convergence is strong enough to support Gates LC–LL as **production hypotheses with high confidence**, while Bell-specific workflow details remain bounded.
