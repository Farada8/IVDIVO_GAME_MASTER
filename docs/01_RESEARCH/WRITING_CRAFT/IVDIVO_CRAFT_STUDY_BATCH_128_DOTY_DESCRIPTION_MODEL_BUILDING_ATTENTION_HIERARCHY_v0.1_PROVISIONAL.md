## 1. Description as model-building
Description can be an epistemic process rather than a static picture.

Operational sequence:
`NOTICE → NAME / COMPARE → RELATION EMERGES → MODEL CHANGES → NEXT ATTENTION SHIFTS`.

Production implication:
A technically competent or investigative character should not always receive the correct concept before observing. Let observation alter the model when that is causally and epistemically appropriate.

### Gate B128-G01 — MODEL-BUILDING DESCRIPTION
A descriptive passage earns extended reader time if it changes at least one of:
- the perceiver’s model;
- the reader’s model;
- the action option set;
- relationship state;
- evidence status;
- emotional orientation.

Otherwise test compression.

## 2. Earn abstraction through particulars
Use:
`PARTICULAR → RELATION → PATTERN → PROVISIONAL CONCEPT`.

Avoid:
`ABSTRACT WORLD-BIBLE CLAIM → decorative examples`.

### Gate B128-G02 — ABSTRACTION EARNED
If an abstract statement can be removed and the selected particulars already let the reader infer it, consider removing or delaying the statement.

If the abstraction is necessary for orientation, place it where it clarifies rather than pre-empts perception.

## 3. Dynamic accumulation
A list/catalogue remains alive only when successive entries generate movement.

Possible vectors:
- scale change;
- sensory-channel change;
- tonal shift;
- contradiction;
- relation change;
- conceptual enlargement;
- emotional pressure;
- emerging pattern.

### Gate B128-G03 — CATALOGUE VECTOR
Remove or reorder several items.

If meaning, momentum and model barely change, the accumulation is probably a catalogue rather than active description.

## 4. Simple landing after complexity
A short/simple terminal phrase can gain force from accumulated particulars.

Use:
`PARTICULARS → RELATIONS → PRESSURE → SIMPLE LANDING`.

### Gate B128-G04 — EARNED LANDING
Do not append a thematic summary merely because the paragraph ends.

A simple landing is justified when the previous material gives the simple phrase new density.

Failure mode: `THEME AFTER EVERY IMAGE`.

## 5. Productive limits of perception
Precise description can retain uncertainty.

Useful statuses:
`NOTICED / INFERRED / UNKNOWN`.

### Gate B128-G05 — PERCEPTUAL HUMILITY
Do not let vividness masquerade as certainty.

Especially for mystery, nonhuman perception and consciousness-practice scenes, mark the boundary between what was sensed and what was concluded.

## 6. Attention hierarchy as worldbuilding
Culture is shown not only by what people notice but by what they take for granted.

For post-money orbital life:
- ordinary manufactured abundance may receive little attention;
- another person’s consent, time, trust, privacy, role, expertise or unique opportunity may receive intense attention.

### Gate B128-G06 — NORMALITY BY NEGATIVE ATTENTION
Before explaining a social norm, ask whether the norm can be revealed by what the POV character does **not** treat as remarkable.

This avoids exposition while preventing Earth-2020s defaults from silently returning.

## 7. Embodied attention for conscious robots
More sensors do not imply omniscience.

Use:
`EMBODIMENT + OWN WANT + CURRENT TASK + RELATIONSHIP + KNOWLEDGE LIMIT → SALIENCE → NOTICED DETAIL`.

### Gate B128-G07 — NONHUMAN SALIENCE
A robot’s selected detail should be specific to its current personhood and situation, not a generic diagnostic feed.

If the same paragraph can be assigned unchanged to any robot, the attention model is underwritten.

## 8. Evidence firewall
Artistic description may reshape experience; evidence fields may not be aesthetically rewritten.

Keep exact when evidence-bearing:
- source;
- sequence/order;
- timestamp;
- dimensions/measurements;
- provenance;
- confidence/status;
- raw wording where legally/causally relevant.

### Gate B128-G08 — BEAUTY DOES NOT ALTER PROOF
`BEAUTIFUL DESCRIPTION ≠ LICENSE TO MUTATE EVIDENCE`.

## 9. Anti-choppy prose application
Bad repair:
`OBJECT → one-line sensory note → OBJECT → microreaction → metaphor → theme sentence`.

Preferred diagnostic order:
`SCENE FUNCTION → POV ATTENTION → SELECTED PARTICULARS → RELATION/INFERENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

### Gate B128-G09 — PARAGRAPH ATTENTION CONTINUITY
When several sentences occupy the same perceptual/action state, test paragraph integration before changing individual sentence length.

Short sentences remain legal when they produce a real contrast, decision, revelation, end-weight or breath.
