## 3. Highest-value mechanisms retained

### M1 — Process is not story
Visible activity is not progression merely because many actions occur.

`PROCESS / ACTIVITY → ask WHAT STATE CHANGED?`

For fiction:
`PRESENT WANT → TACTIC → WORLD / OTHER RESPONSE → MODEL / RELATION UPDATE → NEXT TACTIC → CHANGED STATE`.

This reinforces Scofield's `ACTION IS NOT EVENT`, Swain/Bickham scene-state logic, and the IVDIVO anti-microdramatization router.

### M2 — Causal narrative is a model, not proof
Storynomics correctly values how/why links over lists of disconnected facts, but a coherent causal account can still be wrong.

`DATA / TRACE → CAUSAL STORY → ALTERNATIVE MODEL → DISCRIMINATING TEST → STATUS`.

Standing firewall:
`STORY COHERENCE ≠ EVIDENCE QUALITY ≠ TRUTH`.

### M3 — Purpose and audience effect should be explicit upstream
Before drafting a purposeful communication, know whom it serves and what response is intended.

For fiction this becomes:
`READER CONTRACT / DESIRED EFFECT → CHARACTER / WORLD TRUTH → FORM CHOICE`.

It does **not** mean manipulating characters or canon to force a predetermined emotion.

### M4 — Expectation gap can drive model revision
McKee/Gerace's strongest story mechanism is the gap between what an agent expects and what reality returns.

`EXPECTATION → ACTION → ACTUAL RESPONSE → GAP → QUESTION → MODEL UPDATE → NEW TACTIC`.

But `GAP` is not mandatory in every scene. Genuine success may also generate progression by increasing trust, access or responsibility.

### M5 — Decision quality requires tradeoff visibility
Their crisis/dilemma material is useful once stripped of mandatory climax doctrine.

`OPTION A / OPTION B → WHAT EACH PRESERVES → WHAT EACH COSTS → WHO OWNS DECISION → CHOICE → CONSEQUENCE`.

This is particularly valuable for consent, governance, youth authority and nonhuman personhood.

### M6 — Repetition needs changed meaning or function
The useful core behind their 'diminishing returns' claim:

`REPEAT ONLY IF SOURCE / STATUS / RELATION / PRESSURE / TACTIC / MEANING CHANGES`.

No fixed law of thirds is retained.

### M7 — Source interest affects credibility
A communicator who benefits from a claim has a source-interest problem, not automatic falsehood.

`CLAIM → SOURCE → SOURCE INTEREST / INCENTIVE → EVIDENCE LINEAGE → INDEPENDENT CORROBORATION`.

This connects directly to le Carré, Zunshine, Ephron and Blundell.

### M8 — Brand-story congruence generalizes as promise/reality congruence
Their brand lesson transfers usefully to fiction and institutions:

`STATED PROMISE / OFFICIAL MODEL → OBSERVED BEHAVIOR → MATCH / CONTRADICTION → TRUST UPDATE`.

This is not a marketing KPI in IVDIVO; it is a character/institution credibility mechanism.

### M9 — Audience building depends on repeatable quality, not a single hit
For series craft the transferable mechanism is:

`PROMISE → DELIVERY → REPEATED DELIVERY WITH VARIATION → TRUST / RETURN`.

Do not replace this with forced cliffhangers or constant escalation.

### M10 — Measurement must follow the actual objective
Their Ch13 correctly warns against measuring activity without first defining the intended outcome.

IVDIVO form:
`REAL OBJECTIVE → OBSERVABLE OUTCOME → PROXY METRIC → GOODHART / GAMING AUDIT → READER / STORY TEST`.

Engagement, clicks, episode completion or short-sentence density are not self-justifying objectives.

### M11 — Internal narrative can force causal thinking, but narrative can also rationalize
The Bezos memo example usefully emphasizes full causal explanation over bullet-point accumulation.

Retain:
`WHAT HAPPENED → WHY → WHAT DEPENDS ON IT → WHAT HAPPENS NEXT`.

Add firewall:
`NARRATIVE FLUENCY ≠ CAUSAL VALIDITY`.

### M12 — Communication design has ethical status
The book treats story as a persuasion technology. IVDIVO must add:

`PERSUASIVE NARRATIVE ≠ TRUTH ≠ LEGITIMACY ≠ INFORMED CONSENT`.

A story can persuade precisely because it hides assumptions, selects evidence and creates identification. Therefore persuasion itself must never upgrade evidence status.

## 4. Claims rejected or strongly bounded

1. **Eight stages as universal story form** — retained only as one compact design heuristic.
2. **Every meaningful scene must turn positive↔negative** — rejected; knowledge, consent, relationship, responsibility and strategy changes can matter without binary value reversal.
3. **Conflict as essence of all reality/story** — rejected; support, cooperation, discovery and competence-success can be causal.
4. **Positive climax restores a 'more perfect balance' and answers all questions** — rejected; local closure plus bounded uncertainty is legitimate.
5. **All marketing stories should end with a frictionless clear choice** — not transferable to fiction or ethical decision systems.
6. **Nature always chooses the positive/minimal risk** — overgeneralized psychology/evolution claim.
7. **Pleasure/pain as two fundamental emotions** — not accepted as current science.
8. **Emotion as a simple chemical side effect of value change** — oversimplified neuroscience.
9. **'Open-mind moment' lasts six–eight seconds and permits memory insertion** — not accepted without modern primary-source verification.
10. **Empathic identification erases skepticism** — dangerous overstatement; identification can increase persuasion without increasing truth.
11. **Story is the typical/primary human communication mode** — narrative-theory claim, not a universal scientific fact.
12. **Marketing/channel statistics and platform claims** — historical 2018 evidence only.
13. **Gender/generation marketing generalizations** — historical segment claims, not character psychology.
14. **Story is inherently more honest than rhetoric/advertising** — rejected; story can be manipulative or deceptive.

## 6. Cross-source synthesis

### vs McKee — Story
Storynomics reuses much of McKee's value-turn / expectation-gap architecture. The new value is not a separate fiction theory but exposure of story as **purposeful persuasion**. That makes the ethical/evidence firewall more important than the eight-stage form.

### vs Aristotle / Truby / Bell / Bickham / Scofield
All emphasize causal progression in different vocabularies. IVDIVO synthesis remains:
`ACTION / PROCESS → CHANGED STATE → DOWNSTREAM DEPENDENCY`.
No single beat system owns causality.

### vs Chatman / Genette / Fludernik
Those sources show that discourse order, duration, frequency, voice and focalization shape reader models. Storynomics is comparatively coarse. Use narratology to audit how a persuasive story selects and orders information.

### vs Zunshine / Herman / le Carré / Ephron / Blundell
These sources supply the missing epistemic discipline:
`SOURCE / LINEAGE / ALTERNATIVE MODEL / TEST`.
Their mechanisms override Storynomics whenever narrative persuasion risks being mistaken for evidence.

### vs Oatley / Storr
Storynomics makes broad cognitive claims. Oatley/Storr show similar reader-model interests but also require science firewalls. Current science should be checked separately for any empirical claim.

### vs Le Guin / Prose / Hodgins / Clark / Williams-Bizup
Nothing in Storynomics justifies short-sentence or white-space optimization. It strengthens the need to compress process and preserve meaningful continuity instead.

## 7. IVDIVO operationalization

### ONE MAIN STORY
Use:
`VISIBLE ACTIVITY → WHAT CHANGED? → WHAT NEXT NOW DEPENDS ON THAT CHANGE?`
If the answer is 'nothing,' activity is process, atmosphere or setup and must justify its reader-time separately.

### LESSON ZERO
No global rewrite. This source provides no new concrete manuscript defect evidence.
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.
If a future beta/audio defect appears, Storynomics may help diagnose state-neutral process, repetition or unclear decision tradeoffs.

### ROOM 917
A compelling causal story about clues is still a hypothesis:
`TRACE → SOURCE LINEAGE → MODEL A/B/C → DISCRIMINATING TEST → CORROBORATION STATUS`.

`STORIFIED EXPLANATION ≠ CORROBORATION`.
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

### Orbital Youth
Use reader promise and changed-state clarity, not marketing conflict formulas. Protect:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.
Post-money stakes remain trust, time, consent, responsibility, role, privacy, mastery, belonging and unique opportunity—not salary/rent/credits.

### B07 / nonhuman personhood
Emotionally compelling framing of distributed life is not personhood proof.
`TRACE → INDEPENDENT EVIDENCE LINES → PERSONHOOD THRESHOLD → ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

### Consciousness-practice schools
Narrative elegance must not upgrade ontology:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 8. Anti-choppiness / prose implications

Highest-value prose lesson is indirect:
`PROCESS ≠ STORY`.

Do not dramatize every process beat merely because an eight-stage model values action/reaction.

Standing router:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH TOPIC/READER-STATE → SENTENCE RHYTHM/CONTRAST → WORDING`.

`BEAT / TURN / REACTION ≠ SENTENCE BREAK`.
`COMPRESSION ≠ CHOPPING`.
`ACTION / SUSPENSE / EMOTION / PERSUASION ≠ SHORT-SENTENCE DENSITY`.

## 10. Final synthesis

The highest-value contribution of *Storynomics* to IVDIVO is not 'story sells.' It is a warning and a tool:

`A WELL-SHAPED CAUSAL NARRATIVE CAN CHANGE WHAT PEOPLE BELIEVE AND DO.`

Therefore the production system must separately ask:

`IS THE STORY CLEAR / PERSUASIVE?`

and

`IS THE CLAIM TRUE / SUPPORTED / LEGITIMATE / CONSENTED?`

Those are different gates. IVDIVO keeps both.
