## HIGH-VALUE MECHANISMS

### B98-G01 — CAUSAL CONTINUITY
`STIMULUS / EVENT -> CHARACTER APPRAISAL -> RESPONSE -> WORLD / RELATION RESPONSE -> NEXT STATE`.
Use when reader continuity breaks. Do not force every sentence into visible alternating units.

### B98-G02 — EXTERNAL / INTERNAL DUAL STATE
Track both:
- state of affairs;
- state of mind / relationship / evidence model / obligation.
A meaningful scene may move either or both.

### B98-G03 — RESPONSE PROVENANCE
Before a reaction, verify the reader can infer what it responds to. If the link is intentionally delayed, signal that the gap is deliberate rather than accidental.

### B98-G04 — PROPORTION / DURATION
Detail a change in proportion to its reader-facing importance, subtlety, immediacy, decision difficulty and action difficulty. Summarize mechanics that do not earn real-time treatment.

### B98-G05 — ANTI-CHOP
A choppy passage does not automatically need more reaction beats. First test:
1. merge sentence actions;
2. merge paragraph fragments;
3. summary/indirect mode;
4. only then add missing causal perception/reaction.

### B98-G06 — INTENSITY IS NOT SENTENCE LENGTH
`READER EFFECT -> TEMPO / DURATION -> SYNTAX`.
Short sentences and paragraphs are one contrastive instrument, not a tension KPI.

### B98-G07 — M-R TOOL, NOT TEMPLATE
Draft naturally. Audit causal legibility afterward. This converges with Lamott/LaPlante/Bell generation-vs-revision separation.

### B98-G08 — COMPLEX CAUSALITY FIREWALL
Swain's simplified cause/effect chain is a narrative legibility model, not a scientific inference rule.
For mystery/SF:
`OBSERVATION -> SOURCE -> INTERPRETATION -> ALTERNATIVE MODEL -> CORROBORATION -> ACTION`.

### B98-G09 — EVENT HAS NO UNIVERSAL VALENCE
`EVENT -> EVALUATOR -> YARDSTICK -> BENEFIT/COST -> RESPONSE`.
Avoid narrator-decreed claims such as `the system was good`, `the practice was higher`, `the robot was safe` without a defined evaluator/evidence status.

### B98-G10 — SCENE/SEQUEL ROUTER (PROVISIONAL UNTIL CH4 CLOSES)
Swain:
`GOAL -> CONFLICT -> DISASTER`
`REACTION -> DILEMMA -> DECISION`.

IVDIVO provisional translation:
`PRESENT WANT -> PRESSURE / RESISTANCE / SUPPORT -> CHANGED STATE`
`PROCESSING -> OPTION SET / TRADEOFF -> NEW STRATEGY / COMMITMENT`.

No mandatory disaster, no mandatory argument, no mandatory negative outcome.

## FAILURE MODES
- M-R METRONOME: prose alternates mechanically stimulus/reaction.
- REACTION OVEREXPLANATION: every stimulus receives an explicit emotional gloss.
- CAUSAL SIMPLIFICATION AS TRUTH: a legible model is treated as proven cause.
- SHORT-SENTENCE TENSION KPI.
- DISASTER MONOCULTURE.
- SEQUEL AS BROODING MONOLOGUE.
- MORAL REWARD LAW: virtue mechanically produces success.
- AUTHOR YARDSTICK LEAK: narrator labels a technology/person/institution without provenance.
- MICRODRAMATIZATION: mechanics expanded because M-R can be identified, not because reader time is earned.

## CROSS-SOURCE COMPARISON
- **LaPlante:** corrects simplistic why-causality; render behavior precisely and avoid pop-psychology causes.
- **Herman/Zunshine:** separate plausible causal story from verified cause/motive/consent.
- **Rosenfeld/Bell:** broaden scene outcomes beyond Swain's disaster-heavy commercial model.
- **Francine Prose/Le Guin/Zinsser/Lodge:** confirm functional sentence-length variation and reject chop as default intensity.
- **Lamott/LaPlante:** converge with Swain's own advice to generate first and audit technique later.

## IVDIVO OPERATIONALIZATION
### ONE MAIN STORY
Each important response should change action, knowledge, relationship, authority, responsibility, strategy or future option space. It need not cause the next physical event directly.

### MYSTERY
Never convert an emotionally convincing cause-effect sequence into proof of motive or ontology.

### ORBITAL YOUTH
A competent success may legitimately generate the next pressure by increasing trust, access or responsibility.

### CONSCIOUS ROBOTS
Human appraisal of robot behavior is not robot motive. Preserve own want/model/consent/refusal/choice.

### CONSCIOUSNESS SCHOOLS
`PRACTITIONER OBSERVATION -> REPRODUCIBLE EFFECT -> SCHOOL INTERPRETATION -> COMPETING INTERPRETATION -> POSSIBLE ONTOLOGICAL FACT`.

## ANTI-OBRUBKI ROUTER
`ONE MAIN STORY / CAUSALITY -> SCENE NECESSITY -> ORDER/DURATION/FREQUENCY -> SHOW/TELL -> POV -> DIALOGUE MODE -> PARAGRAPH INTENT -> READER-STATE CONTINUITY -> SENTENCE RHYTHM -> WORDING`.

Do not fix structural fragmentation with cosmetic sentence expansion.
