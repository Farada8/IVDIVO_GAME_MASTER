# IVDIVO CRAFT STUDY — BATCH 118
## Suzanne Collins — The Hunger Games — Youth · Institution · Public/Private Identity · Coercive Choice

Date: 2026-08-19
Status: OPERATIONALIZED FROM STRICT-COMPLETE CORE #29

## Purpose

Extract reusable mechanisms from *The Hunger Games* without importing its dystopian economy, spectacle cruelty or first-person-present cadence into IVDIVO.

## 1. Ordinary-life baseline gate

`SPECIFIC ROUTINE → RELATIONSHIPS / VALUES / COMPETENCE → RUPTURE → MEASURABLE LOSS`.

Ordinary youth life survives if it establishes later causal stakes. It is not automatically filler.

## 2. Formal-equality / unequal-burden gate

`SAME RULE ≠ SAME BURDEN`.

For any institutional rule ask:
- who has more pressure to participate?
- who can refuse?
- who repeatedly bears cost?
- who benefits?
- who can appeal?

Do not confuse universal wording with fair impact.

## 3. Public/private identity engine

`PRIVATE STATE → PUBLIC PERFORMANCE → AUDIENCE MODEL → REAL CONSEQUENCE → PRIVATE / RELATIONSHIP COST`.

Public identity must affect options, access, trust, reputation or institutional treatment; otherwise it is decorative disguise.

## 4. Real audience gate

`VISIBLE INTERLOCUTOR → ACTUAL AUDIENCE → AUDIENCE MODEL → RESOURCE / RULE / REPUTATION CHANGE`.

Use in interviews, hearings, broadcasts, public tests and institutional ceremonies.

## 5. Audience-driven institution

`AUDIENCE INCENTIVE → INSTITUTIONAL INCENTIVE → RULE / ENVIRONMENT CHANGE → CHARACTER OPTION SPACE`.

This gives institutions adaptive behavior without requiring a single mastermind.

## 6. Domain competence

`ORDINARY SKILL → NEW CONTEXT → REFRAMED AFFORDANCE → ACTIONABLE ADVANTAGE`.

Competence is specific. It does not grant universal intelligence, virtue or authority.

## 7. Intelligent mistake

`OBSERVATION → MULTIPLE MOTIVE MODELS → ACTION UNDER LIMITED MODEL → NEW EVIDENCE → MODEL UPDATE`.

Young protagonists may be wrong without becoming stupid.

## 8. Strategic performance → real relationship pressure

`STAGED BEHAVIOR → REPEATED EMBODIED INTERACTION → RELATIONSHIP STATE MAY CHANGE`.

Firewalls:
- later genuine feeling does not retroactively turn earlier performance into truth;
- performance does not equal consent;
- attraction does not equal evidence.

## 9. Constrained mentor signaling

`MENTOR OBSERVES → RESOURCE / SIGNAL TIMING → PROTAGONIST INFERS → TACTIC CHANGE`.

Inference remains fallible. Silence/withholding may itself carry information only where a shared code has been established.

## 10. Complementary team competence

`AGENT A CAPABILITY + AGENT B CAPABILITY → MUTUAL DEPENDENCE → JOINT PLAN → RELATIONSHIP UPDATE`.

No cast member should exist only as a skill label.

## 11. Dependency-map action

Instead of direct-force escalation:

`OPPONENT / SYSTEM STRENGTH → DEPENDENCY MAP → TARGET SUPPORT / CONSTRAINT → OPTION SPACE CHANGES`.

Strong for technical, governance and institutional conflicts.

## 12. Character-specific world affordances

`SAME SETTING → DIFFERENT EXPERIENCE / WANT → DIFFERENT RISK / OPPORTUNITY MODEL → DIFFERENT ACTION`.

Use to make orbital-world description character-owned.

## 13. Symbolic action as causal action

`ACTION → PUBLIC INTERPRETATION → AUDIENCE / INSTITUTION MODEL UPDATE → DOWNSTREAM CONSEQUENCE`.

Symbolism is story mechanics only when observers act on its meaning.

## 14. Record/edit/public-model firewall

`RAW EVENT → RECORD → EDIT / OMIT / ORDER → PUBLIC NARRATIVE → AUDIENCE MODEL`.

Always retain source provenance. Edited public narrative is not a full evidence record.

## 15. Surveillance pressure

`POSSIBLE OBSERVATION → SELF-MONITORING → SELECTIVE SPEECH / PERFORMANCE → AUDIENCE INFERENCE`.

Private and public dialogue cannot have identical tactics when surveillance matters.

## 16. Institutional dependency leverage

`INSTITUTION REQUIRES OUTPUT X → CHARACTER IDENTIFIES DEPENDENCY → CREDIBLE REFUSAL / THIRD OPTION → INSTITUTION MUST UPDATE`.

This is the deep mechanism of the berry move.

## 17. Forced-binary audit

When an institution says only A or B are possible:

`WHO DEFINED THE BINARY? → WHO OWNS THE DECISION? → WHAT SYSTEM DEPENDENCY EXISTS? → WHAT THIRD OPTION IS POSSIBLE?`

Do not accept a forced binary merely because it structures the climax.

## 18. Consent after rescue

`BENEFICIAL OUTCOME ≠ CONSENT`.

A rescue may be effective and still violate another person's explicit preference. Later success does not erase this relational/ethical fact.

## 19. Aftermath without reset

`SHARED CRISIS ENDS → RELATIONSHIP STATE PERSISTS / CHANGES → NEW TERMS REQUIRED`.

Do not use survival as automatic reconciliation.

## 20. Success creates series pressure

`LOCAL SUCCESS → PUBLIC MEANING → AUTHORITY MODEL CHANGES → NEW SERIES PRESSURE`.

No need to convert a true success into a hidden failure to launch the next book.

## 21. IVDIVO firewalls

Do NOT import:
- scarcity economy as orbital norm;
- sponsorship as hidden currency;
- cruelty/dystopia as default institution;
- forced suffering as proof of YA depth;
- first-person-present thriller cadence as house style;
- popularity as moral legitimacy;
- romance as evidence;
- public performance as private truth.

## Bottom line

The highest-value transfer is not arena brutality. It is the causal triangle among **young person, institution and audience**, with public performance changing real options while private identity and relationships remain only partially controllable.
