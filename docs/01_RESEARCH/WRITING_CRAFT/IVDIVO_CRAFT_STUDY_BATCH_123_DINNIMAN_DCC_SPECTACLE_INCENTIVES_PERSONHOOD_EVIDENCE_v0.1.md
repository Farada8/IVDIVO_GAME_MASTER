## WHY THIS SOURCE MATTERS

The transferable value of *Dungeon Crawler Carl* is not LitRPG stats. It is the interaction among a rule-making institution, a measured participant population, a public audience, resource incentives, classification systems and real moral stakes.

## PRODUCTION MECHANISMS

### B123-G01 — REAL OBJECTIVE / PROXY METRIC
For every rating/ranking/reputation system write:
`REAL OBJECTIVE → MEASURED PROXY → BEHAVIOR REWARDED BY PROXY → POSSIBLE DIVERGENCE → COST`.

### B123-G02 — OBSERVATION CHANGES BEHAVIOR
`KNOWN AUDIENCE → SELF-PRESENTATION → TACTIC CHANGE → TASK EFFECT`.
If being watched never changes behavior, the audience layer is decorative.

### B123-G03 — EDITED EVIDENCE PROVENANCE
`EVENT → RAW TRACE → SELECTED CLIP → ORDER/FRAME → PUBLIC MODEL`.
Never let edited footage silently become raw causal evidence.

### B123-G04 — CLASSIFICATION/PERSONHOOD FIREWALL
`SYSTEM CATEGORY ≠ PERSONHOOD STATUS`.
NPC, robot, service unit, anomaly, asset, organism, pet, trainee or risk category are operational labels, not conclusions about moral agency.

### B123-G05 — CHOICE-ARCHITECTURE RESPONSIBILITY
When an actor commits harm, audit:
`AVAILABLE OPTIONS → INFORMATION → INCENTIVES → COERCION → DESIGNER OF OPTION SET → ACTOR CHOICE → DISTRIBUTED RESPONSIBILITY`.

### B123-G06 — COMPLIANCE/CONSENT FIREWALL
`INFLUENCE SUCCESS ≠ CONSENT`.
Charisma, algorithmic nudging, institutional pressure, status and powerful technology can alter behavior without legitimizing agreement.

### B123-G07 — AUTHORITY CLAIM NEEDS TRACES
`OFFICIAL/PERSUASIVE ACCOUNT → INDEPENDENT TRACE → CONTRADICTION TEST → CONFIDENCE UPDATE`.

### B123-G08 — ADAPTIVE-RULE SYSTEM
If agents exploit a system, ask whether administrators observe and patch the exploit.
`EXPLOIT → OBSERVATION → POLICY UPDATE → NEW OPTION SPACE`.
Static rules are inappropriate for an actively governed adaptive system unless canon explains why.

### B123-G09 — ACCEPTED RESPONSIBILITY AS ADHESIVE
In post-money stories, causal involvement can come from:
`VOLUNTARY COMMITMENT → REAL DEPENDENCE BY OTHERS → COST OF WITHDRAWAL → CONTINUED ACTION`.
No salary/rent/debt is required.

### B123-G10 — PERSONHOOD WITHOUT HUMANIZATION
A nonhuman character can acquire new capabilities, language, responsibility and relationships without converging toward human embodiment or human tastes.

### B123-G11 — TOOL × USER × ENVIRONMENT
`TECHNOLOGY/ABILITY → OPERATOR CAPABILITY → BODY → ENVIRONMENT → ACTUAL EFFECT`.
A tool description is not its scene-level affordance.

### B123-G12 — MORAL CAUSAL LEDGER
For complex harm:
`MY ACTION → DIRECT EFFECT → OTHER AGENTS' CHOICES → SYSTEM CONDITIONS → DOWNSTREAM RESULT → RESPONSIBILITY BOUNDARY`.
Avoid both total self-exoneration and total personalized blame.

## FAILURE MODES

1. METRIC-AS-MISSION — proxy optimization replaces the real purpose without narrative awareness.
2. LEGALITY-AS-LEGITIMACY — procedure is treated as consent or justice.
3. CATEGORY-AS-PERSONHOOD — institutional label decides moral status.
4. PLATFORM-MORAL-OUTSOURCING — institution engineers a cruel option set and blames only participants.
5. EDITED-CLIP CERTAINTY — montage treated as raw event record.
6. CONSENT-BY-COMPLIANCE — behavioral success treated as free agreement.
7. NONHUMAN-HUMANIZATION — character growth means becoming more human.
8. GAME-MECHANIC IMPORT — stats/achievements/countdowns imported into a non-LitRPG novel as universal retention tools.
9. AUDIENCE-CURRENCY LEAK — reputation accidentally becomes hidden money in post-money Orbital Youth.
10. TRANSLATION-STYLE OVERCLAIM — Russian translation cadence used to diagnose Dinniman's English sentence craft.
