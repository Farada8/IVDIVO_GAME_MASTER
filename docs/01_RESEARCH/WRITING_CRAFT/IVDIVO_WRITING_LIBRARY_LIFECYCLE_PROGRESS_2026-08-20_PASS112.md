## Major synthesis

Current Scofield scene profile:

`BEFORE STATE → PULSE / WANT → TENSION OR NEGOTIATION → FOCAL POINT / TERMS CHANGE → RELEASE → AFTER STATE → DOWNSTREAM LINK`.

This is diagnostic, not formulaic.

### Ch4 — Focal Point
`BEFORE → X → AFTER`.
X may be a quiet evidence, consent, relationship, authority, responsibility, or model turn. It is not required to be a climax/twist/epiphany.

### Ch5 — Pulse
`BOOK PULSE → SCENE PULSE → EVENT → CHANGED STATE`.
Pulse is persistent underlying pressure, not necessarily overt conflict.

### Ch6 — Tension
`LIVE QUESTION → TENSION SOURCE → MAINTENANCE → RELEASE MODE → CONSEQUENCE`.
Tension may be internal, relational, anticipatory, evidentiary, or physical. Release can be positive, deferred, suppressed, or carried into the next scene.

### Ch7 — Negotiation
`WANT/BOUNDARY A ↔ WANT/BOUNDARY B → TACTICS → REFRAME / CONCESSION / REFUSAL → NEW TERMS OR COLLAPSE → CONSEQUENCE`.
Negotiation provides a broader model than direct confrontation and preserves agency under asymmetric power.
