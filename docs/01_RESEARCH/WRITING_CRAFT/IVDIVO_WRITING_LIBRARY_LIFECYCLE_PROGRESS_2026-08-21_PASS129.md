## 7. Idea vs Story
Mayer reinforces:
`IDEA ≠ STORY`.

IVDIVO conversion:
`SEED / PREMISE → DOMINANT CAUSAL ENGINE → WHO WANTS WHAT → ACTION → WORLD RESPONSE → CHANGED STATE → NEXT CHOICE`.

His claim that the original idea should never change is rejected as too rigid.

Replacement:
`ORIGINATING PROMISE / HYPOTHESIS → DRAFT EVIDENCE → CHARACTER/CANON/CAUSALITY TEST → KEEP / REPLAN / BANK / DISCARD`.

## 8. Defect-level routing

`OBSERVED DEFECT → DEFECT LEVEL → DEPENDENCIES → MINIMAL CORRECT FIX → REGRESSION TEST`.

## 9. Tool 4 — research / preparation
Stable findings:
- research must produce actionable story material, not prove author expertise;
- book dissection is mechanism analysis, not imitation;
- source/page provenance should survive research compression;
- maps and diagrams protect spatial/temporal causality;
- outline can and should change when live writing reveals facts/constraints the plan missed;
- chapter planning benefits from START STATE / END STATE / FUNCTION / CONTINUITY DEBT.

## 10. Tool 5 — story / pacing
Useful mechanisms:
- `WRITER FEELS X ≠ READER FEELS X`;
- coincidence may complicate but should not repeatedly solve from outside the causal system;
- memory is a person-sourced model of the past, not objective world fact;
- show/tell is a sliding scale;
- reader-time communicates implied importance;
- backstory earns space when it changes present comprehension/action;
- local payoff and aftermath are distinct.

Rejected as universal:
- mandatory protagonist/antagonist confrontation;
- suspense as necessary engine of nearly all fiction;
- darkest-moment crisis;
- all loose ends must close;
- action must always be shown;
- fixed 2003 word-count/market/submission conventions.
