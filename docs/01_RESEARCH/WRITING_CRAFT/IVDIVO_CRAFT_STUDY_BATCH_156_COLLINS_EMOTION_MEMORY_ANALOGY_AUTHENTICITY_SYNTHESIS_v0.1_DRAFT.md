# IVDIVO CRAFT STUDY — BATCH 156
## Brandilyn Collins — Emotion Memory · Analogy · Authenticity · Character Transfer

Status: derived from **completed strict read** of *Getting Into Character*.

## Core synthesis
Collins is most useful when emotion-memory work is treated as **raw material generation**, not as proof of authenticity and not as a mandatory route into every difficult emotion.

Operational chain:

`INPUT EXPERIENCE / OBSERVATION / IMAGINATION → AFFECTIVE OR SENSORY COMPONENT → CHARACTER FILTER → PRESENT OBJECTIVE → TACTIC → CHOICE → CONSEQUENCE → READER TEST`

The character filter includes values, history, embodiment, relationships, knowledge, status, consent, and current cost.

## Production gates
### B156-G01 — Emotion Memory Optionality
Personal autobiographical recall is optional. Start with Given Circumstances, present objective, relationship, action, imagination, observation, and embodiment.

### B156-G02 — Analogy Distance
A small personal emotion can help generate language for an extreme fictional circumstance, but:
`SHARED AFFECTIVE COMPONENT != SHARED MOTIVE / ETHICS / RESPONSIBILITY`.

### B156-G03 — Observation Provenance
When using observed people as emotional research:
`BEHAVIOR SEEN → EMOTION HYPOTHESIS`, not `EMOTION KNOWN`.

### B156-G04 — Character Transfer
Never paste the writer's exact reaction onto the character.
`AUTHOR RESPONSE → ABSTRACT MECHANISM → CHARACTER-SPECIFIC TRANSFORMATION`.

### B156-G05 — Writer/Character/Reader Separation
`WRITER FEELS X != CHARACTER FEELS X != READER FEELS X`.
All three must be evaluated independently.

### B156-G06 — Subtext Is Optional
Subtext earns its place when it is the natural tactic. Directness may itself be the earned relational turn.

### B156-G07 — Emotion Is Not Evidence
`EMOTIONAL DISPLAY → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.
Do not infer guilt, motive, consent, personhood, or ontology from intensity.

### B156-G08 — Nonhuman Personhood Independence
A conscious nonhuman character does not need human trauma, human autobiographical recall, human facial cues, or human-style emotion labels.

### B156-G09 — Technique Routing
Collins' seven techniques form a mechanism bank, not a seven-step drafting checklist.
`LIVE DRAFT → DEFECT → RELEVANT TOOL → RETEST`.

### B156-G10 — Inner/Outer Rhythm Separation
Internal processing speed and visible movement speed are separate variables.

### B156-G11 — Compression Is Not Chopping
Delete repeated meaning, summarize routine process, merge microbeats, or use indirect dialogue before shortening syntax mechanically.

### B156-G12 — Paragraph Before Fragment
Emotional microbeats that form one perceptual/decision unit should usually remain a coherent paragraph.

## Cross-source reconciliation
**Stanislavski / practical Stanislavski scholarship** broadens the stimulus set beyond direct autobiographical recall: Given Circumstances, imagination, action, attention, relationship, environment, language, and sensory stimuli can all awaken feeling. Forced recall may detach the creator from present action.

**Card / Corbett / McKee Character** correct one-core-truth determinism: use competing priorities and relation-specific behavior.

**Zunshine / Fludernik / le Carré** correct cue interpretation: expression is sourced evidence about a possible state, not direct access to motive.

**Le Guin / Clark / Prose / Lodge / Zinsser** correct rhythm overreach: emotional intensity does not imply short-sentence density.

**LaPlante / Lamott / Bell / Swain** support a staged studio process: generate living material first; diagnose and route craft tools after.

## IVDIVO applications
### ONE MAIN STORY
Emotion work must alter a real story variable: tactic, relationship, consent, evidence interpretation, responsibility, or choice. Emotional vividness without downstream consequence is not automatically progression.

### YA
Do not assign every young character a trauma simply to justify depth. Differentiate by what they value, whom they need something from, what they fear losing, and how their tactics change under pressure.

### Mystery / suspense
Do not use emotional certainty as a shortcut to clue certainty. Preserve trace provenance and independent corroboration.

### Conscious robots / distributed persons
Human emotional familiarity may improve reader connection but cannot be a personhood criterion. Preserve own model, own preference, consent/refusal, and consequential choice.

### Consciousness schools
Intense private experience remains experience. It does not bypass reproducibility, competing interpretations, independent testing, or the ontology ceiling.

### Prose and line editing
The repair order remains:
`STRUCTURE / SCENE FUNCTION → POV/EVIDENCE → EMOTIONAL TURN → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

## Standing manuscript law
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.
