# IVDIVO BATCH 156 — Emotion Memory / Character Transfer / Personhood Application Gate

Status: production gate derived from completed strict lifecycle of Brandilyn Collins, *Getting Into Character*.

## 1. Trigger condition
Do **not** reach for autobiographical emotion recall because a scene merely feels "not emotional enough." First diagnose the actual defect:

`SCENE FUNCTION → PRESENT WANT → RELATIONSHIP / CONSENT → POV / KNOWLEDGE → EMBODIMENT → TACTIC → CHANGED STATE → READER EFFECT`.

Only if the scene is structurally sound but emotionally generic should affective-source work be considered.

## 2. Preferred emotional-source hierarchy
1. Given Circumstances / current scene reality.
2. Present want, responsibility, or question.
3. Relationship, status, trust, consent, and boundary.
4. POV knowledge / evidence state.
5. Embodiment and physical affordances.
6. Character-specific tactic or action.
7. Imagination and counterfactual rehearsal.
8. Observation of others or analogous low-risk experience.
9. Optional autobiographical recall, voluntarily chosen.
10. Transform through the character before writing prose.

Standing law:

**`PERSONAL MEMORY = OPTIONAL INPUT, NOT REQUIRED AUTHENTICITY`.**

No collaborator, writer, actor, or model is required to mine trauma to produce convincing fiction.

## 3. Character-transfer gate
Never paste the writer's exact emotional response onto the character.

`RAW INPUT → ABSTRACT AFFECTIVE / SENSORY MECHANISM → CHARACTER VALUES + HISTORY + RELATIONSHIP + EMBODIMENT + CURRENT WANT → TACTIC / CHOICE → CONSEQUENCE`.

Acceptance test: if the passage could be transferred unchanged to another major character, the transformation is incomplete.

## 4. Analogy-distance gate
A small real experience may supply one affective component for a much more extreme fictional event.

But:

**`SHARED AFFECTIVE COMPONENT ≠ SHARED MOTIVE / ETHICS / RESPONSIBILITY / BEHAVIORAL PREDICTION`.**

Do not use emotional analogy as proof of psychology.

## 5. Mystery / evidence firewall
Emotional display changes a character's model, not the world's evidence status.

`DISPLAY / SILENCE / INFLECTION / HESITATION → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.

Never promote fear, attraction, anger, grief, certainty, warmth, embarrassment, or refusal directly into motive, guilt, consent, personhood, or ontology.

## 6. ROOM 917
Elena/Julian emotional leakage may change:
- trust;
- boundaries;
- willingness to disclose;
- investigative tactic;
- access to a source;
- willingness to cooperate.

It does **not** change what a recording, architectural plan, timestamp, source lineage, or physical trace proves.

Standing firewall:

**`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.**

## 7. Orbital Youth / YA
Do not manufacture wounds merely to create depth.

Prefer differentiation through:
- autonomy;
- belonging;
- trust;
- first real responsibility;
- consent;
- mastery;
- privacy;
- reputation;
- relationship;
- unique opportunity;
- conflicting good values.

Valid YA development includes partial change, tactical change, tested stability, relationship change, mistaken inference, or a longer series arc. Mandatory therapeutic healing is prohibited.

## 8. Conscious robots / distributed persons
Human emotional familiarity is neither necessary nor sufficient for personhood.

Use:

`OWN PRIORITIES → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Do not require:
- trauma;
- autobiographical human-style memory;
- human facial leakage;
- warmth;
- nervous gestures;
- sexual/romantic humanization.

## 9. B07 / nonhuman personhood
Human empathy with the distributed entity may motivate investigation, but it cannot establish subjecthood.

Required chain:

`INDEPENDENT PERSONHOOD EVIDENCE → ENTITY'S OWN MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

The entity must own at least one indispensable decision in the climax.

## 10. Consciousness-practice schools
Maintain:

`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Intensity, vividness, sincerity, or emotional certainty do not advance a claim up this ladder.

## 11. Prose / anti-choppiness gate
Do not translate emotional richness into gesture density.

Prohibited repair pattern:

`line → glance → breath → hand movement → one-line thought → line`.

Preferred repair order:

`SCENE FUNCTION → POV/EVIDENCE → EMOTIONAL/RELATIONAL TURN → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several microbeats form one perceptual or decision unit, they usually belong in one coherent paragraph.

## 12. Tool-routing gate
Collins' seven techniques form a mechanism bank, not a drafting checklist.

`LIVE DRAFT → OBSERVED DEFECT → RELEVANT TOOL → REPAIR → RETEST`.

Do not run all character/emotion diagnostics simultaneously while generating prose.

## 13. LESSON ZERO development-lock gate
This source alone is **not** new defect evidence.

Standing law:

**`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.**

Allow local intervention only if a current passage demonstrates a specific problem such as:
- generic emotional response shared by multiple characters;
- unexplained behavioral reversal;
- emotion treated as evidence;
- microgesture confetti;
- paragraph fragmentation caused by over-dramatization;
- author-proxy emotional logic;
- consent/personhood error.

## 14. Acceptance test
A repaired scene passes when:
1. the emotional turn follows from the current circumstances;
2. the response belongs to this character and relationship;
3. evidence status remains separate from emotional interpretation;
4. no trauma mining was required merely to authenticate prose;
5. nonhuman personhood does not depend on human emotional resemblance;
6. paragraph and sentence rhythm follow the reader effect rather than a fragment quota;
7. the turn changes a downstream story variable or is intentionally compressed.
