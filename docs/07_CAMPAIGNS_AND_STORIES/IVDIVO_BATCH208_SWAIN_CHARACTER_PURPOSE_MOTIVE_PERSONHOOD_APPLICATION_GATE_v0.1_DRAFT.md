## Standing application order
`OBSERVED DEFECT → CHARACTER LAYER → MINIMAL REPAIR → REGRESSION TEST`.

Do not open a global rewrite merely because this source adds a new character theory.

## LESSON ZERO Book One
Development lock remains.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Only use this gate if current reader/audio/continuity evidence demonstrates one of:
- generic character differentiation;
- action without a legible present objective;
- sudden tactic change with no changed value/relationship/cost/evidence;
- impossible POV knowledge;
- quirk/mannerism clutter;
- backstory that does not alter the present;
- dialogue that reports motive as fact without evidence.

### Surgical diagnostic
For a suspect scene:
`WHAT MATTERS TO POV NOW? → WHAT DO THEY WANT NOW? → WHY DO THEY REMAIN INVOLVED? → WHAT RELATIONSHIP/COST MODIFIES PRIORITY? → WHAT TACTIC? → WHAT CHANGED?`

If those answers already exist in current text, do not add explanatory prose.

## Orbital Youth
For each major teen:
`PRIORITY / CONCERN → PRESENT PURPOSE → CONTINUING INVOLVEMENT → RELATION-SPECIFIC TACTIC → OUTCOME → NEXT CHOICE`.

Character differentiation must not rely on five slang packages or five decorative quirks.

### Post-money stakes firewall
Valid stakes include:
- trust;
- consent;
- privacy;
- access;
- responsibility;
- time;
- belonging;
- mastery;
- relationship;
- reputation;
- unique mission/opportunity.

Do not reintroduce salary/rent/credits under renamed abstractions.

### Milieu gate
`ORBITAL RULE / SOCIAL NORM → WHAT THIS TEEN NOTICES → AFFORDANCE / FRICTION → TACTIC → CONSEQUENCE`.

Ordinary worldbuilding is strongest when different characters treat different facts as normal, prestigious, embarrassing, unfair or irrelevant.

## ROOM 917
### Motive/evidence separation
`OBSERVED SPEECH / BEHAVIOR / SILENCE → MOTIVE MODEL A/B/C → DISCRIMINATING EVIDENCE → UPDATE`.

Never promote behavior directly to guilt/motive.

`SILENCE / INFLECTION / TRUST / ATTRACTION / KISS / CONFESSION ≠ CORROBORATION`.

### Dialogue admission
Exact dialogue is protected when wording changes:
- clue access/provenance/status;
- Elena↔Julian trust/boundary/disclosure;
- consent;
- authority;
- investigative tactic;
- decision ownership.

Routine transfer can be indirect/summary.

## B07 — THE UNLISTED CITY
Human or institutional labels such as `anomaly`, `service unit`, `organism`, `monster`, `asset` are reader-model inputs, not personhood facts.

Personhood gate:
`INDEPENDENT EVIDENCE → OWN WANT/PREFERENCE → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

`CREATED / DISCOVERED / RESCUED ≠ OWNED`.

Do not use human quirk, trauma, slang or emotional display as a shortcut to nonhuman personhood.

## Character background gate
Before inserting backstory:
`WHAT PRESENT BEHAVIOR / SALIENCE / RELATION / OPTION / EVIDENCE DOES THIS BACKGROUND CHANGE?`

If none: compress, bank or cut.

## Anti-choppiness gate
Do not translate character mechanics into typography.

Bad mechanical conversion:
`stimulus. reaction. gesture. thought. choice.`

Preferred:
`PERCEPTUAL / DECISION UNIT → COHERENT PARAGRAPH → RHYTHM BY READER EFFECT`.

`BEAT / TAG / GESTURE ≠ SENTENCE BREAK`.

## Regression tests
After a repair confirm:
1. causal engine unchanged unless defect required it;
2. canon unchanged unless separately authorized;
3. evidence status not promoted by motive language;
4. POV knowledge remains legal;
5. voice remains character-owned;
6. no new explanatory restatement after already legible action;
7. paragraph continuity improves rather than fragment density increasing.
