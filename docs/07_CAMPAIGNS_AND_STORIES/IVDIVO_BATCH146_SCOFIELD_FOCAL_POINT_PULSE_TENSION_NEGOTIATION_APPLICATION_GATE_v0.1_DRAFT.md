# IVDIVO — Batch 146 Application Gate
## Focal Point · Pulse · Tension · Negotiation

Status: **PRODUCTION GATE / additive only**. This does not reopen any development-locked manuscript by itself.

## Standing law

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

LESSON ZERO Book One remains development-locked. Use these gates only when a current manuscript, reader, audio, continuity, or evidence-provenance defect is observed.

## Scene admission profile

Before line editing any scene, record:

`BEFORE STATE → SCENE PULSE → TENSION / NEGOTIATION MODE → FOCAL POINT / TERMS CHANGE → RELEASE → AFTER STATE → DOWNSTREAM LINK`.

If no meaningful after-state or downstream dependency exists, test SUMMARY / MERGE / DELETE / REBUILD before prose polishing.

## Focal-point gate

The focal point may be:
- evidence-status change;
- consent/refusal;
- relationship boundary;
- authority/access change;
- responsibility accepted/rejected;
- model revision;
- recognition;
- decision;
- operational result.

Do not manufacture a twist, disaster, epiphany, or one-line punch merely to make the focal point visible.

## Pulse gate

Ask:
- What underlying need/question/obligation remains alive?
- Why does this exact event matter to this POV/agent now?
- What does contact between pulse and event change?

A quiet or procedural scene is admissible if this pressure is live and consequential.

## Tension gate

`LIVE QUESTION → PRESSURE / UNCERTAINTY → RELEASE MODE → CONSEQUENCE`.

Do not equate tension with:
- shouting;
- physical danger;
- failure;
- cliffhanger;
- withheld information;
- short sentences.

A correct answer, reconciliation, successful test, consent, or earned relief may increase the next responsibility and therefore strengthen the story.

## Negotiation / decision-ownership gate

For any scene where agents negotiate terms:

`FORMAL AUTHORITY → COST BEARER → DECISION OWNER → RIGHT TO REFUSE → AVAILABLE APPEAL / EXIT`.

Then track:

`WANT / BOUNDARY A ↔ WANT / BOUNDARY B → TACTICS → REFRAME / CONCESSION / REFUSAL → NEW TERMS → CONSEQUENCE`.

Compliance under pressure is not automatically consent.

## ROOM 917

Protect real-time dialogue when exact wording changes:
- clue provenance/status;
- Elena↔Julian trust or boundary;
- consent;
- evidence access;
- investigative tactic.

Compress repeated recorder/contact-mic setup, corridor movement, known technical confirmation, and logistics when they do not change state.

Hard firewall:
`TRUST / ATTRACTION / KISS / CONFESSION ≠ CORROBORATION`.

## Orbital Youth

Institutional pressure should often be written as negotiation over:
- qualification;
- standing;
- responsibility;
- evidence thresholds;
- privacy;
- consent;
- access;
- appeal;
- team membership.

Avoid default YA frame `teen vs evil institution` when competent adults/robots have legitimate countermodels.

Post-money firewall remains active: negotiation over access/roles/priority must not silently recreate salary, rent, credits, or consumer purchasing hierarchy.

## B07 — THE UNLISTED CITY

After independent personhood threshold:

`ENTITY'S OWN MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Humans may negotiate their obligations and safety constraints, but may not settle the entity's continuity exclusively among themselves.

Kyra's strongest arc remains:
`PROCEDURAL PRECISION → EVIDENCE EXCEEDS CATEGORY → BOUNDED DISCRETION → DOCUMENTED ACCOUNTABILITY`.

## Conscious robots

Do not reduce negotiation to human request + machine compliance.
Require:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → TACTIC → CHOICE → CONSEQUENCE`.

A robot may negotiate by silence, refusal, conditional cooperation, counterproposal, withdrawal, or reframing.

## Consciousness-practice schools

No emotional or negotiated consensus upgrades ontology:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Anti-choppy prose gate

Analytic beats/tactics are not sentence boundaries.

Before editing a choppy passage:

`SCENE NECESSITY → SCENE WEIGHT/MODE → EVENT TARGET → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several microbeats are one perceptual/decision unit, prefer coherent paragraph architecture over one-line beat transcription.

## Acceptance test

A revised scene passes Batch 146 only if:
1. its pulse is identifiable;
2. its focal point changes state;
3. tension/negotiation has a specific source;
4. release changes downstream options;
5. consent/evidence/personhood statuses remain distinct;
6. prose rhythm follows reader effect rather than beat count;
7. the scene pays into ONE MAIN STORY or an earned payoff.
