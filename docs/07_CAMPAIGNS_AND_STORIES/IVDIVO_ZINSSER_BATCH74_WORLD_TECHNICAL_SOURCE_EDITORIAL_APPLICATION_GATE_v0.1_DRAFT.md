# A. RUN ORDER
This gate runs after causal and scene-level acceptance:
`ONE MAIN STORY → SCENE NECESSITY → POV/KNOWLEDGE → MODE → B74 WORLD/SOURCE/TECH GATE → PARAGRAPH/RHYTHM/LINE EDIT`.

# B. ORBITAL WORLD SCENES
For each unusual place/system:
1. What rule/practice is different here?
2. Who is actually doing something because of it?
3. What option becomes easier/harder/impossible?
4. What relation/decision changes?
5. Can at least one decorative paragraph be removed without losing story? If yes, remove/compress it.

Reject `technology catalogue` and `orbital tourism` when no state changes.

# C. POST-MONEY MECHANISM TEST
Flag: `allocation`, `quota`, `priority`, `qualification`, `contribution`, `service`, `assignment`, `access`, `scheduling`.
For each:
`WHAT IS SCARCE? → WHY CAN'T ROBOTIC PRODUCTION SOLVE IT? → WHO DECIDES? → WHO CAN REFUSE/APPEAL? → WHAT IS THE HUMAN/ROBOT COST?`
If mechanism is only disguised purchasing power, repair canon before prose.

# D. TECHNICAL EXPOSITION
Use:
`CURRENT CHARACTER QUESTION → MINIMUM ANSWER → ACTION/TEST → RESULT → NEXT QUESTION`.
Do not let experts explain everything because author researched it. Do not make experts incompetent merely so protagonist can ask questions.

# E. SOURCE / ARCHIVE / MYSTERY MATERIAL
Every important claim carries:
- source;
- direct observation vs report;
- compression/editing status if quoted;
- context;
- confidence;
- alternative interpretation;
- what evidence could change status.

Exact wording is protected when wording itself changes evidence, consent, relation or decision. Otherwise summary/indirect reporting is allowed.

# F. CONSCIOUS ROBOTS
Never use `robotic` to mean empty, cold or mechanical as a default ontology.
Named robot acceptance:
`OWN WANT + OTHER RELATIONSHIPS + RELATION-SPECIFIC SPEECH + CONSENT/REFUSAL + CONSEQUENCES OF OWN CHOICES`.

# G. CONSCIOUSNESS SCHOOLS
Production notes must distinguish:
`OBSERVED / REPRODUCED / SCHOOL INTERPRETATION / CONTESTED / UNKNOWN / CANON FACT`.
No prestigious terminology can upgrade the status.

# H. HUMOR / YOUTH VOICE
- joke follows real character/system pattern;
- no universal writers-room wit;
- youth voice comes from worldview and cultural normality, not imported Earth-2020s slang;
- joke cannot erase injury, consent, betrayal or serious consequence immediately after it occurs unless that reaction belongs specifically to the character and scene.

# I. EDITORIAL PASS
Reviewer note format:
`EVIDENCE → READER EFFECT → DIAGNOSIS → REPAIR OPTIONS`.
Do not directly rewrite all voices into a shared editorial register.

# J. ANTI-ОБРУБКИ
If prose feels chopped:
1. verify scene belongs;
2. verify show/tell mode;
3. verify POV-distance;
4. verify direct dialogue is necessary;
5. group uninterrupted attention units into paragraphs;
6. run reader-state continuity;
7. only then tune sentence length.

No short-sentence KPI.
