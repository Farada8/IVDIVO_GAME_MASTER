# 1. Global rule
A newly studied craft source is **not evidence that a manuscript is defective**.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Bell's revision methods are tools to route an observed problem; they are not permission to reopen every locked book.

# 2. Revision router
For any manuscript defect, route in this order:

`BOOK ENGINE / ONE MAIN STORY`
→ `CHAPTER / SEQUENCE CAUSALITY`
→ `SCENE ADMISSION / WEIGHT / MODE`
→ `CHARACTER / RELATIONSHIP / PERSONHOOD`
→ `POV / KNOWLEDGE / EVIDENCE`
→ `DIALOGUE / EXPOSITION / SUBTEXT`
→ `PARAGRAPH / READER-STATE CONTINUITY`
→ `SENTENCE RHYTHM / CONTRAST`
→ `WORDING / COPY`.

Do not solve an upstream defect with downstream polish.

# 3. Whole-read gate
Before any new full-book revision campaign:
1. state the new evidence;
2. read/inspect the current authoritative manuscript as a reader, not against an old outline;
3. mark broad effects first;
4. build/update the actual story-state map;
5. rank defects by dependency;
6. repair the highest upstream defect only;
7. regression-test downstream chapters.

# 4. Deepening-lab firewall
Bell's exploratory exercises may be used privately for:
- alternate objectives;
- background/ghost possibilities;
- sensory expansion;
- voice experiments;
- first/third-person recasting;
- fear/stakes variants;
- alternate endings;
- opposite-character tests.

Nothing generated enters canon automatically.

`LAB OUTPUT → CHARACTER TRUTH → CANON → CAUSALITY → PERSONHOOD → ONE MAIN STORY → READER EFFECT → ADMISSION`.

# 5. Anti-choppiness gate
Do **not** repair prose by forcing more short lines.

Before editing a choppy passage ask:
- should this material be a scene at all?
- should part of it be summary/indirect/ellipsis?
- are related microbeats split into separate paragraphs?
- does sentence B inherit the reader-state left by sentence A?
- is the key moment receiving enough subjective duration?

Standing law:
`ACTION / SUSPENSE / EMOTION ≠ SHORT-SENTENCE DENSITY`.

`COMPRESSION ≠ CHOPPING`.

# 6. LESSON ZERO Book One
**DEVELOPMENT LOCK REMAINS.**

Bell does not supply new current defect evidence.

Allow local repair only if there is new, reproducible evidence such as:
- repeated beta-reader confusion;
- audio-performance ambiguity;
- continuity/canon error;
- wrong POV knowledge access;
- evidence provenance leak;
- duplicate scene function;
- state-neutral dramatization that should be compressed;
- choppiness traceable to paragraph/mode fragmentation;
- copy defect.

Otherwise: KEEP.

# 12. Release / stop gate
A revision campaign stops when:
- accepted upstream defects are repaired;
- downstream regression tests are green;
- no repeated reader/audio evidence supports another global change;
- remaining differences are taste/preferences rather than demonstrated failures.

`NO NEW DEFECT EVIDENCE → STOP GLOBAL REVISION`.
