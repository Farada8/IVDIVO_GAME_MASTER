## A. Universal pre-line-edit gate
Before prose polishing, test the selected chapter/scene sequence:

1. **Unified action:** what dominant book problem does this material change?
2. **After vs because:** what prior state causes the next state?
3. **Episode payment:** what downstream choice/evidence/relationship/access/result changes because this scene exists?
4. **Scale:** is the material serving this book or merely proving the saga/world is large?
5. **Reveal causality:** did discovery emerge from earlier traces/actions rather than author declaration?
6. **Resolution integrity:** is the solution already earned by established story resources?
7. **Reader model:** does surprise revise earlier meaning without changing earlier literal facts?
8. **Character truth:** is apparent inconsistency explainable by changed values/relationship/knowledge/cost?
9. **Style:** is unusual diction/metaphor selective enough that clarity and contrast survive?
10. **Only then:** paragraph continuity → sentence rhythm → wording.

## B. LESSON ZERO Book One
Standing authority remains:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Do **not** retrofit Aristotle's tragedy architecture, tragic fall, pity/fear, unhappy ending or plot-first hierarchy.

If new reader/audio evidence identifies a structural problem, diagnose in this order:
`AFTER/BECAUSE → EPISODE PAYMENT → REVEAL CAUSALITY → POV/EVIDENCE → SCENE MODE → PARAGRAPH/RHYTHM`.

Only the affected dependency layer may reopen.

## C. ROOM 917 — mystery
For every load-bearing clue maintain:

`WORLD FACT → TRUE TRACE → ORIGINAL SOURCE → SOURCE LINEAGE → ELENA ACCESS → JULIAN ACCESS → READER ACCESS → INTERPRETATION A → ALTERNATIVE MODEL → DISCRIMINATING TEST → CORROBORATION STATUS → NEXT ACTION`.

### Fair paralogism
Allowed:
`TRUE TRACE B → plausible false cause A → later evidence reveals cause C`.

Forbidden:
- false trace supplied by narrator;
- earlier fact silently changed;
- POV hero already knows X but narration conceals X solely for surprise;
- culprit/identity reveal requiring personality retcon.

Standing firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

Relationship change may alter disclosure/access/tactic, never the physical truth-status of evidence.

## D. Orbital Youth

`ONE MAIN STORY ≠ ONE POV`.

For each teen/robot strand:
`LOCAL WANT → LOCAL ACTION → UNIQUE CHANGE → EFFECT ON SHARED ENGINE → PAYOFF`.

No mandatory setback merely to imitate tragedy.

## E. B07 — THE UNLISTED CITY
Personhood discovery must not be a token reveal or author declaration.

Required chain:
`PATTERN → INDEPENDENT TRACE LINES → ALTERNATIVE EXPLANATIONS → DISCRIMINATING TEST → PERSONHOOD THRESHOLD → HUMAN CATEGORY FAILS → ENTITY PREFERENCE/CONSENT BECOMES DECISION-RELEVANT → ENTITY CHOICE CHANGES HUMAN OPTION SPACE`.

After threshold, humans may create options/protections; they may not decide the entity's continuity entirely among themselves.

## F. Conscious robots / nonhuman agents
Aristotle's human moral categories do not define nonhuman personhood.

Use:
`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

`MORE SENSORS ≠ OMNISCIENCE`.

`OBSERVED BEHAVIOR ≠ MOTIVE`.

## G. Consciousness-practice schools
Dramatic plausibility and analogy are not scientific proof.

Required epistemic ladder:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

`METAPHOR / PROBABILITY / INTENSITY OF EXPERIENCE ≠ CORROBORATION`.

## H. Anti-choppiness gate
Do not translate plot beats, discoveries or emotional turns into one-line typography.

`BEAT MAP ≠ SENTENCE BREAK`.

`ACTION / SUSPENSE / DISCOVERY ≠ SHORT-SENTENCE DENSITY`.

Repair:
`BOOK ENGINE → UNIFIED ACTION → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → PARAGRAPH INTENT / READER-STATE → SENTENCE CONTRAST → WORDING`.

A short line is protected only when it has a distinct function: decision, revelation, pause, contrast, comic timing or end-weight.

## I. Book Engine checks worth encoding
Where machine-checkable or hybrid:
- scene/chapter has declared dominant-engine dependency;
- adjacent major beats identify a changed state rather than chronology only;
- reveal has upstream trace/source IDs;
- climax solution does not introduce an unregistered late mechanism;
- POV knowledge does not exceed source/access permissions;
- parallel strand has a downstream dependency/payoff;
- book-scale material does not rely on unrelated saga exposition;
- evidence reinterpretation preserves literal earlier trace.

## Final decision law
Use Aristotle as a **causal diagnostic**, not a tragedy template.

`STORY PROBLEM → CAUSAL / INFORMATION DIAGNOSIS → MINIMAL CORRECT REPAIR → RETEST`.
