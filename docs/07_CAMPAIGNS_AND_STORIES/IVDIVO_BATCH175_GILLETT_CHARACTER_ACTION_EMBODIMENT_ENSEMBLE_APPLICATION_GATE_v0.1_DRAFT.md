# IVDIVO BATCH 175 — GILLETT CHARACTER ACTION / EMBODIMENT / ENSEMBLE APPLICATION GATE

## Purpose

Translate useful Stanislavski-derived acting mechanisms into prose/story diagnostics without importing acting dogma, dated psychology or metaphysics.

## 1. Scene action audit

For any weak scene:

`PRIOR STATE → GIVEN CIRCUMSTANCES → OWNER → PRESENT WANT → TACTIC → RESPONSE / SUPPORT / RESISTANCE → ADAPTATION → EXIT STATE → DOWNSTREAM LINK`.

Fail if:
- character has only mood, no actionable pressure;
- partner changes but tactic mechanically repeats;
- exact words/actions do not alter anything;
- scene requires author explanation after the action.

## 2. Dialogue audit

For every important exchange:

`WHAT DO I WANT FROM THIS PERSON NOW?`

Then:
`TACTIC → LISTENER'S ACTUAL RESPONSE → MODEL UPDATE → NEXT TACTIC`.

Do not:
- prewrite subtext performance independent of listener;
- add gesture after each line;
- interpret silence as consent;
- treat attraction/trust as evidence.

ROOM 917:
`RELATIONSHIP STATE ≠ EVIDENCE STATUS`.

## 3. POV / character evidence audit

Separate:
- world/text fact;
- observed behavior;
- self-report;
- other-report;
- POV interpretation;
- hypothesis;
- corroborated claim.

`OBSERVED BEHAVIOR ≠ MOTIVE`.

## 4. Embodiment audit

For humans, robots and nonhumans:

`EMBODIMENT → AFFORDANCES / LIMITS → SALIENCE → ACTION OPTIONS → SOCIAL RESPONSE → CHOICE`.

Do not infer moral status/personhood from human-like facial expression or speech.

For conscious robots:
`MORE SENSORS ≠ OMNISCIENCE`.

## 5. Anti-choppiness / line edit

Never map analytic actions directly to typography.

Wrong:
`beat. reaction. gesture. thought. next beat.`

Correct diagnostic order:
`SCENE NEED → PARAGRAPH UNIT → READER-STATE CONTINUITY → INNER/OUTER TEMPO → SENTENCE CONTRAST`.

## 6. Re-imagination trigger

If a scene's objective, relationship geometry, staging, knowledge access or causal purpose is wrong, use:

`ROUGH RE-IMAGINATION / ACTIVE-ANALYSIS LAB → OBSERVE LIVE TACTICS → REWRITE`.

Do not line-edit first.

## 7. Writers' Room orchestration

Do not run all specialists on live generation.

Use:

`LIVE MATERIAL → DEFECT OBSERVED → RELEVANT DESKS → REPAIR → REGRESSION TEST`.

All desks share canon authority, evidence statuses, scene owner, decision owner and defect vocabulary.

## 8. LESSON ZERO

Standing decision:

`KEEP DEVELOPMENT LOCK`.

Only reopen a layer if there is new reader/audio evidence, canon/continuity defect, acquisition problem, or objectively reproducible line/POV/evidence failure.

## 9. Orbital Youth

Protect:
- competent success;
- relationship-specific tactics;
- post-money stakes;
- agency through refusal/delay/cooperation;
- embodiment-specific choices without humanization.

## 10. B07

After independent personhood evidence:

`ENTITY WANT / MODEL / PREFERENCE → COMMUNICATION / CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Humans may create a bounded choice space; they may not choose continuity for the entity.

## 11. Consciousness-practice firewall

No acting exercise or embodied subjective effect can shortcut:

`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.
