# IVDIVO — BATCH 143 APPLICATION GATE
## Scofield: Event · Meaning · Consequence

**Status:** PROSPECTIVE PRODUCTION GATE  
**Source status:** Sandra Scofield, *The Scene Book* — FULL READ IN PROGRESS; Batch 143 is provisional and does not imply source completion.

---

## 1. Core production law

A scene is not justified by the amount of activity inside it.

Use:

`MICRO-ACTIONS → SCENE EVENT → CONSEQUENCE → DOWNSTREAM CHANGE`.

Before prose polish, complete:

`Because these actions occurred, ______ changed.`

Valid changed-state families:

- physical / operational;
- knowledge / evidence;
- relationship / trust;
- consent / boundary;
- authority / access;
- responsibility / obligation;
- strategy / causal model;
- emotional commitment;
- future option space.

If the blank cannot be filled with a consequential state change, route the material to:

`SUMMARY / MERGE / DELETE / REBUILD`.

---

## 2. ROOM 917 gate

Do **not** treat the following as scene events merely because they are audible/visual/procedural:

- recorder setup;
- contact-mic attachment;
- tape measurement;
- corridor movement;
- repeated wall checks;
- repeated switchboard observation;
- routine playback.

Protect real-time scene weight when exact sequence changes at least one of:

- clue status;
- source provenance;
- Elena↔Julian trust/boundary;
- consent;
- investigative tactic;
- what one character is willing to reveal;
- who controls access to the evidence.

Mystery firewall:

`RELATIONSHIP STATE ≠ EVIDENCE STATUS`.

`TRUST / ATTRACTION / KISS / CONFESSION ≠ CORROBORATION`.

---

## 3. Orbital Youth gate

A new technology, district, transport system, gravity regime, robot, or school is not a scene event because it is novel.

Require:

`WORLD RULE → PERSON-SPECIFIC AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

Use full scene weight only when exact unfolding changes responsibility, evidence, relationship, access, consent, strategy, or future options.

Routine travel/setup/process should normally be compressed unless the process itself is the causal problem.

Post-money firewall remains:

Do not manufacture stakes through salary/rent/credits when the real non-fungible stakes are time, trust, consent, role, unique opportunity, belonging, reputation, mastery, privacy, relationship, or responsibility.

---

## 4. B07 — THE UNLISTED CITY gate

Do not define the event as merely:

`unusual pattern detected`.

Preferred event ladder:

`PATTERN → INDEPENDENT PERSONHOOD EVIDENCE → HUMAN CATEGORY/POLICY BECOMES INADEQUATE → ENTITY PREFERENCE/CONSENT BECOMES DECISION-RELEVANT → HUMAN OPTION SPACE CHANGES`.

Once personhood threshold is reached, the distributed nonhuman entity must own an indispensable decision:

`OWN MODEL/PREFERENCE → CONSENT/REFUSAL → CHOICE → HUMAN OPTIONS CHANGE`.

Kyra may create a bounded accountable decision space; she must not choose continuity on the entity's behalf.

---

## 5. Conscious robot gate

Human-observed behavior is not the final meaning of the event.

Use:

`BEHAVIOR → CONTROL PROVENANCE / OWN MODEL → AVAILABLE CHOICE → CONSENT/REFUSAL → ACTION → CONSEQUENCE`.

Do not infer motive directly from compliance, silence, efficiency, refusal, or unusual sensor behavior.

---

## 6. Consciousness-practice schools gate

A consequential experience for a practitioner can be a valid scene event while its ontology remains unresolved.

Preserve:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

`EXPERIENCE CONSEQUENCE ≠ ONTOLOGY CONFIRMATION`.

---

## 7. ONE MAIN STORY gate

Before inventing a new anomaly, attack, witness, technology, secret, institution, or subplot, perform Consequence Harvest:

`EXISTING EVENT → DIRECT EFFECT → SECONDARY EFFECT → RELATIONSHIP / EVIDENCE / ACCESS / RESPONSIBILITY CHANGE → LATER PAYOFF`.

Question:

**What has already happened that has not yet been allowed to cause its natural downstream effects?**

Only add a new event when existing causal material cannot perform the required function.

---

## 8. Anti-choppy prose gate

Never render Scofield-style event causality as mechanical microbeats:

`action. reaction. gesture. thought. conclusion.`

Use the full router:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT → NARRATIVE MODE → EVENT TARGET → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several micro-actions belong to one perceptual/decision unit, allow them to form a coherent paragraph and syntactic movement.

---

## 9. LESSON ZERO Book One lock

This gate does **not** authorize a global rewrite.

Book One remains development-locked.

Open a scene only when current evidence identifies a concrete defect such as:

- activity without changed state;
- repeated technical/logistical process that should be compressed;
- POV interpretation silently promoted to fact;
- a state-neutral scene whose removal changes nothing downstream;
- repeated microbeat fragmentation that belongs in a coherent paragraph;
- ignored natural consequence of an already established event.

Standing law:

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.
