## Scope
Apply only the mechanisms that survive the Part Two Red Team. Do not retrofit manuscripts to Booker's archetypal/gender system.

## A. LESSON ZERO Book One
Standing law remains:

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

- protagonist competence paired with an implausibly invisible blind spot;

## B. Orbital Youth
### 1. Competence-with-blind-spot
Use:
`COMPETENCE → LIMITED MODEL → NEW EVIDENCE / DIFFERENT AGENT MODEL → STRATEGY UPDATE`.

Do not use:
`competent teenager becomes foolish so the plot can teach a lesson`.

### 2. Strong YA escalation
Preserve:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

A blind spot may be exposed **after** success creates broader responsibility.

### 3. Ensemble convergence
For every major strand:
`LOCAL WANT → UNIQUE CAPABILITY / EVIDENCE → EFFECT ON MAIN ENGINE → OTHER AGENT'S OPTIONS CHANGE → PAYOFF`.

Supporting characters are not psychic extensions of the lead.

### 4. Post-money firewall
Booker's inheritance/kingdom/wealth symbols are translated only by function.

Valid stakes:
- time;
- trust;
- consent;
- privacy;
- responsibility;
- role/access;
- mastery;
- belonging;
- unique opportunity;
- relationships;
- safety.

No salary/rent/credits retrofit.

## C. ROOM 917
### 1. Blind-spot mystery
A skilled investigator may hold a reasonable but incomplete model:

`TRUE TRACE → MODEL A → BLIND VARIABLE → DISCRIMINATING TRACE/TEST → MODEL UPDATE → NEW TACTIC`.

Never convert `archetypal recognition` into evidence.

### 2. Relationship/evidence firewall
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

Relationship state may change:
- disclosure;
- source access;
- willingness to cooperate;
- investigative tactic.

It does not alter what a recording, timestamp, plan or physical trace actually proves.

## D. B07 — THE UNLISTED CITY
### 1. Personhood is not an archetype
Reject Monster/Shadow/Princess/Self symbolism as proof.

Personhood threshold requires independent evidence lines, not human projection.

### 2. Post-threshold decision ownership
After independent personhood evidence:

`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Kyra may create bounded accountable conditions for choice. She does not choose continuity for the entity.

### 3. Distributed capability
The nonhuman person may possess a capability/model humans lack, but it remains an independent agent, not a magical helper that exists to complete Kyra.

## E. Conscious robots / synthetic persons
Never:
`NONHUMAN FORM → MONSTER / INFERIOR / UNCONSCIOUS / MORALLY INCOMPLETE`.

Use:
`EMBODIMENT + OWN PRIORITY + OWN MODEL/EVIDENCE + OWN RELATIONSHIPS + CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

A robot may expose a human blind spot; this does not make the robot a symbolic extension of the human.
