# 2. ROOM 917

## Core causal braid

`MYSTERY EVENT / TRACE → RELATIONSHIP / TRUST CHANGE → ACCESS / DISCLOSURE CHANGE → NEXT INVESTIGATIVE CHOICE`.

This allows mystery and romance to inhabit one causal engine.

## Hard evidence firewall

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

Relationship state may change:
- whether Elena asks a question;
- whether Julian discloses something;
- access to a source/location;
- willingness to cooperate;
- investigative tactic.

It may **not** change what a recording, timestamp, plan, measurement or physical trace objectively proves.

## Scene-weight gate

Full real-time is protected when exact wording/action changes:
- clue provenance/status;
- consent/boundary;
- Elena↔Julian trust terms;
- evidence access;
- investigative strategy;
- decision ownership.

Routine candidates for compression:
- recorder setup already established;
- repeated contact-mic placement;
- repeated geometry check;
- known corridor movement;
- known technical verification;
- briefing that only repeats current evidence state.

## Consequence Harvest

Before adding a new paranormal clue, ask:

`What must the previous clue / disclosure / institutional action still cause?`

Prefer:
- witness behaviour;
- altered access;
- changed trust;
- institutional containment;
- evidence reinterpretation;
- consequence of prior testing;

over another unrelated impossible event.

## Strong youth escalation

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Do not force a setback merely because a structural framework expects one.

## World detail gate

`WORLD RULE → CHARACTER-SPECIFIC AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

A new habitat, interface, robot technology or gravity regime does not earn a full scene solely through novelty.

## Relationship layer gate

For every recurring pair/thread:

`RELATIONSHIP CHANGE → NEXT EXTERNAL CHOICE CHANGES`.

If not, it may be lived reality worth brief space, but it is not a major structural layer.

# 5. Mystery / evidence global gate

For all IVDIVO investigations:

`WORLD FACT → TRACE/SOURCE → CHARACTER ACCESS → INTERPRETATION → ALTERNATIVE MODEL → INDEPENDENT CORROBORATION → STATUS UPDATE → ACTION`.

Information withholding is fair only when the reader remains oriented to:
- what the question is;
- what is observed;
- what is inferred;
- what remains unknown.

Do not use relationship trust, emotional certainty, specialist prestige or vivid description as evidence substitution.

# 6. Anti-choppy / line-edit gate

Do not repair prose before confirming narrative mode and scene weight.

Full router:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → EXPOSITION/DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If the draft reads:

`action. reaction. gesture. thought. conclusion.`

ask first whether these microbeats are:
- one natural paragraph;
- an embedded scene inside summary;
- routine process that should be compressed;
- redundant reactions that should be deleted.

`ACTION / SUSPENSE ≠ SHORT-SENTENCE DENSITY`.

# 7. Writers' Room routing

During discovery:

`GENERATE LIVE MATERIAL`.

After material exists:

`OBSERVED DEFECT → DEFECT LEVEL → RELEVANT SPECIALISTS → MINIMAL CORRECT FIX → REGRESSION TEST`.

Do not run every production gate as a simultaneous sentence generator.

For new plot material:

`CONSEQUENCE HARVEST → LAYER PAYMENT → CANON / PERSONHOOD / CAUSALITY → KEEP / BANK / DISCARD`.
