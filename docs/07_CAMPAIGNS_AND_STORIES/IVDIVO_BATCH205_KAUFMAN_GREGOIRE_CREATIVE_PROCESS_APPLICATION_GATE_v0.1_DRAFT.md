# IVDIVO BATCH 205 — CREATIVE PROCESS APPLICATION GATE

**Source:** Kaufman & Gregoire — *Wired to Create*  
**Status:** production-facing diagnostic gate  
**Scope:** LESSON ZERO / Orbital Youth / ROOM 917 / B07 / Book Engine

## 1. Book Engine phase separation
Do not run every specialist against every sentence during discovery.

### Required state machine
`DISCOVERY_SEED`
→ `DIVERGENT_VARIANTS`
→ `INDEPENDENT_SPECIALIST_MODELS`
→ `CONVERGENT_SELECTION`
→ `CANON_CAUSALITY_PERSONHOOD_EVIDENCE_GATE`
→ `LIVE_DRAFT`
→ `DISTANCE`
→ `REVISION_DIAGNOSIS`
→ `TARGETED_REPAIR`
→ `READER_AUDIO_REGRESSION_TEST`.

### Interrupt contract
During `LIVE_DRAFT`:
- FATAL / MAJOR current defect: interrupt.
- useful alternative / optional improvement / new idea: backlog.
- speculative new canon: `DISCOVERY_ONLY` until explicit promotion.

## 2. Variant quality gate
A set of alternatives is only genuinely divergent if it changes at least one of:
- decision owner;
- present want;
- evidence available;
- relationship pressure;
- world constraint;
- tactic;
- cost bearer;
- exit state;
- downstream consequence.

Changing only location name, technology skin or dialogue wording is cosmetic variation.

## 3. ONE MAIN STORY gate
Every generated side idea must answer:
`WHAT DOMINANT CAUSAL STATE DOES THIS CHANGE?`
`WHAT LATER SCENE DEPENDS ON THAT CHANGE?`

If neither answer exists: BANK / DISCARD, do not inflate current book.

## 4. LESSON ZERO Book One
**Development lock remains.**

This source introduces no new current manuscript defect.

Standing law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Only reopen a layer if reader/audio/current-text evidence shows a reproducible defect such as:
- generic voice/salience across characters;
- premature overediting that flattened live prose;
- discovery artifact leaking into canon;
- intuition presented as evidence;
- process fatigue being mistaken for structural failure;
- framework overload generating unnecessary scenes.

## 5. Orbital Youth
### Character differentiation
Use different intrinsic interests as attention/tactic engines, not as hobbies pasted onto dialogue.

`PERSONAL SALIENCE + CURRENT RESPONSIBILITY + RELATIONSHIP → WHAT THEY NOTICE → WHAT THEY TRY`.

### YA firewall
No mandatory trauma / rejection / suffering credential.

Reader bond can come from:
`competence + responsibility + belonging + humour + curiosity + autonomy + relationship + moral uncertainty`.

Preserve:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST/ACCESS/RESPONSIBILITY → HARDER NEXT CHOICE`.

## 6. ROOM 917
Creative intuition may generate a lead but never certify it.

`INTUITIVE RECOGNITION → TRACE THAT TRIGGERED IT → MODEL A/B/C → DISCRIMINATING TEST → EVIDENCE STATUS → NEXT ACTION`.

Absolute firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION / INTUITION ≠ CORROBORATION`.

## 7. B07 — THE UNLISTED CITY
Human sensitivity to pattern may motivate investigation, but does not prove personhood.

`PATTERN → INDEPENDENT EVIDENCE LINES → PERSONHOOD THRESHOLD → ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

No created/discovered entity becomes property because a human first noticed or protected it.

## 8. Conscious robots
Do not humanize creativity/personhood by requirement.

A robot does not need:
- trauma;
- human-style daydreaming;
- human facial affect;
- artistic eccentricity;
- human humour.

Personhood remains:
`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

## 9. Consciousness-practice schools
Creative insight is not ontology.

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

No intuition, synchronicity, vivid experience or elegant metaphor bypasses this chain.

## 10. Prose / line-edit gate
Do not translate writer-process speed into reader syntax.

`FAST DRAFT ≠ CHOPPY FINAL PROSE`.

`IDEA SWITCH ≠ SENTENCE BREAK`.

`MENTAL BEAT ≠ PARAGRAPH BREAK`.

For choppy passages diagnose in this order:
`SCENE/MODE → POV/KNOWLEDGE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE CONTRAST/RHYTHM → WORDING`.

## 11. Science firewall
Use Kaufman/Gregoire as creative-process synthesis, not current neuroscience authority.

Current science check before factual use:
- openness/creativity: relationship remains supported but effect and domain vary;
- mindfulness/creativity: positive average effects exist but task/intervention are meaningful moderators;
- mind wandering/incubation: benefits are context-dependent and not universal.

### Final rule
`POPULAR SCIENCE MECHANISM → CURRENT EVIDENCE CHECK → BOUNDED PRODUCTION CLAIM`.
