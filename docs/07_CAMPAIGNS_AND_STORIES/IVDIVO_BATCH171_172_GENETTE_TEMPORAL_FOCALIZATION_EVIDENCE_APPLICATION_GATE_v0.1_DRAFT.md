# IVDIVO APPLICATION GATE — GENETTE BATCHES 171–172
## Order · Duration · Frequency · Focalization · Voice · Evidence

**Status:** PRODUCTION GATE / PASS 136  
**Source:** Gérard Genette — *Narrative Discourse* — strict lifecycle complete.

## Purpose

Use this gate when a chapter feels confusing, slow, repetitive, over-explained, unfairly withholding, POV-leaky or choppy. Do **not** assume the underlying story event is broken until presentation variables have been checked.

## Master diagnostic order

`STORY FACT → ORDER → DURATION → FREQUENCY → DISTANCE / FOCALIZATION → VOICE / SOURCE LEVEL → READER MODEL → PARAGRAPH/RHYTHM`.

Only after the correct defect level is located should prose be rewritten.

## A. Temporal architecture gate

For every major reveal / flashback / forecast:

1. What happened in world chronology?
2. When does the reader receive it?
3. Is it completing a gap, reinterpreting a prior event, forecasting, or thematically grouping material?
4. Who has access to this information?
5. What evidence status changes?
6. What action/relationship/model changes because the reader/character receives it now?

### Fail conditions

- later reveal silently changes an already observed trace;
- flashback exists only because backstory is interesting;
- nonlinear order cannot be causally reconstructed where proof requires chronology;
- a forecast spoils a question without buying irony, tension or model change.

## B. Duration / scene-weight gate

Before line edit, classify the material:

`ELLIPSIS / SUMMARY / SCENE / DESCRIPTIVE-PERCEPTUAL EXPANSION`.

Exact reader-time is protected when exact sequence changes:
- evidence status;
- consent;
- trust / relationship terms;
- authority/access;
- responsibility;
- decision ownership;
- strategy/model;
- future option space.

Routine travel, setup, interface operation and repeated verification are normally compressed unless they themselves are the causal event.

## C. Frequency gate

Classify every recurrence:

`SINGULATIVE / REPEATING / ITERATIVE`.

### Repeating scene/clue

Keep only if at least one changes:
- source/provenance;
- POV;
- evidence status;
- relationship meaning;
- model/hypothesis;
- decision/action.

### Iterative baseline

Use habitual narration to show ordinary systems and culture. A singular exception becomes structurally important only if future routine/expectation changes.

## D. Focalization / knowledge gate

For each critical information unit:

`WHO PERCEIVES? → WHAT CAN THEY ACCESS? → WHAT DO THEY INFER? → WHAT DOES NARRATION STATE? → WHAT CAN READER INFER? → WHAT REMAINS UNKNOWN?`

### Paralipsis check

If POV character already knows X but narration hides X solely to manufacture a later surprise: **FAIL unless a defensible narrating/discourse mechanism exists**.

### Paralepsis check

If narration enters another mind, unseen event or unavailable fact: identify source/access. If none: **FAIL / repair access**.

## E. Speech/thought mode gate

Choose among:

`NARRATIZED / INDIRECT / FREE-INDIRECT / DIRECT / IMMEDIATE`.

Use exact wording when wording itself changes the state of the story. Otherwise exact dialogue/thought is not automatically superior.

### Evidence firewall

`THOUGHT / SELF-REPORT / INFLECTION / SILENCE / GESTURE ≠ MOTIVE FACT`.

## F. Narrating-time gate

For retrospective narration:

`HERO-THEN KNOWLEDGE ≠ NARRATOR-NOW KNOWLEDGE`.

Any late knowledge injected into an earlier scene must be intentionally signaled or withheld under a fair rule.

## G. Source-level gate

For testimony, memories, recordings, archives, dream reports, institutional summaries or stories within stories:

`ORIGINAL SOURCE → INTERMEDIARIES → EDIT/SELECTION → CURRENT SPEAKER/NARRATOR → CLAIM → CORROBORATION STATUS`.

Vivid retelling does not erase provenance.

## H. Anti-choppiness gate

Never translate analytical beats into automatic typography.

Full repair order:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → EXPOSITION/DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

`ACTION / SUSPENSE / INTERIORITY ≠ SHORT-SENTENCE DENSITY`.

## Application — LESSON ZERO Book One

**NO GLOBAL REWRITE.**

Open a local patch only when current manuscript evidence shows one of:
- clue/reveal order is unfair or redundant;
- repeated explanation adds no new state;
- full scene dramatizes recoverable process that should be compressed;
- focalizer/narrator access leaks information;
- paragraph fragmentation is downstream of incorrect duration/mode.

Standing law:

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## Application — ROOM 917

Maintain four separate maps:

`WORLD CHRONOLOGY → CLUE DISCLOSURE ORDER → CHARACTER ACCESS → READER MODEL`.

For every repeated clue ask what new source/provenance/status is added.

Hard firewall:

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## Application — Orbital Youth

Use iterative narration to establish post-money normality through repeated lived patterns instead of exposition. Let a singular event split that baseline only when responsibility/access/relationship/future choices materially change.

## Application — B07 THE UNLISTED CITY

Early traces may be reclassified as personhood evidence; their literal observed content cannot be rewritten after the fact.

After independent threshold:

`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Human focalization about the entity remains interpretation unless corroborated.

## Application — conscious robots

`MORE SENSORS ≠ OMNISCIENCE`.

`SELF-REPORT ≠ AUTOMATIC MOTIVE TRUTH`.

Embodiment/task/access determine focalization; personhood determines decision ownership.

## Application — consciousness-practice schools

Discourse placement never changes ontology status:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.
