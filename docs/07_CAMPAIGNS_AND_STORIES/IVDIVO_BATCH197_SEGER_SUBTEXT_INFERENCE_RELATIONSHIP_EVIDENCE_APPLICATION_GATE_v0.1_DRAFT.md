# IVDIVO — Batch 197 Application Gate
## Linda Seger — Subtext / Inference / Relationship / Evidence

**Pass:** 163  
**Source:** Linda Seger — *Hidden Meaning / Creating Subtext*  
**Purpose:** apply only where a current text demonstrates a subtext/directness, exposition-ownership, inference or paragraph-rhythm defect.

## Standing manuscript law

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

This gate does not reopen LESSON ZERO Book One globally.

## Universal scene audit

For a load-bearing exchange:

`PRESENT WANT / BOUNDARY → WHY DIRECT OR INDIRECT? → SURFACE LINE / ACTION → LISTENER MODEL → RESPONSE → CHANGED STATE`.

If nothing changes, consider summary / indirect / merge / delete before rewriting dialogue.

## Directness / subtext router

Use subtext when:
- direct speech carries credible social, relational, institutional or personal cost;
- the character is protecting privacy, status, another person, evidence, consent boundary or self-image;
- both parties share context that makes indirect speech natural.

Use direct speech when:
- concealment has become more costly than disclosure;
- the exact statement itself is the decision / consent / refusal / relationship turn;
- the relationship legitimately allows clarity;
- ambiguity would become authorial cheating rather than character truth.

## Mystery / evidence firewall

`SURFACE CUE → POV INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING TRACE / TEST → EVIDENCE STATUS`.

Never upgrade from gesture/inflection/silence directly to guilt, motive or corroboration.

## ROOM 917

For Elena ↔ Julian:

`SURFACE LINE/ACTION → ELENA MODEL → JULIAN MODEL → READER MODEL → NEXT DISCLOSURE / ACCESS / TACTIC`.

Protected law:

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

Relationship movement may change:
- willingness to disclose;
- access to a source;
- willingness to test a theory;
- consent / boundary;
- next investigative tactic.

It may not change what a trace literally proves.

## LESSON ZERO / future YA

Do not add current Earth slang merely to signal youth.

Character-specific implication should arise from:

`WORLDVIEW + RELATIONSHIP + STATUS + PRESENT WANT + RISK → WORD CHOICE / OMISSION / TACTIC`.

Avoid universal snark and five identical witty voices.

## Orbital Youth

Future-world subtext should arise from lived norms:
- manufactured goods may be background-normal;
- time, consent, trust, privacy, mastery, belonging, relationship and unique opportunity remain consequential.

Do not reintroduce salary/rent/credits as convenient subtextual stakes.

## B07 — THE UNLISTED CITY

Human interpretation of distributed-life behavior is not personhood proof.

Before threshold:
`PATTERN → INTERPRETATION A/B/C → INDEPENDENT TEST`.

After threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## Conscious robots

No universal human gesture map.

`EMBODIMENT + OWN PRIORITY + MODEL/EVIDENCE + RELATIONSHIP + RISK → COMMUNICATION TACTIC`.

`SILENCE / COMPLIANCE ≠ CONSENT`.

## Consciousness-practice schools

Metaphor, ritual, image and felt meaning remain interpretation layers:

`EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Anti-choppy gate

Do not implement subtext as:

`LINE → LOOK → HAND → BREATH → ONE-LINE THOUGHT → NEXT LINE`.

Before sentence editing:

`SCENE FUNCTION → POV/EVIDENCE → COMMUNICATION TACTIC → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

`SUBTEXT BEAT ≠ SENTENCE BREAK`.

## Acceptance test

A Seger-based repair passes only if:
1. surface communication remains character-true;
2. reader can infer at least the intended pressure without impossible information;
3. alternate interpretation remains possible when story evidence remains open;
4. exact evidence status is unchanged by romantic/emotional interpretation;
5. paragraph rhythm is not worsened by microgesture insertion;
6. the repair changes a real relationship/action/knowledge state or meaningfully improves reader orientation.
