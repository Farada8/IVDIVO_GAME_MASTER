# IVDIVO BATCH 201 — WRITER / PROCESS STATE APPLICATION GATE

**Source:** James Scott Bell — *The Mental Game of Writing*  
**Status:** production gate / additive; does not supersede manuscript authority

## Purpose
Prevent IVDIVO's high-complexity writers' room from turning temporary writer/process problems into unnecessary manuscript rewrites.

## Gate A — Before any development rewrite
Answer in order:
1. What exact reader/text defect was observed?
2. Is it reproducible in the current authoritative manuscript?
3. Is the defect structural, scene-level, POV/evidence, dialogue/exposition, paragraph/rhythm, or wording/copy?
4. Could the apparent problem instead be fatigue, context switching, tool overload, envy/comparison, deadline pressure or one weak work session?
5. What is the minimum correct repair?
6. What regression test proves the repair did not damage working material?

If Question 1 cannot be answered with current evidence:

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## Gate B — Multi-agent interruption control
During live drafting:

`SPECIALIST OBSERVATION → FATAL/MAJOR CURRENT-TEXT DEFECT?`
- YES → interrupt and route to relevant authority.
- NO → capture in backlog with target artifact, reason, source and validation condition; continue the live draft.

Do not allow 100 specialist agents to evaluate every sentence during generation.

## Gate C — Generation / evaluation separation
`GENERATE OPTIONS → BANK → DISTANCE → CANON / CHARACTER / CAUSALITY / ONE MAIN STORY / READER-EFFECT TEST → SELECT`.

What-if output, exercise output and spontaneous side ideas remain `DISCOVERY_ONLY` until validated.

## Gate D — Process metric firewall
Never promote these directly to quality targets:
- word count;
- scenes per day;
- number of revisions;
- number of agent checks;
- number of cliffhangers/conflicts;
- short-sentence percentage;
- retention proxy;
- market ranking.

`PROCESS METRIC ≠ STORY QUALITY`.

## Gate E — Recovery / retest
If multiple unrelated scenes suddenly seem bad during the same session:

`STOP CANON EDIT → CAPTURE CONCERNS → RECOVER / REDUCE SWITCHING → RE-READ FRESH → DIAGNOSE TEXT`.

This is a production safeguard, not medical advice.

## Gate F — Prose rhythm
`FAST DRAFT ≠ CHOPPY FINAL PROSE`.

For choppiness repair:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE/MODE → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

## LESSON ZERO Book One
Development lock remains. Batch 201 is not evidence of a defect.

Reopen only for concrete current evidence such as:
- repeated reader/audio confusion;
- continuity/canon error;
- impossible POV/evidence access;
- duplicate or state-neutral scene function;
- demonstrable paragraph/rhythm defect;
- acquisition/copy issue that actually exists in the current locked text.

## Future IVDIVO books
Use Batch 201 before introducing a new antagonist, trauma, romance, mystery, technology or subplot merely because drafting momentum temporarily fell.

First ask whether the problem is the story, the current scene, or the production state.
