# IVDIVO — BATCH 135 APPLICATION GATE
## Research Provenance · Causal Complication · Processing · Anti-Choppiness

Date: 2026-08-19
Status: additive production gate; does **not** reopen locked manuscripts by itself.

## 1. LESSON ZERO Book One

**NO DEVELOPMENT REOPEN.**

A new craft source is not evidence of a manuscript defect. Apply Batch 135 only if a current-version passage shows a concrete problem such as:

- technical/historical claim with weak or missing provenance;
- unrelated complication that does not alter the chapter's causal engine;
- processing split into choppy microbeats without functional contrast;
- full real-time dramatization of routine process that should be compressed;
- scene whose apparent escalation changes no action/evidence/relationship/decision state.

Absent such evidence, development lock remains intact.

## 2. Future IVDIVO books — Research Provenance Gate

For any story-critical external claim:

`CLAIM → SOURCE → SOURCE TYPE / AUTHORITY → CONTEXT / DATE → OBSERVATION OR MEASUREMENT → INTERPRETATION → ALTERNATIVE → CONFIDENCE → ACTION`

### Mandatory questions

1. Is this directly observed, reported, inferred, hypothesized, corroborated, contested, or unknown?
2. Is the source independent or merely repeating another source?
3. Does the source have authority in this exact domain?
4. Is the character's confidence higher than the evidence warrants?
5. What evidence would change the model?

## 3. Alligator Test for scenes and chapters

Before accepting a new accident, anomaly, villain move, secret, technology, discovery, or interruption:

`CURRENT CAUSAL QUESTION → NEW EVENT → WHAT EXACTLY DOES IT CHANGE?`

A new event must change at least one:

- objective;
- evidence status;
- relationship;
- authority/access;
- responsibility;
- cost;
- tactic/model;
- future option space.

If it changes none, classify as **ALLIGATOR COMPLICATION** and bank/merge/delete it.

### Important

A bigger event is not automatically stronger escalation.

Preferred progression:

`competent action → real success → more trust/access/responsibility → harder next choice`

is often stronger than:

`failure → accident → larger accident`.

## 4. Scene-outcome gate

Do **not** impose mandatory disaster.

Allowed meaningful outcomes include:

- failure;
- partial success;
- costly success;
- genuine success;
- correct restraint / refusal;
- evidence upgrade or downgrade;
- changed relationship;
- new authority or lost authority;
- new obligation;
- narrowed or widened option space.

The requirement is **changed state + downstream dependency**.

## 5. Processing router

After a major event ask:

`WHAT CHANGED → WHAT MUST BE REASSESSED → WHAT OPTIONS NOW EXIST → WHAT NEW STRATEGY / COMMITMENT FOLLOWS?`

Render processing as one of:

- immediate;
- delayed;
- embedded in action;
- compressed summary;
- implied through later changed behavior.

Do not force every event into an explicit emotion→thought→decision paragraph.

## 6. Anti-choppiness application

Before sentence-level repair:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT/MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → SHOW/TELL → DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

### Choppy diagnostic

If a passage looks like:

`stimulus → one-line reaction → microgesture → one-line thought → second microgesture → decision`

ask whether these are actually one continuous perceptual/decision unit. If yes, combine at paragraph/syntax level rather than adding more beats.

## 7. Orbital Youth / post-money world

Research and worldbuilding must not accidentally reconstruct Earth-2020s economics.

When a source uses job/rent/debt/money as causal adhesive, translate only the structural function where appropriate:

- concrete responsibility;
- qualification;
- unique access;
- time;
- trust;
- relationship;
- reputation;
- privacy;
- consent;
- mission place;
- nonfungible lived experience.

Do not create credits/status points as hidden currency without explicit canon authority.

## 8. Conscious robots / nonhuman persons

Human observation of behavior does not close motive or consent.

`OBSERVED ACTION → CONTROL / CONSTRAINT PROVENANCE → ENTITY'S OWN MODEL → CONSENT / REFUSAL → MOTIVE HYPOTHESES → RESPONSIBILITY STATUS`.

A nonhuman person must not be added merely as an exotic complication. Personhood requires its own want, relationships, evidence/model, choices, and consequences.

## 9. Consciousness-practice schools

Research clarity cannot collapse the epistemic ladder:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

A vivid experience, respected teacher, or old text can raise narrative importance without raising ontological certainty.

## 10. Acceptance test for a new scene

PASS only if we can answer:

1. What prior consequence created this scene?
2. Who owns the present want/question?
3. Why is this material full scene rather than summary/embedded scene?
4. What pressure/support matters?
5. What changes by the end?
6. How does that changed state constrain or cause what follows?
7. If there is a major complication, does it pass the Alligator Test?
8. If technical/mystery information matters, is provenance preserved?

If 5–6 fail, do structural repair before line editing.
