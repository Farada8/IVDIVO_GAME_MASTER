# IVDIVO — BATCH 140 APPLICATION GATE
## Revision Layering · Completion · Development-Lock Protection
Date: 2026-08-20

## Purpose
Operationalize the final strict read of Jack M. Bickham — *The 38 Most Common Fiction Writing Mistakes* without importing his dated submission rules or commercial-fiction absolutisms.

## Primary production law
**Do not repair a lower layer while a higher-layer defect remains unresolved.**

`BOOK ENGINE → CANON → CAUSALITY → CHARACTER/PERSONHOOD → CHAPTER/SCENE FUNCTION → POV/EVIDENCE → MODE/DURATION → DIALOGUE/SUBTEXT → PARAGRAPH/READER-STATE → SYNTAX/RHYTHM → WORDING/COPY`.

If a scene is unnecessary, deleting adjectives is not revision.
If evidence provenance is wrong, improving dialogue is not revision.
If paragraph logic is broken, increasing sentence length is not revision.

---

## A. Revision pass contract

Every revision pass must declare:
1. **Primary defect layer**
2. **Observable reader/story failure**
3. **Evidence for the failure**
4. **Allowed edit surface**
5. **Protected material**
6. **Acceptance test**
7. **Stop condition**

A pass without these fields is exploratory, not production-authorized.

---

## B. LESSON ZERO Book One

### Status
**Development lock remains.**

### Reopen only if at least one is true
- repeated independent reader confusion at the same causal/evidence point;
- current canon/continuity contradiction;
- audio performance repeatedly exposes the same sentence/paragraph orientation failure;
- acquisition/editorial feedback identifies a concrete repairable defect;
- a scene demonstrably fails to alter any downstream action/knowledge/relationship/decision state;
- evidence provenance or POV knowledge is objectively wrong.

### Do not reopen for
- a newly completed craft book;
- desire to make every chapter “hookier”;
- desire to insert more threat;
- desire to make prose globally shorter/longer;
- one reader's taste preference;
- historical market advice.

### Specific choppy-prose gate
When a passage feels fragmented, diagnose in this order:
1. Is the whole scene necessary?
2. Is full scene the correct mode, or should process become summary/indirect?
3. Is POV/evidence access stable?
4. Do several microbeats belong to one paragraph-intent unit?
5. Is reader-state continuity intact from sentence to sentence?
6. Only then edit sentence rhythm.

**Forbidden shortcut:** `fragmented → make each sentence longer`.

## C. ONE MAIN STORY gate

Before adding a new event/subplot:
`EXISTING CONSEQUENCES HARVESTED? → ACTIVE CAUSAL QUESTION → NEW EVENT CHANGES WHAT? → DOWNSTREAM DEPENDENCY?`

If the answer is only “more tension,” bank the event.

### PASS
New material changes objective, evidence, relationship, authority/access, responsibility, cost, model/strategy or future option space.

### FAIL
New material is spectacle, lore, technology tourism or another anomaly with no downstream dependency.

---

## D. Chapter-end gate

Do **not** require twist/disaster/cliffhanger.

Allowed ending operators include:
- decision;
- consequence;
- partial answer;
- evidence-status change;
- relationship change;
- permission/refusal;
- successful completion that creates new responsibility;
- reframing;
- quiet irreversible commitment.

### PASS
`CHANGED STATE + SPECIFIC READ-ON VALUE`.

### FAIL
Only a thematic restatement or manufactured cliffhanger remains.

---

## E. Ending / saga boundary

`LOCAL BOOK PROMISE → DECISIVE ACTION/CHOICE → OUTCOME → COST → AFTERMATH → CHANGED STATE → OPTIONAL SERIES VECTOR`.

### Proof ceiling
The final chapter may state only what the evidence architecture has earned.

For consciousness/mystery arcs:
`LOCAL OPERATIONAL ANSWER` may be proven while `GLOBAL ONTOLOGY` remains unknown.

**Forbidden:** final-scene metaphysical lecture that resolves the saga because a craft rule requested an unequivocal answer.

---

## F. Conscious nonhuman personhood

Bickham's cast-economy advice never overrides personhood.

Do not merge/remove a conscious robot/nonhuman agent merely because another character can perform the same plot function if doing so erases:
- independent desire;
- relationship;
- consent/refusal;
- source/evidence provenance;
- decision ownership;
- embodiment-specific affordance.

Required causal line:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

---

## G. Consciousness-practice schools

Maintain evidence ladder:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Neither emotional conviction nor clear exposition upgrades interpretation to world fact.

---

## H. Orbital Youth / post-money society

Do not translate Bickham's professional/market incentives into fictional salary/rent/credits.

Use nonfungible stakes:
- time;
- trust;
- consent;
- privacy;
- specific responsibility;
- qualification;
- mastery;
- relationship;
- belonging;
- unique mission/opportunity;
- safety.

Prefer YA progression:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST/ACCESS/RESPONSIBILITY → HARDER NEXT CHOICE`.

---

## I. Revision stop rule

### STOP the current pass when
- named defect no longer reproduces;
- protected mechanisms remain intact;
- downstream continuity still works;
- no new same-layer FATAL/MAJOR appears;
- reader/audio retest improves or stabilizes;
- further edits become taste variation.

### ESCALATE to an earlier layer only when
new evidence shows that the current repair cannot solve the actual defect.

### Project-wide rule
**NO NEW EVIDENCE → NO NEW GLOBAL REWRITE.**

---

## Acceptance summary
PASS if revision is causally justified, layer-correct, minimally invasive, and demonstrably improves reader/story state.

FAIL if revision is driven primarily by formula compliance, stylistic fashion, threat/cliffhanger inflation, or historical market advice.
