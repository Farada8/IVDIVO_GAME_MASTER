# A. WHEN THIS GATE RUNS
Run only after:
1. ONE MAIN STORY / causal engine accepted;
2. scene exists for a reason;
3. show/tell mode accepted;
4. POV/knowledge boundaries accepted;
5. dialogue mode accepted.

Then run:
`PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORD FUNCTION`.

# B. ANTI-ОБРУБКИ PASS
For any page with heavy short-paragraph density:
1. mark actor/time/location/focus for each paragraph;
2. if adjacent paragraphs preserve all four and do not create a real beat, test recombination;
3. preserve short standalone lines only when they deliver a genuine shift: revelation, reversal, silence, breath, comic timing, danger recognition, decision or end-weight;
4. do not target a percentage of short sentences;
5. read the repaired page aloud and restore variation where economy became monotony.

# C. READER-STATE CONTINUITY
For each sentence pair:
- what entity is most active in the reader's mind after Sentence A?
- what time/place/knowledge state is active?
- does Sentence B attach to that state or unexpectedly change it?
- if changing, is there enough signal?

Typical repairs:
- move attribution or time marker earlier;
- replace ambiguous pronoun with specific noun;
- reorder sentences;
- merge duplicated thoughts;
- add one causal/contrast transition rather than another explanatory sentence.

# D. POST-MONEY LANGUAGE FIREWALL
Flag any line where these terms function like concealed money:
`allocation / quota / contribution / access / priority / qualification / assignment / scheduling / service / resource share`.

For each flagged term ask:
- what physical/social mechanism does it name?
- who decides?
- what is genuinely scarce?
- can robots fabricate more of it?
- is the limitation actually time, space, safety, expertise, consent, attention or a unique opportunity?

If the answer is merely purchasing power under another name, rewrite the world logic before line editing.

# E. CONSCIOUS ROBOT LANGUAGE
Do not simplify robot dialogue into generic precision. Remove fog while preserving:
- independent desire;
- relationship-specific register;
- cultural assumptions;
- right to refuse/withhold;
- nonhuman embodiment where relevant.

# F. SPECIALIST CONSCIOUSNESS SCHOOLS
Every factual sentence touching metaphysics must carry the correct epistemic status in notes/canon control:
`OBSERVED / REPRODUCED / INTERPRETED / CONTESTED / UNKNOWN / CANON FACT`.
Prestige vocabulary cannot upgrade status.

# G. OPENING / ENDING
Opening test:
`ATTENTION + ORIENTATION + PROMISE`, not mandatory accident/action/mystery.

Ending test:
`LOCAL WORK COMPLETE? → STOP OR PAYOFF`, not summary of lesson already dramatized.

# H. MANUSCRIPT POLICY
## LESSON ZERO BOOK ONE
No reopening based on Zinsser alone. Apply only if a current passage fails an already-authorized regression/line-edit gate.

## FUTURE ORBITAL YOUTH
Use Zinsser especially to prevent:
- technology-tourism prose;
- bureaucratic pseudo-economics;
- five characters restating the same conclusion;
- fake suspense via sentence fragments;
- world explanations that label their own significance.

# I. ACCEPTANCE TEST
A successful Zinsser pass should make prose:
- easier to follow;
- less repetitive;
- more specific;
- more rhythmically varied;
- no less personal;
- no less strange where the world is genuinely strange;
- no less emotionally complex.

If clarity pass makes every character sound alike, roll back and repair at voice/POV level.
