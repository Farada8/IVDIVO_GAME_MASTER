# IVDIVO — BATCH 179 — STORR APPLICATION GATE
## Character Models · Curiosity · Layered Change · Science Firewall

**Source:** Will Storr, *The Science of Storytelling*  
**Source status:** strict lifecycle complete  
**Application status:** additive diagnostic layer only.

## 1. Character-model gate

Do not begin with `What is the hero's flaw?` as an obligation.

Use:

`VALUES / RELATIONSHIPS / KNOWLEDGE / EMBODIMENT → CURRENT MODEL / PRIORITY → PRESENT WANT → OPTION SET → TACTIC → RESPONSE → CONSEQUENCE → MODEL UPDATE OR TESTED STABILITY`.

A character may:
- change a model;
- change only a tactic;
- change a relationship;
- remain stable under test;
- regress temporarily;
- change across several books rather than one.

## 2. Curiosity / mystery gate

A mystery beat should provide:

`CLEAR QUESTION → PARTIAL MODEL → 2+ PLAUSIBLE EXPLANATIONS → DISCRIMINATING EVIDENCE → MODEL UPDATE → NEXT ACTION`.

Avoid:
- total confusion;
- one hypothesis presented as fact before proof;
- emotional certainty treated as evidence;
- clue repetition without status change.

## 3. Other-mind firewall

`OBSERVED BEHAVIOR / SPEECH / SILENCE → POV MODEL OF OTHER PERSON`.

Never auto-upgrade to:
- motive fact;
- guilt;
- consent;
- personhood status;
- clinical diagnosis.

Require alternative models and corroboration where the claim matters.

## 4. Layered-change middle audit

When a middle feels static, do **not** immediately add danger/anomaly.

Check which layers have stopped changing:
- action/physical state;
- knowledge/evidence;
- relationship/consent;
- authority/access;
- responsibility;
- goal/tactic;
- self-model;
- reader model;
- secondary-character state;
- future option space.

Repair the stalled layer before adding a new event.

## 5. Ignition gate

A strong opening/turn is not merely a large event.

`EVENT → WHY THIS PERSON? → WHICH VALUE/MODEL/RESPONSIBILITY DOES IT HIT? → SPECIFIC RESPONSE → NEW CAUSAL ENGINE`.

Quiet events may pass this gate.

## 6. Science firewall

Storr's neuroscience/evolutionary-psychology explanations are **not** IVDIVO scientific authority.

Never write into canon as fact merely because Storr says it:
- brain as literal prediction machine in a specific contested formulation;
- control as universal human master motive;
- status as universal story engine;
- Western/Eastern character binaries;
- sacred flaw/origin damage as universal psychology;
- tribal storytelling as the sole/primary purpose of narrative.

Use these only as craft hypotheses unless independently verified against current evidence.

## 7. LESSON ZERO Book One

**Decision:** KEEP DEVELOPMENT LOCK.

No new current-text evidence from Storr justifies global rewrite.

If future beta/audio evidence finds a weak scene, ask:
1. what question/model is active for Ethan?
2. what new evidence/relationship/authority state changes?
3. does Ethan's tactic follow his current model?
4. does the consequence update anything downstream?
5. is confusion intentional mystery or missing orientation?

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## 8. Orbital Youth

Useful:
- adolescent belonging/status can be one pressure, not the only pressure;
- different youths can inhabit different models of the same institution;
- environment should be filtered through character-specific salience;
- progress can occur through knowledge, trust, responsibility or access rather than physical danger;
- keep real-success escalation: `SUCCESS → MORE TRUST/RESPONSIBILITY → HARDER CHOICE`.

Reject:
- mandatory childhood wound;
- status as hidden currency replacing money;
- East/West cultural stereotypes;
- every protagonist needing a sacred flaw.

## 9. ROOM 917

Use:

`TRACE → ELENA/JULIAN MODEL → ALTERNATIVE MODEL → DISCRIMINATING TEST → EVIDENCE UPDATE`.

Relationship changes can alter disclosure/access/tactic, but:

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## 10. B07 — THE UNLISTED CITY

Human classification of a distributed entity is a **model**, not personhood fact.

Required:

`INDEPENDENT TRACE LINEAGES → PERSONHOOD THRESHOLD → ENTITY'S OWN MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Do not use human theory-of-mind fluency as proof of nonhuman motive.

## 11. Conscious robots

`MORE SENSORS ≠ OMNISCIENCE`.

`HUMAN READABILITY ≠ PERSONHOOD`.

`BEHAVIORAL COMPLIANCE ≠ CONSENT`.

Build character through own priorities, knowledge limits, relationships, models, choices and consequences.

## 12. Consciousness-practice schools

Predictive-processing language, confabulation, intuition or self-model theory cannot establish subtle-world ontology.

Preserve:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 13. Anti-choppiness

A fast-changing model can be narrated slowly if suspense requires close attention.

`SUSPENSE / CHANGE ≠ SHORT-SENTENCE DENSITY`.

Route prose through:

`NARRATIVE FUNCTION → SUBJECTIVE TIME → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM / CONTRAST → WORDING`.

## 14. Stop rule

This source is successfully integrated when it improves **model diagnosis and evidence discipline**, not when every IVDIVO protagonist receives a childhood wound and sacred flaw.
