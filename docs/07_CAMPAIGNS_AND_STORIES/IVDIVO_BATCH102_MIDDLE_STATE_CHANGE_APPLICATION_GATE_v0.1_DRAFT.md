# IVDIVO — BATCH 102 MIDDLE STATE-CHANGE APPLICATION GATE

Date: 2026-08-19
Status: PRODUCTION CONTROL / ADDITIVE

## PURPOSE
Apply the Swain-derived middle-state model without retrofitting active manuscripts to a mechanical scene/sequel formula.

## GLOBAL MIDDLE AUDIT
For every chapter in the middle 50–60% of an IVDIVO book, record:

`ENTRY STATE -> OWNER / WANT -> PRESSURE / SUPPORT -> EVIDENCE / RELATION CHANGE -> DECISION / TACTIC -> EXIT STATE -> DOWNSTREAM DEPENDENCY`

Audit state axes:
- operational/physical;
- knowledge/evidence;
- relationships;
- authority/access;
- responsibility;
- strategy/model;
- emotional commitment;
- future option space.

A chapter that changes none of these is presumed redundant until proven otherwise.

## ONE MAIN STORY
For every subplot/POV strand ask:
1. What local action does this strand own?
2. What does that action change in another strand or the dominant book engine?
3. What becomes impossible/possible because of it?
4. Where is the payoff?

`CO-PRESENCE / BRIEFING / RECAP != CONVERGENCE`.

## YA / ORBITAL YOUTH
Preferred escalation options:
- a correct decision earns more responsibility;
- a successful repair exposes a systems-level interaction;
- a trusted teen receives access that creates a harder ethical choice;
- a relationship deepens, making later consent/refusal more costly;
- evidence becomes stronger but also narrows what can responsibly be claimed;
- an institution responds competently, forcing protagonists to revise rather than simply rebel.

Do not default to:
- another accident;
- another secret villain;
- salary/rent/credits;
- arbitrary punishment for competence;
- death inflation.

## TECHNICAL MIDDLE FIREWALL
Potentially repetitive sequences such as:
`meeting -> model -> test -> review -> meeting`
are not repaired by sharper banter.

Route each unit:
- exact wording/action changes consent, evidence, authority, relationship or decision -> SCENE;
- process/repetition/logistics -> SUMMARY / INDIRECT;
- multiple units perform same causal job -> MERGE;
- unit does not affect downstream state -> DELETE / BANK.

## EVIDENCE MIDDLE
When a fact repeats, record status changes explicitly:
`OBSERVED -> REPORTED -> INFERRED -> HYPOTHESIS -> CORROBORATED / CONTESTED / DISPROVEN / UNKNOWN`.

A second discussion of the same evidence earns space only if its status, interpretation, source, consequence or action changes.

## RELATIONSHIP MIDDLE
Relationship scenes do not require overt conflict. They qualify when they change:
- trust;
- intimacy;
- consent;
- obligation;
- future availability;
- what one person is willing to reveal;
- the cost of a later choice.

## CONSCIOUS ROBOTS / NONHUMANS
Every named conscious nonhuman strand requires:
`OWN WANT -> OWN MODEL/EVIDENCE -> OWN RELATIONSHIPS -> CONSENT/REFUSAL -> OWN CHOICE -> CONSEQUENCE`.

Do not use a robot merely as:
- clue dispenser;
- mentor appliance;
- obstacle;
- emotional pet;
- rescue cargo.

## CONSCIOUSNESS SCHOOLS
A practice scene may alter a character's choices without upgrading ontology.

Maintain:
`OBSERVATION -> REPRODUCIBLE EFFECT -> SCHOOL INTERPRETATION -> COMPETING INTERPRETATION -> POSSIBLE ONTOLOGICAL CLAIM`.

## LINE-EDIT FIREWALL
Do not solve state-neutral chapters by polishing prose.

Order:
`BOOK ENGINE -> CHAPTER FUNCTION -> SCENE NECESSITY -> MODE -> POV/EVIDENCE -> PARAGRAPH INTENT -> READER-STATE CONTINUITY -> SENTENCE RHYTHM -> WORDING`.

## ACCEPTANCE TEST
A middle sequence is GREEN when:
- every major unit changes a downstream-relevant state;
- pressure changes type, not merely volume;
- success is allowed to create harder responsibility;
- repeated information changes evidence/meaning/action status;
- POV switches buy unique value;
- ordinary life remains causally connected;
- all conscious agents retain personhood;
- no obsolete money/body-transfer assumptions re-enter by convenience.
