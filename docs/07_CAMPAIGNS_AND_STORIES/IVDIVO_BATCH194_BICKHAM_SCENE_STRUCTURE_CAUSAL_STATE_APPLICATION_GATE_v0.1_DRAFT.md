# IVDIVO — Batch 194 Application Gate
## Bickham Scene & Structure — Causal State / Scene-Sequel / Hidden Story / Pacing

## Standing rule
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

This gate does not reopen a locked manuscript because a new craft source was studied. It authorizes intervention only when a current defect is demonstrated.

## A. Scene admission
For every candidate full scene:
1. What is the owner's present want/responsibility?
2. Why must this material occur in reader real time?
3. What changes by the exit?
4. Which later scene/action depends on that change?

Record:
`OWNER → WANT → PRESSURE/SUPPORT → TACTIC → OUTCOME → ACTION STATE → EVIDENCE → RELATIONSHIP/CONSENT → AUTHORITY/RESPONSIBILITY → FUTURE OPTIONS → NEXT DEPENDENCY`.

If downstream state does not change: `SUMMARY / MERGE / DELETE / REBUILD` before prose polish.

## B. Outcome direction audit
For a load-bearing ending:
`SCOPE → IMMEDIACY → FINALITY → DIRECTION`.

If the scene is vivid but sends the book onto an unintended causal branch, repair the outcome that created the branch rather than polishing later symptoms.

## C. Success escalation
Protected YA / competence pattern:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Do not insert arbitrary failure merely to satisfy Goal–Conflict–Disaster.

## D. Processing router
After a consequential outcome choose one:
- immediate processing,
- delayed processing,
- embedded processing inside action,
- summary/indirect processing,
- implied processing demonstrated by later changed behavior.

Do not write `emotion. thought. gesture. decision.` as separate fragments by default.

## E. Hidden-story / mystery ledger
For important offstage events:
`ACTOR → WANT → ACTION → TIME/PLACE → TRACE → SOURCE LINEAGE → ACCESS → DISCLOSURE ORDER → PAYOFF`.

### ROOM 917
For each load-bearing clue also record:
`ELENA ACCESS → JULIAN ACCESS → READER ACCESS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION STATUS → NEXT TEST`.

Standing firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## F. Inadvertent clue-promise audit
If dialogue or description strongly foregrounds a possible danger/clue, decide whether it is:
- lived-world detail,
- legitimate red herring / alternative model,
- load-bearing setup.

If none, reduce emphasis rather than creating an unpaid promise.

## G. POV access
`WHO PERCEIVES ≠ WHO KNOWS ≠ WHO INTERPRETS ≠ WHO DECIDES`.

Do not transfer knowledge across minds without source/access provenance.

Multiple POV is allowed when each switch buys unique evidence/action/consequence/relationship/countermodel/decision. No arbitrary screen-time equality.

## H. Anti-choppiness / mode-before-line-edit
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH LOCAL JOB → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Rules:
- `BEAT MAP ≠ SENTENCE BREAK`.
- `COMPRESSION ≠ CHOPPING`.
- `ACTION / SUSPENSE / EMOTION ≠ SHORT-SENTENCE DENSITY`.

If five microbeats form one perceptual/decision unit, test one coherent paragraph before adding more dramatic line breaks.

## I. LESSON ZERO Book One
Do not globally reopen.

Only use Batch 194 if current evidence shows one of these specific defects:
- scene is state-neutral,
- scene outcome causes wrong downstream direction,
- causal bridge is missing,
- POV/knowledge access is impossible,
- repeated real-time procedure should be summary,
- choppy prose is caused by microbeat fragmentation,
- accidental clue emphasis creates an unpaid promise.

## J. Orbital Youth
Protect post-money stakes and competence.

`SUCCESS → TRUST / ACCESS / RESPONSIBILITY`, not automatic punishment.

Use hidden-story mapping for institutional actions so apparently sudden policy/system behavior has a plausible offstage causal chain.

## K. B07 — THE UNLISTED CITY
Bickham's role labels never override personhood.

After independent personhood threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

`CREATED / DISCOVERED / RESCUED ≠ OWNED`.

## Acceptance test
Batch 194 is correctly applied only if the repair can name:
1. the observed defect,
2. the level of the defect,
3. the changed-state or evidence problem,
4. the minimal repair,
5. the regression test proving no protected function was lost.
