# IVDIVO — Batch 148 Application Gate
## Character Values · Objectives · Personhood · Prose Restraint

Status: ADDITIVE PRODUCTION GATE. Does not reopen development-locked manuscripts by itself.

## 1. Major-character value matrix

For every primary/secondary-major character, record at least two live priorities that can conflict or reorder under pressure.

Examples suitable for Orbital Youth:
- autonomy ↔ coordinated responsibility
- belonging ↔ privacy
- mastery ↔ caution
- fairness/procedure ↔ person-level exception
- evidence integrity ↔ loyalty
- intimacy ↔ independence
- curiosity ↔ consent

Do not turn these into static labels. Validate them through different relationships and decisions.

## 2. Character-specific response test

Same obstacle, five different people:
`WHAT DOES EACH NOTICE? → WHAT VALUE IS THREATENED? → FIRST TACTIC → SECOND TACTIC IF BLOCKED → COST ACCEPTED / REFUSED`.

If the cast converges on the same sarcasm, same competence display, same moral speech, or same rebellion, the ensemble is cosmetically differentiated.

## 3. Objective router

A scene objective can be:
- obtain / stop / protect / persuade;
- understand / verify / decide;
- negotiate / refuse / preserve consent;
- cooperate / delegate / ask for help;
- delay until evidence threshold is met.

`AGENCY ≠ AGGRESSION` and `OBJECTIVE ≠ PHYSICAL ACTIVITY`.

## 4. Personhood firewall

For a conscious robot or other nonhuman person:
`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Human-looking gestures, quirks, slang, vulnerability, or imitation are not proof of personhood.

## 5. Mystery firewall

Keep separate:
`AUTHOR'S PRIVATE MOTIVE MODEL ≠ POV INFERENCE ≠ REPORTED CLAIM ≠ CORROBORATED FACT`.

Characterization may explain why a hypothesis is plausible; it may not upgrade evidence status.

## 6. Mannerism restraint / anti-chop gate

Forbidden repair pattern:
`dialogue → glance → hand motion → one-line thought → dialogue → object touch → breath`.

Before adding physical business, ask whether it changes:
- relationship/status;
- evidence;
- consent/boundary;
- tactic;
- physical possibility;
- reader orientation.

If not, remove it or fold it into a coherent paragraph.

## 7. Discovery material

If a live draft produces unexpected character behavior:
`KEEP WRITING → AFTERWARD TEST CHARACTER TRUTH / CANON / CAUSALITY / ONE MAIN STORY → REPLAN / BANK / DISCARD`.

Do not freeze generation with the full specialist stack; do not canonize every surprise either.

## 8. LESSON ZERO lock

No global rewrite from this batch.

Allowed reopening only if current evidence shows one of:
- major characters differentiated mainly by quirks/slang;
- unexplained behavior that breaks the established model;
- duplicated mannerism clutter creating choppy prose;
- current reader/audio evidence of character confusion;
- concrete continuity/canon/evidence defect.

Standing law: `NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.
