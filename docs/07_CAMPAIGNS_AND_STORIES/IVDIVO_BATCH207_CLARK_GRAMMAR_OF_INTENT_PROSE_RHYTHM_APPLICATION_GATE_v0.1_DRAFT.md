# IVDIVO BATCH 207 APPLICATION GATE
## Roy Peter Clark — Grammar of Intent · Prose Rhythm · Paragraph Continuity

**Status:** production diagnostic gate  
**Source authority:** WIDER / strict-synthesized  
**Pass:** 172

## Purpose
Apply Clark only where a current text exhibits a concrete prose/clarity defect. This gate does **not** authorize broad restyling of development-locked manuscripts.

Standing law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## Gate A — Choppiness diagnosis
Before changing sentence length, inspect in this order:
1. Is the material worth a full scene or should it be summary/indirect?
2. Is POV/evidence access correct?
3. Does the paragraph represent one coherent perceptual/decision unit?
4. Does sentence B continue the reader-state left by sentence A?
5. Are short sentences/fragments serving distinct functions or merely splitting one thought?
6. Would merge/subordination/coordination restore continuity?
7. Only then adjust sentence length, punctuation and diction.

### Reject
`BEAT → PERIOD → BEAT → NEW PARAGRAPH` as a default prose engine.

### Protect
A one-line or fragment paragraph when it buys a real function: revelation, decision, contrast, comic timing, shock, pause, release, isolated image or terminal emphasis.

## Gate B — Paragraph admission
New paragraph requires at least one meaningful shift:
- speaker;
- time/place;
- focal attention;
- tactic;
- evidence status;
- relationship/consent;
- authority/access;
- emphasis;
- new unit of thought.

If none changes, test merge.

## Gate C — Agency visibility
For institutional sentences using passive/nominalized language, ask:
`WHO DECIDED? → WHO ACTED? → WHO COULD REFUSE? → WHO BEARS COST? → WHO CAN APPEAL?`

Do not ban passive voice; repair only when the construction hides load-bearing agency or responsibility.

## Gate D — Specialist/future vocabulary
For every unusual term/acronym:
`WHO USES IT? → WHO UNDERSTANDS IT? → WHY HERE? → CAN CONTEXT CARRY IT? → WHAT STORY FUNCTION DOES IT PERFORM?`

Do not reintroduce Earth-2020s salary/rent/credits through opaque future words such as `allocation`, `priority`, `contribution`, `access` or `qualification` unless the actual in-world mechanism is explicitly distinct.

## Gate E — Mystery language
`WORDING / PAUSE / INFLECTION / SCARE QUOTES / METAPHOR → STANCE OR HYPOTHESIS`, not proof.

Evidence architecture remains:
`WORLD FACT → TRACE/SOURCE → SOURCE LINEAGE → POV ACCESS → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING TEST → CORROBORATION STATUS`.

Exact clue wording is locked when wording itself is evidence.

## Gate F — Character voice
Voice must arise from:
`WORLDVIEW + RELATIONSHIP + WANT + STATUS + ATTENTION + OMISSION`.

Red flags:
- all five youths share the same syntax and metaphors;
- all smart characters use the same ironic register;
- conscious robots share a universal clipped/technical voice;
- future youth voice depends on current Earth slang.

## Gate G — LESSON ZERO Book One
No global rewrite. Open only a bounded prose layer if external evidence identifies a repeatable defect such as:
- fragment monoculture;
- paragraph confetti;
- accidental ambiguity;
- impossible modifier/reference;
- tense instability;
- jargon opacity;
- hidden decision owner;
- repeated explanatory restatement after action already made meaning clear.

Repair at the smallest correct level and run continuity/regression after patching.

## Gate H — ROOM 917
Protect exact clue wording/provenance. Dialogue punctuation and performance may change stance or relational inference, but:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION / SARCASM ≠ CORROBORATION`.

If audio performance needs a wording change, first classify:
- clue wording load-bearing? LOCK;
- character relationship load-bearing? preserve function;
- filler/process wording? compress/rewrite permitted.

## Gate I — Orbital Youth
Use future language through lived context rather than lectures. Technical/social vocabulary should reveal community membership and character attention. No universal youth slang and no hidden monetary economy via acronyms.

## Gate J — B07 / nonhuman personhood
Human names, labels, metaphors and quotation marks are human model layers only:
`NAME / LABEL / ANALOGY ≠ ENTITY ESSENCE`.

After independent personhood threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## Gate K — Consciousness schools
Language may organize experience but does not prove ontology:
`TERM / METAPHOR / ETYMOLOGY / ELEGANT ANALOGY ≠ ONTOLOGICAL EVIDENCE`.

Retain proof ladder:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Acceptance condition
A Clark-driven prose patch is accepted only when it improves the diagnosed reader effect **without** changing canon, evidence status, decision ownership, personhood, causal state or character voice unintentionally.
