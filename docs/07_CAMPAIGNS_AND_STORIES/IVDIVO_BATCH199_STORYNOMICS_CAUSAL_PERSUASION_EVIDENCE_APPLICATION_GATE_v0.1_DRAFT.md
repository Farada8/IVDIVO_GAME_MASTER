# IVDIVO BATCH 199 — STORYNOMICS APPLICATION GATE

**Source:** McKee / Gerace — *Storynomics*  
**Status:** manuscript-facing production control  
**Pass:** 164

## 1. Prime firewall

`PERSUASIVE NARRATIVE / STORY COHERENCE ≠ TRUTH ≠ LEGITIMACY ≠ INFORMED CONSENT`.

This gate has priority whenever an elegant causal explanation, emotionally powerful story, institutional message or character interpretation risks being treated as evidence.

## 2. LESSON ZERO Book One

**Decision:** `KEEP DEVELOPMENT LOCK`.

Storynomics provides no new concrete defect evidence in the locked manuscript.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Allowed future use only when reader/audio/continuity evidence identifies one of:
- state-neutral process dramatized in real time;
- repeated explanation without changed function;
- unclear tradeoff / decision ownership;
- persuasive institutional framing being mistaken for evidence;
- proxy metric replacing actual objective;
- paragraph/syntax fragmentation caused by beat-by-beat process rendering.

## 3. ONE MAIN STORY gate

For every substantial scene/chapter:

`VISIBLE PROCESS → WHAT CHANGED? → WHAT LATER ACTION NOW DEPENDS ON THAT CHANGE?`

Track at least:
- action / operational state;
- knowledge / evidence state;
- relationship / trust state;
- consent / boundary state;
- authority / access / responsibility;
- model / tactic;
- future option space.

If no downstream-relevant state changes, test `SUMMARY / MERGE / DELETE / REBUILD` before line editing.

## 4. ROOM 917 mystery gate

A coherent clue narrative is not corroboration.

`TRACE → ORIGINAL SOURCE → SOURCE LINEAGE → ELENA ACCESS → JULIAN ACCESS → READER ACCESS → MODEL A/B/C → DISCRIMINATING TEST → CORROBORATION STATUS → NEXT ACTION`.

Standing laws:
- `STORIFIED EXPLANATION ≠ CORROBORATION`.
- `TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.
- `SOURCE SELF-INTEREST ≠ FALSEHOOD`, but requires lineage and independent verification.

Relationship change may alter disclosure, access, willingness to cooperate or investigative tactic. It may not change what a physical/audio trace proves.

## 5. Orbital Youth gate

Reject Storynomics's mandatory negative setup / conflict escalation as a YA law.

Preferred progression remains:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Post-money stakes remain:
`TIME / TRUST / CONSENT / PRIVACY / ROLE / RESPONSIBILITY / MASTERY / BELONGING / RELATIONSHIP / UNIQUE OPPORTUNITY / SAFETY`.

Do not import salary/rent/credits from commercial examples.

### Training / metric audit
`REAL TRAINING OBJECTIVE → PROXY METRIC → INCENTIVE → BEHAVIOR → MISSION RESULT`.

If a cadet can rationally win the metric while worsening the real mission, repair the metric/institution, not the cadet's intelligence.

## 6. B07 — THE UNLISTED CITY

A moving story about distributed life does not prove personhood.

`PATTERN / TRACE → INDEPENDENT EVIDENCE LINES → ALTERNATIVE MODELS → DISCRIMINATING TEST → PERSONHOOD THRESHOLD`.

After threshold:
`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

`EMPATHY / IDENTIFICATION ≠ PERSONHOOD PROOF`.
`DISCOVERED / CREATED / RESCUED ≠ OWNED`.

## 7. Conscious robots / nonhuman agents

Human persuasive framing must not erase own-agency architecture:
`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

`PREDICTED BEHAVIOR ≠ REASON ≠ CONSENT`.

## 8. Consciousness-practice schools

Storynomics's broad cognition/neuroscience language is not imported.

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Narrative elegance, subjective certainty and emotional identification do not upgrade ontology.

## 9. Reader-effect gate

Before optimizing a metric, define the real effect:
`WHAT SHOULD THE READER UNDERSTAND / FEEL / QUESTION / EXPECT / REMEMBER → WHAT TEXTUAL MECHANISM PRODUCES IT → WHAT STORY COST DOES IT CREATE?`

Do not optimize:
- cliffhanger count;
- short-sentence percentage;
- number of conflicts;
- number of reversals;
- raw dialogue share;
- chapter-end shock;
- retention proxy detached from book promise.

## 10. Anti-choppiness / line-edit gate

`PROCESS ≠ STORY` is the primary application.

Wrong repair:
`connect. look. think. click. react. answer.`

Correct diagnostic order:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH TOPIC/READER-STATE → SENTENCE RHYTHM → WORDING`.

If five microbeats are one perceptual/decision unit, merge them. If the process is not load-bearing, summarize or omit it.

`COMPRESSION ≠ CHOPPING`.
`ACTION / SUSPENSE / EMOTION / PERSUASION ≠ SHORT-SENTENCE DENSITY`.

## 11. Regression check

Any repair triggered by Batch 199 must prove:
1. the original observed defect;
2. the level of the defect;
3. why the chosen repair is the smallest correct repair;
4. no canon/personhood/evidence regression;
5. no destruction of protected payoff / reader reward;
6. no new paragraph-confetti / fragment monoculture.
