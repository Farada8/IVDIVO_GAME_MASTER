# ORBITAL YOUTH / IVDIVO — BATCH 47 MCKEE APPLICATION GATE
Date: 2026-08-17
Status: ADDITIVE / NO RETROFIT

## VERDICT
**REPAIR WHEN A CONCRETE DEFECT EXISTS. DO NOT REBUILD BOOKS TO MATCH MCKEE.**

McKee adds scene/information/climax diagnostics. It does not override current canon or force a three-act screenplay structure onto novels/audio books.

## ONE MAIN STORY
Before prose:
`main local problem → character-specific tactics → changed information/relations/world state → qualitatively changing pressure → bounded final choice → local result`.
A side story stays only if it changes this engine or materially changes the person whose later choice affects it.

## ORBITAL WORLD
A future detail earns page weight when it changes:
- route/time/gravity/body behavior;
- social or human–robot relation;
- access/responsibility;
- privacy/consent;
- evidence;
- a concrete opportunity or obligation.

No "future-tech tour" scenes whose state is unchanged afterward.

## POST-MONEY FIREWALL
Do not import McKee's "make a living" questions literally.
For mature orbital cities ask instead:
- what contribution is expected/desired?
- what time/attention is limited?
- what trust/qualification is needed?
- what unique mission/place/relationship cannot be fabricated?
- what responsibility has the character accepted?

No salary/rent/credits replacement economy without explicit Founder change.

## CONSCIOUS ROBOTS
Reject protagonist-centric supporting-character logic.
A conscious robot must have:
`own want + own relationships + own constraints + right to refuse + consequence independent of human convenience`.

## SPECIALIST CONSCIOUSNESS SCHOOLS
Exposition should emerge through:
`lineage/practice → observable claim → reproducibility limit → disagreement → personal cost/use`.
High engineering capability does not imply mature public science of soul/dimensional worlds.

## YA SCENE GATE
A scene should change at least one:
`autonomy / trust / belonging / first real responsibility / intimacy / consent / future role / reputation / evidence / relationship`.
Ordinary life is not filler if one of these changes.

## SUSPENSE / MYSTERY
Maintain an evidence ledger:
`fact → source → observation/inference → confidence → alternative model → what changes confidence`.
Never create suspense by hiding known POV information.

## CLIMAX
Preferred IVDIVO form:
`CAUSAL CONVERGENCE → BOUNDED CHOICE → COST → LOCAL RESULT → AFTERMATH`.
The largest accident/attack/reveal may occur earlier. The climax is the decisive local choice.

## PROSE / RHYTHM
Do not import screen brevity.
- suspense may slow down;
- decisive scenes may use longer sentences/paragraphs;
- short lines are contrast, not KPI;
- summarize routine process;
- dramatize exact words/actions when they change power, consent, trust, evidence, relationship or choice.

## LESSON ZERO BOOK ONE
No new McKee-derived defect currently justifies breaking development lock. A new theory is not evidence. Reopen only for a specific present defect or external reader/editor evidence.

## REQUIRED PRE-PROSE QUESTIONS
1. What is the scene owner's immediate want?
2. What tactic do they try?
3. What reacts?
4. What information/relationship/world state changes?
5. Why is direct scene treatment better than summary?
6. Does this feed ONE MAIN STORY?
7. Does any future technology actually change human/robot choice?
8. Is the opposition competent and partly right?
9. Is suspense fair?
10. If this is a climax candidate, what local problem does the choice close?
