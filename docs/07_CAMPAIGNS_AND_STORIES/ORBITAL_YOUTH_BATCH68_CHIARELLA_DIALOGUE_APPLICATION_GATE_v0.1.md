# 2. CHARACTER-SPECIFIC VALIDATION

## Local / conscious robot characters
No generic orbital-local dialect and no universal robot register. Each named person needs independent want, relation-specific diction/tactics, and the right to refuse, redirect or remain silent.

# 3. SCENE DIALOGUE ACCEPTANCE TEST
Before retaining a long direct exchange answer:
1. What changed because these exact words were spoken?
2. Who owns the scene-level want?
3. What is the other person's independent want?
4. How do direction/speed/distance change during the exchange?
5. Which facts genuinely need to be spoken now?
6. What is omitted/evasive because of the relationship?
7. Can setting/gesture/silence do some of the work?
8. Is narration helping interpretation or merely explaining lines already clear?
9. Does the dialogue have one primary job rather than carrying the entire chapter architecture?
10. Does the exchange create the next causal state?

If #1 or #10 fails, repair structure before line editing.

# 4. POST-MONEY FIREWALL
Do not use contemporary consumer/work talk to create easy youth authenticity. Ordinary conversation should normalize the actual world:
- access to ordinary goods is not the central status problem;
- scarce things are time, trust, mission slots, attention, consent, specific responsibility, unique places/experiences and relationships;
- no hidden replacement currency through `credits`, allowances or rent logic.

# 5. CONSCIOUSNESS-SCHOOL FIREWALL
Dialogue must preserve epistemic status:
- `I experienced/observed X`;
- `our practice can reproduce Y`;
- `our school interprets it as Z`;
- `another school disagrees`;
- `the civilization/world knows` only when independently established.

Do not allow one practitioner's confident speech to silently upgrade a school interpretation into civilization-wide ontology.

# 6. ANTI-CHOP PASS
Before merging short sentences, inspect in this order:
`DIRECT-SCENE NECESSITY → DIALOGUE NECESSITY → SILENCE/SETTING OPPORTUNITY → NARRATIVE MODULATION → PARAGRAPH INTENT → SENTENCE RHYTHM`.

Common repair:
`quote → microreaction → quote → microreaction → quote`
may become
`quote → coherent POV/setting paragraph → reply/changed tactic`.

But preserve genuinely sharp one-line beats when contrast/function earns them.
