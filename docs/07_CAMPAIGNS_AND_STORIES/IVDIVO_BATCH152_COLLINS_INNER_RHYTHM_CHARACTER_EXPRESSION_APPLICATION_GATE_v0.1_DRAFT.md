# IVDIVO — BATCH 152 APPLICATION GATE
## Inner Rhythm · Character-Specific Expression · Anti-Choppiness

Status: DRAFT
Date: 2026-08-20
Source: Brandilyn Collins, *Getting Into Character*, Secret #5 `Inner Rhythm` — strict chapter read complete.

## Purpose

Use Collins to improve character-specific emotional behaviour **without** turning analytical beats into fragments, microgestures or evidence shortcuts.

## Gate 1 — Separate internal and external tempo

For any emotionally important scene, answer independently:

- What is the speed / pressure of the POV character's inner process?
- What is the speed / density of visible action?
- What is the social / conversational tempo?
- What is the environmental tempo?

Do not assume they match.

## Gate 2 — Generate expression options before choosing a tell

`INNER STATE -> 3+ POSSIBLE EXPRESSIONS -> CHARACTER / RELATIONSHIP / OBJECTIVE FILTER -> SELECT ONE OR NONE`

Reject the first generic gesture if it merely names the emotion physically.

## Gate 3 — Evidence firewall

`BODY / VOICE / SILENCE SIGNAL -> POV INTERPRETATION`, not `MOTIVE FACT`.

Especially in mystery:

- hesitation is not guilt;
- eye contact is not truthfulness;
- attraction is not corroboration;
- compliance is not consent;
- calmness is not innocence;
- visible agitation is not deception.

## Gate 4 — Paragraph before fragment

When emotional beats accumulate, first test whether they form one perceptual or decision unit.

Bad default:

`line -> glance -> hand -> thought -> line -> breath`.

Preferred diagnostic order:

`SCENE FUNCTION -> POV STATE -> INNER/OUTER RHYTHM -> LOAD-BEARING ACTION/OMISSION -> PARAGRAPH INTENT -> SENTENCE RHYTHM`.

## Gate 5 — No microgesture confetti

An action beat earns space only if it does at least one of the following:

- changes tactic;
- changes relationship / boundary;
- changes consent;
- changes evidence access/status;
- changes physical possibility;
- reveals a character-specific coping method with downstream value;
- preserves reader orientation at a needed moment.

Otherwise cut, merge or absorb into normal prose.

## Gate 6 — Nonhuman personhood

For conscious robots / synthetic / distributed persons:

`EMBODIMENT + OWN PRIORITIES + OWN MODEL/EVIDENCE + RELATIONSHIP + CONSTRAINT -> COMMUNICATION TIMING / ACTION / REFUSAL`.

Do not use human nervous gestures as a mandatory proof of interiority.

## Acceptance test

A revised passage passes only if:

1. the emotional pressure is legible without naming every emotion;
2. behaviour is specific to this character and relationship;
3. no evidence claim depends on body-language mind-reading;
4. no additional fragment density was introduced merely to simulate intensity;
5. paragraph flow remains natural;
6. removing a retained gesture would measurably reduce character, causality, orientation or relationship information.
