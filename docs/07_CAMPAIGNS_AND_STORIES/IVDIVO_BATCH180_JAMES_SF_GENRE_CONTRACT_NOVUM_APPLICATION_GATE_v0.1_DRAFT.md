# IVDIVO BATCH 180 — EDWARD JAMES — SF GENRE CONTRACT / NOVUM / READER PROTOCOL APPLICATION GATE v0.1

## Standing decision

**APPLY ADDITIVELY. DO NOT RETROFIT LOCKED MANUSCRIPTS TO A GENRE TEMPLATE.**

## A. ONE MAIN STORY

Every novel must be able to complete:

`THE SF DIFFERENCE changes ________, which forces ________ to choose/do ________, causing ________.`

If the blank is only “the world looks futuristic,” the novum is not causal enough.

## B. ORBITAL YOUTH

### Post-money normality
Do not explain the economy in a lecture. Establish it via attention:
- ordinary producible goods barely attract scarcity-thinking;
- scarce attention goes to time, consent, trust, privacy, role, responsibility, mastery, belonging, unique experiences and mission opportunities.

### Technology
For each foregrounded technology ask:
- `WHAT NEW ACTION DOES IT ENABLE?`
- `WHAT OLD ACTION DOES IT REMOVE?`
- `WHO GAINS?`
- `WHO BEARS COST?`
- `WHAT SOCIAL NORM EVOLVES AROUND IT?`

### Reader orientation
Unfamiliar world vocabulary can remain partially unknown, but each scene must preserve who wants what, what changed and what the current uncertainty is.

## C. CONSCIOUS ROBOTS / NONHUMAN CIVILIZATION

Do not inherit older SF's “robot as device / metaphor / servant” as a default.

Named conscious entity must have:
- independent objective;
- knowledge/model limits;
- relationships not reducible to service;
- consent/refusal;
- consequence-bearing choice.

`MORE SENSORS ≠ OMNISCIENCE`.

## D. B07 — THE UNLISTED CITY

Personhood evidence must be independently sourced.

`PATTERN → INDEPENDENT PERSONHOOD EVIDENCE → HUMAN CATEGORY FAILS → ENTITY PREFERENCE/CONSENT BECOMES DECISION-RELEVANT → ENTITY CHOICE CHANGES HUMAN OPTIONS`.

Do not use “alien mystery” merely as a mirror for Kyra's moral development.

## E. ROOM 917

Where unfamiliar/uncanny information is used, keep:
`TRACE → PARTIAL MODEL → NEW CLUE → MODEL UPDATE`.

Do not let uncanny presentation alter evidence provenance.

Standing firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## F. CONSCIOUSNESS-PRACTICE SCHOOLS

Historical SF's psi/telepathy traditions are a warning about ontology leakage.

Required:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

High technological maturity in other domains does not bypass this chain.

## G. LESSON ZERO BOOK ONE

**NO GLOBAL REWRITE.**

Edward James supplies no new concrete current defect evidence. Only reopen a local layer if current manuscript/beta/audio/continuity evidence shows confusing world-rule orientation, exposition dump, a foregrounded novum with no causal payment, Earth-present default leakage, nonhuman agency collapse or an actual prose/rhythm defect.

Standing law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## H. PROSE / RHYTHM

Do not imitate pulp staccato, New Wave fragmentation or cyberpunk density because they are historically “SF.”

`READER EFFECT → DISCOURSE MODE → PARAGRAPH INTENT → SENTENCE CONTRAST`.

Short lines are preserved only when they perform a real local function.
