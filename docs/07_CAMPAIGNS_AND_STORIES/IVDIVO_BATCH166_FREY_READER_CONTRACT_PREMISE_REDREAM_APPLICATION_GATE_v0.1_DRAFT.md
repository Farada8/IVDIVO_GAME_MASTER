# IVDIVO — BATCH 166 APPLICATION GATE
## Frey — Reader Contract · Premise · Re-Dream · Fair Play

**Status:** production guidance; does not override canon authority or locked manuscripts.

## 1. Global story gate

Before adding or rewriting a scene:

`CURRENT BOOK PROMISE → CURRENT STATE → SCENE FUNCTION → CHANGED STATE → DOWNSTREAM DEPENDENCY`.

If a scene exists mainly because a framework says a beat should exist, reject or rebuild it.

## 2. ONE MAIN STORY

Use a causal premise only as a working hypothesis.

For every major strand:
`LOCAL WANT → LOCAL CHANGE → EFFECT ON MAIN ENGINE / ANOTHER STRAND → PAYOFF`.

Shared city, school, family or mystery does not by itself create one story.

### Reorderability audit
If Chapters/Scenes A and B can swap without changing evidence, relationships, responsibility, authority, strategy or future options, test for episodicity or missing consequences.

## 3. LESSON ZERO Book One

**Decision:** `KEEP DEVELOPMENT LOCK`.

Frey supplies no new concrete current defect that justifies global rewriting.

Allowed interventions only when evidence shows:
- reader promise/payoff failure;
- current POV/evidence laundering;
- causal dependency failure;
- scene that should be re-imagined rather than line-edited;
- repeated coincidence solving core problems;
- confirmed choppy prose arising from paragraph/mode errors.

Standing rule:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## 4. Orbital Youth

### Reader bond
Do not buy sympathy through injury, poverty or victimhood.

Prefer:
`first real responsibility / competence / belonging / humor / relationship / autonomy / privacy / moral uncertainty / unique opportunity`.

### Escalation
Protect:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

### Post-money firewall
Meaningful stakes:
`time / trust / consent / specific role / access / mastery / reputation / belonging / relationship / privacy / unique mission / safety`.

Forbidden default regressions:
`salary / rent / credits / shopping power as ordinary youth engine`.

### Voice
Youth voice must arise from what a future teenager notices, values, omits, exaggerates and considers normal — not contemporary Earth slang pasted over orbital vocabulary.

## 5. ROOM 917

### Mystery contract
For each major question:
`QUESTION → CLUE/SOURCE → PROVENANCE → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION → PAYOFF / MODEL REVISION`.

### Relationship braid
Elena↔Julian relationship may change:
- willingness to disclose;
- access to sources;
- trust/boundaries;
- investigative tactics;
- willingness to cooperate.

It may **not** change what evidence objectively proves.

Hard firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

### Reader contract
Do not promise a fair evidence-led mystery and later solve it through paranormal assertion, romantic intuition or previously inaccessible decisive information.

## 6. B07 / nonhuman personhood

Human dramatic attachment is not evidence of personhood.

Evidence chain:
`PATTERN → INDEPENDENT PERSONHOOD EVIDENCE → HUMAN CATEGORY FAILS → ENTITY'S OWN MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Once personhood threshold is crossed, the human protagonist cannot own the entity's continuity decision.

## 7. Conscious robots

Frey's ruling passions / human inner-conflict model is optional craft language, not a personhood requirement.

Required:
`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

No universal robot voice. No requirement to become more human.

## 8. Consciousness-practice schools

Frey's passion, empathy and fictive-dream rhetoric cannot raise metaphysical certainty.

Maintain:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 9. Re-dream router

When a passage fails, diagnose level first:

- book-engine defect → development repair;
- chapter causal defect → sequence repair;
- scene-purpose/staging defect → re-dream scene;
- POV/evidence defect → access/provenance repair;
- paragraph defect → paragraph rebuild;
- sentence defect → line edit.

Do not paraphrase a structurally broken scene.
Do not explode a working book because one sentence is weak.

## 10. Anti-choppy prose gate

Before touching sentence length:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

`SUSPENSE / ACTION ≠ SHORT-SENTENCE DENSITY`.

A beat is not a paragraph break.

## 11. Acceptance criteria

A Frey-derived intervention passes only if:
1. it improves a demonstrated reader/story function;
2. canon/evidence status remains intact;
3. personhood and consent remain intact;
4. no 1994 market rule is being mistaken for current policy;
5. it does not introduce harm merely to manufacture seriousness;
6. it strengthens causal dependency or reader contract;
7. it survives regression against already protected payoffs and voices.
