# IVDIVO — BATCH 57 LODGE APPLICATION GATE
## Prose · World · Youth · Mystery · Endings

Date: 2026-08-17
Status: WORKING / ADDITIVE PRODUCTION CONTROL
Source layer: David Lodge strict lifecycle + Batch 57.

This file does not overwrite Founder canon, locked continuity, approved book engines or development locks. It is a diagnostic/application layer.

## 1. GLOBAL RULE
**ONE MAIN STORY at book scale does not require ONE LOCAL FORM.**

A chapter may be dialogue-heavy, contemplative, external, deeply interior, compressed, scenic, procedural or socially observational if it changes the shared causal engine or a state that changes later choices.

## 2. ORBITAL YOUTH

### A. Post-money civilization must appear as normality
Do not explain that money is obsolete in a paragraph. Show what young people compete over when ordinary manufactured goods are abundant:
- trust of a specific person;
- one non-fungible role or mission place;
- time with someone;
- reputation after a public decision;
- mastery/certification where experience cannot be printed;
- belonging to a team/community;
- consent and intimacy;
- responsibility and right to decide;
- access to a unique event, place or relationship.

**Firewall:** never replace money with a disguised universal `credit/status-points` economy unless Founder canon explicitly introduces such a system.

### B. Youth voice is attitude before slang
For each major youth POV define:
`WHAT THEY ASSUME IS NORMAL → WHAT THEY NOTICE → WHAT EMBARRASSES THEM → WHAT THEY EXAGGERATE → WHAT THEY REFUSE TO SAY → HOW THEY JOKE → CADENCE RANGE`.

Contemporary Earth slang is optional and often wrong for orbital youth.

### C. Future-normality reveal
Prefer:
`ordinary youth task/relationship → one orbital condition changes it → choice → consequence`
over explanatory tourism.

Examples of valid consequential differences: gravity transition changes a date/competition; mixed-species transport changes route etiquette; conscious robot consent changes a repair assumption; environmental compatibility changes where friends can meet.

### D. Setting length gate
Orbital transit, rings, gravity, habitats and infrastructure earn detailed description only when they alter movement, status, timing, relationship, evidence, sensory experience or decision.

## 3. CONSCIOUS ROBOTS

**Replace-with-terminal test:** if a named conscious robot can be replaced by a smart appliance with no change in consent, relationship, motive, conflict or consequence, robot personhood is not yet written.

Robot voice must be relationship-specific. No generic `precise machine speech` default. A conscious robot may speak differently to a friend, another robot, an institution, a child, a stranger or a person whose request it intends to refuse.

POV access follows the same contract as human POV: the narrative cannot know a robot's internal state merely because the author calls it AI.

## 4. SPECIALIST CONSCIOUSNESS SCHOOLS

Maintain epistemic separation:
`PRACTITIONER OBSERVATION → REPRODUCIBLE PRACTICE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → WORLD-ONTOLOGY CLAIM`.

Low population of long-term practitioners is a knowledge-production bottleneck. High orbital engineering/robotics capacity does not automatically collapse these stages into mainstream science.

Use Lodge's uncanny/double-model mechanism only when the book contract genuinely benefits from uncertainty. Do not call an unresolved author decision 'mystery'.

## 5. SMITH / B03 / MYSTERY

Before clue/reveal architecture declare the reader contract:
1. solvable puzzle;
2. bounded operational answer while deeper ontology stays unknown;
3. intentionally irrecoverable human truth;
4. designed double-model ambiguity.

For B03 / precursor-type cases, prefer **bounded operational closure** unless current canon explicitly upgrades the ontology. A case can prove how to respond safely without proving the metaphysics of time, soul or dimensional worlds.

Evidence ledger should keep separate:
`OBSERVATION / SOURCE / INTERPRETATION / CONFIDENCE / COUNTERMODEL / CORROBORATION / WORLD FACT`.

Surprise gate:
`PLANT → UNDERWEIGHT → REVEAL → RETROSPECTIVE LEGIBILITY → ACTION`.

Chance may create a problem or encounter; it may not purchase the decisive solution.

## 6. LESSON ZERO BOOK ONE

**DEVELOPMENT LOCK STAYS CLOSED.**

Lodge alone is not grounds for another whole-book rewrite. Reopen a passage only when the current master demonstrates a concrete defect such as:
- POV access violation;
- early information overload;
- youth voices collapsing into one authorial cadence;
- suspense rendered as repetitive fragments;
- description tourism;
- repetition without changed meaning;
- implication without adequate trace;
- local ending-contract failure.

New theory is not evidence of a manuscript defect.

## 7. PROSE / ANTI-FRAGMENT GATE

When prose feels chopped or mechanically AI-like, do **not** start by increasing average sentence length.

Repair order:
`STORY/CAUSALITY → SCENE NECESSITY → SHOW/TELL/MODE ROUTING → POV/DISTANCE → DURATION → PARAGRAPH INTENT → SENTENCE RHYTHM → WORDING`.

Possible root causes of 'short-fragment' texture:
- a logistical process is dramatized that should be summarized;
- every reaction receives its own paragraph;
- every internal inference is direct thought;
- direct dialogue is used where indirect dialogue would carry routine information;
- suspense is artificially translated into fragments;
- paragraph breaks do not correspond to a change in intention/focus/pressure;
- repeated thematic restatements are being used as pseudo-emphasis.

Protected short sentence test: keep it if removing its isolation destroys a real beat, contrast, revelation, comic timing, emotional hit or deliberate breath.

## 8. IDEA / THEME GATE

If a chapter contains several intelligent people discussing the theme, run the **Anti-Ideas-Panel test**:

Delete the explanatory dialogue mentally. If the chapter no longer demonstrates the issue through choices, benefits, costs and consequences, rebuild causality before polishing dialogue.

For institutions, adults and conscious robots, preserve competent countermodels. An opposing position should possess real benefits and evidence, not exist merely to be defeated by youth protagonists.

## 9. CHAPTER / ENDING RHYTHM

Do not end every chapter on the same cliffhanger grammar. Valid endings include:
- decision;
- changed relationship;
- partial answer;
- new model;
- evidence-status shift;
- emotional aftershock;
- quiet consequence;
- widened question;
- genuine suspense.

Book ending gate:
`LOCAL ENGINE CLOSED → COST/AFTERMATH → FINAL IMAGE/REFRAME → OPTIONAL SAGA HOOK`.

Do not solve the whole IVDIVO cosmology merely to make one book feel 'complete'. Do not leave the book's own main conflict unpaid merely to preserve franchise mystery.

## 10. FINAL APPLICATION PRINCIPLE
**World through consequential normality. Character through selective behaviour. Mystery through contract and evidence. Prose mode through reader effect. Local closure before saga continuation.**
