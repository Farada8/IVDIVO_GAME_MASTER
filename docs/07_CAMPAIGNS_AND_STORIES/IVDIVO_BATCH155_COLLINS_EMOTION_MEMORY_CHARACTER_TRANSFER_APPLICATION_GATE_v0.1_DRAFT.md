# IVDIVO Batch 155 — Emotion Memory / Character Transfer Application Gate

Status: additive production-control layer. Does not reopen locked manuscripts by itself.

## Standing law
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`

## A. Emotional-scene troubleshooting router
When an emotional scene feels flat, false or generic, do not begin by adding tears, fragments, gestures or traumatic backstory.

Run in this order:
1. `SCENE FUNCTION` — what changes?
2. `GIVEN CIRCUMSTANCES` — what is objectively true now?
3. `PRESENT WANT` — what does this character want from this person/system?
4. `RELATIONSHIP / STATUS / CONSENT` — what is at stake between agents?
5. `POV / KNOWLEDGE` — what can this character actually know and notice?
6. `EMBODIMENT` — what physical/sensory affordances matter?
7. `TACTIC` — what does the character do with the feeling?
8. only then, if useful: imagination / observation / analogous memory / personal emotion memory.
9. transform the material through this character.
10. reader-effect retest.

## B. Emotion-transfer gate
`AUTHOR EXPERIENCE → ABSTRACT FELT/SENSORY MECHANISM → CHARACTER VALUE/HISTORY/EMBODIMENT/RELATIONSHIP/OBJECTIVE → CHARACTER-SPECIFIC ACTION/PERCEPTION`

Reject direct transplantation when the character simply reacts as the writer would.

## C. Ethical memory gate
Personal trauma recall is never mandatory.

Allowed substitutes:
- imagined analogous circumstances;
- observed behavior;
- sensory research;
- non-traumatic analogous memories;
- objective/action work;
- relationship modelling;
- physical/environmental constraints;
- reader feedback on the draft.

## D. Mystery / ROOM 917
`EMOTION / ATTRACTION / SILENCE / INFLECTION / DISTRESS ≠ CORROBORATION`

Emotional leakage may change:
- Elena's or Julian's suspicion;
- trust/boundary;
- willingness to disclose;
- investigative tactic;
- consent.

It does not change what a recorder trace, plan, structural report, timestamp or independent source actually proves.

Required separation:
`TRACE → SOURCE → OBSERVATION → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.

## E. Orbital Youth
Do not buy adolescent depth with mandatory trauma.

Prefer pressures that cannot be manufactured cheaply in a post-money society:
- trust;
- responsibility;
- consent;
- belonging;
- privacy;
- mastery;
- another person's time;
- unique experience / mission role;
- reputation as social relationship, not currency;
- autonomy versus coordination.

A young character can have a powerful emotional arc through success, responsibility and changed relationships without a breakdown/healing template.

## F. Conscious nonhuman persons
Do not use human emotion recall as a personhood test.

Required personhood line:
`OWN WANT / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Human observers may misread timing, silence, compliance or nonhuman embodiment. Their emotional interpretation remains an interpretation.

## G. B07 / distributed life
Human empathy with the distributed entity is useful only as a character-state change. It is neither necessary nor sufficient evidence of personhood.

After independent personhood threshold:
`ENTITY MODEL/PREFERENCE → ENTITY CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## H. Consciousness-practice schools
`INTENSE EXPERIENCE ≠ ONTOLOGY`.

Preserve:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

The writer's own felt experience cannot be used to bypass this chain.

## I. Anti-choppiness gate
Never express every internal shift as a separate physical cue or one-line paragraph.

Before line editing:
`SCENE NECESSITY → POV/EVIDENCE → EMOTIONAL/RELATIONAL TURN → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several microbeats constitute one perception/decision, merge them into a coherent sentence/paragraph unless contrast genuinely requires separation.
