# IVDIVO BATCH 204 APPLICATION GATE
## Bell — Process · Scene · Dialogue · Revision

**Authority:** additive craft gate; does not override locked canon/manuscript authority.  
**Book One rule:** `NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## 1. Discovery-mode specialist routing
During live generation:

`NEW SPECIALIST OBSERVATION → FATAL/MAJOR NOW?`
- YES → interrupt and repair.
- NO → capture to backlog with target, reason and validation condition.

After discovery:
`BACKLOG → RELEVANT SPECIALIST PASS → MINIMAL CORRECT FIX → RETEST`.

This prevents the specialist stack from sterilizing live prose.

## 2. Scene acceptance
Before line editing a scene:

`PRIOR STATE → OWNER → PRESENT WANT / RESPONSIBILITY → PRESSURE / SUPPORT → TACTIC → BULL'S-EYE CHANGE → EXIT STATE → NEXT CAUSAL LINK`.

If no downstream-relevant state changes, test `SUMMARY / MERGE / DELETE / REBUILD` before prose polish.

## 3. Dialogue routing
Use direct dialogue when exact wording changes:
- evidence or source access;
- consent / refusal;
- trust / relationship terms;
- authority / standing;
- decision / commitment;
- emotional or social state;
- future option space.

Use indirect dialogue / summary when wording is not load-bearing: routine logistics, repeated briefing, process, small talk, already-known information.

## 4. RUE / anti-restatement
If the reader can already infer the effect from action, context or dialogue, do not immediately explain it again.

Forbidden pattern:
`behavior shows change → narrator explains change → one-line thematic restatement`.

## 5. Progressive-revelation fairness
`WORLD FACT → TRACE / SOURCE → POV ACCESS → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

Close POV may not silently suppress a fact the character already knows solely to create a later reveal.

## 6. Anti-choppiness / compression
Do not translate Bell's advice to write quickly into final prose style.

`FAST DRAFT ≠ CHOPPY FINAL PROSE`.

Repair order:
`SCENE/MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → MERGE RELATED MICROBEATS → SENTENCE CONTRAST → WORDING`.

`COMPRESSION ≠ CHOPPING`.
