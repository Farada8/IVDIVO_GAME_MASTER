# IVDIVO BATCH 162 APPLICATION GATE
## Kempton — Dialogue Function · Voice · Evidence

**Date:** 2026-08-20  
**Status:** PRODUCTION GATE / DRAFT  
**Applies to:** LESSON ZERO, Orbital Youth, ROOM 917, B07 and future IVDIVO prose/audio stories.

## 1. Standing manuscript law

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Kempton does **not** reopen LESSON ZERO Book One. Use this gate only when a concrete dialogue defect is observed in current prose, reader feedback, audio performance or continuity/evidence review.

---

## 2. Dialogue admission test

Before protecting a conversation as real-time dialogue, answer:

1. What does each active speaker want **now**?
2. What tactic is each using?
3. What does the actual listener hear/understand/misread?
4. What changes because these exact words were spoken?
5. Would summary or indirect dialogue preserve the same story value more efficiently?

Protect direct dialogue when exact wording changes:
`CONSENT / TRUST / EVIDENCE / ACCESS / AUTHORITY / RELATIONSHIP TERMS / DECISION / COMMITMENT / FUTURE OPTION SPACE`.

---

## 3. Exposition ownership

Forbidden default:
`AUTHOR NEEDS READER TO KNOW X → CHARACTER EXPLAINS X`.

Required:
`CHARACTER NEEDS/WANTS TO SAY/ASK/HIDE X → WHY NOW → WHY THIS LISTENER → CONSEQUENCE`.

If the in-story ownership is weak, reroute to:
- narration;
- summary;
- document/log;
- observed test;
- evidence artifact;
- later scene where the information becomes actionable.

---

## 4. Evidence firewall

For mystery and science-fiction investigation:

`UTTERANCE / SILENCE / INFLECTION / GESTURE → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.

Never silently promote communication behavior into fact.

Standing rules:
- `TRUST ≠ CORROBORATION`
- `ATTRACTION ≠ CORROBORATION`
- `CONFESSION ≠ CORROBORATION` unless independently verifiable and legally/causally sufficient for the specific claim
- `SILENCE ≠ GUILT`
- `COMPLIANCE ≠ CONSENT`
- `BEHAVIOR ≠ MOTIVE`

---

## 5. ROOM 917

Relationship dialogue Elena↔Julian may legitimately change:
- willingness to disclose;
- access to a room/source/device;
- boundary/consent;
- trust;
- investigative tactic;
- who is willing to cooperate with whom.

It may **not** change what an audio trace, structural plan, timestamp, physical measurement or provenance chain objectively demonstrates.

Production shorthand:

`RELATIONSHIP STATE → ACCESS / TACTIC`  
`EVIDENCE STATE → TRACE / SOURCE / CORROBORATION`

Keep the channels separate.

Audio-performance consequence: a pause, clipped answer or changed tempo is character/subtext evidence, not forensic proof.

## 6. LESSON ZERO Book One

Current audio-director material already assigns dialogue turns:
`IMMEDIATE WANT + TACTIC + SUBTEXT + PERFORMANCE CONSTRAINT`.

That is strongly compatible with the useful Kempton mechanism.

Do **not** reopen the book globally.

Only inspect locally if evidence shows:
- multiple characters using the same relationship-independent register;
- dialogue explaining information solely for the reader;
- repetitive exchange with no tactic/state change;
- action-beat fidgeting around otherwise clear speech;
- silence/compliance being overinterpreted;
- routine process dramatized line-by-line where summary would be stronger.

## 7. Orbital Youth

Future-youth voice is not current-Earth teen slang.

Differentiate through:
`WHAT IS NORMAL TO THEM → WHAT THEY NOTICE → WHAT THEY VALUE → WHO THEY ARE TALKING TO → WHAT THEY WANT → WHAT THEY OMIT`.

Post-money normality should emerge through what teenagers **do not bother explaining** as much as through what they explicitly discuss.

Do not let every teenager become equally witty, equally blunt or equally comfortable naming feelings.

---

## 8. Conscious robots / nonhuman persons

No universal `robot voice`.

Communication design must derive from:
`EMBODIMENT + OWN WANT + OWN MODEL/EVIDENCE + RELATIONSHIP + STATUS + TASK + CONSENT/REFUSAL`.

A named conscious robot must be able to:
- choose not to answer;
- refuse a request;
- change register across relationships;
- hold information for its own reasons;
- ask questions from its own model of uncertainty;
- make a choice that changes human option space.

Human interpretation of its silence or cooperation does not establish motive or consent.

---

## 9. Dialogue and the anti-"обрубки" pipeline

Do not translate every conversational beat into a separate sentence/paragraph.

Repair order:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → NARRATIVE MODE → POV/EVIDENCE → COMMUNICATION TACTIC → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If a sequence is:
`line → glance → fingers → breath → thought → next line`, ask first whether those microbeats form **one perceptual/decision unit** that should be one coherent paragraph.

`INTENSITY ≠ SHORT-SENTENCE DENSITY`.

---

## 10. Dialogue scene acceptance

A dialogue scene passes only if at least one meaningful state changes and the change has downstream consequence.

Possible states:
- evidence/knowledge;
- consent/boundary;
- relationship/trust;
- authority/access;
- responsibility;
- strategy/model;
- commitment;
- future options.

If nothing changes:
`SUMMARY / MERGE / DELETE / REBUILD` before line editing.

---

## 11. Final production rule

**Exact words earn reader/listener time when communication itself is causal.**

Otherwise compress.
