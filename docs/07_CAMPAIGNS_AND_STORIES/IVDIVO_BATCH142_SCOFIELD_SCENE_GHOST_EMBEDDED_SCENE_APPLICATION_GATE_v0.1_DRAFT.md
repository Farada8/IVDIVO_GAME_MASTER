# IVDIVO — BATCH 142 APPLICATION GATE
## Scofield: Scene Ghost · Embedded Scenes · Scene Weight · Prior-Scene Laboratory

**Status:** production gate / additive only  
**Source status:** Sandra Scofield — *The Scene Book* remains `FULL READ IN PROGRESS`; these gates are provisional and cannot override canon or manuscript authority.

---

## 1. Core rule

A finished IVDIVO novel does **not** need to look like a chain of equally explicit full scenes.

Use the least expensive narrative mode that preserves the required reader effect and causal clarity:

`FULL SCENE / EMBEDDED SCENE / SCENE FRAGMENT / SUMMARY / COMMENTARY`.

Underlying requirement:

`VISIBLE MODE MAY VARY; CAUSAL EVENT MUST REMAIN LEGIBLE.`

---

## 2. Scene-resolution gate

Before line editing any passage, answer:

1. What is the chapter's causal function?
2. What exact event/state change occurs here?
3. Does exact real-time sequence matter?
4. Which mode buys the effect most efficiently?
5. What weight does the material deserve?

Scene weights:

`HEAVY / MEDIUM / LIGHT / COMPRESSED`.

Do not let all technical, relational, investigative, travel, or worldbuilding material receive equal narrative resolution.

---

## 3. ROOM 917 application

### Protect full real-time scene when exact words/actions alter:
- evidence status;
- Elena↔Julian trust/boundary;
- consent;
- access to a source/space/object;
- investigative tactic;
- interpretation of the missing-fourth-note / call / room evidence.

### Compress by default:
- repeated recorder setup;
- repeated contact-mic procedure;
- walking between known locations;
- already-established hotel logistics;
- routine audio verification after the reader understands the method.

Preferred technical form:

`SUMMARY OF PROCEDURE → EXACT CLUE / CONSENT / TRUST MOMENT → SUMMARY OF COMPLETION`.

### Mystery firewall

`ROMANTIC STATE CHANGE ≠ EVIDENCE STATUS CHANGE` unless the relationship change directly changes source access, testimony, action, or provenance.

---

## 4. Orbital Youth application

A technology or orbital environment receives full-scene treatment only when:

`WORLD RULE → CHARACTER-SPECIFIC AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

Do not full-scene every transport ride, interface setup, qualification routine, or institutional briefing merely to display the civilization.

### Post-money normality

Ordinary manufactured goods may remain low-attention background. Preserve scene weight for genuinely nonfungible pressures:
- consent;
- another person's time;
- trust;
- qualification for a specific role;
- unique mission access;
- privacy;
- belonging;
- relationships;
- mastery;
- responsibility.

## 5. B07 — THE UNLISTED CITY

After personhood threshold:

`HUMAN EVIDENCE → ENTITY'S OWN MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Do not use a heavy scene merely to show humans debating the entity while the entity itself remains passive.

Human planning may create a bounded option space; the nonhuman person must retain at least one decision that humans cannot legitimately make for it.

---

## 6. Consciousness-practice schools

Use prior-scene laboratory privately when lineage or old practice events are unclear:

`WRITE PRIOR EVENT → IDENTIFY OBSERVATION / EFFECT / INTERPRETATION / LIMIT → EXTRACT PRESENT CONSEQUENCE`.

Do not automatically publish the laboratory scene.

Epistemic firewall remains:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

A vivid real-time scene of a practice experience does not promote the school's explanation to world fact.

---

## 7. Anti-choppy prose gate

Before changing sentence length:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT → MODE → POV/EVIDENCE → EVENT/RESPONSE COUPLING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Forbidden repair pattern:

`event. reaction. gesture. thought. conclusion.`

If these are one perceptual/decision unit, merge them into coherent paragraph flow unless a deliberate break has a specific reader-effect function.
