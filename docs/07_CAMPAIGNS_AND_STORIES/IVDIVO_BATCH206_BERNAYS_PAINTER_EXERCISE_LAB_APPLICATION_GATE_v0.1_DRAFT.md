# IVDIVO BATCH 206 — CONTROLLED EXERCISE LAB APPLICATION GATE

**Source:** Bernays & Painter — *What If?* 3rd ed.  
**Status:** production-facing diagnostic gate

## 1. New artifact status
All exercise-generated material is born as:
`authority = DISCOVERY_ONLY`.

Required metadata:
- target artifact / scene / character;
- diagnosed question or defect;
- exercise / variable changed;
- variant id;
- observed effect;
- canon status;
- promotion reason;
- regression test.

Nothing is promoted because it is vivid, moving or clever.

## 2. Exercise routing by defect
### Scene drags
Test:
- full scene;
- embedded scene;
- summary;
- indirect dialogue;
- later entry / earlier exit.

### Voices merge
Test dialogue stripped of narration; then relation-specific register under the same situation.

### POV unclear
Run one controlled version in alternate POV/distance. Keep only if it buys unique evidence, blindness, relation pressure, irony or decision ownership.

### Character feels generic
Put several major characters through the **same non-canon scenario** and compare what they notice, want and choose.

### Ending weak
Generate several materially different consequences / exit states, not merely different final lines.

### Choppy prose
First test:
- paragraph recombination;
- scene→summary compression;
- indirect dialogue;
- one continuous long-sentence / long-paragraph variant.

Do **not** solve choppiness by adding more reaction beats.

## 3. LESSON ZERO Book One
Development lock remains.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Exercises are allowed only after reproducible current defect evidence and remain non-canon until selected.

## 4. ONE MAIN STORY
Prompt-generated idea admission:
`WHAT MAIN ENGINE STATE CHANGES?`
`WHAT LATER SCENE DEPENDS ON IT?`

No causal payment → BANK / DISCARD.

## 5. ROOM 917
Routine technical/investigative exchanges may be summary or indirect dialogue.

Protect real time when exact wording changes:
- clue provenance/status;
- Elena↔Julian disclosure/trust/boundary;
- consent;
- evidence access;
- investigative tactic.

`UNRELIABLE / SUSPICIOUS SPEECH ≠ CORROBORATION`.

## 6. Orbital Youth
Run same non-canon situation across multiple adolescents/robots to expose different salience, thresholds and tactics.

Do not import exercise-default Earth salary/rent/job logic into post-money canon.

## 7. B07 / nonhuman personhood
Writing an exercise from the entity's POV can help the writer discover possibilities.

But:
`EXERCISE POV ≠ PERSONHOOD EVIDENCE`.

Personhood remains an in-story evidentiary question. After threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## 8. Mystery / memory
`MEMORY / JOURNAL / SUBJECTIVE RETELLING = SOURCED TESTIMONY`.

Exercise-generated memory is not forensic fact.

## 9. Prose law
`SHORT FORM ≠ SHORT SENTENCE`.

`BEAT ≠ SENTENCE BREAK`.

`CONSTRAINT ≠ HOUSE STYLE`.

`COMPRESSION ≠ CHOPPING`.

Repair order:
`BOOK ENGINE → CHAPTER/SCENE FUNCTION → MODE → POV/EVIDENCE → PARAGRAPH INTENT/READER STATE → SENTENCE RHYTHM → WORDING`.
