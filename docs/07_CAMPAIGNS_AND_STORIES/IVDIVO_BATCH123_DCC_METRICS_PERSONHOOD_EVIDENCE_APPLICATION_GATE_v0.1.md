## 1. ORBITAL YOUTH — METRIC / MISSION AUDIT

Any qualification, ranking, reputation, recommendation or public-visibility mechanism must answer:

`REAL PURPOSE → PROXY MEASURE → WHAT BEHAVIOR MAXIMIZES THE PROXY → WHERE PROXY AND PURPOSE DIVERGE → WHO PAYS`.

Forbidden shortcut: replace money with reputation points/credits and call the society post-money.

A cadet can be highly visible yet unqualified; highly qualified yet unpopular; formally admitted yet socially excluded. Keep these axes separate.

## 2. PUBLIC RECORD / MEDIA GATE

For any recording, stream, transcript, edited briefing or public report:

`WORLD EVENT → RAW RECORD → SELECTOR/EDITOR → OMITTED CONTEXT → PUBLIC VERSION → AUDIENCE REACTION → CONSEQUENCE`.

A true clip does not guarantee a true causal story.

Aoife-type evidence roles should preserve provenance instead of merely producing dramatic footage.

## 3. B07 — THE UNLISTED CITY

Once distributed nonhuman life crosses a personhood threshold, classification as infrastructure/anomaly/asset loses final authority.

Required climax architecture:

`HUMAN EVIDENCE → PERSONHOOD THRESHOLD → ENTITY'S OWN MODEL/PREFERENCE → CONSENT/REFUSAL → HUMAN OPTION SPACE CHANGES → BOUNDED ACCOUNTABLE DECISION`.

The distributed entity must own at least one irreplaceable choice. Kyra may create a lawful/technical opportunity for choice; she may not own the entity's final preference.

If harmful contact was partly produced by system design, audit responsibility across the option architecture rather than assigning all blame to the last human operator.

## 4. CONSCIOUS ROBOTS

Operational labels such as service unit, assistant, safety system, anomaly or asset never settle personhood.

Use:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Behavioral compliance under authority, nudging or code constraint does not automatically prove motive or consent.

Development does not require becoming more human in body, speech, romance or values.

## 5. MYSTERY / INVESTIGATION

Use:
`CLAIM → SOURCE → TRACE → ALTERNATIVE MODEL → DISCRIMINATING EVIDENCE → STATUS UPDATE → ACTION`.

Do not let a public narrative silently overwrite the evidence ledger.
