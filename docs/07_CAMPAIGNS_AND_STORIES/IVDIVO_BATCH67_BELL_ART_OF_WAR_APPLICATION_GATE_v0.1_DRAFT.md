# 2. FUTURE ORBITAL YOUTH BOOKS
## Post-money firewall
Bell's career/economic examples do not enter storyworld motivation. Replace neither money nor rent with disguised credits/status currency.

Valid high-value stakes include:
- trust of a specific person or institution;
- concrete responsibility;
- membership/role in a real team or mission;
- consent and autonomy;
- relationship continuity;
- time with another person;
- mastery and qualification;
- reputation after a public decision;
- one nonfungible opportunity/experience.

## Conscious robot personhood
A robot cannot serve merely as mentor, Q-factor, exposition carrier or reader-bond device. Required:
`OWN WANT → OWN RELATIONS → RIGHT TO REFUSE → OWN TACTICS → OWN CONSEQUENCES`.

If replacing the robot with a smart terminal leaves the scene functionally unchanged, personhood is not yet written.

## Rare consciousness schools
Use progressive revelation under the current epistemic firewall:
`PRACTITIONER OBSERVATION → REPRODUCIBLE PRACTICE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → LIMIT OF KNOWLEDGE → POSSIBLE ONTOLOGICAL CLAIM`.

Never promote a school interpretation to civilization-wide fact merely because it appears in a later chapter.

# 3. ONE MAIN STORY GATE
For every major scene record:
`PRIOR CONSEQUENCE → SCENE OWNER → PRESENT WANT → PRESSURE → BULL'S-EYE CHANGE → OUTER STATE → INNER/RELATION STATE → NEXT CAUSAL LINK`.

If no later action depends on the scene and no relationship/model/commitment changes, compress/merge/cut before line editing.

# 4. MYSTERY / SUSPENSE GATE
Progressive revelation must preserve fairness:
- reader can access observable evidence available to active POV;
- interpretation can remain uncertain;
- source status stays attached to claims;
- late reveal must retrospectively fit earlier traces;
- withheld fact requires an in-world reason;
- no final oral answer key replaces causal proof.

# 5. DIALOGUE / SUBTEXT GATE
For every direct exchange ask:
`WHAT DOES EACH PERSON WANT RIGHT NOW?`
`WHAT TACTIC IS EACH USING?`
`WHAT CHANGED AFTER THE EXCHANGE?`

Direct agreement is allowed when it changes intimacy, consent, commitment, trust or evidence. Artificial conflict added only to hide exposition is rejected.

# 6. ANTI-CHOP / LINE-EDIT GATE
Before joining or lengthening sentences, test in order:
1. Is this material necessary?
2. Should it be scene, summary or indirect dialogue?
3. Is POV distance stable?
4. Are paragraph breaks intentional?
5. Is there explanatory echo after an already clear action?
6. Is dialogue repeating a tactic?
7. Only then adjust sentence length/rhythm.

Short sentences remain contrast tools, not quality metrics.

# 7. STUDIO PROCESS GATE
The large IVDIVO professional system should operate in passes, not simultaneously inside every generative sentence:

`DISCOVERY / DRAFT → CAUSAL AUDIT → CHARACTER/RELATION AUDIT → EVIDENCE/POV AUDIT → SCENE/DIALOGUE AUDIT → PROSE/RHYTHM AUDIT → READER VALIDATION`.

The 100-specialist knowledge base remains available, but generation should not become a 100-way committee transcript.

# 8. CRITIQUE TRIAGE
External feedback is processed as:
`READER EFFECT → REPEATED OR ISOLATED? → TEXTUAL EVIDENCE → ROOT DEFECT → MINIMUM CORRECT LAYER → RETEST`.

Do not defend a passage because work was invested. Do not implement a suggested rewrite merely because the reader correctly detected discomfort.
