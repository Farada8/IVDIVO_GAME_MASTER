# IVDIVO BATCH 185 APPLICATION GATE
## Oatley — Reader Simulation · Emotion · Motive Inference · Personhood

**Date:** 2026-08-21  
**Applies to:** LESSON ZERO / Orbital Youth / ROOM 917 / B07 / future IVDIVO fiction.

## A. Global rule
`READER MODEL ≠ WORLD FACT`.

Narrative may invite a reader to infer motive, emotion, responsibility or ontology. The project must still preserve source/evidence status separately.

## B. LESSON ZERO Book One
**Decision:** development lock remains.

Do not reopen the book because Oatley offers a new theory. Local repair is authorized only if current beta/audio/continuity evidence shows one of the following:
1. Ethan's goal/plan is not legible enough for readers to model his next action.
2. Emotion is repeatedly named without changing tactics, relationships or decisions.
3. The five youth characters respond to the same event with effectively the same appraisal and tactic.
4. Intended reader emotion repeatedly fails in reader/audio evidence.

Standing law: `NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## C. Orbital Youth
### C1 — YA reader bond
Prefer:
`PRESENT RESPONSIBILITY / WANT → PLAN → ACTION → WORLD RESPONSE → RESULT → APPRAISAL → NEXT PLAN`.

Do not buy attachment with mandatory wound, victimhood or humiliation.

### C2 — Differentiated appraisal matrix
For a shared event, record per major youth character:
- present concern;
- what they notice;
- what they think the event threatens/offers;
- emotion/appraisal;
- first tactic;
- second tactic if resisted;
- changed relationship/model.

If five rows are near-identical, character differentiation is cosmetic.

### C3 — Post-money stakes
Allowed high-value concerns include:
- trust;
- consent;
- another person's time;
- concrete responsibility;
- privacy;
- mastery;
- belonging;
- reputation;
- relationship;
- unique mission/opportunity/access.

Do not reintroduce salary/rent/credits as an easy motivation generator.

## D. Conscious robots / nonhuman persons
### D1 — Identification without humanization
A reader can identify by simulating a goal/plan.

Required personhood line:
`OWN CONCERN / PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

### D2 — Prediction firewall
`PREDICTED BEHAVIOR ≠ REASON ≠ CONSENT`.

A routing/recommendation/AI system may predict behavior accurately and still be normatively wrong to allocate burden on that basis.

### D3 — Human interpretation firewall
`HUMAN OBSERVATION OF ROBOT BEHAVIOR → HUMAN MOTIVE MODEL`, not motive fact.

## E. B07 — THE UNLISTED CITY
Before personhood threshold:
`PATTERN / TRACE → MULTIPLE MODELS → INDEPENDENT TESTS → STATUS UPDATE`.

After independent personhood threshold:
`ENTITY OWN CONCERN/MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Human emotional identification with the entity may motivate investigation but is neither necessary nor sufficient proof of personhood.

## F. ROOM 917
For behavior/dialogue-based suspicion:
`BEHAVIOR / UTTERANCE → ELENA/JULIAN MODEL A/B → ALTERNATIVE MODEL → DISCRIMINATING TRACE/TEST → STATUS UPDATE`.

Absolute firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

Relationship state may change:
- disclosure;
- willingness to share a source;
- evidence access;
- next investigative tactic.

It may not change what a physical trace objectively proves.

## G. Consciousness-practice schools
`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Intensity of experience and narrative persuasiveness do not raise epistemic status.

## H. Reader-effect validation
For a load-bearing emotional beat record:
- intended reader effect;
- character's actual goal/concern;
- event/appraisal causing character emotion;
- evidence available to reader;
- beta/audio observed effect;
- repeated vs isolated response;
- repair hypothesis if needed.

`AUTHOR INTENDS EFFECT ≠ READER EXPERIENCES EFFECT`.

## I. Anti-choppiness gate
Do not materialize every appraisal as a separate fragment/gesture/thought line.

Before line editing:
`SCENE FUNCTION → POV/KNOWLEDGE → MODEL CONTINUITY → EMOTIONAL/RELATIONAL TURN → PARAGRAPH INTENT → READER-STATE → SENTENCE RHYTHM`.

If several microbeats form one appraisal/decision, test one coherent paragraph.

## J. Release conditions
A manuscript-facing change from this batch is admissible only if it improves at least one observable dimension:
- motive/goal legibility;
- differentiated appraisal;
- causal emotional progression;
- evidence/motive separation;
- nonhuman agency/consent;
- reader-model continuity;
- measured reader/audio effect.

Otherwise: no change.
