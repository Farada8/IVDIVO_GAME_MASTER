# IVDIVO BATCH 211 — CRON READER-MODEL / CAUSAL-MEANING APPLICATION GATE

**Status:** ACTIVE DIAGNOSTIC GATE  
**Date:** 2026-08-22  
**Source:** Lisa Cron — *Wired for Story*  
**Authority:** additive craft diagnostic; lower than current canon / locked manuscript / active project authority.

## 1. Global law
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Cron does not reopen a locked manuscript merely because a new craft lens exists.

## 2. Scene causality
For any suspect scene record:
`ENTRY STATE → OWNER/WANT → NEW EVENT/TRACE → POV APPRAISAL → TACTIC/CHOICE → EXIT STATE → LATER DEPENDENCY`.

If no meaningful exit-state or later dependency exists:
`SUMMARY / MERGE / DELETE / REBUILD` before line editing.

## 3. Knowledge-state matrix
For every load-bearing clue/reveal:
- WORLD FACT
- SOURCE / TRACE
- POV ACCESS
- POV INTERPRETATION
- OTHER CHARACTER MODEL
- READER MODEL
- CORROBORATION STATUS
- NEXT ACTION

Do not collapse these fields.

## 4. Reveal gate
A late reveal is allowed only if:
1. early traces remain literally true;
2. the reader had a detectable gap/question;
3. the new evidence actually distinguishes models;
4. POV knowledge is not unfairly hidden;
5. the reveal changes action or interpretation downstream.

## 5. Motive / personhood firewall
`GESTURE / PAUSE / INFLECTION / SELF-REPORT / COMPLIANCE → HYPOTHESIS`.

Not sufficient for:
- motive,
- guilt,
- consent,
- personhood,
- ontology.

## 6. Genuine-success gate
Do not force every attempted solution to fail.

Protected pattern:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

## 7. Subplot gate
For each large subplot:
`LOCAL CHANGE → WHAT MAIN-ENGINE STATE CHANGES? → WHICH LATER DECISION DEPENDS ON IT?`

If nothing: bank, merge or compress.

## 8. Exposition / specificity gate
Before adding a detail:
`WHO NOTICES? → WHY NOW? → WHAT DOES IT MEAN TO THEM? → WHAT READER MODEL DOES IT UPDATE?`

Lived-reality texture is allowed; it need not become a Chekhov gun.

## 9. Anti-choppiness gate
Never translate causal analysis into typography mechanically.

`BEAT / APPRAISAL / DECISION ≠ SENTENCE BREAK`.

Repair order:
`SCENE/MODE → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE CONTRAST/RHYTHM → WORDING`.

## 10. LESSON ZERO Book One
**Development lock remains.**

Only open a local patch if current evidence shows:
- reader cannot state the operative question;
- known POV fact is unfairly hidden;
- setup creates unpaid expectation;
- scene has no downstream state change;
- character choice lacks causal bridge;
- technical process is over-dramatized;
- repeated paragraph fragmentation damages reader-state continuity.

Otherwise no rewrite.

## 11. Orbital Youth
Protect:
- competent youth can succeed;
- no mandatory wound / inner-flaw arc;
- future stakes remain non-monetary where canon requires;
- technology must alter affordances, relationships, authority or responsibility;
- each teen must have a distinct appraisal/tactic, not merely different slang.

Required chain:
`WORLD FACT → TRACE / SOURCE → ELENA/JULIAN ACCESS → INTERPRETATION → ALTERNATIVE MODEL → DISCRIMINATING TEST → CORROBORATION STATUS → ACTION`.

Absolute:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION / BODY LANGUAGE ≠ CORROBORATION`.

## 13. B07 / nonhuman life
Human emotional reaction is not personhood evidence.

After independent personhood threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.
