## DECISION
Use W001 as a **routing library**, not a template.

### Ordinary orbital life
`NORMAL POST-MONEY ROUTINE → NONFUNGIBLE PRESSURE → CHARACTER-SPECIFIC RESPONSE`.
Do not manufacture rent, wages or credits to create stakes.

### Conscious robots
No universal "AI voice." Require:
`own want + refusal right + other relationships + relation-specific tactics + embodiment-specific options`.

### Consciousness schools / mystery
Maintain:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE WORLD FACT`.
Mark speculation rather than silently upgrading it.

### Scene acceptance
A quiet scene may remain if it changes later action, interpretation, relationship or emotional readiness.
A busy scene may be cut if it only repeats an existing state.

### Dialogue
Direct wording earns space when wording changes:
`trust / consent / evidence / power / relationship / decision / emotion`.
Otherwise compress to indirect dialogue or summary.

### Prose / cadence
Before fixing "обрубки":
`scene necessity → mode → POV → dialogue mode → paragraph intent → rhythm → wording`.

### Book One firewall
Current submission manifest keeps LESSON ZERO Book One development locked. W001 creates **no automatic reopening condition**.

Open a targeted regression only after current beta/agent/editor evidence identifies the same local defect.

## PASS / FAIL QUESTIONS
1. What state changes in this scene?
2. Is this material in the correct mode: dramatic, narrative, lyrical, or mixed?
3. Does exact dialogue wording deserve page-time?
4. Does the POV know what the prose claims it knows?
5. Does each paragraph break perform a function?
6. Is rhythm varied by meaning rather than optimized by percentage?
7. Is an unusual setting/technology doing causal or character work?
8. Are inference/speculation/world-fact statuses distinct?
9. Are major characters changing tactics differently under frustration?
10. Is the repair occurring at the correct scale?
