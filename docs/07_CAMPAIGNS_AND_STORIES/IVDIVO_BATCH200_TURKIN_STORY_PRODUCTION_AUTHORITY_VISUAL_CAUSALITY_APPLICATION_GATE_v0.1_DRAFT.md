# IVDIVO BATCH 200 — TURKIN APPLICATION GATE

**Source:** В. К. Туркин — *Драматургия кино*  
**Status:** manuscript / audio / production-facing control  
**Pass:** 165

## 1. Prime authority rule

`STORY / LITERARY AUTHORITY ≠ TECHNICAL PRODUCTION AUTHORITY`.

Audio render plans, mix instructions, TTS block maps, shot plans, visual prompts, animation staging, machine-state and production manifests may **realize** story state. They may not silently alter:
- canon;
- character motivation;
- evidence status;
- dialogue meaning;
- consent;
- chronology;
- clue provenance;
- ending outcome.

Any discovered conflict routes upstream to story authority before production proceeds.

## 2. ONE MAIN STORY / spectacle gate

For any major technical, visual, environmental or action event:

`WHAT HAPPENS → WHO EXPERIENCES / VALUES IT → WHAT CHANGES → WHAT LATER NOW DEPENDS ON THAT CHANGE?`

If no downstream-relevant state changes, classify as:
`TEXTURE / SETTING / ATMOSPHERE / SPECTACLE WITH BUDGET`, not a new plot engine.

Do not add another anomaly, technology, attack, location or visual set piece when existing consequences can still be harvested.

## 3. LESSON ZERO Book One

**Decision:** `KEEP DEVELOPMENT LOCK`.

No new current defect evidence was found.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Batch 200 permits local repair only if later reader/audio/continuity evidence identifies:
- action spectacle with no person-specific consequence;
- technical artifact overriding locked story;
- dialogue carrying no tactic/relationship/evidence function;
- repeated clever transition mannerism;
- a decisive event with missing aftermath;
- a flashback that does not alter present state.

## 4. ROOM 917 — story / audio authority boundary

Required dependency direction:

`LOCKED SCRIPT / CLUE FACT → DIRECTOR SCORE → RENDER BLOCK → TTS / SFX / FOLEY / MIX → QC`.

Never:
`MIX / TTS CONVENIENCE → NEW STORY FACT`.

If an audio implementation needs a clue line shortened, moved or replaced, that is a story-layer change request and must re-enter story/evidence review.

### Audio transition gate
A sound bridge earns emphasis only when it does at least one:
- orients time/place;
- preserves causal continuity;
- links parallel strands;
- changes clue interpretation;
- carries earned motif/relationship meaning.

Otherwise prefer an invisible/simple transition.

### Evidence firewall
`AUDIO EFFECT / PERFORMANCE / SILENCE / INFLECTION ≠ CORROBORATION`.

A production choice can shape reader inference, not objective clue status.

## 5. Orbital Youth

Worldbuilding rule:

`TECH / HABITAT / GRAVITY / ROBOTIC SYSTEM → PERSON-SPECIFIC AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

If a new technology is only impressive, it remains background rather than scene engine.

Post-money stakes remain:
`TIME / TRUST / CONSENT / PRIVACY / RESPONSIBILITY / ROLE / MASTERY / BELONGING / RELATIONSHIP / UNIQUE OPPORTUNITY / SAFETY`.

Do not restore salary/rent/credits through historical screenplay assumptions.

## 6. B07 / nonhuman personhood

A visually striking behavior or environmental pattern is evidence input, not personhood proof.

`TRACE → SOURCE / SENSOR LINEAGE → ALTERNATIVE MODELS → DISCRIMINATING TEST → PERSONHOOD THRESHOLD`.

After threshold:
`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

`SILENCE / COMPLIANCE ≠ CONSENT`.

## 7. Dialogue / subtext gate

`PRESENT WANT → VERBAL / NONVERBAL TACTIC → PARTNER RESPONSE → TACTIC UPDATE → CHANGED STATE`.

A silent action may be a reply. But:
`SILENCE / GESTURE / SUBTEXT → POV HYPOTHESIS`, not motive fact.

Exact dialogue is protected when wording changes:
- consent;
- evidence/access;
- trust/relationship terms;
- authority;
- decision;
- commitment.

Routine process / repeated information → summary / indirect / compression candidate.

## 8. Past-time gate

Before full flashback:
`WHY NOW? → WHAT PRESENT KNOWLEDGE / RELATION / EVIDENCE / CHOICE CHANGES?`

Then route:
`FULL FLASHBACK / REPORTED MEMORY / SUMMARY / OMIT`.

## 9. Climax / aftermath gate

`DECISIVE EVENT / CHOICE → LOCAL OUTCOME → COST → RELATION / RESPONSIBILITY / KNOWLEDGE AFTERMATH → OPTIONAL SERIES VECTOR`.

Do not let scale/spectacle substitute for resolution of the book's governing problem.

## 10. Anti-choppiness gate

Turkin's distinction between mechanical movement and dramatic dynamics has prose consequences:

`FAST ACTION / FAST CUTS ≠ SHORT SENTENCE REQUIREMENT`.

Wrong translation of film craft into prose:
`shot → sentence → cut → paragraph → shot → sentence`.

Correct router:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH TOPIC/READER-STATE → SENTENCE RHYTHM/CONTRAST → WORDING`.

`SHOT / CUT / BEAT / REPLY ≠ SENTENCE BREAK`.
`COMPRESSION ≠ CHOPPING`.

## 11. Regression requirements
Any repair triggered by Batch 200 must prove:
1. observed defect;
2. correct defect layer;
3. minimum necessary fix;
4. no story/canon/evidence regression;
5. no personhood/consent regression;
6. no destruction of protected reader reward/payoff;
7. no new transition or staccato mannerism.
