# ORBITAL YOUTH — BATCH 60 APPLICATION
## Wolf Canon Provenance · World Database · Default Override Gate

Date: 2026-08-17
Status: WORKING / ADDITIVE PRODUCTION GATE

## VERDICT
**REPAIR / DO NOT REBUILD.** Wolf does not justify replacing an accepted book engine with a worldbuilding exercise. It supplies a stronger governance layer around the existing saga and future orbital books.

## 1. CURRENT AUTHORITY FIREWALL
For Orbital Youth and later saga books, use this practical order:

`Founder/direct correction → approved Saga Bible/Narrative OS → active reconciler → locked book manuscript → production audits → working concepts → reference/craft sources`.

A newer document cannot silently restore an older superseded rule.

## 2. POST-MONEY DEFAULT OVERRIDE
Because readers will otherwise reconstruct familiar Earth economics, each book should establish post-money normality through a few causal everyday signals.

Good stakes:
- one particular mission slot;
- another person’s limited time;
- trust of a mentor/team/community;
- consent and intimacy;
- reputation after a public decision;
- access that depends on competence/responsibility;
- a unique location/event/window;
- lived practice and mastery;
- belonging without possession.

Forbidden regression:
- generic credits as replacement money;
- rent/wages/consumer-status as ordinary orbital youth engine;
- artificial scarcity of robot-manufacturable common objects merely to recreate contemporary YA pressure.

## 3. CONSCIOUS ROBOT PERSONHOOD
Robot civilisation is not world decoration. For each named conscious robot test:
1. What does it want independently of the human protagonist?
2. What relationships/obligations exist off the protagonist’s axis?
3. What can it refuse?
4. What information can it withhold or choose to share?
5. What changes if it is replaced by a smart appliance?

If answer 5 is “nothing important,” rewrite personhood before adding more robot lore.

## 4. CONSCIOUSNESS-SCHOOL KNOWLEDGE
Use an explicit epistemic ladder:
`PRACTICE OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL MODEL → COMPETING SCHOOL MODEL → UNKNOWN/PROVISIONAL ONTOLOGY`.

High orbital engineering development does not erase the practitioner bottleneck. Do not turn rare schools into a mass technology sector by exposition.

## 5. WORLD DATABASE / SCENE ROUTING
Before a world fact enters a scene ask:
- Does it alter this character’s action or available options?
- Does it alter a relationship, risk, evidence status or decision?
- Does the reader need it now to avoid a wrong inference?
- Can ordinary behavior carry it instead of explanation?

If all answers are no, route the fact to Saga Bible/world database rather than prose.

## 6. CANON-PROVENANCE LEDGER FOR FUTURE RECONCILIATION
For every high-impact disputed fact record:
`CLAIM | SOURCE | AUTHORITY | STATUS | SUPERSEDES | WHY | DOWNSTREAM FILES`.

Minimum statuses:
`CURRENT CANON / SUPERSEDED / WORKING / VARIANT / REFERENCE ONLY / IN-WORLD CLAIM`.

This specifically prevents recurrence of:
- money returning after Founder post-money correction;
- consciousness-transfer technology returning from an older draft;
- school interpretation becoming mainstream dimensional science;
- conscious robots being demoted to human-owned AI tools.

## 7. TRANSMEDIA
When adapting an IVDIVO book to audio/video/game, preserve:
- who is a person;
- what technologies/ontologies are and are not possible;
- post-money normality;
- relationship history;
- causal consequences and final book state.

Do **not** require identical exposition. Audio may externalize through sound/dialogue; prose may use interiority/summary; games may reveal through space and interaction.

## 8. BOOK CLOSURE
A huge persistent world must not weaken local closure:
`BOOK ENGINE RESOLVED → COST / AFTERMATH → CHANGED RELATIONSHIPS/WORLD STATE → OPTIONAL SAGA HOOK`.

The reader does not need an explanation of the whole orbital civilisation, robot civilisation or dimensional ontology to receive a complete novel.

## 9. LESSON ZERO
No Wolf-derived issue currently reaches the threshold for reopening the development-locked first book. Use this gate prospectively and for specific continuity regressions only.
