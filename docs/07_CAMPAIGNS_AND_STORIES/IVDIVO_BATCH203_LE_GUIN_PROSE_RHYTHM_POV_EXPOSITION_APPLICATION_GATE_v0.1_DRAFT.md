**Date:** 2026-08-22

**Status:** PRODUCTION GATE / ADDITIVE — DOES NOT REOPEN LOCKED MANUSCRIPTS BY ITSELF

## Governing rule
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Le Guin is used as a diagnostic and repair router, not permission to retrofit every manuscript to a new style.

## A. Global prose repair order
`ONE MAIN STORY / CAUSALITY`
→ `CHAPTER / SCENE FUNCTION`
→ `NARRATIVE MODE (SCENE / SUMMARY / INDIRECT / ELLIPSIS)`
→ `POV / KNOWLEDGE / EVIDENCE`
→ `PARAGRAPH INTENT / READER-STATE CONTINUITY`
→ `SENTENCE CONTRAST / RHYTHM`
→ `PUNCTUATION / WORDING`.

## B. Anti-choppiness gate
Flag when several short lines share actor, time/place, focus and one perceptual/decision unit without a real state change.

Repair:
1. test whether full scene is needed;
2. test summary/indirect compression;
3. merge related microbeats;
4. rebuild paragraph/topic continuity;
5. tune sentence shape only afterward.

Never optimize a short-sentence percentage.

## C. Paragraph architecture
A break must buy real work: speaker, time/place, focus, tactic, evidence-status, relation/consent, emphasis/breath or a new thought unit.

One-line paragraphs remain legal when load-bearing; they are not a house style.

## D. POV / evidence
`WHAT WAS OBSERVED? → WHO HAD ACCESS? → WHAT DO THEY KNOW? → WHAT DO THEY INFER? → WHAT IS UNKNOWN? → WHAT MAY NARRATION STATE?`.

Never silently upgrade interpretation to world fact.

### ROOM 917
`WORLD FACT → TRACE → ELENA/JULIAN ACCESS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION STATUS → NEXT ACTION`.

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## E. POV switching
Accept only if the new consciousness supplies unique evidence/access, perception, relationship pressure, irony, decision ownership or emotional cost.

Reject switches whose only purpose is ensemble fairness or momentary information leakage.

## F. Exposition ownership
For information X:
`WHO NEEDS / NOTICES / ASKS / REMEMBERS X? → WHY NOW? → WHY THIS SOURCE? → WHAT CHANGES AFTERWARD?`.

If the only answer is "reader needs it", reroute through action, consequence, environment/trace, dialogue with an objective, summary/indirect narration or sourced document.

### Orbital Youth
Post-money social rules should emerge through lived normality and friction, not explanatory lectures.

## G. Character polyphony
If wording can be swapped unchanged among characters, rebuild from:
`WORLDVIEW + RELATIONSHIP + WANT + STATUS + ATTENTION + OMISSION`.

No universal witty youth voice. No universal robot voice.

## H. Passive agency
Passive constructions are allowed. When institutional language affects rights/consent/resources, ask:
`WHO DECIDED? → WHO ACTED? → WHO COULD REFUSE/APPEAL? → WHO BEARS COST?`.

## I. Crowding / leaping
At revision:
`DETAIL / PROCESS / EXPLANATION → LOAD-BEARING?`.

Keep if it changes/supports causal option space, evidence, relation/consent, authority/responsibility, reader orientation, developing motif or central trajectory. Otherwise compress or leap.

## J. Conflict firewall
A scene is not rejected solely for lacking overt conflict. A quiet scene passes if it changes downstream-relevant knowledge/evidence, relationship/trust, consent/boundary, responsibility, strategy/model, commitment or future option space.

## K. Repetition
For a repeated image, line, action, joke or situation:
`WHAT IS DIFFERENT THIS TIME?`.

Accept when context, pressure, relation, interpretation, evidence-status or meaning develops.

## L. Feedback / audio
`REPORTED EFFECT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES → RETEST`.

Reader/listener repair proposals are not automatically authoritative.

### LESSON ZERO Book One
Development lock remains. Reopen only a targeted layer if current beta/audio/acquisition/continuity evidence repeatedly identifies a defect. If the issue is choppiness, start at paragraph/mode continuity rather than sentence-count statistics.

## M. Nonhuman personhood
Human POV vocabulary does not establish motive or personhood. After independent threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## N. Consciousness-school epistemics
Vivid subjective prose may represent experience faithfully while remaining epistemically limited:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Acceptance condition
Batch 203 is integrated when:
- no short-sentence/paragraph-length KPI is treated as an artistic target;
- narrative mode is routed before line polish;
- POV access/evidence status stay explicit;
- exposition has in-story ownership;
- voices remain person-specific;
- compression preserves causal clarity;
- locked manuscripts stay locked absent new evidence.
