## A. Genre contract
For each book/season:
1. What is the dominant causal engine?
2. What is the primary genre promise?
3. What local question must this book actually answer?
4. Which secondary genre functions are present?
5. What changed state / later payoff does each secondary function buy?

No causal payment = remove or bank.
