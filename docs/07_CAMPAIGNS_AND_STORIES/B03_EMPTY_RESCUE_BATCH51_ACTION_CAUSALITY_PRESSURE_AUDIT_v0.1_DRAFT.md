# B03 — THE EMPTY RESCUE
## Batch 51 Action / Causality / Pressure Audit v0.1

Date: 2026-08-17
Status: WORKING / PRE-PROSE AUDIT
Source production inputs reviewed: `THE EMPTY RESCUE — Scene Cards Part I–II v0.1` and current rescue-geography/voice gate.

## VERDICT
**KEEP ENGINE / DO NOT REBUILD.**

Part I–II already has strong causal progression. Main risks are repetition of command-room geometry, mortality inflation, and treating storm/mountain as a pseudo-villain instead of a real environment with specific constraints.

## 1. CAUSAL SPINE — GREEN
Current chain is strong:

`impossible warning → empty site → later echo → bounded response saves civilians → faster reliance creates secondary loss → OES suppression → apparent stabilization → blocked warning later proves costly → Smith audits his own doctrine → shared protocol → unauthorized bounded rescue saves someone → responder-created detail appears in precursor recording → model changes → controlled test designed`.

This satisfies qualitative progression because the warning changes function across the first twelve chapters:
- false signal;
- useful signal;
- useful + hazardous signal;
- suppressed signal;
- costly absence;
- actionable signal under disobedience;
- causal feedback evidence.

Do **not** replace this with simple “warnings become stronger/more dangerous.”

## 2. OBJECT / MOTIVE SPLIT
### Smith
Object: establish a usable causal/evidence model that protects rescue operations without amplifying the anomaly.
Motivation: responsibility for the consequences of OES doctrine + professional need to reduce uncontrolled variables.

### Jana
Object: retain a warning protocol that saves real people without surrendering local rescue command.
Motivation: duty to casualties/rescuers + ownership of real-world operational consequences.

### Nika
Object: decide when uncertain information deserves action and what she is personally willing to risk when procedure blocks it.
Motivation: responsibility to callers/casualties, not rebellion for its own sake.

Gate: never collapse these into one shared “solve anomaly” motivation.

## 3. ACTION STATE + INFORMATION STATE
Every major rescue/action scene must leave two ledgers changed:

**ACTION STATE** — people moved / access changed / casualty status / team availability / route / command authority / equipment / weather window.

**INFORMATION STATE** — what is now observed, inferred, disproved, source-tracked, or newly uncertain.

Example Ch11:
- Action state: unauthorized bounded local action saves someone; Nika incurs disciplinary exposure.
- Information state: next precursor contains a detail created by that rescue, weakening the external-future-message model.

This dual change is one of the strongest features of the current engine. Protect it.

## 4. SET-PIECE DIFFERENTIATION
Part III onward must not repeat:
`call → command room → dispatch → site → result`.

Require different movement geometries:
1. **toward danger** — field team enters a narrowing weather/access window;
2. **away from danger** — evacuation/retreat becomes constrained by geography;
3. **rescue movement** — casualty extraction where warning changes route or timing;
4. **contested information/access** — physical evidence exists somewhere difficult to reach before weather destroys it;
5. **direct confrontation** — Smith/Jana/OES disagreement becomes operational because one decision must be made now.

At least three of these should appear across Ch13–18 without duplicating the same terrain mechanics.

## 5. LABYRINTH / RESCUE GEOGRAPHY
Use mountain/rescue geography as a causal system, not scenery:

`terrain/weather/communications rule → route/access limitation → tactical choice → consequence`.

Examples of legitimate constraints:
- helicopter unavailable because of visibility/wind, not because “the plot needs no helicopter”;
- valley geometry blocks radio in a specific sector;
- alternate foot approach changes casualty extraction time;
- road closure makes a previously safe deployment path unsafe;
- weather destroys or contaminates a physical trace if not reached within a real window.

Do not write “the mountain wanted them dead.” Subjective language is allowed only as character perception.

## 6. POWER / LEVERAGE MAP
Pressure can be high without shouting or gunfire.

### Jana controls
- local operational command;
- deployment priorities;
- trust of local responders;
- practical terrain knowledge.

### Smith/OES controls
- legacy anomaly records;
- restricted analytic context;
- ability to classify/quarantine signal traffic;
- external investigative leverage.

### Nika controls
- first-contact information;
- chronology of what callers said before later contamination;
- willingness to obey/bend procedure.

### Weather/terrain controls
- access;
- timing;
- line of sight;
- evacuation geometry.

Use this asymmetry in quiet scenes. Avoid generic authority speeches.

## 7. FAVORITE-TACTIC REMOVAL
The best escalation is already present: Smith's favorite tactic is **remove contaminated relation from system**. Ch8–9 proves that suppression itself has cost.

Continue this logic. Before introducing a larger supernatural event, remove or complicate another habitual solution:
- no reliable chronology;
- no clean separation between signal and response;
- no uncontaminated witness;
- no ability to reproduce a test without creating new causal influence;
- no single authority able to optimize both rescue and anomaly containment.

This is stronger than simply increasing body count.

## 8. NO OBVIOUS OFF-SWITCH
Do not reveal a simple rule such as “ignore the calls and loop stops” or “answer exactly this way and future changes.”

Any eventual usable protocol should be earned through accumulated evidence and should have tradeoffs/limits.

## 9. MORTALITY FIREWALL
Ch3 and Ch9 already contain serious irreversible harm. Do not use additional deaths merely to prove escalation.

Escalate through:
- narrower rescue windows;
- responder trust;
- disciplinary exposure;
- jurisdiction/cooperation fracture;
- loss of a verified evidence channel;
- danger to multiple operations caused by one protocol choice;
- inability to know whether intervention creates the evidence being followed.

Death remains available when causally necessary, not as chapter fuel.

## 10. REPUTATION / PRAISE / MOCKERY
Do not tell the reader Smith is legendary, Jana is brilliant, or OES is terrifying through repeated praise.

Competence must be paid by behavior:
- Smith asks the right evidence question and revises his own doctrine when it fails;
- Jana balances rescue utility with responder safety;
- Nika preserves chronology under stress and makes an accountable choice.

Mockery should not deflate the anomaly or competent opposition merely for wit.

## 11. CRISIS / CLIMAX TARGET
Do not pre-commit to a lethal final confrontation.

Preferred abstract climax:
`easy protocol unavailable → rescue need and anomaly-containment need conflict → evidence incomplete but sufficient for bounded choice → Smith/Jana/Nika each contributes non-interchangeable information/agency → decision taken → immediate local rescue/security problem resolved → cost visible → wider ontology remains open`.

This fits ONE MAIN STORY and preserves saga scale for later books.

## 12. PROSE / RHYTHM GATE
For physical rescue:
- use sensory specificity only where it changes orientation, risk or decision;
- slow down near ambiguous/high-cost decisions;
- compress routine logistics already established;
- short sentences are accents, not default action grammar;
- command-room sequences require verbal tactics/subtext, not transcript realism.

## 13. CH13–18 REQUIREMENTS
Before prose authorization, scene cards Ch13–18 should pass:

1. no repeated warning/dispatch geometry without new function;
2. at least one major physical-site sequence where geography changes the evidence problem;
3. at least one action success that genuinely works and complicates the model rather than “everything fails”;
4. at least one quiet high-leverage confrontation where access/authority/evidence is the pressure;
5. midpoint reveal changes the next tactic, not merely lore;
6. Smith's doctrine changes because of evidence, not a speech from Enia;
7. Jana remains local operational authority;
8. Nika retains agency and consequence;
9. no ontology reveal;
10. no coincidence performs the decisive solution.

**B03 Part I–II = GREEN WITH WATCH ON REPETITION.**
