## 1. Scope
This file adds diagnostics. It does **not** reopen LESSON ZERO Book One and does not replace current Founder corrections, Saga Bible authority rules or active reconcilers.

## 2. Evidence ladder for IVDIVO
For every important mystery/metaphysical/system inference:

`OBSERVATION → SOURCE → INTERPRETATION → CONFIDENCE → ALTERNATIVE → TEST / COUNTEREVIDENCE → STATUS UPDATE → ACTION`.

Permitted status labels:
- OBSERVED
- REPORTED
- INFERRED
- HYPOTHESIS
- CORROBORATED
- CONTESTED
- DISPROVEN
- UNKNOWN

Never silently upgrade one status to another between chapters.

## 3. Proof ceiling
Before drafting a mystery book define:
1. what can be demonstrated locally by the ending;
2. what remains plausible but unproven;
3. what the book is forbidden to prove because it belongs to later saga ontology.

A finished book does not require a finished cosmology.

## 4. Conscious-robot gate
For each named conscious robot:
- What does it want independent of the human protagonist?
- What relationship does it have that does not involve the protagonist?
- What can it refuse?
- What does its embodiment make possible/impossible?
- How do humans miscategorize it?
- What evidence would make them revise that category?

Mandatory firewall:

`PREDICTED ROBOT BEHAVIOR ≠ ROBOT MOTIVE ≠ ROBOT CONSENT`.

If the robot can be replaced by a terminal without changing desire, refusal, relationship or consequence, personhood is underwritten.

## 5. Human prediction / infrastructure gate
For systems that infer human behavior:

`LIKELY TO YIELD / HELP / WAIT / COMPLY` does not mean `WANTS TO`, `CONSENTS TO`, or `SYSTEM MAY SPEND THAT COMPLIANCE`.

The strongest conflict is allowed to occur when prediction is technically accurate but normative allocation is wrong.

## 6. Specialist consciousness-school gate
High technology does not imply mature consciousness science.

Use:
`PRACTITIONER OBSERVATION → REPRODUCIBLE PRACTICE EFFECT → SCHOOL MODEL → RIVAL MODEL → TEST/LIMIT → POSSIBLE ONTOLOGY`.

Also track:
- lineage;
- years of practice;
- teacher/student judgment;
- reproducibility conditions;
- failure/false positive;
- disagreement between schools;
- what mainstream orbital science accepts versus what remains niche.

A robot/AI may analyze records at enormous scale; it cannot automatically manufacture the lived training history of thousands of human practitioners.

## 7. Ensemble intelligence gate
For a climax or complex investigation, distribute functions when appropriate:
- Agent A — observes anomaly.
- Agent B — preserves evidence/provenance.
- Agent C — proposes interpretation.
- Tool/robot — reveals a constraint or alternative computation.
- Agent D — contributes lived experience/context.
- Countermodel — gives strongest reason not to act.
- Decision owner — makes bounded choice under uncertainty.

This keeps ONE MAIN STORY without turning one protagonist into the only mind in the book.

## 8. Archive / testimony gate
Every recovered record has a production history:

`EVENT → WHO RECORDED/TOLD → WHEN → PURPOSE → WHAT WAS OMITTED → FORMAT/MEDIUM → WHO LATER RECEIVED IT → WHAT MODEL THEY BUILT → WHAT THEY DID`.

An official archive can be canonically official and still factually incomplete or wrong.

## 9. Causal-overgeneration gate
If an investigator develops a theory that explains every datum, ask:
- What would falsify it?
- Which datum currently strains it?
- What alternative explains at least some evidence?
- Which next test discriminates between them?

If no possible result can count against the theory, it cannot be upgraded to fact.

## 10. Orbital Youth / post-money gate
Do not let Earth-default causal assumptions fill gaps:
- no wage/rent/credit motivation by default;
- no consumer-status shorthand;
- no AI servant default.

Show ordinary coordination through lived constraints:
`TIME / TRUST / ATTENTION / CONSENT / UNIQUE ROLE / MISSION SLOT / RELATIONSHIP / REPUTATION / RESPONSIBILITY / EMBODIED EXPERIENCE`.

## 11. Place/world gate
Orbital architecture earns prose when it carries reasoning or social standing:

`PLACE RULE / MARKER / INTERFACE → WHAT CHARACTER CAN INFER OR DO → WHO HAS ACCESS/STANDING → CHOICE → CONSEQUENCE`.

Do not describe another ring, transit system or gravity zone merely because it is impressive.

## 12. POV gate
For every reveal ask:
- Which mind could know this?
- Which mind actually sees it?
- What has the focal character inferred rather than learned?
- Is a withheld fact honestly unavailable to the focal character?
- What reader model must be repaired when viewpoint changes?

## 13. Dialogue/subtext gate
Track both content and positioning:

`WHAT IS SAID → WHO IS BEING POSITIONED AS WHAT → ACCEPT / RESIST / REVERSE → RELATIONSHIP CHANGE`.

Teen/adult arguments often concern not only procedure but status: `child vs operator`, `student vs colleague`, `outsider vs stakeholder`.

## 14. LESSON ZERO Book One
No automatic rewrite. Apply only if a current passage demonstrably:
- confuses behavior with motive;
- launders an inference into fact;
- cheats focal knowledge;
- makes one character hold all knowledge/functions;
- or uses an in-world source as transparent canon.

Absent such evidence, development lock remains.

## 15. Future-book acceptance test
A future IVDIVO book passes this Herman layer if:
1. local causal engine is clear;
2. key explanations remain falsifiable until earned;
3. source/provenance is trackable;
4. people/robots remain larger than categories;
5. the ensemble can distribute cognition without fragmenting ONE MAIN STORY;
6. specialist-school claims remain epistemically bounded;
7. local resolution does not require premature cosmological revelation.
