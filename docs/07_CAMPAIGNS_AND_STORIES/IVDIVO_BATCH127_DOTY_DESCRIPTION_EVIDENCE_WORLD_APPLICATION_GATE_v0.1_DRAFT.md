## Governing rule
Description is not a neutral camera feed. It is selected attention belonging to a situated consciousness.

`WORLD → POV/EMBODIMENT FILTER → SELECTED PARTICULAR → READER MODEL → ACTION / INFERENCE / RELATION CHANGE`.

## A. Orbital Youth
### PASS when
- the city is revealed through what a specific character needs, notices, misreads, ignores or cannot access;
- ordinary post-money abundance is shown through lived defaults rather than exposition;
- non-fungible stakes such as time, trust, consent, role, unique opportunity, belonging and reputation become naturally salient;
- environment affects available action.

### FAIL when
- description is a technology catalogue;
- every POV notices the same impressive infrastructure;
- the paragraph exists mainly to prove how advanced the civilization is;
- `allocation/access/priority/contribution` silently function as disguised purchasing power.

## B. Conscious robots
### PASS when
`EMBODIMENT + OWN WANT + CURRENT TASK + RELATIONSHIP + KNOWLEDGE LIMIT → SALIENCE`.

A robot may have unusual sensors, but attention still has priorities and omissions.

### FAIL when
- all robots speak/notice through the same generic sensor-feed register;
- sensor availability becomes omniscient understanding;
- human description of robot behavior is treated as proven robot motive;
- embodiment change is treated as “becoming more human.”

## C. Mystery / clue architecture
Separate:
1. raw trace;
2. noticing;
3. description;
4. interpretation;
5. alternative explanation;
6. corroboration;
7. action.

**No metaphor, image, intuition, mood, or aesthetic coherence may raise evidence status.**

Exact fields — source, time, order, dimensions, hashes, provenance — are protected from literary beautification.

## D. ROOM 917
Use descriptive attention to strengthen Elena’s professional POV:
- she should notice acoustic/material facts because they matter to her current test;
- Julian may notice Elena, status, architecture or danger differently;
- romantic attention may alter what each notices and what each chooses to disclose.

But:

`ATTRACTION / TRUST / INTIMACY ≠ CORROBORATION`.

A sensual or emotionally loaded perception of the wall, receiver, amber lamp or voice cannot substitute for evidence handling.

## E. B07 / distributed nonhuman life
Before personhood threshold:
`pattern → observation → interpretation → competing model → independent test`.

After sufficient personhood evidence:
`ENTITY OWN MODEL / PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Description of beauty, coherence or “living” pattern alone is not personhood proof.

## F. Consciousness-practice schools
Keep four levels distinct:
- reported subjective experience;
- reproducible practice effect;
- school interpretation;
- possible ontology.

Intense visual/somatic description can be valid first-person evidence of experience while remaining neutral about metaphysical explanation.

## G. Anti-choppy prose gate
When a descriptive passage feels fragmented, do not first lengthen sentences.

Repair order:
`SCENE FUNCTION → POV ATTENTION → DETAIL SELECTION → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

Merge one-line paragraphs when actor/time/place/focus remain continuous and no deliberate contrast/revelation justifies the break.

## H. Scene-level checklist
For each descriptive block ask:
1. Who notices?
2. Why now?
3. What can this body/skill set detect?
4. What is excluded from attention?
5. What relation between details is developing?
6. What changes for the reader or character after the block?
7. Is uncertainty preserved where knowledge is incomplete?

If 5–6 have no answer, compress heavily.
