# IVDIVO BATCH 210 — STANISLAVSKI CHARACTER ACTION / DIALOGUE / RHYTHM APPLICATION GATE

**Status:** DRAFT / manuscript-facing production gate  
**Date:** 2026-08-22

## 1. Scene causal-action gate
Before line editing, record:
`GIVEN CIRCUMSTANCES | OWNER | PRESENT TASK / WANT | PARTNER / COUNTERFORCE / SUPPORT | TACTIC | RESPONSE | ADAPTATION | EXIT STATE | NEXT DEPENDENCY`.

If response does not alter tactic/model/relationship/evidence/option space, check whether the scene is static, redundant or should be compressed.

## 2. Result-posing gate
Reject scenes that tell the character to perform the desired authorial result directly:
- “show fear”;
- “show growth”;
- “show chemistry”;
- “show authority”;
- “show guilt.”

Repair through circumstances, present objective, relationship, action and actual response.

## 3. Dialogue partner gate
For each load-bearing line:
`WHAT DOES SPEAKER WANT FROM THIS PARTNER NOW? → WHAT TACTIC DOES THE LINE USE? → WHAT DID PARTNER ACTUALLY DO/UNDERSTAND? → WHAT CHANGES NEXT?`

If the sole purpose is “reader needs information,” route to exposition/narration/document/rebuilt scene.

## 4. Direct-vs-summary router
Use direct real-time dialogue when exact wording changes:
- consent/boundary;
- evidence status/access;
- trust/disclosure;
- authority/standing;
- decision/commitment;
- relationship terms;
- next tactic.

Routine conversation/process/logistics may be summary/indirect.

## 5. Emotion gate
`PERSONAL MEMORY = OPTIONAL INPUT`.

For emotional weakness inspect first:
`GIVEN CIRCUMSTANCES → WANT → RELATIONSHIP → KNOWLEDGE → EMBODIMENT → TACTIC → IMAGINATION/OBSERVATION → OPTIONAL PERSONAL RECALL`.

Do not add traumatic backstory merely to intensify emotion.

## 6. Beat-to-prose gate
Use beats/tasks to diagnose causality only.

Then recombine:
`ANALYTIC MICROBEATS → ONE PERCEPTUAL / DECISION / COMMUNICATION UNIT → NATURAL PARAGRAPH`.

Forbidden default:
`beat. reaction. gesture. thought. new beat.`

## 7. Pause / emphasis gate
A one-line paragraph, dash, ellipsis or fragment must buy a real function: revelation, decision, interruption, contrast, comic timing, change of focus or protected silence.

`PAUSE / BREAK WITHOUT FUNCTION → MERGE / REWRITE TEST`.

## 8. Inner / outer rhythm
Do not map emotional intensity directly to sentence length.

`INNER PROCESS SPEED ≠ OUTER MOTION SPEED ≠ SENTENCE LENGTH`.

Use paragraph continuity and sentence contrast to create reader effect.

## 9. ONE MAIN STORY / through-line
Each scene's exit state must create/limit a later action or choice.

`LOCAL SCENE QUALITY ≠ BOOK UNITY`.

If a sequence consists of beautiful independent fragments, inspect missing causal dependencies before adding transitions or theme explanations.

## 10. Mystery / evidence
Character action, confidence, silence, emotion or self-report do not become evidence automatically.

`BEHAVIOR / SPEECH → MOTIVE MODEL → ALTERNATIVE MODEL → DISCRIMINATING TRACE / TEST → STATUS UPDATE`.

For `ROOM 917`:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## 11. Conscious robots / nonhuman agents
Do not require human gesture/emotion memory/physiology to prove personhood.

`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → ACTION/COMMUNICATION → CONSEQUENCE`.

Embodiment changes affordances and salience; it does not rank humanity.

## 12. Orbital Youth
Differentiate teens through:
`WHAT THEY NOTICE → WHAT THEY WANT → WHAT THEY CONSIDER SUFFICIENT EVIDENCE → TACTIC → ADAPTATION`.

Do not use five interchangeable sarcastic voices.

## 13. B07 personhood
Human classification is not entity identity.

After independent threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## 14. LESSON ZERO Book One
Standing verdict: **development lock remains**.

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Do not retrofit explicit objectives, gestures or pauses into already functioning prose merely to make Stanislavski mechanics visible.

If future reader/audio evidence finds a dead conversation:
1. verify given circumstances;
2. verify present want/task;
3. verify actual partner response;
4. verify tactic adaptation;
5. only then line edit.

## 15. Framework invisibility release gate
A repair fails if the reader can feel the technique more strongly than the character/action.

`OBSERVED DEFECT → RELEVANT TOOL → REPAIR → FRAMEWORK DISAPPEARS → RETEST`.

## Release condition
Pass only if:
- scene causal state is clearer;
- character/partner interaction becomes more specific;
- evidence/consent/personhood boundaries remain intact;
- paragraph continuity improves or remains intact;
- no new gesture/fragment/choppiness monoculture is introduced;
- ONE MAIN STORY dependencies remain stronger than local technique display.
