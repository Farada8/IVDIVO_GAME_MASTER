# IVDIVO — BATCH 212 APPLICATION GATE
## Vorhaus — Character-Owned Humor · Shared Ground · Escalation · Feedback

**Status:** APPLICATION GATE / NO AUTOMATIC MANUSCRIPT MUTATION

## Global law
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Humor is subordinate to character truth, personhood, consent, causal integrity and ONE MAIN STORY.

## Character-owned humor
For every recurring character:
`WORLDVIEW + ATTENTION + RELATIONSHIP + PRESENT WANT → HUMOR LENS`.

Reject interchangeable smart banter. If a line can be reassigned unchanged among several characters, test whether it is authorial leakage.

## Orbital Youth
Future youth humor should emerge from future norms, role, training, relationships and what the teen considers embarrassing, prestigious, unfair or normal.

No current-Earth teen slang layer as the sole marker of youth.

No body/disability/nonhuman embodiment as automatic comic flaw.

Microhumor may echo macro pressures—authority, autonomy, consent, responsibility, privacy—without forcing every interaction into conflict.

## ROOM 917
Banter and irony may change trust, disclosure, boundaries and investigative tactics.

Standing evidence firewall:
`JOKE / SARCASM / TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

A joke that relies on specialized historical/technical knowledge needs actual shared ground or contextual setup.

## Conscious robots / nonhuman persons
No universal robot-humor voice.

Humor may arise from embodiment, protocol ambiguity, culture, relationship, timing or model mismatch only if personhood remains intact.

`NONHUMAN EMBODIMENT ≠ COMIC FLAW`.

## B07 — THE UNLISTED CITY
Distributed nonhuman life cannot become a joke mechanism or human comic foil after personhood threshold.

`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## Running-gag gate
Retain recurrence only when at least one changes:
- source / speaker;
- relationship meaning;
- stakes / cost;
- evidence status;
- tactical context;
- reader understanding.

Otherwise compress or cut.

## Coupled escalation gate
Prefer:
`CHARACTER FIX → UNINTENDED CONSEQUENCE → NEW FIX → GREATER COUPLING / COST`.

Reject:
`SCENE FEELS FLAT → AUTHOR ADDS RANDOM DANGER / HUMILIATION / DEATH`.

## Secondary-strand gate
Humor subplot must pay:
`LOCAL CHANGE → A-STORY CONSEQUENCE / REFRAME / PAYOFF`.

Good jokes that do not pay belong in the idea bank.

## Beta-reader humor questions
Ask:
- Which exact lines/behaviors made you laugh?
- Which felt like the same authorial voice from another character?
- Which required knowledge you did not have?
- Where did the setup feel too long or too short?
- Which running joke improved or decayed on repetition?
- Did humor undercut a serious consent/evidence/aftermath moment?

Reader effect is evidence; suggested repair is a hypothesis.

## Seriousness preservation
Do not automatically place a joke immediately after:
- consent violation;
- major injury/death;
- personhood threshold;
- moral decision;
- grief or irreversible consequence.

Comedy may coexist with serious material, but the aftermath must retain weight when the story requires it.

## Anti-choppiness gate
Humor beats do not dictate typography.

`SCENE / COMMUNICATION FUNCTION → PARAGRAPH INTENT → READER-STATE CONTINUITY → SETUP/PAYOFF RELATION → SENTENCE RHYTHM / CONTRAST → WORDING`.

`JOKE BEAT / CALLBACK / PAYOFF / REACTION ≠ SENTENCE BREAK`.

Do not implement subtext or comedy as `line → microgesture → one-line thought → next line` by default.

## LESSON ZERO
No global rewrite. Apply only if current beta/audio/text evidence identifies:
- universal snark voice;
- humor undercutting protected seriousness;
- repeated running gag without new function;
- confusing setup/payoff shared ground;
- paragraph fragmentation caused by joke timing.
