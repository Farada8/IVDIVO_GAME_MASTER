# ACCEPTANCE TEST
A Booker-derived repair is admissible only when all are true:
1. it fixes an observed current defect;
2. it preserves canon and evidence status;
3. it improves causal dependency or reader model;
4. it does not add a scene merely to satisfy a pattern;
5. it preserves independent personhood/consent;
6. it states what would falsify the pattern diagnosis;
7. it passes regression against downstream dependencies.
