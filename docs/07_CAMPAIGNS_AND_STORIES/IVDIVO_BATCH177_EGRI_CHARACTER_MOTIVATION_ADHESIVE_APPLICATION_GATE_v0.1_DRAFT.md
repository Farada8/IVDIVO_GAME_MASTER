# IVDIVO — BATCH 177 APPLICATION GATE
## EGRI — CHARACTER · MOTIVATION · ADHESIVE · TRANSITION

**Status:** PRODUCTION GATE / ADDITIVE / NOT STORY CANON  
**Source:** Lajos Egri, *The Art of Creative Writing*  
**Pass:** 142

## 1. Use only after a concrete defect appears
Do not reopen a locked manuscript merely because this mechanism exists.

Standing law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Use this gate when current text/reader/audio evidence shows:
- unexplained behavior reversal;
- generic ensemble reactions;
- repeated tactic with no adaptation;
- weak reason for staying involved;
- strawman opposition;
- transition that feels abrupt;
- thematic sermon unsupported by consequences;
- suffering inserted mainly to purchase sympathy.

## 2. Character-causality card
For the affected scene/sequence write:

`CHARACTER`  
`CURRENT WANT / RESPONSIBILITY`  
`VALUE A`  
`VALUE B / COMPETING PRIORITY`  
`RELATIONSHIP / STATUS`  
`WHAT THEY KNOW / BELIEVE`  
`CURRENT COST / RISK`  
`TACTIC`  
`WORLD / PARTNER RESPONSE`  
`OUTCOME`  
`MODEL / RELATIONSHIP UPDATE`  
`NEXT CHOICE`

If the behavior still cannot be explained, repair the cause before line editing.

## 3. Contradiction test
When the character behaves “oppositely”:
- changed circumstance?
- changed relationship/status?
- changed evidence?
- changed cost?
- competing value won?
- genuine character change?
- author convenience?

Do not solve with extra exposition until the causal variable is known.

## 4. Adhesive test
Ask:
`WHY DOES THIS PERSON REMAIN CAUSALLY INVOLVED?`

Prefer:
- responsibility already accepted;
- relationship;
- evidence ownership;
- consequences of prior choice;
- shared mission;
- access/authority;
- physical/world constraint;
- consent-based cooperation.

Reject as automatic patches:
- kidnapping;
- surprise debt/poverty;
- random new villain;
- forced romantic proximity;
- arbitrary death threat.

## 5. Countermodel test
For every major opponent/counterforce:
1. What real benefit does their model protect?
2. What evidence supports it?
3. Who depends on it?
4. What is its blind spot / cost?
5. What can falsify or weaken it?

No `hero correct / opponent stupid` construction.

## 6. Transition test
For a major turn:
`OLD STATE → LOAD-BEARING PRESSURE / EVIDENCE → REASSESSMENT → OPTION SET CHANGE → CHOICE → NEW STATE`.

If the reader can infer intermediate movement, use summary/ellipsis. Do not dramatize every emotional rung.

## 7. Scene admission consequence
A scene does not qualify merely because conflict is present.

It must change at least one:
- action/operational state;
- knowledge/evidence;
- relationship/trust;
- consent/boundary;
- authority/access;
- responsibility;
- strategy/model;
- future option space.

If not: `MERGE / SUMMARY / DELETE / REBUILD` before prose polish.

## 8. LESSON ZERO
No broad revision authorized.

Only patch if current evidence identifies a specific:
- character-causality break;
- relation/tactic duplication;
- abrupt unearned reversal;
- straw countermodel;
- state-neutral scene;
- paragraph-level choppiness caused by microbeat over-separation.

Do not retrofit every character with an Egri “deep motive.”

## 9. Orbital Youth
Youth differentiation:
`WHAT THEY VALUE → WHAT THEY NOTICE → WHAT COST THEY ACCEPT → WHAT TACTIC THEY TRY → HOW THEY ADAPT`.

No mandatory wound, maximal conflict or financial stakes.
Post-money nonfungible stakes:
`TRUST / CONSENT / TIME / RESPONSIBILITY / ROLE / ACCESS / PRIVACY / MASTERY / BELONGING / RELATIONSHIP / UNIQUE OPPORTUNITY`.

## 10. ROOM 917
Relationship pressure may change disclosure and investigative tactic.
It does not change clue truth.

`RELATIONSHIP STATE ≠ EVIDENCE STATUS`.

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## 11. B07 — THE UNLISTED CITY
Do not use human opposition/importance as proof of nonhuman personhood.

After independent personhood threshold:
`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

The entity cannot remain only the object through which Kyra learns a lesson.

## 12. Conscious robots
Egri's universal human ego theory is not applicable by default.

Personhood:
`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

## 13. Consciousness schools
No psychological craft theory receives ontological authority.

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 14. Anti-choppiness gate
Do not map dramatic pressure to typography.

`BEAT MAP ≠ SENTENCE BREAK`.

If several beats form one perceptual/decision unit, first test a coherent paragraph.

Standing order:
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH TOPIC/READER-STATE → INNER/OUTER TEMPO → SENTENCE RHYTHM/CONTRAST → WORDING`.

## 15. Acceptance
PASS only if the repair:
- improves causal legibility;
- preserves independent personhood;
- does not mutate evidence status;
- does not add conflict merely to satisfy a framework;
- does not introduce new canon without authority;
- does not create new paragraph/sentence fragmentation;
- passes regression against neighboring scenes and ONE MAIN STORY.
