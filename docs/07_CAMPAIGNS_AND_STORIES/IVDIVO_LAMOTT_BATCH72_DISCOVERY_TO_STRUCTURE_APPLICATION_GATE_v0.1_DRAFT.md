# IVDIVO — LAMOTT BATCH 72 APPLICATION GATE
## Discovery → Structure → Prose

Status: WORKING / ADDITIVE PRODUCTION CONTROL
Date: 2026-08-18
Source: Anne Lamott, *Bird by Bird* — W010 strict lifecycle complete.

# VERDICT
Lamott does **not** justify reopening locked manuscripts or replacing the existing Narrative OS with discovery-only writing. Her value is procedural: protect emergence during generation, then apply ruthless causal and line-level validation afterward.

# 1. MASTER PASS ORDER
Use this sequence unless a specific defect requires a narrower route:

`DISCOVERY / GENERATION → HOT-SPOT EXTRACTION → CANON FIREWALL → ONE MAIN STORY → CAUSAL TREATMENT → SCENE ACCEPTANCE → POV / KNOWLEDGE → DIALOGUE / SUBTEXT → PARAGRAPH INTENT → SENTENCE RHYTHM → WORDING → READER TEST`.

Do not run the complete 100-agent Writers’ Room as a simultaneous sentence-by-sentence approval committee during first generation.

# 2. LESSON ZERO BOOK ONE
Development lock remains in force.

A completed new craft source is not evidence that the manuscript needs another development rewrite. Reopen a structural layer only if:
- a current text defect is demonstrated in the latest master;
- multiple blind readers reproduce the same effect problem;
- continuity/canon has materially changed;
- a protected payoff fails in the actual manuscript.

Otherwise use the new gates only for future diagnostics and line-level regression checks.

# 3. FUTURE IVDIVO / ORBITAL YOUTH
## Ordinary-life generation
Permit exploratory scenes built from small lived moments: commute, shared meal, repair, training, awkward responsibility, friendship, attraction, privacy disagreement, robot-human negotiation.

Then require the scene to survive:
`what changed? → who now wants something different? → which later action/relationship/evidence state depends on it?`

If nothing downstream changes, compress/merge/delete regardless of how attractive the vignette is.

## Post-money civilization
Demonstrate post-money normality through lived details rather than exposition.

Allowed nonfungible stakes include:
- another person’s time or consent;
- trust;
- a unique mission/training opportunity;
- responsibility;
- mastery;
- reputation;
- belonging;
- access tied to competence/safety rather than purchasing power;
- irreversible lived experience;
- relationship repair.

Forbidden regression:
`salary / rent / consumer status / credits-as-money / points-as-money` unless later canon explicitly creates a narrow accounting system and distinguishes it from money.

# 4. CONSCIOUS ROBOTS
Discovery drafting may reveal behavior not anticipated by the outline. Preserve it when it is:
- compatible with robot personhood and embodiment;
- motivated by the robot’s own goals/relationships;
- causally credible;
- not merely a device for human character growth.

Red Team question:
`If the robot were replaced by a smart terminal, would consent, relationship, refusal, motive and consequence materially change?`
If no, personhood is not yet written.

# 5. CONSCIOUSNESS / PRACTICE SCHOOLS
Lamott’s intuition, spiritual language and unconscious metaphors are **not** ontology evidence.

Maintain:
`practitioner observation → reproducible practice effect → school interpretation → competing interpretation → possible ontological conclusion`.

AI/robotic analytic power may process evidence quickly but cannot manufacture decades of embodied practitioner experience. Do not erase the human-practitioner bottleneck.

# 6. CHARACTER DISCOVERY WITHOUT PLOT PUPPETS
During first prose, a character may produce an unexpected response.

Router:
`unexpected behavior → is it true to existing person/world? → what prior evidence supports it? → does it alter causal architecture?`

If credible, update the model and downstream beats.
If not credible, remove it.
Never keep a beat solely because an outline needs it.

# 7. PLOT-TREATMENT REPAIR
When a draft has good characters/scenes but weak whole-book movement, do not start with line edits.

For each chapter record:
`START STATE → OWNER / WANT → PRESSURE → BULL’S-EYE CHANGE → END STATE → WHY THIS END STATE CREATES / CONSTRAINS THE NEXT CHAPTER`.

If the author must orally explain a relationship, motive, causal bridge or missing fact for the book to make sense, put that function into the manuscript or rebuild the sequence.

# 8. DIALOGUE / VOICE
Exact dialogue earns real-time space when exact wording changes:
`trust / consent / evidence / relationship / authority / emotion / decision`.

Routine/process/repeated conversation may become indirect dialogue or summary.

Youth voice is not contemporary Earth slang. Build it from:
`attitude → normal assumptions → attention → social risk → relation-specific tactic → rhythm`.

Robot voice is not one “AI register.” It changes by person, purpose, relationship and stakes.

# 9. “ОБРУБКИ” / LINE EDITING
Do not repair choppy prose by targeting average sentence length.

Use:
`SCENE NECESSITY → SHOW/TELL → POV DISTANCE → DIALOGUE MODE → PARAGRAPH INTENT → SENTENCE RHYTHM → WORD`.

If several short paragraphs continue one thought, tactic or attention unit, first test whether they should be one paragraph.
If a micro-action does not deserve full dramatization, compress the scene rather than glue sentence fragments together cosmetically.

# 10. FEEDBACK ROUTER
External reader response:
`reported effect = evidence`
`proposed repair = hypothesis`.

Track repeated effects across readers. Diagnose before implementing suggestions.

# 11. PROTECTED FIREWALLS
Do not derive IVDIVO rules from Lamott that require:
- likable narrators;
- mandatory wounds/illness/death;
- mandatory character transformation;
- climax as killing/healing/domination;
- spiritual intuition as fact;
- 1990s publishing economics as current market guidance.

# FINAL PRODUCTION PRINCIPLE
**PROTECT DISCOVERY, THEN BECOME RUTHLESS ABOUT STRUCTURE.**

This is additive to the existing IVDIVO Writing Production Canon and does not supersede Founder canon corrections.
