# IVDIVO — BATCH 65 READER-EFFECT / THEME / ANTICIPATION APPLICATION GATE

Date: 2026-08-17  
Status: ADDITIVE PRODUCTION GATE / DOES NOT OVERRIDE CANON

## PURPOSE
Use the transferable reader-effect mechanisms from Karl Iglesias Chapters 4–7 without importing his 2005 screenplay-market formulas into IVDIVO novels/audio fiction.

## A. PRE-ARCHITECTURE
1. State ONE MAIN STORY causal engine in one sentence.
2. State the dominant reader experience promise separately.
3. State the thematic question, not the answer.
4. Build at least one competent countermodel.
5. Define what local ending condition makes the book complete.

If reader promise and causal engine describe two different books, repair before prose.

## B. MAJOR CHARACTER CHECK
For each PRIMARY/SECONDARY MAJOR character:
- concrete current want;
- reason this matters now;
- characteristic first tactic;
- characteristic second tactic after resistance;
- one relationship where behavior changes;
- principal reader connection route: empathy / fascination / mystery / competence / relationship / moral uncertainty;
- what the character can refuse.

Do not add trauma, illness, victimhood, children/animal sympathy or sacrifice merely because connection feels weak.

## C. SCENE READER-EFFECT DOUBLE ENTRY
For every high-value scene record two rows:

`STORY STATE:` what changes in action / access / evidence / relationship / commitment?  
`READER STATE:` what changes in expectation / question / confidence / hope / worry / understanding?

A scene can succeed strongly on one row and modestly on the other. It does not need to maximize both.

## D. ANTICIPATION LEDGER
Track only meaningful promises:
- known goal;
- plan;
- warning;
- future appointment/event;
- relationship promise;
- system rule likely to matter;
- visible setup;
- declared risk.

For each: `PAY OFF / TRANSFORM / EXPLICITLY CLOSE`.

Do not create new future promises merely to keep a hook alive.

## E. MYSTERY / FAIR SURPRISE
Required chain:
`TRUE FACT → SOURCE → INTERPRETATION → READER MODEL → NEW EVIDENCE → REVISED MODEL → ACTION`.

Red herring must remain true after the reveal.  
POV may be mistaken; narration may not cheat.  
School interpretation is not ontology.  
Robot predicted behavior is not robot motive or consent.

## F. THEME
After outline:
- delete all explicit theme speeches in a diagnostic copy;
- ask whether choices/consequences still make the thematic conflict legible;
- if not, repair story causality before restoring dialogue.

A supporting character must remain a person, not a thematic placard.

## G. POST-MONEY ORBITAL YOUTH FIREWALL
Increasing stakes may use:
- trust;
- consent;
- belonging;
- relationship;
- reputation;
- real responsibility;
- unique mission/role;
- non-fungible time/opportunity;
- safety;
- access that cannot simply be manufactured.

Forbidden default substitution:
- wages;
- rent;
- credits/status points as currency;
- consumer scarcity for ordinary manufacturable goods.

## H. CONSCIOUS ROBOT PERSONHOOD
Do not use automatic empathy shortcuts such as helplessness, petlike behavior or secret humanity.

Require:
`independent want + independent relationships + relation-specific communication + consent/refusal + capability limits + consequences of own choices`.

Replacement test: if the named robot can become a smart terminal with no causal/relational change, rewrite.

## I. STRUCTURE FUNCTION, NOT STATIONS
Do not require:
- fixed inciting percentage;
- mandatory point of no return;
- midpoint at 50%;
- darkest moment;
- final physical showdown;
- twist ending.

Require instead:
`durable disturbance → changing strategy/commitment → escalating or changing consequence → bounded decisive action → local resolution/aftermath`.

## J. STYLE / LINE EDIT
Never translate `reader engagement` into `more short sentences`.

Repair order:
`causal engine → scene necessity → show/tell mode → POV → dialogue mode → paragraph intent → sentence rhythm → wording`.

A quiet tense passage may need expansion; a routine exchange may need summary; an already-legible emotional beat may need deletion rather than emphasis.

## LESSON ZERO STATUS
No reopening of Book One development lock from Batch 65 alone. A new edit requires a concrete defect verified in the current manuscript or external reader evidence.

## FUTURE BOOK ACCEPTANCE TEST
A future IVDIVO book passes this gate when:
1. the local story can be stated independently from world exposition;
2. reader promise is clear;
3. major characters use different tactics under shared pressure;
4. countermodels are competent;
5. anticipation promises are paid or transformed;
6. mystery remains source-fair;
7. climax resolves the local engine without requiring maximum spectacle;
8. ending closes the book before opening the saga again.
