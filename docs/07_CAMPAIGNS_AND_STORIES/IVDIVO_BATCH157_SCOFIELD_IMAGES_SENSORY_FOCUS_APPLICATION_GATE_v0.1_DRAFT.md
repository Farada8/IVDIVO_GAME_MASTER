## Standing law
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

This craft layer does not reopen development-locked `LESSON ZERO` by itself.

## A. Scene description admission
Before expanding description in real time:
1. What is the scene event?
2. Who is the POV / attention owner?
3. What is their current want / task / relationship pressure?
4. Which 1–3 particulars are salient to that person now?
5. What does the image sequence change in reader orientation, relation, inference, evidence, or choice?

If nothing changes, use less description or keep only the strongest lived-world detail.

## B. Paragraph architecture / choppiness
Do not implement sensory intensity as fragment density.

Repair order:
`SCENE FUNCTION → EVENT TARGET → POV ATTENTION → SELECTED PARTICULARS → CONTRAST / RELATION → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`

Merge image fragments when they are one continuous perceptual unit. Preserve a one-line image only when it creates real contrast, revelation, pause, timing, or end-weight.

## C. Mystery / forensic layer
Maintain two layers:
- literal trace/evidence data;
- POV literary rendering.

`VIVID DESCRIPTION / METAPHOR / EMOTIONAL ASSOCIATION ≠ EVIDENCE STATUS UPGRADE`.

For ROOM 917 this applies to recorder output, contact-mic findings, wall measurements, plans, timestamps, switchboard behavior and all clue-SFX.

`TRUST / ATTRACTION / KISS / SILENCE / IMAGE ASSOCIATION ≠ CORROBORATION`.

## D. Orbital Youth
World detail enters scene via:
`WORLD RULE / EMBODIMENT → PERSON-SPECIFIC NOTICE → AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

Do not spend a descriptive paragraph proving that the orbital civilization is advanced. Show what a young person does not notice because it is normal, and what they notice sharply because it is scarce/nonfungible: time, consent, trust, privacy, role, unique access, relationship, reputation, mastery or responsibility.

## E. Conscious robots / nonhuman persons
No generic `sensor-feed voice`.

Use:
`EMBODIMENT + OWN PRIORITY + CURRENT TASK + RELATIONSHIP + KNOWLEDGE LIMIT → SALIENCE`.

Rich sensing does not imply access to another person's motive or internal state.

## F. B07 / distributed life
Before personhood threshold:
`PATTERN / TRACE → OBSERVATION → ALTERNATIVE MODELS → INDEPENDENT TEST`.

After personhood threshold:
`ENTITY'S OWN MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Human visual/emotional response to the entity does not substitute for independent personhood evidence.

## G. Consciousness schools

`EXPERIENCE INTENSITY ≠ ONTOLOGICAL STATUS`.

Preserve:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## H. LESSON ZERO
No global prose pass is authorized.

Only inspect locally if there is concrete evidence of:
- generic camera description;
- tech/world catalogue blocking scene movement;
- image fragments producing choppy paragraphing;
- metaphor mutating clue/evidence meaning;
- redundant thematic explanation after a strong image already carries the meaning.

## Acceptance test
A descriptive passage passes when:
1. its attention belongs to the POV/person;
2. its details are selective rather than checklist-like;
3. images focus or transform scene meaning;
4. evidence facts remain intact;
5. paragraph/sentence architecture matches the continuous perceptual unit;
6. removal would materially reduce orientation, relation, inference, reader reward, or causality.
