## Purpose

Apply CRAFT-016 to the current Book One state so new craft research improves the novel without reopening already-validated architecture by default.

## Current production state

Book One is treated as:

`DEVELOPMENT-LOCKED WORKING NOVEL → TARGETED LINE/PROSE REGRESSION → BLIND READER VALIDATION → COPY/SUBMISSION PREP`

Source hierarchy:

1. v0.16 Final Development / Story Gate — structural source of truth;

3. v1.0 Chapter Map and Production/Submission Dossier — declared dramatic function;
4. earlier audits — historical evidence only until reverified on current text.

## Editorial rule

A newly studied craft principle does not automatically justify rewriting the manuscript.

Every proposed change must identify:

`CURRENT DEFECT → CURRENT-TEXT EVIDENCE → SOURCE/MECHANISM → EXPECTED READER BENEFIT → CONTINUITY RISK → PATCH SCOPE → REGRESSION CHECK`.

Without current-text evidence, the change remains a craft note, not a manuscript patch.

## Structural lock

Do not cut, merge, replace or reorder a chapter unless at least one condition is met:

- current causality is demonstrably broken;
- continuity is demonstrably broken;
- a character decision is unsupported by current text;
- the main story loses its objective/pressure/payoff chain;
- independent beta readers converge on a serious retention/confusion failure;
- a later approved canon change makes current architecture impossible.

Taste alone is insufficient.

## Prose/cadence lock

The previous short-paragraph problem was real, but percentage is now an inspection tool rather than a target.

For each suspicious passage classify short units as:

`IMPACT | DIALOGUE RESPONSE | POV THOUGHT | REVELATION | TIME/SPACE SHIFT | RHYTHMIC RELEASE | MOTIF | ACCIDENTAL CHOP`.

Only `ACCIDENTAL CHOP` is automatically repaired.

Do not run a global paragraph merge. Do not force chapters toward one density. An earlier over-compression result below ~5% was already rejected; variation is required.

## Repetition lock

Recurring thematic/motif material is retained only as developing repetition.

For each recurrence ask:

`WHAT IS DIFFERENT THIS TIME?`

At least one must change:

- meaning;
- cost;
- relationship;
- tactic;
- authority;
- access;
- risk;
- emotion;
- reader interpretation.

If none changes, compress/remove/rewrite the recurrence.

Current example already applied in v0.16: duplicate door imagery in Chapter 34 was removed so Chapter 35 owns the final open-door payoff.

## Exposition / dialogue routing

Do not dramatize every informational exchange.

Use direct scene dialogue when exact wording/action changes:

- relationship;
- power;
- consent;
- clue interpretation;
- decision;
- emotional state;
- character revelation.

Use indirect dialogue/summary when only the upshot matters and dramatization would add banal process.

Reject summary that becomes a generic `and then → and then → and then` chronology.

## POV routing

Book One's current POV architecture remains locked unless a current defect is demonstrated.

For future books or genuinely stuck sequences, test alternate POV modes in disposable prototypes before large manuscript migration.

POV review fields:

`KNOWLEDGE | ATTENTION | SENSORY FILTER | VALUE FILTER | MISREAD | LEXICON | SYNTAX | HUMOR | INTIMACY DISTANCE`.

## Historical-audit regression

Older audit findings do not automatically survive into current text.

Required process:

`OLD FINDING → LOCATE SAME PASSAGE IN v0.16/v1.0 → VERIFY DEFECT STILL EXISTS → PATCH OR CLOSE FINDING`.

Priority historical recheck:

- old Chapter 2/3 duplicated eligibility arithmetic;
- older first-chapter runway/hook-delay concern;
- any intermediate Insert-7C micro-fragmentation visible in superseded assemblies;
- repeated authorial growth formulas already partially removed in v0.16.

Do not patch these from old reports alone.

## Reader-validation gate

Use the existing blind beta-reader pack without briefing readers on intended themes.

Major structural reopening after development lock requires either:

- convergence from independent readers on the same problem;
- or new objective causal/continuity evidence.

High-value data:

- voluntary continuation;
- exact boredom/skim point;
- exact confusion point;
- who readers attach to;
- what they think the protagonist wants;
- what question they carry forward;
- whether the ending feels earned;
- whether the epilogue creates curiosity rather than invalidating closure.

## Final-scene / epilogue lock

Protect the current architecture in which Book One's main arc closes before the epilogue.

The epilogue may deepen the provenance question but may not:

- undo Ethan's Book-One resolution;
- convert Samir into a chosen-one reveal;
- prove the Matrix hypothesis prematurely;
- reopen the Youth Cohort decision;
- substitute lore for emotional closure.
