## 3. ROOM 917

### Evidence ecology

For each major clue, store:

`TRACE → SOURCE → SOURCE LINEAGE → WHO HAS ACCESS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION STATUS → NEXT ACTION`.

**Proof variety is not enough.** Several measurements/recordings derived from one physical or archival chain are not automatically independent proof.

### Relationship firewall

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

Relationship change may alter disclosure, willingness to cooperate, source access and investigative tactic; it does not upgrade the physical evidence by itself.

### Dialogue / exposition

Use direct dialogue when exact wording changes evidence, trust, consent, authority or relationship terms. Compress repeated equipment setup, known procedure and re-explanation.

### Current production implication

No global rewrite is authorized merely because Batch 174 exists. Apply to later script/reader QA as a provenance/flow diagnostic.

## 4. Orbital Youth / future IVDIVO

## 5. Conscious robots / nonhuman persons

## 8. Anti-choppiness / line-edit gate

Before editing sentence length:

`BOOK ENGINE → CAUSAL FENCE → CHAPTER FUNCTION → SCENE ADMISSION → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → PARAGRAPH TOPIC/READER-STATE → TRANSITION NEED → SENTENCE RHYTHM/CONTRAST → WORDING`.

Specific repairs:

- `EMPTY TRANSITION + EXPLANATION → MERGE / DELETE / REORDER`;
- routine recoverable logistics → summary/ellipsis;
- related microbeats → one coherent paragraph when they are one perceptual/decision unit;
- preserve short lines only when they perform a real contrast/revelation/decision/pause function;
- allow long sentences for continuous fast action/thought when the grammatical core stays legible.

Standing law:

`SPEED / ACTION / SUSPENSE ≠ SHORT-SENTENCE DENSITY`.
