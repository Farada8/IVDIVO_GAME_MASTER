# IVDIVO — BATCH 151 APPLICATION GATE
## Collins: Emotional Dimensionality + Inner/Outer Rhythm

Status: additive production control. Does not override current canon, active reconciler, accepted manuscript locks, or evidence ledgers.

## 1. Character gate

For every major character under consequential pressure, test:

`VALUE / CONCERN + PRESENT WANT + RELATIONSHIP + CIRCUMSTANCE + COST -> EMOTIONAL MIX -> TACTIC -> CHOICE -> CONSEQUENCE`

Reject:
- one emotion = one behaviour;
- one trait = one behaviour across every relationship;
- random opposite behaviour added for “depth”;
- sudden end-of-book conversion without earlier capacity evidence.

## 2. Inner/outer rhythm gate

Do not equate external motion with internal intensity.

Record when useful:

- INNER RHYTHM: thought/attention/pressure speed and stability;
- OUTER RHYTHM: physical behaviour, speech, environmental pace;
- RELATION: aligned / divergent / alternating;
- TACTIC: leak / conceal / redirect / exploit / refuse;
- CHANGED STATE: what becomes different downstream.

A quiet character can be internally fast. A physically active character can be emotionally deliberate.

## 3. Prose gate — anti-choppy

Never translate analytical rhythm directly into fragments.

Forbidden:

`inner state fast -> sentence short -> paragraph short`

Use:

`SCENE FUNCTION -> POV/EVIDENCE -> INNER/OUTER RHYTHM -> PARAGRAPH INTENT -> READER-STATE CONTINUITY -> SENTENCE RHYTHM`

Merge microbeats when they form one perceptual/decision unit.

## 4. LESSON ZERO Book One

Development lock remains intact.

Only open a local passage if current evidence shows one of:
- generic identical emotional behaviour across characters;
- unexplained contradiction;
- decorative mannerism clutter;
- sentence/paragraph rhythm that contradicts the intended reader effect;
- emotional explanation repeated after behaviour has already communicated it.

Standing law:

`NO NEW EVIDENCE -> NO NEW GLOBAL REWRITE`

## 5. Orbital Youth

Post-money youth stakes should surface through rhythm and attention as well as explicit goals.

Different characters under the same institutional pressure should differ in:
- what they notice first;
- how quickly they commit;
- evidence threshold;
- whether they conceal or expose uncertainty;
- preferred tactic;
- relationship-specific behaviour.

Do not manufacture youth intensity with modern Earth slang or constant argument.

## 6. ROOM 917

Elena/Julian relational scenes may exploit inner/outer mismatch:
- outward professional calm / inner urgency;
- controlled speech / changed attention;
- silence / delayed answer / physical distance as tactics.

But maintain the firewall:

`RELATIONSHIP STATE != EVIDENCE STATUS`

`ATTRACTION / FEAR / HESITATION / INFLECTION != CORROBORATION`

A clue changes status only through source/provenance/corroboration logic.

## 7. B07 — THE UNLISTED CITY

Do not encode personhood as “humanlike emotional display.”

After personhood threshold:

`ENTITY OWN PRIORITY -> ENTITY MODEL/PREFERENCE -> CONSENT/REFUSAL -> ENTITY CHOICE -> HUMAN OPTION SPACE CHANGES`

Human perception of the entity's rhythm is only an interpretation unless independently supported.

## 8. Conscious robots / nonhuman persons

Use embodiment-specific expression:

`EMBODIMENT + OWN WANT + CURRENT MODEL/EVIDENCE + RELATIONSHIP + CONSTRAINT -> SALIENCE / TIMING / COMMUNICATION / ACTION`

No universal robot voice. No mandatory face/eye/hand tells. Compliance does not equal consent.

## 9. Consciousness schools

Emotional or contemplative intensity remains epistemically bounded:

`PRACTITIONER EXPERIENCE -> REPRODUCIBLE EFFECT -> SCHOOL INTERPRETATION -> COMPETING INTERPRETATION -> INDEPENDENT TEST -> ONTOLOGY CEILING`

Inner certainty does not raise a claim's evidence status.

## 10. Scene acceptance

An emotional beat earns full-scene reader time if it changes at least one downstream variable:
- relationship/trust;
- consent/boundary;
- evidence interpretation;
- authority/access;
- responsibility;
- strategy/model;
- commitment;
- future options.

Otherwise consider summary, compression, merge or deletion before line editing.

## 11. Stop rule

Batch 151 does not authorize global style normalization or rhythm KPIs.

Do not optimize:
- average sentence length;
- fragment percentage;
- number of gestures;
- number of emotional reversals.

Optimize reader effect and causal clarity in context.
