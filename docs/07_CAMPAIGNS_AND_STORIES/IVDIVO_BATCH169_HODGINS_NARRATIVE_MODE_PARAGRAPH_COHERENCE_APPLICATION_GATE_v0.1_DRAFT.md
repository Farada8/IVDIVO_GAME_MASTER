# IVDIVO — BATCH 169 HODGINS APPLICATION GATE

## Narrative Mode · Paragraph Coherence · Organic Structure · Revision

**Source:** Jack Hodgins, *A Passion for Narrative* — strict lifecycle complete  
**Status:** production gate / additive; not a canon rewrite instruction

## Standing law

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

This gate applies during planning, drafting and evidence-backed revision. It does not reopen development-locked `LESSON ZERO Book One` by itself.

---

## Gate A — Story level before prose level

Before touching sentence style, answer:

1. What is the chapter/scene function?
2. What changes because this material exists?
3. Does it belong in full scene, partial/embedded scene, narrative summary or exposition?
4. Which POV owns access?
5. What does the reader know before and after?

Only then edit paragraphs and sentences.

---

## Gate B — Narrative Mode Router

### FULL SCENE
Use when exact words/actions change one or more:

- evidence status;
- consent/boundary;
- relationship/trust;
- authority/access;
- responsibility;
- decision;
- emotional commitment;
- personhood threshold;
- future option space.

### PARTIAL / EMBEDDED SCENE
Use when a long process contains one consequential moment.

`SUMMARY → REAL-TIME BULL'S-EYE → SUMMARY / CHANGED STATE`.

### NARRATIVE SUMMARY
Use for:

- process;
- routine;
- logistics;
- repeated procedure;
- elapsed time;
- already-understood conversation;
- low-value transitional action.

### EXPOSITION
Use when direct orientation or conceptual information is genuinely the clearest mode and has a valid POV/narrative owner.

---

## Gate C — Anti-`обрубки` Paragraph Coherence

When prose feels chopped, do **not** begin by increasing sentence length globally.

Test in this order:

`SCENE NECESSITY → MODE → POV → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM`.

### Merge test

If consecutive short lines share:

- one actor;
- one time;
- one place;
- one perceptual focus;
- one emotional/decision movement;

then create a coherent paragraph candidate.

### Preserve standalone short line only if it performs a distinct function

- revelation;
- reversal;
- deliberate silence/pause;
- punch line;
- end-weight;
- contrast;
- decision;
- sharp sensory arrest.

### Reject

`beat → sentence → beat → paragraph break → beat → sentence` as default drafting logic.

**Beat maps are diagnostic; they are not typography.**

---

## Gate D — Reader-State Continuity

For every sentence/paragraph transition:

`STATE LEFT BY A → WHAT B ASSUMES → MATCH / SIGNAL / REORDER / REWRITE`.

Track:

- active subject/person;
- time;
- place;
- knowledge/evidence;
- perceptual focus;
- emotional/relational pressure;
- causal direction.

A sequence of individually clear sentences can still feel artificial if the reader is repeatedly forced to restart orientation.

---

## Gate E — Social Setting

For every major environment, do not stop at physical description.

Map:

`PHYSICAL RULE + SOCIAL NORM + PEER EXPECTATION + INSTITUTIONAL PRACTICE + POV ATTITUDE`.

Then ask what this changes in action.

### Orbital Youth examples

Post-money normality should be experienced through salience:

- standard manufactured goods barely attract attention;
- nonfungible stakes attract attention: time, trust, consent, role, privacy, mastery, belonging, relationship, unique mission/experience.

Do not explain this in a lecture if ordinary behavior can prove it.

---

## Gate F — Character Precious Particle

Before adding another quirk/mannerism/detail, ask:

`WHAT DOES THIS DETAIL REVEAL OR CHANGE?`

Prefer a small number of details that expose:

- present want;
- relationship history;
- value/priority;
- tactic;
- social position;
- embodiment;
- conflict between self-model and behavior.

Reject decorative repeated mannerisms that merely label the character.

---

## Gate G — Dialogue Tactic Progression

Dialogue chain:

`WANT → TACTIC → LISTENER RESPONSE → TACTIC / MODEL CHANGE → CHANGED STATE`.

If several turns use the same underlying tactic, compress or redesign.

### Mystery firewall

`UTTERANCE / SILENCE / INFLECTION / GESTURE → POV HYPOTHESIS`, not `CORROBORATED FACT`.

### ROOM 917

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE ≠ CORROBORATION`.

Relationship state may alter disclosure/access/tactic. It does not alter what a trace objectively proves.

---

## Gate H — Middle Position Change

For each middle scene, ask whether the protagonist/ensemble exits in a materially different position.

Possible axes:

- physical/operational;
- knowledge/evidence;
- relationship/trust;
- consent/boundary;
- authority/access;
- responsibility/obligation;
- strategy/model;
- emotion/commitment;
- future option space.

Repeated obstacles with the same response and same exit state are not progression.

### Protected positive progression

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Do not manufacture failure merely to satisfy escalation doctrine.

---

## Gate I — Flashback Present Dependency

Before full flashback:

1. Why now?
2. What does present POV need from it?
3. What present knowledge/relationship/evidence/decision changes afterward?
4. Can back-flash or summary do the job?

If past material consistently carries more energy than the current story, reconsider story start rather than expanding flashbacks indefinitely.

---

## Gate J — Structure Must Pay

Nonlinear order, frame, repeated retelling, multiple POV or unusual formal device must buy a measurable reader effect:

- fair withholding;
- changed causal interpretation;
- irony;
- relationship revaluation;
- reconstructive participation;
- theme generated through form.

If not, simplify.

---

## Gate K — Driftwood Motif / Symbol

Before importing a symbolic prop, search the existing story for an object/location/action already causal.

`EXISTING ELEMENT → RECUR → MEANING/RELATION CHANGES → PAYOFF`.

Reject:

- symbolic prop introduced only to announce theme;
- recurring image with no development;
- author explanation after the image already worked.

---

## Gate L — Correct-Level Revision

`OBSERVED DEFECT → DEFECT LEVEL → MINIMAL CORRECT REPAIR → REGRESSION TEST`.

- word defect → word
- sentence/rhythm defect → line edit
- paragraph continuity → paragraph rebuild
- communication tactic → dialogue rebuild
- scene purpose/POV/staging → re-imagine scene
- chapter causal chain → sequence rebuild
- book engine → development rewrite

Never use a deep rewrite because a new craft book was read.

---

## Gate M — Conscious Robot / Nonhuman Personhood

Hodgins' character tools are anthropocentric examples; IVDIVO personhood remains:

`OWN PRIORITY / WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Human interpretation of robot/nonhuman behavior remains sourced interpretation.

For B07 after personhood threshold:

`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Humans may create a bounded choice architecture; they do not own the entity's continuity decision.

---

## Gate N — Schools of consciousness / ontology

Keep the epistemic ladder:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

A vivid POV, metaphor, intuition or traditional vocabulary does not raise ontology status.

---

## LESSON ZERO decision

**NO GLOBAL REWRITE.**

Only apply Hodgins locally when current evidence identifies:

- unnecessary real-time dramatization;
- paragraph fragmentation;
- POV authority/access error;
- repeated middle state;
- imported-symbol obviousness;
- flashback with no present dependency;
- foundational scene staging/purpose defect.

Otherwise preserve the development lock.

## Final production reminder

The goal is not prose that visibly obeys Hodgins. The goal is prose whose **underlying construction is disciplined while its surface reads naturally and continuously**.
