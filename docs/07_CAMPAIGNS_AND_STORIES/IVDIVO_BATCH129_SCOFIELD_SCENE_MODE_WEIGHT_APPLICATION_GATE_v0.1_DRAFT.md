# IVDIVO BATCH 129 APPLICATION GATE
## Scene Mode · Weight · Embedded Scenes · Compression

Date: 2026-08-19
Status: DRAFT / PROVISIONAL SOURCE LAYER
Source: Sandra Scofield, *The Scene Book* — FULL READ IN PROGRESS

## Primary router
For every candidate passage:
`BOOK ENGINE → CHAPTER FUNCTION → DOES THIS NEED REAL-TIME SCENE? → FULL / EMBEDDED / FRAGMENT / SUMMARY → DURATION → POV → DIALOGUE → PARAGRAPH → RHYTHM`.

Do not begin with sentence polishing.

## Full-scene acceptance
Use full scene when exact moment-by-moment experience materially changes at least one of:
- decision;
- evidence status;
- relationship/trust;
- consent/boundary;
- authority/access;
- responsibility;
- model/strategy;
- future option set;
- emotional commitment with downstream consequence.

## Embedded-scene acceptance
Use a brief embedded scene when one exchange/image/action inside a longer process deserves exact reader time.

Pattern:
`SUMMARY → BULL'S-EYE MOMENT IN REAL TIME → SUMMARY / NEW STATE`.

## Summary acceptance
Use summary/indirect mode for:
- routine procedure;
- repeated logistics;
- travel/transit that does not alter the action set;
- repeated research steps;
- conversations where exact wording does not matter;
- elapsed processing time whose result matters more than each beat.

## Orbital Youth
WATCH for:
- every commute becoming a civilization tour;
- every lesson becoming a full classroom scene;
- every technical test receiving equal weight;
- every friend reacting to every line.

Protect full scene for:
- first real responsibility;
- consent/refusal;
- earned belonging or exclusion;
- evidence/model break;
- relationship state change;
- successful competence that produces more responsibility.

## ROOM 917
Full scene/high immediacy is justified for:
- first impossible indicator;
- clue-bearing exact audio behavior;
- Julian/Elena trust/boundary turn;
- evidence handling where exact procedure matters.

Compress repeated searching, transit, setup and non-clue procedure.

`ROMANTIC IMMEDIACY ≠ EVIDENCE STATUS` remains active.

## Conscious robots
Do not force human interior monologue as proof of personhood.

A nonhuman scene can be fully immediate through:
`SELECTIVE ATTENTION → OWN MODEL → RELATION-SPECIFIC RESPONSE → CONSENT/REFUSAL → CHOICE`.

## Anti-choppy gate
If a passage reads as:
`ACTION → one-line thought → gesture → one-line speech → reaction → separate theme sentence`, test whether the whole unit should instead be:
- one integrated paragraph;
- summary plus one exact beat;
- indirect dialogue;
- or deleted.

Short lines remain legal when they perform a real structural/rhythmic function.

## LESSON ZERO
Development lock remains.

Only open targeted passages with evidence of:
- microdramatized logistics;
- uniform scene weight;
- unnecessary full-scene treatment;
- missing decisive scene;
- paragraph confetti caused by over-rendering.

## PASS conditions
PASS when narrative mode matches reader-time value.

FAIL/WATCH when:
- every event gets full scene;
- every scene receives similar length/intensity;
- exact dialogue survives without exact-word consequence;
- discovery-only scenes survive because the author likes them;
- prose imitates screenplay beats instead of exploiting prose interiority and compression.
