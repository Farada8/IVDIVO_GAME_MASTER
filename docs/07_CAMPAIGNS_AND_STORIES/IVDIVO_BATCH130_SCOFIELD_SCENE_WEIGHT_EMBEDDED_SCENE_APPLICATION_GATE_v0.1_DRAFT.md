## 1. Global production rule
Before expanding, cutting or line-editing a passage, route it through:

`BOOK ENGINE -> CHAPTER FUNCTION -> SCENE NECESSITY -> SCENE WEIGHT -> NARRATIVE MODE -> POV/EVIDENCE -> PARAGRAPH/RHYTHM -> WORDING`.

No sentence-level cleanup is allowed to substitute for a wrong scene/mode decision.

---

## 2. LESSON ZERO Book One
Current authority remains DEVELOPMENT LOCKED / PUBLISHING VALIDATION.

Batch 130 does **not** reopen Book One.

Use Scofield only if external reader/audio/copy evidence identifies a concrete passage where:
- routine process is over-dramatized;
- several light scenes should be summarized/merged;
- a buried bull's-eye moment deserves real-time expansion;
- microreaction confetti creates choppy cadence.

Otherwise: NO REWRITE.

### Protected logic
Ordinary life, Shared Sky, friendship fracture, autonomy/consent work and major WCF/payoff scenes cannot be cut merely because they are quiet. Their function is determined by changed state, not spectacle.

---

## 3. Orbital Youth / future books
### Scene Weight Pass
Every planned scene receives one label:
- HEAVY
- MEDIUM
- LIGHT
- COMPRESSED

Then answer:
1. What changes?
2. How irreversible is it?
3. Does exact wording/action matter?
4. Is the reader paying too much time for the change produced?

### Embedded Scene candidate
Use when:
- the process is routine;
- one exact moment changes consent, evidence, trust, authority or decision.

Pattern:
`SUMMARY -> REAL-TIME BULL'S-EYE -> SUMMARY / NEXT STATE`.

### Examples
- calibration summarized; dispute over permission shown;
- commute summarized; one route decision shown because it changes access/relationship;
- training summarized; exact evaluation feedback shown because it changes role;
- archive work summarized; source-lineage contradiction shown.

---

## 4. Technical-scene anti-monotony gate
Reject repeated pattern:
`arrive -> connect -> inspect -> explain -> think -> ask -> receive answer -> leave`.

Instead determine:
- What is the real question?
- Which exact beat changes the model?
- Which material can be narrated indirectly?
- What state exists after the passage that did not exist before?

---

## 5. Mystery / evidence scenes
A clue discovery may be compressed until the exact provenance/evidence turn.

`SEARCH PROCESS (summary) -> TRACE FOUND (scene) -> INTERPRETATION CONTESTED (scene if exact language matters) -> RESULTING ACTION`.

Evidence itself cannot be beautified or altered for scene shape.

---

## 6. Conscious robots / nonhuman persons
Do not assume a nonhuman subject deserves a full scene merely because its embodiment is novel.

Full scene is earned when the being's own:
- preference;
- consent/refusal;
- model/evidence;
- relationship;
- decision
changes the option space.

Conversely, do not compress a nonhuman decision into human summary if that would erase its agency.

---

## 7. Post-money worldbuilding
Do not expand ordinary resource logistics into scenes merely to explain the world.

Show post-money normality through selective lived signals. Expand only when the scene concerns genuinely nonfungible stakes:
- time;
- trust;
- consent;
- relationship;
- unique role/mission;
- reputation;
- scarce compatible space;
- lived expertise.

---

## 8. Anti-'обрубки' surgical test
When a passage feels fragmented:
1. Is this passage a full scene by mistake?
2. Is scene weight too high for its function?
3. Should routine beats be summary/indirect?
4. Are multiple one-line paragraphs one continuous perceptual/causal unit?
5. Only then adjust sentence length.

Do not optimize short-sentence percentage.

---

## 9. Acceptance gate
A scene/mode decision passes if:
- ONE MAIN STORY remains visible;
- exact reader time is proportionate to change;
- character/personhood is preserved;
- evidence status remains honest;
- relationship/consent changes are shown at the correct granularity;
- prose rhythm is then revised downstream.

## Final verdict
Use Scofield as a **mode/weight router**, not as a demand to convert the manuscript into scene-after-scene dramatic coverage.
