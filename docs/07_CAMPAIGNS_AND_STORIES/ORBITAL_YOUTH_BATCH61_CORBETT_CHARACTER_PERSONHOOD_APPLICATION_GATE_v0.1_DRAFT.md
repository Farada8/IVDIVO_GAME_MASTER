# ORBITAL YOUTH — BATCH 61 CORBETT APPLICATION GATE

Date: 2026-08-17
Status: ADDITIVE PRODUCTION CONTROL / DO NOT RETROFIT FORMULA

## Purpose
Use Corbett's strongest characterization mechanisms to protect the post-money Orbital Youth line from plot puppets, Earth-2020s motivation regressions, same-voice ensembles and synthetic-person servitude.

## 1. POST-MONEY MOTIVATION GATE
For every major youth before prose, specify one concrete nonfungible want:
`specific responsibility / mission place / trust / relationship / consent / mastery / belonging / time / reputation / unique experience`.

Forbidden shortcut:
`money removed → credits/status points inserted`.

A want is usable only if another person, institution, circumstance or finite opportunity can meaningfully resist it.

## 2. FRUSTRATION FINGERPRINT
For every recurring character record:
- first response when blocked;
- second tactic after first response fails;
- unacceptable cost;
- person they seek/avoid;
- information they want before acting.

If several youths share the same sarcasm, defiance, procedural challenge or brilliant technical improvisation, differentiation has failed even if biographies differ.

## 3. RELATIONSHIP-SPECIFIC SELF
Test the same person with:
`friend / parent-family / instructor / rival / intimate interest / public audience / conscious robot`.
The voice and tactic should change because risk, trust and desire change—not because the writer assigns different slang.

## 4. CONSCIOUS ROBOT PERSONHOOD
Every named conscious robot must have:
- private or off-axis want;
- at least one relationship not routed through the protagonist;
- something it can refuse;
- embodiment-specific affordance/constraint;
- cultural/social normality;
- distinct tactics with different interlocutors.

Replacement test:
`If a smart terminal could perform the same scenes without changing consent, relationship, motive or consequences → ROBOT PERSONHOOD FAIL.`

## 5. SOCIAL ECOLOGY
Worldbuilding enters through character pressure:
`HABITAT / COHORT / FAMILY / Vocation / INSTITUTION / HUMAN-ROBOT NORM / PRACTICE LINEAGE → what this person expects → what they can do → what is embarrassing/risky/desirable → choice`.

Do not explain post-money society in lecture form when a daily causal signal can establish the changed default.

## 6. CONSCIOUSNESS-SCHOOL FIREWALL
A practitioner may sincerely hold a metaphysical interpretation without making it world fact.

Maintain:
`OBSERVATION → REPRODUCIBLE PRACTICE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL FACT`.

Character psychology, Corbett psychoanalysis and school doctrine cannot bridge these levels automatically.

## 7. ONE MAIN STORY
Independent personhood does not license unrelated subplots.
Every major personal line must change at least one of:
`shared causal problem / relationship network / evidence state / available options / final choice / aftermath`.

`ONE MAIN STORY ≠ ONE HERO DOES EVERYTHING.`

## 8. SCENE / DIALOGUE REGRESSION
For each conversation-heavy scene:
`WHO WANTS WHAT? → HOW DO THEY TRY TO GET IT? → WHAT DOES THE OTHER PERSON DO? → HOW DOES TACTIC CHANGE? → WHAT STATE IS DIFFERENT AFTERWARD?`

If exact wording does not change trust, consent, evidence, relationship, power, emotion or decision, consider indirect dialogue or summary.

## 9. STYLE / “OBRUBKI” PROTECTION
Do not cure character or scene defects by sentence-length manipulation.

Repair order:
`CAUSAL ENGINE → PERSONHOOD/WANT → SCENE NECESSITY → TACTIC → POV → DIALOGUE MODE → PARAGRAPH INTENT → RHYTHM → WORDING`.

A short line stays when it earns contrast. A chain of micro-lines disappears when the underlying micro-dramatization was unnecessary.

## 10. CURRENT VERDICT
This layer is **additive**. It does not authorize rebuilding an accepted book architecture or reopening `LESSON ZERO Book One` without a demonstrated current defect.

Highest-value use is on new Orbital Youth story cores, new named robots, new cadet/instructor casts, and scene regression before prose lock.
