# IVDIVO Batch 149 Application Gate
## Collins — Objectives · Subtext · Dialogue Motivation

Status: ADDITIVE PRODUCTION GATE. Does not override canon or reopen locked manuscripts by itself.

## 1. Dialogue scene admission

Before writing or retaining a full dialogue scene:

`WHAT CHANGES BECAUSE THESE EXACT WORDS ARE SPOKEN / WITHHELD?`

Acceptable changed-state axes include:
- evidence / source status;
- trust / relationship terms;
- consent / boundary;
- authority / access;
- responsibility / commitment;
- strategy / causal model;
- decision ownership;
- future option space.

If none changes, test `SUMMARY / INDIRECT DIALOGUE / EMBEDDED SCENE / MERGE / DELETE` before line editing.

## 2. Objective / tactic split

For each important participant:

`PRESENT WANT → CURRENT TACTIC → RESPONSE → WHAT DID THEY LEARN? → NEXT TACTIC`.

A conversation is structurally flat when characters repeat the same tactic under cosmetically different wording.

## 3. Subtext motivation gate

Before hiding meaning, answer:

- Does the speaker NOT WANT to state the operative objective?
- Or does the speaker NOT NEED to state it because shared history/context already carries it?
- What does the listener believe the line means?
- What cost or risk is directness avoiding?

If there is no answer, do not add subtext merely to make dialogue feel sophisticated.

## 4. Honesty payoff gate

Direct speech is not inferior craft.

When a sequence has built pressure through avoidance, concealment or coded interaction, a plain sentence can be the earned turning point:

`LONG AVOIDANCE → DECISION → DIRECT CLAIM / REFUSAL / CONFESSION / BOUNDARY → CONSEQUENCE`.

Do not bury every climax under another layer of clever implication.

## 5. Exposition ownership

Reject:

`AUTHOR NEEDS READER TO KNOW X → CHARACTER SAYS X`.

Require:

`CHARACTER NEEDS / WANTS TO ASK / SAY / HIDE X NOW → INTERLOCUTOR MATTERS → CONSEQUENCE FOLLOWS`.

If not, route the information through narration, summary, document, evidence handling, or a differently motivated scene.

## 6. TIME minimum

Collins's Thought / Inflection / Movement / Expression are optional channels.

Never use them as a four-item checklist after each line.

Preferred rule:
`USE THE FEWEST CUES THAT KEEP THE RELATIONAL ACTION LEGIBLE`.

Failure mode:
`LINE → LOOK → HAND → THOUGHT → LINE → EXPRESSION`.

That is characterization clutter and often creates choppy prose.

## 7. Evidence firewall

Always separate:

`SURFACE WORDS / TONE / GESTURE → POV INTERPRETATION → HYPOTHESIS → CORROBORATION`.

A pause, evasive answer, attraction, silence or apparent nervousness can alter the investigator's model; it does not itself prove motive, guilt, personhood or ontology.

## 8. Youth ensemble gate

Do not give all young characters one authorial subtext style.

For each relationship track:
`STATUS + SHARED HISTORY + PRESENT WANT + EMBARRASSMENT / RISK + CULTURAL NORM → WHAT IS SAID / OMITTED / MISREAD`.

Future youth voice is not current-Earth slang pasted onto orbital nouns.

## 9. Conscious robot / nonhuman gate

Do not use human facial micro-signals as mandatory personhood evidence.

Track:
`EMBODIMENT → OWN WANT → OWN MODEL/EVIDENCE → RELATIONSHIP → CONSTRAINT → CONSENT/REFUSAL → COMMUNICATION TACTIC`.

Human interpretation of robot silence/compliance remains an interpretation.

## 10. ROOM 917

Elena↔Julian subtext may legitimately change:
- trust;
- willingness to disclose;
- access to a room/object/source;
- investigative tactic;
- consent/boundary;
- future relationship options.

It may NOT change what a recording, plan, structural report, timestamp or physical trace actually proves.

Standing firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / INFLECTION ≠ CORROBORATION`.

Repeated recorder/contact-mic/setup dialogue should be compressed unless exact wording changes clue status or relationship/consent.

## 11. Orbital Youth

Subtext should reveal the actual scarcity structure of the world. Characters may avoid/directly discuss:
- trust;
- time;
- privacy;
- belonging;
- qualification;
- responsibility;
- a unique mission/place/experience;
- consent/intimacy.

Do not reintroduce salary/rent/credits as familiar dialogue shorthand.

## 12. B07 / distributed nonhuman personhood

Before personhood threshold:
`TRACE → HUMAN INTERPRETATION → ALTERNATIVE MODEL → INDEPENDENT TEST`.

After threshold:
`ENTITY'S OWN MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Human subtext about what the entity “must want” is not a substitute for the entity's own agency.

## 13. LESSON ZERO lock

No global rewrite is authorized by this batch.

Standing law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Reopen only a targeted layer if current manuscript evidence shows:
- exposition dialogue with no character objective;
- repeated tactic without changed state;
- subtext-to-evidence leap;
- generic same-voice ensemble dialogue;
- microgesture confetti / choppy paragraphing;
- a directness payoff being weakened by unnecessary implication.
