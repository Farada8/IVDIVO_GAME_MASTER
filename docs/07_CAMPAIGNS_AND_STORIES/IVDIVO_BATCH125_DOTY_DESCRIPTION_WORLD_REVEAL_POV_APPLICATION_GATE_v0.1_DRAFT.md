# IVDIVO — BATCH 125 APPLICATION GATE
## Description · World Reveal · POV Attention

Date: 2026-08-19
Status: WORKING / PROVISIONAL SOURCE LAYER

This gate applies provisional mechanisms extracted from Mark Doty — *The Art of Description*. The source has passed integrity verification but not FULL READ; therefore these gates are additive diagnostics, not permanent law yet.

## Core routing

Before expanding description, ask:

`WHO IS PERCEIVING? → WHAT DO THEY WANT NOW? → WHAT CAN THEIR BODY / TRAINING / ACCESS NOTICE? → WHICH DETAIL MATTERS? → WHAT DOES IT CHANGE?`

If the answer to the last question is 'nothing', the detail is likely atmosphere-only and should compete for a very small budget.

## Orbital Youth

Do not reveal the orbital city through a tourism catalogue.

Prefer:
`WORLD RULE / MATERIAL DETAIL → TEENAGER'S PRESENT WANT → FRICTION / OPPORTUNITY → CHOICE → CONSEQUENCE`.

Post-money civilization should emerge from what young people do not bother noticing versus what they care about intensely: consent, time, trust, privacy, responsibility, qualification, belonging, relationships, unique experiences.

## Conscious robots / nonhuman persons

No generic sensor-feed voice.

Description must reflect:
- embodiment and sensorium;
- current task and independent desire;
- learned attention habits;
- relationship to the observed person/object;
- uncertainty and model limits.

`OBSERVED SIGNAL ≠ MOTIVE` remains mandatory.

## Mystery / ROOM 917

Descriptive noticing can create a clue only when the trace is actually present in the storyworld.

`TRACE → POV NOTICES → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION / TEST`.

A poetic association, visual resemblance, emotional intuition, attraction, trust, or confession does not upgrade evidence status.

## Consciousness-practice schools

Phenomenological precision is valuable, but:

`VIVID EXPERIENCE ≠ REPRODUCIBLE EFFECT ≠ SCHOOL INTERPRETATION ≠ ONTOLOGICAL FACT`.

Keep the existing evidence ladder intact.

## Line-edit / anti-choppy gate

Bad repair:
`object → one-line sensory fragment → second object → one-line reaction → metaphor → one-line theme`.

Preferred repair:
`paragraph purpose → attention owner → selective particulars → evolving relation/inference → coherent rhythm`.

Short lines remain legal when they create real contrast, revelation, interruption, humor, or end-weight.

## Description density test

For any descriptive cluster of 3+ details, label each item:
- ACTION OPTION
- CHARACTER / POV
- RELATIONSHIP
- EVIDENCE / MYSTERY
- EMBODIMENT
- WORLD RULE
- ATMOSPHERE
- RHYTHM / EMPHASIS

If most items are only ATMOSPHERE, compress. If several items perform identical work, choose the strongest.

## Protected principle

`WORLD DATABASE ≠ BOOK NARRATIVE`.

The saga may know far more than any scene should say.
