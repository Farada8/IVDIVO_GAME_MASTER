# IVDIVO — BATCH 141 APPLICATION GATE
## Scofield: Scene Event · Emotion · Consequence
**Production status:** additive gate; no canon override; no automatic rewrite authorization.

## Core rule

Before writing or revising a passage as a full scene, determine:

`PRIOR CONSEQUENCE → SCENE OWNER → PRESENT AGENDA → FOCUSED EVENT → PRESSURE / SUPPORT → ACTION / NOTICE / RESPONSE → CHANGED STATE → DOWNSTREAM CONSEQUENCE`

If the exact real-time sequence does not matter, route to SUMMARY / EMBEDDED SCENE / SCENE FRAGMENT / COMMENTARY.

## Scene-weight gate

Assign one of four weights before line editing:

- **HEAVY** — irreversible choice, evidence, consent/personhood, relationship, authority or responsibility turn.
- **MEDIUM** — meaningful local state change with downstream consequence.
- **LIGHT** — one precise scenic function; short real-time contact.
- **COMPRESSED** — logistics, repetition, procedure or transit whose exact beats do not matter.

Do not make every meeting, test, commute, interface setup, lesson, archive search, or briefing HEAVY merely because the worldbuilding is interesting.

## Scene changed-state matrix

A scene should normally change at least one axis:

1. physical/operational state;
2. knowledge/evidence status;
3. relationship/trust;
4. authority/access;
5. responsibility/obligation;
6. strategy/model;
7. emotion/commitment;
8. future option space.

`NO DOWNSTREAM CHANGE → TEST SUMMARY / MERGE / DELETE / REBUILD.`

## Event/emotion coupling gate

Do not alternate action with decorative reaction lines. Ask:

`WHAT HAPPENED → WHAT DID IT MEAN TO THIS POV → WHAT DOES THAT MEANING CHANGE NEXT?`

Emotion earns reader time when it changes interpretation, relationship, evidence handling, commitment, tactic, consent/boundary, or future choice.

## Anti-choppy gate

Forbidden default implementation:

`stimulus. reaction. gesture. thought. decision.`

Revision order:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT/MODE → POV/EVIDENCE → EVENT/EMOTION COUPLING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`

If several microbeats form one perceptual/decision unit, merge them into coherent prose rather than polishing fragments separately.

Compress repetitive equipment setup, corridor movement, routine playback, and process confirmation unless exact sequence itself is evidentiary.

## ORBITAL YOUTH

Use environment causally:

`WORLD RULE → CHARACTER-SPECIFIC NOTICE → AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

Do not dramatize technology because it exists. A technical sequence earns full scene when it changes evidence, responsibility, access, consent, relationship, or the next strategy.

Post-money firewall remains: ordinary availability of manufactured goods is background; stakes center on time, trust, consent, role, responsibility, privacy, belonging, mastery, relationships, unique opportunity and safety.

## B07 — THE UNLISTED CITY

Do not treat the distributed nonhuman life as a scene complication. Once personhood threshold is reached:

`ENTITY OWN MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Kyra may create a bounded, documented decision space; she does not own the nonhuman entity's continuity choice.

## Conscious robots

`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Human interpretation of robot behavior remains interpretation.

## Consciousness-practice schools

A vivid subjective scene can establish experience and its consequences, not ontology:

`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.
