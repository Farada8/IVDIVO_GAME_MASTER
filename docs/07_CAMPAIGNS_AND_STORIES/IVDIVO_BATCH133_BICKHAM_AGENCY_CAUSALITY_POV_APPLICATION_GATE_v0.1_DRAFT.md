# IVDIVO — BATCH 133 APPLICATION GATE
## Bickham: Agency · Causality · POV

Status: additive production-control layer. Does not override current canon or reopen locked manuscripts by itself.

## Scene / chapter acceptance

For each meaningful unit ask:

1. **Whose present want/responsibility is active?**
2. **What form does agency take?** Action, refusal, delay, cooperation, delegation, bounded non-action?
3. **What supplies pressure?** Person, institution, world rule, evidence uncertainty, relationship, embodiment, time, consent, incompatible good values?
4. **What causal bridge makes the next response legible?**
5. **What changed?** Action state, evidence, relationship, authority/access, responsibility, strategy/model, emotion/commitment, future options?
6. **Whose POV owns access?** What can this mind observe, know, infer, report, or not know?
7. **Why is this POV worth the switching cost?**
8. **Does the result feed ONE MAIN STORY?**

## Mystery / evidence gate

Never collapse:

`OBSERVED TRACE → POV INTERPRETATION → HYPOTHESIS → CORROBORATION → WORLD FACT`

A character's certainty, expertise, attraction, trust, fear, institutional status or spiritual conviction cannot skip evidence stages.

## YA gate

Do not equate agency with loudness or rebellion. Strong youth agency includes:
- asking for evidence before acting;
- refusing a recommendation;
- consenting conditionally;
- seeking help;
- choosing cooperation;
- delaying until a threshold is met;
- taking responsibility after a successful decision.

Preferred escalation where appropriate:

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`

## Conscious robot / nonhuman person gate

Do not classify silence, compliance or refusal as proof of non-personhood.

Required line once personhood is relevant:

`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → OWN CHOICE → CONSEQUENCE`

Human POV interpretation of robot behavior remains interpretation.

## Consciousness-practice epistemic gate

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`

A close POV may render the experience intensely without turning its metaphysical interpretation into canon.

## Anti-choppy-prose gate

Do not implement stimulus/response as:

`stimulus. reaction. thought. gesture. next stimulus.`

Use the existing router:

`ONE MAIN STORY → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT / MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → SHOW/TELL → DIALOGUE/SUBTEXT → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several microbeats are one perceptual or decision unit, combine them before line polishing.

## Locked manuscript policy

LESSON ZERO Book One remains locked unless current reader evidence, continuity evidence or a concrete text defect establishes a real problem. A newly learned craft rule is not sufficient reason to rewrite it.
