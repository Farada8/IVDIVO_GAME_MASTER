# IVDIVO — BATCH 178 — KING APPLICATION GATE
## Discovery · Rewrite · Description · Reader Effect

**Source:** Stephen King, *On Writing*  
**Source status:** strict lifecycle complete  
**Application status:** additive production gate; **not** authority to rebuild locked manuscripts.

---

## 1. Universal repair router

Before changing prose, route the defect:

`ACTUAL TEXT → WHAT READER EXPERIENCES → DEFECT LEVEL → MINIMAL CORRECT FIX → RETEST`.

Defect levels:
1. book engine / ONE MAIN STORY;
2. causality / objective / consequence;
3. character / relationship / consent;
4. scene admission / scene weight;
5. POV / evidence / knowledge access;
6. exposition / dialogue mode;
7. paragraph topic chain / reader-state continuity;
8. sentence rhythm;
9. wording/copy.

Never fix level 1–7 problems by merely making sentences prettier.

---

## 2. Discovery-stage gate

During live drafting:

- allow character/model discoveries;
- do not run every craft framework simultaneously;
- do not promote discovery to canon automatically;
- flag deviations for post-scene review.

After the scene/chapter:

`DISCOVERY → CHARACTER TRUTH → CANON → CAUSALITY → ONE MAIN STORY → KEEP / REPLAN / BANK / DISCARD`.

---

## 3. Description gate

For every descriptive cluster ask:

1. Who is perceiving?
2. What do they want now?
3. Why does this detail become salient now?
4. What does their embodiment/knowledge permit them to notice?
5. Does the detail change orientation, affordance, relation, inference, mood, rhythm or payoff?
6. Is the textual space proportionate to the detail’s story importance?

If not, compress.

**No sensor checklist. No technology catalogue. No physical-trait personality shortcut.**

---

## 4. Anti-choppiness gate

When prose feels fragmented, do **not** begin by increasing average sentence length.

Audit:

`NARRATIVE MODE → PARAGRAPH INTENT → READER STATE LEFT BY PREVIOUS SENTENCE → TOPIC CHAIN → RELATED MICROBEATS → SENTENCE CONTRAST`.

Repair options:
- merge fragments into one coherent perceptual/decision unit;
- remove repeated interpretation;
- remove inferable stage direction;
- convert routine process to summary/indirect narration;
- reorder old→new information;
- retain a short line only when it buys a distinct beat: decision, revelation, contrast, pause or comic timing.

**Forbidden KPI:** percent short sentences / one-line paragraphs.

---

## 5. Revision gate — King `1408` lesson

Use the demonstrated behavior, not slogans:

- cut redundant reader-thinking;
- cut stage directions that add no state change;
- cut clumsy backstory;
- move a necessary setup/prop earlier if later payoff depends on it;
- retain an adverb or longer sentence if it performs unique work;
- preserve local atmosphere/detail when it earns reader time;
- verify motive after draft distance.

`FUNCTION > RULE NAME`.

---

## 6. Reader evidence gate

### One trusted reader
Useful for:
- simulated pacing;
- local confusion;
- emotional effect;
- factual mistakes;
- missing motivation.

Not sufficient for:
- universal target-audience judgment;
- canon change;
- proof that the reader’s proposed fix is correct.

### Production rule

`READER REPORT → OBSERVED EFFECT → CONVERGENCE → DEFECT LEVEL → MULTIPLE FIX OPTIONS → TEST`.

---

## 7. LESSON ZERO Book One

**Current decision:** `KEEP DEVELOPMENT LOCK`.

Batch 178 does not constitute new manuscript evidence.

Open a local layer only if beta/audio/current-text evidence shows a specific defect, for example:
- repeated one-line paragraph fragmentation;
- redundant reader-thinking;
- stage-direction clutter;
- backstory with no present-state consequence;
- detail weight disproportionate to narrative importance;
- motivation inconsistency;
- fair-play setup arriving after payoff.

If choppiness is reported, test **paragraph organization and unnecessary real-time dramatization before sentence length**.

Standing law:

`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

---

## 8. Orbital Youth

### Apply
- ordinary future life through a few salient lived details;
- allow live draft to reveal stronger motives, then canon-test them;
- distinguish character competence from institutional legitimacy;
- preserve real success as a valid escalator;
- keep description proportionate to actual causal importance.

### Do not import from King
- money/career stakes as default into post-money cities;
- human physical shorthand as universal character coding;
- chronological narration as mandatory;
- discovery drafting as only valid method.

Post-money stakes remain:
`TRUST / CONSENT / TIME / RESPONSIBILITY / PRIVACY / ROLE / UNIQUE OPPORTUNITY / MASTERY / BELONGING / RELATIONSHIP / SAFETY`.

---

## 9. ROOM 917

For dialogue/description/revision:

- exact dialogue earns real-time treatment when it changes disclosure, trust/boundary, evidence access or investigative tactic;
- routine setup/playback/search may be compressed;
- props/clues required for payoff must be fairly planted early enough;
- factual clue content must not be beautified into a different fact;
- reader-thinking explanations should not repeat what the audio/physical action already made legible.

Absolute firewall:

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

---

## 10. B07 — THE UNLISTED CITY

King’s empathy/character tools do not lower the personhood proof threshold.

Required chain:

`TRACE → INDEPENDENT SOURCE LINEAGES → PERSONHOOD THRESHOLD → ENTITY'S OWN MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Human emotional identification with the entity is motive for investigation, **not proof of subjectivity**.

---

## 11. Conscious robots / synthetic persons

Do not use:
- human grooming;
- human facial expression;
- human trauma;
- human-like slang;
- “warmth”

as required proof of personhood.

Use:

`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

`MORE SENSORS ≠ OMNISCIENCE`.

`OBSERVED BEHAVIOR ≠ MOTIVE FACT`.

---

## 12. Consciousness-practice schools

King’s “telepathy” is craft metaphor only.

Never use it as evidence for IVDIVO metaphysics.

Maintain:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

---

## 13. Stop condition

Batch 178 is successfully applied when it improves **diagnosis and routing**, not when every manuscript resembles King.

If no concrete defect exists, **make no change**.
