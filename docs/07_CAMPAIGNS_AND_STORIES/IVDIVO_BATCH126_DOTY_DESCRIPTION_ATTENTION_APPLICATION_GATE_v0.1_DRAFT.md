## Purpose
Apply only the mechanisms verified from Mark Doty *The Art of Description* without promoting the source beyond its actual lifecycle stage.

## A. Universal descriptive gate
Before expanding descriptive prose, ask in order:
1. What is the scene/chapter function?
2. Who is perceiving?
3. What is that agent trying to do now?
4. What can this body/training/history notice?
5. Which particulars change action, inference, relationship, evidence, or reader orientation?
6. What belongs in one coherent paragraph rather than separate sensory fragments?
7. What can be omitted because it is world-database residue?

## B. ONE MAIN STORY firewall
Description pays rent to the dominant causal engine through at least one of:
- actionable affordance/constraint;
- evidence or model change;
- relationship/status change;
- character-specific attention;
- setting rule needed for a later decision;
- reader orientation;
- rhythm/emotional pressure.

Pure sightseeing is compressible.

## C. Mystery / evidence firewall
Separate:
WORLD FACT → TRACE → OBSERVER SELECTION → DESCRIPTION → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION

Never allow a vivid metaphor, emotional reaction, or confident technical description to silently upgrade hypothesis to fact.

## D. Orbital Youth
Worldbuilding target:
WORLD RULE → YOUTH-SPECIFIC NOTICE → AFFORDANCE/FRICTION → CHOICE → CONSEQUENCE

Examples of legitimate attention:
- a cadet notices a transit rule because it changes whether they can make a qualification window;
- a teenager notices privacy architecture because someone they care about can overhear/see them;
- a conscious robot notices a thermal/EM/structural pattern because its embodiment and current objective make it salient;
- post-money life is shown because ordinary objects do not attract economic anxiety while trust/time/mission access do.

Do NOT explain the civilization merely to prove that the Saga Bible is rich.

## E. Conscious robot POV
Forbidden default: generic sensor readout.

Required model:
EMBODIMENT + OWN WANT + RELATIONSHIP + TASK + MEMORY/KNOWLEDGE → ATTENTION FILTER → DETAIL → INFERENCE/ACTION

The robot may perceive more data than a human but still select according to personhood.

## F. Rare consciousness-practice schools
Description may represent lived experience intensely while preserving epistemic status:
EXPERIENCE ≠ EXPLANATION.

Required ladder:
experience → report → repeatability → school interpretation → competing interpretation → evidence ceiling.

## G. Anti-choppy line-edit gate
Do not solve weak description by adding isolated one-line sensory beats.

Diagnosis order:
SCENE NECESSITY → POV ATTENTION → DETAIL SELECTION → PARAGRAPH FUNCTION → READER-STATE CONTINUITY → SENTENCE RHYTHM.

Merge adjacent fragments when they share actor/time/place/focus and no real attentional turn occurs.

## H. ROOM 917 applicability
ROOM 917 should privilege forensic attention rather than Gothic decoration.

ELENA descriptive filter:
- material;
- source;
- distance;
- repeatability;
- deviation from expected acoustic/structural behavior;
- evidence ceiling.

JULIAN descriptive filter should differ: management history, human use of space, remembered routes, reputational/institutional consequences.

Romantic attention may alter what each notices about the other, but:
ATTRACTION / TRUST / SUBTEXT ≠ CORROBORATION.

## I. Acceptance tests
A descriptive passage passes if:
- removing it would reduce orientation, character specificity, evidence/model status, relationship pressure, action options, or necessary rhythm;
- the noticed particulars plausibly belong to the current perceiver;
- unusual terms are legible in context;
- metaphor reveals a property rather than merely decorating;
- evidence facts remain exact;
- paragraph breaks correspond to genuine shifts of focus/meaning;
- the passage does not re-import money/credits or unsupported ontology through descriptive shorthand.
