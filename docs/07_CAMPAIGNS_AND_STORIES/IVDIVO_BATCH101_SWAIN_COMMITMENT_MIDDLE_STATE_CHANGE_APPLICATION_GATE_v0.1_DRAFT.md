## FUTURE IVDIVO / ORBITAL YOUTH

### 1. OPENING PAY-IN
Any high-attention early element must load the actual main story:
- unusual technology;
- cadet privilege;
- robot encounter;
- specialist school;
- anomaly;
- romantic encounter;
- institutional conflict.

Test:
`WHAT BOOK QUESTION / RELATIONSHIP / RESPONSIBILITY DOES THIS OPENING ELEMENT LOAD?`

If none, cut, delay, bank or causally integrate it.

### 2. COMMITMENT IS RESPONSIBILITY, NOT A FIGHT POSE
A young protagonist enters the sustained main engine when an action creates continuing responsibility or obligation.

Strong Orbital Youth forms:
- accepting a bounded mission role;
- choosing to continue an audit/investigation;
- consenting to a risky but legitimate test;
- promising a person or conscious robot something concrete;
- refusing an institutional request and accepting its consequences;
- taking responsibility for a trace/problem created by one's prior successful action.

Avoid fake commitment via arbitrary danger, debt, salary dependence, kidnapping or sudden villainy.

### 3. MIDDLE STATE-CHANGE MATRIX
For every sustained scene/chapter, track BEFORE -> AFTER on relevant axes:
- action / physical-social state;
- knowledge / evidence status;
- relationship / trust / intimacy;
- authority / access / role;
- responsibility / obligation;
- strategy / causal model;
- emotion / commitment;
- future option space.

At least one relevant axis must change in a way that matters downstream.

This is NOT permission to force a twist into every scene. A quiet scene can pass through a meaningful relationship, evidence, obligation or strategy change.

### 4. SUCCESS MAY BE THE ESCALATOR
Protected YA engine:
`COMPETENT ACTION -> REAL SUCCESS -> MORE TRUST / ACCESS / RESPONSIBILITY -> HARDER NEXT CHOICE`.

Do not make a capable adolescent artificially incompetent merely because a plotting school prefers setbacks.

### 5. NO REHASH / NO MEETING LOOP
If a technical middle starts repeating:
`new anomaly -> briefing -> explanation -> concern -> next anomaly`,
route each unit through the state-change matrix.

If the same evidence/model/relationship returns at the same status, use MERGE / SUMMARY / INDIRECT / DELETE before line editing.

This is also an anti-fragmentation rule: prettier sentences do not repair repeated state-neutral material.

### 6. ONE MAIN STORY / ENSEMBLE
Each major strand must exchange causality with the main engine:
`LOCAL ACTION -> MAIN ENGINE / ANOTHER STRAND CHANGES -> NEW OPTION OR CONSTRAINT -> LATER PAYOFF`.

Five POVs or five interesting lives are allowed. Five causally isolated mini-novels are not.

### 7. CONSCIOUS ROBOT / NONHUMAN PERSONHOOD
Structural labels never outrank personhood.

A conscious robot or nonhuman intelligence must retain:
`OWN WANT -> OWN MODEL/EVIDENCE -> OWN RELATIONSHIPS -> CONSENT/REFUSAL -> CHOICE -> CONSEQUENCE`.

Do not use a conscious being merely as `Opponent`, `Obstacle`, `Disaster`, `Mentor`, `Proof`, or emotional reward for the human protagonist.

### 8. POST-MONEY FIREWALL
Do not translate Swain's period commercial examples into salary/rent/credits.

Meaningful nonfungible stakes remain:
- trust;
- consent;
- time;
- concrete responsibility;
- unique mission/place/opportunity;
- privacy;
- reputation;
- mastery;
- belonging;
- relationship;
- evidence integrity;
- safety.

### 9. CONSCIOUSNESS-SCHOOL EPISTEMIC FIREWALL
A character's commitment to a practice or school's interpretation does not raise the interpretation to world fact.

Keep:
`PRACTITIONER OBSERVATION -> REPRODUCIBLE EFFECT -> SCHOOL INTERPRETATION -> COMPETING INTERPRETATION -> POSSIBLE ONTOLOGICAL CLAIM`.

### 10. ANTI-OBRUBKI APPLICATION
Before touching sentence length, ask:
1. Is this whole scene/unit needed?
2. Does it change a relevant state?
3. Is the material better as scene, summary, indirect dialogue or transition?
4. Is POV/evidence routing correct?
5. Does paragraphing reflect actual attention shifts?
6. Only then tune sentence rhythm.

Short sentences remain valid when functional. State-neutral microbeats do not become useful because they are combined into longer sentences.

## ACCEPTANCE TEST FOR A MIDDLE CHAPTER
A chapter is ready for prose when the room can answer:
- What prior consequence created this chapter?
- Who owns the current problem/choice?
- What is the current trackable objective or responsibility?
- What relevant state changes?
- Why does that change matter later?
- What next option/constraint does it create?
- Is the personhood/consent of every conscious participant preserved?

If these answers are weak, repair architecture before prose polish.
