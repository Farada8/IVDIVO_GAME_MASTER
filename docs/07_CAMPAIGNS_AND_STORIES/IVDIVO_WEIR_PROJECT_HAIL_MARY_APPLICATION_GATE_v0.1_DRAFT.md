# IVDIVO — PROJECT HAIL MARY APPLICATION GATE

Version: v0.1 DRAFT
Date: 2026-08-19
Source status: Andy Weir, *Project Hail Mary* — FULL READ IN PROGRESS
Authority: additive production gate only; does not supersede Founder/canon documents.

## 1. ORBITAL YOUTH — TECHNICAL SCENE ROUTER
Use:

`YOUTH/ROBOT QUESTION → MINIMUM NECESSARY TECH → TEST/ACTION → RESULT → MODEL UPDATE → CHANGED CHOICE`.

A technical scene is not paid for by novelty alone. It must change at least one: physical options, evidence, trust, authority, responsibility, strategy, emotional commitment, or future option space.

### Avoid
- encyclopedia technology tours;
- equations that prove what the story already decided;
- five consecutive `problem → calculation → answer` scenes with identical human consequences;
- fragmenting every technical inference into a one-line paragraph.

## 2. INTELLIGENT YOUTH ERROR
Competent young characters may make mistakes without becoming incompetent:

`REASONABLE MODEL FROM AVAILABLE EVIDENCE → TEST → CONTRADICTION → UPDATE`.

This is preferred over `teen ignores obvious fact so plot can happen`.

A successful technical choice is also allowed:

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST/ACCESS/RESPONSIBILITY → HARDER NEXT DECISION`.

## 3. MYSTERY / PROOF CEILING
Track evidence status explicitly:

`WORLD FACT → TRACE/SOURCE → OBSERVATION → INTERPRETATION → ALTERNATIVE → TEST → CORROBORATION/CONTEST → ACTION`.

A technically persuasive explanation cannot exceed the book's proof ceiling. Local mechanism may be proved while global origin remains UNKNOWN.

## 4. B07 — THE UNLISTED CITY
Weir's evidence ladder is useful for distributed-life recognition, but the following must remain separate:

`ANOMALOUS PATTERN → REPRODUCIBLE BEHAVIOR/TRACE → MODEL OF DISTRIBUTED ORGANIZATION → EVIDENCE OF PREFERENCE/AGENCY → PERSONHOOD CLAIM → CONSENT/REFUSAL`.

Technical pattern recognition does not automatically prove motive or personhood. Conversely, once agency/personhood has adequate evidence, the nonhuman subject must own an indispensable choice; it cannot remain cargo for Kyra's moral growth.

Kyra's protected arc remains:
`PROCEDURAL PRECISION → EVIDENCE EXCEEDS CATEGORY → BOUNDED DISCRETION → DOCUMENTED ACCOUNTABILITY`.

Do not rebuild B07 into a Weir-style science puzzle chain.

## 5. CONSCIOUS ROBOTS
Never infer:

`PREDICTED BEHAVIOR = MOTIVE = CONSENT`.

For a named conscious robot require:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

Technical competence must not erase robot personhood. Human interpretations of robot behavior remain interpretations until independently supported.

## 6. CONSCIOUSNESS SCHOOLS / METAPHYSICAL CLAIMS
Weir is a fiction mechanism laboratory, not authority for science or ontology.

Preserve:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL CLAIM`.

Scientific vocabulary, confidence, advanced instruments, or AI analysis cannot skip scarcity of long-trained practitioners or convert a school's explanatory model into established world fact.

## 7. FLASHBACK ROUTER
Use flashback when:
`CURRENT ANOMALY/CHOICE → PAST CONTEXT → PRESENT MODEL CHANGES → PRESENT ACTION CHANGES`.

If only biography is added, use summary, indirect recall, or remove it.

Avoid memory-as-answer-machine: a protagonist should not recover exactly the missing fact every time the plot needs it without a credible trigger or residual uncertainty.

## 8. TECHNICAL EXPOSITION AND PROSE RHYTHM
For IVDIVO prose:

`INTENSITY ≠ SHORT-SENTENCE DENSITY`.

Technical inference may require complete paragraphs and longer syntax so the reader can preserve the causal model. Do not write:

`He looked.\nA number.\nWrong.\nHe calculated.\nAgain.`

unless the fragmentation has a specific reader-effect function.

Repair order:
`SCENE FUNCTION → INFORMATION ORDER → POV → SHOW/TELL → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

## 9. INSTITUTIONAL COUNTERMODEL
A competent institution/opponent should be allowed genuine strength:

`CAPABILITY + URGENCY + BENEFIT + LEVERAGE + COST/BLIND SPOT`.

Do not make institutions stupid so adolescents can look intelligent. Do not make competence excuse coercion, missing consent, or absence of appeal.

## 10. LESSON ZERO BOOK ONE
No current defect found in the sequentially read Weir material warrants reopening the development-locked Book One.

Policy:
- apply this gate prospectively;
- use it diagnostically only when a concrete current passage fails;
- do not perform a wholesale Weir retrofit.

## 11. ACCEPTANCE TEST FOR A TECHNICAL SCENE
PASS only if most relevant questions have clear answers:
1. What current character question forces the technical information into the scene?
2. What is observation versus inference?
3. What could falsify the current model?
4. What does the test change?
5. What becomes possible/impossible afterward?
6. Who gains or loses trust/authority/responsibility?
7. Is the information legible from this POV?
8. Is the prose rhythm serving comprehension and suspense rather than a short-sentence metric?
9. Does any personhood/consent claim exceed the evidence?
10. Does the scene still belong to ONE MAIN STORY?
