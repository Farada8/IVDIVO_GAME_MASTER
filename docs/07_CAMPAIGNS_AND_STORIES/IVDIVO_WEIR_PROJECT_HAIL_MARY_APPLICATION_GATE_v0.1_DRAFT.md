# IVDIVO — PROJECT HAIL MARY APPLICATION GATE

Version: v0.2
Date: 2026-08-19
Source status: Andy Weir, *Project Hail Mary* — STRICT_LIFECYCLE_SYNTHESIZED_v1.0
Authority: additive production gate only; Founder/canon/locked continuity always outrank source patterns.

## 1. ORBITAL YOUTH — TECHNICAL SCENE ROUTER
Use:

`YOUTH/ROBOT QUESTION → MINIMUM NECESSARY TECH → TEST/ACTION → RESULT → MODEL UPDATE → HUMAN/RELATIONSHIP CONSEQUENCE → CHANGED CHOICE`.

A technical scene is not paid for by novelty alone. It must change at least one: physical options, evidence, trust, authority, responsibility, strategy, emotional commitment, relationship state, or future option space.

### Avoid
- encyclopedia technology tours;
- equations that merely prove what the story already decided;
- five consecutive `problem → calculation → answer` scenes with identical human consequences;
- fragmenting every technical inference into a one-line paragraph.

## 2. INTELLIGENT YOUTH ERROR AND REAL SUCCESS
Competent young characters may make mistakes without becoming incompetent:

`REASONABLE MODEL FROM AVAILABLE EVIDENCE → TEST → CONTRADICTION → UPDATE`.

Prefer this over `teen ignores obvious fact so plot can happen`.

A successful technical choice is also allowed:

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST/ACCESS/RESPONSIBILITY → HARDER NEXT DECISION`.

Do not enforce setback monoculture.

## 3. UNEVEN CIVILIZATION DEVELOPMENT — HIGH PRIORITY IVDIVO GATE
Use:

`DOMAIN A MATURITY ≠ DOMAIN B MATURITY`.

For orbital civilization this means, explicitly:
- high robotics does not imply mature science of consciousness;
- interplanetary engineering does not imply settled ontology of dimensions;
- powerful AI analysis does not create thousands of people with decades of lived contemplative/yogic practice;
- advanced instrumentation cannot replace absent historical datasets, reproducibility history, trained subjects or institutional attention;
- a rare practice school can know reproducible things unknown to mainstream academia while still being wrong about part of its explanation.

Every asymmetry needs a causal bottleneck, not arbitrary authorial convenience.

## 4. FIRST CONTACT / SHARED SEMANTICS
For human/nonhuman/robotic contact where a shared language is not already available:

`SHARED PHENOMENON → MUTUAL SIGNAL → COMMON REFERENT → NUMBER/UNIT MAP → ACTION WORDS → GRAMMAR → ABSTRACT CONCEPTS`.

World explanation should grow after common reference exists. Do not make first contact an immediate philosophy seminar.

## 5. DISTRIBUTED COMPETENCE
Before solving a large problem, separate:
- raw evidence owner;
- interpretation owner;
- specialized tool/capability owner;
- lived-consequence witness;
- competent countermodel;
- bounded decision owner.

If one protagonist owns nearly all of them, test redistribution.

Use complementary asymmetry:
`A HAS X / LACKS Y + B HAS Y / LACKS X → SHARED TASK → MUTUAL MODEL UPDATE → NEW JOINT OPTION SPACE`.

## 6. SYSTEMS-COUPLING GATE
After any genuinely successful intervention, ask:

`WHAT OTHER SUBSYSTEM DOES THIS SUCCESS ALTER?`

Possible interfaces: environment, embodiment, logistics, evidence, incentives, relationship state, access, social rules, safety, or another technology.

If a successful fix later causes a new failure, that coupling must be retrospectively inferable from established conditions. Do not use random reversal merely to extend suspense.

## 7. MYSTERY / PROOF CEILING
Track evidence status explicitly:

`WORLD FACT → TRACE/SOURCE → OBSERVATION → INTERPRETATION → ALTERNATIVE → TEST → CORROBORATION/CONTEST → ACTION`.

A technically persuasive explanation cannot exceed the book's proof ceiling. Local mechanism may be proved while global origin remains UNKNOWN.

## 8. B07 — THE UNLISTED CITY
Weir's evidence ladder is useful for distributed-life recognition, but keep separate:

`ANOMALOUS PATTERN → REPRODUCIBLE BEHAVIOR/TRACE → MODEL OF DISTRIBUTED ORGANIZATION → EVIDENCE OF PREFERENCE/AGENCY → PERSONHOOD CLAIM → CONSENT/REFUSAL`.

Technical pattern recognition does not automatically prove motive or personhood. Conversely, once agency/personhood has adequate evidence, the nonhuman subject must own an indispensable choice; it cannot remain cargo for Kyra's moral growth.

Kyra's protected arc remains:
`PROCEDURAL PRECISION → EVIDENCE EXCEEDS CATEGORY → BOUNDED DISCRETION → DOCUMENTED ACCOUNTABILITY`.

Do not rebuild B07 into a Weir-style science-puzzle chain.

## 9. CONSCIOUS ROBOTS / NONHUMAN PERSONHOOD
Never infer:

`PREDICTED BEHAVIOR = MOTIVE = CONSENT`.

For a named conscious robot/nonhuman person require:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE THAT CHANGES OTHERS' OPTIONS → CONSEQUENCE`.

Embodiment should change sensory access, motor options, vulnerability, communication, and social assumptions. Do not write a human personality in decorative machinery and call the work complete.

Reciprocal agency is preferred over passive-rescue architecture: the nonhuman person should be capable of helping, refusing, warning, saving, negotiating, or making a decision inconvenient to the human lead.

## 10. CONSCIOUSNESS SCHOOLS / METAPHYSICAL CLAIMS
Weir is a fiction mechanism laboratory, not authority for science or ontology.

Preserve:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL CLAIM`.

Scientific vocabulary, confidence, advanced instruments, or AI analysis cannot skip scarcity of long-trained practitioners or convert a school's explanatory model into established world fact.

This is where the uneven-civilization gate matters most: external technological sophistication and internal-practice knowledge can develop at very different rates.

## 11. RELATIONSHIP / A-STORY BRAID
Use:

`SHARED WORK → RELIABILITY → TRUST/BOUNDARY CHANGE → EXTERNAL OPTION SET CHANGES → COSTLY CHOICE`.

Relationship state should alter what characters do next. It must not alter what a physical/archive clue objectively proves.

Do not substitute a declaration of friendship/love for accumulated behavioral evidence.

## 12. FLASHBACK ROUTER
Use flashback when:
`CURRENT ANOMALY/CHOICE → PAST CONTEXT → PRESENT MODEL CHANGES → PRESENT ACTION/SELF-MODEL CHANGES`.

If only biography is added, use summary, indirect recall, or remove it.

Avoid memory-as-answer-machine: the protagonist should not recover exactly the missing fact every time the plot needs it without a credible trigger or residual uncertainty.

## 13. IDENTITY REVISION GATE
When new evidence revises a character's self-image:

`OLD SELF-MODEL → CONTRADICTORY EVIDENCE → REVISED SELF-MODEL → LATER BEHAVIORAL TEST`.

Do not end an arc with an explanatory sentence such as "he finally understood he was brave." Make the revised model pay in action.

## 14. TECHNICAL EXPOSITION AND PROSE RHYTHM
For IVDIVO prose:

`INTENSITY ≠ SHORT-SENTENCE DENSITY`.

Technical inference may require complete paragraphs and longer syntax so the reader can preserve the causal model.

Repair order:
`BOOK/SCENE FUNCTION → INFORMATION ORDER → POV/EVIDENCE → SHOW/TELL → DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

## 15. INSTITUTIONAL COUNTERMODEL
A competent institution/opponent should be allowed genuine strength:

`CAPABILITY + URGENCY + BENEFIT + LEVERAGE + COST/BLIND SPOT`.

Do not make institutions stupid so adolescents can look intelligent. Do not make competence excuse coercion, missing consent, absent appeal, or hidden cost.

## 16. ENDING ROUTER
For technical/SF saga volumes:

`LOCAL OPERATIONAL RESOLUTION → COST → AFTERMATH → CHANGED LIFE/RELATIONSHIP → OPTIONAL INDEPENDENT CONFIRMATION → SAGA VECTOR`.

The book may leave larger cosmological or ontological questions open if its promised local problem is actually resolved.

Do not make self-sacrifice the mandatory proof of courage, friendship or love.

## 17. LESSON ZERO BOOK ONE
No concrete defect found in the full Weir read warrants reopening the development-locked Book One.

Policy:
- apply this gate prospectively;
- use it diagnostically only when a current passage fails;
- do not perform a wholesale Weir retrofit.

## 18. ACCEPTANCE TEST FOR TECHNICAL / CONTACT SCENES
PASS only if the relevant questions have clear answers:
1. What current character question forces the technical information into the scene?
2. What is observation versus inference?
3. What could falsify the current model?
4. What does the test change beyond merely supplying an answer?
5. What becomes possible/impossible afterward?
6. Who gains/loses trust, authority or responsibility?
7. Is information legible from this POV/embodiment?
8. Are different agents genuinely complementary rather than redundantly brilliant?
9. Does a successful solution alter another subsystem in a causally prepared way?
10. Does any personhood/consent claim exceed the evidence?
11. Is nonhuman agency reciprocal?
12. Is the prose rhythm serving comprehension/reader effect rather than a short-sentence metric?
13. Does the scene still belong to ONE MAIN STORY?
