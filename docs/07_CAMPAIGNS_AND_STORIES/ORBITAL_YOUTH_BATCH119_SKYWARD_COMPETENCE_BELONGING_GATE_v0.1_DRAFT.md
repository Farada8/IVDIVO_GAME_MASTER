# ORBITAL YOUTH — BATCH 119 SKYWARD COMPETENCE / BELONGING GATE

Date: 2026-08-19
Status: ADDITIVE / PROVISIONAL
Source boundary: *Skyward* strict-read Prologue + Chapters 1–14 only.

This document does not change locked canon by itself. It adds diagnostics for future Orbital Youth development.

## 1. DO NOT BUILD ORBITAL YOUTH AS A MILITARY-SCARCITY COPY

Do not import:
- food/resource merit currency;
- salary/rent/credits;
- inherited consumer wealth as default youth engine;
- fighter-school lethal attrition as the default institution;
- humiliation/brutalization as the required path to maturity.

Translate useful functions into post-money, nonfungible stakes:
- qualification for a specific role;
- trust of a specific mentor/team;
- access to a unique mission/place/time window;
- responsibility for a real system/person;
- privacy;
- consent;
- reputation;
- belonging;
- mastery;
- relationship;
- future option space.

## 2. STRONG ORBITAL YOUTH ENGINE

Preferred progression:

`ORDINARY COMPETENCE → LIVE TEST → REAL SUCCESS OR INTELLIGENT LIMIT → UPDATED SELF-MODEL → EARNED TRUST → MORE RESPONSIBILITY → HARDER CHOICE`.

Do not default to:

`ERROR → PUNISHMENT → BIGGER ERROR → BIGGER ACCIDENT`.

## 3. FIVE-CHARACTER DREAM OWNERSHIP AUDIT

For every member of an ensemble, answer separately:

- What do they want now?
- What would they choose if the cohort dissolved tomorrow?
- What successful qualification might they still decide not to use?
- What do they enjoy that the protagonist does not?
- What social pressure might make outsiders falsely assume they share the same goal?

Fail if multiple characters exist mainly to validate the protagonist's chosen path.

## 4. INSTITUTION TWO-LAYER AUDIT

For every school, cadet program, lab, expedition, municipal body or specialist practice:

`PUBLIC IDEAL → FORMAL POLICY → ACTUAL ACCESS → INFORMAL PRESTIGE → ACTUAL BEHAVIOR → WHO BEARS COST → WHO CAN APPEAL / LEAVE`.

An institution may be useful, competent and well-intentioned while producing unfair effects through history, status or subculture. Avoid cartoon dystopia.

## 5. PARTIAL INCLUSION

A youth can be officially accepted while still lacking some combination of:
- schedule priority;
- physical access;
- information;
- mentoring time;
- participation in informal team life;
- decision rights;
- privacy;
- compatible space/equipment;
- social trust.

In post-money IVDIVO these are better stakes than financial deprivation.

## 6. PRIVILEGE / COMPETENCE FIREWALL

`UNFAIR ACCESS ≠ INCOMPETENCE`.
`COMPETENCE ≠ FAIRNESS / MORAL AUTHORITY`.

If a privileged rival exists, give them at least one real earned competence. If an outsider hero is exceptionally capable, do not let capability alone settle governance, consent or ethical questions.

## 7. EMBODIED COMPETENCE

For any new orbital skill:

`THEORY → LIVE BODY / TOOL / ENVIRONMENT TEST → LIMIT / AFFORDANCE → PRACTICE → UPDATED CAPABILITY`.

This is especially important for:
- changed gravity;
- EVA;
- environmental compatibility;
- unfamiliar control systems;
- performance/movement;
- contact interfaces;
- high-speed transport;
- work with differently embodied robots.

Do not use human consciousness-transfer bodies as a shortcut; current canon does not permit routine human transfer.

## 8. ROBOT PERSONHOOD

A conscious robot may be a trainer, peer, rival or administrator only as a temporary story function.

Required:
`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → OWN CHOICE → CONSEQUENCE`.

Do not write a universal “robot voice.” Do not treat efficient performance as moral authority.

## 9. SPECIALIST CONSCIOUSNESS SCHOOLS

A rare practice school may create social status, belonging and access pressure, but its claims remain epistemically layered:

`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → ONTOLOGY CEILING`.

Few long-term practitioners remain a real development bottleneck even in a technologically mature orbital civilization.

## 10. ORDINARY LIFE AS WORLD REVEAL

Instead of explaining the post-money system, use small causal episodes:

`ORDINARY NEED → EASY MATERIAL PROVISION → REAL NONFUNGIBLE WANT REMAINS → CHOICE / RELATIONSHIP PRESSURE`.

Example function, not canonical scene: equipment replacement is trivial, but obtaining a specific mentor's time or another person's consent is not.

## 11. LANGUAGE / CULTURE MISREADING

For silence, short speech, accent, atypical eye contact or timing:

`OBSERVE → MULTIPLE MOTIVE MODELS → CONTEXT / EVIDENCE → UPDATE`.

This applies equally to human cultures and differently embodied conscious robots.

## 12. ONE MAIN STORY CHECK

A training/qualification subplot remains only if it changes the main causal engine through:
- action;
- evidence;
- relationship;
- access;
- responsibility;
- option space;
- later payoff.

A cool school, technology or test is not sufficient reason for a parallel mini-novel.

## 13. PROSE CHECK

No Skyward cadence retrofit.

Action and technical scenes can use sustained syntax and full paragraphs. Continue to diagnose:
`SCENE FUNCTION → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE → RHYTHM`, not “make it shorter because it is exciting.”
