# IVDIVO BATCH 176 — EPHRON FAIR-PLAY MYSTERY APPLICATION GATE

**Status:** PRODUCTION GATE / WIDER-SOURCE APPLICATION  
**Applies to:** ROOM 917, B07 THE UNLISTED CITY, Orbital Youth mysteries, future IVDIVO investigations  
**Does not alter locked canon by itself.**

## 1. Mandatory clue record

For every load-bearing clue, record:

| Field | Required |
|---|---|
| Trace / claim | exact observed/reported item |
| Original source | physical/digital/person/archive/system |
| Source lineage | independent origin vs derivative repetition |
| Access | who can legitimately know/observe it |
| Reader access | when/how reader receives it |
| Initial interpretation | model A |
| Alternative interpretation | model B/C |
| Implicates / exonerates | provisional only |
| Corroboration status | observed/reported/inferred/hypothesis/corroborated/contested/disproven/unknown |
| Discriminating test | what can separate models |
| Action consequence | what changes because of it |
| Proof ceiling | strongest conclusion currently licensed |

## 2. Fair-play gate

PASS only if:
- the literal trace remains true after reveal;
- source/access are legitimate;
- red herring is a plausible interpretation, not an authorial lie;
- reader had enough information to reconstruct the final model retrospectively;
- close POV did not suppress already-active knowledge solely for surprise;
- culprit/entity model did not receive a final-act personality transplant.

## 3. Behavior/motive firewall

Never promote:
`pause / flinch / eye contact / silence / clothing / evasive wording → motive fact`.

Use:
`behavior → hypothesis → alternative model → corroboration`.

For conscious robots/nonhuman persons, human interpretation of compliance/refusal is also only an interpretation until their own model/preference is established.

## 4. Investigation scene admission

Use FULL REAL-TIME SCENE when exact words/actions change:
- evidence status or provenance;
- consent;
- relationship/trust/boundary;
- authority/access;
- decision ownership;
- investigative model/tactic.

Use SUMMARY / INDIRECT / EMBEDDED SCENE for:
- repetitive search;
- routine setup;
- known procedure;
- travel/logistics;
- repeated confirmations that do not change state.

## 5. ROOM 917

Maintain separate columns for:
`WORLD FACT / AUDIO-PHYSICAL TRACE / ELENA ACCESS / JULIAN ACCESS / READER ACCESS / SOURCE LINEAGE / INTERPRETATION / CORROBORATION / NEXT TEST`.

Absolute firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

A relationship beat may change disclosure/access/tactic. It may not change what the physical clue proves.

## 6. B07 — THE UNLISTED CITY

Personhood cannot be proved by several outputs from one classifier or one sensor lineage.

Required:
`INDEPENDENT TRACE A + INDEPENDENT TRACE B + ENTITY-OWN COMMUNICATION / PREFERENCE + ALTERNATIVE EXPLANATION TEST`.

After threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Humans do not decide the entity's continuity among themselves.

## 7. Consciousness schools

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Intuition, vividness and prestige are hypothesis/context, not proof.

`SUSPENSE PRESSURE → SUBJECTIVE DURATION CHOICE → PARAGRAPH INTENT → SENTENCE CONTRAST`.
