# IVDIVO — BATCH 191 APPLICATION GATE
## Booker: Collective Models · Worldview Infrastructure · Polarity Firewall

## Scope
Use only the retained causal/worldview mechanisms from Booker Ch31–33. Jungian, gender-essentialist, religious-metaphysical and psychohistorical universals are **not** IVDIVO canon or science.

## A. ONE MAIN STORY
A worldview/institutional strand earns space only when:

`STRAND → CHANGED STATE → DOWNSTREAM DEPENDENCY / PAYOFF`.

A philosophical discussion with no changed evidence, relationship, responsibility, option or action is not progression.

## B. Institutional model audit
For any school, administration, lab, cohort, archive or conscious-robot institution:

1. What is the official model?
2. What real benefit makes competent people defend it?
3. What access/status/reward reinforces it?
4. What evidence does it privilege?
5. What evidence becomes hard to see?
6. What outlier trace could distinguish the model from alternatives?
7. Who can challenge/appeal/refuse?
8. What changes if the model is wrong?

`COMPETENCE ≠ LEGITIMACY`.
`ORDER / STABILITY ≠ CONSENT`.

## C. Worldview-in-action gate
Do not explain a culture's worldview first. Show:

`BELIEF / MODEL → RULE / RITUAL / LANGUAGE / ARCHITECTURE / ROLE → PERSON-SPECIFIC AFFORDANCE OR FRICTION → CHOICE → CONSEQUENCE`.

### Orbital Youth
Post-money society should appear through normal attention:
- ordinary reproducible goods are background;
- time, consent, trust, privacy, responsibility, mastery, belonging, relationships and unique opportunities remain consequential.

Do not re-import salary/rent/credits as familiar YA stakes.

## D. Third-model gate
When the story presents two competing models:

`MODEL A: explains / misses`
`MODEL B: explains / misses`
`DISCRIMINATING EVIDENCE / CONSEQUENCE`
`THIRD MODEL only if it explains more without hiding costs`.

Do not manufacture compromise merely to seem balanced.

`OWN PRIORITY → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`.

`MORE SENSORS ≠ OMNISCIENCE`.
`HUMAN INTERPRETATION OF ROBOT BEHAVIOR ≠ ROBOT MOTIVE`.
