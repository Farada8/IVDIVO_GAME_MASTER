## Purpose

## A. Orbital Youth
### A1. World-rule description
Use:
`WORLD RULE → WHO NOTICES → WHY NOW → AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

Reject technology-tourism paragraphs that can be removed without changing behavior, relations or understanding.

### A2. Post-money normality
Show abundance partly through **low attention**: ordinary manufactured goods and routine provisioning need not be narrated as acquisition problems.

Concentrated attention belongs to genuinely nonfungible stakes:
- consent;
- another person’s time;
- trust;
- privacy;
- relationship;
- role/responsibility;
- specialist expertise;
- unique mission/opportunity;
- lived experience.

Do not replace money with `credits`, `points`, `allocation score`, prestige score or reputation-as-currency unless current canon explicitly establishes such a mechanism.

### A3. Technical observation
For a competent young character:
`OBSERVE → SELECT DETAIL → RELATE → HYPOTHESIZE → TEST / SEEK CORROBORATION → ACT`.

Do not write `technical vocabulary → correct conclusion` as a shortcut to intelligence.

## B. Conscious robots and nonhuman persons
### B1. Selective attention
Use:
`EMBODIMENT + OWN WANT + TASK + RELATIONSHIP + KNOWLEDGE LIMIT → SALIENCE`.

Never assume that more sensors equal omniscience.

### B2. No universal robot prose
A robot should not automatically narrate through diagnostic readouts.

Ask:
- what matters to this specific person now?
- what does this embodiment make easy/hard to perceive?
- what is being ignored because it is normal?
- what is uncertain despite available sensors?

### B3. Perception is not motive
`OBSERVED BEHAVIOR / SIGNAL ≠ MOTIVE ≠ CONSENT`.

## C. Mystery / suspense / evidence
### C1. Description-driven inference
Use:
`TRACE → ATTENTION → RELATION/PATTERN → HYPOTHESIS → ALTERNATIVE MODEL → CORROBORATION`.

### C2. Evidence fields are immutable by style
Do not beautify or compress away fields whose exactness is causal:
source, order, timestamp, dimensions, wording, provenance, confidence/status.

### C3. Productive uncertainty
Permit precise description of an uncertain phenomenon.

Use explicit or implicit distinction:
`NOTICED / INFERRED / UNKNOWN`.

Do not reward vivid description by upgrading it to proof.

## D. Consciousness-practice schools
Maintain:
`PRACTICE OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGY CEILING`.

A vivid, personally transformative experience can be narrated at full intensity while remaining epistemically unproven.

## E. ROOM 917
Description may control attention to:
- receiver;
- switchboard indicator;
- sealed wall;
- recorder;
- service architecture;
- physical distance between Elena and Julian.

But:
`VISUAL / ACOUSTIC SALIENCE ≠ EVIDENCE STATUS`.

Romantic attention can change trust, access and next investigative action; it cannot replace corroboration.

## F. Anti-choppy prose gate
Before sentence edits, run:
1. Is the scene necessary?
2. Whose attention owns the paragraph?
3. What selected details form one perceptual/thought movement?
4. Does the list have a vector?
5. Does an inference actually emerge?
6. Is a paragraph break marking a real change?
7. Only then tune sentence length/rhythm.

Do not create:
`OBJECT → fragment → OBJECT → fragment → microgesture → fragment → theme sentence`.

## G. LESSON ZERO lock
No automatic rewrite.

Open a section only if a current-manuscript defect is demonstrated, such as:
- generic camera description;
- technology catalogue without action consequence;
- paragraph confetti inside one attention-state;
- sensory checklist;
- evidence beautification;
- abstraction stated before the character can earn it through perception.

Otherwise preserve development lock.

## H. Acceptance checks
PASS if:
- description belongs to a specific perceiving person;
- selected detail changes experience/model/action or earns lived reality;
- accumulation has direction;
- abstraction is earned or necessary;
- epistemic status survives poetic language;
- nonhuman sensor abundance does not become omniscience;
- paragraph and rhythm serve the attention movement.

FAIL/WATCH if:
- the same paragraph could belong to any POV;
- worldbuilding reads like a product catalogue;
- every sensory channel is checked off;
- every image is followed by thematic explanation;
- metaphor silently becomes ontology;
- evidence is altered for elegance;
- short paragraphs fragment one continuous attention-state.
