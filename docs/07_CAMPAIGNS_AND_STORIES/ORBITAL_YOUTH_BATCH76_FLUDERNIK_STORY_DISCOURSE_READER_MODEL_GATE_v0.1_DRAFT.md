# VERDICT
**REPAIR / ROUTE; DO NOT REBUILD BY THEORY.**
Fludernik supplies diagnosis for presentation, POV and reader-model problems. It does not replace the accepted causal engine or impose a new plot template.

# 1. POST-MONEY ORBITAL LIFE
Do not explain post-money civilization in exposition unless a character actually needs that information.
Use selective lived details that alter ordinary action:
- an ordinary object is trivially available while a specific person's time is not;
- access depends on responsibility/qualification rather than purchasing power;
- a unique mission slot or rehearsal window cannot be manufactured;
- trust, consent, relationship, reputation and mastery remain scarce/nonfungible.

Reader-default problem:
If the text is too vague, readers may reconstruct salary/rent/credits from present-day habits. Override that default through causal everyday evidence, not a lecture.

# 2. CONSCIOUS ROBOTS
Hard firewall:
`HUMAN POV INTERPRETATION OF ROBOT → NOT ROBOT MOTIVE`.

Track separately:
- robot's observable action;
- robot's own statement;
- human interpretation;
- institutional classification;
- independently supported world fact.

No generic `robot voice`. A conscious robot may narrate/focalize and remains a person regardless of human resemblance.

# 3. CONSCIOUSNESS / PRACTICE SCHOOLS
Use nested narrative levels:
`PRACTITIONER OBSERVATION → REPRODUCIBLE PRACTICE EFFECT → SCHOOL INTERPRETATION → COMPETING SCHOOL INTERPRETATION → POSSIBLE ONTOLOGICAL FACT`.

A canonically real school may canonically be wrong. A character's genuine unusual experience does not prove souls/dimensional worlds/body-transfer technology.

# 4. MYSTERY FAIR PLAY
Maintain five columns in clue/evidence ledgers:
1. WORLD FACT
2. SOURCE / TRACE
3. CHARACTER / INSTITUTION INTERPRETATION
4. DISCOURSE PLACEMENT
5. CURRENT READER MODEL

A reveal may reorder or recontextualize true evidence; it may not depend on authorial falsehood.

Early-frame rule:
If early chapters deliberately induce Model A, later Model B needs enough contradiction/evidence for a fair reframe and retrospective support.

# 5. ENSEMBLE / ONE MAIN STORY
Separate character lives are welcome. They converge causally only when one strand changes another strand's:
- action;
- evidence;
- relationship;
- access;
- decision;
- cost.

`MEETING + RECAP` is not convergence.

# 6. OPENING ORIENTATION BUDGET
An orbital adolescent need not explain normal orbital life. But first pages cannot simultaneously demand the reader learn too many independent unknowns:
- social system;
- city geography;
- robot ontology;
- specialist-school terminology;
- new relationship network;
- mystery anomaly.

Reduce axes or stage them causally.

# 7. QUIET SCENE GATE
A quiet scene survives when it changes at least one later-relevant state:
`relationship / identity / obligation / knowledge / evidence-status / model / future choice`.
Quiet does not mean filler; atmosphere alone is not progression.

# 8. ANTI-"ОБРУБКИ" ROUTER
Before sentence editing:
`CAUSAL ENGINE → SCENE NECESSITY → ORDER/DURATION/FREQUENCY → POV/FOCALIZATION → SHOW/TELL → DIALOGUE MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If routine transit/procedure is being microdramatized, compress it before merging sentence fragments.

# 9. DESCRIPTION / WORLD DETAIL
Do not apply `every detail must pay off` mechanically.
A detail may legitimately pay as:
- lived reality;
- POV/characterization;
- social norm;
- spatial orientation;
- memory;
- rhythm/atmosphere.
But concentrated emphasis creates an expectation of higher significance.

# 10. BOOK ONE LOCK
No Fludernik result alone justifies reopening development-locked LESSON ZERO Book One. Reopen only for a concrete current defect or external reader evidence.

# ACCEPTANCE TEST
Before approving a scene/chapter, answer:
- What is true in the world?
- Who knows what?
- Who merely believes what?
- Who is speaking/perceiving/evaluating?
- Why is information placed here?
- What model does the reader currently hold?
- Does this scene alter a later-relevant state?
- Is the problem structural/discourse-level before line edit begins?
