# IVDIVO BATCH 163 — CHARACTER ARC / FORMULA FIREWALL — APPLICATION GATE

## Purpose
Prevent structure/arc frameworks from overwriting live IVDIVO story evidence.

## Mandatory pre-check
Before any rewrite proposed from a craft framework, answer:
1. What **observed defect** exists in the current manuscript?
2. At what level is it: book engine / chapter / scene / character-personhood / POV-evidence / dialogue-subtext / paragraph-rhythm / wording?
3. Which single framework is being used as a diagnostic lens?
4. What does it predict?
5. Does the repair preserve canon, personhood, causality and ONE MAIN STORY?
6. Would the repair still be desirable if the framework's beat-name were removed?

If #6 = NO: **DO NOT APPLY.**

## Arc Gate
Use:
`CURRENT MODEL / VALUE → PRESSURE / EVIDENCE → CHOICE → CONSEQUENCE → UPDATE OR TESTED STABILITY`

Do not require wound, Ghost, Lie, moral Truth, mentor, breakup, Dark Night, final battle, redemption or happy ending.

## Cast Gate
`BOOK FUNCTION ≠ STORYWORLD PERSONHOOD`.

For every named conscious supporting person/nonhuman require own want, own evidence/model, own relationships, consent/refusal and consequential choice.

## YA Gate
Do not purchase depth with trauma.

Preferred post-money stakes: trust, consent, time, responsibility, specific access, unique mission/opportunity, privacy, mastery, reputation, belonging and relationship.

## Mystery Gate
`CHARACTER BELIEF ≠ WORLD FACT`.

Route:
`TRACE/SOURCE → OBSERVATION → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION → STATUS UPDATE`.

## Scene/Prose Gate
Warner's formulae do not modify the standing anti-chop router:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → POV/EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

`ACTION / SUSPENSE ≠ SHORT-SENTENCE DENSITY`.
