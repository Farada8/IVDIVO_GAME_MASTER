# IVDIVO — BATCH 136 APPLICATION GATE
## Bickham Observation · Scene · Processing · Story Compass

**Scope:** additive production gate. It does not override locked canon or reopen a development-locked manuscript by itself.

## 1. LESSON ZERO protection

Book One remains development-locked. Batch 136 authorizes a patch only if a current concrete defect is found, such as:

- observation presented as fact when it is only inference;
- scene with no meaningful changed state;
- unrelated complication that does not affect the main causal engine;
- redundant full-scene dramatization that should be summary/embedded scene;
- processing rendered as repetitive microbeat fragments;
- outline/canon mismatch that creates a real continuity defect.

A new craft theory alone is not evidence for a rewrite.

## 2. ONE MAIN STORY gate

For each chapter/scene, record:

`PRIOR CONSEQUENCE → OWNER / PRESENT WANT → PRESSURE / SUPPORT → TACTIC → CHANGED STATE → DOWNSTREAM DEPENDENCY`

A new subplot, technology, school, relationship beat, or anomaly is accepted only if it changes the dominant causal engine or is banked for another book.

## 3. Scene outcome gate

Do not force a Bickham-style disaster.

Valid outcomes include:
- failure;
- partial success;
- costly success;
- genuine success;
- correct restraint;
- new evidence;
- changed trust/relationship;
- new authority/access;
- new responsibility;
- narrowed or expanded future options.

Preferred YA escalation when appropriate:

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`

## 4. Technical / institutional scene routing

Before dramatizing a process in real time, ask:

1. Do exact words/actions change consent, evidence, authority, relation, decision, or emotion?
2. Is there one bull's-eye moment inside otherwise routine process?
3. Can the process be summary/indirect with one embedded real-time moment?

Use:

`SUMMARY → BULL'S-EYE MOMENT → SUMMARY / CHANGED STATE`

Avoid `meeting → model → test → review → meeting` as a sequence of equally weighted scenes.

## 5. Observation and evidence

Every significant descriptive/evidentiary item is tagged:

`OBSERVED / REPORTED / INFERRED / HYPOTHESIS / CORROBORATED / CONTESTED / UNKNOWN`

Human interpretation of robot/nonhuman behavior does not become motive. School terminology does not become ontology.

## 6. Post-money orbital firewall

Ordinary future life must not quietly regenerate salary/rent/credits through terms such as allocation, contribution, priority, qualification, access, or status.

If such a term matters, identify the real mechanism and the nonfungible stake: time, consent, trust, privacy, concrete responsibility, unique mission/slot, relationship, mastery, belonging, reputation, or safety.

## 7. Conscious nonhuman personhood

Once personhood threshold is met, preserve:

`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → CHOICE → CONSEQUENCE`

A human protagonist may create options or provide evidence; they do not automatically own the nonhuman agent's final decision.

## 8. Consciousness-practice epistemics

Never collapse:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`

Narrative clarity, intensity of experience, prestige of a school, or technological sophistication do not substitute for evidence.

## 9. Anti-choppiness gate

Before line editing:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT/MODE → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → OBSERVATION/INFERENCE → DIALOGUE/PROCESSING → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`

When several short sentences/paragraphs represent one continuous perception or decision, test merge/restructure first. Do not optimize a short-sentence percentage.

## 10. Adaptive planning gate

Treat outline as hypothesis.

For emergent live material:

`CHARACTER TRUTH? → CANON? → CAUSAL CONSEQUENCE? → IMPROVES ONE MAIN STORY? → REPLAN / BANK / DISCARD`

Do not suppress stronger character-true material merely because an older outline says otherwise; equally, do not canonize every spontaneous idea.

## Release criterion

Batch 136 passes when structural/evidence problems are repaired before sentence polish, scene outcomes remain varied and earned, and all new material preserves ONE MAIN STORY, personhood, canon, and epistemic status.
