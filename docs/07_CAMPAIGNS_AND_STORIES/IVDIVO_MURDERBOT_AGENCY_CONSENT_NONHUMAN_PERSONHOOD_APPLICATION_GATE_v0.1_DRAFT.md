# IVDIVO — NONHUMAN AGENCY / CONSENT / PERSONHOOD APPLICATION GATE

Date: 2026-08-19
Status: WORKING / ADDITIVE
Source basis: Martha Wells *All Systems Red* (prior strict-complete Core #27) + *Artificial Condition* (new strict-complete reference source).

## Mandatory firewalls

1. **Personhood ≠ humanity.** Do not use human resemblance as the progress metric for robots/nonhuman persons.
2. **Observed behavior ≠ motive.** Establish control provenance and available choice.
3. **Body modification requires subject consent.** Optimization by designers/caretakers does not override decision ownership.
4. **Intelligence ≠ moral authority.** Compute advantage does not create legitimacy.
5. **Control removed ≠ liberation complete.** Audit downstream social/legal/institutional dependencies.
6. **Relationship state ≠ evidence status.** Trust can unlock evidence; it cannot alter what evidence proves.
7. **Autonomy ≠ isolation.** Chosen teams/roles/relationships can be evidence of autonomy.
8. **Nonhuman relationship ≠ compulsory human template.** Romance/family/pet coding is optional, not default.
9. **Corporate scarcity ≠ orbital-city norm.** Do not import contracts/salary/rent/credits from Murderbot worldbuilding.
10. **Governor-module fiction ≠ consciousness ontology.** No inference to soul transfer, body transfer or dimensional science.

## B07 — THE UNLISTED CITY

Once evidence establishes the distributed life as a person, the climax must stop treating it as preservation cargo.

Required architecture:
`HUMAN EVIDENCE MODEL → PERSONHOOD THRESHOLD → ENTITY'S OWN MODEL/PREFERENCE → CONSENT OR REFUSAL → HUMAN OPTION SPACE CHANGES → BOUNDED ACCOUNTABLE DECISION`.

At least one outcome-critical choice must belong to the nonhuman person itself.

## Orbital Youth

For every named conscious robot/nonhuman person, verify:
- What do they want when the protagonist is absent?
- Which other relationships do they have?
- What can they refuse?
- What information/model do they possess independently?
- Which choice of theirs changes human options?
- How does embodiment alter what they can perceive/do without defining their moral worth?

If these answers are missing, the character is still functioning as equipment.

## Ensemble climax

Preferred distributed-intelligence structure:
`EVIDENCE HOLDER → INTERPRETER → EMBODIED OPERATOR → LIVED-EXPERIENCE WITNESS → COMPETENT COUNTERMODEL → LEGITIMATE DECISION OWNER`.

Do not collapse all six functions into one prodigy protagonist.

## Consciousness-school firewall

Maintain:
`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → POSSIBLE ONTOLOGICAL FACT`.

Fictional control technology from reference novels cannot move an IVDIVO claim upward on this ladder.
