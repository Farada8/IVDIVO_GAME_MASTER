# IVDIVO BATCH 164 APPLICATION GATE
## Mayer — Plan vs Actual · Story-State Infrastructure · Defect-Level Routing

**Status:** DRAFT / ADDITIVE / NO CANON OVERRIDE

## Standing law
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

This gate does not reopen locked manuscripts merely because a new craft source has been read.

## A. Four-ledger separation
For complex IVDIVO books/projects maintain, conceptually or explicitly:

1. **PLAN** — intended future structure;
2. **ACTUAL** — what current locked/draft text actually contains;
3. **CANON** — authorized world/character facts;
4. **EVIDENCE STATUS** — what characters/readers can presently prove or infer.

Never silently merge them.

### Hard fail
A planned beat is treated as if it already happened in prose, or a character inference is promoted into canon because it appears in a planning file.

## B. Chapter state record
For a chapter under diagnosis record:

`START STATE → OWNER/WANT → REQUIRED CAUSAL EVENTS → EXIT STATE → DOWNSTREAM DEPENDENCY`.

State axes:
- operational/physical;
- knowledge/evidence;
- relationship/trust;
- consent/boundary;
- authority/access;
- responsibility/obligation;
- strategy/model;
- future option space.

If the chapter changes none of these in a way later material depends on, test SUMMARY / MERGE / DELETE / REBUILD before line editing.

## C. Reader-time weight
`TEXTUAL DURATION / SPACE` signals importance.

Protect full real-time treatment for:
- irreversible choice;
- evidence-status change;
- consent/refusal;
- relationship terms change;
- authority/responsibility shift;
- personhood threshold;
- model revision with downstream action.

Compress routine process/logistics unless exact sequence itself is causal.

## D. Research / mystery provenance
Research notes and in-story evidence must preserve source lineage.

`CLAIM → SOURCE → OBSERVATION → INTERPRETATION → ALTERNATIVE MODEL → CONFIDENCE → ACTION`.

Expert fluency is not corroboration.

## E. LESSON ZERO
Do not compare old planning docs against the locked manuscript and automatically “repair” every difference.

Allowed intervention only if PLAN-vs-ACTUAL comparison reveals a **current defect**, such as:
- continuity contradiction;
- duplicated function;
- causal gap;
- evidence/provenance error;
- state-neutral scene consuming disproportionate reader time;
- concrete reader/audio comprehension failure.

Otherwise keep development lock.

## F. Orbital Youth / future books
Do not let planning terminology reintroduce old world assumptions.

Separate:
- planned allocation/access rule;
- actual lived mechanism;
- canon post-money rule;
- POV interpretation.

A plan containing `credits`, `rent`, `salary` or routine consciousness-transfer does not become canon through repetition.

## G. Conscious nonhuman persons
Character/state registry must distinguish:
- human interpretation of entity behavior;
- entity's own demonstrated want/model;
- consent/refusal;
- independent decision;
- resulting change to human option space.

`SYSTEM CLASSIFICATION ≠ PERSONHOOD STATUS`.

## H. ROOM 917 / audio runtime
Current exact-text and scene-state artifacts are examples of the correct direction: derive production state from locked text rather than from a speculative outline.

Use:
`LOCKED TEXT → TEXT UNIT MAP / ACTUAL STATE → PRODUCTION PLAN`.

Do not reverse this into:
`PRODUCTION PLAN → retroactively alter story fact`.

Evidence remains separately tracked:
`TRUST / PERFORMANCE / ROMANCE STATE ≠ CORROBORATION`.

## I. Defect router before prose polish
`OBSERVED EFFECT → ENGINE? → CHAPTER? → SCENE? → POV/EVIDENCE? → DIALOGUE/EXPOSITION? → PARAGRAPH? → RHYTHM? → WORDING?`

Repair at the highest broken level first.

## J. Anti-fragmentation consequence
Before merging/lengthening sentences, ask whether the underlying passage is over-dramatized process.

`SCENE NECESSITY → MODE/WEIGHT → PARAGRAPH UNIT → READER-STATE CONTINUITY → SENTENCE RHYTHM`.

The cure for choppy prose may be summary, deletion or paragraph reconstruction—not longer sentences.
