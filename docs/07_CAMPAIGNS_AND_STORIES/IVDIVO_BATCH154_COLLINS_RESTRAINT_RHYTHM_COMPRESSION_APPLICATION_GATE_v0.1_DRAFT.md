# IVDIVO — BATCH 154 APPLICATION GATE
## Collins: Restraint / Sentence Rhythm / Compression

Purpose: apply Collins only where a concrete manuscript defect exists. This file does not authorize global rewriting of development-locked work.

## Standing law
`NO NEW EVIDENCE -> NO NEW GLOBAL REWRITE`

## A. Cadence gate
Before changing sentence length, record:
1. intended reader effect;
2. dominant POV experience;
3. subjective duration/continuity;
4. paragraph function;
5. current cadence defect.

Reject any edit justified only by:
- 'more suspense needs shorter sentences';
- 'make prose punchier';
- target short-sentence percentage;
- target one-line-paragraph percentage.

## B. Fragment / choppiness gate
For every suspicious fragment cluster:
`SAME ACTOR? + SAME TIME? + SAME PLACE? + SAME FOCUS? + SAME DECISION/PERCEPTION UNIT?`

If mostly YES, test one coherent paragraph or sentence before local polishing.

## C. Compression router
Compression options, in preferred diagnostic order:
1. delete duplicated meaning;
2. summarize routine process;
3. indirect-report non-load-bearing dialogue;
4. merge microbeats;
5. choose a more specific load-bearing word;
6. shorten only when the resulting rhythm is actually better.

Compression must preserve:
- mystery provenance;
- clue order/status;
- consent/boundary beats;
- character-specific voice;
- setup/payoff;
- protected pauses;
- ordinary-life character evidence.

## D. Evidence-safe wording
When a verb contains an inference, mark it:
`OBSERVATION / POV INTERPRETATION / CORROBORATED CLAIM`.

Do not let vivid prose convert hesitation into guilt, compliance into consent, unusual sensor behavior into motive, or a practitioner's experience into ontology.

## E. ROOM 917
Use rhythm to differentiate processing without damaging clue fairness.
- Elena: controlled external phrasing can coexist with rapid internal evidence processing.
- Julian: restraint may appear through timing, omission, refusal to press, and precise disclosure; do not reduce him to clipped alpha-male dialogue.
- clue sounds/readouts: evidence status remains independent of emotional cadence.

Permanent firewall:
`TRUST / ATTRACTION / INFLECTION / SILENCE != CORROBORATION`.

## F. Orbital Youth
Do not create one universal 'teen under pressure' cadence.
For each POV track:
`SALIENCE -> THRESHOLD -> INNER/OUTER RHYTHM -> TACTIC -> CHANGED STATE`.

Competent success remains allowed:
`SUCCESS -> MORE TRUST/ACCESS/RESPONSIBILITY -> HARDER NEXT CHOICE`.

## G. Conscious nonhuman persons
No human-panic default. Derive prose rhythm from:
`EMBODIMENT + OWN PRIORITIES + PROCESSING LIMITS + RELATIONSHIP + CURRENT TASK + CONSENT/REFUSAL`.

Behavioral timing is evidence about behavior, not automatic evidence about motive.

## H. LESSON ZERO
Current decision: KEEP DEVELOPMENT LOCK.
Open a passage only when there is concrete evidence of one of the following:
- paragraph confetti / choppy continuity;
- duplicated explanation;
- unnecessary real-time process;
- evidence wording that overstates proof;
- cadence regression that damages character voice or reader comprehension.

After edit: rerun causal, clue, setup/payoff, character, and audio/read-aloud regression. A smoother line that weakens story evidence is a failed edit.
