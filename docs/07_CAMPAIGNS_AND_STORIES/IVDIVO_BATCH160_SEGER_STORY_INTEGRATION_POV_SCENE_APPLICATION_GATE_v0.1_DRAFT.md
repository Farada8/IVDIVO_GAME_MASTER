## PURPOSE
Apply Seger Chapters 2–7 without retrofitting IVDIVO novels/audio to screenplay percentages or mandatory three-act arithmetic.

## GLOBAL LAW
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

New craft knowledge may open a manuscript only when it identifies a concrete present defect.

## ONE MAIN STORY
A secondary line is admitted as a true subplot only when:

`LOCAL OBJECTIVE → LOCAL CHANGE → EFFECT ON MAIN CAUSAL ENGINE / MAJOR LATER CHOICE → PAYOFF`.

Otherwise classify it as thread, texture, relationship presence, motif, or ordinary-life material and budget accordingly.

### REJECT
- five parallel mini-novels that never alter one another;
- subplots added solely to make the middle feel busy;
- relationship material that never changes external choices;
- technology/worldbuilding strands with no downstream causal payment.

## MOMENTUM GATE
Before adding a new incident ask:
1. Which state variable has stopped changing?
2. Is the next scene changing evidence, relationship, access, responsibility, model, consent, objective, or future option space?
3. Can an already introduced event generate the needed consequence?

`MOMENTUM = CAUSAL STATE CHANGE + PRESSURE ON THE NEXT OPTION`.

Do not repair weak momentum with louder action by default.

## YA ESCALATION
Preferred available pattern:

`COMPETENT ACTION → REAL SUCCESS → MORE TRUST / ACCESS / RESPONSIBILITY → HARDER NEXT CHOICE`.

Do not force teenage protagonists to become incompetent merely to manufacture setbacks.

## ORBITAL YOUTH
- Qualification/success may be a major turn if it changes access/responsibility.
- A technology is not a new scene function merely because it is novel.
- Repeated training/test/setup sequences should be grouped into a scene sequence or compressed.
- Relationship subplots must change later decisions while preserving independent personhood.
- Post-money stakes remain trust, role, responsibility, consent, time, belonging, reputation, mastery, privacy, unique opportunity, safety.
- Do not import screenplay page percentages or contemporary money/status shortcuts.

## ROOM 917
### Mystery / romance braid
Relationship state may alter:
- willingness to disclose;
- access to a source/location;
- interpretation;
- investigative tactic;
- risk accepted for another person.

Hard firewall:
`TRUST / ATTRACTION / KISS / CONFESSION ≠ CORROBORATION`.

### Fair surprise
A reveal may make Elena reinterpret a true trace.
It may not retroactively alter a timestamp, source, physical measurement, recording content, or provenance simply for surprise.

### Scene sequence
Technical investigation may be organized as:
`SEQUENCE QUESTION → test 1 → evidence update → test 2 → relational/access change → sequence payoff`.

Routine recorder setup, walking, reconnecting, replaying known material, or repeated briefing should be summary/indirect unless exact sequence changes clue status or relationship terms.

## B07 — THE UNLISTED CITY
Personhood evidence is a structural turn when it changes decision ownership:

`PATTERN → INDEPENDENT PERSONHOOD EVIDENCE → HUMAN CATEGORY FAILS → ENTITY PREFERENCE / CONSENT BECOMES DECISION-RELEVANT → HUMAN OPTION SPACE CHANGES`.

After personhood threshold:
- the entity is not a subplot-object for Kyra's growth;

Repeated human meetings that merely restate category failure should be merged/compressed.

## POV GATE
For every switch:
`WHY THIS MIND NOW? → WHAT UNIQUE KNOWLEDGE / EXPERIENCE / RELATION / DECISION DOES IT BUY? → WHAT CHANGES BECAUSE THE READER ENTERED IT?`

No POV distribution for ensemble fairness alone.

## EXPOSITION GATE
`WHO NEEDS/WANTS TO KNOW/SAY X? → WHY NOW? → SOURCE/ACCESS → MINIMUM NECESSARY INFORMATION → CHANGED ACTION/MODEL`.

If no story-internal owner exists, use narration/document/summary or restructure.

## FLASHBACK GATE
`WHY DOES PAST MATERIAL NEED READER-TIME NOW? → WHAT PRESENT INTERPRETATION/EVIDENCE/RELATION/DECISION CHANGES?`

If nothing changes, compress or omit.

## UNITY / REPETITION GATE
Every recurrence must develop:
`ELEMENT RETURNS → CONTEXT/FUNCTION/MEANING CHANGES`.

For clue/payoff:
`SETUP EXISTS → PAYOFF OCCURS → READER CAN RETROSPECTIVELY CONNECT THEM`.

## CHANGE IMPACT MAP
Before accepting any structural rewrite trace:
- earlier setup;
- source/evidence provenance;
- character motive;
- relationship state;
- authority/access;
- later payoff;
- series continuity.

No isolated structural patch.

## ANTI-CHOPPY / LINE-EDIT ORDER
`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION → SCENE WEIGHT/MODE → EVENT TARGET → POV/EVIDENCE → EXPOSITION OWNERSHIP → PARAGRAPH INTENT/READER-STATE → SENTENCE RHYTHM → WORDING`.

`MOMENTUM ≠ SPEED ≠ SHORT-SENTENCE DENSITY`.

Do not fragment prose to simulate movement when the real defect is state-neutral scenes, repeated information, over-dramatized process, or weak causality.
