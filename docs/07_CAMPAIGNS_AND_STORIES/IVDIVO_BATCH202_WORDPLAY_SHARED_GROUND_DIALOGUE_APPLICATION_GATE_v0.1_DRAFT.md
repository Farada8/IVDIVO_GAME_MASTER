# IVDIVO BATCH 202 APPLICATION GATE
## Wordplay · Shared Ground · Dialogue · Mystery Evidence

**Authority class:** additive production gate; does not override canon or manuscript locks.

## 1. LESSON ZERO
Standing decision: **NO GLOBAL REWRITE**.
Apply only when current reader/audio evidence shows one of:
- multiple characters sharing the same witty/pun register;
- a joke/allusion whose required shared ground was never established;
- wordplay obscuring consent, clue status or causal information;
- after-joke explanation producing choppy/redundant prose.

Repair sequence:
`OBSERVED EFFECT → CHARACTER OWNERSHIP → SHARED GROUND → FUNCTION → PARAGRAPH/RHYTHM → MINIMAL FIX → RETEST`.

## 2. ORBITAL YOUTH
Future-youth humour must be generated from:
`WORLD NORM + ROLE + RELATIONSHIP + PRESENT WANT + KNOWLEDGE`.

Do not use contemporary Earth slang as the primary youth marker. Different teens may use procedure literalism, institutional mockery, technical deadpan, observational humour, understatement, language mixing or no wordplay at all.

Post-money life should also shape jokes: ordinary manufactured objects are weak status signals; time, access, trust, consent, mastery, belonging and unique experience are stronger social material.

## 3. ROOM 917
For any sarcasm/double entendre/pun that touches the investigation, store:
`SURFACE LINE → SECONDARY READING → ELENA DECODES? → JULIAN DECODES? → READER DECODES? → RELATIONSHIP EFFECT → EVIDENCE EFFECT`.

Default evidence effect = **NONE**.

Hard firewall:
`PUN / SARCASM / DOUBLE ENTENDRE / INFLECTION / SILENCE / ATTRACTION ≠ CORROBORATION`.

If audio adaptation changes a homophone or wordplay:
- preserve character/relationship function;
- preserve clue provenance and evidence status;
- do not alter exact clue wording if that wording is load-bearing without explicit authority/version update.

## 4. B07 / NONHUMAN PERSONHOOD
Human labels, jokes, nicknames or metaphors applied to a distributed/nonhuman entity are human interpretive frames, not personhood evidence.

After independent personhood threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

A conscious nonhuman may possess its own humour/wordplay, but the narrative must establish its communication affordances and a plausible path by which another agent decodes it.

## 5. PROSE / ANTI-CHOPPINESS
Do not render each cue as an isolated beat:
`line. glance. pause. pun. thought.`

Use:
`COMMUNICATION UNIT → CONTEXT CUES → INTERPRETIVE TURN → RESPONSE` within the paragraph shape that best preserves reader-state continuity.

`WORDPLAY BEAT ≠ SENTENCE BREAK`.
`COMPRESSION ≠ CHOPPING`.

## Acceptance tests
- Can the wordplay be reassigned unchanged to another speaker? If yes, recheck ownership.
- Can intended listener plausibly decode it? If no, add shared ground or adapt.
- Does the reader have enough context without an explanatory after-line?
- Does any interpretation get promoted to evidence without independent corroboration? If yes, fail.
- Does adaptation preserve function while protecting exact load-bearing clue language?
- Does the line change something worth the reader/audio time it consumes?
