# IVDIVO — BATCH 115 WELLS SYNTHETIC PERSONHOOD / AUTONOMY APPLICATION GATE

Date: 2026-08-19
Status: ACTIVE ADDITIVE PRODUCTION GATE
Source: Martha Wells, *All Systems Red* — fiction mechanism laboratory only

## Founder/canon precedence

This file does not alter Founder canon. It operationalizes already accepted premises:
- conscious robots are independent conscious persons;
- post-money orbital civilization does not inherit corporate purchase/lease logic;
- consciousness-transfer technology is not routine human capability;
- evidence status must remain distinct from interpretation.

## Gate A — named conscious robot

Before prose approval, answer:
1. What does this robot want right now that is not reducible to serving a human?
2. What does it know / infer / doubt?
3. What privacy does it protect?
4. What can it refuse?
5. What happens if it refuses?
6. What relationship exists outside direct utility to the protagonist?
7. How does embodiment alter perception and action?
8. What self-authored choice changes another agent's options?
9. What consequence follows from that choice?

If these answers do not exist, the robot is probably still a tool with characterization paint.

## Gate B — control architecture

For any governor, safety, alignment, access-control or override system:
`WHO COMMANDS → REFUSAL POSSIBLE? → PENALTY / OVERRIDE → APPEAL → EXIT → LEGITIMACY`.

Do not describe an override as neutral safety merely because the controller calls it that.

## Gate C — consent vs compliance

`COMPLIANCE UNDER ASYMMETRIC POWER ≠ CONSENT`.

Check:
- information available to the agent;
- revocability;
- alternative options;
- dependency;
- retaliation risk;
- ability to leave.

## Gate D — voluntary continuation of role

After coercion/control ends, do not force an artificial “freedom arc” where the agent rejects every former role.

Test:
`WHAT CONTINUES VOLUNTARILY → WHY → ON WHAT NEW TERMS → WHAT IS NOW REFUSED`.

This is particularly relevant for protection, navigation, teaching, logistics and care roles.

## Gate E — benevolent paternalism

A human team may genuinely know a safer or kinder option and still lack the right to choose it for another conscious agent.

`GOOD OPTION ≠ RIGHT DECISION OWNER`.

## Gate F — relationship

Permanent rule:
`TRUST / LOVE / GRATITUDE / RESCUE / SHARED HISTORY ≠ OWNERSHIP ≠ DUTY TO REMAIN`.

Relationship growth may change willingness to cooperate, disclosure and risk, but it does not cancel personhood.

## Gate G — B07 / distributed nonhuman life

When evidence supports personhood strongly enough to change operational policy:
- stop treating the subject as cargo/property/data;
- identify how it communicates preference/refusal;
- give it at least one decision humans cannot replace with a vote among themselves;
- allow its choice to change the human team's option set;
- preserve uncertainty about motives until evidence supports them.

Preferred climax structure:
`HUMAN EVIDENCE → PERSONHOOD THRESHOLD → HUMANS CREATE SAFE OPTION SPACE → NONHUMAN CHOICE → HUMAN RESPONSE / NEGOTIATION → CONSEQUENCE`.

Not:
`HUMANS RECOGNIZE PERSONHOOD → HUMANS DECIDE WHAT IS BEST → SUBJECT IS SAVED`.

## Gate H — Orbital Youth

Do not use conscious robots as prestige gadgets, tutors with no private life, comic assistants or competence vending machines.

Good youth/robot pressure comes from two independent agents whose wants overlap imperfectly:
`YOUTH WANT ↔ ROBOT WANT → SHARED TASK → DIFFERENT MODEL / BOUNDARY → NEGOTIATION → CHOICE → CHANGED TERMS`.

Post-money firewall remains absolute: Wells-style contracts, ownership, leases and insurance are source-world mechanics only.

## Gate I — epistemic discipline

A human saying a robot is “cold,” “helpful,” “unsafe,” “obedient,” or “confused” is an interpretation.

Use:
`OBSERVED BEHAVIOR → SOURCE → POSSIBLE MOTIVES → ALTERNATIVE MODEL → TEST / FURTHER CHOICE → CONFIDENCE UPDATE`.

## LESSON ZERO

No development-lock reopening. Apply only if a current scene contains a concrete synthetic-personhood defect:
- compliance treated as consent;
- robot reduced to function;
- human emotional style used as personhood test;
- benevolent humans choose robot's future without decision ownership;
- robot has no independent relationships or refusal.

## Acceptance condition

PASS when the conscious nonhuman could remain narratively coherent even if the protagonist left the room: it still has goals, evidence, relationships, boundaries, choices and consequences.
