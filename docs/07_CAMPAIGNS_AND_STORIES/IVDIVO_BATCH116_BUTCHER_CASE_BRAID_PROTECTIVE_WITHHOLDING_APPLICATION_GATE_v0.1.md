# IVDIVO — BATCH 116 BUTCHER CASE-BRAID / PROTECTIVE-WITHHOLDING APPLICATION GATE

Date: 2026-08-19
Status: ACTIVE ADDITIVE PRODUCTION GATE
Source: Jim Butcher, *Storm Front* — fiction mechanism laboratory only

## 1. Case braid acceptance test

For two investigation strands A/B:
`A TRACE → changes B model/action → B evidence/pressure → changes A model/action → convergence → shared endgame`.

FAIL if the strands only alternate chapters and meet at a final briefing.

## 2. Evidence ladder

Every significant mystery claim carries:
- observed trace;
- source/provenance;
- POV interpretation;
- alternatives;
- corroboration status;
- next discriminating action.

Never promote a protagonist's confidence to fact without evidence.

## 3. Protective withholding

Before allowing a protagonist to hide information “to protect” another agent, record:
`WHAT IS WITHHELD → WHY → WHAT MODEL THE OTHER AGENT NOW LACKS → WHAT ACTION THEY TAKE → TRUST/SAFETY COST`.

The withholding may still be understandable or even locally rational. It is not consequence-free.

### ROOM 917
Elena/Julian withholding must alter investigation access, evidence handling or trust. Romance cannot repair evidence status.

### Orbital Youth
Adult/youth secrecy must be tested against the young person's actual decision rights and safety model; no paternalistic shortcut.

### Conscious robots
Human operators may not withhold relevant information while calling subsequent compliance informed consent.

## 4. Multi-authority matrix

For each institution/actor:
`KNOWLEDGE → JURISDICTION → SANCTION → INCENTIVE → BLIND SPOT → APPEAL/EXIT`.

Use competent competing authorities rather than a single evil institution whenever the story permits.

## 5. Institutional update

Strong opposition does not require ideological conversion.
Preferred:
`PRIOR MODEL → NEW VERIFIED EVIDENCE → DUTY / STANDARD FORCES STATUS UPDATE → RELATIONSHIP MAY REMAIN HOSTILE`.

## 6. Procedural worldbuilding

A speculative rule earns real-time explanation when it changes the current investigation:
`QUESTION → RULE/LIMIT → TRACE/TEST → RESULT → MODEL UPDATE → ACTION`.

If explanation does not change an option, clue, risk, relationship or decision, compress it.

## 7. Case-loop variation

For each investigative loop, require at least one changed axis:
- evidence status;
- model;
- authority/access;
- relationship/trust;
- tactic;
- physical geometry;
- decision owner;
- cost;
- future option set.

Otherwise merge/compress.

## 8. Local closure

`PROMISED LOCAL QUESTION → PROOF → DECISIVE ACTION → RESULT → AFTERMATH → OPTIONAL SERIES VECTOR`.

Do not postpone the promised local answer merely to create a sequel.

## 9. Canon / ethics firewalls

Do not import:
- money/rent/job pressure into post-money orbital life;
- magical Sight/soul-gaze as IVDIVO ontology;
- gender stereotypes as motive evidence;
- induced desire as harmless romance;
- protagonist competence as moral legitimacy.

## LESSON ZERO

No development-lock reopening. Use this gate only if a current manuscript defect is found in evidence provenance, institutional pressure, case braiding or protective withholding.

## PASS condition

A mystery passes when the reader can reconstruct:
`WHAT HAPPENED → HOW WE KNOW → WHAT REMAINS INFERRED → WHO HAS AUTHORITY TO ACT → WHY THE NEXT ACTION FOLLOWS`.
