## 1. Scene admission

Before prose revision, complete:

`Because these actions occurred, __________ changed.`

Valid changed-state axes:

- physical / operational;
- knowledge / evidence;
- relationship / trust;
- consent / boundary;
- authority / access;
- responsibility / obligation;
- strategy / model;
- emotional commitment;
- future option space.

If the blank cannot be filled with a downstream-relevant change, test:

`SUMMARY / MERGE / DELETE / REBUILD`.

---

## 2. Event is not activity

Do not count technical manipulation, travel, gestures, interface use, walking, equipment setup or repeated conversation as story progression merely because characters are busy.

`MICRO-ACTIONS → must add up to → EVENT → CONSEQUENCE`.

Failure mode:

`ACTION POPPING = high visible activity + state-neutral result`.

---

## 3. Beat map before sentence edit

For scenes that survive admission, map only the functional progression:

`ENTRY STATE → BEAT 1 → BEAT 2 → SHIFT → ... → EXIT STATE`.

A beat is a causal/action-response unit, **not** a mandatory sentence or paragraph.

### Anti-choppy rule

Never convert beat analysis into:

`action. reaction. gesture. thought. conclusion.`

If several beats form one continuous perceptual or decision unit, write them as coherent prose at the paragraph/sentence scale that best serves reader effect.

---

## 4. Dialogue-event test

Use full direct dialogue when exact wording changes:

- trust;
- consent;
- evidence status;
- authority;
- relationship terms;
- decision;
- commitment;
- future expectations.

If wording is not consequential, prefer summary / indirect dialogue / embedded scene.

`TALK CAN BE EVENT; TALK IS NOT AUTOMATICALLY EVENT.`

---

## 5. Pulse vs tension

Track the persistent underlying desire/need/pressure separately from overt tension.

`PULSE → can remain quiet`

`ACTION / OPPORTUNITY / REFUSAL / DISCLOSURE → activates consequences → TENSION`.

Do not create arguments merely to prove a scene has conflict.

---

## 6. Event / interpretation firewall

For mystery, technical evidence and consciousness-practice material:

`WORLD FACT → TRACE / SOURCE → OBSERVED EVENT → POV INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION → ACTION`.

Never collapse:

`WHAT HAPPENED = WHAT POV THINKS IT MEANS`.

Emotion, confidence or elegant description do not upgrade evidence status.

## 8. Orbital Youth

`NEW TECHNOLOGY ≠ NEW SCENE FUNCTION`.

A technical scene earns reader time through:

`WORLD RULE → PERSON-SPECIFIC AFFORDANCE / FRICTION → CHOICE → CONSEQUENCE`.

Protect quiet events involving:

- belonging;
- first real responsibility;
- consent;
- trust;
- reputation;
- autonomy;
- relationship terms.

Do not force disaster merely to make the event visible.

## 9. B07 — THE UNLISTED CITY

After independent personhood evidence reaches threshold:

`ENTITY'S OWN MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Human meetings that merely repeat the insufficiency of the old category should merge/compress.

Kaira may create accountable conditions for choice; she must not choose continuity on behalf of the personhood-proven entity.

---

## 10. Conscious robots

Observed motion/action is not motive.

Require:

`OWN WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → OWN CHOICE → CONSEQUENCE`.

Beat analysis must preserve nonhuman embodiment and agency rather than translate every response into stereotyped human emotion.

---

## 11. Consciousness-practice schools

Keep evidence stages separate:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

A quiet experiential scene can be a major character event while remaining low-status ontological evidence.

## 12. Full anti-choppy pipeline

`BOOK ENGINE → CHAPTER FUNCTION → SCENE ADMISSION / NECESSITY → SCENE WEIGHT / MODE → EVENT TARGET → BEAT LOGIC (NOT TYPOGRAPHY) → POV / EVIDENCE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.
