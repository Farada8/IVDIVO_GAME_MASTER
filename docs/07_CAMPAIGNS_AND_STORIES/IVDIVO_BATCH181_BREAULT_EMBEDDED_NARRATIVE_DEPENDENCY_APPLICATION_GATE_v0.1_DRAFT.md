# IVDIVO BATCH 181 — BREAULT EMBEDDED NARRATIVE / DEPENDENCY APPLICATION GATE

Status: `PRODUCTION APPLICATION / WIDER STRICT SOURCE COMPLETE`

## Governing principle
Michael Breault's strongest transfer to IVDIVO is organizational rather than stylistic:

`NARRATIVE QUALITY IS UPSTREAM OF DOWNSTREAM PRODUCTION QUALITY`.

If story, character, knowledge, consent, clues or relationship-state errors survive until audio/render/release, every downstream artifact becomes more expensive to repair.

## 1. IVDIVO Book Engine

### B181-A01 — STORY AUTHORITY UPSTREAM
Story Core, Character State, Knowledge State, Relationship State, Clue/Secret/Promise/Payoff and Causal Event artifacts must exist as versioned upstream inputs before dependent scene/draft/audio artifacts are treated as stable.

### B181-A02 — PLAN IS NOT IMPLEMENTATION
Keep four layers separate:
- planned intent;
- actual current text/state;
- approved canon;
- evidence/knowledge status.

When draft evidence contradicts a planning assumption, do not silently force the draft back to the plan. Route through authority/canon/causality review.

### B181-A03 — SELECTIVE INVALIDATION
`UPSTREAM CHANGE → EXPLICIT DEPENDENCIES → ONLY AFFECTED DOWNSTREAM ARTIFACTS DIRTY/RECHECK`.

Do not regenerate unrelated chapters/scenes merely because an earlier artifact changed chronologically.

### B181-A04 — FEATURE FREEZE
At development/release lock:
`COOL IDEA / NEW CRAFT THEORY ≠ REOPEN`.
Only concrete defect evidence may reopen the minimum affected layer.

This directly preserves the standing Book One law:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

## 2. LESSON ZERO Book One
No global rewrite is authorized by Batch 181.

Reopen only for evidence-backed defects such as:
- reader/audio confusion repeated across independent readers;
- canon/continuity error;
- wrong knowledge/evidence provenance;
- relationship/consent state contradiction;
- scene whose function is duplicated or state-neutral;
- exact-text production defect that survives current QA.

Breault strengthens the development lock rather than weakening it.

## 3. ROOM 917 / AUDIO
Breault is unusually relevant because dialogue has literal downstream production cost.

### B181-A05 — SPOKEN LINE PAYMENT
For every isolated spoken line/block ask:
`WHY MUST THESE EXACT WORDS EXIST?`

Valid payments include:
- clue/evidence state;
- consent/boundary;
- trust/relationship turn;
- status/authority shift;
- decision/commitment;
- performance contrast that cannot survive indirect report;
- protected sonic clue.

If none apply, consider compression, indirect report or deletion before rendering.

### B181-A06 — AUDIO DEPENDENCY CHAIN
`EXACT TEXT → PERFORMANCE INTENT/TACTIC → VOICE TAKE → ACOUSTIC PASSPORT → EDIT → MIX → QC`.

Changing exact text or clue ordering invalidates affected downstream assets. Changing a non-load-bearing production note must not invalidate unrelated dialogue.

### B181-A07 — EVIDENCE FIREWALL
`RELATIONSHIP STATE ≠ EVIDENCE STATUS`.

Elena/Julian trust, attraction, kiss, confession, silence or performance intensity may change disclosure/access/tactic, but they never count as corroboration of a physical/audio clue.

## 4. ORBITAL YOUTH
Use lived environmental/social traces to establish future normality.

Prefer:
`WORLD RULE → CHARACTER-SPECIFIC NOTICE → AFFORDANCE/FRICTION → CHOICE → CONSEQUENCE`.

Do not explain post-money society in a lecture, and do not silently restore salary/rent/credits merely because present-day genre convention expects them.

Protect the stronger YA escalation:
`COMPETENT ACTION → REAL SUCCESS → MORE TRUST/ACCESS/RESPONSIBILITY → HARDER NEXT CHOICE`.

## 5. B07 — THE UNLISTED CITY / NONHUMAN PERSONHOOD
Environmental/system traces can trigger a personhood hypothesis but not prove it alone.

Required progression:
`TRACE / PATTERN → SOURCE LINEAGE → INDEPENDENT PERSONHOOD EVIDENCE → CATEGORY FAILURE → ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

Once personhood is independently established, the entity cannot remain a passive asset, rescue object or lesson for Kyra.

## 6. Environmental storytelling without evidence corruption
Breault's environmental storytelling transfers cleanly only with evidence discipline:

`WORLD FACT → TRACE → POV ACCESS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION`.

A damaged wall, sound cue, prop, layout anomaly or data trace can imply history. It cannot silently prove a motive or ontology.

## 7. Dialogue/style firewall
Game production rewards concise dialogue because of UI, pacing and voice-production constraints. This does **not** establish a prose law.

Maintain:
`ACTION / SUSPENSE / AUDIO COST ≠ SHORT-SENTENCE DENSITY`.

For prose:
`SCENE/MODE → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM/CONTRAST → WORDING`.

Compression may merge several choppy microbeats into a longer coherent sentence or paragraph.

## 8. Release gate
Before release candidate:
- authoritative upstream story state valid;
- no stale dependent artifacts;
- no unresolved hard clue/knowledge/consent dependencies;
- feature freeze respected;
- accepted feedback has been regression-tested;
- new features are excluded unless explicitly approved and impact-scoped.

## Final production rule
`LIVE MATERIAL → ACTUAL STORY STATE → DEFECT LEVEL → RELEVANT SPECIALIST TOOL → MINIMAL CORRECT REPAIR → SELECTIVE INVALIDATION → REGRESSION / READER TEST`.
