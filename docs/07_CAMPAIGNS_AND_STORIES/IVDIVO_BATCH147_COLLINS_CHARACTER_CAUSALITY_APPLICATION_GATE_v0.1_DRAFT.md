# IVDIVO — BATCH 147 CHARACTER CAUSALITY APPLICATION GATE

Source status: Collins *Getting Into Character* is `FULL READ IN PROGRESS`; this gate is provisional and may only use mechanisms earned from sequentially read Introduction + Secret #1 material.

## Apply before adding quirks, wounds, speeches, or extra scenes
For every major character in a target book:

`CURRENT RESPONSIBILITY / WANT → VALUE(S) AT STAKE → RELATIONSHIP-SPECIFIC PRIORITY → FIRST TACTIC → WHAT BLOCKS/COMPLICATES IT → SECOND TACTIC → CONSEQUENCE → UPDATED MODEL`.

### Required checks
1. **Observable evidence** — What choices on the page support the claimed value?
2. **Counterexample** — Where does the character behave differently, and why?
3. **Relationship variation** — Does the person change tactics appropriately across different relationships?
4. **Frustration fingerprint** — What do they do when the first tactic fails?
5. **Independent life** — What do they want when the protagonist is not present?
6. **Causal payment** — Does this characterization change plot, evidence, relationship, consent, authority, or future option space?

## Ensemble test — Ethan / Maya / Ollie / Aoife / Samir
Reject differentiation that exists only as:
- different slang;
- five kinds of authorial wit;
- different hobbies that never affect choices;
- five identical moral conclusions reached through different dialogue.

Accept differentiation when the same pressure produces different salience, value conflicts, tactics, thresholds for evidence, willingness to intervene, and relationship costs.

## Orbital Youth / post-money firewall
Do not restore monetary motivation under new labels. Character-driving scarcity may legitimately involve:
- another person’s time;
- consent;
- trust;
- responsibility;
- privacy;
- belonging;
- mastery;
- a unique mission/place/opportunity;
- reputation as a relationship consequence, not a spendable currency.

## Conscious robots / nonhuman persons
Do not use “human-looking emotion” as the test of depth.

Required:
`OWN PRIORITY/WANT → OWN MODEL/EVIDENCE → OWN RELATIONSHIPS → CONSENT/REFUSAL → TACTIC → CHOICE → CONSEQUENCE`.

A human observer’s label for the robot’s behavior remains an interpretation, not proof of motive.

## Mystery firewall
Character design does not alter evidence status.

`AUTHOR MOTIVE MODEL ≠ POV INTERPRETATION ≠ CORROBORATED WORLD FACT`.

Trust, attraction, familiarity, charisma, or emotional truth do not replace independent source/provenance tests.

## Consciousness-practice schools
Craft language about “inner truth,” emotion memory, or deep identification must not leak into ontology.

Keep:
`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## Revision routing
If a character feels flat:
1. do not add a tic first;
2. identify the current want/responsibility;
3. identify the competing values;
4. inspect tactics under pressure;
5. inspect relationship-specific behavior;
6. only then revise voice, gesture, description, and sentence rhythm.

Standing LESSON ZERO law remains:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.
