# IVDIVO — BATCH 202 APPLICATION GATE
## Le Guin — Prose Rhythm · POV · Exposition · Crowding/Leaping

**Date:** 2026-08-22  
**Status:** PRODUCTION GATE / ADDITIVE — DOES NOT REOPEN LOCKED MANUSCRIPTS BY ITSELF

## Governing rule
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

Le Guin is used as a diagnostic and repair router. It is not permission to retrofit every manuscript to a new style.

## A. Global prose repair order
Before changing sentence length:

`ONE MAIN STORY / CAUSALITY`
→ `CHAPTER / SCENE FUNCTION`
→ `NARRATIVE MODE (SCENE / SUMMARY / INDIRECT / ELLIPSIS)`
→ `POV / KNOWLEDGE / EVIDENCE`
→ `PARAGRAPH INTENT / READER-STATE CONTINUITY`
→ `SENTENCE CONTRAST / RHYTHM`
→ `PUNCTUATION / WORDING`.

## B. Anti-choppiness gate
Flag a passage when several short paragraphs/sentences share:
- same actor;
- same time/place;
- same perceptual focus;
- same thought/decision unit;
- no meaningful state change at the break.

Repair sequence:
1. test whether the material belongs in full scene at all;
2. test summary/indirect compression;
3. group related microbeats into one paragraph;
4. rebuild topic/re reader-state continuity;
5. only then tune sentence length and punctuation.

Do **not** optimize a short-sentence percentage.

## C. Paragraph architecture gate
A paragraph break should buy at least one real function:
- speaker change;
- time/place shift;
- focus shift;
- tactic change;
- evidence-status change;
- relationship/consent change;
- deliberate emphasis/breath;
- transition to a new unit of thought.

One-line paragraphs remain legal when load-bearing. They are not a default style.

## D. POV / evidence gate
For every load-bearing observation:

`WHAT WAS OBSERVED?`
→ `WHO HAD ACCESS?`
→ `WHAT DO THEY KNOW?`
→ `WHAT DO THEY INFER?`
→ `WHAT IS STILL UNKNOWN?`
→ `WHAT MAY NARRATION STATE?`.

Never silently upgrade inference to world fact.

### ROOM 917
Maintain:
`WORLD FACT → TRACE → ELENA/JULIAN ACCESS → INTERPRETATION → ALTERNATIVE MODEL → CORROBORATION STATUS → NEXT ACTION`.

`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

## E. POV switching gate
A switch is accepted only if it supplies unique:
- evidence/access;
- perception;
- relationship pressure;
- irony;
- decision ownership;
- emotional cost.

Reject a switch whose only function is ensemble fairness or a single moment of information leakage.

## F. Exposition ownership gate
For information X:

`WHO NEEDS / NOTICES / ASKS / REMEMBERS X?`
→ `WHY NOW?`
→ `WHY THIS SOURCE / PERSON?`
→ `WHAT CHANGES AFTER X?`.

If the only answer is "the reader needs to know", reroute via:
- action;
- consequence;
- environment/trace;
- dialogue with real objective;
- summary/indirect narration;
- document/source with provenance.

## G. Character polyphony gate
For ensemble dialogue, check whether wording can be swapped unchanged among characters.

If yes, rebuild from:
`WORLDVIEW + RELATIONSHIP + WANT + STATUS + ATTENTION + OMISSION`.

No universal witty youth voice. No universal robot voice.

## H. Passive agency gate
Passive constructions are allowed. But when an institutional sentence affects rights/consent/resources, ask:

`WHO DECIDED?`
`WHO ACTED?`
`WHO COULD REFUSE/APPEAL?`
`WHO BEARS THE COST?`.

Do not let passive grammar hide governance.

## I. Crowding / leaping gate
At revision:

`DETAIL / PROCESS / EXPLANATION → LOAD-BEARING?`

Keep if it changes or supports:
- causal option space;
- evidence;
- relationship/consent;
- authority/responsibility;
- reader orientation;
- motif with developing meaning;
- central focus/trajectory.

Otherwise compress or leap.

## J. Conflict firewall
A scene is not rejected solely for lacking overt conflict.

A quiet scene passes if it changes downstream-relevant:
- knowledge/evidence;
- relationship/trust;
- consent/boundary;
- responsibility;
- strategy/model;
- commitment;
- future option space.

## K. Repetition gate
For a repeated image, line, action, joke or situation:

`WHAT IS DIFFERENT THIS TIME?`

Accept only when context, pressure, relation, interpretation, evidence-status or meaning develops.

## L. Feedback / audio gate
Use reader/listener evidence as:

`REPORTED EFFECT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES → RETEST`.

A reader's suggested repair is not automatically the repair.

### LESSON ZERO Book One

## M. Nonhuman personhood gate
For B07 and future conscious robots:

Human POV vocabulary does not establish motive or personhood.

After independent personhood threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## N. Consciousness-school epistemic gate
Vivid subjective prose may faithfully represent an experience while remaining epistemically limited:

`PRACTITIONER OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.
