# IVDIVO — BATCH 107 HAYES RELATIONSHIP BRAID APPLICATION GATE

Status: WORKING / ADDITIVE — NO RETROFIT
Date: 2026-08-19

## Purpose
Apply Gwen Hayes relationship-arc mechanisms without importing a mandatory 20-beat romance formula into every IVDIVO book.

## Master rule
`EXTERNAL EVENT / CHOICE → RELATIONSHIP STATE CHANGE → NEXT EXTERNAL CHOICE`.

Romance is causal when it changes what a character will do, reveal, risk, trust, permit, refuse, investigate, protect, or sacrifice next.

## Relationship ledger fields
For every protected relational scene:
1. state before;
2. each person's current independent want;
3. boundary/consent status;
4. new information or lived interaction;
5. trust/desire/respect/expectation change;
6. state after;
7. downstream effect on ONE MAIN STORY.

## ROOM 917 — mystery-primary application
The romance may intensify through evidence and shared risk, but it cannot solve the case.

Good braid examples:
- Julian's handling of a clue changes Elena's trust and therefore what access/help she accepts;
- Elena's refusal or boundary changes Julian's next action;
- a mystery revelation changes the meaning of an earlier intimate moment;
- increased trust allows a new investigative action that was previously impossible.

Forbidden:
- confession of love = proof of innocence;
- kiss substitutes for evidence;
- Julian becomes safe because Elena "feels" he is;
- mystery clue exists only to create touching or proximity;
- full Hayes romance-beat density overrides MYSTERY-PRIMARY dial.

## Orbital Youth application
Romantic/close relationships should pressure adolescent stakes specific to the setting:
- autonomy;
- belonging;
- consent/privacy;
- friendship group;
- future role/mission;
- reputation;
- trust in an instructor/institution;
- family expectation;
- first real responsibility.

No hidden return of salary/rent/credits as romance stakes.

## Conscious robot / nonhuman relationship gate
If a conscious robot or other nonhuman person enters a romantic or intimate relational arc:
- own want;
- own relationships outside partner;
- own evidence/model;
- consent/refusal;
- embodiment-specific experience;
- independent future options.

The arc is not "becoming human enough to love" unless Founder explicitly creates that particular character problem.

## Grand gesture replacement
Use:
`RELATIONAL CLAIM → SPECIFIC COSTLY ACTION → FREE ACCEPTANCE/REFUSAL`.

Cost may be vulnerability, changed plan, public accountability, loss of a unique opportunity, time, disclosure, defended boundary, or accepting consequences. Spectacle is optional.

## Rupture alternatives
Do not force a break-up. Valid turns include:
- trust downgrade;
- negotiated distance;
- refusal;
- boundary change;
- incompatible obligations;
- evidence-driven reinterpretation;
- temporary separation;
- consent conflict;
- changed future expectations.

## Ending gate
`LOCAL RELATIONSHIP QUESTION RESOLVED → PERSONALITY CONTINUITY → NEW TERMS → OPTIONAL SERIES VECTOR`.

No personality transplant. No epilogue used to repair an unearned relationship transition.
