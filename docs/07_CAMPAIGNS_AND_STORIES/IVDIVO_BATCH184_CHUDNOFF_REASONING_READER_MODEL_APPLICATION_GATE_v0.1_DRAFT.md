# IVDIVO BATCH 184 — CHUDNOFF REASONING / READER-MODEL APPLICATION GATE

## Scope
Use Chudnoff as a **reasoning and reader-orientation diagnostic**, not as a fiction-style template.

## Gate A — Claim precision
Before a scene/book treats a proposition as decision-relevant:
`WHAT EXACTLY IS THE CLAIM? → WHAT WOULD SUPPORT IT? → WHAT WOULD REFUTE OR QUALIFY IT?`

## Gate B — Support type
For each load-bearing conclusion store:
`OBSERVED / REPORTED / DEDUCED / IBE / ANALOGY / CHARITY / HYPOTHESIS / CORROBORATED / CONTESTED / UNKNOWN`.

Do not allow a character's intended argument type to silently determine its actual status.

## Gate C — Competing models
`TRACE SET → MODEL A / B / C → WHAT EACH EXPLAINS → DISCRIMINATING TEST → STATUS UPDATE`.

## Gate D — Reader intelligibility
If a reader is confused, classify the defect before adding exposition:
`EXPRESSION? → MOTIVATION? → BACKGROUND? → ELABORATION? → POV/EVIDENCE ACCESS?`

## Gate E — Narrative-order separation
`DISCOVERY ORDER ≠ LOGICAL/EXPLANATORY ORDER ≠ BEST READER ORDER`.
Outline/research order does not dictate final chapter order.

## Gate F — Paragraph local job
Each substantive paragraph should have a local narrative/explanatory function:
`ENTRY READER STATE → JOB → INTERNAL ORDER → EXIT STATE`.

This strengthens anti-choppiness control. Do not split one local job into five one-line paragraphs merely to imitate intensity.

## LESSON ZERO
Standing rule remains:
`NO NEW EVIDENCE → NO NEW GLOBAL REWRITE`.

If future beta/audio evidence reports confusion, diagnose whether the reader lacks:
- the question;
- the motivation for the current material;
- required background;
- source/evidence status;
- an example/elaboration;
- paragraph/reasoning continuity.

Do not solve all six by adding explanatory sentences.

## ROOM 917
For every load-bearing theory:
`TRACE → CLAIM → SUPPORT TYPE → HIDDEN ASSUMPTIONS → ALTERNATIVE MODEL → DISCRIMINATING TEST → CORROBORATION STATUS → NEXT ACTION`.

Standing firewall:
`TRUST / ATTRACTION / KISS / CONFESSION / SILENCE / INFLECTION ≠ CORROBORATION`.

If Elena or Julian uses analogy or best-explanation reasoning, script/ledger must preserve that status instead of allowing later scenes to treat the theory as fact.

## ORBITAL YOUTH
Worldbuilding exposition is admitted only when reader/POV need is causal:
`PRESENT WANT / PROBLEM → NEEDED DISTINCTION OR FACT → CHARACTER ACCESS → ACTION/CHOICE CHANGE`.

Post-money norms should emerge from lived causes rather than lecture-like background.

## B07 — THE UNLISTED CITY
Human resemblance to familiar organisms can generate a personhood hypothesis but cannot complete the proof:
`PATTERN → INDEPENDENT SOURCE LINES → ALTERNATIVE NONPERSON MODEL → DISCRIMINATING TEST → PERSONHOOD THRESHOLD`.

After threshold:
`ENTITY MODEL/PREFERENCE → CONSENT/REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

## Consciousness schools
`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → SUPPORT TYPE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

Thought experiment, analogy, elegance or intuitive obviousness may generate a hypothesis; none independently establishes ontology.

## Style / anti-choppiness
Chudnoff recommends short sentences in an academic-philosophy context. Do **not** promote that genre-local advice into IVDIVO prose law.

Standing law:
`CLARITY ≠ SHORT-SENTENCE DENSITY`.

Repair order:
`BOOK ENGINE → CHAPTER FUNCTION → ORDER/DURATION/FREQUENCY → POV/EVIDENCE → PARAGRAPH JOB/TOPIC CHAIN → READER-STATE CONTINUITY → SENTENCE RHYTHM/CONTRAST → WORDING`.
