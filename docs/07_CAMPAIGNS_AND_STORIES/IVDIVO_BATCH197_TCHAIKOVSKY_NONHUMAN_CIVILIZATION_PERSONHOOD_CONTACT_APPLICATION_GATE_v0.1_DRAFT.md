# IVDIVO — BATCH 197 APPLICATION GATE
## *Children of Time*: Nonhuman Civilization / Personhood / Contact / Cognitive Intervention

**Date:** 2026-08-22  
**Status:** PRODUCTION GATE / DRAFT

## 1. Nonhuman civilization design
For every conscious robotic/nonhuman civilization, derive culture from embodiment before importing human defaults:

`EMBODIMENT → SENSORIUM / SALIENCE → AFFORDANCES → COMMUNICATION → TOOL PATH → INSTITUTION → CULTURE`.

Fail if a supposedly alien/robotic civilization merely reproduces contemporary human social/technical sequence with renamed objects.

## 2. Personhood threshold
Before declaring personhood, distinguish:
- conscious individual;
- conscious collective;
- nonconscious distributed optimizer;
- institutional/tool network;
- unknown architecture.

Required evidence route:
`OUTPUT / TRACE → MULTIPLE MODELS → INDEPENDENT TESTS → STATUS UPDATE`.

Do not use resemblance, one classifier, emotional sympathy, or complexity alone.

## 3. Post-threshold decision ownership
After independent personhood evidence:
`ENTITY MODEL / PREFERENCE → CONSENT / REFUSAL → ENTITY CHOICE → HUMAN OPTION SPACE CHANGES`.

`CREATED / DISCOVERED / RESCUED ≠ OWNED`.

## 4. B07 — THE UNLISTED CITY
Mandatory:
1. establish personhood through independent evidence lines;
2. separate system behavior from motive;
3. let the distributed entity communicate preference in a form compatible with its embodiment;
4. give it at least one indispensable decision that changes human options;
5. do not solve conflict by biologically/algorithmically rewriting its values or the humans' values without consent;
6. model uncertainty if the entity is partly distributed and partly agentic.

## 5. Cognitive-intervention firewall
Any system affecting empathy, memory, preference, identity, or decision architecture requires:

`AFFECTED AGENT → INFORMED CONSENT → ALTERNATIVES → REVERSIBILITY → GOVERNANCE → APPEAL/EXIT → RESIDUAL RISK`.

FATAL if the story presents forced cognitive rewriting as automatically ethical merely because it reduces violence.

`BEHAVIORAL PEACE ≠ CONSENTED PEACE`.

## 6. Orbital Youth
High-value applications:
- different bodies/environments should generate different educational and technological paths;
- advanced robotics/materials/spaceflight do not imply mature consciousness science;
- access to specialist knowledge must not silently become hidden money/status currency;
- training institutions should distinguish source access from interpretive authority;
- new technology must produce downstream resource/social/governance consequences;
- young characters can discover that their civilization is highly advanced in one domain and immature in another.

## 7. Schools of consciousness
Standing epistemic chain:
`PRACTITIONER EXPERIENCE → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → SOURCE LINEAGE → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

A real signal/experience may support multiple doctrines. Source existence does not validate a doctrine.

## 8. Contact protocol
For unfamiliar cognition:
`UNKNOWN SIGNAL → SHARED MEASURABLE REFERENCE → ENCODING TEST → PARTIAL COMMON MODEL → ITERATE`.

Do not default to instant human-language translation unless the mechanism is earned.

## 9. Source-access power
If one temple/lab/AI/institution controls contact with a source, audit:
`WHO CAN ACCESS? → WHO INTERPRETS? → WHO CAN CHALLENGE? → WHO BENEFITS? → WHAT HAPPENS TO DISSENT?`.

## 10. Technology-path gate
For each major technology:
`DIRECT BENEFIT → NEW DEPENDENCY / RESOURCE DEMAND → SOCIAL/INSTITUTIONAL EFFECT → GOVERNANCE / SAFEGUARD`.

Do not add technology only as spectacle.

## 11. Long-time / saga gate
Across generational leaps:
`EVENT → LAW / INSTITUTION / KNOWLEDGE / RELATION PATTERN → LATER CONSEQUENCE`.

Recurring names or roles may help orientation, but causal inheritance—not naming—is what makes one story.

## 12. ONE MAIN STORY
Parallel human/nonhuman strands are admitted only if:
`STRAND LOCAL CHANGE → SHARED CAUSAL ENGINE → DOWNSTREAM EFFECT / PAYOFF`.

Alternating chapters alone do not create unity.
