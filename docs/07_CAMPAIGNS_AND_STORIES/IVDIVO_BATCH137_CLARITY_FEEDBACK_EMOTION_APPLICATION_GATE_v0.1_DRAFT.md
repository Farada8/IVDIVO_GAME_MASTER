# IVDIVO — BATCH 137 APPLICATION GATE
## Clarity · Feedback · Emotion · Reader-State

Status: DRAFT
Source layer: Jack M. Bickham, *The 38 Most Common Fiction Writing Mistakes*, Section 26 complete; Sections 27–31 under strict continuation.

## 1. CLARITY ROUTER

For every important beat:

`WORLD/SCENE CHANGE → WHO PERCEIVES → WHAT THEY KNOW → WHAT THEY WANT → WHAT THE READER MUST KNOW NOW → WHAT MAY REMAIN INFERENTIAL`

Required clarity:
- current action state;
- current evidence status;
- scene owner's practical objective;
- decision/relationship change that drives the next beat.

Do **not** automatically explain:
- theme;
- motive that remains genuinely uncertain;
- subtext already legible from behavior;
- global ontology not yet proved.

## 2. MYSTERY FIREWALL

Never confuse:

`READER CONFUSION` with `PRODUCTIVE UNCERTAINTY`.

Productive uncertainty = reader knows the question and competing models but not the answer.
Reader confusion = reader cannot tell what happened, whose evidence this is, or why a decision follows.

Use:

`OBSERVED / REPORTED / INFERRED / HYPOTHESIS / CORROBORATED / CONTESTED / UNKNOWN`.

## 3. FEEDBACK CONTRACT

Every external note is normalized to:

`PASSAGE/BEAT → OBSERVED READER EFFECT → REPEATABILITY → DEFECT LEVEL → REPAIR HYPOTHESES`.

Do not average the manuscript toward every proposed solution.

A repeated independent reader effect can justify reopening a locked section. A single preferred rewrite does not.

## 4. LESSON ZERO DEVELOPMENT LOCK

Batch 137 does not reopen Book One by itself.

Reopen only if current evidence demonstrates one of:
- goal/evidence confusion;
- continuity defect;
- repeated explanation echo;
- scene-level orientation failure;
- externally repeated reader-effect failure.

Otherwise preserve development lock.

## 5. ORBITAL YOUTH

Future-world unfamiliarity must come from changed norms, not hidden basic orientation.

Preferred method:

`ORDINARY FUTURE RULE → CHARACTER USES/IGNORES IT → FRICTION OR AFFORDANCE → CHOICE → CONSEQUENCE`.

Post-money life is shown by attention hierarchy: ordinary reproducible goods receive little attention; trust, consent, time, privacy, belonging, unique opportunity and responsibility receive real pressure.

## 6. CONSCIOUS ROBOTS

Clarity about behavior must not become false clarity about mind.

`OBSERVED ACTION → CONTROL PROVENANCE / CONTEXT → OWN STATEMENT OR OTHER EVIDENCE → MOTIVE HYPOTHESES → RESPONSIBILITY STATUS`.

No universal robot voice; no behavior→motive shortcut.

## 7. CONSCIOUSNESS SCHOOLS

Clear language from a practitioner does not establish truth status.

`OBSERVATION → REPRODUCIBLE EFFECT → SCHOOL INTERPRETATION → COMPETING INTERPRETATION → INDEPENDENT TEST → ONTOLOGY CEILING`.

## 8. ANTI-CHOPPY PROSE

Before touching sentence length:

`BOOK ENGINE → CHAPTER FUNCTION → SCENE NECESSITY → SCENE WEIGHT/MODE → POV/EVIDENCE → EXPOSITION OWNER → PARAGRAPH INTENT → READER-STATE CONTINUITY → SENTENCE RHYTHM → WORDING`.

If several short paragraphs carry one actor/time/place/focus without a real shift, test merge first.

## 9. ACCEPTANCE

A patch passes Batch 137 only if:
1. necessary story state is clearer;
2. evidence provenance is not flattened;
3. theme/subtext is not redundantly explained;
4. character agency/personhood is preserved;
5. causal flow is stronger;
6. prose rhythm is not mechanically shortened or lengthened.
