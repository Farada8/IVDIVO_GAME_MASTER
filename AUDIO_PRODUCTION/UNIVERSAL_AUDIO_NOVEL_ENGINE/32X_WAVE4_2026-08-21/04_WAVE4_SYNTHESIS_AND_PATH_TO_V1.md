# IVDIVO AUDIO NOVEL ENGINE — WAVE 4 SYNTHESIS + PATH TO V1

## Executive decision
Wave4 Prompts 01–32 were executed sequentially against the freshest recovered authority. The result does **not** justify another generic engine redesign.

It sharpens five evidence layers: story/source authority; deterministic production contracts; provider/live execution; human/perceptual quality; commercial/economic release proof.

## What materially improved

### 1. Stale-branch failure was caught before integration
The initial Wave4 branch inherited an old Wave3-finalize base and was 193 commits behind current main. It was rejected as an integration target. A fresh main-based Wave4 branch was created instead.

### 2. Wave3 machine mechanisms now have a main-rebased promotion surface
Canary identity, spend idempotency, ambiguous-request reconciliation, provider error normalization, 48k asset normalization, TTD/TTS alignment normalization, capability drift and scoped invalidation are candidate executable contracts with tests. They are `GO_FOR_CODE_REVIEW`, not CURRENT.

### 3. LESSON ZERO sound is no longer an undefined later-mix problem
CH01 now has explicit public festival/pavilion, reflecting-pool intimate and diegetic-recorder domains plus causal/protected-silence/music gates. The engine can reject short-loop ambience, decorative silence fill, uncaused Foley, fake intimacy by reverb, wallpaper music, extreme-pan dependence, synthetic timing as live and stereo-source collapse.

### 4. ROOM917 generated a universal regression, not a copied project rule
The actual failure class `wide stereo source -> mono stem` is abstracted into a universal integrity check. Greyhaven/Cate/917 content is not transferred.

### 5. Release boundary is now stricter
A deterministic PASS is not provider PASS, voice lock, human naturalness, commercial attractiveness or measured economics.
