# ROOM 917 — 32-PROMPT SYNTHESIS + DECISIONS v1.0

## Executive result

ROOM 917 has already crossed the engineering threshold from plan to real rendered audio. The core technical engine is no longer the main uncertainty. The unresolved question is whether the pipeline can repeatedly produce audio that listeners experience as dramatically alive, commercially competitive and worth continuing — at acceptable cost and with bounded manual intervention.

- Real E01 master exists with exact identity/hash/size/duration/format.
- File Library persistence pointer exists; controlled Drive duplicate/readback does not yet.
- Provider connectivity and live render occurred.

## Engineering PASS != product PASS

Technical QC asks whether the episode rendered, clipped, lost text, broke alignment, violated protected cues or failed mono/mobile constraints.

Product QC asks whether listeners believe the actors, feel bodies in space, understand the scene in one listen, experience music as dramaturgy, feel romance/mystery/emotional pull and want the next episode.

Founder dissatisfaction with music/sound richness is therefore compatible with a technical PASS.

## Music principle

Do not solve 'not enough music' with wallpaper. Design functionally motivated cues for propulsion, tension, aftermath, transition, intimacy, motif memory and hook shaping, each with entry/exit cause. Protect clue comprehension and boundaries from manipulative scoring.

## Sound-world/body principle

Premium value comes from causal embodiment:

`OBJECT -> ACTION -> MATERIAL -> DISTANCE -> ROOM RESPONSE -> STORY IMPLICATION`

Use selective body/cloth movement, footsteps, receiver handling, paper/evidence, doors/locks/lifts, weather/building continuity, occlusion and perspective changes. Reject random SFX density.

## Clue-SFX protection

- line isolation = `CLACK—CLACK`
- door confinement = `CLINK—CLACK—THUNK`
- key = `INSERT -> loaded HALF-TURN -> SNAP`
- selector = light technical clicks
- real power loss = slow decay
- local line cut = abrupt communication loss while broader power remains

Commercial polish must not reduce recognition.

## Selective repair law

`ISSUE -> TIME/CUE -> SYMPTOM -> EARLIEST FAILED LAYER -> PROTECTED FIELDS -> SMALLEST PATCH -> INVALIDATED DESCENDANTS -> ACCEPTANCE TEST -> RESULT`

Order: edit/rebalance -> local sound/music/space correction -> selective voice regen -> local scene remix -> whole episode only if local lineage cannot be preserved.

## Commercial gate

Loudness-match before comparison. Score: acting, body presence, music, Foley, space, intimacy, mystery, emotional pull, naturalness, one-listen comprehension, desire to continue, fatigue and phone/low-volume survival.

## Economics gate

Record provider cost, rejected generations, human review/edit/mix minutes, regeneration count, accepted duration, cost per accepted minute, human minutes per accepted minute and manual-polish percentage.

## Universal engine distinction
