## 3. Why technical PASS did not settle the product question

Technical QC asks whether the artifact rendered, clipped, lost text, broke alignment, violated a protected cue, or failed machine constraints.

Product QC asks whether the listener believes the actors, feels bodies in space, understands what happened in one listen, experiences tension/romance/mystery, hears meaningful musical shaping, and wants the next episode.

These are different evidence axes. Founder dissatisfaction with music/sound richness is therefore not contradicted by technical master validity.

## 7. Music principle

The problem is not “music on/off” or “more music”. Premium scripted audio uses music for functional dramaturgy:
- propulsion;
- tension contour;
- aftershock;
- emotional pressure without answering the mystery;
- transition energy;
- intimacy shaping;
- end-button/hook;
- motif memory.

Every cue needs an entry cause and exit cause. Wallpaper scoring is a failure mode.

## 8. Sound-world / body-presence principle

Premium value comes from causal embodiment, not asset count:

`OBJECT -> ACTION -> MATERIAL -> DISTANCE -> ROOM RESPONSE -> STORY IMPLICATION`

Target classes include selective cloth/body movement, footsteps/stops/turns, receiver handling, paper/evidence manipulation, doors/locks/lifts/service machinery, weather/building beds that change with geography, threshold occlusion, movement perspective and silence with a living room around it.

Random SFX density is rejected.

## 9. Clue-SFX protection

Commercial polish must preserve mechanical grammar:
- line isolation = `CLACK—CLACK`;
- confinement = `CLINK—CLACK—THUNK`;
- key break = `INSERT -> loaded HALF-TURN -> SNAP`;
- selector/routing = light technical clicks;
- real power loss = slow decay;
- local line cut = abrupt communication loss with broader power remaining.

Spectacle that makes categories less learnable is a downgrade.

## 10. Performance / romance / mystery protection

- **Elena:** controlled precision, smaller/narrower under fear/grief; no noir whisper/prosecutor prestige monotone.
- **Julian:** managerial restraint; attraction through respect and costly restraint, not alpha possession.
- **Mina:** practical warmth/staff-world authority, not comic sidekick or second Elena.
- **Sana:** skeptical methodological authority, not oracle or Elena clone.
- **Margot:** credible institutional authority; no early murderer telegraph.
- **Cate:** ordinary human across media states; impossible transmission is not ghost acting.

Wrong performance coding can break story even with exact text.

## 11. Selective repair law

Repair only a proven symptom.

`ISSUE -> TIME/CUE -> LISTENER SYMPTOM -> EARLIEST FAILED LAYER -> PROTECTED FIELDS -> SMALLEST PATCH -> INVALIDATED DESCENDANTS -> ACCEPTANCE TEST -> RESULT`

Preferred order:
`edit/rebalance -> local room/Foley/music/space correction -> selective voice regeneration -> local scene remix -> whole-episode rerender only if lineage makes local repair impossible`.

`ACTING / BODY PRESENCE / MUSIC / FOLEY / SPACE / INTIMACY / MYSTERY / EMOTIONAL PULL / NATURALNESS / ONE-LISTEN COMPREHENSION / DESIRE TO CONTINUE / FATIGUE / PHONE-LOW-VOLUME SURVIVAL`.

Founder and preferably a small blind cohort are required. Do not infer a human PASS.

## 14. Cost / scale gate

Record:
- provider generation cost;

- regeneration count;
- accepted runtime;

A beautiful one-off that requires uncontrolled manual rescue is not engine proof.
