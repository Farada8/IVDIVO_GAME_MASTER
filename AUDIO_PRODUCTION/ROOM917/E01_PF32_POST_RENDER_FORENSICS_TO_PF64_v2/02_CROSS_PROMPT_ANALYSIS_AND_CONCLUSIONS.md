# CROSS-PROMPT ANALYSIS AND CONCLUSIONS — PF32

## 1. What the 32-prompt pass proved

This pass did not create new audio evidence. It converted the current E01 post-render problem into an executable evidence/repair system without fabricating what is not available.

The strongest production fact remains D003: pre-Scene3 room/material identity is undercovered at aggregate level. The combination of authored room contracts, only 0.450 s of formal protected pre-Scene3 silence, and approximately 36.1 s below -85 dBFS supports a MAJOR aggregate defect. However the exact intervals are unknown, so blanket ambience fill is prohibited.

D004 is structurally plausible because Scenes 1–2 contain many obligatory physical actions, but current aggregate metrics cannot prove which Foley/actions are missing versus already present at low level. D004 therefore remains a candidate.

D005 remains a commercial hypothesis. The Founder perceives insufficient music/background scoring, but music is downstream of physical-world repair and cannot substitute for room bed or causal action. It must be tested after D003 correction using matched A/B/C variants.

## 2. New structural findings

### A. Byte evidence and human evidence are different gates
Machine-forensic work can define extraction, classification and repair contracts; it cannot invent master intervals or listener preference.

### B. Every repair needs an interval evidence envelope
Minimum:
`MASTER HASH -> INTERVAL -> SCENE/BLOCK/CUE -> CLASS -> STORY/ACOUSTIC CONTRACT -> PATCH ELIGIBILITY -> SOURCE ASSET VERSION -> OPERATION -> REGRESSION`.

### C. Low density is not one defect class
It may be protected authored pause; valid low-density beat/transition; missing room/ambience support; missing causal overlap candidate; or unknown requiring listen/live timeline.

### D. Physical-world repair precedes commercial score enhancement
Correct order:
`ROOM/WEATHER/MATERIAL BED -> BODY/FOLEY/CAUSAL ACTION -> OPTIONAL MUSIC -> MASTER/COMMERCIAL POLISH`.

### E. A/B/C must vary controlled layers
A = forensic control/current restrained intent. B = commercially enriched physical world + selective score. C = premium dramaturgical hand-polish. Locked story and accepted performance should remain common where possible.

### F. Scaling is a release decision, not a capacity decision
No E02–E24 batch manufacturing until E01 V2 passes technical + human/commercial evidence.

## 3. Prompt-design implications

The next 64 prompts are organized around eight production families: master/provenance/materialization; interval extraction; evidence classification; room/material continuity; body/Foley causality; music/clue/commercial control; human/perceptual QC; selective repair/regression/release.

This is a better next step than merely doubling spatial-directing checks because it targets the actual post-render bottleneck.
