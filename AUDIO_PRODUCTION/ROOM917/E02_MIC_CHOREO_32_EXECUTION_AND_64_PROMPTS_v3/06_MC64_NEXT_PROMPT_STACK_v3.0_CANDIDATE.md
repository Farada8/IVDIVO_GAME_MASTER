# IVDIVO MICROPHONE CHOREOGRAPHY / SCENE EMBODIMENT ENGINE — 64-PROMPT STACK v3.0 CANDIDATE

**Status:** WORKING CANDIDATE FOR SUBSEQUENT VALIDATION — NOT YET UNIVERSAL AUTHORITY  
**Derived from:** complete sequential execution of v2 MC-00…MC-31 on ROOM917 E02 `LENI-BIRD`.  
**Design goal:** expand microphone choreography from spatial movement planning into an evidence-aware, listener-centered scene embodiment and post-render repair system.

## Global v3 laws

1. Story/project authority outranks spatial design.
2. Every staging assertion carries an evidence grade: `SCRIPT_EXPLICIT / CONTINUITY_REQUIRED / DIRECTORIAL_INFERENCE / UNSUPPORTED`.
3. Unknown geometry/timing remains unknown until measured/locked.
4. Listener inference outranks spatial spectacle.
5. Relationship authority controls intimate spatial signals.
6. Voice, body, object, Foley, media domain, room and movement must describe one coherent causal world.
7. Absolute automation time derives only from accepted take/alignment lineage.
8. Human perceptual evidence is never simulated.
9. Selective repair targets the earliest demonstrated failed layer.
10. Provider output/render success is not story or release authority.

# FAMILY A — AUTHORITY / EVIDENCE / PROVENANCE

## MC-00 MASTER SCENE EMBODIMENT DIRECTOR
Load locked source, current production state, relationship authority, Listener Contract, performance plan, asset state and current open gates. Route only the controls needed to turn the scene into a coherent embodied audio event. Return `SCENE_EMBODIMENT_PLAN / BLOCKERS / REQUIRED_SPECIALISTS / NEXT_UNBLOCKED_ACTION`.

## MC-01 CURRENT AUTHORITY RESOLVER
Resolve exact project/episode/scene authority, source version/hash/Drive ID where available, current execution frontier and superseded branches. FAIL closed on conflicting current authorities.

## MC-02 EVIDENCE-GRADE CLASSIFIER
Classify each proposed staging fact as `SCRIPT_EXPLICIT / CONTINUITY_REQUIRED / DIRECTORIAL_INFERENCE / UNSUPPORTED`. Cite the source/action that justifies the grade. Never promote inference to script fact.

## MC-03 UNKNOWN-PRESERVATION GUARD
Inventory unknown dimensions, surfaces, positions, timing, mic topology, provider state, motif facts and human judgments. Replace fake precision with semantic zones/relationships. Return all `UNKNOWN_REQUIRES_EVIDENCE` items.

## MC-04 PROVENANCE CHAIN BUILDER
For every important scene artifact record `SOURCE -> DERIVATION -> VERSION/HASH -> ACCEPTANCE STATUS -> DESCENDANTS`. Distinguish chat recovery, script authority, machine analysis, live render and human evidence.

## MC-05 CONTRADICTION / SUPERSESSION RESOLVER
When old staging, new script, current state or another AI disagree, determine which claim is stale, project-only, current, compatible or unresolved. Do not blend incompatible branches.

## MC-06 PROTECTED-FACT / REVERSIBILITY MAP
Separate hard protected story facts from reversible directorial choices. Mark what may be changed cheaply later without invalidating text/performance/asset locks.

## MC-07 EXECUTION-PERMISSION GATE
Before any paid/render/write action, ask whether current project frontier actually authorizes it. Return `PLAN_ONLY / ZERO_COST_ALLOWED / LIVE_RENDER_ALLOWED / FINALIZATION_ALLOWED / BLOCKED`.

# FAMILY B — DRAMATURGY / RELATIONSHIP / LISTENER INFERENCE

## MC-08 LISTENER CONTRACT EXTRACTOR
State what the listener must understand, feel, suspect, not conclude and still wonder after the scene. Tie spatial choices to these outcomes.

## MC-09 NARRATIVE POV vs POINT-OF-AUDITION RESOLVER
Separate story POV character, listener acoustic position, focus owner and temporary source focus. Choose POA according to inference task, not automatic head-POV imitation.

## MC-10 FOCUS-OWNER COMPILER
For every beat assign `FOCUS_OWNER / PRIMARY INFORMATION / ELEMENTS THAT MUST YIELD / HANDOFF TRIGGER`. Prevent simultaneous equal-priority sound clutter.

## MC-11 WAITING-QUESTION / REVEAL SPATIALIZER
Identify the active waiting question and show how space/movement/source changes delay, sharpen, answer or transform it without explanatory narration.

## MC-12 STATUS-GEOMETRY DIRECTOR
Map how entrance, distance, orientation, seating/standing, access and object ownership express status shifts. Reject prestige blocking with no status/story function.

## MC-13 RELATIONSHIP-AUTHORITY SPATIAL FIREWALL
Load inherited relationship state + current scene function. Allow only spatial signals authorized by that state. Flag intimacy, dominance, rescue or confinement implications created accidentally by staging.

## MC-14 CONSENT / POWER / ENCLOSURE QC
Audit blocking for trapping, body enclosure, obstructed exits, coercive proximity, touch authority and power imbalance. Distinguish intended threat/status from accidental romantic or abusive coding.

## MC-15 STILLNESS / SILENT-REACTION DIRECTOR
Map purposeful stops, waits, looks, listening holds and withheld movement. Return `TRIGGER -> BODY STATE -> LISTENER FUNCTION -> RELEASE TRIGGER`. Do not fill silence by default.

# FAMILY C — GEOMETRY / BODY / OBJECT CONTINUITY

## MC-16 SEMANTIC FLOOR-PLAN BUILDER
Create named zones, thresholds, source objects, visibility relations and travel routes. Use exact measurements only when sourced.

## MC-17 CONTINUOUS BODY-PATH VALIDATOR
Track every important character continuously through the scene. FAIL teleportation or any line/action impossible from current physical position.

## MC-18 ACCESS / SIGHT / HEARING / REACH MATRIX
For each key beat check `CAN_SEE / CAN_HEAR / CAN_TOUCH / CAN_REACH / CAN_BE_HEARD / CAN_EXIT`. Use it to validate evidence discovery and object actions.

## MC-19 ENTRY / EXIT / THRESHOLD DIRECTOR
Design pre-entry audibility, door/threshold action, first address, entry path, last address and departure consequences. Treat thresholds as status/information boundaries where justified.

## MC-20 MULTI-ROOM ROUTE COMPILER
For routes across rooms/zones map acoustic transitions, audibility, surfaces if known, offscreen source ownership, destination event and return path.

## MC-21 MOTION-ECONOMY CONTROLLER
Give every move a reason and every non-move a reason. Remove redundant pacing, stereo choreography and decorative body motion. Return the minimum movement set that preserves causal geography.

## MC-22 OBJECT OWNERSHIP / CUSTODY LEDGER
Track important objects through `OWNER -> LOCATION -> ACTION -> RECEIVER -> SOUND -> STORY FUNCTION -> NEW STATE`. Apply especially to evidence, keys, phones, documents, weapons/tools and personal objects.

## MC-23 TOUCH / CONTACT GEOMETRY
For handoffs, touch, restraint, assistance and object manipulation define body/object contact, permission, story function and audible consequence. Reject generic Foley detached from physical ownership.

# FAMILY D — PERFORMANCE / VOICE / PHYSICAL PLAUSIBILITY

## MC-24 PERFORMANCE↔BODY↔SPACE COMPATIBILITY
Check whether take energy, projection, breath, confidentiality, effort and listener address physically support planned movement/distance. Route to rerender before mix when they do not.

## MC-25 BODY + HEAD + MOUTH ORIENTATION DIRECTOR
Define body orientation, head turn, mouth/source direction and intended addressee at important beats. Distinguish physical turn from pan automation.

## MC-26 LINE-ENTRY IMPULSE / MOVEMENT BINDING
For each important line define what was heard/seen/felt immediately before entry and whether the line occurs before/during/after movement. Prevent arbitrary movement-on-dialogue.

## MC-27 MOVEMENT-DURING-SPEECH CLASSIFIER
Choose `SPEAK_BEFORE_MOVE / SPEAK_DURING_MOVE / MOVE_AFTER_LINE / LINE_TRIGGERS_MOVE / MOVE_INTERRUPTS_LINE / MOVEMENT_STOPS_FOR_LINE` with rationale.

## MC-28 PROJECTION / DISTANCE PERFORMANCE TEST
Test whether a voice still sounds physically plausible at planned distance/room. Distinguish directorial underplay from impossible whisper/shout reconstruction.

## MC-29 DIRECTION-RESPONSIVENESS TEST
For important roles, compare natural/restrained take with one precise playable direction change. Use response quality as evidence for future performance/casting decisions.

## MC-30 PERFORMANCE CONTINUITY / FATIGUE CHECK
Across scene/episode, inspect breath, energy, vocal age, accent, cadence, emotional state and synthetic fatigue. Do not approve an isolated attractive take that collapses in long form.

## MC-31 PAIR / ENSEMBLE PHYSICALITY TEST
Check whether combined performances create believable shared room/status/listening behavior. Chemistry/conflict must survive underplay and spatial realism; reject pairings that work only through forced intensity.

# FAMILY E — MEDIA / ACOUSTIC / MUSICAL IDENTITY

## MC-32 CAPTURE-MODE SELECTOR
Choose `REAL_STAGE / VIRTUAL_STAGE / HYBRID_STAGE` from story, editability, provider/human constraints, repeatability and cost. State why.

## MC-33 CAPTURE-TOPOLOGY CAPABILITY GATE
Choose mono/stereo/binaural/multi-mic/virtual topology and explicitly list localization promises the topology can and cannot support.

## MC-34 ACOUSTIC-PASSPORT RESOLVER
Load/create current room/acoustic passport: material identity, directness, reflection intent, noise floor, source hierarchy and prohibited substitutions. Never invent measured RT60/dimensions.

## MC-35 DEVICE-DOMAIN LOCALIZER
For phone/cassette/radio/intercom/logger/speaker define physical device location, media processing, room inheritance and offscreen localization. Recorded people must not float as live bodies.

## MC-36 SAME-PERSON / DIFFERENT-MEDIUM IDENTITY GATE
Protect core performer identity across media while allowing bandwidth/noise/device changes. Reject accidental actor/age/ghost/villain identity change.

## MC-37 POINT-OF-AUDITION / SOURCE-DEPTH COMPILER
Translate source geometry into direct/reverberant ratio, spectral depth, occlusion, width and distance intent. Avoid pan-only distance.

## MC-38 MUSICAL-FACT PASSPORT
For recurring diegetic motifs/clues define canonical identity, pitches/intervals if actually locked, rhythm/contour, allowed transformations, medium variants, source asset, unresolved facts and forbidden substitutions.

## MC-39 MUSIC-STORY-FUNCTION FIREWALL
For score/diegetic music assign exact story function and entry/exit authority. Reject music that reveals guilt, romance, supernatural ontology or emotional verdict before evidence earns it.

# FAMILY F — FOLEY / EDIT / TIMING / MIX

## MC-40 MOVEMENT↔FOLEY COUPLER
Bind trajectory segments to footsteps, cloth, doors, chairs, surfaces and body changes. Voice and Foley must describe one moving body.

## MC-41 STORY-CRITICAL FOLEY CLASSIFIER
Classify Foley as `CAUSAL_EVIDENCE / ORIENTATION / CHARACTER_BEHAVIOR / TEXTURE / DECORATIVE`. Causal Foley receives higher preservation and QC priority.

## MC-42 CLUE-MASKING BUDGET COMPILER
For every evidence beat specify allowed competing energy from Foley, ambience, music and automation. Protect mono/mobile/1.25x comprehension where required.

## MC-43 SEMANTIC ANCHOR REGISTRY
Create stable anchors tied to source units/actions before absolute timing exists. Record what each anchor controls: movement, Foley, silence, media, mix or music.

## MC-44 LIVE-ALIGNMENT LINEAGE RESOLVER
Convert anchors to absolute time only through `SOURCE -> ACCEPTED TAKE -> VERIFIED ALIGNMENT -> RESOLVED EVENT`. Block synthetic/stale timing.

## MC-45 EDIT-FIRST PERFORMANCE PRESERVER
Before rerender, test whether edit, comp, trim, pause, gain or source selection can fix the defect without altering a good performance. Preserve accepted takes by default.

## MC-46 SPATIAL-AUTOMATION COMPILER
Generate renderer-neutral automation for distance, width, pan/binaural intent, off-axis change, room send and occlusion from accepted geometry/timing. No aesthetic curves without causal purpose.

## MC-47 MIX-HANDOFF CONTRACT
Produce explicit stem/source/event/automation/mono-fallback/asset-lock instructions and unresolved gates. Separate “resolved instruction” from “executed mix evidence.”

# FAMILY G — QC / HUMAN COMPREHENSION / SELECTIVE REPAIR

## MC-48 GEOMETRY / CONTINUITY QC
Machine/human audit positions, paths, thresholds, source objects, sight/hearing/reach constraints and event order. Flag impossible geography.

## MC-49 RELATIONSHIP / FALSE-INTIMACY QC
Audit proximity, breath, whisper, stereo placement, touch and score for relationship implications not authorized by current story state.

## MC-50 MEDIA-IDENTITY QC
Blind-test whether same performer remains same person across media and whether device/source identity is obvious without explanatory narration.

## MC-51 MONO / PHONE / HEADPHONE TRANSLATION QC
Verify critical causal distinctions survive mono, ordinary phone speaker and headphones; localization must not depend on pan alone.

## MC-52 ONE-LISTEN CAUSAL COMPREHENSION TEST
After one normal-speed listen ask what source/object produced what fact, who knew what, what is proved/not proved, what choice occurred and what question remains. Record earliest false inference.

## MC-53 SPATIAL NATURALNESS / ARTIFACT QC
Listen for automation jumps, phase/width artifacts, floating sources, implausible reverb, detached Foley and processing that reveals the technique instead of the scene.

## MC-54 EARLIEST-FAILED-LAYER ROUTER
Given a real defect classify earliest failed layer: `SOURCE / PERFORMANCE / BODY_PATH / FOLEY / DEVICE_DOMAIN / ACOUSTICS / ALIGNMENT / EDIT / MIX / MASTER`. Do not patch descendants first.

## MC-55 SELECTIVE REPAIR + REGRESSION CONTRACT
Define smallest patch, protected upstream, affected descendants, required regression listen/metrics and explicit “do not change” list. Close only on new evidence.

# FAMILY H — PRODUCTION / SCALE / HANDOFF / LEARNING

## MC-56 ASSET-LOCK / VERSION-IDENTITY GATE
Verify every recurring voice, Foley, ambience, device, motif and room asset has identity/version/hash/provenance where required. Reject silent asset substitution.

## MC-57 PROVIDER-CAPABILITY / FALLBACK GATE
Check current provider actually supports required voice count, model, output, timing/alignment and audio format. Define fail-closed fallback without rewriting story.

## MC-58 COST / BATCH / CANARY ROUTER
Choose smallest decisive render: technical canary -> fair comparison -> discriminating test -> pair/ensemble -> hard scene -> scale. Full manifest is capacity plan, not spend permission.

## MC-59 HUMAN-PERCEPTUAL EVIDENCE GATE
Define which questions require real Founder/listener/human review. Reject simulated Human Signal or internal-model claims of commercial/emotional success.

## MC-60 RELEASE-GATE COMPILER
Require story authority, asset locks, live timing, causal comprehension, mono/device translation, no FATAL/MAJOR, human listen and current scale permission. Return `GO / RETEST / NO-GO / BLOCKED`.

## MC-61 CROSS-AI REVIEW PACKAGER
Prepare bounded source-parity packets for Claude/Grok/GPT/specialists. Separate diagnosis from proposed repair; semantic-dedupe repeated model findings; external AI never becomes canon by vote.

## MC-62 PROJECT-LEARNING EXTRACTOR
After validated production, extract abstract reusable mechanism from project result, strip names/clues/voice IDs/chronology, test generality and send only qualified learning to universal registry.

## MC-63 CONTINUOUS-STATE / NEXT-OBLIGATION HANDOFF
Persist `DONE / STATUS / SOURCE VERSION / ACCEPTED LOCKS / OPEN GATES / BLOCKERS / EXACT NEXT UNBLOCKED ACTION`. Re-read fresh state before continuing in concurrent-dialog environments.
