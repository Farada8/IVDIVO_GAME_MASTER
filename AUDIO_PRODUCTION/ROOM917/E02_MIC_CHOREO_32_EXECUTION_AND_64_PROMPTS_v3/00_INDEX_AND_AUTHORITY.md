## Evidence-grade law introduced by this pass

Every staging assertion is classified as one of:

- `SCRIPT_EXPLICIT` — directly stated by locked script/SFX/action.
- `CONTINUITY_REQUIRED` — not separately narrated, but must be physically true for a later explicit line/action to make sense.
- `DIRECTORIAL_INFERENCE` — compatible, motivated production choice; useful but not a script fact.
- `UNSUPPORTED` — not justified by current source; do not promote.

This distinction corrects an over-broad tendency in earlier recovery prose to describe some good directorial choices as though they were literal script facts.
