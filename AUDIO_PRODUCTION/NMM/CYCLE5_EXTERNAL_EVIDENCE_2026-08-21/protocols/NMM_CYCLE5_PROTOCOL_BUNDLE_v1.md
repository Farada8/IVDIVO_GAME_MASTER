# NMM CYCLE5 PROTOCOL BUNDLE v1

## Failure classification
Every prompt ends `PASS_ENGINEERING`, `HOLD_EXTERNAL`, `HOLD_DEPENDENCY`, `REJECT`, or `PASS_EXTERNAL`. External PASS requires authenticated provider or declared real-human evidence. Engineering readiness is not an external PASS.

## Provider → Cast
1. Check credential without persisting secret.
2. Acquire universal authenticated snapshot through the shared Audio Studio path.
3. Revalidate freshness.
4. Consume Wave10 normalized inventory/cast readiness; do not duplicate it.
5. Apply NMM role metadata filters.
6. No paid audio until exact S0 manifest is sealed.
7. Capability PASS never implies voice lock.

## S0 canary
Exact source + settings must be sealed before dispatch. Each role canary is paid only after provider snapshot and cast metadata gates pass. Ingest must produce canonical evidence; malformed alignment is quarantined. No canary result exists in this cycle because provider credential is absent.

## Real human/device
A session is sealed before playback with listener ID, protocol hash, artifact-set hash, device and one-listen rule. Raw answers are frozen before scoring. Headphones and phone are separate runs. Per-listener failures remain visible. No human result may be fabricated.

## Finalist + ledger
At most two finalists. Human/device evidence is mandatory. Earbuds + low-volume phone translation precede hash-binding. Ledger is append-only and accepted/rejected/HOLD decisions retain provenance.

## Self-improvement
Cycle5 learning enters self-improvement as project evidence only. One NMM run cannot allocate/promote a universal SI mechanism. Reuse Wave10, SI-0014 and SI-0015. New project-neutral candidate requires replication on another real project and no leakage of NMM story/asset identity.
