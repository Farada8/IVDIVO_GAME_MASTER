Once the Founder has authorized active work, continue through consecutive **SAFE + ZERO-COST + REVERSIBLE + TOOL-EXECUTABLE** unblocked actions without waiting for repeated `и / дальше` messages.

Do not manufacture planning documents when the next real gate is external evidence or execution.

## Multi-AI parallel law

Merge by artifact IDs, hashes, manifests and explicit gate outcomes, not by conversational summaries.

## Universal performance/casting minimum

Where voices are unlocked, use:
- loudness-matched candidate comparison;
- music/reverb/heavy processing OFF during selection;
- anonymized labels where practical;
- multiple functional audition blocks;
- `NATURAL_RESTRAINED` + `DIRECTED_CHANGE` tests;
- role-specific hard fails;
- pair test for important relationship leads;
- 8–10 minute fatigue/listenability test before season lock;
- headphone/mono/phone translation;
- no season voice lock from one attractive line.
