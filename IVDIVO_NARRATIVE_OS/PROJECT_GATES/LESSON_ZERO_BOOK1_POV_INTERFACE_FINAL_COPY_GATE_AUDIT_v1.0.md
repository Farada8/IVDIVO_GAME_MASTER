## 2. INTERFACE / DISPLAY LANGUAGE — GREEN

Protect the distinction: **DATA STRING ≠ SPOKEN REFERENCE ≠ NARRATIVE REFERENCE.**

Examples such as `PROFILE RECOGNIZED`, `MATRIX / ROOT LIBRARY — REF ONLY` and `PROTOCOL INSERT 7C — RELATIONAL STATE MAPPING` remain materially stable when functioning as actual data.

**Decision:** Interface / Display Gate GREEN.

## 4. CANON QUERY — ORRIN vs ORREN

**Status: OPEN / DO NOT NORMALIZE**

The manuscript contains two stable forms:

`ORRIN` — visiting group/reference-profile designation in WCF material (`VISITING GROUP ORRIN`, `ORRIN FRAME-SUPPORTED`, `ORRIN: NOT PRESENT`).

`Orren` — named provenance specialist (`Specialist Orren`).

Both forms recur consistently enough that neither can safely be treated as a typo. They are nevertheless close enough to confuse a reader.

Current evidence does not establish whether Orren is intentionally associated with the Orrin group, the similarity is intentional but unrelated, or one spelling originated accidentally.

**Rule:** do not replace `Orrin` with `Orren` or vice versa without Founder/canon decision.

This does not require reopening story development.
