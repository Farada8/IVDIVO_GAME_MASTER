# IVDIVO NARRATIVE OS — ADVERSARIAL 10-LENS REVIEW GATE

**Status:** PROPOSED CURRENT UPGRADE
**Version:** 1.0
**Date:** 2026-08-21

## PURPOSE

Replace ritualized headcount review with a compact operational gate while retaining the 100-profession studio as a deep specialist catalog.

The gate is for **review/orchestration**, not for eliminating specialist knowledge.

## DEFAULT 10 LENSES

Each lens returns at most:
- 1 FATAL;
- 1 MAJOR;
- 1 MEDIUM;
- optional POLISH only if material.

1. **Dramaturgy & Causality** — want/action/resistance/price/escalation/midpoint/climax/resolution.
2. **Character Psychology & Agency** — desire, contradiction, choice, believable cost/change, non-passivity.
3. **Relationship / Romance** — earned attachment, power, consent, rupture/repair, P46–P50 where applicable.
4. **Mystery / Information Fairness** — clue economy, knowledge states, alternate hypotheses, no cheating reveal.
5. **Dialogue / Idiolect** — verbal action, subtext, P51 fingerprint, blind-swap resistance, loss of polish under pressure.
6. **Emotional Dynamic Range** — P52 temperatures, control breaks, ordinary-life texture, catharsis vs monotony.
7. **Medium Craft** — prose/screen/audio-specific legibility; for audio include sonic causality, clue audibility and silence.
8. **Continuity / Canon / Factual Plausibility** — timeline, authority, prior consequences, specialist flags.
9. **Reader / Retention / Market Promise** — turn-page/play-next desire, boredom/homework, genre promise vs packaging.
10. **Independent Red Team** — breakage, cliché, false stakes, consent/power, easiest damaging counterargument.

## SPECIALIST ESCALATION

A lens may call a deeper specialist only when the result could materially change a decision.

Examples:
- sports medicine;
- law/evidence procedure;
- orbital engineering;
- youth psychology;
- sociology/economics;
- Smith/OES historical depth;
- audio mastering/voice provider;
- action/horror;
- market specialist.

Do not run all specialists by default.

## INDEPENDENCE

Where practical, the most diagnostic lenses should not see each other’s verdicts before submission, especially:
- causality;
- character;
- mystery/continuity;
- reader reception;
- market;
- Red Team.

Reconciler/Integrator compares afterward.

## VERDICT LAW

- Any FATAL blocks dependent progression.
- MAJOR must be repaired or explicitly rejected with evidence before the affected gate passes.
- MEDIUM may be queued if it does not threaten the current gate.
- POLISH does not reopen locked structure.

Do not average severities into a reassuring numeric score.

## HUMAN SIGNAL

This panel remains internal model/editorial evidence. It cannot produce external Human Signal.

For release validation where required, use blind target-audience evidence separately.

## 100-STUDIO RELATION

The `100-person` layer remains useful as:
- a role taxonomy;
- specialist prompt library;
- routing inventory;
- domain escalation source.

It is **not** evidence that one hundred independent reviews occurred.

## OUTPUT

Return one integrated report:
- FATALS;
- MAJORS;
- MEDIUMS;
- specialist escalations;
- protected strengths / do-not-break;
- earliest failed stage;
- repair scope;
- gate verdict.

No fake committee transcript.
