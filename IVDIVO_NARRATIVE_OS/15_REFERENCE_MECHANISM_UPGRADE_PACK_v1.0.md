## SOURCE DISCIPLINE

Classify source before using it:
- `LIKELY_FULL`
- `FRAGMENT_EXPLICIT`
- `COLLECTION_UNVERIFIED`
- `SCANNED_TEXT_UNAVAILABLE`
- `DUPLICATE`

Never infer whole-book architecture from an opening fragment. Duplicates add zero independent evidence weight.

Reusable mechanism record:
`FUNCTION -> HUMAN EFFECT -> ABSTRACT FORMULA -> CONDITIONS -> FAILURE MODE -> COPY BOUNDARY -> POSSIBLE ACTIVE-PROJECT USE`.

## PROMOTED ABSTRACT MECHANISMS

### Controlled revelation loop
`CONCRETE HUMAN TASK/WANT -> COLLIDES WITH RULE/UNKNOWN -> OBSERVABLE CONSEQUENCE -> CHARACTER UPDATES MODEL -> NEW KNOWLEDGE CREATES HARDER DECISION`.

### Experience before explanation
`SYMPTOM/RESULT/BEHAVIOR -> INTERPRETATION -> TERMINOLOGY -> DEEPER ONTOLOGY`.
Explanation should arrive when it enables a more consequential action, not merely when lore wants page space.

### Competence before confession
`TASK -> METHOD -> TRADEOFF -> CONSEQUENCE -> HUMAN DISCLOSURE`.
Demonstrated work should carry character before explanatory biography does.

### Attachment through behavior
Use repeated attention, remembering, making room, accepting cost, respecting boundaries, changing routine and returning without applause. Do not force every relational movement into declaration.

### Ontology serves a human want
Ask: `If the metaphysics/technology vanished, what immediate human problem would remain?` If none, the story may be lore-led.

### Answer -> action
Important answers should alter objective, hypothesis, relationship, authority, risk, location, resource or moral choice. Avoid `answer -> lecture`.

### Finite near-term pressure window
`LARGE SYSTEMIC PROBLEM + CAUSAL FINITE LOCAL WINDOW = PLAYABLE PRESSURE`.
Use real custody/shift/launch/hearing/medical/contract/access windows, not arbitrary clocks.

### Hierarchy through body/labor/access
Show who waits, repairs, carries, gets keys, rooms, transport, interruption rights, refusal rights and belief before naming the hierarchy.

### Control separation
`FORMAL OFFICE != PRACTICAL COMPETENCE != TECHNICAL CONTROL != SOCIAL STATUS != LEGAL AUTHORITY != INFORMATION ACCESS != EMOTIONAL LEVERAGE`.

### Role/person contradiction
Strong character pressure often comes from the role colliding with the private person. The contradiction must create choices, not just biography.

### Self-protective interpretation
`FACT -> SELF-PROTECTIVE MODEL -> ACTION -> COST -> MODEL PRESSURE`.
Believable delay need not require stupidity.

### Help without consent can repeat control
Test whether help was requested, whether refusal is possible, whether information is withheld “for their own good,” and whether rescue is buying intimacy/obedience.

### Meaningful choice before culpability
Where possible, let a suspect/character make an autonomous consequential choice before the narrative reduces them to guilty/innocent function. Preserve the strongest reasonable innocent interpretation until evidence defeats it.

### Choice proves personhood
For AI/synthetic/nonhuman consciousness stories, independent preference, refusal, responsibility and self-authored costly choice are stronger than speeches declaring consciousness.

### Exit state law
Prefer chapter/episode exits that change `information / decision / relationship / status / location / risk / commitment / question quality`, not generic danger wallpaper.

## ORIGINALITY / COMBINATION LAW

1. identify current story problem;
2. retrieve 2–3 mechanisms by function;
3. remove source-specific content;
4. combine compatible causal functions;
5. transform through current hero/world/conflict;
6. run source-distance check;
7. reject any result still recognizably dependent on one source’s distinctive execution.

A mechanism is useful only if it changes a real production decision. Interesting terminology alone is not enough.
