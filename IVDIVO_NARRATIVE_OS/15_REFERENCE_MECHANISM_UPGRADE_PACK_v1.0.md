## Current reusable craft abstractions

### Story causality
A checklist, beat sheet or production pipeline does not substitute for internal causality. Story remains:
`HERO -> WANT -> WHY NOW -> OPPOSITION -> ACTION -> RESISTANCE -> CHOICE -> PRICE -> ESCALATION -> CLIMAX -> CHANGE -> RESOLUTION`.

Do not reopen a GREEN/locked Story Core merely because a new craft source exists. Route structural craft to Development/Architecture only when evidence shows that layer failed.

### Character action / adaptation
Use:
`GIVEN CIRCUMSTANCES -> PRESENT WANT -> PARTNER/WORLD RESPONSE -> TACTIC -> ADAPTATION -> CHANGED STATE`.

A character can be active by pursuing, refusing, delaying, cooperating, testing, restraining, bargaining, withdrawing, protecting, exposing or enduring in a way that changes state.

**AGENCY != AGGRESSION.**

### Dialogue / performance
Dialogue is action under pressure. For important exchanges track:
`WANT / RESISTANCE / TACTIC / STATUS / LISTENING / PAUSE / SAID / UNSAID / UNSAYABLE / TURN`.

Pleasant wording or timbre cannot replace objective, opposition, subtext and changed relationship/status.

### Inner tempo / outer motion / typography firewall
Keep distinct:
`INNER PROCESS SPEED != OUTER MOTION SPEED != SENTENCE LENGTH`.
`BEAT MAP != TYPOGRAPHY`.
`ACTION / SUSPENSE / EMOTION != SHORT-SENTENCE DENSITY`.

Private rehearsal/character laboratory is also separate from page obligation:
`PRIVATE REHEARSAL / CHARACTER LAB != MANUSCRIPT EXPOSITION`.

### Evidence / knowledge-state law
For factual, investigative, mystery and world claims distinguish:
`WORLD FACT -> TRACE/SOURCE -> SOURCE LINEAGE -> ACCESS -> INTERPRETATION -> ALTERNATIVE MODEL -> CORROBORATION STATUS -> ACTION`.

A clue is not its interpretation. A preferred theory is not proof. A character may not act on information unavailable in current story state.

### Story / discourse control
Chronological truth and presentation order are separate variables:
`STORY FACT -> ORDER -> DURATION -> FREQUENCY -> DISTANCE/FOCALIZATION -> VOICE/SOURCE LEVEL -> READER MODEL -> ACTION/INFERENCE`.

Fair withholding controls reader inference without making competent POV characters artificially forget or conceal what they naturally know.

### Anti-choppiness / coherence route
When prose feels mechanical, diagnose upstream before line cosmetics:
`BOOK ENGINE -> CAUSAL FENCE -> CHAPTER FUNCTION -> SCENE ADMISSION -> ORDER/DURATION/FREQUENCY -> SCENE WEIGHT/MODE -> POV/EVIDENCE -> EXPOSITION/DIALOGUE MODE -> PARAGRAPH TOPIC CHAIN -> OLD->NEW / READER-STATE CONTINUITY -> INNER/OUTER TEMPO -> SENTENCE RHYTHM/CONTRAST -> WORDING`.

Do not repair a broken scene by varying sentence length before the scene has a real objective, resistance, turn and consequence.

### Sound / audio dramaturgy
Sound, music, proximity, point-of-audition, perspective and silence are story information, not decorative density. Performance rhythm may drive edit/sound timing. Plot-relevant pitched/musical identity follows current Audio contracts rather than independent provider invention.

### Suspense / listener contract
Track what the reader/listener is emotionally waiting for. Mystery asks what is true; suspense asks what may happen and whether it can be prevented/survived. Delay must arise from opposition, uncertainty, incomplete evidence, competing goals, risk or relationship cost — not arbitrary withholding.

## Tool anti-overfit / rewrite law

Tools help ask, organize, compare and diagnose. The story does not exist to validate tools.

A rubric score, mechanism count, beat count, prompt-compliance report, temperature chart or improved average does not prove a stronger story. Verify causal, emotional, character and reader/listener consequence.

Standing rule:
`NO NEW EVIDENCE -> NO NEW GLOBAL REWRITE`.

New craft learning may improve new/open work and targeted FATAL/MAJOR repair. It does not automatically reopen locked books or GREEN structures.

## Craft metaphor / ontology firewall

Craft/acting language such as energy centres, telepathy, right-brain/left-brain shorthand, mystical inspiration or analogous rehearsal metaphors remains craft/historical language unless independently verified by the relevant factual/scientific authority. It does not become IVDIVO cosmology, science or metaphysics because a craft source uses it.
