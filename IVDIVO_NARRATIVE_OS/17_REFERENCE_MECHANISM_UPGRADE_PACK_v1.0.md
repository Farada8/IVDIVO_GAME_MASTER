## PROMOTED ABSTRACT MECHANISMS

### Controlled revelation loop
`CONCRETE HUMAN TASK/WANT -> RULE/UNKNOWN -> OBSERVABLE CONSEQUENCE -> MODEL UPDATE -> HARDER DECISION`.

### Experience before explanation
`SYMPTOM/RESULT/BEHAVIOR -> INTERPRETATION -> TERMINOLOGY -> DEEPER ONTOLOGY`.

### Competence before confession
`TASK -> METHOD -> TRADEOFF -> CONSEQUENCE -> HUMAN DISCLOSURE`.

### Attachment through behavior
Build attachment through noticing, remembering, making room, respecting boundaries, accepting cost, changing routine and returning without applause.

### Ontology serves a human want
Ask what immediate human problem remains if the metaphysics/technology vanishes. If none, the scene/story may be lore-led.

### Answer -> action
Important information should alter objective, hypothesis, relationship, authority, risk, resource, location or moral choice. Avoid `answer -> lecture`.

### Finite pressure window
`LARGE SYSTEMIC PROBLEM + CAUSAL FINITE LOCAL WINDOW = PLAYABLE PRESSURE`.

### Hierarchy through labor/body/access
Show who waits, repairs, carries, gets keys/rooms/transport, can interrupt/refuse and gets believed before naming the hierarchy.

### Power-domain separation
`FORMAL OFFICE != COMPETENCE != TECHNICAL CONTROL != SOCIAL STATUS != LEGAL AUTHORITY != INFORMATION ACCESS != EMOTIONAL LEVERAGE`.

### Role/person contradiction
The institutional/social role should collide with the private person in choices, not only biography.

### Self-protective interpretation
`FACT -> SELF-PROTECTIVE MODEL -> ACTION -> COST -> MODEL PRESSURE`.

### Help without consent can repeat control
Test whether refusal is possible, whether information is withheld “for their own good,” and whether rescue is purchasing intimacy/obedience.

### Meaningful choice before culpability
Preserve autonomous consequential choice and the strongest reasonable innocent interpretation until evidence actually defeats it.

### Choice proves personhood
For AI/synthetic/nonhuman consciousness stories, independent preference, refusal, responsibility and self-authored costly choice are stronger than speeches about personhood.

### Exit-state law
Prefer chapter/episode exits that change `information / decision / relationship / status / location / risk / commitment / question quality` rather than generic danger.

## COMBINATION / ORIGINALITY LAW

`CURRENT PROBLEM -> RETRIEVE 2–3 MECHANISMS BY FUNCTION -> REMOVE SOURCE-SPECIFIC CONTENT -> COMBINE COMPATIBLE CAUSAL FUNCTIONS -> TRANSFORM THROUGH ACTIVE HERO/WORLD/CONFLICT -> SOURCE-DISTANCE AUDIT`.

Reject any result still recognizably dependent on one source’s distinctive execution.

A mechanism is useful only if it changes a real production decision.
