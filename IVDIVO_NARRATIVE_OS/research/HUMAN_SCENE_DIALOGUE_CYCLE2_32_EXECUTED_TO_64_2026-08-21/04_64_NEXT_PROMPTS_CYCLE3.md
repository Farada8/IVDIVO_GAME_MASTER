# PHASE A — EPISTEMIC REALISM + POV FIREWALL — 01–08

## 01 — CERTAINTY WORD AUDIT
For every claim using words such as `is / proves / means / knows / must / obviously / definitely`, compare grammatical certainty to the speaker's evidence tag. Rewrite only where wording outruns evidence; preserve character confidence when overconfidence itself is intentional.

## 02 — INFERENCE-AS-FACT DETECTOR
In close POV, mark every statement about another person's motive/emotion. Classify OBSERVED / INFERRED / ASSUMED / KNOWN-BY-CANON. Flag narrator syntax that accidentally turns inference into omniscient fact.

## 03 — DISCONFIRMING CUE REQUIREMENT
For each high-confidence interpersonal judgment, identify at least one cue the POV character could plausibly notice that would weaken or complicate the judgment. Test whether selective blindness is character-caused or writer convenience.

## 04 — EPISTEMIC COMPRESSION WITHOUT CAVEAT DIALOGUE
Take a scene with repeated `that proves X, not Y` dialogue. Move clue boundaries into scene state and test three behavioral alternatives—silence, action, narrower question—while preserving fair-play logic.

## 05 — WRONG-CONFIDENCE VALUE TEST
Choose one important wrong belief. Increase the character's confidence by one level and test whether the scene becomes more dramatically truthful; decrease by one level and compare. Select the version that best fits history, stakes and evidence.

## 06 — KNOWLEDGE SOURCE COLLISION
For each shared fact, record who learned it first, from whom, and whether versions differ. Flag conversations where characters act as if everyone possesses the same clean source text.

## 07 — POV INTERPRETATION DEBT
When a POV character repeatedly interprets someone, track unresolved interpretations across scenes. Require later confirmation, revision or abandonment instead of leaving every inference functionally correct.

## 08 — MYSTERY EPISTEMIC REGRESSION
After drafting a clue-heavy block, build an episode/chapter table of what each principal can legitimately know at each boundary. Detect knowledge leakage introduced by later revisions.

# PHASE B — ATTENTION, MEMORY, COGNITIVE LOAD — 09–16

## 09 — ATTENTION BUDGET CARD
Allocate 100 notional attention points among task, threat, body, relationship, environment, status and private worry. Do not treat the number as scientific; use it to expose impossible simultaneous focus.

## 10 — MISSED-BUT-AVAILABLE FACT
Identify one fact each character technically knows but should fail to retrieve in this moment. Verify the miss follows attention/load rather than plot contrivance.

## 11 — COGNITIVE LOAD SPEECH DISTORTION
Increase task load, social threat or physical discomfort and predict how syntax/questioning changes for each speaker. Compare to actual draft; flag unchanged polished speech under extreme load.

## 12 — RECALL FRICTION LADDER
For an important memory, test five forms: instant exact recall / delayed exact recall / partial recall / confident wrong recall / uncertain fragment. Choose based on established memory conditions, not plot convenience.

## 13 — MEMORY CONTAMINATION TEST
If characters discussed the event before, separate original memory from later information. Flag dialogue that treats reconstructed memory as pristine observation.

## 14 — INTERRUPTED RETRIEVAL
Place an interruption between cue and recalled fact. Test whether the character resumes, forgets, simplifies or retrieves a different memory. Use only where psychologically and structurally plausible.

## 15 — FATIGUE / PAIN INFORMATION LOSS
In scenes after prolonged stress, identify what cognitive precision should degrade first for this person: names, chronology, nuance, emotional inhibition, patience, or language complexity.

## 16 — ATTENTION RE-ANCHOR TRIGGER
For every major attention shift, identify the sensory/social trigger that moves the character from task to person, threat to evidence, or private worry back to scene action. Flag untriggered writer-directed shifts.

# PHASE C — RESPONSE CAUSALITY, LATENCY, REPAIR — 17–24

## 17 — LIVE TRIGGER TRACE
For every major reply, quote the exact preceding stimulus—word, gesture, silence, object, interruption. If no live trigger exists, classify whether the line belongs to internal processing, prior unresolved business or author outline.

## 18 — EMOTIONAL LATENCY CURVE
Graph the emotional stimulus across at least five beats: first body response, first tactic, first verbal leak, private recognition, explicit naming. Flag scenes where all five collapse into one sentence.

## 19 — LATENCY CHARACTER SIGNATURE
Compare three scenes for the same character. Determine which emotions produce immediate speech versus delayed processing. Reject one-size-fits-all `pause before emotion` direction.

## 20 — DISPLACEMENT TARGET TEST
When a character cannot answer the real issue, identify what safer topic/object/person receives the response instead. Verify displacement protects a real fear/status need.

## 21 — ACTION-FIRST COMPETITION
At each high-pressure line, write an action-only alternative and an action-plus-minimal-word alternative. Keep the full line only if it performs necessary work neither alternative can.

## 22 — REPAIR STYLE STRESS TEST
Give the character the same relational overstep in three contexts: public, private, time-pressured. Verify repair style changes by register but remains recognizably theirs.

## 23 — REPAIR CEILING TEST
For each apology/repair, state the maximum believable relationship improvement before material action. Flag scenes exceeding the ceiling because a sentence is unusually eloquent.

## 24 — FAILED-REPAIR AFTERSHOCK
After a failed repair, trace how tension changes the next three interactions. Prevent conflict from disappearing because the plot moved on.

# PHASE D — CORPUS RHETORIC, REGISTER, VOCABULARY — 25–32

## 25 — CORRECTION-SYNTAX CORPUS SCAN
Across one chapter/block, list all `No / not X, Y / that is not / you mean / correction / technically` structures by speaker and narrator. Distinguish role-owned precision from house-style collision.

## 26 — ACKNOWLEDGMENT PHRASE COLLISION
Track `I know / right / fine / okay / exactly / sure` equivalents by speaker, function and register. Identify repeated neutral acknowledgments that erase voice difference.

## 27 — REGISTER DISTANCE SCORECARD
For each principal compare professional vs intimate vs defensive samples. Use qualitative distance: LOW / MEDIUM / HIGH. Flag characters whose register never changes or changes into another character's voice.

## 28 — VOCABULARY BIOGRAPHY
Take five unusual words/metaphors from a character and write a plausible biography of acquisition. If the biography cannot be supported by canon/life context, mark the wording AUTHOR-OWNED CANDIDATE.

## 29 — METAPHOR DOMAIN COLLISION
Across speakers, classify metaphors by domain: finance, machinery, body, weather, law, sport, architecture, religion, food, digital culture, etc. Identify improbable cross-speaker convergence.

## 30 — STRESS DEFORMATION REGRESSION
Compare one calm and one crisis sample per principal. Verify stress changes sentence length, certainty, humor, politeness, repetition or silence according to the person's profile.

## 31 — QUESTION-FAMILY SEPARABILITY
Blind-remove speaker names from ten questions. Ask whether question form alone suggests speaker. If not, diagnose whether convergence is natural shared culture or weak voice identity.

## 32 — DISAGREEMENT-FAMILY SEPARABILITY
Repeat the blind test using refusals/disagreement. Preserve common institutional formulas where justified; target only unsupported convergence.

# PHASE E — RELATIONSHIP SEMANTICS, POWER, PERMISSION — 33–40

## 33 — SHORTHAND AGE MAP
For each central pair mark shorthand stage: NONE / EMERGING / ESTABLISHED / DAMAGED / RESTORED. Flag lines requiring intimacy/history the relationship has not earned yet.

## 34 — RELATIONSHIP DEBT SEMANTICS
Choose five neutral phrases (`fine`, `I know`, `come here`, `leave it`, `thank you`) and test how unresolved debt changes their meaning for this pair. Use results to prevent generic wording judgments.

## 35 — RECURRENT MISREAD EVOLUTION
Track one signature misread across three scenes. It must either intensify, become questioned, or be corrected through evidence; prevent static repetitive misunderstanding.

## 36 — FORMAL VS EPISTEMIC STATUS
Create a 2-axis map of formal power and who knows more. Test how a formally weaker but epistemically stronger character can resist without false equality.

## 37 — EMOTIONAL VS SOCIAL STATUS
Map who needs whom more privately versus who can afford public loss. Use the mismatch to shape concessions, jokes and silence.

## 38 — PERMISSION SENTENCE RIGHTS
For each participant list what they can safely ask, refuse, interrupt, accuse, disclose or joke about. Flag dialogue that exercises a right the social/legal situation does not grant without consequence.

## 39 — EXIT POWER PRESSURE TEST
Rewrite a scene under three exit conditions: both free to leave / one cannot leave / neither can leave. Compare pacing and disclosure. Use the canonical condition's pressure explicitly.

## 40 — POWER CHANGE REVALIDATION
After a material power change (resignation, promotion, release, breakup, arrest, confession), regenerate the permission geometry. Do not carry old intimacy restrictions forward mechanically, and do not erase emotional residue instantly.

# PHASE F — ENSEMBLE ATTENTION + SOCIAL TOPOLOGY — 41–48

## 41 — ATTENTION TOPOLOGY TIMELINE
For each beat in a 3+ person scene, map intended audience, actual listener, visual target and task target. Detect impossible universal attention.

## 42 — SIDE-SIGNAL ECONOMY
Identify gestures/looks noticed by only one person. Verify why others miss them and what later consequence follows. Reject decorative secret looks with no behavioral effect.

## 43 — ALLIANCE SIGNAL DIVERSITY
Across one ensemble block, count who answers for whom, protects silence, hands objects, redirects attack, shares information first. Avoid repeating one alliance signal until it becomes mechanical.

## 44 — PERFORMANCE-FOR-THE-ROOM TEST
Identify lines addressed ostensibly to one person but actually intended to influence the group. Make the double audience explicit in tactic/subtext, not explanatory prose.

## 45 — GROUP STATUS CASCADE
Introduce one high-status entrance, revelation or failure. Trace how speaking order, interruption rights and eye contact change among everyone, not only the protagonist.

## 46 — MISSED INFORMATION OWNERSHIP
Choose one important line that one character misses because of task/attention. Ensure later ignorance remains consistent and does not disappear when the plot needs them informed.

## 47 — ENSEMBLE SILENCE ROLE
During a major exchange, identify why each non-speaking character remains silent: agreement, fear, calculation, distraction, respect, exclusion, uncertainty. Flag empty spectators.

## 48 — THIRD-PARTY SHADOW TEST
Remove an absent but socially powerful person from the characters' mental field. If dialogue is unchanged, test whether their supposed influence is actually active in the relationship.

# PHASE G — SCENE ARCHITECTURE + LANGUAGE BURDEN — 49–56

## 49 — STRUCTURE-BEFORE-WORDS REBUILD
Take the most explanatory scene. Describe it using only actions, choices, evidence and obstacles. Identify what dialogue is still required after structure carries its share.

## 50 — INFORMATION NEED GRAPH
For every exposition fact, connect `owner -> needer -> decision changed by fact`. Any fact with no decision/action consequence becomes narration/document/cut candidate.

## 51 — BEAT IRREVERSIBILITY TEST
For each major beat ask: what becomes impossible after this beat? If nothing changes, the beat may be conversational activity rather than drama.

## 52 — TURN WITHOUT THEME LINE
Remove the most thematic line at the scene turn. If the value shift disappears, strengthen action/consequence. If the scene improves, the line was likely naming what behavior already proved.

## 53 — SUBTEXT PRESSURE SOURCE
For every unsaid truth name the force suppressing it: fear, status, loyalty, shame, uncertainty, self-deception, strategic concealment. Flag ornamental subtext.

## 54 — INDIRECT PLAN SUCCESS/FAILURE
For each participant with hidden desire, state the indirect plan and whether each dialogue beat advances or damages it. Reject lines that merely sound suggestive.

## 55 — SILENCE DOMINANCE TEST
At the three most polished lines, compare silence/action versions. If silence preserves or increases dramatic meaning, treat the line as deletion/underplay candidate.

## 56 — SCENE TAIL DECAY TEST
After the turning point, mark each remaining line as CONSEQUENCE / NEW DECISION / NEW THREAT / EXPLANATION / EMOTIONAL LABEL. Compress explanation/label clusters unless required for next causality.

# PHASE H — VALIDATION, AUDIO, LOCALIZATION, PROMOTION — 57–64

## 57 — TEXT VS PERFORMANCE SPLIT
For each flagged line, create two hypotheses: WORDING FAILURE and PERFORMANCE FAILURE. Specify the minimum audio test that can discriminate between them before rewriting source text.

## 58 — UNDERPLAY CANARY
Choose lines vulnerable to sounding clever or therapeutic. Direct one neutral/underplayed take and one emphasized take. Test whether credibility changes without text edits.

## 59 — LISTENING-REACTION CANARY
Render/perform the same line with and without partner reaction before it. Determine whether the perceived artificiality comes from missing listening rather than wording.

## 60 — LOCALIZATION FUNCTION PRESERVATION
For humor, status and intimacy, translate the **social function** first, then compare literal wording. Classify SOURCE / LOCALIZATION / PERFORMANCE failure separately.

## 61 — HUMAN DISAGREEMENT MATRIX
When listeners disagree, record language fluency, context familiarity, performance version and defect label. Separate taste variance from repeated independent credibility breaks.

## 62 — MINIMAL PATCH A/B/C
For a proven text defect create: A=current, B=minimal causal repair, C=over-naturalized banal control. Human-test whether B improves belief without losing compression/voice.

## 63 — CORPUS REGRESSION AFTER PATCH
After accepting B, rescan rhetorical fingerprint, register, question/disagreement identity and relationship semantics. Reject repairs that solve one line by importing another house-style pattern.

## 64 — CYCLE-3 PROMOTION GATE
For each mechanism N01–N16 classify: UNIVERSAL HARD GATE / UNIVERSAL SOFT GATE / PROJECT OVERLAY / NEEDS HUMAN SIGNAL / REJECT / MERGE. Require evidence, regression result, cost, false-positive risk and rollback plan.
