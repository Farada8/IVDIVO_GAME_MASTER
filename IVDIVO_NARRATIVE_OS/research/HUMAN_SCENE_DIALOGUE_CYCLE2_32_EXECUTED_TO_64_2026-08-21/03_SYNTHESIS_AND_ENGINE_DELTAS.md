# 03 — SYNTHESIS + ENGINE DELTAS — CYCLE 2

**Status:** COMPLETE

**Output:** candidate mechanisms N01–N16 + integration priorities.

## Core conclusion

The Naturalism Engine has moved the system from `good scene objective -> polished lines` toward `human state -> response -> line`, but the second cycle proves a remaining structural problem:

> **Scene-level naturalism is not enough. A model can pass a local Human Scene gate and still reproduce the same rhetorical reflex across a chapter, episode block or whole book.**

That is exactly what the cross-project comparison shows:
- LESSON ZERO has repeated correction/reframe and dry-semantic patterns across characters;
- BLOODBOUND E06 v1.0 was already repaired for a similar cluster;
- BLOODBOUND E07 remains stronger than older material but still regenerates some compact semantic correction ladders.

The next engine layer therefore must operate at **three scales simultaneously**:

`LINE CAUSALITY -> SCENE HUMAN TRUTH -> CORPUS RHETORICAL SEPARATION`.

---

# N01 — EPISTEMIC STATE TAG

For every important claim, scene state should carry:
`basis = observed / told / remembered / inferred / suspected / believed / known / wrong` plus confidence.

Purpose: preserve mystery/logic without making characters repeatedly say polished caveats such as `That proves X, not Y`.

**Promotion:** REQUIRED for mystery/institutional/high-stakes scenes.

---

# N02 — POV PERCEPTION FIREWALL

A close-POV narration may not silently upgrade inference about another mind into fact.

Required distinction:
`OBSERVABLE CUE -> POV INTERPRETATION -> CONFIDENCE -> ALTERNATIVE`.

Purpose: prevent `writer omniscience disguised as empathy`.

**Promotion:** REQUIRED in close POV / limited narrator modes.

---

# N03 — ATTENTION BUDGET

Characters do not have perfect RAM.

Each scene state can allocate attention among:
- task/evidence;
- physical threat;
- status/social threat;
- relationship;
- fatigue/pain;
- environment;
- private worry.

Known information outside active attention should not be retrieved instantly without trigger.

**Promotion:** REQUIRED for complex ensembles, crisis and technical scenes.

---

# N04 — RECALL FRICTION

Memory access under pressure needs a realism model:
`retrieval speed / completeness / confidence / contamination / correction later`.

Purpose: prevent thriller characters from recalling exact dates, wording and names because the outline needs them now.

**Promotion:** CONDITIONAL HARD GATE in high-stress investigative scenes.

---

# N05 — FALSE BELIEF LANGUAGE CONSEQUENCE

False belief must affect:
- what is noticed;
- which question is asked;
- which answer is rejected;
- what is omitted;
- what wording feels safe.

A false belief that only exists in a bible is inert.

**Promotion:** REQUIRED for major character/relationship arcs.

---

# N06 — LIVE TRIGGER / CAUSE-TO-LINE GRAPH

Every important response should have a live stimulus from the partner/environment, not merely thematic relevance.

`stimulus -> perceived meaning -> want -> risk -> tactic -> words/action`.

Purpose: detect when the **writer is replying to the previous sentence** instead of the character replying to the person.

**Promotion:** REQUIRED for flagged lines, clever lines and emotional turns.

---

# N07 — EMOTIONAL LATENCY CURVE

Track emotional response over several beats, not one pause.

Possible states:
`IMMEDIATE / DELAYED / DISPLACED / SUPPRESSED / ACTION-FIRST / PRIVATE PROCESSING / LATE VERBALIZATION`.

Purpose: stop every emotional stimulus receiving an immediate perfectly articulated answer.

**Promotion:** REQUIRED in intimacy, betrayal, grief, fear and status-loss scenes.

---

# N08 — REPAIR STYLE + REPAIR CEILING

Each character needs a repair fingerprint and each relationship needs a ceiling on how much words can repair without action.

Repair modes:
`direct apology / joke / factual correction / service / retreat / silence / touch / gift / disclosure / restitution`.

Purpose: stop generic emotional literacy and instant resets.

**Promotion:** REQUIRED for relationship-heavy projects.

---

# N09 — CORPUS RHETORICAL FINGERPRINT

New mandatory scale above scene QA.

Track across chapter/block/book:
- correction syntax;
- certainty markers;
- `I know` type acknowledgments;
- rhetorical reversals;
- semantic distinctions;
- apology forms;
- question families;
- joke mechanics;
- metaphor domains;
- narrator cadence.

Then compare speakers and narrator for collisions.

Purpose: catch the LESSON ZERO / BLOODBOUND recurrence that local gates miss.

**Promotion:** HIGHEST-PRIORITY NEW UNIVERSAL GATE.

---

# N10 — REGISTER STATE MACHINE

One character does not have one voice.

Define register states:
`professional / peer / intimate / defensive / public / family / private / command / exhausted`.

For each, specify triggers, syntax, vocabulary, humor and forbidden carryover.

Purpose: make identity dynamic without losing separability.

**Promotion:** REQUIRED for recurring principals.

---

# N11 — VOCABULARY + METAPHOR PROVENANCE LEDGER

For unusual words/metaphors ask:
`Where did this person get this language?`

Sources may include profession, class, family, region, hobby, media, school, obsession or shared culture.

Purpose: preserve unusual memorable lines when owned, reject them when they are merely author cleverness.

**Promotion:** REQUIRED for distinctive jokes/metaphors/technical speech.

---

# N12 — STRESS DEFORMATION PROFILE

Do not enforce generic short sentences under pressure.

Each character may become:
`shorter / more formal / fragmented / repetitive / literal / fast / silent / procedural / sarcastic / over-explanatory`.

Purpose: character-specific cognitive/linguistic stress behavior.

**Promotion:** REQUIRED for major recurring characters.

---

# N13 — DIALOGUE IDENTITY TRIAD

Voice separability should use three high-value axes:
1. `QUESTION STYLE`;
2. `DISAGREEMENT STYLE`;
3. `REPAIR/APOLOGY STYLE`.

These are harder to fake with catchphrases and more connected to personality/status.

**Promotion:** REQUIRED inside speech fingerprints.

---

# N14 — RELATIONSHIP SEMANTIC LEDGER

Combine:
- shorthand age;
- unresolved debt;
- recurrent misread;
- status layers;
- absent-third-party pressure.

Purpose: identical words should mean different things in different relationships because history changes interpretation.

**Promotion:** REQUIRED for central relationships.

---

# N15 — PERMISSION + EXIT GEOMETRY

Track separately:
- formal authority;
- ability to refuse;
- ability to interrupt;
- ability to leave;
- ability to force continuation;
- touch/physical-access rights;
- disclosure rights;
- social/emotional cost of saying no.

Purpose: prevent dialogue from pretending equality before structural equality exists.

BLOODBOUND is the current strongest test case.

**Promotion:** HARD GATE for custody, command, teacher/student, employment, medical, coercive/protective and similar asymmetrical scenes.

---

# N16 — ENSEMBLE ATTENTION TOPOLOGY

For 3+ people, map attention dynamically:
`speaker -> intended target -> actual listeners -> task/object focus -> side-signal observer -> missed information`.

Purpose: eliminate orderly round-robin ensemble dialogue and create believable social texture.

**Promotion:** REQUIRED for major group scenes.

# SYSTEM-LEVEL FINDINGS

## 1. Naturalism ≠ messiness
McKee/Truby support selective, heightened but credible speech. The system must not respond to the current problem by adding filler, stutters or random slang.

## 2. Mystery discipline and natural speech can conflict
IVDIVO is good at epistemic precision. If that precision is expressed every time as polished correction dialogue, the logic PASS can create a naturalism FAIL. Move certainty/clue boundaries into scene state and let behavior carry more of the distinction.

## 3. Smart characters need different intelligence signatures
The problem is not that characters are too intelligent. It is that several can be intelligent through the **same rhetorical mechanism**.

## 4. Relationship fluency is temporal
New relationships cannot have the shorthand of old friendships. `SHORTHAND AGE` is therefore an arc variable.

## 5. Power is linguistic physics
Permission and exit power determine how safe questions, jokes, refusals, intimacy and disclosure can be. Power cannot remain a plot-only field.

## 6. Audio is still a necessary diagnostic layer
The current research can identify text risks but cannot resolve performance-sensitive lines such as `failing investment bank` without a properly directed human/listener comparison.
