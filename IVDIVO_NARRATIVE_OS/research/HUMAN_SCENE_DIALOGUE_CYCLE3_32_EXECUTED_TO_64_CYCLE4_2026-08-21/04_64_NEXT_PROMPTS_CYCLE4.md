# PHASE A — EPISTEMIC MODALITY COMPILER — 01–08

## 01 — GRAMMATICAL CERTAINTY HEATMAP
Mark every declarative claim in a selected scene/block as FACT / STRONG INFERENCE / WEAK INFERENCE / BELIEF / WRONG CONFIDENCE. Compare grammar (`is`, `means`, `proves`, `must`) to evidence level and identify only the unsupported certainty spikes.

## 02 — RHETORICAL CONFIDENCE VS BELIEVED TRUTH
Separate how certain the character **sounds** from how certain they **are**. Test whether bluff, authority performance, shame or social defense explains the gap.

## 03 — CLAIM ANCESTRY TRACE
For each high-stakes claim, trace `original source -> transformations/retellings -> current speaker`. Detect facts that became cleaner or stronger as they moved between people/documents.

## 04 — NARRATOR UNCERTAINTY CAMOUFLAGE
Find close-POV sentences that grammatically present another person's motive/emotion as fact. Generate a version that preserves force while clearly owning interpretation, then compare for unnecessary hedging.

## 05 — CAST CONFIDENCE DIVERGENCE
For one shared piece of evidence, map each principal's confidence and reason. Reject scenes where everyone converges to the same confidence merely because the author knows the answer.

## 06 — EVIDENCE THRESHOLD BY CHARACTER
Define what kind of evidence each character requires before changing a belief: document, behavior, authority, repeated pattern, personal testimony, physical proof. Test whether belief change respects this threshold.

## 07 — RETROACTIVE CERTAINTY REGRESSION
After later reveals are drafted, rescan earlier scenes for lines that became accidentally too knowing during revision. Restore earlier uncertainty without weakening legitimate foreshadowing.

## 08 — MYSTERY FAIR-PLAY KNOWLEDGE COMPILER
Generate a chapter/episode table of `KNOWN / SUSPECTED / UNKNOWN / FALSE` for each principal. Reject any line that uses knowledge from a future boundary unless there is explicit earlier evidence.

# PHASE B — INTERPRETATION DEBT + DISCONFIRMING CUES — 09–16

## 09 — INTERPRETATION DEBT AGING
List all OPEN interpersonal interpretations older than three scenes. Require each to be CONFIRMED / REVISED / WRONG / ABANDONED or deliberately kept open for a named reason.

## 10 — DISCONFIRMING CUE VISIBILITY
For every strong judgment, test whether at least one weakening cue is perceptible to the POV. If none exists, decide whether certainty is earned or the scene is over-controlled.

## 11 — SELECTIVE BLINDNESS CAUSE
When a character ignores a disconfirming cue, identify the cause: desire, fear, status, attraction, fatigue, ideology, shame, prior trauma, task fixation. Reject convenient blindness with no character cause.

## 12 — WRONG INTERPRETATION PAYOFF
Choose one plausible misread and trace how it changes a later decision. If the wrong belief has no behavioral consequence, it is decorative uncertainty rather than drama.

## 13 — RELATIONSHIP MISREAD ASYMMETRY
For a pair, identify what A repeatedly misreads in B and what B misreads in A. Prevent symmetrical therapeutic understanding unless earned by history.

## 14 — OBSERVER DISAGREEMENT TEST
Give the same interaction to two credible observers with different loyalties. Compare interpretations. Use disagreement to test whether the scene permits human ambiguity without becoming unclear.

## 15 — INTERPRETATION CORRECTION COST
When a character realizes they were wrong about someone, require a cost: embarrassment, lost leverage, apology, changed tactic, damaged self-story, practical repair. No free cognitive update.

## 16 — OMNISCIENCE CAMOUFLAGE DETECTOR
Search for phrases like `he knew`, `she realized`, `he wanted`, `she was afraid` in close POV about other characters. Classify canonical knowledge vs POV guess vs narrator authority and repair only leakage.

# PHASE C — ATTENTION, RETRIEVAL, MEMORY — 17–24

## 17 — RETRIEVAL TRIGGER VALIDITY
For every important fact remembered later, state `WHY NOT EARLIER?` and the exact later trigger. Reject plot-timed memory without attention or cue logic.

## 18 — SOURCE/MEMORY SEPARATION
Tag each remembered claim WITNESSED / RETOLD / INHERITED / DOCUMENT-DERIVED / RECONSTRUCTED. Test whether the character speaks with precision appropriate to the source type.

## 19 — DESIRE-DRIVEN ATTENTION TUNNEL
Map what a character notices because they want something badly and what they fail to notice for the same reason. Verify both effects appear in behavior.

## 20 — STATUS-THREAT ATTENTION HIJACK
In scenes with authority pressure, test which neutral cues become threatening and which task facts drop out of active attention. Keep changes character-specific.

## 21 — CONCURRENT TASK OVERLOAD
Give the scene a real task plus relationship pressure plus environmental demand. Audit whether characters still track implausibly many details. Repair attention, not intelligence.

## 22 — MEMORY AFTER RETELLING
For events discussed multiple times, separate original observation from phrases borrowed from later retellings. Flag suspiciously standardized memories across characters.

## 23 — INTERRUPTION CARRYOVER TEST
When retrieval is interrupted, test whether the person resumes, abbreviates, forgets or substitutes. Use the result only if interruption has a causal source and later consequence.

## 24 — BODY-STATE COGNITION MAP
Before reducing precision for fatigue/pain/fear, prove the body state exists. Then specify what degrades first for this person: chronology, patience, inhibition, names, nuance, syntax, humor, or attention.

# PHASE D — LIVE RESPONSE, LATENCY, REPAIR — 25–32

## 25 — RESPONSE ORIGIN CLASSIFIER
For every major line classify origin: LIVE PARTNER / OBJECT-EVENT / INTERNAL PROCESSING / UNRESOLVED PRIOR BUSINESS / OUTLINE-ONLY. OUTLINE-ONLY is a rewrite trigger.

## 26 — SILENT TRIGGER TRACE
Identify replies caused by gaze, object handling, pause length, physical withdrawal or non-response rather than words. Verify the silent cue was actually perceivable.

## 27 — INTERNAL-PROCESSING LEGITIMACY
For a line not triggered by the partner, reconstruct the internal chain that produces it. Reject theme delivery disguised as spontaneous thought.

## 28 — INTIMACY LATENCY SHAPE
Across three relationship stages, compare how quickly attraction, hurt, trust and jealousy move from body response to explicit language. Require evolution rather than one permanent pace.

## 29 — DISPLACED ANSWER DESTINATION
When the real question is too risky, identify the safer target: task, joke, object, third person, technical correction, exit. Confirm displacement protects a real need.

## 30 — APOLOGY TACTIC IDENTITY
Blind-test apologies from major characters. Separate factual correction, responsibility, reassurance, repair action, humor, withdrawal and self-exposure. Flag generic emotionally literate apologies.

## 31 — REPAIR CEILING AFTER MATERIAL BETRAYAL
For betrayal/conflict scenes, define the maximum immediate improvement words alone can create. Require external action/consequence for movement beyond that ceiling.

## 32 — AFTERSHOCK PERSISTENCE
After failed/partial repair, audit the next three interactions for changed interruption, trust, disclosure, humor, proximity or exit behavior. Prevent plot reset.

# PHASE E — CORPUS RHETORICAL FINGERPRINTS — 33–40

## 33 — CONTRASTIVE SYNTAX DENSITY
Count `not X/Y`, `that is not`, `not because/because`, semantic correction ladders and mirrored reframes by speaker+narrator across one block. Flag concentration, not isolated use.

## 34 — NARRATOR VS SPEAKER RHETORIC SPLIT
Build separate rhetorical fingerprints for narrator and each principal. Detect when narrator habits leak into unrelated mouths.

## 35 — SEMANTIC CORRECTION OWNERSHIP
For every semantic correction, identify whether it comes from profession, personality, relationship history, institutional culture or author reflex. Keep only owned repetition.

## 36 — ACKNOWLEDGMENT FUNCTION COLLISION
Track `I know / okay / fine / right / sure / exactly` by phrase, function, register and speaker. Flag repeated phrase+function collisions across major characters.

## 37 — APHORISM / TRAILER COMPRESSION TEST
Identify highly quotable two-part lines. Test whether the live tactic requires that compression or whether the line exists because it sounds like a trailer/epigraph.

## 38 — SENTENCE-PAIR SYMMETRY SCAN
Find paired rhetorical constructions (`A is X. B is Y.` / `Not A. B.`) across narrator and dialogue. Distinguish deliberate motif from uncontrolled house cadence.

## 39 — RHETORICAL CONTAGION THROUGH RELATIONSHIP
Test whether two characters legitimately begin borrowing each other's phrases after sustained intimacy/teamwork. Require a visible relationship history before treating convergence as intentional.

## 40 — DELIBERATE MIRRORING AUTHORIZATION
When identical syntax is intentionally used by two speakers, state the story function: irony, bonding, rivalry, inheritance, ideological capture. Without function, classify as collision candidate.

# PHASE F — REGISTER, VOCABULARY, METAPHOR, VOICE — 41–48

## 41 — REGISTER DISTANCE BLIND TEST
Strip scene labels and compare professional/intimate/defensive speech from one character. Test whether register changes are recognizable while identity remains stable.

## 42 — PROFESSIONAL LEAKAGE INTO INTIMACY
Find institutional/procedural language in intimate scenes. Classify as defense mechanism, genuine habit, joke, status move or unsupported leakage.

## 43 — VOCABULARY ACQUISITION PROOF
For five unusual words per principal, identify plausible acquisition source. If unsupported, compare a context-owned alternative without automatically simplifying intelligence.

## 44 — METAPHOR DOMAIN OWNERSHIP
Map owned metaphor domains per character and narrator. Flag elegant domain jumps without biography/context and repeated domains across unrelated speakers.

## 45 — STRESS REGISTER DEFORMATION
Compare calm vs crisis language for each principal. Verify pressure changes form according to character rather than making everyone short, fragmented or profane.

## 46 — HUMOR REGISTER SHIFT
Audit how humor changes across public/private/stressed/intimate contexts. Detect one universal author joke mode.

## 47 — QUESTION-FAMILY BLIND CLASSIFIER
Blind-remove speaker names from 12 questions. Classify likely speaker from question tactic/form. Record confusion pairs and diagnose shared culture vs weak voice identity.

## 48 — DISAGREEMENT-FAMILY BLIND CLASSIFIER
Repeat with refusals/corrections/disagreement. Separate tactic identity from shared surface syntax.

# PHASE G — CROSS-SCENE / CORPUS VALIDATION — 49–56

## 49 — BLOCK FINGERPRINT DASHBOARD
At each 4–6 chapter/episode gate, summarize correction syntax, acknowledgments, metaphor domains, question families, disagreement families and narrator overlap by speaker.

## 50 — CHAPTER-TRANSITION VOICE DRIFT
Compare the same character immediately before/after chapter boundaries and model switches. Detect silent reset to generic model voice.

## 51 — BEGINNING / MIDDLE / END VOICE STABILITY
Sample recurring speakers at three points. Classify differences as ARC-EARNED / REGISTER-DRIVEN / STRESS-DRIVEN / UNCONTROLLED DRIFT.

## 52 — DIALOGUE/NARRATOR CONTAMINATION
Take the narrator's ten most common rhetorical shapes and search principal dialogue for the same shapes. Require ownership justification for high overlap.

## 53 — LEGITIMATE SHARED-CULTURE CONVERGENCE
For family, military, professional or institutional groups, define which phrases/syntax they should legitimately share. Protect these from false-positive dedupe.

## 54 — MINIMAL CORPUS REPAIR
When collision is proven, change the smallest number of lines needed to restore ownership. Do not globally vary synonyms or destroy motifs.

## 55 — OVER-NATURALIZED NEGATIVE CONTROL
For every repair, create an intentionally banal/filler-heavy version. Confirm the accepted line preserves dramatic compression and intelligence.

## 56 — POST-PATCH CORPUS REGRESSION
After repair, rerun fingerprints. Reject a patch that removes one collision by importing another character's signature or narrator cadence.

## 58 — WORDING VS PERFORMANCE HYPOTHESIS PAIR

## 59 — UNDERPLAY + LISTENING CANARY

## 60 — LOCALIZATION FUNCTION TEST

## 61 — HUMAN DISAGREEMENT MATRIX

## 62 — BLOODBOUND E06–E12 CORPUS GATE

## 63 — SMITH PRE-DRAFT VOICE CALIBRATION
