## Core result
The strongest recurring defect class is now **rhetorical fingerprint collision** rather than isolated wording failure. BLOODBOUND E07, even after prior Naturalism work, still shows repeated contrastive/corrective constructions across narrator and multiple speakers (`not X / Y`, `that is not`, `No...`, semantic correction ladders) plus neutral acknowledgement collision (`I know`). This independently reinforces the earlier LESSON ZERO house-style finding.

New governing principle:

`LINE CAUSALITY -> SCENE HUMAN TRUTH -> CHARACTER REGISTER -> CORPUS RHETORICAL FINGERPRINT -> NARRATOR/SPEAKER SEPARATION -> PERFORMANCE/HUMAN BELIEF`.

**Do not solve corpus convergence by making everyone less intelligent. Solve it by restoring ownership, provenance, reaction causality and register-specific rhetorical habits.**
