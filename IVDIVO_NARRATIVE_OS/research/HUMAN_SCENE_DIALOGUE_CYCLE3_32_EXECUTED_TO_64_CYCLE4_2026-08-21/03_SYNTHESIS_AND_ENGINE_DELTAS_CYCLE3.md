# 03 — SYNTHESIS + ENGINE DELTAS — CYCLE 3

**Derived from:** 32/32 executed prompts in Cycle 3.  
**Status:** SYNTHESIS COMPLETE / PROMOTION REQUIRES BOUNDED INTEGRATION + REGRESSION.

## Core conclusion
The engine already has good scene-level causality and naturalism checks. The new evidence shows a different failure layer:

> **A scene can be psychologically credible and still contribute to book-wide authorial voice convergence.**

This is visible when multiple speakers and the narrator independently use the same semantic correction, contrastive sentence shape, acknowledgement token, metaphor logic or emotionally literate repair syntax.

Therefore the next engine layer must model **rhetorical ownership across a corpus**, not merely line quality inside one scene.

---

# C3M01 — EPISTEMIC MODALITY COMPILER
Every consequential claim receives one of:
`FACT / STRONG_INFERENCE / WEAK_INFERENCE / BELIEF / RHETORICAL_CONFIDENCE / WRONG_CONFIDENCE`.

Purpose: stop grammar from silently outrunning evidence while preserving character-owned certainty and overconfidence.

# C3M02 — POV INTERPRETATION DEBT LEDGER
Every important inference about another person's intent/emotion can remain open.
Statuses:
`OPEN / CONFIRMED / REVISED / WRONG / ABANDONED`.

Purpose: prevent close POV from becoming hidden omniscience.

# C3M03 — DISCONFIRMING CUE BUDGET
High-confidence interpersonal judgments require at least one plausible disconfirming cue unless the scene genuinely supplies certainty.

Purpose: keep ambiguity human and fair without forcing hedging dialogue.

# C3M04 — SOURCE PROVENANCE GRAPH
For each key claim:
`SOURCE -> VERSION -> RECIPIENT -> BIAS/TRUST -> CURRENT CONFIDENCE`.

Source types include person, document, system, inherited narrative, memory and later reconstruction.

Purpose: characters should not magically share a clean canonical information packet.

# C3M05 — DISTRIBUTED CONFIDENCE MAP
The same evidence can produce different confidence levels across characters.

Purpose: avoid a room full of equally cautious analysts or equally certain plot mouthpieces.

# C3M06 — RETRIEVAL TRIGGER CONTRACT
For delayed use of already available knowledge:
`WHY_NOT_NOW + WHAT_TRIGGERED_LATER_RETRIEVAL`.

Purpose: distinguish human attention from plot-delayed memory.

# C3M07 — MEMORY TYPE LABEL
`WITNESSED / REMEMBERED / RETOLD / INHERITED_NARRATIVE / DOCUMENT_DERIVED / RECONSTRUCTED_AFTER_DISCUSSION`.

Purpose: stop inherited stories and reconstructed memories from being treated as firsthand perception.

# C3M08 — COGNITIVE LOAD VOICE DEFORMATION PROFILE
Per character, define likely language changes under stress: brevity, repetition, formality, silence, literalism, sarcasm, question narrowing, loss of nuance, etc.

Purpose: preserve intelligence while making pressure character-specific.

# C3M09 — LIVE TRIGGER COVERAGE
Every major line must attach to:
`LIVE_PARTNER_STIMULUS / OBJECT_OR_EVENT / INTERNAL_PROCESSING / UNRESOLVED_PRIOR_BUSINESS`.

`OUTLINE_ONLY` origin is a fail.

Purpose: dialogue should feel like response, not scheduled delivery.

# C3M10 — EMOTIONAL LATENCY TRAJECTORY
Track emotion through possible stages:
`BODY -> TACTIC -> LEAK -> PRIVATE_RECOGNITION -> EXPLICIT_LANGUAGE`.

Purpose: prevent instant psychologically perfect self-reporting while allowing character-specific fast processors.

# C3M11 — REPAIR CEILING + ACTION REQUIREMENT
A sentence can improve understanding but cannot erase material betrayal/status/history beyond a declared immediate ceiling.

Purpose: stop eloquent apology from functioning as magic relationship reset.

# C3M12 — CONTRASTIVE SYNTAX FINGERPRINT
Corpus scan by speaker and narrator for structures such as:
- `not X, Y`;
- `that is not...`;
- `not because... because...`;
- semantic correction ladders;
- mirrored two-part reframes.

Purpose: detect authorial rhetorical reflex shared by unrelated characters.

This is the **strongest Cycle-3 promotion candidate**.

# C3M13 — ACKNOWLEDGMENT FUNCTION MATRIX
Track neutral tokens (`I know`, `okay`, `fine`, `right`, `sure`) by:
`PHRASE + FUNCTION + REGISTER + SPEAKER`.

Functions include agreement, defense, impatience, shame, face-saving, closure and invitation.

Purpose: raw frequency is not enough; repeated phrase/function combinations create voice collapse.

# C3M14 — REGISTER DISTANCE MATRIX
For each recurring character compare professional / intimate / defensive / public / family / peer registers using qualitative distance `LOW / MEDIUM / HIGH`.

Purpose: verify register switching without forcing maximal difference before a relationship earns it.

# C3M15 — VOCABULARY + METAPHOR PROVENANCE
Unusual language classified:
`BIOGRAPHY_SUPPORTED / SHARED_CULTURE / CONTEXT_GENERATED / AUTHOR_OWNED_CANDIDATE`.

Purpose: preserve unusual smart language when earned, flag elegant lines that seem to belong to the writer rather than the person.

# C3M16 — TACTIC VS SURFACE SEPARABILITY
Blind-test question and disagreement families. Diagnose two independent layers:
1. `TACTIC_IDENTITY` — how the character resists/asks/repairs;
2. `SURFACE_SYNTAX` — how the sentence is shaped.

Purpose: characters can have distinct tactics yet still sound like one author because surface rhetoric converges.

# False-positive warning
A repeated phrase or syntax is **not automatically a defect**. Shared profession, family, region, institution, intimacy or deliberate mirroring may justify convergence.

Required question:
`IS THIS SHARED RHETORIC OWNED BY THE STORY WORLD/RELATIONSHIP, OR IS IT AN UNCONTROLLED MODEL/AUTHOR REFLEX?`

Only the latter is a repair target.
