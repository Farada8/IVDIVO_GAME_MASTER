## Core rule

**Do not make dialogue more ordinary. Make it more causally human.**

Target:
`PERSON -> STATE -> PERCEPTION -> LISTENING -> DESIRE -> RISK -> TACTIC -> REACTION -> WORDS -> PERFORMANCE -> BELIEF`.

Not:
`THEME/EXPOSITION -> CLEVER LINE -> CHARACTER NAME`.
