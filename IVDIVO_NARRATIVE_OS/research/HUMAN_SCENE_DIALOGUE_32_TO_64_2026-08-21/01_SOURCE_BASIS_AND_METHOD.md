## Evidence classes

Every finding in this cycle is tagged conceptually as one of:
- `SOURCE-DERIVED` — supported by a named Library/current-system source.
- `CORPUS-DERIVED` — observed in LESSON ZERO / BLOODBOUND material.
- `INFERENCE` — synthesis across supported findings.
- `DECISION` — proposed IVDIVO process/engine action.

No source becomes IVDIVO story canon. No distinctive external dialogue, scene sequence, character or proprietary construction is imported.

## External craft source findings used

### Robert McKee — Dialogue
Supported mechanisms used in this cycle:
- credible dialogue targets **fictional authenticity**, not literal everyday conversation;
- dialogue concentrates meaning while ordinary talk dilutes it;
- a line rings true when verbal action fits character motivation, inner desire and outer tactic;
- credibility failures include empty talk, overly knowing talk and overly perceptive talk;
- all speech functions as action: it responds to a need, pursues a purpose and produces action/reaction;
- effective dialogue must simultaneously carry action, progressive scene beats, exposition, unique role style, narrative drive and authenticity;
- character-specific voice begins with vocabulary and extends to phrasing, pace and behavior;
- silence can execute scene action economically.

### John Truby — The Anatomy of Story
Supported mechanisms used:
- dialogue must not be forced to do work that belongs to story/scene structure;
- good dialogue is selective language that *sounds* as though it could be real, not a transcript of real talk;
- subtext is useful when character desire/plan and fear/pain/embarrassment justify indirectness;
- hidden desires plus indirect plans can generate subtext;
- scenes should enter as late as possible without losing required structure, rather than simulating mundane chronology.

## Sequential execution method for the 32 prompts

For Prompt N:
1. pose one bounded diagnostic question;
2. inspect source law + IVDIVO current mechanisms + corpus implications;
3. state the finding;
4. identify failure mode;
5. state whether an engine delta is needed;
6. classify the result as `KEEP / STRENGTHEN / ADD / HOLD_FOR_HUMAN_SIGNAL`;
7. carry only supported deltas into synthesis.

Prompts are executed in order so later prompts may use earlier conclusions, but no later conclusion retroactively changes source evidence.

## Guardrails

- Naturalism is not random filler, stutters or slang.
- Wit is not automatically a defect.
- Frequency statistics are signals, not verdicts.
- Audio performance failure is not automatic prose failure.
- Translation/localization failure is not automatic source-text failure.
- Intelligent characters may speak intelligently; the question is whether the exact line is caused by this person in this moment.
- Repair the earliest failed layer and the smallest necessary unit.
