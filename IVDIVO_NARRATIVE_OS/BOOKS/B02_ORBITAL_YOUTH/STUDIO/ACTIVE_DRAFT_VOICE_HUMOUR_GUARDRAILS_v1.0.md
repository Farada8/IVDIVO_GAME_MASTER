## Dialogue red flags
- five clever answers in sequence;
- repeated “What?” reaction beats;
- repeated “I know.” beats;
- symmetrical correction jokes;
- adult/teen voices sharing identical clipped wit;
- character states the theme after action already showed it.

## Paragraph/cadence red flags
Use deliberate staccato sparingly.
Do not overrepeat:
- “Not X. Y.”
- “That was worse.”
- “That mattered.”
- standalone moral-verdict lines.
- repeated look/turn/pause blocking.

## Scene ending rotation
Do not end every chapter on:
- a note Ollie writes;
- a screen update;
- an aphorism;
- a withheld message.

Rotate:
physical action / social interruption / unresolved practical task / image / decision / changed route / absence.
