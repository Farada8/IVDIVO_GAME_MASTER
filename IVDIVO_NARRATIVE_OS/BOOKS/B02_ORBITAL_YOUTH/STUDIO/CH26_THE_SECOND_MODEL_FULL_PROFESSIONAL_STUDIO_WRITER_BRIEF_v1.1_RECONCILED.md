## NEW MODEL — WORKING HYPOTHESIS, NOT CANON PHYSICS

Old model grouped events by visible operational labels:
`partition overlap / service door / return correction / buffer response`.

Second model asks whether different visible sequences can enter the same deeper **shared-loop state relationship**.

The key alignment variable becomes:
**estimated state-entry time**, inferred from allowed control-state relationships, not the first fixed sensor/display alarm and not a particular named door/partition.

Evidence streams remain distinct:
A. control/route state;  
B. fixed environmental response;  
C. resident/personal-support event timing;  
D. movement-order / held-transition timing.

Do NOT merge C into A as cause.
Do NOT call people sensors.

Provisional hypothesis:
> Under a narrow class of shared-loop service/return states, some resident/personal-support events may occur after the system has entered the coupled state but before aggregate fixed sensing/display reports it.

Alternative explanations remain live:
- harmless local variation sensed early;
- interface-specific adaptation;
- module-generation artifact;
- reporting/timestamp bias;
- participation in feedback rather than sensing it;
- unrelated coincidence.
