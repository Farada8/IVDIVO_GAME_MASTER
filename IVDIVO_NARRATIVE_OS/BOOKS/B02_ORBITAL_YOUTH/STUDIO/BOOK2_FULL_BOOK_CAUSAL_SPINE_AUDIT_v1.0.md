# 3. MAJOR WATCH 1 — THREE FALSE-SUCCESS / AUTHORIZATION PEAKS

**Ch12 THE CLEAN MODEL → Ch15 LIMITED OPEN → Ch19 GO / NO-GO** all increase confidence before Ch20 failure.

This is structurally defensible because the levels differ:
- Ch12 = model coherence;
- Ch15 = bounded test/opening evidence;
- Ch19 = institutional go/no-go under live decision conditions.

But in a continuous read, these may feel like:
`model looks good -> more review -> model looks good -> more review -> model looks good -> failure`.

**Severity:** MAJOR WATCH, not confirmed MAJOR.

**Continuous-read test:** if Ch12–19 loses forward pressure, do not delete the false-victory architecture. First identify whether one chapter repeats explanation rather than changing stake.

**Minimum repair if confirmed:** compress repeated evidence explanation across one of Ch15/19, strengthen the human consequence attached to that authorization, or move one already-existing housing/relationship pressure closer to the decision. Avoid inventing a new plot beat.

- avoid repeated full restatement of Ring Six technical state inside those chapters.
