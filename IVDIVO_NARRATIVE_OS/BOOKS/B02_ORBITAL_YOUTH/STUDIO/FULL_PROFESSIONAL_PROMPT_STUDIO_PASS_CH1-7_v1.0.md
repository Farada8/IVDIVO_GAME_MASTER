# 1. SOURCE / MECHANISM PASS

The active draft was checked against already extracted library mechanisms and a fresh targeted cross-source read.

Sources/functions used:

1. **IVDIVO Story Engine v4.1** — controlled revelation; task → rule → consequence → model update → harder decision.
2. **IVDIVO Orbital Reference Deep Pass** — station as coupled city/system; gravity as culture; infrastructure as social geography; scarcity survives abundance.
3. **David Gerrold / orbital-settlement material** — jobs, civic life, recreation, economy, local identity.
4. **Andy Weir, Project Hail Mary** — discovery through action; physical constraints; gravity felt through work; reliable systems before spectacle.
5. **Ursula K. Le Guin / frontier-worldmaking mechanisms** — the visitor enters somebody else’s home; locals are not guides.
6. **Pierce Brown, Red Rising — negative model** — status and labor should be embodied, but no caste/color imitation and no human-worth-equals-utility ideology.
7. **Jessica Brody / YA craft** — teenage identity, independence, friendship/status pressure, tight page-level propulsion.
8. **John Truby** — scene weave by structural function rather than chronological padding.
9. **Linda Seger** — every scene is action and change; use contrast between adjacent scenes.
10. **Jordan Rosenfeld / Make a Scene** — scene intention, tension, subtext, launch/turn/exit, pacing contrast.
11. **Sandra Scofield / The Scene Book** — utility/economy test; no repeated scene behavior.
12. **Robert McKee / Dialogue** — dialogue as action/character/exposition; exposition only when wanted/needed.
13. **James Scott Bell / novel craft** — pacing variation, rapid dialogue/action, chapter propulsion.

### Cross-source synthesis

The strongest common mechanism for Book 2 remains:

**ordinary youth objective → orbital constraint → social/physical consequence → character choice → new evidence or relationship change.**

This is stronger than:
**technology explanation → clever observation → plot clue.**

- averaging/placement/feedback lag as possible contributors;
- no magical “body knows truth” mechanism;
- no instant causal certainty.

### Ch8 sport design constraint
The sport must exploit rotational geometry rather than merely call itself “zero-g.”

Preferred:
- movement across radial bands;
- different effective gravity at different radius;
- momentum management;
- handoff timing;
- safe lanes and grip surfaces.

Synthetic-bodied participant:
- ordinary body/equipment class rule;
- no embodiment lecture;
- no implication that synthetic bodies are unfair by default.
