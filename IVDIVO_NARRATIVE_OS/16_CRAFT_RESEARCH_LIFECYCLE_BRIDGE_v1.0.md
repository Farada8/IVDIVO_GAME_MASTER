# IVDIVO NARRATIVE OS — CRAFT RESEARCH LIFECYCLE BRIDGE

**Status:** CANDIDATE UNIVERSAL BRIDGE / pending merge to main  
**Version:** 1.0  
**Date:** 2026-08-21  
**Scope:** converting verified craft/reference research into reusable Narrative OS mechanisms without turning reference books into canon.

## 1. PURPOSE

The reference library is an evidence source, not a second canon and not a reason to rerun development indefinitely.

This bridge connects the strict research lifecycle to live writing/revision only when a verified reusable mechanism can materially improve a current decision.

Primary law:

`REFERENCE EVIDENCE -> VERIFIED MECHANISM -> ABSTRACT PROJECT-NEUTRAL LAW -> RUNTIME DIAGNOSTIC -> PROJECT-SPECIFIC APPLICATION`

Never:

`REFERENCE BOOK -> COPY ITS PLOT/VOICE/SCENE SEQUENCE -> IVDIVO`.

## 2. STRICT SOURCE LIFECYCLE

A source may be treated as strict-complete only after:

`REGISTERED -> INTEGRITY VERIFIED -> FULL READ -> STRUCTURE MAP -> SOURCE PASSPORT -> CLAIM EXTRACTION -> MECHANISM EXTRACTION -> FAILURE MODES -> CROSS-SOURCE COMPARISON -> IVDIVO OPERATIONALIZATION -> MANUSCRIPT VALIDATION -> SYNTHESIZED`.

TOC snippets, search results, partial scans, excerpts, summaries and defective copies do not equal a full read.

Duplicate copies/translations/formats of one work do not gain extra evidentiary weight merely by duplication.

## 4. PROMOTED ACTION / ADAPTATION LAW

For character action and scene truth, use:

`GIVEN CIRCUMSTANCES -> PRESENT WANT -> PARTNER/WORLD RESPONSE -> TACTIC -> ADAPTATION -> CHANGED STATE`.

A character is active when they pursue, refuse, delay, cooperate, test, restrain, bargain, withdraw, protect, expose, endure or succeed in a way that changes the state.

**AGENCY != AGGRESSION.**

Do not force every protagonist into loud confrontation merely to prove activity.

## 5. BEAT / TEMPO / TYPOGRAPHY FIREWALL

Keep these variables distinct:

`INNER PROCESS SPEED != OUTER MOTION SPEED != SENTENCE LENGTH`.

`BEAT MAP != TYPOGRAPHY`.

`ACTION / SUSPENSE / EMOTION != SHORT-SENTENCE DENSITY`.

A tense or emotional scene may require long syntax, ordinary physical action, sustained silence or slow external movement. Do not manufacture intensity by chopping prose into uniform fragments.

## 6. PRIVATE CHARACTER LAB FIREWALL

`PRIVATE REHEARSAL / CHARACTER LAB != PAGE OBLIGATION`.

Writers/actors/models may use private biography, sensory imagination, objectives, substitutions or rehearsal exercises to find truthful action. The manuscript is not required to explain that private process.

Do not convert character-lab material into exposition merely because the development system generated it.

## 7. TOOL ANTI-OVERFIT LAW

`TOOLS HELP ASK / ORGANIZE / DIAGNOSE; STORY DOES NOT EXIST TO VALIDATE TOOLS`.

A rubric score, mechanism count, beat count, temperature chart or prompt compliance result does not prove that the story works.

Use tools to locate risks and test consequences. The accepted story must still win on causality, character truth, emotion, reader/listener engagement and completed resolution.

Standing rewrite rule:

`NO NEW EVIDENCE -> NO NEW GLOBAL REWRITE`.

## 8. EVIDENCE / KNOWLEDGE LAW

For factual, mystery, investigative or world claims track:

`WORLD FACT -> TRACE/SOURCE -> SOURCE LINEAGE -> ACCESS -> INTERPRETATION -> ALTERNATIVE MODEL -> CORROBORATION STATUS -> ACTION`.

Do not confuse a clue with its interpretation. Do not let a character act on information they cannot access. Do not let a preferred theory become proof because the outline needs it.

## 9. STORY / DISCOURSE CONTROL

For reveal architecture and POV:

`STORY FACT -> ORDER -> DURATION -> FREQUENCY -> DISTANCE/FOCALIZATION -> VOICE/SOURCE LEVEL -> READER MODEL -> ACTION/INFERENCE`.

Chronological truth and presentation order are different design problems. Fair withholding preserves character/POV truth while controlling when the reader can infer the larger pattern.

## 10. ANTI-CHOPPINESS / COHERENCE ROUTE

When prose feels mechanical, thin or over-cut, diagnose in this order:

`BOOK ENGINE -> CAUSAL FENCE -> CHAPTER FUNCTION -> SCENE ADMISSION -> ORDER/DURATION/FREQUENCY -> SCENE WEIGHT/MODE -> POV/EVIDENCE -> EXPOSITION/DIALOGUE MODE -> PARAGRAPH TOPIC CHAIN -> OLD->NEW / READER-STATE CONTINUITY -> INNER/OUTER TEMPO -> SENTENCE RHYTHM/CONTRAST -> WORDING`.

Do not repair a broken scene by varying sentence length before the scene has a real function/turn.

## 11. CRAFT METAPHOR / ONTOLOGY FIREWALL

Acting/writing concepts such as energy centres, telepathy, right-brain/left-brain shorthand, mystical inspiration or analogous craft language remain historical/craft metaphors unless independently verified.

They do **not** enter IVDIVO science, cosmology or ontology merely because a craft source uses them.

## 12. RUNTIME INVOCATION

Load this bridge when:
- a development/rewrite problem needs craft evidence not already represented by current runtime controls;
- a newly strict-complete source creates a materially stronger reusable diagnostic;
- character action is being mistaken for aggression;
- prose is being over-shortened to simulate intensity;
- POV/reveal/evidence access is failing;
- a new craft mechanism is being considered for promotion.

Do **not** load/reprocess the full research library on every scene or chapter.

Delta-first rule:
1. reuse the current abstraction/mechanism stack;
2. inspect the newest strict research ledger;
3. deep-read only the source/mechanism relevant to the live defect;
4. promote only after comparison and project-neutral abstraction.

## 13. LOCK PROTECTION

A newly synthesized craft source does not reopen a locked book/project automatically.

Apply new mechanisms to:
- new work;
- currently open stages;
- explicit FATAL/MAJOR repair;
- future projects;
- downstream QA where the locked source remains protected.

Locked text reopens only under the governing lock/repair authority.
