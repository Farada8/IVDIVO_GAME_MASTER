## 2. Vela / Orbital city must be a possibility system

For every emphasized orbital rule ask:
`RULE / CONDITION → WHAT ACTION IT ENABLES → WHAT IT PREVENTS → WHO EXPERIENCES IT DIFFERENTLY → CHOICE → CONSEQUENCE`.

Examples of legitimate story-world material:
- a transit geometry that changes who can arrive together;
- a gravity/environment rule that changes movement or responsibility;
- a human/robot social norm that changes consent or authority;
- a habitat layout that gives one person privacy and another exposure;
- a local safety convention that a visitor misunderstands;
- a non-fungible location/time window that creates real competition without money.

Red flag:
`new ring → new technology → explanation → no changed behavior`.

That is orbital tourism, not causal worldbuilding.

## 4. Post-money genre-convention update

McKee's useful point: genres evolve when social assumptions change.

Therefore future YA conventions must be rebuilt around current orbital canon.

Forbidden regressions:
- first paid job as universal adulthood milestone;
- rent/credits/purchasing power as default independence engine;
- material consumer status as primary peer hierarchy;
- `service economy` interpreted as wage economy;
- ordinary manufactured objects treated as scarce because of price.

Use instead:
- responsibility;
- trust;
- qualification/mastery;
- unique mission/role;
- non-fungible time/place;
- belonging;
- relationship;
- consent;
- reputation;
- access granted by a living person/institution for reasons other than payment;
- obligation/contribution chosen or assigned under civic/social rules.

Do not turn these into disguised points or currency.

## 5. Character choice without catastrophe inflation

McKee is strongest when consequential choice reveals the person's operative model.

Book Two gate:
`PRESSURE → AT LEAST TWO MEANINGFUL OPTIONS → CHARACTER-SPECIFIC CHOICE → COST / CONSEQUENCE → NEW READER MODEL`.

But do not require:
- death;
- betrayal;
- secret trauma;
- maximum danger;
- total inner reversal.

A young person can be revealed strongly by:
- refusing authority they wanted;
- admitting uncertainty publicly;
- choosing another person's consent over a useful shortcut;
- accepting responsibility for a successful decision that later has costs;
- allowing someone else to lead;
- keeping a promise when no material reward exists;
- giving up a unique opportunity rather than violating another person's boundary.

## 6. Ensemble reaction matrix

McKee's cast-polarization insight is useful only if reactions remain grounded in independent personhood.

For any major shared event, test:
`WHAT HAPPENED → WHAT EACH PERSON NOTICES FIRST → WHAT THEY THINK IT MEANS → WHAT THEY WANT NOW → WHAT THEY DO`.

Do not manufacture five opinions simply to distribute dialogue.

Distinct response must grow from:
- history;
- relationship;
- skill;
- value priority;
- current want;
- social position;
- body/environmental experience.

If Ethan, Maya, Ollie, Aoife, Samir, Iri or another major person could swap reactions without changing the scene, characterization is too generic.

## 7. Conscious robot personhood strengthened

McKee explicitly allows any free-willed desiring agent to function as protagonist. For IVDIVO this reinforces—not creates—the existing robot-personhood rule.

Named conscious robot test:
`OWN WANT → OWN MODEL → CHOICE → RIGHT TO REFUSE → CONSEQUENCE → RELATIONSHIPS OUTSIDE HUMAN UTILITY`.

A robot may be:
- correct against the youth;
- emotionally opaque without being emotionless;
- culturally different without being a machine stereotype;
- committed to an institution for independent reasons;
- unwilling to perform a useful task.

If replacing the robot with an advanced terminal leaves the story intact, personhood has not been dramatized.

## 8. Gap mechanism — use selectively

Useful McKee unit:
`EXPECTATION → ACTION → ACTUAL RESPONSE → GAP → MODEL UPDATE → NEW STRATEGY`.

Use when the gap reveals something real about:
- a person;
- a relationship;
- a system;
- a world rule;
- evidence.

Do **not** force a gap into every scene.

Protected non-gap functions:
- competence succeeds;
- a friend keeps a promise;
- a safety system genuinely works;
- a prediction is correct;
- intimacy is reciprocated;
- training produces mastery;
- a repair works locally before a later coupled problem appears.

These scenes can create trust/dependency/responsibility that makes later conflict stronger.

## 9. Theme / countermodel gate

Book Two should not `win` an ethical argument by making adults, institutions, local residents, or robots stupid.

For every major opposing model require:
`REAL BENEFIT → EVIDENCE → WHO DEPENDS ON IT → HARM OF REMOVING IT → BLIND SPOT / LIMIT`.

The youth proposal also needs:
`BENEFIT → EVIDENCE → COST → FAILURE POSSIBILITY`.

Theme test:
If the ethical meaning disappears when explanatory speeches are removed, rebuild the events/consequences.

---

## 10. Inciting incident: function before spectacle

Do not retrofit Book Two to McKee's screenwriting percentage.

The opening engine passes if the early disturbance:
1. matters to the young person's current life;
2. changes the relevant equilibrium;
3. creates a durable pursuit/problem/responsibility;
4. changes what the protagonist/team must now do;
5. gives the reader enough context to understand why it matters.

A small granting of responsibility, invitation, mistake, disagreement, access change, or failed assumption can perform this function better than an accident.

`PHYSICAL SIZE ≠ STRUCTURAL IMPORTANCE`.

## 11. Selective authenticity gate

For every technical/social explanatory paragraph ask:
- which exact detail makes this situation credible?
- which exact detail changes action?
- which detail is merely proof that the author researched the world?

Keep telling details; compress reference-display.

Orbital credibility should come from coherent consequences, not encyclopedia density.
