## 1. Verdict

**REPAIR / DO NOT REBUILD remains the correct decision.**

Do not retrofit Book Two to Truby's seven or 22 steps. The final full-book read adds narrower, high-value diagnostics:
- separate action state from information state;
- require revelations to change decisions;
- use scene weave to detect episodic orbital tourism;
- make technology alter capability/dependency/choice;
- use motifs only when their meaning develops;
- preserve local closure before saga hook.

## 2. ONE MAIN STORY stays one causal engine

Current target shape remains:
`ARRIVAL / LIMITED RESPONSIBILITY → EARLY COMPETENCE / TRUST → INTERDEPENDENT PROBLEM → INCOMPLETE MODEL → HUMAN COST → BROADER DIAGNOSIS → SEGMENTED ACCOUNTABLE RESPONSE → RESULT / AFTERMATH`.

Multiple youth POVs and independent lives remain valid only if consequences feed this engine.

## 3. Action state + information state

Every major Book Two chapter should be auditable on two axes:

### Action state
What physically/socially changed?

### Information state
What does each relevant person now know, infer, doubt or have evidence for?

A chapter fails if it only adds facts for the reader while nobody's operational model changes.

## 4. Reveal ladder for Book Two

Use:
`OBSERVATION → SOURCE → INTERPRETATION → COUNTERMODEL → TEST → STATUS CHANGE → ACTION`.

Do **not** use:
`mysterious thing → bigger mysterious thing → even bigger mysterious thing`.

Revelations need logical order and causal consequence, not mandatory increase in spectacle or frequency.

## 5. Technical discovery gate

For any engineering/system discovery:
1. What was observed?
2. Which sensor/person/source produced it?
3. Is it raw data or interpretation?
4. What other explanation remains alive?
5. What test distinguishes them?
6. What changes in the plan after the result?

If step 6 is empty, the discovery is probably exposition.

## 6. Vela scene-weave gate

Before drafting/rewriting a cluster of scenes, list:
`OWNER | PRIOR CONSEQUENCE | INTENTION | WORLD RULE | PRESSURE | INFO CHANGE | RELATIONSHIP CHANGE | OUTCOME | NEXT LINK`.

Red flag:
- three scenes differ only by ring/location;
- each scene introduces another technology but the characters behave the same;
- every chapter ends with a new warning rather than changed action;
- five POVs merely rotate airtime.

If so: merge/compress/rebuild **before** line editing.

## 7. Passageways and transit

Orbital transitions deserve full scene treatment when crossing changes:
- gravity or movement rules;
- compatible environment;
- human/robot social norm;
- access/authority;
- privacy expectations;
- sensory assumptions;
- safety behavior.

After the reader understands the rule, routine travel should normally compress.

This preserves the value of early `arrival without a floor` / transit-learning material without turning the book into repeated transport tutorials.

## 8. Technology as relationship

For every featured technology ask:
`WHAT IT AMPLIFIES → WHO MAY USE IT → WHAT DEPENDENCY IT CREATES → WHO CAN REFUSE → WHAT IT CHANGES IN CHOICE/RELATIONSHIP → CONSEQUENCE`.

No page space merely because a technology is advanced.

Post-money firewall remains active:
- ordinary manufactured goods are not narratively scarce because of price;
- no wages/rent/credits by stealth;
- meaningful scarcity may come from time, attention, unique access, compatible space, mission slots, trust, non-fungible location or living persons' choices.

## 9. Conscious robot gate

A robot person cannot occupy a Truby `ally/opponent/mentor` slot without independent life.

Require:
- own want;
- own relationships;
- right to refuse;
- own reasons for accepting risk/cooperation;
- consequences if replaced by equipment.

A robot disagreement should be capable of remaining reasonable after the human protagonist disagrees.

## 10. Symbol / motif gate

Do not engineer a visible `symbol web` just because Truby recommends one.

Accept a recurring object/image/phrase only if:
`FIRST MEANING → NEW CONTEXT → MEANING SHIFTS → PAYOFF`.

For Orbital Youth, likely motifs should emerge from lived objects/processes already in story rather than imported poetic furniture.

## 11. Dialogue gate

Use direct dialogue where exact wording changes:
- authority;
- trust;
- consent;
- relationship;
- evidence status;
- plan;
- public interpretation.

Routine technical procedure and repeated explanation should move to summary/indirect mode.

Do not turn values into panel discussions. If the ethical question only exists because characters state it, rebuild the action/consequences.

## 12. Opposing model gate

Preserve competent resistance.

For every major person/system arguing against the protagonists' preferred response:
- what real benefit are they protecting?
- what evidence supports them?
- what harm could the youth proposal cause?
- what blind spot remains in the opposing model?

No adult/robot/institution should become stupid so the Cohort can win.

## 13. Ending gate

Book Two must not use a late revelation as substitute for closure.

Required order:
`MAIN LOCAL PROBLEM → BOUNDED CHOICE/ACTION → RESULT → COST/AFTERMATH → NEW RELATIONSHIP/WORLD STATE → OPTIONAL SAGA HOOK`.

The world may remain complex and future desire may continue. The **book's local problem still closes**.

## 14. Never-ending story correction for saga production

Reread value should come from:
- earlier details gaining later meaning;
- characters becoming reinterpretable;
- consequences of good choices proving more complex;
- relationships changing the meaning of earlier exchanges;
- a saga hook that expands rather than cancels closure.

Do not confuse `life continues` with `book refuses to finish`.

## 15. Specialist consciousness-school gate

Truby's fantasy passageways/symbolic mentor logic is **not** evidence that dimensional knowledge is common or mature in orbital civilization.

Keep:
`LINEAGE / METHOD → YEARS OF PRACTICE → OBSERVATION → REPRODUCIBILITY LIMIT → INTERPRETATION → SCHOOL DISAGREEMENT`.

The scarcity here is trained practitioners and longitudinal practice, not lack of computers or manufacturing capacity.

## 16. Prose / line-edit consequence

Truby reinforces structural priority only.

If a chapter feels flat/rubbery:
1. check causal function;
2. check reveal ownership;
3. check POV/information state;
4. check scene weave;
5. only then cadence, syntax, paragraphing and line polish.

Do not manufacture suspense with chopped sentences.

## 17. Current production decision

No current scene is automatically added, deleted or reordered solely because Truby says so.

Before the next large prose block, run the relevant chapter cluster through:
- ONE CAUSAL ENGINE;
- ACTION + INFORMATION STATE;
- REVEAL CHANGES ACTION;
- WORLD CHANGES OPTIONS;
- SCENE-WEAVE DIFFERENTIATION;

If these pass, **stop theory retrofit and write the story**.
