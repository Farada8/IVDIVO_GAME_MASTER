This addendum promotes only mechanisms supported by the 64-prompt executed research pass. It does not reopen locked story canon or authorize global rewrites.

## 1. PERCEPTION / MISSED-SIGNAL CONTRACT

For major dialogue beats add:
- `PERCEIVED_SIGNAL`: exact words, tone, gesture, silence, status move or environment event registered;
- `MISSED_SIGNAL`: relevant information not noticed/processed;
- `INTERPRETATION`: what the character thinks it means;
- `RESPONSE_IMPULSE`: defend / clarify / attack / repair / withdraw / joke / test / comply / delay.

A response that answers authorial meaning rather than a plausible perceived signal is `AUTHOR_RESPONSE` and requires review.

## 2. EMOTIONAL LATENCY CONTRACT

Do not assume insight is immediate.

Allowed/expected chain where character/state supports it:
`EVENT -> BODY/AFFECT -> DEFENSE/ACTION -> LATER INTERPRETATION -> LATER LANGUAGE`.

High-stress characters may temporarily become more concrete, repetitive, terse, rigid or task-focused. Polished psychological synthesis under stress requires explicit character support.

## 3. MULTI-REGISTER SPEECH FINGERPRINT

One global speech fingerprint is insufficient for complex principals.

Where relevant define:
- `PUBLIC`;
- `PROFESSIONAL_AUTHORITY`;
- `FRIEND`;
- `INTIMATE`;
- `CRISIS`.

For each register track vocabulary, sentence length, directness, certainty, humor, metaphor domain, correction style, emotional vocabulary, silence and stress deformation.

Pass requires continuity within a register and believable transitions between registers.

## 4. RELATIONSHIP SHORTHAND / MISREAD MAP

For recurring relationships store:
- earned abbreviations and unfinished-reference patterns;
- already-argued topics that should not be re-explained;
- unique wound triggers;
- safe/unsafe joke domains;
- believable apology/repair forms;
- stable misreads;
- who can end/leave the conversation;
- what kindness or concern may be distrusted.

Relationship history must alter how language is generated and interpreted.

## 5. GROUP ATTENTION GRAPH

For ensemble scenes create:
`SPEAKER -> INTENDED TARGET -> ACTUAL LISTENERS -> OVERHEARERS -> IGNORED/EXCLUDED -> ATTENTION SHIFT`.

Do not default to round-robin dialogue. Interruptions, overlaps, silence and topic capture must follow attention/status/urgency.

## 6. SPEECH PATTERN MATRIX

Book/chapter naturalism audits must not use raw frequency alone.

Measure suspect rhetorical patterns by:
`PATTERN x SPEAKER x RELATIONSHIP x REGISTER x CHAPTER/SCENE`.

Classify each high-frequency pattern:
- CHARACTER SIGNATURE;
- RELATIONSHIP SIGNATURE;
- NECESSARY REGISTER;
- AUTHOR HOUSE STYLE;
- GENERATED REPETITION.

Only the last two create automatic repair candidates. Statistical detection never authorizes rewriting without contextual review.

## 7. COMPETENCE / PERSONHOOD SPLIT

Professionally competent characters may speak accurately without becoming documentation interfaces.

For technical/institutional dialogue test:
- why this detail is needed now;
- how much the listener needs;
- speaker patience/tolerance;
- status intention;
- uncertainty threshold;
- emotional cost/defense;
- whether a human consequence can carry part of the explanation.

Institutional language may be formal. That syntax must not leak automatically into private speech.

## 8. TEXT / PERFORMANCE / LOCALIZATION TRIAGE

Every reported credibility break is classified before repair:
- `WRITING_DEFECT`;
- `PERFORMANCE_DEFECT`;
- `ADAPTATION_DEFECT`;
- `TRANSLATION_LOCALIZATION_DEFECT`;
- `CONTEXT_REQUIRED`;
- `NO_DEFECT`.

For audio complaints, exact text remains protected through first properly directed diagnostic render unless a text-only FATAL/MAJOR is already independently established.

## 9. APPLICATION LAW — LESSON ZERO

No bulk rewrite.

Required sequence:
`REPRESENTATIVE SAMPLE -> EXACT TEXT PREMIUM PERFORMANCE -> FOUNDER/HUMAN MARKERS -> TEXT/PERFORMANCE/LOCALIZATION TRIAGE -> SPEECH PATTERN MATRIX -> MINIMAL A/B PATCHES -> REGRESSION`.

Sample target: 45–60 minutes including ensemble, Ethan/Aoife, institutional Lesson Zero, friendship conflict, later high-stakes scene.

The `failing investment bank` exchange remains a diagnostic case, not a pre-decided defect.

## 10. APPLICATION LAW — BLOODBOUND

Before scaling E04+:
- core cast multi-register fingerprints;
- power/consent relationship maps;
- world-rule exposition-as-action audit;
- attention graphs for political/court/ensemble scenes;
- Human Scene/Naturalism Gate on E04–E06.

No generic seductive banter or policy-language romance.

## 11. APPLICATION LAW — SMITH BOOK 3

Before substantial prose drafting:
- multi-register speech fingerprints for Smith and principals;
- institutional/private register separation;
- relationship shorthand/misread maps;
- perception/listening state on major dialogue beats;
- Attention Graph for ensemble/institutional scenes;
- full Naturalism Gate for first major interactions, institutional confrontation, intimate conflict, midpoint relationship turn, climax and final emotional resolution.

Any `documentation-shaped dialogue` leakage in major human scenes is MAJOR until justified by character/tactic.

## 12. LEARNING LOOP

Human/audio failure evidence must feed:
`OBSERVED BREAK -> CLASSIFY LAYER -> CLUSTER -> ROOT CAUSE -> CANDIDATE MECHANISM -> A/B PILOT -> REGRESSION -> PROMOTE/HOLD/REJECT`.

No improvement is promoted merely because multiple models agree.

**PERCEIVE FIRST. FEEL BEFORE EXPLAINING. RELATIONSHIP HISTORY CHANGES LANGUAGE. EXPERTISE DOES NOT ERASE PERSONHOOD.**
