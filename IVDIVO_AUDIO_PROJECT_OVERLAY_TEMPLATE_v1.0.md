# 15. BLIND LISTENER GATE

Without script or notes, target listeners should be able to reconstruct the project-specific essentials.

Required questions:
1. Who is the protagonist / focal character?
2. What do they want now?
3. Why does this episode/chapter matter?
4. What causal action happened?
5. What clue/change matters?
6. What is the current relationship state if relevant?
7. What changed by the end?
8. What exact next question/action do they want?

# 20. CONTINUATION COMMAND

When Founder says `и / дальше / продолжай / делай / работай`:

- restore this project's current authority and overlay;
- identify last completed artifact;
- execute the highest unblocked production obligation;
- do not restart ideation or reopen locked story without evidence;
- save/version the resulting artifact;
- report `DONE / STATUS / EXACT NEXT ACTION`.

**STORY FIRST. CHARACTER SECOND. COMPREHENSION THIRD. SOUND SERVES STORY. NO SILENT CANON CHANGES.**
