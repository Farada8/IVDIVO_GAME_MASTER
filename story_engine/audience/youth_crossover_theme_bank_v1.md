## Selection rule
A theme enters story development only if it passes all four gates:
1. A concrete young-person problem exists before cosmology.
2. The IVDIVO rule changes a decision, relationship, access, duty or cost.
3. The theme can generate at least 6–10 meaningful state changes, not just discussion.
4. It can be expressed without copying the surface of any reference franchise.
