## Red Rising — mechanisms to retain
1. Hierarchy is embodied before it is theorized: labor, scarcity, law, family, visible caste signs and physical access.
2. Protagonist begins as a high-competence member of a low-status group.
3. Personal loss and sensory proof that the official social story is false destroy the original life objective.
4. Infiltration requires becoming legible to the higher-status world, not merely entering a building.
5. Status progression changes body, language, access, peer group, risk and moral interpretation.
6. Opponent category becomes more complex after direct contact; members of the elite are not interchangeable.
7. Advancement creates a danger of identity drift: winning inside the hierarchy can make the infiltrator functionally resemble it.

Abstract engine: EMBODIED LOW STATUS → PERSONAL LOSS → OFFICIAL STORY COLLAPSES → IDENTITY RECONSTRUCTION → ENTRY INTO HIGHER STATUS → COMPETE FROM INSIDE → ENEMY CATEGORY COMPLEXIFIES → PURPOSE IS TESTED BY SUCCESS.

## Ninth House — mechanisms to retain
1. Outsider is recruited because the institution needs a capability it does not itself possess reliably.
2. Operational value does not automatically grant social authority or belonging.
3. Different elite houses/functions create distinct domains, rules, incentives and accountability gaps.
4. Oversight is real but imperfect; the oversight body can itself normalize harm or depend on the structures it monitors.
5. Lore is delivered when a ritual, archive, building, record or case requires interpretation.
6. Knowledge loop: perceive anomaly → research institution/history → compare official account → test rule → expose exception/abuse.
7. Local cases can close while a larger mentor/oversight/mythology arc remains open.
8. Marginality can become an epistemic advantage: outsider notices what insiders have normalized.

Abstract engine: OUTSIDER CAPABILITY → CONDITIONAL ACCESS → SPECIALIZED OFFICE/DOMAIN → CASE/ANOMALY → ARCHIVE/PROCEDURE → INSTITUTIONAL CONTRADICTION → ACCOUNTABILITY CHOICE → LOCAL CLOSURE + LARGER OVERSIGHT QUESTION.

## Dungeon Crawler Carl — mechanisms to retain
1. Give the audience a finite local objective before expanding the world.
2. Use visible state changes and micro-payoffs frequently.
3. Build modular arenas/problems that can each resolve while the global condition persists.
4. Each transition should alter constraints, resources, relationships or available strategies.
5. Progression is retention only when it changes future choices; decorative accumulation is weak.
6. Moral/value choices should impose measurable cost, not merely dialogue.
7. Transition hooks should arise from the consequence of the completed module.

Abstract engine: CLEAR LOCAL OBJECTIVE → CONSTRAINTS → ATTEMPT → PAYOFF/LOSS → STATE CHANGE → NEW RESOURCE/RELATIONSHIP → HARDER MODULE → TRANSITION CAUSED BY PRIOR RESULT.

## Shortlist — 7 youth/crossover serial machines for next testing

### YE1 Classification Error
A young person receives an official low/ordinary classification, but repeated practical cases show capabilities or access effects inconsistent with that label. Each episode produces new evidence and raises the institutional cost of admitting error.
Engine: TEST → ANOMALOUS RESULT → AUDIT → TEMPORARY EXPLANATION → HARDER TEST → STATUS CONSEQUENCE.
Best source support: Fourth Wing progression, Red Rising embodied hierarchy, Ninth House outsider competence.

### YE2 Ability Without Mandate
The protagonist can solve a concrete problem but lacks jurisdiction/right. Obedience and intervention each have costs; the episode turns on finding who actually holds authority and why.
Engine: HUMAN DANGER → CAPABILITY → PROHIBITION → PROCEDURAL SEARCH → CHOICE → CONSEQUENCE → REVIEW.
Best source support: Night Watch jurisdiction, Ninth House oversight, DCC finite-objective cadence.

### YE3 The Missing Record
Everyone is legible to the system except one person. Different offices interpret the absence differently, producing competition over protection, recruitment, classification or exclusion.
Engine: DETECTION FAILURE → MULTIPLE INTERPRETATIONS → FIELD TEST → NEW CONTRADICTION → ACCESS CONFLICT → RECLASSIFICATION.
Best source support: Project Hail Mary anomaly-first logic, Ninth House institution, Red Rising legibility/status.

### YE4 Initiation Review
A real violation causes loss/restriction of initiation or rights. Evidence later shows the conditions were engineered, forcing a review of responsibility without erasing the protagonist's real choice.
Engine: VIOLATION → PENALTY → HUMAN COST → NEW EVIDENCE → PROCEDURAL RECONSTRUCTION → RESPONSIBILITY SPLIT → RESTORATION/REFUSAL/NEW LIMIT.
Best source support: IVDIVO canon/applied model + Recursion causality + le Carré procedure + Ninth House oversight.

### YE5 Two Legitimate Authorities
Two higher offices issue incompatible orders; both are authentic and jurisdictionally grounded. The protagonist must identify which coordinate governs the specific case rather than discover a fake order.
Engine: TASK → SECOND VALID ORDER → DEADLINE → JURISDICTION TEST → RELATIONSHIP SPLIT → ACTION → INSTITUTIONAL AFTERMATH.
Best source support: Night Watch, le Carré, Ninth House, DCC clear local objective.

### YE6 Conditional Belonging
An outsider is admitted because their capability is useful, but access remains conditional and socially contested. Each case makes the institution more dependent on someone it still refuses to treat as fully legitimate.
Engine: RECRUITMENT → USEFUL SUCCESS → SOCIAL REJECTION → HIGHER-STAKES CASE → DEPENDENCE → BARGAIN/BOUNDARY CHANGE.
Best source support: Ninth House + Red Rising + Fourth Wing.

### YE7 Status Infiltration
A young protagonist enters a higher-status environment for a defined purpose and must become behaviorally legible to it. Success creates new friendships, loyalties and temptations that complicate the original mission.
Engine: LOW-STATUS LIFE → PROOF OF FALSE/INCOMPLETE SYSTEM STORY → RECONSTRUCTION → ENTRY → COMPETITION → RELATIONSHIP COMPLEXITY → PURPOSE TEST.
Best source support: Red Rising. Use sparingly because the surface trope is common; require a distinctly IVDIVO status/jurisdiction problem.

## Retention specification for all 7 candidates
- First 5–10 minutes: human problem and one concrete abnormality/threat.
- By ~20%: stable repeatable engine is visible.
- Every 8–15 audio minutes: at least one state delta — task, evidence, status, relationship, access, cost or reclassification.
- Each episode/module: finite objective with a real outcome.
- Every lore term must alter a current decision, permission or interpretation.
- Progression must change choices/obligations, not simply increase power.
- Institutional opposition must have an incentive/procedure, not generic hostility.
- Local closure plus caused larger opening.

## Current conclusion
The strongest youth/crossover IVDIVO territory is not a single academy or tournament model. It is a hybrid of: human attachment + visible status/access + real institutional work + anomaly/investigation + frequent finite objectives + relationship consequences + reclassification of what the case means.
