# SOURCE ROUTING — WHERE TO TAKE WHAT

A source is never “good in general”; it has a defined job.

| Source school | Take | Do not take | Use stage |
|---|---|---|---|
| John Truby | story architecture: weakness/need, desire, opponent, revelations, moral choice, climax, transformation | style, dialogue voice, ready-made plot | Architecture / Red Team |
| John le Carré | institutions, professional behavior, files, interviews, information asymmetry, career incentives, compromised self-audit | Cold War surface, Circus jargon, exact mole plot | Institution / investigation |
| Kazuo Ishiguro | self-deception, service identity, emotion displaced into procedure, subtext | formal prose voice, manor/butler surface, unsupported later arc from fragment | Character room |
| Blake Crouch — Dark Matter | identity, alternate realizations, simple human want anchoring large ontology | box/multiverse surface, Jason/Daniela plot | Ontology-to-human |
| Blake Crouch — Recursion | causality, symptom-before-mechanism, recursive consequences, origin vs symptom, correction ethics | memory-chair/timeline surface | Causality / engineered violation |
| Andy Weir — Project Hail Mary | observation → hypothesis → test → result → revised model; competence through work; discovery changes mission | science voice, spaceship/alien plot | Lore delivery / problem solving |
| Martha Wells — Murderbot | autonomy under control, operator competence, attachment through actions, capability vs control | SecUnit surface, sardonic voice | Smith/operator |
| Matt Dinniman — Dungeon Crawler Carl | finite goals, deadline, visible state change, micro-payoffs, modular arenas, transition hooks | LitRPG UI, XP, achievements, dungeon/floor surface | Audio retention |
| Jim Butcher — Storm Front | profession → case → hidden rule → investigation → local closure + mythology drip | wizard detective surface, Chicago lore, quippy first-person style | Case engine |
| Dan Brown | clue chain, physical carriers of information, complementary expertise, micro-cliffhangers | pseudo-history claims, exact puzzles, secret-society plot | Mystery / archive |
| James Rollins | fixed specialist team, artifact/expedition, historical anomaly + modern proof, multi-team convergence, institutional aftermath | Sigma characters, exact ancient-secret plots | Archive / ensemble |
| Sergey Lukyanenko — Watches | ordinary city + hidden service, field diagnosis, opposing services sharing rules, effective ≠ lawful | Light/Dark cosmology, full-arc claims from fragment | Hidden-service jurisdiction |
| Roman Prokofiev | scale, rank as access + obligation, information outranking force, multiworld practical systems | power-ladder surface, exact terminology | Long-term hierarchy scale |
| Leigh Bardugo — Ninth House | specialized hidden offices, outsider competence vs formal authority, imperfect oversight | Yale/dark-academia surface | Multi-office / review |
| Pierce Brown — Red Rising | rank embodied in work/access/body/punishment; infiltration into higher status | Colors/mines/Institute/revolution surface | Make hierarchy tangible |
| Ballard / Pelevin | unusual questions about consciousness, body, environment, social systems | voice, satire, conclusions as canon | IDEA LAB only |
| Agni Yoga / Blavatsky / Bailey / other esoteric corpus | comparative worlds, entities, hierarchy concepts, laws/limitations as external source | plot template; silent import into IVDIVO | WORLD SOURCE |
| IVDIVO corpus | authoritative IVDIVO worlds, hierarchy, status, office, initiations, powers, transitions, safety laws | replacement by external systems | CANON |

## Rule of combination
A final IVDIVO plot should normally draw:
- architecture from one craft school;
- human/character mechanism from one or more human schools;
- institution/investigation mechanism from a different source school;
- retention mechanism from a serial/audio engine;
- world rules only from IVDIVO canon.

No one reference author should dominate protagonist + plot sequence + setting + twist + voice.
