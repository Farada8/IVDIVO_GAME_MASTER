## Professional extraction protocol

1. **P0 Source integrity** — verify FULL / FRAGMENT / COLLECTION / DUPLICATE / SCAN. Never infer missing midpoint/climax/ending from a demo.
2. **P1 Source role** — every source gets one primary production job, max two secondary jobs, and a weight.
3. **P2 40-parameter passport** — structural model with explicit evidence confidence. Unsupported fields are BLOCKED, not guessed.
4. **P3 Scene map** — goal → obstacle → turn → state delta. This is not a chapter summary.
5. **P4 Mechanism extraction** — 10–25 reusable mechanisms per strong source.
6. **P5 Abstraction** — strip names, setting, signature imagery, scene order and author voice.
7. **P6 Semantic dedupe** — repeated ideas collapse into one canonical mechanism; five authors do not create five votes for the same trick.
8. **P7 IVDIVO crosswalk** — mechanism + exact canon boundary + concrete story use.
9. **P8 Story assembly** — human problem + IVDIVO rule + genre engine + 4–7 mechanisms from at least three source schools.
10. **P9 Red Team** — reject filler, exposition dumps, continuity breaks, cliches and recognizable source imitation.
11. **P10 Audio adaptation** — each 50–90 minute story gets clear local objective, meaningful state change every scene, and a new information/emotional turn roughly every 5–15 minutes.

## Normalized core mechanism families

Current normalization produces **48 canonical mechanisms** in five layers:

- `CM-001…010 HUMAN` — human want, role/person conflict, self-deception, attachment-through-action, competence, autonomy, identity coordinates, priced moral choice, subject agency, past-act reclassification.
- `CM-011…020 KNOWLEDGE` — anomaly-before-theory, experiment ladder, clue chain, procedural anomaly, physical/archive evidence, witness mini-story, reinterpretation, network reconstruction, knowledge hazard, discovery changes mission.
- `CM-021…030 INSTITUTION` — institution through procedure, oversight paradox, career incentives, multi-axis jurisdiction, offices by function, embodied status, advancement obligations, effective≠lawful, insider-outsider investigator, persistent aftermath.
- `CM-031…040 SERIAL` — finite objective, scene state delta, micro-payoffs, modular arena, local closure + open mythology, escalation through answers, solution creates exposure, resource trade-off, fixed team/new case, threshold ending.
- `CM-041…048 WORLD` — ordinary world + hidden overlay, rule at decision point, observable diagnostics, mundane grounding, transition changes constraints, old source as testable hypothesis, practical cosmological institution, attack origin rather than symptom.

## Hard assembly gates

A story is rejected if: it requires an ontology lecture before the human problem is understandable; a reveal does not change action; a moral choice costs nothing; a scene changes nothing; one reference novel dominates the structure; an external metaphysical source silently overwrites IVDIVO canon; or the episode ends without resolving its local human problem.

Evidence labels remain mandatory: `[SOURCE BOOK]`, `[IVDIVO CANON]`, `[OUR SYNTHESIS]`.
