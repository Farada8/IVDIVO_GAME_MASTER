**Status:** WORKING / LOCAL CANDIDATE / NOT VERIFIED_CURRENT

## Purpose
Convert authorized story/IP into controlled commercial product pipelines while preserving story authority, canon, rights, evidence-class integrity and quality.

This is a downstream overlay on current Writing Production + Self-Improvement v2. It is not a competing universal engine.

## Primary law
`STORY AUTHORITY > PRODUCT PRESSURE`.

State machine:
`WORKING_STORY -> STORY_GATE -> FOUNDER_LOCK/AUTHORIZED_TEXT -> PRODUCT_ELIGIBILITY -> RIGHTS_PROVENANCE -> SKU_PLAN -> FORMAT_ADAPTATION -> COST_CAPACITY -> PROVIDER_CANARY -> FORMAT_QC -> RELEASE_CANDIDATE -> RELEASE_GATE -> RELEASE -> MARKET_SIGNAL -> LEARNING -> RETAIN/ITERATE/NARROW/SUNSET`.

## Evidence classes
- STORY
- RIGHTS/LEGAL
- TECHNICAL/PROVIDER
- COST
- HUMAN QUALITY
- MARKET

No class substitutes for another. AI/model opinion is never market evidence. A dry run is never live-provider proof. A legal template is never jurisdiction-specific legal approval.

## Hard invariants
1. Founder/project authority outranks business routing.
2. WORKING text cannot masquerade as locked/release-ready.
3. Rights/provenance precedes monetizable release.
4. Reference material stays REFERENCE ONLY unless separately licensed/owned.
5. Provider spend/paid distribution/irreversible external action requires explicit execution authority.
6. `ESTIMATE != QUOTE != COMMITTED != ACTUAL`.
7. `AI REVIEW != HUMAN SIGNAL != MARKET BEHAVIOR`.
8. Market hypotheses cannot silently rewrite locked story.
9. No universal promotion before a real locked-product pilot and regression evidence.
