# 2. WHAT THE LOCAL SYSTEM ACTUALLY MEASURES

There is **no single person sensor**.

The rare occupancy/local-actuation code is generated only when several ordinary subsystems disagree strongly enough that local automation cannot resolve the state safely.

## Working signal bundle
1. **Credential / declared-presence state**
   - no registered household member or authorized visitor is logged as physically present in the affected zone.

2. **Environmental metabolic-demand pattern**
   - persistent heat/moisture/gas-exchange demand resembles an occupied biological environment rather than an idle room.

3. **Distributed low-level electrochemical activity**
   - the support installation contains living tissue/ecology with measurable electrical/chemical activity across multiple points; this is not a brain signal and not evidence of sentience.

4. **Local environmental-control requests**
   - a certified household support controller legitimately requests humidity/flow/trace-chemistry/power adjustments in response to the living ecology's state.
   - these are valid local automation requests, not a human credential and not a hacked network command.

5. **Safety-state consequences**
   - some room systems enter an occupied-protection branch because shutting down ventilation/environmental service under that signal bundle could harm a living system.

The conflict is therefore real:
`credentialed persons = zero`
while
`biological environmental demand + legitimate local support actuation = active`.

The system chooses the rare unresolved state rather than pretending certainty.

# 4. WHY LOCAL REGISTRATION DID NOT PREVENT THE INCIDENT

The support ecology is lawful and documented.
The failure is semantic interoperability, not illegal installation.

Working local history:
- housing/service registry accepted it under a broad `environmental support` equipment class;
- its imported/translated documentation correctly described required environmental conditions but the local occupancy model still treated environmental support as passive equipment;
- the controller is allowed to request local condition changes, but those requests are not attributed to a person credential;
- normally this causes no problem because a resident is physically present and all signals agree;
- when all registered persons leave while the ecology remains fully active, the disagreement becomes visible.

This can exist for years without incident because the rare code requires an unusual combination of no-person state + active support demand + specific local actuation threshold.

No conspiracy required.
