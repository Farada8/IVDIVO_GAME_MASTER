# 2. ORDINARY ENGINEERING FUNCTION

B-17 is a **modular service load-buffer cassette** used in habitat maintenance/service nodes.

Story-level function only:
- temporarily smooths short utility/load transitions when a local service node is being switched, serviced or reconfigured;
- helps keep ordinary low-consequence corridor/service equipment from dropping out during maintenance handoffs;
- is replaceable and standardized;
- is not a reactor, weapon, AI, life-support core or rare prototype;
- one cassette being removed does not endanger the habitat because the node can be placed in a normal reduced-service state or use another approved buffer when available.

Do not specify chemistry, exact stored energy, voltage, capacitance, mass or proprietary architecture unless later science needs it.

# 3. WHY B-17 MOVES

At Incident B onset, the maintenance/service room is already in an ordinary service cycle.

A worker has removed B-17 from its node because the node's scheduled maintenance requires the cassette to be inspected/replaced/reseated after an irregular health reading unrelated to the later anomaly interpretation.

Important chronology:
1. rare occupancy/local-actuation code fires in the service room;
2. local staff initially preserve the room but B-17 has already been released from the node under the existing maintenance work order / is physically in the handoff chain;
3. because nobody yet knows the rare code is material-associated, B-17 is treated as ordinary tagged service hardware and moved to the next controlled service staging point under normal documented handling;
4. the original room's rare signature later drops/ceases while the same signature appears at the staging point after B-17 arrives.

This avoids making responders foolishly move known anomalous evidence.

If exact minute ordering becomes prose-critical, preserve only this causal order; do not invent timestamps casually.
