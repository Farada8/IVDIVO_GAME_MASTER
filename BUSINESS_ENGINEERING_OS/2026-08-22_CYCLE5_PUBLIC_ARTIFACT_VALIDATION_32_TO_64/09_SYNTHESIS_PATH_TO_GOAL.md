# CYCLE5 — SYNTHESIS / PATH TO GOAL

## What Cycle5 changed
Cycle4 identified promising zero-founder-cash business archetypes from current public signals. Cycle5 tested whether those archetypes can produce **decision-changing artifacts** before outreach, spending or claims of market proof.

The architecture is now:
`PUBLIC SOURCE -> TYPED INPUT -> DECISION ARTIFACT -> UNKNOWN/FALSIFIER -> NEXT ACTION -> REGRESSION -> RED TEAM -> PA-GRADE -> REAL USER TEST`.

This is materially stronger than `signal -> idea -> generic service pitch`.

## Portfolio result
### 1. Procurement decision intelligence — PRIMARY
Why it remains strongest:
- public source data is structured and time-bounded;
- every opportunity has a concrete deadline and identifiable buyer/authority;
- a sample artifact can change a real pre-bid decision even before outreach;
- fatal criteria can be extracted from tender documents;
- the paid hypothesis can eventually be tested around saved bid effort, missed opportunities and qualification errors.

Current proof: PA3 sample on live resource 8872468.  
Next gate: full tender pack + verified supplier profile -> qualification matrix -> independent PA4 validation.

### 2. Retrofit qualification/orchestration — PILOT
Why it remains useful:
- current SEAI schemes create real workflows, grants, registered-provider dependencies and timing constraints;
- route triage can reduce confusion and unqualified enquiries.

Why it is not PRIMARY yet:
- public programme rules alone cannot determine a real property's route;
- BER/property/technical/quote/provider/cash evidence is required;
- One Stop Shops already provide a managed path, so an independent service needs a sharp wedge.

Current proof: PA3 schema/sample.  
Next gate: one real property packet.

### 3. SME AI workflow implementation — PILOT, REPOSITIONED
The original generic 'AI/digital diagnostic' hypothesis is weakened by a direct substitute: Local Enterprise Office Digital for Business is a fully funded one-to-one digital review.

The stronger hypothesis is downstream:
`POST-DIGITAL-FOR-BUSINESS IMPLEMENTATION -> workflow decomposition -> product/category selection -> configuration/migration -> staff training -> measurement -> handover`.

Current proof: PA3 fictional workflow artifact bound to current Grow Digital rules.  
Next gate: one real Digital for Business report + one real high-friction workflow.

## Three important engineering laws learned
1. **Decision artifact > generic report.** Every output must name the decision it changes.
2. **Unknowns are an output.** A useful artifact can correctly say `UNKNOWN -> next cheapest evidence`, rather than fake a score.
3. **Public support is both opportunity and competitor.** A subsidy can create implementation work while simultaneously destroying a generic advisory offer.
