# Cycle4 — Synthesis / Path to Goal

## What changed
Business Engineering OS is extended into a design-to-business production layer rather than a prompt generator:

`SOURCE -> SITE -> BRIEF -> USER JOURNEY -> COMPOSITION -> MATERIAL/LIGHT/ACOUSTIC -> BUILDABILITY -> COST BAND -> COMMISSION ROUTE -> PROOF PACK -> RED TEAM -> LEARNING`

## Three simplifications rejected by Run32
1. **One giant image prompt** — rejected. Use staged brief → composition → material/lighting → constraints → render compilation.
2. **Aesthetic-only point cost** — rejected. Use assumption-banded ranges, sources and explicit unknowns.
3. **One total project score** — rejected. Preserve Design / Technical / Market / Cash evidence axes and explicit gates.

## Proof law
`K != D != T != E`.
- K = source/reference knowledge.
- D = design/site-fit evidence.
- T = technical/buildability/maintenance evidence.
- E = buyer/market evidence.

Good references do not prove a good design. A good render does not prove buildability. Technical plausibility does not prove buyer demand. Public signals do not prove willingness-to-pay.

## Library law
Raw copyrighted sources remain private in Drive. GitHub contains only source registry/passports, hashes, provenance pointers, derived mechanisms, contracts, runtime, tests and original engine outputs.

## Self-Improvement law
Cycle4 feeds Self-Improvement only from evidence-bearing project observations. One occurrence is capture-only. Repeated defects/successes with root-cause evidence may enter candidate review; no auto-promotion.

## Next real production gate
Do not start another architecture cycle just because Next64 exists. Choose one real Irish site with dimensions/photos/access context and compile a complete Project Object. Preferred pilots:
- mural/public-art wall;
- visitor intervention with sculpture + seating + wayfinding + night lighting;
- hospitality interior with FOH/BOH, capacity, lighting, acoustics and integrated art.

Then run D/T Red Team, commission proof pack and current no-outreach public-signal scan. Measure actual rework and defects. Those measurements — not prompt count — determine the next engine change.
