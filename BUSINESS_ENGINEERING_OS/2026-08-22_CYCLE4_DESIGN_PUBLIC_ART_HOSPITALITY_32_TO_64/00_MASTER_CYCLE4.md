## Cycle4 objective
Build a real production engine for projects such as:
- murals and monumental painting;
- sculpture, memorials and monuments;
- small architectural forms and visitor infrastructure;
- public-space installations, light/sound/media art;
- hotel, bar, restaurant, office and visitor-centre interiors;
- heritage/adaptive-reuse concepts;
- Irish tourism/destination concepts;
- commercial packaging of the above into commission-ready offers.

The engine must convert an idea into a traceable project package:

`SOURCE/REFERENCE -> MECHANISM -> SITE/CONTEXT -> DESIGN BRIEF -> USER/JOURNEY -> CONCEPT -> COMPOSITION/SPATIAL SYSTEM -> MATERIAL/LIGHT/ACOUSTIC SYSTEM -> BUILDABILITY -> COST BAND -> COMMISSION ROUTE -> PROOF -> RED TEAM -> REVISION -> PORTFOLIO/PROPOSAL`.

## Non-substitution law
Four evidence planes are independent:
1. **K-proof** — source/reference knowledge and provenance.
2. **D-proof** — design quality/coherence and site-fit.
3. **T-proof** — technical/buildability/maintenance maturity.
4. **E-proof** — buyer/market evidence inherited from Business OS.

`K != D != T != E`.
A beautiful image cannot create T-proof or E-proof. A code-aware concept cannot create buyer evidence. A book mechanism cannot establish a current Irish market fact.

## Cycle4 core laws
1. Site before style.
2. Programme before decoration.
3. User journey before hero render.
4. Composition before detail.
5. One dominant visual hierarchy before multiple local attractions.
6. Viewer distance is a design input, not a final check.
7. Historical style is a mechanism bundle, not a surface filter.
8. Art integration is architectural when it changes spatial experience; otherwise label it decoration.
9. FOH and BOH flows must be modelled separately for hospitality.
10. Technical unknowns stay null/TBD; do not hallucinate dimensions, structural capacity or code compliance.
11. Coastal Irish weather, moisture, UV, wind and maintenance are first-class constraints for outdoor work.
12. Accessibility and public safety are gates, not optional polish.
13. Cost band is a range with assumptions, never fake precision.
14. Commission path and buyer class are separate from artistic merit.
15. Public-art stakeholder disagreement is preserved and routed, not averaged away.
16. Render quality is not project maturity.
17. A prompt is a compiled design instruction, not the design itself.
18. Repeated image-generation failure triggers brief/composition decomposition before more retries.
19. Raw copyrighted books remain private; GitHub stores metadata, mechanisms and provenance pointers only.
20. Self-improvement candidates require real pilot gain before promotion.

## Synthesis
The highest-value change is not “more art prompts”. It is a **design-to-business compiler** that forces every project to carry site/context, user journey, spatial/compositional logic, technical risk, lifecycle, offer route and evidence state.

The immediate bottleneck is now concrete rather than meta:

`DESIGN RAW SOURCES -> SOURCE PASSPORTS -> ONE REAL IRISH SITE -> COMPLETE PROJECT OBJECT -> D/T RED TEAM -> COMMISSION-READY PROOF PACK -> ONLY THEN MARKET TEST`.
