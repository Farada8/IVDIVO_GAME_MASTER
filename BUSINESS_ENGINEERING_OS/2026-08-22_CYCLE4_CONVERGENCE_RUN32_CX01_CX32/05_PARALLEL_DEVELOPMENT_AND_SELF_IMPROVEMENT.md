## Self-Improvement discoveries

### SI-CAND-BIZ-01 — NAMESPACE_COLLISION_GATE
**Observed defect:** independent Cycle4 branches allocated the same numeric B/C ranges to different semantics.  
**Root cause:** integer availability was treated as identity.  
**Repair:** semantic namespace reservation + collision HOLD; history preserved.  
**Retest:** executable negative canary B81/Public vs B81/Shillelagh must HOLD.  
**Status:** `ENGINEERING_CANARY_IMPLEMENTED / NOT_CURRENT`.

### SI-CAND-BIZ-02 — CONCURRENT_AUTHORITY_RESTORE
**Observed defects:** stale library authority moved 69→71→78; stale plan assumed PR #173 still awaited renamespace/merge after it had already been superseded.  
**Root cause:** write plans were not automatically invalidated by current-main/open-PR/Drive drift.  
**Repair:** fail-closed authority snapshot guard before substantial writes and closure.  
**Status:** `ENGINEERING_CANARY_IMPLEMENTED / NOT_CURRENT`.

### SI-CAND-BIZ-03 — LIBRARY_DELTA_AFTER_CYCLE_GATE
**Observed defect:** uploads can land while a cycle is being completed.  
**Repair:** closure requires prior/current count and a complete enumeration of the delta; exact-byte aliases carry zero new evidence weight.  
**Status:** `ENGINEERING_CANARY_IMPLEMENTED / NOT_CURRENT`.

### SI-CAND-BIZ-04 — DATASET_NEQ_ENGINE
**Observed defect risk:** multiple 32-object packs can look like competing engines simply because they are persisted and large.  
**Repair:** dataset persistence/size cannot create core authority; unique runtime contract + dedupe + regression + review are mandatory.  
**Status:** `ENGINEERING_CANARY_IMPLEMENTED / NOT_CURRENT`.

### SI-CAND-BIZ-05 — SOURCE_WEIGHT_NORMALIZATION
**Observed defect:** a duplicate physical book could inflate apparent evidence volume.  
**Repair:** exact byte aliases receive one evidence weight; edition/translation ambiguity remains explicit.  
**Status:** `DISCOVERY_REPLICATED_BY_LIBRARY78 / CANDIDATE`.

### SI-CAND-BIZ-06 — ROOT_WORKLOAD_DEDUPLICATION
**Observed defect:** 64 opportunity rows contain repeated buyer jobs hidden by different regulatory/sector labels.  
**Repair:** dedupe by buyer job + decision artifact, while keeping domain rules and source lineage distinct.  
**Status:** `DISCOVERY_ONLY / NEEDS PUBLIC-ARTIFACT CANARY`.
