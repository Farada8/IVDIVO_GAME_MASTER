# IVDIVO SELF-IMPROVEMENT — 32 RUN SYNTHESIS

**Date:** 2026-08-21  
**Scope:** the entire IVDIVO self-improvement system, with books and book→audio as first production priorities but not the only improvement domain.

## Executive conclusion
The 32-run pass confirms that IVDIVO already has unusually strong *governance*: authority hierarchy, fail-closed gates, project-wide continuation, evidence-class separation, cross-dialog recovery, audio source protection, candidate lifecycle, canary-before-scale and rollback concepts. The largest remaining opportunity is no longer another layer of prose instructions. It is **execution integration**.

The system needs to move from:

`MANY CURRENT FILES + LARGE PROMPTS + MANUAL NORMALIZATION`

to:

`PERSISTED STATE -> STATE ADAPTER -> OBLIGATION DAG -> ROUTER -> PROMPT/TASK COMPILER -> BACKEND/TOOL DRIVER -> GUARDS -> EXECUTION -> EVIDENCE/TELEMETRY -> TRANSACTIONAL PERSISTENCE -> LEARNING -> NEXT ROUTE`.

## Cross-dialog delta harvested during this pass
A sibling ROOM 917 E02 32→64 execution landed on GitHub while this package was being prepared. Freshness/rebase was performed before write-through. Its strongest portable discovery is an **assertion evidence-grade law**: distinguish source-explicit facts, continuity-required conditions, directorial/design inference, and unsupported claims. This independently reinforces our evidence-separation architecture and adds a new universal rule: **a useful inference must not silently become a fact just because downstream production benefits from it; when precise measurements/timestamps are unavailable, preserve semantic constraints instead of inventing precision.** This mechanism is incorporated into the 64-prompt expansion as Prompt 06.

A second concurrent Human Scene / Dialogue 32→64 research cycle added a useful **evidence-origin taxonomy**: `SOURCE_DERIVED / CORPUS_DERIVED / INFERENCE / DECISION`, plus an explicit `KEEP / STRENGTHEN / ADD / HOLD_FOR_HUMAN_SIGNAL` research disposition. This is accepted as a portable research/telemetry mechanism and reinforces Prompt 41 (Cross-Domain Evidence Map), Prompt 59 (Rule Value Audit) and Prompt 61 (Supersession/Garbage Collector). It does not import any dialogue/story content.

## Highest-value findings
1. **Evidence-backed NO-OP is a first-class success state.** A prompt must refuse to reopen solved/locked work.
2. **State normalization is the biggest orchestration bottleneck.** Current state is rich but distributed.
3. **Prompt text should become an intermediate representation, not runtime payload.** Shared laws belong in code/schema/shared boot; stage-specific deltas compile into bounded task packets.
4. **One normalized telemetry bus is missing.** Story gates, audio QC, code tests, provider canaries and human tests need a common observation/defect/repair/experiment event model.
5. **Selection itself needs staged evidence.** The audio voice audition cascade generalizes to models/tools/backends.
6. **Shared facts must be centrally bound across parallel agents/providers.** The audio musical-fact contract generalizes to cross-agent identity contracts.
7. **Consumer contracts should precede generation.** Reader/listener/user success conditions must be explicit before output.
8. **Promotion is a lifecycle, not a label.** PASS → ready for approval → applied → readback → verified current are distinct.
9. **Human/provider/market evidence needs import protocols.** AI cannot simulate it.
10. **Compaction is now as important as accumulation.** The system must shrink CURRENT context as it learns.

## Top systemic bottlenecks
- State/pointer fragmentation and Drive/GitHub freshness debt.
- Manual normalized-state creation for routing.
- Repeated universal boot text across prompt packs.
- Candidate registry write-through not yet fully transactional.
- Verified-main vs packaged-ZIP drift.

- Scarce real human/listener/provider/market evidence.
- Risk that meta-work starves books/audio.
