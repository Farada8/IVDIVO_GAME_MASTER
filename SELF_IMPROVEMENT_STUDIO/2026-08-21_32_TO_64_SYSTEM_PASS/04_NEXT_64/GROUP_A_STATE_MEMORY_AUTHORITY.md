## PROMPT 06 — ASSERTION PROVENANCE / FACT–INFERENCE CLASSIFIER

**MISSION:** Classify every consequential assertion as `SOURCE_EXPLICIT / CONTINUITY_REQUIRED / DERIVED_INFERENCE / DIRECTORIAL_OR_DESIGN_CHOICE / UNSUPPORTED`, preserve provenance, and prevent good planning choices from silently becoming facts or authority. When measurements/timestamps/coordinates are unavailable, keep plans semantic rather than inventing precision.

**INPUTS:** current authority/state; exact source/version/hash where applicable; relevant evidence/ledger; protected invariants; downstream consumer.

**EXECUTION:**
1. Restore and freshness-rebase the smallest relevant state surface.
2. Inventory consequential claims, decisions and inferred constraints.
3. Assign an assertion grade with evidence locator and downstream consequence.
4. Reject or quarantine UNSUPPORTED claims; keep design/directorial choices explicitly non-factual.
5. Where later explicit facts require an unstated intermediate condition, mark `CONTINUITY_REQUIRED` rather than pretending it was stated.
6. Replace fake numeric/absolute precision with semantic constraints until measured evidence exists.
7. Persist the classification and ensure all parallel agents/providers consume the same grades.
8. Recompute any decisions that depended on an over-promoted inference.

**OUTPUTS:** `ASSERTION_PROVENANCE_REPORT`; claim ledger; downgraded/blocked assertions; affected decisions; state delta; learning return.

**PASS:** every consequential assertion has provenance and grade, no unsupported inference is silently promoted, and downstream plans remain usable.
