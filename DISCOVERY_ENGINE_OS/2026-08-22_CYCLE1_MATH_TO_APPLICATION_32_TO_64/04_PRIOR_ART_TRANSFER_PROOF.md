## Discovery Translation Certificate v1

Candidate pipeline:

`CLAIM_ATOMS -> SOURCE_AUTHORITY -> PRIOR_ART_FEATURE_MATRIX -> TRUTH_OR_COUNTEREXAMPLE -> MECHANISM -> TRANSFER_MAPPING -> NEGATIVE_TRANSFER_GATE -> PROTOTYPE -> EXPERIMENT_AND_UNCERTAINTY -> PATENT_TRIAGE -> ENGINEERING_MATURITY -> APPLICATION_VALUE -> BUSINESS_EVIDENCE -> RED_TEAM -> CLAIM_LEDGER_WRITEBACK`.

Non-substitution:
- formal truth != scientific novelty;
- scientific novelty != patent novelty;
- patent novelty != engineering usefulness;
- engineering usefulness != market proof.

Current classification: **ENGINEERING_SYNTHESIS**. Scientific novelty remains **NOVELTY_UNVERIFIED**.

## Proof/evidence controls

- Square-law rediscovery: exact quadratic recovery, known result.
- Forest control: exhaustive through n≤5 only; bounded computation is not general proof.
- K4 counterexample rejects triangle/cyclomatic conjecture.
- Logistic-law rediscovery: exact planted law recovery.
- Bin-packing hidden shift: train winner fails hidden transfer.
- Patent exact-reference control: full feature disclosure in one reference kills novelty in the toy triage.
- Patent combination control: no single anticipating reference, but inventive step unresolved.
- Causal firewall: observational evidence remains associational.
- Self-improvement: evidence-first gate is LOCAL_KEEP only.

## Strongest supported contribution class

`ENGINEERING_SYNTHESIS + BENCHMARK/TRANSLATION PROTOCOL`.

No new theorem, scientific law, patentable invention or market-proven product is claimed in Cycle1.
