# PRIOR-ART / RED-TEAM MAP — GENESIS RESIDUAL SEARCH

## Known overlap

1. Elementary symmetric polynomials already provide canonical permutation-invariant polynomial coordinates `e1,...,en`; `SYMMETRIC_GENESIS` is therefore known mathematics.
2. Functional ANOVA / Hoeffding decomposition already decomposes multivariate functions into main effects, pair interactions, triple interactions and higher-order terms.
3. Sobol sensitivity analysis quantifies first-order, pairwise and higher-order interaction contributions.
4. Möbius inversion on the subset lattice is a general mechanism for recovering interaction contributions from cumulative set functions.

## Surviving project-specific hypothesis

The potentially useful project object is not `higher-order interactions exist`.
It is the protocol:

`promote whole -> test symmetry -> choose symmetric or subset interaction basis -> fit order k -> measure held-out residual -> stop/continue -> residual outside declared closure becomes candidate unknown -> counterexample/prior-art/domain-transfer gates`.

Current classification: `ENGINEERING_SYNTHESIS / NOVELTY_UNVERIFIED`.

## Important limitation

For dependent inputs, the classical orthogonal Hoeffding/Sobol decomposition is not uniquely available in the same form; real-data use must declare dependence assumptions or use a generalized decomposition.
