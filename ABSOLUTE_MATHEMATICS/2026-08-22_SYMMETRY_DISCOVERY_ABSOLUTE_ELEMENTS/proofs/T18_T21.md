# SYMMETRY DISCOVERY -> ABSOLUTE ELEMENT GENESIS

## T18 — Relation-type quotient by symmetry

Let G <= S_n act on the nonempty subsets B_n*.

Two formal relations have the same structural type iff they belong to the same G-orbit. Therefore the number of relation types is

N_type(G) = |B_n* / G|.

Burnside orbit counting gives

N_type(G) = (1/|G|) sum_{g in G} |Fix_{B_n*}(g)|.

For four peers:
- G=S4: 4 relation types;
- G=S2 x S2: 8 relation types;
- G=C4: 5 relation types;
- G={e}: 15 relation types.

So the number of "absolute relation types" depends on the actual symmetry group, not on n alone.

## T19 — Relation count is not intrinsic dimension

For four labeled scalar peers list all 15 nonempty square-free monomials.

Although this gives 15 formal relation coordinates, the image has intrinsic dimension 4. The singleton coordinates x1,...,x4 are part of the map, so its Jacobian contains the 4x4 identity and has rank exactly 4.

Thus:

RELATION COUNT != INDEPENDENT DEGREE COUNT.

For n scalar peers, the analogous full square-free tier has 2^n-1 formal coordinates but intrinsic dimension n.

## T20 — Three different numbers

The project must separate:

1. formal relation count: 2^n-1;
2. relation-type count under symmetry: |B_n*/G|;
3. independent state-coordinate count: intrinsic dimension/task sufficiency.

For n=4 with block symmetry S2 x S2:
- formal relations = 15;
- symmetry relation types = 8;
- four scalar invariant generators (sum/product per block) can reconstruct the two unordered blocks.

All three statements are true because they refer to different objects.

## T21 — Symmetry discovery from behavior

For a task/observable T define

G_T = {pi in S_n : T(pi x)=T(x) for all x}.

Finite random tests only produce an empirical candidate symmetry group. Exact promotion requires symbolic proof, exhaustive finite-domain verification, or an explicit domain contract.

After G_T is fixed, orbit sums provide explicit G_T-invariant relation features.

The project-specific "absolute element" compiler is therefore:

current tier
-> discover/declare symmetry G
-> quotient relation types by G
-> find sufficient invariant generators
-> verify tasks/interventions
-> promote to next-tier peers.
