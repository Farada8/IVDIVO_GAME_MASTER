## Bottom line

The original idea survives only after a major change of meaning. The strongest current object is not an 'order number' but a **Promotion Record** describing what information is quotiented, which behaviors/contexts are preserved, whether dynamics close, what micro/history information remains, what resource benefit is gained, whether the upper representation composes recursively, and whether the claimed hierarchy can be flattened.

`Absolute number` is no longer defensible as a context-free compressed scalar. If retained, it is project shorthand for a context-relative minimal autonomous predictive state class, usually only unique up to isomorphism.
