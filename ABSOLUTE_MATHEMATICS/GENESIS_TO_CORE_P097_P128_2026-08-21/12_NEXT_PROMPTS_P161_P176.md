# NEXT RESEARCH PROMPTS P161–P176

## E — Genesis Algebra and Process Grammar

### P161 — GENESIS OPERATOR SIGNATURE
Define a typed signature of genesis operators: closure, quotient, interaction, abstraction, substitution, feedback, replication and parameter instantiation. Specify domains/codomains so meaningless operator compositions are rejected.

### P162 — GENESIS REWRITING / NORMAL FORMS
Search for rewrite rules among genesis words that preserve resulting behavior. Determine whether useful normal forms exist, and construct nonconfluent examples where different rewrite paths lead to inequivalent results.

### P163 — NONCOMMUTATIVITY CATALOG
Systematically test pairs of genesis operators for commutation under stated conditions. Build a table COMMUTES / CONDITIONALLY COMMUTES / DOES NOT COMMUTE with minimal witnesses and theorem assumptions.

### P164 — SCC MODULE GENESIS
Represent cyclic genesis by strongly connected modules plus condensation DAG. Define module-level interface, internal attractor/feedback state and composition rules. Test whether SCC modularization reduces descriptive complexity without losing relevant dynamics.

### P165 — FEEDBACK COMPLEXITY
Develop complexity measures for cyclic process graphs that generalize DAG depth/width: feedback vertex set, SCC depth, internal recurrence complexity and interface complexity. Test invariance under graph refactoring.

### P166 — OPERAD / PROP / PROCESS-GRAMMAR CROSSWALK
Map the genesis grammar to operads, PROPs/properads, graph grammars and categorical process theories. Mark exact correspondences and avoid reinventing existing composition machinery.

### P167 — GENETIC EQUIVALENCE
Define W1~G W2 when their minimal genesis programs are equivalent under a declared rewrite/isomorphism system. Test whether this relation is transitive and computationally tractable in restricted finite grammars.

### P168 — GENESIS COMPLEXITY ROBUSTNESS
Evaluate K_G(W)=minimum genesis-program cost under multiple reasonable cost functions. Identify which rankings are robust and which are coding artifacts. Do not call K_G intrinsic without an invariance result.

## F — Cross-Domain Physical / Computational Validation

### P169 — ISING PREDICTIVE STATE DISCOVERY
Stop hand-selecting domains/walls/memory. Infer predictive states directly from coarse Ising histories and compare them to field, regime and latent-memory coordinates. Test whether predictive-state discovery yields stronger closure.

### P170 — LEARNED STOCHASTIC FIELD GENERATOR
Model coarse Ising dynamics with drift plus a learned non-Gaussian spatiotemporal residual process. Validate ensemble structure factor, coarsening scale, magnetization distribution and long-horizon statistics. Separate known Model-A physics from framework validation.

### P171 — CELLULAR AUTOMATON BLIND FACTOR SEARCH
Hide the Rule-90 factor map and search a restricted class of local spatial coarse maps and time rescalings. The Reactor must rediscover the exact factor and reject nonfactors. Then move to harder CA rules.

### P172 — EXACT / QUASI-LUMPABLE MARKOV SUITE
Generate random finite chains with planted exact and epsilon-quasi-lumpable partitions. Infer the partition from trajectories, estimate closure defect with uncertainty and measure false-positive/false-negative rates.

### P173 — LTI MINIMAL REALIZATION SUITE
Generate systems with controllable/observable and hidden redundant modes. Recover minimal realization order from input-output data and test uniqueness up to similarity. Use as an exact benchmark for state minimization.

### P174 — NONLINEAR REALIZATION CONTROL
Use analytically tractable nonlinear systems with known minimal realization/observability properties. Test whether the Promotion framework extends beyond LTI without silently assuming linear identifiability.

### P175 — NETWORK BISIMULATION / AGGREGATION
Apply behavioral equivalence and Promotion to finite transition networks/MDPs with known bisimulation quotients. Include intervention/action contexts so passive and active equivalences can be compared.

### P176 — RENORMALIZATION-GROUP CROSSWALK
Compare project Promotion chains to renormalization/coarse-graining flows. Identify where RG provides more structure (scale transformations, fixed points, universality) and where the project asks different questions (state sufficiency, resource/generative rise, admissibility depth).
