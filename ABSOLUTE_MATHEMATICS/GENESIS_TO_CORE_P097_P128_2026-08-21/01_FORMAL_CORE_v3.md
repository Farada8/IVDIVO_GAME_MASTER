# ABSOLUTE MATHEMATICS — FORMAL CORE v3.0

## 0. Scope

This is a research framework, not an established new mathematical field.

Its surviving target is to study when a lower-level representation can be replaced by a smaller, behaviorally adequate, dynamically reusable representation under explicit contexts, operations and resource/admissibility constraints.

## 1. Primary object: PROMOTION RECORD

A Promotion candidate is not a scalar "order".

Use:

\[
\mathfrak P=(B,\mathcal K,\mathcal A,E,\Gamma,D,\epsilon,\tau,C,M,G_\mu,R,F,N).
\]

Where B is lower→upper map; K admissible observation/intervention contexts; A admissible transformations/compositions; E behavioral/predictive equivalence; Gamma upper effective generator; D dynamic/compositional closure defect; epsilon,tau tolerated defect/horizon; C compression/resource cost; M residual memory/history dependence; G_mu extra micro-information gain; R recursive upper-level usability; F flattenability; N generativity/novelty type.

## 2. Exact Promotion

Deterministic: `B∘F_micro = F_macro∘B`.

Algebraic: `B(f(x1,...,xn)) = fbar(Bx1,...,Bxn)`.

Stochastic: macro state must preserve the declared conditional future/intervention law.

## 3. Approximate Promotion

Use horizon-indexed defect, not one-step fit alone:

`D_tau(B,Gamma)=E[d(B F^tau x, Gamma^tau Bx)]`.

Always pair local defect with stability/Lipschitz information.

## 4. State discovery

Primary comparator: histories are equivalent when they induce the same future law, or controlled-test analogue. This merges with causal-state / predictive-state theory. Hand-designed domains, walls, latent memory and regime variables are candidate coordinates, not privileged ontologies.

## 5. Minimal autonomous state

`Z* = argmin_Z C(Z)` subject to low history gain, low micro gain, bounded closure defect, plus recursive/ensemble fidelity in the declared context family. This is explicitly context- and model-class relative.

## 6. Rise taxonomy

- R-Rise: representational quotient/compression.
- Resource Rise: same extensional closure, improved reach under a cost budget.
- G-Rise_L: generator extension relative to a declared definability language L.

Never infer G-Rise from quotienting or compression.

## 7. Hierarchy

Intrinsic count of Promotion steps is rejected. Define `Ord_A(x,y)` only relative to an admissibility class. If A is composition-closed, finite endpoint depth flattens to 1. Use an Order Spectrum across independently justified admissibility classes.

## 8. Genesis

Genesis is not generally a DAG. Use directed process graph; SCC decomposition for feedback modules; condensation DAG; noncommutative genesis words / rewriting grammar. Operator order matters: `Q∘C != C∘Q` in explicit controls.

## 9. Boundary evidence

Never accept a boundary because one detector has an optimum. A boundary record must include detector, null families, selectivity, geometry matching, temporal evidence, scale robustness, failure controls and context/admissibility sensitivity.

## 10. Permanently rejected shortcuts

1. Numeral base change = new mathematical order.
2. Compression = Promotion.
3. Prediction on one target = primitive.
4. Natural-looking domain/interface = primitive.
5. Pure quotient = G-Rise.
6. Promotion-step count = intrinsic order.
7. Large spectral gap = objective hierarchy.
8. More compression = more memory universally.
9. Context-free canonical compressed absolute number in general.
10. Reactor must always return a finite upper state.

## 11. Absolute-number replacement

If historical terminology is retained, use only `A^(dyn)_(K,A)(W)` as a chosen minimal representative of a behaviorally sufficient autonomous state class. It may be unique only up to isomorphism, not coordinates. The term is project terminology; underlying ideas overlap established predictive-state, minimal-realization, quotient and coarse-graining theories.

## 12. Remaining project-specific research residue

Potential value remains in a unified falsifiable protocol combining predictive/contextual equivalence; algebraic/dynamic closure; micro/history sufficiency tests; resource vs genuine generativity; recursive reuse; admissibility-relative non-flattenability; cross-domain benchmark calibration; and automatic Red-Team rejection of false order boundaries.

The next phase must test whether this integrated Promotion Record adds mathematically useful results beyond existing theories, rather than merely collecting them under new names.
