# SOURCE MAP — P225–P256

1. Littman & Sutton — Predictive Representations of State (NIPS 2001).
https://papers.nips.cc/paper_files/paper/2001/hash/1e4d36177d71bbb3558e43af9577d70e-Abstract.html
Supports action-conditioned predictive state representations and the fact that predictive state can be lower-dimensional than nominal POMDP state.

2. Taxonomy for similarity metrics between Markov decision processes.
https://link.springer.com/article/10.1007/s10994-022-06242-4
Supports state abstraction, bisimulation and MDP homomorphism framing.

3. Buchholz — Exact and ordinary lumpability in finite Markov chains.
https://www.cambridge.org/core/services/aop-cambridge-core/content/view/2DC748F09D80BEEB03CCF18036E149D7/
Supports exact/ordinary lumpability and near-lumpability model reduction.

4. Proportional lumpability and proportional bisimilarity.
https://link.springer.com/article/10.1007/s00236-021-00404-y
Restates ordinary lumpability as equality of aggregate transition rates from equivalent states.

5. Markov Chain Order estimation with Conditional Mutual Information.
https://arxiv.org/abs/1301.0148
Supports CMI-based Markov-order diagnostics and significance calibration.

6. Minimal LTI realization result / uniqueness up to similarity.
https://citeseerx.ist.psu.edu/document?doi=800390d84248f81085cf6f8d12cf556e2bee736c&repid=rep1&type=pdf
Supports minimal iff controllable/observable and minimal realization uniqueness up to similarity.

7. Communication Complexity lecture notes / deterministic Equality lower bound.
https://theory.stanford.edu/~tim/w15/l/w15.pdf
Supports deterministic communication lower bound of n bits for Equality.

8. Causal-state minimal sufficient predictive statistics.
https://pmc.ncbi.nlm.nih.gov/articles/PMC2849313/
Supports causal states as minimal sufficient predictive representations.

These sources sharply limit novelty claims for state abstraction/minimal prediction.
The possible project-specific residue remains the integrated Promotion falsification protocol and its joint semantic/dynamic/construction/generativity bookkeeping.
